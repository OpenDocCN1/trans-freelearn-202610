The People section in the New Event dialog box has two sub-sections: Assignee and Owner. In the Assignee sub-section, you can assign the event to one or more users. Subsequently, you can assign people from this group of users to individual tasks as you create the tasks. By default, the person who creates the event is set as Owner of the event, but this might be another person. So, you are provided with the option to change the event owner to ensure that the notifications are addressed to the right person--to the real task owner, not the creator.

+   11. Click on the Select Assignee icon, and select users (A) from the Select Users screen.
