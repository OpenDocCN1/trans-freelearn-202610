# Setting preferences

You can change the look and feel of your agenda by applying custom formatting attributes through the Preferences dialog box, which you can access by clicking on the Preferences icon ( 🔧 ) on the toolbar.

In the Preferences dialog box, you can change the name of your agenda (A). The name you set here is referenced throughout the Digital Boardroom. You can also add a thumbnail image (B) for visual recognition.

![](bbox=[0.31, 0.3, 0.69, 0.59])

In the Meeting Settings section, you can set the Presentation Mode by selecting whether to show the agenda or jump right into the first sub-item. From the Online Meeting Session list, you can choose whether to start the meeting in the same window as the Digital Boardroom or in a new window.
