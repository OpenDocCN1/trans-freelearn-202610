# Viewing calculated measures in data view

At any time, when you're working on a story, you can select the arrow under Data View (A) to switch between the explorer and your story pages. For now, click on this arrow to hide the story page and show the data view panel.

Note that the two measures Net Revenue and Gross Margin % (B) you created in the previous exercises have been added to the measures list.
