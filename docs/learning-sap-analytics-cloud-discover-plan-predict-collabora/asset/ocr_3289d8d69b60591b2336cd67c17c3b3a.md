# Signing up for the trial version

I know that most of you will purchase this book to evaluate SAP Analytics Cloud and will not have access to a live SAP environment. The good news for you is that you can explore the platform using most of the exercises provided in this book by signing up for a free thirty-day trial. Note that the trial version doesn’t allow you to access all the features of SAP Analytics Cloud. For example, you cannot create a planning model in the trial version nor can you access its security and administration features. Execute the following steps to get access to the free SAP Analytics Cloud trial:

+   1. Put the following URL in your browser's address bar and press enter: http://discover.sapanalytics.cloud/trialrequest-auto/.
+   2. Enter and confirm your business email address in relevant boxes.
+   3. Select No from the Is your company an SAP Partner? list.
+   4. Click on the Submit button. After a short while, you will get an email with a link to connect to SAP Analytics Cloud.
