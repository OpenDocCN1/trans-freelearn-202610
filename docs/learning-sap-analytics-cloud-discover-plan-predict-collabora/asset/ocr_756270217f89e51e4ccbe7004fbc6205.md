# Deleting a model

The delete icon on the toolbar lets you delete a model and all its data:

![](bbox=[0.41, 0.19, 0.59, 0.22])

However, this option is available to user roles that have the privileges to delete models.

![](bbox=[0.09, 0.28, 0.16, 0.33])

> *Note that you cannot delete models that are currently in use. Stories are dependent on models, so if you try to delete a model used in a story, the name of the story is displayed and the delete operation is aborted.*

Use the following set of steps to delete a model:

+   1. Go to main menu | Browse | Models.
+   2. Use the check box beside the model you want to delete. Note that you can select multiple models and delete them at once.
+   3. Click on the Delete icon on the toolbar.
