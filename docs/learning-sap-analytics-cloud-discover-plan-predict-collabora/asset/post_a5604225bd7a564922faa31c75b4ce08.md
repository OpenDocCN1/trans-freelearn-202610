## Creating calculated and restricted measures with input control

You went through the process of creating some calculated measures in the previous exercises through the Calculation Editor interface. In this exercise, you will create both the Calculated and Restricted Measures with Input Control. By adding the Restricted Measures to your chart or table, you can use only selected values in a measure that helps you compare one value to a set of others. Using the input controls, you define some values that act as variables in your Calculated Measures. By selecting these values in an input control, a user can influence the result of a calculation without modifying the underlying data or formula. For example, when you add a list of predefined values for an input control, the users can select different values from this list to see the impact on their canvases.
