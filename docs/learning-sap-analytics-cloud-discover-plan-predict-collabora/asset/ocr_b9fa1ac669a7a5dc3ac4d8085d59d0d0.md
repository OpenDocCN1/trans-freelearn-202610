The Tile Settings section lists options for charts and other objects. Here, you can set different backgrounds and texts for your different page objects. In the Chart/Geo section, you have an additional option to set color palettes. In addition to a range of default color settings, you can also create your own palette (G). Even after specifying these default styling options, you can override these preferences for your page objects in the Designer panel.
