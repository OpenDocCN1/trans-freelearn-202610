# Testing the effects of page filters on a table

You used story and page filters in Chapter 5, *Extending Filters with KPI, Filters and other Handy Objects*, to narrow down the scope of your analysis. In that chapter, you applied these filters to charts. In this exercise, you will see how a page filter affects a table. In order to see accurate results, you have to modify the sorting order you set in Step 32.

+   35. Click on the Net Revenue link displayed in the title area of the table to see the Edit Value Sorting window.
+   36. In the Edit Value Sorting window, click on the edit link to modify the sort value.
+   37. In the *Select* member for Date dialog box, switch the sort value from Q1 to 2016 and click on OK. The selected value will appear in the *Edit Value Sorting* dialog box (A). Click on OK to dismiss this dialog box.
