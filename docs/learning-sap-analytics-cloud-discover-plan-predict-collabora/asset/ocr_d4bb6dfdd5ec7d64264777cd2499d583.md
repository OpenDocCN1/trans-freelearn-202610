# Optimizing the display

As just mentioned, you first need to create an agenda for the Digital Boardroom meeting. But before that, you have to optimize the display and navigation for Digital Boardroom.

Execute the following steps to set up the stage:

+   1. With your story open, click on the Styling tab in the Designer panel.
+   2. Turn on the Fix Page Size switch.
+   3. Set Width to 1920 pixels. This is the optimal width for each story page displayed in the Digital Boardroom.
+   4. Place check marks in the two checkboxes to select the Continuous Height and Snap to Nearest Grid options:
