# Gross margin percentage numeric point chart

This is the third Numeric Point chart that will show the Gross Margin percentage. The chart will be based on a calculated measure that will be assessed using an Account measure from the model and the Net Revenue calculated measure, which was created in a previous exercise. To render the derived value in an appropriate format, you will scale this calculated measure as percentage.
