# Creating a geomap with a bubble layer

Models that include latitude and longitude information can be used in stories to visualize data in geomaps. By adding multiple layers of different types of data, we can show different geographic features and points of interest, enabling us to perform sophisticated geographic analysis. In this exercise, we will create a geomap based on the BestRun_Demo model, which is already geo-enriched.
