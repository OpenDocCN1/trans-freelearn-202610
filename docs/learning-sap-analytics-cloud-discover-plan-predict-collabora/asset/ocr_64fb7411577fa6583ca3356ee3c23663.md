# Displaying and monitoring events and tasks

To monitor is to check on how events and tasks are progressing. Using the monitoring feature of SAP Analytics Cloud, you can observe the activities taking place in the created events and assigned tasks. It helps you keep an eye on all aspects of the project. When it comes to displaying and monitoring the events and tasks you have created, SAP Analytics Cloud provides you with the following three options:

+   - **Calendar**: This is the default view in which the events and tasks are presented in a standard calendar layout
+   - **Gantt**: In this view, the events and tasks are presented in a bar chart with the start and due dates
+   - **Timeline**: This provides a linear view of the process

Click on the Gantt View option to switch to this view from Calendar View, which is set by default.
