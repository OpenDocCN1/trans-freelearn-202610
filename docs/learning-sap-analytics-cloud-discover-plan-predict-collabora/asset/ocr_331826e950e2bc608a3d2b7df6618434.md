# Formatting a measure

After creating the `Gross Margin %` calculated measure, you will format the result of this calculation:

+   42. Open the Formatting window for the calculation by clicking on the ellipsis icon in the Builder tab and selecting Format from the menu.
+   43. In the Formatting window, you can set the scale, decimal places, and unit. For this example, set Scale to Percentage, Decimal Places to 2, and Unit to %. Click on OK after setting these parameters:

![](bbox=[0.34, 0.32, 0.66, 0.74])

+   44. Click on the Conditional Formatting icon to add a threshold for the `Gross Margin %` measure.
+   45. Click on the Add Threshold link. As you can see, the two thresholds you created earlier are also visible in the Conditional Formatting panel.
+   46. Set the three ranges according to this illustration.
