Because we are moving the character based on fractions that could have rounding issues, we allow for a small threshold value in deciding whether George is near enough to the touched location, and if he is, we stop the animations. So, let's continue inside this code block and add the check for the threshold:

```
double threshold = 1.0;
var difference = targetLocation - position;
if (difference.x.abs() < threshold &&
    difference.y.abs() < threshold) {
    stopAnimations();
    movingToTouchedLocation = false;
    return;
}
```
