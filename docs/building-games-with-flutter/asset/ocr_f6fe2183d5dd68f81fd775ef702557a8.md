+   10. Under this, we need to add our main function to initialize the game and the screen:

```
void main() async {
final goldRush = GoldRush();
WidgetsFlutterBinding.ensureInitialized();
await Flame.device.fullScreen();
await Flame.device.setPortrait();
runApp(
GameWidget(game: goldRush)
);
}
```

Here, we set up our `GoldRush` game object (which we will define next) and told Flame that we want to run the game in full screen and in portrait mode.
We also ran the app, passing the `GameWidget`.
