of the SAS/STAT procedures. On the other hand, PROC NLMIXED can be generalized to the case of ordinal markers as well, as we will see in Chapter 5, so there is a value in adopting PROC NLMIXED as the primary choice of SAS/STAT procedure for modeling ROC curves.

Now we can model the covariates jointly. Consider a binary marker W first:

```
T = α₀ + α₁D + α₂W + e^{2β} ε
```

which implies

```
T = { α₀ + α₁D + e^{2Dβ} ε,   W = 0
      α₀ + α₂ + α₁D + e^{2Dβ} ε,   W = 1 }
```

These two equations represent the basis for the ROC curves for the two markers implied by the model. Notice that the coefficient of D is the same for both ROC curves. In fact, the two equations differ only in their intercept. Therefore, the implied binormal parameters, a and b, are the same.

You can conclude that adding the covariate as a main effect only does not result in two ROC curves being modeled separately.

Now consider the following:

```
T = α₀ + α₁D + α₂W + α₃DW + e^{2βD} ε
```

which produces the following submodels for W=0 and W=1:

```
T = { α₀ + α₁D + e^{2βD} ε,          W = 0
      (α₀ + α₂) + (α₁ + α₃)D + e^{2βD} ε,   W = 1 }
```

These two submodels generate two different ROC curves since the coefficient of D differs by a factor of α₃.

Specifically for W=0

```
a = α₁ / (e^{β} σ₀²),   b = e^{β}
```

and for W=1

```
a = (α₁ + α₃) / (e^{β} σ₀²),   b = e^{β}
```

Note that if α₃=0, the ROC curves for the two markers are identical.
