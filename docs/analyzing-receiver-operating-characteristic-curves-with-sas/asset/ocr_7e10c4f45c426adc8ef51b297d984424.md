Once θ is estimated, the ROC curve is completely specified and summary measures such as the AUC can be computed. Using the functional form of the Lehmann family of ROC curves, you can compute an estimate of the AUC as

AŪC = ∫ x^θ dx = 1 / (1 + θ̂)

and the variance of the AUC estimate is given by

V(AŪC) = V(θ̂) / (θ̂ + 1)^4

All the required components are again available from PROC PHREG output. You can also form pointwise confidence bands for ROC curves using the standard error of x^θ:

V(y(x)) = [x^θ̂ log x]^2 V(θ̂)

Using the Lehmann family for ROC curves is studied in detail by Gönen and Heller (2007). ROC curves given by y = x^θ have been studied in the literature; see, for example, Hanley (1988). Their derivation using a Lehmann family and implementation using Cox regression procedures have been made explicit by Gönen and Heller (2007).

# 6.3 Magnetic Resonance Example

Zajick et al. (2005) reported a study on using chemical shift magnetic resonance in differentiating normal, benign, and malignant vertebral marrow processes. The marker of interest was the percent difference between the in-phase and out-phase signal intensities. The article focused on establishing a range of values for signal intensity change in normal vertebral marrow. Here, we use their data for a different objective: evaluating the ability of signal intensity change in discriminating between normal and benign vertebral marrow processes.
