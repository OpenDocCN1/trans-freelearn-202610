# 4.4.2 Comparisons with Unpaired Data

In theory, the %ROC macro can only compare the AUCs of two predictors if the data are paired. Because unpaired designs are so uncommon in the field of ROC curves, no macro performs the desired comparison. Fortunately, unpaired comparisons are easy to be performed by hand or by a few lines of DATA step code: If AUC₁ and AUC₂ are the two AUC estimates with associated standard errors s₁ and s₂, then the test statistic for the unpaired comparison is as follows:

T = (AUC₁ - AUC₂)² / (s₁² + s₂²)
