估计方程的一个吸引人的特点是该方法基于回归模型，因此协变量调整在原则上和实现上都是微不足道的。例如，以下对 PROC PHREG 的调用拟合了一个年龄调整模型，同时考虑了每个患者有多个椎体骨髓过程的事实：

```
proc phreg data=ph covs(aggregate);
    model signal=grp age grpage / rl;
    id name;
    if group='normal' then grp=0;
    else if group='benign' then grp=1;
```

## 6.6 使用 Lehmann ROC 曲线族比较标记

第 5 章探讨了使用回归模型比较两个或多个 ROC 曲线的想法。主要思想是在回归模型中包含标记类型的指示变量。对于双正态模型，适当的回归模型是异方差正态回归。对于 Lehmann 族，适当的回归模型是比例风险回归，正如我们在第 6.3 节中已经看到的那样。

具体来说，设 U 为指示变量，对两个不同的标记或预测因子取值为 0 和 1。然后，遵循第 6.3 节的逻辑，你可以写出以下方程：

```
h(V | U, D = 1) / h(V | U, D = 0) = exp{β₁ + β₃U}
```

该模型与第 4 章和第 5 章中在双正态模型背景下的模型相似。它在形式上也与第 6.2 节中考虑的模型完全相同，其中 U 表示年龄，一个连续协变量。因此，PHREG 语句也完全相同，这里不再重复显示。

如果 β₃ = 0，则两个 ROC 曲线相同。因此，可以通过检验 H₀ : β₃ = 0 来进行正式比较。PROC PHREG 输出中 readily 可用的 Wald 检验可用于此目的。从操作角度来看，比较两个标记的 ROC 曲线与比较不同年龄组的 ROC 曲线没有区别，因此第 6.4 节中描述的步骤也适用于此。

标记比较可能与协变量比较不同的一个潜在重要方面是，正如我们在第 4 章中讨论的那样，配对设计是大多数涉及多个标记比较的研究中数据收集的主要形式。之前的模型在用偏似然估计时隐含假设观测是独立的。但第 6.4 节表明，使用估计方程方法拟合回归模型可以让你在数据相关时获得适当的标准误差估计。配对数据是相关数据的特例，前一节概述的边际模型方法可用于在存在配对数据的情况下拟合模型。

## 6.7 Lehmann ROC 曲线族的优点和缺点

随着单个预测因子 ROC 曲线的非参数方法的出现，你不需要使用双正态模型或 Lehmann 族。这些基于模型方法的实用性只有在考虑更复杂的问题时才会变得明显，例如协变量调整或相关数据。

与任何基于模型的统计方法一样，Lehmann ROC 曲线族的性能直接取决于数据生成过程被 Lehmann 假设近似的程度。如果有强有力的证据表明数据遵循 Lehmann 假设，则本章讨论的方法是适当且优选的。在这些条件下，ROC 曲线的常见统计任务，例如协变量调整、多个标记的比较以及使用聚类数据的分析，都可以使用 PROC PHREG 处理，这是 Lehmann 族的一个主要优势。

尽管尽最大努力验证或排除 Lehmann 假设，数据可能既不强烈偏离也不强烈支持 Lehmann 假设。虽然没有替代仔细和专业的统计分析，但你应该考虑 Lehmann 族和竞争方法的优点和缺点。Lehmann 族的主要优点是其简单的函数形式，使结果易于解释并获得洞察，以及软件的可用性。主要缺点是其灵活性不足：使用单个参数，可能无法容纳经验上明显的 ROC 曲线形状。

## 7.1 引言

在许多应用中，二元结果事件并非立即可观察。例如，大多数信用评分算法试图预测到某一时间点的违约概率。如果数据集中每个受试者在至少到该时间点仍在观察中，则结果是真正二元的，我们迄今看到的方法适用。但可能不希望等待所有受试者的结果都被观察到。可以进行时间-事件分析，用违约发生前的经过时间替代是/否违约。这种分析的优点是可以容纳受试者之间不同的随访时间。虽然它不如等待所有受试者达到预设时间那样有力，但通常可以更快完成，且效率损失通常很小。

## 7.2 肺癌示例

肺癌是最常见和致命的癌症之一。其预后受两个因素 heavily 影响：肿瘤大小和淋巴结受累。使用这些因素，你可以预测死亡的可能性并据此计划进一步治疗。这些因素最好在手术中切除的肿瘤标本上测量。然而，在手术前准确描述预后有相当大的兴趣。第 3 章描述了来自正电子发射断层扫描（PET）扫描的标准化摄取值（SUV）。在本例中我们将研究 SUV 作为肺癌死亡率标记的准确性。本分析的目标是看看 SUV 是否能预测手术后肺癌患者的生存。由于 SUV 在手术前可用，如果它具有合理的预测价值，将具有重要的实际意义。

本研究的的数据集有三个变量：SUV、Survival 和 Status。Survival 是手术到死亡之间经过的时间。对于分析时仍存活的患者，它代表手术到最后随访之间的时间。Status 是一个二元变量，表示患者在最后联系时是死亡还是存活。如果 status=1，则患者死亡，Survival 变量是实际生存时间。如果 status=0，则患者存活，Survival 是随访时间。这些患者被称为删失，因为我们没有观察到他们的生存时间。

这种数据结构是删失数据的典型形式，它立即揭示了所需统计分析的复杂特征。结果（即生存时间）以特定方式由两个变量（Survival 和 Status）组合表示。此外，对于部分患者，实际结果未被观察到。传统的统计方法不能直接应用于 Survival 变量来推断生存时间。例如，Survival 变量的中位数会低估实际中位数，因为它把删失患者的随访时间当作实际生存时间处理。

因此，删失数据的分析需要特殊方法。由于删失数据在临床研究中无处不在，更不用说工程可靠性（设备故障时间）和金融（违约时间）等其他领域，这些特殊方法已被广泛研究。本章使用了两种更受欢迎的删失数据方法。一种是生存时间分布的 Kaplan-Meier 估计，另一种是比例风险（Cox）回归。我们在上一章中已经使用了 Cox 模型，尽管是从完全不同的角度。

严格来说，了解本章几乎不需要关于删失数据的先验知识，但要掌握细节而没有一些经验是困难的。Paul Allison 的 Survival Analysis Using the SAS System: A Practical Guide（1995）或 Alan Cantor 的 SAS Survival Analysis Techniques for Medical Research, Second Edition（2003），两者都是 SAS Press 出版的书籍，对此目的有帮助。

## 7.3 带删失数据的 ROC 曲线

我们反复强调生成 ROC 曲线需要二元结果。如果 W 是预测因子，D 是二元结果，你可以写

P(W > c | D = 1)
P(W ≤ c | D = 0)  (7.1)

来表示对应于某个阈值 c 的灵敏度和特异性。我们在第 3 章中看到，这两个概率可以用 W 的条件分布表示，并且它们构成了经验 ROC 曲线的<|message|>。

在生存模型背景下，结果是事件发生（例如死亡或违约）为止经过的时间。这可以被视为随时间变化的二元结果。方程（7.1）现在被替换为

P(W > c | D(t) = 1)
P(W ≤ c | D(t) = 0)  (7.2)
