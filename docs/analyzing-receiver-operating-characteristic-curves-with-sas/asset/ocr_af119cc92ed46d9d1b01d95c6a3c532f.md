The more important use of the CONTRAST statement here is to test the equality of the two ROC curves in their entirety. Note that two binormal ROC curves are identical only if they have the same binormal parameters. Therefore, comparing a and b for two or more binormal curves offers one way of testing whether the two curves are identical. This is accomplished by the following CONTRAST statement:

```
contrast 'Equality of ROC curves' a1-a0, b1-b0;
```

which tests the null hypothesis

H₀ : a₀ = a₁  &  b₀ = b₁

against the alternative that at least one of the binormal parameters is different. Note that it is not possible to express this using an ESTIMATE statement.
