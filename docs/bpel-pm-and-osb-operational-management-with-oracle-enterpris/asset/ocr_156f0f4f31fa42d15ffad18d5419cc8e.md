# Comparing BPEL process versions for the same process

Grid Control can provide target comparisons for different target types. One of the more interesting comparisons in the BPEL world is to compare successive versions of a BPEL process, or similar BPEL processes on different environments. Grid Control enables the administrator or developer to do just that, thereby assisting with change management and impact analysis.

+   1. In our current scenario, we will compare two versions of the same BPEL process on the same server.
+   2. Click the Compare BPEL Process Manager breadcrumb.
+   3. Click on the Processes tab.

![](bbox=[0.14, 0.34, 0.86, 0.75])

> Notice the differences in the processes across the two targets. You can see that newer versions of the BPEL processes are available for FlowSample, AmericanLoan, and UnitedLoan.

+   4. Click on the greater than sign for the FlowSample process.
+   5. This takes you to the compare process page where you can compare different versions of the process.
