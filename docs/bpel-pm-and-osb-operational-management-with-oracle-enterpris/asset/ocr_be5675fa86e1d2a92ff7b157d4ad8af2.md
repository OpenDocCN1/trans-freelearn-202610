# Viewing the infrastructure availability definition

This is similar to viewing the definition for the service availability except the underlying component availability is used to measure availability rather than service tests.

+   1. Click on the **Monitoring Configuration** tab.
+   2. Click on the **Availability Definition**.

> Note the basis for determining availability based on system components. By default, all components are set to "key" components. A "key" component is used to determine availability. Non-key component data is also collected historically, but is not used for availability determination.

3. Click on **Cancel**.
