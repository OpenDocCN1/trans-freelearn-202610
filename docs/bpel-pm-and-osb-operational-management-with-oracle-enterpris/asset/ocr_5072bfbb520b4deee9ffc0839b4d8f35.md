> Availability can be defined based on Service Test or System. Further, availability can be defined based on up/down status as well as usage metrics. Service Test-based availability can be defined as the status of one or more recorded web transactions as tested by one or more agents (Beacons). System-based availability is determined on the status of the underlying system components—either all or one component can be up based on the requirement.
