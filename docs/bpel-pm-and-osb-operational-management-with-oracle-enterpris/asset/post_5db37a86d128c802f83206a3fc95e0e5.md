## Summary

Configuration management is critical for administrators to control change within the environment and troubleshoot problems associated with changing configurations. With Grid Control's configuration management capabilities, administrators can manage change and reduce time to troubleshoot problems.

In this chapter, we discussed configuration management and how it applies to BPEL PM and the application server target. We discussed the configuration overview for both target types, looked at the most recent configuration information, and saved a reference "gold" configuration snapshot to the Grid Control repository. Then we proceeded to make a few configuration changes via the individual product consoles. It was fairly simple to observe these changes in Grid Control, as well as compare the changes with the "gold" standard. Further, it was also useful to compare BPEL process versions and note the changes across successive versions.

Configuration management has been extended with Enterprise Manager's acquisition of two new products, namely **Configuration Change Console (CCC)** and **Application Change Console (ACC)**. With these two products, administrators can view changes actively as they happen, as well as roll back and roll forward to a desired configuration.
