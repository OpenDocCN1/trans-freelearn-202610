5. You will now be taken to the Usage Metrics screen, as seen in the next screenshot. Usage metrics measure user demand for your service. You can define usage metrics based on the metrics of one or more system components. Once you've added metrics, you can define thresholds, which, when exceeded, will generate alerts. You can also select the metric whose graph you want to show in the home page for this service.
