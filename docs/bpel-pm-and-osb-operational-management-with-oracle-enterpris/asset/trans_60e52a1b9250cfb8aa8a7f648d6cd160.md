## 关于作者

**Narayan Bharadwaj** (aka Nadu) 在企业软件市场涉足了多个不同的领域。他拥有超过十年的经验，工作涉及服务导向架构、系统管理等多种分散技术。其他技术领域包括云计算、数据库、中间件和 IT 管理软件。在涉足这些技术期间，Narayan 扮演了多个角色——从软件顾问、数据库管理员、应用开发人员到产品经理。在此之前，他就读于马里兰大学和印度理工学院哈格布尔分校，攻读各种技术学位。认为这还不够，他又获得了加州大学伯克利分校哈斯商学院的 MBA 学位。

Narayan 在美国加州红木岸的 Oracle USA Inc 工作了近十年，担任中间件和服务导向架构产品管理的集团产品经理。在应用与系统管理产品部门任职期间，Narayan 推动了诸如实时用户监控、Java 应用诊断、中间件管理以及服务导向架构管理等新市场的发展。这包括了 Moniforce、ClearApp 和 AmberPoint 等关键收购。最近，Narayan 已移居旧金山的云端，负责 Salesforce.com 在云管理与云数据分析方面的平台战略和执行。他与妻子和两岁的儿子住在加州圣马特奥。

当他不通勤上班、追求学位或扮演不同角色时，Narayan 喜欢在羽毛球或网球场挥拍，打排球，或偶尔跑一次半程马拉松。

> 我不断受到我生命中两位女性的启发——我的母亲和我的妻子。感谢你们一直陪伴在我身边。

## 关于审阅者

**Hans Forbrich** 是 Oracle 社区中知名成员。他于 1984 年开始使用 Oracle 产品，并一直紧跟 Oracle 几乎所有核心技术。作为 ACE 负责人，Hans 受邀在 Oracle Open World 以及世界各地的 Oracle 用户组会议上演讲。他的公司 Forbrich Computer Consulting Ltd. 在加拿大西部已建立良好声誉。Hans 专注于通过 Oracle University 以及 Exit Certified 等合作伙伴提供 Oracle University 培训。

尽管他的特别兴趣包括 Oracle Spatial、OracleVM 和 Oracle Enterprise Linux，但 Hans 对 Oracle SOA、Oracle WebLogic 和 Oracle Grid Control 的进步尤为兴奋。

Hans 曾为多本 Packt Publishing 书籍担任技术审阅者，包括 "Mastering Oracle Scheduler in Oracle 11g Databases"、"Oracle 10g/11g Data and Database Management Utilities" 和 "Oracle VM Manager 2.1.2"。

> 我要感谢我的妻子 Susanne，以及埃德蒙顿歌剧院，在我进行这些审阅以及我自己的书籍工作时给予的耐心。

**Hector R. Madrid** 是 "Oracle 10g/11g Data and Database Management Utilities" 书籍的作者。他目前担任自由顾问；他与 Oracle University 合作，担任 DBA、Java 和应用服务器课程的认证讲师。他是一位备受尊敬的 Oracle 专业人士，拥有 20 年的全职 DBA 经验。他处理从日常 DBA 任务到与任务关键型和高可用性系统相关任务的各种 DBA 需求。他是拉丁美洲第一位 Oracle 认证大师。他获得了墨西哥自治都会大学的计算机科学硕士学位，并在多场 Oracle 会议上发表过技术论文。

> 我要感谢我的家人，在审阅本书期间给予的耐心和我借用的时间。

**Arvind Maheshwari**，Oracle Enterprise Manager 开发团队的高级软件开发经理，专注于为中间件构建管理解决方案。他在 IT 行业拥有超过 15 年的经验，曾在金融、制造和电信行业担任开发人员、顾问、架构师和技术经理的角色，开发部署在高可用性架构中的企业解决方案。

**Matt Wright** 是 Rubicon Red 的董事，这是一家独立咨询公司，帮助客户通过采用服务导向架构、业务流程管理、云计算等新兴技术实现企业敏捷性和运营卓越。

Matt 拥有超过 20 年构建企业级分布式系统的经验，他在 SOAP 1.1 于 2000 年提交给 W3C 后不久就开始涉足 SOA，并自 BPEL 于 2002 年首次发布以来就与一些早期采用者合作。此后，他参与了 EMEA 和 APAC 地区一些最早的基于 SOA 的实施。

在 Rubicon Red 之前，Matt 在 Oracle 担任过多个高级职位，最近担任亚太区 Oracle Fusion Middleware 产品管理总监，负责与组织合作，帮助他们在解决复杂业务问题时充分发挥 SOA 的业务效益。

作为 SOA 的公认权威，Matt 是私人及公开活动的常客演讲者和讲师。他也喜欢写作并运营自己的博客 (http://blog.rubiconred.com)。Matt 拥有伦敦大学帝国理工学院计算机科学工程学士学位。
