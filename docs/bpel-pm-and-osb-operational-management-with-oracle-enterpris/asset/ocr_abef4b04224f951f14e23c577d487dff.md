> Beacons are Grid Control agents configured to emulate end-user behavior by running recorded Service Tests. Frequently, these are deployed outside the firewall to test applications from an end-user perspective. Beacons are deployed where users are located, typically one per geographical segment. Beacons help to break down the end-user time into network time and server time, which helps to isolate user-related problems.
