# Viewing key system metrics

Grid Control's default system views capture the key metrics for the system and display it for the administrator.

+   1. Click on the Back button on your web browser to go to the System home page.
+   2. Click on the Charts sub-tab.

> Note the key metrics for the system components graphed on this page. A dropdown is provided to change the time range of the graphs. The set of metrics to display on this page is configurable.
