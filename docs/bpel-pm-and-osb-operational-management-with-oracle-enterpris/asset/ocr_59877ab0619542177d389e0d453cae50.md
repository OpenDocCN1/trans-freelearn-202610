# Recording a web transaction as a Service Test

Once the web application target type has been created, we can start to record end-user-type web transactions using an inbuilt recorder:

+   1. On the **Service Test** step, fill in the following fields as shown in the next screenshot:
+      - Select a Service Test name as **Order Submission Test**.
+      - Select the radio button for **Record a transaction**.
+      - Click on **Go**.
