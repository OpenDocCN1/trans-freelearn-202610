# Navigating to the OSB target home page

Once the WebLogic and OSB components are discovered, it is useful to visit the OSB target home page and observe useful monitoring-related information.

+   - Click on the **Oracle Service Bus target name** hyperlink.

> > On the Oracle Service Bus target home page you will see the availability status of the OSB server, Availability % (last 24 hours), Oracle WebLogic Server Domain, Version, and Host.
