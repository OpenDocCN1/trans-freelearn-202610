# Testing the SOAP tests

Once the SOAP tests have been created, Grid Control provides the capability to run any of the SOAP tests on demand to test the availability and performance of the underlying service.

+   1. Click on one of the SOAP tests that you've created.

> The test page shows the test availability, Beacons that run this test, and alerts associated with this test. The graph shows the test response times from the beacon. Note that the test metrics will take some time to show up on the test home page. One or more Beacons could be used to test the service, potentially from multiple geographic locations that emulate the user base.
