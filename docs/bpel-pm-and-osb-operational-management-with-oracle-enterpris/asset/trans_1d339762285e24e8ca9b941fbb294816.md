
## 书中应包含的内容

本书详细介绍了如何在生产环境中设置和自动化各种对 Oracle SOA 产品平稳运行至关重要的操作任务。它将通过逐步练习引导您，帮助管理员从单一基于 Web 的控制台管理这些产品。它将使管理员免于执行单调、耗时且重复的任务。

## 书中不会包含的内容

本书避免对 SOA、BPEL 或 Service Bus 进行解释说明。如果您想使用 JDeveloper 等工具开发 BPEL 和 OSB 服务，本书并非合适的选择。此外，除第一章外，本书也避免讨论 Grid Control 产品的基础问题，如下载和安装。

## 本书涵盖内容

引言章节包含其他章节的前提基础信息。您可以根据需要，按需深入阅读其他章节，具体取决于您希望完成的目标。所有章节均定义了问题陈述，并附有提供的解决方案摘要。解决方案本身是对如何完成特定任务以解决问题进行的逐步讲解。

本书分为三个部分。第一部分涵盖使用 Grid Control 管理 BPEL Process Manager。第二部分侧重于 SOA Suite 的整体管理。第三部分涵盖 Oracle Service Bus 的管理。

第 1 章《Grid Control、BPEL 和 OSB 概述》对 Grid Control 进行了基础介绍，包括下载、安装和基本配置。这是提供从单一控制台管理各种目标的基础设施的基础技术。

## I：BPEL 管理

第 2 章《发现 BPEL PM》讨论 BPEL Process Manager 目标的发现和配置。将 BPEL PM 作为 Grid Control 管理的目标进行发现是在执行其他管理任务之前的第一步。

第 3 章《BPEL 流程监控》讨论查看已部署的 BPEL 流程及其构成的合作伙伴链接。随后讨论如何使用指标和合成测试的组合来监控 BPEL 流程和合作伙伴链接。

第 4 章《BPEL 基础设施管理》描述如何管理底层基础设施组件，如 BPEL Process Manager 服务器、脱水数据库、应用服务器、主机等。管理员可以按组管理多个不同的系统，从而减少检测系统相关问题根本原因所需的时间。

第 5 章《BPEL 服务级别管理》描述如何为 BPEL 流程、合作伙伴链接设置服务级别期望，并通过各种指标跟踪这些级别。这使服务提供商能够监控与服务消费者约定的合同保证。

第 6 章《BPEL 服务仪表板》说明仪表板对于可视化关键服务的服务级别性能和指标的重要性。本章还逐步讲解如何构建一个简单的仪表板，以显示所有关键服务及其主要指标，包括服务级别。运营团队通常使用此方法随时关注服务，并在偏离预期 SLA 时采取行动。

第 7 章《BPEL 部署自动化》说明 BPEL 工件的部署是一项重复且耗时的任务。本章描述如何以自动化方式将 BPEL 工件部署到多台服务器。这确保部署以无错误的方式进行，并减少整体计划停机时间。

第 8 章《BPEL 配置管理》描述如何管理 BPEL 基础设施的配置设置，包括设置基线和进行比较。这有助于诊断因配置更改导致的问题，并使企业范围内的配置标准化。

## II：SOA Suite 管理

第 9 章《SOA Suite 克隆》讨论克隆是一项需要深入产品专业知识的复杂管理任务。本章逐步讲解一个简单场景，将现有 SOA Suite 从一个实例克隆到另一个实例。管理员可以使用此方法以标准化、无错误的方式执行关键且耗时的任务。

第 10 章《Web 应用监控》描述如何使用 Grid Control 服务模型、SLA 规则和合成测试设置和监控 Web 服务。Web 应用也可以被监控——包括记录和回放 HTTP(s) 事务以排查问题。应用管理员可以从最终用户角度主动监控应用。

## III：WebLogic 和 Oracle Service Bus 管理

第 11 章《WebLogic 和 OSB 目标的发现》讨论从单一控制台管理多个 WebLogic 域和 OSB 实例的问题，这是中间件管理员经常遇到的问题。中间件管理员可以使用单一控制台管理所有安装、执行复杂的管理任务，并深入各自的 WebLogic 或 OSB 控制台执行管理活动。所有这些使管理员能够标准化管理任务，从而使 WebLogic 和 OSB 服务器的行为标准化，导致正常运行时间增加。

第 12 章《OSB 部署自动化》讨论将 OSB 项目和资源部署到多个域可能繁琐且耗时。本章逐步讲解典型的部署场景以及如何使用部署流程框架对其进行自动化。这使基础设施团队能够标准化部署，并集中跟踪和管理工件。
