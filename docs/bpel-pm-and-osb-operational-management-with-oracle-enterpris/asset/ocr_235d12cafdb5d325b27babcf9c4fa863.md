# Viewing system components

Viewing the system components lets the administrator figure out what is part of the system, and what affects the overall availability of the system.

+   1. Click on the **Components** tab.

> This page displays all the components of this system. An "and" or an "or" relationship between the system components availability determines the availability of the system itself.
