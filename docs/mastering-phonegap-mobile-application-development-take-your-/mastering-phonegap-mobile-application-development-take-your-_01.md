# 简介

PhoneGap/Cordova 作为一种创建混合移动应用的技术，严重依赖 JavaScript、HTML 和 CSS 来向用户展示应用。这在许多方面都是理想的，特别是因为您可以利用现有的 Web 技术知识来创建跨平台移动应用。能够基于现有知识构建应用是推荐 Cordova 的一大优势，通常使用 Cordova 构建第一个简单应用非常容易。但当涉及构建更大、更复杂的应用时，探索各种技术和工具以更高效地开发移动应用就显得很有用。本书前几章正是专注于这一需求。我们将介绍 Gulp 等任务运行器、Browserify 等打包工具，以及使用 Sassy CSS 编写更易维护 CSS 的方法。

在本书中，我们通常将 PhoneGap 和 Cordova 统称为 Cordova——PhoneGap 本身是 Cordova 的一个发行版，并提供额外的功能和实用程序。如果有特定差异需要提及，我们将在适当的时候说明。

大型复杂应用的一个显著特征是需要高效存储复杂数据的方法。当使用 Local Storage 和 File API 变得笨重难用时，了解其他数据存储方法就变得很重要，例如 IndexedDB 和 Web SQL Database。通常，应用也需要在设备和外部服务器之间传输大量数据。您可以想象，社交摄影应用可能需要上传图片，电子书应用则需要下载代表书籍的文件。我们也将专门用一章来探讨这一主题。



# 前言

当然，大多数开发者都希望让他们的应用进入尽可能多用户的设备中。这就是为什么创建无障碍应用很重要。并非每个用户都拥有完美的视力。一些用户可能难以阅读小字体或低对比度的文本。其他用户可能难以辨别各种色调。还有一些用户可能听不清您应用的声音。借助许多移动平台上的辅助技术，构建应用以便尽可能多的用户能有效地使用它们是一个非常好的主意。

部署最终是我们的目标，因此本书的后半部分将专门讨论这一点：如何为应用创建启动画面和图标，如何创建发布版本，以及最终如何将应用部署到各个应用商店。

在此过程中，我们还将涉及其他概念，例如可用于使应用的用户界面适当响应其运行所在的各种设备形态的技巧。您还将找到可以验证应用是否按预期工作的工具，以及关于如何查找和修复性能问题的技巧。

读完本书后，您希望能具备必要的知识，以应对大型、更复杂且无障碍、高性能、响应式的应用开发。

在本书中，我们将重点关注 iOS 和 Android 平台。然而，Cordova 支持许多其他平台。一般来说，本书涵盖的大部分内容也适用于这些其他平台。不过，书中使用了一些第三方插件。如果您确实想支持另一个平台，您需要验证是否有相同或类似的插件可用。

## 章节概览

- 第 1 章，*任务自动化*，向您介绍自动化常见开发任务的过程，包括将文件以各种方式复制和转换作为构建步骤的一部分。各节具体涉及创建一个可扩展的构建系统，该系统可以转译 JavaScript、自动压缩代码、执行 `cordova` CLI 任务，并对代码进行 lint 检查以捕获语法错误。

- 第 2 章，*ECMAScript 2015 和 Browserify*，简要介绍了 ECMAScript 2015 及更高版本中的许多新特性，包括字符串插值、对象解构、命名参数和默认参数、词法绑定函数等。本章还介绍了 Browserify 作为一种打包您自己的代码并复用其他 JavaScript 开发者优秀代码模块的方式。

- 第 3 章，*Sassy CSS*，向您介绍 CSS 转译器的世界，特别是 Sassy CSS 语言。具体而言，本章涵盖变量、嵌套和混入，所有这些都使编写可读且可维护的 CSS 代码变得更加容易。

- 第 4 章，*更多响应式设计*，重点介绍可用于创建能适当响应各种设备形态的混合应用的步骤和特性。本章探讨逻辑像素和物理像素、重要的 CSS 单位、媒体查询、图像尺寸调整，以及使用弹性盒模型设计复杂但响应式的用户界面。

- 第 5 章，*混合应用无障碍*，探讨您作为开发者可以使用的各种方法，使您的应用对可能需要帮助查看、听取或使用应用内内容的用户具有无障碍性。

- 第 6 章，*测试与 UI 自动化*，解决了确保我们构建的应用实际功能正确的切实需求。本章向您介绍测试概念以及各种自动化测试工具。最后，本章探讨如何自动化用户界面，作为在真实设备上测试的另一种方法。

- 第 7 章，*IndexedDB*，向您介绍一种除 Local Storage 或 File API 之外的持久化存储方法。本章涵盖如何创建新的对象存储、保存、检索和搜索数据等内容。

- 第 8 章，*Web SQL 数据库*，向您介绍关系型数据库以及如何在 Cordova 中使用第三方插件来使用它们。本章重点介绍如何使用 SQL 存储和检索数据。

- 第 9 章，*传输文件*，涵盖如何从外部服务器将内容下载到您的应用，以及如何从您的应用上传内容并将其传输到外部服务器。

- 第 10 章，*性能*，讨论您可以用来检查应用在真实设备上运行情况的方法，并提供可用于在必要时提高性能的技巧。

- 第 11 章，*图形资源*，讨论如何为您的应用创建启动画面和图标。本章提供关于如何创建令人难忘的图标和良好的启动画面的技巧。

- 第 12 章，*部署*，逐步向您展示如何为 Google Play 市场和 Apple App Store 创建开发者账户，以便您将应用部署到全球。创建账户后，本章将指导您完成上传应用图形资源、定义元数据，最后上传应用本身的过程。
