# 简介

PhoneGap/Cordova 作为一种创建混合移动应用的技术，严重依赖 JavaScript、HTML 和 CSS 来向用户展示应用。这在许多方面都是理想的，特别是因为您可以利用现有的 Web 技术知识来创建跨平台移动应用。能够基于现有知识构建应用是推荐 Cordova 的一大优势，通常使用 Cordova 构建第一个简单应用非常容易。但当涉及构建更大、更复杂的应用时，探索各种技术和工具以更高效地开发移动应用就显得很有用。本书前几章正是专注于这一需求。我们将介绍 Gulp 等任务运行器、Browserify 等打包工具，以及使用 Sassy CSS 编写更易维护 CSS 的方法。

在本书中，我们通常将 PhoneGap 和 Cordova 统称为 Cordova——PhoneGap 本身是 Cordova 的一个发行版，并提供额外的功能和实用程序。如果有特定差异需要提及，我们将在适当的时候说明。

大型复杂应用的一个显著特征是需要高效存储复杂数据的方法。当使用 Local Storage 和 File API 变得笨重难用时，了解其他数据存储方法就变得很重要，例如 IndexedDB 和 Web SQL Database。通常，应用也需要在设备和外部服务器之间传输大量数据。您可以想象，社交摄影应用可能需要上传图片，电子书应用则需要下载代表书籍的文件。我们也将专门用一章来探讨这一主题。
