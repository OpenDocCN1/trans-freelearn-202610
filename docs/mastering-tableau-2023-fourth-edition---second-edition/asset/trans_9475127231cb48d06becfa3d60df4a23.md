
此外，可能会出现特殊的制图需求，要求为地图上通常不包含的区域绘制多边形。例如，组织可能会定义不遵循常规地图边界的销售区域。最后，可能会出现自定义图像的制图需求。Tableau 制作者可以将篮球场或足球场的图像导入 Tableau，并绘制多边形来表示比赛区域的特定部分。要为这些示例中的每一个创建填充地图（Tableau 本身不提供多边形），必须创建自定义多边形。

### 在零岛周围绘制正方形

在本节中，我们将从基础开始，在传说中的零岛周围绘制一个简单的正方形，零岛位于本初子午线和赤道的交汇处。

我们将进阶到一个更稳健的示例，该示例要求为德克萨斯州的每个城市绘制多边形。Tableau 中有一个选项，允许制作者对未知位置 `Show Data at Default Position`（在默认位置显示数据）。选择此选项将导致 Tableau 将所有未知位置的纬度和经度坐标设置为 0（零），从而在世界地图上非洲西海岸外 1,600 公里处创建一个标记。Tableau 开发者亲切地称该区域为零岛。

零岛甚至有自己的 YouTube 视频：[https://youtu.be/bjvIpI-1w84](https://youtu.be/bjvIpI-1w84)。

在此练习中，我们将在零岛周围绘制一个正方形：

1. 在 Excel 中重新创建以下数据集：

| | **A** | **B** | **C** |
|---|---|---|---|
| **1** | **点** | **纬度** | **经度** |
| **2** | 0 | -1 | -1 |
| **3** | 1 | -1 | 1 |
| **4** | 2 | 1 | 1 |
| **5** | 3 | 1 | -1 |
| **6** | 4 | -1 | -1 |

2. 将数据集复制并粘贴到 Tableau 中。这样做会出现一个名为 `Clipboard_...` 的新数据源：

![](Images/B18435_08_34.png)

图 8.34：零岛坐标

3. 从工作表中移除所有字段。

4. 将 `Point` 转换为维度。这可以通过右键单击 `Point` 并选择 `Convert to Dimension`（转换为维度），或将其拖动到 `Data`（数据）窗格的维度区域来完成。

5. 双击 `Latitude` 和 `Longitude`。顺序无关紧要；Tableau 会自动将 `Longitude` 放在 `Columns`（列）货架上，将 `Latitude` 放在 `Rows`（行）货架上。

6. 选择 `Map`（地图）| `Background Maps`（背景地图）| `Streets`（街道）。您可能需要稍微缩小一点才能看到陆地边界：

![](Images/B18435_08_35.png)

图 8.35：定位零岛

7. 将视图类型更改为 `Line`（线），并将 `Point` 拖放到 `Path`（路径）货架上。您应该会看到以下结果：

![](Images/B18435_08_36.png)

图 8.36：定位零岛 II

8. 返回 Excel 文件，交换包含点 1 和点 2 数据的行，并再次将数据复制到 Tableau 中。

9. 按照 `Steps 2–7`（步骤 2-7）操作并观察生成的图像：

![](Images/B18435_08_37.png)

图 8.37：错误勾勒零岛

这个有趣但不正确的图像是由于点顺序不正确而产生的。根据经验法则，在确定点顺序时，选择一个如果您亲自绘制多边形时合理的顺序。如果您无法使用给定的点顺序在纸上绘制所需的多边形，Tableau 也无法做到。

您可能会发现，在 Tableau 中完成此练习相对容易。挑战在于获取正确的数据，特别是多边形点。一个用于生成多边形数据的有用（且免费）工具可以在 [http://powertoolsfortableau.com/tools/drawing-tool](http://powertoolsfortableau.com/tools/drawing-tool) 找到。这是 InterWorks 创建的众多工具之一，有助于解决常见的 Tableau 挑战。

### 使用多边形创建交互式书架

我自己不太擅长绘画，但我一直喜欢在 Tableau Public 上看到的那些花哨的多边形背景，它们形状各异，并且能够让 Tableau 与它们交互、根据度量为它们着色，或将操作链接到特定区域。例如，您知道大陆可以重塑为鸡的形状吗？Niccolo Cirone 利用多边形制作了一个 Tableau 仪表板：[https://www.theinformationlab.co.uk/2016/06/01/polygons-people-polygon-ize-image-tableau/](https://www.theinformationlab.co.uk/2016/06/01/polygons-people-polygon-ize-image-tableau/)。

您也想构建花哨的仪表板，但绘画技巧平平，就像我一样？别担心！本节将为您提供工具，无论如何都能实现它。InterWorks 开发了一个类似于数字填色游戏的工具——这是一个无需自己过多绘制即可构建多边形的完美应用程序。您可以在这里找到它：[https://cbistudio.interworks.com](https://cbistudio.interworks.com)。您只需找到一张图片，将其上传到工具中，然后开始沿着线条绘制。

对于此练习，我在互联网上搜索了一张书架的图片。您可以做同样的事情，为该练习找一张图片，或下载我使用的图片，可在此处下载：[https://github.com/PacktPublishing/Mastering-Tableau-2023-Fourth-Edition/Chapter08/bookshelf.png](https://github.com/PacktPublishing/Mastering-Tableau-2023-Fourth-Edition/Chapter08/bookshelf.png)：

1. 打开来自 InterWorks 的免费绘图工具并选择 `Images`（图像）选项：

![](Images/B18435_08_38.png)

图 8.38：CBI Studio

2. 上传您的图片，并在 `I’M CREATING`（我正在创建）部分选择 `Polygon`（多边形）。

3. 现在从一本书的边缘开始点击。将出现一个橙点。现在转到同一本书的下一个边缘并再次点击。将沿着书的该边缘绘制一条线，坐标会自动出现在右侧的列表中：

![](Images/B18435_08_39.png)

图 8.39：绘图工具

4. 一本书的最后一个点应该位于第一个点（比其余点大）的上方。再次点击第一个点将完成第一个多边形，这由绿色指示：

![](Images/B18435_08_40.png)

![](Images/B18435_08_41.png)

![](Images/B18435_08_42.png)

图 8.42：书店
