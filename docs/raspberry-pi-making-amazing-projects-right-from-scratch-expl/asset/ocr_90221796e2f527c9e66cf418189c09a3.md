Before you can access OpenCV with the Raspberry Pi camera, you'll need to do two things. First, you'll need to add a Python library; it is called `picamera`. To get this, and the required libraries, type `sudo apt-get install python-picamera python3-picamera python-rpi.gpio`. Second, you'll need to type `sudo modprobe bcm2835-v412`. The Raspberry Pi camera can now be used in the OpenCV examples in the next section.
