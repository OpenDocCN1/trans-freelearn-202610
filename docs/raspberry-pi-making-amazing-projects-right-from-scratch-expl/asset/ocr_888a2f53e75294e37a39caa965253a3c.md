First, we print the status of the counter, and then we execute the all() function, which will refresh all the LEDs and ensure that they are turned off at the beginning. Then, we actually show the pattern that we set in the earlier statement via the show() function. Finally, we increment the counter and add a delay of 100 milliseconds.

This pattern gets repeated for every LED, and when done in quick succession, it appears like the spokes are cycling.
