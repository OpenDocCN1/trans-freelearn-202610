# 第 1 部分：RPA 的重要性

在本部分中，我们将讨论 **机器人流程自动化 (RPA)** 的重要性，以及如何利用它来支持自动化之旅。本节的主要目标是更好地理解自动化背后的概念，以及为确定最适合自动化的流程而需考虑的因素。这是任何自动化项目中最重要的方面。此外，我们还将着重了解 UiPath 的整个生态系统，以便开始深入探讨。

在本部分中，我们将介绍以下章节：

- 第 1 章：自动化之旅与识别合适的业务流程
- 第 2 章：UiPath 生态系统
- 第 3 章：UiPath Orchestrator 简介
- 第 4 章：在 UiPath 生态系统中创建、部署和执行 RPA 流程
