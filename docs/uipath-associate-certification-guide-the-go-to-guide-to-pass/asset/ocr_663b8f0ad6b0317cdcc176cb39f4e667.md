In addition to this, the `name` tag looks for a specific invoice number. Locate the name tag within the selected items section and uncheck it. This action will remove the name tag from the selector so that the selector can handle any open document. Once the change has been applied, the selector will look similar to Figure 11.14:

14. The next change is to make the name tag dynamic to capture any invoice number in documents that have the same layout and structure. We can introduce a wildcard character instead of the invoice number in the name tag. The name tag should be configured as follows: name = 'invoice *'.
