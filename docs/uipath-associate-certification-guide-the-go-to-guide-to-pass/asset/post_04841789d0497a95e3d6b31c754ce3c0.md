
No matter whether it is a desktop application or a web application, the Basic recording generates full selectors, which means there are no separate containers generated, such as **Attach Browser** or **Attach Window**. Therefore, this recording is the _slowest_ and most suitable for single activities within containers or for linear workflows.

## When to use which types of recording?

Let's discuss the different types of available recordings, their usage, advantages, and disadvantages, as shown in Figure 10.50:

| Recording Type | Usage, Advantages, and Disadvantages |
|---|---|
| Basic | • Best suited for linear workflows where not many windows or web pages are involved.<br>• It is the slowest type of recording.<br>• Can automate desktop and web applications.<br>• SimulateType / SimulateClick is not enabled (False) by default. |
| Desktop | • Suitable for all types of desktop applications where multiple windows and web pages are involved.<br>• Generates partial selectors for each activity.<br>• It is faster than the Basic recording. |
| Web | • Best suited for recording web applications where multiple pages and actions are involved.<br>• Generates partial selectors for each activity (for example, Attach Browser).<br>• It is faster than the Basic recording.<br>• SimulateType / SimulateClick is enabled (True) by default. |
| Image | • Only use it if you want to record virtualized environments (such as Virtual Networking Computers, virtual machines, and Citrix) or SAP.<br>• It allows only image, text, and keyboard automation, and requires explicit positioning. |
| Native Citrix | • Only used in native Citrix automation projects.<br>• As a prerequisite, you need to install the UiPath Citrix extension on the client machine and the UiPath Remote Runtime component (Citrix XenApp) on the application servers.<br>• You can use activities such as Click, Type Into, Get Text, and Extract Data.<br>• Selectors are natively generated for Citrix application elements. |
| Computer Vision | • It uses computer vision neural networks to identify UI elements such as buttons, texts, and checkboxes.<br>• It does not use selectors.<br>• Used to record virtualized environments (such as VNC, virtual machines, Citrix, and remote desktops).<br>• Automating local applications where the other mentioned recording options are not reliable. |

Figure 10.50 – Different types of recordings and their uses
