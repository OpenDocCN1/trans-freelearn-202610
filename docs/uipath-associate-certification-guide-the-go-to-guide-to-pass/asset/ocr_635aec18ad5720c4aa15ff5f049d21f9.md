# 3. Configure the Get Outlook Mail Message properties

Click the Get Outlook Mail Message activity to view the Properties panel. In the Input section, enter the Outlook account email address in the Account field (1) and the corresponding MailFolder (2) from where you will be accessing the email. Now, it is time to filter the expected emails from the Options section using the Filter field (3), where you need to enter the sender's email address. Alternatively, you can use Subject, or any other email parameters, to filter the emails. Enable the OnlyUnreadEmails option (4) and enter the Top field as 10 (5) to read the top 10 unread emails.
