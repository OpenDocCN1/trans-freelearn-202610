+   3. Save the Excel file in a folder that can be used as the input for our process.

+   4. Open the Main.xaml file in UiPath Studio.

+   5. Drag and drop an Excel Application Scope activity and configure the Workbook Path property by giving the file path to the Excel file you created.

The Excel Application Scope activity has a DO sequence within it. This is where you place all the activities that you need to perform on the Excel file. Place a Read Range activity within the DO sequence by dragging it from the Excel App Integration section of the Activities panel.
