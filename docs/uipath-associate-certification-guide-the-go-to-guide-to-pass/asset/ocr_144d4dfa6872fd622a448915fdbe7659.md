5. Program a robot to upload the following details to the Orchestrator queue:

+   - Customer Details
+   - Invoice Particulars

6. Repeat steps 4–5 for the remaining invoices.

7. Program the robot to successfully end the process if all the attachments downloaded from the mail in step 2 are processed.
