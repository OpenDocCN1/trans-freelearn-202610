# # Create, Deploy, and Execute RPA Process on the UiPath Ecosystem

Once your robots have been created and assigned to processes, you are faced with the task of how to manage all their actions. This is where Orchestrator comes into the picture – it helps you to manage multiple robots in one place.

As part of this chapter, you will create a robot and establish a connection between your local machine robot and UiPath Orchestrator. Then, you will create your first robotic process automation (RPA) process in UiPath Studio, publish it to Orchestrator, and deploy the process. And finally, you will learn how the processes can be executed using UiPath Assistant and attended automation.
