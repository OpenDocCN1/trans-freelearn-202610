+   2. **Indicate Element**

This is used to select the new UI targets or to *overwrite* the previously selected targets on the screen.

+   3. **Repair**

This button is enabled when the selector is *invalid* and is used to *repair the existing selector* by indicating the same target UI element on the screen.

+   4. **Highlight**

This button is used to *ensure* that the modified selector is still *valid* for the target element. Once clicked, the target element will be highlighted on the screen.
