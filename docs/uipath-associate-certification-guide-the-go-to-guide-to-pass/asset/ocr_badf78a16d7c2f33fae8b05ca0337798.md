+   4. Program a robot to enter the following details on the **Order Entry CRM** web page:
+   * Customer details
+   * Invoice particulars

+   5. Repeat Steps 2, 3, and 4 for the remaining queue items.

+   6. Program the robot to successfully end the process if no new queue items are present in Orchestrator.
