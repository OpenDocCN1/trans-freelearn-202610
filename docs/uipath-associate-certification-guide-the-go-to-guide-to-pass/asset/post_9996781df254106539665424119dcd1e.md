## What are flowcharts?

**Flowcharts** are used in project settings where the business processes are complex and have multiple decision points. Flowcharts support multiple logical branching using various types of activities such as **If/Else**, **loops**, and **switches**.

For example, you can create a flowchart that takes input information, such as `Year`, from a user through an **Input Text Box** and verify whether it is a leap year. In this example, it can have two possible outcomes. One is *leap year*, while the other is *not a leap year* based on the input provided. Let’s look at an example.
