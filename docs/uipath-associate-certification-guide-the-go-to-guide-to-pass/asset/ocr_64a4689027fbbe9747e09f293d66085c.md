+   - **Get Queue Items**: Retrieves all the queue items that have the defined status in the activity.
+   - **Wait Queue Item**: Waits for a transaction to be available in the queue for processing and sets its status to In Progress.
+   - **Bulk Add Queue Items**: Allows the user to add a set of items to the queue at one time. All added items will have a New status.
+   - **Delete Queue Item**: Used to delete specified items with the New status.
