Now that you have downloaded the CRM, let's start building the automation:

+   1. In UiPath Studio, open the Main.xaml file.
+   
+   2. Drag and drop the Open Browser activity from the **Activities** panel into the **Designer** panel.
+   
+   3. Next, click on the **Properties** panel of the Open Browser activity and type in Environment.CurrentDirectory+"\CRM\Order Entry.html" underneath **Url**.
+   
+   4. Choose **Chrome** as the **BrowserType** option:

![](bbox=[0.133, 0.301, 0.863, 0.623])

Figure 15.7 – The Open Browser activity

+   5. Drag and drop the Maximize Window activity inside the Open Browser activity. This will ensure that the Order Entry CRM web page always opens up in a maximized window.
