Follow these steps to create your second automation process:

+   1. Launch UiPath Studio and navigate to the home view by clicking on the **HOME** tab.

+   2. Click **Process** in the **New Project** section to create a new project. The **New Blank Process** window is displayed:

![](bbox=[0.182, 0.208, 0.818, 0.602])

Figure 4.30 – A new process creation

+   3. Enter a suitable name for the project and select a drive location to save the project. Note that the project name cannot exceed 128 characters, and the description cannot exceed 500 characters.

+   4. Click **Create** after entering all the details. The new project is opened in Studio.
