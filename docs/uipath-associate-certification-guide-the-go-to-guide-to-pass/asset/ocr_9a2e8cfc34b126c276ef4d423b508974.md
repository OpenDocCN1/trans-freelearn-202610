# Processing the queue

In this section, you will read transaction items from the queue and enter them into the
Order Entry CRM web page.

Let's start by building the workflow:

+   1. Create a new Flowchart workflow with the name of Read_From_Queue.

+   2. Next, drag and drop a Sequence activity, rename it to Fetch transaction
