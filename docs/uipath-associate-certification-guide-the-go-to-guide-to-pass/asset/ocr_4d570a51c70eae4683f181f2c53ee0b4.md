# 4. Create an app password in Google

Next, you need to create an app password to use in UiPath Studio for accessing your Gmail to connect to IMAP. To perform this, create an app password by going to https://myaccount.google.com/apppasswords. Click the GENERATE button (shown in Figure 12.16) and copy the generated password that will be copied inside UiPath activities in the upcoming steps.

Select the app and device you want to generate the app password for.
