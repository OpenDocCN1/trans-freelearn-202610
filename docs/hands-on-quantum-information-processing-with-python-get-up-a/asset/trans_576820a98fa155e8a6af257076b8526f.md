

量子系统与环境的相互作用可能会导致一些需要纠正的错误。自 1990 年代以来，已经提出了大量量子纠错技术。

目前，尚未实现完全成熟且高度可扩展的量子计算机。然而，较小的量子计算机已经开始构建。这些中小规模的量子计算机通常不使用一些复杂的纠错技术，被称为噪声中等规模量子（NISQ）计算机。NISQ 计算机通常用于小规模量子计算，因为它们仍然不具备纠错能力。因此，NISQ 计算机主要用于展示量子计算的某些有限能力，因为它们不是全规模量子计算机。

## 量子游戏的设计

除了量子密码学和量子计算之外，QIP 的另一个子领域是量子游戏的设计。在传统安排中，博弈论关注冲突环境中的理性决策。量子博弈论将传统博弈论推广到量子领域。与其他 QIP 子领域一样，量子游戏利用量子现象，尤其是纠缠，作为资源，其目标是超越其经典对应物。

## pipenv 和创建环境

Python 包可以使用 pip 等安装工具进行安装。在某些情况下，可能有必要将某些 Python 包与主 Python 安装分开。这样做的原因可能包括避免安装冲突并保护主 Python 安装免受不稳定包的安装。用于以此意义隔离主 Python 安装的工具示例包括 `virtualenv` 和 `venv`。

通常，为了管理 Python 包和依赖项，会使用不同的 Python 库。例如，`pip` 用于包的安装、更新和卸载，而另一个工具如 `venv` 用于管理虚拟环境。这些包通常单独使用。这在实践中使得 Python 项目的管理非常繁琐。解决办法是使用一个可以执行包管理（安装、更新和卸载）以及虚拟环境创建和支持任务的工具。合适的工具是 `pipenv`。

`pipenv` 是一个 Python 打包工具。该工具用于管理和简化 Python 包依赖项。

它可以使用以下命令进行安装：

```
```bash
pip install pipenv
```
```

一旦安装了 `pipenv`，它将取代 pip 作为包管理工具。此外，它将负责所有包依赖任务。它还创建两个新文件，即以下文件：

- `pipfile`：列出所有已安装的包
- `pipfile.lock`：用于管理复杂依赖项
