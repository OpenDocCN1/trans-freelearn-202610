# 智谱AI开放平台

智谱AI开放平台（BigModel.cn）是北京智谱华章科技有限公司推出的大模型开放平台，作为智谱AI的官方API入口，为开发者提供弹性的、普惠的开箱即用的大模型服务。

开放平台已汇聚25个系列模型、超过100个模型版本，覆盖语言、图像、视频、音频等模态，提供API、SDK、私有化部署等多种服务方式。
