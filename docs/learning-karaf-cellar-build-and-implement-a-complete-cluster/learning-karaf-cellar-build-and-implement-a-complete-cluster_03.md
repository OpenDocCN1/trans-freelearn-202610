## 关于作者

**Jean-Baptiste Onofré** 是 Apache 软件基金会的成员，过去 10 年一直参与 Apache 项目。他是 Apache Karaf 及其子项目（包括 Cellar、Cave 和 EIK）的 PMC 主席。

他也是 Apache ACE、Apache ServiceMix 和 Apache Syncope 的 PMC 成员，并且是 Apache ActiveMQ、Apache Archiva、Apache Aries、Apache Camel 和 Apache jClouds 的提交者。

他目前就职于 Talend (http://www.talend.com)，担任软件架构师，并且是 Talend Apache 团队的成员。

他为 *Linux 杂志法国版* 撰写 Java 技术文章，并曾担任 *Apache ServiceMix How-To、Henryk Konsek 以及 Learning Apache Karaf、Johan Edstrom、Jamie Goodyear 和 Heath Kesler* 的审阅人。这两本书均由 Packt Publishing 出版。他目前正在审阅 *Apache Karaf Cookbook、Johan Edstrom、Jamie Goodyear、Heath Kesler 和 Achim Nierbeck，Packt Publishing*。

他还曾在不同会议上就 Apache 项目（Karaf、Camel 等）发表演讲，尤其是在 ApacheCon NA、ApacheCon Europe 和 CamelOne 上。

我想感谢整个 Karaf 团队，尤其是 Guillaume Nodet、Achim Nierbeck、Jamie Goodyear、Ioannis Canellos 以及所有其他成员。我们是一个伟大的团队，你们都做得非常出色。

我还要感谢我的妻子 Lucile，她接受了我花了几个晚上写这本书。
