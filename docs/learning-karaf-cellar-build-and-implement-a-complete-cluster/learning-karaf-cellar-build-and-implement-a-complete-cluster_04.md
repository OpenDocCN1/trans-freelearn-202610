## 关于审阅人

**Ladislav Gažo** 是一位计算机爱好者，长期深入探索软件世界。他在开发和软件工程方面拥有超过 12 年的专业经验。在开始计算机图形和网络管理的实验后，他意识到真正的道路在于软件工程与业务的结合。他已经开发、分析并架构了基于 Java、基于桌面以及最终基于现代 Web 的解决方案多年。应用敏捷方法和先进技术既是他的爱好，也是他的日常工作。

丰富的技术经验促使他与他人共同创立了 Seges Ltd.，这是一家位于斯洛伐克的软件开发公司。他积极参与创业活动，并帮助建设开发者社区，例如斯洛伐克的谷歌开发者集团和 Java 用户组。他与同事们设计并发布了一个名为 Synapso 的交互式内容管理解决方案，该方案在考虑用户体验的同时利用了当代技术。

如果没有所有同事、朋友和家人的支持，我无法将我的知识付诸实践，成为本书审阅过程中的一部分。一个良好的长期环境帮助我获得了可以继续传承的经验。

**Sachin Handiekar** 是一位高级软件开发人员，在 Java EE 开发方面拥有超过五年的经验。他毕业于伦敦格林威治大学的计算机科学专业，目前在一家全球咨询公司工作，该公司使用各种开源技术（如 Apache Camel、ServiceMix、ActiveMQ 和 ZooKeeper）开发企业应用。

他对开源项目非常感兴趣，曾向 Apache Camel 贡献代码，并为 Spring Social 开发了插件，这些插件可以在 GitHub 上找到：https://github.com/sachin-handiekar。

他还积极在博客上撰写有关企业应用开发的文章：http://sachinhandiekar.com。

**Achim Nierbeck** 在设计和实现 Java 企业应用方面拥有超过 14 年的经验。他是 Apache Karaf 的提交者和 PMC 成员，同时也是 OPS4J Pax Web 项目的负责人。自 2010 年以来，他一直致力于 OSGi 企业应用。他是 Packt Publishing 出版的 *Apache Karaf Cookbook* 的作者之一（尚未出版）。

在不参与项目或开源开发的时候，他喜欢与家人和朋友共度时光。可以通过 notizblog.nierbeck.de 联系他。
