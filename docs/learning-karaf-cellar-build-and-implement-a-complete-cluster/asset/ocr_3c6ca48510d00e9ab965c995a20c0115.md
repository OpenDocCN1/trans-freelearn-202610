# Summary

In this chapter, we learned how to configure the filtering of cluster events. It provides fine-grained management of the cluster events: per cluster group, per direction (inbound or outbound), per resource (feature, bundle, and config), supporting regex to identify the cluster events and type of filtering (whitelist or blacklist).

It also allows the cluster administrator to define which resources should be synchronized on the cluster.

In the next chapter, we will see another application for resource synchronization: remote communication between bundles using **Distributed OSGi (DOSGi)**.
