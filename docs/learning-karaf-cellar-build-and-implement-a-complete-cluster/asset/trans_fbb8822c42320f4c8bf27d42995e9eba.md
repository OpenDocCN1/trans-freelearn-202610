# 前言

Apache Karaf 已成为 Open Software Gateway 计划（OSGi）应用的主要容器。这主要是因为越来越多的人可以看到 OSGi 在组件复用、版本控制以及通过真正的模块化应用降低复杂性方面的优势。

人们也在寻找一个即用型容器，它提供在关键任务和企业级环境中预期的所有功能：管理、监控和配置。这就是 Karaf 所提供的，它简化了 OSGi 应用的开发、执行和生产。然而，Karaf 不仅仅是一个专注于 OSGi 的容器；尽管它由 OSGi 驱动，但它也支持非 OSGi 应用，如 Spring 或 Web 应用。

在现代架构中，大多数情况下，我们并不是运行容器的单一实例。为了提供可扩展性和高可用性，经典架构包含多个容器实例，它们构成 Karaf 容器的农场或集群。这种架构带来新的问题：你如何在不同实例上部署应用组件？你如何将此部署仅针对一组节点，例如用于分阶段目的？如何处理不同节点上的配置？

Apache Karaf Cellar 正是为了应对这些问题以及更多问题而创建的。

本书首先会给你提供理解 OSGi 和 Apache Karaf 以及配置集群概念的手段。通过这样做，它提供了在转向 Cellar 的高级使用，例如集群组或集群事件过滤之前所需的基线。

本书详细介绍了 Cellar 架构以及 Cellar 提供的不同命令，从安装到集群管理。

本书不仅是一个简单的配置或同步集群，它还会向你展示 Cellar 的运行时功能，例如分布式 OSGi（DOSGi）以及与 Apache Camel 的交互，以创建多节点集成平台。

使用本书，读者将通过操作步骤详细了解如何设置 Karaf 节点集群。

## 本书涵盖内容

第1章，Apache Karaf – 配置和集群，回顾 OSGi 是什么、目的、架构和组件。我们将介绍 Apache Karaf 容器的细节、其架构和功能。我们还将介绍如何管理多个 Apache Karaf 实例的问题。

第2章，Apache Karaf Cellar，介绍 Apache Karaf Cellar 以及它可以处理的不同的集群拓扑。在介绍 Cellar 架构之后，我们将进行第一次集群安装，并使用不同的技术在集群上管理不同的资源以监控当前集群状态。

第3章，Hazelcast，深入探讨 Cellar 引擎。在介绍 Hazelcast 之后，我们将看到对 Cellar 有用的不同配置，特别是在网络设置方面。

第4章，集群组，展示如何在 Cellar 中设置集群组，从而创建节点子集并针对配置。

第5章，生产者、消费者、处理器、监听器和同步器，向你介绍 Cellar 用于在集群中不同节点之间生产、消费和传输集群事件的组件。

第6章，集群事件的过滤，展示如何过滤集群事件，从而实现集群中资源同步的精细化配置。

第7章，DOSGi，展示 Cellar 不仅仅是一个配置和同步集群解决方案，通过介绍 Cellar 提供的第一个运行时集群功能：DOSGi。我们将看到如何使用 Cellar 通过示例在不同节点上位于不同节点的 bundle 之间实现远程通信。

第8章，Cellar 与 Camel，通过利用 camel-hazelcast 组件展示 Cellar 提供的第二个运行时集群功能。借助 Cellar 和 Hazelcast，我们将通过示例了解如何在不同节点上位于不同节点的 Camel 路由之间实现远程通信。

第9章，路线图，介绍将在 Cellar 的未来版本中推出的新想法和功能。本章概述了 Cellar 的路线图。
