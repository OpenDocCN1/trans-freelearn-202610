# 关于审稿人

**Luiz Henrique Bueno** 是一名认证 ScrumMaster®（CSM）和 Unity 认证开发人员，拥有 29 年以上的软件开发经验。他尝试过语言、编辑器、数据库和框架的演变。

2002 年，他在 Visual Studio .NET 推出时撰写了《使用 Visual Studio .NET、ASP.NET 和 C# 开发 Web 应用程序》一书。他还参与开发了一本名为 Casa Conectada 的巴西杂志，内容关于家庭自动化。

基于该杂志的项目，他开始开发专注于同一主题的项目。他使用过 Crestron、Control4、Marantz、Windows Mobile 和 Symbian OS 等技术，始终实现触摸屏应用程序。

自 2010 年以来，他一直在为移动设备开发应用程序和视频游戏，包括 VR/AR 应用程序。他已使用 Unity、C#、Xcode、Cocoa Touch、Core Data、SpriteKit、SceneKit、Objective-C、Swift、Git、Photoshop 和 Maya 为 iPhone、iPad、Apple Watch、Apple TV 和 Android 开发了许多项目。

他的座右铭是“_不要为 QA 编写代码，要为生产环境编写代码。_”
你可以通过 Luiz Henrique Bueno 的个人网站联系他。

**Dr. Sebastian Thomas Koenig** 获得新西兰坎特伯雷大学的人机界面技术博士学位，开发了一个用于个性化虚拟现实认知康复的框架。他于德国雷根斯堡大学获得心理学文凭，研究领域包括实验心理学、临床神经心理学和虚拟现实康复。

Dr. Koenig 是 Katana Simulations 的创始人兼首席执行官，负责监督认知评估和训练模拟的设计、开发和评估。他的职业经验涵盖了认知康复和虚拟现实研究、开发以及人机交互领域 10 年以上的临床工作。作为首席研究员和行业合作伙伴，他已在美国、德国和澳大利亚获得超过 200 万美元的研究资助。他在国际会议上担任演讲者，并在康复、认知心理学、神经心理学、软件工程、游戏开发、游戏用户研究和虚拟现实领域担任科学出版物的审稿人，拥有丰富的经验。

Dr. Koenig 开发了众多用于认知评估和训练的软件应用程序。因其在虚拟记忆任务方面的工作，他于 2011 年获得了享有盛誉的 Laval Virtual Award 医学与健康类别奖项。其他应用包括与新泽西州凯斯勒基金会合作开发的 Wonderworks 虚拟现实注意力训练，以及南加州大学创意技术研究所基于微软 Kinect 的运动和认知训练 JewelMine/Mystic Isle（专利待批）。Dr. Koenig 于 2016 年获得国际虚拟康复学会颁发的早期职业研究员奖（第二名）。
