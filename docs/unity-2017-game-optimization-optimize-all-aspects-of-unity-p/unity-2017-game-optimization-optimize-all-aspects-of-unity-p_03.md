# 关于作者

**Chris Dickinson** 在英格兰一个安静的小角落长大，对数学、科学，尤其是视频游戏充满热情。他喜欢玩游戏、解析游戏玩法，并试图弄清楚它们的工作原理。看着他父亲修改 PC 游戏的十六进制代码以绕过早期的复制保护，这完全让他大开眼界！当时他对科学的热情赢得了胜利；然而，在完成物理与电子学硕士学位后，他飞往加利福尼亚，在硅谷中心从事科学研究工作。不久之后，他不得不承认，研究工作不适合他的性格。他向四面八方投递简历，最终找到了一份工作，这让他终于在软件工程领域走上了正确的道路（据我所知，物理专业毕业生出现这种情况并不罕见）。

他作为 IPBX 电话系统自动化工具开发人员的工作更适合他的性格。现在，他正在弄清楚复杂的设备链条，帮助开发人员修复和改进它们，并构建自己的工具。Chris 学到了很多关于如何处理大型、复杂、实时、基于事件、由用户输入驱动的状态机（听起来很熟悉？）的知识。在这一点上，Chris 主要是自学成才，他对视频游戏的热情再次高涨，推动他真正弄清楚视频游戏是如何构建的。一旦他感到足够自信，他就回到学校攻读游戏与仿真编程学士学位。到他完成学业时，他已经在用 C++ 拼凑自己的（虽然很简陋）游戏引擎，并在日常工作中经常运用这些技能。但是，如果你想构建游戏，你应该直接构建游戏，而不是构建游戏引擎。因此，Chris 选择了当时他最喜欢的公开可用游戏引擎——一个名为 Unity 3D 的优秀小工具——开始制作一些游戏。

在短暂的独立游戏开发经历后，Chris 遗憾地决定，那条特定的职业道路不适合他，但他在短短几年内积累的知识量在大多数标准下都令人印象深刻，他喜欢以能够帮助其他开发者进行创作的方式运用这些知识。从那以后，Chris 撰写了一本关于游戏物理的教程书（《使用 Bullet 物理和 OpenGL 学习游戏物理》，Packt Publishing 出版）以及两版 Unity 性能优化书籍（你正在阅读的这本）。他与挚爱 Jamie 结婚，并在加州圣马特奥市 Jaunt Inc. 担任软件开发测试工程师（SDET），该公司是一家专注于提供 VR 和 AR 体验（例如 360 度视频等）的虚拟现实/增强现实初创公司。

工作之外，Chris 继续与对桌游（特别是《星际迷航： Battlestar》和《Blood Rage》）的成瘾作斗争，沉迷于暴雪的《守望先锋》和《星际争霸 II》，满足一对脾气暴躁却可爱的猫咪日益增长的需求，并怅然若失地凝视着 Unity 的最新版本，脑海中浮现着许多游戏创意。总有一天，当时机成熟（并且当他不再偷懒时），他的计划或许会实现。

从卑微的起步到今天，这是一段漫长的旅程。我要感谢一路上遇到的所有朋友、老师、导师和同事。他们的教导、批评和指导使我取得的许多成就成为可能。其余的我要感谢我的家人，尤其是我的妻子兼好友 Jamie，她们一直对我爱好、热情和抱负表示理解和支持。
