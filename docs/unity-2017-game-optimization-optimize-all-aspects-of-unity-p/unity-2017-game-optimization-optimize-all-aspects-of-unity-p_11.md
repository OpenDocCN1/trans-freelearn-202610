# 前言

第 4 章，启动你的艺术，帮助你理解美术资产背后的底层技术，并学习如何避免导入、压缩和编码方面的常见陷阱。

第 5 章，更快的物理，是关于调查 Unity 内部物理引擎在 3D 和 2D 游戏中的细微差别，以及如何正确组织物理对象以提高性能。

第 6 章，动态图形，对渲染管线进行了深入探讨，以及如何改进在 GPU 或 CPU 上遭受渲染瓶颈的应用程序，如何优化光照、阴影和粒子效果等图形效果，优化 Shader 代码的方法，以及针对移动设备的一些特定技术。

第 7 章，虚拟速度和增强加速，专注于虚拟现实 (VR) 和增强现实 (AR) 这两种新的娱乐媒介，并包括针对为这些平台构建的应用程序特有的几种性能优化技术。

第 8 章，精通内存管理，探讨了 Unity 引擎、Mono 框架的内部工作原理，以及这些组件内部如何管理内存，以保护我们的应用程序免受过多的堆分配和运行时垃圾回收的影响。

第 9 章，战术技巧和窍门，以 Unity 专业人士用于改进项目工作流程和场景管理的大量有用技术结束本书。
