![](bbox=[0.27, 0.145, 0.73, 0.487])

In the preceding example, we have objects flagged as **Player**, **Enemies**, **Player Missiles**,
**Enemy Missiles**, and **Powerups**, and we have minimized the number of possible inter-
object collisions for the Physics Engine to check.

Starting with the first row of checkmarks labeled **Player**, we want the **Player** object to be
able to collide with **World** objects, pickup **Powerups**, get hit by **Enemy Missiles**, and
collide with **Enemies**. However, we do not want them to collide with their own **Player**
**Missiles** or themselves (although there would probably only be one object in this Layer,
anyway). Hence, the enabled checkboxes in the **Player** row reflect these requirements. We
only want **Enemies** to collide with **World** objects and **Player Missiles**, so these are checked
in the **Enemies** row. Note that the **Player**-to-**Enemies** collision pair would have been
handled already by the previous row; hence there is no need for it to appear in the **Enemies**
row. We also want both **Player Missiles** and **Enemy Missiles** to explode when they hit
**World** objects, so these are marked, and finally we don't care about **Powerups** colliding
with anything but the **Player**, nor do we want **World** objects to collide with other **World**
objects, so no checkboxes are marked on the final two rows.
