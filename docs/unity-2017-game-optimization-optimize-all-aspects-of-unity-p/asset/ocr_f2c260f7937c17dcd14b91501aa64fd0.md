The Editor has a log file, which can be accessed by opening the **Console** window (where log messages are printed), left-clicking on the _hamburger_ icon in the top-right corner (which looks like three thin horizontal lines), and selecting **Open Editor Log**. This can help us get more information about build failures. Alternatively, if we successfully built our project, it will contain a breakdown of compressed file sizes of all assets that were packed into the executable and ordered by size. This is an extremely helpful way of figuring out which assets consume the majority of our application footprint (hint: it's almost always texture files), and which files take up more space than we would expect.

Additional windows can be added to the Editor by right-clicking on the title of an existing window and selecting **Add Tab**. This also allows us to add duplicate windows, such as having more than one **Project** window or **Inspector** window open at a time. This can be particularly useful for moving files between different locations via multiple **Project** windows.
