# 前言

如果你正在阅读这一行，我想祝贺你，因为你已经克服了追求理解区块链，特别是以太坊智能合约的最困难的障碍。这个障碍是围绕这一有前途但尚不成熟的技术所产生的压倒性炒作，以及试图了解引擎盖下真正发生了什么。

我是一名软件开发人员，通过我的书，你正在电子设备上查看或手持的这本书，我们将一起踏上穿越这一神秘而革命性技术的迷人旅程。

本书的章节以增量方式安排。我们首先使用熟悉的比特币对区块链进行温和介绍，并迅速深入以太坊世界及其生态系统中的主要参与者。

然后我们进行一些动手编码，编写一个典型的“Hello World”智能合约。然后我们讨论去中心化自治组织、去中心化应用和智能合约优化。我们还分析了以太坊社区最近发生的两个著名的数百万美元黑客攻击，以及为避免未来发生而采取的预防措施。

然后我们转向 solidity 编程语言和 web3.js 库的复杂性。

最后几章主要涉及标准化代币的开发、首次代币发行概念、智能合约的潜在企业用例、设计去中心化微博客平台以及冲浪暗网市场。

我们通过提供关于具有光明未来前景的高级主题的入门知识来结束本书，例如基于图的 DLT 和量子安全区块链。

在开始时，我想在我们之间达成明确的理解。尽管我是本书的作者，并且有责任尽可能准确地在本书记载事实，但无论如何我都不认为自己是该主题的唯一权威。

作为我的读者，我希望你意识到我只是另一个过度热情的同行学习者，我将尝试通过介绍启动你旅程所需的最佳信息量来协助你的知识追求。而且我会让你了解我在途中遇到的障碍和陷阱，以便你能从我的错误中学习。

够了。让我们开始我们的区块链之旅，用 *Ethereum Smart Contract Development* 弄脏我们的双手。

祝阅读愉快！

# 本书涵盖内容

第 1 章，*区块链基础*，将在我们深入以太坊和智能合约开发之前，作为关于区块链的热身环节。为了真正欣赏区块链，我们必须理解区块链作为技术牢牢建立的两个奠基支柱：分布式系统和密码学。一旦我们涵盖了这两个核心概念，我们就尝试从两个不同角度理解区块链：作为软件开发人员和作为金融工具交易者。然后我们深入区块链中一个区块的内部逻辑架构，重点关注比特币区块结构，并对挖矿和分叉过程进行温和介绍。我们通过讨论区块链近年来如何演变并明确标出其在技术炒作周期中的当前位置来结束本章。

第 2 章，*理解以太坊*，将帮助我们理解去中心化的含义以及以太坊是否真正去中心化。我们还将涵盖其核心技术栈，并熟悉各种术语，例如 Mist、EVM、Swarm、Whisper、Ether 和 Gas。我们将简要讨论图灵完备语言的概念。然后我们将从以太坊的角度重新审视分叉、挖矿和区块架构。我们将以对以太坊钱包和客户端界面的认识结束本章，这将为智能合约开发奠定坚实基础。

第 3 章，*以太坊智能合约的 Hello World*，提供了开发我们第一个智能合约的实用指南。作为软件开发人员的不成文传统，我们从“Hello World”程序开始。然后我们尝试使用合约进行一些基本的算术递增和递减操作。然后我们学习如何在智能合约内部编写循环以及如何在 GitHub 上提出问题。我们通过从创世区块开始创建我们自己的私有区块链，将其与 Geth 关联，并使用 Mist 浏览器部署我们研究过的一个智能合约来结束本章
