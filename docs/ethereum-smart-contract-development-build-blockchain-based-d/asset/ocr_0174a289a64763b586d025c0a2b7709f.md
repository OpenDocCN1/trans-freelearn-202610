In a nutshell, the functions inside the API sub-modules of the web3.eth module help to accomplish the following tasks:

+   - web3.eth.subscribe: This lets us subscribe specific events happening on the blockchain.
+   - web3.eth.Contract: This makes it easy to interact with smart contracts on the blockchain, as if they are JavaScript objects.
+   - web3.eth.accounts: This helps to generate data, Ethereum accounts, and sign transactions.
+   - web3.eth.personal: This allows our contract to interact with the Ethereum node accounts.
+   - web3.eth.Iban: This lets us convert Ethereum addresses from and to International Banking Account Number (IBAN) and Basic Banking Account Number (BBAN).
