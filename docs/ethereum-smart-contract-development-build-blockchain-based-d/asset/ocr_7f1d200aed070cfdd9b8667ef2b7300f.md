# # Summary

This chapter was more of a lab exercise with minimal theoretical backing. We started it with a simple hello world smart contract on remix IDE, using a web browser. We also explored the increment and decrement operation using a contract. We then jumped in to code a quick for loop in Solidity and proceeded to learn how to consult while troubleshooting and raise issues on GitHub. We closed the chapter by creating a private blockchain using a geth console, mining blocks, earning rewards in ethers, and using those ethers to deploy and execute smart contracts in the MIST browser.

In Chapter 4, *A Noob's Guide to DApps and DAO*, we will take on the topic of decentralized applications and DAOs.
