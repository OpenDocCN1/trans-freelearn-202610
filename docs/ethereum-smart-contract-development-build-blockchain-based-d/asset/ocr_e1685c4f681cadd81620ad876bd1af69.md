# btcrelay.org

This is a project that has been recommended by Joris Bontje. It is developed by Joseph Chow and has a live status on ethercast. It is actually the first working side chain for bitcoin.

This DApp serves as a building block that allows Ethereum-based smart contracts to verify bitcoin transactions securely and without any intermediaries. It stores bitcoin blockheaders, which in turn, is used to build a mini-version of the bitcoin blockchain. In simple words, users can pay in bitcoin to use Ethereum DApps.
