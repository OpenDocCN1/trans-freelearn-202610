# Registries

Registries are mainly data design patterns. IT helps to refer contracts or addresses in a human-readable form. It typically consists of name-to-address associations. It is analogous to the facade (literally meaning a deceptive outward appearance) design pattern and belongs to the category of structural design patterns.

In the Solidity programming language, the registry pattern can be implemented using the mapping keyword. It is used to structure value types, such as Booleans, integers, addresses, and structs. It consists of two main parts: a _KeyType and a _ValueType. They appear in the following syntax:

```
mapping (_KeyType => _ValueType) mapName
```
