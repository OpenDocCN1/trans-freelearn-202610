# Service setup on the private blockchain

Setting up the tweet service on our private blockchain is quite simple. First we need to initiate our **inter protocol communication (IPC)** using the geth command line inside our project folder, as discussed in _Chapter 3, Hello World of Smart Contracts_.

```
```bash
$ geth -datadir=./chaindata/
```
