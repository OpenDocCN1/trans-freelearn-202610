# 关于作者

**Mayukh Mukhopadhyay** 的职业生涯始于 BI 开发人员。2008-09 年金融危机后，他在 Tata Consultancy Services 为电信行业的财富 500 强客户工作。拥有 Jadavpur University 软件工程硕士学位，他目前担任数据洞察开发人员，专注于将数据科学和机器学习应用于原始电信设备日志以生成业务洞察。他的学术兴趣广泛，涵盖音频信号处理、结构生物信息学、生物启发算法到意识工程等。除了是 Oracle 认证专家外，他还是 C4（Crypto Currency Certification Consortium）认可的认证比特币专业人士。他尝试将区块链作为技术应用于不同的业务领域。

# 关于审阅者

**Daniel Kraft** 在奥地利格拉茨学习应用数学和理论物理，并于 2015 年在格拉茨大学获得博士学位。此后，他在瑞士苏黎世担任软件工程师。自 2011 年起他对比特币和加密货币非常感兴趣，并自 2013 年起参与比特币开发。自 2014 年起，他一直是 Namecoin 和 Huntercoin 的主要开发者，并成功地在现代 Bitcoin Core 代码库之上重新实现了两者。在可能的情况下，Daniel 还为上游 Bitcoin Core 贡献了改进。他在同行评审期刊上发表了多篇研究文章，其中两篇直接与加密货币相关。
