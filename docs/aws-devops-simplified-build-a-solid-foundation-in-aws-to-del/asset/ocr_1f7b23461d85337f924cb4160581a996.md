# Part 2

# Faster Software Delivery with Consistent and Reproducible Environments

This part focuses on the AWS foundations that enhance the software delivery process using consistent and reproducible environments. You will explore the benefits of managing infrastructure as code, learn how AWS CloudFormation works under the hood, and experience the setup of a CI/CD pipeline using AWS-managed services. Taking the learnings further, you will dive into the fundamentals of AWS CDK – a programmatic approach to managing infrastructure in AWS – while deploying an image recognition app in your AWS account.

This part has the following chapters:

+   - Chapter 4, Managing Infrastructure as Code with AWS CloudFormation
+   - Chapter 5, Rolling Out a CI/CD Pipeline
+   - Chapter 6, Programmatic Approach to IaC with AWS CDK
