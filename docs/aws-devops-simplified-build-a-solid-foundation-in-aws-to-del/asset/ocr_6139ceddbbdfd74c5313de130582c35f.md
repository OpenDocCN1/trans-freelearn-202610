```

--language typescript
```

cdk init uses the name of the directory to generate dynamic prefixes, or suffixes, for most things – classes, subfolders, and so on.

> **Tip**
> You might have noticed that instead of using the cdk command line directly, we used npx aws-cdk instead. This practice allows you to pin these components to specific versions and ensure that every developer uses the same versions. Generally speaking, new releases of these components are always backward compatible, so the chance of something breaking is rare.
