# Creating a new AWS account

If you don’t have an AWS subscription, you can create a new account at https://aws.amazon.com by choosing Create an AWS account.

The initial screens will ask for your email address and contact information. Once you’ve provided that information, the website will ask you to create a root user password, as shown in Figure 3.1:

![](bbox=[0.44, 0.37, 0.52, 0.42])

![](bbox=[0.22, 0.44, 0.74, 0.78])

Figure 3.1: Root user credentials during AWS account creation

This is an extremely sensitive credential that should never be shared with anyone else. After the payment details have been successfully verified, you will be asked to select a support plan. For your personal use, I recommend signing up for the Basic Support plan, which is intended for developers or users who are just getting started with AWS.
