# 第 4 部分

## 迈出下一步

本部分聚焦于从文化和技术的角度成功组建团队。它深入探讨了随着 AWS 的日益普及，企业面临的典型问题，并提供了实用的解决技巧，同时增强团队协作、优化开发者流程。你将了解一些持续改进和遵循 AWS Well-Architected Framework 的策略。通过着陆区（landing zones）的概念，我们还将向你介绍一些开源解决方案和框架。这些框架可以与 AWS 服务（如 Control Tower）结合使用，以提高多账户、多区域环境的合规性和安全性。

本部分包含以下章节：

- 第 10 章，成功组建团队
- 第 11 章，确保多账户和多区域环境拥有强大的 AWS 基础
- 第 12 章，遵循 AWS Well-Architected 原则
