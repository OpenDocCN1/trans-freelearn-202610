In the following code, the principal entity `Blog`, with its primary key `Id`, will have the foreign key `BlogId` in the `Post` entity:

```
public class Blog
{
    public int Id { get; set; }
    // Code removed for brevity
}
public class Post
{
    // Code removed for brevity
    public int BlogId { get; set; }
}
```
