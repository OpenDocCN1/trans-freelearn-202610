The Tags list required for the Create screen to populate tag drop-down is persisted in ViewData as a MultiSelectList object, which allows the user to map multiple tags to an individual post. The code which sets the MultiSelectList field with data is shown below:

```
public IActionResult Create()
{
  // Code removed for brevity
  ViewData["TagIds"] =
    new MultiSelectList(_context.Tags, "Id", "Name");
}
```
