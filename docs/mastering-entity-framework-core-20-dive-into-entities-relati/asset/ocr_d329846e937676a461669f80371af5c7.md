We can configure the custom error message for each model field as follows:

```
public class Blog
{
    // Code removed for brevity
    [Required(ErrorMessage = "Url is required")]
    [Url(ErrorMessage = "Provide a valid url")]
    public string Url { get; set; }
}
```
