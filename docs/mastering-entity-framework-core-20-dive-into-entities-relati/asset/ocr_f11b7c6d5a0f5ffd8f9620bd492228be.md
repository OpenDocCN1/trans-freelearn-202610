The source code required to add Required validation is shown here; it consumes built-in validation and throws a default error message:

```
public class Blog
{
    public int Id { get; set; }
    [Required]
    public string Url { get; set; }
    public ICollection<Post> Posts { get; set; }
    public int AuthorId { get; set; }
    public User Author { get; set; }
}
```
