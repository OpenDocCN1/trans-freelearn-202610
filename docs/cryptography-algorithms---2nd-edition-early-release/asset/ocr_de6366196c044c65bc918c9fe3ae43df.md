# Key generation

As we have already said, the master key, [K], is made up of 9 bits. For each round, we have a different encryption key, [Kᵢ], generated by 8 bits of the master key, starting counting from the iᵗʰ round of encryption.Let's take an example to clarify the key generation K₄ (related to the fourth round):

+   - K = 010011001 (9-bit key, the master key)
+   - K₄ = 01100101 (8 bits taken by K)
