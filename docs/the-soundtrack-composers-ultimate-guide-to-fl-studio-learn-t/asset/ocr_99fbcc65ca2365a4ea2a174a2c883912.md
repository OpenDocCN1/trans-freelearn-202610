# Reformer

Krotos’s **Reformer** plugin creates Foley sounds in a dynamic way. It allows you to create real-time synced sound effects for visuals.

![](bbox=[0.14, 0.19, 0.842, 0.518])

Figure 5.25 – Krotos Reformer

Modifying the Reformer controls in real time creates a new sound. Its most obvious application is for creating sounds for animations that have no existing sound to begin with so you need to invent something from scratch. For example, it can be used to create sounds for animations where you need a new sound to be a custom length.

You can learn more about Reformer at https://www.krotosaudio.com/reformer-pro/.
