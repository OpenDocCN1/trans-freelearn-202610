## Jumpstart Logic Pro 10.6

Jay Asher

ISBN: 978-1-80056-277-6

- 了解音频和 MIDI 的区别以及它们的工作原理，同时涵盖 Apple Loops
- 录制和编辑音频，例如你的声音或吉他
- 使用 Logic Pro 的软件乐器创建和编辑 MIDI 乐段
- 利用 Logic Pro 10.5 的出色 Drummer 功能开发逼真的鼓和电子鼓
- 探索随 10.5 版本一起包含的新 Step Sequencer、Live Loops 和 Quick Sampler
