At the time of writing, Splice doesn't have the ability to merge changes between file versions like Git does, so only one of you will be able to make changes at a time to the newest project version. You won't be able to make changes simultaneously. This means that each time you plan to work on the project file, it's essential that you log in to Splice and open up the most recent version of the project. If you don't do this, you'll probably find yourself working on an outdated version of the project file.

Splice also offers a library of royalty-free sounds that you can pay for and use in your projects. It also allows you to rent instrument plugins until you've paid off the amount that it would take to originally buy the plugin and lets you own it afterward. So, if you're strapped for cash at the moment but need plugin equipment, this may be a handy alternative to buying instrument plugins outright.
