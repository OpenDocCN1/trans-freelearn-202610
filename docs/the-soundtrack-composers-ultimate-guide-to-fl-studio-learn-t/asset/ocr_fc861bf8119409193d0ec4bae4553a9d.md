When an event is triggered in the game, you tell it to play a sound that was loaded in the **Audio** tab folders. Events are originally created in the game-designing engine. In other words, events are created in Unreal Engine, Unity, or whatever game engine you happen to be using. In the game engine, you would designate an event to be linked to Wwise. The steps to do this are game engine-specific, so the topic goes beyond the scope of this chapter. Fortunately, for our example, the Cube game already has events created for our use.
