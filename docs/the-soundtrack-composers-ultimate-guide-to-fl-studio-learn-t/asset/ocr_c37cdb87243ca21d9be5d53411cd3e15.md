In the preceding screenshot, we can see the five mixer channel tracks: Arp, Saw Synths, Bass, Drums, and Percussion FX. These have been carefully labeled. Later, when we export the song, it will use the names of these channel tracks, so it's important that we can identify what the tracks are by name.

When we export the song, we can export each of these mixer channels as their own audio clip. This will export the song layer clips in sync with the same length and time as all the other layers. This is important for when we want to recombine them later on.
