
- `docker commit`: This command commits the changes that have been made to a container to a new container image
- `docker stop`: This command stops a running container
- `docker rm`: This command removes an existing container

The Docker approach allows you to store images as code, perform continuous integration with a development life cycle, and recreate quick and repeatable images for upgrade and maintenance purposes with consistent results.

## Maintaining container images

Container images should be regularly updated to ensure they receive changes that are made via code and patching.

The base OS layer contains OS elements that the host OS does not share. It comprises two images: the base layer and the update layer. The base layer is the larger layer but changes the least amount and needs the least amount of maintenance; the update layer is smaller. The following diagram represents these layers:

![](img/cf35f46a8dd5f11e58349c1d81611b75_370_0.png)

Figure 10.6 – Container image update layers

In the update layer, a new image is created for each code change. The base OS layer gets its updates from the updates layer.

## Exercise – installing Docker on Windows Server using PowerShell

In this exercise, we will install Docker on a Windows Server using PowerShell. To do so, we will use a Windows Server 2019 Gen2 VM.

Install-Package -Name docker -ProviderName DockerMsftProvider
