

## 任务 2 – 创建虚拟机

- 在搜索栏中输入 virtual machines；从服务列表中单击 Virtual machines：

![](img/cf35f46a8dd5f11e58349c1d81611b75_230_0.png)

图 6.28 – 搜索 VM 资源

- 从虚拟机边栏，单击边栏顶部菜单中的 + 创建，然后单击虚拟机。可选：单击了解更多超链接以获取更多信息和学习：

![](img/cf35f46a8dd5f11e58349c1d81611b75_230_1.png)

图 6.29 – 创建 VM

- 按要求设置项目详细信息的订阅和资源组值。

- 设置实例详细信息值，如下：

  - 虚拟机名称：输入名称

  - 区域：选择区域

  - 可用性选项：保留默认选定

  - 安全类型：保留默认选定

  - 映像：选择 Windows Server 映像

  - 大小：保留默认选定或按要求选择：

![](img/cf35f46a8dd5f11e58349c1d81611b75_231_0.png)

图 6.30 – 创建 VM：设置

- 按要求设置管理员帐户用户名和密码：

![](img/cf35f46a8dd5f11e58349c1d81611b75_231_1.png)

图 6.31 – 创建 VM：设置（续）

- 将公共入站端口规则设置为无：

![](img/cf35f46a8dd5f11e58349c1d81611b75_232_0.png)

图 6.32 – 创建 VM：设置（续）

- 对于此练习，将许可设置为未选中的默认值；即，不使用现有的 Windows Server 许可证。

- 单击下一步：磁盘。

- 对于此练习，保留磁盘选项卡的默认设置：

![](img/cf35f46a8dd5f11e58349c1d81611b75_232_1.png)

图 6.33 – 创建 VM：设置（续）

- 单击下一步：网络。

- 从网络接口，设置以下内容：

  - **虚拟网络**：使用提供的默认值

  - **子网**：使用提供的默认值

  - **公共 IP**：单击创建新，输入名称，然后单击确定

  - **NIC 网络安全组**：选择无

  - **删除 VM 时删除公共 IP 和 NIC**：选中以启用/允许

  - 将所有其他设置保留为默认值：

![](img/cf35f46a8dd5f11e58349c1d81611b75_233_0.png)

图 6.34 – 创建 VM：设置（续）

- 单击下一步：管理。

- 保留默认设置。

- 单击下一步：高级。

- 保留默认设置。

- 单击下一步：标记，对于此练习跳过输入任何信息。然后，单击下一步：查看 + 创建。

- 在 **查看 + 创建** 选项卡上，_查看你的设置_；你可以返回之前的选项卡并在需要时进行任何编辑。确认设置符合要求后，可以单击 **创建**：

![](img/cf35f46a8dd5f11e58349c1d81611b75_234_0.png)

图 6.35 – 创建 VM：查看 + 创建选项卡

- 你将收到资源部署成功的通知：

![](img/cf35f46a8dd5f11e58349c1d81611b75_234_1.png)

图 6.36 – VM 部署成功

## 任务 5 – 添加入站规则以允许 RDP 访问

- 导航到在本练习中创建的 NSG。请注意，除非源是 **VirtualNetwork** 或 **Azure LoadBalancer**，否则所有 _入站连接_ 都是 **拒绝** 的。我们将在下一个任务中处理此问题。

- 从 **网络安全组** 边栏，在 **设置** 下单击 **入站安全规则**：

![](img/cf35f46a8dd5f11e58349c1d81611b75_239_0.png)

图 6.43 – 已创建 NSG

- 从 **入站安全规则** 边栏，单击 + 添加：

![](img/cf35f46a8dd5f11e58349c1d81611b75_239_1.png)

图 6.44 – 添加 NSG

- 打开浏览器，在 Google 中输入 what's my IP，并记下你的 IP 以供下一步使用。

- 从 **添加入站安全规则** 边栏，设置以下内容：

  - **源：** 选择 IP 地址

  - **源 IP 地址/CIDR 范围：** 将此设置为任务第 4 步中 Google 结果的你的 IP

  - 源端口范围：保留默认值 *（星号符号）

  - 目标：保留默认值 任何

  - 服务：选择 RDP

  - 操作：确保设置为 允许

  - 优先级：保留默认值 100

  - 名称：提供名称，例如 AllowInbound_RDP_KnownIP

  - 说明：按要求输入说明

![](img/cf35f46a8dd5f11e58349c1d81611b75_240_0.png)

图 6.45 – 添加 NSG（续）

- 单击添加。

- 你将收到规则已成功创建的通知：

![](img/cf35f46a8dd5f11e58349c1d81611b75_241_0.png)

图 6.46 – 已创建 NSG

## 任务 8 – 添加出站规则以拒绝 Internet 访问

- 在虚拟机边栏上，在设置下单击网络；你将从出站端口规则选项卡中看到，所有出站连接都允许访问 Internet。

- 在出站端口规则选项卡上，单击添加出站端口规则。

- 在添加出站安全规则边栏上，除以下内容外，保留所有其他选项的默认值：

  - 目标：选择服务标记

  - 目标服务标记：选择 Internet
