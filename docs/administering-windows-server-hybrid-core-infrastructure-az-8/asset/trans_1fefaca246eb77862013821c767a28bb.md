## 虚拟化和 Hyper-V 简介

在本节中，我们将介绍 **虚拟化** 的概念，具体针对计算（即 CPU 和内存）的上下文，而非存储或网络虚拟化。

无论是虚拟还是物理的计算机（机器）都是本地解决方案和 Azure IaaS 解决方案的核心构建块。
