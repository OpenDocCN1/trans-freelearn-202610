## Exercise – Implementing Group Policy

We have broken down the exercise into individual tasks for a better understanding.

## Task 1 – Creating a GPO to restrict access to Control Panel

This task focuses on security operations by restricting access to a computer’s Control Panel. You apply the same approach to restrict access to Server Manager, Command Prompt, PowerShell, and so on.

This policy will be configured as a _User Configuration_ setting and will apply to all computers a user accesses that this policy applies to; by default, a GPO applies to the _Authenticated Users_ group. You could adjust this behavior by applying security filtering.

We will link the created GPO at the domain level. This means it will be applied to all users and computers in the domain and all child OUs through inheritance. For simplicity, we will not demonstrate override, blocking, or enforcement:

- 1. From the server, once the Group Policy Management tools are installed, launch **Group Policy Management** from **Tools** in **Server Manager**.

![](img/cf35f46a8dd5f11e58349c1d81611b75_119_0.png)

Figure 3.24 – Launch the GPMC

- 2. From the GPMC, right-click the domain, click Create a GPO in this domain, and Link it here...

![](img/cf35f46a8dd5f11e58349c1d81611b75_119_1.png)

Figure 3.25 – Create the GPO

- 3. Provide a name for the GPO and click OK.

![](img/cf35f46a8dd5f11e58349c1d81611b75_119_2.png)

Figure 3.26 – Name the GPO

- 4. Right-click the GPO that we just created and click Edit...

![](img/cf35f46a8dd5f11e58349c1d81611b75_120_0.png)

Figure 3.27 – Edit the GPO

- 5. From Group Policy Management Editor, navigate to User Configuration | Policies | Administrative Templates: Policy definitions (ADMX files) retrieved from the central store | Control Panel.

Then, double-click Prohibit access to Control Panel and PC settings.

![](img/cf35f46a8dd5f11e58349c1d81611b75_120_1.png)

Figure 3.28 – Control Panel admin template

- 6. Select Enabled in the policy settings and then click OK.

![](img/cf35f46a8dd5f11e58349c1d81611b75_121_0.png)

Figure 3.29 – Policy settings
