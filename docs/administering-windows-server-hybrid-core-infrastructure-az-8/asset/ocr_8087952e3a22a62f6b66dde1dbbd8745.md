DFS can be implemented using Server Manager (via the _Add Roles and Features_ and _File and Storage Services_ roles) or PowerShell.

The following PowerShell cmdlet will install _DFSN_, _DFSR_, and the DFS management tools:

```
Install-WindowsFeature FS-DFS-Namespace, FS-DFS-Replication,
RSAT-DFS-Mgmt-Con
```

Interoperability with Azure Virtual Machines is supported. The following URL covers the requirements and limitations: https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-server-2012-R2-and-2012/jj127250(v=ws.11)#interoperability-with-azure-virtual-machines.
