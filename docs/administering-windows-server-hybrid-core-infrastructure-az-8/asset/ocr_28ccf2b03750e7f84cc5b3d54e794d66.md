# # Implementing and Managing On-Premises Network Infrastructure

This chapter covers the AZ-800 Administering Windows Server Hybrid Core Infrastructure exam learning objective: Implement and manage on-premises network infrastructure.

In the previous chapter, we added skills to understand Hybrid Identities.

We will start this chapter by understanding Domain Name System (DNS) for Windows Server; we will cover its implementation and management. We will next look at the Dynamic Host Configuration Protocol (DHCP) and IP Address Management (IPAM) network services and finally cover implementing and managing remote access services. We will then conclude with a hands-on exercise to develop your skills further. The following topics are included in this chapter:

+   - Implementing and managing Windows Server DNS
+   - Implementing and managing DHCP
+   - Implementing and managing IPAM
+   - Implementing and managing remote access
+   - Hands-on exercises

In addition to these topics, this chapter aims to take your knowledge beyond the exam objectives to prepare you for a real-world, day-to-day hybrid environment-focused role.
