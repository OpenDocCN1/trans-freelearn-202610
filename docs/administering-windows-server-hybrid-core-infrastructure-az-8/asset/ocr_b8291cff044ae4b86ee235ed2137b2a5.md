# Task 1 – Creating a GPO to restrict access to Control Panel

This task focuses on security operations by restricting access to a computer’s Control Panel. You apply the same approach to restrict access to Server Manager, Command Prompt, PowerShell, and so on.

This policy will be configured as a _User Configuration_ setting and will apply to all computers a user accesses that this policy applies to; by default, a GPO applies to the _Authenticated Users_ group. You could adjust this behavior by applying security filtering.

We will link the created GPO at the domain level. This means it will be applied to all users and computers in the domain and all child OUs through inheritance. For simplicity, we will not demonstrate override, blocking, or enforcement:

+   1. From the server, once the Group Policy Management tools are installed, launch **Group Policy Management** from **Tools** in **Server Manager**.
