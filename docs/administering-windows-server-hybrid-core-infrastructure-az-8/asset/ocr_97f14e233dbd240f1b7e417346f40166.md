+   - **Service location (SRV) record**: Identifies servers hosting a service, such as identifying the location of domain controllers
+   - **Mail exchanger (MX) record**: Identifies email servers
+   - **Text (TXT) record**: Stores arbitrary strings of information

All forward and reverse lookup DNS zones contain a **start of authority (SOA)** and a **name server (NS)** record. The SOA record contains zone configuration information, with one SOA record per zone. The NS record shows the DNS server for the domain, with one NS record for each DNS server with a zone copy.
