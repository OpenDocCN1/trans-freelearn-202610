The DHCP server has an address pool configured and configuration options. The DHCP server will communicate with the DHCP client, assign IP addresses, and pass the configuration options to the clients requesting.

The DHCP communication flow is given the acronym DORA; the four steps are set out here:

+   - Discover—DHCPDISCOVER
+   - Offer—DHCPOFFER
+   - Request—DHCPREQUEST
+   - Acknowledge—DHCPACK
