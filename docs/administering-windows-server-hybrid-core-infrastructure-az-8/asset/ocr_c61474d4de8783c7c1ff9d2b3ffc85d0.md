# # Summary

This chapter provided coverage for Exam AZ-800 Administering Windows Server Hybrid Core Infrastructure: Implement and manage hybrid identities.

The key lessons to take away from this chapter are understanding the concepts of hybrid identities, how to implement and manage Azure AD Connect, the differences between cloud sync, the different hybrid identity authentication methods, and when to choose between them based on your needs.

We then finished the chapter with a hands-on exercise to simulate a real-world scenario and develop our skills further.

You will have gained new skills through the information provided, and the chapter's goal has been for you to take your knowledge beyond the exam objectives so that you are prepared for a real-world, day-to-day hybrid environment-focused role.

The next chapter will teach us about implementing and managing on-premises network infrastructure.
