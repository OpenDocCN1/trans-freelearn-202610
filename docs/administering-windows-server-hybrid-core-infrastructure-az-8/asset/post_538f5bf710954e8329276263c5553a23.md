
## Task 2 – Creating a VM

- In the search bar, type in virtual machines; click Virtual machines from the list of services:

![](img/cf35f46a8dd5f11e58349c1d81611b75_230_0.png)

Figure 6.28 – Searching for the VM's resource

- From the Virtual machines blade, click + Create and then Virtual machine from the top menu of the blade. Optionally, click the Learn more about hyperlinks for further information and learning:

![](img/cf35f46a8dd5f11e58349c1d81611b75_230_1.png)

Figure 6.29 – Creating a VM

- Set Project details values of Subscription and Resource group as required.

- Set Instance details values as follows:

  - Virtual machine name: Enter a name

  - Region: Select a region

  - Availability options: Leave default selected

  - Security type: Leave default selected

  - Image: Select a Windows Server image

  - Size: Leave default selected or select as required:

![](img/cf35f46a8dd5f11e58349c1d81611b75_231_0.png)

Figure 6.30 – Creating a VM: settings

- Set the Administrator account username and password as required:

![](img/cf35f46a8dd5f11e58349c1d81611b75_231_1.png)

Figure 6.31 – Creating a VM: settings (continued)

- Set Public inbound ports rules to None:

![](img/cf35f46a8dd5f11e58349c1d81611b75_232_0.png)

Figure 6.32 – Creating a VM: settings (continued)

- For this exercise, set Licensing at the unchecked default; that is, No use of an existing Windows Server license.

- Click Next: Disks.

- For this exercise, leave the Disks tab at the default settings:

![](img/cf35f46a8dd5f11e58349c1d81611b75_232_1.png)

Figure 6.33 – Creating a VM: settings (continued)

- Click Next: Networking.

- From Network interface, set the following:

  - **Virtual network**: Use the default provided

  - **Subnet**: Use the default provided

  - **Public IP**: Click Create new, enter a name, and click OK

  - **NIC network security group**: Select None

  - **Delete public IP and NIC when VM is deleted**: Check to enable/allow

  - Leave all other settings at their defaults:

![](img/cf35f46a8dd5f11e58349c1d81611b75_233_0.png)

Figure 6.34 – Creating a VM: settings (continued)

- Click Next: Management.

- Leave the settings at their defaults.

- Click Next: Advanced.

- Leave the settings at their defaults.

- Click Next: Tags and skip entering any information for this exercise. Then, click Next: Review + create.

- On the **Review + create** tab, _review your settings_; you may go back to the previous tabs and make any edits if required. Once you have confirmed your settings are as needed, you can click **Create**:

![](img/cf35f46a8dd5f11e58349c1d81611b75_234_0.png)

Figure 6.35 – Creating a VM: Review + create tab

- You will receive a notification that the resource deployment succeeded:

![](img/cf35f46a8dd5f11e58349c1d81611b75_234_1.png)

Figure 6.36 – VM deployment succeeded

## Task 5 – Adding an inbound rule to allow RDP access

- Navigate to the NSG created in this exercise. Notice that all _inbound connections_ are **denied** unless their source is **VirtualNetwork** or **Azure LoadBalancer**. We will address this in the next task.

- From the **Network security groups** blade, click **Inbound security rules** under **Settings**:

![](img/cf35f46a8dd5f11e58349c1d81611b75_239_0.png)

Figure 6.43 – Created NSG

- From the **Inbound security rules** blade, click + Add:

![](img/cf35f46a8dd5f11e58349c1d81611b75_239_1.png)

Figure 6.44 – Adding an NSG

- Open a browser and in Google, type what's my IP and note your IP for the next step.

- From the **Add inbound security rule** blade, set the following:

  - **Source:** Select IP Addresses

  - **Source IP addresses/CIDR ranges:** Set this to your IP from the Google result for your IP in step 4 of this task

  - Source port ranges: Leave at default of * (asterisk symbol)

  - Destination: Leave at default of Any

  - Service: Select RDP

  - Action: Ensure Allow is set

  - Priority: Leave at default of 100

  - Name: Provide a name, such as AllowInbound_RDP_KnownIP

  - Description: Enter one as required

![](img/cf35f46a8dd5f11e58349c1d81611b75_240_0.png)

Figure 6.45 – Adding an NSG (continued)

- Click Add.

- You will receive a notification that the rule was created successfully:

![](img/cf35f46a8dd5f11e58349c1d81611b75_241_0.png)

Figure 6.46 – NSG created

## Task 8 – Adding an outbound rule to deny internet access

- On the Virtual machine blade, click Networking under Settings; you will see from the Outbound port rules tab that all outbound connections are allowed to the internet.

- On the Outbound port rules tab, click Add outbound port rule.

- On the Add outbound security rule blade, leave all other options at their defaults apart from the following:

  - Destination: Select Service Tag

  - Destination service tag: Select Internet
