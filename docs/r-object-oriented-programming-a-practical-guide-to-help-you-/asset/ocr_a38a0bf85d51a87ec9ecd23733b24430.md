Because of potential ambiguities, it is usually advantageous to use the `difftime` command. The difftime command offers a wide range of options, and you should carefully read its help page, `help(difftime)`, to see the options and details. In its most basic use, you can find the difference between two times, and you can specify what units to use:

```
```r
> earlier <- strptime("2014-01-01 00:00:00", "%Y-%m-%d %H:%M:%S")
> later <- strptime("2014-01-01 12:00:00", "%Y-%m-%d %H:%M:%S")
> timeDiff <- difftime(later,earlier,units="sec")
> timeDiff
Time difference of 43200 secs
> timeDiff <- difftime(later,earlier,units="day")
> timeDiff
Time difference of 0.5 days
```
```

The units that are available are auto, secs, mins, hours, days, or weeks.

One final note; the `difftime` data type offers a convenient way to perform some time arithmetic options. The `as.difftime` command can be used to specify a time interval, and you can specify the units, so it is more likely that the results are consistent with your expectations:

```
```r
> later <- strptime("2014-01-01 12:00:00", "%Y-%m-%d %H:%M:%S")
