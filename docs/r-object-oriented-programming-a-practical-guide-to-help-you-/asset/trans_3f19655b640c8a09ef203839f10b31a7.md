
## 附录 A. 包管理

这里简要概述了如何使用包。作为参考，列出了用于管理包的基本命令。它并不详尽，仅作为管理与你所安装的 R 相关的包的简要参考。

本附录分为四个部分：

- 如何访问包的概述
- 如何安装包的概述
- 如何移除包的概述
- 如何更新包的概述

R 最大的优势之一是能够使用专门的包，而且有大量的包可用。有些包包含在常规安装中，有些包则必须单独安装和维护。我们简要概述了如何在你的系统上安装、移除和升级已安装的包。

我们首先讨论两个在处理包时常用的命令。第一个是`installed.packages`命令。该命令将列出安装中的所有包。另一个命令是`library`命令。`library`命令用于告诉 R 使用给定库中可用的命令。在以下示例中，第一个命令显示有关 splines 包的信息，第二个命令必须在使用 splines 包之前输入：

```r
> library(help = "splines")
> library(splines)
```

如果一个包不在你的安装中，你需要安装它。安装包的命令，奇怪的是，是`install.packages`命令。在以下示例中，car 包（用于额外的回归选项）被安装。这里不提供完整细节。你必须回答一系列问题，然后 R 将自动获取并为你安装该包：

```r
> install.packages("car")
```

使用`remove.packages`命令也可以轻松移除包。在以下示例中，我们移除了 car 包：

```r
> remove.packages("car")
```

最后讨论的主题是如何更新你的包。要更新所有包，只需使用`update.packages`命令。在以下示例中，输入了命令，但不提供完整细节。提交命令后，你会看到一个可以更新的包列表，然后你必须决定在你的系统上更新哪些包：

```r
> update.packages()
```
