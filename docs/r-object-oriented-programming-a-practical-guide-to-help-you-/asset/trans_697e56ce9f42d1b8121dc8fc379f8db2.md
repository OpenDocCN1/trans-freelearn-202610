## 前言

R 环境是一个强大的软件套件，最初是作为贝尔实验室开发的 S 语言的模型。最初的代码库由 Ross Ihaka 和 Robert Gentleman 于 1993 年创建。在其他人的帮助下，它迅速发展壮大，并从此成为统计计算的标准。该软件套件本身已远远超出了语言的实现范畴，演变成一个“环境”。它是可扩展的，种类繁多的可用软件包使其成为一个强大的资源，在受欢迎程度和功能方面持续增长。

本书旨在为使用 R 语言编程提供资源，我们假设您将使用 R 环境来实现和测试您的代码。本书大致可分为四个部分。在第一部分中，我们讨论了理解 R 如何对数据进行分类以及可用于从数据中进行计算的基本思想和主题。在第二部分中，我们讨论了 R 如何组织数据，以及可用于跟踪数据、显示数据、读取和保存数据的选项。在第三部分中，我们讨论了 R 语言特有的编程主题以及可用于面向对象编程的选项。在第四部分中，我们提供了几个扩展示例，以演示所有主题如何组合在一起解决问题。
