

## 本书涵盖内容

这里列出了各章节。前三章重点介绍将数据输入系统的基本要求，以及与数据计算相关的最基本任务。接下来的三章重点讨论在处理和检查数据时实践中遇到的各种问题，包括处理不同数据类型的具体机制。再接下来的三章重点介绍基础和高级编程主题。最后三章提供更详细的示例，以展示如何将所有思路结合起来解决问题。

- [第1章](#)，*数据类型*，概述了不同的数据类型。这包括基本表示形式，如浮点数、双精度数、复数、因子和整数表示形式，还包括如何通过交互式 shell 输入向量的示例。还简要讨论了最基本的操作以及如何与 R shell 进行交互。

- [第2章](#)，*组织数据*，更详细地介绍了数据在 R 环境中的组织方式。其他主题包括如何访问数据，以及如何对各种数据结构执行基本操作。所考查的主要数据结构是列表、数组、表格和数据框。

- [第3章](#)，*保存数据与打印结果*，详细介绍了将数据带入 R 环境的方法，并基于前一章讨论的主题进行了扩展。其他主题围绕结果的显示方式以及数据保存的各种方法展开。

- [第4章](#)，*计算概率和随机数*，详细考察了 R 语言中的概率和抽样特性。R 环境包含许多有助于数据分析的功能。任何统计分析都依赖于概率这一基础，这是一个不可忽视的主题。R 语言的优势之一在于提供了多种概率和抽样选项，本章将探讨其中一些选项。

- [第5章](#)，*字符和字符串操作*，详细考察了可用于检查、测试和执行字符串操作的各种选项。这是一个重要的主题，因为数据集存在不一致的情况并不少见，而从文件读取数据的例程应包含一些基本检查。

- [第6章](#)，*转换和定义时间变量*，详细考察了时间数据结构。第一章已经给出了基本介绍，本章将提供更多细节。时间相关数据的普遍存在使得这些数据结构的重要性不容忽视。

- [第7章](#)，*基础编程*，详细考察了 R 语言最基本的流程控制和编程特性。本章提供了条件执行以及各种循环结构的详细说明。此外，还讨论了与编写程序、执行和格式化相关的常见主题。

## 本书所需环境

假定你将在R环境中工作，示例代码已针对R 3.0.1及更高版本进行开发和测试。R环境是一种自由软件，由R基金会慷慨地提供。可以从[http://www.r-project.org/](http://www.r-project.org/)下载。本书前半部分的材料假定你可以使用R，并能在R环境中的交互式命令行下工作。后半部分的材料假定你熟悉编程，并能编写和保存计算机代码。至少，你应该拥有一个编程编辑器，并熟悉目录结构和搜索路径。

## 本书读者对象

如果你熟悉编程，希望初步了解R环境，并学习如何使用R语言创建编程应用程序，那么这本书适合你。我们假定你对R环境有所接触，并对R有基本的了解。本书不会对某些方法和实践进行大量动机性解释，因为假定读者能够自如地进行软件应用程序开发。
