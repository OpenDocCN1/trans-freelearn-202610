```r
> B <- matrix(1:12,nrow=3)

```

Both matrices and arrays can be manipulated to determine or change their dimensions. The dim command can be used to get or set this information:

```
```r
> C <- matrix(1:12,ncol=3)
> C
     [,1] [,2] [,3]
[1,]    1    5    9
[2,]    2    6   10
[3,]    3    7   11
[4,]    4    8   12
> dim(C)
[1] 4 3
> dim(C) <- c(3,4)
> C
     [,1] [,2] [,3] [,4]
[1,]    1    4    7   10
[2,]    2    5    8   11
[3,]    3    6    9   12
```
