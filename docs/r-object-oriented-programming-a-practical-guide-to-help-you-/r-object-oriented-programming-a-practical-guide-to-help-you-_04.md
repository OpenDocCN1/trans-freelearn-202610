## 第 5 章 字符与字符串操作

本章将为你全面概述可用于操作字符和字符串对象的各类操作。这一章相对简洁，重点放在基本操作上。本章大致分为两部分：

- **基本字符串操作：** 本节将为你全面概述最基本的字符串操作
- **正则表达式：** 本节将简要介绍三个使用正则表达式的命令

### 基本字符串操作

在某些情况下，数据以字符或字符串的形式保存；而在另一些情况下，必须对字符串进行解析或检查，作为统计分析的一部分。由于字符串形式的数据十分普遍，R 语言提供了丰富的字符串操作选项。在本章中，我们将考察其中一些可用的选项，并将考察内容分为两部分，如下所示：

- 第一部分，我们考察若干基本字符串操作，其功能聚焦于特定操作
- 第二部分，我们考察基于正则表达式的函数，这些函数提供了一套功能强大且适用范围广泛的操作

正则表达式的使用代表了一套强大的字符串处理工具，但代价是更高的复杂性。在本章中，我们仅关注这些函数最基本的用法，因为它们最常见的用途往往是更复杂代码的一部分，可能会使用到多种命令的复杂组合。

为了在命令之间建立联系，我们假设整章使用同一组数据集。具体来说，我们假设有一组 URL：

```r
> urls <- c("https://duckduckgo.com?q=Johann+Carl+Friedrich+Gauss",
             "https://search.yahoo.com/search?p=Jean+Baptiste+Joseph+Fourier",
             "http://www.bing.com/search?q=Isaac+Newton",
             "http://www.google.com/search?q=Brahmagupta")
```

### 六项针对性任务

我们首先考察六项具体任务。这些操作包括：确定字符串的长度、定位子字符串、提取或替换子字符串、改变字符串的大小写、将字符串拆分为多个部分，以及将多个对象组合为单个字符串。请注意，示例中将大量使用上一节中定义的 `urls` 向量。

#### 确定字符串的长度

`nchar` 命令用于确定字符串的长度。该选项既可作为一组字符串的简单统计量使用，也可在需要对字符串进行迭代时作为编程工具使用。你可以通过选项指定计数的计算方式，即按字符数、字节数或结果字符串的宽度来计数。在大多数情况下，这些值相同，但可能因环境中 Unicode 设置的不同而有所差异：

```r
> nchar(urls)
[1] 52 62 41 42
```

`nchar` 命令会尝试将其参数强制转换为字符串，这意味着它会把类型为 NA 的对象的值解释为字符串 "NA"。另一个副作用是，当用于因子时，该命令可能返回错误：

```r
> nchar(c("one", NA, 1234))
[1] 3 2 4
> nchar(as.factor(c("a", "b", "a", "a", "b", "c")))
Error in nchar(as.factor(c("a", "b", "a", "a", "b", "c"))) :
  'nchar()' requires a character vector
```

如果你在 UTF-8 这类 Unicode 环境中运行 R，该命令可能返回错误。如果是这种情况，请尝试使用 `allowNA=TRUE` 选项来查看结果是否合适。

最后一点说明：还有一个额外的命令 `nzchar`，用于测试字符串的字符宽度是否为零长度。该函数返回一个逻辑值；如果字符串的长度不为零，则返回 TRUE。举个例子，假设你有一个文件类型列表，其中的空字符串代表无法识别的文件类型。你可能希望使用 `nzchar` 创建一个掩码，以跳过或忽略空字符串：

```r
> fileTypes <- c("txt", "", "html", "txt")
> nzchar(fileTypes)
[1] TRUE FALSE TRUE TRUE
> fileTypes[nzchar(fileTypes)]
[1] "txt" "html" "txt"
```

#### 定位子字符串

在某些情况下，需要确定子字符串在字符串中出现的位置。例如，可能需要搜索一组文件名，以判断它们是否包含与预定参数匹配的内容。用于返回子字符串位置的命令是 `regexpr`。该命令有许多选项，将在下一节中更详细地探讨。这里，我们使用其最基本的形式来确定子字符串的位置。

以 `urls` 向量的定义为例，我们可能希望找出 URL 中冒号的位置。冒号是协议与主机名之间的分隔符，我们不能假设它总是在相同的位置：

```r
> colons <- regexpr(":",urls)
> colons
[1] 6 6 5 5
attr(,"match.length")
[1] 1 1 1 1
attr(,"useBytes")
[1] TRUE
> colons[2]
[1] 6
> colons[3]
[1] 5
```

请注意，第一个字符的假定位置是 1，而不是 0。

#### 提取或替换子字符串

有两个命令可用于更改字符串中的子字符串。这两个命令是 `substr` 和 `substring`，它们的参数相同。`substring` 命令与 S 语言兼容，但我们重点介绍 R 命令 `substr`。该命令有两种形式：一种形式用于提取子字符串，另一种形式用于更改子字符串的值。

首先，我们考察提取子字符串这一选项。该命令接受一个字符串、子字符串的起始位置和结束位置。沿用前面的示例，我们现在使用本章开头定义的 `urls` 向量，并确定每个 URL 的协议：

```r
> protocols <- substr(urls,1,colons-1)
> protocols
[1] "https" "https" "http" "http"
```

可以通过组合 `substr` 命令和赋值运算符来替换子字符串。遗憾的是，插入的字符串长度必须与被替换的字符串长度相同，这可能会产生不太直观的结果。这里，我们将 `urls` 向量中的每个协议替换为 `mailto` 协议：

```r
> colons <- regexpr(":",urls)
> mailto <- urls
> substr(mailto,1,colons-1) <- c("mailto","mailto","mailto")
> mailto
[1] "mailto://duckduckgo.com?q=Johann+Carl+Friedrich+Gauss"
[2] "mailto://search.yahoo.com/search?p=Jean+Baptiste+Joseph+Fourier"
[3] "mail://www.bing.com/search?q=Isaac+Newton"
[4] "mail://www.google.com/search?q=Brahmagupta"
```

请注意，字符串“http”的字符数少于字符串“mailto”，因此命令会截断替换到原字符串中的新字符串。

#### 创建格式化字符串

`sprintf` 函数可以将多个对象组合并表示为格式化字符串。`paste`、`format` 和 `print` 命令已在[第 3 章 *保存数据与打印结果*](#)中介绍过，这些函数也能实现类似的结果。主要区别在于 `sprintf` 函数的行为类似于 C 语言的 `sprintf` 函数。例如，假设我们有一个循环，对前面定义的 `urls` 向量中每个 URL 处找到的文本执行分析。作为分析的一部分，我们可能将计算结果存储在某个变量中，并希望在图表标题中使用该数字。在下面的示例中，为使示例更简洁，我们直接设置该值：

```r
> n <- 1
> calculation <- 123.0
> theTitle <- sprintf("URL: %s, Count=%d",urls[n],calculation)
> theTitle
[1] "URL: https://duckduckgo.com?q=Johann+Carl+Friedrich+Gauss, Count=123"
```

`%s` 表示参数列表中的一个字符串，`%d` 表示参数列表中下一个整数。这些定义遵循与 C 语言中 `sprintf` 定义相同的规范。





### 正则表达式

上一节中介绍的命令缺乏灵活性，但它们的实现方式简单直接。另一方面，在某些情况下，使用正则表达式可以提供更优雅的方法，但它们可能更复杂。我们简要了解一下几个允许通过正则表达式进行字符串操作的命令，并假设你已经熟悉正则表达式。要获取更多关于 R 中正则表达式的信息，可以使用 `help(regular expression)` 命令。

在本节中，我们将重点介绍 `gregexpr` 和 `gsub` 命令。当你输入 `help(gregexpr)` 命令时，还会列出许多其他命令。此外，这些命令有许多选项，但我们只介绍它们最基本的形式。需要提一下的是，之前讨论过的 `grep` 命令所接收的模式也可以是正则表达式。

`gregexpr` 命令是一个通用命令，它返回与正则表达式相关的结果数量。具体来说，它会返回匹配的位置、是否找到匹配项以及匹配项的字符数。该函数的第一个参数是一个模式，然后是待匹配的字符串。该函数返回一个包含匹配信息的列表。在下面的示例中，我们检查搜索前面定义的 `urls` 向量第一个元素中 `=` 分隔符的结果：

```
> loc <- gregexpr("=", urls[[1]])
> loc
[[1]]
[1] 25
attr(","match.length")
[1] 1
attr(","useBytes")
[1] TRUE

> loc[[1]][1]
[1] 25
```

请注意，该函数返回一个列表。由于使用单个方括号会返回另一个列表，所以我们使用双方括号以确保返回的是列表中的元素（作为一个向量）。

`sub` 命令可用于替换字符串中所有符合条件的模式。该函数接受三个参数：模式、替换字符串以及用于执行操作的字符串：

```
> sub("\\?.*$", "", urls)
[1] "https://duckduckgo.com"      "https://search.yahoo.com/search"
[3] "http://www.bing.com/search"  "http://www.google.com/search"
```

请注意，在前面的示例中必须使用两个反斜杠。第一个反斜杠用于表示下一个字符是一个需要被解释的符号；如果使用了第二个反斜杠，则意味着将这一对符号解释为一个反斜杠。

### 总结

在本章中，我们探讨了多种操作字符串变量的方法。我们研究了两大类方法。第一组函数提供了多种功能范围较窄的函数。这些函数相对简单直接，但通常需要配合使用才能完成复杂的任务。第二组函数使用正则表达式，可以通过少量步骤完成一组复杂的任务。
