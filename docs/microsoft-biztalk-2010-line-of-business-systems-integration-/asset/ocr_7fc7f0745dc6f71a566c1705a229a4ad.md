3. Once we have transformed the incoming Work Order Management message, to the InfoPath Message, we need to modify the InfoPath message in a Message Assignment Shape. The intention of this Message Assignment shape is to retrieve the name of the incoming message so that we can maintain the name of the file once it is published to SharePoint. By default, the SharePoint adapter will use a GUID as the file name if you do not provide a static or dynamic file name.
