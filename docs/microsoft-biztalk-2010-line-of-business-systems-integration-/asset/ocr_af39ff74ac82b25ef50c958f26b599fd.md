8. Within the Visual force environment, we have a choice of controller types. The standard controllers are associated with out-of-the-box Salesforce.com objects like Accounts. They expose operations like Save that save changes to the underlying object. A custom controller is one that does not use standard controllers and specifies entirely new behaviors. Finally, the controller extension extends either a standard or custom controller. We want to use the controller extension so that we get the existing operations and data associated with the Account controller while adding new functions to call the cloud.
