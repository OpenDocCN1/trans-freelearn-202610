10. When we download these artifacts, an issue appears in the **Lists_schemas_microsoft_com_sharepoint_soap.xsd** schema at compile time. The error we get is as follows:

![](bbox=[0.23, 0.21, 0.77, 0.24])

There appears to be a bug in the **Consume WCF Service** Wizard in that it inserts a schema import node that does not contain a **schemaLocation**.

![](bbox=[0.24, 0.3, 0.76, 0.56])

11. We can work around this bug by removing the first **<xs:import/>** node with no issues. In order to remove this line, open a text editor such as Notepad or edit the XSD file in Visual Studio by right mouse clicking on it, selecting **Open With**, and then selecting **XML Editor**.
