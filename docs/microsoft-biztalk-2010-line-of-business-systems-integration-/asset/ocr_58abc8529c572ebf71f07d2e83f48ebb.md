# Transactions

When calling BAPIs that perform Create, Update, or Delete operations, it is necessary to generate schemas for two additional operations:

+   - **BAPI_TRANSACTION_COMMIT**
+   - **BAPI_TRANSACTION_ROLLBACK**

Calling either of these operations is required since we may be manipulating multiple sets of data and we either want all of the data to be successful or none of it to be successful.

![](bbox=[0.25, 0.322, 0.75, 0.553])

For convenience purposes, we will generate all of these schemas at the same time. It is important to note that the BAPI_TRANSACTION_COMMIT and BAPI_TRANSACTION_ROLLBACK operations are generic and can be used in conjunction with other BAPIs. If you plan on having multiple BAPI integration scenarios within your environment, placing these schemas in a common project may be a more sustainable solution.
