1. In order to create a schema for the structure being returned from SharePoint, we can use the Generate Schemas feature that is part of the Add Generated Items Wizard.

![](bbox=[0.18, 0.2, 0.82, 0.34])

2. Once we are in the Generate Schemas Wizard, we want to ensure that our Document Type is set to Well Formed XML (Not Loaded) and then we can browse for a sample file. The sample file that we can use is called Sample_Response_From_Lists.xml and can be found in the SampleDocs folder in this Chapter's source code. Once we have found this document we can click on OK to proceed to the next step.

> The sample file has been provided for your convenience. If you want to generate your own sample message from SharePoint, send in your SharePoint List request and then write the response message to your file system.
