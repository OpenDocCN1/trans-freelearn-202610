+   - **Type** – This will contain a value of the System.Data.SqlClient. SqlNotificationType enumeration. Most of the time this will be a change, indicating that there was a change on the data of the notification query. Please refer to the MSDN for the detailed information on these enumerations.

When the **NotifyOnListenerStart** binding option, in our Receive Location, is set to true, a notification message with hardcoded values of Info = ListenerStarted, Source = SqlBinding, and Type = Startup is generated by the adapter.
