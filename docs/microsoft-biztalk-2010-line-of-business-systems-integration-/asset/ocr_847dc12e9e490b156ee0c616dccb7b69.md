7. In the Metadata Address (URL), we need to provide the location of our Lists.asmx Web Service. For example: http://localhost:8080/sites/BizTalkLineOfBusiness/Lists/VehicleMaintanence/_vti_bin/lists.asmx. In this case, BizTalkLineOfBusiness is the name of the SharePoint site, Lists is the location of all lists within this site, and the name of the list we are trying to consume is called VehicleMaintanence. Since the Lists.asmx is not specific to any Custom List, we can generate the schemas from any Lists.asmx endpoint and use it against any list. By providing the URL of the Lists.asmx endpoint, we can click on the Get button and view all of the Web Methods that make up the Lists.asmx Web Service.
