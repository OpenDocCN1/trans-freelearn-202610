# Summary

Microsoft Dynamics CRM 2011 offers a host of options for integration. While it no longer provides a strongly-typed SOAP interface for BizTalk to consume, we have multiple ways to send messages to Dynamics CRM. To send messages from Dynamics CRM to BizTalk Server, we have numerous choices, including the plugin model that we demonstrated in this chapter. As Dynamics CRM 2011 matures in the market, expect to see additional creative ways to integrate it with BizTalk Server.
