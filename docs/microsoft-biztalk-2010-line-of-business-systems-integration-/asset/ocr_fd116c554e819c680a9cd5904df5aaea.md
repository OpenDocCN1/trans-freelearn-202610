# Building a Visualforce page that consumes the cloud service

In this step, we construct a Visualforce page and Apex controller. The controller is responsible for acquiring the Access Control token and then passing that token into a Service Bus call. The Visualforce page contains the markup needed to display the Account details and Service Bus results:

+   1. Our on-premises and cloud-connected environment is ready for consumption. Go to Salesforce.com and get into the Setup screens.

![](bbox=[0.428, 0.315, 0.573, 0.525])

+   2. In order for a call between Apex code and Azure to succeed, we have to explicitly allow outbound calls to the Service Bus endpoints. Specifically, we have to register the Azure Access Control and Service Bus URLs with our Salesforce.com account. Under Administration Setup, navigate to Security Controls, and click on Remote Site Settings.
