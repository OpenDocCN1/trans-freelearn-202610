5. Now, whenever BizTalk picks up an approved Vacation Request, it will make an archive copy of the form in this Forms Library. Up until this point, we have performed the following actions:

+   - Designed an InfoPath form
+   - Created a Forms Library
+   - Published the InfoPath form and created custom columns
+   - Updated the form to submit to our Forms Library
