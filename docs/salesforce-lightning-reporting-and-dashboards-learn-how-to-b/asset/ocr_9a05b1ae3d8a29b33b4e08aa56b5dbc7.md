# Filtering by Relative Date

If you need the report to always filter with a specific time frame, such as last month, this month, last quarter, and so on, instead of putting in a fixed date, you can select a relative date option. With relative date, when you create a report called Last Month Opportunities Won, you do not need to adjust the close date manually every month.

First of all, when you configure the report, you need to add the Date Field to the filter drop zone, not the one in the Date Field filter, see the following screenshot for adding filter on drop zone filter:
