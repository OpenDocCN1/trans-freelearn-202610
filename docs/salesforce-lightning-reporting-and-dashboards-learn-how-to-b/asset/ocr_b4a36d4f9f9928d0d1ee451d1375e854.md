There are two types of Standard Report Types:

+   - The report type that comes with Salesforce for standard objects, such as **Contacts & Accounts**. You can easily distinguish this report type, as it will have a **Preview** when you select that report type when creating a new report.

![](bbox=[0.104, 0.191, 0.894, 0.485])

+   - The report type is autogenerated when you enable the **Allow Report** option for a custom object. This report type will not have **Preview**, but it will just say **No preview available**.

When you relate an object to another object and both objects are enabled for reports, the following options will happen depending on the relationship. In the following example, we will use Customer (custom object) as the parent object and Claim (custom object) as the child object. Both objects have been enabled for the report.
