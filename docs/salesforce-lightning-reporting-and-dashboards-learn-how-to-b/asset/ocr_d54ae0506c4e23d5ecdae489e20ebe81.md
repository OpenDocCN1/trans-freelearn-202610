# Hands-on exercise for creating a Tabular report

Let's consider a use case. We are tasked with showing the first five accounts, sorted by the number of employees in descending order, and filtering with account Type contains Customer. In this exercise, we assume that you have more than five accounts with Type contains Customer text exists, and the number of employees is populated:

+   1. Navigate to the **Reports** tab and click on **New Report..** button.
+   2. Select the **Accounts** Report Type and click on the plus sign under the **Accounts & Contacts** category.
+   3. Click on the **Create** button to continue.

![](bbox=[0.103, 0.333, 0.896, 0.698])

4. Now we are in the **Report Builder**, with the preview showing a limited number of records.
