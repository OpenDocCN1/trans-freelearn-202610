There are two permissions related to this permission, which is as follows:

+   - **Subscribing to reports by adding recipients**: This permission will allow you to add other users to get the e-mail delivery. By default, you are included, but you can remove yourself when you add someone else.

+   - **Subscribing to reports by setting a running user**: This permission will allow you to specify the running user as someone else as long as that user has access to the report.
