Perform the following steps for this hands-on exercise:

+   1. Navigate to the Dashboards tab, look for the Account Dashboard dashboard, and click on the Edit link under the arrow on the right-hand side of the dashboard name. Alternately, you can open the dashboard and then click on the Edit button.
+   2. Click on the gear icon; if you hover your mouse over, the label is called Edit Dashboard Properties.
+   3. Under View Dashboard As, at this moment, Me should be selected.
+   4. Change this to The logged in user, and select Allow dashboard viewers to change this (dynamic dashboard).
+   5. Click on the Save button to close the properties window.
+   6. Click on the Save button again to save the dashboard changes and then click on Done to exit the Dashboard Builder.
