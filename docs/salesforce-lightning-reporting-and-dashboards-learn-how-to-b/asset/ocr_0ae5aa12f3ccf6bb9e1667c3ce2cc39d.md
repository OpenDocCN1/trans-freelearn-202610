To schedule refresh a dashboard, perform the following steps:

+   1. Open the dashboard from Classic.
+   2. Click on the arrow near the **Refresh** button. This is not available for free editions of Salesforce.
+   3. Click on **Schedule Refresh....** Consider the following screenshot:

![](bbox=[0.105, 0.244, 0.895, 0.486])

Next, you need to configure the following:

+   4. **Email Dashboard:** Use this if you (and your team) would like to get emails with the dashboard when it is auto-refreshed.
+   5. **Frequency:** Daily, Weekly, Monthly.
+   6. **Start Date** and **End Date**.
