When opening a dynamic dashboard, the user without the **View My Team's Dashboards** permission will not be able to change the dashboard viewing user. However, a user with this permission will be able to change and enter a user in his/her team in the role hierarchy as viewing user. # Schedule dashboards

We will discuss dashboards in *Chapter 9, Building Dashboards in Lightning Experience*, but for now, you should know that when you open a dashboard, it does not present the latest data, but the data of the dashboard last refreshed by you, or refreshed by your colleague, or data scheduled for auto-refresh.

Salesforce offers the ability to refresh a dashboard up to a limit for a user with the **Schedule Dashboard** permission. I will share more on this in *Chapter 9, Building Dashboards in Lightning Experience*, but for now, just note that we can schedule dashboard refresh, and e-mail the dashboard to ourselves or to other users.

As of the Summer ’17 release, this feature is only available in Classic, and not yet in Lightning Experience.
