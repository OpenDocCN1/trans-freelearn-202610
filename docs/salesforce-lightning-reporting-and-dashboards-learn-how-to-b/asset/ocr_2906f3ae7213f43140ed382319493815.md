# Report and dashboard folders sharing

The same with creating the report and dashboard folder, as of the Summer '17 release, sharing the public reports and dashboards folder can be done in Classic only.

Click on the **Reports** tab, hover your mouse over the folder you want to share, and click on the pin icon next to the folder name--you will see the **Share** option. If you just see **Pin to top** and **Share**, but not **Edit** and **Delete**, that means you are not the Manager for that folder. We'll walk through the folder access level in this chapter.
