# Working with reports in the Salesforce1 app

There are a few options to access reports in the Salesforce1 mobile app. Let us discuss them in detail.

# Report menu items

If you do not see the Reports menu in the Salesforce 1 app menu, make sure to add it-- navigate to Setup | Apps | Mobile Apps | Salesforce1 Navigation, select Reports, and add the selected items. This is shown in the following screenshot:
