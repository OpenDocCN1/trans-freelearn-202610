# # The Cross Filter

With **Cross Filter**, you can create a report for an object and dependencies to other objects and their fields. You can use the **WITH** keyword, such as **All Account WITH Opportunity**. Furthermore, you can also use the **WITHOUT** keyword for an exception report, such as **Account WITHOUT Closed Won Opportunity this year**. This report is important for the sales manager and the management team to evaluate dormant customers.

> > This filter will not be available in a **Joined** format or any report where the report type does not allow optional related objects
