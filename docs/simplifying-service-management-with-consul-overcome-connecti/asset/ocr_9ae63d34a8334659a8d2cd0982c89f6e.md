The `consul-agent-ca-key.pem` file is the private key for the CA (Consul is our CA). The public CA file, `consul-agent-ca.pem`, was pushed to all the machines as part of the image build process. By using the provisioners within the `aws_instance` resource, we are transferring the remaining to each of the three servers (0, 1, and 2) and placing them in the `/etc/consul/consul.d/` directory.

Utilizing the file provisioner, we are also adding an ACL configuration file to the server. This is just to help us when the time comes for us to start playing with ACLs. When we provision our clients, there are a couple of small changes we have to make. First, we must move a new configuration file to the clients to help with the ACL configuration. We're also adding the CA file to the configuration:
