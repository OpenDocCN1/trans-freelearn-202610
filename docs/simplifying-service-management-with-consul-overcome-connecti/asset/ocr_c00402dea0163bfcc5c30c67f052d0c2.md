From here, you can generate your admin token, access the cluster URL in a web browser, and you're ready to go! In order to add clients, download the client configuration and distribute it to your Consul clients. The downloaded package includes the certificate that clients require to access the system, and any additional configuration necessary, and that's all you need to begin your journey into HashiCorp Consul in the cloud!
