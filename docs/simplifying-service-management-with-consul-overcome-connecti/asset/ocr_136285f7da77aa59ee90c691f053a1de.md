Creating the namespaces themselves only requires a simple `write` command. For good measure, we're going to view the namespaces we created as well:

```
```text
# consul namespace write shawn.hcl
Name: shawn
Description:
    Shawns namespace for his funny antics and visions
# consul namespace write gus.hcl
Name: gus
Description:
    Gus' namespace to track his pharmaceutical distribution
# consul namespace list
default:
    Description:
        Builtin Default Namespace
gus:
    Description:
        Gus' namespace to track his pharmaceutical distribution
shawn:
    Description:
        Shawns namespace for his funny antics and visions
```
```

Note that there is a default namespace value that will capture all the data that hasn't been explicitly associated with a namespace.
