# HashiCorp Cloud Platform

If you are ready to fire up services but you don't want to take on the operational management of the Consul system, I strongly recommend signing up for the HashiCorp Cloud Platform. All of that work setting up the server and securing it is done for you. Getting started is really easy, just by signing up at the following URL: https://cloud.hashicorp.com/.

Part of the process requires you to create your own organization, and once that is complete, you have access to the HashiCorp Cloud Platform.
