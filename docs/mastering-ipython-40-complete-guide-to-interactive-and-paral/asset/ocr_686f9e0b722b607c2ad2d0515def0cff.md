# Bulleted lists

Bulleted lists work just like enumerated lists, except that:

+   - The only allowed counters are -, +, and *
+   - There is no delimiter

Bulleted lists support the usual rules for indentation.

# Definition lists

A definition list is just a series of term-definition pairs. The term is on the first line and the definition is in the following paragraph, which is indented. Here is an example:

```
do
    a deer, a female deer
re
    a drop of golden sun
mi
    a name i call myself
fa
```
