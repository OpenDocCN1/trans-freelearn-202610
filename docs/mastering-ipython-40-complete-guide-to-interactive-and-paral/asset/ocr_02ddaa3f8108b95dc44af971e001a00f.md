# Publisher

This is the publisher. It uses a PUB socket to send the time and weather to an arbitrary number of subscribers:

```
```python
import zmq
import random

context = zmq.Context()
socket = context.socket(zmq.PUB)
socket.bind("tcp://*:5678")

while True:
    topic = "load"
    socket.send(topic + " " + str(random.random()))

    topic = "weather"
    messagedata = "dark and stormy night"

# Subscriber

This subscriber uses a SUB socket to listen to the preceding publishers. It is, however, only interested in the weather:

```
```python
import zmq

context = zmq.Context()
socket = context.socket(zmq.SUB)
socket.connect("tcp://localhost:5678")
socket.setsockopt_string(zmq.SUBSCRIBE, "weather")

while True:
    wtr = socket.recv_string()
    print("the weather is: " + wtr)
```
