# An initial graph

```
In [2]: x = randn(90000)
```

```
In [3]: hist(x, 300)
Out[3]:
```

+   - Two arrays and a list (the return values of the hist call)
+   - A stack trace (which went away when I deleted my matplotlib font cache in ~/.cache/matplotlib/fontList*.cache)
