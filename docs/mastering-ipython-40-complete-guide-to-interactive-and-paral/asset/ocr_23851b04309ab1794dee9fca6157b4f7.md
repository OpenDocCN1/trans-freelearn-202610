# Assertions, setup, and teardown

As in pytest, nose2 uses the assert statement found in Python. It does not use the same fixture style as pytest, but it does support both a modified form of the classic xUnit-style setup and teardown along with its own set of fixtures.

> The testing features of nose2 are currently a little buggy when using testing classes. The examples that follow will use individual testing functions contained in modules, but they should otherwise work similarly to the previous examples.
