# Welcome to Microsoft Defender External Attack Surface Management (EASM)!

Microsoft maintains an inventory of internet-facing devices and services (assets) which can be used to discover an organization’s attack surface.

Search from a list of pre-built attack surfaces to understand your organization’s internet exposure.

![](bbox=[0.205, 0.203, 0.783, 0.418])

Figure 9.5 – Setting up EASM in Azure

Many of the largest enterprises have data listed there. However, if your organization does not come up, you need to click on the button at the bottom of the search menu labeled Create a custom attack surface.

Here, we need to define assets that the service will start and crawl to look for information. We can enter information such as organization names, domains, IP blocks, hosts, email contacts, ASNs, or whois organizations.
