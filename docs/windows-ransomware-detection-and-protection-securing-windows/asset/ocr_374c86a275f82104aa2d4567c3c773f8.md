Many legacy systems today rely on implicit trust, which is also one of the fundamental risks that ransomware operators utilize so they can move laterally through the network once they manage to gain access.

So, these are just some examples of services that rely too much on just usernames and passwords for authentication without checking the context, which is an important aspect of any zero-trust-based security architecture.

A zero-trust architecture consists of five distinct pillars, which are then measured at various levels of maturity. The pillars are as follows:

+   - Identity
+   - Device
+   - Network/Environment
+   - Application
+   - Data
