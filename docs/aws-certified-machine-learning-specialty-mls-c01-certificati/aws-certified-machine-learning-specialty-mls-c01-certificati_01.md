# 前言

AWS Machine Learning Specialty 认证考试测试你在 AWS 基础设施上执行 **机器学习 (ML)** 的能力。本书深入使用实际示例涵盖整个考试大纲，帮助你在 AWS 上进行实际机器学习项目。

从 AWS 机器学习的介绍开始，你将学习机器学习的基础知识并探索用于 **人工智能 (AI)** 的重要 AWS 服务。然后你将看到如何为机器学习准备数据，并发现针对不同类型变量的不同数据操作和转换技术。书中还涵盖了缺失数据和异常值的处理，并带你了解分类、回归、聚类、预测、异常检测、文本挖掘和图像处理等各种机器学习任务，以及你应了解的特定 ML 算法，以通过考试。最后，你将探索模型评估、优化和部署，并掌握在生产环境中部署模型并对其进行监控的方法。

到本书结束时，你将获得对机器学习所有关键领域的知识，以及 AWS 为每个领域发布的解决方案，以及在 AWS 机器学习的每个领域中常用的工具、方法和技术。

## 本书适合谁阅读

本书适合想要参加并通过 AWS Machine Learning Specialty 考试或希望更深入了解以 AWS 为重点的机器学习的专业人士和学生。需要熟悉机器学习和 AWS 服务的基础知识。

## 本书涵盖内容

*第一章，机器学习基础，涵盖了一些机器学习定义、不同类型的建模方法，以及构建机器学习产品所需的所有步骤，即建模管道。*

*第二章，AWS 用于 AI/ML 的应用服务，涵盖了 AWS 提供的各种 AI/ML 应用的细节，你应了解这些内容以通过考试。*

*第三章，数据准备和转换，涉及分类和数值特征，应用不同的技术来转换数据，例如独热编码、二进制编码、序数编码、分箱和文本转换。你还将学习如何处理数据中的缺失值和异常值，这两个是构建良好机器学习模型的重要主题。*

*第四章，理解和可视化数据，教你如何根据不同的变量类型和业务需求选择最合适的数据可视化技术。你还将了解用于可视化数据的可用 AWS 服务。*

*第五章，AWS 用于数据存储的服务，教你关于用于机器学习存储数据的 AWS 服务。你将了解许多不同的 S3 存储类别以及何时使用它们。你还将学习如何处理数据加密以及如何在静态和传输中保护数据。最后，我们将介绍其他类型的仍值得为考试了解的数据存储服务。*

*第六章，AWS 用于处理的服务，教你关于用于机器学习处理数据的 AWS 服务。你将学习如何处理批处理和实时处理，如何直接查询 Amazon S3 上的数据，以及如何在 EMR 上创建大数据应用。*

*第七章，应用机器学习算法，涵盖不同类型的机器学习任务，例如分类、回归、聚类、预测、异常检测、文本挖掘和图像处理。这些任务各自具有特定的算法，你应了解这些算法以通过考试。你还将学习集成模型的工作原理以及如何处理维度灾难。*

*第八章，评估和优化模型，教你如何选择模型指标来评估模型结果。你还将学习如何通过调优其超参数来优化模型。*

*第九章，Amazon SageMaker 建模，教你如何启动笔记本进行探索性数据分析以及如何在 Amazon SageMaker 上训练模型。你将学习训练数据应存储在何处以及如何存储，以便通过 SageMaker 访问，以及可使用的不同数据格式。*
