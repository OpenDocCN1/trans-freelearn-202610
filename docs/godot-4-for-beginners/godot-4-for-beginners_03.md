# 第 2 部分
## 使用 Godot 引擎

在本书的这一部分，你将加深对如何有效使用 Godot 引擎的实践知识。我们将通过清晰的解释和实际示例，开始 demystify 向量，任何游戏开发人员工具包中最重要的工具之一。然后，你将通过在两个章节中构建一个完整的 2D 小游戏，将你的技能付诸实践。这个动手项目将指导你完成完整的游戏创建过程，从脚本化玩家机制到设计关卡和处理游戏逻辑。到这一部分结束时，你将拥有经验和信心开始在 Godot 中构建自己的 2D 游戏。

本书的这一部分包含以下章节：

- *第 5 章，理解向量*
- *第 6 章，在 Godot 中创建 2D 小游戏 – 第 1 部分*
- *第 7 章，在 Godot 中创建 2D 小游戏 – 第 2 部分*
