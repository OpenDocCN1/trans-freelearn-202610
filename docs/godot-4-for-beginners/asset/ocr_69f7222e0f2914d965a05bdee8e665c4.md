# Vector addition

We use **addition** to update an object’s position by adding a movement vector to its current position. For example, when you move a character across the screen, you add a direction vector to the character’s position vector in each frame.

Vector addition is shown in Figure 5.10. The corresponding x and y values are added together (Vector A(2,5) in blue added to Vector B(3,1) in green, which results in Vector C(5,6) in red).

![](bbox=[0.33, 0.28, 0.63, 0.56])

Figure 5.10 – Adding Vector (2,5) to Vector (3,1), resulting in Vector (5,6)

Figure 5.10 also shows that the order in which you add the vectors doesn’t matter, as the resulting vector will always be the same.
