Because some of our tiles need to be solid and some need to be pass-through, we will add a second element to Physics Layers of the TileSet, then name the layers so that we can keep track of the interactions. Do this by clicking on the three vertical dots to the right of the layer numbers and clicking on Edit Layer Names. I have named Layer 1: player, Layer 2: ground, and Layer 3: pass_through.
