A vector with a length of 1 is called **normalized**. So, how do we normalize a vector (set its length to 1)?

It’s simple: we just divide each component by the vector’s length.

Since this is such a common operation, Godot has a built-in function to do it for us. The function is called normalized() and can be used in our example as follows:

```
extends Node2D

# Called when the node enters the scene tree for the first time.
func _ready():
    # Normalize direction vector so it has a length of 1
    direction = direction.normalized()

    # Calculate velocity by multiplying direction by speed
    velocity = direction * speed
```
