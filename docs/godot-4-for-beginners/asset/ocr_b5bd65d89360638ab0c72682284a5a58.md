# Running tests

Return to the Level 1 scene. Drag the View scene into the level. Drag the Player scene into the level. Select the View node and drag the Player scene into the Target property of View, as shown in Figure 8.22:

![](bbox=[0.37, 0.21, 0.63, 0.41])

Figure 8.22 – Setting the player as the target for the camera to follow

Now select the Player node. In Inspector, drag the View scene into the View property so that the player uses our View scene as the Camera Controller. This is shown in Figure 8.23:

![](bbox=[0.37, 0.51, 0.63, 0.71])

Figure 8.23 – Setting our View scene as the camera controller for the player

Now run the Level 1 scene and test the game. You can move the player and the camera around the level!
