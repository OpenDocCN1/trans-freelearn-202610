## Understanding GDScript

Godot 拥有自己的内置脚本语言 GDScript，这是一种类似于 Python 的高级编程语言。与 Python 不同，GDScript 针对 Godot 的基于场景的设计理念进行了优化，并且可以指定变量的严格类型。

脚本用于为我们的节点编程自定义行为。在接下来的几个小标题中，我们将了解如何创建脚本、编辑它们并保存它们。
