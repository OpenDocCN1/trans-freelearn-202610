The *Player progression and objectives* page links to anchor points on the main page. As a web-based document, this would typically be a hyperlink, but these points also connect conceptually, guiding how the game unfolds over time.

To define progression clearly, it’s helpful to break it down into two layers:

+   - **Core gameplay loop:** The core gameplay loop represents the fundamental actions the player repeats to play the game. For example, in a platformer, this might involve running and jumping to traverse a level, attacking enemies, and avoiding hazards.
+   - **Outer loop:** The outer loop, on the other hand, describes the broader progression system—how players are rewarded for engaging with the core loop. This could include unlocking new levels, gaining upgrades, or progressing through a story.

The core loop should feed into the outer loop, and vice versa, creating a satisfying and reinforcing gameplay experience.
