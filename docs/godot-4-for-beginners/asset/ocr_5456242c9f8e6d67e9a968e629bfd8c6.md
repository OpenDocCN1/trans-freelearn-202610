# Summary

In this chapter, we explored how to build and organize scenes for a level. We started by creating simple scenes using **StaticBody3D**, **MeshInstance3D**, and **CollisionShape3D** nodes to represent objects in the game world.

Next, we designed a **Player** scene with a script to control movement and added a separate **View** scene featuring a **Camera3D** node that players can control. Finally, we brought everything together by assembling a complex level scene, combining all our individual scene components.

In the next chapter, we will add hazards and collectibles.
