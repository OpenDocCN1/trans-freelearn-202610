# Exploring the Godot Engine Interface

In this chapter, you will edit your first project in Godot 4 and explore the fundamental features of the interface. You will also gain a deeper understanding of the node and scene design philosophy that underscores Godot. It is fundamental to using Godot day in and day out to understand how it is intended to be used.

In this chapter, we’re going to cover the following main topics:

+   - Important terms
+   - Editing an existing Godot project
+   - Creating an additional scene
+   - Reacting to player input

By the end of the chapter, you’ll be able to create new projects, build scenes, and navigate the interface with ease—essential skills for any game developer.
