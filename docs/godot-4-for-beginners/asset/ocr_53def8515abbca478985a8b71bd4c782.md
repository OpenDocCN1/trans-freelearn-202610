# Vector subtraction

**Subtraction** helps calculate the distance or difference between two points, such as the distance between a player and an enemy, which can be used for collision detection or AI behaviors.

**Vector Subtraction** works in a similar way—subtracting each component individually, vector subtraction helps determine a vector that points from one position to another.

For example, imagine a ball is positioned at **(1,2)** and a hole is at **(4,3)**. To find the direction the ball needs to roll to reach the hole, you can find the difference by subtracting the ball’s position from the hole’s position.
