+   - The cannonball scene is loaded from the specified path, and we store it in the scene variable. The preload keyword ensures the scene is ready to use when the game runs and offers a performance improvement over the load function when using GDScript.
+   - An instance of the Ball scene (a copy of the original scene) is stored in the ball variable.
+   - A reference to the Marker3D node is stored in the marker variable.
+   - The position of the newly created cannonball is set to match the position of marker.
+   - Finally, the ball instance is added to the Cannon node hierarchy (scene tree), making it visible and active in the scene.
