# Creating a 3D Mini-Game in Godot — Part 1

Creating a well-structured 3D game world requires understanding how to compose scenes, design levels, and implement functional controllers. In this chapter, we’ll jump into the essential building blocks of 3D game creation in Godot. By learning how to compose and organize scenes, you’ll develop a solid foundation for creating dynamic, interactive environments.

You’ll start by building a 3D character scene and attaching a script to control its movement. Next, you’ll learn how to design levels by combining static objects, collisions, and meshes. We’ll also implement a camera controller that provides a smooth and responsive player view. Finally, we’ll integrate everything into a complete level and test it to ensure functionality.

In this chapter, we’re going to cover the following main topics:

+   - Working in 3D: a new dimension in Godot
+   - Building a 3D character
+   - Creating a level design
+   - Working with a Character Controller script
+   - Using variables
+   - Exploring functions
+   - Implementing a camera controller
+   - Running tests
