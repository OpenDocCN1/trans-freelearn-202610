# Emulated Siemens network stack

Follow these instructions to install the Siemens stack on the Ubuntu machine you built for the Siemens emulation:

+   1. Log into the Ubuntu machine and open a terminal.
+   2. Run the `sudo apt install python-pip python3-dev` command to install the required Python packages.
+   3. Switch to an elevated (sudo) terminal with `sudo su` since the port the Siemens server will run on is in the lower range of port numbers (below 1000), which requires root privileges to assign.
+   4. Run the `pip3 install -upgrade pip ipython` command to install the required Python dependencies.
