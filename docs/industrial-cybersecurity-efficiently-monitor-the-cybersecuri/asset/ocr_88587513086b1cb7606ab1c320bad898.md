The cause of this delay is the fact that we chose to configure Snort in **Legacy Mode** instead of **Inline Mode**. **In Legacy Mode**, Snort makes decision based on copies of packets instead of inspecting packets inline and making block or allow decisions before the packets make it into the industrial network. **Inline Mode** is therefore more secure, but it will not work on all hardware.
