In this command, the real magic happens with grep -E '(^|\s)SHA256' | awk '{ print $2}' | sort | uniq, where we have the following:

+   - grep -E '(^|\s)SHA256' uses a regular expression to catch any lines with a SHA256 strings from the file.
+   - awk '{ print $2}' will print only the SHA256 hash from the line that was output by grep.
+   - sort sorts the output from awk.
+   - uniq only shows unique values.
