# ## Design

The IDMZ broker-service scenario that allows device and URL filtering for network traffic originating in the Industrial Zone and aimed at the internet is built around a Squid proxy server (http://www.squid-cache.org/) installed as a service on a VM, running the CentOS Linux operating system (https://www.centos.org/) deployed in the IDMZ.
