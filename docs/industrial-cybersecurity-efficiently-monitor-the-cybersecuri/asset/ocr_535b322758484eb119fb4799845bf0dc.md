d) Switch to the **Header** tab and set the following:

**Severity**—Set this to **DEBUG** (drop to **WARNING** after verification things are working).

**Host name**—Set this to `SilentDefense-001` .

**Application name**—Set this to `NetworkLogs` .

e) That is all the configuration we need for the network logs. Click **Finish** , located at the top of the screen.

That is all the configuration we need to get syslog messages sent from the SilentDefense Command Center to the Security Onion server.
