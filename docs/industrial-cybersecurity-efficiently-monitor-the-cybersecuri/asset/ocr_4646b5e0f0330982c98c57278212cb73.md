# Vulnerability discovery

Host-based agents can be used to (periodically) scan the endpoint they are installed on for vulnerabilities such as missing patches, misconfigured services, and other security-related issues. The agent's functionality is to interrogate the endpoint it is installed on for versions/revisions/configuration for any relevant part of the system, and then send that list over to the vulnerability management solution that deployed the agent. The solution will then verify the versions/revisions/configuration against a database to identify any known vulnerabilities.
