When we run this command, we are faced with a long list of services that all use the host process svchost.exe with PID 1040. This is a common nuance with older Windows systems (Windows 7 and beyond are better at limiting the number of services per host process instance). The most common way for a service to be implemented through a host process such as svchost is by having the host process load a dll (short for dynamic link library) with all of the service code in it, so let's have a look at all the dlls loaded by process 1040, using the dlllist Volatility command:
