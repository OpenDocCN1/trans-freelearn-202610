# Deploying a pfSense VM

In order to get a pfSense VM up and running, follow along with the next instructions:

+   1. Head on over to https://www.pfsense.org/download/ and download the latest version of the pfSense install ISO file. Make sure to select the proper architecture for your hardware (AMD64 if you install on a virtual platform) as well as choosing the CD Image (ISO) Installer media, as illustrated in the following screenshot:

![](bbox=[0.18, 0.28, 0.82, 0.62])

Figure 6.39 – Exercise 2: Downloading pfSense

+   2. As we did in the previous exercise, create a new VM in VMware Workstation and attach the freshly downloaded ISO image to install from.
