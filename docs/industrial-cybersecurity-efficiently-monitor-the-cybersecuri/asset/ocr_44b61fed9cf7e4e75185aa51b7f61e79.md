# Emulated CIP network stack

Follow these instructions to install the CIP stack on the Ubuntu machine you built for the CIP emulation:

+   1. Log into the Ubuntu machine and open a terminal.
+   2. Run the `sudo apt install python-pip python3-dev` command to install the required Python packages.
+   3. Run the `pip3 install -upgrade pip ipython` command to install the required Python dependencies.
