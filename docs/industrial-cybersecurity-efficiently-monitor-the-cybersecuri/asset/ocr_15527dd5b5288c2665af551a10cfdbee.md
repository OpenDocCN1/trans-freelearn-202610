# SMB

The first service we will interrogate is the **Server Message Block**, or SMB. SMB is what allows file and printer sharing functionality. Nmap has a few scripts that can help us discover a variety of information from the SMB service. We can list all the scripts that Nmap has for SMB interrogation by running the following command on our Kali Linux machine:
