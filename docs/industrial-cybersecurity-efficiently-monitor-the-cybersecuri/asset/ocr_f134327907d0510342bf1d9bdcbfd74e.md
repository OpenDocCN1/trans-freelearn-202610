As an example, the following command will go out and read the status of coils (%M) 1 through 5:

```
# modbus read 172.25.200.21 %M1 5
```

| %M1 | 1 |
| %M2 | 1 |
| %M3 | 1 |
| %M4 | 1 |
| %M5 | 1 |

Modbus-cli can also be used to write to coil/registers, as shown here, by writing a 0 to coil number 1:

```
# modbus write 172.25.200.21 1 0
```

The following command writes a 0 to coil 1, which we can verify worked correctly by running the following code:

```
# modbus read 172.25.200.21 1 5
```

| 1 | 0 |
| 2 | 1 |
| 3 | 1 |
| 4 | 1 |
| 5 | 1 |
