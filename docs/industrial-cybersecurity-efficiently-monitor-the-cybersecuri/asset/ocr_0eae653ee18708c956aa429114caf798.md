As you can see, the Sysmon tool adds a tremendous amount of detail around the process start event. We can see who started the PowerShell process (user.name), from what application the process was started (*.parent*), where the process executable file is located (process.executable), the command-line arguments (process.command_line), the process ID, the process and parent executable file hashes (winlog.event_data.hashes), and so on.
