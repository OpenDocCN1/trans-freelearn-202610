To capture both types of login attacks (brute-force attacks), we are going to create a visualization that trends failed login attempts over time. Follow along with these instructions to create a graph widget:

+   1. Navigate to our **Breach Detection** dashboard (**Kibana | Dashboards | Breach Detection**) and click on **Edit** in the top left of the dashboard screen.
+   2. Click on the **Create New** button to add a new widget (visualization).
+   3. Select the Vertical Bar visualization type and search for and add the Security Onion - Alerts data source.
+   4. Add a Split Series data bucket and set **Aggregation** to **Terms**, with `winlog.event_data.targetUserName.keyword` as the **Field** selection. Set the **Size** option to 50.
+   5. Add an X-axis data bucket and set **Aggregation** to **Data Histogram**, and then click **Update**.
+   6. This sets the aggregation as a timeline display, viewing all alerts' target username logs over time.
+   7. Now for the magic: click on the **Add Filter** button, then set the **Field** option to `event.code` and the **Operator** option to `is one of`.
