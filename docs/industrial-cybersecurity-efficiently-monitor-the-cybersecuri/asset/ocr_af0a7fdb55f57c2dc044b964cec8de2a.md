# ## Logging and alerting

Along with proper packet capturing, all equipment in the ICS environment should be configured to generate events, logs, and alerts, and a SIEM solution should be used to aggregate and correlate all those events, logs, and alerts, known as event forwarding. Setting up event forwarding, deploying SIEM, and visualizing of all this data is covered in later chapters.
