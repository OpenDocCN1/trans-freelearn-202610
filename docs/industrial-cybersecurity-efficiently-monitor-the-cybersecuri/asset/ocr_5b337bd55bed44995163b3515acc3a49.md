# Asset management

The first capability of SilentDefense we will be looking at is asset management. The product manages by merely passively monitoring the network traffic on its sniffing interface to build a map of the network it is monitoring. It also tries to overlay discovered assets on a Purdue model, where assets are categorized as belonging to one of the following Purdue model levels:

+   - Level 4 - Site Business Network
+   - Level 3 - Site Operations and Control
