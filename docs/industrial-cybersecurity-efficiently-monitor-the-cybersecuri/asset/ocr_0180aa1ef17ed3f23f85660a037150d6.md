One detail I need to point out is how Wazuh knows to start looking for PowerShell Script Block logs. Well, if you recall from Chapter 6, Passive Security Monitoring, we changed the configuration file for the Wazuh agent to include this snippet:

```
<localfile>
  <location>Microsoft-Windows-PowerShell/Operational</location>
  <log_format>eventchannel</log_format>
</localfile>
```

As with the Sysmon logs, the preceding code instructs Wazuh to start monitoring the PowerShell log, sending any new entries to Security Onion to be added into the Elasticsearch database.
