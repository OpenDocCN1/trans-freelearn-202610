# Penetration Testing ICS Environments

In this chapter, we will be talking in detail about the tools, techniques, methodologies, and activities that are used when performing penetration tests in the **industrial control system (ICS)** environment. We will learn how penetration tests are the most effective if they’re based on real-world attack **tools, techniques, and procedures (TTPs)** by referencing the Cyber Kill Chain. We will also discuss how to perform penetration test engagements with no risk to the production process, by building a test bed and approximating the industrial environment under scrutiny. By the end of this chapter, you will have gained the required knowledge and hands-on experience to perform these types of assessments yourself.

We will cover the following topics in this chapter:

+   - Practical view of penetration testing
+   - Why ICS environments are easy targets for attackers
+   - Typical risks to an ICS environment
+   - Modeling pentests around the ICS Kill Chain
+   - Pentesting results allow us to prioritize cybersecurity efforts
