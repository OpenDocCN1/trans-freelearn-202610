# Event logs

The next major source of security-related data that we can use for security monitoring activities is event logs. Most computer systems and network devices have the ability to record system events, including details surrounding the event—hence the name event log. On some systems, the event log is a plaintext file where applications or the system itself record events. These types of event logs can be viewed with a text editor.
