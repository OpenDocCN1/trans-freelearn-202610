+   4. Run the following commands to get the required installation files and install them:
+   - `git clone git@github.com:pjkundert/cpppo.git`
+   - `cd cppo`
+   - `python setup.py install`

5. Now, you can start an EtherNet/IP (CIP) listening server with the following command:

```
enip_server --print SCADA=INT[1000] TEXT=SSTRING[100] FLOAT=REAL
```

6. This starts the server with 1000 INT tags, 100 string tags, and a FLOAT tag exposed.
