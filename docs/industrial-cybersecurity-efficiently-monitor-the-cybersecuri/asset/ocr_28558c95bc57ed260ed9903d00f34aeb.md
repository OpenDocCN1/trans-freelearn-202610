On the system where you want to deploy the malware, open an elevated (administrator) Command Prompt and run the rundll32.exe IPRIPa.dll,install command:

![](bbox=[0.132, 0.145, 0.867, 0.28])

Figure 19.16 – Installing the IPRIPa.dll malware

This installs the malware as a service. You can start the service with the net start IPRIP command:

![](bbox=[0.132, 0.359, 0.867, 0.691])

Figure 19.17 – Starting the IPRIP service

The malware will now start trying to reach out to http://very-malicious-website.com every 10 minutes, until the service is deleted (sc delete IPRIP). Because we installed the malware as a service, it will survive reboots as well.
