Now, let's look at the functions:

![](bbox=[0.13, 0.225, 0.485, 0.505])

Figure 20.11 – The BP_Configurator functions

This is what each function does:

+   * **initConfigVarSets**: It gets the Variant Sets of the Level Variant Sets Actor and stores them in the `ObjectVariantSets` array, the `EnviroVarSet` variable, and the `CameraVarSet` variable.
+   * **resetAllVariants**: Calls the **resetVariant** function for `EnviroVarSet`, `CameraVarSet`, and each element of the `ObjectVariantSets` array.
+   * **resetVariant**: Resets a Variant Set by activating the first element of the Variant Set.
+   * **callVariantActorAction**: Calls the `Variant Switched On` function for all Actors and components used by the current Variant that implements the `BPI_RuntimeAction` interface. This allows Actors to run script when the Variant is activated.
