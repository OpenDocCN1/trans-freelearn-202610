Now that we have a template selected and the project settings set up the way we like, we can create the project. To do so, follow these steps:

+   1. Click on the blue Create button. After the engine is done with initializing the assets and setting up your project, the Unreal Editor will open the Level Editor.

+   2. Press the Play button to try the default gameplay that is built into the First Person template. You must click on the viewport for the game to start reacting to input.
