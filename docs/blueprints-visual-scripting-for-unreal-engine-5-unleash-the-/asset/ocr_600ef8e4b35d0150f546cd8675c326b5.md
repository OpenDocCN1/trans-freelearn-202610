# # Map

A **map** container uses a key-value pair to define each element. The key type can be different from the value type. A map is unordered and is searched by using the key value, so duplicate keys are not allowed. Duplicate values, however, are allowed.

These are the steps to create a map:

+   1. Create a variable, and in **Variable Type**, select the type that will be used as the key type.
+   2. Click on the icon next to the **Variable Type** drop-down menu, and select the icon of a map, as shown in the following screenshot.
+   3. After that, you need to choose the value type on the second dropdown that appeared. The example in the following screenshot uses **String** as the key type and **Float** as the value type:
