# AnimGraph

In the **AnimGraph**, we use nodes to play Animation Sequences and Blend Spaces. We can also create State Machines to organize the animation into states.

The **AnimGraph** can only access variables from the Animation Blueprint, so we use the **EventGraph** to get the updated values from the Pawn.
