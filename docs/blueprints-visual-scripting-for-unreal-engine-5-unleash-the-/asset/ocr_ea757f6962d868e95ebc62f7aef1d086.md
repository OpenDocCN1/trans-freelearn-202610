# # Overlapping a patrol point

We will use **Event ActorBeginOverlap** to verify when an instance of `BP_EnemyCharacter` reaches one of its two patrol points, and then we swap the patrol point that the instance is moving toward. Every time we update the **CurrentPatrolPoint** variable, we need to call the **UpdatePatrolPointBB** macro.

In **Event BeginPlay**, we will set an initial patrol point to **CurrentPatrolPoint** and call the **UpdatePatrolPointBB** macro.
