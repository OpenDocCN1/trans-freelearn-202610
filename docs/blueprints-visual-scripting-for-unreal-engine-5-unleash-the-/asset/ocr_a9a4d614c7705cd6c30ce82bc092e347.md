# Points and vectors

There is a structure in Unreal Engine named **Vector**, which has three
variables of the float type: **X**, **Y**, and **Z**. Same as the concept of a vector in
mathematics, this **Vector** can be used to represent a point (location) in 3D
space or velocity (speed in a specified direction).
