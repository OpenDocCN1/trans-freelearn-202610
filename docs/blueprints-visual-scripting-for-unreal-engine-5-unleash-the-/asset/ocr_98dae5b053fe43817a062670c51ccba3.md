# # Creating the third function and testing

In the third function, we will use local variables to store temporary values. Local variables are only visible within the function where they are defined. The values of local variables are discarded at the end of the function execution.

Another important point to note is that we will use only one Random Integer in Range node to generate the values of the three dice.

These are the steps to create the third function and test:

+   1. In the My Blueprint panel, click the + icon at the right of FUNCTIONS. Name the function RollThreeDice:
