The Branch node takes a Boolean variable as an input. Since Boolean values can only be either True or False, the Branch node can produce only two outcomes. These two outcomes can be executed by linking additional nodes to the two output execution pins, representing the True path and the False path.

The first step of creating Branch is to determine what will be represented by your Boolean, and what will cause the conditional value to change from False to True. In our case, we want to create a Primed variable to show that the target has been hit and that it could be destroyed with a second hit. Let's go ahead and create a Primed Boolean variable:
