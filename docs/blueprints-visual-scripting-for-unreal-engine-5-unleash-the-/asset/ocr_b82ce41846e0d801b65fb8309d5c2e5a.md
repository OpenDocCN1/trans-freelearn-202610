The functions created in an Editor Utility Blueprint will appear in the **Script Actions** submenu when you right-click an Asset or an Actor in the level. To create functions that will manipulate Assets in the content browser, you need to select **AssetActionUtility** as the parent class. To manipulate Actors in the level, use **ActorActionUtility** as the parent class.
