# Figure 6.16 – Projectile variables

First, find the **Initial Speed** and **Max Speed** fields, which are currently set to 3000. **Initial Speed** determines how fast the projectile travels when it is first created at the tip of our gun, and **Max Speed** determines how fast it can go if an additional force is applied to it after creation. If we had a rocket, we might wish to apply acceleration to the rocket after it is launched to signify the thruster engaging. However, since we are representing a bullet coming from a gun, it makes more sense to make its initial speed the fastest that the bullet will ever travel at. Adjust both **Initial Speed** and **Max Speed** to twice their original value: 6000.
