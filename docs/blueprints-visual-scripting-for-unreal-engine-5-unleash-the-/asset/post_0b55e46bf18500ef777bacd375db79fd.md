## Important Information

In most cases, Event BeginPlay will call the subsequent Actions as soon as the game is started. If the Blueprint instance isn't present when the game starts, then instead, it will trigger as soon as the instance is spawned. Since the `FirstPersonCharacter` player instance is present as soon as the game begins, attaching the displaying logic to this event will create the HUD immediately.
