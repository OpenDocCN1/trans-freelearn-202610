# Selecting the patrol points in the BP_EnemyCharacter instance

We created the **PatrolPoint1** and **PatrolPoint2** variables as **Instance Editable** in `BP_EnemyCharacter` to be able to set them in the Level Editor.

These are the steps to selecting the patrol points:

+   1. In the Level Editor, select the instance of `BP_EnemyCharacter` that we placed on the level.

+   2. In the **Details** panel, navigate down to the **Default** category and set **Patrol Point 1** to the **PatrolPoint1** instance and **Patrol Point 2** to the **PatrolPoint2** instance:
