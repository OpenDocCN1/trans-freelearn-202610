

## 设置带混合的视图目标

设置带混合的视图目标节点是 **玩家控制器** 类的一个函数。它用于在不同摄像机之间切换游戏视图。**新视图目标** 输入参数是要设置为视图目标的角色，通常是一个摄像机。

## 启用输入和禁用输入

启用输入和禁用输入节点是用于定义角色是否应响应输入事件（例如来自键盘、鼠标或游戏手柄的输入事件）的函数。这些节点需要引用正在使用的 **玩家控制器** 类。

这些节点的常见用途是允许角色仅在玩家靠近角色时接收输入事件，如下面的屏幕截图所示：

![](img/e1fd47ad71d32bbc4bf189d4cf9ed94d_536_0.png)

图 15.35 – 启用输入和禁用输入节点示例

当玩家开始与 Blueprint 重叠时，会调用 **启用输入** 节点。当玩家结束与 Blueprint 重叠时，会调用 **禁用输入** 节点。

## 设置输入模式节点

有三个 **设置输入模式** 节点，用于定义处理用户输入事件的优先级是在 UI 还是在玩家输入上。这些节点如下：

- **仅设置输入模式为游戏**：只有 **玩家控制器** 接收输入事件。
- **仅设置输入模式为 UI**：只有 UI 接收输入事件。
- **设置输入模式为游戏和 UI**：UI 在处理输入事件方面具有优先权，但如果 UI 未处理，则 Player Controller 接收输入事件。例如，当玩家与代表商店的 Blueprint 重叠时，会显示一个带有选项的 UI，供玩家选择使用鼠标，但玩家仍然可以使用箭头键远离商店。

![](img/e1fd47ad71d32bbc4bf189d4cf9ed94d_537_0.png)

图 15.36 – 设置输入模式节点

## 探索 VR 模板

Unreal Engine 编辑器有一个 Blueprint VR 模板，使开始尝试 VR 开发变得容易。VR 模板使用 OpenXR 框架，这是 VR 和增强现实开发的开放标准。得益于 OpenXR，VR 模板可在多个设备上运行，无需任何特定平台的修改。

如果你的计算机上安装了 VR 显示设备并设置为开发模式，则可以通过单击 **播放** 按钮的下拉菜单并选择 **VR 预览** 以 VR 模式启动关卡。如果你没有 VR 显示设备，可以使用 **播放** 按钮的 **新建编辑器窗口** 选项启动关卡，并按 *Tab* 键切换旁观者模式。你将能够使用 *W、A、S* 和 *D* 键以及鼠标在关卡中移动。

在 VR 模式下，你可以通过按下右侧运动控制器的摇杆向上来标记位置并释放摇杆以执行瞬移，从而在关卡的不同位置之间瞬移。关卡中的某些对象可以被抓取。要抓取一个对象，请将运动控制器靠近对象并按住抓握按钮。要释放对象，请松开抓握按钮。

模板中使用的 Blueprint 位于 **Content > VRTemplate > Blueprints** 文件夹中。让我们了解它们的工作原理，以便更轻松地将它们适应到我们的项目中。此外，这将是一个观察 Blueprint 实际示例的绝佳机会。
