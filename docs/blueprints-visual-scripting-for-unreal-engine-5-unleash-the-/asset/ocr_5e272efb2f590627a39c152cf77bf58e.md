Now that we have our **Branch** node set up, we need to provide the target Cylinder with instructions on what to do in each state. Namely, what should happen when it is first hit (the **Primed** variable is **False**) and what should happen when it is hit a second time (the **Primed** variable is **True**).

Let's handle when the target is hit for the first time. In this case, we must change **Material** to **TargetRed**. Additionally, we will also have to set our **Primed** Boolean variable to **True**.
