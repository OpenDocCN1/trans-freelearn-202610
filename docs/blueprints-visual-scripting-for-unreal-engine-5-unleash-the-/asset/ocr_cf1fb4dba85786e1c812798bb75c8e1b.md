# # Displaying a target goal in the HUD

First, we need to create a variable in the **FirstPersonCharacter** Blueprint that will establish how many targets we are asking the player to destroy to win the game. Then, we need to display this information to the player in the **HUD** Blueprint.

Follow these steps to display the target goal:

+   1. In the **Content Browser**, access the /Content/FirstPersonBP/Blueprints folder and double-click on the **FirstPersonCharacter** Blueprint.

+   2. In the **VARIABLES** category of the **My Blueprint** panel, click on the + sign to add a variable, name it **TargetGoal**, and change **Variable Type** to **Integer**.

+   3. Compile the **FirstPersonCharacter** Blueprint and set **Default Value** to 2 for now:
