# Creating your local project

Select **Create a new project** at the bottom of the window and search using the `function` keyword in the search box, as follows:

![](bbox=[0.148, 0.19, 0.867, 0.5])

Figure 4.3 – Creating a new Functions app

Select the **Azure Functions** template and then select **New** to configure the project. This template creates a C# class library project that you can publish to a function app in Azure. We will provide the project name. Select the location and then select **Next**. You can change the solution name and check **Place solution and project in the same directory**:
