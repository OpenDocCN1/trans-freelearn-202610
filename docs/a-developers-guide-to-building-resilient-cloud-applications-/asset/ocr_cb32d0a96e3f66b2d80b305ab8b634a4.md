# Bindings

Binding to a function is a method of declaratively connecting another resource to the function. Bindings can be connected as input bindings, output bindings, or both. Some examples of bindings include the following:

+   - Cosmos DB: Connect to the database to be able to load or save files easily
+   - Table Storage: This uses the key/value storage from your functions app
+   - Queue Storage: This retrieves one or more items from a specific queue, or places a new one in the queue

You can use different bindings by mixing or matching them according to your scenario.
