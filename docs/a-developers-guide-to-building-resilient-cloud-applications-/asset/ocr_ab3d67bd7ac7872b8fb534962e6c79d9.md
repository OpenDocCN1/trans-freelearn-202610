You can implement your orchestrator according to your needs and add or delete the generated methods.

We can create an orchestrator function using the Azure portal. In Azure Functions, we will select Functions from the left pane, then select Add from the top menu.

In the search field of our new function page, we can use the durable keyword and then select the Durable Functions HTTP starter template.

We are requested to provide a function name. After, we can click on the Create function.

We implemented an orchestrator function using Visual Studio 2022, but let's review some of the orchestration patterns that Durable Functions provides. We will start with the function chaining pattern.
