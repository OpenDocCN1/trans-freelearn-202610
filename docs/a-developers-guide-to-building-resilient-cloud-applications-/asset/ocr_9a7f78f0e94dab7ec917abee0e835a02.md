# # 香港特别行政区政府 社会福利署

# ## 2024/25年度 关爱基金援助项目

+   - 为租住私人楼宇的综援受助人士提供津贴
+   - 为居住于不适切住房的综援受助人士提供津贴
+   - 为低收入家庭提供津贴

| 项目 | 津贴金额（港元） |
| --- | --- |
| 租金津贴 | 200 - 5,000 |
| 不适切住房津贴 | 300 - 1,200 |
| 低收入家庭津贴 | 1,000 / 个月 |

本计划旨在纾缓低收入家庭的经济压力，改善其生活质素。申请人必须通过入息及资产审查，并符合相关居住要求。

> > 「关爱基金」为未能纳入安全网或虽已纳入安全网但仍有特定需要的人士提供支援。

申请方法：
1. 填妥申请表格；
2. 连同所需证明文件副本；
3. 递交至所属地区社会福利署办事处。
