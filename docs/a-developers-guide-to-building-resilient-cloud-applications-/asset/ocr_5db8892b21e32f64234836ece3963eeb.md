# Fan-out, fan-in

Fan-out, fan-in is a pattern that runs multiple activity functions in parallel and then waits for all the activities to finish. The results of the parallel executions can be aggregated and used to compute a final result. This pattern is very hard to use without a framework such as Durable Functions:
