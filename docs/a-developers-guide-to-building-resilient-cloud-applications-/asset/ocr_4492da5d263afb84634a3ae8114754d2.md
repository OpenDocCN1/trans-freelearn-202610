Once the API has been imported, and the backend has been configured, it’s time to test the API. In the next section, we will learn how to test our API in the Azure Management API service.

# Testing the API

We need to select the Test tab. On the left, we will find all operations related to our API. On the right of the page are the query parameters and headers, if any. Ocp-Apim-Subscription-Key is auto-populated for the subscription key associated with this API. Another selection will show a list of methods. We can select a method, for example, BillingList, then click on Send.
