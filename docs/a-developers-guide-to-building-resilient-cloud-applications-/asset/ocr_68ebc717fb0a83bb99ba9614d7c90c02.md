To customize the file or files you upload, you can click Advanced and then select the authentication type, blob type, blob size, tier, and folder. We’re going to leave the defaults. Once the file or files have been uploaded, you can then change the specific settings for that file.

You could view or edit the file, download it, see the properties, generate the shared access signature, view the snapshots, create snapshots, and change the tier if you wanted to do so.
