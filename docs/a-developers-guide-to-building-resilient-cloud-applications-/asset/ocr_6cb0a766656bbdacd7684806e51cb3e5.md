Let’s describe the workflow. We have all these actions:

+   1. When a customer places a new order, the application (web or mobile) submits a message to the **service bus queue**. The message includes the order details.
+   2. Azure Functions separates the orders placed for the products to be submitted to the topic, and the other orders are sent to the service bus queue.
+   3. The product order will further be separated based on order category using **topic subscription rules**. This topic filters, by category, the orders into two subscriptions using **subscription rules**.
+   4. Azure Functions retrieves the price of the ordered product from the storage table and calculates the price of the order.
+   5. An invoice will be created based on the price, and a notification will be sent to the customer—including the product details and the invoice—using Microsoft Outlook.
