Link to thickness is a very useful option for ensuring that cuts are made correctly even if the sheet size changes later. However, there are certain situations where it may not give the outcome that we want, such as cutting across bends, as shown in the following example:

+   1. Add an Edge Flange to the short edge of the Base Flange nearest to the cut.
+   2. This can be done by selecting Edge Flange from the Sheet Metal tools and then selecting the appropriate edge. Use the following settings:

+   - Angle: 60°
+   - Flange Length: Blind, 50mm, Outer Virtual Sharp
+   - Flange Position: Material Outside
