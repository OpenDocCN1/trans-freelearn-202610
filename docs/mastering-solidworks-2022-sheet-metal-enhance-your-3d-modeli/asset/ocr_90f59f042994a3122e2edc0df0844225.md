Editing the flange profile in this way allows more flexible use of Edge Flanges and unlocks the ability to create many different shapes.

# The Custom Bend Allowance and Custom Relief Type options

Two more minor options in the **Edge Flange** settings can be found at the bottom of the Property Manager and they are the **Custom Bend Allowance** and **Custom Relief Type** options (*Figure 2.21*). These allow the global *part* settings from the `Sheet-Metal` properties folder to be overridden for specific features. They can be used in exactly the same way as the options within the **Sheet-Metal Properties** feature, as covered in *Chapter 1, Sheet Metal Basics – Exploring Sheet Metal Properties and Material Selection.*

# The Trim side bends option

The final setting in the **Edge Flange** options is the **Trim side bends** option. This automatically trims away material in corners where two Edge Flanges meet and can be useful for avoiding manufacturing issues that can occur in tight corners with adjacent bends.

This is best explained using the following example:

+   1. Delete the Edge Flange feature from your current *part* so that only the Base Flange remains.

+   2. Add a new Edge Flange feature on one of the short edges. This Edge Flange should run the entire length of the edge (just use the default flange profile that is automatically selected).
