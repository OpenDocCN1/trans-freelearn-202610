**Note**
**Sheet thickness selection**
The thickness of your sheet metal parts will depend on exactly what you need to do, and how they will be manufactured and used. Thinner sheet thicknesses will result in parts that are lighter (and cheaper!) but if you are creating large parts then thin sheets can lack rigidity.
**Bend Allowance selections**
In *Chapter 1, Sheet Metal Basics – Exploring Sheet Metal Properties and Material Selection*, we discussed the different types of Bend Allowance in detail, but if you are unsure which Bend Allowance type to use, then the safest option is usually to set a K-Factor of 0.5.
You may also find it helpful to seek advice directly from your manufacturing partner.

Next, we can build up the enclosure base by adding some walls. We could use a simple **Edge Flange** feature, but in my example, I am going to use a **Miter Flange** feature.

**The Advantages of Using a Miter Flange Feature**
The **Miter Flange** feature allows you to create more complex flange shapes using only a single feature, instead of using multiple **Edge Flange** features to build the same profile. The **Miter Flange** feature will also automatically miter any corners (trim them to fit together properly), whereas not all **Edge Flange** types will do this.
