# 11
Converting to Sheet Metal Using the Insert Bends Tool

3D models with a constant wall thickness (for example, *Shelled* or *Thin Feature* parts), can be converted into Sheet Metal *parts* by using the **Insert Bends** tool. This chapter shows how to use this tool to create Sheet Metal parts.

By the end of this chapter, learners will be able to confidently use the Insert Bends tool.

In this chapter, we're going to cover the following main topics:

+   - Using the Insert Bends tool with Shelled parts
+   - Using the Insert Bends tool with Thin Feature parts
