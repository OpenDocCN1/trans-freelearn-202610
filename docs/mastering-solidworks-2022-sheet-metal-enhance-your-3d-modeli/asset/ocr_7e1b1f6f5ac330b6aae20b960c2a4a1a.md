One final important aspect of using the **Convert to Sheet Metal** tool is that bends have to be selected in order:

+   1. Edit the **Convert Solid** feature again so that we are back in the tool's Property Manager.
+   2. Clear all of the selections in the **Bend Edges** selection box. Then select the five edges in the order shown in *Figure 12.11*. If you try to select an edge that is not connected to the Fixed Face (for example, if you try to select Edge 4 before selecting Edge 3) then a warning will pop up; edges must be selected in the correct order so that they are connected to the Fixed Face.
+   3. After selecting Edge 5 note that the **Rip Edges** automatically appears on the top-right edge.
