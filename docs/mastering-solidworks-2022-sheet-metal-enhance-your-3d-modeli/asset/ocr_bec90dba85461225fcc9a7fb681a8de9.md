3. We can now start creating the Vent feature. Select the Vent tool and use the sketch to populate the fields in the Property Manager. I used the following parameters (Figure 13.23):

+   - **Boundary**: Select the outer (40mm) circle.
+   - **Ribs**: Select the five straight lines. The ribs are 2mm thick.
+   - **Spars**: Select the middle (32mm) circle. The spars are 2mm thick.
+   - **Fill In Area**: Select the smallest (24mm) circle.
+   - **Set a 2mm radius**: This will round off all of the sharp internal corners of the vent:
