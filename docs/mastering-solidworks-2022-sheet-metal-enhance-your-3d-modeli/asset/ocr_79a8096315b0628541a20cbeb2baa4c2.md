# Summary

In this chapter, we learned how to create basic 2D sheet metal drawings, as well as how to use **Ordinate Dimensions** and how to add **Flat Patterns** to drawings. We also explored some of the different 2D file types that can be used to export your Sheet Metal models for production in the real world.

In the next chapter, we will look at a more advanced flange type—the **Swept Flange**—and we'll discover how to use the **Fold** and **Unfold** tools, and why these are important.
