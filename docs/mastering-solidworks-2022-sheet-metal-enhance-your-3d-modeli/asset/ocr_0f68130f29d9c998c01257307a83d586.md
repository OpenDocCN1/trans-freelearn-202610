4. Close the Section View and select the Insert Bends tool from the Sheet Metal tab or toolbar.

The Insert Bends Property Manager appears (Figure 11.3). We can use this to set the default parameters of the Sheet Metal part (such as the Bend Radius and Auto Relief). Note that the Thickness setting is unavailable because the thickness is determined by the actual thickness of the solid part.

Set a Bend Radius of 2mm and keep the other settings as the default values.
