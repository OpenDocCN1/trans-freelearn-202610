## Stepwise regression method for variable selection

In stepwise regression method, a base regression model is formed using the OLS estimation method. Thereafter, a variable is added or subtracted to/from the base model depending upon the **Akaike Information Criteria (AIC)** value. The standard rule is that a minimum AIC would guarantee a best fit in comparison to other methods. Taking the `Cars93_1.csv` file, let's create a multiple linear regression model by using the stepwise method. There are three different ways to test out the best model using the step formula:

- Forward method
- Backward method
- Both

In the forward selection method, initially a null model is created and a variable is added to see any improvement in the AIC value. Independent variables are added to the null model until there is an improvement in the AIC value. In backward selection method, the complete model is considered to be the base model. An independent variable is deducted from the model and the AIC value is checked. If there is an improvement in AIC, the variable would be removed; the process will go on till the AIC value becomes minimum. In the both method, alternatively forward and backward selection is used to identify the most relevant model. Let's look at the model result at first iteration:

```r
> #base model
> fit<-lm(MPG.Overall~.,data=Cars93_1)
> #stepwise regression
> model<-step(fit,method="both")
```
