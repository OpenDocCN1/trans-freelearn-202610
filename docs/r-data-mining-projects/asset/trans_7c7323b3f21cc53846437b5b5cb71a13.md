## 非参数方法

当训练数据集因不符合特定概率分布的假设而不服从任何特定概率分布时，分析数据的唯一选择就是使用非参数方法。非参数方法不遵循有关概率分布的任何假设。使用非参数方法，可以在不遵循任何假设的情况下进行推断和假设检验。现在，我们来看一组非参数检验，当数据集不符合任何特定概率分布的假设时，可以使用这些检验。

### Wilcoxon符号秩检验

如果不满足正态性假设，则需要应用非参数方法来回答诸如此类的问题：自动挡和手动挡汽车在城市内的平均油耗里程是否存在差异？

```
> wilcox.test(Cars93$MPG.city~Cars93$Man.trans.avail, correct = F)
Wilcoxon rank sum test

data: Cars93$MPG.city by Cars93$Man.trans.avail
W = 380, p-value = 1e-06
```

```

alternative hypothesis: true location shift is not equal to 0
```

如果两个样本恰好是配对样本，且样本不满足正态性假设，可以使用`paired`参数：

```
> wilcox.test(Cars93$MPG.city, Cars93$MPG.highway, paired = T)
Wilcoxon signed rank test with continuity correction

data: Cars93$MPG.city and Cars93$MPG.highway
V = 0, p-value <2e-16
alternative hypothesis: true location shift is not equal to 0
```

### Mann-Whitney-Wilcoxon检验

如果两个样本不匹配、相互独立，且不服从正态分布，则需要使用Mann-Whitney-Wilcoxon检验来检验两个样本的均值差异在统计上是否显著不同：

```
> wilcox.test(Cars93$MPG.city~Cars93$Man.trans.avail, data=Cars93)
Wilcoxon rank sum test with continuity correction

data: Cars93$MPG.city by Cars93$Man.trans.avail
W = 380, p-value = 1e-06
alternative hypothesis: true location shift is not equal to 0
```

### Kruskal-Wallis检验

要比较两个以上组的均值，也就是方差分析的非参数版本，可以使用Kruskal-Wallis检验。它也被称为无分布假设的统计检验：

```
> kruskal.test(Cars93$MPG.city~Cars93$Cylinders, data= Cars93)
Kruskal-Wallis rank sum test

data: Cars93$MPG.city by Cars93$Cylinders
Kruskal-Wallis chi-squared = 68, df = 5, p-value = 3e-13
```

## 可视化钻石数据集

如果没有适当的数据可视化，任何数据挖掘项目都是不完整的。仅看数字和统计数据时，或许也能看出不同切工下这些变量的相似规律，但当我们以可视化方式观察变量与因素之间的关系时，呈现的却完全是另一番景象。因此，数据可视化传达出数字和统计无法传达的信息。从数据挖掘的角度来看，数据可视化有许多优点，可以概括为以下三个要点：

- 数据可视化在数据与数据使用者之间建立了强有力的沟通
- 它能留下持久的印象，因为人们可能记不住数字，但会记住图表和形状
- 当数据扩展到更高维度时，用数字表示没有意义，但可视化表示却有意义

在本章中，读者将了解数据可视化的基础知识，以及如何使用R编程语言中的现有库创建高级数据可视化。通常，数据可视化方法可以从两个不同的角度来考虑：

- 你想向受众展示什么？是比较、关系还是其他功能？
- 你想如何展示这些洞察？哪种图表或图形方式最适合直观地展示这些洞察？

基于上述两点，我们先来看看数据可视化的规则以及每种可视化背后的理论，然后再来看使用R脚本实现图形和图表的具体实践。

## 可视化钻石数据集

考虑到前面提到的十个要点，可以根据你想要表示的内容制定数据可视化规则，来选择最佳表示方式：

- 两个变量之间的关系可以用散点图表示
- 两个以上变量之间的关系可以用气泡图表示
- 为了理解样本量较小的单个变量的分布，可以使用直方图
- 为了理解样本量较大的单个变量的分布，可以使用密度图
- 两个变量的分布可以用散点图表示
- 3个变量之间的分布关系可以使用3D散点图表示
- 任何带有时间戳的变量，如日、周、月、年等，都可以用折线图表示
- 时间应始终位于水平轴上，要度量的指标应始终位于垂直轴上
- 每个图形都应有名称和标签，这样用户不必再回到数据中才能理解它表示什么

在本章中，我们将主要关注`ggplot2`库和`plotly`库。当然，我们还会介绍一些更有趣的库来创建数据可视化。R中的图形包可以按以下顺序进行组织：

- 绘图
- 图形应用（例如效应排序、大型数据集和树、以及图形）
- 图形系统
- 设备
- 颜色
- 交互式图形
- 开发

有关支持上述功能的各种库的详细说明，可以参阅链接`https://cran.r-project.org/web/views/Graphics.html`。为了获得良好的可视化效果，我们需要更多的数据点，以便提高图形的密度。在本节中，我们将使用两个数据集`diamonds.csv`和`cars93.csv`来展示数据可视化。
