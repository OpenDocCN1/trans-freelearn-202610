# # Useful Wireshark links

The main Wireshark link is of course [http://www.wireshark.org](http://www.wireshark.org). Here you can find:

+   - The downloads page at [http://www.wireshark.org/download.html](http://www.wireshark.org/download.html).
+   - The learning page at [http://www.wireshark.org/docs/](http://www.wireshark.org/docs/).
+   - And what is called the **Enhancement** area at [http://www.riverbed.com/products-solutions/products/performance-management/wireshark-enhancement-products/](http://www.riverbed.com/products-solutions/products/performance-management/wireshark-enhancement-products/). This is a link to Riverbed, who acquired CACE Technologies, the primary sponsor of Wireshark, and became the main sponsor; they now develop and sell commercial add-ons.
+   - As open source software, Wireshark development resources are located under [http://www.wireshark.org/docs/wsdg_html_chunked/](http://www.wireshark.org/docs/wsdg_html_chunked/) or [http://www.wireshark.org/develop.html](http://www.wireshark.org/develop.html)

Also some other useful links are:

+   - The Wireshark graphical user interface was created using GTK+, or the GIMP toolkit, an open source kit that can be found on the GTK+ project web page at [http://www.gtk.org/](http://www.gtk.org/)
+   - For WinPcap (the Windows capture driver), go to [www.winpcap.org](http://www.winpcap.org), and for remote monitoring go to [http://www.winpcap.org/docs/docs_40_2/html/group__remote.html#Config](http://www.winpcap.org/docs/docs_40_2/html/group__remote.html#Config)
