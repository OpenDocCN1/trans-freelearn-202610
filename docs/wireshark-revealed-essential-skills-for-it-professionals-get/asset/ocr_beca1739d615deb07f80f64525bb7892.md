# # Other stuff

Some other tools you might need to get for working with networks are:

+   - A neat tool, **Xplico**, for extracting application data contained in capture files:  
+     [http://www.xplico.org/about](http://www.xplico.org/about) (freeware)
+   - **Nmap** security scanner: [http://nmap.org/](http://nmap.org/)
+   - **Netcat** (nc) for Linux: [http://nc110.sourceforge.net/](http://nc110.sourceforge.net/)
