# How it works...

When we open a website, it usually sends requests to several URLs. In this example, one of the websites we opened was [www.cnn.com](http://www.cnn.com), which took us to [edition.cnn.com](http://edition.cnn.com), where we have sent several requests: to the root URL, to the `breaking_news` URL, and to two other locations on the home page.
