# # tcpdump

**tcpdump** is free Unix-based software that runs under the Unix/Linux command line.\nSome of the useful resources for it are:

+   - The tcpdump website: [http://www.tcpdump.org/](http://www.tcpdump.org/)\n- The Windows version of tcpdump (Windump): [http://www.wincap.org/windump/default.htm](http://www.wincap.org/windump/default.htm)\n- A friendly tutorial: [http://danielmiessler.com/study/tcpdump/](http://danielmiessler.com/study/tcpdump/)\n- The official man page: [http://www.tcpdump.org/tcpdump_man.html](http://www.tcpdump.org/tcpdump_man.html)

Wireshark can open tcpdump files, so when you capture packets with tcpdump, you can later open it with Wireshark or any other graphical tool.
