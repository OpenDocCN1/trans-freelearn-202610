# # ARP scans

ARP scans, also called as ARP sweeps, are used to discover active localhost[s] on a network segment. An ARP sweep can be difficult to detect unless you apply a display filter and observe a steady, incremental sweep from the same device, as seen in the following screenshot:

![](bbox=[0.073, 0.218, 0.927, 0.355])

As ARP packets cannot pass through a router, the source device conducting the ARP sweep must be on the same network segment that the ARP packets are seen on.
