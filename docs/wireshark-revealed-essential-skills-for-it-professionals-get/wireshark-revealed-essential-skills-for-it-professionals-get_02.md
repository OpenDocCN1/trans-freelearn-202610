## 前言

Wireshark 是一款广受欢迎且功能强大的工具，用于分析网络中传输的比特和字节数量。Wireshark 中显示的数据包捕获结果能让您深入了解不同协议的安全性和缺陷，从而帮助您进行安全研究和协议调试。

## 本学习路径涵盖的内容

模块 1《Wireshark 基础知识》向跨多个领域的 IT 专业人员介绍 Wireshark 网络分析器。

本模块从 Wireshark 的安装开始，逐步引导您完成第一次数据包捕获、识别并过滤出感兴趣的数据包，以及将它们保存到新文件中供以后分析。后续章节将在此基础上，涵盖应用正确的 Wireshark 功能进行分析、网络协议基础知识、故障排除以及性能问题分析等关键主题。最后，本模块着重介绍用于安全任务、命令行实用程序以及管理跟踪文件的工具的数据包分析。

完成本模块后，您将成功地将扎实的 Wireshark 技能添加到您的技术工具包中，并显著提升您作为 IT 专业人士的价值。

模块 2《使用 Wireshark 进行网络分析 Cookbook》重点介绍 Wireshark 作为网络分析工具的操作。本书为您提供了一套实用技巧，帮助您通过逐步方法解决网络中的任何问题。

《使用 Wireshark 进行网络分析 Cookbook》首先讨论 Wireshark 的功能，例如统计工具和专家系统、捕获过滤器与显示过滤器，以及如何使用它们。然后，本书引导您详细了解主要网络协议，即以太网、局域网交换和 TCP/IP，随后讨论应用协议及其在网络上的行为细节。书中讨论的应用协议包括标准互联网协议，如 HTTP、邮件协议、FTP 和 DNS，以及数据库、终端服务器客户端、Citrix 和 IT 环境中常见的其他应用的行为。

本书采用自下而上的故障排除方法，依次通过 OSI 参考模型的各层，解释如何解决网络问题。本书从以太网和局域网交换开始，经过 IP，然后到 TCP/UDP，重点关注 TCP 性能问题。它还关注 WLAN 安全。然后，我们讨论应用行为问题，包括 HTTP、邮件、DNS 和其他常见协议。本书最后介绍了网络取证以及如何搜索和发现可能危害网络的安全问题。

模块 3《精通 Wireshark》将帮助您将知识提升到专家水平。在本模块开始时，您将了解其界面，以便理解其所有功能。接下来，您将发现创建和使用捕获过滤器与显示过滤器的不同方法。读到本书一半时，您将掌握 Wireshark 的功能，分析网络协议的各个层，查找任何异常。当您读到本书末尾时，您将学习如何使用 Wireshark 进行网络安全分析，并将其配置用于故障排除目的。
