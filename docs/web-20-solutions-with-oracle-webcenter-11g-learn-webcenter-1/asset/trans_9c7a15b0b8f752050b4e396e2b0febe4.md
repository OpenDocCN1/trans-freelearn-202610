## 开发群组空间

Oracle Space 提供的另一项功能是使用 Oracle Group Spaces 工具开发工作群组空间。此选项允许创建可用于促进项目、区域或工作组成员之间协作的工作环境。

在此练习中，我们将使用它为参与新采购系统的团队创建工作环境。

1. 以管理员身份登录 Oracle Spaces。

![](img/fccf6c511126cf79e98510edd3b343ac_261_2.png)

2. 在菜单栏中，选择 **Group Spaces** | **Create Group Space...**

![](img/fccf6c511126cf79e98510edd3b343ac_262_0.png)

3. 输入项目数据以管理此群组并选择 **Group Project**。单击 **Create** 按钮。

![](img/fccf6c511126cf79e98510edd3b343ac_262_1.png)

4. 接下来，您可以添加群组成员。为此，输入成员姓名，选择 Participant 角色，并单击 Add Members 按钮将成员添加到群组中。

![](img/fccf6c511126cf79e98510edd3b343ac_262_2.png)

5. 重复该过程以添加所有先前注册的用户。
6. 再次使用 **martin.alban** 作为用户名登录 Oracle Spaces。

![](img/fccf6c511126cf79e98510edd3b343ac_263_0.png)

7. 从主菜单中，选择 **Group Spaces | Procurement System Implementation**。

![](img/fccf6c511126cf79e98510edd3b343ac_263_1.png)

8. 请注意，已自动创建用于管理群组项目的环境。上半部分定义群组将要执行的活动。单击 **Create** 按钮以添加新活动。

![](img/fccf6c511126cf79e98510edd3b343ac_263_2.png)

9. 输入活动信息并将其分配给 diego.munoz。单击 Save 按钮。

![](img/fccf6c511126cf79e98510edd3b343ac_264_0.png)

10. 在群组环境底部，您有一个日程表来定义团队的议程。单击 **Create** 按钮。

![](img/fccf6c511126cf79e98510edd3b343ac_264_1.png)

11. 输入会议数据并按 **Create** 按钮。

![](img/fccf6c511126cf79e98510edd3b343ac_264_2.png)

12. 请注意，您已创建新的日历事件。

![](img/fccf6c511126cf79e98510edd3b343ac_265_0.png)

13. 现在以用户 **diego.munoz** 身份登录。

![](img/fccf6c511126cf79e98510edd3b343ac_265_1.png)

14. 转到 Oracle Spaces 环境和采购群组。
15. 单击选项 **Group Spaces | Procurement System Implementation**。

![](img/fccf6c511126cf79e98510edd3b343ac_265_2.png)

16. 最后，您会发现先前输入的活动和事件已定义在 **diego.munoz** 的群组环境中。

![](img/fccf6c511126cf79e98510edd3b343ac_266_0.png)

## 摘要

Oracle Space 允许组织成员以简便方式开发自己的环境，以提高效率。

对于群组，Oracle Spaces 提供了一个允许其管理活动和会议的环境。

此外，如本章所讨论，您可以创建 Business Roles Pages，这些页面允许将信息定向到组织中的特定群组。

最后，正如我们所见，无需进行任何开发，因为该解决方案即开即用。
