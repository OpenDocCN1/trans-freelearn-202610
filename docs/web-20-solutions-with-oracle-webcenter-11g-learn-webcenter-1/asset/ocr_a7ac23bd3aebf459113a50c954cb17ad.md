# # Step 7: Deploying the portlet to the integrated WebLogic server

From Application Navigator, highlight **HelloWorldPortlet** and right-click on it. Select Deploy | **HelloWorldPortlet** | to | **IntegratedWLSConnection** from the context menu. This will deploy the WAR file to the integrated WebLogic server.

![](bbox=[0.187, 0.26, 0.813, 0.535])

In the **Select deployment type** dialog, select **Yes** to allow JDeveloper to enable the portlet to be exposed as a WSRP service. Click **OK**.

![](bbox=[0.347, 0.6, 0.653, 0.822])
