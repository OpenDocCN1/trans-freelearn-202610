# # Step 5: Creating a Web Service from the Java class

In the Application Navigator, select the `HelloWorld.java` file and right-click on it. From the context menu, select **Create Web Service**. This will launch the Web Service creation wizard.

![](bbox=[0.1982, 0.2617, 0.8018, 0.6812])

We will create a Java EE 1.5 web service for Weblogic 10.3. Select the appropriate platform from the **Platform** list.
