## 摘要

在本章中，我们在 Linux 环境中安装了 WebCenter 11g 的核心构建块。这些构建块为创建 WebCenter 复合应用程序奠定了基础，这些应用程序通过 Web 服务、SOA 等中间件组件以及通过 WebCenter 热插拔架构集成的其他业务应用程序等“触手”真正得以实现。

重要说明：

- 这是一个单服务器、独立环境，可以快速搭建以满足测试和培训的基本需求。它不考虑高可用性、企业安全性或生产解决方案通常需要的其他考虑因素。

- 此环境将用作开发我们示例应用程序的基线，因此确保您已成功完成上述步骤非常重要。

要开始 WebCenter 开发，我们将使用 JDeveloper IDE，我们将在下一章中对其进行回顾，并附带一个简单的示例——WebCenter 版本的“Hello World”。

## 3 设置开发环境

在服务器端安装 Oracle WebCenter 组件后，有必要准备开发环境。

如前所述，构建 Oracle WebCenter 解决方案的工具是 JDeveloper 11g。该工具通常用于开发 Java EE 解决方案；然而，在本书中，我们将其用于构建复合解决方案。这意味着我们将把不同种类的组件（如 portlets、数据访问组件（表、值列表）和促进参与的组件（讨论、wiki））组合到单个用户界面中，以门户的概念为基础。

那么，在本章中，我们将专注于准备开发环境，我们将使用该环境来创建我们的 WebCenter 应用程序。

因此，在本章中，我们将涵盖以下主题：

- JDeveloper 11g 安装
- 为 JDeveloper 添加 WebCenter 扩展
- 安装控制版本系统（Subversion）
- 将 JDeveloper 与 Subversion 集成
- 测试 WebCenter 服务器的集成

那么，让我们开始工作吧。
