# ## 2. Preinstall steps

+   - Create a group called `oracle` belonging to a group called `dba` to be used for the installation.
+   - Ensure the `/etc/hosts` file is configured with a fully qualified domain (FQDN) name as the first entry. We used the following: `192.168.1.74 wc11g.mandsconsulting.com`.
+   - Ensure you have set the number of open file set on the OS. Set the appropriate limits in `/etc/security/limits.conf` by adding the following lines:
+     ```
+     oracle soft nproc 2047
+     oracle hard nproc 16384
+     oracle soft nofile 1024
+     oracle hard nofile 65536
+     ```
+   - Ensure Linux system settings are settings properly. Edit the `/etc/sysctl.conf` file and add following lines:
+     ```
+     kernel.shmall = 2097152
+     kernel.shmmax = 2147483648
+     kernel.shmmni = 4096
+     kernel.sem = 250 32000 100 128
+     fs.file-max = 6553600
+     net.ipv4.ip_local_port_range = 1024 65000
+     net.core.rmem_default = 4194304
+     net.core.rmem_max = 4194304
+     net.core.wmem_default = 262144
+     net.core.wmem_max = 262144
+     ```
