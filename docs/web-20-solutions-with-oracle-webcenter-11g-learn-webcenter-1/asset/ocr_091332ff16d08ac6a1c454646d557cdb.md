# Deploying the application to the Integrated
WebLogic Server

Deploy the application to the Integrated WebLogic Server using the steps described
earlier. Once deployment is complete, we can view the new test_page.jspx
page using a browser. The URL in our case is http://127.0.0.1:7101/TagsApp-
ViewController-context-root/faces/test_page.jspx.

We will create a new link to a URL, in this case to a site that provides currency
conversion facility.
