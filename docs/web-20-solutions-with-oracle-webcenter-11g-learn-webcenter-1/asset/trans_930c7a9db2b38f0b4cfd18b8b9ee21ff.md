## 为何使用 WebCenter RSS 服务

RSS 服务允许您将通过 RSS 源提供的内容集成到自定义 WebCenter 应用程序中。RSS 是传播网页更改的一种非常流行的方式。这在页面更新频繁的网站（例如新闻网站）中尤其流行。WebCenter RSS 查看器任务流使在 WebCenter 应用程序中包含 RSS 内容变得非常简单。

## WebCenter RSS 服务的要求

RSS 服务不需要任何其他资源。您只需在自定义 WebCenter 应用程序中包含 RSS 查看器任务流即可。如果环境中存在 HTTP 代理，则需要使用 **工具 | 首选项 | Web 浏览器和代理** 配置代理。

## Oracle 组件类型

Oracle 组件可按功能分为以下类型：

- 常见组件
  - 更改模式按钮：这是一个按钮，允许用户从运行时模式切换到设计模式。
  - 更改模式链接：此链接与前一个组件具有相同的用途。
  - 图像链接：此组件提供带有关联图像的链接。
  - 页面可自定义：使用此组件，我们可以创建一个区域，其内容可以由用户动态更改。
- 布局组件
  - 面板可自定义：此面板充当用户在运行时模式下选择的组件的容器。
  - 布局可自定义：这是另一种容器，其特点是允许用户以多种方式对其进行划分。
  - 显示详细信息框架：此容器的特点是提供类似于端口的区域。它可以用于包含一个项目。
- 操作组件。
  - 自定义操作：此组件可以调用任务流。
