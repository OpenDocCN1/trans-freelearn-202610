

## 关于审稿人

**Vince Casarez**，甲骨文公司副总裁，专注于 Web 2.0 技术开发、Enterprise 2.0 和门户产品。过去 14 年中，Vince 在甲骨文担任过多个关键职位。目前，他是甲骨文公司 Enterprise 2.0 和门户产品的产品管理副总裁。他最近合著了一本名为 _Reshaping Your Business with Web 2.0_ 的书，该书一直位列 Amazon 技术畅销榜。他还负责管理 WebCenter 开发团队，处理 Web 2.0 和社交计算服务。在此之前，他专注于托管门户开发和运营，包括面向外部客户的 Oracle Portal Online、用于构建门户社区的 Portal Center 以及面向员工内网的 My Oracle。此前，他曾担任工具营销副总裁，负责所有工具产品，包括开发工具和商业智能工具。在负责工具营销之前，他曾担任 Oracle JDeveloper 的产品管理总监。加入甲骨文之前，Vince 在 Borland International 工作了七年，担任 Paradox for Windows 和 dBASE for Windows 的产品组经理。他拥有加州大学洛杉矶分校的生物化学学士学位。

Oracle 是全球最大的商业软件公司，拥有 345,000 名客户——包括 100 家《财富》全球 100 强企业——并在 145 多个国家为这些客户提供支持。

**Hector R. Madrid** 是 _Oracle 10g/11g Data and Database Management Utilities_ 书籍的作者。他目前担任自由职业顾问；他与 Oracle University 合作，担任 DBA、Java 和应用服务器课程的认证讲师。他是一位备受尊敬的 Oracle 专业人士，拥有 20 年全职 DBA 经验。他处理广泛的 DBA 需求，从日常 DBA 职责到与关键任务和高可用性系统相关的任务。他是拉丁美洲第一位 Oracle Certified Master。他获得了大都会自治大学（UAM）的计算机科学硕士学位，并在多次 Oracle 会议上发表过不同的技术论文。
