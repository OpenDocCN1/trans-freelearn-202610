From the **Component Palette**, select **Panel Group Layout** and drag it to the page.

![](bbox=[0.3828, 0.1758, 0.6211, 0.3734])

Next, select **Tagging Button** from the **Component Palette** and drop it inside the **Panel Group Layout** on the page.

![](bbox=[0.3613, 0.4367, 0.6387, 0.5406])

Fill in the values for the three parameters presented in **Insert Tagging Button** dialog.

| Field    | Description    |
|---|---|
| ResourceId    | The ID that uniquely identifies the object to which you are binding the Tagging Button. For example:
To tag pages, enter #{ facesContext.viewRoot.viewId }.
To tag custom components, enter customComponentABC.    |
| ResourceName    | The name of the object to which you are binding the Tagging Button.
For example:
To tag pages, enter #{ facesContext.viewRoot.viewId }.
To tag custom components, enter Custom Component ABC.    |
| ServiceId    | An application-wide ID:
To tag pages, enter oracle.webcenter.page.
To tag custom components, enter
mycompany.myproduct.myapp.mycomponent.    |
