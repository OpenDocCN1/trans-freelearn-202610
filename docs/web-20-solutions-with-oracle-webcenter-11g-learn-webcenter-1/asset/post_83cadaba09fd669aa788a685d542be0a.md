## Developing a Group Space

Another feature offered by Oracle Space is the development of a working group space using the tool Oracle Group Spaces. This option allows the creation of a working environment that can be used to foster collaboration among members of a project, area, or work group.

In this exercise, we will use it to create a working environment for the team involved in a new procurement system.

1. Enter Oracle Spaces as an administrator.

![](img/fccf6c511126cf79e98510edd3b343ac_261_2.png)

2. In the menu bar, choose **Group Spaces** | **Create Group Space...**

![](img/fccf6c511126cf79e98510edd3b343ac_262_0.png)

3. Enter project data to manage this group and choose **Group Project**. Click the **Create** button.

![](img/fccf6c511126cf79e98510edd3b343ac_262_1.png)

4. Next, you may include members of the group. To do this, type the name of the member, choose the Participant role, and click the Add Members button to include members in the group.

![](img/fccf6c511126cf79e98510edd3b343ac_262_2.png)

5. Repeat the procedure to include all previously registered users.
6. Again, enter the Oracle Spaces using **martin.alban** as the username.

![](img/fccf6c511126cf79e98510edd3b343ac_263_0.png)

7. From the main menu, choose **Group Spaces | Procurement System Implementation**.

![](img/fccf6c511126cf79e98510edd3b343ac_263_1.png)

8. Note that an environment has been automatically created for managing group’s projects. The upper part defines activities to be undertaken by the group. Click the **Create** button to add a new activity.

![](img/fccf6c511126cf79e98510edd3b343ac_263_2.png)

9. Enter the activity information and assign it to diego.munoz. Click the Save button.

![](img/fccf6c511126cf79e98510edd3b343ac_264_0.png)

10. In the bottom of the group environment, you have a schedule to define the agenda of the team. Click the **Create** button.

![](img/fccf6c511126cf79e98510edd3b343ac_264_1.png)

11. Enter the data of the meeting and press the **Create** button.

![](img/fccf6c511126cf79e98510edd3b343ac_264_2.png)

12. Note that you have created a new calendar event.

![](img/fccf6c511126cf79e98510edd3b343ac_265_0.png)

13. Enter now as the user **diego.munoz**.

![](img/fccf6c511126cf79e98510edd3b343ac_265_1.png)

14. Go to the Oracle Spaces environment and procurement group.
15. Click the option **Group Spaces | Procurement System Implementation**.

![](img/fccf6c511126cf79e98510edd3b343ac_265_2.png)

16. Finally, you’ll see that the activity and event entered previously are defined in the group environment of **diego.munoz**.

![](img/fccf6c511126cf79e98510edd3b343ac_266_0.png)

## Summary

Oracle Space allows members of the organization develop their own environment in an easy way in order to improve their efficiency.

For groups, Oracle Spaces provides an environment that allows them to manage their activities and meetings.

Additionally, as discussed in this chapter, you can create Business Roles Pages that allow targeting information to certain groups of the organization.

Finally, as we have seen, it’s not necessary to do any kind of development because the solution is ready for use.
