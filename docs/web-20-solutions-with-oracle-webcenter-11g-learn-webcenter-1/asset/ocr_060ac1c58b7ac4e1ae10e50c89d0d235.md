# # Step 2: Configuring application settings

From the Application Template list, select **Generic Application**. The Generic Application template is suitable when you intend to manually select the technology scope of the project. Choose a name for the application, `HelloWorldWSApp` in this case. Click Next.

> Note the various templates present including `Portlet Producer Application` and `WebCenter Application` towards the end of the list. If you do not find the aforementioned templates listed, then the most likely cause is that WebCenter extensions for JDeveloper are not installed.
