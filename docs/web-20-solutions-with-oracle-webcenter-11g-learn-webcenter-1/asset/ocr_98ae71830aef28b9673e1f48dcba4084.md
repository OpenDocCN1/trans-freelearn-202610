# # Why to use the WebCenter RSS Service

The RSS Service allows you to integrate content available via RSS feeds into your custom WebCenter application. RSS is an extremely popular means of disseminating changes to web pages. This is particularly popular with websites where the pages are updated frequently such as news sites. The WebCenter RSS View Task Flow makes it trivial to include RSS content in WebCenter applications.
