我们的图书和出版物分享了您的 IT 专业同行在调整和定制当今系统、应用程序和框架方面的经验。我们的基于解决方案的图书为您提供知识和能力，以定制您正在使用的软件和技术来完成工作。Packt 图书比您过去看到的 IT 图书更具体、更不笼统。我们独特的商业模式使我们能够为您带来更聚焦的信息，让您了解更多需要知道的内容，而减少不需要知道的内容。

Packt 是一家现代且独特的出版公司，专注于为开发人员、管理员和新手社区制作高质量、前沿的图书。有关更多信息，请访问我们的网站：www.packtpub.com。

## 关于 Packt Enterprise

2010 年，Packt 推出了两个新品牌，Packt Enterprise 和 Packt Open Source，以继续其专业化的重点。本书是 Packt Enterprise 品牌的一部分，该品牌专注于企业软件图书的出版——即由主要供应商（包括但不限于 IBM、Microsoft 和 Oracle）创建的软件，通常用于其他公司。其书名将为该软件的一系列用户提供相关信息，包括管理员、开发人员、架构师和最终用户。

## 为 Packt 撰写

我们欢迎所有有兴趣撰写的人士的咨询。书籍提案应发送至 author@packtpub.com。如果您的书籍创意仍处于早期阶段，并且希望在撰写正式书籍提案之前先讨论，请联系我们；我们的一位委托编辑将与您联系。

我们不仅在寻找已出版的作者；如果您拥有强大的技术技能但没有写作经验，我们经验丰富的编辑可以帮助您发展写作生涯，或者仅仅为您的专业知识获得一些额外回报。
