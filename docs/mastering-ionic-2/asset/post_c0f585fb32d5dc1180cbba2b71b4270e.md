## The future of PWAs

Progressive web applications give us so many possibilities such as the ability to install, send push, and offline support, which bridge the gap between mobile web and native applications. Currently, the problem is that iOS and Safari do not have support for service workers, which is still under consideration. There are assumptions going on that in the latter half of 2017, they might come up with service worker support, which will help enable PWA features.

Progressive web applications are the next step forward in improving mobile web. With growing mobile traffic day by day, this makes a lot of sense. Also, from last some time we were seeing that many websites are forcing their users to use mobile web to install native applications, which is really annoying. One of the famous e-commerce giants in India, Flipkart, even discontinued its mobile web version once with a banner that asks users to install their native application. Later, as they realized this mistake, they were the first ones in the industry to support PWAs by releasing Flipkart Lite version on mobile web.

Statistics show that in the US smartphone application downloads decreased by 20% in the past year, which shows that the market has become saturated and consumer needs are changing. You can find a lot of case studies here (https://developers.google.com/web/showcase/2016/flipkart), which have key insights into how PWAs have positively affected product growth and user engagement. There are many PWAs such as MakeMyTrip, Housing, and so on. You will find that they helped me uninstall native applications to free my device space and use PWA versions.
