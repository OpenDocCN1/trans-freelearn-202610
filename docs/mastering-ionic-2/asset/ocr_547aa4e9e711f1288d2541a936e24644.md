Next, if you want to translate any JavaScript value inside our TypeScript file then we can use translateService and its get method, which then subscribes to the observable and returns the translated string:

```
translateService.get('HELLO').subscribe(
  value => {
    // value returned is translated
    console.log(value);
  }
)
```
