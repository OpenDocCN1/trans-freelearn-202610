'http://0.0.0.0:8080/user/signin' \

-H 'Content-Type: application/json' \

"email": "fastapi@packt.com",
"password": "password!"
}'
```

The response from the preceding request is as follows:

```
{
  "detail": "Wrong credential passed"
}
