The following activities describe the ways you should be monitoring your Salesforce org:

+   - Tracking and understanding the adoption and usage of your Salesforce products
+   - Monitoring platform performance and security

+   - Performing regular technical and security audits
+   - Monitoring incoming feature requests
+   - Monitoring incoming bugs
+   - Facilitating sprint retrospectives and demos

# Tip

Here are a few ideas you can use to improve how you collect feedback:

+   - Facilitate user feedback forums.
+   - Regular cadence with superuser representatives from the users of your Salesforce products. Host forums per Salesforce product and user group.
+   - You should provide a simple template and method for your users and other stakeholders to submit new feature requests and changes to existing ones.
+   - Use a **product management system** to consolidate user feedback, validate ideas, create roadmaps, and integrate with your development tool. Leading product management system vendors include **Productboard**, **Aha!**, and **JIRA Discovery**.
