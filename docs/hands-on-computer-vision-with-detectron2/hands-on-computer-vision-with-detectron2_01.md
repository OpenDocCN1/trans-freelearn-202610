# 前言

我与 Van Vung Pham 相识并共事超过 10 年，同时也是他博士学位的学术顾问。Vung 在攻读博士学位期间赢得了多项数据可视化、计算机视觉和机器学习挑战，包括使用 Detectron2 检测和分类道路损坏。在本书《使用 Detectron2 实战计算机视觉》中，Vung 将带你踏上一段从常见计算机视觉任务开始的学习之旅。然后，他通过利用 Detectron2 Model Zoo 中的预训练模型，使用简单的代码和惊艳的深度学习模型，逐步指导你开发计算机视觉应用的步骤。

针对海量数据集上训练的、面向最常见对象类型的现有模型，可以满足常见的计算机视觉任务。然而，本书还专注于针对特定业务需求在自定义领域上开发计算机视觉应用。为此，Vung 提供了在脑肿瘤数据集上收集和准备数据、训练模型以及微调模型以完成目标检测和实例分割任务的步骤，以说明如何在自定义业务领域上开发计算机视觉应用。

在他的演示和示例中，Vung 提供了可以方便地在 Google Colab 上执行的代码以及可视化内容，以帮助说明理论概念。在 Google Colab 上执行代码的能力消除了硬件和软件设置的负担，因此你可以快速、方便地开始。可视化让你能够轻松掌握复杂的计算机视觉概念，更好地理解用于计算机视觉任务的深度学习架构，并成为该领域的专家。

除了为计算机视觉任务开发深度学习模型之外，你还将学习如何将训练好的模型部署到各种环境中。Vung 解释了不同的模型格式，如 TorchScript 和 ONNX 格式，以及它们各自的执行平台和环境，如 C++ 服务器、Web 浏览器或移动和边缘设备。

使用 Detectron2 成为开发、部署计算机视觉应用的开发者和专家。
