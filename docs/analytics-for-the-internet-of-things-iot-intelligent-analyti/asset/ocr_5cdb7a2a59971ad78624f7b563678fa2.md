There will also be a NAT gateway in each public subnet (although not shown in the previous diagram). The IP address range defined for the VPC allows plenty of room to grow for your future analytics projects. Each EC2 instance, database, or node in a Hadoop cluster will reserve an IP address number. The range of available IP addresses is therefore a constraint on the number of resources you can have in your VPC. The VPC we will create has over 65,000 available IP addresses.
