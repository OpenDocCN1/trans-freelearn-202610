# Name: Precip Value Validity

# Calculation:

```
CASE [Amount of Precipitation (inches)]
    WHEN -9999 THEN
        "Invalid"
    WHEN 999.99 THEN
        "Invalid"
    ELSE
        IF [Amount of Precipitation (inches)] >= 0 AND [Amount of Precipitation (inches)] <20 THEN
            "Valid"
        ELSE
            "Invalid"
        END
END
```
