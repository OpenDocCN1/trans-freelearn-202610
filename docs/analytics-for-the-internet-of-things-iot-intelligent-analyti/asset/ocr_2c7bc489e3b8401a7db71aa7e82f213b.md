# AWS machine learning

This service has wizards and visualization tools that guide you through the process of creating machine learning models. You can deploy the trained models to make predictions on new data without having to set up a separate system. You pay as you go, there are no upfront costs. It is highly scalable and can handle billions of predictions in a day.
