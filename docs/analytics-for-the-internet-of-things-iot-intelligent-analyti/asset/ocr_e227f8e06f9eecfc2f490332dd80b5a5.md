+   - **Lines or LineString:** A LineString is defined by a set of points and order is important. More than one LineString can be stored together; in that case it is called, unsurprisingly, a **MultiLineString**. A river system or roadway network is an example of a MultiLineString. A file that contains a MultiLineString for the US Interstate roadways network can be downloaded from the University of Iowa GIS Library (`ftp://ftp.igsb.uiowa.edu/gis_library/USA/us_interstates.htm`). +   - **Polygon:** A polygon is defined as a closed network of points. Order of the points is important and the starting point is also repeated as the ending point, thus closing out the shape. More than one polygon can be stored together, which is then called, you guessed it, a **MultiPolygon**.
