The Hadoop components are designed to operate distributed across multiple servers. One cluster could have thousands of separate servers. It is fault tolerant, server failures are expected by design, and adding or removing servers can be done while the cluster is up and operating normally.

It can be helpful, from the viewpoint of analytics, to think of the Hadoop ecosystem as four interconnected but loosely coupled services.
