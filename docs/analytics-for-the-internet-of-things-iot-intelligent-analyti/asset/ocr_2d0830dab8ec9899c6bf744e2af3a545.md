Another model is then trained on all but one of the subsets, but a different one this time. The fold that is held out is used to check on prediction error for the model trained on the other folds. This continues so that each fold is held out exactly once, and all the data is used in both training and validation. The resulting set of models will each run its own prediction and the average of the results will be given as the output.

10 folds is the most commonly used amount, but the number is set more by convention than by anything special about the exact number of 10. 10-fold cross-validation is the typical terminology used to describe this. The advantage of using cross validation is that you simulate a variety of datasets using the same set of training data. This increases the chance that the resulting model will generalize well. It also allows you to have a robust validation process, even if your training data is limited:
