## 前言

自然语言处理（NLP）目前是人工智能领域增长最快的子领域之一，其中 NLP 框架的新进展或变更每天都在发生。初入该领域的人会发现很难知道从哪里开始，哪些想法已经过时，哪些仍然相关，哪些即将成为最先进的技术。同样，拥有扎实的 NLP 理论背景并希望获得 NLP 实践经验的人也会发现，很难在开源社区目前提供的众多不同选项中选择合适的 NLP 库或框架。作为一个在专业工作和个人项目中都使用过 Flair 的人，我很难推荐其他任何框架，它像 Flair 一样直观、相关且集成了大量即用型、最先进的模型。

关于 Flair 最有趣的事情可能并不是它的简洁性、性能或易用性。相反，这与 Flair 最初的设计方式有关。首次发布从未打算作为一个功能齐全的 NLP 框架。Flair（v0.1）的首次发布，本质上只是一个工具，作为 Flair 嵌入的实际实现——这一底层概念赋予了 Flair 序列标注模型惊人的性能。直到后来的 Flair 版本，库才引入了 Transformer 模型、文本分类模型以及你通常期望从成熟 NLP 框架中获得的其他工具。

任何旨在构建实际 NLP 解决方案的人都需要在这两者之间取得平衡：在学习更多 NLP 理论上花费时间，以及在选择合适的工程方法上投入精力。本书将帮助您在这两者之间找到合适的平衡。它将为您提供恰到好处的理论基础，帮助您理解底层 NLP 概念，同时帮助您获得足够的工程知识和经验，以便熟练使用 Flair。

## 本书适合谁

本书适合任何渴望通过目前最适合初学者、同时功能强大的 Python NLP 库之一来学习 NLP 的人。读者包括软件工程学生、开发人员、数据科学家，以及任何正在转型进入 NLP 并对使用 Flair 解决问题的实用方法感兴趣的人。然而，本书不推荐给希望深入了解 NLP 数学原理的读者。建议具备 Python 初级知识以充分利用本书。

本书也是希望开始为开源社区做出贡献的任何人的一个机会。您可以修复错误、创建新教程、扩展文档、通过构建预训练模型来添加对新语言的支持，或简单地在 GitHub 上开新 issue，提出改进 Flair 的建议。通过阅读本书并完成练习所获得的知识，将极大地帮助您成为一名活跃的 Flair 贡献者。

## 本书涵盖内容

- *第 1 章，Flair 简介，* 提供 NLP 及其基本问题和技术的快速概述。随后本章介绍 Flair 并展示如何设置本地环境。
- *第 2 章，Flair 基础类型，* 介绍 Flair 的基本语法、典型类和方法。
- *第 3 章，Flair 中的嵌入，* 解释词嵌入和文档嵌入背后的概念及其在 NLP 中的作用。它描述了 Flair 中可用的所有不同类型的嵌入。
- *第 4 章，序列标注，* 描述序列标注及其子类型，例如命名实体识别和词性标注。本章还演示了如何在 Flair 中使用预训练的序列标注器。
- *第 5 章，训练序列标注模型，* 解释如何在 Flair 中训练、保存和使用自定义序列标注模型。
- *第 6 章，Flair 中的超参数优化，* 展示了在模型训练中使用正确超参数的重要性。它介绍了 Python 中的超参数优化工具，并解释了如何在 Flair 中执行超参数优化。
- *第 7 章，训练自己的嵌入，* 解释如何在 Flair 中训练自定义嵌入以及如何利用不同的评估技术来衡量成功。
- 第 8 章，Flair 中的文本分类，介绍文本分类问题。本章演示了如何使用预训练模型以及如何训练自定义分类器。它还介绍了一种名为 TARS 的新型文本分类方法。
- 第 9 章，在生产环境中部署和使用模型，讨论了在生产环境中部署和使用 NLP 模型的挑战。本章演示了如何设置自定义最小可行产品 NLP 服务以及如何在 Hugging Face 模型集线器上托管 Flair 模型。
- 第 10 章，动手练习 – 使用 Flair 构建交易机器人，通过构建交易机器人作为动手练习来解决一个实际问题。

## 使用的约定

本书中使用了多种文本约定。

代码中的代码：表示文本中的代码词、变量名、类名、对象方法和属性。

代码块如下所示：

```
from flair.data import Sentence
from flair.tokenization import SpaceTokenizer

tokenizer = SpaceTokenizer()
s = Sentence('Some nice text.', use_tokenizer=tokenizer)

print(s)
```

当我们希望引起您对代码块中特定部分的注意时，相关行或项目以粗体显示：

```
from flair.data import Sentence

sentence = Sentence('A short sentence')
sentence.get_token(1).add_label('manual-pos', 'DT')

print(sentence)
```
