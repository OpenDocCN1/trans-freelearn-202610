# Speed optimizations

Note that in the preceding function, we instantiated the WordEmbeddings object only once and then passed it directly to our functions. This improves the performance of our solver. There are also many other optimizations we could have made, namely to do with how we found our closest matching word. Instead of iterating our vocabulary using a for loop and computing the cosine similarity for each word, we could have passed our entire vocabulary to the cosine_similarity method, which allows computing similarity for several embedding pairs at once.
