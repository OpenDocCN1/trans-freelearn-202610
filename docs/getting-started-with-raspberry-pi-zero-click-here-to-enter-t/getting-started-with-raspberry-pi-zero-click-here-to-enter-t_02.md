# 关于审阅者

**David Whale** 是一位居住在英国埃塞克斯的软件开发人员。他 11 岁时在学校就开始编程，受学校科学技术员启发自己从套件组装电脑，很快就开始编写机器代码程序，因为它们“小而快”。这些早期实验使他在仅 13 岁时就有一部分代码被用于一款可销售的教育类文字游戏中。

此后他一直从事专业软件开发，主要编写小而快的代码，用于电子产品，包括自动化机械、电动汽车、手机、能源表和无线门铃。

如今，他经营着自己的软件咨询公司 Thinking Binaries，并将近一半的时间用于帮助设计下一代互联网，即物联网，将电子设备连接到互联网上。其余时间他为工程技术学会做志愿者，为教师开设培训课程，为学童设计和运营工作坊和俱乐部，并忙于他的 Raspberry Pi、BBC micro:bit 和 Arduino。

他曾担任书籍 *Adventures in Raspberry Pi* 的技术编辑，并合著了书籍 *Adventures in Minecraft*，也是多家图书出版商技术书籍的常客审阅者和编辑。

> 我很高兴被邀请审阅这本使用 Raspberry Pi Zero 的精彩新项目书。Pi Zero 的尺寸使其非常适合集成到其他产品中。在这本书中，Richard Grimmett 带领我们踏上了一段令人惊叹的电路改造、编程和创新之旅，使用这台微型计算机！但不要止步于此；本书中的项目将为您提供所需技能，并激发您自己产生许多新想法！
