You can, however, connect your Raspberry Pi Zero to the DC motors by using an H-bridge DC motor controller. An H-bridge is a fairly simple device. It basically consists of a set of electronic switches and provides the additional functionality of allowing the direction of the current to be reversed so that the motor can be run in either forward or reverse directions.

Let's start this example by building the H-bridge circuit and controlling just one motor. To do this, you need to get an H-bridge. One of the most common options is the L293 dual H-bridge chip. This chip allows you to control the direction of the DC motors. These are available at most electronics stores and online.
