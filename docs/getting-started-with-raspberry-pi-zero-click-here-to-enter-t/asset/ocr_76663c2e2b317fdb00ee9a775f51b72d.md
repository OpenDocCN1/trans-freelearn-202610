If you have chosen to use the RasPiRobot Board V2 you can also use its special connections and libraries to connect the HC-SR04 sonar sensor. Here is a picture of the special connector on the board:

![](bbox=[0.24, 0.2, 0.76, 0.5])

To use this connector, simply connect the VCC to the 5V, the Trig to the T connection, the Echo to the E connector, and the GND to the GND connection. You can then use the library for the motor controller board and simply call the function rr.get_distance(). Similarly, there is also a special connector and libraries for the I2C interface, if you want to add the compass to your mobile project.
