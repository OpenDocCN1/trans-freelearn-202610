Make sure that the speaker is powered because your board will generally not be able to drive a passive speaker with enough power for your applications. Now, we move on to getting the Raspberry Pi Zero to access these devices. You can follow these instructions in either of the two following ways:

+   - If you are still connected to the display, keyboard, and mouse, log in to the system and use the GUI by opening a terminal window
+   - If you are only connected through LAN, you can do all this by using an SSH terminal window; as soon as your board indicates that it has power, open up an SSH terminal window using PuTTY or any similar terminal emulator
