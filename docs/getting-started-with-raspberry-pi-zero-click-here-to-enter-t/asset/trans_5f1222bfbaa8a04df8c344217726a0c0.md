

## 在 Linux 中创建程序来控制你的四足机器人

以下是代码的解释：

- #!/usr/bin/python: 这一行允许你从命令行执行此 Python 文件。
- `import serial`: 这一行导入了 `serial` 库。你需要 `serial` 库才能通过 USB 与你的设备通信。

- `setAngle(ser, i, 90)`: 现在，你可以将每个舵机设置为中间（初始）位置。默认情况下，每个舵机都设置为 90 度。如果你的腿不在中间位置，你可以通过调整每个舵机上舵机臂的位置来调整它们。

在这种情况下，你使用 setAngle 命令来设置舵机以操纵机器人前右臂。中间的舵机抬起手臂，然后下方的舵机在 100 度角和 130 度角之间来回移动。

你希望机器人执行的最基本动作之一就是向前行走。以下是如何操纵腿部来实现这一点的示例：

```
ser = serial.Serial("/dev/ttyACM0", 9600)
# Home position
for i in range(0, 12):
    setAngle(ser, i, 90)

setAngle(ser, 4, 110)
time.sleep(1)
setAngle(ser, 5, 100)
time.sleep(1)
setAngle(ser, 4, 90)
time.sleep(1)

setAngle(ser, 7, 70)
time.sleep(1)
setAngle(ser, 8, 80)
time.sleep(1)
setAngle(ser, 7, 90)
time.sleep(1)

setAngle(ser, 1, 110)
time.sleep(1)
setAngle(ser, 2, 100)
time.sleep(1)
setAngle(ser, 1, 90)
time.sleep(1)

setAngle(ser, 10, 70)
time.sleep(1)
setAngle(ser, 11, 80)
time.sleep(1)
setAngle(ser, 10, 90)
time.sleep(1)

for i in range(0, 12):
    setAngle(ser, i, 90)

ser.close()
```

该程序一次抬起并向前移动每条腿，然后将所有腿移动到初始位置，从而使机器人向前移动。不是最优雅的，但它确实有效。有更复杂的四足机器人行走算法；请参阅 http://letsmakerobots.com/node/35354 和 https://www.youtube.com/watch?v=jWP3RnYa_tw。一旦程序运行正常，你需要将所有硬件打包到移动机器人上。

你可以让你的机器人执行许多令人惊叹的事情，例如向前行走、向后行走、跳舞和转圈；各种动作都是可能的。最好的学习方法是尝试舵机的不同位置。

## Raspberry Pi Zero 与机器人之间的通信

你将连接到内部串行总线，以便你而不是遥控器发送命令。你将添加一个 Arduino 来处理 Raspberry Pi Zero 与机器人之间的实时通信。以下是步骤：

- 1. 首先，你需要拆开机器人以获得主控制器板的访问权限。为此，将机器人面朝下放置，以便你能够接触到背面。拆下背面的板子，拧下固定它的四个螺丝。现在，在暴露的板子上方，你应该能看到主连接器。以下图像是连接器的特写照片：

![](img/324d126a7e2da696837a3e066326bd61_141_0.png)

你只对其中两根线感兴趣。第一根是黑色线，它是 Robosapien 系统的 GND。第二根是白色线。这是控制 Robosapien 命令的串行连接。

你可能希望添加一些热缩管来覆盖你的连接。

![](img/324d126a7e2da696837a3e066326bd61_143_0.png)

- 5. 这张图片还显示了外壳两侧的另外两个孔，你可以使用它们与扎带一起将 Raspberry Pi 固定到机器人上。现在你可以将外壳重新装回机器人上。

- 6. 现在，你需要将这两根线连接到 Arduino。有几种 Arduino 版本可以使用，但最常见的是 Arduino Uno。如果你使用具有不同定时器的不同 Arduino，Arduino 代码中的延迟常量可能需要调整。你需要使用 Arduino 的原因是发送给机器人的位模式以相当高的速率发送，需要由专门用于这种实时通信的处理器创建。这允许 Raspberry Pi Zero 执行其他处理器密集型活动，例如语音，同时保持通信以正确的速率进行。

有关如何使用 Arduino 系列处理器的开发环境的具体信息，请访问 https://www.arduino.cc。有关如何使用 Raspberry Pi 创建和上传程序到 Arduino 的信息，请参阅 http://www.instructables.com/id/Arduino-On-Pi/ 或 https://www.youtube.com/watch?v=wCxQrW96jTM。
