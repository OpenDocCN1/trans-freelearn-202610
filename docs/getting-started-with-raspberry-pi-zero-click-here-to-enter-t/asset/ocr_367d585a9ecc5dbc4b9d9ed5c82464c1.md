# Connecting a webcam

Now, you can connect your computer, tablet, or cell phone to the wireless access point. Using a terminal emulator program, like PuTTY, you can use the SSH protocol to access your device as described in Chapter 1, Getting Started with Raspberry Pi Zero. You can then execute your vncserver and run a vncviewer program on your remote device.

Now you are ready to observe the output of a USB webcam connected to your car. This is quite straightforward; simply plug in a USB webcam and download a video viewer. One such video viewer that works well is guvcview. To install this, type

```
sudo apt-get install guvcview.
```

With all these tools installed, you can now run vncview. When you are viewing the graphical screen of Raspberry Pi Zero type guvcview -r 2 and you will be able to see the video from the webcam.
