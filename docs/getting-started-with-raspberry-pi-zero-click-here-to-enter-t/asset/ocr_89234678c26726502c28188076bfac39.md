# Playing Rock, Paper, or Scissors with Raspberry Pi Zero

There are several tools that can allow you to access the webcam, but a simple program with video controls is called guvcview. To install this, type `sudo apt-get install guvcview`. Once the applications are installed, you'll want to run it. To do this, you'll need to be either connected directly to a display or connected to a remote computer using vncviewer. Open a terminal window on Raspberry Pi and run guvcview. You should see something similar to this:

![](bbox=[0.205, 0.255, 0.794, 0.612])

Don't worry about the quality of the image you'll be capturing and processing your images inside OpenCV, a vision framework.
