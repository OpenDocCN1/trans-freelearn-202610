To calculate the distance, use the following equation:

d = √((Xgoal − Xgoal)² + (Ygoal − Yrobot)²)

You use this equation to tell your robot how far to travel to reach the goal. A second equation tells your robot the angle at which it needs to travel:

θ = arctan((Ygoal − Yrobot) / (Xgoal − Xrobot))

> If you'd like a tutorial on the basic math of path planning, see https://www.khanacademy.org/math/trigonometry/trigonometry-right-triangles.

Now that you have a goal angle and distance, you can program your robot to move. To do this, you need to write a program to do the path planning and call the movement functions that you created earlier in the chapter. You need to know the distance that your robot will travel in a certain period of time so that you can tell your robot in time units, rather than distance units, how far to travel.

You also need to be able to translate the distance that might be covered by your robot in each time unit that you run the motor. If you know the angle and distance, you can move your robot towards the goal by turning the robot and then running it forward for a certain time.
