After plugging in your card, you might see something like the following screenshot:

![](bbox=[0.205, 0.365, 0.797, 0.579])

Note that your card is at sdb. Now go to the directory in which you downloaded the archived image file and use the following command:

```
```bash
sudo dd if=2015-11-21-raspbian-jessie.img of=/dev/sdX
```
```

The `2015-11-21-raspbian-jessie.img` command will be replaced by the image file that you downloaded and `/dev/sdX` will be replaced by your card ID, in this example `/dev/sdb`. Be careful to specify the correct device as this can overwrite the data on any of your drives. Also, this may take a few minutes. Once the file is written, eject the card and you are ready to plug it into the board and apply the power.
