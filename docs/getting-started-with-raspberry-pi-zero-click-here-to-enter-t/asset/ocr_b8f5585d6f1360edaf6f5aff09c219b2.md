Now enter the program. Lets go through the program line by line:

+   - `#!/usr/bin/python`: This line lets you run this program without having to type python before the filename. You'll learn how to do this at the end of these instructions.
+   - `import RPi.GPIO as io`: This lets you import the RPi.GPIO library, which will allow you to control the GPIO pins.
+   - `import time`: The time library provides several time-based functions. In this case, you'll use it to pause the program for a few seconds.
+   - `io.setmode(io.BCM)`: This sets the specification mode of the GPIO pins to Broadcom SOC channel number (BCM). This means that you will specify the GPIO numbers of the pins you want to control, instead of the actual physical pin numbers.
