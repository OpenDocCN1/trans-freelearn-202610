The document README.txt will give you explicit instructions on how to install the software. This is basically done in two steps. First, install a set of supporting libraries by typing sudo apt-get install libusb-1.0-0-dev mono-runtime libmono-winforms2.0-cil, then copy the configuration file by typing sudo cp 99-pololu.rules /etc/udev/rules.d/.

Unfortunately, you can't run Maestro Control Center on your Raspberry Pi Zero, as your version of Windows doesn't support the graphics, but you can control your servos using the UscCmd command-line application to ensure that they are connected and working correctly.
