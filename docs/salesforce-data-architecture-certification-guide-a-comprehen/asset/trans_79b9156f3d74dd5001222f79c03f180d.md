## Webassessor

**Kryterion Webassessor** 是一个用于安排、支付和参加考试的平台。由 Salesforce、**Amazon Web Services (AWS)** 和其他组织用于管理资格认证考试，它提供了一个安全的机制来预订和支付你的考试，然后启动考试本身。成绩永久保存，这意味着你针对特定产品套件（如 Salesforce）的所有考试历史都保存在一个地方。
