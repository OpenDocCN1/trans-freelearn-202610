## 第 48 章。如何选择开发者专长？

通过多年的培训开发者，我发现对程序员来说，决定自己的专长并专注于此至关重要。在本章中，我将与你分享我个人如何看待可用的不同开发者方向和专业领域。

你很可能在开发者职业生涯中不止一次做出这个选择，所以我建议你始终观察并意识到职业生涯中可以做出的选择。

### 如何选择开发者专长？

软件开发的世界如此庞大，以至于一个人不可能精通流程的每个方面。设想我走近一位世界级的田径教练并说我想为奥运会训练并在田径项目中赢得金牌。教练很可能会扫我一眼然后自嘲地笑。但之后他的第一个问题会是：*“你想训练哪个项目？”* 他会问这个问题，因为 100 码短跑的训练制度与跳高截然不同。

同样，作为一名开发者，你至少需要一次，很可能多次，缩小你的关注范围，确定未来几年你想成为什么类型的开发者。

我将带你了解每种开发者类别，以便你了解它们包含的内容。

### #3 – 前端开发者

在选择开发者专长时，第三层选择是前端部分。直到不久前，前端开发者被认为是一整天都在处理 HTML 和 CSS 的人。他们的主要目标是让应用看起来*漂亮*。

然而，随着客户端框架的出现，前端开发者的定义发生了巨大变化。这些框架，例如 Angular 和 React，使得前端程序员能够用很少的服务器端交互构建完整的应用。

这些应用完全在浏览器中渲染，因为它们是用 JavaScript 编写的。每当应用需要获取额外数据时，它只需与 API 通信。我常用的一个模式是构建多个服务器端 Ruby 应用，然后使用一个 Angular 前端应用在浏览器中渲染用户界面。

因此，如果你喜欢构建用户会直接交互的应用，并且不害怕与 API 合作，前端开发可能就是适合你的选择。

### #4 – 移动开发者

开发者类型列表中的下一个是移动开发。如果你对构建下一个 Angry Birds 或 Instagram 的想法感到兴奋，移动开发领域可能是不错的选择。

移动编程曾经是一个非常难以进入的领域。仅在几年前，你就需要掌握多种语言（Objective C 和 Java）来构建智能手机应用。然而，JavaScript 框架

例如 Ionic 和 React Native 已经让用 JavaScript 构建行为类似原生智能手机应用的应用程序成为可能。

你仍然可以使用 Swift、Objective C 和 Java 等语言来构建真正的原生应用。而且，对于专精于这些语言的开发者来说，始终会有大量工作岗位。然而，如果你是自由职业者或全栈开发者，通过利用 JavaScript 框架，你可以为所有平台构建基于智能手机和平板电脑的应用。

而且，根据我的经验，这些 JavaScript 框架的学习曲线比传统移动语言要低不少。此外，你可能已经注意到，用于基于 JavaScript 的移动应用和前端编程的工具是相似的。正是由于这种协同效应，我有不少开发者朋友已经从服务端开发转向了前端编码，因为这样可以让他们着手构建适用于桌面、平板和手机的应用。

### #5 – 数据科学家

这过去被认为是数据领域，几年前我会把它称为数据开发者类别。然而，数据和大数据已经迅速演变为统计数据分析以及使用人工智能（如神经网络）来洞察现在可用的大量信息的领域。

这些新领域正在改变我们处理数据和理解信息的方式，对开发者来说也是一个巨大的新职业领域。目前，所涉及的数学可能相当令人生畏，因此你需要决定自己是否准备好应对大量的数学和深入的算法学习。随着时间的推移，数学会变得更加抽象，如果你对人工智能和深度算法学习系统的想法感兴趣，这无疑是当今有抱负的开发者可以考虑的一个领域。一些最现代的 Python 库为开发者沉浸于这一领域提供了极好的途径。

### 做出决定

如果你是开发新手，不要感到有压力要立刻选择一个专业方向。相反，我的建议是探索每一种开发层面，直到找到你真正热爱的焦点。

在本章中，我提供了开发者类型的非常高层面的视图。然而，在现实中，你需要让你的开发焦点变得更加具体。

例如，如果你是服务端开发者，你可能希望专注于构建电子商务应用或实现会计系统。如果你是一名有抱负的前端开发者，你可能想成为一名世界级的安全专家。

我发现的一个关键见解是，查看开发者招聘公告板对相当多的人（尤其是较新的程序员）有帮助。招聘公告板非常适合列出各公司正在招聘的专业方向。通过浏览一系列潜在的职位描述，它可能帮助你弄清楚在职业生涯中下一步想要专注的方向。
