## 第 41 章 自由职业者的客户沟通技巧

最初建立自由职业业务时，我经常听到客户对之前项目开发者的抱怨：沟通不畅、缺乏透明度。

作为开发者，我知道陷入“想立刻埋头写代码、构建项目”这一陷阱有多容易。然而，如果没有恰当的客户沟通，你会遇到以下问题：

- 客户会认为你没有在做事。不管实际情况如何，如果你不告诉客户你做了什么，他们的第一反应就是什么都没做。当你发出账单，而所收工时与客户根据你的更新所估算的不一致时，事情就会变得非常麻烦。
- 你可能会以客户意想不到的方式构建功能。我曾多次遇到这种情况：我把某个需求理解成一种意思，而客户心里想的却完全是另一回事。

虽然解决沟通问题的本能反应可能是与客户保持持续沟通，但这种方法会浪费你的时间，还会让他们觉得你随时都有空，这会限制你的自由，而自由恰恰是你当初成为自由职业者的主要原因之一。

### 维持良好客户沟通的系统

考虑到这些问题，如果你能完善自由职业者身份中的这一部分，你会发现它既能带来满意的客户，也能为你营造健康的自由职业环境。

```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
```
