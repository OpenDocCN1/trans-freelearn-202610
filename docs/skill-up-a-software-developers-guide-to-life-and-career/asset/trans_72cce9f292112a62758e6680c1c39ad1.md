## 复制粘贴是学习的敌人

除了创建视觉思维导图和利用模式之外，我还要补充最后一条记忆技巧：不要复制粘贴你试图学习的新概念。

我第一次听到这个建议是从 *泽德·A·肖* 那里，他是 *《硬核学习》* 编程书系列的作者。他告诉读者，在编写代码时甚至不要同时看书。他认为，强迫自己在不参考文档的情况下敲代码，会迫使大脑真正思考每一次击键。

以我作为开发者和教师的个人经验来看，我发现那些复制粘贴代码或只是跟着教程走的学生，与那些尝试（即使失败了）自己实现代码的学生之间存在显著差异。

## 并非所有东西都需要记忆

最后，我想消除一个常见的误区。作为开发者，你不需要记住每个类和方法才能构建项目。

即使是专业程序员也会经常查阅文档。与其觉得必须记住所有东西，不如专注于记住你最常用的术语。这将使记忆过程更加实际和自然。

## 第20章 学习新编程语言的系统

在本章中，我将讨论如何学习一门新的编程语言。我会带你了解我在学习一门新语言或框架时使用的五个步骤。

多年来，我受雇于 Learn.co 和 AppDev 等机构，为以下内容编写编程课程：

- Ruby on Rails
- Ruby编程
- Python
- Java
- 多种JavaScript框架

我真正用来构建应用的唯一语言是 Ruby，这意味着我不得不熟练使用多种我实际上没有太多经验的语言，有时时间非常短。多年来，我形成了一套学习新语言或框架的系统，这正是本章要介绍的。

当我学习一门新的编程语言时，我会遵循以下步骤：

1. 观看该语言的完整教程系列。观看时我不试图跟着做，只是观察讲师在演示中的操作，从而对语言语法和流程有一个宏观了解。
2. 创建一个 *你好，世界* 应用。我会加入一些基础知识，例如 **运行循环**、**创建并实例化一个类**，以及我从教程中记住的其他高级概念。
3. 选择一种排序算法并用该语言实现。即使排序算法是像选择排序或冒泡排序这样的基础算法也没关系。排序算法会迫使你使用数据结构、循环、变量和函数。将这些元素结合起来，你就能很好地掌握这门语言的工作方式。
4. 学习该语言的高级教程，这次要跟着讲师一起构建程序。
5. 学习该语言的编程面试题。能够自信地回答这些问题，能让你很好地了解自己是否对该语言有扎实的理解。

我已经将这五个步骤用于多种语言，并且我可以告诉你，一旦你精通了一门语言，你会发现学习新编程语言容易得多，因为大多数语言都有不少共通之处，你只需要学习语法上的差异。

希望这些技巧能帮助你学习一门新的编程语言。如果你在学习过程中发现了其他有用的方法，欢迎随时写信告诉我。祝你好运，编码愉快！

## 第21章 开发学习技巧——反向记笔记

在本章中，我们将回到过去，回顾我开发反向记笔记系统的那段经历。用 Google 快速搜索一下就会发现，这个词是我创造的；然而，这个流程并非我发明的。

当我刚开始在得州理工大学读计算机科学研究生时，有一门课让我很吃力。距离我上次坐在教室里已经有大约十年了，我很难在1.5小时的讲座中保持专注。

### 传统记笔记的问题

那段时间，我花费了大量时间与理查德·沃森博士会面。在一次会面中，我提出了自己遇到的问题。他的第一个问题与我是如何为课程记笔记有关。

我把笔记拿给他看，他立刻告诉我，我记笔记的方法完全错了。他指出了我笔记中多处遗漏了作为统一元素的关键概念。如果不记下这些内容，我根本无法理解这些主题。

在重新审视笔记时，我意识到他说得完全正确。我把时间花在了记录事实和我以为是关键术语的内容上，却常常未能阐明所有内容是如何协同工作的。

例如，在关于树形数据结构的笔记中，我列出了二叉搜索树和B树的每个关键元素，但未能从行为角度描述树组件之间的内在差异。

这就像在历史课上记笔记，写下拿破仑在滑铁卢战役中战败的人名、日期和地点，却没有描述他旧军队与战败时那支军队之间的关键差异。

### 反向记笔记

发现自己记笔记的方法是错的，这很好。但如果没学到一种替代方法，也不会有太大用处。于是，沃森博士让我尝试一种不同类型的记笔记技巧。

他说，上课时要把笔和纸收起来。他建议我上课时不要记笔记，只需专心听讲。他还指示我，讲座一结束，就应该找一个安静的地方，写下我从讲座中记住的所有主题。

起初，我对这种方法持怀疑态度，主要是因为我担心重要的概念会左耳进右耳出。他补充说，我应该把讲座录下来，这样我可以把录音作为安全网，以防忘记某些主题。

尽管我对这种方法持否定看法，我还是决定试一试。（显然，我自然的记笔记方法并不有效，所以我没什么可失去的。）我严格按照沃森博士的建议去做。结果我惊喜地发现，与在讲座中只顾着写下概念相比，这种反向记笔记的方法让我记住了更多信息。

### 反向记笔记的好处

多年前我就开始采用这种反向记笔记的流程，今天仍在沿用。在这段时间里，我注意到了这种方法的一些关键好处。

### 更集中的专注力

首先也是最重要的，知道自己之后必须复述讲座的关键内容，这会迫使我在听讲时保持更高的专注程度。
