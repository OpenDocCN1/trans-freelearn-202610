def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

在处理客户项目时，我参与过各种应用程序，从几天就能构建的应用，到开发时间超过一年、涉及十多名开发人员的应用。那么，与外包Web开发人员合作的最佳方式是什么？

## 管理外包Web开发人员的系统

根据我管理外包Web开发人员的复杂经历，我构建了以下系统，以确保我挑选到合适的开发人员，并且他们生成的代码能让客户满意：

- 1. 自动化测试：无论你是独立工作还是与外包开发人员合作，使用自动化测试都至关重要。这可以包括BDD（行为驱动开发）或单元测试。无论如何，这个过程将有助于确保应用程序的所有功能正常运行，同时确保新功能不会破坏已有的功能。

- 2. 每日报告：根据你与客户的具体情况，每天收到当天开发工作的报告非常重要。如果你没有收到每日更新，很可能当天没有进行任何工作。

- 3. 应用程序访问权限：如果你恰好只负责管理应用程序而不实际开发，请确保你拥有适当的访问权限。这包括命令行数据库访问权限、你在应用程序部署服务器上的公钥，以及任何错误日志系统，例如Honeybadger或AppSignal。

## 总结

如果你引入外包开发团队，这通常意味着你的时间有限。但是，如果你遵循这三个步骤，它将有助于你的项目取得成功。

## 第43章 如何创建准确的自由职业报价？

作为自由职业者，能够给出良好的估价是你最关键的任务之一。如果你报价过低，最终会面对愤怒的客户，因为即使你做了出色的工作，他也必须支付超出预算的费用。如果你报价过高，你很可能失去这份工作，而潜在客户会去找报价更低的竞争对手。

多年来，我曾犯过偏向两个极端的错误，并不得不承担后果。这些后果并不令人愉快，这就是为什么我在本章为你整理了一个我用于构建报价的公式：

- 1. 获取项目需求的详细分解。没有这一点，无论你做什么都无法创建准确的报价。想象一下，如果建筑师必须给一位说“我想要一栋带漂亮围栏的好房子”的客户做估算，他无法准确估算建房的成本。建筑师会获得平方英尺、卧室数量以及所有附加功能的详细清单。同样，你需要对应用程序所需的每一项功能进行详细分解。
- 2. 获取功能列表后，将它们分类，例如：数据库设置、前端设计、用户权限配置等等。然后把每个功能放入其中一个类别桶中。
- 3. 将所有数据放入电子表格中，按你在第二步中创建的类别进行分段。
- 4. 对电子表格中的每项功能给出保守的估算。
- 5. 让电子表格汇总总小时数或成本，这就是项目估算。

这个公式看起来像是常识吗？很好，因为创建准确的自由职业报价本应是一个简单的过程！
