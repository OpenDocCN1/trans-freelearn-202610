
这种专业水平将让你能够向潜在客户、同事和未来的雇主清晰地展示你的专业能力。这些项目还会为你提供一个出色的代码库，供你在未来的项目中参考。

我已记不清有多少次回看过去的作品集项目，只为查看自己当时是如何实现某个特定功能的，以便在我当时正在开发的应用中使用同样的做法。希望这份清单能激励你构建出自己的项目作品集。

## 第 39 章 测试驱动开发对程序员的重要性

让我们来讨论**测试驱动开发**的重要性。首先，如果你对 TDD 或 BDD 这些术语感到陌生——它们分别是测试驱动开发和行为驱动开发的缩写——那么它们指的是为应用程序构建代码测试的做法。

更具体地说，TDD 和 BDD 是*软件开发流程，即在实现任何代码之前，先创建一个测试来设定预期结果。*

下面是一个使用 TDD 为用户类创建“返回全名”功能的示例：

1. 创建一个测试，调用名为 `full_name` 的新方法；该方法将用户的名和姓组合起来，并返回一个把两部分合并为单个值的字符串：

![](img/de22e3e00f8df753e0d57f7da4d1c581_216_0.png)

2. 然后运行测试，同时知道它会失败：

### 测试失败

3. 接着，添加一个最基本的代码实现：

### 实现代码

```ruby
def full_name(first, last)
  first + " " + last
end
```

这样测试就会通过：

### 测试通过

4. 然后回头重构实现，以确保其符合最佳实践，并且重构不会破坏任何东西：

### 重构代码

```ruby
def full_name(first, last)
  return "" unless first && last
  first + " " + last
end
```

这个过程被称为“红、绿、重构”工作流，是所有语言和框架中相当标准的实践。

在*极限编程*中，贝克（Beck）说，测试是让开发过程不偏离轨道、不超出预算的最大关键之一。

3. **文档**：当一个使用 TDD 构建的应用程序完成后，测试应该能够提供该软件 100% 的文档。某些测试框架（如 RSpec）甚至能够以文档形式输出测试，完整描述应用的行为，即使是非技术人员也能理解。

4. **引导开发过程**：编写优秀软件的最重要关键之一，是尽可能将代码拆分成许多小而易于管理的块。使用 TDD 时，你自然会写出小方法、高效的类定义，并且代码膨胀会降到最低。当你遵循 TDD 实践时，测试本身应当引领软件开发，最终结果应该是一个组织良好且可扩展的代码库。

TDD 有一个告诫：如果测试套件结构不佳，测试就毫无意义。如果你只是创建大量测试，而这些测试除了测试某个语言或框架的核心功能外没有任何作用，那么你的测试套件将不会带来任何好处。然而，如果你在构建应用时让测试驱动你的开发和代码结构，你最终会得到一个值得骄傲的优秀应用。

如需了解更多信息，我建议阅读*马丁·福勒*（Martin Fowler）的完整系列文章，这被视为有史以来对 TDD 最深入的讨论之一。

### 小结

希望本章能帮助你回答与 TDD 重要性相关的问题，祝你面试顺利！

## 第 40 章 自由职业者的 SEO 最佳实践与策略

如果你构建的是用户通过网络访问的应用，那么你很可能被客户要求提供一个对 SEO 友好的网站，以帮助将新客户引导到他们的网站。你可能也意识到，SEO 的世界如此广阔，即使你把余下的职业生涯都用来研究它，也无法完全掌握。

话虽如此，我发现只要遵循一套 SEO 最佳实践，我创建的网站就会对搜索引擎友好，客户也会对其获得的自然流量感到满意。搜索趋势似乎每天都在变化，而我个人没有时间去追踪谷歌搜索算法的每一次更新。因此，我专注于 SEO 最佳实践；这些实践对我来说效果不错，而且它们遵循搜索引擎的白帽营销做法，这样我就不用冒被谷歌或必应惩罚的风险。

### SEO 最佳实践教程

首先，*内容为王*。独一无二的优质内容永远是 SEO 最重要的标准。

### 内容为王

作为一个从计算机科学角度花了无数小时研究谷歌搜索算法的人，我可以说，这个算法想要做的全部事情，就是把搜索用户与他们正在寻找的最佳、最相关的内容连接起来。

算法的所有细微之处，例如页面排名、链接计数等，都只是谷歌试图自动在互联网上找到最佳内容的方式。话虽如此，优质内容本身并不能保证流量，但没有它，你无法在搜索引擎中获得很长时间的关注。

### 反向链接

第六是反向链接。这是一个危险的领域，因为反向链接曾经是决定网站页面排名的首要标准。我记得大约 15 年前，刚开始做网站时，如果我能让一个热门网站链接到我发布的网站，新网站就会开始获得搜索引擎流量，并在 24 小时内出现在搜索结果中更靠前的位置。

不过，情况已经发生了很大变化，反向链接如今不像过去那么重要，但仍然很有帮助。我之前说反向链接可能很危险，是因为谷歌在检测试图钻空子的用户方面已经变得出奇地擅长。如果你使用黑帽技术获取反向链接，很快就会发现自己的网站受到惩罚，甚至被谷歌完全除名。

所以，我现在获取反向链接的做法是：使用 HARO 等工具联系记者和其他博主，在其他网站贡献引言并接受采访。作为回报，他们通常会链接到我的某个网站。

这种建立反向链接的方式较慢，但从长远来看是个好策略。谷歌还会关注那些向你收费、让你发布客座文章并链接回你网站的站点，所以我强烈建议远离这类服务。

### 内容聚焦

这份清单的最后一项是，你的内容要有焦点。射箭时，有靶子会更有帮助；写博客文章或发布页面时，有一个目标关键词也很重要。创作内容时，我会选择一个短语，并让整篇内容围绕它展开。

如果没有焦点词或短语，你的文章很难获得关注。因此，请确保你创作的每一篇文章都始终保持聚焦。市面上也有很多不错的工具，可以确保你遵循搜索引擎最佳实践。通常，我会使用一款名为 Yoast 的工具，它对每篇文章采用复选框式的方式。

### 小结

希望这份 SEO 最佳实践总结对你有所帮助，你可以将其用在自己的项目中，为自己或客户的网站带来更多流量。

## 第 41 章 自由职业者的客户沟通技巧

最初建立自由职业业务时，我经常听到客户对之前项目开发者的抱怨：沟通不畅、缺乏透明度。

作为开发者，我知道陷入“想立刻埋头写代码、构建项目”这一陷阱有多容易。然而，如果没有恰当的客户沟通，你会遇到以下问题：

- 客户会认为你没有在做事。不管实际情况如何，如果你不告诉客户你做了什么，他们的第一反应就是什么都没做。当你发出账单，而所收工时与客户根据你的更新所估算的不一致时，事情就会变得非常麻烦。
- 你可能会以客户意想不到的方式构建功能。我曾多次遇到这种情况：我把某个需求理解成一种意思，而客户心里想的却完全是另一回事。

虽然解决沟通问题的本能反应可能是与客户保持持续沟通，但这种方法会浪费你的时间，还会让他们觉得你随时都有空，这会限制你的自由，而自由恰恰是你当初成为自由职业者的主要原因之一。
