## 第 38 章 帮助获取新客户的自职业作品集示例

在本章中，我将讨论*自由职业作品集示例*，你可以用它们来吸引客户。在决定要在作品集中包含哪些类型的项目之前，回答几个关键问题很重要：

- 我要向谁展示这个作品集？
- 我喜欢开发哪些类型的功能？

第一个问题相当标准；你需要了解你的受众，以确保你的作品能够产生最大的影响。例如，如果你想吸引小型夫妻店，那么在作品集中塞满 3D Unity 僵尸游戏渲染图就没有太大意义了。

第二个问题关系到你作为开发者的热情。太多的程序员创建了充满普通项目的作品集，他们并不真正热爱这些项目，这一点潜在雇主和客户都能看得出来。确保你构建的项目符合你作为开发者的个性，并且你对最终结果感到满意。作品集项目不是简单地从你的开发者清单上划掉的条目，它们应该是你个人引以为豪并且喜欢构建的项目。

### 自由职业作品集示例

以下自由职业作品集项目示例包含了全面的功能集，应该会给各种客户留下深刻印象。不过，它们只是起点，不是硬性规定。

#### 社交网络工具

这类项目是构建一个设计简洁的基本社交网络，具备帖子、关注者和评论等功能，并整合至少一个独特/高级功能，例如让用户能够互相编辑帖子。

当我想雇佣新开发者时，我希望看到他们能够自如地处理复杂的数据模型，例如社交网络应用所需的数据模型，并且能够处理高级权限结构非常重要，所以这是一个不错的作品集项目。

#### 一个 API 工具

例如，为 Stack Overflow 开发一个搜索引擎，使其具备比主 Web 应用更高级的功能。这样的项目可以证明你能够使用 API，并且能够实现搜索引擎功能。

#### 一个会计应用程序

你不需要重建 QuickBooks。不过，一个会计项目可以展示你懂得如何处理财务计算、回调、高级数据库查询和信息安全。

#### 一个日程安排应用程序

我构建过几个日程安排应用。这类应用可以展示你懂得如何处理日期和时间（这对任何开发者来说都不是容易的任务），以及复杂的验证。

#### 一个前端应用程序

使用 AngularJS 或 React 等前端框架创建一个应用，并将其与 Ruby on Rails 等服务端后端集成。这将展示你懂得如何运用基于服务的架构和设计，而这正是我的客户的一个先决条件。
