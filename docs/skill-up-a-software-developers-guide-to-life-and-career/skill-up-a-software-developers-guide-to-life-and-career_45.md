## 第 49 章 如何选择你的下一门编程语言？

我们已经讨论了选择开发专业方向（如前端、服务端或移动端）的重要性。然而，仅仅选择一个专业方向是不够的。你还需要决定在职业生涯的初始阶段或下一阶段，你想专注于哪种编程语言。

当然，没有哪本书或指南能告诉你接下来应该学习什么语言。这个决定只能由你自己做出。因此，在本章中，我的目标是帮助你根据当前目标决定如何选择编程语言。

### 如何选择编程语言？

如果你经历了选择开发者专业方向的练习，你会注意到决定编程语言也有类似的模式。快速浏览维基百科就会发现，可供选择的编程语言有数百种之多。如果你采取逐一看每种语言的方法，你可能要等到未来一百年左右才能做出明智的决定！

由于逐一遍历完整的语言列表并不实际，我推荐两个过程来帮助你决定如何选择编程语言。

### 你想要的下一份工作

列表中的第一个是基于你想要的工作来选择编程语言。如果你听过“为想要的工作而打扮”这句话，它也适用于开发。

例如，如果你想为微软工作或从事基于微软的产品开发，花数年时间学习 Python 和 Django 是没有意义的。相反，你应该专注于学习 .NET 开发技术栈以及诸如 *C#* 之类的语言。

这种策略在某些情况下是明智的，例如微软，因为就业市场上有无数 .NET 框架的职位。这意味着即使你没有被微软录用，你仍然可以在使用 .NET 技术栈的组织中找到工作。

然而，这种方法对于更专门的语言和公司并不那么有效。例如，想象一下你花数年时间学习 Facebook 定制的 PHP 版本，代号 HipHop。如果你没能得到 Facebook 的工作，你会发现使用 HipHop 框架的公司并不多，你的工作机会将受到限制。我认为这种方法有点冒险，因为它往往把所有的鸡蛋放在一个篮子里。

### 你的专业方向

我个人最喜欢的方法是选择一种与你的开发专业方向相匹配的语言。我偏爱这种策略，因为这是我在开发之旅中使用的，而且对我很有效。

基于你的开发专业方向来决定如何选择编程语言，意味着你要考虑自己想构建的应用程序类型。然后逆向推导，整理出一份最适合你目标的语言列表。

例如，假设你决定自己的开发专业方向是构建大数据应用。通过这种方法，你可以大幅缩小符合你目标的编程语言列表。许多语言都能进行大数据处理，但真正专门从事这一领域的语言只有少数，例如：

- R
- Scala
- Python

所以，通过先确定你的专业方向，你就已经把语言列表从数千种……缩小到了三种。

### 基于专业方向的映射

既然我认为这种方法最有效，那就让我们来看一看开发专业方向与流行语言之间的映射：

- **全栈开发**：如果你想成为全栈开发者，Ruby on Rails 技术栈可能是你的最佳选择。这个技术栈为 Web 开发者提供了一套很棒的工具，并支持构建健壮的应用程序。
- **前端开发**：对于前端开发者来说，要走的路径就在 JavaScript 轨道上。JavaScript 编程语言已成为前端开发领域的明显赢家。而当你精通 JavaScript 后，你将能够使用 React 和 Angular 等流行的前端框架。
- **服务端开发**：服务端开发的世界可能有点令人生畏。如果你查看服务端语言，你会发现 C、C++ 和 Java 等底层语言。然而，Ruby、Python 和 Go 等编程语言也专注于服务端开发。
- **数据科学家**：数据科学的世界乍一看似乎对开发者提出了不可能的要求，即同时要成为高级数学家。然而，如果你探索现代 Python 库，你会发现丰富的现成算法，因此你确实可以很快创建自己的神经网络和机器学习系统。如果你已经熟悉 Python，基于这个原因我推荐它。如果你有更多统计背景，那么我建议你进一步探索 R 语言如何成为新职业路径的入口。

在我的编程之旅中，我努力专精于一门解释型语言和一门编译型语言。我选择 Ruby 作为我的解释型语言，至于编译型语言，我从 C 开始。然而，这些年来我并没有发现我的 C 知识有多少实际用途。此外，我已经转向了 Scala 语言，因为它非常适合构建大数据算法。




### 总结

总而言之，与选择你的开发专业方向一样，我给有志于学习的学生们的建议是：在决定深入学习哪些语言之前，先尝试多种语言。网上有许多工具可以帮助你并排比较各种语言。

例如，促使我学习 Scala 的决定性因素之一，就是浏览 Rosetta Code（https://rosettacode.org/wiki/Category:Scala）上的 Scala 算法实现。所以，不要急于挑选一种编程语言。多花些时间思考和调研，你会更有能力做出正确的选择。
