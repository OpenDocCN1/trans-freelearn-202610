+   2. We will Change the Groups to Content, and select the Content: Text: **Available at these meals** checkbox.
+   
+   3. Click **Add**, and Drupal will prompt you for the order to sort the items on. In our case, the default sort order of **Ascending** is fine, so we can simply click **Update**.
