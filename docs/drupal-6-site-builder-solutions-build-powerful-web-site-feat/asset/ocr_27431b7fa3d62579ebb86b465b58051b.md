# Inserting images using the image module

Because inserting images manually can be a security risk, as well as a time-consuming and error-prone process, the Drupal team created the Image module which allows images to be easily added to any page. We have already installed the Image module in a previous section, so we can now jump straight into adding images.

# Creating images

To create a new image, select the Image link from the Create content menu. Drupal will display a form where you can select the image to be added to the site, give the picture a Title, and add a description to it.
