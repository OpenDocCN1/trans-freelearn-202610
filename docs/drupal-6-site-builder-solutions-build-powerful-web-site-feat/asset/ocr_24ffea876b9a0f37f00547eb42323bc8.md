# Creating a page and menu

Now that the view has been fully set up, we can create a Page and Menu for the View. Because we cloned this content type, we can simply modify the existing values.

+   1. Click on the **Page link** link for the view.
+   2. Click on the link next to the **Path** label in the **Page Settings** group. Change this value to `search_menu`, and update the setting.
+   3. Click on the link next to the **Menu** label and change this value to **Search the Menu**.
