6. You can specify the center of the map by modifying the portion of the URL after the q. This can be an actual street address, the name of a well-known building or monument, or a specific latitude and longitude. You can verify whether or not Google will be able to find the address by checking on maps.google.com.

An example of a URL based on an address or place name is:

```
q=Washington+Monument
```

An example of a URL based on a specific latitude and longitude is:

```
ll=39.521985,-104.784765
```
