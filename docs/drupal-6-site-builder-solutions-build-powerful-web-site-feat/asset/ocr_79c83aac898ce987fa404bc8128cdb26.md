# Setting up notifications when orders are complete

Good Eatin' Goal: Ensure that the kitchen is notified when orders are submitted from customers, so that they can prepare the meal for the customer.

Additional modules needed: Ubercart (http://drupal.org/project/ubercart).

# Basic steps

+   1. In order to be notified each time an order is placed, we will use **Conditional actions**. These are configured by selecting **Site configuration** and then **Conditional actions**, from the **Administer** menu.
+   2. As you can see from the following screenshot, there are several actions that are automatically added when you install Ubercart.
