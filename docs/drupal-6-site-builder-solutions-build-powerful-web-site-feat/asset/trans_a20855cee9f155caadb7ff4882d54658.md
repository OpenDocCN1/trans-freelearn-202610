

将服务器放置在专用数据中心通常能提供最佳的整体性能和可靠性，因为数据中心会进行气候控制以优化服务器性能，会拥有快速可靠的互联网连接，并提供充足的清洁电力，并在电力暂时中断时配备发电机。然而，如果你需要进行物理维护，访问服务器会变得不那么方便，而且你将不得不放弃对环境的部分控制。

提供硬件和托管服务的托管提供商会让你对服务器的控制权最少，因为你通常无法访问数据中心或查看物理硬件。然而，这种类型的提供商会为你处理大部分或全部管理任务，因此你不必担心服务器的日常维护。

我使用过全部三种类型的托管，每种类型都有其优势，具体取决于你的网站规模以及网站的繁忙程度。较小的网站通常会选择一体式托管，因为性能不是那么关键，初始成本较低，而且你不需要太多知识即可开始。较大的企业网站通常会购买自己的服务器，并将其托管在自己的站点或数据中心，具体取决于其位置的连接速度以及他们保护和维护服务器的能力。

## Drupal 专用托管计划

几家提供一体式托管计划的公司拥有专门针对 Drupal 网站量身定制的服务器或计划。Drupal 专用功能可以表现为满足繁忙 Drupal 网站需求的改进硬件、Drupal 的安装和维护，或包含具有创建和维护 Drupal 网站经验的人员的支持团队。

Drupal 网站在此列出了此类主机：`http://drupal.org/hosting`。其中许多主机为 Drupal 协会提供支持，以直接帮助 Drupal 的持续开发和维护。此提供商列表比我在此提供的任何列表都更及时。

## 托管公司评测

当你研究要合作的网站主机时，你应该查看 Drupal.org 上的论坛，看看其他用户是否使用过他们，以及是否遇到过任何问题。如果某个托管提供商没有评测，你可能需要对互联网进行额外研究，看看是否有其他意见。当然，负面评论应持保留态度，因为大多数人只有在遇到问题时才会花时间抱怨，而不会记得发布关于优质服务的帖子。如有疑问，可以尝试联系托管提供商，看看他们如何回应你的问题。你也可以要求他们提供可能向你提供服务意见的客户。

## 经验很重要

当你选择一体式托管提供商时，你实际上是将网站成功的一个关键因素交给了别人。毕竟，如果你的网站宕机，没有人能找到你，而恢复取决于托管提供商纠正问题的速度。

考虑到这一点，审查公司成立的时间非常重要，因为经验更丰富的公司已经处理过更广泛的问题，这 hopefully 意味着他们知道如何在未来避免这些问题。较新的公司可能在问题出现之前并不了解潜在问题，这可能会导致你出现额外的停机时间。

当然，每个新企业都需要公平的机会，所以如果你发现一家较新的公司，你认为它能满足你的需求，请随意使用它。但请确保你对他们处理你能想到的所有紧急情况的计划进行额外研究。

## 访问便捷性

当你设置网站时，你需要确保在需要安装新版本、添加新模块以及执行其他维护任务时能够访问它。如果你的网站托管在你的建筑物中或附近的数据中心，你当然可以走到服务器前，登录并执行所需的维护。然而，大多数情况下，你希望使用 FTP 将文件传输到服务器，并使用 SSH（安全 shell）远程登录服务器。确保你的主机提供使用这些方法访问服务器的方式。

图形化控制面板为某些网站主机提供了 SSH 的替代方案。高质量的控制面板可以提供快速完成网站大多数管理任务的方法。如果你的主机确实提供控制面板，请确保在评估主机时审查其提供的功能，以确保它能满足你的需求。

## 其他包含的功能

为了吸引新客户，托管公司会包含可能对你有用也可能无用的额外功能。许多主机包含的项目如下：

- 1. 免费域名：这可能很不错，但你也可能想从转售商处购买域名，这可能会给你额外的域名设置控制权。对域名的单独控制也可以使在必要时更换主机变得更容易。
- 2. 电子邮件账户：在大多数情况下，你会随网站托管套餐获得电子邮件托管。除非你已有单独的电子邮件功能，否则最好使用主机的电子邮件，或者你可以为你的网站创建一个 Gmail 账户。Gmail 账户允许你从各种位置访问邮件，并且具有出色的垃圾邮件保护。根据企业规模，提供免费和付费选项。你可以在以下位置获取更多信息：http://www.google.com/apps/intl/en/business/messaging.html。
- 3. 在线网站构建器和网站创建器：由于我们使用的是 Drupal，我们不需要任何其他网站构建工具。
- 4. SSL 证书：如果你计划设置电子商务商店，你将需要 SSL 证书。你可以单独购买，但包含的证书将为你节省时间和金钱。
- 5. 定期备份：某些计划提供定期自动备份。你应该检查备份了什么、备份频率如何，以及在需要时从备份恢复需要做什么。
- 6. 支持：这是托管计划的一个关键方面。你希望确保支持技术人员知识渊博且易于联系。没有什么比在主机处长时间等待，然后技术人员无法回答你的问题，或看起来在照本宣科给出不适用于你特定问题的罐头答案更令人沮丧的了。你还应寻找提供电子邮件和电话支持的主机。你应在注册前测试支持，以确保主机对问题做出响应。

## 聘请开发者

尽管使用 Drupal 创建网站比使用传统方法和程序创建网站容易得多，但许多人仍然会聘请专业开发者为他们构建网站。这可以节省时间，让你专注于确保你的网站满足业务需求，而技术工作由他人处理。

当你选择开发者时，有几个问题需要牢记。本节将详细讨论这些问题。

### 开发者资质

当你选择开发者为你构建网站时，你希望确保开发者或开发公司在以下方面具有经验：

- 构建基于 Drupal 的网站的先前经验
- 如果你需要开发自定义功能，则构建 Drupal 模块的经验
- 使用 MySQL 的经验
- 对你计划部署网站的硬件和操作系统的经验
- 调优 Drupal 以满足网站性能需求的经验
- 运行与你的项目范围和复杂性相似的项目的经验

开发者还应易于合作，你应能够使用你选择的媒介轻松与他或她沟通。例如，如果你更喜欢通过电话讨论项目，选择只通过电子邮件沟通的开发者是没有意义的。

### 图形设计资质

可以让平面设计师负责开发网站的外观和感觉。平面设计师可能与开发者合作，也可能独立工作，只向开发者提供成品图像，开发者将其集成到网站主题中。

选择平面设计师可能是一个非常个人化的过程，因为网站设计是非常主观的工作。优秀的设计师会采纳你的建议并将其转化为比你想象更好的艺术作品。然而，成功并非 guaranteed，因为每个设计师往往都有自己擅长的特定风格。在聘请平面设计师之前，你应仔细审查设计师的作品集，以确保你喜欢他或她之前创作的设计。你还应联系他或她提供的任何参考，以确保其之前的客户感到满意。

你还需要确保开发者之前曾在基于 Drupal 的网站上工作过，以确认他们了解如何构建可与各种内容轻松使用的设计，并确保他们能提供正确的信息以成功主题化你正在创建的每个区块和自定义视图。
