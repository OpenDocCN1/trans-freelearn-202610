+   3. Drupal will display a page similar to the following where you can enter the API key and a shared secret.

+   4. After you have entered this information, click on **Save configuration**.

+   5. We can now build an input format that allows us to embed Flickr images into content, by clicking on **Site configuration** and then **Input format**, from the **Administer** menu.

+   6. Next, click **Add Input format** to begin building the new format.
