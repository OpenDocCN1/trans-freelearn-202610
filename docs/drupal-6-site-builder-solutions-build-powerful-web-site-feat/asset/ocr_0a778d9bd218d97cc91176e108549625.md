To create a new Input format, select the Add input format link. Drupal will now open a form to create a new input format. You will need to enter a name for the format, and you can also decide which users should be allowed to use this input format. This allows you to provide more functionality to users that have more experience, or are more trusted. The settings for our new image filter are as follows:

![](bbox=[0.15, 0.18, 0.84, 0.73])

After saving the input format, you need to configure the filters so that the image tag is allowed. Click on the Configure link and Drupal will display the settings for the filters.
