# Adding Products and Services

# Basic steps

+   1. Install the Content Taxonomy Module and activate it.
+   2. Open the **Content Type Manager** and edit the Menu Item type.
+   3. Click on the **Add Field** link at the top of the screen.
+   4. Enter the basic information about the new field type including the **Field name** and **Label**. Set the **Field type** to **Content Taxonomy Fields**, as shown here:

![](bbox=[0.084, 0.248, 0.918, 0.546])

+   5. Click Continue to save the basic information, and Drupal will prompt you for the type of Widget to be displayed. Because we will be entering from a large list of possible values, the **Autocomplete** widget is the most appropriate.
