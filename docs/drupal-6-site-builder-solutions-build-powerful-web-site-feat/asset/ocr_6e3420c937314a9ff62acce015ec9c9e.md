# Full size display settings

These settings control how this image is displayed in its full size, which defaults to 500x800. Note that if one of the dimensions is 0, then the image will be resized to be no larger than the other dimension.

Full size display width: *
500
The width of the image. It defaults to 500. Set it to 0 if you want to leave the image at its original aspect ratio.

Full size display height: *
800
The height of the image. It defaults to 800. Set it to 0 if you want to leave the image at its original aspect ratio.

Full size link:
Link to provider
Where the image will link when displayed in its full size. 'Content' links to the content page, 'provider' links to the provider's image page, and 'none' displays the image with no link.

In our case, the defaults are acceptable, so we will leave them alone.
