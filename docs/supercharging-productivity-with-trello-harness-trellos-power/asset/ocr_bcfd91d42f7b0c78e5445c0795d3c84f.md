# # Getting started

To start using Placker, add the Projects by Placker Power-Up to your board. You can find it by searching in the Power-Up directory for Placker.

![](bbox=[0.336, 0.218, 0.648, 0.36])

Figure 14.16 – Projects by Placker Power-Up card

When the Power-Up is added, the **Placker-sign up** button becomes visible on the board:

![](bbox=[0.168, 0.489, 0.825, 0.64])

Figure 14.17 – Placker buttons in the toolbar

Click **Placker - Sign-up** from the toolbar and you’ll be prompted to accept privacy terms and finish sign-up. After signing up, you’ll need to import the boards that you want to use.

When the board is imported into Placker, the Power-Up settings page will be available automatically so you can take the next step in setting up the board: mapping your board.
