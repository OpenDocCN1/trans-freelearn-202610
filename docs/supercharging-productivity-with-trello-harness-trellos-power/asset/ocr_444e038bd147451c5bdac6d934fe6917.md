# ## Selecting multiple cards to edit

Before you’re ready to make changes to cards, you need to select the ones you want to edit. You can do this by manually checking the box on each card, but that can still be a lot of clicking around, so I only do this if there’s no clearer way to quickly grab all the cards.

If you want to select all the cards in a list, click the checkbox at the top of the list. If you want to select all the cards on the board, just click the checkbox on each of the lists.
