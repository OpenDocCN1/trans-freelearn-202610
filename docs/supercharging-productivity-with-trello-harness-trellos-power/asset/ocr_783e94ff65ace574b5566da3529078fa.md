# # Accessing Power-Ups

To access Power-Ups, click the **Power-Ups** button in the top toolbar of any Trello board.

![](bbox=[0.124, 0.218, 0.866, 0.447])

Figure 11.1 – Power-Ups board button

If you have any Power-Ups already added to the board, you’ll see them appear in a list with the choice to toggle board button displays, as well as accessing the Power-Up settings. If you haven’t added any yet, you’ll see an inspiring graphic and an **Add Power-Ups** button.
