This does exactly what it says—removes all the members from a card. This is really handy if you need to reset a card that you’ve copied, or if you have a trigger that takes a card back to the beginning of a workflow.

# Real-world example

When the **reset** label is added to a card, move it to the **Backlog** list and remove all members from a card.

Just like with due dates and checklists, there might be scenarios when you need to reset a card. Use this rule to clear all members if a task has been deprioritized or needs re-assignment.

# Content actions

Content actions are all about changing the text you interact with inside cards, such as the card title, description, and comments. You can even send emails to yourself, which is a great way to customize notifications.
