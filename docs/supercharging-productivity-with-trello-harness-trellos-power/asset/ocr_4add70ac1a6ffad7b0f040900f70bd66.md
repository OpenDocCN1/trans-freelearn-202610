# # Rules

Rules simply combine the triggers and actions we’ve already discussed. _Chapter 6_ showed the possible triggers that can be set for events. You’ll find all of these triggers in this section, and you can then string to any number of actions.

Remember the examples such as “When a card is added to the board, set the due date to seven days from now”? You’d set that type of automation up here because it’s watching for an activity that happens on the board (such as a new card being added).
