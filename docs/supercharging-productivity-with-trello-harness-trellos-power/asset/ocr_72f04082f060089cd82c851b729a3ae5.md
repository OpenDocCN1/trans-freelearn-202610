# # Adding the Slack Power-Up

Search for Slack in the top-left search bar and select the first card that appears.

![](bbox=[0.347, 0.217, 0.649, 0.382])

Click the **Add** button. Immediately, the color and text of the button change. Click the newly created **Settings** button, then click **Edit Power-Up settings**.
