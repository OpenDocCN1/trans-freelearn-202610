# # Archive list

The last action in the **List** menu is to archive the list, which will archive the cards _and_ the list itself. This is useful if you realize you no longer need the list. If you accidentally archive a list (or cards in a list), you can go to the board settings in the **Archived items** area and send the list back to the board.
