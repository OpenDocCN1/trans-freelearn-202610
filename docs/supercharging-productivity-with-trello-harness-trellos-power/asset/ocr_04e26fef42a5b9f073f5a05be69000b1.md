# # Mapping a board

Once you connect a board, you’ll need to configure some settings about the board to help Placker function best.

You can do this by clicking the **Projects by Placker** button in your toolbar and selecting **Edit Power-Up** settings.

This will open the related Power-Up settings directly and help you set up tracking, calendar, and other relevant settings. You can also copy these from another board, so once you have it set up, you don’t have to do it again!
