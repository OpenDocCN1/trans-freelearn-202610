# # When an item is added to/removed from a checklist

This is like when a checklist is added, but now we’re looking at items inside of it. This is a trigger for when any item is added to a checklist.

# ## Real-world example

When an item containing “design” is added to a checklist, add @nanun-designer to the card.

This rule is useful if there are specific roles and tasks that members of your team consistently do.
