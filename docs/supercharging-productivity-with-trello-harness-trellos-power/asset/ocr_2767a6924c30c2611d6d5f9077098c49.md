In this template, the first list is a resource or details list. This is used to collect all the links and related information about a specific project. Here, you can include any project briefs, reports, blueprints, designs, or anything else that is relevant to the project. You may also want to include a section for FAQs on this list.

I like to create sections of a list by creating a card that is just a horizontal line. To do that, simply create a new card and type `-----` as the name. This will create a card that has a line in it, which is great for breaking up items inside a list:
