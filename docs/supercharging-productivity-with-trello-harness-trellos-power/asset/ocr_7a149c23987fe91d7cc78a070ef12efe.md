# # Getting started

Before you can dive into the elements of Trello, you’ll need to create an account and create your first workspace.

# # Creating an account

Go to [trello.com](https://trello.com/) and click **Sign up**. You’ll be directed to an Atlassian login page. You can use your existing Atlassian login if you use other Atlassian products (such as Jira, Confluence, or Bitbucket). This makes it extremely easy to get started and keeps everything under one login if you use multiple tools. Otherwise, you’ll need to create a new account.

You can do that by typing an email address or choosing one of the social account options, such as Gmail:
