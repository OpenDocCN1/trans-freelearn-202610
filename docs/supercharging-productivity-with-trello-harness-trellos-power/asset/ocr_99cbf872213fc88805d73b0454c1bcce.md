# Cloud drives

Many of us use tools to share documents in the cloud, such as Google Drive, Box, Dropbox, and OneDrive. Attaching cloud files works very similarly, regardless of the platform.

Previously, Trello's attachments had sections for some of those, such as Box and Google Drive. But with recent updates to their Attachment menu, those have moved away. If you want to incorporate Cloud files in your board, you can search for a Power-Up (such as the Google Drive Power-Up), or you can attach those files via their link, which we'll talk about in a minute.
