Notice that you have access to all the core fields in Trello, as you’d expect, such as the list and board, dates and members, and so on. But you can also see **Time in List**, as well as any custom fields you have set. I like to use the **Expected Effort** field that I created because I can see whether I’ve made a realistic plan for the week, or look back on tasks completed for the previous week and see how much I’ve accomplished. **Priority** is also helpful to look at so I can determine where to start and focus my time.
