# # Add a member at random/in turn to a card

If you have multiple people that you want to fairly assign to cards, you can
use this option to either randomly pick someone or assign people evenly
and in order (in turn). This is much better than trying to build out the steps
to make this happen, so having it as a command is fantastic. It’s great if you
have a whole team of people that can do something, so you don’t want to
assign it to just one person every time.
