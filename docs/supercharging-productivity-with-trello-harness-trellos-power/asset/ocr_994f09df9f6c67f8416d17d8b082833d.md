# # Inline attachments

Rather than attaching links to a card via the **Attachments** section, you can incorporate them inside descriptions and comments. Try it out!

Paste a link into a comment. I used to hate recording myself, but now I actually prefer communicating thoughts over Loom rather than typing a long comment, so I’ll paste in a link from Loom.
