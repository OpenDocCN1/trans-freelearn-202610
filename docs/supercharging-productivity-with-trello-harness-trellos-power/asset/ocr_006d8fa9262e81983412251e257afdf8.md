# # Viewing multiple boards together

Go to any other boards you want to add to Placker and follow the preceding steps. Now when you want to access Placker features, you’ll be able to access those boards as well!

From any board that you’ve added Placker to, click one of the view options in the toolbar. I’ll choose **Board** for now.
