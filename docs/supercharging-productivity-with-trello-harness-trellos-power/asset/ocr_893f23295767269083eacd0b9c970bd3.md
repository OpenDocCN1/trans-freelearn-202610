# # When a custom field is set to a specific value

This checks when a custom field has a specific value—so, not just that it’s set but that it matches what you’re looking for.

Real-world example

When the **Department** custom field is set to `Design`, add **@venus** to the card.

This rule is useful to assign owners to a card based on the department it might belong to, which you can select from a dropdown field.

# # When a checkbox custom field is checked/unchecked

Custom fields come in multiple shapes and sizes, one of which can be a checkbox. This trigger lets you set criteria based on whether a specific checkbox custom field is checked or unchecked.

Real-world example

When the **Approved** custom field is checked, post a comment to the card saying `@card this has been approved`.

This rule allows you to use fields to indicate details about the status of a project and communicate that to the next team member without needing to manually create a comment and alert everyone.
