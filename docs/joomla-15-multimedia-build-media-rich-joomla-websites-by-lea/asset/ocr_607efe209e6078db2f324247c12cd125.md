When new podcasts are added to the Podcast Suite, they will be shown automatically, and any users subscribed to these feeds will be notified of the new podcasts that are available.

I have rushed through this pretty quickly in order to show you the basic process, but there are other features available in the Joomla! Podcast Suite. In the administration, click on Menu | Main Menu. Create a new menu link to Articles | Article Layout, and select the Joomla! Audio Article that was just created for your first podcast. Create a link called Podcast Number 1, and make it a submenu of the main audio link. Once you have saved this new menu item, visit the frontend of your site to view the results:
