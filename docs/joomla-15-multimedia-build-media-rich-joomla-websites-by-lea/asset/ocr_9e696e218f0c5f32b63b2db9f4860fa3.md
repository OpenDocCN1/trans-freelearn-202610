# RokBox Plugin (P)

![](bbox=[0.15, 0.2, 0.84, 0.58])

RokBox is a MooTools powered JavaScript slideshow that allows you to quickly and easily display multiple media formats including images, videos (video sharing services also), and music.

RokBox provides a theme system that allows you to create your own custom ones to fit your websites design. It includes two predefined themes, a light theme and a dark theme that will fit seamlessly into your site design.

RokBox is a nice all-in-one solution to present multimedia content off with professional effects. It can play external media sources such as YouTube videos as easily as it can play your own files.
