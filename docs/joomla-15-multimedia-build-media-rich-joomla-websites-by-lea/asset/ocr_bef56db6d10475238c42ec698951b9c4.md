# Bit rates

Bit rates describe how much information is processed per unit of time. Bit rates are an important part of video and audio compression, and all major video compression formats use various bit rates to crunch the data during compression.

![](bbox=[0.28, 0.18, 0.72, 0.37])

The unit of bit rate is bits per second (bps or bit / s) and can be used with prefixes such as (Kilo) Kbps, or (Mega) MBps, and so on. When exporting files from video editing applications, you may see the bit rate as an exporting option. What is important to remember is the higher the bit rate, the more information the file contains, resulting in a higher quality video file. A higher bit rate file will also result in more effort to encode / decode it, as well as a larger file size. Further information about video bit rates can be found at http://en.wikipedia.org/wiki/Bit_rate.

# Video containers

There are many compression standards used to compress video file sizes into an efficient state. A compressed video file will be wrapped in a container file, which contains all of the relevant information to play back the video. In order to play this video, the viewing system needs to understand both the video codec the file has been compressed with, and the video container.

The following is a list of the most common video containers used for the Web:

+   - AVI
+   - FLV
+   - MOV
+   - MPEG
