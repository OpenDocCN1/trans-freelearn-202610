# Joomla! and video channel integration

Video is the coolest thing on the Web at the moment, and there are some great Joomla! Video Extensions available to display content from external video distribution sites.

> It is important to mention that there are a number of specific video solutions for Joomla! that also provide support for streaming external video content. Please see the extensions listed in Chapter 6, Using Video in Your Joomla! Website for further video solutions.

# easiertube (P)

easiertube is a Joomla! Plugin that couldn't get any easier to manage and use. It is designed to display videos in your articles from the following sources: YouTube, Google, UStream, Revver, and MySpace.

![](bbox=[0.27, 0.42, 0.73, 0.64])

To use it, simply install this plugin and configure its settings in the Plugin Parameters area. Enter the remote video link within your content articles and the plugin will automatically convert the URL and embed the player in your page. Parameters can be set for:

+   - Front page display width and height
+   - Main content display width and height
+   - Fullscreen
+   - Autoplay
