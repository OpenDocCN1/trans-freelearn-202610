For the purpose of this topic, I have chosen to use and take screenshots from an FTP program called "Transmit". It is a commercial product, but personally one of my favorites. For those whose use MAC computers, Transmit is recognized as a wonderful FTP tool.

# Connecting using an FTP program

Almost all FTP programs require similar information in order to connect to the web server. Depending on the program you are using, the naming of these fields may be slightly different.

In order to connect, we need the following information which is usually derived from setting up a user account (with FTP permissions) on your web hosting control panel:

+   1. **Server**
+      This is the server address that you wish to connect to. Typically this can look like `ftp.yourserver.com`. Depending on the domain name settings, it can sometimes be your domain name, such as `www.yourserver.com`.
