# Scripting and multimedia

When the majority of users hear the term "Multimedia", it may conjure initial thoughts of "Images" and "Video" content. The term is used to describe these prominent media elements; however, in this quickly evolving world of the Web, new features and interactive elements are presenting themselves regularly.

A number of commercial template providers are now creating feature packed template systems for Joomla! that not only contain the basic template elements, but also include numerous scripts, making the package more feature packed and versatile for users.

These features include sophisticated JavaScript drop-down menu systems, user-defined module ordering, mobile web themes, extensive typography options, and many more. While some of these features may not be considered as traditional forms of "Multimedia", they usually contain text, images, fonts, colors, and provide an interactive experience to the site user.
