# Text, Characters, and Fonts
in Your Joomla! Site

Some may ask, why is a chapter about text and fonts being included in a book about multimedia?

The answer is quite straightforward: Text (and the styling of it) is one of the most prominent media types that has been, and is still, used in web pages. Although it's such a major media element, web developers often pay little attention to this subject.

In this chapter, we will highlight the use of fonts, characters, and text within your Joomla! site, and how we can not only change the site design by using another font typeface, but also affect your site user's overall experience by doing so.

Topics include:

+   - Overview of text, characters, and fonts
+   - Fonts and their effect on website users
+   - Which font is best to use?
+   - Joomla! Templates and Cascading Style Sheets (CSS)
+   - Alternative methods to use custom fonts in your web pages
+   - Joomla! text and typography extensions
+   - Browser support and accessibility around fonts
