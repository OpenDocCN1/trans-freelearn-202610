If you plan to support other controllers or consoles such as the MOGA, OUYA,
or Nvidia Shield, you should have a different image for each of the controllers
and detect which one is connected by using the device descriptor. In the
particular case of OUYA, since it is a different marketplace, you can just have
another build variant with a special graphic.
