```
PersistableBundle bundle = new PersistableBundle();
bundle.putInt(MY_JOB_ARG1,2);

```

# Note

A PersistableBundle is a special kind of bundle that can be saved and restored
later. Its main purpose is to pass arguments to the deferred job execution.

As soon as we have all the criteria to schedule our defined job, we are able to
construct our JobInfo and use it to incorporate the job execution in our
application:

```
JobInfo.Builder jobBuilder = ...
// Set Criterias
JobInfo jobInfo = jobBuilder.setRequiresCharging(true)
setRequiresDeviceIdle(true).
...
        build();
```
