When any thread is in the waiting state, it releases the lock temporarily and gives
a chance to another thread to enter the mutual exclusion to push new messages
or enter into the wait state.

will call the start method to start the working threads and we will push 10
messages into a queue of work to be processed.

When the pushMessage()method is invoked, a new logging message is inserted
at the end of the queue and notifyAll() is invoked to notify all the available
threads.

As the pullMessage() method runs in a mutual-exclusion (synchronized) zone,
only one thread will wake up and return from the pull method. Once
pullMessage() returns, the logging message is printed:
