Static methods are often provided in classes with uses that are so generic, it doesn't make sense to have to create an object of the class. Another really useful class with static methods is Math. This class is actually a part of the Java API, not the Android API.

# Tip

Want to write a calculator app? It's easier than you think with the static methods of the Math class. You can take a look at them here:
http://docs.oracle.com/javase/7/docs/api/java/lang/Math.html.

If you try this out, you will need to import the Math class the same way you imported all the other classes we have used.
