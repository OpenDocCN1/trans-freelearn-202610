Right-click on the values-es folder and navigate to **New | Android resource file**. Name the file strings.xml. Now, copy and paste the following code:

```
<resources>
<string name="app_name">Localización</string>
<string name="movie_title">Lo que el viento se llevó</string>
<string name="line_one">... Rhett, si te vas, dónde iré? ¿Qué debo hacer?</string>
<string name="line_two">Francamente, querida. Me importa un bledo.</string>
</resources>
```

# Tip

If you don't provide all the string resources in the second strings.xml file, then the resources from the default will be used.
