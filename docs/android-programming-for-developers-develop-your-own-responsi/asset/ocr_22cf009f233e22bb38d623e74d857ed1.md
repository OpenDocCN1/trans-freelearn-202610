Let's start with the modifications to GameFragment. This class will be the one
implementing GameOverDialogListener.

As it happens, GameFragment already has a method called exitGame, which we
were invoking from the PauseDialog, so the only one to implement is
startNewGame.

For that we are going to extract all the logic for creating the GameEngine to a
method and then we will call it from the two places where a game can start:

+   - The onGlobalLayout method when the fragment is created and measured
+   - startNewGame when the "Play Again?" button is clicked on the GameOver
+   dialog

The code is like this:
