# The solution

Fortunately, this is a problem faced so commonly by mobile developers that the Android API has a solution built in.

We can add a single ListView widget (like ScrollView with boosters) to our UI layout and then interact with it using an adapter. We will use the BaseAdapter class, extend it, customize it, and then use it to control the data from ArrayList and display it in ListView.
