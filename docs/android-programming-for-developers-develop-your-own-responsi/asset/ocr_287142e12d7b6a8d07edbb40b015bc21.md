# # Running the Simple Photo app

If you are running this app on the emulator, then now would be a good time to slightly change the emulator's configuration to increase compatibility.

To do this, click on the AVD Manager icon in the menu bar of Android Studio. Click on the pencil icon to edit the emulator. Click on the **Advanced Settings** button. Find the **Camera** section. And set both the **Front** and **Back** options to **Emulated**.

Run the app and click on the **TAKE PICTURE** button. You will see that the default camera app for your device has opened. You can take a picture with all of the same options that you have when taking a photo under normal circumstances.
