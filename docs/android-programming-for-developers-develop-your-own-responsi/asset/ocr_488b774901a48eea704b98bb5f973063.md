# Summary

In this chapter, we looked at how to use simple Java arrays to store large amount of data with the same type. We also used ArrayList, which is like an array with a lot of extra features. Furthermore, we found out that both arrays and ArrayList are polymorphic, which means that a single array (or ArrayList) can hold multiple different objects as long as they are all derived from the same parent class.

Also, we learned about the BaseAdapter class that implements the Adapter interface. It allows us to bind together ListView and ArrayList, allowing the seamless display of data without us (the programmer) having to worry about the complex code that is part of these classes.

In the next chapter, we will put our theory into practice and enhance our Note To Self app.
