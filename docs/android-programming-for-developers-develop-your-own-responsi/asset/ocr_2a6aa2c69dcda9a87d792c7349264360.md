```
intArray [3] = 123;
```

Here is another example of initializing an array element:

```
intArray[10] = intArray[9] - intArray[4];
```

This declaration also includes assigning the value from an array to a regular variable of the same type, like this:

```
int myNamedInt = intArray [3];
```

Note, however, that myNamedInt is a separate and distinct primitive variable, and any changes to it do not affect the value stored in the intArray reference. It has its own space in the warehouse and is unconnected to the array. To be more specific, the array is on the heap and int is on the stack.
