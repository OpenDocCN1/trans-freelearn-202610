Then, it is as simple as pausing the game when a device is disconnected:

```
@Override
public void onInputDeviceRemoved(int deviceId) {
    if (!mGameEngine.isRunning()) {
        pauseGameAndShowPauseDialog();
    }
}
```

Note that this pauses the game when *any* device gets disconnected. It is unlikely that a device that is not a controller gets disconnected, but we could make sure it is a controller just by checking the source, as we did for
isGameControllerConnected.
