Most of this code will be quite straight forward because of the preparation we have done, but I will point out all the new code as it arises.

First, we have to add some more permissions to the AndroidManifest.xml file. Open it up now and add the highlighted lines in the next code listing:

```
<?xml version="1.0" encoding="utf-8"?>
<manifest
    xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.gamecodeschool.whereitssnap2" >

    <uses-permission
        android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:theme="@style/AppTheme" >
        <activity
            android:name=".MainActivity"
            android:label="@string/app_name" >
            <intent-filter>
                <action android:name="android.intent.action.MAIN" >
                <category android:name="android.intent.category.LAUNCHER" >
                </intent-filter>
            </activity>
        </application>
</manifest>
```

As we will soon see, we will be creating our own file, which will be used to save the photo. This is why we need the WRITE_EXTERNAL_STORAGE permission.
