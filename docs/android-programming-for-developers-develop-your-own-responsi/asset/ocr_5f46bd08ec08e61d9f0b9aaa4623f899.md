When the user clicks on the **Search** button, we will create a Runnable
anonymous class that searches for the word typed in R.id.wordEt EditText and
starts the thread to execute Runnable.

When the search completes, we will create an instance of Runnable
SetSynonymResult to publish the result back on the synonym TextView over the
UI thread:

```
class SetSynonymResult implements Runnable {
    final String synonym;

    SetSynonymResult(String synonym){
        this.synonym = synonym;
    }
    public void run() {
        TextView tv = (TextView)findViewById(R.id.synonymTv);
        tv.setText(this.synonym);
    }
};
```
