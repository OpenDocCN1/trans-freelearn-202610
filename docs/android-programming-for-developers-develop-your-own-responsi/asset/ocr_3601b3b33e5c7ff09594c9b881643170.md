* In the previous sections, we discussed Java classes in brief. An `Activity` class is a special Java class and every Android app must have at least one. It is the part of the code where our app will start when it is launched by the user, and this also handles any interaction with the user. The options on this screen provide different ready-made templates of the `Activity` class code in order to give programmers a fast start when creating various types of apps. As we are starting from scratch, the most appropriate option for us is **Blank Activity**. Make sure that **Blank Activity** is selected by clicking on it and then clicking on **Next**.
