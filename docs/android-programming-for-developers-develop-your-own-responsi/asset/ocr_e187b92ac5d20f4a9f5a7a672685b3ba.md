In the previouus code, we saw that we can use some really useful methods of the ArrayList class in our ArrayList object. We can add an item (myList.add), add it at a specific location (myList.add(x, value)), check whether ArrayList is empty (myList.isEmpty), see how big the array is (myList.size())), and get the current position of a given item (myList.indexOf).
