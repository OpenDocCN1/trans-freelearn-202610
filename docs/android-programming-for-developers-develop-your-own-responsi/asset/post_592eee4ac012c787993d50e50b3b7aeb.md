
## Appendix A. Bibliography

This learning path has been prepared for you to get started with developing applications using Android programming and advanced with deeper concepts. It comprises of the following Packt products:

- Android Programming for Beginners, John Horton
- Asynchronous Android Programming, Second Edition, Helder Vasconcelos
- Mastering Android Game Development, Raul Portales
