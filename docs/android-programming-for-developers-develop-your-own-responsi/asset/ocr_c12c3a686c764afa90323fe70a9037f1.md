highlighted in red in Android Studio. They are errors. We know that Toast and Log are classes and that classes are containers for code. Android Studio doesn't know about them until we tell it about them. We must add import to each class. Fortunately, this is semi-automatic. Click anywhere in the onCreate method.

+   3. Hold the Alt key and then press Enter. You need to perform this step twice. Once for Toast and once for Log. Android Studio adds the import directives at the top of the code with our other imports, and with this, the errors are gone.

+   4. Scroll to the top of MyActivity.java and take a look at the added import directives. Here they are, in case you are following along on a tablet or a paperback and don't have your development machine close by:

```
import android.util.Log;
import android.widget.Toast;
```

+   5. Now, run the app in the usual way.

It is possible that you might be wondering why the messages were output at the time they were. The simple answer is that the onCreate method is called just before the app starts to actually respond to the user. We will often put code in this method to get our apps set up and ready for user input. This is part of the lifecycle of an Android app, and you will learn more about it in Chapter 6, The Life and Times of an Android App.
