# Creating the AddressDetailFragment class and layout

Create a new class and call it AddressDetailFragment. Amend the class declaration and add two new members that can hold the entire collection of NameAndAddress objects as well as a single object for whatever the current one is. Add code so that the new class looks like this:

```
public class AddressDetailFragment extends Fragment {
    private ArrayList<NameAndAddress> mNamesAndAddresses;
    private NameAndAddress mCurrentNameAndAddress;
}
```

Now, add the onCreate method that gets an AddressBook instance from our singleton. Then, we chain getArguments and getInt to get the position of the NameAndAddress object that we want.

Now, override onCreate with this code:

```
@Override
public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);

    mNamesAndAddresses = AddressBook.getInstance().getBook();

    // Get the position from the Bundle
    // using the constant string
    int position = (int)getArguments().getInt("Position");

    // Initialize with the current name and address
    mCurrentNameAndAddress = mNamesAndAddresses.get(position);
}
```
