+   Now, look at the **Package name** field. It has been automatically derived from the previous two fields. If you used the same two values as suggested in the previous two steps, your package name will be com.gamecodeschool.helloandroid. Remember that a package is a collection of the Java classes that are our code files, and our apps can comprise one or more packages if we wish them to, but they must comprise at least one package. We can edit the package name by clicking on the edit link, but we have no need to do so here.
