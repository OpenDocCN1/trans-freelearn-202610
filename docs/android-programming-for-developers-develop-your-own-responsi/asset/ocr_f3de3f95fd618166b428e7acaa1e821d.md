Now, navigate to New | Java class. Type AddressBook in the Name field and click on the Kind drop-down menu and choose Singleton. Android Studio will give us a template for our singleton class called AddressBook. Here is the generated code:

```
public class AddressBook {
    private static AddressBook ourInstance = new AddressBook();

    public static AddressBook getInstance() {
        return ourInstance;
    }

    private AddressBook() {
    }
}
```
