# Anonymous classes

In the last chapter, we briefly introduced anonymous classes. Here, you will learn a little more about them and see how they can help us. When RadioButton is part of RadioGroup, the visual appearance of all of them is coordinated for us. All we need to do is react when any given radio button is pressed. Of course, as with any other button, we need to know when they have been clicked on.
