# Running the app

Run the app to see it working as normal. Now, we can change the localization settings to see the app in Spanish. Different devices vary slightly in how to do this, but the Nexus 5 emulator can be changed by clicking on the **Custom Locale** app, selecting es - ES, and then clicking on the **SELECT 'ES'** button in the bottom-left corner of the screen, as shown in the next screenshot:
