# # Adding visual feedback

As we did for rectangle collision detection, we will add some visual feedback to
the sprite to show the collision area while playing. In this case we just need to
draw a circle:

```
canvas.drawCircle(
(int) (mX + mWidth  2),
(int) (mY + mHeight  2),
(int) mRadius,
mPaint);
```

And, as simple as that, we can see the collision area of the sprites on the game.
