# Note

Fragments are going to be a fundamental part of many, if not all, of our future apps. As we did with naming conventions, string resources, and encapsulation, however, we will not use fragments for simple learning purposes or mini apps when they would be overkill. The exception to this will, of course, be when we are learning about or making mini apps to specifically demonstrate fragments.

In addition, there will be a few fragment-based mini apps where we will focus on just the fragment-related code in order to understand it properly.
