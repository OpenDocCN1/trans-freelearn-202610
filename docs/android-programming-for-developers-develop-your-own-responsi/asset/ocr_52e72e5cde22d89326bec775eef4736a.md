24. Finally, left-click on `TextView` to select it. Find the `visibility` property.
By default this is set to `visible`. Try changing it to `invisible`. It
disappears. This is probably what you expected and not the highlight of the
chapter. But now try changing the `visibility` property to `gone`. Note how
`ImageView` jumps up the layout to below the buttons. It does indeed behave
as if the text is "gone". You probably remember that we said we can change
properties on-the-fly while our app is running, using our Java code.
Switching between `visible`, `invisible`, and `gone` can be really useful.
