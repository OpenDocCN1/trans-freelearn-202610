Likewise, the Edit Properties button will be disabled if the user does not have the right to update properties on that specific document. The evaluation of that right does not include implicit owner/admin rights (described in Chapter 8, Security Features and Planning). From the screenshot, you can deduce that the document was created by poweruser and the logged in user is gcd_admin. Therefore, gcd_admin must have been explicitly granted AccessRight.WRITE (called Modify all properties in FEM) for that document.

# Restricted quantity documents

Recall that restricted quantity (RQ) documents are documents for which a limited number of copies may be in circulation at any given time. These requirements apply only to RQ documents:
