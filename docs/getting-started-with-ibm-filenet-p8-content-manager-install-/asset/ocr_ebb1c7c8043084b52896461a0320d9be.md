# Stored Searches and Search Templates

XT has a feature for pre-defining searches. The usual use case is that an administrator or someone who is technically adept creates the search definition. A more general population can then run the searches with less technical knowledge about the CE and application data models.

The difference between a Stored Search (SS) and a Search Template (ST) is that the template allows some input from the user at run time. The user who designs an SS or an ST has a great deal of flexibility in predefining restrictive conditions which the running user cannot evade, but there is equal flexibility in the input collected from a user. An SS or an ST is created using a Java applet called Search Designer (SD). You launch SD from XT by navigating to Tools | Advanced Tools | Search Designer.
