# Running the application

Running the application within VC# is quite simple. Right-click on the WhoAmI project node in the Solution Explorer and select Build to make sure all the latest changes have been compiled. Run the application by right-clicking the project node and navigating to Debug | Start New Instance. A console window will open up and you will see the output of the program. Press enter to end the program and close the window.

![](bbox=[0.156, 0.255, 0.814, 0.365])

The simple sample connects to the CE, asks if for information about the calling user, and then obtains and lists the names of all of the Object Stores (only one in our case).
