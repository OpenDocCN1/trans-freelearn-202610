A UITabBar instance (tab bar) at the bottom of the screen displays the Journal and Map buttons. The Journal button is selected, and you can see a table view displaying a list of journal entries in table view cells. A UISearchController instance displays a search bar at the top of the screen. This allows you to search for a particular journal entry.

To add a new journal entry, you tap the + button at the top of the screen. This displays the Add New Journal Entry screen.
