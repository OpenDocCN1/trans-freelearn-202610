# Use type safety to check values

Swift is a type-safe language. It checks to see whether you’re assigning values of the correct type to variables and flags mismatched types as errors. Let’s see how this works by following these steps:

+   1. Add the following statement to your playground to assign a string to restaurantRating and run it:

```
restaurantRating = "Good"
```

+   2. You’ll see an error notification (a red circle with an x inside it). The x means Xcode can’t suggest a fix for this. Click on the red circle.

+   3. Since you are trying to assign a string to a variable of type Double, the following error message is displayed:

![](bbox=[0.19, 0.365, 0.845, 0.47])

Figure 2.13: Expanded error notification with no fix

+   4. Comment out the line by typing // before it, as shown here:

```
// restaurantRating = "Good"
```

The red circle disappears as there are no more errors in your program.

![](bbox=[0.19, 0.625, 0.865, 0.71])
