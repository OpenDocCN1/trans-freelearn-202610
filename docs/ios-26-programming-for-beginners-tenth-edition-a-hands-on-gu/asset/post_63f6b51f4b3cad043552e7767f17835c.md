After a view has been loaded successfully, the view controller’s viewDidLoad() method will be called. You will override the viewDidLoad() method in your TableViewExampleController class to call createTableView(). Type in the following code just before the createTableView() method:

```

}
```

This sets the size of the live view, creates a table view instance, assigns it to tableView, and adds it as a subview to the view of the TableViewExampleController instance.         ["cloud.sun", "14 Sept 2025", "It's cloudy out"]

        view.bounds = CGRect(x: 0, y: -150, width: 375, height: 667)

    func createTableView() {

                                              width: view.frame.width,
                                              height: view.frame.height))

                           forCellReuseIdentifier: "cell")

        journalEntries.count
    }
