Let’s study the different parts of this screen.

A tab bar at the bottom of the screen displays the Journal and Map buttons. The Map button is selected, and you can see an MKMapView instance (map view) displaying a map on the screen, with pins indicating journal entries.

Tapping a pin will display an annotation, and tapping the button in the annotation will display the Journal Entry Detail screen for that journal entry.
