+   - **Border (9)**: This border separates the **Editor** and **Results** areas. You can drag the border to the left or right to change the space allocated to each area.
+   - **Debug area (10)**: This displays the results of the print() command.
+   - **Run and Stop buttons (11)**: This executes or stops the execution of all code in the playground.
+   - **Debug button (12)**: This shows and hides the Debug area.
