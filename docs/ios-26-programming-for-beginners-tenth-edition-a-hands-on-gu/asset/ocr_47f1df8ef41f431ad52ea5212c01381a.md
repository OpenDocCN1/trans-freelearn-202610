It is common to make mistakes when using Ctrl + drag to drag from an element in a storyboard scene to a file. If you make a mistake while doing so, this may cause a crash to occur when the app is launched. To check whether there are any errors in the connection between the table view and the JournalListViewController class, follow these steps:

+   1. Click the Navigator and Inspector buttons to display the Navigator and Inspector areas.

+   2. Click the Main storyboard file if it is not already selected. Click Journal under Journal Scene in the document outline and click the Connections inspector button:

![](bbox=[0.13, 0.27, 0.87, 0.41])

Figure 11.17: Connections inspector selected

The Connections inspector displays the links between your UI objects and your code. You will see the tableView outlet connected to Table View in the Outlets section.

+   3. If you see a tiny yellow warning icon, click on the x button to break the connection:

![](bbox=[0.33, 0.54, 0.72, 0.74])

Figure 11.18: Connections inspector showing the tableView outlet with a yellow warning icon
