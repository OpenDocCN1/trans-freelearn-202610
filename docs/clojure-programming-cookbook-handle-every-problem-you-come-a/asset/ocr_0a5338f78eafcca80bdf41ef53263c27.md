After registering, you will get a URL like the one shown here:
https://hooks.slack.com/services/T04692339/B1X2ECBCJ/1iYCVuXc9b

The section after the last / of the webhook URL you are given is what you need to use as a token, in the Riemann configuration - so, in this case, the token is 1iYCVu....

This gives the configuration and token shown here:

```
(def credentials
  {:account "your_slack_account",
   :token "1iYCVuXc9bsxZHBNPpeBDtR1"})

(def slacker
  (slack credentials
    {:username "webhookbot"
     :channel "#monitoring"
     :icon ":smile:"}))
```

The Slack integration is ready, so now let's filter on critical events and forward the events to Slack:

```
(streams
  (where (state "critical")
  slacker))
```

The sending of the original event is about the same as usual, but our first-service is having problems!

```
(-> c (r/send-event {:service "first-service" :state "critical" :metric 100 :description "first description"}))
```
