# core.spec

Clojure 1.9 supports spec library to support structures of data, validations, and generations by specifications by spec_. It's similar to prismatic/schema_, but it is included in Clojure, and there is no need to load additional libraries.

Let's create a new project named spec-example:

```
$ lein new spec-example
```

Then replace the version of Clojure:

```
:dependencies [[org.clojure/clojure "1.9.0-alpha7"]]
```

We will declare to use clojure.spec as follows:

```
(ns spec-example.core
```
