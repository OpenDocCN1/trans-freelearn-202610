A JAR file generated by uberjar contains all classes defined in the dependency section in the project.clj. It also contains Clojure core classes. So, the size of the JAR files is large and takes time to generate. Let's run the demo under JVM. The following command line starts the demo:

```
$ java -jar target/cljc-example-0.1.0-SNAPSHOT-standalone.jar
```

We will build the runtime for your browser. To invoke the following command compiles ClojureScript into JavaScript:

```
$ lein cljsbuild once min
```

In the following screenshot, check if the compilation is successful:

![](bbox=[0.06, 0.57, 0.94, 0.67])

We can specify dev or min as a build option in the :cljsbuild section:

```
:cljsbuild {:builds
  [{:id "dev"
    :source-paths ["src"]
    ......
    {:id "min"
    :source-paths ["src"]
    :compiler {:output-to
"resources/public/js/compiled/cljc_example.js"
```
