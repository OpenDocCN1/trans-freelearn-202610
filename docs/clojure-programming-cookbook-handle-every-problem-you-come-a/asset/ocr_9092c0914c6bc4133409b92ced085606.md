; ;=> 1000

Then we will define a method for the rectangular parallelepiped. It calculates a cubic capacity:

```
(defmethod volume :rectangular-parallelepiped [shape]
  (* (:length shape) (:width shape) (:height shape))
)
; ;=> #multifn[volume 0x3695e4a4]
(volume {:shape :rectangular-parallelepiped :length 2 :width 3
:height 4})
; ;=> 24
```

We will define another shape ball. The calculation is 4 / 3 (Pi radius **3):

```
(defmethod volume :ball [shape]
  (/ (* (. Math PI) (:radius shape) (:radius shape) (:radius shape)) 4.0) 3.0)
)
; ;=> #multifn[volume 0x3695e4a4]
(volume {:shape :ball :radius 2})
; ;=> 33.510321638291124
```

# How it works...

Multimethods dispatch by function specified as the first argument. In the preceding example, the :shape is a function to dispatch.

When the expression (volume {:shape :cube :length 10}) is called, the function :shape is applied as follows:

```
(:shape {:shape :cube :length 10})
; ;=> :cube
```

Then the following method is called.

```
(defmethod volume :cube [shape]
  (* (:length shape) (:length shape) (:length shape))
)
; ;=> #multifn[volume 0x4f6134c8]
```
