The next sample demonstrates splitting collections using the filter function. The split-into-two function splits a collection into two collections according to whether its elements are odd or even. The split-into-three function splits a collection into three collections by taking out remainders of its elements:

```
(defn split-into-two [col]
  (list (filter odd? col)
        (filter even? col)
        )
)
;;=> #'chapter03.core/split-into-two
(split-into-two (range 12))
;;=> ((1 3 5 7 9 11) (0 2 4 6 8 10))
(defn split-into-three [col]
  (list (filter #(= (rem % 3) 0) col)
        (filter #(= (rem % 3) 1) col)
        (filter #(= (rem % 3) 2) col)
        )
)
;;=> #'chapter03.core/split-into-three
(split-into-three (range 12))
;;=> ((0 3 6 9) (1 4 7 10) (2 5 8 11))
```
