Another version combining earlier techniques; we want to find all possible permutations such that a is in between 0 and 5 and q such that q is a concatenation of a and [2 3]. This is done easily using what we know already:

```
(run* [q]
    (fresh [a]
        (fd/in a (fd/interval 0 5))
        (conso a [2 3] q)))
; ((0 2 3) (1 2 3) (2 2 3) (3 2 3) (4 2 3) (5 2 3))
```

# Generating more data with more logic variables

Finding multiple values in core.logic simply requires looking for more than one q. Let's call them c1 c2 c3 and put a few constraints on them. All of c1, c2, and c3 are in the interval 1 to 20 and are such that c3 is 5 and c2 - c1 = c3. There are quite a few solutions, so we will limit ourselves to five possible solutions:

```
(run 5 [c1 c2 c3]
    (fd/in c1 c2 c3 (fd/interval 1 20))
    (fd/eq
        (= (- c2 c1) c3)
        (= c3 5)))
; ([1 6 5] [2 7 5] [3 8 5] [4 9 5] [5 10 5])
```

We now understand that more and more logic can be used to generate data. With just a bit more logic, we can take it where we are sure we only generate distinct tuples:

```
(run 5 [c1 c2 c3]
    (fd/in c1 c2 c3 (fd/interval 1 20))
    (fd/distinct [c1 c2 c3])
    (fd/eq
        (= (- c2 c1) c3)
        (= c3 5)))
; ([1 6 5] [2 7 5] [3 8 5] [4 9 5] [6 11 5])
```
