```
(def c (async/chan 1 (filter odd?)))
; We put an infinite lazy sequence on the channel
(async/onto-chan c (range))
; We then retrieve values ...
(async/<!! c) ; => 1
(async/<!! c) ; => 3
(async/<!! c) ; => 5
```

As planned, only odd values are popping up from the channel. Good job! It's now up to you to imagine new uses for those transducers.
