# Reactive Vaadin - Telegram on Raspberry Pi

The last example of this recipe brings Telegram bots to your local Raspberry Pi.

The library morse, a wrapper around the Telegram API, is used to register an event coming through your registered bot, meaning the Vaadin-based application will be running on the Raspberry Pi, and will be listening to bot messages caught by the morse polling engine.

In your project.clj, add the following line:

```
[morse "0.1.1"]
```
