```
sudo gem install riemann-tools
```

The script can then be started with the following:

```
riemann-health --host riemann-host
```

In the preceding command, `riemann-host` is either the hostname or the IP of the machine running the Riemann daemon.

Alright, now we have the daemon sending events to the Riemann host, but now you would eventually like to visualize them.
