# Methods and status codes of HTTP

The following table shows the major methods, and their descriptions and actions in Liberator:

| Method | Description |  |
|---|---|---|
| GET | Reads only access to a resource | exists? |
| PUT | Creates a new resource | put! |
| DELETE | Used for a removal of a resource | delete! |
| POST | Updates an existing resource or creates a new resource | post! |
| PATCH | Is similar to PUT but it sends only differences | patch! |
