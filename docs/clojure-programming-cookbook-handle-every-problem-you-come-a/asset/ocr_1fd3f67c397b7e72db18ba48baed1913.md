```
(- 1))
; -1
```

You can see the difference right away by comparing it with the previous macro:

```
(-> 2
    (- 1))
; 1
```

A few common Clojure functions are particularly well adapted to this second macro, in particular, map:

```
(->> [1 2 3]
    (map inc))
; (2 3 4)
```

The into function is another function that is very well suited and can be used to convert easily to a vector again at the end of the chain:

```
(->> [1 2 3]
    (map inc)
    (into []))
; [2 3 4]
```

# Introducing the cond-> and the cond->> macros

Now that we have seen the basics of two threading macros, we can build and expand on them with two other pretty useful ones, cond-> and cond->>.

First let's quickly remind ourselves how to use cond, which takes a set of conditions and returns the value with the first matching test:
