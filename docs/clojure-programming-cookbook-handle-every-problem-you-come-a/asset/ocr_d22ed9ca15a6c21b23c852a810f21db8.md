# Defining a protocol

Now, let's define a protocol and use it. First, define the Point record:

```
(defrecord Point [x y])
; ;=> chapter03.protocols.Point
```

The following code defines the IPoint protocol. It has move and distance functions. Protocols are Java interfaces and their functions are Java methods:

```
(defprotocol IPoint
  "A simple protocol for flying"
  (move [self delta])
  (distance [self])
)
; ;=> IPoint
```

Then, using _extend-protocol, define an implementation:

```
(require '[clojure.math.numeric-tower :as math])
; ;=> nil
(extend-protocol IPoint
  Point
  (move [self delta]
    (->Point
      (+ (.x self) (delta 0))
      (+ (.y self) (delta 1))))
  (distance [self]
    (math/sqrt
      (+ 
        (* (.x self) (.x self))
```
