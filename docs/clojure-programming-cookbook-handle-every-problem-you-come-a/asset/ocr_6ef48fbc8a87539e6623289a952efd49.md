# Compiling code for both Clojure and ClojureScript

To finish this recipe properly, we will show how to simply call Clojure code from ClojureScript, and the very good news today is, close to nothing. See for yourself! We will write the Fibonacci code we had earlier in a regular Clojure file:

```
(ns example.shared)
(def fib-seq
  ((fn rfib [a b]
    (lazy-seq (cons a (rfib b (+ a b)))))
  0 1))
```
