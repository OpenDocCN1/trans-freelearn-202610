# Summary of three reference types in Clojure

Concurrent operations can be classified as coordinated/uncoordinated and synchronous/asynchronous.

# Coordinated/uncoordinated

A coordinated operation keeps consistency between multiple resources. We previously saw an example of transferring money between accounts. That requires a coordinated operation. On the other hand, an uncoordinated operation only keeps the consistency for a single resource.

# Synchronous/asynchronous

A synchronous operation waits for its execution. An asynchronous operation only fires execution and does not wait.
