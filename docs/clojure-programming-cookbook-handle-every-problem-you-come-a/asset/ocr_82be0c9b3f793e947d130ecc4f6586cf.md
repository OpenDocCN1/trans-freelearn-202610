# What is Amazon EC2?

Using EC2, we don't need to buy hardware or install an operating system. Amazon provides various types of instance for customer use. Each instance type has various combinations of CPU, memory, storage, and networking capacity.

Some instance types are given in the following table. You can select appropriate instances according to the characteristics of your application.

| Instance type | Description |
|---|---|
| M4 | M4 type instance is designed for general-purpose computing. This family provides a balanced CPU, memory and network bandwidth |
| C4 | C4 type instance is designed for applications that consume CPU resources. C4 is the highest CPU performance with the lowest cost |
| R3 | R3 type instances are for memory-intensive applications |
| G2 | G2 type instances have a NVIDIA GPU and are used for graphic applications and GPU computing applications such as deep learning |
