defui is a macro to define components. It creates a js class, inheriting from React.Component. The next DateDisplay defines an HTML page for rendering a button and a current date/time:

```
(defui DateDisplay
  Object
  (render [this]
    (let [{:keys [date]} (om/props this)]
      (dom/div nil
        (dom/button
          #js {:onClick
               (fn [e]
                 (swap! app-state-date update-in [:date]
          get-local-now-string))}
          "Get current time ")
        (dom/h2 nil (str "Date : " date))
      ))))
;;=> #object[Function "function ....
```

Let's define a reconciler that holds app-state-date as a state:

```
(def reconciler-date
  (om/reconciler {:state app-state-date}))
;;=> #'om-next-example.core/reconciler-date
```

Let's add a DOM root for the reconciler to control. The first parameter is a reconciler, the second one is a component, and the last is a target DOM node:

```
(om/add-root! reconciler-date
              DateDisplay (gdom/getElement "app"))
;;=> #object[om-next-example.core.DateDisplay]
```
