Now the full ClojureScript version of the preceding jQuery code becomes easy to write. Let's create a new callback function click-slide-fn:

```
(defn click-slide-fn[]
    (if (.is (js/jQuery "div:first") ":hidden")
      (.slideDown (js/jQuery "div") "slow")
      (.hide (js/jQuery "div"))))
```

And let's replace the code handling the click with the new callback:

```
(.click
  (js/jQuery "body")
  click-slide-fn)
```
