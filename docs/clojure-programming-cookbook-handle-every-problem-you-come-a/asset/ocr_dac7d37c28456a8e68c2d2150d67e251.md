# Note

Note: It seems the query cannot be empty, so if you get no data showing on the dashboard later, make sure you have a query.

You can then escape widget editing by pressing Esc twice, the second time to escape widget selection mode. You should get something like the following:

![](bbox=[0.05, 0.26, 0.94, 0.6])

With almost no effort, you already have live data coming from your system.

If you want to limit the amount of data coming from it, update the query to show only, say, the CPU usage:

```
host != "Debian-jessie-amd64-netboot"  and service = "cpu"
```
