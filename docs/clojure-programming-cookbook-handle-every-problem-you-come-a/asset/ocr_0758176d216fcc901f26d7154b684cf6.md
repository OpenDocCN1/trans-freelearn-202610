# Installing Docker on Debian

Installing on Debian is conceptually easy, but let's take a few more steps, summarized in the following script.

It seems that the system, while being the default nowadays, does not read /etc/default/docker, as is usually the case, so the update is included in the following snippet too:

```
# get super powers
sudo -s
# prepare sustem to accept https repositories
apt-get install apt-transport-https ca-certificates
apt-key adv --keyserver hkp://p80.pool.sks-keyservers.net:80 --recv-keys 58118E89F3A912897C070ADBF76221572C52609D
# add the docker repository
echo "deb https://apt.dockerproject.org/repo debian-jessie
```
