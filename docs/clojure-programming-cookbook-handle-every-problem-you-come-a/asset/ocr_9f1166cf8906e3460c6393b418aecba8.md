To access fields, use keywords such as :name or :genre:

```
(:name doyle)
;;=> "Arthur Ignatius Conan Doyle"
(:name christie)
;;=> "Agatha Mary Clarissa Miller"
(:genre doyle)
;;=> ["Detective fiction" "fantasy" "science fiction" "historical novels" "non-fiction"]
(:genre christie)
;;=>["murder mystery" "thriller" "crime fiction" "detective" "romance"]
```

# Defining a type

Clojure's types are Java class but they have fewer features than records.
To define type, use the deftype:

```
(deftype Point [x y])
```
