We can plug this to a core.async channel so that the response will be pushed to a channel whenever the response is retrieved:

```
(ns chapter04.async
  (:require [org.httpkit.client :as http])
  (:require [clojure.core.async :as async]))

(defn async-get [url result]
  (http/get url {:keepalive 60000}
    #(async/go (async/>! result %))))
```

We can then go through the finish line, send async HTTP request, pipe the result to a channel, and then, finally, do some simple reading from the same channel:

```
(time
  (let [c (async/chan) res (atom [])]

    ;; send requests
    (doseq [i (range 1 3)]
      (async-get
        (format
          "http://requestb.in/tp6d3jtp?requestnumber=%d" i) c))
    ;; gather results
    (doseq [_ (range 1 3)]
      (swap! res conj (async/<!! c)))
    @res
  ))
```

Of course, we could do some more processing and encoding, but we will leave it as an exercise for you.
