All this recurring bumping around must be quite tiring. recur calls for the whole block to get called again so that the actor keeps on relaxing, which may not be a problem on such a sunny day after all!

Our actor is getting a bit masochistic and would like to be able to bump himself. Luckily for him, the defsfn macro exposes a self-reference that can be used to point to oneself:

```
(defsfn relaxing-afternoon-5 []
    (println "I am relaxing ...")
    (sleep 5000)
    (! @self :bump)
    (receive
        :bump
        (println "bumping myself!")))
```

```
(spawn relaxing-afternoon-5)
```

After five seconds, the relaxing afternoon will start sending a message to itself and react to it. @self is very useful and a widely used pattern for exchanging messages between different actors. The following sample code brings this to a better light by enhancing the message receiving part so that you can see who has been sending the message. Note that the receive part now gets a vector instead of a simple message keyword and also note that the message sending part is also sending a vector:

```
(defsfn relaxing-afternoon-6 []
    (println "I am relaxing ...")
    (sleep 1000)
```
