Now that you have the queue, it is time to listen to it, and send messages. The listen function takes a queue or a topic as well as a callback, as a simple Clojure function:

```
(msg/listen queue
  (fn[msg]
    (println msg)))
```

Then some regular Compojure routing will allow you to send messages to the same queue:

```
(require '[compojure.core :refer :all]
        '[compojure.route :as route])
(defroutes app
  (GET "/" [] "<h1>Hello Compojure World</h1><br/><a href=\"/msg\">Send a message</a>")
  (GET "/msg" [] (msg/publish queue "world") "OK")
  (route/not-found "<h1>Page not found</h1>"))
```

Here we go:

```
(defn -main []
  (web/run-dmc app :host "0.0.0.0" :port 8080))
```
