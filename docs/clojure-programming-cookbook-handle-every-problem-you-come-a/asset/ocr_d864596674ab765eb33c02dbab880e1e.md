```
namespace ClassLibrary1
{
    public class Class1
    {
        public int compute(int a)
        {
            return a + 1;
        }
    }
}
```

When you build the library from Visual Studio, or Xamarin for that matter, you will get a DLL file, which we can load with either LoadWithPartialName, if the path can be guessed by the runtime, or LoadFrom, to specify the full path to the DLL:

```
; (System.Reflection.Assembly/LoadWithPartialName "ClassLibrary1")
(System.Reflection.Assembly/LoadFrom "ClassLibrary1.dll")
```

In Clojure code, we can reference the code through an import call, specifying both the namespace and the Class we want to load:

```
(ns hello-clr2.core
  (:import [ClassLibrary1 Class1])
  (:gen-class)
)
```

Finally, we can make use of the C# compute function you wrote previously:

```
(defn -main
  [& args]
  (println  (.compute (Class1.) (first args))))
```

A regular call to the main function either through lein or directly through a compiled EXE file will do it!

```
lein clr run -m hello-clr2.core 10
; 11
```
