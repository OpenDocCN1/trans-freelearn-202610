# Tracing requests

Liberator has tracing and debugging features. In the following code, we will redefine a handler using liberator.dev/wrap-trace to show a trace text and a trace graph:

```
(def handler
  (-> customer
    wrap-params
    (wrap-trace :header :ui)))
```
