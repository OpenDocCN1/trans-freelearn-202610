# Using Maven for Clojure and Java projects

We will demonstrate how to convert an existing Leiningen project into a Maven project to create a mixed project using Clojure and Java. Now let's start!

```
$ lein pom
```

Let's look at the generated pom.xml. Dependent JARs (such as Clojure JAR and Jackson-related JARs) used in Clojure are declared in the dependencies section in the pom.xml:

```
<dependencies>
    <dependency>
        <groupId>org.clojure</groupId>
        <artifactId>clojure</artifactId>
        <version>1.8.0</version>
    </dependency>
    <dependency>
        <groupId>org.clojure</groupId>
        <artifactId>math.numeric-tower</artifactId>
        <version>0.0.4</version>
```
