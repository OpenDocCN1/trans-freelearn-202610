```
[x y z a b c]
)
;;=> [1 2 3 "a" "b" "c"]
```

The variadic arguments feature accepts variable number of arguments we have already seen in Chapter 1, Live Programming with Clojure. In the following example, the z binds to (3 4):

```
(let [[x y & z] [1 2 3 4]]
  [x y z]
)
;;=> [1 2 (3 4)]
```

Underscore (_) represents unused arguments explicitly:

```
(let [[x _ z] [1 2 3]]
  [x z]
)
;;=> [1 3]
```

# Using map destructuring

The map destructuring extracts desired values from maps. In the following example, the x, y, and z bind to 1, 2, and 3:

```
(let
  [{x :x y :y z :z} {:x 1 :y 2 :z 3}]
  [x y z])
;;=> [1 2 3]
```

The preceding expression looks a bit verbose. There is a simpler, shortcut expression of map destructuring, as follows:

```
(let
  [{:keys [x y z]} {:x 1 :y 2 :z 3}]
  [x y z])
;;=> [1 2 3]
```

If keys of maps are strings or symbols, use the :strs or :syms instead:

```
(let
  [{:strs [x y z]} {"x" 1 "y" 2 "z" 3}]
  [x y z])
;;=> [1 2 3]
```
