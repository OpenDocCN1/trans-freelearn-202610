```
(println
  (str "- " (rand-int i)))
; this is the part where you look at the console
```

After just a bit of clean up, the generated code looks like the following, which is mostly a simple loop, but we'll admit that the preceding was easier on the eyes:

```
(loop [i 0 value nil]
  (if (< i 10)
    (let [new-value
          (do (println (str "- " (rand-int i))))]
      (recur (inc i) new-value))
    value))
```

A nice way to write your own macro is actually to first write what you want the generated code from the macro to be like, then work your way backward to the defmacro exercise.

Voila!

# There's more...

There's more, but not much as far as macros are concerned. Macros are fast, so be sure to use them when you can.

To finish on my favorite example, we will quickly have a look at the deftest macro from clojure.test.

# deftest

Without all the boilerplate, this is how the deftest macro looks. You have to admit that you are not surprised by the macro-specific syntax anymore, are you?

```
(defmacro deftest
  [name & body]
  (when *load-tests*
    `(def ~(vary-meta name assoc :test `(fn [] ~@body))
       (fn [] (test-var (var ~name))))))
```
