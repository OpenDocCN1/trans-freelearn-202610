The first step is to create our DTDL models based on an ontology and the specific structure of the model file in DTDL, which in turn is based on the **Resource Description Framework (RDF)**. The RDF nature of DTDL was covered in _Chapter 4, Getting Started with Our First Digital Twin_. There are no specific requirements for the structure of the ontology, but it is recommended that you follow the guidance of _Digital Twins Definition Language-based RealEstateCore ontology for smart buildings_ (`http://bit. ly/idt-buildingontology`), an open source initiative by Microsoft for creating Digital Twins. It provides a very comprehensive description of the ontology and is highly recommended if you want to create more advanced Digital Twin ontologies.
