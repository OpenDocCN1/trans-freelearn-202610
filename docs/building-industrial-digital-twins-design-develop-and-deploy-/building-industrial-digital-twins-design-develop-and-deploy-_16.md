# 与 GE 可再生能源数字服务首席技术官 Anwar Ahmed 的数字孪生访谈

### 简介：

Anwar Ahmed 是一位经验丰富的工程与技术领导者，负责软件产品和数字平台开发，拥有丰富的工业物联网平台、数据、分析以及面向能源领域的数字孪生经验。他拥有 Kakatiya 大学的工程物理学硕士学位，以及印度 Devi Ahilya 大学的仪表与控制系统第二个硕士学位。

1. 请分享一下你正式简历中未涵盖的一个方面。

我在相关领域拥有两项专利。

- 用于运营风电场的数字孪生接口 (US9995278B2)
- 用于管理耦合到电网的拥有多台风力涡轮机的风电场的数字系统和方法 (US10132295B2)

2. 请分享贵公司在过去 1-2 年的主要关注点。

在 GE 可再生能源，我们的重点是设计高效且可靠的风力涡轮机，为此我们在从设计和制造强大涡轮机到在其整个生命周期内高效运行的全过程中大量利用软件技术。我们构建的数字风电场软件从传感器产生数据开始，数据在边缘收集并流式传输到云端进行存储和分析。这使我们能够实时监控涡轮机并保持正常运行时间，从电气安全边界采取快速行动。历史数据被分析以检测涡轮机的问题，并预测可能的部件故障，使我们能够从非计划停机转向计划停机，从而提高涡轮机的整体可用性。我们在过去几年的重点是通过对多年涡轮机运行中收集的数据进行机器学习，并利用我们对所制造涡轮机部件物理特性的理解，来完善我们的分析能力，以便为客户带来直接的成果。

3. 你如何定义数字孪生，或者你对数字孪生的独特观点是什么？

数字孪生是物理资产的软件副本。它是云端涡轮机的数学模型，通过机器学习不断了解其物理对应物。随着越来越多的数据随时间从真实资产流入，模型变得越来越智能，使我们能够更轻松地模拟可能导致部件故障的恶劣条件或情况。现在的学习成果可以转移到物理资产，要么作为优化的控制算法，要么通过手动采取行动，例如更换模型识别出即将故障的部件。每个资产在其自身意义上都是独特的，因为它在运行中可能会遇到不同的物理条件，因此单独建模每个资产至关重要。

4. 贵公司如何为数字孪生做出贡献或拥抱数字孪生？

数字孪生的概念并不新鲜，但“数字孪生”这个术语是新的。我们长期以来一直在进行基于模型的控制，其中学习到的模型有助于驱动控制算法。数字孪生是一项进步，它将建模提升到一个新水平，即不再建模特定的控制回路，而是建模整个资产并不断训练这个模型。我们为新设计的涡轮机创建软件模型，并模拟实际涡轮机在运行中遇到的风况和各种物理条件，以查看模型的表现并调整设计，帮助我们构建更可靠、经久耐用的涡轮机。我们还使用数字孪生来计算部件的剩余寿命，并执行基于寿命的维护，而不是固定计划维护。

5. 今天数字孪生是准备好用于生产、试点使用、前沿概念，还是仅仅是炒作？

底层技术的可用性正在帮助使数字孪生成为现实。能够每秒执行 15 万亿次浮点运算的强大 CPU 到多核 GPU 已成为主流。微软 Azure 和 AWS 都提供基于 GPU 的虚拟机或容器，可以轻松运行计算密集型数学模型，并提供进行机器学习和 AI 所需的所有软件和现成算法。如今，物联网硬件甚至可以在边缘运行重型计算，使构建数字孪生成为可能，从而在我们优化和运行资产的方式上翻开新篇章。

我仍然认为为完整且大型的物理资产构建机器学习模型成本高昂。今天的关键是识别问题中高价值的部分，并尝试通过数字孪生解决该特定问题，例如通过提前检测潜在部件故障来减少非计划停机，或构建数字孪生以优化风力涡轮机的发电量或提高风力涡轮机的整体可用性。

6. 对那些希望在其业务中采用新兴技术的人有什么建议？

技术已经存在，许多事情都是可能的！但要“聚焦”，识别你想要解决的、能为客户带来特定结果的问题。你不想构建一个寻找问题的解决方案，而是要识别你想要解决的问题，然后构建你的解决方案。
