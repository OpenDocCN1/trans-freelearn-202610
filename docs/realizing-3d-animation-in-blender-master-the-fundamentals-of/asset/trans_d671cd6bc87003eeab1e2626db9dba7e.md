## 作者简介

**Sam Brubaker** 是一位艺术家、3D 动画师和 Blender 专家。2004 年偶然发现 Blender 后，Sam 立志成为一名动画师，2006 年他的短片获得了 Blender 基金会颁发的 Suzanne 奖最佳动画奖。2012 年，Sam 从北卡罗来纳州立大学毕业，获得艺术与设计学士学位，随即开始了自由动画师的职业生涯，随后担任 Blender 讲师。此后，他一直作为自由职业者和教育工作者生活在美国东西两海岸。他现在与妻子 Dr. Elina Thomas 定居在中西部。

**Daniele Daldoss** 是一位创意设计师，专注于将经典设计转化为动态图形和 3D 动画。他的工作范围从一次性艺术项目到全规模品牌开发，并额外在流程中融入数字技术。他的客户既有小企业，也有大型跨国公司。

## 前言

当有人对学习 3D 动画产生兴趣时，他们通常问的第一个问题是：“我该用什么软件？”

根据最聪明、最有经验的动画师的回答，争论这个问题是浪费时间。应用程序只是工具，不是让你成为动画师的原因。重要的是动画师的创意、耐心和学习意愿。每一分钟花在纠结“哪个软件最好”上，都是在分散你实际制作动画的注意力，所以直接选一个开始吧！

我喜欢这个答案，你呢？不管怎样，正确答案是 Blender。

让 Blender 成为最好的不是它出色的功能和极具竞争力的价格（$0）。这个古怪的免费程序自 2004 年我作为青少年下载的版本以来已发生巨大变化。它作为动画师行业工具的适用性不再像过去那样有争议。但让它成为最佳 3D 程序的原因丝毫未变——Blender 根据 GNU 通用公共许可证作为自由软件授权。不仅是免费如 $0，而是*真正*自由。该程序及其源代码可供任何人免费下载、修改和分享，并依法规定永远保持如此。它不会被其他公司收购。它永远不会向你收取订阅费。如果你打算在一个程序上投入数小时乃至数小时的时间和创造力，这一“特性”应是你最看重的。

Blender 另一个未变的特点是教学的乐趣。Blender 向来充满用户偶然发现的功能。社区像学者分享晦涩知识一样互相分享这些“秘诀”。通过本书，我希望能与你分享一点这种魔力。

### 你的动画工作站

运行 Blender 的最低和推荐系统要求可在 Blender 官方网站找到：

`https://www.blender.org/download/requirements/`

几乎所有新款笔记本和台式电脑都能满足这些标准。即使你的机器不再是最新款，也很有可能完美运行 Blender。

#### 硬件

如果你在为 3D 动画专门选购新电脑或升级，我建议将预算投向独立的 NVIDIA 或 AMD 显卡。高性能 GPU 是确保动画在 Blender 中流畅播放的最关键电脑部件。

你还需要鼠标和键盘。Blender 几乎利用键盘上每个键作为热键，因此带有所有功能键和小键盘的全尺寸键盘最有帮助。至于鼠标，这是不可商量的。你需要一只带有左键、右键和中间可点击滚轮的鼠标。触控板不行！

#### 操作系统

Blender 运行在 Windows、macOS 和 Linux 上。如果你有选择权且对 Linux 好奇，那恰好是 Blender 的最佳操作系统。现在是尝试的绝佳时机！
