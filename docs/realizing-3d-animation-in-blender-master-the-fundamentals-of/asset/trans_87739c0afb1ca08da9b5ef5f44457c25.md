
![图14.14：两个动作条](image/B17149_14_14.jpg)

我们可以那样做，也可以通过直接在`Nonlinear Animation editor`中将动作添加为条带来节省几次按键。要执行此操作，请遵循以下步骤：

1. 前往`Nonlinear Animation editor`，确保选中`RIG-rain`。
2. 使用`Add Action`（`Shift + A`），选择你刚刚追加的对口型动作。
3. 如有需要，将新动作条移动到正确的时间点。

有两个动作条同时影响Rain，我们终于能看到是什么让NLA如此特别了！

我们之前制作的那两个动作已被合成为一个完整的动画，同时将这两个动作保留在单独的轨道中——这使得它们更容易独立控制、调整，或作为链接库进行引用。现在，Rain可以在真正移动的同时说出她的台词了！

# 动画条带时间

这里还有一个我们可以用NLA做的技巧：控制时间本身！通过为一个简单的值制作动画，我们可以控制动作条的时间评估方式，从而模拟慢动作、延时摄影，甚至倒转时间让动作反向播放。

它是如何工作的？想象一下，你通过来回刷帧来玩弄你的动画，随着鼠标左右移动让Rain跳一小段舞。结果本身就是一种动画。本质上，你是在为当前帧号制作动画，这几乎正是我们在本节即将做的事情。

## Strip Time属性

我知道你在想什么：我们难道不能已经控制时间了吗？只需随意拖动一些关键帧，直到所有东西以我们想要的速度移动。这不就是动画吗？

不再是这样了！以这种方式编辑关键帧是破坏性且粗糙的，而且我们现在正在`Nonlinear Animation editor`中！我们已经超越了编辑那些繁琐的小关键帧的需求。

相反，我们只需要为`Strip Time`属性制作动画：

![图14.16：Strip Time属性](image/B17149_14_16.jpg)

图14.16：Strip Time属性

`Strip Time`属性决定当前帧，不是针对场景本身，而只是针对动作条。换句话说，我们可能位于帧`50`，但我们具体想看`Rain Walkcycle`的哪一帧？现在由我们决定！

### 为Strip Time属性设置关键帧

让我们开始为`Rain Walkcycle`的`Strip Time`属性设置关键帧：

1. 在`Nonlinear Animation editor`中，选择Rain的走路循环动作条。
2. 在右侧边栏（`N`）中，启用`Strip` | `Active Strip` | `Animated` `Strip Time`。

   启用此属性最初会冻结动作条。无论场景本身位于哪一帧，动作都认为它是`Strip Time`指示的那一帧。必须有意地为该值制作动画，才能让事物再次移动。
3. 在帧`0`处，为`Strip Time`值设置关键帧。
4. 转到动画的最后一帧，将`Strip Time`值设为不同的帧号，并设置关键帧。

现在，为`Strip Time`值制作动画是让动作条时间前进的唯一方式，根据你如何为该值制作动画，走路循环的时间可能移动得非常慢或非常快。

在我们开始控制时间结构本身之前，通常最好先让时间正常流动，通过为`Strip Time`制作动画以匹配当前帧。这将帮助我们理解该功能的工作原理，并更容易选择确切的时间和方式来弯曲时间的流动。

### 从线性Strip Time开始

让我们看看`Strip Time`的`F-curve`。在我的情况下，我在帧`0`设置了值`0.0`，在帧`250`设置了值`250.0`，所以我知道`Strip Time`值将在这两个关键帧处匹配帧号：

![图14.17：Strip Time的初始动画](image/B17149_14_17.jpg)

图14.17：Strip Time的初始动画

但仍有插值的问题，它会产生加速和减速Rain步伐的有趣效果。

让我们尝试使其完全线性：

1. 前往`Graph Editor`，找到你刚刚设置关键帧的`Strip Time`动画通道。
2. 编辑`Strip Time`的关键帧，使其值等于帧号。
3. 将`F-curve`段设为`Linear`。

现在我们回到了最无聊的线，字面上就是`X = Y`：

![图14.18：线性函数](image/Image96542.jpg)

图14.18：线性函数

这个一对一函数使`Strip Time`匹配当前帧，动作条再次表现正常。

我发誓这么做是有原因的。现在，我们有一个合适的起点可以偏离，如这个例子中Rain直接走进慢动作区域：

![图14.19：线性时间变为子弹时间再变回](image/B17149_14_19.jpg)

图14.19：线性时间变为子弹时间再变回

仅用走路循环做这事不算最刺激，但你明白了——这就是事情真正变得非线性的部分。我们可以在一个镜头中让Rain减速、加速和倒放，而无需接触动作数据本身。我们可以让Rain处于慢动作中，而其他一切像延时摄影一样移动。如果我们也为Rain对口型动作的`Strip Time`值设置关键帧，我们可以让她在向前走时倒着说话，反之亦然。想象一下，当你添加更多自己的动作和角色时，你能做什么！

# 总结

想象你在读一本关于Blender的书，指导你在每个练习中只建模一个且仅一个物体。直到最后一章你才学到什么是物体，以及如何使用所谓的`Object Mode`将多个物体组合在一起。这就是教授`Nonlinear Animation editor`的感觉！

NLA有点晦涩难懂。截至写作时，真正理解如何使用它的人不多——基本上就我、阿姆斯特丹的十几个人、亚洲和澳大利亚的半打人，还有三个来自南美叫Pablo的不同家伙。我只开半玩笑。但现在你知道了NLA的作用和用法，你可以算作这个独家精英俱乐部的成员了！

我们开始这本书学习如何为立方体制作动画，最后我们学会了如何为动画制作动画。这算是开始和结束旅程的不错方式。我想说你终于成为动画师了，但你不记得了吗？当你完成本书的[*第1章*](#B17149_01.xhtml#_idTextAnchor015)时，你已经是动画师了。你当然仍是学生，但这很好——我也是学生，你知道吗。我将永远学习和制作动画，希望你也一样。谢谢阅读。
