Apache Spark is a powerful, distributed data processing system that can read from a wide variety
of data sources. Its ability to integrate with many diverse types of data storage systems is one of the
reasons for its popularity in big data processing and analytics. Here are some of the key data sources
from which Apache Spark can ingest data.

# Filesystems

Let's explore an example of data ingestion from Hadoop Distributed File System (HDFS). Here is a
sample code snippet to read data from HDFS:

```
from pyspark.sql import SparkSession
spark = SparkSession.builder \\
.appName("HDFS Read Example") \\
.getOrCreate()
# Define the HDFS path
hdfs_path = "hdfs://namenode:port/path/to/your/file.csv"
# Read the CSV file into a DataFrame
df = spark.read.csv(hdfs_path, header=True, inferSchema=True)
# Show the DataFrame
df.show()
```
