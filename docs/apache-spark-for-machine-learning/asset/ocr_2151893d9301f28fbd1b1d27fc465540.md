Method chaining in PySpark allows you to perform multiple operations on a DataFrame concisely and sequentially. Instead of assigning intermediate DataFrames to variables, you can chain methods together directly.

The following code calculates the total sales achieved by every employee. First, it groups the records in the emp_id column for each unique value of emp_id. For each group, (that is, for every employee ID), it calculates the sum. Then, the output is sorted by employee ID.

```
df.groupby("emp_id").agg({"sales": "sum"}).orderBy("emp_id").show()
```

Here is the output:

| emp_id | sum(sales) |
|--------|------------|
| 1      | 500        |
| 2      | 900        |
| 3      | 900        |

The following code calculates the maximum sales achieved by every employee. It first groups the records in the emp_id column for each unique value of emp_id. For each group (that is, for every employee ID), it calculates the maximum value. Then, the output is sorted by employee ID.

```
df.groupby("emp_id").agg({"sales": "max"}).orderBy("emp_id").show()
```

Here is the output:

| emp_id | max(sales) |
|--------|------------|
| 1      | 200        |
| 2      | 500        |
| 3      | 400        |

The following code outputs the most recent sales achieved by every employee. It first groups the records in the emp_id column for each unique value of emp_id. For each group (that is, for every employee ID), it reads the last sales in every group. Then, the output is sorted by employee ID.

```
df.groupby("emp_id").agg({"sales": "last"}).orderBy("emp_id").show()
```
