# Trimming strings

To remove leading and trailing spaces from string columns, use trim():

```
from pyspark.sql.functions import trim
df = df.withColumn("new_column_name", trim(df["name"]))
```

Here's the result:

| name | age |
|---|---|
| "tony" | 15 |
| "tony" | 25 |
| " mike" | 30 |

| name | age | Name_new |
|---|---|---|
| "tony" | 15 | "tony" |
| "tony" | 25 | "tony" |
| " mike" | 30 | " mike" |

# Sorting data

Sort data using orderBy ():

```
df = df.orderBy(df["age"].desc())
```

Here is the output:

| name | age |
|---|---|
| tony | 25 |
| tony | 15 |
| mike | 30 |

| name | age |
|---|---|
| tony | 15 |
| tony | 25 |
