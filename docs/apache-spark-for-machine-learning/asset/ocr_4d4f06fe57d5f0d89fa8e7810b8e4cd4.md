# UnivariateFeatureSelector

The UnivariateFeatureSelector is a feature selector in PySpark that selects the most important features based on univariate statistical tests. It evaluates each feature independently and ranks them according to their relevance to the target variable. The UnivariateFeatureSelector is useful for feature selection in classification or regression tasks.
