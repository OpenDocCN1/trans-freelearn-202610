Use fillna() to replace null values with a specified value:

```
df = spark.createDataFrame([('tony', None), ('tony', 25),
 ('mike', 40)], ["name", "age"])
df.na.fill({'age': 55}).show()
```

# Filtering data

You can filter out rows based on a condition, using the filter() or where() method:

```
df = df.filter(df['age'] > 20)
```
