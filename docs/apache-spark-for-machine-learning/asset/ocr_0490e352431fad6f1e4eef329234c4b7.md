# Bucketizer

Bucketizer is a feature transformer in PySpark that discretizes continuous features into buckets (bins). It assigns each value to a specific bucket based on specified splits (boundaries). Bucketizing continuous features can improve model performance by capturing non-linear relationships.

The following code snippet creates a sample Spark DataFrame with two columns:

```
from pyspark.sql import SparkSession
from pyspark.ml.feature import Bucketizer
from pyspark.sql.functions import col
data = [(0, 1.5), (1, 2.5), (2, 3.5), (3, 4.5), (4, 5.5)]
columns = ["id", "value"]
df = spark.createDataFrame(data, columns)
df.show()
```
