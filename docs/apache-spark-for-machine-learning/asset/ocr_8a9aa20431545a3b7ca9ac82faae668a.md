Here's the explanation of how each row's value is calculated from the previous rows:

+   The first row value of the sum column = the current row value of salary + the two following row values:
+   
+   18,000 = 7,000 + 6,000 + 5,000

+   Similarly, the second row value of the sum column = the current row value of salary + the two following row values:
+   
+   17,000 = 6,000 + 5,000 + 6,000

+   Similarly, the last row value of the sum column = the current row value of salary + the two following row values:
+   
+   8,000 = 8,000 + 0 (note that no following row exists, hence 0)

In Figure 2.11, the dataset in the left-hand section is untransformed. We first define the window function. This function partitions the dataset by applying partitionBy to the column. This action groups the records based on unique values in the dept_id column. It then sorts the emp_id column for each grouped record. Then, the function defines the start and end point of the windows through rowsBetween.

```
window = Window.partitionBy("dept_id") \\
.orderBy("emp_id").rowsBetween(0, 2)
```
