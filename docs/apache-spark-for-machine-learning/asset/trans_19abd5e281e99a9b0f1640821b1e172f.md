

## 设置 Apache Spark

在本地开发环境中设置 Apache Spark，涉及在你的机器上安装 Spark，并将其配置为独立模式运行。以下是设置 Apache Spark 以进行本地开发的一般步骤：

> **注意**
> 以下说明假设你的机器上已安装 Java，而 Apache Spark 需要 Java。

- 1. **下载 Apache Spark:**
  - I. 访问官方 Apache Spark 网站：https://spark.apache.org/。
  - II. 转到 **下载** 部分。
  - III. 选择要下载的 Spark 版本。
  - IV. 选择包类型。对于本地开发，你可以选择 **预构建的 Apache Hadoop** 选项。
  - V. 下载包含 Spark 的 tarball (.tgz) 或 ZIP 文件。

- 2. **提取 Spark 存档:**
  - I. 导航到下载 Spark 存档的目录。
  - II. 提取存档的内容，使用像 `tar` 这样的工具，或者如果你下载了 ZIP 文件，可以使用图形工具：

  ```
  tar -xvf spark-3.x.x-bin-hadoop3.x.tgz
  ```

- 3. **配置环境变量:**
  - I. 打开你的 shell 配置文件。例如，如果你使用 Bash，请使用以下命令编辑你的 `bashrc` 文件：

  ```
  ~/.bashrc
  ```

  或者，使用此方法：

  ```
  ~/.bash_profile
  nano ~/.bashrc
  ```

  - II. 添加以下行以设置环境变量：

  ```
  export SPARK_HOME=/path/to/extracted/spark-3.x.x-bin-hadoop3.x
  export PATH=$PATH:$SPARK_HOME/bin
  ```

  - III. 将 /path/to/extracted/spark-3.x.x-bin-hadoop3.x 替换为提取 Spark 的实际路径。
  - IV. 保存文件并退出文本编辑器。
  - V. 运行以下命令以应用更改：

  ```
  source ~/.bashrc
  ```

- 4. 以独立模式启动 Spark:
  - I. 导航到 Spark 目录：

  ```
  cd $SPARK_HOME
  ```

  - II. 启动 Spark master：

  ```
  ./sbin/start-master.sh
  ```

  - III. 启动 Spark worker：

  ```
  ./sbin/start-worker.sh spark://localhost:7077
  ```

- 5. 访问 Spark Web UI:
  - I. 打开 Web 浏览器并访问 http://localhost:8080/ 以查看 Spark Web UI。master 和 worker 应该会被列出。

- 6. 测试 Spark 安装:
  - I. 打开一个新终端窗口。
  - II. 导航到 Spark 目录：

  ```
  cd $SPARK_HOME
  ```

  - III. 运行一个简单示例来测试安装：

  ```
  ./bin/run-example SparkPi
  ```

  此命令使用 Spark 计算 Pi 的近似值。

- 7. 停止 Spark:
  - I. 停止 Spark worker 和 master：

  ```
  ./sbin/stop-worker.sh
  ./sbin/stop-master.sh
  ```

除了使用上述方法设置 Spark 之外，以下是运行 PySpark 的其他方式：

- 使用 PyPI:

```
pip install pyspark
pyspark
```

- 使用预构建的 docker 镜像:

```
docker run -it --rm spark:python3 /opt/spark/bin/pyspark
```

> 注意
> 本书中的代码示例使用 Apache Spark 版本 3.5.1。

这完成了设置 Spark 的步骤。

### 了解数据预处理

**数据预处理** 是数据挖掘过程中的一个基本步骤。它涉及对原始数据进行一系列操作，将其转换为适合进一步分析和建模的格式，特别是在机器学习和 AI 应用中。数据预处理的关键目标是基于历史数据提升天气预测的质量、可靠性和效率。

数据处理的主要步骤包括以下内容：

- 1. **数据收集**: 第一步涉及从各种来源提取原始数据。数据可以有多种格式，可以包括数字、文本和图像。

- 2. **数据准备**: 此步骤涉及为处理准备数据。它可能包括对数据进行排序，并将其组织成表格、数据库或文件。

- 3. **数据清理**: 数据清理涉及通过数据插值填充缺失值，其中缺失值被替换为诸如均值、中位数和最大值等替代值。它还可能涉及移除异常值并纠正数据中错误、不完整、无关或重复的部分。此步骤对于保持数据质量至关重要。

- 4. **数据转换**: 这涉及将数据转换或转换为适合分析的格式。它还可以涉及归一化或缩放数据、聚合数据点或转换数据类型。

- 5. **数据集成**: 如果数据从多个来源收集，可能需要将其合并或集成到一个连贯的数据集中。这可能涉及合并数据库、表格或文件，并对齐不同的数据格式。

- 6. **数据编码**: 这包括将分类数据转换为数值格式，以便机器学习算法可以使用。常见技术包括标签编码和独热编码。

- 7. **特征选择和特征工程**: 这涉及识别分析或模型中最相关的特征，并从现有数据中创建新特征，以提高模型性能。

数据预处理可以通过减少数据的复杂性和大小、选择最相关的特征以及处理错误和不一致性来提高机器学习模型的性能和可扩展性。数据预处理可以区分成功的机器学习项目和失败的机器学习项目。因此，在将数据馈送给机器学习模型之前，应用适当的数据预处理技术和工具非常重要。

由于缺乏数据预处理而导致的失败机器学习项目的一个例子是 **IBM Watson for Oncology** 项目。数据未被正确清理和验证，因为它包含错误、不一致和过时信息。数据也没有被集成和标准化，因为它来自不同的来源和格式，例如医疗记录、临床试验和研究论文。

现在，让我们看看如何摄取数据进行预处理。

## 数据摄入

数据摄入是将数据导入和加载到系统（例如数据库、数据仓库或数据湖）的过程。数据摄入可以手动或自动完成，使用各种工具和技术。数据摄入是数据分析和机器学习的第一步，因为它为进一步处理和使用做好数据准备。
