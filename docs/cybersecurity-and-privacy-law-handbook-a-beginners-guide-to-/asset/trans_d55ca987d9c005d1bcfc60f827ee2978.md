
在一个正常的企业中，许多任务都是在没有正式流程的情况下执行的。存在不成文的规范和非正式流程。然而，有时这些不成文的原则必须通过流程加以规范化。以下是可能需要发生这种情况的一些示例：

- 不断被提出类似的问题
- 人们似乎感到困惑
- 该技术的可能解释太多

## 如何编写规程

不仅读者希望知道的内容，也应传达他们必须知道的内容。读者可能需要知道如何更准确、更快或更少浪费地完成任务。他们可能还想知道为什么必须以特定方式执行任务、在哪里可以获得帮助，以及如果出现问题会发生什么。在需要时，确保您的流程同时解决技术和主观因素。

流程拥有适当的信息量也很重要。这里有一些需要考虑的问题：

- 用户是否有足够的信息采取行动？
- 它是否包含足够的信息来帮助用户做出合理的专业判断？
- 信息程度是否适合主题？
- 细节程度是否适合受众？
- 读者对该主题有多熟悉？

## 第一步：收集信息

在开始写作之前，您应该收集有关您正在创建的技术的大量信息。

与主题专家以及掌握关键知识的人员交谈，包括长期员工、利益相关者、技术人员和流程使用者。

做好大量笔记，然后在方便时整理材料。作为流程作者，您应该全面了解正在发生的事情。从那里，将信息精简为最终用户完全理解该规程所需的内容（思维导图是整理信息的绝佳工具。这可以帮助您确保已包含并链接了所有必要组件）。

## 第二步：开始写作

在撰写方法初稿时，您不必担心术语和结构的完美性。主要目标是提供必要的信息。之后，您可以专注于措辞和安排。

这里有一些有用的指导原则：

- 按发生的顺序记录活动
- 从第一个动作开始，以最后一个动作结束
- 避免冗长的措辞
- 只要明确到足以确保清晰沟通即可
- 使用项目符号和列表
- 如果过于简略，您可能会失去清晰度
- 解释您的假设并确保其准确
- 谨慎使用行话和俚语

## 第三步：评估设计元素

您可能会发现，仅靠文字不足以描述该技术。有时，额外的功能可能会增强演示效果。以下是一些常见的格式。

### 流程图

这是流程的示意图。您可以使用一系列符号和箭头来显示活动流程，从而概述和简化流程。确保您的图表不包含太多奇怪的符号或过多的文本。如有必要，将其分成多个较小的流程图。

### 剧本

这看起来像是包含许多角色的剧院剧本。然而，在这种情况下，您列出具有不同职责的员工。当多人参与流程时，剧本可能特别有益：

| 负责人 | 动作 |
|---|---|
| | 收集信息 |
| 作者责任 | 编写流程 |
| | 与利益相关者分享草案 |
| | |
| | 审阅草案 |
| 利益相关者责任 | 提交评论和更正 |
| | |
| 作者责任 | 创建最终草案 |
| | |
| 经理（业务部门） | 批准最终版本 |

部门主管必须批准最终版本。

### 问答

将常见的流程问题与适当的回答匹配。这种风格在方法不明确或存在多种变体时是有益的。它也有助于解决“what if”问题。

*示例：*

Q：列不平衡时会发生什么？

A. 首先，不要惊慌。从最基本的解释开始并向后推算。重新计算每一列。然后，查找转录错误。如果这不能解决问题，请检查您是如何获得数据的。如果您对任何一点不确定，请再次核实这些数字。然后，系统地审查每个数字，直到发现问题。

### 矩阵

## 社会工程学、密码指导和政策

在上一章中，我们深入了解了政策和程序，现在我们将了解最强大的攻击向量：社会工程学。为什么它是最强大的？主要是因为它攻击了安全链中最薄弱的环节：人类。虽然机器（软件）旨在执行命令和指令，但我们使用我们的智力、情感等与他人互动。但正是与其他人类的互动使我们的行为变得不同且安全性降低。

在本章中，我们将涵盖以下主题：

- 起点
- 常见的社会工程攻击方法
- 你有 M.A.P.P. 吗？

### 起点

由于互联网促进了信息的获取，它已成为现代商业和个人生活不可或缺的一部分。企业和个人出于各种原因使用互联网，包括浏览内容、社交网络、交流、购买、下载……

目前全球约有 48.1 亿互联网用户。如今，人们在互联网上寻找某个答案并获得满意结果已是常见做法。除了查找不同互联网服务的便利性外，社交网络网站如今已成为最重要且增长最快的公众兴趣领域之一。个人利用社交网络网站与朋友和家人保持频繁联系相当普遍。

入侵者出于各种动机破坏系统。因此，了解敌对黑客为何以及如何针对和利用系统至关重要。根据孙子《兵法》，如果知己不知彼，每一次胜利你也会遭受一次损失。系统管理员和安全专家有责任通过了解其对手来保护其基础设施免受利用：那些想利用基础设施进行非法操作的恶意黑客。

社会工程学是通过人际接触实施的恶意操作的广泛类别。它采用心理操纵手段欺骗用户犯下安全错误或泄露敏感数据。

社会工程学是指操纵、说服或误导个人以获取其计算机系统访问权限的做法。黑客可能通过电话、电子邮件、邮寄或直接接触获得未经授权的访问。示例包括网络钓鱼、精准钓鱼和 CEO 欺诈。

社会工程攻击包含几个阶段。犯罪者最初分析目标受害者，以获取继续攻击所需的背景信息，例如可能的入口点和薄弱的安全程序。攻击者接下来试图获得受害者的信任，并为后来违反安全规范的行为提供刺激，例如披露敏感信息或提供对重要资源的访问。

### OSINT

开源情报 (OSINT) 是社会工程学的生命线。信息是每一次互动的基础和支撑。由于 OSINT 对我们社会工程师如此关键，了解收集目标信息的多种方法至关重要。

无论您如何收集 OSINT，您都必须清楚您正在寻找什么。这听起来并不那么简单。您不能只是请求有关目标的所有信息。每种类型的信息都有独特价值，这可能取决于您想要执行的攻击类型。
