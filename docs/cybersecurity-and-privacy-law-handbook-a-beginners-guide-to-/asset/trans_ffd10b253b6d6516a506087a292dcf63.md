
- **网络:** 此次测试可以发现外部网络及其相关系统中的常见或重大安全漏洞。专家使用一份清单，其中包含加密传输协议的测试用例、SSL 证书范围困难以及管理服务的使用等项目。
- **云:** 云环境与传统的本地部署有很大不同。通常，使用该环境的企业和云服务提供商共同承担安全义务。因此，云 PT 需要一套特定的技能和知识来检查云的配置、API、数据库、加密、存储和安全控制等组件。
- **容器:** Docker 容器通常包含可能被大规模利用的漏洞。与容器及其环境相关的常见风险也是配置错误。这两种威胁都可能被一名合格的渗透测试人员发现。
- **嵌入式设备/物联网 (IoT):** 由于其生命周期长、位置偏远、功耗限制、监管要求和其他因素，嵌入式或物联网设备（如医疗设备、汽车、家用电器、油井设备和手表）具有特定的软件测试需求。专家进行全面的通信分析以及客户端-服务器研究，以发现与用例相关的故障。
- **移动设备:** 渗透测试人员使用自动和人工分析相结合的方法来识别移动应用程序二进制文件及其相关服务器端功能中的漏洞。身份验证和授权问题、客户端信任问题、配置错误的安全控制以及跨平台开发框架困难是应用程序二进制漏洞的示例。典型的服务器端 Web 服务漏洞包括会话管理、加密困难、身份验证和授权问题等。
- **APIs:** 使用自动化和手动测试方法，均涵盖了 OWASP API 安全十大风险。测试人员搜索的安全威胁和漏洞包括对象级权限破坏、用户身份验证、数据过度暴露、资源缺乏、速率限制等。
- **CI/CD 流水线:** 现代 DevSecOps 流程将智能和自动化的代码扫描技术纳入 CI/CD 流水线。除了识别已知漏洞的静态工具外，自动化的 PT 工具也可以纳入 CI/CD 流水线，以模拟黑客可能如何破坏应用程序的安全性。自动化的 CI/CD PT 可能发现静态代码扫描无法发现的漏洞和攻击模式。

## PT 的优势和劣势是什么？

随着安全漏洞的频率和严重程度不断上升，企业从未像现在这样更需要了解其抵御攻击的能力。为了遵守 PCI DSS 和 HIPAA 等法规，需要频繁进行 PT。考虑到这些因素，以下是这种缺陷查找方法的优势和劣势。

## PT 的优势

- 识别上游安全保证程序中的漏洞，例如自动化工具、配置和编码标准、架构分析以及其他轻量级 VA 操作
- 识别已知和未发现的软件故障和安全漏洞，包括单独来看不会引起警报但作为更大攻击方案的一部分可能造成严重损害的微小问题
- 可以通过模仿大多数危险黑客的行为来攻击任何系统，尽可能地模拟真正的对手

## PT 的劣势

- 费力且昂贵
- 不能彻底防止错误和缺陷进入生产环境
