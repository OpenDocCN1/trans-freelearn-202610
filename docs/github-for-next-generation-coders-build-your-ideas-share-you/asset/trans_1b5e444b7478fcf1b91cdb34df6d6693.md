
我们了解到引入 `CODEOWNERS` 文件可以让你指定谁来审查项目某些部分的更改，从而进一步保护你的工作。我们还介绍了安全编码实践的重要性，包括使用 `.gitignore` 来保护敏感信息以及设置分支保护规则。

在下一章中，我们将探讨在项目中设置 **持续集成** 和 **持续部署** (**CI**/**CD**) 工作流，这是从保护代码库到为效率和可靠性自动化和优化开发流程的自然进展。
