### 打造你的 GitHub 个人资料

本章中，我们将学习如何打造有影响力的 GitHub 个人资料，以展示你的项目和贡献，从而突出你作为程序员的技能、奉献精神和多才多艺。通过优化你的个人资料，你可以给访客留下深刻的第一印象，包括潜在的合作者、雇主和同行开发者。本章旨在提供实用指导，帮助你让 GitHub 个人资料不仅反映你的编码之旅，也成为职业机会的平台。
本章中，我们将涵盖以下主要主题：
* 优化你的 GitHub 个人资料概览
* 展示技能和专业知识
* 在个人资料中添加统计数据和成就
* 战略性地展示项目和贡献

#### 技术要求

对于某些活动，我们将使用外部工具和服务，例如 [https://shields.io/](https://shields.io/) 和 [https://github-readme-streak-stats.herokuapp.com](https://github-readme-streak-stats.herokuapp.com)。请确保你熟悉 `Markdown`，因为它是自定义 README 个人资料的必备条件。
此外，从 [https://github.com/PacktPublishing/GitHub-for-Next-Generation-Coders/tree/main/Chapter%2012](https://github.com/PacktPublishing/GitHub-for-Next-Generation-Coders/tree/main/Chapter%2012) 下载名为 `Chapter 12` 的 GitHub 文件夹，其中包含可供你跟随使用的 `README` 模板。

#### 优化你的 GitHub 个人资料概览

你的 GitHub 个人资料就像你的在线编码传记——一个展示你的技能、项目和对编码世界的贡献的地方。正如你希望在现实生活中给人留下良好的第一印象一样，拥有经过优化和个性化的 GitHub 个人资料会产生很大的不同。在本节中，我们将学习一些很酷的技巧，让你的个人资料看起来很棒！
让我们开始：
* **添加个人资料图片和简介**：首先使用一个清晰的自己照片，背景为漂亮的单色。它让你的个人资料更具个人特色。写一个简短但能透露很多关于你信息的简介。你是网页开发者、Python 开发者还是游戏设计爱好者？在这里提及！
    *示例*：**你好！我是 Igor Iric，我对编码如何将想法变为现实着迷。我喜欢学习新的编程语言并与其他程序员合作。现在，我正在构建一个有趣的 ****新游戏！**
