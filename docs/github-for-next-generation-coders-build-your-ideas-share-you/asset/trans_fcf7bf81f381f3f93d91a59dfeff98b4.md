
## 图 12.19 – 社交网络

以下代码片段旨在为你的 README 增加一个专门的部分，用于个人或项目网站以及社交媒体链接。此增添不仅提升了个人资料的视觉吸引力，还使访客更容易在各个平台上与你联系：

```
<!-- Website -->
## Website
Link : [[your name]](https://[your-username].github.io/[your-username]/)
<!-- Social Media Links -->
## 🖇️ Let's connect!
<p align="center">
  <a href="https://dev.to/[your-username]" target="blank"><img align="center" src="https://dev-to-uploads.s3.amazonaws.com/uploads/logos/resized_logo_UQww2soKuUsjaOGNB38o.png" alt="[your-username]" height="30" width="40" /></a>
<a href="https://twitter.com/[your-username]" target="blank"><img align="center" src="https://www.freepnglogos.com/uploads/twitter-x-logo-png/twitter-x-logo-png-9.png" alt="[your-username]" height="30" width="40" /></a>
<a href="https://linkedin.com/in/[your-username]" target="blank"><img align="center" src="https://www.freepnglogos.com/uploads/linkedin-logo-design-30.png" alt="[your-username]" height="30" width="40" /></a>
<a href="https://www.youtube.com/c/[your-username]" target="blank"><img align="center" src="https://www.freepnglogos.com/uploads/youtube-circle-icon-png-logo-14.png" alt="[your-username]" height="30" width="40" /></a>
</p>
```

在前面的代码片段中，我们有以下内容：
* **网站** 部分允许你插入指向个人或项目网站的直接链接，邀请访客探索更多你的作品。
* **让我们连接！** 部分被设计为社交媒体链接的集中枢纽。每个图标都是一个可点击的链接，可将访客引导至你在 dev.to、X（前称 Twitter）、LinkedIn 和 YouTube 等平台上的个人资料。

请将 `\[your-username\]` 替换为你在这些平台上的实际用户名，并将 `\[your name\]` 替换为你希望为网站链接显示的名称。这种个性化的方法不仅展示了你的项目和技能，还为专业网络和个人联系开辟了渠道。

## 使用 GitHub Pages 展示你的作品

正如你在 [*第9章*](#B21847_09.xhtml#_idTextAnchor239) 中学到的，GitHub Pages 允许你免费将仓库转变为实时网站。这是一个展示个人资料页作为网站的绝佳方式。就像拥有自己的数字作品集，可以与朋友、家人甚至潜在雇主分享。

通过遵循这些提示，你可以让你的 GitHub 个人资料成为编程之旅的精彩展示。井然有序的 GitHub README 个人资料不仅能给人留下良好的第一印象，还能引导访客（如潜在协作者或雇主）查看你的最佳作品并了解你作为开发者的历程。

通过这些步骤，你学会了如何将 GitHub 个人资料转变为动态作品集，不仅展示你的项目，还能让你与更广泛的社区和潜在机会建立联系。通过突出你引以为傲的成就、分享你的贡献，并链接到你的社交网络和个人网站，你创建了专业自我的全面快照。
