+   4. Since you declared `(?i)` for case insensitivity, the string is matched and the expression is returned as true.
+   5. You then declare "TheUsernames are not written." and use the `-match` comparison operator with the `$searchRegex` regular expression.
+   6. The result of this returns the value of True.
+   7. This is due to the regular expression matching the string "username" in the string "TheUsernames".
+   8. Since you declared that username can appear with any characters before or after the string, the expression is returned as True.
+   9. Finally, you call the `$searchRegex` expression with the `.toString()` method.
+   10. This displays the text of the regular expression as it was dynamically built.
+   11. The regular expression of `(?i)^.*(administrator|password|username).*$` is then displayed on the screen.
