The final step of the script requires that you have a local folder shared with the named csvFiles. The script will copy the log file and CSV file to \\localhost\ csvFiles after execution. To tag the end of the script, and copy the log files and the CSV file to a UNC path, you can perform the following:

```
$date = (Get-Date -format "yyyyMMddmmss")
log "Windows Server Scanning Script completed execution at $date" "Y" "Y"
log "Scriptend,$date"
copy-item -Path $scnresults -Destination $csvunc.id -Force
copy-Item -Path $scanlog -Destination $csvunc.id -Force
```

In this example, you tag the end of the script, and copy the log files and the CSV file to a UNC path:

+   1. You first start by obtaining the date with the Get-Date cmdlet and the -format parameter set to the "yyyyMMddmmss" attribute.
+   2. You leverage the log function with the "Windows Server Scanning Script completed execution at $date" "Y" "Y" value.
+   3. If enabled, this adds the string to both the log file and the event log.
+   4. You continue to leverage the log function with the "Scriptend,$date".
+   5. This writes, in the CSV file, the completion of the script with a timestamp.
+   6. Finally, you leverage the copy-item cmdlet to copy the $scnresults file to the $csvunc.id path with the -Force parameter.
+   7. You also leverage the copy-item cmdlet to copy the $scanlog file to the $csvunc.id path with the -Force parameter.
