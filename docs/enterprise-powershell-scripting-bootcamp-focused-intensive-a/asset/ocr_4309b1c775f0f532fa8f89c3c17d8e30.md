# Converting disk space to MB and GB

When working with the Size and FreeSpace properties of the logical disks, the values are represented in bytes. PowerShell offers a quick method to convert bytes into multiple formats. You can take the Size or FreeSpace properties and divide them by 1MB for megabytes, 1GB for gigabytes, 1TB for terabytes, and 1PB for petabytes. After the conversion, however, you often need to round the numbers, leveraging the [System.Math]::Round() method. By default, this .NET Round() method rounds to the closest full number. To include decimal places, you can provide an additional numerical argument, such as [System.Math]::Round($value,2), to round the $value to two decimal places.

To convert the disk Size property to megabytes and gigabytes, you can perform the following actions:

```
$disks = get-wmiobject win32_logicaldisk
Foreach ($disk in $disks) {
    $driveletter = $disk.DeviceID
    $sizeMB = [System.Math]::Round(($disk.size / 1MB),2)
    $sizeGB = [System.Math]::Round(($disk.size / 1GB),2)
    Write-host "$driveletter | Size (in MB): $sizeMB | Size (in GB): $sizeGB"
}
```
