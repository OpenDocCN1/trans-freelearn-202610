## 1 使用企业 PowerShell 脚本入门

PowerShell 语言是为了让工程师能够快速自动化环境的配置和管理而开发的。在过去十年中，PowerShell 的使用大幅扩展，涵盖了各种硬件和软件系统的设置和配置。由于第三方制造商正在创建 PowerShell 模块来控制其系统，PowerShell 正在成为首选的自动化语言。它使用单一的 PowerShell 代码集来配置来自多个制造商的多个系统。

为企业环境创建脚本需要一个强大的脚本框架。脚本框架由可重用的代码组成，您可以在大部分脚本中利用这些代码。该框架需要高效、可靠且安全。它还必须提供日志记录功能，利用应答文件，并能够在各种各样的系统上灵活执行。

在阅读本书的过程中，您将学习大量经过测试且业界验证的脚本技术。您创建的示例将在本书结尾应用于 Windows 服务器扫描脚本。这将使您能够快速将新的代码段集成到自己的脚本中，并提供一个值得信赖的平台，您可以自信地在环境中部署。

在本章中，您将：

- 了解贯穿本书创建的 Windows 服务器扫描脚本
- 探索在各章中实施的性能优化
- 回顾应包含在所有 PowerShell 脚本中的不同组件

### 性能注意事项

本书深入探讨了脚本的重要性能注意事项。由于 PowerShell 是一种极其灵活的语言，您可以用多种方式完成相同的活动。虽然两组代码都能使脚本产生相同的结果，但有方法可以优化代码使其更高效。随着您评估的数据量增大，这变得越来越重要。

例如，文件扫描的执行时间随文件数量和文件大小呈指数增长。100 个文件包含 100 行代码即可快速产生 10,000 次评估。现在，如果将其扩展到存储卷中的 600 万个文件乘以 100 行代码，您将执行 6 亿次评估。小代码性能改进可以显著优化大规模脚本的扫描。

一些性能注意事项包括：

- **测量命令：** 您将评估一种衡量命令执行时间的技术。
- **Cmdlet 注意事项：** 您将学习哪些 cmdlet 更高效以及如何避免常见的 cmdlet 错误。
- **正则表达式优于数组：** 正则表达式可能难以学习，但它们可为脚本提供显著的性能改进。您将学习如何在脚本中正确实现动态正则表达式。
- **Switch 语句：** 您将评估如何使用 switch 进行数据排序以及 switch 语句为何显著更快。
