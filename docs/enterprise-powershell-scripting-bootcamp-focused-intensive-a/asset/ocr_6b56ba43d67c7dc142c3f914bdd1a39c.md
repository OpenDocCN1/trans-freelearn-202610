The very last command used in the script specifies an invalid XML answer file of "C:\temp\POSHScript\DOES_NOT_EXIST.xml". Since this is an invalid file, the script throws an error message of read-xmltag: C:\Temp\POSHScripts\DOES_NOT_EXIST.xml not found on system. Select any key to exit! When you press any key on the keyboard, the script exits.
