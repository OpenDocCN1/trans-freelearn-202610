## 企业 PowerShell 脚本训练营

*企业 PowerShell 脚本训练营* 解释了如何创建自己的可重复 PowerShell 脚本框架。该框架包含脚本日志记录方法、答案文件交互以及字符串加密和解密策略。

本书重点关注评估各个组件以识别系统的功能、角色和独特特征。为此，你将利用内置的 CMDlet 和 Windows 管理规范 (WMI) 来探索 Windows 服务、Windows 进程、Windows 功能、计划任务和磁盘统计。你还将创建自定义函数来对文件中的特定字符串进行深度搜索，并通过可执行文件属性评估已安装软件。

然后我们将讨论不同的脚本技术以提高脚本的效率。通过利用代码中的一些小改动，你可以将执行性能提高超过 130%。

到本书结束时，你将能够将所有概念整合到基于 PowerShell 的 Windows 服务器扫描脚本中。此发现脚本将能够扫描 Windows 服务器以识别众多组件。

## 你将学到：
- 创建一个高级 PowerShell 脚本模板，提供可重复的代码来启动你的所有脚本项目
- 学习如何在 PowerShell 脚本和答案文件中安全地加密和存储用户名、密码和其他敏感数据
- 了解如何优化脚本性能以帮助快速处理大型数据集并避免耗时错误
- 开发脚本以扫描非标准的 Windows Server 配置并识别 Windows Server 上使用的服务帐户
- 在不通过本地交互式登录的情况下，从 Windows 服务器收集大量数据
