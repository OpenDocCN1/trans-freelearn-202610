You will see that, in this example, switches for data sorting are about 128 times as fast than using `if` statements.

You will notice that the order of evaluation in the `switch` statement is set as `.dll` first, `.exe` second, and `.xml` last. These are evaluated based on commonality on the system. Since switches stop evaluation after a match is found, the script is written to have the most popular items evaluated first, optimizing the switches' function.
