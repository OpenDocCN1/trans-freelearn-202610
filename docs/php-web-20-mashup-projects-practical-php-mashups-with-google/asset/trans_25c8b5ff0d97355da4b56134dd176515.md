## Summary

本章我们涵盖了大量技术。我们学习了如何读取 RDF 文档，以及如何使用 SPARQL 和 RAP for RDF 从中提取数据。这些标准相当新。然而，鉴于尽可能多地将内容放入 RSS 的愿望，这些技术肯定会迅速发展。

当我们创建前端应用程序时，还有更多新技术，包括使用 AJAX 从服务器向设备通信。这个 AJAX 应用程序最大的陷阱是竞态条件。我们研究了如何通过各种技术克服这些问题。
