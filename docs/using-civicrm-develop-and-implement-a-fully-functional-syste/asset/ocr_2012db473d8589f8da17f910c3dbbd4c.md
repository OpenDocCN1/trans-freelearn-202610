If you have your own server or high-resource VPS, you may want to increase the PHP timeout and memory limit significantly. If the site is not live or you are not experiencing much site traffic, you could consider setting the timeout value to zero, which will prevent it from timing out altogether. +   - The best format for importing data is UTF-8. If your data has special characters, this format is required. By default, CiviCRM will have the Windows-1252 format configured for this setting (used by MS Excel). Wherever possible, use UTF-8 as it provides the greatest data integrity.
