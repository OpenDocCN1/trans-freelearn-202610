# 前言

CiviCRM 是一个基于 Web 的开源支持者关系管理（CRM）系统，专门设计用于满足倡导组织、非营利组织和非政府组织的需求。民选官员、专业/行业协会、政治竞选活动和政党、政府机构以及其他类似组织都在其不断增长的热心用户之列。本书将向你展示如何在制定和执行对绩效至关重要的 CRM 战略时，充分利用 CiviCRM 令人惊叹的各种可能性。

在本书中，我们将通过详细的解释和实际示例，指导你为组织制定并成功实施 CRM 战略，同时回顾 CiviCRM 的结构和主要功能。

此外，我们将讨论受 CiviCRM 影响的组织流程/工作流，在您审查和分析与 CRM 实施相关的内部运营时提供指导。我们将介绍支持者关系管理的最佳实践，并指导如何利用 CiviCRM 有效实施这些实践。使用 CiviCRM 的好处将惠及整个组织，帮助您更好地实现使命。

通过使用 CiviCRM，您的组织将能够更有效地与支持者互动，并通过在组织内共享的统一系统中跟踪联系人及其互动，更顺利地处理人员变动。组织领导层将利用从支持者处收集的数据来分析并为决策过程提供信息。

如果您的组织通过捐赠、捐款、活动费用和会员费来筹集资金，您将能够通过识别合格潜在捐赠者来开展有针对性的筹款活动，从而筹集更多资金并降低成本。我们将演示如何使用 CiviCRM 通过在线、直邮、电话营销和直接联系渠道吸引新的潜在捐赠者并将其转化为捐赠者。您将了解为什么以及如何建立和发展月度捐赠计划，并提高捐赠者基础的捐赠频率、平均捐赠金额和留存率。
