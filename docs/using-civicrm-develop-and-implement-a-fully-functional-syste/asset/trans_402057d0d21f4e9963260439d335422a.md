

## 关于评审者

自1989年以来，**艾伦·迪克森（Alan Dixon）** 一直帮助非营利组织管理其联系人数据库。他是一名独立网站开发者，现居加拿大多伦多，自2006年起使用CiviCRM构建网站。他维护着网站 http://community.civicrm.ca。

**大卫·盖尔胡费（David Geilhufe）** 在硅谷出生长大，专注于技术与社会变革的交汇点。他曾创办非营利组织和营利组织，打造企业公民组织和私人基金会的运营体系，开发风险投资支持的企业软件系统，汇聚开源社区，并指导高风险青少年进入高科技行业。他一直在寻求创造并实施一个能为世界带来些许益处的宏大构想。

大卫目前运营着 http://netsuite.org/，这是NetSuite的企业公民计划，致力于为全球慈善机构和社会企业提供超低成本的后台办公解决方案。

**穆罕默德·M·哈加格（Mohamed M. Hagag）** 是一名Unix/Linux系统工程师，对自由开源软件充满热情。他喜欢自由开源软件（FOSS）的研究与开发，自2004年起独立或与团队合作进行FOSS研发。他现任和前任雇主均为中小规模公司，主营IT市场业务，并具备一定水平的UNIX/Linux专长。虽然没有正式参与任何书籍的编写，但他曾将一些技术书籍翻译成阿拉伯语。

我想首先感谢上帝赐予我生命中一切美好，然后感谢我的父母、姐妹和妻子，是他们让我的生活如此美好，使我能够不断前行。

**里科·兰德曼（Rico Landman）** 是来自荷兰兹沃勒的网页开发者。在多家公司担任网页开发者后，他创办了自己的公司Futurix。他主要使用PHP，是一位坚定的开源拥护者，擅长使用Magento、Drupal、vTiger等工具。

近年来，他倾向于寻求与其他开源导向的公司合作。他的大部分项目都归属于Simourix（共同所有者）或Trinfinity——一个由高端互联网行业专家组成的国际网络。

谨以此献给玛尔亚（Marja）、卡门（Carmen）和拉尔夫（Ralph），以及我的商业伙伴马塞洛（Marcello）和汉斯（Hans）。

**艾琳·麦克诺顿（Eileen McNaughton）** 居住在新西兰惠灵顿，她的时间分配在CiviCRM咨询、家族汽车业务的账目、两个学龄前“超级英雄”以及偶尔的睡眠之间。她最初是在为惠灵顿马戏信托基金（她是该组织的受托人）设置在线课程注册时开始接触CiviCRM，此后便为Fuzion参与了多个CiviCRM和Drupal实施项目。她为核心代码库贡献了大量补丁，包括支付处理器、自定义搜索和发票增强功能。她还在研究Xero会计软件包的集成，以及为流行的Drupal Migrate模块开发CiviCRM扩展。

她是论坛和CiviCRM博客上的常客，并推动着“Make-it-Happen”倡议。她在CiviCRM API和CiviAccounts团队中任职，这些任命有时是一种荣誉，有时则让人想到“傻瓜”这个词。艾琳是参与编写原始CiviCRM FLOSS手册的书籍冲刺团队成员之一。

我要感谢唐纳德·洛博（Donald Lobo）和CiviCRM核心团队的其他成员，感谢他们为世界提供了如此出色的CRM，并付出了巨大努力帮助人们使用它。
