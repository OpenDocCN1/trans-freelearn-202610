## Foreword

Donald Lobo、Michal Mach 和我几乎六年前开始了 CiviCRM。当时，开源软件在操作系统领域已经站稳脚跟，但从零开始设计一款满足非营利组织和其他公民部门组织需求的开源应用的想法仍然相当激进。我们坚信，开源开发的原则，即同伴生产、协作和透明度，与许多公民部门组织的宗旨和文化之间存在天然的亲和力。

在我看来，开源软件的主要好处在于，软件的功能会随着赞助和使用它的组织的需求而增长和扩展。这被称为“适用性”，它使 CiviCRM 与其他 CRM 软件区别开来，后者往往更像是企业部门传下来的“不合身的旧衣服”。

CiviCRM 已发展成为全球数千家组织的首选 CRM 软件。我们组建了一支才华横溢、敬业的开发团队，并应对了构建能够满足从社区艺术团体到全国性会员协会、草根组织、政治竞选、宗教组织、基金会和政府机构等各类组织多样化需求的软件的挑战。

在这一过程中，我们一直在努力寻找合适的流程和工具来培育一个支持性强、欢迎度高的社区，在不断涌现的对更多更复杂功能的需求中提高软件的质量和可用性，并开发可持续的收入来源以维持项目。这是一段持续的旅程，而首部商业出版的 CiviCRM 指南的问世是又一个里程碑。

这本书可以说是一种强力工具。作为一本“可能性手册”，它将激发新的思考，让你能够基于之前可能使用过或缺乏的旧技术，实现组织回报的最大化。如果你是 CiviCRM 的现有用户，你将找到简化工作流程并更有效地利用现有数据的方法。无论你的情况如何，这本书都是为你量身定制的。

作者 Brian Shaughnessy 和 Joseph Murray 多年来一直活跃于 CiviCRM 社区，并为各种各样的组织实施了基于 CiviCRM 的解决方案。这使他们深入了解 CiviCRM 的精髓，以及如何实现最佳回报。

当我看到新的、富有创意的基于 CiviCRM 的活动出现在我的 Twitter 动态中，新的本地 Civi聚会宣布，或是新上手开发者提交的补丁，或是看着非营利组织员工的眼睛在看到所有利益相关者信息集中在一个地方的强大功能时亮起来，我对 CiviCRM 的未来充满信心。

归根结底，任何开源项目的强大之处在于其背后的社区力量。我敦促所有使用 CiviCRM 的人积极参与社区。赞助新功能和改进，提交补丁，分享案例研究，并帮助刚起步的人！你可以在 http://civicrm.org/ 上完成所有这些。

David Greenberg

CiviCRM 联合创始人
