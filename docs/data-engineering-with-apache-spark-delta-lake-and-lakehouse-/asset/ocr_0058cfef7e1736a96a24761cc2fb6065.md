# Important Note

You can further understand the issue of duplicates arising due to changed data by asking a simple question: What do the end users want to query? Undoubtedly, it's the latest version of data only. Fortunately, Delta Lake allows you to store, retrieve, and recover previous versions of data, but by default, it only supplies the latest version.

# Verifying insecure data

Finally, we want to validate whether the data in the silver layer conforms to the security standards. During the discovery phase, a core security requirement was to mask all PII data. In the cell titled Define functions, notice the following function that masks a PII column:

```
def mask_value(column):
    mask_value = hashlib.sha256(column.encode()).hexdigest()
    return mask_value
```
