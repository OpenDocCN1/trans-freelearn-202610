## 前言

我认为现在已经不需要再解释数据在现代世界中的重要性了。我们今天使用的许多在线服务都由各种复杂程度的数据系统驱动。机器学习很大程度上得益于现代数据平台，能够收集、处理和分发大量数据，才成为某些任务的强大工具。这些数据平台还为数据分析提供了坚实的基础，并在医疗保健、商业和教育等现实世界决策中发挥作用。

我开始从事数据领域工作时遇到的一个挑战，我相信你们中的许多人也熟悉，那就是缺乏关于该主题的好书和其他教育资源。关于可以使用哪些具体工具，有大量文档，但关于好的架构是什么样的，以及哪些模式适用于哪些具体情况的知识，只掌握在少数已经做过此类工作的人手中。这在新兴的云技术方面尤其如此。

Manoj 就是这样一位专家，他在过去 10 年里为不同行业公司的实施数据平台。在本书中，他将分享他在使用 Microsoft Azure —— 数据工作负载领先的云服务提供商之一 —— 构建和实施现代数据平台方面的知识和经验。你将学习在生产环境中实施数据湖架构、实施数据管道并运行它们的实用技能。像这样的书很有用，因为它们让你能够快速获取 Manoj 多年来积累的知识和经验，你知道他提供的配方和建议在实际实施中会有效，因为他以前多次实施过类似的系统。

掌握实用的数据工程技能是对你职业生涯的巨大投资，了解你可以依赖的模式将为你节省大量试错，并帮助你更快地取得成果。祝你享受阅读！
