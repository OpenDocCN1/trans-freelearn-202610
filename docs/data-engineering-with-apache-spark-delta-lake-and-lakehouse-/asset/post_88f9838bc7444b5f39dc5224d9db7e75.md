Let's briefly look at the structure of the YAML file:

- **Trigger**: Specifies the branch that will be invoked for CI/CD.
- **Variables**: Configuration data for the CI/CD pipeline. This can be pointed to a named group of variables in a library.
- **Stage, Job, and Steps**: A collection of jobs that are run sequentially. A job is a series of steps, and steps are the actual tasks and scripts that do a certain function.
