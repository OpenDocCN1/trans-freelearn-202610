+   - Additionally, we noticed that the `store_orders` and `e-commerce` transactions are done in varying currencies – USD, CAD, EUR, and INR. Ideally, we should convert all transactions to a uniform currency.

Before making this data available to end users, we should make it uniform across all data consumption layers.
