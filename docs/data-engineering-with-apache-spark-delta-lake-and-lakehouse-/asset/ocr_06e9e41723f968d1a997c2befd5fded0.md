The end users at Electroniz can invoke the following query to show the current state of their inventory levels:

```
SELECT TOP (100) [product_category]
, [product_name]
, [year]
, [quarter]
, [units_sold]
FROM [dbo].[ext_aggregated_products_by_quarter]
WHERE year=2021
ORDER BY 3 DESC, 2 ASC
```
