Here is some valuable advice:

+   - It is always a good idea to remove the compute resources once you've used them.
+   - You get 5 GB of **locally redundant data (LRS)** data for free. There is no need to remove data that's stored during future exercises since we will not be exceeding this limit.
+   - While using the free services in Azure, please keep a strict eye on your billing using the following link: https://portal.azure.com/#blade/Microsoft_Azure_Billing/BillingMenuBlade/Overview.

It is always a good idea to be extra cautious about billing. You can also set budgets in Azure to monitor costs over time. Azure will send you a notification if the set budget has been exceeded: https://docs.microsoft.com/en-us/azure/cost-management-billing/costs/tutorial-acm-create-budgets.
