3. Azure Data Lake Storage will store data in blobs. In Azure Data Lake Storage, blobs are organized in a filesystem hierarchy. To enable the hierarchy, we need to create a namespace for the bronze layer. Copy each of the following commands, line by line, and paste them inside the Cloud Shell window. Then, press Enter:

```
NAMESPACE="bronze"
az storage fs create -n $NAMESPACE --account-name $STORAGEACCOUNTNAME --metadata project=lakehouse environment=development layer=bronze --only-show-errors
```
