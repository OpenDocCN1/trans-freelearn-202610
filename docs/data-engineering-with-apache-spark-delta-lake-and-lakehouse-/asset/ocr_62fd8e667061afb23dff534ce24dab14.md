# Figure 5.35 – New linked service for geo-location data

In the Activities pane, search for Copy data.

Drag the copy data activity to the pane on the right-hand side. Input the following:

+   - Name: Get Geo-location Mapping

Click on Source. For the source dataset, click on New. Inside the New dataset pane, click on File. Now click on HTTP.

Click on Continue. Then, click on DelimitedText. Input the following:

+   - Name: GeoDelimitedTextSource

+   - Linked service: httpsource

Click on OK. Then, click on Sink.

For the Sink dataset, click on New.
