## 前言

在数据不断变化、模式不断演进的世界里，构建能够自动适应变化的数据管道至关重要。本书将帮助你构建可扩展的数据平台，供管理者、数据科学家和数据分析师信赖。

从数据工程的介绍及其关键概念和架构开始，本书将向你展示如何有效地使用 Microsoft Azure 云服务进行数据工程。你将涵盖数据湖设计模式以及数据在典型数据湖中需要流经的各个阶段。在探索 Delta Lake 的主要功能以构建注重性能和治理的数据湖之后，你将进阶到使用 Delta Lake 实现 Lambda 架构。本书包含大量实用示例和代码片段，带你通过作者在大数据领域 10 年经验中遇到的生产场景的真实案例。最后，你将了解数据湖部署策略，该策略在配置云资源和以可重复、持续的方式部署数据管道方面发挥着重要作用。

阅读完本数据工程书籍后，你将学会如何有效应对不断变化的数据，并创建可扩展的数据管道，以简化数据科学、机器学习和人工智能任务。

## 本书适合谁阅读

本书适合有志于成为数据工程师和数据分析师、对数据工程世界感兴趣并希望获得构建可扩展数据平台的实用指南的人。如果你已经使用 PySpark 并希望将 Delta Lake 用于数据工程，你会发现本书很有用。预计读者具备 Python、Spark 和 SQL 的基础知识。

## 本书涵盖内容

- *第 1 章，数据工程与分析的故事，*介绍了数据工程的核心概念。它向你介绍了大数据中的两种数据处理架构——Lambda 和 Kappa。

- *第 2 章，发现存储和计算数据湖架构，*介绍了数据工程中最重要的概念之一——分离存储和计算层。遵循这一原则，你将被介绍构建数据湖的理念。对这一关键原则的理解将为你理解本书后面讨论的现代数据湖设计模式奠定基础。

- *第 3 章，Microsoft Azure 上的数据工程，*介绍了 Microsoft Azure 云平台上的数据工程世界。它将使你熟悉所有在 Azure 数据工程生态系统中发挥重要作用的 Azure 工具和服务。这些工具和服务将在本书的实践示例中贯穿始终。

- *第 4 章，理解数据管道，*向你介绍了数据管道的概念。本章进一步增强了你对数据工程各个阶段的了解，以及数据管道如何通过集成各个组件并以流畅的方式运行来提高效率。

- *第 5 章，数据收集阶段 – Bronze 层，*指导我们使用 Lakehouse 架构构建数据湖。我们将从数据收集和 Bronze 层的开发开始。

- *第 6 章，理解 Delta Lake，*介绍了 Delta Lake 并帮助你快速探索 Delta Lake 的主要功能。理解 Delta Lake 的功能是数据工程专业人士希望构建注重数据新鲜度、快速性能和治理的数据湖的必备技能。我们还将详细讨论 Lakehouse 架构。

- *第 7 章，数据治理阶段 – Silver 层，*继续我们的构建数据湖工作。本章的重点是数据清洗、标准化和使用 Delta Lake 构建 Silver 层。

- *第 8 章，数据聚合阶段 – Gold 层，*继续我们的构建数据湖工作。本章的重点是数据聚合和构建 Gold 层。

- *第 9 章，在生产环境中部署和监控管道，*解释了如何有效管理在生产环境中运行的数据管道。我们将从运营角度探索数据管道管理，并涵盖安全、性能管理和监控。

- *第 10 章，解决数据工程挑战，*列出了数据工程专业人士遇到的主要挑战。本章将涵盖各种用例并提出挑战。我们将深入探讨挑战的有效处理方法，使用代码片段和示例解释其解决方案。

第 11 章，基础设施配置，教你使用 Terraform 进行基础设施配置的基础知识。使用 Terraform，我们将在 Microsoft Azure 上配置运行数据管道所需的云资源。

第 12 章，数据管道的持续集成和部署，介绍了数据管道的持续集成和部署的概念。利用 CI/CD 原则，数据工程专业人士可以以可重复的方式快速部署新的数据管道/对现有数据管道的更改。
