
## Pi Zero 重置
### 重置开关

一个简单的首次焊接项目，为你的 Pi Zero —— 或全尺寸 Pi —— 添加重置开关，是防止崩溃和挂起毁掉你一天的好方法

## 所需材料
- 焊接烙铁和焊锡
- 2× 2.54mm 公头排针
- 回收的 PC 机箱重置开关
Or
- 瞬时开关，常开 magpi.cc/zdXrPZg
- 2× 母头跳线

![](img/d8322379620245fcd21eccc3855b8c78_153_0.png)

从旧 PC 机箱拆下的重置开关非常适合这个项目，自带线缆已连接

现代所有 Raspberry Pi 上都提供 RUN 引脚，可用于从崩溃中恢复或启动已关机的 Pi。

Pi Zero 体积小巧、成本低廉且功耗极小，使其非常适合嵌入式项目。只有一个问题：如果代码进入无限循环或以其他方式导致 Pi Zero 崩溃，如何快速恢复运行，尤其是在 Pi Zero 被锁在不易触及的地方并由难以中断的内部电池供电的项目中。解决方案？一个连接到 Pi Zero 上 RUN 引脚的重置开关，可在崩溃时重启 Pi，或从关机状态将其开机。

## STEP-01
### 找到 RUN 引脚

在早期型号中称为 P6 引脚，RUN 引脚连接到处理器中保持其标准运行模式的引脚——因此得名 RUN。当通过将引脚上的一个触点短接到另一个触点而接地时，处理器会离开 RUN 状态。就实际效果而言，这与短暂切断处理器电源相同；如果 Pi 正在运行，它将重启，如果 Pi 已关机，它将开机。RUN 引脚位于 Pi Zero 板的右侧，夹在 GPIO 引脚和复合视频引脚（标记为‘TV’）之间。

## STEP-02
### 插入公头排针

所有 Raspberry Pi 型号的 RUN 引脚都是未布线的，即没有插入任何引脚。虽然可以直接将开关焊接到引脚上，但这样会阻挡 GPIO 和 TV 引脚；最好将公针焊接到引脚上并将线缆引到重置开关。

取一捆引脚中的两根，通过将拇指放在引脚之间塑料上的凹槽中并推动将其折断。从顶部将它们插入 Pi Zero 的 RUN 引脚，并用胶带或 Blu-Tack 固定，准备焊接。

![](img/d8322379620245fcd21eccc3855b8c78_154_0.png)

公头排针就位后，接线开关就像将母头排针套在新引脚上一样简单

## STEP-03
### 准备烙铁

确保烙铁安全地放在支架上，然后将其插入插座。

## STEP-04
### 焊接引脚

翻转 Pi Zero 以露出你穿过插座的引脚。如果你使用清洁海绵，先在流动水下浸湿，然后拧干，使其潮湿但不湿透；如果使用铜丝屑，则不需要水。

给烙铁几分钟预热，然后将烙铁头在海绵或铜丝屑上擦拭。清洁后，通过将少量焊锡熔化在烙铁头上，然后再次在清洁材料上擦拭来“上锡”。烙铁头应看起来有光泽，没有黑色残留物或变色的迹象。

将烙铁压在其中一个引脚的底部，确保它也接触到电路板上的亮铜环或方块。数到三，然后用另一只手将焊锡推向引脚底部，不要触碰烙铁头。

焊锡应熔化然后似乎被“吸入”引脚孔中。如果没有，请移除焊锡和烙铁，清洁烙铁头的尖端，调整位置，然后重试。

## STEP-05
### 检查焊点

两个引脚焊接完成后，在尝试使用 Pi Zero 之前检查你的手艺。焊点应看起来从电路板平滑地流向引脚，没有任何间隙。如果电路板上仍能看到铜，或焊锡没有粘在引脚的腿上，请再次使用烙铁“回流”焊锡，必要时添加更多。

确保你没有用多余的焊锡将两个引脚连接在一起。如果有，请使用吸锡泵或吸锡带去除多余焊锡，否则 Pi 将无法启动。

## STEP-06
### 接线开关

如果你使用的是来自 PC 机箱的重置开关，母头排针可以直接以任意方向插入 RUN 引脚的新引脚上。否则，使用一对母对母跳线将引脚连接到任何描述为“瞬时，常开”的开关。这些开关形式多样，从廉价的触觉开关到更昂贵的防破坏设备。

Pi 运行时可短按开关进行重置，但请注意，如果 Pi 正在写入时，这可能会导致 SD 卡损坏。如果 Pi 已关机，按下开关可将其重新开机——这是始终安全的。

## QUICK TIPS
### KEEP THE TIP CLEAN

脏的烙铁头会使焊接变得困难。焊接时定期清洁烙铁头，并不时用新焊锡重新上锡。

### EMERGENCY USE ONLY

就像切断电源一样，使用重置开关也可能导致 SD 卡损坏。仅在无法以其他方式关闭 Pi 时才使用它！

## SLACKTIVITY MONITOR

使用此 LED 显示屏跟踪 Slack 聊天活动。你可以一目了然地知道是否有安静、轻度聊天或喧闹的争论

为了在 Raspberry Pi 基金会内部进行沟通，我们使用 Slack，这是一种类似 IRC 的聊天服务。活动可能非常多，人们花了时间来调整通知设置。但我们想要的不仅仅是 Slack 通知所能提供的。我们希望能够一目了然地看到同事之间有多少聊天。幸运的是，Slack 的 API 和 Python 库功能强大且易于使用。组装简单，材料 inexpensive，尤其是在使用 Pi Zero 的情况下。

## Initial configuration

要设置自己的 Slacktivity Monitor，请从全新的 Raspbian 安装开始。对于 Raspberry Pi Zero，你需要使用 Raspbian Jessie，可以在 NOOBS 上找到，或使用 Raspberry Pi 下载页面上的映像写入 SD 卡（raspberrypi.org/downloads）。与其它 Raspberry Pi Zero 项目一样，最简单的方法可能是先用 Raspberry Pi 2 或 B+ 配置和安装所有内容，然后在准备好后将 microSD 卡移到 Pi Zero。确保通过进入终端并使用以下命令进行必要的更新：

```
sudo apt-get update
sudo apt-get upgrade
```

你需要设置一些基本配置选项。从桌面进入偏好设置菜单中的 Raspberry Pi 配置。在系统选项卡下，将 Pi 设置为启动到 CLI（命令行界面）并启用“等待网络”。你也可以使用命令行实用程序 raspi-config 设置这些选项。确保你也已配置 Pi 连接到你的 WiFi 网络。或者，你可以使用 USB 以太网适配器与 Pi Zero 配合使用。

## Software setup

从命令行下载 Python Slack 客户端库：

```
sudo pip install slackclient
```

下载项目代码：

```
git clone https://github.com/mrichardson23/slacktivity-monitor.git
```

你需要在项目代码中使用自己的 Slack API 令牌，以便 Slacktivity Monitor 可以验证自身身份。登录 Slack 后，前往 magpi.cc/1Vai8OF 并为你要监控的用户和团队点击创建令牌。将该令牌代码复制到你的代码中，替换文本 SLACK TOKEN HERE。

代码跟踪大约最近一分钟的活动。如果在此期间没有发送消息，则红色 LED 会点亮。如果在最近一分钟内有消息（但少于 15 条），则黄色 LED 会点亮。如果在最近一分钟内发送了 15 条或更多消息，LED 将变绿。你可能需要根据 Slack 团队的典型活动水平调整此阈值。

设置脚本在启动时运行。从命令行执行：

```
sudo nano /etc/rc.local
```

在 exit 0 行之前，添加一行以启动你的代码：

```
python /home/pi/slacktivity-monitor/main.py &
```

## Physical build

在 Pi Zero 上焊接排针并将 Pi Traffic Light 连接到这些引脚。代码使用 15 号引脚用于红色，14 号引脚用于黄色，28 号引脚用于绿色。这是因为它们都与一个接地引脚相邻，所以 Pi Traffic Light 可以直接插入排针并完美工作。根据你希望如何布置 Slacktivity Monitor，你可能想要更改引脚编号和颜色。

使用 Blu-Tack 或 Command Strips 将 Slacktivity Monitor 固定到你的显示器上。

当你为 Pi 通电时，脚本应自动启动并连接到你团队的 Slack 实例。即使没有最近的活动，你最初也可能会看到交通灯变黄，因为当新客户端连接时，Slack API 会返回最近的消息。

## Going further

代码忽略除消息之外的所有内容，因此你也可以调整 Slacktivity Monitor 以对不同类型的事件做出反应。例如，你可以使用红灯指示你的老板离线，黄灯指示她处于空闲状态，绿灯指示她处于活动状态。

## Main.py

```
import time
from slackclient import SlackClient
from gpiozero import LED

token = "SLACK TOKEN HERE" # found at
# https://api.slack.com/web#authentication

red = LED(15)
yellow = LED(14)
green = LED(18)

red.off()
yellow.off()
green.off()

sc = SlackClient(token)

message_counts =[]

if sc.rtm_connect():
    while True:
        message_count = 0
        events = sc.rtm_read()
        for event in events:
            if event['type'] == 'message':
                message_count = message_count + 1
                message_counts.insert(0, message_count)

            if len(message_counts) > 600:
                message_counts.pop(600)
                total_message_count = 0

            for i in range(0,len(message_counts)):
                total_message_count = total_message_count + message_counts[i]

            if total_message_count == 0:
                red.on()
                yellow.off()
                green.off()

            if total_message_count > 0 and total_message_count < 15:
                red.off()
                yellow.on()
                green.off()

            if total_message_count >= 15:
                red.off()
                yellow.off()
                green.on()

            time.sleep(.1)
else:
    print "Error. Invalid token?"
```
