## 到目前为止最好的树莓派 Zero 项目

人们几乎立刻就开始使用全新的 Pi Zero 来驱动更小巧、更酷的项目

好吧，树莓派 Zero 的发布令人兴奋，不是吗？我们卖光了所有库存，不得不加印第二批，这意味着已经有大量树莓派 Zero 流向用户开始用于项目。几天之内，人们就完成了一些令人难以置信的事情：新黑客、更新的黑客、概念验证……各种优秀作品层出不穷。你可以花上好几个小时翻阅 #pizero 标签来查看它们全部，但在撰写本杂志时，我们找到了其中一些最好的作品。

请通过 Twitter @THEMAGPI1 发送你的项目

### Xbox 控制器 Pi Zero

通过将 Doom 内置到控制器中，为 Xbox Media Centre 赋予新意义

第一代 Xbox 的原装控制器有很多俗称。Duke。熊。火灾隐患。它的尺寸被归因于“适合大美国手”的都市传说；正因其尺寸，它却非常适合 Terence Eden 的项目。

“我想要在电视上玩复古游戏，”Terence 告诉我们。“但我不想再买一台放在下面。 我也不想折腾太复杂的东西——我当时想，如果能把整台游戏机塞进控制器里该多好？

与我们的项目构想类似（最终在这本书中形成了一份完整的教程），Terence

> 我想要在电视上玩复古游戏

最初考虑使用标志性的 NES 控制器。然而，他的妻子指出更大的 Xbox 控制器非常适合他的计划。

“所以，这个项目就是把 Pi 塞进控制器里，用它来玩 Doom！”

显然即使是树莓派 Zero 也很紧凑，意味着控制器外壳内部的一些部分必须被削掉才能塞进去。“所有端口都在同一侧，这太棒了；这样在狭小空间里安装更容易，”Terence 补充道。

组件清单并不花哨：只是让 Zero 工作的标准电缆以及所需的各种工具。

像其他人一样，Terence 也受到了启发，并思考还能如何利用 Zero。“我很好奇是否可以用它作为门窗传感器。Pi Zero 比 Z-Wave 传感器便宜，所以只要我能为它供电，我就可以把它放在家里的每一扇门和窗上。”

TERENCE EDEN
Web developer
shkspr.mobi

![](img/d8322379620245fcd21eccc3855b8c78_84_0.png)

把 Pi Zero 装进控制器里，你甚至不需要主机

![](img/d8322379620245fcd21eccc3855b8c78_84_1.png)

USB OTG 是对现有 micro-USB 规范的简单扩展。连接器非常便宜：网上不到 1 英镑。话虽如此，如果你对布线和焊接有信心，自己制作也很简单。Terence 直接把旧的连接器接到控制器线上

RetroPie 是模拟器爱好者的绝佳资源，Terence 说。他记得当年为了让 MAME 运行而到处折腾的日子，但这是一个包含所有内容的单张磁盘镜像。神奇的是，它甚至通过 xpad 为 Xbox 控制器提供了内核支持——Terence 以为自己肯定得自己动手搞定！

### 能源监控

物联网借助能源消耗监控来到 Zero 身上

> “该项目使用 Pi Zero 作为一个小小的中心，将我家里的电子设备连接到几乎任何东西，”Laura Trevail 谈到 Pi Zero 能源监控时说。“它测量设备的能源消耗并实时发布该数据，其他地方的设备可以找到并与其交互……当我在泡 [饮料] 时，我可以把我的电水壶变成完全不同的地方的某样东西，如果我愿意的话，有人可以在我喝茶时加入我，如果他们愿意的话，或者使用我推断出的咖啡消费数据（或我分享的任何其他内容）以我从未想象过的方式驱动他们自己的故事。”

所以，这是一个从简单概念出发却用途无穷的典型物联网设备！据说，Laura 和 Danielle 花了一上午在两个郡里寻找一本《The MagPi》，当她们终于拿到手时，对 Pi Zero 的小巧感到惊讶。

该项目使用了 Energenie，具体来说是 Energenie 双向 PiMote 和 Energenie MiHome 监控器，使用了 David Whale 的 pyenergenie 库（magpi.cc/1jKpQ8L）。

### 树莓派笔记本电脑 – Zero 版

得益于树莓派 Zero 的新尺寸和规格，经典的 Pi 外壳焕然一新

PETER HOWKINS
Software engineer
marutan.net

![](img/d8322379620245fcd21eccc3855b8c78_85_2.png)

它基本上是一台完整的笔记本电脑，只是很容易打开和维护

乐高外壳自树莓派首次推出以来就一直是其重要组成部分——尤其是在最初几乎没有外壳可用的时期。很快就将其推向了逻辑的极致，一台由乐高驱动的 Pi 笔记本电脑诞生了，每个人都爱上了它。

> “这是一款小巧便携的树莓派系统，非常适合去活动时携带，无需再携带单独的显示器和键盘，”其创造者 Peter Howkins 告诉我们。“它结合了我两个爱好：树莓派和乐高。这是我的笔记本的第三个版本，最初使用的是原版 Model B，然后我重建以适应 B+ 和 Pi 2，现在它使用的是 Pi Zero。”

Peter 在得知 Pi Zero 的价格时简直不敢相信，但它确实大幅降低了整体乐高笔记本的成本。它包含转换器、改装的 USB 端口、屏幕、USB 电源组、迷你键盘、电缆，以及大量的乐高。

### Matchbot

一个很棒的小机器人，真正展示了 Pi Zero 的多功能性

![](img/d8322379620245fcd21eccc3855b8c78_86_0.png)

MARK CANTRILL
Electronics design engineer, Maker
astro-designs.com

在上一期中，我们有一台由 Richard Hayler 制作的出色的 3D 打印 Pi Zero 机器人（magpi.cc/1lmeoi）。我们没想到这么快就会看到更多机器人，但几天后，Mark 的 Zero 驱动 Matchbot 就出现在我们的 Twitter 动态中。

> Matchbot 只用了几天就建成了

“Matchbot 只用了几天就建成了，主要是为了好玩，”Mark 告诉我们。“当 Pi Zero 发布时，我给自己设定了一个挑战，建造一个非常小的东西。我最近想从一直在做的事情中休息一下，也想加入 Pi Wars 的乐趣。此外，作为一个简单的小机器人，我希望它能帮助我的两个女儿对树莓派和物理计算产生兴趣。”

虽然使用他闲置的机器人套件本身就很棒，但 Mark 实际上重新利用了 CamJam EduKit 3 的零件来建造它。

![](img/d8322379620245fcd21eccc3855b8c78_86_2.png)

![](img/d8322379620245fcd21eccc3855b8c78_86_3.png)

![](img/d8322379620245fcd21eccc3855b8c78_86_4.png)

Matchbot  fits in a matchbox and uses little more than the CamJam EduKit 3

Matchbot  fits in a matchbox and uses little more than the CamJam EduKit 3

电机必须非常小，齿轮恰到好处，并且足够强劲

LED 在循线程序中闪烁两次，在接近测试中闪烁三次，而四次和五次闪烁分别会退出脚本并关闭 Pi

“它由一个大号火柴盒、两个微型齿轮电机、车轮以及其余部分（电机驱动器、传感器和电池盒）主要来自 CamJam EduKit 3 组成。还有一个 5V 稳压器，这样它就可以使用电机电池为 Pi 供电。”除了电动轮之外，Matchbot 还配备了超声波测距传感器和循线传感器。把机器人装进火柴盒本身就是一项壮举。然而，Matchbot 的控制界面别出心裁——由于没有 WiFi 远程连接，Mark 编程让测距传感器根据你把手放在它前面停留的时间长短来切换模式，闪烁的 LED 会提示你激活了哪种模式。在 Pi Wars 当天，它处理循线赛道非常出色！
