
## Pi Zero 配件

你可以为你的 Raspberry Pi Zero 获取哪些东西来让使用它和创建项目变得更加轻松？

如今已经形成了一个小小的 Raspberry Pi 经济，当新设备推出时，针对它的新配件的反应速度要快得多。尽管 Raspberry Pi Zero 仅上市几个月，这意味着你已经可以买到一些配件来提升你的 Pi Zero 使用体验。你还需要一些设备来完成本期中的项目，甚至开始打造你自己的惊人作品。

## Zero 外壳

用这些时尚的外壳让你的 Pi Zero 更具风格

### ZEBRA ZERO

magpi.cc/2dXqMZ9

由两层木材和厚实的亚克力中心组成坚固的外壳，Zebra Zero 为你的 Raspberry Pi Zero 增添了一丝品味。它还配备了一个巨大的散热片，可能有点多余。你还可以获得带有一个完整面包板的 Zebra Zero Plus，以便轻松测试。

### PIBOW ZERO CASE

magpi.cc/1KljtQz

经典激光切割 Pibow 的特殊 Pi Zero 版本现已上市。凭借其独特的贴合芯片设计，它让端口保持非常开放，可用于任何定制项目，甚至一些 Pimoroni HAT —— 尽管你需要在组装前插入 SD 卡。

### MODMYPI ZERO CASE

magpi.cc/1KLgEiu

一款用于 Raspberry Pi Zero 的哑光黑色、激光切割、分层外壳。它保持了四个主要端口的开放以让 Zero 工作（HDMI、SD、USB 和电源），同时也保持 GPIO 引脚自由。甚至复位和视频输出引脚也可以通过它访问。

### ADAFRUIT PI PROTECTOR

magpi.cc/1ZEZbhn

与这里介绍的其他外壳相比，Protector 是一个更简单的外壳，它覆盖了 Pi Zero 的底部和顶部的一部分，并没有提供与其竞争对手完全相同的保护。然而，它在 GPIO 周围留出了更多的空间，从而在你的项目空间紧张时可以更好地访问它。

## 杂项附加组件

其他可以提升你的 Raspberry Pi Zero 的零部件

### MINI USB OTG ADAPTOR

magpi.cc/jT9aZc
有几种这样的适配器可供选择——我们对 meZmory 品牌的适配器有不错的体验，但还有其他几种。它使将单个 USB 设备插入 Pi Zero 变得更加容易——非常适合只需要无线连接而不需要其他功能的项目。

![](img/d8322379620245fcd21eccc3855b8c78_148_0.png)

### RIGHT-ANGLE GPIO HEADER

magpi.cc/1ZFoH31
我们曾向你展示如何将标准 GPIO 排针焊接到 Pi Zero 上，但这个很酷的替代方案允许 GPIO 引脚与电路板平行。这对于空间限制固定的笨拙项目或安装来说是理想的，而且它像任何其他 GPIO 排针一样焊接。

![](img/d8322379620245fcd21eccc3855b8c78_148_1.png)

### ESSENTIAL RASPBERRY PI ZERO KIT

magpi.cc/1RSULPN
一套可与 Raspberry Pi Zero 一起使用的组件精选，包括额外的适配器、几种 GPIO 排针选项，甚至还有一些可粘贴的小脚垫来抬高 Pi Zero 离地面。它全部装在一个类似薄荷糖的小盒子里，这个盒子也可以容纳整个 Pi Zero 作为临时便携箱。

![](img/d8322379620245fcd21eccc3855b8c78_148_2.png)

### SCROLL PHAT

magpi.cc/1JT9cQT
这款实际上也适用于其他 Raspberry Pi，但它采用与 Pi Zero 相同的外形尺寸。该板为你提供 55 个 LED 以矩形排列，其工作原理与 Sense HAT 上的 LED 矩阵类似。使用 Python 脚本，你可以控制 LED 或让它在板长上滚动文字。

![](img/d8322379620245fcd21eccc3855b8c78_148_3.png)

### EXPLORER PHAT

magpi.cc/1Pk5sdN
这款用于 Zero（和其他 Pi）的扩展板使其能够比直接将它们焊接到 Pi 上更容易地与不同对象通信。这包括电机和传感器——我们曾看到由于这个原因而在机器人中使用 Explorer。它允许模拟输入以及其他输入和输出，并拥有自己的 Python 库以便快速开发。非常适合微型项目。

![](img/d8322379620245fcd21eccc3855b8c78_148_4.png)

## 基础套件

你需要这些基础设备来创建惊人的 Pi Zero 项目

### 元件

LED、导线、电阻，也许还有一些光、热或运动传感器。所有这些在本地电子商店或像 RS Components 这样的分销商的在线商店中都能以非常便宜的价格成捆买到。你也可以在电子入门套件中获得很多，比如 ModMyPi（magpi.cc/1RvzWta）图片中展示的那种。对于本期中的教程，我们会在你外出购买之前确保你确切知道需要哪种组件。

![](img/d8322379620245fcd21eccc3855b8c78_148_5.png)

### 烙铁

制作更高级的项目或组装适用于 Raspberry Pi 的套件时必不可少的一件设备。除了实际的烙铁外，你还需要高质量的焊锡来配合使用。烙铁的合适支架也很理想——一个不太可能烫伤你的支架，配有良好的海绵。焊接可能很危险，所以在他们制作时一定要监督年轻的创客。

![](img/d8322379620245fcd21eccc3855b8c78_148_6.png)

### 面包板

原型制作和测试电路的完美工具。如果你从未使用过面包板，它的作用是提供一排排排列的引脚，充当连接器，这样你就不必将组件焊接在一起。这意味着你可以快速更改电路以使其正确，或反复重复使用面包板用于新的和不同的电路。你可能不需要一开始就买一个巨大的面包板，但要选择两侧都有正负导轨的。

![](img/d8322379620245fcd21eccc3855b8c78_148_7.png)

### 剥线钳

如果你决定购买一卷电线而不是一堆预先剪好的线，你需要一种从线轴上取线的好方法。用剪刀或刀子慢慢小心地攻击会很快变得极其无聊，投资一副合适的剥线钳，它还能剥掉塑料，会让你的生活改善至少 10%（不要引用我们的话）。

## Pi Zero 游戏机

Pi Zero 小巧的身形让我们第一次能够用一个简单的 USB 手柄打造一台完整的复古游戏机。方法如下……

### 所需物品

- USB SNES 手柄 – eBay
- PowerBoost 500 makersify.com
- 3.7V 500mAh LiPo 电池 – eBay
- RetroPie magpi.cc/Retro-Pie
- 迷你 HDMI 转 HDMI 电缆（3m） amazon.com
- 2x micro USB 电缆 amazon.com

![](img/d8322379620245fcd21eccc3855b8c78_149_0.png)

这款 USB SNES 手柄仿制品看起来时尚纤薄，但实际上内部包含一个广阔的荒地，等待被黑客改造……

PowerBoost 500 是主角。它安全地将电池升压至输出 5V，从而为 Pi Zero 供电，即使它通过 micro USB 为电池充电时也是如此

凭借 3-4 小时的电池续航时间，这个小小的 3.7V LiPo 对于这个项目来说是完美的

我们将小心地对这两根 micro USB-to-USB 电缆进行改造以窃取连接器。一根将为 Pi Zero 供电；另一根将直接连接到手柄的 USB 电缆

### 提示

SNES 手柄

由于它们非常便宜，我们实际上从 eBay 上买了几副 USB SNES 手柄。

这个项目受到了杂志特约编辑 Rob Zwetsloot 几期前完成的一个类似项目的启发。Rob 取了一个现代 USB 版本的复古任天堂娱乐系统手柄，打开它并将 Pi Zero 放了进去。虽然它运行完美，通过 RetroPie 运行经典的 NES 游戏，但我们认为这个项目可以更进一步。经典手柄上不会有两根线从中出来（在本例中为 HDMI 和电源 USB），因此我们的新目标是创建一个完全自包含的手柄内主机，只有一根线出来连接到电视或显示器的 HDMI 端口。于是 Pi Zero 驱动的 SNES Consoller 诞生了…… 为了让这个项目在手柄内部工作，需要挤进惊人数量的技术。幸运的是，大多数 USB 手柄内部大部分是空的，只使用四根细小的 USB 彩色编码线连接到一个细长的电路板，该板处理输入（方向键和六个按钮）。我们如何从手柄获取输入并将其发送到 Pi Zero？实际上再简单不过了——我们要做的就是剪掉手柄的 USB 电缆并直接将电线焊接到一个 micro USB 连接器上，该连接器可直接插入 Pi Zero 的 USB 端口。由于 USB 布线完全通用，因此它可以正常工作。
