## 规格

- **CPU:** BCM 2835（与原版树莓派相同），1GHz 单核 ARM11
- **RAM:** 512MB
- **存储:** 通过 microSD
- **电源:** Micro-USB 连接器
- **视频输出:** Mini-HDMI
- **连接性:** 1× micro-USB、未焊接 40 针 GPIO 连接器、摄像头端口、未焊接复合视频输出
- **尺寸:** 65mm × 30mm × 5mm  **重量:** 9g

### 电源供应

您需要一张 microSD 卡才能为树莓派 Zero 安装操作系统。有些附带 SD 适配器，以便您可以将其插入电脑。

连接显示器到树莓派 Zero 需要一根 mini-HDMI 转 HDMI 电缆 – 普通 HDMI 电缆无法使用。

这个 micro-USB 端口用于数据；要实际用来插入鼠标、键盘或无线适配器，您需要一个 micro-USB 转 USB 适配器。

这是电源接口 – 不要把它与数据端口混淆！您需要一个手机充电器，或官方的树莓派电源，才能启动 Zero。

### 第一步
插入 SD 卡

您需要在树莓派 Zero 上安装 NOOBS（New Out Of Box Software，即开箱即用软件），以便选择操作系统。将您的 microSD 卡插入另一台电脑并访问树莓派下载网站（magpi.cc/1MYYTMo）。下载 Raspbian 并按照我们的入门指南通过卡写入器安装它。写入完成后将其插入。

### 第二步
连接电缆

插入 mini-HDMI 转 HDMI 连接器，并确保其在树莓派 Zero 和显示器之间正确连接。现在插入您的 USB 适配器，确保插入正确的 micro-USB 端口，并连接您的 USB 集线器。您可能不需要带外接电源的集线器，但最好备一个以防万一。

### 第三步
通电

将电源线插入 micro-USB 电源插座，再次确认是正确的 – 此时它应该是唯一剩下的接口。将电源适配器的另一端插入墙上插座，树莓派 Zero 会立即启动。您现在准备好开始新的黑客和制作篇章了！

### 如何在命令行连接 WiFi

### 为您的 Pi Zero 设置网络名称

如果您按照本页的无线教程设置静态 IP，那么您将始终能够使用该 IP 地址从任何远程服务访问树莓派 Zero。然而，对于想要更简单自动方式的人，您仍然可以通过设置 Zeroconf 使通过网络连接 Zero 变得同样简单。在命令行或终端中，输入以下命令以确保其已安装：

```
sudo apt-get install avahi-daemon
```

默认情况下，Pi 现在可通过本地网络的 raspberrypi.local 访问。

![](img/d8322379620245fcd21eccc3855b8c78_145_0.png)

左 在某些版本的 Raspbian 上，avahi 可能已预装

![](img/d8322379620245fcd21eccc3855b8c78_145_1.png)

虽然 Raspbian 在桌面界面上使连接 WiFi 变得非常容易，但在命令行中使其工作则涉及更多。在开始之前，有一个技巧您可以尝试：如果在桌面上设置了 WiFi，在命令行中仍然可以使用。不过并非总是可行，因此您可能需要使用手动方式。首先，找出您的网络名称和密码。在 Raspbian 命令行中，输入：

```
sudo nano /etc/wpa_supplicant/wpa_supplicant.conf
```

文件中已经有一些信息，但要使无线连接，请确保文件中包含以下行，并用您的网络名称（SSID）和密码替换现有内容：

左 要在桌面界面上设置静态 IP，您必须经过同样的流程

```
network={
  ssid="YourSSID"
  psk="YourWifiPassword"
}
```

您还可以为树莓派设置静态 IP。为此，您首先需要做一些准备工作，这需要您使用一台已连接到无线网络的电脑。在 Windows 中打开命令行，或在 OS X 或 Linux 中打开终端。对于 Windows，输入 ipconfig；对于 OS X 和 Linux，使用 ifconfig 然后 netstat -nr。记下 IP 地址（inet）、广播地址、子网地址、路由器 IP（Destination）和网关地址。之后打开 DHCPD 配置文件（sudo nano /etc/dhcpcd.conf）并添加：

```
interface wlan0

static ip_address=[address]
static routers=[router IP]
static domain_name_servers=[gateway]
```

## 从另一台电脑使用您的树莓派

### 使用 Samba 在网络上共享文件

借助名为 RealVNC 的软件，您甚至无需将 Pi Zero 插入显示器即可使用其桌面；您可以简单地从另一台电脑控制它。首先，前往 magpi.cc/PiVNC 并将 RealVNC 下载到您的树莓派上。还需获取一个免费许可证密钥（magpi.cc/1O8Hz4J），因为您会用到它。

![](img/d8322379620245fcd21eccc3855b8c78_146_0.png)

上方 在某些版本的 Raspbian 上，Avahi 可能已预装

文件在 Pi 上后，打开终端，使用 cd 导航到 Downloads 中的文件（cd Downloads 应该可以），并使用以下两个命令，将方括号替换为适当名称：

```
tar xvf [VNC file name].tar.gz
sudo dpkg -i [VNC Server package name].deb [VNC Viewer package name].deb
```

复制您获得的许可证密钥，然后运行 sudo vnclicense -add [Licence Key] 并使用您的密钥。在终端或命令行中输入 vncserver 以开始，输入您的树莓派密码（默认为 raspberry）并记下显示器编号。在我们的例子中是 1，并且由于已安装 Avahi，我们可以使用 raspberrypi:1 连接。

从此处安装 VNC 查看器：magpi.cc/1M4uzfG，选择您喜欢的平台，然后使用 raspberrypi:[Number] 连接

### 从命令行远程访问您的 Pi

通过 SSH 协议，您可以从家庭网络上的任何其他电脑访问树莓派。SSH 默认应已激活，但为确保其开启，您可以从菜单的“首选项”类别中进入 Raspberry Pi 配置（或在命令行中输入 sudo raspi-config），并确保在“接口”选项卡中已启用 SSH（或在命令行版本的“高级”菜单下）。如果 SSH 已禁用，请启用它并重新启动。在 OS X 和 Linux 中，您可以从终端使用 SSH；不过在 Windows 中，您需要下载 PuTTY（magpi.cc/1Mm5Npi）。

从 OS X 或 Linux 终端，您可以使用以下命令远程访问 Pi：

```
$ ssh pi@raspberrypi
```

您需要设置网络名称（参见上一页的框）。输入 yes 以信任连接，然后输入密码 raspberry 登录。如果使用 PuTTY，只需在地址字段中输入 pi@raspberrypi 并点击 Connect。再次，您必须同意信任 Pi Zero，然后使用密码 raspberry。现在您可以像通常通过命令行一样控制树莓派。

如果您想将树莓派 Zero 用作文件服务器，这尤其好。为此，或只是为了能够从网络上的任何地方访问 Zero 上的文件，您需要使用 Samba。首先，您需要安装它：

```
sudo apt-get install samba samba-common-bin
```

您需要配置 Samba 以按预期工作。仍在终端或命令行中，输入：

```
sudo nano /etc/samba/smb.conf
```

首先，如果您的网络上有一个 Windows 工作组且具有特定名称，请找到以 workgroup = WORKGROUP 开头的行，并将大写的 WORKGROUP 更改为您的工作组名称。如果您不知道工作组是什么，可以保留此设置。找到行 # wins support = no，删除 # 字符，并将 no 更改为 yes。向下滚动到标记为 Share Definitions 的部分并输入以下代码块：

```
[pihome]
  comment= Pi Home
  path=/home/pi
  browseable=Yes
  writeable=Yes
  only guest=no
  create mask=0777
  directory mask=0777
  public=no
```

按 CTRL+X，然后按 Y 和 ENTER 保存文件。要开始共享，在终端中输入以下内容并使用您的 Pi 密码（默认为 raspberry）：

```
smbpasswd -a pi
```
