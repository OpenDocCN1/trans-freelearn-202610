
## STEP-01
### 剖开鼠标
听起来很残忍，但一旦你能真正打开它，其实比你想象的要容易得多。我们的 Razer Lachesis 在鼠标底部贴纸下藏有一个单独的十字螺丝。拆掉它后，我们能够取下鼠标顶部盖的 LED 灯板，并用侧切钳修剪掉一些支撑支架和塑料模制件。Razer 方便地为 LED 灯甚至 USB 端口使用了连接器，因此清空一切以腾出空间变得轻而易举。

## STEP-02
### 焊接 micro-USB
接下来，我们剪断了鼠标的 USB 线，留出足够的余量在末端焊接一个可直接插入 Pi Zero 的 micro USB 连接器。就这么简单。布线很直接——将 micro USB 连接器最长的平边朝上并朝向你，布线从左到右焊接——黑色、绿色、白色和红色。由于 USB 完全通用，不可能弄错——只需搜索‘micro USB cable connector’即可找到示例图。焊接起来可能有点费劲，但只要有一支不错的烙铁和一些辅助工具来固定它，就相当简单。

## STEP-03
### 安装 Zero 和迷你 HDMI
现在我们要安装 Pi Zero，同时考虑到它会连接一根（相对）庞大的 HDMI 线。我们最好的建议是购买你能找到的最纤薄的 mini HDMI 转 HDMI 线，但你需要用美工刀小心地去除外壳，以免损坏线缆本身。在我们的 Razer 鼠标上，我们发现 Zero 斜着放置很合适，HDMI 线绕过机身通向旧 USB 线所在的前部端口。此时，明智的做法是确保能够牢固地密封鼠标，因为你可能需要再雕刻出一点塑料外壳来容纳它。

## STEP-04
### 为 Pi Zero 供电
遗憾的是，鼠标内部根本没有足够的空间容纳可充电电池和配套的电池控制器板。相反，我们将从 Zero 的电源端口引出一根纤薄的 micro USB 线，从鼠标前面引出，与 HDMI 线并行。一旦项目完成并正常工作，你可以把两根线用胶带缠在一起，或使用一些合适的热缩套管将其牢固地固定在一起。你需要确保两根线都足够长，这样在另一端有

![](img/d8322379620245fcd21eccc3855b8c78_160_0.png)

足够的松弛度，并且 HDMI 和 USB 线都能插入。

## STEP-05
### 安装软件
下一步是在你的 SD 卡上设置一个 Raspbian Jessie 镜像；我们建议将 Zero 从鼠标中取出进行操作，并使用连接了键盘、鼠标和 WiFi  dongle 的 USB 集线器。安装好 Raspbian Jessie 后，你需要设置你的游戏（本例中为 Quake III）。安装并不轻松，但你可以在 magpi.cc/QuakeIII 找到该过程的完整说明。你需要重新编译游戏并从可靠来源获取 Quake III 的 pac 文件。抱歉——我们的律师不允许我们说得更具体了！

![](img/d8322379620245fcd21eccc3855b8c78_160_1.png)

## STEP-06
### 终极游戏鼠标
电源和 USB 连接问题解决后，并且安装了最新版的 Raspbian Jessie 和 Quake III，剩下的就是进入选项菜单并将控制重新分配到尽可能多的鼠标按钮上。我们选择用滚轮切换武器，左侧两个按钮用于前后移动，相对的两个侧键用于横向移动。刚开始需要一段时间适应，但很快你就能掌握它。

## NES ZERO
我们将上个月的项目创意变为现实，用一台被 Zero 赋能的 NES 控制器来运行 NES 游戏…

## You’ll Need
- USB NES 控制器（查看 eBay！）
- 一个 Raspberry Pi Zero - raspberrypi.org
- RetroPie - magpi.cc/z1HVgNba
- 一把旋转工具（如 Dremel）
- 一根旧的 micro USB 线
- 一把螺丝刀、烙铁和剥线工具

自从几个月前在 Pi HQ 第一次看到 Raspberry Pi Zero 以来，我们一直在思考 Pi Zero 的各种酷炫用途。其中一个最初的想法是将 Pi Zero 塞进 NES 控制器中，借鉴 Ben Heck 的伟大发明，进一步将 NES 迷你化到最核心的组件。

我们上期写过如何做到这一点，但现在我们终于有时间制作一个概念验证，所以我们将向你展示如何将 Pi Zero 完全装入 NES 控制器中。

## STEP-01
### 设置 RetroPie
这更多是为了方便。下载 RetroPie 镜像并使用你喜欢的方法将其写入 microSD 卡（如果你以前没做过，请查看 Raspberry Pi 指南：magpi.cc/1XTmymk）。写入后，在文件资源管理器中打开它，导航到 home、pi、RetroPie 并将你的 NES ROM 放入 nes 文件夹。

将 micro SD 卡插入 Pi Zero，并在开机前将 USB NES 控制器连接到它。然后你可以进行初始设置并配置控制器。

![](img/d8322379620245fcd21eccc3855b8c78_161_1.png)

## STEP-02
### 腾出空间
似乎许多 USB NES 控制器内部结构大致相同（它们可能使用 NES 控制器的模具，或只是通用模具），因此你很可能需要腾出一些空间。我们使用旋转工具修剪了螺丝孔和边缘的环。我们想利用原来的 USB 线端口作为 HDMI 线，因此建议你将 Pi Zero（已插入 SD 卡！）放在后盖内，确定需要修剪的位置。

![](img/d8322379620245fcd21eccc3855b8c78_162_0.png)

我们使用记号笔标记需要切割的位置，在工作过程中定期将 Zero 放在后盖上

## STEP-03
### 线缆孔
如果你和我们做一样的操作，不仅需要拓宽 USB 孔以便插入迷你 HDMI 线并为电源端口开一个新孔，还需要为 micro USB 端口伸出留出空间。标记出 mini HDMI 线需要切割的空间；你甚至可以考虑在后盖上切出一个正方形，以便更容易插入。边做边测试，但注意在打磨时塑料碎屑。

![](img/d8322379620245fcd21eccc3855b8c78_162_1.png)

上方 我们的切割在某些地方有点粗糙；你可能还需要打开控制器的底部以便线缆放入

> 剩下的就是把它插入电视和电源…

## STEP-04
### 接线控制器
USB 线的接线非常简单，四根线提供电源、地线和数据。幸运的是，线缆内部的线色是标准的。剪掉你想牺牲的 micro USB 线的末端，剥去橡胶、编织线和包裹四根独立导线的箔层。剥开以露出芯线。对 NES 板上的 USB 线做同样的处理：在我们的设备上，线缆绝缘之前线是可以触及的。将对应的线焊接在一起，并用电工胶带或热缩管单独绝缘。

## STEP-05
### 组装
我们用了一点 Blu Tack 将 Pi Zero 固定在底板的内部，同时仔细确保 micro USB 连接器已插入并且不会遮挡连接控制器各部分的螺丝或卡扣。然后我们小心地将其拧紧并检查连接器是否合适。剩下的就是把它插入电视和电源，确保整个系统正常工作。

## STEP-06
### 开始游戏
正如我们所说，我们的版本只是一个概念验证。然而，它却在 Pi Wars 上成功度过了长达六小时的小朋友对老游戏的激烈挫败，显然控制器和 Pi Zero 足够坚固，可以承受长时间的游戏会话。你需要拆卸设备才能接触到 SD 卡并加载或更改其上的 ROM。不过，你可能可以让它通过 WiFi 连接并通过 SSH 传输文件。
