# RASPBERRY PI ZERO

![](bbox=[0.0, 0.25, 0.72, 0.72])

![](bbox=[0.85, 0.03, 0.95, 0.08])

40-pin unpopulated GPIO port for connecting to your electronic circuits

Unpopulated RUN mode pins which can be used to add a reset button to the Pi Zero

Unpopulated RCA composite video out pins so you can connect to an old TV

A smaller camera connector port to connect a Pi Camera Module to

Power and activity LED – this lets you know the Pi Zero is on and working away

Micro-USB port for power – the same kind that charges Android mobile phones

Broadcom BCM 2835 system-on-a-chip, the same chip that powered the original Raspberry Pi

Micro USB port for connecting to keyboards, mice, WiFi, USB sticks, and more

65mm

# THE SPECS

+   - **CPU:** BCM 2835 (same as the original Raspberry Pi), 1GHz single core ARM11
+   - **RAM:** 512MB
+   - **Storage:** Via microSD
+   - **Power:** Micro-USB connector
+   - **Video out:** Mini-HDMI
+   - **Connectivity:** 1× micro-USB, unpopulated 40-pin GPIO connector, camera port, unpopulated Composite Video Out
+   - **Dimensions:** 65mm × 30mm × 5mm  **Weight:** 9g
