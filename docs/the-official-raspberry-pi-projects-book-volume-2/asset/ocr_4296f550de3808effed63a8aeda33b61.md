# >STEP-01

# Balancing act

Once turned on, the robot starts to balance itself to stay upright. Much like the Boston Dynamics robot, pushing it will cause it to right itself.

![](bbox=[0.56, 0.4, 0.93, 0.57])

# >STEP-02

# Remote control

The robot is not currently fully autonomous, so to control it you have to use a wireless keyboard connected to the Raspberry Pi. It will maintain balance as you drive it around, though.

![](bbox=[0.56, 0.68, 0.93, 0.83])

# >STEP-03

# I see you

The camera can detect faces. If one appears in its line of sight, the robot will look in the direction of the face and react to it with noises.
