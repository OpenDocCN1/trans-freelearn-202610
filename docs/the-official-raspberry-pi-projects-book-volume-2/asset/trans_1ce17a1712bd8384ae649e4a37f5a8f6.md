## 为 MotionEyeOS 添加推送通知

### 所需材料
- MotionEyeOS
  magpi.cc/1UCw1Jk
- Raspberry Pi 摄像头模块
- 适用于 iOS 或 Android 的 Pushover 应用，带完整许可（£3.99/$4.99）
  pushover.net

MotionEyeOS 非常适合将你的 Pi 用作 CCTV 摄像头。想在外出时检测移动吗？那就继续阅读吧…

MotionEyeOS 的一个优点是能够检测运动并捕捉触发它的图像和视频。你还可以在线访问摄像头的实时流，即使不在家时也很方便，如果你想偶尔查看一下的话。外出时，被通知任何移动情况非常有用，而 MotionEyeOS 提供了自定义通知的便捷选项。

本指南假设你已经设置并配置了 MotionEyeOS。需要 Pushover 许可，费用为 £3.99/$4.99。如需帮助，请查看此处的 MotionEyeOS wiki：magpi.cc/1UCvYwV。

### STEP-01
在 Pushover 中创建应用程序

Pushover 拥有一个很棒、易于使用的 API。在开始之前，我们需要在其上注册一个应用程序。在 Pushover 网站（pushover.net）上的“Your Applications”标题下点击 Register Application。为你的应用命名——比如 RaspiMotion——然后确保类型为 Application。为你的应用写一个简短的描述（例如“由我的 Raspberry Pi 发送的推送通知”），如果有创意，还可以上传一个自定义图标，该图标会在每次发送通知时显示在你的 Pushover 客户端应用中。

右侧 确保打开“Run A Command”，然后包含你的脚本路径！

![](img/d8322379620245fcd21eccc3855b8c78_107_2.png)

### STEP-02
获取你的 API 令牌和用户密钥

创建应用程序后，你应该可以访问 API 令牌/密钥。这是一串唯一的数字和字母组合——请务必保密！你还需要你的用户密钥，登录 Pushover 网站后即可看到。好的，现在你有了应用以及 API 和用户密钥。你现在需要下载（或自行重建）一个简单的 Python 脚本，以便在 MotionEyeOS 调用该脚本时让你的 Raspberry Pi 施展魔法。

### pushover.py
```
import httplib, urllib

conn = httplib.HTTPSConnection("api.pushover.net:443")
conn.request("POST", "/1/messages.json",
    urllib.urlencode({
        "token": "APP_TOKEN",          # Insert app token here
        "user": "USER_TOKEN",         # Insert user token here
        "html": "1",                  # 1 for HTML, 0 to disable
        "title": "Motion Detected!",  # Title of the message
        "message": "<b>Front Door</b> camera!", # Content of the message
        "url": "http://IP.ADD.RE.SS", # Link to be included in message
        "url_title": "View live stream", # Text for the link
        "sound": "siren",             # Define the sound played
    }), { "Content-type": "application/x-www-form-urlencoded" })
conn.getresponse()
```

### STEP-03
创建你的 Python 脚本

MotionEyeOS 不像 Raspbian。你不能像平常那样使用某些命令，例如 git clone，所以我们必须手动创建 Python 脚本；如果你喜欢，也可以使用 WinSCP 进行拖放。我们也不需要使用 sudo，因为默认情况下我们已以 root 身份登录。我们的脚本需要位于 data 文件夹中，所以让我们进入那里并使用 nano 创建 pushover.py：

```
cd /data
nano pushover.py
```

在这里，你需要复制粘贴或输入代码列表，同时在需要的地方填入你的 API 令牌和用户密钥。

### STEP-04
使脚本可执行

与任何脚本一样，我们需要确保它可以被执行，否则它只是一堆花哨的文本！你可以通过命令行或 WinSCP 来完成。从命令行，确保你在 data 文件夹中，然后输入：

```
chmod +x pushover.py
```

或者，如果使用 WinSCP，选择 data 文件夹中的 pushover.py 文件，然后按 F9。在出现的窗口中，将权限更改为 0755，然后点击“OK”确认。

### STEP-05
配置 MotionEyeOS 使用你的脚本

现在我们有了脚本，需要告诉 MotionEyeOS 在检测到运动时使用它。为此，登录到 Motion Notifications 菜单并打开“Run A Command”选项。然后你需要指定要运行的命令，这将是你刚刚创建的 Python 脚本——即 /data/pushover.py。完成后点击 Apply 以确认更改。

### STEP-06
测试一下！

希望到现在为止，你已经创建了 Python 脚本，使其可执行，告诉 MotionEyeOS 在检测到运动时使用你的脚本，并且已在你的智能手机或平板电脑上安装了 Pushover 应用。我们现在需要测试它是否有效！在摄像头前挥挥手（如果你精力充沛，也可以跳舞！），随后不久你应该会通过 Pushover 收到通知，警告你检测到运动！

## PI GLOWBE

## 由 Pi 驱动的唤醒灯

将地球仪变成发光球体，并利用它在黑暗的冬季月份帮助你醒来

冬季，或一年中的任何时间，早上起床都可能很困难。如果你黎明前醒来，你的身体仍然认为还是夜晚（因为确实是）。你可以购买唤醒灯，通过模拟人造日出欺骗身体醒来；它们会在闹钟临近时逐渐变亮。这些灯价格可能相当昂贵，所以为什么不使用 Pi 和一些 LED 自己制作一个呢？为了庆祝国际空间站上的 Astro Pis，我们用慈善商店里找到的地球仪制作了一个，里面装有 Sense HAT——也许是 unwanted Christmas present，现在被重新利用了！

### STEP-01
制作 LED 灯泡

通过将 LED 灯带缠绕在塑料瓶周围来制作灯泡。你可以跳过这一步，但 Sense HAT 不够亮，无法制作灯。剪掉空塑料瓶的顶部，用贴纸垫覆盖它，然后以螺旋方式缠绕 LED 灯带。你可以用胶带进一步固定末端。让连接端位于较宽的开口处，以便将电源线引向 Pi，然后再从中心引出。我们将在倒置的瓶口顶部安装 Pi，所以确保它平整。

### STEP-02
毁灭世界

通过将支架的插脚从北极和南极的孔中拉出，将地球从其支架上取下。接下来，沿赤道将其分成两半，拉开两个半球。它应该很容易拆开，只需在正确的位置施加一点力。你需要制作一个新的支架，防止地球仪滚动，同时仍允许电源线从底部孔中退出——你可以使用胶带卷的内侧。你可以用刀切一个小槽，让电线进入。

### STEP-03
安装在地球仪内部

将新的 LED 灯泡安装在地球仪内部。用 Blu-Tack 或腻子将瓶颈安装在下孔上；它应该足够坚固，可以支撑 Pi 放在其顶部。安装 Sense HAT 到 Pi 上，然后将两者放在倒置的瓶子上。给 Pi 连接一个 USB WiFi 适配器（除非你使用有线以太网），否则它会在错误的时间唤醒你。这是因为 Pi 需要互联网访问来设置时钟。

### STEP-04
布线供电

你可能需要剪断并重新连接电源线以使其穿过孔。官方 Pi 电源使用钟线，这使得用螺丝端子（choc block）重新连接变得容易。不幸的是，它提供的电力不足以在全亮度下使用 LED 并同时运行 Pi。剪断电缆并将供电端穿过孔。在电缆上打一个结，防止它被拉回。分离两端的两个电源芯并剥去绝缘层。用 choc block 重新连接，注意极性。

下载代码

### wakeup.py

语言
>PYTHON 2.7
下载:
magpi.cc/1TUKdz7

```
from BlinkyTape import BlinkyTape
from sense_hat import SenseHat
from time import sleep
import optparse

# Default Blinky Tape port on Raspberry Pi is /dev/ttyACM0
parser = optparse.OptionParser()
parser.add_option("-p", "--port", dest="portname",
                  help="serial port (ex: /dev/ttyACM0)",
                  default="/dev/ttyACM0")
(options, args) = parser.parse_args()

if options.portname is not None:
    port = options.portname
else:
    print "Usage: python wakeup.py -p <port name>"
    print "(ex.: python wakeup.py -p /dev/ttyACM0)"
    exit()

sense = SenseHat()
bt = BlinkyTape(port)

# wake phase - gradually get brighter, linearly
sleepTime = 18 # 18 sec for 30 min in 100 steps
maxPower = 100 # flickers or cuts out above 100

for y in xrange(maxPower):
    sense.clear(y * 2, y * 2, y * 2)
    for x in xrange(sleepTime):
        bt.displayColor(y, y, y)
        sleep(1)

# on phase - at full brightness for the same time
sense.clear(255, 255, 255)
for z in xrange(maxPower * sleepTime):
    bt.displayColor(maxPower, maxPower, maxPower)
    sleep(1)

# tidy up
sense.clear()
```

### STEP-06
设置你的日程

我们将使用 cron 运行代码。它应该在你起床前约半小时开始，并且可能只在工作日运行。通过在终端中输入以下内容启动 cron 配置：

```
crontab -e
```

接下来，通过在末尾添加以下行来设置它：

```
15 6 * * 1-5 python /home/pi/pi-glowbe/wakeup.py
```

这将在每个工作日 06:15 运行代码，所以根据你的需要更改它。保存文件并退出编辑器（在默认的 nano 中按 CTRL+X，Y，然后 ENTER）。满意后，重新组装所有东西，等待早晨！
