
## 腹部中弹

凭借这套令人毛骨悚然的互动服装，将惊吓带在身边

LUIS MARTIN
制作者、研发工程师、重伤受害者
bit.ly/1KNZWot

吓人的南瓜、门和房子是一回事，但一个好的吓人服装是万圣节的重要组成部分。虽然你无法超越吸血鬼、女巫和僵尸这些经典形象，但每年都会出现更多富有想象力且更恐怖的服装。Luis Martin 通过加入 Pi 和一些巧妙的编程，将他的服装提升到了新高度，使其看起来像是从《行尸走肉》中被直接射穿了腹部。

实际上这是一个相当简单而巧妙的设计。使用 Raspberry Pi 作为核心，Luis 采用了 Pi Camera Module 和 7 英寸屏幕，让摄像头的实时画面播放到屏幕上。通过将 Pi 和摄像头放在背部，他能够将实时画面传输到衬衫上显示的屏幕上，营造出腹部真的有一个洞的错觉。

确实很吓人——只是不要让他转身，否则会破坏效果。它不仅仅涉及电子产品：屏幕边缘还制作了乳胶边框，以模拟穿过衣服时肉体的恐怖外观，从而更好地营造效果。加上肤色油漆、血液和细节处理以达到理想效果，他还剪开了一件旧 T 恤并用假血染色。

> “你必须渴望弄脏自己的手，”Luis 告诉我们。“尤其是血。僵尸服装里的血越多，就越逼真！”

衬衫准备好后，Luis 拿了一个 GoPro 绑带，让它将屏幕固定在腹部，同时也用来将摄像头固定在他背部的正确位置以使幻觉生效。这随后只需通过 Raspberry Pi 上的 HDMI 端口连接到屏幕——打开电源，你就可以开始了！

这听起来确实很残忍，你会认为看到一个腹部有洞的僵尸走来走去会让每个人尖叫并逃跑。“每个人都想通过洞拍照，就像某种裹着血的自拍？”现在的孩子们，呵？你肚子上开个洞，他们甚至都不害怕。

## HALLOWEENPI AT 3

一项每年都会让你骨头发颤并帮助当地食品银行的传统

CHRIS, PATRICK AND ELISHE
分别是解决方案架构师、系统专家和艺术家，闹鬼数字的提供者
on.fb.me/10uScjv

吓唬上门的人似乎是鬼怪界的大生意。我们见过门廊、门口和怪物派对，它们至少会给出一些警告或试图营造恐怖氛围，但 HalloweenPi 更倾向于跳吓式惊吓，而不是营造悬念。

要理解 HalloweenPi，我们需要了解 Halloween at 3 的历史。3 Michelle Court 的人们每年都会举办一个传统，展示他们最恐怖的万圣节主题创意，以震撼也许吓到来 trick-or-treat 的孩子或路人。Chris Kyte 不断尝试通过增加展示内容来让每年都更好，于是有了一些灵感：

“我们正在考虑如何吸引更多 trick-or-treaters 来到我们的鬼屋。我们决定开始为当地食品银行收集罐头食品捐赠时，我想起了今年生日时收到的 Raspberry Pi B+。我开始思考是否可以建造一两个气动道具来‘提升我们的水平’。”

目前，这个巨大的隧道里摆放着一个实验室，里面有彩虹色混合物在烧杯和试管中，在黑光下反应，还有一个投射的木偶会称赞孩子们的服装，以及万圣节主题展示的其他装饰。这个新增加的部分将附带一个运动控制器道具，当人们到达 Halloween at 3 时，它会弹起并吓唬他们。

“HalloweenPi 控制的气动道具将是一个非常令人毛骨悚然的装置，”Chris 说。“它将作为鬼屋的大使，对经过的人做出反应：道具会张开翅膀并发出巨大的尖叫！我们设计的道具和气动装置是模块化的。它们每年不必保持相同！”

惊吓是为了一个好目的，因为 Halloween at 3 为当地食品银行募集捐款。“气动道具带来的额外兴奋应该会让来的人数大幅增加。希望我们也能看到食品捐赠的增加。”

我们质疑在如此美好的结果下，这样一项事业如何在万圣节精神中真正邪恶，但这次我们就放过它吧。

## MULDER

登载于本刊，这具阴森的骷髅活了过来

MIKE COOK
作家、骨头巫师
magpi.cc/1NqJnTz

僵尸头？肉太多。认识一下 Mulder 这具骷髅，这是一个非常互动的头部，你可以控制它来吓得任何路过的人魂飞魄散。完全控制他的下颌、颈部和眼睛，它可以移动来观察任何人。不仅如此，你还可以让它发出多种颜色的光，并发出致命的尖叫或令人毛骨悚然的猫头鹰叫声。

Mulder 由 Mike Cook 在 Pi Bakery 的一部分制作，并在《The MagPi》第 38 期中作为一个项目刊登——前往 magpi.cc 开始制作。

我们不会剧透，但它涉及大量焊接和调整，因为你需要安装多个舵机和电机来操纵眼睛和下颌，以及多个灯、扬声器系统和控制颈部的方式。所有这些都由用 Python 编写的界面控制，其代码列表和文件可在教程中找到。

我们建议你在骷髅附近放置一个隐藏摄像头，以便跟踪 trick-or-treaters 靠近你家门时。肯定会把他们吓跑，留下更多巧克力给你。

## 资源与灵感

不确定万圣节用 Raspberry Pi 做什么？十月期间，所有科技新闻网站都会充斥着万圣节主题的故事，所以留意它们。否则，你可以前往 Adafruit Learning System 的 Raspberry Pi 标签（bit.ly/1iroRHO），在那里你可以获得许多项目灵感，以及 element14 社区博客和 Raspberry Pi 基金会的博客。获得灵感，变得阴森！
