## 构建项目

这是一个相当直接的项目来构建。无需焊接，不过如果你有烙铁，给传感器引线上的导线末端镀锡使其变粗一些，会更容易将其固定在端子块中。

![](img/d8322379620245fcd21eccc3855b8c78_130_1.png)

> DS18B20 是一款数字设备，精度为 ±0.5 摄氏度

如所需组件清单所示，本项目不需要任何焊接。温度探头的引线通过电气端子块和母对公跳线组合连接到 Raspberry Pi 的 GPIO 引脚。你可在任何销售电气用品的 DIY 或五金店找到螺钉端子块。

## DS18B20 温度传感器

DS18B20 是一款温度传感器芯片，有标准的三针类似晶体管的封装，或内置于带长引线的封装传感器中。在本项目中我们选择了封装版本，但你也可以在面包板上使用三针封装版本。该芯片需要在其数据引脚和正电源引脚之间连接一个 4.7kΩ 电阻。芯片本身可使用 5V 或 3.3V 逻辑，但在使用 Raspberry Pi 时必须将正电源连接到 3.3V，以防止损坏所连接的 Pi GPIO 引脚。温度传感器通常相当不准确，但 DS18B20 是一款数字设备，精度为 ±0.5 摄氏度。该 IC 使用 Raspberry Pi 上的单个 GPIO 引脚，采用称为 1-wire 的接口。温度读数以串行数据发送到 Raspberry Pi。

## 构建你的管道监控器

与所有项目一样，在零件都放在工作台上时先进行测试并确保一切正常是个好主意。一旦确认一切正常，你就可以将项目安装到其外壳中。

### >STEP-01 连接母头引线

将温度探头上的红色（正电源）、黑色（接地）和黄色（数据）导线插入螺钉端子，电阻的引脚置于红色和黄色导线之间。在拧紧螺钉端子之前，将导线的裸露末端缠绕在电阻引脚上可能会有所帮助。将跳线的公端插入端子块的另一半。你的探头引线可能还带有连接到引线屏蔽层的单独裸线连接器；你无需将其连接到任何东西。

![](img/d8322379620245fcd21eccc3855b8c78_130_2.png)

### >STEP-02 连接温度传感器

将正电源引线连接到 3.3V GPIO 引脚，传感器的黑色接地引线连接到 GPIO 排针上的其中一个 GND 引脚，数据引线连接到 GPIO 4。使用 Raspberry Leaf 等 GPIO 引脚模板可以更轻松地找到正确的引脚。我们使用了一个可容纳螺钉端子和 Raspberry Pi 的食品容器，并在其上钻了 USB 电源和传感器引线的孔。传感器引线上的结是为了防止连接被拉脱，而电工胶带则防止电阻引脚意外短路 GPIO 引脚上的任何东西。

![](img/d8322379620245fcd21eccc3855b8c78_131_0.png)

如果任何人都可以触发 IFTTT 发送邮件，可能会发生坏事。因此，当从 Python 发送网络请求以触发邮件时，必须附带一个密钥。

要找到该密钥，请点击 IFTTT 网页顶部“频道”标签，然后找到 Maker 频道。过一会儿，你需要将密钥粘贴到你的 Python 程序中。

这类项目你绝对希望使用 SSH，以便使用 WiFi USB 适配器远程连接到 Raspberry Pi。你可以在官方网站找到设置 Pi 使用 SSH 的说明：magpi.cc/1GULmTr。

在使用 DS18B20 温度传感器之前，你需要启用 Raspberry Pi 的 1-wire 接口。要启用 1-wire，请使用以下命令编辑文件 /boot/config.txt：

```

```

在文件末尾添加以下行：

```

```

现在重启你的 Raspberry Pi，1-wire 应该已启用。

你可以使用以下命令从 Raspberry Pi 命令行下载本项目的程序：

在运行程序之前，使用 nano 编辑器打开它并更改以下行：

将其更改为之前找到的 IFTTT 密钥。使用以下命令以超级用户身份运行程序：

运行程序时，你应该在终端中看到“Monitoring”消息，之后温度读数应开始出现。

## 代码如何工作

本程序的 Python 代码已添加注释。在我们讲解时，将代码打开在编辑器中可能会很有帮助。

程序首先导入所需的库：

glob 用于查找温度传感器的设备文件，因为程序需要使用通配符匹配，因为每个 DS18B20 在制造时都会被赋予不同的设备 ID；time 用于延时；urllib 和 urllib2 用于向 IFTTT 发送网络请求。

你可能想要更改接下来的常量，尤其是在测试系统时。变量 ALARM_TEMP 设置触发警报的温度，因此将其设置为程序在终端中报告的温度低几度，然后去拿一杯冷水进行测试。

常量 MIN_T_BETWEEN_WARNINGS 防止消息发送频率超过每小时一次。在测试项目时，你可能想要更改它。

下一组变量用于标识特定温度传感器文件的位置。这将在文件夹 /sys/bus/w1/devices/ 中，但此后的文件夹名称对每个 DS18B20 都是不同的。

函数 read_temp 读取设备文件的内容。这将是来自温度传感器的两行消息，看起来像这样：

```
28 01 4b 46 7f ff 08 10 4c : crc=4c YES,
28 01 4b 46 7f ff 08 10 4c t=18500
```

两行开头的数字是 DS18B20 的唯一 ID，如果读取成功，第一行以 YES 结尾，温度在第二行末尾报告为摄氏度的千分之一。在本例中，即 18.5°C。函数 read_temp 从消息中提取温度值并返回它。

send_notification 函数为 IFTTT Web 服务构造一个 URL，并在请求正文中提供温度。

主循环反复读取温度，以检查其是否已降至足以触发警报的水平。如果是，则调用 send_notification，然后延迟直到 MIN_T_BETWEEN_WARNINGS 分钟过去。

## 使用你的管道监控器

在安装之前测试项目时，将 ALARM_TEMP 设置为比环境温度低几度，然后将传感器放入一些冷水中。经过几分钟，温度读数将开始下降，直到你收到一条消息：

TEMPERATURE WARNING
Congratulations! You’ve fired the pipe_alert event

如果你去检查你的电子邮件收件箱，你应该会看到一条通知消息。

即使是节能的 Raspberry Pi 也会产生足够的热量，导致温度读数产生误导。为避免这种情况，请确保 DS18B20 远离 Raspberry Pi 本身，最好靠近甚至贴在你试图保护的管道上。当然你还需要一个地方连接电源适配器，并确保你的阁楼空间在 WiFi 路由器的范围内。

这是一个适合其他任务的项目。你可以修改它以定期报告温度，或检查温度过高而不是过低。你还可以从 IFTTT 中选择其他操作，例如发推文或发送 Facebook 更新。

## Pipes.py

语言
>PYTHON

```
import glob
import time
import urllib, urllib2

ALARM_TEMP = 5.0 # degrees C
MIN_T_BETWEEN_WARNINGS = 60 # Minutes
EVENT = 'pipe_alert'
BASE_URL = 'https://maker.ifttt.com/trigger/'
KEY = 'cyR3vPNF1P9K32W4NZ B9cd'  # Place your own key here

# These constants used by the 1-wire device
base_dir = '/sys/bus/w1/devices/'
device_folder = glob.glob(base_dir + '28*')[0]
device_file = device_folder + '/w1_slave'

# Read the temperature message from the device file
def read_temp_raw():
    f = open(device_file, 'r')
    lines = f.readlines()
    f.close()
    return lines

# Split the actual temperature out of the message
def read_temp():
    lines = read_temp_raw()
    while lines[0].strip()[-3:] != 'YES':
        time.sleep(0.2)
        lines = read_temp_raw()
    equals_pos = lines[1].find('t=')
    if equals_pos != -1:
        temp_string = lines[1][equals_pos+2:]
        temp_c = float(temp_string) / 1000.0
        return temp_c

# Send an IFTTT pipe_alert event
def send_notification(temp):
    print("TEMPERATURE WARNING")
    data = urllib.urlencode({'value1' : str(temp)})
    url = BASE_URL + EVENT + '/with/key/' + KEY
    response = urllib2.urlopen(url=url, data=data)
    print(response.read())

print("Monitoring")
while True:
    temp = read_temp()
    print(temp)
    if temp < ALARM_TEMP:
        send_notification(temp)
        time.sleep(MIN_T_BETWEEN_WARNINGS * 60)
```
