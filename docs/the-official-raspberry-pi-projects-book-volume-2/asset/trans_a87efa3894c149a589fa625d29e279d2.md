## TWEET FROM YOUR RASPBERRY PI WITH THE WOLFRAM LANGUAGE

Dana Flinn 和 Brett Haines 将带你了解如何使用 SendMessage 函数在 Wolfram 语言中轻松发送推文

Wolfram 语言是一种功能强大的基于知识的语言，让计算变得人人可及，也是初学者入门编程时容易上手的一门语言。要在 Raspberry Pi 上从 Twitter 发送推文，你只需要一个函数。我们将使用 SendMessage，它是 Wolfram 语言中的一个多用途函数，可让 Raspberry Pi 用户无缝地从设备上发推。

使用 SendMessage 函数，我们将带你了解如何应用符号语言并使用 Raspberry Pi 发送推文。不过别局限于仅用此函数发推！SendMessage 还可用于生成电子邮件、更新 Facebook 或 LinkedIn 状态，以及生成蜂鸣声。

### >STEP-01

### 准备语法

首先，你需要在 Raspberry Pi 上启动 Mathematica 并打开一个空白笔记本。Wolfram 语言内置了超过 5,000 个函数，初看可能会让人望而生畏。然而，使用文档中心可以轻松找到适合项目的正确函数。

在 Wolfram 语言中，所有函数都使用方括号，并且名称以大写字母开头。本项目所需的函数是 SendMessage，相当直接。它用于向指定频道发送消息，在我们这里是 Twitter。

### PYTHON VS WOLFRAM

与 Python 相比，Wolfram 提供了更轻松的 Twitter 访问方式，因此根据你的需求，Wolfram 可能已足够。

### >STEP-02

### 设置你的代码

要设置代码，请在 Pi 上打开 Mathematica 并输入 SendMessage 函数，然后输入你想要推文的内容。因此，根据文档中心，我们知道它应设置如下：

```
SendMessage["Twitter", "Tweet text"]
```

其中写着“Tweet text”的地方，文本可以更改为你希望发布到 Twitter 账户的任何内容。

### >STEP-03

### 评估你的代码

输入后，按 SHIFT+ENTER。这将在 Mathematica 中运行你的代码，并提示授权对话框以允许 Wolfram 语言代表你发送推文。授权后，推文将被发送到你的账户。输入访问密钥后选择“Done”，推文就会出现在你的 Twitter 动态中。

### >STEP-04

### 创建变量

之前的示例展示了发送静态字符串的推文。然而，这远非 Wolfram 语言所能实现的一切。就像其他编程语言一样，它允许用户设置变量，我们可以在其中存储任何内容。要创建变量，只需输入你想要的名称、等号，然后是你想要赋给变量的内容，如下所示：

```
myVariable = "Some string here!"
```

与许多其他编程语言不同，你无需指定变量中存储的数据类型——Wolfram 语言足够智能，可以自行判断它是什么以及如何使用！

### >STEP-05

### 使用 StringJoin

你可以使用 StringJoin 函数合并字符串。就像 SendMessage 一样，StringJoin 是通过将要连接的字符串放在方括号（[ 和 ]）之间，以逗号分隔来使用的。因此，要连接“Hello ”和“world”，你需要输入：

```
StringJoin["Hello ", "world"]
```

这不仅限于静态字符串——变量也可以与字符串连接，如下所示：

```
StringJoin["Hello ", myVariable]
```

### >STEP-06

### 将其全部组合

现在是时候把所有东西组合起来了。我们可以取一个变量，为其存储一个字符串，将其与另一个字符串连接，然后发送到 Twitter：

```
myName = "WolframLanguage"
SendMessage["Twitter", StringJoin["This tweet brought to you by ", myName]]
```

现在你知道了 Wolfram 语言中函数的工作原理，很容易深入文档并探索内置的数千个函数。现在出发去编码吧！

## TIME-LAPSE PHOTOGRAPHY

Photo by NASA JSC

制作一个设备以定期间隔拍摄照片。然后将这些图像合成为视频

### You'll Need
- Raspberry Pi 相机模块
- magpi.cc/1UaFuuW

延时摄影揭示了你 otherwise 看不到的有趣事物。那些发生得太慢以至于我们无法察觉的事情：面包发酵和植物生长；云、太阳、月亮和星星穿越天空；影子在土地上移动。在本教程中，我们将制作一个基于 Raspberry 的设备，让你观察肉眼无法观察到的缓慢事物。为此，我们将拍摄大量静态照片，并使用 FFmpeg/libav 将这些帧合成视频，然后可通过 Web 浏览器访问。

摄像头的顶部位于排线连接的另一端

排线上的金属触点应背向以太网插槽

![](img/d8322379620245fcd21eccc3855b8c78_105_2.png)

### >STEP-01

### 连接相机模块

首先，使用附带的排线将相机模块连接到 Raspberry Pi。找到正确的插槽；它位于 Raspberry Pi 电路板的顶部，是离 micro-USB 电源连接器最远的一个。在较新的 Raspberry Pi 型号上，插槽方便地标有“CAMERA”。抬起插槽外部以释放夹具，然后插入排线，使金属触点朝向 micro-USB 电源连接器。最后，将排线保持在位置并将插槽外部推回以夹紧电缆。

### >STEP-02

### 启用并测试相机

为 Raspberry Pi 通电。现在你有选择：启动到命令行、打开终端窗口或建立安全 shell（SSH）连接。通过从终端运行以下命令启动 Raspberry Pi 配置工具来启用相机：

```
sudo raspi-config
```

然后选择“Enable Camera”选项。你可以通过运行以下命令来测试相机：

```
raspistill -o testimage.jpg
```

相机模块上的红色 LED 应亮起 5 秒钟，并且 JPEG 图像将保存到当前目录。如果相机倒置安装，则可以使用垂直和水平翻转命令行开关（-vf 和 -hf）。

### >STEP-03

### 安装和配置软件

安装 Web 服务器以远程访问你的图像。运行以下命令安装 Apache：

```
sudo apt-get install apache2
```

删除默认页面以查看目录内容：

```
sudo rm /var/www/index.html
```

访问你的 Pi 的 IP 地址（例如 http://192.168.1.45 – 你可以使用 ifconfig 找到它），你应该会看到一个空的目录列表。如果你运行以下命令并刷新页面，你应该会看到一个图像文件列出。你以超级用户身份运行此命令，以便可以写入目录。

```
sudo raspistill -o /var/www/testimage.jpg
```

点击文件链接，你将在浏览器中看到图像。

### >STEP-04

### 捕获图像

设置你的场景并检查相机的定位。

```
sudo raspistill -w 1920 -h 1080 -o /var/www/testimageFullHD.jpg
```

宽度和高度已更改为以 16:9 宽高比捕获较小的图像。这使后续操作更简单。顶部和底部会被裁剪，因此请确保你的主体在画面中。运行以下命令开始捕获：

```
sudo raspistill -w 1920 -h 1080 -t 10800000 -tl 10000 -o /var/www/frame%04d.jpg &
```

这每十秒（10,000 毫秒）拍摄一张照片，持续三小时（10,800,000 毫秒）。末尾的与号（&）在后台运行该进程。

### >STEP-05

### 准备制作视频

你可以在 Raspberry Pi 上渲染视频，但会非常慢。更好的方法是将文件传输到更强大的计算机。无论如何，你需要在渲染机器上安装工具；对于 Pi，输入：

```
sudo apt-get install libav-tools
```

这安装了 FFmpeg 的一个分支，但你也可以使用原始的 FFmpeg。要将图像复制到远程机器，你可以使用 wget 或 curl 从 Web 服务器下载它们。例如：

```
wget -r -A jpg http://192.168.1.45
```

Or if you don’t have wget...

```
curl http://192.168.1.45/frame[0001-0766].jpg -O
```

相应地更改 IP 地址和数字。

### >STEP-06

### 制作视频

最后一步是制作视频。运行以下命令开始渲染进程：

```
sudo avconv -i /var/www/frame%04d.jpg -crf 4 -b:v 10M /var/www/video.webm &
```

完成后，你可以在浏览器中查看视频。默认帧率为 25fps。这将以十秒间隔的三小时帧压缩为约四十秒的视频。你可以使用 -framerate 命令行选项调整此设置。比特率（-b）已设置为高，常数速率因子（-crf）设置为低，以生成高质量视频。

### MAKE AN ANIMATED GIF

不要使用视频，使用 ImageMagick 制作动画 GIF。使用较小的图像，并以较少的频率捕获。

sudo convert /var/www/frame*.jpg /var/www/anim.gif &
