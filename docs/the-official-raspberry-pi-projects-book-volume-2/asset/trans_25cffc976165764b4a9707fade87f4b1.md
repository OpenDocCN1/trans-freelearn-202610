## >STEP-03
### 准备艺术作品

Sense HAT 只能显示 64 个像素，我们的代码假设你拥有的图像正好是这个大小。在普通电脑上，使用图像编辑器（如免费软件 GIMP）来准备图像。通过裁剪图像去除任何边框（你可能需要放大以确保），并将其保存为你能记住的文件名，扩展名为 .png 或 .gif。如果你的 8×8 艺术作品实际上并未以 8×8 图像保存，这一点尤其重要；例如，如果艺术作品中的每个“像素”宽六个像素，就像我们的代码中那样。

## >STEP-04
### 研究像素艺术

如上所述，你的像素艺术可能并非按像素实际保存。我们创建的代码已考虑到这一点。检查像素宽度的最简单方法是查看图像的分辨率。在我们的例子中，它是 48×48，这意味着每个“像素”是六个真实像素宽（并且高，因为它是正方形）。你可以在 GIMP 中通过使用正方形像素画笔并增加大小，直到与图像中的像素相同来检查这一点。或者，在裁剪图像后，你可以将图像缩放到 8×8；不过这样可能得不到理想的结果，因为它会试图把所有内容挤在一起。

## >STEP-05
### 将其全部加载到 Raspberry Pi 上

将图像放到 Raspberry Pi 上并在图像查看器中打开，以确保传输正常。我们是通过将 SD 卡直接插入准备图像的电脑并将其复制到主文件夹中名为“SenseHAT”的目录来完成的，但你也可以将其放在 USB 闪存盘上并从 Pi 中复制，或上传到云存储然后下载到 Pi。

## >STEP-06
### 编写代码！

按照代码列表进行操作并根据自己的像素艺术进行调整，这可能意味着你需要在代码中更改文件的位置（我们的代码假设你将其放在 Raspbian 主目录下的名为“SenseHAT”的文件夹中），或需要将每个像素的宽度更改为 1 或更高。按 F5 运行代码，它将随后在 Sense HAT 上显示图像三秒钟，然后自行关闭。

## Pixelart.py

```
from sense_hat import SenseHat
import time
from PIL import Image
import os

# Open image file
image_file = os.path.join(
os.sep, "/home", "pi", "SenseHAT", "pixelart.png")
img = Image.open(image_file)

# Generate rgb values for image pixels
rgb_img = img.convert('RGB')
image_pixels = list(rgb_img.getdata())

# Get the 64 pixels you need
pixel_width = 6
image_width = pixel_width*8
sense_pixels = []
start_pixel = 0
while start_pixel < (image_width*64):
    sense_pixels.extend(image_pixels[start_pixel:(
start_pixel+image_width):pixel_width])
    start_pixel += (image_width*pixel_width)

# Display the image
sense = SenseHat()
sense.set_rotation(r=180)
sense.set_pixels(sense_pixels)
time.sleep(3)

sense.clear()
```

## 使用 GPIO ZERO 的 Traffic HAT

作为 GPIO Zero 支持的板子之一，Traffic HAT 是展示该库的完美方式...

## 所需材料
- Traffic HAT
  magpi.cc/1Mma7oD
- GPIO Zero
  magpi.cc/1MmaJnP
- 焊接烙铁（可选）

Traffic HAT 是一个很棒的小套件：一个安装在 GPIO 上的 Raspberry Pi 扩展板，使学习物理计算编程变得稍微容易一些也更有趣，同时还有大号组件可以帮助你学习焊接的基础知识。
随着 GPIO Zero 的发布，Traffic HAT 现在比以往任何时候都更容易编程，无论你想手动使用它还是利用内置于 GPIO Zero 中的便捷 Traffic HAT 功能。跟随我们学习如何充分利用 HAT 和 GPIO Zero。

你将使用的主要功能是：三个 LED、一个推按钮开关和一个蜂鸣器。
请务必按照板上的轮廓指南放置它们。蜂鸣器的正极侧在组件上标明，板上也有指南显示应将其安装在哪一侧。LED 应焊接，使灯泡的平面边缘与轮廓的平面边缘相遇。

```
from gpiozero import TrafficHat
from time import sleep

th = TrafficHat()

try:
    while True:
        # Traffic light code
        # First, turn the green LED on
        th.lights.green.on()
        print "Press the button to stop the lights!"
        # Next, we want to wait until the button is pressed
        while(th.button.is_pressed == False):
            #While not pressed do nothing
            pass
        # Button has been pressed!
        th.lights.green.off()
        # Amber on for a couple of seconds
        th.lights.amber.on()
        sleep(2)
        th.lights.amber.off()
        # Turn the red on
        th.lights.red.on()
        # Buzz the buzzer 20 times with 0.1 second intervals
        th.buzzer.blink(0.1,0.1,20,False)
        sleep(1)
        th.lights.red.off()
        # Red off and blink amber 4 times with 0.5 second intervals
        th.lights.amber.blink(0.5,0.5,4,False)
except KeyboardInterrupt:
    exit()
```

## >STEP-06
### 灯光时序

按钮被按下后代码的那部分乍一看可能有点复杂，但仔细检查后应该相当直接。它模拟了斑马线交通灯的工作方式，在提供稳定的红灯之前先激活琥珀灯几秒钟。

当红灯出现时，蜂鸣器会鸣响几秒钟，然后红灯关闭，琥珀灯出现，这次会闪烁，然后恢复为绿色。此时，while 循环重新开始，等待按钮提示。
