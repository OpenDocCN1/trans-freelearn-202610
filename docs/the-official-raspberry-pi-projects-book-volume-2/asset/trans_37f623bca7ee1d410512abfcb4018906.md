## 02 电子轮椅

![](img/d8322379620245fcd21eccc3855b8c78_22_3.png)

### PHIL CASE

Phil Case 是一位英国创客，因事故受伤导致颈椎 C 段受损而致残。
magpi.cc/1lU6z6f

E-Wheelchair 整合了 Cooking Hacks E-Health v2 传感器来监测重要身体参数（cooking-hacks.com）。E-Health v2 和传感器附件使 Raspberry Pi 能够监测身体指标，例如血糖。

一位使用 E-Health 传感器的 Raspberry Pi 项目创作者是来自普雷斯顿的 Phil Case，他的终身目标是打造一辆价格实惠的智能轮椅。Phil 的‘E-wheelchair’由大脑控制，使用 Neurosky MindWave Mobile 和 Mindflex EEG 产品来测量使用者的脑电活动。E-Health 系统用于监测心电图水平和血糖，他计划实现身体位置传感器。
Phil 正在为他的智能轮椅项目筹集资金，2016 年想做慈善的人可以在 GoFundMe 上找到相关页面（gofundme.com/hfymdo）。

> 这里有一些世界上最酷的项目，助你迎接新年

如果你想更认真地监测健康，Cooking Hacks 的 E-Health v2 传感器值得研究。它使你能够将九个传感器连接到 Pi 上，以测量血压、氧气水平、气流、体温和血糖水平，以及心电图和肌电图结果。

### ALEX PINE

Alex Pine 是来自南澳大利亚阿德莱德的 IT 服务工程师。他的项目已被观看超过 800,000 次。 magpi.cc/1Y94RtZ

这个流行的项目将旧 HDMI 显示器变成壁挂式显示屏，显示 Google 日历的信息。Raspberry Pi 放置在显示器的背面，并用支架安装在墙上。

来自邮件过载。Raspberry Pi LED 的明亮灯光提醒你收件箱中有需要处理的电子邮件。这是一个超级简单的项目——只有一个 LED 和大约十行代码——但一旦配置好，它会逼迫你清理电子邮件账户。

最后，如果你真的需要组织帮助，为什么不把你的 Raspberry Pi 变成语音激活的数字助理呢？我们喜欢 Jan Wante 的 Raspberry Personal Assistant。他把 1950 年代的

Bakelite Televox 对讲机变成了一个语音控制的数字助理（想象一下 Siri 在旧美国收音机内部）。内部是带有 USB 音频声卡的 Raspberry Pi，运行 Steven Hickson 的 Voice Command 软件（magpi.cc/1Y95Pqc）。
