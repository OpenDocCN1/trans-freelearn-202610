### 探索5G赋能的智能工厂（工业4.0）

智能工厂是一种智能化工厂，其特点是生产或制造结构中的互联性和数字化，这依赖于连接到互联网的机械设备的使用。数据存储在云端，用于监控和控制生产或制造过程。存储的数据还用于做出决策并解决可能出现的问题。

工业4.0是当前制造业的趋势，它将计算、网络和物理过程集成（信息物理系统）、自动化以及物联网（IoT）相结合，以创建智能工厂。在智能工厂中，机器通过智能传感器和其他智能设备连接到云端。智能工厂将虚拟世界与物理世界融为一体。

工业4.0是工业革命的新阶段，它以更低的成本提高产量和效率。由于智能工厂的诸多好处，许多行业现在正考虑升级或转向智能工厂，我们将在本章中探讨这些好处。智能工厂可以被视为工业自动化的进步，它允许工厂中的自动化机器或设备通过互联网在世界任何地方进行控制和监控。工业4.0由数据和其他关键技术驱动，我们也将在本章中探讨这些内容。

#### 理解工业4.0

为了更好地理解工业4.0，我们需要了解工业革命。

工业革命指的是工业或制造过程随着新的创新技术而发生的转变和变化。

让我们简要回顾一下工业革命及其转变的历史：

- **第一次工业革命（工业1.0）**大约始于1784年。这一时期，机器在工业中得到使用，并以蒸汽为动力。
- **第二次工业革命（工业2.0）**大约始于1870年。这一时期，电力被引入为工业机器提供动力。大规模生产过程也在第二次工业革命中发挥作用。由人工操作的装配线被用于大规模生产。
- **第三次工业革命（工业3.0）**大约始于1969年。在这场革命中，自动化被引入工业过程。正是在这场革命期间，工业过程开始使用传感器、执行器、控制器和机器人，使生产或工业过程几乎不需要人工参与。本书重点介绍自动化在工业中的使用和实施。

**第四次工业革命（工业4.0）**大约于2011年引入。这是工业革命的新阶段。在这个阶段，工业机器连接到互联网。这些机器可以思考、做出决策，并在几乎不需要人工干预的情况下通过互联网相互通信。您可以通过互联网从世界任何地方访问任何机器。

工业4.0借助信息和通信技术实现机器和工业过程的智能联网。机器、计算机和其他设备相互连接并通信，在几乎不需要人工干预的情况下就工业或生产过程做出决策。它融合了物联网、云计算、大数据和其他技术。

工业4.0通过由物联网、人工智能、云计算以及与工业4.0相关的其他技术驱动的智能和自主系统，增强了工业3.0中已开始的内容（自动化机器和计算机的使用）。这些将在下一节中解释。

#### 探索工业4.0的关键技术

工业4.0以更先进的方式实施各种现有技术。工业4.0的关键技术如下：

**物联网（IoT）**：这指的是一个由物理对象或设备组成的网络，这些对象或设备借助传感器收集数据，并通过互联网相互通信。在制造业或其他生产行业中，物联网是一种允许现场设备（传感器和执行器）在几乎不需要人工干预的情况下相互通信的技术。这被称为**工业物联网（IIoT）**。IIoT是工业4.0的一个组成部分。它使制造商能够监控设备的状态、性能和健康状况，安排


预测性维护，或进行远程故障排除并提高运营安全性和安全性。

- **机器人技术**：机器人是经过编程的机器，可以在很少或没有人工干预的情况下执行一系列任务。它们可以根据输入做出决策并自主执行特定任务。机器人是工业 4.0 中的重要组成部分。
- **人工智能（AI）**：这是一种技术或计算机程序，使计算机或机器人能够执行通常由人类完成的任务。有了 AI，机器现在可以学习、思考并像人类一样行动。请注意，目前还没有任何程序能与人类在灵活性和在各个领域运作的能力相匹配。然而，有些程序可以使机器在某些特定领域像人类专家一样工作和运作。

机器现在可以从过去的经验中学习，并像人类一样进行推理和规划，这使它们能够执行复杂任务。AI 关注的是智能机器的开发，这些机器通常需要人类智能。AI 需要机器学习、数据分析和更多功能才能运行。机器学习是一种用于训练计算机或机器从其输入中学习的方法，而无需为每种情况显式编程。

数据分析是分析原始数据以获得有意义的信息或得出结论的科学。数据分析有助于使数据变得有意义。从数据分析中获得的信息可用于优化流程并提高效率。在制造或生产行业中，可以分析各种机器的运行时间、停机时间和作业队列，并用于规划机器的工作负载以有效运行。

当机器人技术与 AI 相结合时，我们称之为智能机器人——即能够像人类一样表现或模仿人类行为的编程机器，例如学习、推理、规划、解决问题等。

- **云计算**：这涉及将数据存储在互联网上，并在需要时访问存储的数据。来自各种设备的数据存储在远程服务器中，以便在需要时可通过互联网从世界任何地方访问。
- **网络安全**：这是一种技术或实践，涉及防御网络中数据、服务器、计算机和其他设备免受恶意攻击。
- **增强现实和虚拟现实**：**增强现实（AR）** 是一种通过实时将真实世界视图与计算机生成的元素相结合来提供交互式 3D 体验的技术。它可以采用护目镜的形式（即 AR 护目镜），也可以是平板电脑或智能手机，利用相应设备的摄像头看到观众面前的真实世界，并通过在上面叠加计算机生成的元素来操纵它。AR 可以实时解释、操纵和增强真实世界的视图。它允许你以有意义的方式与真实世界互动。它可以即时为佩戴 AR 头显的维护工程师提供有用的信息。**虚拟现实（VR）** 另一方面，是一种将用户置于 3D 计算机生成环境/元素中的技术。用户可以在其中移动并与这些计算机生成的 3D 元素互动。VR 在头显内创建一个完整的虚拟世界或计算机环境。佩戴 VR 头显的工程师、设计师或客户可以在无需制作原型的情况下，在不同照明条件下在设施或产品周围移动并查看它。

我们将在下一节中了解工业 4.0 的好处。

#### 工业 4.0 的好处

工业 4.0 带来各种好处：

- **提高生产率**：工业 4.0 提高了生产率，因为可以更快地生产更多产品。工业 4.0 减少了停机时间，从而提高了产量。
- **提高效率**：由于工业 4.0 减少了停机时间，因此可以更快地生产更多产品。
- **灵活性**：工业 4.0 使您的行业或制造过程具有灵活性，因为您可以轻松地扩大或缩小生产规模。向生产线引入新产品也很容易。
- **成本降低**：工业 4.0 由于自动化、物联网和其他已集成到制造流程中的技术而降低了生产或制造成本。然而，在设置阶段您需要投入一定资金。
- **增加收入**：工业 4.0 由于自动化和其他已实施的工业 4.0 技术而增加了收入。在许多情况下，完成任务所需的员工更少。
- **员工安全**：工业 4.0 带来员工安全，因为生产线上使用的机器需要很少或不需要人工干预，并且可以通过互联网远程操作。

#### 建立智能工厂的基本步骤

以下几点有助于开发智能工厂：

- **了解您的需求并定义您的目标**：就像任何其他投资一样，您必须首先确定您想要建立智能工厂的原因，定义目标并对其进行优先排序。智能工厂通常分阶段创建。了解您的需求和目标并对其进行优先排序将帮助您在每个阶段的正确时间投资正确的设备或工具。
- **从最有益的领域开始**：您不必一次开始改造设施的所有区域。您可以将智能工厂实施作为一个循序渐进的过程。
- **培训人员掌握新技术：** 智能工厂涉及新技术，您现有的员工可能不熟悉。让员工掌握使用智能工厂所需的新设备和设备所需的技能非常重要。
- **聘请熟练的劳动力：** 除了培训现有员工掌握智能工厂中的新技术外，您可能还需要引进熟练的劳动力。例如，数据分析师将帮助将工厂数据转化为可用的数据，有助于规划和做出有意义的决策。智能工厂所需的其他熟练劳动力包括具有网络和网络安全技能的 IT 专家、具有机器人基本操作和编程良好理解的机器人专家、PLC 程序员、HMI 程序员等。
- **防范网络攻击：** 智能工厂将设备和装置连接到云端。您的工厂容易受到网络罪犯的网络攻击，而网络攻击正在增加。采取必要的预防措施保护您的数据和设备免受网络攻击。
- **投资新设备和工具：** 需要新设备来促进智能工厂。例如，需要智能传感器和其他智能设备来帮助将机器数据传输到云端。还需要计算机和软件来有效存储、分析和管理数据。
- **不断更新您的智能工厂实施：** 您不太可能一次在设施的所有区域完全实施智能工厂。您需要在一个区域完成后，通过扩展到设施的其他区域来不断更新智能工厂的实施。
- **建立良好的无线连接：** 无线连接是建立智能工厂的关键。良好的无线网络，例如 5G，将实现快速可靠的数据交换，使依赖互联网连接的智能工厂成为现实。

在下一节中，我们将更详细地讨论 5G 赋能智能工厂的好处。

#### 5G 赋能智能工厂的好处

使用 5G 在智能工厂中的好处如下：

- 有了 5G，可以将更多智能传感器和智能设备连接到互联网，从而提高物联网容量。这导致工厂大规模互联。
- 5G 使使用 AR/VR 头显的员工能够在工厂车间自由移动并保持与专用 5G 网络的连接。5G 网络可以提供 AR/VR 有效运行所需的高速度。
- 5G 使员工能够监控机器性能、分析生产流程，并在各种智能工厂地点之间共享这些信息以进行适当的决策和规划。5G 网络能够以高速分析大量数据。
- 机器人被广泛用于工业中移动产品，其中一些还设计为与人类协同工作。大多数这些工业机器人由有线网络连接供电，因为当前的无线速度不足以使它们有效运行。随着 5G 的出现，机器人现在可以无线连接，而不受电缆的限制，从而使它们在智能工厂中得到充分利用和最大化。5G 有助于协作机器人更好地执行。
- 5G 使智能工厂中使用 AI 成为可能，提供低速网络无法提供的更实质性的功能。

总之，5G 连接使工业 4.0 的自动化和其他关键技术（如物联网、AI、机器人技术、云计算、AR/VR 等）能够有效运行，从而导致增加


效率、工厂生产率和质量的提升，以及智能工厂中员工工作条件的改善。

#### 将您的 PLC 或机器数据连接到云端

讨论我们的 PLC 数据如何到达云端非常重要，因为这在智能工厂中至关重要。在本节中，我们将简要介绍 IIoT 网关，它是将 PLC 或机器数据传输到云端所需的关键组件。

IIoT 网关可以是硬件或软件，能够集成各种设备，例如传感器、执行器、PLC 等，从中收集数据并将其传输到云端或本地服务器。它允许连接的设备与外部世界（云端）进行通信。它可以被视为连接工业环境中的连接设备与云端之间的桥梁。有了 IIoT 网关，您可以从世界任何地方监控和控制工厂中的机器或设备，因为设备的数据可在云端获取。您可以通过连接到互联网的 PC、平板电脑或智能手机上的仪表板监控数据；您也可以从 PC、平板电脑或智能手机发送命令来控制您的设备或机器。在每种情况下，数据都经过 IIoT 网关。它是设置智能工厂时所需设备之一。IIoT 网关理解 IoT 设备使用的不同协议，例如 Bluetooth、Zigbee、MQTT、Wi-Fi、蜂窝网络等。IIoT 网关在数据源附近处理关键数据，这有助于快速决策并减轻中央平台的负载。这被称为边缘计算。

不同制造商提供各种型号的 IIoT 网关。西门子 IIoT 网关的示例包括 SIMATIC IOT2020、SIMATIC IOT2040 和 SIMATIC IOT2050。

西门子 SIMATIC IOT2050 是一款智能物联网网关，连接内部 IT、制造、云部门，并整合来自各种来源的数据。它采用强大的德州仪器 ARM 处理器（AM6528）构建。它具有 1 GB 的 DDR4 RAM。SIMATIC IOT2050 配备多种接口，例如用于无线卡的 mPCIe 插槽、Gbit LAN、USB 端口、串行端口、Arduino 端口以连接 Arduino UNO Rev3 以及 DP 端口以直接连接到显示器。

以下是一些其他 IIoT 网关制造商及其型号：

- **Advantech**：UNO-125IG
- **Welotech**：EG602W、EG503W、EG602L
- **Softing**：UAGATE SI、UAGATE MB 和 edgeGate
- **WLINK**：WL-D80 和 G510-LF4（兼容 5G）

每个 IIoT 网关都有手册和指南，可帮助安装和配置它们。有些还会有论坛，您可以在其中向使用过该设备的人学习。
