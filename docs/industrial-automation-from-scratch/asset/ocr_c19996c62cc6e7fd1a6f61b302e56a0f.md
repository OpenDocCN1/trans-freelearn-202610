# 政治局势

柬埔寨实行君主立宪制，国家稳定，政府推行对外开放政策，近年来政局持续稳定。

柬埔寨是东南亚地区政治局势最稳定的国家之一，为外商投资提供了良好的政治保障。

# 经济自由指数

根据美国传统基金会发布的经济自由指数排名，柬埔寨得分逐年提升。2024年经济自由指数得分达到57.45分，在184个国家和地区中排名第89位。

近年来柬埔寨经济保持高速增长，年均GDP增速保持在7%左右，位居东南亚国家前列。
