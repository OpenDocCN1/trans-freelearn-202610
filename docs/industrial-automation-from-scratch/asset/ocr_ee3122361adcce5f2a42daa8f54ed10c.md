Considering the wiring diagram, when the switch connected to I0.0 is pressed (ON), I0.0 in the program will be closed and Q0.0 will be energized (ON) after 25s according to the program. The input has to be ON for the timer to complete the time and energize the output. Hence, a switch that will remain ON when pressed is preferred to be used to test the preceding program rather than a push button.
