The S7 1200 PLC and KTP400 HMI already have inbuilt PROFINET ports, making it easy to establish communication between them and other devices using the PROFINET protocol. Configuration can be done easily with the TIA portal. Refer to Chapter 10, Understanding Human Machine Interfaces (HMIs), for more information.
