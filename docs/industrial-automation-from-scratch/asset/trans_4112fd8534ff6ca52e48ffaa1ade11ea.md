## 前言

本书旨在为工业自动化工程师提供从基础到高级所需了解的知识——对工业自动化领域的初学者和专业人士均有益处。对于工业自动化工程师或任何想要入门或在工业自动化领域建立职业生涯的人来说，这是一本不可或缺的书籍。本书也是高等院校工程、物理和计算机系本科生和研究生的宝贵资源，以及制造业、食品加工、化工、石油天然气等使用自动化机器的其他行业中电气、机械、生产、过程控制和仪器仪表工程部门员工的参考资料。你将学习并能够使用传感器、执行器和**可编程逻辑控制器（PLCs）**进行工业自动化。书中包含大量关于 PLC 接线和编程、HMI 设计与开发、SCADA 系统设置以及过程控制的动手分步指南。

本书分为三个部分。每个部分包含若干关于重要主题的章节。

*第1部分* 致力于入门工业自动化所需的概念和技能。这是一个介绍性部分，你将了解工业自动化是什么以及如何识别电气控制元件并为基本的工业控制操作进行接线。你还将学习如何使用 CAD 软件绘制原理图/接线图。

*第2部分* 将带你了解工业自动化的主要工具（PLC、HMI 和 SCADA）。你将通过提供的分步指南边做边学。某些步骤中也可以进行仿真，这使得没有实际设备的人也能轻松理解其工作原理。看似复杂的内容通过动手方式变得简单。

*第3部分* 致力于过程控制、工业网络和智能工厂，你将获得关于这些方面的基础知识。

## 本书适合谁阅读

我坚信，本书对工业自动化领域的新手以及在该领域有经验并从事实践的人都将大有裨益，因为它以简化和实用的方式涵盖了从初级到高级的主题。阅读本书后，你可以通过文章、书籍或专门针对你想深入了解的主题的资源来进一步提升特定领域的技能。

## 本书涵盖内容

第1章，*工业自动化简介*，提供了工业自动化的概述。

第2章，*开关和传感器 – 工作原理、应用和接线*，涉及开关和传感器。了解开关和传感器在工业自动化中很重要。开关和传感器为控制器提供有关环境的<|message|> 信息以供处理。本章中，你将了解开关和传感器到底是什么以及它们如何工作，并学习其接线方法。

第3章，*执行器及其在工业自动化中的应用*，解释了工业自动化中使用的各种执行器。你将了解它们的基本工作原理及其在工业中的应用。

第4章，*交流和直流电机的概述*，涉及工业自动化中使用的电动机，如交流电机、直流电机、伺服电机和步进电机。电动机在工业中发挥着重要作用。因此，自动化工程师必须对其有良好的了解。

第5章，*变频器（VFD）简介*，重点介绍 VFD 的基本实际使用，以控制感应电机的速度和方向。感应电机是制造业中最广泛使用的电动机，始终需要根据各种应用改变其速度和方向。

第6章，*使用 CAD 软件绘制原理图/接线图*，展示如何使用 CAD 软件（PCSCHEMATIC 自动化软件）绘制与工业自动化相关的原理图/接线图。你将学习如何使用该软件创建控制系统图纸。

第8章，*了解 PLC 软件并使用 TIA Portal 进行编程*，重点介绍 PLC 的软件方面。你将学习开始使用最常见的 PLC 编程语言（梯形图）编程 PLC 所需的基本知识。

第9章，*使用 TIA Portal 深入 PLC 编程*，更深入地探讨 PLC 的软件方面。你将通过提供的分步指南学习更多关于 PLC 编程的知识。

第10章，*了解人机界面（HMIs）*，涉及 HMI 以及如何与 PLC 接口以向机器发出指令并从机器获取反馈。

第11章，*探索监控与数据采集（SCADA）*，重点介绍 SCADA 系统。SCADA 是工业自动化中一个有趣且先进的方面，在石油天然气、制造和其他行业中被广泛用于在大型工厂中对位于远程位置的待控制或监测的机器进行监测、控制和其他功能。

第12章，*过程控制 – 基础知识*，涉及工业过程的控制。过程控制也是工业自动化中的一个重要领域。没有控制就无法生产出优质产品。本章解释了过程控制以及适用于工业过程控制的各种测量和设备。你将学习如何使用温度控制器控制温度。你将通过分步指南了解西门子 S7-1200 PLC 模拟输入的接线和编程。

第14章，*探索 5G 时代的智能工厂（工业4.0）*，概述了智能工厂，这是制造业的当前趋势，允许工厂中的自动化机器或设备通过互联网从世界任何地方进行控制和监测。本章以全面方式解释了智能工厂及其支撑技术（物联网、人工智能、机器人、云计算等）。

## 如何充分利用本书

本书的写作是为了迎合初学者或工业自动化领域的新手，正如书名 *从零开始的工业自动化* 所暗示的那样。然而，为了能够在 Windows 操作系统计算机上跟随简单步骤，读者最好具备基本的电气知识和计算机技能。此外，本书要求你拥有一台安装了 Windows 操作系统的个人电脑，可以是台式机或笔记本电脑。

以下硬件用于进行部分实践练习，但不是必须的：

- SIMATIC S7-1200 PLC（CPU 1211C AC/DC/RELAY）
- SIMATIC HMI（KTP 400）
- 电源单元（220V AC - 24V DC）
- 用于 Pt100 的 RTD 温度变送器
- RTD 温度传感器（Pt100）
- 500 欧姆电阻
- 加热器
- 断路器
- 用于连接 PLC 或 HMI 与 PC 的以太网电缆
- **常开（NO）** 和 **常闭（NC）** 按钮（各两个或以上）
- 指示灯、接触器、电线等
