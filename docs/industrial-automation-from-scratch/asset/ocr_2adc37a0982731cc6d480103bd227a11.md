# # Launching PCSCHEMATIC Automation and exploring the screen elements

In this section, we will learn how to launch PCSCHEMATIC Automation and also explore the screen elements. Let’s start by learning how to launch the application.

# ## Launching the application

Follow these steps to launch PCSCHEMATIC Automation:

+   1. From the **Start** menu, locate **PCSCHEMATIC Automation**.
+   2. Click **PCSCHEMATIC Automation** to start the application.
