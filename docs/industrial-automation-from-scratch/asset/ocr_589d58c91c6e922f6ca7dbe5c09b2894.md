S7 1200 (CPU 1211C AC/DC/RLY) has six digital inputs and four digital outputs, which can be addressed in a program as follows:

+   - **Inputs:** `I0.0, I0.1, I0.2, I0.3, I0.4, I0.5`
+   - **Outputs:** `Q0.0, Q0.1, Q0.2, Q0.3`

You can find the input/output addressing of a PLC or model of a PLC in its manual. Always read the documentation/manual of any PLC you want to program.

+   - **Comments:** Comments are used to describe the logical operation that a rung or group of rungs will perform in an LD. They are usually displayed at the start of each rung. They make the program easy to understand.
