+   A. 输入
+   B. 解析

+   D. 摄入

56. 为什么持久队列在 Splunk 中很有用？

+   A. 它有助于减少 Splunk 中的总体存储需求
+   B. 它能够为关键事件启用实时告警和通知
+   C. 它防止高容量数据摄入期间的数据丢失
+   D. 它提高了历史数据分析的查询性能

你已经完成了模拟考试题部分的全部内容。让我们回顾一下答案。

## 回顾答案

+   1. 选项 A 是正确答案。inputs.conf 文件通常包含用于摄入的数据输入。props.conf 和 transforms.conf 包含解析阶段配置和字段提取，而 indexes.conf 配置 Splunk 索引。我们在第 6 章“Splunk 配置文件”中简要介绍了这些文件。
+   2. 选项 D 是正确答案。选项 C 涉及向 Splunk 进行用户认证所需的认证方法。请参阅第 3 章“Splunk 中的用户、角色和认证”中的“角色和认证方法”部分。
+   3. 选项 A 是正确答案。部署服务器（DS）为连接到它的转发器存储应用程序。通过使用 serverclass.conf 配置文件，DS 配置要部署到转发器的必要应用程序。有关各种 Splunk 组件的更多详细信息，请参阅第 1 章“Splunk Enterprise 认证管理员考试入门”中的“了解 Splunk 组件”部分。
+   4. 选项 A 是正确答案。索引器的重要功能是存储数据并响应用户通过搜索头（SH）发出的搜索请求。在典型的生产部署中，索引器上会禁用 Web UI。选项 B、C 和 D 是搜索头（SH）的功能。
+   5. 选项 C 是正确答案。顾名思义，LDAP 认证方法通常配置为连接到组织现有的目录服务器，并让用户使用现有凭据进行认证。Splunk 还支持其他认证方法，例如 SAML、本地和外部认证。
