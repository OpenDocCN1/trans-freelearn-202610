Let’s take a closer look at the concept depicted in the preceding diagram:

+   1. The first thing to notice is that there is a **Run Script** action mentioned, and this allows us to use all of the representative engines available in PAD, which include DOS command, VBScript, JavaScript, PowerShell Script, and Python Script. Scripting can be very useful for smaller blocks of code for certain functionalities that would otherwise be very cumbersome or not available at all. The different scripting engines each have their own strengths and give us the option to select the scripting language we already know. It is also conceivable that certain functionalities have already been implemented elsewhere with a scripting language so that this implementation can be used again here.
+   
+   2. Now, to integrate a script into a PAD flow, we need to pass data and values to the script and play the result back. We can do this very easily using the % notation we already learned about in the chapter on variables.
