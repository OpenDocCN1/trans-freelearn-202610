When working with AD and the corresponding PAD actions, you will typically come across these terms:

+   - **Object**: This is the general term for every item that is managed within AD. Each different object type has specific attributes.
+   - **User**: This object type consists of attributes such as the user’s logon name, first name, and last name, and represents someone logging on to a Windows domain with this user account.
+   - **Group**: This consists of user accounts, other groups, or computer accounts.
+   - **Computer**: This is information that relates to a computer within a domain.
+   - **Organizational unit (OU)**: These are logical containers that can contain objects and also other OUs. Often, OUs are used to mirror the organization’s structure. They also allow the delegation of administrative control.
