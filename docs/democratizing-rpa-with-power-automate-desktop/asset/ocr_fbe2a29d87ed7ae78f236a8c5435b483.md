To successfully execute the preceding flow, PAD must be executed with higher authorization. To do this, PAD must first be closed completely. The background process in the system tray must also be closed. Then, PAD can be started from the Windows menu. To do this, right-click on the program icon and select the **Run as administrator** option. Afterward, PAD can be used normally, and the flow runs without errors.

Another topic worth mentioning is a helpful feature of the actions for **Processes and Services**, which makes work easier when creating desktop flows. For both **Processes** and **Services**, the selection of the relevant element is made considerably easier by prefilling a drop-down list.
