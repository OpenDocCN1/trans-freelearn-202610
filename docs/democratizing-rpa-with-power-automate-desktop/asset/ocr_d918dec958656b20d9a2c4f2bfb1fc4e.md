# Final remark

The flow shown here was created on a desktop with a screen resolution of 1,920x1,200 with a scaling of 100% (i.e., no enlargement of the font or icons). If the flow were run on another desktop with a different resolution, then this would probably not work. In this respect, the flow shown here is a demonstration of what is possible. In practice, other mechanisms would certainly be used to create such a report.
