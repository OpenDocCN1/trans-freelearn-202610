# Starting with If and Else

In most cases, when we need to check a condition, the `If` statement action is the starting point. If you drag an `If` action onto the workspace, the actions parameter dialog appears and needs information, as we can see in *Figure 4.2*:

+   - **First operand:** Determines what we want to check
+   - **Operator:** Determines which operation to use for the check
+   - **Second operand:** Determines what to check against
