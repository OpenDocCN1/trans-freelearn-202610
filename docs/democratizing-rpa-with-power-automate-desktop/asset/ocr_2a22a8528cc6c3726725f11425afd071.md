As we can see in the preceding diagram, the coordinates **X=960** and **Y=540** are exactly in the middle of the screen on the left side. But when the screen resolution changes, these coordinates are in the top left area rather than in the middle. This means that when using actions that work with mouse coordinates, you must always make sure that the screen resolution is also the same as the one used to create the flow. With the **Get screen resolution** and **Set screen resolution** actions, these settings can be checked and changed if necessary.
