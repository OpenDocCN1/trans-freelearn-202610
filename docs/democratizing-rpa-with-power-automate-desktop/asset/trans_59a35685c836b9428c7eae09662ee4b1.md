# 重要说明

请注意，该程序称为 Power Automate 而不是 Power Automate Desktop。不要混淆——我们是在正确的位置。该程序可能会找到软件的更新版本并自动应用。

当程序最终启动时，你还需要使用 Microsoft 帐户登录。之后，你应该再次选择一个区域并浏览 Power Automate 的导览，这也是 PAD 已成功安装的确认。
