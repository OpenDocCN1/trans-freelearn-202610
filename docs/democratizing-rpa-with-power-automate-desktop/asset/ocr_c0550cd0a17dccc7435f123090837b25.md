This data type is especially useful when we need to create a flow that communicates with some external web services that expect or return JSON objects. We will discover this later in this book.

To convert the custom object into a valid JSON string, we can make use of the Convert custom object to JSON action, which expects a custom object as input and produces a new variable containing the JSON string. The reverse operation is Convert JSON to custom object. Both actions are also in the Variables action group. We will look at examples of how these actions are used later in this book.
