## 前言

在我们的私人生活和职业生活中，我们都熟悉这样的场景：不得不执行重复且乏味的 IT 任务。微软提供了 Power Automate Desktop，这是一个免费工具，可用于解决从小型到大型的自动化场景。

在本书中，您将学到使用 Power Automate Desktop 自动化重复且单调的流程所需的一切，从而释放出更多时间去做更重要的事情。本书介绍了该程序的历史及其在 Microsoft Power Platform 中的当前角色，然后解释了用户界面自动化的概念，以及如何利用 Power Automate Desktop 实现本地安装的程序或进程以及 Web 浏览器的自动化。

随着学习的深入，您将通过大量示例了解 Power Automate Desktop 的完整功能集，从变量、条件和分支等基本概念，到本地桌面的功能（如文件和文件夹管理），再到连接数据库、大型机计算机和 SAP 自动化。

最后几章还涉及人工智能的主题以及如何将其融入流程，同时介绍了 Power Automate Desktop 如何用于大型企业，在大型企业中，治理、合规性、扩展和安全性等额外主题也发挥着作用。
