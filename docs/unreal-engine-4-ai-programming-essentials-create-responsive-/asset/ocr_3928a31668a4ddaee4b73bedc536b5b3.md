# The pros and cons of using randomness

The following are the pros:

+   - There is virtually no limit to the output
+   - This introduces balance to systems

The following are the cons:

+   - You must create a large output table for increased deviation
+   - The paths are limited to control

# The pros and cons of using probability

The following are the pros:

+   - You can predetermine the output
+   - You can dictate the frequency of output
+   - You can introduce balance to systems

The following are the cons:

+   - It is not as random
+   - You must determine the output table

Probability is powerful when you want to predetermine the output. Probability allows you to choose how often an output is given. Randomness doesn't give you any control on the output. Introducing these can add another layer of abstraction to player experience.

# Introducing movement

We only covered movement for pawns because this book is just an introduction. However, if you had any interest in getting other pawn types to move, you have to recreate the junction box, which is the movement component. This movement component for a type of pawn is responsible for taking input delta and converting it into acceleration.

What this means for the car AI is first getting the direction from one point to another, resulting in the position direction. Then, we need to make this position direction relative to the car AI by subtracting it from the car AI's forward direction. This results in a direction delta, which can be applied to the car AI's direction.
