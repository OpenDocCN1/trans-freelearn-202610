The **Cancel** and **Delete** buttons are created only if the `isNoteEdit` argument to the constructor is `true`. The **Cancel** button is used when you’ve navigated to `NotePage` to edit a note, but after typing in a little, you decide to abandon those edits. There is no **Ok** button to confirm your edits. That’s just a matter of navigating back to the home page.

It’s polite to obtain a confirmation from the user when deleting something or cancelling an operation. For confirmation purposes, the Xamarin.Forms `Page` class defines a `DisplayAlert` method, which displays a native platform alert box. Three different version of `DisplayAlert` exist.
