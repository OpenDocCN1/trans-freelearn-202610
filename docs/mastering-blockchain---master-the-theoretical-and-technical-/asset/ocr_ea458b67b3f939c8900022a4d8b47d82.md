# Oyente tool

Currently, Oyente is available as a Docker image for easy testing and installation. It is available at https://github.com/ethereum/oyente, and can be quickly downloaded and tested. In the example below, a simple contract taken from solidity documentation that contains a re-entrancy bug has been tested and it is shown that Oyente successfully analyzes the code and finds the bug:

![](bbox=[0.105, 0.105, 0.895, 0.405])

Why3

```
pragma solidity ^0.4.0;
contract Fund {
    mapping(address => uint) shares;
    function withdraw() {
        if (msg.sender.send(shares[msg.sender]))
            shares[msg.sender] = 0;
    }
}
```
