# Alternative Blockchains

Finally, the contract can be uploaded using the following command. This command expects the argument passed to the contract as defined in the contract code. In the example, it expected a text string as shown in the following example screenshot:

```
```bash
$ bloc upload Greeter "Hello bloc"
```
```
