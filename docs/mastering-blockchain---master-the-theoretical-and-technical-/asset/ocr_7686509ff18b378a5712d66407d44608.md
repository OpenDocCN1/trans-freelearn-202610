# How to generate public and private key pairs

First, it is shown how the RSA private key can be generated using OpenSSL.

# Private key

```
~/Crypt$ openssl genpkey -algorithm RSA -out privatekey.pem -pkeyopt rsa_keygen_bits:1024

........................................++++++
```
