Getblockchaininfo and getpeerinfo RPCs were updated with a new functionality to cater for this change. An RPC, getchaintips, is used to list all known branches of the blockchain. This also includes headers only blocks. Getblockchaininfo is used to provide the information about the current state of the blockchain. Getpeerinfo is used to list both the number of blocks and the headers that are in common between peers.
