# 作者简介

**Imran Bashir**拥有伦敦大学皇家霍洛威学院的信息安全理学硕士学位，并拥有软件开发、解决方案架构、基础设施管理和IT服务管理方面的背景。他还是**电气与电子工程师协会（IEEE）**和**英国计算机学会（BCS）**的会员。Imran在公共部门和金融领域拥有十六年的经验。在进入金融服务行业之前，他曾参与公共部门的大型IT项目。此后，他在欧洲金融中心伦敦的多家金融公司担任过各种技术职务。目前，他在伦敦一家投资银行的技术部门担任副总裁。

*我要感谢Packt才华横溢的团队，包括Ajith Menon、Nilesh Sawakhande、Sumeet Sawant和Tushar Gupta，他们在整个项目中提供了及时的指导和非常宝贵的反馈。我也非常感谢审稿人Daniel Kraft，他提供了建设性且非常有用的反馈，极大地帮助改进了本书内容。*

*感谢我的妻子和孩子忍受我通宵达旦和整个周末的写作时光。*

*最后，我要感谢我的父母，他们的祝福让我的一切都成为可能。*

# 审稿人简介

**Daniel Kraft**曾学习数学和物理学，并拥有奥地利格拉茨大学的应用数学博士学位。自2013年以来，他一直参与加密货币相关的开发工作，自2014年起担任Namecoin和Huntercoin的首席开发者和首席科学家，并在同行评审期刊上发表了两篇关于加密货币的研究论文。他是一名软件工程师，也是Crypto Realities Ltd的联合创始人，这家初创公司致力于利用区块链技术构建去中心化的多人游戏世界。
