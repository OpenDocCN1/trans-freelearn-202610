The equation of point addition is as follows:

```
x₃ = s² - x₁ - x² mod p
y₃ = s(x₁ - x₃) - y₁ mod p
```

Here, this is the result:

```
S = ((y₂ - y₁)/(x₂ - x₁)) mod p
```

S in the preceding equation depicts the line going through $P$ and $Q$.
