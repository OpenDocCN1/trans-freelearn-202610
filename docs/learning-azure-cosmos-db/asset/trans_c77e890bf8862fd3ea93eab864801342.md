# 在表 (键值存储) 中执行 CRUD 操作

表存储 API 为我们提供了高效且轻松地存储键值对数据的能力。你需要在 Cosmos DB 内创建一个新的表数据库来执行 CRUD 操作。

## 创建表数据库

1. 登录到你的 Azure 门户，然后单击选项栏左侧的 **Azure Cosmos DB** 选项。

2. 单击 **+** 按钮，为你的新数据库指定一个合适的 ID，然后从 API 下拉菜单中选择 **表 (键值)** 选项。

3. 你可以创建一个新资源或使用现有资源。选择大多数写入操作将发生的位置，然后单击 **创建** 按钮。你可以参考屏幕截图：

   ![](assets/8bbe31dc-7d64-4f27-80fc-dee0d715466d.png)

4. 现在你可以在其中创建一个表来存储你的数据。请参考以下屏幕截图：

   ![](assets/66edfaa7-7a9c-4f22-8426-045f0ab96230.png)

## 使用实体

我们可以对同一数据执行 CRUD 操作。我们需要创建表实体以该格式存储数据。单击 **添加新实体** 并添加行键和分区键。有关详细信息，请参阅 [第 3 章](#2884078b-5f26-4689-a71d-230d1f20e997.xhtml) *Cosmos DB 多模型数据库*。

创建实体后，我们可以在其中添加数据。此外，你可以从 Azure 门户复制连接字符串并粘贴以在自定义应用程序中进一步使用。

你可以添加任意数量的实体，完成后，可以从数据资源管理器中删除、编辑或查询它们。

# 在 Cassandra 中执行 CRUD 操作

Cassandra API 为我们提供了在 Cassandra 中高效且轻松地存储 NoSQL 数据的能力。你需要在 Cosmos DB 内创建一个新的 Cassandra 数据库来执行 CRUD 操作。

## 创建 Cassandra 数据库

1. 登录到你的 Azure 门户，然后单击选项栏左侧的 **Azure Cosmos DB** 选项。

2. 单击 **+** 按钮，为你的新数据库指定一个合适的 ID，然后从 API 下拉菜单中选择 **Cassandra** 选项。

3. 你可以创建一个新资源或使用现有资源。选择大多数写入操作将发生的 **位置**，然后单击 **创建** 按钮。你可以参考屏幕截图：

   ![](assets/fc900918-0e66-49a0-9a7e-3b65e8e095d0.png)

4. 现在，单击 **数据资源管理器 | 新建表** 按钮并创建一个新表来存储数据。请参考下面的屏幕截图：

   ![](assets/32d22c55-5bd3-4176-ac67-36e721b63842.png)

## 使用表和数据

5. 现在，我们可以使用标准 SQL 命令插入数据，如下所示。

```
INSERT INTO uprofile.user
(first_name, last_name)
VALUES ('Shahid', 'Shaikh');
```

6. 你可以使用 `SELECT` 查询从 `Cassandra` 表中读取数据。

```
SELECT * from uprofile.user;
```

同样，可以分别使用 `UPDATE` 和 `DELETE` 命令来更新和删除 Cassandra 表中的记录。

这涵盖了使用各种数据模型执行 CRUD 操作的内容。

Cosmos DB 支持多种编程语言，如 Java、.NET、Python 和 Node.js。Node.js 实际上不是一种编程语言，而是 JavaScript 的运行时框架。

我是一名 Node.js 爱好者，更习惯使用 Node.js 开发后端系统，因此我们将在本章以及后续章节中进行 Cosmos DB 与 Node.js 的集成。

以下是我们将在本章中介绍的主题：

- Node.js 设置
- Cosmos DB MongoDB 设置
- 将 Cosmos DB 与 Node.js 应用连接
- 在 Cosmos DB 中探索应用数据
- 将 DocumentDB API 与 Node.js 集成

- 将图 API 与 Node.js 集成

那么，让我们开始吧。

## Node.js 设置

你需要在你的机器上安装并设置 Node.js。访问 Node.js 官方网站 ([https://nodejs.org/en/download/](https://nodejs.org/en/download/)) 并根据你的操作系统下载最新版本。

我在这里介绍 Ubuntu 的安装。让我们逐步进行：

1. 打开终端并运行此命令：

```
curl -sL https://deb.nodesource.com/setup_8.x | sudo -E bash -
```

这将为 Node.js 8+ 版本添加 Ubuntu 存储库条目。

2. 现在，运行此命令安装 Node.js：

```
sudo apt-get install -y nodejs
```

片刻后，Node.js 连同 `npm` 将设置完成。

3. 要检查 Node.js 和 `npm` 的版本，请运行以下命令：

```
node -v
npm -v
```

输出如下：

![](assets/7f49cf95-4cf2-4cd3-8338-ddd47a48ae03.png)

你也可以在 macOS 以及 Windows（使用 PowerShell 或 Windows 命令提示符）中运行类似的命令。

这应该能确保 Node.js 正确设置，我们可以继续进行 Cosmos DB MongoDB 的创建。
