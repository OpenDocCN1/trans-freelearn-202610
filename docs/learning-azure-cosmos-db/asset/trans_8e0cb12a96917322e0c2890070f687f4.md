- [第2章](#f8c36a85-28c9-452c-8c81-e31b4050b672.xhtml)，《*Cosmos DB 全球交钥匙分布*》—— 涵盖 Cosmos DB 的关键功能之一，即其全球交钥匙分布系统。您可以使用非常简单的界面，将数据库复制到遍布全球的 30 多个区域。

- [第4章](#f5161897-9696-4441-9e45-f2346e49978e.xhtml)，《*查询 Cosmos DB*》—— 涵盖多模型数据库所需的不同查询类型。本章按 CRUD（创建、读取、更新和删除）方式对这些查询进行分类，以便更好地解释。
- [第5章](#bbbd9fe4-f9da-44d6-9d1d-99612ef7197f.xhtml)，《*将 Cosmos DB 与 Node.js 集成*》—— 涵盖与流行的后端运行时引擎 `Node.js` 的所有集成。我们介绍了如何使用 `Node.js` 连接到 Cosmos DB 的数据库模型。
- [第6章](#5c360edf-dd5e-4d41-991a-11103f5b7705.xhtml)，《*使用 Cosmos DB 构建高性能链接缩短与追踪系统*》—— 涵盖使用 Cosmos DB 和 `Node.js` 开发一个简单且高性能的链接缩短与追踪系统，该系统非常类似于 `bit.ly`。读者将学习并了解如何使用 Cosmos DB 托管数据库解决方案构建此类复杂系统。
- [第7章](#59413440-6b69-4d90-a2c2-e28c2dd874fe.xhtml)，《*使用 Cosmos DB 构建高可用实时邮件追踪系统*》—— 涵盖开发一个处理数百万用户邮件打开率追踪并将其存储在数据库中以供进一步分析的系统。
- [第8章](#4af46b38-5c09-4a5e-a5f6-e37632e5f68e.xhtml)，《*Cosmos DB 部署与管理*》—— 涵盖将您的自定义应用程序和 Cosmos DB 数据库部署到生产环境的所有内容。

# Microsoft Azure 云与 Cosmos DB 简介

公有云以订阅制向公众提供虚拟专用服务器和托管数据库等服务。一些平台（如 Amazon）按小时收费或提供按需付费（`Lambda`）服务，而其他平台（如 `DigitalOcean`）则按月收取固定费用，等等。`Windows Azure` 公有云平台是 **Microsoft 的云操作系统愿景** 的重要支柱之一，该愿景正在改变传统数据中心环境，帮助企业释放存储在任何位置的数据中的洞察力，支持开发各种现代业务应用程序，并赋能 IT 部门支持在任何设备上随处工作的用户，同时能够以安全一致的方式管理这些设备。

- Azure 特性
- Azure 作为 **服务、平台和基础设施** (**SPI**)
- Azure 组件
- Azure 入门
- Azure Cosmos DB
- Azure Cosmos DB 特性
- Azure Cosmos DB 用例
