## 前言

在云中开发和部署应用已成为现代商业技术计划中不可或缺的组成部分。随着组织踏上数字化转型之旅并将其应用迁移到云中，对能够开发、保护、部署和管理基于云的应用程序的熟练且获得认证的专业人才的需求呈现象级增长。

开发人员需要掌握各种架构设计模式的知识和实践技能——从虚拟机部署到容器，从事件驱动架构到松散耦合的无服务器解决方案。

本书旨在帮助你通过 AWS Certified Developer Associate（DVA-C02）认证，并获得雇主和客户所要求的宝贵实践经验。为此，本书从零开始设计，重点围绕一家虚构公司 Todo Plus Limited 的应用程序开发和部署展开。在给定场景中，该公司希望构建一个全球可访问、高可用、可扩展且安全的生产力 Web 应用。它必须在最有效的技术上做出战略决策，并专注于实现快速部署、降低管理开销、提升安全性，同时保持成本效益。

随着你逐步阅读本书，你将专注于培养技能，帮助你为应用技术栈选择合适的技术，从而应对各种用例。你将理解这些技术的核心理论概念，更重要的是，如何配置这些工具和服务以实际托管和支持你的应用程序。所有章节的项目练习中都提供了分步指南。这些将帮助你培养规划、配置和支持各种关键服务的专业知识，从而成功托管和管理你的应用程序。

本书涵盖了与 AWS Certified Developer Associate（DVA-C02）考试相关的主题，包括在设计应用时强调安全性、采用最佳实践构建松散耦合架构、整合自动化与**持续集成/持续交付（CI/CD）**DevOps 原则等。

学完这本学习指南后，你将拥有通过 AWS Certified Developer Associate（DVA-C02）考试所需的全部工具，并在应用开发、安全、部署和管理方面获得实际技能。

## 本书涵盖内容

*第 1 章，AWS 账户与全球基础设施简介，* 介绍了设置和配置 AWS 多账户架构以促进应用开发生命周期策略的基本安全概念。本章还涵盖了与 AWS 全球云基础设施相关的核心概念，这些概念是使用 AWS 服务并按照最佳实践启动资源的基础。

*第 2 章，使用 AWS Identity and Access Management 保护访问安全，* 重点介绍遵循**最小权限原则（POLP）**为 AWS 账户开发安全访问的方法，并研究了为托管在 AWS 上的应用构建强大身份验证和授权解决方案的策略。

*第 3 章，了解 Amazon S3 对象存储、混合存储和静态网站托管，* 重点介绍使用 Amazon S3 进行数据存储，其丰富的功能旨在帮助构建高可用和可扩展的云存储解决方案。本章还讨论了使用 Amazon S3 进行静态网站托管的核心优势——这是大多数云托管应用的入口点。

*第 4 章，使用 Amazon VPC 在云中构建私有网络，* 让读者深入理解如何在云中构建安全的私有网络。在设计以安全为首要考虑的应用解决方案时，通过防火墙和流量路由策略托管受限访问的后端服务至关重要。

*第 5 章，了解 Amazon EC2 和存储选项等 AWS 计算服务，* 讨论了虚拟机架构和配置选项的基础概念，用于托管应用的业务逻辑。你还将了解与 EC2 实例常配合使用的相关块存储和文件系统存储服务。

*第 6 章，使用 AWS 关系型和非关系型（NoSQL）数据库管理多个数据集，* 涵盖了托管、管理和操作数据是每个应用的核心。本章重点介绍可用于应用技术栈的各种数据库解决方案，涵盖安全、性能和可靠性的核心概念。

*第 7 章，构建具有高可用性、弹性和数据安全性的应用解决方案，* 重点在于构建高可用、可扩展的应用解决方案，减少停机时间并具备按需配置容量的灵活性。此外，本章还探讨了使用加密技术保护传输中和静态数据的数据安全基础知识。





*第 8 章，使用 AWS Lambda 进行事件驱动计算以及使用 Amazon API Gateway 保护后端 API 访问*，涵盖了从传统基于服务器的架构向现代无服务器解决方案的范式转变，并融入了事件驱动解决方案。本章介绍了创建、发布和管理**应用程序编程接口 (API)** 的核心概念，以增强安全性、提升性能并构建可扩展的解决方案。

*第 9 章，使用 Amazon CloudFront 和 Route 53 集成边缘网络服务以连接您的应用程序*，探讨了为全球客户提供服务需要透彻理解如何通过低延迟连接使应用程序可访问，以确保出色的终端用户体验。在本章中，您将学习如何使用 Amazon CloudFront 构建内容分发网络，并集成**域名系统 (DNS)** 服务以设计高效的流量路由策略。

*第 10 章，使用 AWS Elastic Beanstalk 设计部署策略*，使开发人员能够专注于应用程序设计和开发，而无需担心底层基础设施的重活。本章还教您了解不同的部署策略，以帮助确保在应用程序的发布、更新和升级过程中将停机时间降至最低。

*第 11 章，使用 Amazon ECS、Fargate 和 EKS 部署多层应用程序堆栈*，讨论了从传统虚拟机架构转向容器化解决方案以托管应用程序，从而使您能够将应用程序代码与可在任何基础设施上运行的文件和库捆绑在一起。

*第 12 章，使用 AWS CI/CD 工具掌握 DevOps*，专注于遵循 DevOps 原则开发应用程序，通过自动化实现快速部署、更快的问题解决和更稳定的环境。

*第 13 章，使用 CloudFormation 和云开发工具包 (CDK) 通过代码构建基础设施*，涵盖了 CloudFormation 和 CDK 的设计目的是帮助开发人员快速配置可靠、稳定且可通过自动化在不同环境中重复部署的基础设施。

*第 14 章，使用 AWS 无服务器应用程序模型 (SAM) 和 AWS AppSync 设计无服务器应用程序*，使开发人员能够使用无服务器概念重新设计应用程序，从而避免与传统 IT 架构相关的不必要成本。本章还教您如何使用 GraphQL 和 Pub/Sub API 安全地将应用程序连接到数据和事件。

*第 15 章，解耦应用程序堆栈并管理数据摄取*，讨论了可以帮助您构建微服务和松耦合架构的策略和技术。本章还向您介绍了 AWS 上的数据流服务。

*第 16 章，使用 Amazon CloudWatch 和 AWS CloudTrail 进行监控*，专注于监控、分类和管理您在 AWS 上的应用程序健康状况和性能，使您能够快速解决与性能相关的问题并补救任何瓶颈。

通过多套模拟考试、交互式 flashcards 和可从所有现代网络浏览器访问的实践练习，磨练您对 DVA-C02 概念的掌握。如果您遇到困难，可以直接通过网站向作者提出您的疑虑。在此之前，也请查看已解决问题的列表。这些问题基于其他用户提出的问题。最后，查看网站上的考试技巧，以确保您做好充分准备。

## AWS 账户和全球基础设施简介

云计算是按需交付 IT 服务，使客户能够配置基础设施、平台和软件组件等 IT 资源来托管和管理其应用程序。云计算相比传统本地解决方案具有多项优势，例如访问尖端技术、弹性和可扩展性以及降低管理开销。转向云的最大优势之一是能够将固定成本转变为可变成本——这是因为客户无需购买任何基础设施硬件，而是使用按需付费模式租用提供商底层基础设施的容量。

**Amazon Web Services (AWS)** 是当今最大的云计算服务提供商，其次是微软和谷歌，根据 Gartner 2023 年战略云平台服务魔力象限。AWS 提供超过 200 项服务，旨在帮助各规模的企业在云中构建、设计和部署可扩展、安全且经济高效的解决方案。此外，AWS 提供其全球数据中心的访问，使企业能够将应用程序部署到更靠近客户的位置，而无需在这些位置采购和配置基础设施。即使是小型初创企业也可以接触全球客户群并满足合规和监管要求。

本书将教您通过 AWS Certified Developer Associate 认证所需的所有技能，并在云开发人员、初级 DevOps 工程师、云工程师等典型职位中脱颖而出。它涵盖了遵循行业标准最佳实践的 AWS 架构设计模式，并帮助您在 AWS 上开发、部署和调试基于云的应用程序方面建立熟练程度。本书还旨在帮助您从零开始培养现实世界的实践技能。这是通过在章节中融入一个场景来实现的，这样当您学习新技术和概念时，您也可以通过提供的项目练习培养将这些知识付诸实践的技能。
