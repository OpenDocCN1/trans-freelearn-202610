# # Project Task 10.4 – Configuring an RDS Secret in AWS Secrets Manager

In this project task, you will create a database credentials secret in AWS Secrets Manager for your MySQL database and then configure automatic rotation to enhance the credentials security for your database.

+   1. Ensure you are still logged into the AWS development account as the IAM user “Alice” and are in the London region.
+   2. Search for and navigate to **Secrets Manager** from the search bar at the top of the AWS Management Console.
+   3. From the left-hand menu, click on **Secrets**.
+   4. In the right-hand pane, click **Store a new secret**.
+   5. Select the **Credentials for Amazon RDS database** option in the **Secret type** section.
+   6. Provide the current username and password for the database you created in *Project Task 10.3*.
