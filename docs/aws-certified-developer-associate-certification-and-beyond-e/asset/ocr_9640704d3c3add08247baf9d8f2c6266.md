Now that you have set up the Amazon S3 bucket with the source code files uploaded for the Todo List backend application, you should create an IAM policy, which will grant access for your EC2 instances to download the source code files from the bucket. Later, you will create an IAM role that will be used to grant your EC2 instances with permissions defined in this policy.

+   1. In another browser tab, navigate to the AWS policy generator website located here: `https://awsypolicygen.s3.amazonaws.com/policygen.html`.
+   2. Select **IAM Policy** from the **Select Type of Policy** drop-down list. Ensure that **Effect** is set to **Allow**.
+   3. Select **Amazon S3** from the **AWS Service** drop-down list.
+   4. In the **Actions** drop-down list, select the **GetObject** action.
+   5. You need to provide the **Amazon Resource Name (ARN)** of your bucket. You will find this in the Amazon S3 console, under the **Properties** tab of your bucket, as per the following screenshot:

![](bbox=[0.27, 0.38, 0.72, 0.57])

Figure 7.13 – The ARN of your Amazon S3 bucket

+   6. Copy this ARN value and paste it into the textbox next to the **Amazon Resource Name (ARN)** textbox label on the policy generator web page. You must ensure you also add the value *slash and asterix* (`/*`), after the ARN of your bucket. This denotes that you are granting access to all content within the bucket.
