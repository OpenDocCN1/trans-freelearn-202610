# Project Task 11.8 – Create an ECS Service

In this project task, you will create an ECS service responsible for deploying your ECS tasks. This service will ensure that you have the required number of tasks running according to your scaling policies and monitor your tasks. In addition to defining your capacity provider, which for this project is Fargate, the service will also enable you to configure load balancing and service auto-scaling:

+   1. Ensure that you are still logged into your AWS Development account as the IAM user Alice.
+   2. Navigate, if necessary, back to Elastic Container Service.
+   3. From the left-hand menu, select Clusters.
+   4. In the right-hand pane, click the todo-plus-cluster cluster to view its details.
+   5. Ensure that you are in the Services tab in the right-hand pane.
+   6. Next, click the Create button, as shown in Figure 11.32:
