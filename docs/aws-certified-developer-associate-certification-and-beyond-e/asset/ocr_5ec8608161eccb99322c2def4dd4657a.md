Depending on the services you use on AWS, you can choose to encrypt your data. For end-to-end encryption requirements, you often implement both options.

AWS KMS is an essential service used by Amazon S3 and other services on AWS for encryption. Let's dive deeper by discussing the key features of KMS next and how you can use this service to manage your encryption needs effectively.

# ## Overview of AWS KMS

**AWS KMS** is the primary service you can use to build and integrate data encryption features for your applications and data hosted on AWS. **AWS KMS is FIPS 140-2-compliant and uses shared security hardware modules** to generate encryption keys, which are used to perform cryptographic operations.

**AWS KMS keys** (previously known as Customer Master Keys or CMKs) perform all the data encryption, decryption, and re-encryption. CMKs are designed to only encrypt data up to a maximum size of 4KB. To encrypt larger datasets, you must create data keys, as discussed later.

**AWS KMS keys** can either be customer-managed or AWS-managed. The following are the differences:

**Customer-managed CMKs** are keys that you create, own, and manage. You have complete control over key policies and the ability to enable and disable them. You can optionally define key rotation policies, which can later be disabled, unlike AWS-managed keys.

**AWS-managed CMKs** are created, managed, and used on your behalf by any service that uses AWS KMS natively. While some services will let you choose either an AWS-managed key or a customer-managed one, often, you can opt for the AWS-managed keys unless you are required to have greater control over the keys. With AWS-managed keys, key rotation is performed automatically yearly and cannot be disabled, and the keys cannot be deleted. AWS-managed keys are also not chargeable.

An important concept to understand is that there are two types of encryption you can work with – *symmetric* and *asymmetric encryption* – and accordingly, you would use symmetric keys or asymmetric keys. Let us look at these next.

# ## Symmetric KMS Keys

Symmetric KMS encryption keys are used when you want to use the same keys to perform both the encryption and decryption operations. The keys are securely stored in KMS; you must call KMS to perform the required encryption and decryption tasks. Note that AWS services, which are integrated with KMS, only use symmetric encryption.

Symmetric keys can be used to encrypt, decrypt, and re-encrypt data. They can also be used to generate data key and data key *pairs*, which we will discuss later in this section. There is support for multi-regional symmetric encryption and the ability to import your key material if you wish.
