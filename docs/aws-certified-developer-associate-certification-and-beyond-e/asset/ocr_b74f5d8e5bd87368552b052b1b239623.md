The core components of the CloudWatch Logs service comprise the following:

+   - **Log events:** Log events consist of a timestamp and a RAW message. The event message must be UTF-8-encoded. Each entry in the log file is called a log event.
+   - **Log stream:** A sequence of log events that share the same source. So, in the case of our example in Figure 16.6, you will note three log streams, one for each EC2 instance where the Apache log access file data is being captured.
+   - **Log groups:** For a given resource, you will have one log group, within which you have one or more log streams. Within each log group, log streams will share the same retention period, monitoring, and any access permissions through IAM roles and policies.

An important benefit of using CloudWatch Logs is the ability to create **metric filters**. These allow you to identify patterns in your CloudWatch Logs events within log streams and then create a metric from that filter that you can start to monitor. For example, you can use metric filters to extract and monitor failed logins or errors, which you can then use to trigger alarms once a specified threshold value is crossed.

CloudWatch Logs comes with additional features, which will be discussed further in the next sections.

# Exporting and Streaming CloudWatch Logs Data

You can also export logging data from CloudWatch by sending it to Amazon S3. The logging data can then be kept for long-term retention or used by other applications and systems for analysis and processing. Here, logging data is exported using the `CreateExportTask` action. Please note that the log data can take up to 12 hours to become available for export.

In addition to exporting the log data into Amazon S3, you can configure CloudWatch log data for real-time and near-real-time processing to other destinations using subscriptions. These include Kinesis Data Streams, Firehose, or AWS Lambda, which can be used for custom processing or loading onto other AWS services. You can define subscription filters to filter out which log events are delivered to your destination resources.
