AWS CloudFormation is a general-purpose **Infrastructure as Code (IaC)** tool that allows you to declaratively define and provision a wide range of AWS infrastructure resources. AWS SAM is a specialized IaC tool designed to build serverless applications. Although CloudFormation supports a broad set of AWS services, SAM simplifies the definition, deployment, and management of serverless resources, such as Lambda functions, API Gateway, and DynamoDB, by providing higher-level abstractions and SAM-specific syntax. SAM templates are expanded into full CloudFormation templates, but you write less code with SAM.

## Project Task 14.5: Deleting a CloudFormation Stack

You can use the `sam delete` command to delete the CloudFormation stack. An important point to note here, however, is that because your website bucket has objects in it, the stack delete process will fail. This is because CloudFormation cannot delete an S3 bucket that has objects contained within it. To resolve this issue very quickly, you must delete the bucket's contents. You can then issue the `sam delete` command to delete the stack:

- 1. Navigate to the Amazon S3 management console and click the website bucket created by SAM, which you defined in the `template.yaml` file on line 46, as per *step 3* of *Project Task 14.3*.
- 2. Select all of the contents in the bucket and then click the **Delete** button, as per *Figure 14.20*.
