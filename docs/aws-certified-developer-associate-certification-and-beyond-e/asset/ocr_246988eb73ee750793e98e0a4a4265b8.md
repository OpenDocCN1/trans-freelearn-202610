# Project Task 10.6 – Creating an Elastic Beanstalk Application

You will create an Elastic Beanstalk application and an environment for this project task. You will then upload the application code you downloaded from the GitHub repository and deploy the application across a set of EC2 instances. Amazon Elastic Beanstalk will provision the EC2 instances in an autoscaling group, deploy an Application Load Balancer, and configure connectivity to the backend database with the help of the environment variables that you define.

+   1. Use the search bar at the top of the page from the AWS Management Console to search for and navigate to the Elastic Beanstalk service.
+   2. Ensure that you are still in the London region.
+   3. Click on Applications from the left-hand menu and then click the Create application button in the right-hand pane.
+   4. Provide a name for your application, such as Todo-List-EB-App.
+   5. Provide a description of your application.
+   6. Click the Create button.
+   7. On the Application Todo-List-EB-App environments page, click the Create new environment button in the right-hand pane.
+   8. You will be presented with the Configure environment page. Ensure that Web server environment is selected from Environment tier.
+   9. You will note that Environment name is pre-populated with your application’s name followed by -env. For example, Todo-List-EB-App-env. You can leave this as it is.
+   10. Scroll down to the Platform section of the page. Select PHP from the Platform drop-down list. Accept the default platform branch, which should be PHP 8.3 running on 64bit Amazon Linux 2003.
+   11. Click the Upload your code radio button in the Application code section.
+   12. Provide a version label such as v1.
+   13. Select Local file under Source code origin. Maximum size 500 MB.
