# Block Storage

Block storage stores data in fixed-sized chunks on a physical hard drive. The disk is divided into volumes accessible to your EC2 instances (servers) over network interfaces. This allows your servers’ operating system (OS) to access the volume directly, format it, and write and read data to and from it. The server OS oversees the storage partition to which it has been given access and manages how data is written to the volume. For example, with Amazon Elastic Block Storage (EBS), you can provision a 100 GB volume, and the disk cluster allocates 100 GB of available storage.

# File Storage

This is a method of storing data as individual files on a centralized file server, which other devices can share. An example of this is where you have multiple nodes that need access to commonly shared data, or if your workforce needs a central location to share documents and collaborate. The hierarchical nature of file storage is like its real-life counterpart, the filing cabinet. Data is stored in folders and sub-folders, and access to that data requires knowing the location and structure of that hierarchy. This type of storage uses Network File System (NFS), Server Message Block (SMB), and Common Internet File System (CIFS) protocols.

# Object Storage

Object storage is a technology to store data as objects (flat files). These objects are stored as unstructured flat files, without using any of the previously discussed file storage hierarchy architectures. Objects are instead stored with pieces of data that make up the file, with relevant metadata and unique identifiers. One of the real benefits of object storage is the ability to offer infinite scalability and higher durability levels. Because of this, object storage is often used for use cases such as cloud storage, content delivery networks (CDNs), data lakes, archiving and backup, and media streaming.

In this chapter, you’ll explore object storage, specifically focusing on Amazon S3 and its core components and features. In addition to standard storage capabilities, you’ll discover how Amazon S3 can also be used to host static websites, a feature that supports the design of modern web and mobile application solutions.

# An Introduction to Object Storage with Amazon S3

Object storage is an approach that utilizes objects containing data, metadata for contextualization, and an identifier.

Amazon S3 is a widely used object storage solution with high levels of security, scalability, and durability, making it a preferred choice for businesses of all sizes and industries. With Amazon S3, you can secure your data both in transit and at rest, thanks to its tight integration with Amazon Key Management Service (KMS), which offers encryption services. In addition, your objects are replicated and stored across multiple devices, across multiple Availability Zones within a given Region, offering higher levels of durability.
