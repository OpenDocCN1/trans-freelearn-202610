The service supports standard applications deployed on EC2 instances and Docker containers on **Elastic Container Service (ECS)**.

Because Elastic Beanstalk will work with your code to provide the necessary infrastructure and platform for your application, you will need to ensure that your code is built using supported languages such as Java, .NET, PHP, Ruby, Node.js, Python, and Docker web applications. Amazon Elastic Beanstalk supports the following development stacks:

+   - Java SE
+   - Apache Tomcat for Java applications
+   - Apache HTTPS Server for PHP and Python
+   - NGINX or Apache HTTP Server for Node.js
+   - Microsoft IIS 7.5, 8.0, and 8.5 for .NET applications
+   - Passenger or Puma for Ruby applications
+   - Docker
+   - Go and more
