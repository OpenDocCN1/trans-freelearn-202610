The AWS ::Serverless transform is a macro hosted by CloudFormation, which transforms the SAM syntax and expands it into a compliant CloudFormation template, allowing CloudFormation to build your serverless architecture. It specifies one or more macros that AWS CloudFormation uses to process your template. You can declare one or more macros within a template. AWS CloudFormation executes macros in the order that they are specified.

Some key components of the template are as follows:

+   - **Globals (optional)**: The Globals section allows you to declare resources with a common configuration. For example, you may have identical Runtime, Environment, or VPCConfig configurations that must be declared in your AWS ::Serverless ::Function resources. Rather than duplicating these variables in your individual resources, you can declare them in a Globals section and enable your resources to inherit them.
+   - **Resources (required)**: Within your SAM template, you can create several resource types. These include the following:
+     - `AWS ::Serverless ::Api`: Enables you to create a collection of API Gateway resources and methods that you can involve using HTTPS endpoints.
+     - `AWS ::Serverless ::Application`: Allows you to embed a serverless application from the AWS Serverless Application Repository or an S3 bucket as a nested application. This is useful for multiple applications that have common application components. By nesting those components, you can focus on the business logic unique to your application.
+     - `AWS ::Serverless ::HttpApi`: Enables you to create an HTTP API rather than a REST API, which is cheaper and offers low latency. Both the REST API and HTTP API are RESTful API products supported by API Gateway. However, a REST API offers more features, such as API keys, per-client throttling, request validation, integration with AWS WAF (Web Application Firewall), or private API endpoints.
+     - `AWS ::Serverless ::Function`: Enables you to create a Lambda function with a Lambda execution role and any event source mappings to trigger the function. An example of an event source mapping could be an SQS queue or an SNS topic.
+     - `AWS ::Serverless ::LayerVersion`: Enables you to create a Lambda LayerVersion resource that contains any required runtime code or libraries required by your Lambda function.
+     - `AWS ::Serverless ::SimpleTable`: Creates a DynamoDB table.
+   - **Parameters (optional)**: You can declare Parameters, which will allow sam deploy -guided to prompt the user for additional values. The sam deploy command is explained shortly.
