In *Chapter 6, Managing Multiple Databases with AWS Relational and Non-Relational (NoSQL) Databases*, you discovered the AWS Secrets Manager service, which is designed to store configuration data and secret information such as credentials often required by applications that need to connect to backend databases securely. This credentials data can then be dynamically retrieved and stored as environmental variables that the application can reference. This approach is much better than hardcoding credential data in the application source code. In addition, AWS Secrets Manager enables you to automate the rotation database credentials at scheduled intervals, enhancing your application stack’s security.

Following some of the best practices discussed in this chapter, you will learn how to deploy an RDS database instance external to the Elastic Beanstalk configuration and use AWS Secrets Manager to securely manage your database credentials.
