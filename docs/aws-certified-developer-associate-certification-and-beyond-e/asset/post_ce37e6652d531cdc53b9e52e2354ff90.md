7. Next, you must install the Docker engine on this server:

+   I. Type the sudo yum update -y command and press Enter. This will perform any pending updates to the OS. In most cases, no updates will be required. The use of sudo will elevate your privileges to run these commands.

+   II. Next, type in the sudo yum install docker command and press Enter. This will state the installation of the Docker package. You will be asked to confirm whether you want to download the packages and install them. Go ahead and type in y and press Enter.

+   III. Once the download and installation are successful, you will get the Complete! message, as shown in Figure 11.15:

![](img/34ff9b5b5a734dae3450ab701e223c73_471_1.png)

Figure 11.15: Successfully installed Docker

+   IV. Next, type in the clear command and press Enter. This should clear the screen so it's not too cluttered, making it easier to read.

V. Next, you will need to start the Docker service. Type in the sudo service docker start command and press Enter. You should get the following confirmation:

```
sh-5.2$ sudo service docker start
Redirecting to /bin/systemctl start docker.service
sh-5.2$
```

Figure 11.16: Starting the Docker service

VI. Next, you need to assign the ec2-user built-in account on this instance the ability to interact and work with the Docker service. Currently, this account does not have permissions, and these will need to be assigned by making ec2-user a member of the Docker group. Type in the sudo usermod -a -G docker ec2-user command and press Enter. The command will be accepted, and a new cursor line will appear.

VII. Next, to ensure that the new privileges are usable, you must log out of your session and log back in. Type in exit and press Enter. This will disconnect you from the session, and you must log back in.

VIII. Navigate back to the EC2 Management console, click on Instances in the left-hand menu, and then select the DockerImage-Server-01 instance on the right. Follow the procedure to connect to the example as described in project task 11.2 from steps 16 to 19.
