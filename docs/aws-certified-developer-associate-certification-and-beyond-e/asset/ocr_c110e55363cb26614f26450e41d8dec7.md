Now that you have set up an IAM user and an IAM group, you can ensure that all future exercises are carried out as the IAM user Alice. Avoid logging in as the root user for day-to-day operations, as this is a security risk. Although Alice has been assigned the AdministratorAccess permissions, there are several tasks that only the root user can carry out, including closing the AWS account down. Furthermore, the reason for granting administrative access to our user, Alice, in this exercise is to help you complete the remaining exercises in this study guide with ease.
