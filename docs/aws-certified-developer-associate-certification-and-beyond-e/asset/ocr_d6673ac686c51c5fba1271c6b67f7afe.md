In addition, you can also use several pseudo parameters that AWS CloudFormation defines. These parameters are predefined; you do not need to declare them in your template. These pseudo parameters include the following:

+   - **AWS::AccountId**: Returns the AWS account ID within which the CloudFormation stack is being created.
+   - **AWS::Region**: Returns the Region in which the resource is being created – for example, `us-east-1`.
+   - **AWS::StackId**: Returns the CloudFormation stack ID.
+   - **AWS::NoValue**: Used when you want to remove a corresponding resource property when using the `Fn::If` intrinsic function if the condition evaluates to false.

# Resources

The Resources section is the only **mandatory section** of any CloudFormation template. This makes sense since a CloudFormation template defines resources that must be deployed. Examples of resources that form a stack include VPCs, EC2 instances, and S3 buckets.

The format of the Resources section is depicted in the following snippet:

```
Resources:
  LogicalID:
    Type: Resource type
    Properties:
      Set of Properties
```

The resources section comprises several components, as follows:

+   - **Logical ID**: This is the logical name of the resources that you assign in the CloudFormation template. Logical names (IDs) must be unique throughout the template so that you can reference them where necessary. For example, for the Todo List application, the logical ID for an EC2 instance that will host the backend application might be **TodoAppEC2Instance**. Certain resources will also be assigned a physical ID. For example, the EC2 instance that CloudFormation deploys for the backend application will also have a physical ID, such as `i-29f8bg54`. This physical ID is defined once the EC2 instance has been created and allows you to reference the resource outside of CloudFormation templates.
+   - **Resource type**: This defines the type of resource that you want CloudFormation to create. For example, for the Todo List application, the resource type of **TodoAppEC2Instance** would be of type **AWS::EC2::Instance.**
