# Environment Configuration

This collection of settings controls how the environment and its associated resources interact. Where necessary, the configuration can be updated, which results in Elastic Beanstalk applying changes to existing resources or, if necessary, deleting and deploying new resources.

# Save Configuration

You can store the configuration as a template that can be used as a starting point for creating unique environments. It is particularly useful when standard configurations are used for environments that reflect different stages, such as development, testing, and production.
