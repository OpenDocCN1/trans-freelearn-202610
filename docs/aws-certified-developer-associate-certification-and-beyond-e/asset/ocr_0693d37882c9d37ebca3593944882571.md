+   19. Using File Explorer on Windows or the Finder on Mac, copy the `template.yaml` file you downloaded from the GitHub repository and paste it into the `todolistSam` folder. Confirm that you wish to replace the existing file in the folder. You can also use Command Prompt (on Windows) or Terminal if you wish to copy the file.

+   20. SAM will use CloudFormation to create the Amazon S3 bucket hosting the to-do list website. However, you also need to create another S3 bucket that will be used to store the deployment package containing all the different inputs for your infrastructure. This bucket will be used by CloudFormation. From a Command Prompt or Terminal window, type in the `aws s3 mb s3://<YOURWEBSITEBUCKETNAME.SAM> --region=us-east-1` command. Replace the placeholder value with the name of your bucket. The `.SAM` part at the end of the bucket name is to distinguish the website bucket from this bucket that will be used to store the deployment package.
