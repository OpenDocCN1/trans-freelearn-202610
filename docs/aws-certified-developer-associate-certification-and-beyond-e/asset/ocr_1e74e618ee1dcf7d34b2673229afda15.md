CloudWatch Logs Insights can quickly discover fields in logs from a wide range of AWS services such as Lambda, CloudTrail, and VPC Flow Logs, or any custom logs that deliver log events, such as JSON.

You can also use natural language to create CloudWatch Logs Insights queries. You can ask questions about or describe the data you’re looking for. The AI-assisted feature generates a query based on your prompt and delivers a line-by-line explanation of how the query works.

> **Important Note**
> 
> CloudWatch Logs Insights can’t access log events with timestamps that pre-date the log group’s creation.
