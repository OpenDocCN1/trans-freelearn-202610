# Create a CodeBuild Project

+   1. Next, you will need to create a CodeBuild project file. Ensure you are still logged in to your AWS development account as the IAM user, Alice.
+   2. From the top search bar, search for AWS CodeBuild and navigate to the CodeBuild web console.
+   3. From the left-hand menu, click on **Getting Started**, and then in the right-hand pane, click the **Create project** button.
+   4. Next, provide a name for your project, such as `todolist-frontend-build`.
+   5. Next, set the source provider as **AWS CodeCommit**.
+   6. For **Repository**, ensure that you select `todolist-frontend` (if you gave your frontend source repository a different name, make sure you select the correct one).
+   7. Select **main** from the drop-down list under **Branch**.
+   8. In the environment section, note the **Role name** for the IAM role that will be automatically created for you.
+   9. Next, scroll down to the **Buildspec** section and select **Use a buildspec file**.
+   10. Finally, click on **Create build project** at the bottom of the screen.
+   11. You should then receive a confirmation that the project has been created, as per *Figure 12.43*:

Note that an IAM role will be automatically created for you, which you will need to edit next. This update ensures you provide your project with the necessary permissions to update the frontend code hosted in the Amazon S3 bucket and perform the invalidation request on your CloudFront distribution. The role name depends on your build project name, so you should be able to identify it in IAM quickly.
