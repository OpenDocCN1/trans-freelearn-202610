## Project Task 7.4 – Create a Target Group

In this step, you will create a target group that will be used to route traffic to your targets, in this case, the EC2 instances deployed by the Auto Scaling service that will be configured with your application source files and necessary configurations. A target group will also perform health checks against its targets, identifying healthy and unhealthy ones and ensuring that the load balancer only directs traffic to EC2 instances in the healthy state.

When you configure listener rules for your ALB, you will define which target group to route the relevant traffic to. Hence, you would create the target group before any load balancer configuration.

In addition, when setting up a target group, you need to define the type of target you will be connecting to – in this case, it will be one of the following:

- **Instance**: Where the targets are specified by the instance ID
- **IP**: Where IP addresses specify the targets.
- **Lambda**: Where the target is a Lambda function
