*Principal* represents the trusted account in the preceding code snippet, and *Resource* defines the SQS queue.

In another example, if you configure Amazon S3 event notifications for an S3 bucket such that events trigger a notification that needs to be sent to an SQS queue, you will need to create an access policy that allows Amazon SQS to allow the S3 bucket to send the notification to the queue.
