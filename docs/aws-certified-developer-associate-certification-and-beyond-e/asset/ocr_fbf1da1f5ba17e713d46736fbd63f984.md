# Project Task 14.2: Configuring the AWS CLI with Bob’s Access Keys

In this project task, you will configure your CLI with Bob’s access keys so that you can interact with your AWS production account, access services, and provision the required resources for this project:

+   1. Log in to your AWS production account as the IAM user Bob.
+   2. Navigate to the IAM management console.
+   3. From the left-hand menu, click **Users**.
+   4. In the right-hand pane, select the IAM user **Bob**.
+   5. Select the **Security credentials** tab.
+   6. Scroll down till you get to the **Access keys** section.
+   7. Click the **Create access key** button.
+   8. For **Use case**, select the **Command Line Interface (CLI)** option.
+   9. Ensure you tick the **Confirmation** checkbox to acknowledge that you wish to proceed with the creation of an access key.
+   10. Click **Next**.
+   11. Provide a **Descriptive tag** value for your access key. This is used to help you identify the purpose of the access key, for example, `Access Key For Bob to use SAM`.
+   12. Click the **Create access key** button.
+   13. You should get a confirmation that the access key has been created. You will also find an option to download a `.csv` file, which will allow you to download your access key. Click on the **Download .csv file** button to download this file and save it to your desktop for easy access. Note that this file contains your access key ID and secret access key. Ideally, you want to store this file somewhere safe and ensure no one else can access it. Delete the file if you no longer need these access keys, after you have completed the project.
+   14. Next, you must configure your CLI with this access key. Launch Command Prompt if you are using Windows or Terminal if you are using Mac or Linux.
+   15. Type in the `aws configure` command and press *Enter*.
+   16. You will be prompted to enter the AWS access key ID. Copy the access key ID from the CSV file you downloaded in *step 13*, paste it into Terminal/Command Prompt, and then press *Enter*.
+   17. Next, you will be prompted to enter the AWS secret access key. Copy this key from the CSV file and paste it into Terminal/Command Prompt, and then press *Enter*.
