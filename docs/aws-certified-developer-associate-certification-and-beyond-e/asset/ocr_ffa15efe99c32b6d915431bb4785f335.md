# For macOS-based computers

+   10. Create an SSH Key Pair for macOS (If You’re Using a Mac Computer)
+   11. Launch the Terminal window on your Mac computer.
+   12. Navigate to the `ssh` directory using the `cd ~/.ssh` command, as per Figure 12.24:

![](bbox=[0.21, 0.2, 0.78, 0.27])

+   13. Next, type in the `ssh-keygen` command and press Enter.
+   14. Accept the default filename for your SSH key pair and press Enter.
+   15. Provide a passphrase for your keys and confirm the passphrase again when prompted.
+   16. You will then see a confirmation that your keys have been saved, as per Figure 12.25:
