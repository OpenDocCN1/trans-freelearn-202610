The intention here is to showcase how you can quickly deploy infrastructure using CloudFormation templates and allow you to appreciate how you can deploy solutions across multiple accounts for varying environments quickly and accurately.

# Technical Requirements

Keep in mind that you did not log in to the Todo Plus Production account when you created it using the AWS Organizations service, so you will need to navigate to the main sign-in page of the AWS Management Console and request a password reset for the root user of the Production account, as depicted in Figure 13.29. Specifically, you must provide the email address associated with the root user of the AWS account.

Also, make sure to download the CloudFormation template from the Git Hub repository at the following link and store it locally on your desktop: https://packt.link/xM0tt
