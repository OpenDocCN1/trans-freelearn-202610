# Project Task 8.3 – Create an Internal Network Load Balancer

In this exercise, you will create and deploy a network load balancer:

+   1. Ensure you are still logged in to your developer account and in the N. Virginia region.

+   2. Navigate to the EC2 Management console.

+   3. From the left-hand menu, select Load Balancers under Load Balancing.

+   4. In the right-hand pane, click the Create load balancer button.

+   5. Click the Create button under Network Load Balancer.

+   6. Provide a name for the load balancer, such as todo-list-nlb.
