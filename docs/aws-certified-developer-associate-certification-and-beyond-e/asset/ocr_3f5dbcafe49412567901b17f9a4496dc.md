In Figure 15.13, customer orders must be fulfilled in a strict order of first come, first served. This means your inventory service must update stock inventory following the order of successful transactions received. The inventory service can thus benefit from an SQS FIFO queue being subscribed to an SNS FIFO topic. The shipping service perhaps does not require strict ordering of messages because it might also need to consider the customer’s location to determine the method of dispatch and time of delivery.

The SNS FIFO topic ensures the deduplication of notifications using a deduplication ID or content-based deduplication. Furthermore, when publishing a message to an SNS FIFO topic, you set a message group ID, which defines which group the message belongs to. This group ID is passed to the SQS FIFO queues, which ultimately ensures that the messages of a particular group follow a strict order.
