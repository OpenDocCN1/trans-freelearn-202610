# Policy JSON Document

```
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "Stmt1700830761340",
      "Action": [
        "s3:GetObject"
      ],
      "Effect": "Allow",
      "Resource": "arn:aws:s3:::todoapprepo/*"
    }
  ]
}
```
