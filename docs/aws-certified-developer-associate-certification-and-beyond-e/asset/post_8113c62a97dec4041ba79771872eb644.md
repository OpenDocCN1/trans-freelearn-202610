### Project Task 3.1 – Create an Amazon S3 Bucket

The following steps will create an Amazon S3 bucket that will be used to host the frontend static website for the Todo List application. The Amazon S3 static website service can host all HTML and CSS content, as well as any necessary client-side scripts for all front-end functionalities. In addition, standard HTTP methods can be incorporated to call APIs from backend services as required:

1. Log in to the AWS development account that you provisioned in *Chapter 1, Introduction to AWS Accounts and Global Infrastructure*, and navigate to the **Amazon S3** service.
2. From the top right-hand corner of the screen, ensure that you select the **N. Virginia (us-east-1)** region, if not already in that region.
3. From the left-hand menu, click **Buckets**.
4. In the right-hand pane, click **Create bucket**.
5. Provide a name for your bucket. Remember, these are globally unique names. Bucket names can be between 3 and 63 characters long and must be in lowercase. They can contain numbers, dots (.), and hyphens (-) but must not be formatted as an IP address.
6. Uncheck all the boxes under **Block Public Access settings for this bucket** as per the following figure, and make sure you select the **I acknowledge that the current settings might result in this bucket and the objects within becoming public.** checkbox.

![](img/34ff9b5b5a734dae3450ab701e223c73_132_0.png)

7. Click the **Create bucket** button, and you should then get confirmation that your bucket has been created. You have now created your Amazon S3 bucket.

### Project Task 3.3 – Configure Bucket Policy and Permissions

In this step, you will create a bucket policy to make the bucket publicly accessible as the entry point of your web application. The following policy will need to be configured. Note that the highlighted portion of the Amazon S3 bucket **Amazon Resource Name (ARN)** will need to be modified to reflect the name of your bucket:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::REPLACE_WITH_BUCKET_NAME_HERE/*"
    }
  ]
}
```

1. In the Amazon S3 console, click on **Buckets** from the left-hand menu.
2. Click your bucket name in the right-hand pane to access its configuration details.
3. Select the **Permissions** tab from the right-hand pane, as shown in the screenshot:

![](img/34ff9b5b5a734dae3450ab701e223c73_135_0.png)

Figure 3.13 – The Permissions tab of the Amazon S3 bucket

4. Click the **Edit** button under the **Bucket policy** section.
5. Replace any default policies with the preceding policy, ensuring that you use the correct ARN for the bucket.
6. Click **Save changes** at the bottom of the page.
7. You should get a success message confirming the application of the new bucket policy.
