The components of the CloudFormation template is as explained below:

# Format version

This section of your template is optional and identifies the template's capabilities. AWS CloudFormation expects you to use the current template version, 2010-09-09. This is specified in the template as per the following code snippet:

```
AWSTemplateFormatVersion: "2010-09-09"
```

# Description

This section is optional. It enables you to provide some information about your template, which can be helpful for anyone who needs to review and use it:

```
Description: This template deploys a VPC for Todo Plus Limited, with a pair of public and four private subnets spread across two Availability Zones. It deploys an internet gateway, with a default route on the public subnets. It deploys a pair of NAT gateways (one in each AZ), and default routes for them in the private subnets.
```

# Parameters

AWS CloudFormation allows you to define parameters in your templates. Although an optional section, parameters are extremely valuable as they will enable you to provide additional configuration information when deploying your CloudFormation stack, especially if you cannot offer these configuration details ahead of deployment.
