In the fast-paced world of online services, application performance is not just a feature but the cornerstone of user experience. Expectations for instant access to content and seamless application performance are higher than ever. This is particularly true when your user base is globally dispersed, and you must ensure low-latency access to your content and applications.

This is where Amazon CloudFront, AWS’s robust **content delivery network (CDN)**, comes into play. It provides the backbone for high-speed, secure, and efficient content distribution.

In addition, you must provide a full suite of **Domain Name System (DNS)** services that ensure seamless access to your applications and resources. The ability to use custom domain names further enhances your business branding as does ensuring the best route to your resources while ensuring flexibility and failover capabilities. This is where Amazon Route 53, a fully managed DNS service, comes to the rescue.

From an exam perspective for the AWS Certified Developer – Associate certificate, CloudFront and Route 53 are services that can enable you to address application deployment strategies. CloudFront is a crucial component as it supports content caching, thereby reducing latency, which is a requirement for *Task Statement 3: Optimize applications by using AWS services and features of Domain 4: Troubleshooting and Optimization.* In addition, CloudFront lends itself well to further strengthening your security posture, as it can enforce secure access to content held at the origin.

This chapter delves into the intricacies of Amazon CloudFront and Route 53, exploring how these services enhance your application’s performance, availability, and resilience.

In the case of our fictitious client, **TodoPlus Limited**, Amazon CloudFront is a service that can offer all the features for their new upcoming **Todo List** application. Amazon CloudFront will offer both security features and low latency access with improved performance specifically for any static content that the application hosts. These could include training videos on using the application so that end users do not experience lag or buffering issues.
