+   In the right-hand pane, select the instance by clicking the checkbox next to the Name instance and click the Connect button.
+   
+   You have four methods of connecting to the instance. Select Session Manager and click the Connect button.
+   
+   This will connect you to the EC2 instance shell interface, as per the following screenshot:

![](bbox=[0.14, 0.36, 0.86, 0.57])

+   When connecting with Session Manager, you will have logged in with the SSM-User account. Change your user to the root user by typing in the `sudo su` command and press **Enter**.
+   
+   Perform the following steps to install the required software packages:
+   
+   Update the operating system by typing in the `yum update -y` command and pressing **Enter**. If there are no updates to perform, you will be notified.
+   
+   Type in `curl -fsSL https://rpm.nodesource.com/setup_20.x -o nodesource_setup.sh` and press enter.
+   
+   Type in `bash nodesource_setup.sh` and press **Enter**.
+   
+   Type in `yum install -y nodejs` and press **Enter**.
+   
+   Type in `npm i -g pm2` and press **Enter**.
