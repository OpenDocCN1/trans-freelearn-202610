3. Next, you need to deploy the application. Type in the following command, making sure to replace the [YOURSTACKNAME] placeholder with the name you defined earlier in the samconfig.toml file, then press Enter:

```
sam deploy --template-file packaged.yaml --stack-name [YOURSTACKNAME] --capabilities CAPABILITY_IAM
```

Note that CAPABILITY_IAM must be in capital letters.
