# Project Task 5.1 – Prepare AWS Systems Manager Session Manager for Your EC2 Instances

In this project task, you will perform some pre-requisite tasks to ensure you can use Session Manager to connect to your EC2 instances when you deploy them:

+   1. Log in to your AWS Developer account using the credentials of the IAM user Alice.
+   2. From the top search bar menu, navigate to AWS Systems Manager.
+   3. On the main splash screen, click the Get Started with Systems Manager button as per Figure 5.8. This will take you to the AWS Quick Setup page.
