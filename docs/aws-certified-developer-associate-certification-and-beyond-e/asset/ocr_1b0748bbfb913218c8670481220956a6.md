# CloudWatch Custom Metrics

AWS also enables you to define custom metrics. This is particularly useful when you want to send system-level metrics for your EC2 instances, such as memory and disk utilization, which are not available from the built-in metrics offered by CloudWatch. Another reason for using custom metrics is when you wish to capture data points for application-level metrics, such as the number of current viewers or transactions completed.

To capture system-level metrics such as **memory and disk usage** data points at the system level, you must install the **unified CloudWatch agent**. This agent can be installed on both EC2 instances and on-premises servers. The agent also lets you collect log files that can be ingested into CloudWatch. It’s important to note that besides installing your CloudWatch Agent on your EC2 instance or on-premises servers, you must ensure that the agent is configured with IAM permissions for CloudWatch.
