In the workflow illustrated in the preceding diagram, traffic from the **internet** on port 80 (HTTP) will be permitted from the internet to the ALB that you will deploy later in this study guide. Furthermore, EC2 instances running your application will be hosted in the app subnet and be associated with the app security group. This group will allow inbound traffic on port 80 (HTTP) from the ALB security group. This ensures that all internet-bound traffic must first connect to the load balancer and the load balancer then forwards that traffic to healthy EC2 instances.

Next, your EC2 instances will need to connect to backend databases running MySQL. To ensure that only authorized servers are permitted to connect to the database, you will configure the data security group to only accept inbound connections on port 3306 (MySQL) from EC2 instances that are associated with the app security group.

The following are the steps to configure the security group for the ALB:

+   1. Ensure that you are logged in to your AWS account and navigate to the VPC console. Ensure that you are also in the **N. Virginia** Region.
+   2. From the left-hand menu, select **Security groups** for the **Security** category.
+   3. In the right-hand pane, click the **Create security group** button.
+   4. Provide a name for your security group, such as ALB-Security-Group.
+   5. Under **Description**, provide an appropriate value such as `Security Group for Application Load Balancer`.
+   6. Under **VPC**, select **todolist-vpc**.
+   7. On the **Inbound rules** pane, click the **Add rule** button.
+   8. Configure an inbound rule for port 80 (HTTP) and set the source of that traffic to `0.0.0.0/0` as per the screenshot in Figure 4.19. You can also optionally add a description.
