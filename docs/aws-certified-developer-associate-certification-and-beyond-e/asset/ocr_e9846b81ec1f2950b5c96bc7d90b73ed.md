Your EC2 instance now has all the software packages you need to build out an AMI. In the next project task, you will create an AMI of this EC2 instance. This AMI can then be used to deploy your EC2 instances, which will perform all backend operations and host your APIs.

# Project Task 5.3 – Create a Custom AMI

You will now create an AMI of the current EC2 instance:

+   1. Ensure you are logged in to your development account as the IAM user Alice.
+   2. Navigate to the EC2 dashboard like before.
+   3. From the left-hand menu, select Instances.
+   4. In the right-hand pane, click the checkbox next to your Todo AMI Image Instance instance label, as depicted in Figure 5.16:

![](bbox=[0.145, 0.37, 0.87, 0.47])

+   5. You should ideally first shut down the instance before taking an image. From the Instance state drop-down list, select Stop instance.
+   6. You will be prompted for confirmation to stop the instance. Go ahead and click Stop.
+   7. Once the instance has shut down, from the Actions drop-down list, select Image and templates, and then select Create image, as depicted in Figure 5.17:

![](bbox=[0.145, 0.61, 0.87, 0.76])

+   8. You will be presented with the Create image page. Here, you will note that the EC2 instance is already listed as the one you are creating an image of.
+   9. Provide a name for your image – for example, todolist-worker-ami.
