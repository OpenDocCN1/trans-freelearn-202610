# ## Project Task 7.7 – Application Load Balancer

In this project task, you will deploy an ALB, which is used to distribute inbound traffic to the EC2 instances deployed by the Auto Scaling group. Load balancers enable you to distribute traffic across multiple instances that all provide access to the same application and thus facilitate high availability for your application. If one of the EC2 instances fails, the load balancers redirect any traffic to other healthy instances.

Although, in this chapter, you have been provided with instructions to build an internal ALB, feel free to experiment by deploying an Internet-facing load balancer. You will need to ensure that the load balancer is registered in the public subnets. You can then test the paths to the backend worker instances such as `/`, `/health`, and `/doc` for testing purposes. Once complete, terminate the load balancer and replace it with an internal facing one.
