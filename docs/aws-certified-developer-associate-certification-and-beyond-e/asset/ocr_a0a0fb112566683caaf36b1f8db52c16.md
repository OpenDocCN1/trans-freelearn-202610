# Project Task 12.1 – Prerequisites: Install Git on Your System

In this project task, you will install Git on your computer to manage your source repositories.

# For Windows-Based Computers

+   1. Navigate to https://git-scm.com/download/win.
+   2. Ensure that you download the correct standalone installer for your OS architecture. For example, for Windows 11, you will mainly require the 64-bit version.
+   3. Once downloaded onto your computer, run through the installation routine accepting the defaults, except for the following step (as per Figure 12.18), where you can select the Override the default branch name for new repositories option and set the initial branch to main:
