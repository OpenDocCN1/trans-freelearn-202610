# Query and Mutation Examples

+   - **Query**: A GraphQL query to fetch data might be set up to pull records from a DynamoDB table based on the DynamoDB primary key or any secondary indexes. In the AWS AppSync console, you would connect this query to a DynamoDB data source and configure the resolver to retrieve the data by `id`
+   - **Mutation**: Similarly, a mutation to update or insert data into DynamoDB would be defined in the GraphQL schema. For example, the following snippet shows how to add a new todo item:

```
type Mutation {
  addTodo(title: String!, description: String): Todo
}
```

The resolver for this mutation would specify how the data from the GraphQL request maps to the DynamoDB table attributes, typically using the Apache VTL template to format the request and handle the response. AWS AppSync uses VTL to translate client requests in GraphQL into requests your data source can understand. It also translates responses from the data source back into GraphQL. This allows you to manipulate your application standard requests and responses and handle things such as input validation and formatting, iterating through lists, maps, and arrays extracting required information, performing complex authorization checks, and much more.

The next section discusses how you can handle real-time data using subscriptions.

# Real-Time Data with Subscriptions

Subscriptions in AppSync are used for real-time data operations. When a mutation modifies data in DynamoDB, AppSync can automatically notify all subscribed clients with the new data, thanks to the integrated subscription mechanism with GraphQL.

Imagine a to-do list application where users can add, update, and track tasks. By integrating AppSync with DynamoDB, you can create a robust backend where the following apply:

+   1. Users submit GraphQL queries and mutations from the client application.
+   2. AppSync processes these requests according to the configured resolvers.
+   3. DynamoDB handles the data storage, ensuring high performance and scalability.
+   4. Changes to tasks are pushed in real time to all online users through GraphQL subscriptions, enhancing the collaborative experience.

Integrating AWS AppSync with Amazon DynamoDB enables developers to harness the full potential of serverless architectures by facilitating efficient data operations, real-time updates, and scalable solutions with minimal backend complexity. This integration is ideal for building dynamic web and mobile applications that require reliable, secure, and instantaneous data interactions.
