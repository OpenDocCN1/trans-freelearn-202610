# Asynchronous Invocation and Event Source Mapping

Lambda functions can be invoked synchronously (wait for the result) or asynchronously (queue the invocation). Lambda queues the event before processing for asynchronous invocation; if it fails, it retries automatically. Event source mapping is a way to connect a Lambda function to an event source, such as Amazon SQS or Kinesis, with built-in retries and failure handling.
