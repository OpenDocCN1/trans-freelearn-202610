# Message Visibility Timeout

Consumers of your SQS queue must poll the queue for new messages and then receive the message to process it. Along with the message, you receive a receipt handle related to the action of receiving the message. Once the processing is complete, the consumer must delete it from the queue by calling the DeleteMessage action and providing this receipt handle (instead of the message ID).

If you receive the message more than once and it is duplicated, each message will have a different receipt handle. When deleting the message after processing, you must provide the most recent receipt handle.

To ensure that the message is not processed by other consumers, Amazon SQS sets a visibility timeout period. The default timeout period is 30 seconds; other consumers cannot access that specific message. This allows the consumer who did receive the message to process it and then delete it from the queue.
