+   - **Private API Endpoints**: These are designed to be accessed from your Amazon VPC using an interface endpoint.

API Gateway incorporates several mechanisms to safeguard your APIs. It utilizes AWS IAM for access control, allowing you to define who can call your API. It can also integrate with Amazon Cognito or other identity providers to support user authentication and authorization, enabling you to build APIs requiring users to sign in with a user pool.
