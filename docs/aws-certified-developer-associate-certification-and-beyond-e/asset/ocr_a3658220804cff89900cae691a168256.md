# Project Task 11.7 – Create an ECS Cluster

The Amazon ECS cluster is a logical grouping of your tasks or services. The cluster enables you to define the VPC and subnets where your tasks will run, as well as the infrastructure capacity, which, in the case of our Todo List application, will be AWS Fargate:

+   1. In the Amazon Elastic Container Service web console, click **Clusters** in the left-hand menu. In the right-hand pane, click the **Create cluster** button.
+   2. Next, provide a name for your cluster, such as `todo-plus-cluster`.
+   3. Ensure that **AWS Fargate (serverless)** is selected under **Infrastructure**, as shown in Figure 11.31:

![](bbox=[0.131, 0.305, 0.851, 0.664])

Figure 11.31: Creating an ECS cluster

+   4. Click the **Create** button at the bottom of the page.

Your ECS cluster will take a few seconds to be created. In the next project task, you will configure the ECS service using the configuration in your task definition to build and deploy your containers in AWS Fargate.
