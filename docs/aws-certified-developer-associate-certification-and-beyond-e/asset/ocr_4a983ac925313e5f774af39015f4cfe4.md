As seen in the preceding code block, the details on the instance type are required when launching an EC2 instance, which is not hardcoded in the template. Instead, it is obtained by the value stored in the parameter, using the !Ref intrinsic function. This allows additional flexibility when deploying your CloudFormation stack. You can reference parameters and resources using the !Ref intrinsic function anywhere in your template.

When defining your parameters, you must specify the data type, as per line 4 of the previous code block. Data types can be of any of the following types:

+   *   **String**: Alphanumeric characters – for example, MyVPCName.
+   *   **Number**: This can be an integer or a float. Note that although CloudFormation will validate the parameter value as a number, when referenced in the template using the `!Ref` intrinsic function, the value will be passed as a string.
+   *   **List\<Number\>**: This can be an array of integers or floats.
+   *   **CommaDelimitedLists**: This is a list of strings separated by commas – for example, `test,dev,prod`.
+   *   **AWS-specific parameter types**: AWS defines these and helps to catch invalid values that the user might enter. AWS will validate users’ inputs against existing values in the AWS account. For example, the `AWS::EC2::VPC::Id` parameter type must match an existing VPC ID in the AWS account.
+   *   **SSM parameter**: This enables you to get a parameter value from the SSM parameter store. If the SSM parameter is shared from an external account, you must provide the full ARN of the parameter.

Several additional properties can be defined using the `Parameters` section. Some of these properties are as follows:

+   *   **AllowedPattern**: This enables you to define regular expressions (regex) in text to ensure they conform to a specific pattern. This allows you to validate entries and avoid errors quickly.
+   *   **AllowedValues**: This is an array of allowed values that can be used to define the parameter value.
+   *   **MaxLength**: This is an integer value defining the largest number of characters for `string` types. `MinLength` is the opposite, defining the smallest number of characters.
+   *   **MaxValue**: This is a numeric value defining the largest numeric value of the `number` types. `MinValue` is the opposite, defining the smallest numeric value allowed.
+   *   **NoEcho**: This is used when you need to prevent the value from being displayed in the console, such as a password for a database.
