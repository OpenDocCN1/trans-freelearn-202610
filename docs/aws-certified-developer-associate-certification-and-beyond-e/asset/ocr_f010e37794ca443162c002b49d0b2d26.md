# Technical Requirements

To complete the project tasks in this chapter, you must be logged in to the AWS Development account as the IAM user, Alice.

# Project Task 8.1 – Create a Security Group for the Network Load Balancer

In this exercise, you will create an additional security group in the Todo Plus VPC that will be used by the network load balancer you deploy later:

+   1. Log in to your AWS development account as the IAM user, Alice.
+   2. In the top search bar, search for VPCs and navigate to the VPC management console.
+   3. In the left-hand menu, select Security groups. In the right-hand pane, click on the Create security group button.
+   4. Provide a name for the security group, such as NLB-Security-Group, and an appropriate description. Ensure you select the todolist-vpc VPC, as depicted in the following screenshot:

![](bbox=[0.18, 0.435, 0.8, 0.73])

Figure 8.14 – Create a security group for the network load balancer

+   5. Do not create any inbound rules. Ensure that your outbound rules are set to allow all traffic.
+   6. Click the Create security group button at the bottom of the page.
