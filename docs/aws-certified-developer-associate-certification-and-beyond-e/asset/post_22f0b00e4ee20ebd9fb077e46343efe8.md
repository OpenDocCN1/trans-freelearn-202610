## 10. Designing Deployment Strategies with AWS Elastic Beanstalk

**Platform-as-a-service (PaaS)** solutions are designed to alleviate the complexity associated with infrastructure provisioning and allow developers to focus more on their application code, build, and deployment life cycle. **Amazon Web Services (AWS)** offers one such PaaS tool: **AWS Elastic Beanstalk.**

This is particularly crucial when working in live production environments, as the emphasis is on ensuring minimum disruption with the ability to roll back if necessary. It also covers security concepts, particularly those related to securely accessing application configurations and connecting to backend databases.

In this chapter, we examine Amazon Elastic Beanstalk as a tool for enabling developers to quickly provision the necessary environment to host and manage their applications and their life cycle.

### Introduction to Application Deployment with Amazon Elastic Beanstalk

Amazon Elastic Beanstalk is a PaaS offering from AWS that enables customers to easily deploy their applications by provisioning necessary underlying resources, hosting the application itself, and managing its life cycle.

Although, similar to Amazon CloudFormation (discussed later in this study guide), PaaS offerings such as Amazon Elastic Beanstalk focus on one specific application and provision any required resources to support hosting that application alone. Amazon CloudFormation, on the other hand, is an **infrastructure-as-code (IaC)** service, used to architect and build end-to-end infrastructure components that may be used to host multiple applications. Amazon Elastic Beanstalk uses Amazon CloudFormation to provision those underlying resources.

Although Amazon Elastic Beanstalk takes care of resource creation, it does offer the customer extensive control over how that infrastructure is built – for example, if you wish to deploy your application across multiple **Availability Zones (AZs)** in a given region across different network subnets to support high availability.

As per the following diagram, Amazon Elastic Beanstalk takes care of the entire environment build for the application, which will include any necessary network configurations (Amazon VPC), EC2 instances, web application environments (e.g., Apache, Tomcat, Node.js, etc.), together with supporting infrastructure components such as load balancers, autoscaling groups, and even **Amazon Relational Database Service (RDS)** databases.
