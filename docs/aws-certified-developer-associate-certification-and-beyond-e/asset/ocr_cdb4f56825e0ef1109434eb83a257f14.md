+   7. Try to access the application, and you should find that it still works perfectly.

+   8. You may delete the Auto Scaling group, the launch template, and the target group if you wish. These resources are not chargeable, so you can keep them running if you wish as long as the capacity specifications are set to 0.

You have now successfully migrated from the EC2 architecture, where you had to manage your instances, to a serverless Fargate architecture, reducing the administrative overhead on your part. In addition, you'll benefit from having a more agile and lightweight container environment in which to run your application stack.
