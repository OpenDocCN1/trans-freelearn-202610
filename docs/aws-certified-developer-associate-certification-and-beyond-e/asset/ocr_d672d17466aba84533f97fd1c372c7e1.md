# # Project Task 11.1 – Create an Amazon Elastic Container Registry (ECR) Repository

In this task, you will create a new repository in Amazon ECR to host your Docker (container) image:

+   1.  Log in to the AWS Development account as the IAM user Alice.
+   2.  Navigate to the ECR console by searching for the service in the search bar at the top of the AWS Management console home page.
+   3.  Check the region selected at the top right of the page to ensure that you are in the N.Virginia region.
+   4.  From the left-hand menu, select **Repositories**.
+   5.  In the right-hand pane, click the *Create repository* button.
+   6.  Under **Visibility settings**, select **Private**.
+   7.  Append the default repository name to identify your repository uniquely. For example, you can add the name **todo-plus** as per Figure 11.9.

![](bbox=[0.13, 0.42, 0.87, 0.71])

+   8.  Scroll to the bottom of the page and click the *Create repository* button.
+   9.  You will be redirected back to the list of repositories, and you should find your repository created for you. Ensure that you note the URL of this repository, as you will use it in the next project task.

Next, you will build a Docker image of the updated Node.js application, which will be used to build your containers.
