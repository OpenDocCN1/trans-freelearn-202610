# Amazon CloudWatch Logs

With CloudWatch Logs, you can capture, store, and monitor logging data. You can capture logs from other AWS services, such as VPC Flow Logs, CloudTrail, Elastic Beanstalk, Lambda, IoT devices, and on-premises servers. You can also store Route 53 DNS log requests.

CloudWatch Logs also allows you to capture system and application logging data from your operating systems and applications and ingest it into CloudWatch. For this type of logging data, you must install the CloudWatch agent or use the AWS SDKs, API, or CLI.

You can define expiration policies for your log files and encrypt your logs. You can review log data in CloudWatch Logs and send it to Amazon S3, Kinesis Data Streams, and Firehose.
