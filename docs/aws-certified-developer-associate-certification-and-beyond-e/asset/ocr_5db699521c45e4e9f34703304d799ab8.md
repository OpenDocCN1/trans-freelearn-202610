The application architecture, as shown in Figure 2.9, comprises several AWS components. Some of these are as follows:

+   - **Virtual private clouds (VPCs)**: These enable you to create isolated networks to separate workloads and applications. Certain services, such as EC2 instances, that offer virtual machine compute services, need to be hosted in a VPC. You will use VPCs to separate public-facing workloads from private ones for your Todo List application.
+   - **Amazon Cognito**: This offers authentication and authorization services for your web and mobile applications. As described in the preceding section, Amazon Cognito will allow end users to sign into the Todo List application.
+   - **Amazon S3**: This is a highly scalable and durable object storage platform that can also be used to host the static website for our Todo List application.
+   - **CloudFront**: This offers the ability to distribute and cache content at edge locations to ensure low-latency connectivity. CloudFront can also integrate with **Lambda@Edge** to offer added functionality for added functionality in response to the requests coming into CloudFront.
+   - **API Gateway**: This enables developers to create, publish, and manage their APIs. It is also used in accepting and processing up to hundreds of thousands of concurrent API calls, managing API traffic, offering **cross-origin resource sharing (CORS)** support, authorization, and access control, throttling, monitoring, and API version management.
+   - **Elastic Load Balancers**: These automatically distribute incoming application traffic across multiple targets and virtual appliances in one or more **Availability Zones (AZs)**. There are different types of load balancers, and which ones apply to our application solution are discussed later in this study guide.
+   - **Auto Scaling groups**: These offer the ability to add automatic scalability features to your fleet of compute resources, such as EC2 instances.
+   - **Amazon RDS**: This is a fully managed relational database service that will host all the Todo List data for end users.
+   - **AWS Secrets Manager**: This helps you manage, retrieve, and rotate database credentials and application credentials. You will be using AWS Secrets Manager to store the RDS database credentials for secure access.
