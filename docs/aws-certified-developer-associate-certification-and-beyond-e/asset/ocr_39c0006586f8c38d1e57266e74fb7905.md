# Project Task 12.3 – Create and Upload an SSH Public Key

To access AWS CodeCommit and upload the application code from your local machine, you will use the Secure Shell (SSH) protocol to configure encrypted connections for remote logins to AWS CodeCommit and perform file transfers.

# For Windows-based computer

+   1. Kindly generate an SSH Key Pair for Windows 10 and 11.

+   2. Ensure that OpenSSH is installed on your Windows computer. For instance, in our case, the service is pre-installed on our Windows 11 machine, as shown in Figure 12.21.

![](bbox=[0.13, 0.31, 0.855, 0.485])

Figure 12.21 – OpenSSH Client installed on Windows 11 computer

+   3. If you need to install the client, search for Settings in your Windows search bar, navigate to System, and click Add an optional feature, as per Figure 12.22.

![](bbox=[0.13, 0.585, 0.855, 0.715])

Figure 12.22 – Optional – Adding the OpenSSH client feature

+   4. Once you have confirmed the installation of the OpenSSH client, you can generate your public-private key pair.

+   5. Open Command Prompt by searching for cmd from the search bar on your Windows desktop.
