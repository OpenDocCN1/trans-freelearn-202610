## 前言

在云中开发和部署应用已成为现代商业技术计划中不可或缺的组成部分。随着组织踏上数字化转型之旅并将其应用迁移到云中，对能够开发、保护、部署和管理基于云的应用程序的熟练且获得认证的专业人才的需求呈现象级增长。

开发人员需要掌握各种架构设计模式的知识和实践技能——从虚拟机部署到容器，从事件驱动架构到松散耦合的无服务器解决方案。

本书旨在帮助你通过 AWS Certified Developer Associate（DVA-C02）认证，并获得雇主和客户所要求的宝贵实践经验。为此，本书从零开始设计，重点围绕一家虚构公司 Todo Plus Limited 的应用程序开发和部署展开。在给定场景中，该公司希望构建一个全球可访问、高可用、可扩展且安全的生产力 Web 应用。它必须在最有效的技术上做出战略决策，并专注于实现快速部署、降低管理开销、提升安全性，同时保持成本效益。

随着你逐步阅读本书，你将专注于培养技能，帮助你为应用技术栈选择合适的技术，从而应对各种用例。你将理解这些技术的核心理论概念，更重要的是，如何配置这些工具和服务以实际托管和支持你的应用程序。所有章节的项目练习中都提供了分步指南。这些将帮助你培养规划、配置和支持各种关键服务的专业知识，从而成功托管和管理你的应用程序。

本书涵盖了与 AWS Certified Developer Associate（DVA-C02）考试相关的主题，包括在设计应用时强调安全性、采用最佳实践构建松散耦合架构、整合自动化与**持续集成/持续交付（CI/CD）**DevOps 原则等。

学完这本学习指南后，你将拥有通过 AWS Certified Developer Associate（DVA-C02）考试所需的全部工具，并在应用开发、安全、部署和管理方面获得实际技能。

## 本书适合读者

本书适合准备参加 AWS Certified Developer Associate（DVA-C02）考试，并希望在 AWS 上开发、部署和维护应用方面获得实际技能的读者。

## 本书涵盖内容

*第 1 章，AWS 账户与全球基础设施简介，* 介绍了设置和配置 AWS 多账户架构以促进应用开发生命周期策略的基本安全概念。本章还涵盖了与 AWS 全球云基础设施相关的核心概念，这些概念是使用 AWS 服务并按照最佳实践启动资源的基础。

*第 2 章，使用 AWS Identity and Access Management 保护访问安全，* 重点介绍遵循**最小权限原则（POLP）**为 AWS 账户开发安全访问的方法，并研究了为托管在 AWS 上的应用构建强大身份验证和授权解决方案的策略。

*第 3 章，了解 Amazon S3 对象存储、混合存储和静态网站托管，* 重点介绍使用 Amazon S3 进行数据存储，其丰富的功能旨在帮助构建高可用和可扩展的云存储解决方案。本章还讨论了使用 Amazon S3 进行静态网站托管的核心优势——这是大多数云托管应用的入口点。

*第 4 章，使用 Amazon VPC 在云中构建私有网络，* 让读者深入理解如何在云中构建安全的私有网络。在设计以安全为首要考虑的应用解决方案时，通过防火墙和流量路由策略托管受限访问的后端服务至关重要。

*第 5 章，了解 Amazon EC2 和存储选项等 AWS 计算服务，* 讨论了虚拟机架构和配置选项的基础概念，用于托管应用的业务逻辑。你还将了解与 EC2 实例常配合使用的相关块存储和文件系统存储服务。

*第 6 章，使用 AWS 关系型和非关系型（NoSQL）数据库管理多个数据集，* 涵盖了托管、管理和操作数据是每个应用的核心。本章重点介绍可用于应用技术栈的各种数据库解决方案，涵盖安全、性能和可靠性的核心概念。

*第 7 章，构建具有高可用性、弹性和数据安全性的应用解决方案，* 重点在于构建高可用、可扩展的应用解决方案，减少停机时间并具备按需配置容量的灵活性。此外，本章还探讨了使用加密技术保护传输中和静态数据的数据安全基础知识。
