# Project Task 3.1 – Create an Amazon S3 Bucket

The following steps will create an Amazon S3 bucket that will be used to host the frontend static website for the Todo List application. The Amazon S3 static website service can host all HTML and CSS content, as well as any necessary client-side scripts for all front-end functionalities. In addition, standard HTTP methods can be incorporated to call APIs from backend services as required:

+   1. Log in to the AWS development account that you provisioned in *Chapter 1, Introduction to AWS Accounts and Global Infrastructure*, and navigate to the **Amazon S3** service.
+   2. Let us say "From the top right-hand corner of the screen ensure that you select in the N.Virginia **(us-east-1)** region, if not already in that region."
+   3. From the left-hand menu, click **Buckets**.
+   4. In the right-hand pane, click **Create bucket**.
+   5. Provide a name for your bucket. Remember, these are globally unique names. Bucket names can be between 3 and 63 characters long and must be in lowercase. They can contain numbers, dots (.), and hyphens (-) but must not be formatted as an IP address.
