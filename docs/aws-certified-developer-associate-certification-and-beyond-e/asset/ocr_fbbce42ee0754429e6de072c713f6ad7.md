+   9. From the AWS Management Console, search for IAM and navigate to the IAM console in a separate browser tab.

+   10. From the left-hand menu, select **Policies**.

+   11. In the right-hand pane, click **Create policy**.

+   12. Click the **JSON** button. This will bring up the **policy editor**.

+   13. Remove the existing sample policy and paste the JSON policy you created in the policy generator.
+   
+   An example policy is provided in the following code snippet. Replace the `YOUR BUCKET NAME` placeholder with the name of the bucket that you are using as the source code repository:

```
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "Stmt1716962066285",
      "Action": [
        "s3:GetObject"
      ],
      "Effect": "Allow",
      "Resource": "arn:aws:s3:::[YOUR BUCKET NAME]/*"
    }
  ]
}
```

+   14. Provide a name for your policy, such as `todo-list-s3-sourcecode-access-policy`, and an optional description.

+   15. Scroll to the bottom of the page and click the **Create policy** button.

+   16. You should receive a message notification stating that the policy has been created. You will be using this policy in the IAM role shortly.

Now that you have the source code bucket and configured it with an IAM policy, we can move on to *Step 2* of this project exercise.
