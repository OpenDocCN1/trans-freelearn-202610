# Project Task 6.2 – Integrating AWS Secrets Manager

In this project task, you will configure a secret to host the RDS database credentials data of the database you created in the previous task. As a recommended best practice, you will also configure credential rotation every seven days in accordance with TodoPlus Limited’s corporate policy.

# Prerequisite: Configure the VPC to Prepare for Secrets Manager

AWS Secrets Manager will need to update the credentials information of your Amazon RDS database inside a VPC. Furthermore, to automatically rotate the credentials, a Lambda function will be created in the VPC within the subnet group of your database. This Lambda function will need to communicate with Secrets Manager, so you will need to either grant the function access to the internet or create a VPC endpoint, both of which will allow the Lambda function to communicate with Secrets Manager, which is outside of your VPC.

To facilitate this outbound communication from the VPC, you will also set up a NAT gateway. This will enable the Lambda function to send traffic outside of the VPC. Note that the NAT gateway is a chargeable service and not part of the Free Tier offering:

+   1. From your AWS Management Console, navigate to Amazon VPC by searching for it in the search bar at the top of the screen. Open up the VPC console in a separate browser tab.
+   2. From the left-hand menu, click **NAT gateways**.
+   3. Next, from the right-hand pane, click **Create NAT gateway**.
+   4. Provide an appropriate name for your NAT gateway such as `todolist-nat`.
