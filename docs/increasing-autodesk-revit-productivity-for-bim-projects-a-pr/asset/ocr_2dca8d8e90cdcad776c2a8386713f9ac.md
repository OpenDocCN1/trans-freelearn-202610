The most common linked or imported files in Revit appear in the following formats:

+   - Native Revit files (*.RTV)
+   - AutoCAD files (*.DWG)
+   - IFC files (*.IFC)
+   - Rhino files (*.3DM)
+   - Point cloud files (*.RCP and *.RCS)

Suppose your project team is using any of these formats. In that case, we need to plan and ensure that every company can import and export files with the correct coordinate system to increase productivity and save time across multiple companies.

Let's take a look at an overview of the coordinate system of each application and the best practices to link files into Revit.
