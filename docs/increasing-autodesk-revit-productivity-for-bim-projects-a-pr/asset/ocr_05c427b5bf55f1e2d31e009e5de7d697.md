# Revit internal origin

The Revit internal origin helps you to identify the Revit internal coordinate system's starting point, which is at the X=0, Y=0, and Z=0 coordinates.

We should place the Revit model close to the Revit internal origin because the model geometry needs to be within the maximum distance from the Revit internal origin – a 16-kilometer (that is, 10-mile) radius.
