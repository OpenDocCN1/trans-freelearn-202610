# Annotating drawings with Keynote

The Revit Keynote process will improve our efficiency of annotating drawings because the specification will be associated with objects. If we change the keynote text, it will automatically update in all views and drawings. Keynote’s intelligence is essential to increasing productivity when producing and annotating drawings.
