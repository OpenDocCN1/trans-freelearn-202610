# Local files

The following points are essential for managing Local files:

+   - We should create a new Local file every time we want to open the Revit file.
+   - Always work from the Local file.
+   - Never open an old Local file or use the icons on Revit's opening screen:

![](bbox=[0.193, 0.256, 0.807, 0.622])

Figure 5.91 – Recent Files – Revit opening screen

+   - Synchronize frequently. We recommend doing so every 30 minutes or every time you make a significant change to the model.
+   - Avoid keeping the Local file open and inactive for a long period of time. It may slow down the Local files of your team, and it will take longer to synchronize. If you're going to a meeting, lunch, or leaving the company in the evening, close your Local file.
