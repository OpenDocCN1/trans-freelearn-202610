Figure 5.82 – Path for Revit Local files

We recommend creating a dedicated folder to save the Local files in, such as Revit_20XX_Local_Files (where 20XX is the Revit version), so that the Revit files aren't mixed up with other files located in the Documents folder.

The default path for the user files is C:\Users\<username>\Documents\ Revit_20XX_Local_Files\.
