Although it is possible to install as many packages as you want, it is recommended to keep the number of packages at the minimum required. Ensure that only trusted packages will be installed since, when executing them, this may corrupt the model.

Here is a list of some excellent packages that we recommend to be installed:

+   - Archilab.net
+   - Clockwork
+   - Lunchbox
+   - Rhythm
+   - Spring Nodes
