# How to use Dynamo Player

Dynamo Player is a handy feature that allows users to run a Dynamo script more simply without opening Dynamo. It can be configured to set a specific folder with a list of scripts with all users within an organization.

It is easy to keep the folder updated and ensure that all users will be using the same scripts.
