To create a new page, perform the following steps:

+   1. Open the 07.03_Overall Table.pbix file.
+   2. Press the + icon.
+   3. Double-click and rename the page Level 0.
+   4. Under Format options, change Page size to Letter:

![](bbox=[0.352, 0.244, 0.648, 0.313])

Figure 7.32 – New page created: Level 0

+   5. From the Overall page, while pressing the Ctrl key, select Title and Table and then press Ctrl+C.
+   6. On the new Level 0 page, click Ctrl+V.
+   7. Rename the title to add the level name: Luxury Villa - Level 0.

Now that we have the same table with the overall information, we need to filter this data to get only the data corresponding to Level 0.

+   8. To filter this page per level from Fields, select Level and drag it into the Filters tab under Filters on this page.
+   9. Tick Level 0:
