We advise that you always use the Survey Station Point as the primary option.

The second option will be the Ordnance Survey Map Grid Intersection Point.

We do not advise using the Building Coordinates Point and coordinates points from a structure project grid. There are two reasons not to use these points:

+   - The building coordinates point does not have a rounded number that can cause software inaccuracy (X=5514291.6539, Y=181598.9381). The software might display a rounded number (X=5514291.7, Y=181599.0), and maybe companies will begin using (X=5514291.7, Y=181599.0) instead of the correct coordinate.
+   - The structure project grid can change these positions during development.

> Tip
> Give preference to the survey station point or the Ordnance Survey Map grid intersections point when setting up the Revit project.
