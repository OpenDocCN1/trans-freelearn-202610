# Different visuals

When working with Microsoft Power BI, it is possible to use and combine different types of visualizations. However, it is possible to expand this capacity even more by installing different visuals.

There are some toolkits that can be acquired, and it will streamline the process of connecting Revit models with Microsoft Power BI. One of these is Tracer, which is basically a plugin that allows data information to be exported from Revit straight to Microsoft Power BI.

For more information, please visit the following link:

```
https://bit.ly/3r2ruWX
```
