We can increase productivity by recreating new Phase Filters as required in our project, thus facilitating usability. The Phase Filter description is essential to keeping things simple.

We suggest the following naming convention:

Sequential number + description + graphic overrides description

Some examples are as follows:

+   - 01-Existing-By Category
+   - 02-New-By Category
+   - 03-Demolition-By Category
+   - 04-Existing and New-By Category
+   - 05-Existing and New-Overridden
+   - 06-Existing and Demo-Overridden
+   - 07-New and Demo-Overridden
