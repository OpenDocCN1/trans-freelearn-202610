# Keynote types

There are three ways we can add keynotes:

![](bbox=[0.22, 0.14, 0.78, 0.37])

Let's look at these in detail:

+   - **Element Keynote**

We can apply the **Element Keynote** to component and system families, including walls, floors, roofs, and other Revit families.
