Before we can upgrade Revit files to a new Revit version, we need to consider a few factors:

+   If the project is at a late stage or in the Construction stage, consider working in the same version and not upgrading. That being said, if the required version is not available in the Autodesk Portal to be downloaded, you may need to ask for dispensation from Autodesk to use an old version of Revit.

+   Before the upgrade, you must get the agreement of the whole team.

+   Ensure that the Revit plugins you can used in the project can work in the new Revit version.
