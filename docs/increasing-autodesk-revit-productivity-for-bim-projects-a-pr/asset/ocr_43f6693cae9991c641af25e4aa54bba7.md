# Managing Revit plugins

Autodesk tries to improve Revit every year with a new release, but third-party plugins are necessary to increase productivity and run essential functions, such as batch printing PDF files.

We can download plugins from the Revit Autodesk App Store or directly from the developer website.

The Revit Autodesk App Store can be found at https://bit.ly/3uleRbQ.
