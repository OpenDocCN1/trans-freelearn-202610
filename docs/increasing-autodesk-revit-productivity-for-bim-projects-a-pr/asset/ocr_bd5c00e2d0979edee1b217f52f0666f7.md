# Text types

Text is an essential object as it will be used in almost all drawings. The BS-ISO 3098-0:1998 defines a range of text heights, including 1.8 mm, 2.5 mm, 3.5 mm, 5 mm, 7 mm, 10 mm, 14 mm, and 20 mm.

These settings can be accessed by clicking on Text Types, under Annotate:
