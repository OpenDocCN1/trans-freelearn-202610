# Installing packages

When sharing a Dynamo script, it is vital to ensure that all users will have the same packages that need to be installed to run it. This is very important as any user can install a package available by accessing it directly from Dynamo.

To install packages, perform the following steps:

+   1. Open Revit and, from the Manage tab, click on Dynamo.
+   2. From the top menu, click on Packages and select Search for a Package...:
