# The AutoCAD file position

After rotating Project North and trying to save the Revit file, you should get the following message:

![](bbox=[0.169, 0.183, 0.799, 0.55])

Figure 4.48 – AutoCAD position has changed

Click on **Save**. Saves the new position back to the link. and close the Revit file. This option will change the DWG position.

When you reopen the Revit files, you will not see this message again.
