# Global parameters

A global parameter is a parameter that is not assigned to a specific category and can be used in multiple objects from different categories.

For example, a global parameter can be used to control all of the window sill heights so that they are the same.

To access the global parameters, perform the following steps:

+   1. From the ribbon, click on Manage and then click on Global Parameters:
