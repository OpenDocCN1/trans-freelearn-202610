# Phase – Graphic Overrides

Graphic Overrides can be updated based on your company standards, and we can choose different colors to represent each Phase Status. The following Phase Statuses are available:

+   - **Existing**
+   - **Demolished**
+   - **New**
+   - **Temporary**
