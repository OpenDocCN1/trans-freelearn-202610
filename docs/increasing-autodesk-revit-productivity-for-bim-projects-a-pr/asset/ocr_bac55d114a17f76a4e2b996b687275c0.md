# Rhino files (*.3DM)

Many companies use Rhino to design complex geometry, and the Rhino design needs to be inserted in Revit for project documentation and to be part of the design development.

Unlike Revit, which has two coordinates systems, Rhino has only one coordinate system: the software internal origin at X=0, Y=0, and Z=0.
