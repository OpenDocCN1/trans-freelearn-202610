# Object styles

As mentioned earlier, object styles allow users to set all of the generic settings per category, regarding line weights (cut and projection), line colors, line patterns, and materials (if there is no material assigned to the element):

+   1. From the ribbon, click on **Manage** and then click on **Object Styles**:
