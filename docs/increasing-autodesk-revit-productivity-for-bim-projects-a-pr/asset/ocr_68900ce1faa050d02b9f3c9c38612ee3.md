+   1. Open a view that has a view template assigned.
+   2. From the View Control bar, click on Temporary View Properties and select Enable Temporary View Properties:
+   3. A purple rectangle will be visible wrapping the view, informing us that Temporary View Properties is on:
+   4. Access to all View Properties as needed.
+   5. To restore it to as it was, under the Temporary View Properties option, click Restore View Properties.
