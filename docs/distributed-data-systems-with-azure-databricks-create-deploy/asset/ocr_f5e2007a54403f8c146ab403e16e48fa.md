# StringIndexer

The PySpark StringIndexer class encodes a string column of labels into a column of labeled indices. These indices are in the range from 0 to numLabels, ordered by label frequencies. Therefore, the most frequent label will be indexed as 0. If the input column is numeric, the PySpark StringIndexer class will cast it to a string and index the string values.

The StringIndexer class takes an input column name and an output column name. Here, we will show how we can use it to index a column named cluster:

```
from pyspark.ml.feature import StringIndexer
df = sqlContext.createDataFrame(
    [(0, "a"), (1, "b"), (2, "c"), (3, "a"),
     (4, "a"), (5, "c")],
    ["id", "cluster"])
indexer = StringIndexer(inputCol="cluster",
                        outputCol="categoryIndex")
indexed = indexer.fit(df).transform(df)
indexed.show()
```
