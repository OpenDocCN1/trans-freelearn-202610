# Setting up Azure Blob storage

The first step is to create an Azure Blob storage account, as follows:

+   1. Search for **Storage account** in the Azure portal and select **Create a new storage account**.

+   2. In the **Create storage account** options, fill out the details and set the **Replication** option to **Locally-redundant storage (LRS)**, and for the **Account kind** option select **Blob storage**, as illustrated in the following screenshot:
