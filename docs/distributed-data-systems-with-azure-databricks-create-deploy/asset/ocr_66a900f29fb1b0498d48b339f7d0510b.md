```
splits = Array(Double.NegativeInfinity, 0.0, 1.0,
    Double.PositiveInfinity)
splits = Array(0.0, 1.0, 2.0)
```

The split values must be explicitly provided to cover all Double values.

Take into account that if you don't know which are the upper bounds and lower bounds of the targeted column, it is best practice to add Double.NegativeInfinity and Double.PositiveInfinity as the bounds of your splits to prevent any potential error that might arise because of an "out of Bucketizer bounds" exception. Note also that these splits have to be specified in strictly increasing order.

In the following example, we will show how you can bucketize a column of Double values into another index-wised column using the PySpark Bucketizer class:

+   1. First, we will make the necessary imports and define the DataFrame to be bucketized, as follows:

```
from pyspark.ml.feature import Bucketizer
splits = [-float("inf"), -0.5, 0.0, 0.5, float("inf")]
data = [(-0.5,), (-0.3,), (0.0,), (0.2,)]
dataFrame = sqlContext.createDataFrame(data,
    ["features"])
bucketizer = Bucketizer(splits=splits,
    inputCol="features",
    outputCol="bucketedFeatures")
```

+   2. Then, we can transform the original data into its bucket index, as follows:

```
bucketedData = bucketizer.transform(dataFrame)
display(bucketedData)
```
