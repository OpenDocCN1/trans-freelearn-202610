3. After we have identified the path to our dataset, we can then load images using the Spark API binary file as a data source. We could alternatively use the native Spark API image data source, but the binary file data source will provide us with more flexibility in the way in which we process the images:

```
images = spark.read.format("binaryFile") \
    .option("pathGlobFilter", "*.jpg") \
    .option("recursiveFileLookup", "true") \
    .load("/databricks-datasets/flower_photos")
```

4. After the data has been loaded, we can visualize it using the display function and limit the result to 5 records:

```
display(images.limit(5))
```
