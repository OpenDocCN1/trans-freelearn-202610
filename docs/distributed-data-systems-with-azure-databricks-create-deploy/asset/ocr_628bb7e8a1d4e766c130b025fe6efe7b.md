+   - **IDF**: `IDF` is a PySpark Estimator class that is fitted on a dataset and yields as a result an `IDFModel`. The `IDFModel` takes as input feature vectors, which in this case come from the `HashingTF` class, and scales each feature column. It will automatically lower weights applied on columns, depending on the frequency it appears on the corpus.

In the following example, we take as input an array of sentences. Each sentence will be split into tokens using the PySpark `Tokenizer` class, which will yield a BOW for each sentence:

+   1. Later—and, as mentioned, in the following code block —we will apply the `HashingTF` class to reduce the dimensionality of the feature vector:

```
from pyspark.ml.feature import HashingTF, IDF, Tokenizer
sentenceData = sqlContext.createDataFrame([
    (0, "Hi I heard about Spark"),
    (0, "I wish Java could use case classes"),
    (1, "Logistic regression models are neat")
], ["label", "sentence"])
tokenizer = Tokenizer(inputCol="sentence",
outputCol="words")
wordsData = tokenizer.transform(sentenceData)
hashingTF = HashingTF(inputCol="words",
                    outputCol="rawFeatures",
                    numFeatures=20)
```

+   2. Later, we will apply the IDF class to rescale the obtained features as a good practice when we use this in a machine learning or deep learning algorithm to avoid issues with gradients and generally improve the performance. The code for this is shown in the following snippet:

```
featurizedData = hashingTF.transform(wordsData)
idF = IDF(inputCol="rawFeatures",outputCol="features")
idFModel = idf.fit(featurizedData)
rescaledData = idfModel.transform(featurizedData)
```

+   3. Finally, we can display the obtained features, as follows:
