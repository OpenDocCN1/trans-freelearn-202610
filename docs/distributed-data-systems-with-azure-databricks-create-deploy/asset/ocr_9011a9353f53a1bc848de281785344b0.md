+   - **Upserts and deletes**: It supports DDL manipulations such as merges, delete, and updates thanks to the use of Spark APIs, enabling you to work with cases such as streaming data or SCD operations.
+   - Performance is boosted thanks to automatic data optimization, such as data skipping to read only relevant portions of data, file compression, catching frequently accessed data, and Z-Ordering.
