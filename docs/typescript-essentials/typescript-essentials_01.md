## 前言

本书是学习 TypeScript 语言的快速实用指南。本书全面介绍了 TypeScript 在 JavaScript 之上提供的语言特性，并配有动手示例。TypeScript 是一种相对较新的开发语言，可以减轻普通 JavaScript 开发的痛苦。从下载编译器、涵盖语言特性，到实现动态应用程序，本书将使您做好准备，创建新的大型基于 JavaScript 的应用程序。

## 本书涵盖内容

[第 1 章](#), *使用 TypeScript 入门*, 介绍了为开发 TypeScript 应用程序设置环境并创建简单应用程序的方法。

[第 2 章](#), *TypeScript 基础*, 介绍了 TypeScript 在 JavaScript 之上创建的主要语言特性，以及这些特性如何编译为纯 JavaScript。

[第 3 章](#), *TypeScript 编译器*, 考察了 TypeScript 编译器及其接受的不同参数。不同参数的结果将被讨论，以及它们如何影响最终的 JavaScript 输出。

[第 4 章](#), *使用 TypeScript 进行面向对象编程*, 全部关于面向对象编程的基础知识。您将了解 TypeScript 添加的优势，使 ECMA Script 成为更完善的面向对象语言。

[第 5 章](#), *创建简单的绘图应用程序*, 指导您使用本书中已涵盖的概念创建简单的绘图应用程序。到本章结束时，您将创建一个基于网络的绘图应用程序，这将使您很好地理解如何使用 TypeScript 编写复杂应用程序。

[第 6 章](#), *声明文件和库集成*, 讨论声明文件以及它们如何帮助我们与其他 JavaScript 库集成。jQuery、KnockoutJS 和 RequireJS 等库将被涵盖。

[第 7 章](#), *增强绘图应用程序*, 重新审视绘图应用程序，并向您展示如何创建更可重用的对象集合。将创建模块定义，并涵盖代码压缩的过程。

[第 8 章](#), *调试 TypeScript*, 讨论部署和运行 TypeScript 后可用的不同调试选项。我们还涵盖单元测试和测试驱动开发，这将使我们能够用代码测试功能。

## 阅读本书所需条件

TypeScript 具有独立的编译器安装，因此任何文本编辑器都可用于开发 TypeScript 应用程序。本书提供的示例将使用 Microsoft 的 Visual Studio，建议您也使用它以便跟上示例；但是，这不是必需的。需要对 JavaScript 和 Web 开发有基本了解，因为并非每个语言结构都会被涵盖；只是 TypeScript 在其之上提供的那些。

本书旨在向任何希望开发丰富的 Web 应用程序的人介绍 TypeScript 语言及其特性。无论您是 Web 开发新手，还是拥有扎实 JavaScript 技能的经验丰富的工程师，本书都将帮助您快速编写代码。需要对 JavaScript 及其语言特性有基本了解。
