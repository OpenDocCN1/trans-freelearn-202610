# 第 3 部分 – 为 Django 应用 Docker 化并设置 CI 流水线

在本部分，我们将学习如何将 Docker 集成到我们的 Django 项目中。我们可以使用 Docker 创建一个平台无关的 Django 应用，使生产环境的设置和部署更轻松。我们将学习如何使用版本控制软件 (`git`) 工作并探索如何设置我们的 CI 流水线。我们将学习使用 CI 流水线的不同自动化，并了解如何为我们的 Django 应用实施代码审查流程。

本部分包含以下章节：

*   *第 11 章*，*Dockerizing Django Applications*
*   *第 12 章*，*Working with Git and CI Pipelines Using Django*
