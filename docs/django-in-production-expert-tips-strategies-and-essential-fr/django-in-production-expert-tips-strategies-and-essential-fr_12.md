# Part 4 – Deploying and Monitoring Django Applications in Production

AWS 是领先的云提供商，在行业中被广泛用于托管 Web 应用。在本部分，我们将学习如何使用 AWS 部署我们的 Django 应用。我们将使用 Amazon RDS、Amazon ElastiCache、AWS Elastic Beanstalk 和其他 AWS 服务在生产环境中托管我们的 Django 应用。在本部分，我们还将学习如何监控我们的 Django 应用。我们将学习如何将不同的工具集成到我们的 Django 应用中，例如错误监控工具（如 Rollbar）和 **Application Performance Monitoring** (**APM**) 工具（如 New Relic）。

本部分包含以下章节：

*   *Chapter 13*，*Deploying Django in AWS*
*   *Chapter 14*，*Monitoring Django Applications*
