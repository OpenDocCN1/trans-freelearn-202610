

[*第6章*](#B18867_06.xhtml#_idTextAnchor145)，*缓存、日志记录和节流*，涵盖了缓存的所有概念以及如何将 Redis 与 Django 集成用于缓存。日志记录是生产环境中任何 Web 应用程序的关键组件，在本章中，我们将学习如何将日志记录集成到 Django 应用程序中。

[*第7章*](#B18867_07.xhtml#_idTextAnchor157)，*使用分页、Django 信号和自定义中间件*，涵盖了 Django 的所有高级概念。开发人员可以使用 Django 信号编写解耦的代码。Django 还提供了创建自定义中间件的灵活性，这可以帮助开发人员改进功能。

[*第8章*](#B18867_08.xhtml#_idTextAnchor169)，*使用 Celery 与 Django*，展示了如何为 Web 应用程序处理异步任务。在本章中，开发人员将了解如何将 Celery 集成到 Django 项目中。

[*第9章*](#B18867_09.xhtml#_idTextAnchor179)，*在 Django 中编写测试*，涵盖了为 Django 编写测试用例的核心概念。在本章中，你将学习编写测试用例时应遵循的最佳实践，并了解为项目编写测试用例的重要性。

[*第10章*](#B18867_10.xhtml#_idTextAnchor204)，*探索 Django 中的约定*，展示了在与 Django 协作时使用的所有最佳实践和约定。本章涵盖了许多有主观性的概念，你应将本章作为大纲阅读，并根据自己的判断挑选/学习相关概念。

[*第11章*](#B18867_11.xhtml#_idTextAnchor219)，*Docker 化 Django 应用程序*，涵盖了如何将 Docker 与 Django 应用程序集成。

[*第12章*](#B18867_12.xhtml#_idTextAnchor233)，*使用 Git 和 CI 管道与 Django 协作*，涵盖了版本控制的概念以及如何在 Django 项目中高效使用 Git。在本章中，你将学习如何集成 GitHub Actions 来创建 CI 管道。

[*第13章*](#B18867_13.xhtml#_idTextAnchor256)，*在 AWS 中部署 Django*，涵盖了如何使用不同的 AWS 服务在生产环境中部署 Django 应用程序。在本章中，你将学习如何在生产环境中部署和扩展 Django 应用程序。

[*第14章*](#B18867_14.xhtml#_idTextAnchor283)，*监控 Django 应用程序*，涵盖了如何在生产环境中监控 Django 应用程序。生产环境中需要不同类型的监控，例如错误监控、应用程序性能监控、正常运行时间监控等等。在本章中，你将学习如何集成市场上可用的不同工具来监控 Django 应用程序。
