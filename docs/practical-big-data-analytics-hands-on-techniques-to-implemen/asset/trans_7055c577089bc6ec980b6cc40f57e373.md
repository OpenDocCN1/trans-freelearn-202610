## 前言

本书向读者介绍企业中使用的与大数据相关的广泛主题。大数据是一个庞大的领域，涵盖了技术、统计、可视化、商业智能以及许多其他相关学科。为了从数据中获得真正的价值，而这些数据往往由于数据量或技术限制而无法访问，公司必须在软件和硬件层面都利用适当的工具。

为此，本书不仅涵盖了大数据的理论和实践方面，还补充了高层主题，例如企业中使用大数据、大数据和数据科学计划以及关键考虑因素，如资源、硬件/软件堆栈和其他相关主题。这样的讨论对于计划实施或升级组织大数据和/或数据科学平台的组织中的 IT 部门将非常有用。

本书侧重于三个主要领域：

## 1. 大规模数据集上的数据挖掘

大数据今天无处不在，就像不久前 *数据仓库* 一词无处不在一样。行业中有无数种解决方案。特别是，Hadoop 及其生态系统中的产品已成为企业中既受欢迎又日益常见的选择。此外，更近期的创新，如 Apache Spark，也在企业中找到了永久的位置——意识到他们可能不需要 Hadoop 框架的复杂性，Hadoop 客户已大量转向 Spark。最后，NoSQL 解决方案，如 MongoDB、Redis、Cassandra 以及 Teradata、Vertica 和 kdb+ 等商业解决方案，已取代了更传统的数据库系统。

本书将以相当大的深度涵盖这些领域。Hadoop 和相关产品，如 Hive、HBase、Pig Latin 等已被涵盖。我们还涵盖了 Spark 并解释了 Spark 中的关键概念，如 Actions 和 Transformations。NoSQL 解决方案，如 MongoDB 和 KDB+ 也已得到相当程度的涵盖，并且还提供了动手教程。

## 2. 机器学习和预测分析

第二个被涵盖的主题是机器学习，也以各种其他名称为人所知，例如预测分析、统计学习等。提供了详细的解释，并附有使用 R 和 R 中机器学习包编写的相应机器学习代码。随机森林、支持向量机、神经网络、随机梯度提升、决策树等算法已被讨论。此外，机器学习中的关键概念，如偏差和方差、正则化、特征选择、数据预处理等也已被涵盖。

## 3. 企业中的数据挖掘

通常，涵盖理论主题的书籍很少讨论大数据的高层方面——例如成功的大数据计划的关键要求。本书包含了来自 IT 高管的调查结果，并突出了行业中普遍存在的共同需求。本书还包括一步一步的指南，说明如何根据在大型 IT 部门部署生产解决方案的经验教训，选择正确的使用案例，无论是用于大数据还是基于机器学习。

我们相信，通过对这三个领域的扎实基础知识，任何从业者都可以交付成功的大数据和/或数据科学项目。这就是本书整体结构和内容的首要意图。

## 本书适合谁

本书面向多样化的受众。特别是，渴望从整体层面理解大数据、数据科学和/或机器学习概念的读者，即它们如何相互关联，将从本书中获得最大收益。

**技术受众：** 对于技术倾向的读者，本书包含大数据和机器学习的关键行业工具的详细解释。涵盖了使用 Hadoop 的动手练习、使用 R 编程语言开发机器学习用例、构建使用 R Shiny 的全面生产级仪表板。Spark 和 NoSQL 的其他教程也已包含在内。除了实践方面之外，这些关键技术的理论基础也已得到解释。

**商业受众：** 对大数据的广泛理论和实践处理已补充了关于在工作场所部署和实施稳健大数据解决方案的细微差别的高层主题。IT 管理、CIO 组织、商业分析和其他负责定义公司数据战略的团队将发现此类信息非常有用且可直接应用。
