

## 结构化

顾名思义，结构化数据指的是具有明确组织结构的数据集，例如 Microsoft Excel 或 CSV 文件。从纯数据库角度而言，这类数据可以通过模式（schema）来表示。例如，联合国发布的 2017 年世界幸福指数排名中位列前五的*最幸福*国家所对应的下表，就是结构化数据的典型代表。

我们可以清晰地定义各列的数据类型——排名、得分、人均GDP、社会支持、健康预期寿命、信任、慷慨度和 dystopia 是数值列，而国家则用字母表示，更具体地说，是**字符串**。

诸如 Teradata、Greenplum 等商业数据库，以及开源领域的 Redis、Cassandra 和 Hive，都是提供管理和查询结构化数据能力的技术示例。

## 非结构化

非结构化数据是指任何没有预定义组织模式的数据集，不像上一节表格那样具有明确的组织结构。口头语言、音乐、视频，甚至书籍，*包括本书*，都会被视作**非结构化**。这绝不意味着内容没有组织。事实上，一本书有目录、章节、小节和索引——从这个意义上说，它遵循了确定的组织方式。

然而，将每个词和句子都表示为严格规则集的一部分是徒劳的。一个句子可以由单词、数字、标点符号等组成，并且不像电子表格那样有预定义的数据类型。若要成为*结构化*的，这本书的每个句子都需要具备一组精确的特征，这既不合理也不切实际。

来自社交媒体的数据，例如 Twitter 上的帖子、Facebook 上与好友的消息以及 Instagram 上的照片，都是非结构化数据的例子。

非结构化数据可以以各种格式存储。它们可以是 Blob，而对于文本数据，则可以是存储在数据存储介质中的自由格式文本。对于文本数据，通常使用 Lucene/Solr、Elasticsearch 等技术来进行查询、索引和其他操作。

## 半结构化

半结构化数据是指同时具备组织模式元素和任意性方面的数据。一个个人电话通讯录（如今越来越少见了！）包含姓名、地址、电话号码和备注等列，就可以视为半结构化数据集。用户可能不知道所有联系人的地址，因此一些条目可能只有电话号码，反之亦然。

同样，备注列可能包含额外的描述性信息（例如传真号码、与该联系人相关的亲属姓名等）。这是一个允许用户添加补充信息的任意字段。因此，姓名、地址和电话号码列可以看作结构化的，因为它们可以用表格格式呈现；而备注部分则被认为是非结构化的，因为它可能包含一组任意的描述性信息，无法在通讯录中的其他列中表示。

在计算领域，**半结构化**数据通常以 JSON 等格式表示，这些格式可以封装结构化和无模式或任意的关联，通常使用键值对。一个更常见的例子是电子邮件消息，它既有结构化部分（如发件人姓名、消息接收时间等），这些对所有电子邮件都是通用的；也有非结构化部分，由电子邮件的正文或内容表示。

MongoDB 和 CouchDB 等平台通常用于存储和查询半结构化数据集。

## 大数据来源

当今技术让我们能够以惊人的速度收集数据——无论是在数量还是种类方面。有许多数据来源，但在大数据背景下，主要来源如下：

- **社交网络：** 可以说，我们今天所知的所有大数据的主要来源是过去5-10年间迅速普及的社交网络。这基本上是非结构化数据，以数百万计的社交媒体帖子和通过全球用户在网上的互动按秒生成的其他数据为代表。全球互联网接入的增加对于社交网络中数据的增长来说是一种自我实现的行为。

- **媒体：** 很大程度上是社交网络发展的结果，媒体代表了每天发生的数百万（甚至数十亿）次的音频和视频上传。上传到 YouTube 的视频、SoundCloud 上的音乐录音以及 Instagram 上发布的图片都是媒体的主要例子，其数量继续以不受约束的方式增长。

- **数据仓库：** 公司长期以来一直投资于专门的数据存储设施，通常称为数据仓库（DW）。DW 本质上是公司希望保留和编目以便于检索的历史数据集合，无论是用于内部使用还是监管目的。随着行业逐渐转向将数据存储在 Hadoop 和 NoSQL 等平台的实践，越来越多的公司正在将数据从他们原有的数据仓库迁移到一些更新的技术中。公司电子邮件、会计记录、数据库和内部文档是 DW 数据的一些例子，这些数据现在被转移到 Hadoop 或类似 Hadoop 的平台上，这些平台利用多个节点提供高可用性和容错能力。

- **传感器：** 大数据领域一个较新的现象是从传感器设备收集数据。虽然传感器一直存在，石油和天然气等行业几十年来一直在石油钻塔上使用钻井传感器进行测量，但可穿戴设备（也称为物联网）的出现，例如 Fitbit 和 Apple Watch，意味着现在每个人都可以以十年前几个石油钻塔所拥有的速率来流式传输数据。

  可穿戴设备可以在任何给定时刻从一个个体收集数百个测量数据。虽然目前还不算真正的大数据问题，但随着行业的不断发展，传感器相关数据可能会变得更像通过社交网络活动在网上产生的自发数据。

## 大数据的 4V

在大数据的背景下，4V 这个话题已经被过度使用，开始失去一些最初的魅力。尽管如此，记住这些 V 所代表的意义有助于了解背景语境，以便进行对话。

总的来说，4V 表示如下：

- **Volume（数据量）：** 正在生成的数据量
- **Variety（数据种类）：** 不同类型的数据，如文本、媒体、传感器或流式数据
- **Velocity（数据速度）：** 数据生成的速度，例如在任何给定时间通过社交网络交换的数百万条消息
- **Veracity（数据真实性）：** 这是较新加入 3V 的一个 V，表示数据中固有的噪声，例如记录信息中的不一致之处，需要额外的验证

## 如何判断你是否面临大数据问题，以及从哪里开始寻找大数据解决方案？

最后，大数据分析指的是让数据发挥作用——换句话说，通过使用适当的技术从大量数据中提取有用信息的过程。许多用于表示不同类型分析的术语并没有确切定义，因为它们可以被不同地解释，因此含义可能是主观的。
