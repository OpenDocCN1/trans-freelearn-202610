# Creating a JSF Data Table

Next, generate a client class for the web service. Right-click on the web service node and select **Generate Web Service Proxy**.

![](bbox=[0.175, 0.19, 0.825, 0.525])

In the **Shared Service Endpoint Interface** window, click on **Yes**. In the **Port Endpoints** window, select **Run Against a service deployed to Embedded OC4J** checkbox and click on **OK**. A client class for the web service gets added to the project.
