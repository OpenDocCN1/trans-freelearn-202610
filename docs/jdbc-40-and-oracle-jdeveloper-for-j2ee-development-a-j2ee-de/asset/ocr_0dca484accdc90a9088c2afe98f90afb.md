# Configuring JDBC in WebSphere Application Server

In the Summary page, the summary of the JDBC Provider configuration is displayed. Now, click on the Finish button.

![](bbox=[0.225, 0.173, 0.775, 0.426])

The settings specified are applied to the local configuration. On clicking the Save link in the Messages frame, the changes are applied to the master configuration.
