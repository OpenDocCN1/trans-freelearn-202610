A data source is configured and added to the **Data Sources** table. The data source is registered with the JNDI name, with the help of a naming service and a target server that are deployed by the data source and also listed in the data sources table:

![](bbox=[0.3, 0.205, 0.7, 0.37])

Make the data source available to the applications in the server, by clicking on the **Activate Changes** button. Until the **Activate Changes** or **Undo All Changes** button is selected, a web application is not deployed to the WebLogic server.

# Configuring a Data Source

The data source created in the previous section will be configured. Select the data source to be configured in the Data Sources table, and also select the **Configuration** tab, which is the default setting. In the **Configuration** window, the data source JNDI name can be modified:
