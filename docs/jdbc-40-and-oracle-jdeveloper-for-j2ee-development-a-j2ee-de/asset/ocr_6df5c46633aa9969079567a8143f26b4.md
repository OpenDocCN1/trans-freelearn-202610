Create a JDBC connection to the Oracle database from the JDeveloper IDE. To create a connection select the Connections tab, select the Database node in the Connections Navigator, right-click on the Database node, and select New Database Connection. In the Create Database Connection (Type) window displayed, specify a Connection Name and set Connection Type to Oracle(JDBC).

![](bbox=[0.21, 0.41, 0.79, 0.71])

Click on Next. In the Authentication window, specify the Username and Password and click on Next. In the Connection window, specify the Driver type, Host Name, JDBC Port, SID and click on Next.
