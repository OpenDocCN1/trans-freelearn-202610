# Configuring JDBC in Oracle JDeveloper

In the **Authentication** window specify **Username** as **root** (**Password** is not required to be specified for a root user by default), and click on **Next**. In the **Connection** window, we will specify the connection parameters, such as the driver name and connection URL; click on **New** to specify a Driver Class. In the **Register JDBC Driver** window, specify Driver Class as com.mysql.jdbc.Driver and click on **Browse** to select a Library for the Driver Class. In the **Select Library** window, click on **New** to create a new library for the MySQL Connector/J 5.1 JAR file. In the **Create Library** window, specify Library Name as MySQL and click on **Add Entry** to add a JAR file entry for the MySQL library. In the **Select Path Entry** window select mysql-connector-java-5.1.3-rc\mysql-connector-java-5.1.3-rc-bin.jar and click on **Select**. In the **Create Library** window, after a Class Path entry gets added to the MySQL library, click on **OK**. In the **Select Library** window, select the MySQL library and click on **OK**. In the **Register JDBC Driver** window, the MySQL library gets specified in the Library field and the mysql-connector-java-5.1.3-rc\mysql-connector-java-5.1.3-rc-bin.jar gets specified in the Classpath field. Now, click on **OK**. The Driver Class, Library, and Classpath fields get specified in the **Connection** window. Specify URL as jdbc:mysql://localhost:3306/test, and click on **Next**.
