Because we created an Oracle data source using a non-XA JDBC driver select Non-XA Driver. In the **Add Data Sources** window, add data sources from the **Available** list to the **Chosen** list. If a new data source is required, click on the **Create a New Data Source** button, and then click on **Finish**.
