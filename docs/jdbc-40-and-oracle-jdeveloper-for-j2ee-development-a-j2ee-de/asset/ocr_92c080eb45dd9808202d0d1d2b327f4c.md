# Creating a JSF Panel Grid

Right-click on the **catalog.jsp** node and select **Run**. The panel grid with the initial values specified in the input fields is displayed:

![](bbox=[0.198, 0.188, 0.802, 0.575])

To update a database table row specify the Catalog Id for the row and the input field values, and click on the **Submit** button. The input field **Catalog Id** is specified as a **Required** field. If an input value is not specified in the **Catalog Id** field a validation error is generated. The validation error gets displayed in the message component column.
