# Creating a JSF Panel Grid

Add another row of **Output Label** and **Output Text** components. Next, add a row of command buttons to the panel grid.

![](bbox=[0.176, 0.189, 0.823, 0.439])

In the **Property Inspector**, set the text on the **Output Labels** and the command buttons. To specify the text value for a component, click on the component and specify the text value in the **Value** property in the **Property Inspector**.
