# Creating a JSF Panel Grid

In the **PanelGrid Options** window, select the Javabean class, **PanelGridBean** in the **Class** field and click on **Next**.

![](bbox=[0.225, 0.19, 0.77, 0.47])

In the **Fields Selection** window sort the order of the selected fields to correspond to the **OE.CATALOG** database table columns. Click on **Next**.

![](bbox=[0.205, 0.54, 0.795, 0.825])
