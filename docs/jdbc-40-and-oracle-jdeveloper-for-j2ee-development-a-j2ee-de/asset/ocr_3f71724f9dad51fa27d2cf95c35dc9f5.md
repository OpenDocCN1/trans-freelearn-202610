# XSQL

In an XSQL page, a database connection may be specified as a global connection using the `connection` attribute in the `page` tag. If some of the XSQL page elements use a different connection specify the connection using the `connection` attribute in the individual elements. The `connection` attribute in an element overrides the global connection. Similarly add another page param, `PUBLISHER` with value "Oracle Publishing" Next, add an `xsql:Query` element. Position the cursor in the XSQL page and select **Query** in the XSQL Component Palette.
