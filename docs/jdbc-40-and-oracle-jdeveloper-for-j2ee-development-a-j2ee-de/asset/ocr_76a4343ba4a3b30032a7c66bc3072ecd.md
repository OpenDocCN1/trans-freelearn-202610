# Configuring JDBC in WebSphere Application Server

In the **Create Deployment Profile** window, specify a deployment profile name, webapp1, and click on ok. In the **WAR Deployment Profile Properties** window, select the **General** node. Specify a J2EE web context root, websphere (for example) and click on ok.
