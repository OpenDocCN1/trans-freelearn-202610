# Configuring JDBC in JBoss Application Server

Click on Finish in the Finish window. A JBossConnection node gets added to the Application Server node in Connections navigator.

![](bbox=[0.358, 0.19, 0.643, 0.387])

We will deploy the web application that we created to the JBoss application server. First, in order to create a deployment profile for the web application, select File | New. In the New Gallery window, select General | Deployment Profiles in Categories and WAR File in Items, and click on OK.
