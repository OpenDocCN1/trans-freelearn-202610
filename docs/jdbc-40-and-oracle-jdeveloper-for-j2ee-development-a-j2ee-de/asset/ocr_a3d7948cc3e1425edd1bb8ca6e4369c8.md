The selected operations can be run by commenting out the methods that are not required. To map a database table, JOURNAL, to an XML document, comment out invocations to all the methods except the sqlToXML() method. To run an XMLToDatabase.java application, in JDeveloper right-click on the application node, and select Run.

The output from the application generates an XML document, catalog-output.xml, in which a journal element has been removed. To add the catalog-output.xml to XSU project, click on the project node and select View | Refresh.
