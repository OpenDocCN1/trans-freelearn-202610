To view the data represented by a view object as XML select **View | Data As XML**. A window for the view object XML data is displayed

The SQL query used to create a view object may be modified in the **View Object Editor**. Right-click on the view object node and select **Edit CatalogView**. In the **View Object Editor** window select the **SQL Statement** node. By default the `SELECT` list and the `FROM` clause of the SQL query are automatically defined. To override the default setting of the `SELECT` list and the `FROM` clause, check the **Expert Mode** checkbox. As an example, specify a `WHERE` clause for the SQL query. Click on the **Apply** button to apply the changes to the SQL query.
