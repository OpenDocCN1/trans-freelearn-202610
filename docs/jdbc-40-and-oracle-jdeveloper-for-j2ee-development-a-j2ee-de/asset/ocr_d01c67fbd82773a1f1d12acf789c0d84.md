# Creating a JSF Data Table

In the Error Page Options window, select the default setting, which is to not use an error page, and click on Next. In the Tag Libraries window, the JSF HTML and JSF Core tag libraries are pre-selected. Data Table is a JSF HTML tag library component. JSF Core tag library implements the standard JSF core tags. Click on Next.
