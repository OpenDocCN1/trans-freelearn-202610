Select **All Types** in the **Filter By** selection. Select the `dataResultSet` variable from the `CatalogBean` MBean that we generated earlier. The **Expression** represents an EL expression for the data objects collection returned by the `dataResultSet` method of the Web Service client class, which was encapsulated in the `CatalogBean` MBean.
