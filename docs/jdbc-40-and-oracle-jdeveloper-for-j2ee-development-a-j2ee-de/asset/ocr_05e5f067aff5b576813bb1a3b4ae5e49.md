# Creating a JSF Panel Grid

An Output Label is added to the JSF page. Position the cursor to the right of the output label with the right arrow key and select Input Text in the Component Palette.

![](bbox=[0.177, 0.19, 0.823, 0.44])

An input text field gets added to the JSF page. To add another component to the JSF page, position the cursor to the right of the previous component with the right arrow key. Next, add an Output Label. The output label gets added in a new row as the panel grid has only two columns.
