# Developing Hibernate Mapping and Properties Files

The Hibernate mapping file (a .hbm.xml file) and the Hibernate properties file (hibernate.properties file) form the basis of a Hibernate application. The mapping file consists of class definitions. Each class definition consists of a set of properties to be mapped to a Java class and a database table. The field/column types and additional characteristics of the columns such as length, not-null, and unique are also specified with the properties.
