# XSQL

Bind variables can be set using the values of URL parameters, session variables, cookie values, or page parameters. In our example, we'll set XSQL query bind variables with page parameters. Bind variables, specified with the `bind-params` attribute in the `<xsq1:query>` tag, are used in the SQL statement within the `<xsq1:query>` tag. The bind variables are represented with '?' in a SQL statement. The value of the bind parameters is specified with the `<xsq1:set-page-params/>` tag. Position the cursor in the XSQL page and select **Set Page Param** component in the Component Palette.
