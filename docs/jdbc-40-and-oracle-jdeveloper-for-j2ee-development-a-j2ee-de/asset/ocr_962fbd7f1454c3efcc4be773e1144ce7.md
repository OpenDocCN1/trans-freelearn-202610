# Configuring JDBC in WebSphere Application Server

Click on New in the Data sources table to create a new data source.

![](bbox=[0.22, 0.175, 0.777, 0.459])

Specify a JNDI name for the data source. In the Component-managed authentication alias field, select the J2C authentication alias that we have configured earlier, and click on Next.
