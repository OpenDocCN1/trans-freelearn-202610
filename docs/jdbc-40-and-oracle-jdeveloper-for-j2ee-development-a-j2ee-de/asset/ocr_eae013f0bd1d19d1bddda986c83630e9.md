Select the default installation options, and click on **Next**. The webapp1 enterprise application has a web module, webapp1.war. In the **Map modules to servers** window, specify the server to which the web module is to be deployed. Select the webapp1.war module, select the WebSphere server node and click on **Apply** and then click on next.

![](bbox=[0.215, 0.238, 0.785, 0.517])

In the **Map virtual hosts for web modules** frame, select the checkbox adjacent to the webapp1.war file, and select default_host as the virtual host. Click on the **Next** button.
