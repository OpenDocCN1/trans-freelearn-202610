Another new feature JDBC 4.0 provides is support for the for-each loop to iterate over chained exceptions and chained causes. Chained exceptions are exceptions that are linked to an exception. In JDBC 3.0, chained exceptions could only be retrieved by invoking the getNextException method recursively. Using the Java SE chained exception facility in JDBC 4.0 chained exceptions and chained causes may be retrieved as follows:

```
catch(SQLException e){
for(Throwable e : exception ) {
out.println("Error encountered: " + e);
}
}
```
