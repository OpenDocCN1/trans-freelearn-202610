Next, add a JSF page to the project with File | New. In the New Gallery window, select Web Tier | JSF in Categories and JSF JSP in Items. In the Create JSF JSP wizard select J2EE 1.4 in the Web Application window and click on Next. In the JSP File window specify a File Name and click on Next. In the Component Binding window select the Automatically Expose UI Components in a New Managed Bean. The backing bean name, class and package are pre-specified. Click on Next.
