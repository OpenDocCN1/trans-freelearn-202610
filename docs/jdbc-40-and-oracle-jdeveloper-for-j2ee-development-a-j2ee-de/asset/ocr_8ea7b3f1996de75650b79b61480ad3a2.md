Next, add a JSF JSP page, catalog.jsp, to the project with File | New. In the New Gallery window select Web Tier | JSF in Categories and select JSF JSP in Items. Click on OK. Next, we will create a managed bean from the Java Bean class. Open the faces-config.xml configuration file node in the Applications Navigator and select the Overview tab in the editor window. Select the Managed Beans node (if not already selected). Click on New to add a new managed bean.
