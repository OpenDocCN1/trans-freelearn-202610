Now, we can proceed with creating a private pool. To create your private pool, begin by sourcing the required environment variables and creating a private pool configuration file called private-pool.yaml under the infra/ directory, as follows:

```
$ cat > infra/private-pool.yaml <<EOF
privatePoolV1Config:
  networkConfig:
    # egressOption: NO_PUBLIC_EGRESS
    peeredNetwork: projects/$PROJECT_ID/global/
networks/$PRIVATE_POOL_VPC_NAME
  workerConfig:
    machineType: e2-standard-2
    diskSizeGb: 100
EOF
```

The most important parts with regard to security in this configuration file are under the networkConfig stanza. Private pools, given that they are fully managed by Google, operate similarly to GKE control planes in that they are given access to resources in your VPC via VPC peering.
