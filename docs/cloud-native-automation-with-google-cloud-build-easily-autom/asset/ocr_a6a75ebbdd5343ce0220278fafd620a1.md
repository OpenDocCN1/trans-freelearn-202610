It is in this field where you declare the `availableSecrets` you would like to use at some point in your build, as well as where you are pulling them from. It is recommended that you utilize **Secrets Manager** to store sensitive credentials that you will be using in your builds; we will review this, in detail, in *Chapter 8, Securing Software Delivery to GKE with Cloud Build.*
