```
subnetwork = data.terraform_remote_state.vpc.outputs.
subnet_name
}
}
```

The subnetwork references remote state from our VPC configuration. The VPC Terraform configuration outputs the subnet_name value that will be used by our GCE VM.

Similar to the Terraform backend configuration, the remote state references the VPC state in the GCS bucket and path specified by the VPC backend.

```
data "terraform_remote_state" "vpc" {
  backend = "gcs"
  config = {
    bucket  = "${PROJECT_ID}"
    prefix  = "tfstate/vpc"
  }
}
```

In the pipeline, folders are used to separate the resources, so the Cloud Build steps need to know where to find the appropriate Terraform configurations – we use the dir notation to signify where to execute the terraform commands.

```
- id: 'tf init - vpc'
  name: 'hashicorp/terraform:1.0.0'
  dir: chapter07/terraform/multiple/vpc
  env:
  - "TF_IN_AUTOMATION=true"
  entrypoint: 'sh'
```
