# Creating a new dashboard

A new dashboard can be created by selecting Dashboard from the drop-down menu and choosing the +New option. The new dashboard will be blank with a very small pop-out menu to the left of the row. From that pop-out menu, new panels can be added. The menu on an example dashboard is shown here:

# Creating a graph

Open the pop-out menu for a row and go first to Add Panel then to Graph. The graph editor will then be displayed. There are a lot of options. Do not panic. Most of them are simple with obvious functions. The most complicated is the Metrics tab. This is where the metrics are chosen to be displayed on the graph.
