If etcd shows as healthy, you can check on the status of Flannel with sudo systemctl status flanneld.

When Flannel starts, it creates an environment file named /run/flannel_docker_opts.env. This file is loaded by the docker.service unit file to configure Docker's networking to use Flannel. Because the Docker daemon is configured to use Flannel, there is no need to specify any special networking options when you use docker run.

Now, verify Docker was correctly configured by Flannel to use the subnet for its Docker bridge:
