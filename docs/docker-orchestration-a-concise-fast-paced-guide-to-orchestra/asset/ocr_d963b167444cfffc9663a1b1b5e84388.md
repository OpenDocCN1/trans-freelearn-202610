# ## Using Heapster in Kubernetes

Heapster is a Kubernetes service that collects node and pod metrics and makes them available through InfluxDB and Grafana or through Google Cloud Monitoring. It is installed by default when Kubernetes is installed with `kube-up.sh`. Full details on accessing metrics from Heapster are available at http://kubernetes.io/docs/user-guide/monitoring/.
