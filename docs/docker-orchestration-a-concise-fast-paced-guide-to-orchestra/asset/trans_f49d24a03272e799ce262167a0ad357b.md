## 关于作者

**Randall Smith** 是 Adams State University 的高级系统管理员。他自 1999 年起一直管理 Windows、Linux 和 BSD 系统。

他积极帮助其他系统管理员解决线上和线下问题。他在 Colorado Higher Ed Computing Organization 和 Educause 会议上就包括 Linux KVM 和 Ceph 在内的主题进行过演讲。
