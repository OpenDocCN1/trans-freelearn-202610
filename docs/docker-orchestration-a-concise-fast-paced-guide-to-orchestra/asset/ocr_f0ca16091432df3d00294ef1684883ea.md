+   * Third, /var/run/docker.sock is mapped into the container so that sysdig can retrieve information about running Docker containers.

Once sysdig has been installed, run the command cysdig to start the curses interface. This provides a top-like interface which lets you see what is happening on the server. Use F2 to switch views. The -pc flag adds container information to many of the views that are available:

```
$ cysdig -pc
```

Sysdig can be invaluable in troubleshooting a problem on a system in real time. Each view has options to drill down and see more information about a specific thing, which may be a container, network connection, host process, or any number of other items.
