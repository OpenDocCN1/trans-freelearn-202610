# Logging into the web interface

After DC/OS is installed, it will be possible to log in using the web interface. Mesosphere uses OAuth for authentication with Google, GitHub, or Microsoft accounts. After you have logged in, you will be directed to the Mesosphere **Dashboard**. From there you can start managing applications or install the command-line client, `dcos`:
