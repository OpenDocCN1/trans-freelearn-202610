# # Creating a new chart

To create a new graph, click on Visualize, select the chart type, and then select the name of the index. Logstash data will be in the indices matching the logstash-* pattern. You will then be taken to a page to create the graph:

+   1. Click on the arrow next to Y-Axis to show the options.
+   2. Select the Aggregation method. The Average method works well in most cases.
+   3. Select a Field. Obviously, this will vary depending on the data that is being graphed.
+   4. Optionally, set the Custom Label for the axis.
+   5. Additional metrics can be added:
