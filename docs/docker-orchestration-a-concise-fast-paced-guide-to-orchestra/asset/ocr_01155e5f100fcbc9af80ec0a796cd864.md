# Viewing pods

A list of running pods is available by running `kubectl get pods`. Adding `-o wide` will show the pod's IP address and the node that the pod is running on:

```
$ kubectl get pods
NAME        READY     STATUS    RESTARTS   AGE
simple      1/1       Running   0          12s
$ kubectl get pods -o wide
NAME        READY     STATUS    RESTARTS   AGE       IP            NODE
simple      1/1       Running   0          1m        10.246.46.5   kubernetes-node-1
```

The details of a pod are available using the `kubectl describe pod` command. Everything you need to know about a running pod is displayed in the output of `describe`. The following command displays the details for a pod named `simple`:
