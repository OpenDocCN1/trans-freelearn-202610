```
networks:
frontend:
driver: bridge
backend:
driver: bridge
```

This example builds on the simple multi-container application from the earlier section. This time, there are two networks defined, named frontend and backend, which uses the standard Docker bridge network. Start the application with docker-compose up:

```
$ docker-compose -f docker-compose-networks.yml up
```

If you log into the web container, you will see that Docker has created two NICs in the container, not counting the loopback interface:
