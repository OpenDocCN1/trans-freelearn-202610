Docker Datacenter also supports running applications with Docker Compose. To run an application, go to **Applications** and click on **Compose Application**. You will be prompted for an application name and a compose file. The compose file, can be pasted into the box or uploaded from a file on your desktop. You can also use `docker-compose up` from your desktop or management server to launch applications:
