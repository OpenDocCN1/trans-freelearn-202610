9. You will be setting the table properties for the Title field (see the preview in the dialog box). Select the General tab first.

10. In Properties, set the following:

+   - Fill color: None
+   - Alignment: Middle Center
+   - Type: Label
+   - Margins: 25 (Horizontal and Vertical)

Leave Merge Cells on row/column creation checked.
