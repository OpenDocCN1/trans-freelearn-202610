Autodesk has created the AutoCAD mobile application as part of the AutoCAD Web offering to allow DWG files to be used while mobile. This could be on a construction site or perhaps a factory floor setting. The AutoCAD user experience is maintained with an interface like AutoCAD Web, reminiscent of the AutoCAD desktop.

Also, note that the AutoCAD mobile application is *not* a full working version of AutoCAD on a smartphone or tablet. There are a limited number of AutoCAD commands and features available, but there are enough to easily review, edit, and update any 2D DWG file.
