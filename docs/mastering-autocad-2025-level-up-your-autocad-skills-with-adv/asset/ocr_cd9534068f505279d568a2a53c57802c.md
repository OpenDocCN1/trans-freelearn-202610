# Setting up specific leader styles

In the **Training-ANNO** dimension style, which is now current in the New Office Proposal.dwg file, you had set **Dot** for **Leader** lines in the **Symbols and Arrows** tab, as shown in *Figure 7.21.*

![](bbox=[0.132, 0.18, 0.837, 0.718])

This dimension style setting will apply to any leaders you may create using the older **Quick Leader (QLEADER)** command. You can find out about this leader annotation method in the AutoCAD Help files here:
