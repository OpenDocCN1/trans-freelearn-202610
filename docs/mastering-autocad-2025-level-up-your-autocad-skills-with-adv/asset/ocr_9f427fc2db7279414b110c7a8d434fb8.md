# # Denkmalgeschützte Villenkolonie in Berlin-Niederschöneweide

Die denkmalgeschützte Villenkolonie umfasst Klinkerfassade, Atelierhaus, Galeriehaus, Torhaus und fünf Fabrikantenvillen der ehemaligen Margareten-Aue genannt, Ziegelwerk von 1870 (Gesamtanlage).

# ## Bauten der Villenkolonie

+   - Klinkerfassade
+   - Atelierhaus
+   - Galeriehaus
+   - Torhaus
+   - fünf Fabrikantenvillen
