Various object snap modes are checked in the dialog box, and those checked are known as the running object snaps. It is a good idea to check only some checkboxes. Otherwise, this will make for a frustrating drafting experience! The object snaps selected in Figure 3.17 comprise a good start. Once the object snap modes are set, click OK to close the dialog box.

There is also a flyout menu for Object Snap, as there is for Polar Tracking. When the flyout arrow is clicked, the flyout menu shown in Figure 3.18 displays, allowing you to change your running object snap selection quickly and easily. Those that are switched on have a check mark displayed next to them.
