# Zoom

Zooming in and out of your drawing is essential for you to see close-up details in your drawing, as well as being able to view the overall design. The Zoom icon on the navigation bar provides a flyout menu that gives access to the AutoCAD Zoom commands. Figure 3.29 shows the Zoom flyout menu activated.

The flyout provides a menu listing all the AutoCAD Zoom commands, which are selected by clicking on them. The most recent Zoom command will then display on the navigation bar until the next Zoom command is chosen. The most current Zoom command is highlighted with a check mark on the flyout menu.
