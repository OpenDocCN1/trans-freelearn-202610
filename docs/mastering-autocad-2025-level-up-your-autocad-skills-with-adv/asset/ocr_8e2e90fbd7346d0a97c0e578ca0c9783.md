The AutoCAD mobile application uses the standard iOS interface, including finger gestures for zooming and panning. It also supports the Apple Pencil with an iPad. If you have the Apple tech available (or similar), it is worth checking how it works.

The command panel is at the bottom left, and the icon menu is on the right-hand side of the screen. Note that the icon menu uses the same icons as the AutoCAD Web application. This is to maintain the consistency of the user interface across the AutoCAD Web offering and AutoCAD desktop.
