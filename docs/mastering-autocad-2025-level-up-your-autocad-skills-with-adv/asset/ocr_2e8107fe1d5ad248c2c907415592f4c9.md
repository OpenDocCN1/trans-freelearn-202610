You should already have the exercise file, `New Office Design.dwg`, open from the previous section. You will now create a new blank library drawing, save it with a different filename, and add blocks to it.

You will do this by adhering to the following workflow:

+   1.  With the `New Office Design.dwg` file still open, check the file tabs underneath the ribbon at the top of the AutoCAD screen, as shown in *Figure 9.17*. You will see the **Start** tab and the **New Office Design** tab. A tab with a + (plus) symbol is also displayed. Click on that tab to open a new blank drawing file (note that you may need to turn off the **Grid** setting on the status bar).
