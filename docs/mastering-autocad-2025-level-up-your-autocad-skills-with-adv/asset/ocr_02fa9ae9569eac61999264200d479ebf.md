The markups and/or comments added are saved back to connect to the drawing file when you save the shared view(s) in the Autodesk Viewer.

If you now return to AutoCAD and the drawing and click on the Refresh icon in the Shared Views palette (top right, as shown in Figure 13.28), you will see the shared view, the date it was created, and its expiry period. All shared views last for 30 days. You will also see that it has one comment.
