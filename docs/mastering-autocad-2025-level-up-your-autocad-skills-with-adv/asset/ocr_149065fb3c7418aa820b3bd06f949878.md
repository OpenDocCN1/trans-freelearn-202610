Make sure that you have the following drafting settings switched on:

+   - **Object Snaps** (*OSNAP*)
+   - **Polar Tracking** (*POLAR*)
+   - **Object Snap Tracking** (*AUTOSNAP*)

You'll need the following Osnaps switched on:

+   - **Endpoint**
+   - **Midpoint**
+   - **Intersection**
+   - **Center**

You'll also need to have applied the following polar angle increment: 90, 180, 270, 360...
