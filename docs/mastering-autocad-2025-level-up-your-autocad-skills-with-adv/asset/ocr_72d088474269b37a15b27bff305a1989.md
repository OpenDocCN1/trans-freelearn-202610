The current file tab is the **3D Solid** file tab, highlighted in bold on the file tab itself and in bold on the drop-down menu. The drop-down menu allows you to select any file listed to make it current, such as by clicking the corresponding file tab.

*Figure 3.3 shows how if you hover over a filename in the drop-down list, you are also given options to go to the **Model** and **Layout** tabs for the file hovered over. This is a highly efficient way to navigate the files open in an AutoCAD session.*
