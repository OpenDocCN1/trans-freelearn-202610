**Tips and tricks #23**
When working with dimension styles, there is often a need to remove unused dimension styles from the drawing file to maintain file size and for general housekeeping of your DWG files. To do so, you can right-click over non-used dimension styles in **Dimension Style Manager** and use **Delete** in the shortcut menu (see *Figure 7.19*). You can also remove non-used dimension styles with the **Purge** (*PURGE*) command.

**AutoCAD for Mac**
When creating a dimension style in AutoCAD for Mac, you will find the **Dimension Style** icon in the **Dimension** panel in the left-hand toolbar. When working with dimension styles in Mac, the dialog boxes are similar but use the usual Mac interface, as shown in *Figure 7.20*.
