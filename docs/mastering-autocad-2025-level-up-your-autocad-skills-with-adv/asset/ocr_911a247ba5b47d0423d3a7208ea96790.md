Shared drawings can be set with two different levels of permission:

+   *   **View only**: This means that anyone who receives this link can view the drawing but cannot modify or edit the drawing. They also cannot save a copy of the drawing.
+   *   **Edit and save a copy**: This means that anyone who receives the link can modify and edit the drawing, and also save a copy of the drawing.

If you click on either of these in the dialog box, you will see the `https://` link in the dialog box change. Also, note that the links will expire in seven days from sending. The **Copy link** button does exactly that. It copies the `https://` link for you to insert into an email client, document, or even a text message.
