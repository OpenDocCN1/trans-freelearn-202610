To do this, you'll need the exercise file, BearingCase .dwg, the external outline of which is made up of individual lines and an arc. Follow these steps to find the Geometric Center Osnap:

+   1. Type PE. You'll see PE (EDIT) in the Dynamic Input suggestion menu. Click on it; the Select polyline or prompt will appear.
+   2. Select the arc on the outline of the bearing case, as shown in Figure 5.14:

![](bbox=[0.16, 0.2, 0.805, 0.4])

Figure 5.14: The selected arc with the relevant AutoCAD prompt displayed

You'll receive a prompt stating Do you want to turn it into one? <Y>.

+   3. Press Enter when the default Y option is highlighted. This confirms that you want the selected arc to be converted into a polyline segment. Typing N and pressing Enter will stop the arc from being converted into a polyline segment. The Edit Polyline (PEDIT) menu will appear, as shown in Figure 5.15:
