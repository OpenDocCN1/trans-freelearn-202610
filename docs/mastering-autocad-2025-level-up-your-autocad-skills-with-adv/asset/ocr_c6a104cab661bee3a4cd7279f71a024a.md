+   - **Object Snaps**: The use of object snaps (*OSNAP*) in AutoCAD is fundamental to accurate 2D drafting and 3D modeling. It is good CAD practice to ensure that you are always using object snaps for accuracy, but there might be an occasion when object snaps would need to be switched off, hence the icon being available on the status bar.

As with **Polar Tracking**, the icon for **Object Snaps** (*OSNAP*) is available, and you can see it in *Figure 3.13*. If you right-click on the icon, you can select **Object Snap Settings...** and this will display the **Drafting Settings** dialog box with the **Object Snap** tab open.
