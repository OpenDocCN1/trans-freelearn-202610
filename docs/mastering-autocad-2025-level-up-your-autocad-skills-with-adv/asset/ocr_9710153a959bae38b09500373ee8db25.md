5. Click on the **Settings** icon (*gear wheel*) on the **DWG Compare** toolbar, as shown in *Figure 14.6*. You will notice that the highlight colors can be set there. Set the **Cloud Display** color to make the revision clouds stand out more. In this case, a dark blue cloud display color is selected as the background is white. The default cloud color is orange, which works well when using the default AutoCAD dark color theme in the AutoCAD Options. Colors are used in **DWG Compare** to make sure that the differences between drawings that are highlighted are organized and obvious.
