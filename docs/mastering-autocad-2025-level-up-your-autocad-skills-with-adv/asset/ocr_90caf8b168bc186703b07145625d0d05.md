# Refining drawings using the Modify panel

Your AutoCAD drawings are constantly evolving. Revisions and design iterations must be made as the project you are working on gets refined toward construction or manufacture.

AutoCAD provides many tools that allow you to modify existing drawing geometry quickly, effectively, and, most importantly, accurately and precisely. One of these features is the Modify panel.
