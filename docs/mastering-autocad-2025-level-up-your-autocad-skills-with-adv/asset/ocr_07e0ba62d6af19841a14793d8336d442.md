# ## Adding a dynamic Door block

Having placed a regular **Door** block in our AutoCAD drawing, it’s time to move onto a dynamic **Door** block. Let’s see how we can do that here:

+   1. In order to add a dynamic door block, you will now select the new **Door** block and remove it from the drawing. This may seem odd, as you have only just placed it, but you are now going to place a **DYNAMIC** block of a door to replace the regular block.
+   2. Use the previous steps 1 and 2 to use the **Erase** command to remove the regular **Door** block, leaving the wall opening as before.
