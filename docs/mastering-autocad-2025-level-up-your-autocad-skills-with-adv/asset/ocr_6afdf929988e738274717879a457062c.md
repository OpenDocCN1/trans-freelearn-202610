# # Using the AutoCAD Interface
to Work Smarter

AutoCAD is now over 40 years old. In that time, the AutoCAD interface has adapted and evolved to become more efficient and intuitive. This chapter will take you through several methods to enhance how AutoCAD is used, allowing you to work smarter, not harder.

We will go through some of the AutoCAD interface tools that make your daily use of AutoCAD easier, thus enhancing your efficiency and productivity. In this chapter, you will learn about the following interface tools:

+   - Working with file tabs
+   - Working with the Model and Layout tabs
+   - Utilizing the drafting settings on the status bar
+   - The AutoCAD ViewCube
+   - The AutoCAD navigation bar

All the preceding tools provide specific methods with which to navigate the AutoCAD interface and also navigate your AutoCAD drawing. AutoCAD drawings can be complex, and the AutoCAD interface, when used effectively, can help you work smarter, not harder. Learning how to work smarter using the AutoCAD interface will not only allow you to become a more seasoned AutoCAD user but also enhance your efficiency and productivity on a day-to-day basis.
