# ## Real-time Pan

The **Pan** icon on the **navigation bar** starts the **Real-time Pan** tool. This tool provides you with uninterrupted panning around your AutoCAD drawing or model. You can right-click and use the shortcut menu when in *Real-time Pan* mode. This then allows you to utilize other **Zoom** and **Pan** tools. *Figure 3.28* shows the shortcut menu when activated.
