You will notice that the **Noun/verb selection** checkbox is already checked, which means that **Noun/verb selection is switched on**. The **Noun/verb selection** checkbox works similarly to a human brain when picking up an object. Before picking up an object (*noun*), it will choose the object first and then pick it up (*verb*).
