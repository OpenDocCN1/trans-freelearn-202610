You will need to create a new block for the PC that includes attributes, and the quickest way to do this is to use the Explode (EXPLODE) command to explode the block back to its original AutoCAD objects. With the block still selected, click on the Explode icon on the Modify panel on the Home tab on the ribbon, as shown in Figure 10.2.

![](bbox=[0.308, 0.165, 0.658, 0.295])

Figure 10.2: The Explode icon on the Modify panel

The exploded block had what is known as a nested block within it. You can make blocks of blocks, and these are known as nested blocks. The original PC block was made up of four lines and another block that represented the computer screen. The block will now be returned to its original AutoCAD objects, and you now need to start the workflow to create a new PC block that has attributes included:

+   1. Select the screen block and explode that as well. If you hover over any element of the screen now, it is an AutoCAD object, such as a line or an arc.
+   2. These objects are shown selected in Figure 10.3. Make sure you have all four lines, and the screen block selected as shown (the blue grips will be displayed).
