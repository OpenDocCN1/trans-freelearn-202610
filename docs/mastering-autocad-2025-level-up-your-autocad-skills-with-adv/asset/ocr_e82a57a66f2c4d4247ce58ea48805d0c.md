This snap allows you to specify two points on any geometry (or coordinates) and find the midpoint between them. We’ll be using this to create some new centerlines in the `BearingCase.dwg` file, so make sure you’re using the **Centerlines** layer as the current layer. Also, ensure that you have **Polar Tracking** (*POLAR*), and **Object Snap Tracking** (*AUTOSNAP*) switched on. They should be displayed in blue on the status bar.

To create new centerlines, follow these steps:

+   1. Zoom to the lower left corner of the bearing case outline. Select the **Line** command from the **Draw** panel of the **Home** tab on the ribbon. You’ll be prompted for the first point of the line.
+   2. At this point, hold down the **Shift** key and right-click. The **Osnap Overrides** menu will appear.
+   3. Click **Mid Between 2 Points**. You’ll be prompted to select **First point of mid**.
+   4. Click on the **Endpoint** Osnap shown in *Figure 5.21*. This will be the first midpoint:
