That is all the settings we need for the canvas! Next, let's select the plane object with the particle system and add it to the simulation:

+   1. Select your particle system object and head over to the **Physics** panel. Select **Dynamic Paint**, switch **Type** to **Brush**, and click **Add Brush**.
+   2. In the **Source** tab, switch **Paint** to **Particle System**, and select **ParticleSystem** from the **Particle Systems** dropdown menu.
+   3. Next, check **Use Particle's Radius**. This will allow the radius affecting the canvas to be the exact size of the particle.
