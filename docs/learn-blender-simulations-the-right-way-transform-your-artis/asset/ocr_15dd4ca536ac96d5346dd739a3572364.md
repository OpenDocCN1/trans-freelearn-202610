# IOR

IOR indicates how fast light will pass through an object. The higher this value, the slower light will pass through. For example, air has an IOR value of 1.000277 and ice has an IOR value of 1.31. Light will pass through ice much slower than it passes through air, thus causing the light to bend more and giving it that distorted look. You can find a big list of IOR values for different real-world materials here: https://pixelandpoly.com/ior.html.
