+   - **Initial velocity**: This can be set on a certain axis – be it **X**, **Y**, or **Z**. This is very useful for emitting fluids in a direction very quickly.
+   - **Texture**: This allows you to map a texture to the flow object (only for smoke/fire flows). To create a new texture, go to the **Texture Properties** panel and select **New**. You can either choose from a big list of generated textures or select your own by choosing **Image/Movie**. Once you are done, head back to the **Physics** panel and choose it from the dropdown menu!

# Effectors

Effector objects offer a way to add collisions to your simulation. These types of objects can be any mesh. To add an effector object, select any mesh. Then, in the **Physics** panel, select **Fluid** | **Type** | **Effector**.
