# Creating a Paintbrush Effect

At this point, you should have a good understanding of dynamic paint and how it works in Blender. Now, let's put those skills to the test by creating a paintbrush effect using this simulation! We will learn how to animate a paintbrush along a curve, create hair particles for the bristles, and have the particles paint on a plane object. From there, we will import the color information into the material so that it can be easily customized. After that, we will set up the camera and render the animation. The goal of this chapter is to give you a practical understanding of how to use dynamic paint while also creating something cool in the process!

In this chapter, we'll be covering the following topics:

+   - Animating the brush
+   - Creating hair particles
+   - Simulating dynamic paint
+   - Adding the materials
+   - Rendering the animation

# Technical requirements

This chapter requires you to have Blender version 4.2 or above installed.

To download Blender, visit www.blender.org.

We will also be using a brush model, which you can download here: https://github.com/PacktPublishing/Learn-Blender-4-Simulations-the-Right-Way/tree/main/Chapter%2013
