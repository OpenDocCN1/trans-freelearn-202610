+   5. Now, we need to apply those changes to the rest of the objects. Head back up to the rigid body Object menu and select Copy From Active. This will copy all those changes we just made to the rest of the cubes instantly!
+   
+   6. Next, select each of the Column objects holding up the platforms and add a Passive rigid body to each! Now, the cubes will collide with them as well.
+   
+   7. Now, we can bake in the simulation! Remember to save your file again, then head back to the Scene Properties panel, and go down to the Rigid Body World tab. Inside the Cache tab, make sure that the start frame is at 1 and the end frame is set at 500, and click Bake!
