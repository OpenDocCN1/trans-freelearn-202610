# An Introduction to Dynamic Paint

**Dynamic paint** is a topic that isn't covered very often. It may seem complicated and hard to understand at first, but once you learn and start playing around with it, you will find that it is a very powerful tool in Blender. Dynamic paint allows you to turn your objects into brushes and canvases. Using this tool, you can create mesh displacement, image sequences, color maps, dynamic weight paint, and much more. Effects such as footprints in the snow, painting on walls, ripples in water, raindrops, and fire trails can easily be achieved using dynamic paint!

In this chapter, we will be covering what dynamic paint is and how to use it efficiently in Blender, starting with the basics and progressing from there. Just as with the previous simulations we have discussed in this book, we will learn what each setting does and how to use it the right way!

In this chapter, we'll be covering the following topics:

+   - Getting started with dynamic paint
+   - Creating a paint simulation
+   - Understanding the canvas
+   - Using brushes
