4. You may notice when you play the animation that it's not really working. That's because the camera is following the origin point of the sphere rather than the position of the mesh.

In the Copy Location constraint, there is a Vertex Group option. You can probably guess what we are going to do! Let's create a new vertex group for the sphere and then select it here. This way, the camera will follow the mesh rather than the origin point.

To do this, select Soft Body Sphere and create a new vertex group in the Object Data panel.

![](bbox=[0.22, 0.23, 0.77, 0.42])

Figure 7.33 – Vertex groups

5. Go into Edit Mode with Soft Body Sphere selected and assign all the vertices to Vertex Group with Weight set to 1.

6. Finally, in the Copy Location constraint, select the group in the Vertex Group menu.

![](bbox=[0.22, 0.53, 0.77, 0.7])

Figure 7.34 – Copy Location vertex group

You can go into the camera view by pressing 0 on the number pad or by going up to View | Viewport | Camera. From there, you may need to move the camera around to the correct position facing the sphere.
