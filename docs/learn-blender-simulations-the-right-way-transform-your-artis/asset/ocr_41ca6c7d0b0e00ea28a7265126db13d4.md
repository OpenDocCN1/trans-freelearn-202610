+   2. Check **Motion Blur** as well. The **Shutter** value sets the strength of the blur. A default value of 0 . 5 will work well here. Let’s also set **Steps** to 16 to give us a better quality blur.

Figure 11.33 – The Motion Blur settings

+   3. Finally, open the **Color Management** tab and set **Look** to **High Contrast**. This will make everything pop a bit more.

And that is it! From here, we can render the animation! Head over to the **Output** panel and set a directory for where you want your animation to render. I recommend rendering this animation as an image sequence just in case of any crashes. If you don’t remember how this is done, refer to Chapter 4.

But there it is! We have now created an entire rigid body obstacle course! This doesn’t have to end here. You can add more obstacles or other things to the simulation. For example, you could add a **Wind** force field at the end to push all the red cubes offscreen or have the sphere object trigger something that causes multiple spheres to crash into the tower!

Another cool idea would be to animate the speed of the simulation when the sphere crashes into the tower. This could have a cool slow-motion effect! It’s all up to you and your imagination!
