# Part 2:
Simulating Physics with Soft Bodies and Cloth

Using soft bodies and cloth is a great way to easily create certain objects that would otherwise be quite difficult to model by hand. In this part, we will dive deep into the Soft Body and Cloth simulations and learn all there is to know about them. We will create some nice, satisfying animations along the way!

+   - Chapter 7, Creating a Soft Body Obstacle Course
+   - Chapter 8, An Introduction to Cloth Simulations
+   - Chapter 9, Creating a Realistic Flag
