All application data is stored in a few very large tables in the platform and the kernel materializes virtual tables at runtime. We will look at some of the key tables in the following sections, but the premise is that when the tenant creates, for example, custom objects in their org, the fields, any relationships between them, and other attributes are stored in the UDD. This metadata, along with data tables (tables that hold the tenant's transactional type data) and a few specialized pivot tables maintain the data in a denormalized format.
