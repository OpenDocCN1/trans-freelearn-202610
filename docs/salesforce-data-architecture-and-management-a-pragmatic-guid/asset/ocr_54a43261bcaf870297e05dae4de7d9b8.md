Since most custom code-based applications use SOQL, this is a very handy tool to test how your SOQL queries will perform. Let's also understand what a full table scan is before we deep dive into the Query Plan tool.

# Full table scan

A full table scan is when the database table is scanned row by row and every row is examined to check whether it matches the query's where clause. Performance-wise, this is an expensive operation, and the use of filters is encouraged in SOQL queries:

```
SELECT name FROM Account WHERE name = "Star Wars Innovations";
```

The filter is the part after the where clause in the SOQL query. The name = "Star Wars Innovations" part is the filter, which will cause the index to be used since the name field is indexed in the Account object.
