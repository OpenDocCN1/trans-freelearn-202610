Event Monitoring is an API-only tool, meaning that it can be accessed via the API, and the key object in the tool is EventLogFile. This means that the data can be easily imported into application monitoring tools such as Analytics or Splunk for easier consumption.

You can use the Salesforce Event Log File (ELF) browser app (https://salesforce-elf.herokuapp.com/?_ga=2.82989334.1271813283.1614356382-1891424622.1607399861) to access and download event log files.
