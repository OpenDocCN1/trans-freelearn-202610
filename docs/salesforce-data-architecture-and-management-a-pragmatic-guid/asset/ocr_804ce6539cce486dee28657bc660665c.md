Source IP can be combined with CLIENT_IP in the event log file to get granular information – for example, about the applications that are utilizing the most API calls, the timings when the API calls are made, and other useful information that can be gathered. This is especially useful when the given application is not specified in the login history or CLIENT_NAME is unknown in the event log file.
