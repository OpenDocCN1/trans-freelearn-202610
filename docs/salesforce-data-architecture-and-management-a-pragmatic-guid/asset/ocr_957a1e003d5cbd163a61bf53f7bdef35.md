# Section 3:
Large Data Volumes
(LDVs) and Data
Migrations

In this section, you will learn about LDVs – what they are and how to use them in
searches and SOQL queries. Topics related to loading LDVs will also be discussed, with
examples demonstrating how to load data efficiently without running into issues. In the
final chapter, best practices for migrating data and the use of APIs will be discussed.

In this section, the following chapters are included:

+   - Chapter 7, Working with Large Volumes of Data
+   - Chapter 8, Best Practices for General Data Migration
