the step size being too small to escape. Conversely, suppose the learning rate is too large. In that case, we could step over the minimum and miss it entirely or get stuck oscillating around a minimum (constantly jumping back and forth but never descending to the optimal value).

# Gradient boosting

Now that we understand how gradient descent works, we can see how it is applied in gradient boosting. We will work through the entire gradient-boosting algorithm in detail at the hand of a small example. In our example, we’ll use a regression tree, as it is a bit easier to understand than the case for classification.

# Gradient-boosting algorithm

The gradient-boosting algorithm is defined as follows, where _M_ is the number of boosted trees [3]:

+   1. Given training data \(\{(x_p, y_p)\}_{i=1}^n\), containing _n_ training samples (defined by features _x<sub>i</sub>_ and target _y<sub>i</sub>_) and a differentiable loss function _L_(_y<sub>p</sub>, F_(_x_)), where _F_(_x_) are the predictions from model _F_.
+   2. Initialize the model with a constant prediction value _F_<sub>0</sub>(_X_) = \(\text{argmin}_\gamma \sum_{i=1}^n L(y_i, \gamma)\)
+   3. For _m_ = 1 to _M_:
+      Compute pseudo residuals \(r_{im} = -[\frac{\partial L(y_i, F(x_i))}{\partial F(x_i)}]_{F(x)=F_{m-1}(x)} for i = 1, ..., n\)
+      Fit a regression tree to the _r<sub>im</sub>_ values and create terminal regions _R<sub>jm</sub>_ for _j_ = 1..._J<sub>m</sub>_
+      For _j_ = 1..._J<sub>m</sub>_ compute \(\gamma_{jm} = \text{argmin}_\gamma \sum_{x_i \in R_j} L(y_i, F_{m-1}(x_i) + \gamma)\)
+      Update _F<sub>m</sub>_(_x_) = _F_<sub>_m_-1</sub>(_x_) + \(\nu \sum_{j=1}^{J_m} \gamma_{jm} I(x \in R_{jm})\)
+   4. Result: _F<sub>M</sub>_(_x_)

Although the algorithm and especially the mathematics might look intimidating, it is practically much more straightforward than it appears. We’ll go through the algorithm step by step. Consider the following toy dataset:
