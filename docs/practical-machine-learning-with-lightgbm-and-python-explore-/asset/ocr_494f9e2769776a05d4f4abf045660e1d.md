```
CAST(monthlycharges AS REAL) ,
CAST(totalcharges AS REAL)
)
) AS prediction
FROM pgml.telco_churn;
```

Similar to calling the predict function manually, we use the ROW expression to pass data to the pgml .
predict function but select the data from the table.

This also clearly illustrates the advantage of using PostgresML: a consumer of the ML model could
query new customer data alongside the predictions with minimal overhead and in the same business
transaction with a single network call.
