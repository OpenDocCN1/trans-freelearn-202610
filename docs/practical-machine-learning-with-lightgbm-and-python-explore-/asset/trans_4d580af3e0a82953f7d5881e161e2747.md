## 零样本AutoML

**零样本AutoML** 是 FLAML 的一项功能，其中不执行超参数优化。相反，通过分析算法在各种数据集上的性能，离线确定合适的超参数配置。该过程可描述如下：

- 1. 在构建模型之前：
  - 使用 AutoML 在多个数据集上训练模型
  - 将所有数据集的超参数配置、评估结果和元数据存储为零样本解决方案

- 2. 为新问题构建模型时：
  - 使用 FLAML 将新数据集与零样本解决方案结果进行对比分析，并确定合适的超参数
  - 使用超参数在新数据集上训练模型

对于给定的模型类型（例如 LightGBM），第一步仅执行一次。此后，可以为任何新问题构建新模型而无需调优。该解决方案被称为“零样本”，因为合适的参数在新数据集的首次拟合时即被使用。

FLAML 的零样本 AutoML 方法具有许多优势：

- 如前所述，不涉及调优，在解决新问题时节省了大量计算工作量和时间
- 由于不需要调优，也不需要验证数据集，更多数据可用于训练
- 用户的参与度更低
- 通常不需要更改代码，如我们将在下一部分看到

当然，为模型类型创建零样本解决方案仍然艰巨，需要各种数据集和大量计算来训练许多模型。幸运的是，FLAML 为许多流行模型提供了预训练的零样本解决方案，包括 LightGBM、XGBoost 和 scikit-learn 的随机森林。

要使用零样本解决方案，请将常规的 LightGBM 导入替换为 FLAML 包装的版本：

```
from flaml.default import LGBMRegressor

zs_model = LGBMRegressor()
zs_model.fit(X, y)
```

调用 fit 会分析 X 中的数据，选择合适的参数，并使用这些参数训练模型。训练仅执行一次，不进行调优。

## 介绍机器学习管道

在第 6 章《使用 LightGBM 解决现实世界的数据科学问题》中，我们详细概述了数据科学生命周期，其中包括训练机器学习模型的各个步骤。如果只关注训练模型所需的步骤，给定已收集的数据，则步骤如下：

- 1. 数据清洗和准备
- 2. 特征工程
- 3. 模型训练和调优
- 4. 模型评估
- 5. 模型部署

在之前的案例研究中，我们在使用 Jupyter 笔记本时手动应用这些步骤。但是，如果我们将上下文转移到长期机器学习项目中会发生什么？如果在有新数据可用时需要重复该过程，我们将不得不遵循相同的程序来成功构建模型。

同样，当我们想要使用模型对新数据进行打分时，我们必须每次都正确地应用这些步骤，并使用正确的参数和配置。

从某种意义上说，这些步骤为数据形成一个管道：数据进入管道，完成后产生一个可部署的模型。

正式地，机器学习管道是一个指导机器学习项目工作流程的系统化和自动化过程。它涉及多个相互连接的阶段，封装了之前列出的步骤。

机器学习管道旨在确保这些任务是结构化的、可重复的和高效的，从而更容易管理复杂的机器学习任务。管道在处理大型数据集时特别有益，或者当将原始数据转换为机器学习模型可用输入的步骤复杂且必须频繁重复时（例如在生产环境中）。

管道中涉及的步骤具有一定的流动性：根据管道的使用方式，可以添加或删除步骤。一些管道包括数据收集步骤，从各种数据源或数据库拉取数据，并为机器学习建模暂存数据。

许多机器学习服务和框架提供实现机器学习管道的功能和实用程序。Scikit-learn 通过其 Pipeline 类提供此功能，我们将在下一节中探讨。
