# 第 3 部分：生产级机器学习
### 使用 LightGBM 学习

在第 3 部分，我们将深入探讨机器学习解决方案在生产环境中的实际应用。我们将揭示机器学习管道的复杂性，确保系统化的数据处理和模型构建，以获得一致的结果。MLOps 是 DevOps 和 ML 的交汇点，将成为焦点，强调在实际场景中部署和维护强大的机器学习系统的重要性。通过动手示例，我们将探讨在平台（如 Google Cloud、Amazon SageMaker 和创新的 PostgresML）上部署机器学习管道，强调每个平台提供的独特优势。最后，将探讨分布式计算和基于 GPU 的训练，展示加快训练过程和高效管理更大数据集的方法。本部分将强调机器学习与实用生产级解决方案的无缝集成，使读者具备在动态环境中让模型运行起来的知识。

本部分将包含以下章节：

- 第 8 章，使用 LightGBM 的机器学习管道和 MLOps
- 第 9 章，使用 AWS SageMaker 的 LightGBM MLOps
- 第 10 章，使用 PostgresML 的 LightGBM 模型
- 第 11 章，使用 LightGBM 的分布式和基于 GPU 的学习
