# 关于作者

**Hemanth Manda** 是IBM产品管理负责人，负责Cloud Pak for Data平台。他在技术和软件行业拥有广泛经验，在过去20年中担任过多个战略和执行角色。在目前的职位上，Hemanth领导着一个由20多名产品经理组成的团队，负责简化和现代化IBM的数据与AI产品组合，以支持通过新平台产品Cloud Pak for Data实现云原生架构。此外，他还负责合理化和精简IBM的数据与AI产品组合（这是一项价值60亿美元的业务），并通过Cloud Pak for Data提供新的平台级功能。

**Sriram Srinivasan** 是IBM杰出工程师，领导Cloud Pak for Data的架构和开发。他的兴趣在于云原生技术（如Kubernetes）及其在客户端管理环境和软件即服务中的实际应用。在此职位之前，Sriram领导了IBM Data Science Experience Local和IBM Cloud的dashDB仓库即服务的开发。在IBM职业生涯早期，Sriram领导了各种Web和Eclipse工具平台的开发，如IBM Data Server Manager和SQL Warehousing工具。他在Informix开始了职业生涯，负责应用服务器、数据库工具、电子商务产品和Red Brick数据仓库。

**Deepak Rangarao** 负责IBM全球技术销售，并负责Cloud Pak for Data平台。他在数据仓库和分析领域拥有广泛的跨行业经验，在大型组织构建分析应用，并在初创企业和大型企业软件供应商中从事技术售前。Deepak合著了多本关于OLAP分析、变更数据捕获、数据仓库和对象存储等主题的书籍，并且经常在技术会议上发表演讲。他是Red Hat OpenShift、Apache Spark、Microsoft SQL Server和Web开发技术的认证技术专家。

**Campbell Robertson** 是IBM客户成功集团的全球数据与AI实践负责人。在这个职位上，Campbell负责为IBM客户成功经理、组织和IBM业务合作伙伴提供战略和领域专业知识。他的主要重点是帮助客户做出明智的决策，使他们能够成功地使人员、流程和政策与以AI和数据为中心的技术保持一致，从而改善成果和创新能力。他有超过25年的与全球公共部门组织合作部署最佳技术解决方案的经验。Campbell在架构、数据与AI技术、专家实验室服务、IT销售、市场营销和业务发展方面拥有丰富的背景。
