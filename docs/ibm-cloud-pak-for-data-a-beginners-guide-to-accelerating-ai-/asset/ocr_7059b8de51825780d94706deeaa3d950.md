While configuring deployments, we have the flexibility to not just define them as online or batch model deployments but also to specify the hardware specification for the actual deployment. Once the model is deployed, developers have access to the software development kit (SDK) in multiple languages to score against the model and operationalize it. The UI also allows for the testing of deployment models by passing through the input payload.
