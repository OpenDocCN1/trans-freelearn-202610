| Account [v4] | Description |
|---|---|
| zen-admin-sa | Bound to the cpd-admin-role and, by default, associated with the OpenShift "restricted" SCC. |
| zen-editor-sa | Bound to the cpd-admin-role and associated with the OpenShift "restricted" SCC. |
| zen-viewer-sa | Bound to the cpd-viewer-role and, by default, with the OpenShift "restricted" SCC. This account can only view Kubernetes artifacts within that namespace. |

| default | Automatically created in every OpenShift project, bound to the restricted SCC, and is not granted any RBAC privileges; that is, no roles are bound. This default service account will be used for end user workloads such as notebooks and Python pods and will not be allowed to perform any kind of actions inside the namespace. |

Hence, system Pods and Jobs typically use **cpd-admin-sa** to perform higher-privileged operations, whereas regular user Pods and Jobs (such as data science environments and refinery Jobs) would be associated with **default** or **cpd-norbac-sa** to designate that they are not granted any privileges whatsoever.
