# 第 2 部分：产品能力

在本部分中，我们将了解 IBM AI 阶梯各层级的产品能力，以及 Cloud Pak for Data 如何帮助将这些能力作为一体化平台交付。我们将回顾 Cloud Pak for Data 上可用的 IBM 和第三方高级服务，以及该平台最常见的用例模式，并了解 Cloud Pak for Data 如何满足混合多云需求。

本部分包含以下章节：

- 第 3 章，收集 – 让数据简单且可访问
- 第 4 章，整理 – 创建可信的分析基础
- 第 5 章，分析 – 以信任和透明度构建、部署和扩展模型
- 第 6 章，多云策略与 Cloud Satellite
- 第 7 章，IBM 与合作伙伴扩展服务
- 第 8 章，客户用例
