Since information will be stored on a server and sharing or identifying information between a client and server is necessary, a cookie is the best place to store information. # User authentication

Authentication or web-based user authentication is a process related to the handling and managing of user identification. This is often a combined process where HTML form processing and cookie-related information and activities need to be used.

User login or registration is done using HTML form processing. The information collected is stored and inserted into backend databases or secure files.
