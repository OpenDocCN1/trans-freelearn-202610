# 前言

Lotus Notes 是多种“事物”的集合，包括电子邮件、日历、待办事项（任务）、聊天、RSS 阅读器、应用程序平台等。我们中的许多人会在大部分工作时间里使用 Lotus Notes；能够更高效地使用它，是我们忙碌工作生活中的一大收获。我们中的许多人希望使用工具和功能来节省时间，但常常不确定如何掌握这些工具和功能。

这本简短且节奏快速的书使业务用户能够简单有效地掌握 Lotus Notes 的客户端界面和邮件功能。本书通过清晰的解释和说明，并配有明确的截图，让业务用户对基本功能有更深入、更清晰的理解，解答了在发送邮件和使用 Lotus Notes 应用程序时遇到的许多问题。

本书是更长篇著作 IBM Lotus Notes 8.5 用户指南的精简版（LITE 版）。完整版全面介绍了 Lotus Notes。

# 本书内容概要

第 1 章“第一印象（客户端界面）”探讨并解释了我们在打开 Lotus Notes 时首先看到的内容，以及如何处理所见内容。

第 2 章“掌握 Lotus Notes 邮件”帮助我们更详细地了解邮件。

第 3 章“Lotus Notes 邮件工具”重点介绍了邮件中可用的高级功能，以及我们如何最好地利用它们来辅助高效管理邮件。

# 本书所需内容

Lotus Notes 是一个多平台客户端应用程序，提供多种语言版本。本书专门介绍了在 Windows 操作系统上安装的 Lotus Notes 8.5 英文客户端的属性。由于它是客户端-服务器应用程序，需与 Domino 服务器配合使用。安装和配置客户端软件时，系统会提示我们输入用户名和本地服务器。执行这些步骤时，我们需要确保拥有这些信息，也可以联系 IT 部门以确定所需内容。

# 本书适用人群

本书适合所有使用 Lotus Notes 的人，从初学者到多年使用的资深专业人士。我们常常习惯成性，即使那些习惯是做事的绕远路方式。本书旨在介绍能帮助我们更智慧工作的功能和工具。此外，从早期版本的 Lotus Notes 到当前 8.5 版本有重大变化。本书详细介绍了新功能，因此我们能够充分利用它们；同时也介绍了历经时间考验的早期版本中的关键功能。
