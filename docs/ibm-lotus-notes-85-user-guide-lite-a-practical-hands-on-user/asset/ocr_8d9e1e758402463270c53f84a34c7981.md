# # Performing spell check as we type (Instant Spell check)

Create a message to test the steps given next:

+   1. While the message is open, select Tools | Instant Spell Check.... When Notes doesn't recognize a word, the word will be identified with a red squiggly line underneath.

+   2. Right-click on the misspelled word; we will see alternative suggestions for spelling as well as options to add the word to the dictionary or skip it.

# ## Performing an automatic spell check

In this case, Notes checks the spelling when we send the message.

+   1. Select File | Preferences, click Mail, and then click the Basics tab.

+   2. Select Spell-check messages before sending.

+   3. Click OK.

![](bbox=[0.32, 0.61, 0.633, 0.775])

> > We can enable the Instant Spell Check and the option to spell check messages before sending automatically. This will show us misspelled words as we type as well as prompts to correct any that we have missed when we send the message.
