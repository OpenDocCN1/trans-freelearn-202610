我们可以通过以下方式打开浏览器：

- 单击 Open 按钮，然后单击 Web browser。如果我们想打开多个浏览器页面，可以重复此步骤。
- 将网址 (URL) 键入 Address 工具栏，然后单击 Go 按钮（位于 Print 按钮左侧）。如果 Address 工具栏未显示，在工具栏区域右键单击并选择 Address。如果我们要将刚打开的页面加入书签，请选择 Create | Bookmark。

从内嵌浏览器工具栏中，我们可以：

- 单击 Back 可导航到上一页。
- 单击 Forward 可导航到下一页。
- 单击 Stop 按钮可停止网页加载。
- 单击 Refresh 按钮可重新加载网页。
- 单击 Go home 按钮可返回设置为主页的页面。
- 单击 Print 按钮可打印显示的网页。
- 选择 Print 按钮旁的向下箭头，然后单击 Page Setup 可更改打印显示网页的页面设置。
- 选择 Print 按钮旁的向下箭头，然后单击 Print Preview 可预览打印后的显示网页效果。

## 首选项

我们可以选择许多选项来个性化 Lotus Notes。某些首选项可能由公司 IT 部门代为设置，因为他们拥有一组可设置的策略，这些策略决定了几乎所有可能的首选项和功能。例如，IT 部门可以设置策略，以确定是否将 Open List 显示为按钮，或者是否将其显示为停靠状态。

我们可以自定义 Lotus Notes，使其按我们想要的方式运行和显示。以下是一些可用首选项的示例：

- 决定 Lotus Notes 客户端外观和手感的基本设置
- 我们的 Mail、Calendar、To Do 和 Contacts 应用程序
- 复制
- Lotus Sametime
- IBM Lotus Symphony（例如 Spreadsheets，如果可用）
- Activities 或 Websphere Portal 帐户（如果组织使用它们）

我们已经探索过一些可用的首选项，例如窗口和主题以及工具栏首选项。

要访问首选项，请选择 File | Preferences。可设置的首选项繁多；为简化查找特定首选项，请在首选项对话框顶部的字段中键入名称，如以下屏幕截图所示：

![](img/dc4e954e82cbb69d6ea9b87ab543c676_33_0.png)

一个值得启用的绝佳首选项是 Document AutoSave，它位于 Basic Notes Client Configuration 选项下。

![](img/dc4e954e82cbb69d6ea9b87ab543c676_33_1.png)

要启用它，只需选中 AutoSave every 字段旁的复选框，然后选择分钟数。默认时间为 15 分钟；在以下屏幕截图中，我已将时间更改为 8 分钟。

![](img/dc4e954e82cbb69d6ea9b87ab543c676_34_0.png)

启用后，Lotus Notes 可以自动保存我们正在处理的文档，以防止因系统崩溃或停电导致数据丢失。

AutoSave 可在我们的邮件文件以及任何已升级并启用了 AutoSave 选项的其他数据库中使用。

如果发生崩溃，重新启动 Lotus Notes 时系统会提示恢复文档；如果选择 Yes，系统将随后提供下列选项：

- **Recover**：此选项将打开所选文档，然后关闭对话框。
- **Recover All**：此选项将打开列出的所有文档，然后关闭对话框。
- **Remove**：此选项将从 AutoSave 数据库中删除所选文档。
- **Remove All**：这将从 AutoSave 中删除列出的所有文档。

还有一种手动恢复文档的选项。如果在崩溃后首次打开 Lotus Notes 时选择对提示回答 **No**，我们可以随时通过选择 **File | AutoSave | Recover AutoSaved Documents** 来恢复文档。

## 掌握 Lotus Notes 邮件

电子邮件是企业和社会中最重要的沟通形式之一。它被称作 mail、e-mail、备忘录或消息等多种名称，是一种通过一次操作进行沟通、发送文件并联系许多人的人性化方式。

邮件是我们通常每天使用的业务工具。当邮件系统宕机时，工作往往会完全停滞！由于它是我们依赖的工具，因此了解其所有功能至关重要。这就像拥有一辆汽车，如果启用特定功能可以节省燃油；但是，除非我们知道如何启用节油功能，否则我们可以从 A 地到达 B 地，但无法节省燃油！

本章将帮助我们更详细地了解邮件，并协助我们提高使用 Lotus Notes 邮件的效率。本章和下一章都将探讨节省时间的功能。在本章中，我们将讨论以下主题：

- 在 Lotus Notes 中访问邮件

- 编辑工具
- 附件
- 查看邮件

- 邮件图标

## 创建和回复消息

在以下章节中，我们将讨论如何创建和回复消息，包括审查消息操作以及设置发送选项。

### 创建消息

打开邮件后，我们可以单击 New 按钮，然后选择 Message 来创建消息，如下所示。从消息下拉列表可以看出，还有其他可用选项，例如 Meeting、Contact 等，我们可以创建这些内容。

![](img/dc4e954e82cbb69d6ea9b87ab543c676_37_2.png)

创建消息的另一种方法是使用键盘快捷键 Ctrl+M。这可以在 Lotus Notes 中的任何位置执行，而不仅仅是在打开邮件时——例如，我们可以在日历中、在 Contacts 内部或从主页使用 Ctrl+M 选项来创建消息。

### 消息操作

现在我们已创建消息，将探索一些消息操作。在消息顶部，我们可以看到启用我们执行某些操作的按钮。以下是可用选项的屏幕截图。我们将简要探讨每个选项。

![](img/dc4e954e82cbb69d6ea9b87ab543c676_38_0.png)

- Send：不言而喻；单击后将发送消息！
- Send and File...：发送消息时，这是一个绝佳选项，因为它不仅允许发送消息，还允许同时将消息归档到我们的文件夹中。单击 Send and File... 时，我们将看到包含所有个人文件夹的 Folders 对话框。以下是选择 Send and File 选项时出现的 Folders 对话框屏幕截图。我们将选择要将消息归档到的文件夹，然后单击 OK 按钮或按 Enter 键。消息将被归档到该文件夹，同时还会自动归档到 Sent 和 All Documents。请注意，这并不意味着消息在三个位置有三份副本。我们的个人文件夹中只有一份消息副本；Sent 和 All Documents 只是引用。这意味着如果从个人文件夹中删除消息，它也将从 Sent 和 All Documents 中删除。
