By utilizing Apex classes, the ability to start leveraging OOP practices emerges,
using interfaces and factory methods to implement functional subsystems within the
application to deliver not only implementation speed, consistency, and reuse, but
also help support a common user experience. Domain classes can call between each
other when required to encompass the behavior of related child components, such as
drivers within a team.

Finally, when testing the Domain layer, keep in mind the best practice used for unit
testing is to test as much of the code in isolation with varied use cases and data
combinations despite the fact that other tests, such as those from the Service layer,
and other callers will also exercise the code paths, though likely with less variation.
