The `doLogin()` method handles the user login. Note that there is no password checking in this sample application. If the user is not already logged in, the username is added to the UserDatabase class (its source code is presented shortly) and the user name is added to the HTTP session. The `doLogin()` method returns the name of the page that is shown to the user, be it the main page or the login failure page.

The `doLogout()` method does the reverse, removes the username from the UserDatabase and from the HTTP session.

The `updateUsersOnline()` method uses reverse AJAX to update the logged-in users list in the web pages of users who are logged in. The `getUsersOnline()` method returns the list of logged-in users from the UserDatabase class.
