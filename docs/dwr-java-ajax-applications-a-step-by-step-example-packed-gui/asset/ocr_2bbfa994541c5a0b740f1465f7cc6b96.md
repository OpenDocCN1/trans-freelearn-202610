In the above method, we first instantiate the CreditCardValidatorSoapProxy object and then call its validCard() method to do the credit card validation. The validCard() method calls the remote web service via Internet. If the credit card is not valid, a notification is written to the System.out, and the submitOrder() method returns false. If the credit card is valid, then the submitOrder() method returns true.

Using the existing tools in Eclipse and just a couple of lines of code, we can integrate standard web services into our example.
