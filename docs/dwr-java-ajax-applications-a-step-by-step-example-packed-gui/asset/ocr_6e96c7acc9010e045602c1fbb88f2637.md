# Getting Started

+   - We set up Geronimo server for Eclipse by clicking on **Download additional server adapters**. Then, the **Install New Adapter** dialog box opens. We select **Geronimo Core Feature** and click on **Next** to continue to accept the license screen. After we accept the license, Eclipse downloads and installs the plugin.
