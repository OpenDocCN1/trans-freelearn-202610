# Summary

The two sample applications, Collaborative Book Authoring and Chatroom, presented in this chapter make it clear that DWR makes development of these kind of collaborative applications very easy.

DWR itself does not even play a big part in the applications. DWR is just a transparent feature of the application. So developers concentrate on the actual project and aspects such as persistence of data and a neat user interface, instead of the low-level details of AJAX.
