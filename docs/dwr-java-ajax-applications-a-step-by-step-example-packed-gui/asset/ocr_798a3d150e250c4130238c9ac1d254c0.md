The first function, useTestCreditCardNumber, inserts a test number into the credit card field, so we don't have to use our own card number.

The last function is the submitOrder() function that reads form field values and calls the submitOrder() method in a remot ed Java class. The Java method returns true or false, and the status of order submission is shown to the user.
