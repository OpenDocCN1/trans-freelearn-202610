## 在本地存储中同步

我们将要实现的下一个功能是在本地存储中同步我们的状态。我们可以通过在应用程序中使用 localStorage.setItem() 来实现这一点。然而，这样做将不可维护，并且存储中值的设置会在不同的地方进行。

为了获得更好的实现，我们将使用 ngrx-store-localstorage 库。要安装该库，我们将执行以下命令：

```
npm install ngrx-store-localstorage --save
```

成功安装库后，我们应该确定要与本地存储同步的状态。在我们的例子中，我们希望 auth 状态中的 token 字段得到同步。为此，我们在 auth.module.ts 中进行以下代码更改：

```
import { localStorageSync } from 'ngrx-store-localstorage';
export function localStorageSyncReducer(reducer: ActionReducer<any>): ActionReducer<any> {
  return localStorageSync({keys: ['token']})(reducer);
}
const metaReducers: Array<MetaReducer<any, any>> = [localStorageSyncReducer];

@NgModule({
  declarations: [
    ... declared components
  ],
  imports: [
    ... other imported modules
    StoreModule.forFeature('authState', authReducer, {metaReducers}),
    EffectsModule.forFeature([AuthEffects]),
  ]
})
```

在前面的代码中，我们可以看到我们创建了一个专门的 reducer，它调用来自 ngrx-store-localstorage 的 localStorageSync，负责在本地存储中添加值。

我们还可以指定要同步的字段，在本例中，我们在 keys 数组中添加了 token。一旦 token 状态的值发生变化，新值也将被放置在我们的存储中。

## 使用 Cypress 入门

在本节中，你将学习 Cypress 是什么以及如何开始使用它。

Cypress 是一个用于测试 Web 应用程序的端到端框架。你可以在 HTML 标签中编写测试 ID，并断言 HTML 标签是否以你期望的方式呈现。

让我们定义一下端到端是什么意思。端到端是指用户在登陆你的 Web 应用程序后使用你的应用程序的方式，完成登录、注册、结账、查看个人资料、注销、填写表单等任务。

例如，你可以在不同的示例用例或场景中测试或检查你的 Web 应用程序的 UI：

- 登陆页价值主张的句子包含单词 sale
- 网站某个部分的组件计数是你所期望的
- 在结账页的篮子中的商品在点击 Clear 按钮后被清空
- 当 Web 应用程序的 URL 为 domain.com/login 时，存在登录表单

这些场景是 Web 应用程序中需要测试的示例。Cypress 是一个测试框架，你可以在其中编写和运行设置和配置不需要花费太多时间的测试。

现在，让我们看看 Cypress 如何安装。

## 安装

要开始使用 Cypress，我们必须从 npm 仓库安装它，运行以下命令：

```
npm i-D cypress @testing-library/cypress
```

前面的 npm 命令将在 dev 依赖包中安装 Cypress 和 cypress 测试库。@testing-library 是 Web 开发中一组常见的测试实用程序，使开发者的生活更轻松
