4. The last step we need to do is register the CORS configuration. We will instantiate a new urlBasedCorsConfigurationSource() and use the registerCorsConfiguration() method for the registration. The first parameter is "/**", which indicates that the configuration applies to all the methods found in the application, and the second parameter is corsConfiguration, which is the configuration we have created:

```
var urlBasedCorsConfigurationSource =
    new UrlBasedCorsConfigurationSource();
```
