+   - `springdoc.swagger-ui.operationsSorter`: This applies a sort to the operations list of the API. The value can be `'alpha'` (sort by paths alphabetically), `'method'` (sort by HTTP method), or a function that will identify the sorting criteria.
+   - `springdoc.swagger-ui.tagsSorter`: This applies a sort to the operations list of the API. The value can be `'alpha'` (sort by paths alphabetically) or a function that will identify the sorting criteria.

# The plugins of springdoc-openapi

springdoc-openapi also has plugins that we can use to generate the documentation. Let’s take a look.

# *springdoc-openapi-maven-plugin*

springdoc-openapi-maven-plugin generates a JSON and YAML OpenAPI description during build time. The plugin also works in the integration phase. To enable the plugin, we need to add the following declaration to the `<plugin>` section of the pom.xml file:

```
```xml
<plugin>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-maven-plugin</artifactId>
    <version>${spring-boot-maven-plugin.version}</version>
    <configuration>
        <jvmArguments>
            -Dspring.application.admin.enabled=true
        </jvmArguments>
    </configuration>
    <executions>
        <execution>
            <goals>
                <goal>start</goal>
                <goal>stop</goal>
            </goals>
        </execution>
    </executions>
</plugin>
```
```

We just added the `spring-boot-maven-plugin` plugin. Copy the preceding code and paste it into your `.pom` file.
