In the preceding example, we can see the table uses several properties. The first property is the `dataSource` property, which will be the one accepting the list of data to be displayed. The next property is `matColumnDef`, which defines the field name of each column that should be included in the `columns` variable that is bound to the `matHeaderRowDef` property.
