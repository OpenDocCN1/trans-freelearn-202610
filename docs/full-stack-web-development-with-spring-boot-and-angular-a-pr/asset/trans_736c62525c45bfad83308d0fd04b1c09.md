describe 函数中的第二个函数称为 afterEach。afterEach 函数在每次测试结束时运行。此函数适用于清理或在测试中注销用户。beforeEach 和 afterEach 函数为我们节省了大量可重复的代码。

# What is frontend-maven-plugin?

好吧——在回答 `frontend-maven-plugin` 是什么之前，让我们看看如何打包我们的应用程序。我们可以构建 Spring Boot 以生成 JAR 文件并创建 Angular 的生产构建。

但如果我们能为 Spring Boot 创建一个 JAR 文件，其中也包含 Angular 的生产构建呢？将前端和后端放在单个 JAR 文件中的方法将为我们提供一种更简单的方式将应用程序部署到测试和生产环境。

它将允许我们为 API 和前端应用程序管理单一路径。为此，我们需要一个名为 `frontend-maven-plugin` 的 Maven 插件（`https://github.com/eirslett/frontend-maven-plugin`），它将帮助我们创建包含后端和前端的 JAR 文件。
