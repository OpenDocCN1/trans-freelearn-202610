## 处理付款

在本章中，我们将介绍以下主题：

- Magento 默认支付方式
- 设置 PayPal
- PCI 合规性

### Magento 默认支付方式

Magento 默认包含几种支付方式：

- PayPal
- Braintree
- 支票或汇票
- 银行转账支付
- 货到付款支付
- 零小计结账
- 采购订单
- Authorize.net direct post

你可以在系统配置页面（商店 | 配置）的“销售 | 支付方式”部分查看这些支付方式的配置：

![](img/de3034a92496a32462134266292a51dd_290_0.png)

在这里，你可以看到 Magento 推荐以下支付解决方案：

- PayPal Express Checkout
- Braintree

不过，在**推荐解决方案**部分，你会看到右下角有一个链接——**其他 PayPal 支付解决方案**。如果你点击该链接，就会看到 Magento 中包含的其他 PayPal 解决方案：

![](img/de3034a92496a32462134266292a51dd_291_0.png)

这样，Magento 开箱即用地总共包含了 13 种支付解决方案，这为你设置偏好的支付方式提供了大量选择。

### 设置 PayPal

**PayPal Express Checkout** 是电子商务中使用最广泛的支付方式之一。客户可以使用他们的 PayPal 账户登录，也可以作为 PayPal 访客使用信用卡或借记卡付款。

我们将描述为你的 Magento 商店设置 **PayPal Express Checkout** 的过程。设置完成后，PayPal 按钮将显示在商店前端，如下所示：

产品详情页：

![](img/de3034a92496a32462134266292a51dd_292_0.png)

如果你点击该按钮，将显示以下表单：

![](img/de3034a92496a32462134266292a51dd_295_0.png)

你需要账户中的 API 用户名、密码和签名才能使用 PayPal Express Checkout。

你可以按照以下步骤获取该信息：

1. 登录你的 PayPal 企业账户：

![](img/de3034a92496a32462134266292a51dd_296_0.png)

2. 点击屏幕右上角的**个人资料**链接，然后点击“个人资料和设置”。

3. 点击**我的设置工具**，然后点击 **API 访问**部分中的**更新**链接：

![](img/de3034a92496a32462134266292a51dd_297_0.png)

4. 点击 **NVP/SOAP API 集成**部分中的**请求 API 凭据**链接：

![](img/de3034a92496a32462134266292a51dd_298_0.png)

5. 点击“请求 API 签名”链接，然后点击“同意并提交”：

![](img/de3034a92496a32462134266292a51dd_299_0.png)

现在你已经获得了凭据，请将该信息复制并粘贴到 Magento 中的 PayPal Express Checkout 表单中。

此外，你还会看到 PayPal Express Checkout 部分末尾需要配置的基本和高级设置：

你将看到**基本设置**表单的以下字段：

- **标题**：你可以自定义在商店前端显示的这种支付方式的标题。
- **排序顺序**：你可以设置商店前端支付方式列表中的特定顺序，0 表示支付方式显示在列表顶部。
- **支付操作**：你可以选择以下购买操作：
  - **授权**：此操作中，购买被批准，但需要商家授权才能向客户收费。商家负责开具发票，然后完成订单。
- **销售**：客户下单时立即扣款。当 PayPal 确认付款后，Magento 将创建发票。
- **订单**：此购买代表 PayPal 与商家之间的协议。商家可以在接下来的 29 天内的任何时间捕获总金额。
- **显示在产品详情页**：选择是否应在**产品详情**页面上显示 PayPal 按钮。

你将看到**高级设置**表单的以下字段：

- **显示在购物车中**：选择是否应在购物车页面和页眉中的迷你购物车中显示 PayPal 按钮。
- **适用付款国家/地区**：将 **PayPal Express Checkout** 限制为仅在特定国家/地区作为支付方式可用。
- **调试模式**：启用调试模式以记录开发期间调试有用的信息。
- **启用 SSL 验证**：为 **PayPal Express Checkout** 启用 SSL 保护。
- **传输购物车明细**：在 PayPal 中包含所购商品的详细信息。
- **传输配送选项**：在 PayPal 中包含配送选项的详细信息。
- **快捷按钮样式**：选择动态或静态快捷按钮。
- **启用 PayPal 访客结账**：允许没有 PayPal 账户的客户使用 **PayPal Express Checkout**。
- **要求客户提供账单地址**：指定客户是否应为 **PayPal Express Checkout** 提供账单地址。
- **账单协议注册**：允许客户通过账单协议保存下一次购买所需的账单详细信息。
- **跳过订单审核步骤**：在使用 **PayPal Express Checkout** 时跳过订单审核步骤。

### PCI 合规性

PCI 合规性可确保你的客户能够安全地使用信用卡在你的商店购物。所有信用卡协会都要求商家实施 PCI 合规性，以在线保护他们的客户。

Magento 包含支付网关，通过直接的 API post 方法或支付网关提供的托管支付表单，安全地传输信用卡数据。

以下是满足**支付卡行业数据安全标准（PCI DSS）**的要求：

1. 安装并维护防火墙配置以保护持卡人数据。
2. 不要使用供应商提供的默认系统密码和其他安全参数。
3. 保护存储的持卡人数据。
4. 加密通过开放公共网络传输的持卡人数据。
5. 使用并定期更新你的防病毒软件。
6. 开发并维护安全的系统和应用程序。
7. 将持卡人数据的访问权限限制在业务需要知情的人员范围内。
8. 为每位可访问计算机的人员分配唯一 ID。
9. 限制对持卡人数据的物理访问。
10. 跟踪并监控对网络资源和持卡人数据的所有访问。
11. 定期测试安全系统和流程。
12. 制定一项涵盖信息安全的安全策略。

有两种方法可以保护你的客户并确保 PCI 合规性：

- **直接 post：** 信息直接发送到支付网关，数据不经过 Magento 或在 Magento 中存储。
- **托管支付表单：** 支付表单集成在 Magento 结账流程中，但由支付网关托管，而不是由 Magento 应用程序托管。

通过将敏感数据保存在 Magento 实例之外，商家可以通过 SAQ A 或 SAQ A-EP 级别的自我评估来验证合规性，而无需对整个 Magento 平台进行 PCI 合规性重新评估。
