You can go to the system configuration page by selecting the STORES | Settings | Configuration menu item in the admin panel. You will see the following page on your screen:

![](bbox=[0.104, 0.182, 0.896, 0.531])

The following sections are available in the System Configuration page:

+   - **GENERAL:**
+     - General
+     - Web
+     - Design
+     - Currency Setup
+     - Store Email Addresses
+     - Contacts
+     - Reports
+     - Content Management
+     - New Relic Reporting
