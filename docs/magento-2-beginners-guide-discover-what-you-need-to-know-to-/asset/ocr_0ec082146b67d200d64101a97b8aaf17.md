The Robots.txt settings can be found in the STORES | Configuration | General | Design | Search Engine Robots section:

![](bbox=[0.104, 0.165, 0.896, 0.515])

In this page, you can set:

+   - **Default robots**: Choose the default robots rules:
+     - INDEX, FOLLOW
+     - NOINDEX, FOLLOW
+     - INDEX, NOFOLLOW
+     - NOINDEX, NOFOLLOW
+   - **Edit the custom instruction of robots.txt file**: Enter the custom instructions for the Robots.txt file if required
+   - **Reset to Defaults**: Delete custom instructions and reset the Robots.txt configuration to default
