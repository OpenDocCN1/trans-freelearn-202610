You can see a list of available extensions in the Magento Marketplace at https://marketplace.magento.com:

![](bbox=[0.104, 0.152, 0.896, 0.468])

When you select an extension, you will see all the information that you need from the extension listing page, including:

+   - Available editions for the extension
+   - Available support by the vendor
+   - Installation service
+   - Pricing
+   - Description
+   - Current version
+   - Updated date
+   - Category
