# GENERAL | Store Email Addresses

+   - General Contact / Sales Representative / Customer Support / Custom Email 1 / Custom Email 2:
+     - Sender Name: Set the sender name for each of the contact types
+     - Sender Email: Set the e-mail address for each of the contact types

# GENERAL | Contacts

+   - Contact Us:
+     - Enable Contact Us: Enable the contact us page on the Storefront
+   - Email Options:
+     - Send Emails To: Send the contact e-mails to the specified email addresses
+     - Email Sender: Set the contact type that will be the sender of the contact e-mails
+     - Email Template: Set the e-mail template for the contact e-mails

# GENERAL | Contact Management

+   - WYSIWYG Options:
+     - Enable WYSIWYG Editor: When this setting is dissabled, the WYSIWYG editor won't be displayed and plain text will be used for the text area fields in the admin panel

# CATALOG | Catalog

+   - Storefront:
+     - List Mode: Set the display mode for the product listing page. The possible values are:
+       - Grid Only
+       - List Only
+       - Grid (default) / List
+       - List (default) / Grid
