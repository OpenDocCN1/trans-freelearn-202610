# Self-managed servers

We have the self-managed servers; when you choose this type of server, the configuration, upgrades, and monitoring are the responsibilities of the user.

This is the best option for advanced users or merchants who have their own system administrator. You have total control of the server, which is really important when it comes to managing a Magento store. At the same time, you are in charge of resolving emergencies if the server is down or if there are other kinds of problems related to the server.

When you choose this type of server, you should have knowledge of server administration or find a really good system administrator who can handle emergencies and configure the server properly.

Here is a list of recommended self-managed servers for Magento:

+   - Amazon EC2: https://aws.amazon.com/ec2/
+   - DigitalOcean: https://www.digitalocean.com/
+   - Linode: https://www.linode.com/
