We will create a Bundle Product using the Magento 2 sample data:

+   1. Go to the PRODUCTS | Inventory | Catalog page.
+   2. Click on the arrow inside the Add Product button and select Bundle Product.

You will see that the form will be similar to the other products but there will be a new section, Bundle Items:

![](bbox=[0.105, 0.255, 0.895, 0.6])

3. We will add the following information on this product:

# General Information:

+   - Enable Product: Yes
+   - Attribute Set: Default
+   - Product Name: Bags
+   - Dynamic SKU: Yes
+   - Dynamic Price: Yes
+   - Stock Status: In Stock
+   - Dynamic Weight: Yes
+   - Visibility: Catalog, Search
+   - Categories: Default Category | Collections | Erin Recommends
