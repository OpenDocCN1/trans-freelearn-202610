+   - **Cost:** This is the information for the administrator representing the cost of the product.
+   - **Tier Price:** This is the discounted price for the product based on the website, customer group, and purchased quantity.
+   - **Manufacturer's Suggested Retail Price:** This is the Minimum Advertised Price for the product.
+   - **Display Actual Price:** With this option, you can select where the **Manufacturer's Suggested Retail Price (MSRP)** should be displayed:
+     - **On Gesture:** When this option is selected, the MSRP is displayed in the product listing and product detail pages. In addition, a **Click for price** link is added next to the MSRP price, which opens a popover that includes more information about the price of the product.
