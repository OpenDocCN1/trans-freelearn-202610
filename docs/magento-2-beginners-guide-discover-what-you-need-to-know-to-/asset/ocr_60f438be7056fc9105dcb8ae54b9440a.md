In order to create a backup from the admin panel, you should go to the following section:
SYSTEM | Tools | Backups

![](bbox=[0.1, 0.15, 0.89, 0.47])

In that section, you will see a list of all the backups that you have created. In addition to that, you will be able to create three types of backup:

+   - **System Backup**: Creates a code base and database backup with the ability to include or exclude the media folder
+   - **Database and Media Backup**: Creates a database and media folder backup
+   - **Database Backup**: Creates a database backup

For all these backup types, you have the ability to put the Magento store in maintenance mode, since the process takes a lot of server resources.
