# Default Magento payment methods

Magento includes several payment methods by default:

+   - PayPal
+   - Braintree
+   - Check or money order
+   - Bank transfer payment
+   - Cash on delivery payment
+   - Zero subtotal checkout
+   - Purchase order
+   - Authorize.net direct post
