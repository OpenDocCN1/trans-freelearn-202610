# Catalog and Shopping Cart Price Rules

Magento allows you to set up promotions for your catalog. You can manage those promotions from the MARKETING | Promotions | Catalog Price Rule admin page:

![](bbox=[0.103, 0.141, 0.896, 0.459])

As you can see in the preceding screenshot, the Magento 2 sample data includes one catalog promotion– 20% off all Women's and Men's Pants

You can add a new rule by clicking on Add New Rule in the top-right corner of the page.
