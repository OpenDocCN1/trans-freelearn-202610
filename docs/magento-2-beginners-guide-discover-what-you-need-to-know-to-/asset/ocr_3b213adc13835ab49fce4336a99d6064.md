# Attribute Sets and Custom Attributes

If the cron job is not running in your website, you can manually run the reindex from the Magento command-line tool:

+   1. Open the terminal and go to the project folder.
+   2. Run the following command:

```
```bash
php bin/magento indexer:reindex
```
```
