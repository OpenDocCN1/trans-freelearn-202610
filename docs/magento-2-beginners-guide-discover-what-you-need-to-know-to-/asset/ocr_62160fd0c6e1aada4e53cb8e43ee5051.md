# # Virtual Product

Magento allows you to create non-tangible products for your catalog, such us memberships or professional services. These products can be displayed individually or included as part of grouped or bundle products.

Virtual products are very similar to the simple products in Magento, the only difference being that the virtual products don't have weight as an attribute and they don't require shipping information.

We will create a **Virtual Product** by following these steps:

+   1. Go to the **Products | Inventory | Catalog** page.
+   2. Click on the arrow inside the **Add Product** button and select **Virtual Product**.
+   3. We will set the following information for this product:

# ## General Information:
