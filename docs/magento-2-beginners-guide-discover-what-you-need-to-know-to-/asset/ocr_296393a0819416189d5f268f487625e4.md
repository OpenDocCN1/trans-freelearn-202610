# Fulfilling Orders

Editing the order would be necessary in case you needed to edit the items that the customer purchased, but it's not necessary to change the address information. If you click on the Edit button next to the Billing Address or Shipping Address, you will be redirected to the following form to edit those details:

![](bbox=[0.102, 0.185, 0.896, 0.503])

As you can see in the message in the preceding screenshot, changing the shipping address is not going to alter the order total since the shipping, tax, and order amount are not recalculated.
