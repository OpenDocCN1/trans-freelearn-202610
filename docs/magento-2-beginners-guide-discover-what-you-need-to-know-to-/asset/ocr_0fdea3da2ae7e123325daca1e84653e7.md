# Downloadable Product

A **Downloadable Product** is a digital file that can be sent to a downloadable file, for example, e-books, software, music videos, and so on.

Since the downloadable file is not available before purchase, you can add samples to the product details page, such as the introduction for the e-book, a trial version for the software, or a short clip for the music video.

Let's create a **Downloadable Product** by following these steps:

+   1. Go to the **Products | Inventory | Catalog** page.
+   2. Click on the arrow inside the **Add Product** button and select **Downloadable Product**.
