# 6. Web Configuration:

In this step, you should specify the virtual host that you created for the Magento 2 website (autocompleted by default), and you can define a custom URL for the admin as well as **Advanced Options**, such as **HTTPS Options**, **Apache Rewrites**, **Encryption Key**, and the **Session Save** configuration.
