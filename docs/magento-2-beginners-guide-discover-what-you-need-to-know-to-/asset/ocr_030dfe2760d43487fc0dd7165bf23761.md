# # Invoices, shipping, and credit memos

The process of generating and managing invoices, shipping, and credit memos is very simple, and the process is the same for all of them.

If you go to the order page, you will see the tabs that we reviewed before, including the following ones:

+   - Invoices
+   - Credit Memos
+   - Shipments

From those two sections, as we saw before, we can see the list of invoices and credit memos for that order.
