
## 树视图

树视图是 Dynamics AX 应用程序中的控件。它必须符合以下规范：

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1 | 是否在必须呈现层次信息的地方使用树视图？ | 是 |
| 2 | 树视图中的每一行必须包含一个图标，后跟有关对象的相关信息。是否有任何树视图忽略此标准？ | 否 |
| 3 | 信息可能是一个逗号分隔的列表。如果是逗号分隔的列表，列表中的前两项必须是对象键和对象名称。是否有任何表单忽略此标准？注意：即使是树视图，逗号分隔列表也不能在主菜单中使用。 | 否 |
| 4 | 是否有任何树视图中项目之间的分隔符不是反斜杠、逗号或斜杠？ | 否。 |
| 5 | 如果逗号分隔列表允许超过两项，用户必须能够在选项卡中选择列表的相关项；该选项卡必须命名为 Setup。是否有任何表单忽略此标准？ | 否 |
| 6 | 树视图是否支持拖放以重新定位、添加和删除对象？注意：这取决于要求，因此测试人员可以排除此检查点。 | 是 |
| 7 | 树视图中使用的图标必须有易于访问的说明。说明必须出现在“概述”选项卡上（如果可用则为“树”选项卡）或“设置”选项卡上。是否有任何表单忽略此标准？ | 否 |
| 8 | 选择或取消选择树视图时表单是否会被调整大小？ | 否 |
| 9 | 如果用户调整包含树视图的窗口大小，窗口大小的任何增加都必须用于增加树视图的大小。是否有任何表单忽略此标准？ | 否 |
| 10 | 拖放（可用时）是否在表单的在线帮助中描述？注意：如果任何树视图控件中不可用拖放，则此标准不适用。 | 是 |
| 11 | 逗号分隔列表中项目之间的分隔符应为反斜杠。是否有任何树视图忽略此标准？注意：这是推荐的而不是强制性的，因此如果有理由，测试人员可以自行决定忽略此检查点。 | 否 |

## 函数窗口

函数窗口是 Dynamics AX 中的一种表单类型，用于查看或更改某些设置或启动某些进程。函数窗口除了前面讨论的内容外，还需要符合以下规范。

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1 | 函数窗口是否包含任何表？ | 否 |
| 2 | 启动进程的函数窗口必须包含“确定”和“取消”按钮。是否有任何表单忽略此标准？ | 否 |
| 3 | “确定”和“取消”按钮是否放置在窗口最后一行的最右侧按钮上？ | 是 |
| 4 | 如果在“确定”和“取消”按钮左侧出现任何其他命令按钮，它们必须与“确定”和“取消”按钮正确分隔。是否有任何函数窗口忽略此标准？ | 否 |
| 5 | “确定”和“取消”按钮必须分别具有“确定”和“取消”标签。'Ok' 和 'ok' 等变体是不允许的。是否有任何表单忽略此标准？ | 否 |

## 图标和符号

图标和符号需要符合以下规范：

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1.1 | 图标和符号中使用的图像是否相关？ | 是 |
| 1.2 | 所有图标图像应清晰，以便用户易于理解。是否有任何图标忽略此标准？ | 否 |
| 2.1 | 图标是否符合 Office 标准？ | 是 |
| 2.2 | 是否有任何图标与 Office 图标冲突？ | 否 |
| 3.1 | 所有图标都应有与其关联的屏幕提示。是否有任何图标忽略此标准？ | 否 |
| 3.2 | 在与任何图标关联的屏幕提示中，图标的用途应清楚地解释。是否有任何图标忽略此标准？ | 否 |
| 3.3 | 是否有任何图标的屏幕提示为空？ | 否 |

## 用户帮助—帮助

Dynamics AX 帮助系统包含六种类型的帮助：

- **程序帮助**：这是按下 F1 键然后点击 **内容** 时打开的帮助。该帮助的目标是提供有关焦点屏幕的完整信息，以便用户能够知道如何完成任务。
- **表单帮助**：根据用户请求在单独窗口中打开。它描述了何时以及为何应使用此表单。
- **屏幕提示（这是什么帮助）**：这出现在文本框附近，以便用户能够知道此文本框是什么。
- **工具提示**：如果鼠标指针在命令按钮上保持静止一段时间，此类帮助会出现在命令按钮附近。
- **显式提示**：这是对当前所选对象的解释，会自动出现在表格上方。
- **状态栏消息**：状态栏消息出现在状态栏的左侧。

## 项目

创建和维护项目的基数据

对于每个项目，都会列出项目编号、名称、发票项目、组和项目状态等信息，以及其他基数据。这也是您找到项目交易概览、项目过账设置、项目销售和成本价设置、发票信息、项目预测、WIP 定义和其他关键项目数据的地方。

可以创建四种不同的项目类型。有关这些项目特征的更多信息，请参阅“类型”。

## 项目层次结构

您创建的每个项目都可以作为父子层次结构中的父项目拥有任意数量的子项目。项目层次结构可以包含可选的层级数。每个子项目都可以从父项目继承基数据。

## 查看项目

项目以列表或树结构查看。选择或清除“树”控件复选框可在项目和树视图之间切换。

## 子项目

如果选择“子项目”复选框，则“工时”、“成本”和“收入”窗口中将显示父项目上的交易以及当前父项目的子项目上的交易。如果复选框保持空白，则这些窗口中仅显示父项目上的交易。

此外，如果选择此复选框，则在创建调整交易和发票提案时建议的项目范围内将包含子项目上的交易。

## 按钮

| 选项 | 描述 |
|---|---|
| 交易 | 查看当前项目上已发布的交易。收入交易是没有匹配成本的收入。WIP 交易是所有已应用 WIP 的固定价格项目上发布的交易。 |
| 活动 | 打开活动窗口，您可以在其中输入项目活动。 |
| 项目 | 打开一个子菜单，其中包含在项目上输入项目需求的选项，或访问销售订单或采购订单窗口。 |
| 设置 | 查看并维护当前项目的联系人、过账配置文件、销售价和成本价。 |
| 功能 | 打开计划或调整窗口。 |
| 发票 | 使用此按钮访问开票功能。使用到账按钮，您可以在当前项目上输入到账交易。使用发票提案按钮，您可以创建发票提案和到账发票提案。注意，提案适用于输入在当前发票项目所附项目上的所有交易，而不是输入在当前项目上的交易。发票按钮允许您访问发票登记窗口，其中列出了历史发票信息。 |
| 查询 | 访问三个项目查询功能。分类账过账。查看过账设置。甘特图提供了预测活动的图形概览。在统计窗口中，预算交易和已实现交易进行比较。 |
| 预测 | 此按钮提供在项目上输入和维护预期工时、成本、收入和项目交易的機會。预测用于项目财务控制的基础。工时预测构成项目规划的基础。收入、成本和项目预测用于一般预算目的。四个预测功能也在预测菜单文件夹下可用。 |
| 阶段 | 点击按钮更改项目生命周期的阶段。 |
| 项目控制 | 点击此按钮访问项目控制窗口，在其中为固定价格项目设置估算期间。 |
