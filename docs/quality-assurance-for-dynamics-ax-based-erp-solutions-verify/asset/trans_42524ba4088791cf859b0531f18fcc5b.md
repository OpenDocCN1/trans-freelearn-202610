## 国际化

国际化在业务范围超过一个国家时非常必要。以下特性使 Dynamics AX 成为真正的国际化 ERP 解决方案：

- Dynamics AX 符合 Unicode 标准。今天 Unicode 是最大的行业标准字符集；符合 Unicode 意味着您可以以最小的数据损坏风险访问新地区并通过许多不同的系统传输数据。Unicode 合规性使您能够与使用多字节字符集的语言的子公司集成，例如中国、日本和其他东亚国家。
- Dynamics AX 支持日期/货币格式与区域设置的关联，这使得 Dynamics AX 能够根据区域设置的标准自动更改日期格式。Dynamics AX 支持多种语言和多种货币（超过 36 种语言和 40 种货币）。

## Dynamics AX 的定制

几乎所有企业主都努力做些什么来脱颖而出；但这并不总是适用于他们对现成软件的选择。因此，企业独特的方面往往在“原味香草”集成企业应用中丢失。然而，Dynamics AX 解决方案允许企业将独特的术语、公式、流程和业务战略完全无缝地集成到软件中。现在我们将简要讨论 Dynamics AX 中的一些有用功能，这些功能对 Dynamics AX 定制非常有用。

### MorphX

Microsoft Dynamics AX 提供了一个名为 MorphX 的集成开发环境。它非常直观，使开发人员能够为两种类型的界面即 Windows 客户端和 Web 浏览器界面进行图形化设计、开发和报告。MorphX 开发工具可在 **Tools | Development tools** 菜单中使用。该工具通过单屏提供设计、编辑和编译，大大帮助了开发人员。一旦更改编译完成，所有更改将由应用程序反映。

MorphX 开发套件是一系列广泛功能的集合，可实现快速定制，成本低廉，同时不影响原始解决方案的可靠性、完整性和安全性，即风险最小。另一个有用的工具是 IntelliMorph，它提供了根据位置、语言、货币、监管要求等上下文对齐 GUI 的出色功能。我们将在下一节讨论它。

### IntelliMorph

通常，解决方案设计师或开发人员的主要关注点是 GUI 实体（表单、报表等）在所有受支持语言中都能良好运行。使用标签文件系统翻译不同标签很容易。然而，长度可能差异很大，这可能会破坏整个 GUI 设计，并且此类系统的可用性会受到损害。

在不同国家，功能可能以不同的方式使用，或者某些字段可能被隐藏或需要额外的字段。不同公司也可能出现这种情况。

考虑这样一种情况：某些业务流程可能未实施，因此必须删除其他业务流程到此业务流程的所有连接。因此，可能需要在所有相关业务流程中添加某些字段并删除某些字段。由于此类字段的添加或删除，GUI 可能会发生变化，这对用户来说非常不便。

MorphX 对上述场景有解决方案，即 IntelliMorph 技术。IntelliMorph 技术允许表单和报表自动调整显示宽度以适应单词长度，因此 GUI 保持在可呈现或可用的状态。
