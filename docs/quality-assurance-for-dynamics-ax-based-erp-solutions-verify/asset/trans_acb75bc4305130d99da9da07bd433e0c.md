## 主菜单

主菜单在导航到各种表单、报表等时发挥着关键作用。它设计成能够提高可用性（通过结构化导航），并缩短导航路径（即减少到达各种表单/报表所需的平均点击次数）。为了保持这些特性，任何定制都必须符合以下规范：

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1 | 菜单开头（针对任何模块）的表单数量是否超过六个？ | 否 |
| 2 | 是否有任何菜单，其开头显示的表单使用频率较低？ | 否 |
| 3 | 是否有任何文件夹图标的名称不同于 Journals、Inquiries、Reports、Periodic 和 Setup？ | 否 |
| 4 | 文件夹图标是否按 Journals、Inquiries、Reports、Periodic 和 Setup 的顺序出现？ | 是 |
| 5 | 是否有任何文件夹包含超过六个表单？（不包含任何表单的文件夹是可以接受的。） | 否 |
| 6 | 主菜单中是否有任何节点的缩进级别超过 5？ | 否 |
| 7 | 是否有任何菜单图标与 Dynamics AX 标准不一致？ | 否 |
| 8 | 如果用户点击主菜单上的表单图标，请确保同一表单图标出现在新窗口的左上角。是否有任何窗口未遵循此标准？ | 否 |
| 9 | 是否有任何表单图标，其标题与对应表单上的标题不同？注意：表单标题右侧可能包含额外字符串，但它必须以表单图标中提到的标签字符串开头。 | 否 |
| 10 | 是否有任何表单不能通过单击表单图标打开？注意：有时点击图标后打开表单可能需要时间，建议测试人员耐心测试。 | 否 |
| 11 | 双击表单图标是否会打开两个相同的表单？ | 否 |

## 任务窗格要求

任务窗格（如果选择显示）在应用程序窗口右侧出现。其缺点是它减少了内容窗格的空间，因此许多用户选择不显示它。因此，UI 规范建议以用户无需选择它即可完成任务的方式使用任务窗格。任务窗格的几种建议用途可能是显示搜索结果、帮助内容等。必须遵守以下规范，以确保用户无需使用任务窗格即可完成任何任务：

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1 | 任务窗格必须用于呈现有用但非必需的信息。任务窗格不得用于显示通知或对用户任务至关重要的信息。此标准是否遵循？ | 是 |
| 2 | 任务窗格不得用作对话框或用于设置选项。此标准是否遵循？ | 是 |
| 3 | 任务窗格不得用作与内容窗格竞争的次要工作区。内容窗格是显示与应用程序任务相关联的表单和窗口的主要工作区。此标准是否遵循？ | 是 |
| 4 | 任务窗格不得用于呈现使用户困惑的过量信息。此标准是否遵循？ | 是 |
| 5 | 任务窗格不得用于显示特定于当前所选表单或窗口的内容。任务窗格应显示适用于应用程序的一般信息或具有周边用处的信息。此标准是否对每个窗口都遵循？ | 是 |
| 6 | 考虑使用向导或替代内容格式来呈现信息或指导。是否有任何窗口未遵循此标准？注意：这是一个建议，因此在有充分理由的情况下可以忽略此检查点。 | 否 |

## 表单

精心设计的表单对可用性贡献最大，因为用户大部分时间只处理表单。Dynamics AX 将表单分为三类，所有用户界面规范必须符合特定表单类别。

| 序号 | 检查点 | 预期结果 |
|---|---|---|
| 1 | 表单必须属于三种标准表单类别之一，即两个选项卡控件（即 标题-行）、一个选项卡控件或功能窗口。不允许在单个表单中组合上述类别。是否存在此类表单？ | 否 |
| 2 | 是否有任何双选项卡控件表单不包含可移动分隔符以将表单拆分为标题和行？ | 否 |
| 3 | 表格上方的区域必须为空白或应包含一个或多个与表格中显示记录的常用筛选器或呈现格式相关的控件。是否有任何表单忽略了此标准？ | 否 |
| 4 | 是否有任何筛选控件用于根据组标题筛选记录？ | 否 |
| 5 | 表格的筛选条件不得在同一选项卡控件下的选项卡中提供。例如，包含表格的选项卡控件不得包含控制表格筛选的筛选选项卡。是否有任何表单忽略了此标准？ | 否 |
| 6.1 | 非活动筛选条件必须为空白。是否有任何表单忽略了此标准？ | 否 |
| 6.2 | 是否有任何复选框可用于激活或停用筛选控件？ | 否 |
