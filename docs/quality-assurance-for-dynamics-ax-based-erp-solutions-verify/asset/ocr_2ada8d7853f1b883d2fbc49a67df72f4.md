+   - Not related to this piece of code
+   - Verified
+   - Duplicated
+   - Not reproducible
+   - As designed
+   - Deferred
+   - Withdrawn
+   - No action required

Such a wide list of closed categories will help to identify how the closed issues reached the closing stage.
