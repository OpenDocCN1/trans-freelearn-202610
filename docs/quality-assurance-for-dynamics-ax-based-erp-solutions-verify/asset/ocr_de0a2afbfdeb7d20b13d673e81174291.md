# User Assistance—Wizards

Wizards make many processes very simple. This is only possible if the wizard is carefully designed. The following user interface specifications for wizards help meet the above objective and hence every wizard must abide by the following specifications:

| Sr. No. | Checkpoint | Expected Result |
|---|---|---|
| 1.1 | Is there any wizard without a welcome page? | No |
| 1.2 | Is there any wizard without one or more interior pages? | No |
| 1.3 | Is there any wizard without a successful completion page? | No |
| 2.1 | Is there any welcome page that doesn't explain the purpose of the wizard? | No |
| 2.2 | Are there any controls present on the welcome page? | No |
| 3 | Wizard pages must be divided into three parts: welcome page, interior pages, and successful completion page. The interior pages may appear either in 'standards' or in a 'setup' that is similar to the 'welcome' and 'successful completion page'. Is there any wizard in which this standard is not followed? | No |
| 4.1 | Do the wizard pages appear uniformly? | Yes |
| 4.2 | Do all the wizards have the same style? | Yes |
| 4.3 | Does graphics on the left-hand side follow the same format throughout the wizard? | Yes |
