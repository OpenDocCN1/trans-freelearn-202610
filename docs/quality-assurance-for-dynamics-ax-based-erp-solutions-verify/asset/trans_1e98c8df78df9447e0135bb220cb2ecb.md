
## 总拥有成本 (TCO)

在任何商业组织中，成本都是任何新举措的首要关注点；ERP 系统也不例外。Dynamics AX 因以下独特功能而提供成本优势：

- Dynamics AX 为 Web 和 Microsoft Windows 客户端提供相同的代码版本，这导致开发和 IT 成本更简单、更低廉，并为分布式或拥有移动劳动力的企业提供了极大的便利。
- 用于行业特定垂直领域和国家特定本地化的独立层不仅提供成本节约，还减少了实施 Dynamics AX 所需的工作量。
- 由于 Microsoft Dynamics AX 的分层技术，定制可以更轻松地构建和维护。您可以自定义某一层而不影响其他层的功能。这意味着您可以随着时间的推移以较少的业务中断、风险和费用来适应和升级您的解决方案。
- 由于功能键的缘故，任何功能都可以针对单个用户或用户组启用或禁用。这不仅提供了灵活性，还降低了总拥有成本。
- 由于 Dynamics AX 是基于通用 Microsoft 标准构建的 ERP 应用，而终端用户通常已熟悉这些标准，因此对终端用户的培训所需的工作量更少。

## 灵活性

灵活性是 ERP 解决方案中的另一个重要方面，但不幸的是大多数当前 ERP 解决方案都缺乏这一点。例如，使用 SAP 之类的 ERP 软件包，您必须遵循 SAP 对您业务的想法，他们认为您业务和战略的独特性。Dynamics AX 因以下功能而具有优势：

- **定制灵活性**：Dynamics AX 允许您更改所需的一切。企业将此视为一个很棒的功能。这是您实施的 ERP 能够随业务增长而增长的关键。选择 SAP 之类的 ERP 软件包，您必须遵循 SAP 对您业务的想法，他们认为对您业务运营的最佳方式。而在 Dynamics AX 中，您拥有控制权，并且在追求最佳业务实践的前提下，这些最佳实践可以应用于您的定制需求。这有助于企业降低总拥有成本。
- **分层编程：** Microsoft Dynamics AX 提供分层定制技术以便于构建和维护。您可以自定义某一层而不影响其他层的功能。这意味着您可以随着时间的推移以较少的业务中断、风险和费用来适应和升级您的解决方案。
- **功能键：** 功能键代码是一个很棒的系统。使用功能键，可以针对个人或用户组禁用或启用功能。

> *Microsoft Dynamics AX 结合了丰富的开箱即用功能和额外的灵活性，使 The Systems Depot 能够调整功能以满足其确切的业务需求。* — Jan Sorensen, 高级管理顾问, BKD Technologies (http://www.sdepot.com). (Source: http://www.microsoft.com/casestudies/casestudy.aspx?casestudyid=1000003831.)

## 易于集成

在组织中可能需要保留对不同软件应用程序的旧投资，或某些专用软件需要与 ERP 系统协同工作。在这种情况下，ERP 系统必须提供各种行业标准集成方法。Microsoft 有将各种应用程序如 MS Office、Microsoft Office PerformancePoint server 等集成的长期战略。Dynamics AX 可以使用以下技术进行集成：

- Microsoft Dynamics AX 4.0 包含应用程序集成框架 (AIF)，它允许组织通过在不创建核心解决方案内依赖关系的情况下轻松插入来自其他供应商应用程序的业务逻辑进行扩展。此外，AIF 作为 Web 服务工具箱，通过公开所有应用程序组件来发挥作用，并通过发布用于接收和履行订单等核心业务流程的广泛 Web 服务为开发人员提供先发优势。
- Biztalk 是 Dynamics AX 的兼容集成适配器，它提供了许多优势，例如跨扩展组织的实时可见性、灵活性、部署简便性和投资回报率提升。
- Dynamics AX 可以使用 Web 服务以及行业标准技术（如 Microsoft BizTalk Server、组件对象模型 (COM) 集成、Microsoft 消息队列 (MSMQ)、简单对象访问协议 (SOAP)、Microsoft .NET Framework、XBRL 和 XML）与外部数据源连接。
- Microsoft Dynamics AX 采用与其他 Microsoft 应用程序共享的通用标准设计；它能够与 Microsoft Windows、Microsoft Office 程序和 Microsoft SQL Server 2005 等产品实现更紧密的集成和更无缝的连接。
- Dynamics AX 支持 Microsoft Office Outlook 消息传递和协作客户端、Microsoft Office Word 和 Microsoft Office Excel 电子表格软件使用的不同 Microsoft 开发的文档格式，并且可以确保互操作性。
- 与迫使您使用专用工具集的一些业务管理系统不同，Microsoft Dynamics AX 使用基于 SQL Server Reporting Services 和 Microsoft Visual Studio .NET 开发系统的标准适配器。这立即使您能够访问各种行业标准集成协议和经过培训的集成合作伙伴，您可以使用它们将业务合作伙伴的业务管理解决方案连接起来。
