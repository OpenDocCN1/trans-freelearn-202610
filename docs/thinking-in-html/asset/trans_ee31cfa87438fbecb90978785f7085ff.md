## 标题

标题标签用于区分网页的标题与其他内容。存在层级关系，这意味着 <h1> 中的内容是最重要的，而 <h6> 中的内容是最不重要的。

让我们现在看一个代码示例以便更好地理解：

```
<!DOCTYPE html>
<html>
<head>
<title> HTML Headings </title>
</head>
<body>
<h1>Welcome to Packt</h1>
<h2>Welcome to Packt</h2>
<h3>Welcome to Packt</h3>
<h4>Welcome to Packt</h4>
<h5>Welcome to Packt</h5>
<h6> Welcome to Packt </h6>
</body>
</html>
```

从输出中，你可以看到 `<strong>` 用于表示重要内容，而 `<i>` 用于斜体字体。`<code>` 标签定义计算机代码文本，而 `<em>` 用于描述重要内容。`<b>` 标签用于粗体文本。`<sup>` 和 `<sub>` 标签用于定义上标和下标。上标和下标基本上是那些比正常行型小且略高于或低于它的数字或单词。包含注释是一个良好的实践，可确保代码易于阅读。在 HTML 中，注释位于尖括号之间并带有感叹号，如以下代码所示：

```
<!-- Comments help aspiring newbies -->
```

注释不会在浏览器中显示。

## 链接

HTML 中的锚标签 (`<a>`) 用于定义超链接。**超链接** 可以是一个元素，它会带你到特定位置，无论是网站还是同一文档中的其他位置或其他文档中的位置。我们使用 `href` 属性与 `<a>` 标签一起指定链接目标。

让我们看以下代码以便更好地理解：

```
```html
<!DOCTYPE html>
<html>
<head>
<title> Links </title>
</head>
<body>
<h1 id="packt"> Links in HTML </h1>
<p> A normal link </p>
<a href="http://packtlib.packtpub.com">Packt Library</a>
<br><hr>
<p> Image acts like a hyperlink </p>
<a href="http://www.packtpub.com/">
<img src="Packt-image2.png" alt="Packt" />
</a>
<br><hr>
<p> An email link </p>
<a href="mailto:xyz@packt.com">Send Email</a>
<hr>
<a href="#packt"> Go to the Heading tag </a>
</body>
</html>
```
```

## 表单

表单用于收集用户输入，例如姓名、年龄、性别和电子邮件地址，通过文本、单选按钮和复选框等方式。输入随后会被发送到服务器端进行处理。最常用的表单属性是 name、action、target 和 enctype（读作 encryption）。

表单输入类型有多种，例如文本字段、密码、单选按钮、复选框和提交按钮。在 <form> 标签之间，你可以指定 action 属性，告诉表单其内容将被发送到何处（主要是用于处理的服务器端脚本）。我们使用 method 属性告知表单数据将如何发送；通常默认为 GET，但你也可以使用 POST 和其他方法。

GET 方法的一个例子是搜索引擎结果，你可以在网页地址栏中看到你在搜索框中输入的信息。POST 方法用于敏感数据，其中表单数据对用户不可见，从而确保高度安全性。

让我们看以下代码以便更好地理解：

```
<!DOCTYPE html>
<html>
<body>
<h1> Motorbike Customer requirement </h1>
```

在同一网页上，我们定义了另一个表单。让我们看一下代码示例中的以下行：

```
<form action="MAILTO:abcxyz@demo.com" method="post" enctype="text/plain">
```

我们定义了 action，反馈将通过电子邮件发送给电子邮件地址为 abcxyz@demo.com 的相关人员。我们使用了 POST 方法和纯文本作为加密类型。随后，我们将输入类型定义为文本，并分配了一个值，该值将显示在文本框中以帮助用户了解需要输入哪些信息。

之后，我们为反馈字段定义了一个文本区域，因为我们有多行输入。在此示例中，我们为文本区域分配了 5 行和 40 列。之后，我们创建了 **Send** 和 **Reset** 按钮。**Reset** 按钮将清除你在字段中输入的信息。假设我们输入 Edward 作为姓名，Edward@packt.com 作为电子邮件地址，并在评论字段中输入 Miscellaneous。

> 请记住，你需要拥有 Microsoft Outlook 或 Mozilla Thunderbird 等电子邮件客户端才能使用此功能。在此示例中，我们使用了 Mozilla Thunderbird 作为电子邮件客户端。

## HTML5 – 未来已来

HTML5 仍处于开发阶段，预计标准版本将在 2014 年晚些时候发布。HTML5 将很快被接受为基准。它在多个方面与之前的 HTML 版本不同。HTML5 可与现代浏览器配合使用，同时提供向后兼容性。它具有许多新功能，这些功能最终将改变网站设计的思路。HTML5 中的文档类型声明非常简单。我们只需输入 `<!DOCTYPE html>`，浏览器即可识别我们将使用 HTML5。
