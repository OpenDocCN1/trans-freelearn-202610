# Part 3:
Storing and
Productionizing Graphs

借助本部分，使用生产级系统变得轻而易举。我们首先使用图数据库工作，并展示 Neo4j 的使用，以存储我们的数据库以实现快速高效的处理和信息检索。一旦数据存储完成，我们将继续创建一个路线优化解决方案，利用节点到边的连接的灵活性，以及在图数据库中查询的速度。

逻辑上，过渡到设计可有效演进以满足底层数据变化的生产质量管道。 这些部分的重点是让 Python 与 Neo4j 和谐工作，并确保我们在途中构建的管道可以随着时间的推移而更改、变形和演进。

本部分包含以下章节：
- Chapter 5, Working with Graph Databases
- Chapter 6, Pipeline Development
- Chapter 7, Refactoring and Evolving Schemas
