# Part 2: Making the Graph Transition

在掌握了上一部分关于基础知识的内容后，我们现在可以继续解释图数据库与传统关系数据库结构的不同之处，以及为什么以及如何使用它们。我们将在数据模型转换章节中使用 MySQL 和 Python，最终构建一个推荐引擎来为用户推荐游戏。
