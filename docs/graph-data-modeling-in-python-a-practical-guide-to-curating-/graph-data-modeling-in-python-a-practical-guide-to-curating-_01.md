# 前言

全球各地的组织开始使用图方法和可视化技术来理解复杂网络。这些网络存在于许多行业中，从社交网络分析（分析人们在社交网络上互动的联系）到欺诈检测（查看网络中的交易以发现异常值），建模铁路和能源电网等系统的稳定性，并且作为推荐引擎的关键组成部分，这些引擎被用于许多你喜爱的在线流媒体服务，例如Netflix、Prime等。

本书为你提供了在熟悉语言（如Python）中使用这些方法所需的工具。我们首先介绍如何在igraph、NetworkX中创建图，以及如何使用这些图进行复杂的图分析。然后，我们将深入Neo4j和图数据库的世界，并赋予你用Cypher查询语言查询图数据库的知识。

## 本书读者对象

本书的主要目的是帮助现有的中级Python开发者，他们可能有志于进入图数据建模领域。或者，如果你是数据库开发者或IT专业人士，那么图数据库部分可能会让你深入了解图数据库与传统数据库有何不同。

本质上，本书面向所有热爱用Python编写代码并希望进一步了解如何构建图数据管道、如何摄入和清洗数据、存储图数据关系的各种方式、如何开展社区发现和推荐引擎创建等分析技术，以及如何使用Cypher存储这些关系并随后用Cypher查询*内存中*的图。

## 本书内容

- *第1章 真实世界中的图简介*，带你了解为什么应该考虑使用图。什么是图数据结构的基本要素，例如节点和边？它还涵盖图在各行业中的应用，并温和地介绍igraph和NetworkX。
- *第2章 使用图数据模型*，讲解如何处理图。在此基础上，你将在Python中实现一个模型，以推荐最受欢迎的电视节目。





第 3 章《数据模型转换 – 关系型到图数据库》将通过 MySQL 实践操作，探讨数据如何从图数据库导入到 MySQL，然后介绍如何基于用户在热门平台 Steam 上的游戏历史，构建推荐引擎来为用户推荐类似游戏。

第 4 章《构建知识图谱》将把你的技能应用于构建知识图谱以分析医学摘要，清理数据，然后对知识图谱执行图分析和社区检测。

第 5 章《使用图数据库》将探讨如何使用 Neo4j 工作以及如何使用 Cypher 命令将数据存储在图数据库中。然后将使用 Python 通过将 Neo4j 连接到 Python 来与我们的图数据库交互。

第 6 章《管道开发》包含了设计模式所需的一切知识，并使其能够与你的图管道协同工作，最终在 Neo4j、igraph 和 Python 之间实现产品推荐。

第 7 章《重构和演进模式》讨论了为什么需要重构、如何有效演进以及如何将这些更改应用到你的开发生命周期中。

第 8 章《完美投影》讨论了在 Neo4j 和 igraph 中理解、创建、分析和使用投影。

第 9 章《常见错误和调试》解释了如何调试图问题以及如何处理 Neo4j 和 igraph 中最常见的问题。

## 如何充分利用本书

你需要为这些教程创建 Python 3.8 的虚拟环境，因为所有代码都已在 Python 3.8 上测试过，不过它们应该可以在 Python 的未来版本上运行。此外，在使用 Neo4j 时，请参阅第 5 章《使用图数据库》，其中提供了全面的安装说明。

| 书中涵盖的软件/硬件 | 操作系统要求 |
|---|---|
| Python 3.7/3.8/3.9 | Windows、macOS 或 Linux |
| Neo4j Community Edition v1.5.7 | Windows、macOS 或 Linux |
| MySQL 5.7.39 | Windows、macOS 或 Linux |

每个章节的每个仓库都有一个 `requirements.txt` 文件，你需要在工作 Python 环境中 `pip install` 它。

如果你使用的是本书的数字版，我们建议你自己输入代码或从本书的 GitHub 仓库访问代码（链接在下一节提供）。这样做将帮助你避免与复制和粘贴代码相关的任何潜在错误。
