# 第 4 部分：像专业人士一样构建图

在本部分中，我们将探讨图投影是什么以及如何使用它们。这将为您提供提取投影以执行分析所需的初步知识。这些投影随后可以提取用于进一步的统计和分析用途。您将在本章中了解如何做到这一点。此外，您还将了解如何将投影导出到 igraph 和 Neo4j。系好安全带，让分析随着使用案例的展开而流动，该案例研究了使用诸如 *acted in* 和 *starred with* 等关系的电影分析。
