19. Let's briefly define a method for retrieving products from Neo4j. Because, at first, our customers will make purchases at random, we only need product IDs from our Product nodes in Neo4j. To get the IDs, we can first write a Cypher query inside a method, get_product_ids(), using a MATCH statement. In the same query, we can then RETURN the product IDs for each node. Next, we run the query using connection.query(). The result is returned as a list of dictionaries, each with one key-value pair, with the key productID. So, we can use a list comprehension to extract the product IDs from each dictionary, and add them to a list:

```
def get_product_ids(connection):
    query = 'MATCH (p:Product) RETURN p.productID as productID'
    result = connection.query(query).data()
    result = [product['productID'] for product in result]
    return result
```

20. We will make sure get_product_ids() works, by opening a Neo4j connection and calling the method:

```

    'admin', 'testpython')
product_ids = get_product_ids(connection)
connection.close()
print(product_ids)
print(len(product_ids))
```
