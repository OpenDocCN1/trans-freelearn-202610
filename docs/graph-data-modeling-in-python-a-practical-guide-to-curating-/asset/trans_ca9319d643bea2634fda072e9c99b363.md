在涉及图的生产系统中，图数据库充当持久数据存储解决方案。除了保存大量数据外，图数据库通常设计为高效且并发地执行大量读写操作。它们很可能成为任何依赖于大量图数据处理的生产管道的一部分，例如大型在线零售商的推荐系统。
