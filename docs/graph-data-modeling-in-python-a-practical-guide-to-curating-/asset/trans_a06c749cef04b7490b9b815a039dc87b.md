## 前言

全球各地的组织开始使用图方法和可视化技术来理解复杂网络。这些网络存在于许多行业中，从社交网络分析（分析人们在社交网络上互动的联系）到欺诈检测（查看网络中的交易以发现异常值），建模铁路和能源电网等系统的稳定性，并且作为推荐引擎的关键组成部分，这些引擎被用于许多你喜爱的在线流媒体服务，例如Netflix、Prime等。

本书为你提供了在熟悉语言（如Python）中使用这些方法所需的工具。我们首先介绍如何在igraph、NetworkX中创建图，以及如何使用这些图进行复杂的图分析。然后，我们将深入Neo4j和图数据库的世界，并赋予你用Cypher查询语言查询图数据库的知识。

### 本书读者对象

本书的主要目的是帮助现有的中级Python开发者，他们可能有志于进入图数据建模领域。或者，如果你是数据库开发者或IT专业人士，那么图数据库部分可能会让你深入了解图数据库与传统数据库有何不同。

本质上，本书面向所有热爱用Python编写代码并希望进一步了解如何构建图数据管道、如何摄入和清洗数据、存储图数据关系的各种方式、如何开展社区发现和推荐引擎创建等分析技术，以及如何使用Cypher存储这些关系并随后用Cypher查询*内存中*的图。

### 本书内容

- *第1章 真实世界中的图简介*，带你了解为什么应该考虑使用图。什么是图数据结构的基本要素，例如节点和边？它还涵盖图在各行业中的应用，并温和地介绍igraph和NetworkX。
- *第2章 使用图数据模型*，讲解如何处理图。在此基础上，你将在Python中实现一个模型，以推荐最受欢迎的电视节目。
