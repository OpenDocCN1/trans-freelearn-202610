# ## Building our handler

Now we need to build our handler to get events from our Sanity Studio dataset. We will use the Sanity Client npm plugin as we did in *Chapter 11, APIs - Extending Gatsby*:

+   Go to npm to get the latest version of the package: `https://www.npmjs.com/package/@sanity/client`. You can see the version on the right-hand side of the page. At the time of writing this book, the latest stable version is **1.150.1**:

![](bbox=[0.11, 0.24, 0.83, 0.55])

+   In our **Code** editor in our Alexa console, open the `package.json` file and add the Sanity Client npm plugin to the dependencies array:

```
```
