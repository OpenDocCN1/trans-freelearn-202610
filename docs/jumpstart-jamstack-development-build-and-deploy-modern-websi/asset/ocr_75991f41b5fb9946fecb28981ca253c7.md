# Code

Now that we have explored the Build section, let's jump to the Alexa service part, which is our Node.js code:

![](bbox=[0.13, 0.18, 0.85, 0.52])

Figure 12.20 – Alexa skill Code page

As you can see, the interface provides a code editor where we can implement our Alexa service.

In our index.js file, we can create the handlers for our intent. Any new intent we add can be implemented here. Alexa provides an API to handle the request. It's called the ask-sdk-core API. The requests are inside the handlerInput JSON object.

The handler will process our intent and, from here, will make the Sanity call to our Sanity dataset.

At the top of our index.js file, we require ask-sdk-core:

```
const Alexa = require('ask-sdk-core');
```
