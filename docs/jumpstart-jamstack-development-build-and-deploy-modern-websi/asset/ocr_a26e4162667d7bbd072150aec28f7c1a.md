7. Finally, a trick is employed here to instruct Gatsby to display _rawBody if it exists using a logical and. The double ampersand is used to denote and. The format is if a and b. Here, if a is false, meaning that _rawBody has no contents, then the <PortableText> tag and its contents, _rawBody, will not be displayed.

PortableText is a component that converts Sanity’s content, _rawBody, to React content so that it can be displayed properly:

```
{_rawBody && <PortableText blocks={_rawBody} />}
</div>
</div>
</Container>
</article>
```
