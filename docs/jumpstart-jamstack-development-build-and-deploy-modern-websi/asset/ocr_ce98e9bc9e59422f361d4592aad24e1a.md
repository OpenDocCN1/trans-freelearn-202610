At the end of the file, we export the handler using the ask-sdk-core API:

```
// The SkillBuilder acts as the entry point for your skill,
routing all request and response
// payloads to the handlers above. Make sure any new handlers
or interceptors you've
// defined are included below. The order matters - they're
processed top to bottom.
exports.handler = Alexa.SkillBuilders.custom()
  .addRequestHandlers(
    LaunchRequestHandler,
    HelloWorldIntentHandler,
    HelpIntentHandler,
    CancelAndStopIntentHandler,
    SessionEndedRequestHandler,
  )
  .addErrorHandlers(
    ErrorHandler,
  )
  .lambda();
```
