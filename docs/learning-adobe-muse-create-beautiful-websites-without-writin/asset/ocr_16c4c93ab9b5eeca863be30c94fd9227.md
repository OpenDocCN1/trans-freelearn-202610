# Horizontal menus

Everything we've looked at in relation to a Bar Menu is also applicable to Horizontal and Vertical menus.

To create a horizontal menu, simply click-and-drag it out from the Menus section in the Widgets Library panel. Once the menu is on the page, you can style it using the same options as the Bar Menu.

# Vertical menus

To create a Vertical menu, click-and-drag it out from the Menus section in the Widgets Library panel. The obvious difference here is that the menu item appears one under the other. The submenus fly out horizontally, as shown in the following screenshot:
