# Editing our Photoshop file

One of the nice features in Muse when dealing with a PSD file is that we can easily go back and make changes to our PSD and it will be automatically updated in our Muse web page. Use the following steps to do so:

+   1. In the Assets panel you will see your new image listed as YourFilename.psd. Right-click on its name in the panel to see a list of menu options.

![](bbox=[0.236, 0.217, 0.766, 0.652])

+   2. If you need to go back and edit your original PSD file, choose Edit Original. This takes you back to Photoshop where you can make as many changes as you like.

+   3. When you are finished editing in Photoshop, choose File | Save.

+   4. Back in Muse, you will see that the changes you made to your PSD are reflected immediately.

> If your changes have not appeared, right-click on the filename in the Assets panel again and choose Update Asset. You should now see the update kick in.
