# Setting a gradient fill

Instead of using a solid color as a background to a rectangle, we have the option of using a gradient. The following steps show us how we do it:

+   1. Click on the Fill menu on the Control Panel.
+   2. Click on the Gradient radio button to reveal the gradient options.
+   3. Set your start color by clicking on the color picker on the left. Choose a light blue similar to the main page background.
+   4. Set your end color to a dark navy.
+   5. Set the direction to Vertical and leave the other options as they are. The changes to your rectangle fill will appear as you make changes.
