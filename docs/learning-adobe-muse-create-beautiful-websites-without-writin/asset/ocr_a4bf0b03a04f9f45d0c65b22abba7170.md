In this chapter, we'll continue building using the site structure we set up for the Windsurfing site and make changes to the master page, so that those design elements will appear on each page of our site. The following screenshot shows the sitemap as seen in the Muse's Plan view:

![](bbox=[0.125, 0.154, 0.945, 0.593])

Notice that the Prototype thumbnail shows us the content of that page. We can use the Size slider in the Plan view to zoom in and out. Our home page, often referred to as the Index page, contains links to the Gear page, Learning page, and a Contact page. The Gear page contains links to two other pages—Sails and Boards. This site structure lets us present the information to the users in a logical order, making it easy to always return to the home page from any point within the website.

> Note that under each thumbnail we can see [A-Master] in blue. This tells us that the A-Master page (or first Master page) has been applied to each of our web pages.
