3. To add content to the large area known as the container under the tabs, select the container by clicking first on the widget, then click on the tab under which you want to add content, and then finally click on the container.

4. We can add text by clicking on the Text tool and then typing or pasting text.

5. We can add images by placing an image using File | Place. The image will be automatically resized by Muse to fit within the container.

6. We can add slideshows by dragging them out from the Widgets Library into the container.
