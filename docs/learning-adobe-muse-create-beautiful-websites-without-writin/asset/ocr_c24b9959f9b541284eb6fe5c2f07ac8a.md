In the previous chapter, we added text to the page by selecting the text tool and then clicking-and-dragging a rectangular shape out. This created a text frame. Text frames and other objects such as widgets and images behave very much like rectangles in respect to their design. For example, if you want to add a bevel or a stroke to a text box, you would follow the same procedure for both.

> You can convert any rectangle into a text frame by double-clicking on it with the text tool.

So let's get started and create some rectangles on our pages. If you've been following along, open up the Windsurfing site in the Plan view so that you can see your site map.
