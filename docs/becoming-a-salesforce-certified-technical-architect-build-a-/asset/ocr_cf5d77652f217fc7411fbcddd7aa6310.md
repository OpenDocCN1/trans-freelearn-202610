# The integration interfaces look as follows:

| Interface Code | Source/Destination | Integration Layer | Integration Pattern | Description | Security | Authentication |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Int-001 | Salesforce mobile app (via Mobile Publisher) -> Salesforce | Data | Remote Call-in | Customer registration and interaction with all services available in the customer community. Data is retrieved using Salesforce REST API. | HTTPS (one-way SSL/TLS) | OpenID Connect user-agent flow |
| Int-002 | Salesforce -> MuleSoft -> Vehicle licensing agency of a given country | Business logic | Remote process invocation - request and reply - blocking | Validate a customer's driver's license. This interface is used after a customer enters his/her license. The sales agent clicks on a button that starts the transaction, invoking a web service exposed by MuleSoft. MuleSoft would then determine the right licensing agency to call, call the right web service on behalf of Salesforce. This process is triggered by the customer during itself. | HTTPS (two-way SSL/TLS) between Salesforce and MuleSoft. HTTPS (one-way SSL/TLS) between MuleSoft and the rental calculator. | OAuth 2.0 web server flow (then Refresh Token flow) with mutual authentication between Salesforce and MuleSoft. Simple authentication between MuleSoft and the national car rental agency/Global car rental calculator. |
| Int-003 | Salesforce -> MuleSoft -> Global car rental calculator | | | Calculate the real price based on a set of parameters. The interface is invoked in blocking mode when searching and displaying the available cars. | | |
| Int-004 | Tablet app -> Salesforce | Data | Remote Call-in | Check for car collection. The tablet accepts text input (registration number) and validates the Salesforce REST API to validate it. The tablet will also update the order status of the validation is successful. | HTTPS (one-way SSL/TLS) | OpenID Connect user-agent flow |
| Int-005 | Salesforce <-> MuleSoft <-> ERPs | Data | Batch data synchronization - async | A scheduled MuleSoft batch job to sync customer details from Salesforce to ERP. This also includes several other lookup/master tables, such as Product. The frequency of the scheduled job is assumed to be 15 minutes. | HTTPS (two-way SSL/TLS) between Salesforce and MuleSoft. HTTPS (one-way SSL/TLS) between MuleSoft and the ERPs. | OAuth 2.0 web server flow (then Refresh Token flow) with mutual authentication between Salesforce and MuleSoft and simple authentication between MuleSoft and the ERPs. |
| Int-006 | | | | A scheduled MuleSoft batch job to sync orders, order items, and payments from Salesforce to ERP. The frequency of the scheduled job is assumed to be 15 minutes. | | |
| Int-007 | | | | A scheduled MuleSoft batch job to sync invoice headers from the ERPs to Salesforce. The frequency of the scheduled job is assumed to be one hour. | | |
| Int-008 | Global tracking system -> Tracking devices | Business logic | Remote process invocation - request and reply - blocking | Configure the tracking devices remotely. | HTTPS (one-way SSL/TLS) | OAuth 2.0 asset token flow |
| Int-009 | Tracking devices -> Heroku | Data | Remote process invocation - request and reply - blocking | Data such as the car's GPS co-ordinates and speed is sent from the tracking devices to Heroku. | | |
| Int-010 | Heroku <-> Salesforce | Data | Batch data synchronization - async | Bi-directional data sync between Salesforce Core Cloud (Force.com) and Heroku using Heroku connect. Assumed objects are Accounts and cases. This interface is used to transfer theft incidents from Heroku to Salesforce. | HTTPS (one-way SSL/TLS) | OAuth 2.0 web server flow |
| Int-011 | Heroku -> Salesforce CRM Analytics | | | Copy crime incidents' readings data from Heroku to Salesforce CRM Analytics. | | |
| Int-012 | Violation databases -> MuleSoft -> ERPs | Data | Batch data synchronization - async | A scheduled MuleSoft batch job to query the violation databases for any new data related to PPA, then transfer that data to the ERPs to calculate new invoices. The frequency of the scheduled job is assumed to be 15 minutes. | HTTPS (one-way SSL/TLS) | Simple authentication between MuleSoft and ERPs and between MuleSoft and the violation databases. |
| Int-013 | Salesforce <-> MuleSoft <-> ERPs | Data | Batch data synchronization - async | A scheduled MuleSoft batch job to sync the penalty invoice headers from the ERPs to Salesforce. The frequency of the scheduled job is assumed to be one hour. | HTTPS (two-way SSL/TLS) between Salesforce and MuleSoft. HTTPS (one-way SSL/TLS) between MuleSoft and the ERPs. | OAuth 2.0 web server flow (then Refresh Token flow) with mutual authentication between Salesforce and MuleSoft and simple authentication between MuleSoft and the ERPs. |
