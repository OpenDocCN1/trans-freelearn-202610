

无论你是否在瞄准 CTA 资格认证，作为架构师，你都会发现可以将本书中的知识应用到日常工作中。获得所有所需领域知识的实操经验的最佳方法是遵循以下简单步骤：

- 1. 将本书中解释的方法论（或其自身变体）应用到日常工作中。付诸实践，你会发现过一段时间它会变得得心应手。这使得你更容易通过评审委员会考试。可以这样说：如果你日复一日地练习，你就会在正常工作时间内为评审委员会考试做准备。

- 2. 搭建实验环境亲手试试各种事物。作为架构师，必须对构成解决方案的不同元素和技术拥有实操经验。这一点在使用 Salesforce 平台时尤为重要，考虑到其所有灵活性，以及它能让你轻松注册几乎无限数量的开发者环境。

没有什么能比得上实操经验。因此，下次你在调查某个特定 **单点登录 (SSO)** 流程如何工作时，不要只阅读相关内容：*搭建一个实验环境*并*密切观察系统之间如何交互*。在评估给定业务挑战的不同潜在解决方案时，将此作为你日常工作的一部分。

- 3. 让自己熟悉记录设计决策的活动。在进行 Salesforce 实施项目时，你会遇到无数存在多个潜在解决方案的情况。让自己熟悉以结构化方式记录每个选项的细节以及其优缺点。

此活动有多种好处，包括帮助你通过将想法写在纸上并与他人分享来组织思路。这增加了选择正确解决方案/方法的机会。此外，它可以帮助你清晰地向项目架构委员会和利益相关者传达可用的不同选项。不仅如此，它还能帮助你记录解决方案；这是你的项目赞助商会欣赏的事情。

这是另一个可以显著帮助你为评审委员会做准备的日常活动示例。虽然你可能不会以现实中那样彻底的方式记录不同的解决方案和权衡，但识别不同的方法、权衡、妥协和风险，并理性地证明特定解决方案的合理性，这正是评审委员会期间对你的期望。

上述提到的实践和技能不应被视为仅为了通过评审委员会考试而学习和掌握的东西；这些是有价值的技能和实践，应该成为你日常例行工作的一部分。当你这样做时，你会发现自己正在变得准备好参加评审委员会考试。CTA 证书将简单地成为锦上添花之物，证明你具备所有所需技能，并且知道如何将它们全部付诸实践。

## 考试的性质：一个积分收集练习

了解评审委员会考试的性质将帮助你准备考试，并在演示阶段特别有价值。下表将帮助你揭开此考试某些元素的神秘面纱：

| 主题 | 详情 |
| --- | --- |
| 以引人入胜的故事呈现你的解决方案。 | • 你将被要求创建一个端到端解决方案，并将其传达给评委。为此，你需要创建一组交付物，帮助你以引人入胜的故事讲述解决方案。<br>• 你的演示应以能吸引听众注意力的方式执行。<br>• 一旦开始演示，试着忘记自己身处评委面前的考场。相反，想象自己坐在场景中提到的公司的一群高管和 CXO 面前。暂时忘记这些评委为 Salesforce 工作；让自己处于向他们展示解决方案的正确心态和思维中。他们对该平台有扎实的技术知识，并希望了解你计划如何使用它来解决他们的问题。 |
| 针对所有要求并避免错失易得点。考试是一个积分收集练习。 | • 考试本身就是一个积分收集练习。你通过识别场景中的任何解决方案要求来获得分数。有些要求容易发现并解决。例如，你可能会遇到一个可以通过字段级安全设置来解决的安全要求。不要忽略它，或将其从你即将讲述的解决方案故事中删除。你可能会简单地错失一个易得点。<br>• 在问答环节，评委会尝试询问你在演示中未涵盖的要求。这将为你提供第二次机会来涵盖它们。<br>• 请记住，你在问答环节的时间有限，如果你有许多未识别或未解决的要求，那么在涵盖所有要求之前可能会用完时间。这意味着会丢失可能影响结果的宝贵分数。 |
| 拥抱问答环节。 | • 许多 CTA 候选人误解了问答环节的目的，并将其视为考试中最具挑战性的部分。但你应该将此阶段视为弥补一些遗漏差距的机会。这是帮助你向世界上最优秀的技术架构师展示你的知识、技能和经验的阶段。<br>• 诚然，你将受到挑战，你的知识将受到考验，但这正是你可以向评委展示技能的时刻。<br>• 你必须保持专注，并精确回答。尽量避免重复。记住充分利用问答环节的可用时间。 |
| 为场景中的一些变化做准备并预见它们。 | • 在演示过程中，评委可能会决定更改其中一个要求，以检查你快速调整并即时找到解决方案的能力。<br>• 因此避免紧张，或假设自己可能犯了错误。请记住保持冷静，因为这是测试的一部分。 |
| 处理你犯错时的情况；最重要的是你如何处理这种情况。 | • 在演示（或问答环节）中，你可能会发现犯了错误并决定进行调整。这并非灾难。不要失去专注；评委会欣赏你以专业的方式处理此类困难情况并恢复到正轨。<br>• 如果你犯了错误，请专业地承认，解释你决策背后的原因，并予以纠正。<br>• 此外，简要说明你在实际项目中将如何处理此类要求。<br>• 然而，请记住，如果你犯多个错误，通过考试的可能性将降低。 |
| 让评委知道你在想什么以及你如何做出决策。 | • 评委在场是为了确保你具备使用 Salesforce 平台创建安全、可扩展解决方案的能力。让他们知道你在想什么以及你如何做出决策是件好事。<br><br>• 这将帮助他们理解你的逻辑，从而更好地理解做出导致次优解决方案的决策背后的原因。<br><br>• 你将面对的大多数场景都有多种解决方法。需要牢记的关键是，你的解决方案必须基于正确的考量和逻辑。这是 CTA 必须具备的一项重要技能，即能够思考整体解决方案、识别潜在解决方案，并理性地选择合适的方案。 |
| 从技术角度争取最佳解决方案。 | • 你提出的解决方案应是你能从技术角度想到的最佳方案。你不应假设存在场景中未直接或间接提及的挑战。<br><br>• 例如，不要因为担心客户可能面临预算挑战而选择次优解决方案；只有当场景本身提及时才这样做。 |
| 提升你的沟通技巧。 | • 请始终牢记，你给出的解决方案必须基于给定的要求进行呈现。<br><br>• 记住，你应该向客户公司的 CXO 做演示，并将解决方案与要求联系起来。<br><br>• 这将吸引听众，并使整体画面更加清晰。你将在本书后面章节中遇到多个此类示例。 |
