## COBIT

COBIT 5 基于五项不同的治理和管理控制：

1. 满足利益相关者需求
2. 覆盖企业端到端
3. 应用单一、集成的框架
4. 实现整体方法
5. 区分治理与管理

COBIT 是一套用于 IT 的企业治理和管理框架。该框架指导你如何实施计划并执行这些计划。随后，你审查进度，根据结果评估成功标准，制定补救项目计划，并重新开始该过程。这是启动新项目或持续改进 IT 的有效方式。

## ISO/IEC 27001

由 ISO 制定，ISO/IEC *27001* 是一项国际标准，用于建立基线和保护 IT 资产以及评估风险。*27001* 框架的基础是通过采用和应用**机密性、完整性和可用性**（**CIA**）三要素，确保安全控制到位。

除了 CIA 三要素外，它还规定了使用**信息安全管理体系**（**ISMS**）。ISMS 用于记录环境中实施的安全控制。CIA 三要素定义如下：

- **机密性** – 限制对被视为敏感的 IT 资源或信息的访问
- **完整性** – 确保信息未被预期当事人以外的任何人篡改
- **可用性** – 根据组织或服务级别协议的要求，信息或 IT 资源可用

组织和个人也可以获得 ISO *27001* 认证。组织利用认证向客户证明他们已建立专门的网络安全计划。个人也可以获得认证，这将允许他们为自己的公司或其他组织执行认证评估。

## NIST SP 800-53

# NIST CSF 成功案例

组织可以自由使用和实施 NIST CSF，以最适合其需求。该框架的优势在于其在实施必要网络安全控制方面的灵活性。许多组织通过使用它实现了降低整体网络风险的目标，但不要只听我说。以下是其他实施了 CSF 的组织的成功案例。

## 科罗拉多河下游管理局

作为德克萨斯州居民的服务者，**科罗拉多河下游管理局**（**LCRA**）肩负重任。LCRA 确保来自河流的水可供该州数百万居民安全使用。该河务局被视为关键基础设施，必须确保其 IT 和**运营技术**（**OT**）安全。

LCRA 最初采用 NIST 的 SP *800-53* 来实施网络安全控制。由于其庞大的规模，这导致框架推广出现严重问题。LCRA 需要一个敏捷且可定制的框架，因为其去中心化和组织规模。LCRA 最终放弃了 SP *800-53*，转而采用 CSF。这使他们能够在整个组织应用通用框架。 \[*1*\]

## 生物科学部 – 芝加哥大学

成立于 1890 年，**芝加哥大学**（**UoC**）已为学生服务超过一个世纪。**生物科学部**（**BSD**）是 UoC 内较大的学院之一，拥有 23 个系和 5,000 名教职员工。该学院需要使用多个框架来保持合规，包括 HIPAA 和 FedRAMP。由于其去中心化，学院难以在所有部门维持统一的安全态势。

BSD 汇集了框架**主题专家**（**SMEs**）协助框架推广。该组织开发了一个四阶段流程，使他们能够有效地实现评估和降低网络风险的目标。他们的四阶段方法包括：

1. 开发当前状态概况
2. 执行网络安全评估
3. 创建未来状态概况
4. 执行路线图

团队创建了一个 0-4 的评分系统，以建立两个概况之间的成功度量标准。随后，BSD 为员工创建了培训研讨会，以更好地理解如何使用该框架。 \[*2*》

# 总结

在本章中，我们回顾了什么是框架以及它为什么重要。框架的开发是为了帮助组织填补构建网络安全计划的空白。NIST CSF 是一个可以轻松应用于您组织的框架。

随着网络攻击在 2000 年代初蔓延，我们需要迅速提升安全态势。网络安全框架的创建就是为了协助组织做到这一点。许多人可能认为 IT 和网络安全是相同的，但它们并非如此。正如我们所了解到的，网络安全有其自己的语言和实施解决方案的方式。

正如我们在成功案例中所见，几个组织从其他框架转向使用 CSF，因为其灵活性允许跨多个业务职能实现敏捷性。
