# 第 6 章：检测

在 [第 5 章](#B21915_05.xhtml#_idTextAnchor116) 中，我们了解了 `Protect`（防护）功能。在该章中，我们发现了证明身份的方法。这不仅包括当面验证这些身份，还包括确保认证方法与组织愿意承担的风险级别相称。虽然用户名和密码组合过去足以用于认证目的，但现在已不再足够。

我们还讨论了保护数据的方法。这包括存储在磁盘上的数据、传输中的数据或系统使用的数据。为了充分保护数据，我们必须考虑使用加密来防范**中间人**攻击或内存刮取等攻击。

最后，我们涉及了为系统构建弹性需求。IT 与业务部门之间应有服务级别协议，以确保满足业务需求。如果系统宕机，且对业务至关重要，需要多久才能恢复运行？是否应在所用服务或应用程序中构建冗余？

`Detect`（检测）功能以威胁、漏洞、妥指标和异常的可见性为中心。我们将讨论如何检测它们、可用于执行此检测的方法，以及您的网络中应具备哪些条件来监控此类威胁。

## 持续监控 (`DE.CM`)

应能监控环境中的所有 IT 资源。这不仅包括监控资源和配置漂移的需求，还包括监控资源的安全性和完整性的需求。这可包括监控系统异常、文件完整性检查和日志文件监控。

此监控应是全方位的，意味着我们监控的不仅仅是网络。我们在监控系统、服务器、设备及运行在设备上的软件。我们可以查看用户行为、数据丢失防护和第三方供应商。

### `DE.CM-01`

*监控网络和网络服务以发现潜在的不利事件。*

您的环境中很可能设置了无线网络，但它受保护吗？当用户尝试向网络进行认证时，您是否使用了某种类型的认证？您是否在检测非法接入点以保护网络免受未经授权的访问？这不仅限于无线网络；我们还必须监控本地和广域网。

组织严重依赖互联网开展业务并使用共享服务。您可能拥有集中式或分布式数据中心，从远程位置消费服务。例如，您的总部和分支机构可能有不止一家 **Internet Service Provider**（**ISP**，互联网服务提供商）。为了有效高效地利用多家 ISP，您还需要多个防火墙和网络交换设备。所有这些都使用专用协议来维持高可用性。此外，通信通道应受隔离的 VLAN 和加密保护。

您应保护网络免受可连接到您网络的非法无线接入点的侵害。这些非法接入点可能包含弱密码或加密，或者可能完全开放且无任何保护。这会在您的网络中留下一个漏洞。监控非法接入点，一旦检测到，立即将其关闭。

**802.1x** 等协议允许在获得网络访问权限前进行认证。如果未通过正确的凭据，网络设备将被拒绝访问网络。此协议也可用于无线认证。通过利用 **802.1x** 认证，您可以使用 Active Directory 或类似身份存储中使用的用户名和密码。

监控针对这些及其他协议的攻击，因为这可能是 IT 资源已被攻破的指标。在整个网络中部署 IDS/IPS 传感器，以确保能够捕捉到恶意流量。网络嗅探器和 NetFlow 只是您可以低成本甚至零成本捕捉此类流量的几种方式。

### `DE.CM-02`

*监控物理环境以发现潜在的不利事件。*

我们之前讨论了允许进入数据中心前应做的事。这包括背景调查、前台签到签名以及说明到访目的的工单。所有这些都应定期审查。

您可能拥有刷卡系统，允许员工进入大楼内的特定楼层或门禁区域。这些读卡器存储人员身份信息，以及进出大楼的时间戳。这些系统的日志可发送到您的 **Security Information and Event Management**（**SIEM**，安全信息和事件管理）系统进行分析，并结合最终用户分析来建立用户行为模式。这有助于更好地理解任何异常情况。

监控还有助于针对自然事件发出警报。例如，如果降雨量大且易受洪水影响，您可以在楼宇周围放置传感器以检测积水。也可放置传感器监控服务器室温度，因为服务器通常不耐高温。

### `DE.CM-03`

*监控人员活动和技术使用以发现潜在的不利事件。*

最终用户行为分析工具在高安全环境中确实有其用途。您可能希望监控社交媒体网站上的活动，以监控互联网上发布的内容。这也是检测员工是否浏览招聘网站的绝佳工具。这可能意味着您的知识产权或其他敏感信息会随该员工离职而流失。

监控您的网络和 VPN 日志，查看员工所在位置。我听说过组织受到对手从其他国家登录其 VPN 的影响。正是当组织开始对日志运行查询时，他们检测到来自已知恶意行为者的成功登录。这在 IT 和网络安全团队中引起了警觉，促使他们对事态做出反应。

### `DE.CM-06`

*监控外部服务提供商的活动和服务以发现潜在的不利事件。*

虽然有多种付费服务提供此类信息，但您也可以在内部采取一些措施。我们要监控外部第三方的违规和漏洞，减少攻击面，并审查第三方服务的日志。

如果供应商访问您的环境，您必须审查并批准连接到网络的外来设备。这些外来设备不在您的 IT 或网络安全控制之下。既然这些设备在您的环境中，您就必须确保它们尽可能安全。
