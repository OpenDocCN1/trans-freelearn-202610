

# 事件恢复沟通

让我们来看看这个最后的功能！

## 事件恢复计划执行 (RC.RP)

在该控制系列中，我们将讨论从事件中恢复时该做什么。这包括执行您的恢复计划，使系统恢复到已知的运行状态。这将要求您遵循恢复计划、恢复备份，并为您的 IT 资源建立现有或新的基线。

### RC.RP-01

*一旦从事件响应流程启动，即执行事件响应计划的恢复部分。*

现在我们已经实施了 ICA 和 PCA，是时候开始事件响应计划的实际恢复过程了。这将涉及利用我们的恢复计划，在新建立的基线上让系统重新启动并运行。我们可能还需要让内部和外部利益相关者参与进来以完成此工作。

作为您事件响应计划的一部分，应该有一种方式指示您的 IT 团队开始着手重建环境。应该有关于如何重建系统或 IT 资源并使其恢复到已知运行状态的分步说明。这应包括如何重建服务器或网络设备的程序、从哪里获取必要的软件以及如何安装它。

我们之前制作的网络和应用流程图将派上用场，帮助我们描绘系统如何工作及其相互依赖关系。我们将需要按照这些规格重建我们的环境。除了重建环境外，我们还需要将新系统和流程的实施作为 PCA 的一部分进行规划。

我们的 PCA 可能要求我们拆解旧架构并从头开始，或因使用新应用程序而增强架构。也许我们引入一项新控制，例如实施漏洞管理或新防火墙。这些新系统将需要安装和配置，我们还需要确保它们按预期工作。

如果需要引入新流程，这也是实施的时机。这可能包括需要在设备上配置的额外防火墙规则，或重新审视我们如何针对漏洞修补系统。新流程可能包括更频繁地修补，或根据漏洞的严重性建立何时修补特定漏洞的 SLA。在将新系统实施到环境中时，了解所有这些都很重要。

### RC.RP-02

*选择、确定范围、确定优先级并执行恢复行动。*

当我们开始补救时，必须确定将恢复工作重点放在何处。我们应该回顾我们的 ICA 和 PCA，确定应首先实施什么，以及什么可以暂缓。这可能是由于资源限制或其他问题阻碍了我们实施恢复工作所需的措施。

对恢复所需内容进行调查，并开始制定项目计划，明确实施什么以及何时实施。该项目计划应包括什么最重要、需要尽快恢复，以及什么可以稍后完成。计划应包括可以立即完成的事项，以及需要时间采购并投入生产的事项。

与您的高管领导团队 (ELT) 合作，了解对他们而言什么实施最重要。例如，ELT 和业务部门可能希望您在实施新防火墙之前先实施多因素认证。这些补救工作都基于业务当时愿意接受的风险程度。

也可能同时有多个项目在进行。您可能在致力于流程改进的同时部署新防火墙。根据项目对业务的重要性规划项目实施顺序。这还要求您拥有适当数量的资源。

资源有多种不同类型，但通常归结为财务或人员限制。您的恢复工作将取决于这两者。您可能因预算限制而无法实施新控制系统，直到有更多资金可用时才能推进。

这也可能取决于员工拥有的专业知识水平，因为这可能要求您外包新系统和服务的安装。这也可能要求员工接受正在实施的新系统培训。这两者都将需要项目的额外资金。您甚至可以让受信任的第三方实施新解决方案，同时培训您的员工。

### RC.RP-03

*在用于恢复之前，验证备份和其他恢复资产的完整性。*

我们已经讨论了定期执行备份的重要性。现在是时候测试我们是否有能力将备份恢复到 IT 资源了。除了知道我们能否恢复备份外，我们还必须确保备份中的文件完好无损、未损坏。通过此过程，我们将不得不依赖我们的加密方法来确定是否能成功将系统恢复到正常状态。

执行备份有几种不同的方法。其中一种更流行的方法是“祖父-父-子”法。该方法的目的是定期执行备份，同时最大限度地减少备份的数据量，从而减少存储空间。

“祖父-父-子”备份法如下操作。我们在周日执行全量备份，在一周内执行增量备份。增量备份仅获取给定文件的更改；这是为了减少使用的总磁盘空间。下周日到来时，我们再次执行全量备份，并丢弃本周执行的增量备份。月末时，我们再做一次全量备份并保留该备份以供下个月使用。增量备份称为“子”，每周备份称为“父”，每月备份称为“祖父”备份。

每个备份的文件都应进行哈希处理，以确保在恢复时，我们可以验证正在恢复的文件或镜像与哈希值匹配。不仅每个文件应进行哈希处理，整个备份本身也应有一个哈希值。没有哈希值，我们无法验证正在恢复的备份是否与备份中的内容完全一致。

大多数情况下，攻击者会想访问您的备份，并用某种勒索软件加密它们，意图让您的公司支付赎金以恢复对备份文件的访问。有几种备份解决方案会将您的文件备份到不可变存储格式中。

不可变存储是指文件写入一次且永远无法被覆盖。这种方法有几个好处。首先，一旦文件写入，就无法在备份存储中被修改。这意味着勒索软件无法加密存储磁盘上的文件，从而保持备份文件的完整性。

我们还应强调定期测试备份的必要性。通过测试备份，您可以最大限度地减少定位和恢复备份所需的时间，因为这会变得得心应手。您还应测试能否将镜像恢复到文件系统，并确保该过程未损坏数据。这些额外步骤是为了确保您的备份流程顺利运行。
