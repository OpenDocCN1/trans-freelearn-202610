

# 访问控制 (PR.AA)

## SAML 2.0 和身份提供者

身份验证应防止会话劫持、密码喷射和 MFA 推送疲劳，并确保通信加密。这些只是选择单点登录提供商时需要考虑的几项保障措施。已制定了一些标准来协助解决此问题，其中之一是**安全断言标记语言 (SAML) 2.0**。SAML 2.0 通过**身份提供者 (IdP)** 提供身份验证。IdP 用于对用户进行一次性身份验证，然后向 SP 提供令牌断言。

IdP 和 SP 之间的通信受到保护，免受攻击，并且您可以强制实施 MFA。使用 SAML 提供商的另一个好处是，您可以要求用户重新进行身份验证，从而在发生账户接管事件时终止所有活动会话。

## PR.AA-05

*访问权限、授权和授权在策略中定义、管理、执行和审查，并融入最小权限和职责分离原则。*

当我们向员工授予凭证时，我们为他们提供对特定资源的访问权限。随着时间的推移，这些凭证可能会获得所谓的**权限蔓延**，即调往不同部门或晋升的员工保留了对其不再需要的系统的访问权限。通常，当这种情况发生时，员工使用的凭证会保留其旧权限，同时获得新权限。我们必须考虑将凭证限制为员工完成日常工作所需的权限。

我们还可以考虑**基于属性的访问控制 (ABAC)**，它考虑的因素远不止用户名和密码或 MFA 的使用。ABAC 可以考虑用户或所用凭证的位置、一天中的时间、他们试图访问的内容以及他们的访问意图，无论是读取还是写入文档。

我们应安排时间让员工审查访问权限。这将有助于减少特定用户拥有的权利数量，进一步保障网络安全。用户访问审查应至少每年进行一次，或在提出更改用户账户权限的新请求时进行。

## PR.AA-06

*对资产的物理访问得到管理、监控和执行，与风险相称。*

我们不仅需要保护 IT 资源的逻辑方面，还需要保护物理方面。数据中心安全应始终考虑保护资产的新方法，因为许多逻辑安全配置可能被绕过。管理员账户可通过插入服务器的物理 CD 进行重置，网络设备可通过将注册表设置为特定值来绕过，或通过按住按钮 10 秒来重置设备。

许多数据中心不仅会物理上保护环境，还会实施多项政策和标准，规定人员如何在设施内被陪同。例如，员工可能想进入数据中心维修故障设备。我们应检查他们是否被允许进入数据中心。通常会执行额外的背景调查，以检查试图进入设施的人员是否可信。我们甚至可以决定员工是否可以独自进入设施，或者是否必须由数据中心官员陪同。

我们还必须确立员工进入设施的理由。这通常通过工单完成，因中断而请求访问设施。即使他们已被授予设施访问权限，也不意味着他们可以随时进出数据中心。必须有正当理由。

无论员工能否进入设施，我们仍需验证其身份。这意味着要求员工出示工牌，在签到表上签名并说明访问原因，以及出示授予其进入设施权限的工单号及其访问原因。

这对客人和供应商同样适用。许多客人或供应商若无人陪同，不应被允许进入数据中心。如果他们不为您的公司工作，您可能不希望任何人在无人陪同的情况下访问数据中心。

设施应部署多项防护措施，包括安全摄像头、保安和报警系统。这是为了监控环境，并在出现问题时提供可追溯性。进入服务器室时，我们还可以设置人员闸，要求在进入前进行最后一次授权。在高安全环境中，我们可以使用锁定的机柜，仅提供特定机柜的钥匙。设备上也可使用 RFID 标签，如果服务器被移出设施，则触发警报。

有必要在物理和虚拟层面验证一个人是否为其所声称的人员。这是为了确保正确的个人执行预定职责。安全意识和培训也是教育用户在面对威胁或已识别风险时应采取的适当步骤的关键一步。让我们了解如何做。

# 意识与培训 (PR.AT)

贵公司的员工是网络安全方面的眼睛和耳朵。他们是您的第一道防线。员工往往会在您之前发现针对您设施的新威胁。安全意识和培训不仅面向网络安全专业人员，而是面向公司的每个人。

## PR.AT-01

*为人员提供意识和培训，使其具备知识和技能，能够在考虑安全风险的前提下执行通用任务。*

**安全意识**与**安全培训**是有区别的。**安全意识**旨在在设施内提供通用的网络安全意识。这可能意味着在整个组织张贴传单或海报，宣传网络安全主题。这主要面向 IT 部门以外的人员。

另一方面，**安全培训**则更有针对性，或专注于提供特定领域深入知识的网络安全主题。例如，我们可能了解网络钓鱼诈骗或二维码被恶意利用的危险。一个重点安全培训主题将是培训我们的防火墙管理员使用我们刚刚部署的新防火墙。

网络安全意识活动应定期开展。最佳频率是至少每月一次；时间再长，研究表明人们面对风险时会失去对该做什么的关注 [*1*]。研究表明，每年仅开展一次安全意识项目，与完全不做任何事情一样无效。这就是为什么定期开展这些项目是有益的。

通过网络钓鱼演练跟进您的意识项目，以强化在与电子邮件交互时保持谨慎的必要性。随着网络钓鱼攻击的增加，您需要确保员工接受过培训，知道在收件箱中遇到网络钓鱼邮件时该怎么做。

如前所述，重点培训也是必要的，但这通常针对 IT 相关员工。培训每年至少为您的 IT 和网络安全员工开展一次。也许您需要派他们去上一堂关于使用防火墙的课程，或提供关于新安装的**入侵检测系统/入侵防御系统 (IDS/IPS)** 设备的培训。重点培训也比意识培训昂贵。根据所请求的培训类型，成本可能高达数千美元。这对特定员工是可以接受的，但不适用于全体员工。
