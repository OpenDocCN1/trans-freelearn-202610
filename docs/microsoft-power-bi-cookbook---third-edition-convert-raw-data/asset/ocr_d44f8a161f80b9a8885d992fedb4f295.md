# Building Animation and Storytelling

Business teams and analysts are commonly responsible for sharing or walking through business results, trends, and the findings from their analyses with other stakeholders, such as senior management. To support the message delivery process most effectively, Power BI provides built-in animation capabilities for the standard scatter chart and ArcGIS map visualization types. Additionally, core and custom visuals, such as the pulse chart, further aid the storytelling process by embedding user-defined annotations into the visual and providing full playback control over the animation.

This recipe includes examples to prepare the standard Scatter chart visualization for animation, leveraging the date animation feature of the ArcGIS Maps for Power BI visual. Details on the Bookmarks pane, as well as the Smart narrative and other storytelling custom visuals, are also included.

# Getting ready

To prepare for this recipe, follow these steps:

+   1. Download Building Animation and Storytelling Start.pbix from the following GitHub repository: https://github.com/PacktPublishing/Power-BI-Cookbook-Third-Edition.
+   2. Open Building Animation and Storytelling Start.pbix in Power BI Desktop.
+   3. Edit the AdventureWorks query and change the Source line to point to your SQL server with the AdventureWorksDW2022 database installed.
+   4. Click Close & Apply from the ribbon of the Home tab.
+   5. Save your work.

# How to build animation and storytelling

To implement this recipe, carry out the following steps:

+   1. In the Report view, apply a page-level filter in the Filters pane for the SalesTerritoryGroup column in the SalesTerritories table to only include the value Europe.
+   2. Create a Scatter chart visualization using the SalesTerritoryCountry column from the SalesTerritories table for Values, the CustomerKey column (Count) from the Internet Sales table for the X-axis, and the SalesAmount (Sum) for the Y-axis.
+   3. In the Format your visual tab of the Visualizations pane, expand the Markers card and then the Shape card, set the Size to 100, expand the Color card, set the Color by category toggle to On, and also toggle Category label to On.
+   4. Drag the YearMonth column into the Play Axis field well of the scatter chart visualization.
