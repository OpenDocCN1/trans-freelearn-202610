# # Enhancing Reports

There are many report features that can add greater context and enhance the self-service data exploration experience. Three such features are tooltips, tooltip pages, and drillthrough report pages.

In this recipe, we walk through using **tooltips**, **tooltip pages**, and **drillthrough report pages** to enhance our report.

# ## Getting ready

To prepare for this recipe, follow these steps:

+   - Open the `Creating Table and Matrix Visuals.pbix` file and save the file as `Enhancing Reports.pbix`.

# ## How to enhance reports

To implement this recipe, use the following steps:

+   1. Select the Germany page.
+   2. Select the **Shape map** visualization.
+   3. Add the Internet Net Sales, Internet Margin %, and Internet Sales Per Customer measures from the Internet Sales table to the **Tooltips** field.
+   4. Hover over a colored German state to see the new measures in the **Tooltip** pop-up:

![](bbox=[0.278, 0.5, 0.735, 0.656])

*Figure 4.38: Additional measures displayed in the tooltip*

+   5. Create a new page called `Product Tooltip`.
+   6. In the **Format** pane, expand the **Page information** section and toggle **Allow use as tooltip** to On.
+   7. Create a **Clustered bar chart** visualization and resize it to occupy the entire page.
+   8. Add the `Product Subcategory` column from the Products table to the **Y-axis**. If you do not see this column, unhide this column using **Table view**.
+   9. Add the **Internet Net Sales** measure from the Internet Sales table to the **X-axis**.
