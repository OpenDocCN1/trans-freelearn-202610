As mentioned in the There's more... section of that recipe, Microsoft later extended this functionality with automatic aggregations. Automatic aggregations use machine learning technology to automatically optimize DirectQuery models such that queries against the semantic model can be fulfilled from cached aggregations instead of accessing the source data systems, thus improving performance.

Automatic aggregations work with a small subset of data sources, including:

+   - SQL Server 2019 or later
+   - Azure SQL Database
+   - Azure Synapse Dedicated SQL pool
+   - Google BigQuery
+   - Snowflake
+   - Databricks
+   - Amazon Redshift

To see how to enable automatic aggregations, perform the following steps:

+   1. Ensure that you have a data gateway installed, configured, and running. See Chapter 1, Creating an On-Premises Gateway.
+   2. Complete the Using DirectQuery recipe from Chapter 2 and publish the report to a Premium, PPU, Fabric, or Embedded workspace.
+   3. In the Power BI Service, navigate to the workspace, click the ellipsis (...) next to the semantic model published in step 2, and then choose Settings.
+   4. Expand the Gateway and cloud connections section and ensure that the gateway connection is configured by clicking on the arrow icon under Actions. Map the data source to an existing connection or choose Add to gateway, add the connection, and then repeat steps 3 and 4 to map the data source.
