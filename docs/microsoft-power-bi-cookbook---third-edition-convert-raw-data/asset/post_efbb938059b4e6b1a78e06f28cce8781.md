
An alternative to slicers is the use of the Filter pane. While perhaps not as obvious to end users and requiring specific training, the use of the Filter pane as opposed to slicers does provide the benefit of preserving space on the canvas. However, while the Filter pane can provide some of the basic usage scenarios common to slicers, slicers provide much greater flexibility in terms of interactions with different visuals on a page, synchronization of slicers across specific pages, and the layout and position of filtering elements relative to other visuals.

In this recipe, we look at the primary use cases for slicers and the report design considerations, including selection properties and formatting options. The slicer filter configurations available for Date data types are also reviewed, and additional details on text search and alternative slicer visuals are provided.

## How it works

Slicers are important Power BI visuals, so careful thought should be given when identifying slicer column(s). Typically, slicer columns are parent-level dimensions such as year or region with few individual values. Choosing a column with few values allows these items to be exposed on the canvas as a list, instead of using a dropdown. Using too many slicers, or slicers with too many distinct values, detracts from the usability of report pages. Without significant DAX customization to interpret filter selections, users can be uncertain as to what filters have been applied. Measures cannot be used in slicers, but slicers support the use of hierarchies and ad hoc hierarchies in their Field area.

It is recommended to position slicers to the left of all other visuals on the page. Format the slicer visuals with borders and/or background colors to make the slicers stand out on the page. With regard to using the Slicer header or the Title, pick one of the two and be consistent for all slicers on the page. The Slicer header provides a Clear selections option (the eraser icon).

Selecting items in the slicer cross-filters the other visuals on the page. Select the box next to an option once to select that value, and select the same box again to deselect the same value. Hold down the Ctrl key to select multiple values. This behavior can be controlled using the Selection subcard of the Slicer settings format card.

![](img/5e366dc9e90fe4b1ca9dd97c82976bbd_221_0.png)

You can also force only **Single select**. Turning off **Multi-select with CTRL** makes multiple selection possible without holding down the *Ctrl* key on the keyboard. The **Show “Select all” option** provides a quick method to select and deselect all values. The **Select all** option can be helpful if the slicer contains more than 7 to 10 values. With **Select all**, the user can easily construct a filter to exclude only a few items from a long list.

Slicers can be searched by activating the **Search** option from the ellipsis (...) menu of the slicer.

![](img/5e366dc9e90fe4b1ca9dd97c82976bbd_222_0.png)

*Figure 4.21: Slicer Search option*

Activating this option presents a **Search** bar at the top of the items list. **Search** is useful for long lists of items.

Slicers can also be synchronized between report pages. Synced slicers means that items selected in a slicer on one page affect any other pages where there is a synced slicer. Copying and pasting a slicer between pages prompts the **Sync visuals** dialog box but can also be controlled via the **Sync slicers** pane. By default, slicers with the same **Field** on different pages are “grouped,” but you can use **Advanced options** to control these groupings. In addition to synchronization, the **Sync slicers** dialog box allows you to control whether a slicer is visible on a page. Coupling synced slicers with making slicers invisible on pages can be used to free up page canvas space.

## There’s more…

There are many options when it comes to slicers. In addition to the options discussed so far, there are also special types of slicers, such as horizontal slicers, range slicers, relative date slicers, and the new slicer visualization (in preview).

Horizontal slicers are an alternative design that can be activated by changing the **Style** setting in the **Options** subcard of the **Slicer settings** format card on the **Visual** pane of the **Format** tab. Horizontal orientation slicers are often placed along the top of report pages and can be beneficial for mobile consumption.
