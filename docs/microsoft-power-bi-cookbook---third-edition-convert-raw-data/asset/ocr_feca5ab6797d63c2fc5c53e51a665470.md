# There's more...

Additional data quality dialogs are available in Power Query Editor. From the **View** tab, check the box next to **Column quality** and **Column distribution**. Small visuals will appear under the column headings. Hovering your mouse over this area provides a pop-up dialog that provides suggested actions, as well as common data cleansing activities via the ellipsis menu (...).
