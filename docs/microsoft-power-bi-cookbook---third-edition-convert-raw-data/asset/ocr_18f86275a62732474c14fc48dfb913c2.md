It is common in dev, UAT, and prod scenarios that certain parameters change between environments, such as the name of a database server, the name of a database, or the number of days of data to load. Power BI supports this configuration via deployment pipelines. To demonstrate how parameters can be leveraged within deployment pipelines, perform the following steps:

+   1. Create a new, **Premium**, workspace called **Query Parameters Dev** in the Power BI service.
+   2. Publish the report for this recipe to this workspace.
+   3. Open the **Query Parameters Dev** workspace in the service, and from the ribbon, select **Create deployment pipeline**.
+   4. Name the deployment pipeline Query Parameters and click the **Next** button.
+   5. Accept the defaults for the **Customize your stages** dialog by clicking the **Create** button.
