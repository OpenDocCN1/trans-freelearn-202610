# Building Power BI Reports into PowerPoint Presentations

Microsoft PowerPoint remains a standard slide presentation application, and the integration of data analyses and visualizations from external tools is very commonly an essential component of effective presentation decks. Microsoft now provides its customers with multiple options for surfacing Power BI content within PowerPoint presentations without the need for any third-party add-ins and licenses. One option is the ability to create a new PowerPoint slide deck from scratch by converting each page of a report to their own PowerPoint slide. Another highly valued integration described in the There’s more... section is the ability to insert live and interactive Power BI reports within PowerPoint slides thus enabling data exploration and storytelling during meetings or presentations without leaving PowerPoint.
