# Getting ready

To prepare for this recipe, follow these steps:

+   1. Log in to the Power BI service.
+   2. Click on Workspaces in the left navigation pane and select New workspace at the bottom of the flyout. If you cannot create a workspace, check with your Power BI administrator, as they may have disabled this option.
+   3. In the Create a workspace dialog, enter a workspace name and click Apply.
+   4. In the center area in the ribbon, click Upload and then Browse.
