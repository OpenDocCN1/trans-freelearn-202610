The topic of data quality deals with the overall utility of semantic models, as well as the ability to easily process and use the data for certain purposes, including analytics and reporting. Data quality is an essential component of data governance, ensuring that business data is accurate, complete, consistent, and valid. Good data quality is an essential element of any data analytics and reporting endeavor. Poor data quality can lead to incorrect analysis and decisions by a business—hence the phrase “garbage in, garbage out.” Luckily, Power Query Editor provides powerful data profiling tools to assist in quickly determining the quality of the data that you work with. This recipe demonstrates how to unlock the powerful tools within Power Query Editor to profile columns and gain a sense of the quality of the data being worked upon.

# Getting ready

To get ready for this recipe, import the FactFinance table from the AdventureWorksDW2022 database by doing the following:

+   1. Open Power BI Desktop and choose **Transform data** from the ribbon of the **Home** tab to open Power Query Editor.
+   2. Create an Import mode data source query called AdventureWorksDW2022. This query should be similar to the following:
+   3. Isolate this query in a query group called Data Sources by right-clicking the query in the **Queries** pane and selecting **Move To Group | New Group**.
+   4. Right-click the AdventureWorksDW2022 query and choose **Reference**.
+   5. Choose the FactFinance table link in the Data column and rename the query Finances.
+   6. Move the Finances query to the Other Queries group.
