# How it works

Note that the original North American Total Net Sales metric is now populated with a current value for Progress of 33.16M/45M. This is the sum of the two submetrics' Current value and Final value fields.

Also, note that the Status of each metric is set to Not started. This status can be manually edited to one of six different standard status classifications: Overdue, Behind, At risk, On track, Not started, and Completed. You can also create your own custom statuses and even create automatic rules for when to change status, such as if the value is greater than or equal to 100% of the target, set the status to Completed.

When created, scorecards create their own corresponding semantic model. As data is refreshed, new data points are automatically added to the semantic model. Thus, metric values can be tracked over time. For manual metrics, a new metric check-in can be generated by clicking on the metric name, clicking the New check-in button, entering a date, value, and potentially new status, and then clicking the Save button.

Scorecards also support the ability to create hierarchies that can add additional filters to the scorecard metrics. In the upper left of the scorecard, you can now click Select a hierarchy. Under the Sales Territory hierarchy, you can click on one of the values to filter the scorecard metrics.
