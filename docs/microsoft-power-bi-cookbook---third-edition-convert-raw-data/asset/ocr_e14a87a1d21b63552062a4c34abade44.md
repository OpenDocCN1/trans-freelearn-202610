# How it works

Import mode semantic models use a proprietary file format known as IDF to store VertiPaq data. VertiPaq is the in-memory, columnar compression storage engine for Analysis Services tabular instances. The Fabric engine loads lakehouse delta tables stored in Parquet file format instead of IDF and converts this data into compatible Analysis Services data structures. In addition, the v-order algorithm sorts the data in a similar manner as the native VertiPaq engine in order to improve compression and query performance. The overall effect is improved query times over DirectQuery and roughly analogous to import mode semantic model speeds.
