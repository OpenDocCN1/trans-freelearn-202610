# ## Authoring Power BI Reports

The visually immersive and interactive nature of Power BI reports defines the essence of Power BI to most stakeholders. Although semantic models and their data sources must be developed first to serve as the source of reports, the thoughtful design of intuitive, focused reports that empower users with insights and flexibility can become highly valuable assets for organizations.

Power BI Desktop provides abundant data visualization features and options, enabling the construction of highly targeted, user-friendly reports across devices. As each Power BI Desktop report can contain multiple pages, with each page including multiple visuals, a single Power BI report can support multiple use cases, audiences, and business needs. For example, a KPI visual can be pinned to a dashboard in the Power BI service, while a report page can support detailed, domain-specific analysis. These capabilities compete directly with visualization offerings from competitor analytics platforms and can be further extended with custom visuals and report themes.

The selection and configuration of Power BI visualization features are essential to derive the most value from the data retrieval and modeling processes covered in *Chapter 2, Accessing, Retrieving, and Transforming Data*, and *Chapter 3, Building a Power BI Semantic Model*, respectively. In this chapter, we develop and describe the most fundamental report visualizations and design concepts. Additionally, guidance is provided to enhance and control the user experience when interacting with Power BI reports and consuming them on both Windows and mobile devices.

In this chapter, we will cover the following recipes:

+   - Building rich and intuitive reports
+   - Filtering at different scopes
+   - Integrating card visualizations
+   - Using slicers
+   - Controlling visual interactions
+   - Utilizing graphical visualizations
+   - Creating table and matrix visuals
+   - Enhancing reports
