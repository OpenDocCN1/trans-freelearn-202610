神经网络训练中的关键问题包括梯度消失、梯度爆炸、过拟合与欠拟合等。针对这些问题，研究者提出了多种优化算法与正则化手段，如批量归一化、残差连接、Dropout 等。

# ### 1. 训练挑战与应对策略

+   - 梯度消失：使用 ReLU 激活函数、残差连接或 LSTM 结构缓解。
+   - 梯度爆炸：采用梯度裁剪、合理的权重初始化策略。
+   - 过拟合：增加数据量、使用 Dropout 与权重衰减。
+   - 欠拟合：增大模型容量、适当增加训练轮数。

# ### 2. 优化算法比较

| 算法 | 特点 | 适用场景 |
| --- | --- | --- |
| SGD | 稳定、易调参 | 小数据集 |
| Adam | 自适应学习率 | 大规模参数 |
| RMSProp | 处理非平稳目标 | RNN 训练 |

> > 好的优化器应当兼顾收敛速度与最终精度。
