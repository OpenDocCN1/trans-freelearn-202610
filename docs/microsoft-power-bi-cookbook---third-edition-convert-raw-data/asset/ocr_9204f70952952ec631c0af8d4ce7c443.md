# There’s more...

In addition to using a data science approach to analyze and make predictions about historical data, Fabric also includes the capabilities to analyze real-time data via Real-Time Analytics. Similar to Data Science within Fabric, Real-Time Analytics includes samples that provide a quick way to experiment and learn:

Real-Time Analytics within Fabric leverages the Kusto Query Language (KQL). KQL, or simply Kusto, is a query language used by Azure Data Explorer as well as Fabric. Kusto is optimized to query large datasets of structured, semi-structured, and unstructured data with analytical capabilities for pattern recognition, anomaly detection, and statistical modeling. In addition, Kusto contains features that make it ideal for querying telemetry data and logs, including geospatial features, time-series functions and operators, text and vector similarity searches, and more.
