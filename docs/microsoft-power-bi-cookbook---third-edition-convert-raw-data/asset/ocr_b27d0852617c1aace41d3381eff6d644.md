# How to leverage Dataverse and Dynamics 365

To implement this recipe, use the following steps:

+   1. Navigate to `https://make.powerapps.com` and switch to the new environment created in *Getting ready*. The current environment is located in the upper-right corner.
+   2. In the left-hand navigation, click **Connections** (you may have to click **More** first).
+   3. Create a connection to your SQL Server database as per *steps 7 and 8* of the *Integrating with Power Automate and Power Apps* recipe.
+   4. In the left-hand navigation, click **Dataflows**.
+   5. Click on the **New dataflow** button.
+   6. Provide a **Name** for your dataflow, like **Customers**, and click the **Create** button.
+   7. Choose **SQL Server database** as a data source.
+   8. Enter the connection information for your on-premises **AdventureWorksDW2022** database.
+   9. The **Connection credentials** information should automatically fill in with the connection created in *step 3*. Click the **Next** button.
+   10. Select the **DimCustomer** table and click the **Transform data** button.
