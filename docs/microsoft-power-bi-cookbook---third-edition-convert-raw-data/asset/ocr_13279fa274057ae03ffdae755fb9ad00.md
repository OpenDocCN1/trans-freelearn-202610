# Integrating with Power Automate and Power Apps

Power BI’s tools and services are predominantly read-only given their mission to derive insights from data rather than to create new data or modify existing data. While data analysis and visualization is of course an essential function, it’s only the actions that are taken based on insights that generate value. For this reason, the Power Platform includes Power Automate and Power Apps two rich and mature applications that support the automation of business processes and the development of business applications for creating and editing business data.

Power BI Desktop now includes visuals for Power Automate and Power Apps allowing report authors to easily expose capabilities from these tools directly within Power BI reports. For example, a Power BI report page could expose a Power Apps form for a user to optionally edit the values of a product. Additionally, a Power BI report could contain Power Automate visuals that empower users of the report to trigger various workflows, such as sending an email or refreshing a semantic model.

In this recipe, a Power Automate workflow is created to support a streaming semantic model in the Power BI service. Specifically, the Power Automate workflow is configured to read from an on-premises SQL Server table every five minutes and push this data into Power BI, providing near real-time visibility and support for data-driven alerts and notifications.
