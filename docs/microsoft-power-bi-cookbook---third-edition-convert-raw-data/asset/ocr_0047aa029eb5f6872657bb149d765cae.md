# How it works

The Reseller Margin % measure (step 2) includes three lines of comments to describe the business definitions of the measure’s components. Comments can also be added per line via the -- and // characters and Power BI applies green color coding to this text. Embedding comments is recommended for both complex measures with multiple components and simple measures, which form the foundation of many other measures.

It should be noted that comments in DAX measures are only visible to the developer of the semantic model. However, one can use the Description field shown in Figure 10.16 to provide a brief explanation of the measure. This description will appear as a tooltip when hovering over the measure in the Data and Visualizations panes of the Report view.
