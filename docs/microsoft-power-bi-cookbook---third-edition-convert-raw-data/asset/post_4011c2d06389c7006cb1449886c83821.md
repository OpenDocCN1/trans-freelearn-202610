## How it works

Setting data categories for columns (*steps 1 and 2*) assists in geocoding location-based data. Similarly, setting **Location type** (*step 6*) provides a geographic hint that significantly improves the accuracy of the plotted points returned by the Esri service. Note that locations can also be represented as boundaries, such as states or postal codes. Almost all the advanced report development features provided by ArcGIS are exposed in the Power BI visualization.

If latitude and longitude columns are already available for the dimension to be mapped, then these columns should be used in the ArcGIS visual instead of the **Location** field well. Providing latitude and longitude source data significantly improves performance, as it eliminates the need for Esri to compute these values.

## Building Animation and Storytelling

Business teams and analysts are commonly responsible for sharing or walking through business results, trends, and the findings from their analyses with other stakeholders, such as senior management. To support the message delivery process most effectively, Power BI provides built-in animation capabilities for the standard scatter chart and ArcGIS map visualization types. Additionally, core and custom visuals, such as the pulse chart, further aid the storytelling process by embedding user-defined annotations into the visual and providing full playback control over the animation.

This recipe includes examples to prepare the standard Scatter chart visualization for animation, leveraging the date animation feature of the ArcGIS Maps for Power BI visual. Details on the Bookmarks pane, as well as the Smart narrative and other storytelling custom visuals, are also included.

## Getting ready

To prepare for this recipe, follow these steps:

- 1. Download Building Animation and Storytelling Start.pbix from the following GitHub repository: https://github.com/PacktPublishing/Power-BI-Cookbook-Third-Edition.
- 2. Open Building Animation and Storytelling Start.pbix in Power BI Desktop.
- 3. Edit the AdventureWorks query and change the Source line to point to your SQL server with the AdventureWorksDW2022 database installed.
- 4. Click Close & Apply from the ribbon of the Home tab.
- 5. Save your work.

## How to build animation and storytelling

To implement this recipe, carry out the following steps:

- 1. In the Report view, apply a page-level filter in the Filters pane for the SalesTerritoryGroup column in the SalesTerritories table to only include the value Europe.
- 2. Create a Scatter chart visualization using the SalesTerritoryCountry column from the SalesTerritories table for Values, the CustomerKey column (Count) from the Internet Sales table for the X-axis, and the SalesAmount (Sum) for the Y-axis.
- 3. In the Format your visual tab of the Visualizations pane, expand the Markers card and then the Shape card, set the Size to 100, expand the Color card, set the Color by category toggle to On, and also toggle Category label to On.
- 4. Drag the YearMonth column into the Play Axis field well of the scatter chart visualization.

5. Click on one or more of the circles (hold down the Ctrl key to select multiple values) to display their paths and test the animation capabilities by clicking on the play button to the left of the time axis.

![](img/5e366dc9e90fe4b1ca9dd97c82976bbd_401_0.png)

Figure 9.18: Scatter chart animation and tracing

6. Add a new page and use the Filters pane to add a page filter using the CalendarYear column from the Dates table for the years 2011, 2012, and 2013.

7. In the Visualizations pane, click the ellipsis (...) and choose Get more visuals.

8. Search for, find, and add the Play Axis (Dynamic Slicer) visualization.

9. Create a Clustered column chart visualization, with the YearMonth column from the Dates table as the X-axis and the SalesAmount column (Sum) as the Y-axis.

10. Create a Clustered bar chart visualization with the SalesTerritoryCountry column from the Sales Territories table as the Y-axis, and the SalesAmount column (Sum) as the X-axis. Optionally, toggle Data labels to On using the Format your visual tab in the Visualizations pane.

11. Add the Play Axis visualization and use the YearMonth column from the Dates table as the Field.

The Play Axis visualization adds animation capabilities to visualizations that have no native animation features. The Play Axis visualization works by taking advantage of the native cross-filtering and cross-highlighting capabilities of Power BI. The Play Axis visualization is best used in combination with column charts, bar charts, and other charts that allow for the Highlight visual interaction. The use of animation in visual analytics can assist with viewer engagement and help tell a story, and it appeals to the creative element of data analytics.

## There’s more…

Bookmarks enable the saving of specific report states, including filter context and the visibility of specific items on the report canvas. This can be particularly useful with animated visuals in order to skip to the most interesting parts of the animation. The Bookmarks pane can be accessed in the ribbon of the View tab while in the Report view. Use the Add button to create bookmarks. Use the View tab to easily page through bookmarks like a slideshow.

![](img/5e366dc9e90fe4b1ca9dd97c82976bbd_403_0.png)

Figure 9.20: Bookmarks pane in Power BI Desktop

Alternatively, a Bookmark navigator can be added to a page from the Insert tab of the ribbon by selecting Buttons, Navigator, and then Bookmark navigator.

The Selection pane, also available in the ribbon of the View tab, can be used with bookmarks to set the visibility of visuals for a bookmark. Playing through bookmarks in Power BI reports resembles Microsoft PowerPoint presentations (in presentation mode) that leverage animation. Additionally, bookmarks can be linked with other objects in a report, such as images, making it possible to create an intuitive navigation experience across report pages.
