Instead of using sections, you can also create a library of M functions that you can import via a single query. For example, you can create a file such as this:

```
[ 
    AddOne = ( x as number ) => x + 1,
    NumberExp = (x as number) => Number.Exp(x)
]
```

Save this file as MLibrary.pq. You can then bring in the functions from this file using the following query:

```
Expression.Evaluate(Text.FromBinary(File.Contents("c:\data\MLibrary.pq")), #shared)
```

This query returns the following:

![](bbox=[0.38, 0.36, 0.66, 0.46])

You can right-click on the word Function and then choose Add as New Query to use the function.
