# How it works

The section keyword defines a logical container of named, grouped expressions. Expressions can be prefixed with the shared keyword in order to expose the named expression to the global environment.

Power BI Desktop looks in the [Documents]\Microsoft Power BI Desktop\Custom Connectors file when launched and loads any extensions found there stored as .pq files.

While this example recipe is simple, any kind of complex logic and transformations can be created within section documents.

# There’s more…

Third-party extensions to Power BI are also created in the same manner as described here. Each third-party connector available in Power BI is created in section documents via .pq files. These third-party connectors are then certified by Microsoft and made available within Power BI Desktop.
