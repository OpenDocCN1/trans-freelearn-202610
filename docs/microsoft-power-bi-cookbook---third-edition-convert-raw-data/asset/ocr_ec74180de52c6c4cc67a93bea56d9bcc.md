The Play Axis visualization adds animation capabilities to visualizations that have no native animation features. The Play Axis visualization works by taking advantage of the native cross-filtering and cross-highlighting capabilities of Power BI. The Play Axis visualization is best used in combination with column charts, bar charts, and other charts that allow for the Highlight visual interaction. The use of animation in visual analytics can assist with viewer engagement and help tell a story, and it appeals to the creative element of data analytics.

# There’s more…

Bookmarks enable the saving of specific report states, including filter context and the visibility of specific items on the report canvas. This can be particularly useful with animated visuals in order to skip to the most interesting parts of the animation. The Bookmarks pane can be accessed in the ribbon of the View tab while in the Report view. Use the Add button to create bookmarks. Use the View tab to easily page through bookmarks like a slideshow.

Alternatively, a Bookmark navigator can be added to a page from the Insert tab of the ribbon by selecting Buttons, Navigator, and then Bookmark navigator.

The Selection pane, also available in the ribbon of the View tab, can be used with bookmarks to set the visibility of visuals for a bookmark. Playing through bookmarks in Power BI reports resembles Microsoft PowerPoint presentations (in presentation mode) that leverage animation. Additionally, bookmarks can be linked with other objects in a report, such as images, making it possible to create an intuitive navigation experience across report pages.
