# Getting ready

To prepare for this recipe, follow these steps:

+   - Open the `Utilizing Graphical Visualizations.pbix` file and save the file as `Creating Table and Matrix Visuals.pbix`.

# How to create table and matrix visuals

To implement this recipe, use the following steps:

+   1. Select the France page.
+   2. From the **Visualizations** pane, select **Table visualization**.
+   3. Add the `Product Category` column from the Products table, the `Internet Net Sales`, `Internet Margin %`, and `Internet Customer Count` measures from the Internet Sales table, and the `Reseller Net Sales` and `Reseller Margin %` measures from the Reseller Sales table.
+   4. In the **Columns** field well, double-click the `Internet Customer Count` measure and rename it to `Internet Customers`.
+   5. In the **General** sub-pane of the **Format** pane, expand the **Properties** format card and set **Height** to 194 and **Width** to 832, then under **Position**, set **Horizontal** to 448 and **Vertical** to 525.
+   6. On the **Visual** sub-pane, expand the **Style presets** section and choose **Contrast alternating rows**.
+   7. Copy this visual to the Germany, United Kingdom, and Scratch pages.
+   8. On the Scratch page, use the dropdown for the `Reseller Margin %` measure in the **Columns** field well to apply **Conditional formatting** to **Background color**.
