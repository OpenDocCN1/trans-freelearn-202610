# How it works

Once published to the Power BI service, the service handles the appropriate creation and maintenance of the table partitions. As configured, the initial table partition will consist of the years 2013 and 2014.

Additional partitions will be added to include the last 5 years’ worth of data. This archived data is not refreshed as part of the incremental refresh. Once loaded, the data will remain as initially loaded until such time that the data is not within the archived data window. Thus, a rolling 5 years of data is included in the overall table.

As configured, each incremental refresh only refreshes the last 3 days worth of data and thus can greatly improve refresh times instead of refreshing the entire table. A new partition is added for each incremental refresh.

Setting the option to Get the latest data in real time with DirectQuery makes the table a hybrid table within the Power BI Service. When visualizations render, data is pulled from the import partitions and the data source is also queried via DirectQuery to include any new data not included in the import partitions.

# There’s more…

The scenario covered in this recipe is the only scenario currently supported natively by Power BI Desktop. However, third-party tools such as Tabular Editor 3 can allow us to configure the alternative use case where we load the most recent data into an import partition and the older data is supported via a DirectQuery partition.

To demonstrate this capability, we can create a query such as the following that imports the last 11 years of data from the AdventureWorksDW2022 database. Note that in real-world scenarios, this would likely be the last 2 or 3 years of data. The example shown here is how the partition expression appears within Tabular Editor:

```
let
    Source = Sql.Database("localhost", "AdventureWorksDW2022", [Query="SELECT *#{1f}FROM FactInternetSales#{1f}WHERE OrderDate >= DATEADD(YEAR, -11, CONVERT(DATE,GETDATE()))"])
in
    Source
```

In Tabular Editor 3, we can duplicate this partition and then modify it to be a DirectQuery partition with the following expression:

```
let
    Source = Sql.Database("localhost", "AdventureWorksDW2022", [Query="SELECT *#{1f}FROM FactInternetSales#{1f}WHERE OrderDate < DATEADD(YEAR, -11, CONVERT(DATE,GETDATE()))"])
in
    Source
```
