We use Table.SelectColumns to remove all columns except the ParentOrganizationKey, OrganizationName, FactFinance, and Index columns. Expanding the FactFinance table using the Table.ExpandTableColumn function to retrieve the Amount column increased the number of rows returned, and thus, the Table.Group function is used to aggregate the Amount column, returning the table to the original number of rows prior to expanding the FactFinance column.
