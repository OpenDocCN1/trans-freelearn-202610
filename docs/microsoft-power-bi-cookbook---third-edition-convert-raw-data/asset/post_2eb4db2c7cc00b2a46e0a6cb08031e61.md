## How to transform and cleanse data

We wish to remove duplicates from the EnglishProductName column in our Products query. To implement this recipe, use the following steps:

1. In Power Query Editor, select the Products query.
2. Remove any leading and trailing empty spaces in the EnglishProductName column with a Text.Trim function. This can be done in the user interface by right-clicking the EnglishProductName column header, choosing Transform, and then Trim.
3. Create a duplicate column of the EnglishProductName key column with the Table.DuplicateColumn function and name this new column Product Name. This can be done in the user interface by right-clicking the EnglishProductName column header and choosing Duplicate Column.
4. Add an expression to force uppercase on the EnglishProductName - Copy column via the Table.TransformColumns function. This new expression must be applied before the duplicate removal expressions are applied. This can be done in the user interface by right-clicking the EnglishProductName column header, choosing Transform, and then UPPERCASE.
5. Add an expression to the DimProduct query with the Table.Distinct function to remove duplicate rows. This can be done in the user interface by right-clicking the EnglishProductName column header and choosing Remove Duplicates.
6. Drop the capitalized EnglishProductName - Copy column via Table.RemoveColumns. This can be done in the user interface by right-clicking the EnglishProductName column header and choosing Remove.

The final query should resemble the following:

```m
let
    Source = AdventureWorksDW2022,
    dbo_DimProduct = Source{[Schema = "dbo", Item = "DimProduct"]}[Data],
    #"Removed Other Columns" = Table.SelectColumns(dbo_DimProduct,
        {"EnglishProductName"}),
    #"Trimmed Text" = Table.TransformColumns(
        #"Removed Other Columns",
        {{"EnglishProductName", Text.Trim, type text}}
    ),
    #"Duplicated Column" = Table.DuplicateColumn(
        #"Trimmed Text",
        "EnglishProductName",
        "EnglishProductName - Copy"
    ),
    #"Uppercased Text" = Table.TransformColumns(
        #"Duplicated Column",
        {{"EnglishProductName - Copy", Text.Upper, type text}}
    ),
    #"Removed Duplicates" = Table.Distinct(#"Uppercased Text",
        {"EnglishProductName - Copy"}),
    #"Removed Columns" = Table.RemoveColumns(#"Removed Duplicates",
        {"EnglishProductName - Copy"})
in
    #"Removed Columns"
```

### How it works

In the Trimmed Text expression, the Text.Trim function removes white space from the beginning and end of a column. Different amounts of empty space make those rows distinct within the query engine, but not necessarily distinct within the model. Therefore, it is always a good idea to use Text.Trim first and then remove duplicate rows and values.

In the next expression, the Table.DuplicateColumn function is used to duplicate the column where we will remove duplicate values. This is done because we will need to transform the values in the column we are removing duplicates from, in order to account for mixed cases such as “Fender Set” and “Fender set”. Thus, we wish to preserve the original values and casing by using this duplicate column.

In order to eliminate mixed casing issues, the next expression changes all values in the duplicate column to uppercase, using the Table.TransformColumns function and specifying Text.Upper. The M engine considers mixed casing values unique, but the data model engine does not.

The next expression eliminates rows in our duplicated column that have duplicate values. This can be done for an entire table or by looking at a specific column only.

At this point, the query is now resilient to duplicate values and rows, mixed cases, and spaces. We can now simply drop the duplicated column using the Table.RemoveColumns function.

We can now form a one-to-many relationship between our DimProduct and FactResellerSales tables.

### There's more...

To support troubleshooting, create a query that accesses the same source table and retrieves the values from the EnglishProductName column with more than one row.

```m
let
    Source = AdventureWorksDW2022,
    dbo_DimProduct = Source{[Schema="dbo",Item="DimProduct"]}[Data],
    RemoveColumns = Table.SelectColumns(dbo_DimProduct,{"EnglishProductName"}),
    TrimText =
        Table.TransformColumns(
            RemoveColumns,{"EnglishProductName",Text.Trim}
        ),
    UpperCase =
        Table.TransformColumns(
            TrimText,{{"EnglishProductName", Text.Upper}}
        ),
    GroupedRows =
        Table.Group(
            UpperCase, {"EnglishProductName"},
            {{"Rows", each Table.RowCount(_), Int64.Type}}
        ),
    Duplicates = Table.SelectRows(GroupedRows, each [Rows] > 1)
in
    Duplicates
```

The EnglishProductName column is selected, trimmed, converted to uppercase, grouped, and then filtered to always retrieve any duplicate key values. Disable the loading of this query, as the query would only exist for troubleshooting purposes.

## Creating Custom Columns

Business users often extend the outputs of existing reports and data models with additional columns to help them analyze and present data. The logic of these columns is generally implemented through Excel formulas or as calculated DAX columns. A superior solution, particularly if the logic cannot be migrated to a data warehouse or IT resource, is to create the columns via Power Query Editor and the M language.

Developing custom columns can also significantly enhance the ease of use and analytical power of data models and the visualizations they support. In this recipe, columns are created to apply a custom naming format and simplify the analysis of a customer dimension via existing columns.

### Getting ready

To get ready for this recipe, import the DimCustomer table from the AdventureWorksDW2022 database by doing the following:

1. Open Power BI Desktop and choose **Transform data** from the ribbon of the **Home** tab to open **Power Query Editor**.
2. Create an **Import** mode data source query called AdventureWorksDW2022. This query should be similar to the following:

```m
let
    Source = Sql.Database("localhost", "AdventureWorksDW2022")
in
    Source
```

3. Isolate this query in a query group called **Data Sources** and disable the loading of the query.
4. Right-click the AdventureWorksDW2022 query and choose **Reference**, select the DimCustomer table in the data preview area, and rename this query Customers.

For additional details on performing these steps, see the *Importing Data* recipe in this chapter.

### How to create custom columns

To implement this recipe, perform the following steps:

1. Add variables to the Customers query that allow the expression to support the comparison between the current system date and the BirthDate column. Then copy the following code into the Customers query, replacing all existing content.

```m
let
    Source = AdventureWorksDW2022,
    dbo_DimCustomer = Source{[Schema="dbo",Item="DimCustomer"]}[Data],
    CurrentDate = DateTime.Date(DateTime.LocalNow()),
    CurrentYear = Date.Year(CurrentDate),
    CurrentMonth = Date.Month(CurrentDate),
    CurrentDay = Date.Day(CurrentDate)
in
    dbo_DimCustomer
```

2. Use `Table.SelectColumns` to retrieve the required source columns from the Customers table: `FirstName`, `LastName`, `MiddleName`, `Title`, and `BirthDate`. This can be done in the user interface by holding down the *Ctrl* key, selecting the column headers for those columns, right-clicking one of the selected column headers, and choosing **Remove Other Columns**.

3. Write a `Table.AddColumn` function with an `if...then` expression that accounts for the different scenarios, given a target format of `Mr. John A. Doe`:

```m
NameFormatTable =
    Table.AddColumn(
        #"Removed Other Columns","Formatted Name", each
            if [Title] = null and [MiddleName] = null
                then [FirstName] & " " & [LastName]
            else if [Title] = null
                then [FirstName] & " " & Text.Range([MiddleName],0,1)
                    & ". " & [LastName]
            else
                [Title] & " " & [FirstName] & " "
                    & Text.Range([MiddleName],0,1) & ". " & [LastName]
    )
```

4. Use the `Table.AddColumn` function to create `Customer Year`, `Customer Month`, and `Customer Day` columns based upon the `BirthDate` column.

```m
AddCustomerYear =
    Table.AddColumn(
        NameFormatTable, "Customer Year", each Date.Year([BirthDate]),
        Int64.Type
```
