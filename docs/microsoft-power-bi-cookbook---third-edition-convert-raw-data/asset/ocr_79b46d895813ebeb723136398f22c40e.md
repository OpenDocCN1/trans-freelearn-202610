# Getting ready

To prepare for this recipe, follow these steps:

+   1. Open Power BI Desktop.
+   2. Click Transform data from the Home tab of the ribbon.
+   3. In Power Query Editor, click Manage parameters from the Home tab of the ribbon.
+   4. Create a RangeStart parameter with a Type of Date/Time and a Current Value of 1/1/2013 12:00:00 AM.
+   5. Create a RangeEnd parameter with a Type of Date/Time and a Current Value of 12/31/2014 12:59:59 PM.

+   6. Create a DirectQuery mode query called Dates that loads the DimDate table from your AdventureWorksDW2022 database.
+   7. Create an Import mode query called Internet Sales that loads the FactInternetSales table from your AdventureWorksDW2022 database.
