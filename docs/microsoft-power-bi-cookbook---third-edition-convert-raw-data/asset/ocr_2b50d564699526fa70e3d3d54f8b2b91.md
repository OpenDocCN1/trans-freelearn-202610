# Getting ready

To prepare for this recipe, follow these steps:

+   1. Open Power BI Desktop.
+   2. Create an Import mode data source query called AdventureWorks. This query should be similar to the following:
+   3. Isolate this query in a query group called Data Sources and disable loading.
+   4. Right-click the AdventureWorks query and choose Reference.
+   5. Select the FactInternetSales table and name this query Internet Sales.
+   6. Repeat steps 5 and 6 for the DimDate table and name this query Order Dates.
+   7. Separate the fact query, Internet Sales, into a Facts query group. Refer to the Implementing a Semantic Model recipe in Chapter 3, Building a Power BI Semantic Model.
+   8. Separate the dimension query, Order Dates, into a Dimensions query group. Again, refer to the Implementing a Semantic Model recipe in Chapter 3, Building a Power BI Semantic Model.
+   9. Create a Blank Query called Calculations in the Other Queries group.
+   10. Choose Close & Apply in the ribbon of the Home tab to load the tables to the semantic model.
+   11. Create a relationship using the FullDateAlternateKey column from the Order Dates table and the OrderDate column of the Internet Sales table.

# How to simplify date intelligence

To implement this recipe, perform the following steps:

+   1. From Report view, click on New table in the ribbon of the Modeling view tab.
+   2. In the formula bar, assign a name to the date dimension table, such as Shipment Dates, and use the SELECTCOLUMNS function to retrieve date columns from the existing date dimension table:
+   3. Create a relationship between the Shipment Date column in the Shipment Dates table and the ShipDate table in the Internet Sales table.
+   4. Rename the FullDateAlternateKey column in the Order Dates table to Order Date.

```
Shipment Dates =
    SELECTCOLUMNS('OrderDates',
        "Shipment Date", 'OrderDates'[FullDateAlternateKey],
        "Shipment Year", 'OrderDates'[CalendarYear],
        "Shipment Month", 'OrderDates'[EnglishMonthName],
        "Last Refreshed", NOW()
    )
```
