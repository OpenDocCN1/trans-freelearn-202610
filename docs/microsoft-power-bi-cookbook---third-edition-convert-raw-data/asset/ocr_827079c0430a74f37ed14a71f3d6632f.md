Those with historical knowledge of online analytical processing systems can likely identify parallels between import, DirectQuery, and Direct Lake storage modes. **Relational Online Analytical Processing (ROLAP)** systems are analogous to DirectQuery, where the data remains at rest within the relational database system without the need for pre-aggregated cubes. Similarly, import mode is analogous to **Multidimensional Online Analytical Processing (MOLAP)** systems where data is aggregated into multidimensional cubes.

Direct Lake completes the analogy, essentially being equivalent to **Hybrid Online Analytical Processing (HOLAP)** systems that mix both ROLAP and MOLAP service modes. With HOLAP, data requests are processed via MOLAP until the specific demands of the query force the engine to service the query via ROLAP. Direct Lake is similarly structured in that the Fabric engine first attempts to service the query via the processed Parquet files but fails over to DirectQuery for queries that cannot be serviced from the analytical store created via the Fabric engine.
