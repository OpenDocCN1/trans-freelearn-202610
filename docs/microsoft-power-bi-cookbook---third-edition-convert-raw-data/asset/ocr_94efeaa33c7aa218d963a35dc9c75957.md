# Working in the Power BI Service

While the bulk of Power BI development activities occur in desktop applications, predominantly Power BI Desktop, there are certain artifacts such as dashboards and dataflows that are exclusively created within the Power BI web service. Creating, managing, and integrating these items within the Power BI service serves to deliver robust solutions that address a variety of business needs ranging from holistic dashboards of KPIs to corporate scorecards to scalable data integration dataflows.

In this chapter, Power BI dashboards are constructed to provide intuitive, at-a-glance monitoring of critical measures and high-impact business activities. The unique features of dashboards, such as Q&A natural language queries and data alerts, are also explored. Finally, the creation of additional content objects, such as streaming semantic models, scorecards, dataflows, and shared cloud connections, are also included.

In this chapter, we will cover the following recipes:

+   - Building a dashboard
+   - Preparing for Q&A
+   - Adding alerts and subscriptions
+   - Streaming semantic models
+   - Authoring dataflows
+   - Creating scorecards

# Technical Requirements

The following are required to complete the recipes in this chapter:

+   - Power BI Desktop and a Power BI service account (Pro or PPU).
+   - Power Automate and OneDrive.
+   - SQL Server 2022 or newer with the AdventureWorksDW2022 database installed. See the *Installing SQL Server and the AdventureWorks Database* recipe from *Chapter 1, Installing and Licensing Power BI Tools*.
