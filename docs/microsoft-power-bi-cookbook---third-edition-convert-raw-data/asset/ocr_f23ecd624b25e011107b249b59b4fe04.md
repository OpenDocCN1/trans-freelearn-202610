Dedicated capacities, such as Premium (now Fabric), support additional dataflow functionality, such as the following:

+   - Enhanced compute engine, enabling dataflows to leverage DirectQuery as well as performance improvements
+   - Refresh linked tables from other dataflows
+   - AutoML and Cognitive Services

Once created, dataflows can be used in Power BI Desktop as data sources. To see how this works, do the following:

+   1. Open a new Power BI Desktop file.
+   2. Select Get data from the ribbon of the Home tab and choose Dataflows.
+   3. Under the Dataflows folder, expand workspaces, expand the workspace where the Products dataflow was created, expand the Products dataflow, choose the DimProduct table, and click the Load button.

The DimProduct table has now been added to the semantic model.

# There’s more...

Similar to how dataflows are shareable data transformation queries, the Power BI service also supports the concept of shared cloud data sources.

In Power BI Desktop, the first step in creating a data transformation query is to create a data connection to a source system. This connection along with its credentials is cached to the local computer. However, opening the PBIX file on a different computer requires that the credentials be re-entered.

Instead, one can create the equivalent connection object in the Power BI service and then assign that connection to one or more semantic models. This has a number of advantages, including:

+   - Centralized management of gateway and cloud connections.
+   - If credentials change, there is a single location to update.
+   - The ability to share connections with other users without having to re-enter credentials. You can even specify that the users can reshare the connection with other users.
+   - Multiple shared connections can be created to the same data source, allowing different connection settings for different semantic models.

To create a shared cloud connection, perform the following steps:

+   1. In the Power BI service, click on the gear icon in the upper-right corner and then Manage connections and gateways.
+   2. In the upper-left corner, click New.
