# Getting ready

To prepare for this recipe, we will first build a query through the user interface that connects to the AdventureWorksDW2022 SQL Server database. This query will be used as a reference query for additional queries we will create later in the recipe. To create this query, follow these steps:

+   1. Open Power BI Desktop and create a new report.
+   
+   2. Click on **Get Data** from the **Home** tab of the ribbon. Select **SQL Server** from the list of database sources. For future reference, if the data source is not listed in **Common data sources**, more data sources are available by clicking **More...** at the bottom of the list.
+   
+   3. A dialog will appear, asking for connectivity information. Ensure that **Data Connectivity mode** is set to **Import**. Enter the name of your SQL server as well as the AdventureWorksDW2022 database. In *Figure 2.1*, the SQL server is installed locally and runs under the default instance of MSSQLSERVER. Since it is the default instance, only the computer name hosting the SQL instance or localhost, a reference to the current computer is used. If the **Database** field is left blank, this will simply result in an extra navigation step to select the desired database.

![](bbox=[0.204, 0.385, 0.901, 0.656])

*Figure 2.1: SQL Server Get Data dialog*

+   4. If this is your first time connecting to this database from Power BI, you may be prompted for some credentials. In addition, you may also be warned that an encrypted connection cannot be made to the server. Simply enter the correct credentials to connect and click the **Connect** button. For the encryption warning, simply click the **OK** button to continue.
+   
+   5. A navigation window will appear, with the different objects and schemas of the database. You can check the box next to any table or view but for this example, check the box next to the **DimGeography** table, and then click the **Transform Data** button.
