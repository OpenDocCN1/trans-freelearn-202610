+   2. Ensure that you have a data gateway running that is compatible with Power Automate. See *Chapter 1, Configuring Power BI Tools*, for installation instructions.

In this recipe, an on-premises data gateway is used to support a Power BI streaming semantic model from an on-premises SQL Server database table via Power Automate. Per the previous chapters, the same gateway that supports Power BI refresh processes and live connections or DirectQuery models can also be used for Power Apps and Power Automate. Depending on the workloads generated by these different activities and applications, and based on gateway resource monitoring, it may be necessary to isolate Power Apps and Power Automate to a dedicated on-premises gateway or, in the future, add a server to a high-availability gateway cluster.
