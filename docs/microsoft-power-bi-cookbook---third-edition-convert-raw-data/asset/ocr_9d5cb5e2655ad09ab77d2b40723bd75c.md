# Working with Templates

Power BI templates can be created from Power BI Desktop files as a means of providing users and other report authors with access to pre-defined metadata, such as M queries, DAX measures, model relationships, and report visualizations. As the template files do not contain actual data, they are very lightweight and, for import mode models, data is only retrieved when the template is opened. Additionally, if query parameters have been configured, a user interface is provided for entering parameter values, and these parameters can be integrated with the source queries and other components of the semantic model.

In this recipe, a parameter and supporting query are added to a Power BI Desktop file to support the distribution of a Power BI template.

# Getting ready

To prepare for this recipe, follow these steps:

+   1. Download Working with Templates Start.pbix from the following GitHub repository: https://github.com/PacktPublishing/Power-BI-Cookbook-Third-Edition.
+   2. Open Working with Templates Start.pbix in Power BI Desktop.
+   3. Choose Transform data from the ribbon of the Home tab to open Power Query Editor.
+   4. Edit the AdventureWorks query to point to your copy of the AdventureWorksDW2022 database.

# How to work with templates

In this example, the goal is to provide a Power BI template that only retrieves data for a single customer country. To implement this recipe, perform the following steps:

+   1. In the Queries pane, right-click the Parameters query group and choose New Parameter.
+   2. Create a parameter called Customer Country with Text as the type, and for Suggested Values, choose Query, choose the CustomerCountries query, and set United States as the Current Value.
+   3. In the Other Queries group, create a new query called CustomerKeys that references the Customer Country parameter using the following code and then disable the load on this query:

```
let
    CountryParamFilter = Table.SelectRows(Customers, each [Country] = #"Customer Country"),
    CustomerKeys = Table.SelectColumns(CountryParamFilter, {"CustomerKey"})
in
    CustomerKeys
```
