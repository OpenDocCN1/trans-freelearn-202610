6. Right-click the FactResellerSales query in the Queries pane within Power Query Editor and choose Duplicate. Revise the Navigation step to reference an additional table supporting the model, such as the DimReseller table. This can be done by editing Item in the formula bar, or by clicking on the gear icon next to the Navigation step under APPLIED STEPS in the Query Settings pane. Also, rename this query to reflect the data being referenced, such as Resellers.
