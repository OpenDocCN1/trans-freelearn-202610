+   - `pivotValues` is a list of values of the column that rotates as column headers.
+   - `attributeColumn` is the column that the function aggregates the values upon.
+   - `aggregationFunction` is one of the available aggregation functions, including Count (all), Count (not blank), Minimum, Maximum, Median, Sum, Average, and Don't aggregate.
