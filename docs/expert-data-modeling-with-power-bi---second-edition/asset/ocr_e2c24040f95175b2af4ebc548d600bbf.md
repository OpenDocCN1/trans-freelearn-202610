# Assigning members to roles in Power BI Report Server

The following steps show how to assign members to a role in Power BI Report Server after publishing a report to the server:

+   1. Open a web browser and navigate to Power BI Report Server.
+   2. Click the ellipsis button of the desired report from the Browse tab.
+   3. Click Manage.

The preceding steps are highlighted in the following image:

+   4. Click Row-level security.
+   5. Click the Add Member button.
+   6. Type in a username or group name.
+   7. Select roles to assign to the user.
+   8. Click OK.
