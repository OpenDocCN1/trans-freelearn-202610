# OLS implementation flow

OLS implementation flow in Power BI is very similar to RLS. The following steps explain the OLS implementation flow:

+   1. Creating security roles in Power BI Desktop.
+   2. Securing the objects in third-party tools such as Tabular Editor or SSMS.
+   3. Saving the changes to the Power BI Desktop model.
+   4. Validating roles in Power BI Desktop.
+   5. Publishing the model to the Power BI Service or Power BI Report Server.
+   6. Assigning members to roles within the Power BI Service or Power BI Report Server.
+   7. Validating roles in the Power BI Service (role validation is unavailable in Power BI Report Server).

> Note
> 
> The OLS restrictions apply to the members assigned to the role.
