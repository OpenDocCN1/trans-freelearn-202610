Filtering a column by the values of a column from another table is simple. We only need to know how to reference a column from another table. To reference a column from another table, we need to have the query name followed by the column name in brackets, as shown in the following expression:

```
#"Query_Name"[Column_Name]
```

The result of the preceding structure is a **list** value. In our scenario, the **Approved Product Subcategories** column from the **Approved Subcategories** table filters the **Product Subcategory** column from the **Product** table. So, we use the `List.Contains(list, values)` function to get the matching values with the following structure:

```
```powerquery
List.Contains(#"Referenced_Table"[Referenced_Column], [Column_to_be_Filtered])
```
```

So, the `List.Contains()` function in our scenario looks like the following expression:

```
```powerquery
List.Contains(#"Approved Subcategories"[Approved Product Subcategories], [Product Subcategory])
```
```
