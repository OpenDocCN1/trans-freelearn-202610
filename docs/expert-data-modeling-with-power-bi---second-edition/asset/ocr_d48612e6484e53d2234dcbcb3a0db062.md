When OLS kicks in, the visuals referencing a secure object break. From a user-friendliness perspective, this is pretty bad. But there are ways to make the visuals user-friendly and, at the same time, have a secure model. One way is to create completely separate thin reports connected live to the same dataset for the users whom OLS must apply to them and for the others. The other way is to have separate report pages for users whom OLS applies and the others. That way, we are required to hide all report pages and use buttons with Page Navigation, and control who can access which report page. As this is a data visualization topic, we leave it to you to investigate the ideas. So far, we implemented multiple RLS and OLS scenarios.
