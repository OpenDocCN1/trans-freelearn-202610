As mentioned earlier, one of the differences between Dataflows and Datamarts is that Dataflows load data into ADLS Gen2, while Datamarts load data into an Azure SQL DB. So far, we have created the data transformation layer using Power Query Online, and the data is loaded into an Azure SQL DB. The other thing that automatically happens in the background is that a new dataset is created in the Workspace, which brings us to the next step—to build the data model.
