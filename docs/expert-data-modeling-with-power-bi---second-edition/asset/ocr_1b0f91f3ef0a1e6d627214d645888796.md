# Query Settings pane

This pane, located on the right side of the Power Query Editor window, contains all query properties and all transformation steps applied to the selected query (from the Queries pane). The Query Settings pane disappears if the selected query is a query parameter.

The Query Settings pane has two parts: PROPERTIES and APPLIED STEPS, as illustrated in the following image:
