The following DAX expression activates the relationship between `DueDateKey` and `DateKey` relationship:

```
Internet Sales Due =
    CALCULATE([Internet Sales]
        , USERELATIONSHIP('Internet Sales'[DueDateKey],
'Date'[DateKey])
    )
```

The following DAX expression activates the relationship between `ShipDateKey` and `DateKey`:

```
Internet Sales Shipped =
    CALCULATE([Internet Sales]
        , USERELATIONSHIP('Internet Sales'[ShipDateKey],
'Date'[DateKey])
    )
```
