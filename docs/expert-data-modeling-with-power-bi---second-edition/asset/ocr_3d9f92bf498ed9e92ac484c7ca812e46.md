# Load the data into the Datamart

Log into your Power BI Service and navigate to the desired Workspace. Remember that it must be a Premium Workspace. Follow these steps:

+   1. Click the **New** dropdown button and click the **Datamart (Preview)** from the menu.

+   2. Enter a name for the Datamart and click the **Create** button.

+   3. Click the **Get Data** button.

Click the SQL Server database or Azure SQL database, depending on where you restored the AdventureWroksDW2019 database.

+   4. Enter the Server and Database names. If you use an op-premises SQL database, you must have installed and configured the on-premises Data Gateway and select the gateway here. Read more about the On-premises Data Gateway using this URL: https://learn.microsoft.com/en-us/power-bi/connect-data/service-gateway-onprem?WT.mc_id=DP-MVP-5003466.

+   5. Click **Next**.
