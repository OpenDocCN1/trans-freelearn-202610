# Duplicating and referencing queries

Duplicating and referencing queries are somehow similar. We duplicate a query when we need to have all the transformation steps we already took on the original query. At the same time, we want to change those steps or add more transformation steps. In that case, we must change the original query’s nature, translating it so that it has a different meaning from a business point
