# Figure 5.10: Date and OrderDateTime do not match

As you can see, there is only one match between the two columns. Now that we have identified the issue, the only step we need to take is to convert the OrderDateTime column’s data type from DateTime to Date:

+   1. Open Power Query Editor and select the Internet Sales table from the Queries pane.
+   2. Right-click the OrderDateTime column.
+   3. Click Date from the context menu under the Change Type submenu.
+   4. Click the Replace current button
+   5. Click Close & Apply to apply the changes to the data model:
