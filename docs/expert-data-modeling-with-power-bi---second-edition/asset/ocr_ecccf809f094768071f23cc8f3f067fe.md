**FactInternetSales** in DirectQuery mode, so the **DimProduct** table must also be in DirectQuery mode. But the **DimProduct** table also has a relationship with the **Sales_Agg** table, and the **Sales_Agg** table’s storage is in **Import** mode. Therefore, the only way to avoid limited relationships in the preceding use case is to set the **DimProduct** storage mode to **Dual** mode.
