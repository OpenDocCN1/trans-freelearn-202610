One way of solving the issue is to return BLANK() for the invalid dates. The following calculation shows the Internet Sales MTD Blankin g Invalid Dates measure, which returns null if there is no transaction for a particular date:

```
Internet Sales MTD Blankin g Invalid Dates =
VAR lastorderDate = MAX('Internet Sales'[OrderDateKey])
RETURN
IF(
    MAX('Date'[DateKey]) <= lastorderDate
    , TOTALMTD(
        [Internet Sales]
        , 'Date'[Full Date]
    )
)
```
