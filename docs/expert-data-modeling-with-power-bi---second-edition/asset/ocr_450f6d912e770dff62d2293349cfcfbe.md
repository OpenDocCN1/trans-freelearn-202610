# Data type conversion

Data type conversion is one of the most common steps in Power Query, yet it is one of the most important ones that can become tricky if not managed well. One cool feature of Power BI, if enabled, is to detect data types automatically. While this is a handy feature in many cases, it can be the root cause of some issues down the road. The critical point to note is how Power BI automatically detects data types.
