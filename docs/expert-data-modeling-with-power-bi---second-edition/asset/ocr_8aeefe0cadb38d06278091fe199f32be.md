# No-code experience with the Visual query

Imagine a case where a business analyst who has access to an existing datamart needs to analyze the data further. For instance, imagine a case where a business analyst unfamiliar with T-SQL wants to analyze the products sold in our previous scenario. The following steps explain the process:

+   1. Click the Query view.
+   2. Click the New query dropdown button.
+   3. Click the New visual query option.
+   4. Drag and drop the DimProduct table onto the Visual query canvas.
+   5. Drag and drop the FactInternetSalesLive table onto the canvas.
