# Internet Sales LYTD

The calendar hierarchy holds the following levels:

+   - Year
+   - Month
+   - Full Date

> Note
> 
> The relationship between **Internet Sales** and the **Date** table is created between **OrderDateKey** from **Internet Sales** and **DateKey** from the **Date** table. Both **OrderDateKey** and **DateKey** are in the `Number` data type (integer).

The DAX expressions for the preceding measures are as follows:

Use the following DAX expressions to calculate `Internet Sales MTD`:

```
Internet Sales MTD =
TOTALMTD(
    [Internet Sales]
    , 'Date'[Full Date]
)
```

Use the following DAX expressions to calculate `Internet Sales YTD`:

```
Internet Sales YTD =
TOTALYTD(
    [Internet Sales]
    , 'Date'[Full Date])
```
