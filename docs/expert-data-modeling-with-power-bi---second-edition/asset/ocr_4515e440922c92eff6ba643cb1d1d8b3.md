As you see, the variance values start to make sense only after **28/01/2011**. It is trivial to understand the reason. There were no sales in the past 28 days, so we have to cut off those values. One of the first solutions that may come to mind is eliminating null values for **Internet Sales LM**. The measure looks as follows:

```
Internet Sales MoM Variance Incorrect =
IF(
    NOT(ISBLANK([Internet Sales LM]))
    , [Internet Sales] - [Internet Sales LM]
)
```

In the preceding calculation, we say that if **Internet Sales LM** is not blank, get the variance; otherwise, show blank.
