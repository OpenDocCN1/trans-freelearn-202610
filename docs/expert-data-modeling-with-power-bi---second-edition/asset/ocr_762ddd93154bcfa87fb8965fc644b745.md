# **Creating roles and defining rules**: Follow these steps to create roles and to define rules:

+   1. Click the **Manage roles** button from the **Modeling** tab on the ribbon.
+   2. Click **Create**.
+   3. Type in **AUD Sales Only** as the role name.
+   4. Click the ellipsis button of the **Currency** table.
+   5. Hover over **Add filter....**
+   6. Click **[CurrencyAlternateKey]**.
