Let’s see what SCD 2 means when it comes to data modeling in Power BI. The first question is: Can we implement SCD 2 directly in Power BI Desktop without having a data warehouse? To answer this question, we have to remember that the data model in Power BI is a semantic layer. The semantic layer, by definition, is a view of the source data (usually a data warehouse), optimized for reporting and analytical purposes.
