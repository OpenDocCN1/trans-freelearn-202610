As we see, limited relationships make RLS work slightly differently in composite models with DirectQuery for Power BI datasets than the regular models. That aside, we understand that the RSL applied to different dataset chains always flows downstream, which means that the RLS in the chain 1 dataset filters the data in the chain 2 dataset. This affects how we implement further reports on the datasets from a permission perspective. For instance, think about a situation where we want to enable the contributors to create reports with a composite model dataset structure with DirectQuery for a Power BI dataset. We will discuss this in the next section.
