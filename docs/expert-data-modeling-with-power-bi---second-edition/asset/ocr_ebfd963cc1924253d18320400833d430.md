A business decided to dynamically use predefined color codes in various visuals so that the visuals’ colors are picked depending on the value of the `Sales MoM%` measure. The `Sales MoM%` measure calculates the percentage of sales changes, based on the sales values for each year in comparison with the sales values for the previous year. The goal is to visualize `Sales MoM%` in a **Clustered column chart**. The color for each data point should be calculated based on a config table. The following diagram shows the structure of the config table:
