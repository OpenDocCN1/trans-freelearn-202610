# Summarizing the Internet Sales table

To summarize the **Internet Sales** table at the **Date** level, we must use the **Group by** functionality in Power Query Editor. We want to aggregate the following columns while using a **SUM** or **COUNT** aggregation operation:

+   - **Order Quantity**: SUM
+   - **Sales**: SUM
+   - **Tax**: SUM
+   - **Freight Costs**: SUM
+   - **Internet Sales Count**: COUNT

These need to be grouped by the following key columns:

+   - **OrderDateKey**
+   - **DueDateKey**
+   - **ShipDateKey**
