> > `USERPRINCIPALNAME()`: Returns the user’s UPN at connection time. The UPN is in email format.

Implementing RLS in Power BI only makes sense when we publish the model to the service or Power BI Report Server; therefore, using the `USERPRINCIPALNAME()` function is preferred.

> **Note**
> 
> If we embed Power BI reports into a proprietary application and have to use the user login name, we should use the `USERNAME()` function.
