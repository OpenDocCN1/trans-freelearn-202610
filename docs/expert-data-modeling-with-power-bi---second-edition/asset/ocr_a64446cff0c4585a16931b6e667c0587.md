+   2. Now we need to create a `Sales MoM%` measure. The following DAX expression calculates sales for the last month (`Sales LM`):

```
Sales LM =
    CALCULATE([Internet Sales]
        , DATEADD('Date'[Full Date], -1, MONTH)
    )
```

+   3. After we have calculated `Sales LM`, we just need to calculate the percentage of differences between the **Internet Sales** measures and the `Sales LM` measure. The following expression caters to that:

```
Sales MoM% = DIVIDE([Internet Sales] - [Sales LM], [Sales LM])
```
