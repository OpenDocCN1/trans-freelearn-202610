So far, so good.

The other point to note is that we created a virtual table inside a measure. When we put the Product Category, Product Subcategory, and Product columns into the matrix visual, they show the correct values for the Avg. Product Standard Costs Correct measure. We did not physically create any relationships between Internet Sales and the virtual table created by the SUMMARIZE() function. How come we get the correct results?

The lineage between the derived virtual table and the original physical table is the answer. The virtual table inherits the relationship with the Internet Sales table from the Product table. In other words, the virtual table has a one-to-one virtual relationship with the Product table through ProductKey. Hence, when we put the Product Category, Product Subcategory, and Product columns into the matrix visual, the filters propagate to the Product table and the Internet Sales table.
