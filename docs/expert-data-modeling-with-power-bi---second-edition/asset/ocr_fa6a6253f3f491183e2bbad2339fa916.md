The preceding function accepts text values and works as follows:

+   - Whenever a case transition from lowercase to uppercase happens, it splits the text value into a list of texts.
+   - It combines the split text putting a space between the split parts.

To understand how the preceding custom function works, we need to read the documentation of the `Splitter.SplitTextByCharacterTransition()` function on the Microsoft Docs website: https://docs.microsoft.com/en-us/powerquery-m/splitter-splittextbycharactertransition?WT.mc_id=DP-MVP-5003466

Note that the `Splitter.SplitTextByCharacterTransition()` function returns a function, therefore the `Splitter.SplitTextByCharacterTransition({"a".."z"}, {"A".."Z"})(ColumnName)` part of the preceding expression applies the `SplitTextByCharacterTransition` function to the function’s input parameter, which is `ColumnName`, resulting in a list of texts.
