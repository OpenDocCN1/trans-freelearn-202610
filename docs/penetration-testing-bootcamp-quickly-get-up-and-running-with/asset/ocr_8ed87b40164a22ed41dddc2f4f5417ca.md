# WinDump

WinDump is the tcpdump of Windows. I consider it a necessity for any Microsoft environment. With WinDump, you can analyze your packets right on your Windows machine, using similar filters and syntax as you are familiar with on the open source side with tcpdump. You can even run a capture to a file in WinDump and read it via tcpdump. This utility can be handy if you need to capture traffic on a Windows box directly.

When running WinDump, you need to make sure WinPcap is installed. If you don’t have WinPcap, it is available from WinDump ( http://www.windump.com ).
