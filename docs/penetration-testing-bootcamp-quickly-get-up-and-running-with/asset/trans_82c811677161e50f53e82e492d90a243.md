## 错误处理问题

使用 OWASP ZAP，你还可以检查 Web 应用程序中的错误处理问题。你希望能够让用户了解问题可能是什么，但不要披露太多信息。例如，如果有人尝试登录网站，而密码错误，你不想告诉用户密码不正确，因为这会让对方知道用户名是正确的，只是密码不对。你处理这种情况的方式就是只说登录凭据不正确。
