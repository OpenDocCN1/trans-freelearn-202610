## Session management

确保在使用 Web 应用程序时他人无法劫持你的会话非常重要。否则，他们不仅能够看到你在做什么，还能用你的信息购买商品。Web 应用程序必须具备防范会话劫持的安全措施。会话可以有各种类型。例如，它们可以使用 cookie，或在 URL 中，甚至使用隐藏字段。无论会话类型如何，它们都应唯一属于某个用户，并且不能被其他用户窃取或查看。

使用以下一些工具，我将测试一些 Web 应用程序是否存在会话劫持问题。
