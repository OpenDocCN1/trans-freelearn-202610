## 关于作者

**杰森·贝尔特拉梅** 是 Cisco 的系统工程师，居住在宾夕法尼亚州东部地区。他在网络和安全领域工作了 18 年，其中最近 2 年担任系统工程师，此前 16 年在运营方面担任网络工程师。在此期间，杰森获得了以下认证：CISSP、CCNP、CCNP Security、CCDP、CCSP、CISA、ITILv2 和 VCP5。他毕业于 DeSales University，获得计算机科学学士学位。他对安全充满热情，热爱学习。

在他在 Cisco 的当前职位中，杰森专注于安全和企业网络，但作为一名通才 SE，他涵盖技术的所有方面。杰森与商业区域客户合作，帮助他们根据各自的业务需求实现技术目标。他 16 年的实际工作经验使他能够与客户产生共鸣，了解他们的挑战和期望成果。

## 关于审阅者

**库比莱·奥努尔·贡戈尔** 在网络安全领域工作超过 8 年。他职业生涯的起点是使用混沌 logistic 映射对加密图像进行密码分析。在 Netsparker 项目中担任 QA 测试员后，他继续在渗透测试领域发展职业生涯。他对许多大型客户的 IT 基础设施执行了多次渗透测试和咨询，例如银行、政府机构和电信公司。

在他的渗透测试活动之后，他担任了 Sony Europe 和 Global Sony Electronics 的 Web 应用程序安全专家以及事件管理和响应专家。

库比莱相信网络安全需要跨学科的方法，并将其定义为一场斗争。通过这种方法，他开发了自己独特的认证和培训计划，包括渗透测试-恶意软件分析、事件管理和响应、网络恐怖主义、犯罪侧写、非常规方法、认知管理和国际关系。目前，该认证计划在伊斯坦布尔以 cyberstruggle.org 形式运行。除安全证书外，他还持有外交政策、品牌管理、极端环境生存、国际网络冲突、反恐认证委员会、恐怖主义和反恐比较研究证书。
