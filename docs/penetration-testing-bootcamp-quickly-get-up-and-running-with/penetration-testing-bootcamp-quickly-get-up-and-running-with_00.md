## 前言

渗透测试正随着当今现代环境中安全威胁的不断增多，成为任何个人工具箱中必备的重要技能组合。当前的问题是，许多人根本不知道如何开始学习为其组织正确运行渗透测试的方法。本书的重点是帮助个人了解渗透测试流程以及渗透测试的不同方面。使用运行 Kali Linux 的 Raspberry Pi 以及各种工作站和服务器，我们将通过开源工具进行各种测试场景，不仅告诉你如何使用这些工具，还展示如何解读结果。这样，随着你阅读本书，你可以将所学知识每天应用于正在进行的任何渗透测试项目中。

## 本书涵盖内容

第 1 章《规划与准备》通过使用现实世界的示例来介绍渗透测试流程所需准备的内容。这使你能够通过讨论目标以及获得管理层的认可来建立渗透测试的基础。

第 2 章《信息收集》向读者展示如何开始收集有关环境的信息以及需要获取的信息类型。侦察是一个非常重要的步骤，可能决定渗透测试的成败。

第 3 章《设置和维护命令与控制服务器》介绍如何建立与 C&C 服务器的连接，该服务器可以帮助你进行情报收集和异地处理。

第 4 章《漏洞扫描与 Metasploit》重点关注扫描环境中的漏洞，然后利用这些信息尝试利用发现的目标。

第 5 章《流量嗅探与欺骗》介绍如何嗅探网络，然后利用这些信息运行各种攻击，如中间人攻击和欺骗攻击，以获得有关网络上发生情况的更多洞察和情报。

第 6 章《基于密码的攻击》展示了运行各种基于密码的攻击、获取凭据以及利用这些信息进行未来渗透测试攻击的过程。

第 7 章《对网络基础设施的攻击》将基础设施作为渗透测试的一部分进行审视。我们将探索工具，在坏人之前找到基础设施中的各种漏洞。

第 8 章《Web 应用攻击》探讨了如何在渗透测试中探测和利用 Web 应用。

第 9 章《清理并撤离》重点关注渗透测试完成后清理遗留痕迹的重要性。

第 10 章《撰写渗透测试报告》是本书的最终总结，不仅展示了渗透测试报告的重要性，还展示了如何格式化报告并用测试期间获得的数据填充。

## 阅读本书所需

要能够利用本书中的概念和示例，强烈建议配备运行 Kali Linux 的 Raspberry Pi 3。还建议配备额外的工 作站/笔记本电脑，以帮助不仅进行测试，还处理一些硬件要求更高的工具。Kali Linux 是首选操作系统，以及本书中讨论的其他实用程序/工具。所有这些都是开源的，意味着可以免费下载和使用。如果您只是想了解渗透测试流程，本书涵盖的硬件和软件并非必需。

## 本书适合人群

本书专为任何想了解渗透测试如何工作的人设计。本书的布局允许读者逐章跟随所学内容，并将其应用于实际的渗透测试。本书主题的优点在于，尽管本书是通过将所学知识应用于实践来编写的，但并非必须以这种方式使用本书。只需阅读本书即可让你从头到尾了解渗透测试流程。具备网络和 Linux 的先验知识会有所帮助；然而，并不是理解本书所涵盖概念的必要条件。此外，具备基础层面的安全和渗透测试的先验理解绝对有优势，但由于书中示例众多，因此并非必需。
