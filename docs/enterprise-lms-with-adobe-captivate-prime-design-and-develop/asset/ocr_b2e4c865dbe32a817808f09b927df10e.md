To access the Catalog page, use one of the following two ways:

+   - You can click the Catalog icon, which is the third icon from the top in the left sidebar.
+   - If you are on the learner home page, you can also use the Go To Catalog link located in the Recommended based on your areas of interest section.

At first glance, the Catalog page looks very similar to the My Learning page discussed in the previous section. Indeed, the tools available on the Catalog page are mostly the same as those available on the My Learning page:

+   - There are checkboxes on the left-hand side allowing you to filter the list of visible learning objects.
+   - In the upper-right corner of the list, the Sort By dropdown allows you to sort the items visible on the page. Notice that, by default, the sort order is set to Recently Published, which displays the latest addition to the catalog at the top of the list.

The primary difference between the My Learning page and the Catalog page is that the Catalog page lists all the courses, learning programs, certifications, and job aids available in the catalog, while the My Learning page only lists the learning object the learner is enrolled in. Another way to explain this is to say that My Learning is the list of Must-take trainings because the learner is already enrolled in the trainings listed on that page, while the Catalog page is a list of Could-take trainings since it offers a menu to self-enroll.

From the Catalog page, learners can get information about the learning objects they have access to. They can also enroll in courses or send an approval request to their manager depending on the enrollment option of the course.

**Working with multiple catalogs**
You currently have a single catalog in your Prime account. Therefore, all learning objects are in the same catalog, which is accessible to all learners.
In Chapter 14, Working with Catalogs and Peer Accounts, you will learn how to create additional catalogs, how to place learning objects in them, and how to define which learners have access to a given catalog. This will allow you to control which learning objects each learner has access to.
