On this page, you can modify the default values that will be applied to all future course instances of the chosen course.

+   6. Toggle **L1 Reaction Feedback** on.
+   7. Type `Do you have any other comments or suggestions about this course?` in the **Question 1** field.
+   8. Scroll down the page and also toggle **L3 Behavior Change Feedback** on.

The other feedback-related options are exactly the same as those discussed in the *Enabling L1 and L3 feedback for a course instance* section earlier in this chapter.

+   9. Take some time to examine the other available options. Notice that you can also enable or disable badges by default.

+   10. When ready, click the **Save** button located in the upper-right corner of the screen.

From now on, any new course instance you create for this particular course will inherit the default values you just defined.

This is very useful to make sure that each course instance follows a basic set of rules and best practices. It also streamlines the creation of new course instances, making the job of administrators a little easier. Keep in mind that these are only default values. It means you can override these defaults for each new instance you create. In other words, Prime does not strictly enforce these settings when creating new instances. Also, the different values you just defined only apply to *future* course instances; existing course instances are not affected by these changes.
