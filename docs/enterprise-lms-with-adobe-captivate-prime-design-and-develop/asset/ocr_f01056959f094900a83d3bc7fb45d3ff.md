This is just the general workflow. There are some interesting nuances and variations available, which you can review by performing the following steps:

+   1. From the default **Learning Programs** page of the Administrator or Author experience, hover your mouse over the lower area of the card for the learning program you created earlier in this chapter.
+   2. Click **View Learning Program** from the list of available options. This will open the **Overview** page of the chosen learning program.
+   3. Click the **Instances** link located in the **Manage** section of the left sidebar.

Just like with courses, **Captivate Prime** has created a **Default instance** for your learning program:

![](bbox=[0.12, 0.35, 0.86, 0.57])

Figure 6.13 – Captivate Prime has created a Default instance for your learning program

In this example, since the courses that are part of the learning program contain only self-paced modules, this default instance is probably all you need for your learning program to provide the expected learning experience. But this may not always be the case, so let’s inspect the available options.

+   4. Click the **Courses** property of the default learning program instance (identified by the arrow in the preceding screenshot) to open the **List of Courses** section included in the learning program.

From here, you can decide to go one of two ways:

+   - You can choose a specific course instance for each of the courses included in the learning program using the drop-down list available next to each course. Using this option, learners enrolling in this instance of the learning program are automatically enrolled in the chosen instances of each course. In other words, you can map each learning program instance to the desired course instances.
