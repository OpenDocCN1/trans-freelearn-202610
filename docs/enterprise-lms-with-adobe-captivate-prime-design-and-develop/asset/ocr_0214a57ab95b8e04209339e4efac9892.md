# Editing scores and comments

Sometimes attending a class is enough, but other times, attending a class requires participating in discussions, formulating an opinion, presenting on a topic, and so on. In such cases, instructors can evaluate each learner's participation in the course and add comments about it in the LMS. Let's review this workflow hands-on using the following steps:

+   1. Make sure you are logged in as an instructor to your Captivate Prime account.
+   2. From the instructor home page, click the session you want to mark attendance for, to open the Session Overview page. Keep in mind that if the session has already been delivered, you click the Past Sessions link in the left sidebar to access the desired session.
+   3. Click the Learners link in the left sidebar.
+   4. Next, click the Actions button located in the upper-right corner of the screen.
+   5. Click the Edit Scores & Comments action to switch the page to score editing mode.
