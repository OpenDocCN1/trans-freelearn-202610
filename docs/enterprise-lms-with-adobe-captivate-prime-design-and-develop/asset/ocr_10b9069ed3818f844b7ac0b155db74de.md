If this sounds a little technical to you, remember that the Captivate Prime API is intended for developers. As a Captivate Prime administrator or integration admin, you don’t need to fully understand the details of how developers implement the Captivate Prime API in the programming language they use to build these custom solutions.

The only thing you should be aware of is that the Captivate Prime API uses a security framework named **OAuth 2.0** to authenticate and authorize external applications. This security framework requires that you generate security tokens for each of the external applications that need access to your Captivate Prime account via the API.

> **OAuth**
> 
> **OAuth** stands for **Open Authorization**. If it is an open industry standard used to grant websites and other applications secure access to each other. More information on the OAuth standard can be found on the official OAuth website at `https://oauth.net/`. I strongly suggest you watch the video available on their home page for a quick but thorough explanation of what OAuth is.

To experiment with this workflow, let's say you want to use Captivate Prime as a headless LMS, so you need to develop a custom website/app that will serve as the learner experience for your users. This custom website/app will be hosted by you and will access the necessary Captivate Prime data through the API. Therefore, you need to register this application with your Prime account and generate the necessary security tokens by following these steps:

+   1. Log in to your Prime account as an integration admin.
+   2. From the integration admin home page, click the **Applications** link located in the left sidebar.
+   3. Click the **Register** button located in the upper-right corner of the page to open the **Register a new application** page.
+   4. Type an application name in the **Application Name** field. This is nothing technical, so feel free to choose any name you deem appropriate. Note that this name cannot be changed afterward.
+   5. Provide the URL where your custom application will be hosted in the **URL** field.
+      For the purpose of this exercise, just type the URL of your website or any other valid URL.
+   6. Type `https://*. <the_address-Of_your_website>` in the **Redirect Domains** field.
