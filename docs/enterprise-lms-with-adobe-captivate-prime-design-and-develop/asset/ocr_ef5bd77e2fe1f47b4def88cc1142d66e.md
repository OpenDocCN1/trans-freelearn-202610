As a reminder, a learning program is a set of related courses. When learners enroll in a learning program, they actually enroll in all the courses included in the learning program. Creating learning programs has been discussed in *Chapter 6, Enrolling Users to Courses.*

Let's review the options pertaining to L1 and L3 feedback for learning programs using the following steps:

+   1. Log in to your Prime account as an administrator.
+   2. From the administrator home page, click the **Learning Programs** link located in the **Learning** section of the left sidebar. This takes you to the list of available learning programs in your Prime account.
+   3. Hover over any learning program available on the list.
+   
+   If you have performed the exercises of *Chapter 6, Enrolling Users to Courses*, choose the **Mastering Photo Editing** learning program. Remember that this particular learning program consists of two courses: one course on Adobe Photoshop and another one on Adobe Lightroom.
+   4. Click the **View Learning Program** link to open the learning program overview page.
+   5. Next, click the **Instances** link located in the **Manage** section of the left sidebar.

Just like courses, learning programs also have instances. A default instance is automatically created each time you define a new learning program. Most of the time, this default instance is all you need, but there are situations where it is useful to define additional learning program instances. This has already been discussed in *Chapter 6, Enrolling Users to Courses.*

+   6. Click the **Feedback Enabled** link of the default learning program instance to open the L1 and L3 feedback options.
