There is, however, one option specific to learning programs that requires further discussion. It relates to how learning program instances and course instances work together to create flexible learning programs. This is the subject of the next section.

## Creating Flexible Learning Programs

As discussed in the Creating course instances section, earlier in this chapter, learners do not enroll in courses but course instances. The same is true with learning programs. You can define instances for your learning programs, which is especially useful when one or more of the courses included in the learning program contains synchronous modules.

In this section, you will examine how course instances and learning program instances work together to give learners a smooth learning experience. The general workflow is as follows:

- Create several courses with multiple instances.
- Create a learning program and add some courses to it.
- Create instances of the learning program and map learning program instances to course instances.
- Enroll learners in the desired learning program instance.

This is just the general workflow. There are some interesting nuances and variations available, which you can review by performing the following steps:

- 1. From the default **Learning Programs** page of the Administrator or Author experience, hover your mouse over the lower area of the card for the learning program you created earlier in this chapter.
- 2. Click **View Learning Program** from the list of available options. This will open the **Overview** page of the chosen learning program.
- 3. Click the **Instances** link located in the **Manage** section of the left sidebar.

Just like with courses, **Captivate Prime** has created a **Default instance** for your learning program:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_250_0.png)

Figure 6.13 – Captivate Prime has created a Default instance for your learning program

In this example, since the courses that are part of the learning program contain only self-paced modules, this default instance is probably all you need for your learning program to provide the expected learning experience. But this may not always be the case, so let’s inspect the available options.

- 4. Click the **Courses** property of the default learning program instance (identified by the arrow in the preceding screenshot) to open the **List of Courses** section included in the learning program.

From here, you can decide to go one of two ways:

- You can choose a specific course instance for each of the courses included in the learning program using the drop-down list available next to each course. Using this option, learners enrolling in this instance of the learning program are automatically enrolled in the chosen instances of each course. In other words, you can map each learning program instance to the desired course instances.
- You can also click the **Enable Learners to Choose instances (Flexible Learning Program)** button, which allows learners to choose the course instance they wish to attend for each of the courses included in the learning program. In such a case, the drop-down lists mentioned in the previous bullet points disappear from the screen.

In this example, these options are not relevant since the learning program you created in this chapter only contains courses with self-paced modules that do not have multiple course instances defined.

After reading this section, you should have a pretty good understanding of learning programs and the different options available in Captivate Prime for creating and maintaining them. Therefore, it is time to move on to the next section, where you will learn about certifications.

## Creating Certifications

**Certifications** are similar to learning programs, which we discussed in the previous section, in that they also allow you to enroll learners in a series of courses rather than a single course (although certifications may contain only one course). But certifications add a few more things to the mix: a *Days to complete* option and the possibility of creating *recurring* certifications with automatic learner re-enrollment.

The process of creating a certification is very similar to the process of creating a learning program and is a task that both administrators and authors can accomplish. Let's examine it hands-on by creating the *Certified Prime Learner* certification:

- 1. From the administrator or author home page, click the **Certifications** link located in the **Learning** section of the left sidebar.

This takes you to the **Certifications** page, where a list of **Published** certifications, if any, will be displayed. By default, no certifications should be defined in a new Prime account.

- 2. Click the **Add** button located in the top-right corner of the screen.
- 3. Type `Certified Prime Learner` in the **Certification Name** field.
- 4. Type `30` in the **Days to complete** field located further down the page. This means that learners who enroll for this certification have 30 days to complete it. If the certification is not completed within this timeframe, the learner shall *not* be certified.

Note that, at this point, the **Certification Name** and **Days to complete** fields are the only two required fields.

- 5. As a best practice, take the necessary time to type in a **Description** and **Certification Overview** in the corresponding fields.

You can also supply a **Cover Image** and a **Banner Image** to make the certification stand out in the course catalog.

Sample files are provided in the `/certification` folder of the download associated with this book.

- 6. Scroll down the page until you see the **Type** field.

Here, you can choose between a **Recurring** or a **Perpetual** certification. A **Recurring** certification expires after a certain **Validity** period, requiring learners to constantly recertify to maintain their status. A **Perpetual** certification, on the other hand, is granted once and for all and never expires. You can use a **Perpetual** certification to certify people in a specific version of a software application, for example.

- 7. For this example, choose a **Perpetual** certification.

Note that this action hides the **Reassignment** and **Validity** fields.

- 8. A little below, notice the **Certification Issuer** field.

The default value of the **Certification Issuer** field is **Internal**. This means that this certification is entirely organized by your organization and is only recognized internally. **External** certifications are organized by third-party providers and may be recognized by a large number of organizations across a variety of industries. When choosing **External**, the **Certification Completion Date** option appears. This allows you to define how the completion of the certification is reported to Captivate Prime. This can be a formal approval by a manager or administrator or a direct submission by the learner at the end of the certification.

Note that **Certification Issuer** cannot be changed after the certification is published.

- 9. Take a quick look at the other available options. They should be self-explanatory for the most part.
- 10. When ready, click the **Save** button located in the top-right corner of the screen.

This concludes the first step in creating a certification. This action creates the new certification in the *draft* status. When the page reloads, you should see additional links in the left column and be redirected to the **Courses** page for the new certification.

- 11. Make sure you are on the **Courses** page of the new certification. If not, click the **Courses** link in the **Manage** section of the left sidebar. From here, you will decide on the courses that should be included in this certification.
