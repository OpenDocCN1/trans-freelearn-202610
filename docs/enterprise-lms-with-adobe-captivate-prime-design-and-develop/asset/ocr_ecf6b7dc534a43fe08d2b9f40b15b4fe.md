# Setting a completion criteria

As an instructor, it may be tempting to always set the completion criteria to 100% to make sure that the whole content is reviewed by every learner. In practice, though, this may not always be a good idea. In the case of a Word document, for example, the learner can read the whole document without actually scrolling to the very end (especially if the document is very short). In such a case, the module will not be reported as completed by Captivate Prime, even though the learner has reviewed 100% of the relevant information contained in the file. To circumvent this issue, some authors set completion criteria around 90%, though in my opinion, the completion criteria for a static text-centric document can be left to the default value of On Launching Content.
