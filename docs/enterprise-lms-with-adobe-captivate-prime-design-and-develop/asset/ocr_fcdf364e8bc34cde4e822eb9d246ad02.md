# Creating custom dashboards

The custom reports you have created so far in this chapter have been added to the default dashboard, which is available out of the box in every Captivate Prime account. This default dashboard is unique to your user account. It means that other administrators have their own default dashboard where they can define their custom reports. In other words, the custom reports you have defined so far are only visible to you.

Sometimes, this default dashboard is all you need, but there are lots of circumstances where additional custom dashboards are very useful:

+   - Custom dashboards allow you to group your custom reports so you can better organize them, which helps you analyze the data and make sense out of it.
+   - Custom dashboards can be shared with other managers. Thanks to this feature, administrators can define reports that can be used by the manager of the organization. This allows you to give busy managers access to meaningful data without having to create their custom reports themselves. It also helps you standardize the reports used by various members of the organization. This, of course, does not prevent managers from adding their own custom reports and dashboards on top of those shared by other users.

You will now create a custom dashboard that you will share with all the managers in the organization using the following steps:

+   1. Make sure you are logged in to your Prime account as an administrator.
+   2. From the administrator home page, click the **Reports** link located in the **Manage** section of the left sidebar.
+   3. Then, click the **Custom Reports** link in the left sidebar and go to the **Dashboard Reports** tab.
+   4. Click the **Add Dashboard** link located to the right of the **View Dashboard** drop-down menu to open the **Add Dashboard** dialog.
+   5. Type `All Managers dashboard` in the Name field.
+      As a best practice, also add a short description in the **Description** field.
+   6. Type `All Managers` in the Share With field and select this user group when it becomes available in the list.
