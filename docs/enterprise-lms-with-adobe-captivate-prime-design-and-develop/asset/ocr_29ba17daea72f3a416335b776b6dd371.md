+   - Many professions (Accounting, HR, Project Managers, and so on) require ongoing training, and you want to define the series of courses that make up this ongoing certification program.

The preceding examples are just a few of the many situations where such course bundling is relevant. That is why Captivate Prime offers many features to address this type of use case. This is what you will review in this section.

# Creating Learning Programs

Let's start with the simplest of these features: the **Learning Program**. In Captivate Prime, a learning program is a simple collection of courses. You can use it to group a set of related courses or create a longer curriculum in which each course is considered a chapter.

> **Learning programs versus learning plans**
> The learning programs discussed in this section should not be confused with another concept used in Captivate Prime, namely learning plans. Learning plans allow the system to automatically enroll learners when an event occurs. This feature will be discussed in more detail in the *Automatic enrollment using learning plans* section, later in this chapter.

To illustrate this feature, you will use some of the courses that are automatically available with your Prime trial account to create a learning program dedicated to photo editing using Adobe Lightroom and Adobe Photoshop. Creating learning programs can be done by both Administrators and Authors. Let's create a new learning program by performing the following steps:

+   1. From the administrator home page, click the **Learning Programs** link located in the **Learning** category of the left sidebar.
+   
+   This takes you to the **Learning Programs** page of the administrator application, where you can see a list of the currently available **Learning Programs**, if any.

+   2. Click the **Add** button located in the top-right corner of the **Learning Programs** page.

+   3. Type `Mastering Photo Editing` in the **Learning Program Name** field. Note that, at this point, this is the only required field of the form.

+   4. As a best practice, also enter a **Learning Program Overview** and **Benefits of this Learning Program** in the corresponding fields.
+   
+   Some sample text for these two fields is provided in the `masteringPhoto/masteringPhoto_desc.pdf` file of the download associated with this book.
