# The Time spent to learn per user report

The second custom report you will create is the **Time spent to learn per user** report. Unlike the default **Learning Time Spent Report** of the **User Activity** dashboard discussed earlier, this custom report will allow you to compare the learning time spent per user. This will help you identify the most active users and compare the user activity per profile, content, manager, and so on. It will help you determine whether there is too much skipping/advancing in the Fluidic Player as well.

Because you may have hundreds or even thousands of users on your Prime account, the ability to filter this report is paramount. That is why the report you will create now will only take internal users into account. Let's get started by following these steps:

+   1. Make sure you are on the **Custom Reports** page of the **Reports** section of the administrator application.
+   2. Go to the **Dashboard Reports** tab and click the **Add** button located in the upper-right corner of the screen to open the **Add Report** dialog.
+   3. Open the **Type** drop-down menu and select the **Learning Time Spent per Course** report.
+   4. In the **Name** field, change the name of the report to `Learning Time Spent per Internal User.`
+   5. Open the **For (X-axis)** dropdown and select the **User** option.
+   6. Open the **Filters** section at the end of the **Add Report** dialog.
+   7. Click the **User Group** tab.
+   8. Add the **All Internal Users** group to do list using the **Type Here** field. Remember that the **All Internal Users** group is one of the automatically generated groups maintained by Adobe Captivate Prime. This section is illustrated in the following screenshot.
