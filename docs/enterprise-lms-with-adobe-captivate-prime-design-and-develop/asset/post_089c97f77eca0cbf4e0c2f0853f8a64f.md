
## Registered Users Report

Date Range: Last 12 months | Export

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_365_0.png)

### Figure 10.2 – The Registered Users Report

This report tracks the number of registered users in your account on a weekly basis. This is an important report for administrators. Remember that Captivate Prime is priced based on the number of registered users. So, this report allows administrators to keep an eye on the evolution of the cost of Captivate Prime over time.

In the preceding screenshot, notice that the number of registered users suddenly drops at the end of the month of April. This is because the external registration profile created in Chapter 5, Managing Users, was disabled on May 1 of that year, so the seats used by that external profile were released on that date and the users registered through this external registration profile lost their access to Captivate Prime.

For organizations using the Monthly Active Users (MAU) licensing model, this report shows the count of active learners on a monthly basis.

### Captivate Prime licensing models

There are two main pricing models available for Adobe Captivate Prime: the Registered User pricing model and the Monthly Active Users pricing model. These two models were discussed in the Getting Captivate Prime section of Chapter 1, Introduction to Adobe Captivate Prime.

Note that it is possible to export this data to a **Comma-Separated Value (CSV)** file using the following steps:

- 1. Make sure you are on the **User Activity** page of the administrator application.
- 2. Click the **Export** button located in the upper-right corner of the **Registered Users Report** (see the arrow in the preceding screenshot).
- 3. Take some time to read the message in the **Generating Report Request** dialog before clicking the **OK** button.
- The report will be available sometime later in the notification area.
- 4. When the report is available, click the notification icon (the bell icon in the upper-right corner of the screen) to download the report. The downloaded `.csv` file can be opened with any spreadsheet application.

The **Registered Users Report** is only the first report available on the **User Activity** page. Use the following steps to explore the next available report.

- 5. Scroll down the **User Activity** page until you see the **User Visits Report.**

The **User Visits Report** shows the number of learners who have accessed the platform in a given period of time. Note that each login is considered an access, even if the logged-in user does not consume any content and just browses the system.

By default, the report is configured to show data for all users in your account over the last 30 days, but you can change this by using the drop-down lists available above the report.

- 6. Open the **Date Range** drop-down list.
- 7. Choose any available date range. The report is immediately updated for the chosen date range.
- Note that if you choose a different value than **Last 30 Days**, the report displays the data on a month-to-month basis. When choosing **Last 30 Days** for **Date Range**, the data is displayed on a day-to-day basis.
- 8. Open the **Date Range** dropdown and return to the default value of **Last 30 Days.**

You can also filter the report by *User Groups*. Remember that Captivate Prime automatically creates a large number of user groups based, for example, on each user's manager. Custom groups are also possible. All this was discussed in *Chapter 5, Managing Users*. Note that you must first configure the user groups you want to use to filter the report using the following steps:

- 9. Click the **Configure** link located above **User Visits Report.**
- 10. Take some time to read the message that is displayed in the Configure User Group Filters dialog.

When done, type the name of the user group in the User Group field.
Click the desired group when it appears in the list. Repeat this action with up to 10 user groups.

The ability to filter this report by user group is very useful to compare how various groups of users use the platform. In the following screenshot, I have configured the report to see the data pertaining to my own team.

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_367_0.png)

Note that Captivate Prime only records data for configured user groups. This means that if the user group configuration changes, Captivate Prime can only display data for the newly configured group from the date the group was added to the drop-down list.

Finally, note that the report distinguishes between visits made from the Captivate Prime mobile app and visits made from other sources. Other sources are desktop and laptop computers as well as headless access made through the Captivate Prime API from external applications.

Scrolling down the User Activity page, there is one last report available. Let's explore it now!

- 11. Scroll down the User Activity page until you see Learning Time Spent Report.

This report shows the total learning time spent on the platform in blue and the median time spent by individual learners in green. This is a good indication of learner engagement: the more time learners spend learning on the platform, the more engaged they are.

Captivate Prime calculates time spent learning based on the amount of time users spend actually taking courses on the platform. In other words, time spent browsing the course catalog is not included in this report.

Note that the **User Group** and **Date Range** dropdowns discussed earlier also apply to this report. Also notice the **Export** button available in the upper-right corner of the report, which allows you to export this data as a CSV file.

This concludes our overview of the **User Activity** report page, where three basic reports are available to Prime administrators. In the next section, we will continue exploring the reports available by default in Captivate Prime by visiting the **Training Content** page.

## Reviewing the Training Content dashboard

The second dashboard available in the left column of the **Reports** section is the **Training Content** dashboard. Just like the **User Activity** dashboard discussed in the previous section, the **Training Content** dashboard is also available out of the box on every Prime account. It contains two reports that give you insights into training available on your Prime account. You can view popular trainings, track all available trainings, review the number of the trainings offered, and so on. These reports allow you to answer questions such as the following:

- How many trainings are available on the Prime account and how does that number evolve? You can then decide whether this matches the organization’s ambitions in terms of course offerings, and determine whether an increase in the number of courses available translates into more time spent learning on the platform, and so on.
- What are the courses that are most successful in terms of enrollment, views, and completion? This allows you to verify that the courses promoted by the organization are effectively being taken by learners. You can also use this information to determine what makes these courses so successful and use that data to improve the other courses hosted on your Prime account, among other things.

Let’s now explore this dashboard hands-on using the following steps:

- 1. Log into your Prime account as an administrator.
- 2. From the administrator home page, click the **Reports** link located in the **Manage** section of the left sidebar.
- 3. Next, click the **Training Content** link in the left sidebar to open the **Training Content** dashboard.

The first report available on the Training Content dashboard is the Trainings Report illustrated in the following screenshot.

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_369_0.png)

### Figure 10.4 – The Trainings Report

This report shows the evolution of the number of trainings available on your platform in the last 12 months on a month-to-month basis.

Note that this particular graph has two vertical axes (also called y axes). The vertical axis on the left is used for the Total trainings available and generates the blue line of the graph. The vertical axis on the right is used for the Trainings newly added and generates the green line of the graph. It is possible that these two axes do not use the same scale. For example, in the preceding screenshot, the total trainings axis on the left goes from 0 to 16, while the newly added axis on the right goes from 0 to 14, which explains why the two lines do not reach the same height. The idea behind this report is to allow administrators and managers to see the behavior of learners from the standpoint of new training versus old training, and what's being consumed. Perhaps new content is more popular?

Also note the Export button in the upper-right corner of the graph, which allows you to generate a CSV file of the represented data.

- 4. Scroll down the Training Content dashboard until you see the Active Trainings Report.
