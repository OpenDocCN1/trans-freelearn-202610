# Creating internal users

You will start by reviewing the mechanisms that allow you to create internal users. To do so, you need to be logged in as an Administrator and perform the following steps:

+   1. From the Administrator home page, click the Add Users link located in the top section of the main content area. You can also click the Users link located in the Manage section of the left sidebar.

This takes you to the Internal Users page, as shown in the following screenshot:

![](bbox=[0.13, 0.29, 0.86, 0.62])

Figure 5.1 – This action takes you to the Internal Users page of the admin application

At this point, if you are using a Prime trial account, the only internal user available should be you!

+   2. Click the Add button located in the top-right corner of the screen.

+   3. Take some time to inspect the available options.
