## Importing users from a CSV file

You will now create two additional users: Learner 02 and Instructor 01. But instead of creating these two users one by one using the Single User option described in the previous section, you will create these two users by importing a CSV file containing the required information. Of course, in real life, you will use the CSV import to create a lot more than two users at a time, so for the sake of this demonstration, let's assume that the CSV file contains several hundred users.

> CSV
> CSV stands for comma-separated value. A CSV file is a text file containing data items separated from each other by a comma. This type of file can be edited by any spreadsheet application, such as Microsoft Excel, Open Office Calc, Apple Numbers, and so on. When reading the file, the spreadsheet software moves to the next column each time it encounters a comma and to the next line each time it encounters a line break. A very wide range of applications support exporting and importing data in CSV format, which makes CSV one of the preferred ways to exchange information between almost any system.

You will now inspect the CSV file provided in the download associated with this book using any spreadsheet application available on your system. Follow these steps:

- 1. Double-click the users/internalUsers.csv file of the download associated with this book to open the file in the default spreadsheet application installed on your system.

- 2. Take some time to inspect the content of the file. You should find four rows and six columns, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_179_0.png)

Figure 5.6 – The internalUsers.csv file, as seen in Microsoft Excel

- 3. Type your full name (as it appears in your existing user profile in Captivate Prime) in cell A2 and your Prime administrator email address in Cell B2. *This is a very important step!* More on that in a short while after the import is finished.

- 4. Type the email address you created for *Learner 02* in cell B3 and the email address you created for *Instructor 01* in cell B4.

- 5. When done, save the CSV file and close the spreadsheet application. The CSV file is now ready to be imported into Captivate Prime.

- 6. Return to the **Internal Users** page of the admin application of your Prime account.

- 7. Click the **Add** button located in the top-right corner of the screen.

- 8. In the menu that opens, click the **Upload a CSV** option. This opens the **Upload a CSV** window.

- 9. Drag and drop the `internalUsers.csv` file into the **Upload a CSV** window.

- 10. Now, you need to map the columns of the CSV file to the fields of the **Add User** form using the drop-down lists that appear on the screen.

Map the **Name** field with the **Employee name** column of the CSV file, the **E-mail** field with the **Employee email** column, and the **Profile** field with the **Job Title** column. Leave the **Manager's ID** field empty for now.

Before moving on, notice that the **Employee ID**, **Department**, and **Location** columns are not mapped to any fields. This does not mean that these extra columns have no influence, though, as you will discover in the *Customizing the user form* section, later in this chapter.

> **Troubleshooting column mapping**
> If column mapping doesn't work as expected, make sure that the separator used in the CSV file is a comma (,). Depending on the regional settings of your system, the separator could have been switched to a semicolon (;) instead. To fix this issue, open the CSV file in a text editor (such as Notepad on Windows or TextEdit on Mac) and use the **Find and Replace** feature of the text editor to replace all the semicolon (;) characters with commas (,).

- 11. When ready, click the **Save** button located in the lower-right corner of the **Upload a CSV** window.

- 12. A message should inform you that the CSV upload was successful and that the CSV file is currently being processed by Captivate Prime. Take some time to read this message. Then, click the **Close** button to go back to the **Internal Users** page.

After a short while, you should see two additional users in the Internal Users list. Note that these two users are currently unregistered, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_181_0.png)

Figure 5.7 – Instructor 01 and Learner 02 are currently marked as unregistered users

There is one more important thing to observe regarding these two new users.

- 13. Click on one of the two Unregistered users. This opens the details of the user you clicked on.
- 14. Notice that you are defined as the user's Manager.

When you import users using a CSV file, a manager is always defined for the users you import. If you do not provide this information in a dedicated column of the CSV file, the value of the Manager field is automatically set to one of the platform administrators. For this to be possible, it is necessary that the chosen administrator be part of the CSV file and that they are defined before the users to be created. This is the reason why you had to add yourself in the first row of the CSV file.

Instructor 01 and Learner 02 are now part of the Internal Users list, but they are not properly registered to the platform yet. You will register these two users in the next section.

## Registering imported users

In the previous section, you created Instructor 01 and Learner 02 using a CSV import. These users have been properly imported into the Internal Users list, but they are currently marked as Unregistered users.

**Unregistered** users have not received the welcome email containing the instructions on how to access your Captivate Prime account yet. Register these users by performing the following steps:

- 1. Make sure you are logged in as an Administrator and that you are on the **Internal Users** page.
- 2. Use the checkboxes in the first column to select the two **Unregistered** users. If you have a large number of **Unregistered** users to select, you can use the **Users** filter located above the list of users.
- 3. Click the **Actions** link located in the top-right corner of the screen.
- 4. Select the **Register** option in the menu that opens, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_182_0.png)

Figure 5.8 – Clicking the Register action

- 5. Click **Yes** to confirm.

At the end of this process, you should see the **Users Registered Successfully** message, which indicates that the welcome email has been sent to both *Instructor 01* and *Learner 02*.

- 6. Click the **Close** button to clear the **Users Registered Successfully** message.
