This interactivity layer makes it possible to differentiate the *completion criteria* from the *success criteria*. The completion criteria determines when this course module can be considered *complete* for a particular learner, whereas the success criteria determines if the learner has *passed* or *failed* this particular course module.

Normally, these criteria are set by the module author within the authoring tool when creating the SCORM package. Captivate Prime only reads this data from the uploaded .zip file. You can, however, modify these criteria within Prime.

+   8. Click the **Edit** button located in the top-right corner of the page.
+   9. Modify the completion criteria and/or the success criteria as you require.
+   10. Click the **Save** button in the top-right corner of the page to confirm the changes and go back to the Content Library.

You should now have one more module available in your Content Library. Note that, in this section, you uploaded a SCORM 2004-compliant package, but the process is the same when uploading a SCORM 1.2 package, an AICC package, or an xAPI-compliant package.

# Uploading interactive content from Adobe Captivate

Captivate Prime supports interactive content created by *any* authoring tool, provided that the authoring tool is capable of generating either an AICC-, a SCORM-, or an xAPI-compliant package. Adobe Captivate is one such authoring tool, but there are plenty of other excellent applications available, such as Articulate Storyline, TechSmith Camtasia, iSpring, and others.
