# Additional Active Fields options

Just because a form pops up when users log in doesn't mean they will enter information into the form. How should Captivate Prime react when users don't take the time to fill out all the extra fields or skip the form altogether? That's what you'll examine in this section by performing the following steps:

+   1. Return to the Administrator application of your Prime account.
+   2. From the Administrator home page, click the **Users** link located in the **Manage** section of the left sidebar.
+   3. Then, click the **Active Fields** link in the **Advanced** section of the left sidebar.
+   4. Finally, switch to the **Settings** tab, as shown in the following screenshot:

![](bbox=[0.2, 0.423, 0.77, 0.655])

Figure 5.19 – Switching to the Settings tab of the Active Fields page

+   5. Scroll down the page until you see the **User Display** section.
+   6. Select the **Show only unfilled fields on Learner Login** checkbox.
+   7. Scroll back up the page and click the **Save** button located in the top-right corner.

With this configuration, Captivate Prime displays the **Complete your profile** form each time the user logs in until all the additional fields have been completed.
