## The Time spent to learn per user report

The second custom report you will create is the **Time spent to learn per user** report. Unlike the default **Learning Time Spent Report** of the **User Activity** dashboard discussed earlier, this custom report will allow you to compare the learning time spent per user. This will help you identify the most active users and compare the user activity per profile, content, manager, and so on. It will help you determine whether there is too much skipping/advancing in the Fluidic Player as well.

Because you may have hundreds or even thousands of users on your Prime account, the ability to filter this report is paramount. That is why the report you will create now will only take internal users into account. Let's get started by following these steps:

- 1. Make sure you are on the **Custom Reports** page of the **Reports** section of the administrator application.
- 2. Go to the **Dashboard Reports** tab and click the **Add** button located in the upper-right corner of the screen to open the **Add Report** dialog.
- 3. Open the **Type** drop-down menu and select the **Learning Time Spent per Course** report.
- 4. In the **Name** field, change the name of the report to `Learning Time Spent per Internal User.`
- 5. Open the **For (X-axis)** dropdown and select the **User** option.
- 6. Open the **Filters** section at the end of the **Add Report** dialog.
- 7. Click the **User Group** tab.
- 8. Add the **All Internal Users** group to do list using the **Type Here** field. Remember that the **All Internal Users** group is one of the automatically generated groups maintained by Adobe Captivate Prime. This section is illustrated in the following screenshot.

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_387_0.png)

Figure 10.15 – Adding filters to a custom report

Note that you can add multiple user groups to the filter as well as any combination of **Manager**, **Profile**, **User Group**, and **Content**. This allows a very large number of variations for this report.

- 9. Click the **Save** button located in the bottom-right corner of the **Add Report** dialog to add the reports to the default dashboard.

Thanks to the preceding steps, you have created an additional custom report that has been added to the default dashboard. Notice that you can use the same *date range* and *manager* filters discussed earlier to adjust the data displayed by the report. Remember that you may have thousands of users on your Prime account, so these filters are very handy in displaying just the data you want to see.

You will now create the same report, but for *external users*. The **Learning Time Spent for External Users** report is going to be very similar to the report you just created. - 10. Click the drop-down arrow located in the top-right corner of the **Learning Time Spent for Internal Users** report.
- 11. Click the **Create a Copy** option to open the **Copy Report** dialog.

The **Copy Report** dialog allows you to choose the dashboard you want to copy the report to. Since you have not created a custom dashboard yet, the only option available is to copy the report to the **Default Dashboard**.

- 12. Select the **Default Dashboard** option and click the **Copy** button.

A new custom report named **Copy of Learning Time Spent for Internal Users** appears on the default dashboard.

- 13. Click the drop-down arrow located in the upper-right corner of the **Copy of Learning Time Spent for Internal Users** report.
- 14. Choose the **Edit Report** option.
- 15. Type `Learning Time Spent per External User` in the **Report Name** field.
- 16. Open the **Filters** section and go to the **User Group (1)** tab.
- 17. Remove the **All Internal Users** group from the filter and replace it with the **All External Users** group.
- 18. Click the **Save** button to close the edit form and generate the new report.
