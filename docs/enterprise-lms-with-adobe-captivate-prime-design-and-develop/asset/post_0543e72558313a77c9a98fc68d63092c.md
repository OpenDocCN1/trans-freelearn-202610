
## Looking at the available connectors

When looking at how organizations manage their user directories, it quickly appears that some solutions are more popular than others. For example, lots of organizations use an LDAP directory (such as Microsoft Active Directory) or cloud-based solutions such as Salesforce or Workday. That's why Captivate Prime comes with special connectors that allow you to integrate with a growing number of the most popular solutions on the market. Let's examine the available connectors in this section:

- 1. Make sure you are logged in as an Administrator.
- 2. Once logged in, click the user icon in the top-right corner of the screen.
- 3. Click the **Integration Admin** role in the menu that opens.

When the page reloads, you should be logged in as an Integration Admin, with the list of available **Connectors** displayed on the screen.

> **Integration Admins**
> Within the Captivate Prime environment, *Integration Admins* are responsible for configuring and maintaining the connectors that integrate Captivate Prime with the other systems used in the organization. You will learn more about the Integration Admin role in *Chapter 16, Exploring the Integration Admin Role.*

Take some time to inspect the list of available connectors. You should recognize famous names such as **Salesforce, Workday, Power BI, LinkedIn Learning**, and others. Some of these connectors can automatically fetch user data.

- 4. Hover over the **Salesforce** connector to reveal the available options.
- 5. Click the **Getting started** link to open a page describing the capabilities of the **Salesforce** connector.

Notice that one of the core capabilities of the Salesforce connector is to *automatically fetch employee details from Salesforce and import them into Captivate Prime.* If your organization uses Salesforce, you can click the **Next** button in the top-right corner of the screen to start the process of connecting Captivate Prime to Salesforce.

Details on how to connect Captivate Prime to Salesforce are beyond the scope of this book, so you will return to the list of available connectors to continue your inspection.

- 6. Click the **Back to Connectors** link located in the left sidebar to return to the list of available connectors.
- 7. Hover over the **Workday** connector to reveal the available options.
- 8. Click the **Getting started** link to open a page describing the capabilities of the **Workday** connector.

Notice that the Workday connector can also *fetch employee details from Workday and import them into Captivate Prime automatically*. Again, you could click the **Next** button in the top-right corner of the screen to start connecting your Prime account to Workday.

- 9. Click the **Back to Connectors** link located in the left sidebar to return to the list of available connectors.
- 10. Repeat these steps for the other connectors to identify those that allow you to automatically import user data into Captivate Prime.

While inspecting all those connectors, take note of their core capabilities. As discussed earlier in this section, some of them can import user data. Other connectors are used to provide additional content to the Content Library, to export data to external analysis tools, to integrate with third-party video conferencing systems, and more.

If your organization uses one or more of the solutions that a connector is available for, you're in luck: Prime has you covered! But if the solution you're using in your organization isn't on this list, don't be disappointed – there are other ways to connect Captivate Prime to almost any external system. That's what the next section covers.

## Connecting to a generic third-party system

Virtually every enterprise solution for maintaining user accounts can export data to a CSV file. Captivate Prime is then able to automatically import such a CSV file using either an FTP connection or a cloud-based file sharing service such as Box.com.

In this section, you will use Captivate Prime FTP to automatically upload a CSV file containing user data. This FTP connection will be triggered regularly, so any changes to the CSV file will automatically be reflected in your Prime account the next time the FTP connection runs. If you set up your existing system to export this type of CSV to a location where it can be picked up by Prime, you can create a workflow that automatically syncs every change you make to your user data with your Prime account.

## Configuring the Prime FTP connector

The first step in setting up such a workflow is to configure the FTP server that you will use to automatically upload user data to Captivate Prime. If your organization already has an FTP server available, you can use the Custom FTP connector to connect Captivate Prime to your organization's existing FTP server. If you do not have an FTP server available, Adobe has partnered with an external organization called Extra vault to provide you with the necessary FTP service. This service is available through the built-in Captivate Prime FTP connector, which you will now configure by performing the following steps:

- 1. Make sure you are logged in as an Integration Admin and that you are seeing the list of available Connectors.
- 2. Hover over the Captivate Prime FTP connector to reveal the available options.
- 3. Click the Connect link.
- 4. Enter your email address and click the Connect button located in the top-right corner of the screen.

After a few moments, you should receive an email from a company called Extra vault, asking you to set up your FTP password.

> **Extra vault**
> *Extra vault* is the company Adobe has partnered with to offer you the Captivate Prime FTP service. This service is part of your Captivate Prime subscription and comes at no extra cost. It is also available to Prime trial accounts for the duration of the trial. Note that only a single Extra vault account is available for each Prime account.

- 5. Click the link in the email message and follow the on-screen instructions to create your Extra vault password.

Take note of the FTP server URL (https://primedev.extravault.com/) and your username (primeuser-XXXXXX). Both of these are available in the welcome email you received from Extra vault. In addition to the password you just set, these are the credentials you will need to upload to the CSV files you exported from your internal user directory.

After completing these steps, you will have access to an FTP server. The next step is to configure how users are automatically imported by Captivate Prime by mapping the columns of the CSV file to the fields of Captivate Prime.

## Mapping the import fields

Each directory solution has its own way of naming fields and exporting CSV files. That is why it is important to map the columns of the exported CSV file to the fields of Captivate Prime. To do so, you'll need to return to the Integration Admin role and perform the following steps:

- 1. Make sure you are logged in as an Integration Admin.
- 2. From the list of available Connectors, hover over the Captivate Prime FTP connector to reveal the available options.
- 3. Click the Manage Connections link. This will take you to the Manage Connections page, where you should see the FTP connection you created in the previous section.
- 4. Click the name of your FTP connection (by default, it should be something like CaptivatePrimeFTP-Connection-XXXX).
- 5. If needed, you can rename this FTP connection by typing a new name in the Connection Name field. Make sure you click the Save button in the top-right corner of the screen to save this change.
- 6. Click the Import Internal Users link located in the Capabilities section. This will take you to the Import Users – Map Attributes page.
- 7. Click the Choose CSV link located at the end of the description message that appears at the top of the page.
- 8. Browse to the users/importUsers.csv file of the download associated with this book. This CSV file contains seven columns and five rows.
- 9. Map the Adobe Captivate Prime fields (in the left column) to the columns of the CSV file.
- Note that the Name, Email, Profile, and Manager fields are required. Make sure that you map at least those fields.
