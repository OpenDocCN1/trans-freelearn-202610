+   7. Open the **For (X-axis)** dropdown and select the **Course** option.
+   8. Leave the other options at their default value and click the **Save** button to add this new custom report to the default dashboard.

Remember that the course effectiveness is automatically calculated by Captivate Prime based on several factors, including L1, L2, and L3 feedback. It is possible that this data is not yet available for some courses (remember that L3 feedback is typically provided 45 days after course completion).
