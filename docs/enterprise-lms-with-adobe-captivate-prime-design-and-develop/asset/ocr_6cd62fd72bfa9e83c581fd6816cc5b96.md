# Using inclusion and exclusion sets

When using groups of learners, you can create what are known as **inclusion sets**. An inclusion set is a list of groups. The learners that get enrolled in the course are those that are a part of *all* the groups listed in an inclusion set. For example, an inclusion set containing the **All Admins** and the **All Managers** groups enrolls learners that are *both admins and* managers. Those learners that are only admins or managers are *not* enrolled. Similarly, you can use **exclusion sets** to exclude individual learners or groups from the inclusion sets defined in the **Include Learners** section of the dialog.
