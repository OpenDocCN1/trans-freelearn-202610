**Excel or not Excel...**
... that's the question! Although Captivate Prime calls them *Excel* reports, all exports are done in CSV format. Keep in mind that a CSV file can be opened in many applications, not just spreadsheets, and if you use a spreadsheet application, not just Microsoft Excel. Excel is simply the most popular spreadsheet software among Prime customers and that's probably why it's called **Excel Reports** in Prime. Feel free to try this feature with whatever spreadsheet application you are using to take advantage of the unique charting and data analysis features present in your specific software package.

You will now export three of the available Excel reports starting with the **Learner Transcripts** report in the next section.

# Exporting the Learner Transcript report

The first Excel report you will explore is the **Learner Transcripts** report. This report allows you to access a comprehensive overview of all the learning activity of a learner or a group of learners. This type of report is very useful for human resources departments as it helps grasp the full picture of all the learning activities performed by a learner on your Captivate Prime account.

In this section, you will generate a **Learner Transcripts** report for your team of learners using the following steps:

+   1. From the **Excel Reports** tab of the **Custom Reports** section of the administrator, click the **Learner Transcripts** link to open the **Learner Transcripts** page.
+      If you have generated learner transcripts previously, these will be listed on this page with the ability to download them again.
+   2. Click the **Generate New** button located in the upper-right corner of the page to open the **Learner Transcripts** dialog.
+   3. Open the **Select Range** drop-down menu and inspect the available options.
+      In this example, I choose the **Last One Month** option but feel free to choose any option that suits your needs.
+   4. Use the **Select Learners** section to select the users or user groups you want to generate the learner transcript for.
+      You can use any number of individual users, user groups, or any combination of both. In this example, I choose the user group representing the team that I manage (**Damien Bruyndonckx's Team**).
