As you type in the questions, keep in mind that the instructor should be able to answer each question with a Yes or a No.

+   10. When you're done, click the **Save** button to save the questions.
+   11. As you are yet to define potential instructors in your account, leave the **Submission Instructor(s)** field empty for now.
+   12. Optionally, you can type a note for the instructor in the **Note to Instructor** field.
+   13. When ready, click the **Add** button in the lower-right corner of the form to save the new activity to the course content.
+   14. Finally, click the **Save** button in the upper-right corner of the page to save the changes you've made to the course.

The **Checklist** activity is yet another assessment tool available in Captivate Prime. Use it to complement the other assessment activities used in the course and provide the organization with meaningful data to measure the effectiveness of the course.

# Adding alternative delivery types to modules

There are many instances where it is helpful to be able to deliver the same modules using different delivery types, as shown by the following examples:

+   - A specific instructor is out on medical leave for a few months, so his/her instructor-led classes have been temporarily replaced with self-paced modules (recordings of previous classes, for example).
+   - You may not have instructors who can conduct live or virtual classes in every language, so for some languages, you must provide a self-paced module (for example, a recording of the live class with subtitles in different languages) instead of the instructor-led class itself.
