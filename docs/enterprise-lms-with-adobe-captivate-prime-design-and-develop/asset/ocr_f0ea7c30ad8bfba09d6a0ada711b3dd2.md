> **Note**
> When it comes to AICC, SCORM, or xAPI modules, keep in mind that Captivate Prime is only one of two parties involved, the other party being each individual module that can be generated by a wide variety of authoring tools. For instance, the detailed data displayed in the **By Question** tab is only available if the corresponding interaction data is transmitted by the individual course modules to the LMS. This has to be defined in the authoring tools used to generate the AICC, SCORM, or xAPI packages. Some authoring tools support this functionality, while others do not. Also, this detailed reporting may be enabled for some course modules and not for others. In other words, don't be too quick to blame Captivate Prime for the lack of data and make sure that reporting is properly configured in whatever authoring tools are used to build the course modules.

Take some time to review the available data and to relate what you see on the screen with the experience you've been through while taking the course as a learner in *Chapter 7, Reviewing the Learner Experience.*

Also, you might be puzzled by the lack of data available for the *essay* or *checklist* activities. Remember that these activities have been reviewed by an instructor in *Chapter 8, Exploring the Instructor Role.* But the instructor only had to *approve* or *reject* these activities without actually grading them, which explains why no L2 data is available for these activities. For these activities to be graded, you must select the **Enable scoring for this Module** checkbox when creating the course while logged in as an author.
