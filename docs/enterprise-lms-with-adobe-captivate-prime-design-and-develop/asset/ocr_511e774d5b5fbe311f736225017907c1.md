# Accessing L2 Feedback Data

L2 feedback refers to the second level of Kirkpatrick's Four Levels of Learning Evaluation model. As a reminder, this is the *Learning* level, which is the level that involves grading and individual assessment in order to measure the acquisition of new skills or knowledge by learners. L2 feedback examines learners' performance on quizzes, as well as their results on their various assignments.

In Captivate Prime, L2 feedback refers to quiz scores achieved by learners as they take courses and learning programs. These come from all the graded activities included in courses, as well as from quizzes included in interactive course modules, whose results are reported to the LMS via the AICC, SCORM, or xAPI standards.

As such, L2 feedback is mostly automatic in Captivate Prime. There is nothing to do on your end to enable L2 feedback for a course or learning program and have Captivate Prime LMS collect this data. The only requirement for a course or learning program to have L2 feedback enabled is to contain at least one graded activity or quiz. Note that for some activities (such as file submissions and checklists), the grades must be manually entered into the system by an instructor, as discussed in *Chapter 8, Exploring the Instructor Role.*

> **AICC, SCORM, and xAPI**
> AICC, SCORM, and xAPI are the three standards used in the eLearning industry to transmit data between interactive course modules and the LMS. Captivate Prime supports all three standards, so Captivate Prime can host the content created by virtually any eLearning authoring tool. For more information on AICC, SCORM, and xAPI, refer to *Chapter 3, Uploading Learning Content and Managing the Content Library.*

When you created the *Fundamentals of cybersecurity* course back in *Chapter 4, Creating Skills and Courses*, you included a SCORM-compliant activity containing a quiz. This activity was built using the Adobe Captivate authoring tool but remember that Captivate Prime can host content created by *any* AICC-, SCORM-, or xAPI-compliant authoring tools.

You will now review how administrators and managers can access quiz data using the following steps:

+   1. Log in to your Captivate Prime account as an administrator.
+   2. From the administrator home page, click the **Courses** link located in the **Learning** section of the left sidebar.
