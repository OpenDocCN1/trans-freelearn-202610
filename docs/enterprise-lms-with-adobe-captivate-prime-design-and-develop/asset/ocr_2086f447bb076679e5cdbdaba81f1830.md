You also entered values into these three fields for your user account using the **Internal Users** page of the administrator application. Of course, as an administrator, you could enter these three pieces of data for each user, one by one, but that would quickly become tedious. A better approach is to have users enter this data themselves the next time they log in. Well, it turns out that this is exactly the default behavior of Captivate Prime! Let’s check this out by performing the following steps:

+   1. Open another browser or a new private window in your web browser.
+   2. In this new private window, browse to your Prime account URL and log in as *Learner 01*.
+   3. Once logged in as *Learner 01*, you will immediately be prompted to complete your profile.
+   4. Enter some data in the **Department**, **Location**, and **Hobbies** fields, and then click the **Proceed** button to submit the new data.
+   5. This last action redirects *Learner 01* to the learner experience of your Prime account.
+   6. Click on the user icon in the top-right corner of the screen to log out as *Learner 01*.
+   7. Once logged out, browse the URL that was sent by email to *Learner 03* when that user registered to the Prime account.

# Accessing the custom login page

If you do not remember the custom login URL or if you do not have access to this email anymore, go to the **External Users** page of the administrator application and hover over the external registration profile you created earlier. Click the *chain* icon that appears to copy the custom link to the clipboard. Then, return to the private browser window and paste the link in the address bar. When the page loads, click the **Already Registered** link to access the custom login page.

When logging in as *Learner 03*, notice that the **Complete Profile** form does *not* appear. This is because *Learner 03* is an external user and you have created custom fields for internal users only.

+   8. Make sure you log out as *Learner 03* before moving on with the rest of the exercises.

Thanks to this default behavior of Captivate Prime, every user is prompted to enter data in the new custom fields the next time he/she logs in.
