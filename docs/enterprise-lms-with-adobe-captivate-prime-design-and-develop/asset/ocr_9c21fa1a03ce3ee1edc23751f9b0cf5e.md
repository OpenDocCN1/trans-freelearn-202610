Let's review the process of uploading resources to a session using the following steps:

+   1. Make sure you are logged in as an instructor to your Captivate Prime account.
+   2. From the instructor home page, click any of the available upcoming sessions. This opens the **Session Overview** page of the chosen session.
+   3. Click the **Resources** link located in the left sidebar of the **Session Overview** page to open the **Resources** page of the chosen session.
+   4. Click the **Add** button located in the upper-right corner of the screen.
+   5. Browse your computer for the file you want to upload. You can upload a wide variety of file types, such as text files, spreadsheets, presentations, video files, audio files, and so on.

If you don't have a suitable file available, you can use the `courseContent/liveClass_practicalDetails.pdf` file provided in the downloads associated with this book.
