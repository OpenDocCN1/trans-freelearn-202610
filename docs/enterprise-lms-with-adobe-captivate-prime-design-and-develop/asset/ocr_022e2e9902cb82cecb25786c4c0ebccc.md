Repeat this operation for all the courses that should be added to the learning program.

In this example, add the **Learn Photoshop: Fundamentals for Getting Started** and **Fundamentals of Photo Editing using Adobe Lightroom** courses, both of which should be available in the default course catalog that comes with your Prime trial account.

+   4. When done, return to the **Curriculum** tab of the **Courses** page of the learning program.

+   5. If needed, you can reorder the courses using drag and drop actions.

You can also adjust your **Completion Requirements** using the drop-down list located above the list of courses in the **Curriculum** section. By default, **Completion Requirements** is set to **All** courses.

+   6. When ready, click the **Publish** button located in the top-right corner of the page.

Before you click the **Publish** button, your learning program is in the *draft* status. Clicking the **Publish** button is the action that gives birth to your new learning program. From now on, this learning program is available in the course catalog and is open for enrollment.

In the next section, you will review the options that are available for maintaining your learning programs, which include modifying, retiring, and deleting the learning programs available in your Prime account.

This takes you to the **Learning Programs** page, which displays a list of all the **Published** learning programs by default.

+   2. Hover your mouse over the lower area of the card of any published learning program to reveal the available options.
