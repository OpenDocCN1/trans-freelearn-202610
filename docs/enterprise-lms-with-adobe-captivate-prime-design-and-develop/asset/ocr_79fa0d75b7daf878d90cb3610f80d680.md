You can view the list of users in each group by clicking the number in the **No. of People** column. Take some time to inspect these **Auto-generated** groups and the users they contain. These groups are dynamic – they are *generated* and *maintained* automatically by Adobe Captivate Prime. There is absolutely no action required on your side to create these groups or place users in them.

Maybe these autogenerated groups are all you need to effectively manage the users of your Prime account, but your organization may as well require other groups to be created. That's why, in addition to the autogenerated groups discussed in this section, Captivate Prime also allows you to create custom groups. This will be discussed in the next section.

# Creating custom groups

In this section, you will create the *Advisory Board* group. This group comprises the CEO, some managers, and some employees. It does not correspond to any department, location, role, hierarchical relationship, and so on in the organization and therefore cannot be automatically generated by Captivate Prime.

Perform the following steps to create a new custom user group:

+   1. From the **User Groups** page, click the **Add** button located in the top-right corner of the screen. This will bring up the **Add User Group** form.
+   2. Enter `Advisory Boards` in the **Name** field.
+   3. As a best practice, take the necessary time to supply a short **Description** for your new group.
+   4. Finally, you must supply the list of group members. You can do that using the username or the email IDs of the users.
+      Type the name of a user in the **Add Learners – Name** field and select the desired user when it appears in the list. Notice that you can also select other groups rather than individual users. This is how you can create nested groups.
+      If you're using an **Email ID**, you must supply a comma-separated list of email addresses of existing users.
+   5. When done, click the **Save** button located in the lower-right corner of the **Add User Group** form.
