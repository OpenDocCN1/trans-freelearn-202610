# 4
Creating Skills and Courses

In the previous chapter, you uploaded custom content modules to the Content Library of your Prime account. But this content is not available to learners yet. Remember that content modules are only the fundamental building blocks used to create Courses.

Courses are what learners enroll in. So, for the content that we uploaded in the previous chapter to start *actually* being useful, you need to start building courses with this content. This is what you will do in this chapter.

But before creating courses, let's think about why learners would take courses in the first place and why organizations would put so much time, effort, and money into making courses available to their workforce. The answer to these two questions can be found in one word: **Skills**.
