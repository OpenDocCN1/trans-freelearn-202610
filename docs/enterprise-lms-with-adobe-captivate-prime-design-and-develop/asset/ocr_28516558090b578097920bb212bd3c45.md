# Summary

Congratulations! With learners taking courses, your Prime account finally comes to life.

In this chapter, you have reviewed the default learner experience. You have visited all the pages of the learner application using a web browser. While taking courses, you experienced the features of the fluidic player, which allows learners to seamlessly progress through courses regardless of the type of instructional content being served. You have reviewed a PowerPoint file, SCORM packages created with Adobe Captivate, and external links activities. You have also submitted an assignment to Captivate Prime using a file submission activity. Finally, you used the Adobe Captivate Prime mobile app to enroll in a course and access a few course modules. You've even downloaded the content of a course so that it can be accessed even when the mobile device is not connected to the internet.

Now that you have active learners on your Prime account, a new challenge arises: following up on your learners' progress on a daily basis. This includes preparing instructor-led classes, managing waitlists, reviewing learner assignments, and filling out checklists. These are the main tasks devoted to the instructor role, which you will review in the next chapter.
