# A first look at the Content Library

The Content Library is where all the asynchronous course modules are available in your Prime account live. By default, every course module ends up in the Content Library, regardless of which author uploaded a particular file. In other words, Author A can see the content uploaded by Author B and vice versa. It is possible to segment the Content Library into folders that can be made public or private. This feature will be discussed in the Using content folders section, later in this chapter.

To have access to the Content Library, it is necessary to be logged in as an Author:

+   1. Make sure you are logged in as an Author and that you are on the Author home page.
+   2. Click the Content Library link located in the Manage section of the left sidebar.
