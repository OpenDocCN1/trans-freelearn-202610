Now that you have a better understanding of what course instances are, you understand that learners enroll in course instances and not courses, per se.

> The default course instance
> Even if you do not explicitly create course instances, remember that, when creating a new course, a default course instance is automatically created. If the course only contains self-paced modules, this default instance may be all you need for the course to work as expected. In such a case, learners would enroll in that default course instance.
