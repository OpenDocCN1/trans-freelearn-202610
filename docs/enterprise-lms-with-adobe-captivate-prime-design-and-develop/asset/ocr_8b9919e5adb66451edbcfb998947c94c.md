8. When you're ready, open the **Unused** dropdown and choose the **All** option to return to the complete list of available modules.

This feature is particularly useful when creating a new course using course modules that have just been uploaded.

These are the main options available for sorting and filtering the modules available in the Content Library. In the next section, you will learn how you can further divide your Content Library into folders.

# Using content folders

In the previous section, you discovered that, by default, the Content Library is a long list containing every module of your Prime account. There are some advantages to this default behavior:

+   - As an author, can you take advantage of the modules that have been uploaded by other authors to create and update courses.
+   - Any author can add a language version to any module. This is very useful in organizations where different teams are responsible for authoring different language versions of the same course module. There's no need to be the author of the original language content to upload a translation. This makes it much easier to manage the various language versions of a course module.
+   - Each author can also update, retire, and delete *any* course module available, not only the modules that they have uploaded. This makes it easy to delete the content that's been created by a contractor or an employee that no longer works for the organization or that has moved to another position.

If it feels strange for you to consider this default behavior as an advantage, remember that Captivate Prime is designed as an enterprise LMS. Therefore, it is assumed that the content available in the Content Library belongs to the organization, not to any particular content author or teacher. This is very different from the mindset that prevail in most schools and universities.

That being said, there are instances where this default behavior is somewhat limited, even for a company:

+   - As a company, you may contract with many agencies providing course content. You may not want Agency A to have access to the list of course modules provided by Agency B.
+   - You may have confidential course content that should only be accessed by a specific team of users with proper accreditation.
