# Assigning Badges to Courses and Learning Programs

Another way to earn badges is by completing courses and learning programs. To do this, administrators must first link badges to courses and learning programs. This is precisely what you will do in this section.

To be more exact, you will link the badges to course instances and learning program instances. This allows you to have different badges for each course instance (kind of like how each Space Shuttle mission had its own badge).
