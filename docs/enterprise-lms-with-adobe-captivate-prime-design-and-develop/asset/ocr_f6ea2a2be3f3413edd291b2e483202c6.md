# The course effectiveness by course report

This third report will allow you to gain some insight into the effectiveness score of each course. Remember that Captivate Prime calculates this score automatically based on the L1, L2, and L3 feedback of each course. Thanks to this report, you will be able to quickly identify the courses with the highest/lowest course effectiveness, and so on.

To build this third report, you will not use any of the predefined templates available in the **Type** drop-down menu. Instead, you will build your report from scratch using the following steps:

+   1. Make sure you are on the **Custom Reports** page of the **Reports** section of the administrator application.
+   2. Go to the **Dashboard Reports** tab and click the **Add** button located in the upper-right corner of the screen to open the **Add Report** dialog.
+   3. Open the **Type** drop-down menu and choose **Custom**.
+   
+   Notice that, unlike the other options used in the previous sections, the **Custom** report type does not provide any default values for the other fields available in the **Add Report** dialog.
+   4. Type `Course effectiveness by course` in the **Name** field.
+   5. Open the **Y-axis** drop down and choose the **Course Effectiveness** option.
+   6. Open the **And (Secondary Y-) axis** dropdown and choose the **Learning Time Spent** option.
