Also, note that a course discussions board is a very simple messaging application. It does not offer any mechanism to reply to another person's message or to like/dislike a message. That said, Learner 02 has the opportunity to keep the conversation going by posting another message of his/her own.

+   18. While logged in as Learner 02, add a second message to the discussion.

When you're done, notice that Learner 02 can delete the message he/she has posted, but that Learner 02 cannot modify or delete Learner 01's message.

This raises the issue of moderating these discussion boards. What happens if participants start shouting at each other? Or if the content that's been posted has nothing to do with the course or is of poor quality? Or when older messages are not relevant anymore and need to be deleted? These are a few of the circumstances where someone else, other than the message owner, must be able to delete a post.

In the case of course discussion boards, this task is the responsibility of the platform administrator. Let's take a look at this workflow.

+   19. Return to the browser window where you are logged in as an administrator.
+   20. Click the user icon located in the top-right corner of the screen to switch to the Learner role.
+   21. When in the learner experience, go to the learning catalog and open the course where Learner 01 and Learner 02 have posted messages.

The administrator doesn't need to be enrolled in the course.
