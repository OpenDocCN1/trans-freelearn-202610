Adobe Captivate Prime lets you customize four different aspects of each theme: **Top Bar Color**, **Accent Color**, **Primary Color**, and **Sidebar Brightness.**

+   5. To identify which area of the interface is controlled by each of these options, click the **Show Hints** link at the bottom of the theme options area.

This toggles on hints on the theme preview as shown in the following screenshot.

Now that you have a better idea of what aspect of the **user interface (UI)** each option controls, let’s start customizing the top bar color.

+   6. In the options for the chosen theme, click the **Top Bar Color** field. By default, the top bar color is #FFFFFF in every theme. (#FFFFFF is the hex code for *white*.)

+   7. Type in the desired color code or choose the color in the color picker. Click the **Select** button when done.

The **Top Bar Color** is the background color of the header area that spans across the top of the Captivate Prime interface. Your change is immediately reflected in the theme preview area. If you don’t like the new color, just repeat the above actions with another color code until you find a color that you like.
