This opens the **Learnings** dialog, which allows you to select the courses, learning programs, and certifications that should be included in the **Compliance Dashboard** report. Note that the learnings available for analysis must have a deadline to be taken into account for this report. Most of the time, this implies creating several course instances of the same course, each with a different deadline. A learner is considered *compliant* if they have completed the course by the deadline.

26. Click the **Cancel** button to close the **Learnings** dialog and return to the **Compliance Dashboard** report.

27. Click the **Compliance Status Details** link located in the bottom-right corner of the **Compliance Dashboard** report.

This allows you to see the same data in a tabular fashion. Note that this data table has the same basic capabilities as the other data table discussed earlier in the section. Of special interest is the **Actions** menu, which allows you to export the data to a CSV file.

28. Take some time to examine the data tables available. When ready, click the **Learning Summary** link in the left sidebar to return to the **Learning Summary** dashboard.

This concludes our exploration of the default dashboards and reports available in Adobe Captivate Prime. There is nothing you need to do to make these reports available. These reports are designed to give you a general overview of everything happening in your Prime account:

+   - The **User Activity** dashboard gives you some insight into the users defined on your Prime account. You can use it to get information about the number of registered users, the number of visits, and the learning time spent on your account.
+   - The **Training Content** dashboard gives you information about the trainings offered to your users on your Prime account. Here, you can see the total trainings available, the newly added trainings, and the active trainings.
+   - Finally, the **Learning Summary** dashboard gives you information about how users interact with the training content. You can see a basic summary of enrollments, views, and completions as well as the **Skills Status** report and the **Compliance Dashboard** report.

Various filters and links provide a lot of meaningful variations on these basic reports. Remember that, to take full advantage of these reporting capabilities, you need to give your learners enough time to interact with learning content and complete courses. You also need to give Captivate Prime some time to generate meaningful daily, weekly, and monthly datasets.
