# Adding Content Modules to Folders

Creating Content Folders is a task devoted to a Prime administrator, but putting modules into folders is part of the Author role:

+   1. Go back to the Author role and click the Content Library link located in the Manage section of the left sidebar.
+   2. Click the Add button, as if you wanted to add a new module to the Content Library.

As shown in the following screenshot, a new field is available in the Add New Content form:
