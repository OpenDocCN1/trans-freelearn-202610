
Now, let's imagine that, with the increasing demand from learners, you decide to move the live class to a bigger venue and designate an additional instructor so that you can accommodate a lot more learners than planned when you created the course instance. In such a case, you want to reopen the course instance so that new enrollments can be accepted again.

Let's reopen our retired instance.

- 6. Locate the retired instance that you wish to reopen. If necessary, you can use the **Retired** tab located above the list of instances.
- 7. Click the down arrow located in the top-right corner of the course instance you wish to reopen.
- 8. Click the **Reopen Instance** option in the menu that opens.

Note that when the enrollment deadline or the first synchronous activity has passed, the course instance is automatically retired by Captivate Prime.

After reading this section, you know enough about course instances to complete the rest of this chapter. The main point to remember is that learners do not enroll in *courses* but in *course instances*. In the next section, you will learn how to group courses so that learners can enroll (or be enrolled) in several courses at once.

## Taking advantage of Learning Programs and Certifications

So far in this book, you have taken for granted that learners enroll in courses. In this section, you will discover that, although this is often the case, this assertion is not always true. There are many cases where it makes sense to group courses together and enroll learners in a group of courses rather than a single course:

- You offer different levels of courses on the same subject (for example, photography level 1, photography level 2) and you want to allow learners to enroll in the full curriculum in one go.
- You want to split longer courses into chapters, but Captivate Prime does not allow you to organize modules into chapters within a single course. In such a case, you can group courses together and consider each course a chapter of a larger program.
- For reasons of advancement in the organization, or to let learners become a trainer/manager/SME, you want to allow your learners to get certified, but some certifications require learners to take multiple courses.
- Many professions (Accounting, HR, Project Managers, and so on) require ongoing training, and you want to define the series of courses that make up this ongoing certification program.

The preceding examples are just a few of the many situations where such course bundling is relevant. That is why Captivate Prime offers many features to address this type of use case. This is what you will review in this section.

## Creating Learning Programs

Let's start with the simplest of these features: the **Learning Program**. In Captivate Prime, a learning program is a simple collection of courses. You can use it to group a set of related courses or create a longer curriculum in which each course is considered a chapter.

> **Learning programs versus learning plans**
> The learning programs discussed in this section should not be confused with another concept used in Captivate Prime, namely learning plans. Learning plans allow the system to automatically enroll learners when an event occurs. This feature will be discussed in more detail in the *Automatic enrollment using learning plans* section, later in this chapter.

To illustrate this feature, you will use some of the courses that are automatically available with your Prime trial account to create a learning program dedicated to photo editing using Adobe Lightroom and Adobe Photoshop. ## Adding courses to a Learning Program

A learning program being a bundle of courses, the most important step in creating one is choosing the courses that are part of it. This section picks up from where the previous section left off: you should be on the **Courses** page of the learning program you started creating in the previous section, as shown in the following screenshot:

Perform the following steps to add courses to your learning program:

- 1. Switch to the **Catalog** tab of the **Courses** page of your learning program (see the arrow in the preceding screenshot).
- 2. If needed, search for the desired courses using the **Search** field in the top-right corner of the screen and/or the **Skills** and **Sort By** filters available in the top-left corner of the screen.
- 3. When you spot a course you want to add to the learning program, hover over the lower area of the course card and click the **Add** link.

- 5. If needed, you can reorder the courses using drag and drop actions.
