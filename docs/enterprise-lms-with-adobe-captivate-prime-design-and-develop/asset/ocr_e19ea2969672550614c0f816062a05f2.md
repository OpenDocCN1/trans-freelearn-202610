Note that it is possible to export this data to a **Comma-Separated Value (CSV)** file using the following steps:

+   1. Make sure you are on the **User Activity** page of the administrator application.
+   2. Click the **Export** button located in the upper-right corner of the **Registered Users Report** (see the arrow in the preceding screenshot).
+   3. Take some time to read the message in the **Generating Report Request** dialog before clicking the **OK** button.
+   
+   The report will be available sometime later in the notification area.
+   4. When the report is available, click the notification icon (the bell icon in the upper-right corner of the screen) to download the report. The downloaded `.csv` file can be opened with any spreadsheet application.

The **Registered Users Report** is only the first report available on the **User Activity** page. Use the following steps to explore the next available report.

+   5. Scroll down the **User Activity** page until you see the **User Visits Report.**

The **User Visits Report** shows the number of learners who have accessed the platform in a given period of time. Note that each login is considered an access, even if the logged-in user does not consume any content and just browses the system.

By default, the report is configured to show data for all users in your account over the last 30 days, but you can change this by using the drop-down lists available above the report.

+   6. Open the **Date Range** drop-down list.
+   7. Choose any available date range. The report is immediately updated for the chosen date range.
+   
+   Note that if you choose a different value than **Last 30 Days**, the report displays the data on a month-to-month basis. When choosing **Last 30 Days** for **Date Range**, the data is displayed on a day-to-day basis.
+   8. Open the **Date Range** dropdown and return to the default value of **Last 30 Days.**

You can also filter the report by *User Groups*. Remember that Captivate Prime automatically creates a large number of user groups based, for example, on each user's manager. Custom groups are also possible. All this was discussed in *Chapter 5, Managing Users*. Note that you must first configure the user groups you want to use to filter the report using the following steps:

+   9. Click the **Configure** link located above **User Visits Report.**
