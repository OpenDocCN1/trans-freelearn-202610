# Figure 10.2 – The Registered Users Report

This report tracks the number of registered users in your account on a weekly basis. This is an important report for administrators. Remember that Captivate Prime is priced based on the number of registered users. So, this report allows administrators to keep an eye on the evolution of the cost of Captivate Prime over time.

In the preceding screenshot, notice that the number of registered users suddenly drops at the end of the month of April. This is because the external registration profile created in Chapter 5, Managing Users, was disabled on May 1 of that year, so the seats used by that external profile were released on that date and the users registered through this external registration profile lost their access to Captivate Prime.

For organizations using the Monthly Active Users (MAU) licensing model, this report shows the count of active learners on a monthly basis.

# Captivate Prime licensing models

There are two main pricing models available for Adobe Captivate Prime: the Registered User pricing model and the Monthly Active Users pricing model. These two models were discussed in the Getting Captivate Prime section of Chapter 1, Introduction to Adobe Captivate Prime.
