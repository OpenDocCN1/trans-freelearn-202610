The available connectors cover many of the most popular enterprise applications and services used by organizations all around the world. But in an ever-changing technology landscape, it is impossible to provide a dedicated connector for every conceivable external application. Chances are that the application used within your organization is not covered by any of these connectors. In this case, you need to rely on the Captivate Prime API and on some custom development to integrate Captivate Prime with the solution used in your organization. This is what we will discuss in the next section.

# Developing applications with the Captivate Prime API

API stands for **Application Programming Interface**. It is a type of interface commonly used by developers to connect different applications together. Thanks to the Captivate Prime API, virtually any data contained in your Prime account and any services provided by Captivate Prime LMS can be programmatically accessed and integrated into any type of custom application developed by your in-house development team.

Here are some of the most common use cases involving the Adobe Captivate Prime API:

+   - Some organizations want to take advantage of the capabilities of Adobe Captivate Prime without using the default learner experience. In this case, they can develop their own personalized learner experience using any technology of their choice. Most often, this customized user experience comes in the form of a website and/or a mobile app entirely designed and developed by the organization's in-house developers. Behind the scenes, this website/application uses the Captivate Prime API to access the necessary data (such as details about the logged-in user, the list of available courses, and the completion status) and to report learner interactions back to Captivate Prime. This is what is referred to as using Captivate Prime as a *headless* LMS.
+   - You can use the Captivate Prime API to integrate Captivate Prime with enterprise applications not covered by the built-in connectors available in the platform.
+   - You can use the Captivate Prime API to build custom applications that extends the native capabilities of Captivate Prime.

These are just a few of the many instances in which the Captivate Prime API is useful.
