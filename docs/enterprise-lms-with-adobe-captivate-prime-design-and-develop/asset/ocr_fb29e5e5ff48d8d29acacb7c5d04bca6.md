# Exploring the learner experience using the mobile app

The learner experience provided by the mobile app is very similar to the experience you reviewed in the *Touring the default learner experience* section earlier in this chapter using your web browser. Let's check this out using the following steps:

+   1. Make sure you are connected to your Prime account as *Learner 03* using the mobile app.

+   2. Scroll the home page up and down and take the necessary time to identify all the sections. You should recognize the sections discussed in the *Touring the default learner experience* section earlier in this chapter.

+   3. At the bottom of the screen, tap the **My Learning** icon. This takes you to the **My Learning** page, where you can see all the courses, learning programs, and certifications *Learner 03* is currently enrolled in.

Also note the **My Learning** and **My Job Aids** tabs at the top of the page. *Job aids* have been discussed in *Chapter 4, Creating Skills and Courses.*

+   4. The next item available at the bottom of the screen is the **Catalog** icon. Taping this icon takes you to the course catalog, where all the courses available on the platform are displayed.

+   5. The fourth and final item available at the bottom of the screen is the **Social Learning** icon. Note that an administrator must have enabled social learning on the account for this icon to be displayed. Social learning will be further discussed in *Chapter 12, Enabling and Managing Social Learning.*

+   6. Tap the hamburger icon (the icon with the three horizontal bars) located in the upper-left corner of the screen to reveal a side panel with additional options.
