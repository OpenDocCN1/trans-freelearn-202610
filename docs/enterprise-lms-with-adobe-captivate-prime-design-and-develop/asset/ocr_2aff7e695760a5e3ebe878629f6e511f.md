# Figure 9.15 – Making a file submission activity a graded activity

In this section, you learned about L2 feedback in Captivate Prime. Remember that collecting L2 data is mostly automatic. The data either comes from the AICC, SCORM, or xAPI reports sent to the LMS by the interactive learning modules or is manually entered into the system by an instructor.

The L1, L2, and L3 data is also used by the system to automatically calculate the course effectiveness score. This will be discussed in the next section.
