# Viewing manual recommendations as a learner

In this section, you will return to the browser window in which you are logged in as Learner 01 and examine how the recommendation you created in the previous section is displayed on the learner home page:

+   1. Return to the browser window in which you are logged in as Learner 01.
+   2. If necessary, click the logo in the upper-left corner of the page or the Home icon of the left sidebar to return to the learner home page.
+   3. Scroll up and down the learner home page in search of the announcement you created in the previous section.

Bad news! Your manual course recommendation is not displayed on the learner home page by default. This is because the Recommended by <your organization name> widget is not present, by default, on the learner home page. So, let's return to the administrator role to enable that widget:

+   4. Return to the browser window in which you are logged in as an administrator.
+   5. From the administrator home page, click the Branding link located in the Configure section of the left sidebar.
+   6. From the Branding page, click the Learner Homepage link of the left sidebar to open the Learner Homepage Settings page.
+   7. Make sure that the Immersive switch, which is located at the top of the page, is turned on.
+   8. Scroll down the page and select the Recommended by <your organization name> checkbox, as shown in the following screenshot:
