+   - Subscribing to external course libraries provided by third-party vendors comes at a cost. Most of the time, this cost depends on the number of users accessing these online libraries. Therefore, you might want to limit the number of users accessing these third-party courses to those for whom they are most relevant (for instance, courses on leadership for the managers or courses on programming for the developers).
+   - Some courses might only be relevant in certain parts of the world. This is the case, for example, for courses on local regulations. Only users in the corresponding regions should have access to these courses.

These are just a few of the situations where it is useful to control which learners have access to which courses.

Captivate Prime addresses this problem through the use of catalogs. A **catalog** is a collection of learning items that can contain courses, learning programs, certifications, and job aids. As an administrator, you can create an unlimited number of custom catalogs within your Prime account and decide who has access to which catalog. Controlling who has access to which course is a simple matter of getting the courses into the right catalog(s).

A single course can be part of multiple catalogs and a single catalog can contain an unlimited number of learning items.
