
## Activating, using, and managing course discussions for a single course

By default, course discussions are disabled across your entire Prime account. In other words, none of the courses currently available on your account have discussions enabled. In this section, you will override this general account setting and enable discussions for a single course.

First, you will quickly review the current learner experience by performing the following steps:

- 1. Use the browser window where you are logged in as *Learner 01*.
- 2. From the learner home page, click the **My Learning List** link or the **My Learning** icon on the left sidebar to access the **My Learning** page.
- 3. Click any of the course cards available on the **My Learning** page to open the overview page for that course.

Remember that the **My Learning** page of a learner lists all the courses the logged-in learner is enrolled in.

In this example, I have chosen the **Fundamentals of Cybersecurity** course, which we created back in *Chapter 4, Creating Skills and Courses*.

As shown in the following screenshot, *Learner 01* currently has access to the **Modules** and **Notes** tabs of the course overview page:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_434_0.png)

Figure 12.1 – Learner 01 has access to the Modules and Notes tabs

You will now return to the administrator application and enable discussion for that course using the following steps:

- 4. Switch to the browser window where you are logged in as an administrator.
- 5. From the administrator home page, click the Courses link located in the Learning section of the left column.
- 6. Hover over the course card of the course currently displayed in Learner 01's browser window.
In this example, I chose the Fundamentals of Cybersecurity course.
- 7. Click the View Course link to display the course overview page in the admin application.
- 8. When on the course overview page, click the Settings link located in the Configure section of the left sidebar.
- 9. Finally, select the Enable checkbox associated with the Discussion Board setting. This last action is illustrated in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_435_0.png)

Figure 12.2 – Enabling Discussion Board for the selected course

Now that the course discussion has been activated for that specific course, return to the learner experience, refresh the page, and see what has changed.

> Note
> Course discussion is only available for internal learners. If you are using your own users, make sure you log in as an internal learner to follow along with this exercise.

- 10. Return to the browser window where you are logged in as Learner 01.
- Confirm that you are still on the course overview page. If not, use the My Learning section of the learner experience to return to the course overview page.

- 11. Refresh the page in the browser window and confirm that the **Discussions** tab is now visible next to the **Modules** and **Notes** tabs:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_436_0.png)

Figure 12.3 – The Discussions tab is now visible on the course overview page

- 12. Click the **Discussions** button (identified by the arrow in the preceding screenshot) to open the newly activated discussions tab.

- 13. Type a short message in the **Say something about this Course** field and click the **Post** button.

Your message has been posted on the course's **Discussions** board. It is now visible to the other users involved in this course. Let's check this out.

- 14. Click the user icon located in the top-right corner of the screen and use the **Sign Out** link to log *Learner 01* out of Captivate Prime.

- 15. Log back in as *Learner 02*.

- 16. If *Learner 02* is already enrolled in the course *Learner 01* added a message to, use the **My Learning** page of *Learner 02* to access that course.

If *Learner 02* is not enrolled in the course yet, use the Catalog to self-enroll *Learner 02*.

In either case, *Learner 02* should end up on the course overview page.

- 17. When on the course overview page, switch to the **Discussions** tab.

As shown in the following screenshot, the message posted by *Learner 01* can be seen by *Learner 02*:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_437_0.png)

Figure 12.4 – Learner 02 sees the message posted by Learner 01

Also, note that a course discussions board is a very simple messaging application. It does not offer any mechanism to reply to another person's message or to like/dislike a message. That said, Learner 02 has the opportunity to keep the conversation going by posting another message of his/her own.

- 18. While logged in as Learner 02, add a second message to the discussion.

When you're done, notice that Learner 02 can delete the message he/she has posted, but that Learner 02 cannot modify or delete Learner 01's message.

This raises the issue of moderating these discussion boards. What happens if participants start shouting at each other? Or if the content that's been posted has nothing to do with the course or is of poor quality? Or when older messages are not relevant anymore and need to be deleted? These are a few of the circumstances where someone else, other than the message owner, must be able to delete a post.

In the case of course discussion boards, this task is the responsibility of the platform administrator. Let's take a look at this workflow.

- 19. Return to the browser window where you are logged in as an administrator.
- 20. Click the user icon located in the top-right corner of the screen to switch to the Learner role.
- 21. When in the learner experience, go to the learning catalog and open the course where Learner 01 and Learner 02 have posted messages.

The administrator doesn't need to be enrolled in the course.

- 22. If the course has multiple instances, click any of the available instances.
- 23. When on the course overview page, click the **Discussions** tab to open the course discussion board.

As shown in the following screenshot, you can access the discussion board of the course without being enrolled, and, because you are an administrator, you can delete any of the messages that have been posted:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_438_0.png)

Figure 12.5 – Administrators can delete any posted message

In this section, you have enabled discussion for a single course, and you reviewed the tools and features that learners can use to post and delete messages.

> **Tip**
> Remember that instructors are, first and foremost, ordinary learners. Therefore, instructors can browse the catalog as learners and self-enroll to the course to participate in the discussions with the other enrolled learners. Also, some administrators like to enroll themselves in the courses they moderate as it helps them keep a better eye on the course discussion board.

In the next section, you will modify the general account settings and enable discussion by default for every course available on your Prime account.

## Enabling Course Discussion by default on your Prime account

Remember that course discussions are disabled by default at the account level. In the previous section, you overridden this default for a specific course by enabling discussion for that course only. In this section, you will return to the administrator role and enable course discussions by default on your account.

Once this is done, all the courses in your account, including all those that are currently available, will have their discussion board enabled. Perform the following steps to experiment with this feature:

- 1. Make sure you are logged in as an administrator and that you are located on the administrator home page.
- 2. From the administrator home page, click the Settings link located in the Configure section of the left sidebar. This action opens the Basic Info page.
- 3. When on the Basic Info page, click the General link located in the Basics section of the left sidebar.
- 4. When on the General page, locate the Discussion Board option, which is disabled by default.
- 5. Select the Enable checkbox associated with the Discussion Board option. This action is illustrated in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_439_0.png)

Figure 12.6 – Enabling course discussion by default on the account

This action enables discussion for all the courses of the Prime account. This includes the courses currently available, as well as all the future courses you will publish from now on.
