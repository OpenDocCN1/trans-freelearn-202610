
In this example, you updated a module that is not yet part of any course. Therefore, the update has no impact on the courses or learners who are currently active in your Prime account. If the module you update is already part of a course, a small icon will appear next to the module once it has been updated, as shown in the following screenshot:

You must click this icon to update all the courses that are using this content. As long as you have not clicked this icon, the old version of the module will still be used.

Another question that arises when updating course modules this way is what happens to the completion and success criteria of the learners that have reviewed the old version of the content before the update. Here’s how Captivate Prime handles such a situation:

- The completion and success criteria of current learners that have reviewed the old version of the content are maintained. This means that the learners do not have to review that course module again, even if these criteria have been modified by the update. Note that if such a learner decides to review the course module anyway, the new version will be displayed.
- By default, the update applies to all learners, which means currently enrolled learners that have already started the course, learners who are yet to start, and future learners. For these organizations, it is sometimes necessary to provide the same course content in different languages to ensure equal access to the content for each worker. In some countries, local regulations mandate that content be provided in the official language of the country.

For these reasons (plus all the ones not listed here), Captivate Prime supports delivering the same course content in various languages. Let's explore this feature hands-on:

## Retiring and deleting content

When a module is no longer relevant or undergoes a complete revision (possibly by a contractor other than the one who created the original version), it is necessary to remove this module from the Content Library. Retiring and deleting content may also be helpful as the number of authors, and therefore content, grows over time.

Captivate Prime does not allow you to *remove* the published content directly. You must first *retire* the content and only then can you remove it. Perform the following steps to retire an existing course module:

- 1. Make sure you are logged in as an Author and that you are on the **Content Library** page.
- 2. Use the checkboxes to select the course module(s) you want to retire.
- 3. Click the **Actions** button located in the top-right corner of the screen and choose the **Retire** action.

This action moves the selected module(s) from the list of *Published* modules to the list of *Retired* modules.

- 4. Click the **Retired** tab located above the list of modules, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_116_0.png)

Figure 3.23 – Click the Retired tab located above the list of modules

A retired module is no longer visible to Authors when creating a new course. However, existing courses that currently use the retired module *are not affected* by the retirement.

You will now *actually* delete the module(s) that you have previously retired.

- 5. While in the list of retired modules, use the checkboxes to select the modules you want to delete.
- 6. Click the **Actions** button located in the top-right corner of the screen.

Take note of the two actions that are available. **Republish** allows you to move the selected module(s) back to the **Published** list. This makes the module(s) available again when you're creating new courses.

- 7. Click the **Delete** action to delete the selected retired module.

Take some time to read the message that Captivate Prime displays on the screen. This message warns you that the content will be permanently deleted. But, at the same time, the deleted module continues to exist in the courses that currently use it. So, it has not actually been deleted from the system. A deleted module can no longer be used when creating new courses and can no longer be republished. It is only when all the courses using those modules will, themselves, be deleted that the module will be gone once and for all.

Thanks to this system, you can safely retire and delete modules without the risk of compromising the learning experience of learners currently enrolled in courses using the modules you retire/delete.

## Working with tags

As discussed in the Searching for content section earlier in this chapter, tags are keywords that are used to help the internal search engine of Captivate Prime index the content, making it easier to search for objects throughout the system.

Tags can be associated with a wide range of learning objects, including the course modules discussed in this chapter. By default, an administrator must create the tags before authors can associate them with the various learning objects they create in the system. This ensures that the tags available in your Prime account remain consistent (no typos, no duplicates, compliance with naming conventions, and so on).

You will now head back to the administrator area of Captivate Prime and create a handful of tags. Then, you will return to the Author role and see how tags can be linked to a course module:

- 1. Click the user icon in the top-right corner of the screen to reveal the list of available roles and return to the Administrator role.
- When Captivate Prime reloads, you should be back on the Administrator home page.
- 2. From the Admin home page, click the Tags link located in the Manage section of the left sidebar.
- This will open the Tag Management page of the administrator.
- 3. Click the Add button located in the top-right corner of the screen to open the Add a Tag dialog.
- 4. Enter the name of the tag you want to create. You can also create multiple tags at once by separating the tags with a comma, a semi-column, or a line break.
