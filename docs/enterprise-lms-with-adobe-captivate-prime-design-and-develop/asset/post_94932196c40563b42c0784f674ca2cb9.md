Note that in Prime, there’s a difference between interactive content and static content:

- **Static Content** is content in front of which the learner is mostly passive. Typical static content is made up of MP4 video tutorials, audio podcasts, and text documents.
- **Interactive Content**, on the other end, is content that makes the learner active. Typical interactive learning content includes quizzes, surveys, interactive videos, scenario-based training, and so on. This interactive content is created by dedicated eLearning authoring tools such as Adobe Captivate, Articulate Storyline, iSpring, and more, and it is uploaded to Captivate Prime as either SCORM-, AICC-, or xAPI-compliant packages.

## Uploading static content

It is now time to upload your first custom module to the Content Library. You will start by uploading static content in the form of a Word document, a PDF file, a PowerPoint presentation, and an MP4 video.

> **Getting access to content**
> To complete the exercises in this section of this book, feel free to use any file that is available to you. You can also use the sample files provided in the `courseContent` folder of the download associated with this book. Note that most of these sample files only contain placeholder text.

Let's start by uploading a Word document to the Content Library:

1. From the Author home page, click the **Create Content** button located in the topmost section of the main content area.

Remember that this action takes you to the **Add New Content** form. Note that there are only two pieces of information that are required: the **Name** and **Add Content File** fields.

2. Type in the name of the new module in the **Name** field.
3. Drag and drop a Word document into the **Add Content File** field. (You can use both the `.doc` and the `.docx` file formats.)

> **Tip**
> If you do not have a suitable Word document available, you can use the `courseContent/Theory of file extensions - Part 1.docx` file of the download associated with this book.

4. As a best practice, take some time to enter a meaningful description in the **Description** field (max 400 characters) and a duration (in minutes) in the **Duration** field.

Note that the **Duration** field is used for informational purposes only, so that learners know what to expect, but it has no other impact on how content is delivered by Captivate Prime.

The last remaining field is the **Tags** field at the bottom of the form. At this time, you should not be able to add any tags as these must be defined beforehand by an Administrator.

The **Add New Content** form should now look as follows:

You are now ready to save your new module to the Content Library.

5. Click the **Save** button, located in the top-right corner of the screen.

This takes you back to the Content Library, where you should see your new module at the top of the list. Note that your new module is not immediately available. Captivate Prime needs to process the new content before it is made available.

6. Click your new module when Captivate Prime has finished processing it.

Processing times vary based on various factors, such as the file type, size, and complexity.

This last action reopens the form you used to upload the module a few minutes ago. Note that a new section has appeared at the bottom of the page, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_88_0.png)

This new section contains additional options that depend on the content type being uploaded. That's why these options can only be made available after Prime has finished processing the content.

In the case of static content, these additional options allow you to set the Completion Criteria. The completion criteria instructs Captivate Prime about when the content is considered complete. This is very important as Prime can be set to give access to the next module of a course, but only when the previous module has been completed. Captivate Prime also uses the Completion Criteria property of each module that makes up a course to determine if a badge can be awarded, if a skill has been achieved, if a certification has been passed, and so on:

- If you leave Completion Criteria to its default value of On Launching Content, this means that the module is considered complete as soon as the learner opens the Word document.
- If you want to make sure the learner spends time reading the document, you can change Completion Criteria to Based on the Minimum percent required and specify a minimum percentage. For example, if you set a minimum percentage of 50%, that means this module is considered complete when the learner has reviewed at least 50% of the document.

## Setting a completion criteria

As an instructor, it may be tempting to always set the completion criteria to 100% to make sure that the whole content is reviewed by every learner. In practice, though, this may not always be a good idea. In the case of a Word document, for example, the learner can read the whole document without actually scrolling to the very end (especially if the document is very short). In such a case, the module will not be reported as completed by Captivate Prime, even though the learner has reviewed 100% of the relevant information contained in the file. To circumvent this issue, some authors set completion criteria around 90%, though in my opinion, the completion criteria for a static text-centric document can be left to the default value of On Launching Content.
