# Reviewing the Administrator options

Back in *Chapter 2, Customize the Look and Feel of Captivate Prime*, we discussed the differences between the **Classic** learner experience and the **Immersive** learner experience, and we customized the content that was available on the learner home page. Let's quickly review these options and make sure that you are ready for the exercises of this chapter:

+   1. Use the browser window in which you are logged in as an administrator.
+   2. From the administrator home page , click the **Branding** link located in the **Configure** section of the left sidebar.
+   3. Scroll down the **General** page until you can see the **Homepage Experience** option.
+   4. Click the **Edit** link associated with the **Homepage Experience** option. This enables all the options that are located at the bottom of the **General** page, as shown in the following screenshot:

![](bbox=[0.1, 0.42, 0.85, 0.62])

Figure 13.1 – The Homepage Experience section of the Branding page

5. Make sure **Homepage Experience** is set to **Immersive**.

As a reminder, the immersive experience was introduced in the December 2020 update. It has been designed as a Netflix-like interface displaying personalized recommendations to each learner. We discussed this in the *Customizing the learner experience* section of *Chapter 2, Customize the Look and Feel of Captivate Prime*.

6. Make sure the **Training Type** option is currently set to **Custom**.
