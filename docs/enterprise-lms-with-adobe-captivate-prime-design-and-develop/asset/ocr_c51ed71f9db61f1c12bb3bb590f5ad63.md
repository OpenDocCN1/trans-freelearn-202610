3. Use your mouse to reduce the width of your browser window. As you do so, notice how the learner home page adapts to the new size. As discussed in *Chapter 2, Customize the Look and Feel of Captivate Prime*, the default learner home page is *responsive*.

> **Responsive design**
> *Responsive design* is a design and development technique used across the web industry to create pages that can adapt to any screen size, allowing a website to be visited from virtually any device. # Reviewing the Learner home page

You have already reviewed the options related to the learner home page from an administrator perspective in *Chapter 2, Customize the Look and Feel of Captivate Prime*. Keep in mind that there are two layouts available for the home page: the *classic* layout and the *immersive* layout. The immersive layout was introduced with the December 2020 update and is the default layout used by new Captivate Prime accounts. Older accounts (prior to December 2020) use the classic layout by default. These accounts may still be using the old classic layout, as switching from classic to immersive must be done manually by an administrator.

These options are available from the **Branding/Learner Homepage** page of the administrative application.
