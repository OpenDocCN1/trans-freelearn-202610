## Creating internal and external users

Organizations use Captivate Prime to train their employees, but also their customers, partners, suppliers, contractors, franchisees, and more. This is the reason why Prime recognizes two main types of users: internal users and external users:

- **Internal users** are the employees of the organization. Depending on their role, these users can take advantage of all the features Captivate Prime has to offer.
- **External users** are not part of the organization, but they need access to your LMS. These users have limited access to your account.

There are a few key differences between internal and external users. They all relate to the fact that external users have limited access to your account:

- External users can be assigned the Author and Manager roles, but they cannot be Administrators or Integration Admins.
- Gamification is not available for external users. Gamification will be discussed in *Chapter 11, Badges and Gamification.*

Apart from these few differences, Captivate Prime offers the same learning experience to both internal and external users.

It is possible to provide different learning content to internal and external users using different learning catalogs. For example, courses dedicated to partners or contractor onboarding should only be visible to external users, while courses dedicated to the organization's internal tools and applications should only be visible to internal users. This will be covered in *Chapter 14, Working with Catalogs and Peer Accounts.*

In the next few sections, you will review various ways of creating internal and external users.

## Creating a single user

The first way to create internal users is to use the Single User option, which allows you to create one user at a time. You will use this option to create a new learner that you will name Learner 01 by performing the following steps:

1. From the Internal Users page of the Admin application, click the Add button located in the top-right corner of the screen.
2. In the menu that opens, click the Single User option. This will open the Add User form.
3. Type Learner 01 in the Name field.
4. Enter the email address that you have created for Learner 01 in the E-Mail field. Note that Name and E-mail are the only two required pieces of information.
5. Type Marketing Specialist in the Profile field.
6. Leave the Manager's Name field empty at the moment.
7. When ready, click the Add button located in the bottom-right corner of the form.

Take some time to read the message that appears on the screen. It tells you that the user has been successfully added and that Captivate Prime has sent a verification email.

8. Click the Close button to close the message and return to the Internal Users page.
