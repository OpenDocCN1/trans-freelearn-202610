Most of these links are the same as those available for courses. Notice, for example, the **Instances** link, which allows you to create instances of a learning program and map them to course instances. This will be discussed in the *Creating flexible learning programs* section, later in this chapter.

# Adding courses to a Learning Program

A learning program being a bundle of courses, the most important step in creating one is choosing the courses that are part of it. This section picks up from where the previous section left off: you should be on the **Courses** page of the learning program you started creating in the previous section, as shown in the following screenshot:

![](bbox=[0.12, 0.38, 0.84, 0.64])

Figure 6.11 – The Courses page of the Mastering Adobe Photoshop learning program

Perform the following steps to add courses to your learning program:

+   1. Switch to the **Catalog** tab of the **Courses** page of your learning program (see the arrow in the preceding screenshot).
+   2. If needed, search for the desired courses using the **Search** field in the top-right corner of the screen and/or the **Skills** and **Sort By** filters available in the top-left corner of the screen.
+   3. When you spot a course you want to add to the learning program, hover over the lower area of the course card and click the **Add** link.
