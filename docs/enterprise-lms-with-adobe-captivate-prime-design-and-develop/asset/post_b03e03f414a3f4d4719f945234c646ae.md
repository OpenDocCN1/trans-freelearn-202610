
## Adding Content Modules to Folders

Creating Content Folders is a task devoted to a Prime administrator, but putting modules into folders is part of the Author role:

- 1. Go back to the Author role and click the Content Library link located in the Manage section of the left sidebar.
- 2. Click the Add button, as if you wanted to add a new module to the Content Library.

As shown in the following screenshot, a new field is available in the Add New Content form:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_106_0.png)

Figure 3.15 – The Add to Folder field is available after you define Content Folders in your Prime account

Now, let's take a closer look at this field to discover how to attach new modules to a Content Folder.

- 3. Click the Search area associated with the Add to Folder field.

This reveals the list of all the available Content Folders. You should recognize the folders you created when you were logged in as an Administrator. If you do not want to add this new course module to a specific folder, choose the Public folder, which is the default folder that's visible to all the users of your Prime account.

Now, let's review how you can add existing course modules to a Content Folder. To do so, you need to return to the main Content Library page.

- 4. Click the Cancel button in the top-right corner of the form to return to the Content Library page.

Back on the main Content Library page, you should see a new Folders column in the list of available modules. Currently, all the modules should be in the Public folder by default. Above the list of modules, there are also two additional filters (Folders and All Authors) that have appeared since you created Content Folders while logged in as an administrator.

You will now try to move one of your custom modules into one of the folders that you created earlier.

- 5. Use the checkboxes column to select one of the available modules.
- 6. With one module selected, click the Actions button located next to the Add button in the top-right corner of the page.

As shown in the following screenshot, an Organise Content option containing additional sub-options is displayed in the Actions menu. Unfortunately, these options are not available, even though a module has been selected:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_107_0.png)

Figure 3.16 – Organise Content options are not available in the Actions menu by default

To enable the **Organise Content** options of the **Actions** menu, it is necessary to use the **Folders** filter located above the modules list.

- 7. Open the **Folders** filter and select the **Public** folder from the drop-down list.

This action filters the list of modules to show only the modules in the **Public** folder. Since, at this time, all the modules are in the **Public** folder, nothing changes on the screen.

- 8. If needed, you can also add a **Type** filter to show only the **Unused** content, or the **All Authors** filter to show only the modules that *you* have uploaded.

- 9. Use the checkboxes to select all the modules you uploaded earlier in this chapter.

- 10. Return to the **Actions** button located in the top-right corner of the screen. Since the **Folder** filter is active, the **Organise Content** option is now available.

- 11. Select **Organise Content – Move Contents to Folder** to open the **Move Content** dialog box.

- 12. Use the **Search** field to search for the name of the destination folder. Once found, click the folder's name in the drop-down list.

Note that you can add the selected module(s) to more than one destination folder if needed.

- 13. When ready, click the **Confirm** button in the lower-right corner of the **Move Content** dialog. A quick message should confirm that the move operation has been successful.

- 14. When done, click the **Clear** link to remove all the active filters and return to the full list of modules available in the Content Library.

This is how you can move new and existing modules into folders. If you return to the Organise Content item of the Actions button located in the top-right corner of the screen, you will see that two more operations are available:

- **Copy Content to Folder** is somewhat of a misleading label. Remember that Content Folders are just logical containers. The module is stored only once on the system and then linked to one or more of these folders. Copying content to a folder simply means that you link a module to at least one more folder, but there is no actual copying of the content involved. In other words, you do not consume any more disk space after this "copy" operation.
- **Unlink Folder** is used to remove the link between a content module and one or more folders. Note that the content must exist in at least one folder, so you cannot use the Unlink Folder operation on the modules that are linked to only one folder.

Moving existing modules into folders can be very helpful for organizing content as your Captivate Prime authors and usage grows over time!

## Creating new versions of your content

There are numerous instances where one or more modules need to be updated:

- Someone finds a bug (such as a typo, a content issue, and so on) in one of your modules.
- Your organization updates its brand identity (logo, color guide, and so on), which triggers older course modules being updated.
- A new policy or a legal change needs to be implemented in a compliance course or certification.
- A third-party vendor has made enhancements or improvements to popular content and has made the update available to you.
- Etc.

Captivate Prime has a built-in versioning system that makes uploading new versions of your modules a breeze. Let’s take a look at it:

> **Tip**
> If you want to follow along but do not have access to any suitable file, you can use the `courseContent/Theory of file extensions - Part 1 - Version 2.docx` file from the download associated with this book. If you use that file, you will update the course module associated with the Word document that you created earlier in this chapter.

- 1. Make sure you are logged in as an Author and that you are on the author home page.
- 2. Click the **Content Library** link located in the **Manage** section of the left sidebar to open your **Content Library**.
- 3. Once on the **Content Library** page, click the module that you want to update.
- 4. Click the **Edit** button in the top-right corner of the page.

To update a module, you need to remove the current file that is associated with your module and replace it with a new version of that file.

- 5. Click the *delete* icon associated with the file currently loaded in the **Add Content File** field to remove the current file from the module, as shown in the following screenshot:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_111_0.png)

Figure 3.18 – Remove the file currently associated with the module you want to update

The next operation is to upload the new file.

- 6. Drag and drop the new version of the file into the **Add Content File** field. You can also take this opportunity to make further changes to this course module if necessary.

- 7. When ready, click the **Save** button located in the top-right corner of the screen.

This action takes you back to the Content Library, where you can see that Captivate Prime is currently processing the new version of your module. When Prime has finished processing your updated module, version 2 of your course module is made available in the Content Library, as shown in the following screenshot:
