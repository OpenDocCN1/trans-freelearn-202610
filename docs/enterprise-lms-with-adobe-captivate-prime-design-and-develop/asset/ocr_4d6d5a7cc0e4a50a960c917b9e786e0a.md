Let's experiment with uploading a SCORM-compliant .zip package to Captivate Prime hands-on:

+   1. Make sure you are logged in as an Author and that you are on the Author home page.
+   2. Click the **Create Content** button located in the top section of the main content area. You will be taken to the **Add New Content** page.
+   3. Type the name of your new module in the **Name** field. Remember that this information is required.
+   4. Drag and drop the .zip file of the SCORM package you want to upload on top of the **Add Content File** field. You can use any SCORM-compliant package you have access to. If you don't have access to any suitable package, you can use the course `Content/identifyingPhishing_scorm2004.zip` file provided in the download associated with this book.

> **Note**
> The SCORM package provided in the download was created with Adobe Captivate, but remember that it could have been created by any SCORM-compliant authoring tool.

+   5. As a best practice, take some time to also fill in the optional **Description** and **Duration** fields.
+   6. Once you have finished filling out the form, click the **Save** button in the top-right corner of the page.

Clicking the **Save** button takes you back to the Content Library, where you can see that Captivate Prime is processing your new course module. So far, the process of uploading an interactive SCORM-compliant module to the Content Library is the same as the process of creating a static module.

+   7. When Captivate Prime has finished processing your new module, click its name to reopen the form.
