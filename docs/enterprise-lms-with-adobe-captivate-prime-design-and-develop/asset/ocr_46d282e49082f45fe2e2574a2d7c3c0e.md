You can use learning plans to automatically enroll learners in *courses*, *learning programs*, and *certifications*. Automatic enrollment of learners is triggered by an event that's chosen when the learning plan is created. Learning plans are very useful in many situations, including the following:

+   - You want to automatically enroll new learners in onboarding courses.
+   - You want to automatically enroll learners in courses when they join or leave a group. For example, when someone becomes a manager (that is, when he/she joins the self-generated **All Managers** group), that person is automatically enrolled in a course on *Management Best Practices*. You can use the same technique to automatically enroll learners when they change position, move to a new department, and so on.
+   - You want to ensure that users are only enrolled in a given course once they have completed a previous course. This is one of the ways to ensure that prerequisites are met.
+   - You want to automatically enroll learners in courses on a certain date. For example, you need to train people when a new product is released, after an organization acquisition has been made official, or when a new branch opens.

These are only some of the situations where learning plans are very useful. In this section, you will use a learning plan to automatically enroll every new learner in the **Certified Prime Learner** certification you created in the *Creating certifications* section, earlier in this chapter.

Remember that a certification has a time limit for completion. In this example, you have given learners 30 days to complete this particular certification. Adding the training plan to the mix allows you to ensure that each new learner completes a basic course on how to use Captivate Prime within 30 days of registration. The idea is to maximize the learners' use of the platform and provide them with the most compelling learning experiences possible.

Now, let's create a learning plan by performing the following steps:

+   1. Make sure you are logged in as an administrator.
+   2. From the administrator home page, click the **Learning Plans** link located in the **Learning** section of the left sidebar. This takes you to the **Learning Plans** page, where a list of all available learning plans, if any, is displayed.
+   3. Click the **Add** button in the top-right corner of the page to start creating a new learning plan.
+   4. Type `New Learner Prime Certification` in the **Learning Plan Name** field.
+   5. Open the **Occurs When** drop-down and inspect the list of available events.
