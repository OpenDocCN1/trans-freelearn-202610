# Accessing L1 and L3 feedback data

Remember that L1 and L3 feedback are collected at the course instance or learning program instance level. So, to access this data, you need to access the course or learning program whose feedback you want to review. Let's take a look at this workflow hands-on using the following steps:

+   1. Log in to your Prime account as an administrator.
+   2. From the administrator home page, click the Courses link located in the Learning section of the left sidebar.
+   3. Hover over the course card of the course whose data you want to review.
+      In this example, choose the Color Masterclass: Simple Steps to Create Vivid Art course, or any other course for which you provided L1 feedback earlier in this chapter.
+   4. Click the View Course link to access the course overview page.
+   5. Click the L1 Feedback link located in the Reports section of the left sidebar.
+   6. If the course has multiple instances, use the Select Instance drop-down list to select the course instance of the course for which you want to review L1 feedback.
