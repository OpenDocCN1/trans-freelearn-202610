# Providing the necessary session details

In this section, you will continue creating the course instance you started in the previous section by providing the necessary details for the different sessions. The following exercises pick up where the previous section left off. Follow these steps to provide the necessary session details:

+   1. From the Instances page of your course, locate the course instance you started to create in the previous section.
+   
+   Notice the instance properties that are visible at a glance. This includes the number of Modules in the course, the number of Learners Enrolled in this course instance, the number of Sessions that you must provide details for, Badges associated with this course instance, and so on.

+   2. Click the Modules link in the properties of your course instance to open the list of modules. This operation is illustrated in the following screenshot:

![](bbox=[0.121, 0.475, 0.845, 0.803])

+   3. If the modules in this course have more than one delivery type, this is where you can choose, for each module, the delivery type that will be used in this course instance.
