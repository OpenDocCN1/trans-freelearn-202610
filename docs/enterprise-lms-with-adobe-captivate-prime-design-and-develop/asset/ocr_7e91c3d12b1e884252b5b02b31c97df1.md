+   - Under the masthead, you find the **My Learning List** section. This is where the courses you are currently taking are displayed. This section of the home page is just a summary of the **My Learning** page that you will review later in this chapter.
+   - Under the **My Learning List** section, you'll find a row containing various items. The **LEVELS** item is related to the **gamification** features of Captivate Prime. You will learn more about gamification in *Chapter 11, Badges and Gamification.*
+   - The next item is a calendar where the day's activities are displayed. If you select the date of a scheduled live class you are enrolled in, you will see the class activity listed in the calendar with a link to access it directly. This is illustrated in the following screenshot:

+   - The **SOCIAL FEED** item is related to the **social learning** features of Adobe Captivate Prime. You will review these features in *Chapter 12, Enabling and Managing Social Learning.*
+   - Scrolling down the page, you'll find the **Recommended based on your areas of interest** section. This section is based on the **skills** defined in Captivate Prime. In *Chapter 4, Creating Skills and Courses*, you learned how to create skills and how to associate them with courses. Your *areas of interest* are based on these skills. It can be the skills covered by the courses in which you have (or previously have been) enrolled, the skills that have been assigned to you by an administrator, or the skills that you can choose for yourself using the **Skills** page of the learner experience, which you will review later in this chapter.

This section is different for each user and depends on different factors that you will examine in more detail in *Chapter 13, AI-Powered Recommendations for Learners.*
