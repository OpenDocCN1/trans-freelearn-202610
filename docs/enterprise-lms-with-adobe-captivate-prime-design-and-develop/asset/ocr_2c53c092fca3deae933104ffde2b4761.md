There is one more important thing to observe regarding these two new users.

+   13. Click on one of the two Unregistered users. This opens the details of the user you clicked on.
+   14. Notice that you are defined as the user's Manager.

When you import users using a CSV file, a manager is always defined for the users you import. If you do not provide this information in a dedicated column of the CSV file, the value of the Manager field is automatically set to one of the platform administrators. For this to be possible, it is necessary that the chosen administrator be part of the CSV file and that they are defined before the users to be created. This is the reason why you had to add yourself in the first row of the CSV file.
