+   2. Hover over the **Mastering Photo Editing** learning program's card.
+      (If the **Mastering Photo Editing** learning program is not available on your Prime account, feel free to use any other learning program or course available to you.)
+   3. Click the **View Learning Program** link to open the learning program **Overview** page.
+   4. Click the **Instances** link located in the **Manage** section of the left sidebar.
+   5. Click the **Badges** link associated with the instance you want to modify.
+      In the case of the **Mastering Photo Editing** learning program, only the default instance is available.
+   6. Toggle the **Enable Badge** switch to on.
+   7. Open the **Choose from the following Badges** drop-down menu and choose the **Photo Editing Master** badge you created earlier in this section.
