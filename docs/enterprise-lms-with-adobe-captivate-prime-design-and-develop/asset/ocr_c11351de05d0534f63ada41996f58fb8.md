# Discovering the migration process

If your organization already has an LMS, the migration process will help you migrate the training data and content that exists in your current LMS to Captivate Prime.

To initiate a migration project, you must contact the Captivate Prime support team, who will activate the functionality in your account.

Basically, the migration process uses the following main steps:

+   - First, you need to export the data from your current LMS to .csv files.
+   - Next, you must match the information exported from your current LMS with the information expected by Adobe Captivate Prime. The Adobe Captivate Prime support team will help you by providing the necessary technical information on how to prepare the data so that it imports flawlessly into Captivate Prime.
+   - Finally, you must use the migration wizard available in the integration admin experience to import the data in Adobe Captivate Prime. This must be done in a certain order and data integrity checks must be performed throughout the entire process. Once again, the Captivate Prime support team will help you get through this process and troubleshoot any issues that may arise.

To learn more about the migration process, please refer to the migration manual in the official Adobe Captivate Prime user guide at https://helpx.adobe.com/captivate-prime/user-guide.html/captivate-prime/integration-admin/feature-summary/migration-manual.ug.html.
