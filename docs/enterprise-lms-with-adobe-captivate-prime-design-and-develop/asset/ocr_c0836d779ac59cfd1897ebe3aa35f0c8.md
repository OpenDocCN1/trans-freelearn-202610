# Taking a course while offline using the mobile app

In the previous section, you had a first look at the process of taking a course using the mobile app. In this section, you will use another feature of the app, namely the ability to download a course and review it offline. The course tracking data is transferred to Captivate Prime the next time you connect to the internet:

+   1. Make sure you are logged in as *Learner 03* using the Captivate Prime mobile app.
+   2. From the home page, tap the course card of the **Fundamentals of cybersecurity** course (make sure you do *not* tap the **Start** button in the lower-right corner of the course card).
+      This action takes you to the course overview page.
