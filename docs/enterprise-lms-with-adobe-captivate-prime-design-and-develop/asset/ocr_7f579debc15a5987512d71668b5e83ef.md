# Reviewing File Submission Assignments

In addition to conducting face-to-face or virtual classes, instructors are also responsible for reviewing the material uploaded by learners using the file submission activity. As discussed in Chapter 4, Creating Skills and Courses, the file submission activity is one of many types of modules that can be added to a course. When using this activity in a course, you must define the instructor(s) responsible for reviewing the uploaded content. Also remember that the designated instructor(s) can be different for each course instance, as covered in Chapter 6, Enrolling Users to Courses.

It is now time to review the workflow used by instructors to download the learner's assignment, review it, and grade it:

+   1. Make sure you are logged in as an instructor to your Captivate Prime account.
+   2. From the instructor home page, click the Submissions/Checklists link located in the Modules section of the left sidebar.

This takes you to the Modules page of the instructor experience. From here, instructors can review their assigned File Submission and Checklist activities.
