## Exploring the My Learning page

The **My Learning** page lists all courses, learning programs, and certifications in which the learner is enrolled. From this page, the learner has a complete overview of all the learning resources they are taking or have taken.

Use the following steps to access the **My Learning** page:

- 1. Click the hamburger icon (the icon with the three horizontal bars) located in the top-left corner of the screen. This action reveals the labels associated with each of the icons on the left sidebar.
- 2. Take some time to read these labels and memorize the meaning of each icon.
- 3. To access the **My Learning** page, you can use the second icon from the top. If you are on the learner home page, you can also click the **Go to My Learning** link located in the **My Learning List** section of the home page.

Once on the **My Learning** page, you should see a list of all the courses, learning programs, and certifications *Learner 01* is enrolled in. The **job aids** accessed by this learner (if any) are also displayed here. Notice the **Sort By** dropdown, in the upper-right corner of the screen, as well as the checkboxes in the left column used to filter the list of learning content displayed on the page.

Figure 7.3 – The My Learning page of the learner experience

Note that, by default, the courses displayed on this page are sorted by Due Date. This allows learners to focus their immediate attention on the courses with the closest due date. Also notice the Status checkboxes (not displayed in the preceding screenshot) located at the end of the left column. These allow learners to filter the list in order to see only the Completed courses, the In Progress courses, or the Yet To Start courses.

The My Learning page is a great tool, especially for long-time learners who have a lot of past, present, and future learning activities to display. In the next section, you will briefly review the Catalog page of the learning experience.

## Exploring the Catalog Page

The primary purpose of the Catalog page is to allow learners to self-enroll in courses. Indeed, as already discussed in Chapter 6, Enrolling Users to Courses, the primary means for a learner to register for a course is through self-enrollment.

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_275_0.png)

To access the Catalog page, use one of the following two ways:

- You can click the Catalog icon, which is the third icon from the top in the left sidebar.
- If you are on the learner home page, you can also use the Go To Catalog link located in the Recommended based on your areas of interest section.

At first glance, the Catalog page looks very similar to the My Learning page discussed in the previous section. Indeed, the tools available on the Catalog page are mostly the same as those available on the My Learning page:

- There are checkboxes on the left-hand side allowing you to filter the list of visible learning objects.
- In the upper-right corner of the list, the Sort By dropdown allows you to sort the items visible on the page. Notice that, by default, the sort order is set to Recently Published, which displays the latest addition to the catalog at the top of the list.

The primary difference between the My Learning page and the Catalog page is that the Catalog page lists all the courses, learning programs, certifications, and job aids available in the catalog, while the My Learning page only lists the learning object the learner is enrolled in. Another way to explain this is to say that My Learning is the list of Must-take trainings because the learner is already enrolled in the trainings listed on that page, while the Catalog page is a list of Could-take trainings since it offers a menu to self-enroll.

From the Catalog page, learners can get information about the learning objects they have access to. They can also enroll in courses or send an approval request to their manager depending on the enrollment option of the course.

### Working with multiple catalogs
You currently have a single catalog in your Prime account. Therefore, all learning objects are in the same catalog, which is accessible to all learners.
In Chapter 14, Working with Catalogs and Peer Accounts, you will learn how to create additional catalogs, how to place learning objects in them, and how to define which learners have access to a given catalog. This will allow you to control which learning objects each learner has access to.

Using the catalog to self-enroll in courses has already been discussed in Chapter 6, Enrolling Users to Courses, so you will move on to reviewing the Social Learning page of the learner experience in the next section.

## Reviewing the Social Learning page

The next page of the learning experience is the **Social Learning** page. To access this page, it is necessary to click the **Social Learning** icon, which is the fourth icon from the top in the left sidebar.

This page is where learners can interact with their peers in an informal way similar to what is found on social networks. The social learning features of Captivate Prime will be discussed in *Chapter 12, Enabling and Managing Social Learning*. Note that administrators can decide to completely turn off the social learning features of Captivate Prime. In such cases, the **Social Learning** icon does not appear in the left sidebar and the page is not available to learners.
