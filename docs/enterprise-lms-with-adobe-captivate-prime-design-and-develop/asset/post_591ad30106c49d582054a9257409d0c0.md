
As a reminder, a learning program is a set of related courses. When learners enroll in a learning program, they actually enroll in all the courses included in the learning program. Creating learning programs has been discussed in *Chapter 6, Enrolling Users to Courses.*

Let's review the options pertaining to L1 and L3 feedback for learning programs using the following steps:

- 1. Log in to your Prime account as an administrator.
- 2. From the administrator home page, click the **Learning Programs** link located in the **Learning** section of the left sidebar. This takes you to the list of available learning programs in your Prime account.
- 3. Hover over any learning program available on the list.

If you have performed the exercises of *Chapter 6, Enrolling Users to Courses*, choose the **Mastering Photo Editing** learning program. Remember that this particular learning program consists of two courses: one course on Adobe Photoshop and another one on Adobe Lightroom.
- 4. Click the **View Learning Program** link to open the learning program overview page.
- 5. Next, click the **Instances** link located in the **Manage** section of the left sidebar.

Just like courses, learning programs also have instances. A default instance is automatically created each time you define a new learning program. Most of the time, this default instance is all you need, but there are situations where it is useful to define additional learning program instances. This has already been discussed in *Chapter 6, Enrolling Users to Courses.*

- 6. Click the **Feedback Enabled** link of the default learning program instance to open the L1 and L3 feedback options.

As depicted in the following screenshot, the available options are similar to those available for course instances, with a few important differences:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_346_0.png)

Figure 9.11 – L1 and L3 feedback options for learning programs

There are three toggle buttons in the preceding screenshot and, by default, all three are turned off. The available options reflect the fact that learning programs are made up of several courses. This means that some (or all) of the courses included in the learning program may already have L1 and/or L3 feedback enabled for their respective instances. Let's see how the feedback options for each course interfere (or not) with the feedback options for the learning program as a whole:

- When toggling the **Enable for Learning Program** button on, you activate L1 feedback for the entire learning program. This means that the learner will be asked to fill out an L1 feedback form *once* after completing *all the courses* included in the learning program.

- If you want to also enforce the L1 feedback options for each course included in the learning program, you must also toggle on the **Enable for Each Course** button.
In such a case, if the courses included in the learning program have L1 feedback enabled, the learner will *also* be prompted to fill out an L1 feedback form for these courses *in addition to* the L1 feedback form of the whole learning program. Note that if none of the courses included in the learning program have L1 feedback enabled, this button *has no effect*. It is important to understand that this button does *not* activate L1 feedback for each course. It simply tells the learning program to apply what is defined at the course level *in addition to* what is defined at the learning program level. It is also worth mentioning that this button only applies to L1 feedback, not to L3 feedback.
- Toggling on **L3 Behavior Change Feedback** enables L3 feedback for the learning program as a whole. Note that if a course contained in the learning program already has L3 feedback enabled, Captivate Prime does *not* honor course-level L3 feedback. Only the L3 feedback of the learning program is observed. This is to prevent busy managers from receiving too many L3 feedback requests when their team members are enrolled in learning programs.

Take the necessary time to review the available options. After the discussions of the previous sections and chapters, they should be self-explanatory. When ready, return to the administrator home page.

You have also learned how to submit L1 feedback as a learner, and how managers can submit L3 feedback when their team members have completed a course.

## Retrieving L1, L2, and L3 Feedback

Gathering data is only the first step. The most important thing is to be able to access and use the data in order to generate meaningful reports and make informed business decisions.

To review L1, L2, and L3 feedback data, you must be either an administrator or a manager. The difference between these two roles is that administrators have access to all the data available on the platform while managers only have access to the data pertaining to their team members.

In this section, you will log in to your Captivate Prime account as an administrator and review how you can access the L1, L2, and L3 feedback data available.

### Accessing L1 and L3 feedback data

Remember that L1 and L3 feedback are collected at the course instance or learning program instance level. So, to access this data, you need to access the course or learning program whose feedback you want to review. Let's take a look at this workflow hands-on using the following steps:

- 1. Log in to your Prime account as an administrator.
- 2. From the administrator home page, click the Courses link located in the Learning section of the left sidebar.
- 3. Hover over the course card of the course whose data you want to review.
In this example, choose the Color Masterclass: Simple Steps to Create Vivid Art course, or any other course for which you provided L1 feedback earlier in this chapter.
- 4. Click the View Course link to access the course overview page.
- 5. Click the L1 Feedback link located in the Reports section of the left sidebar.
- 6. If the course has multiple instances, use the Select Instance drop-down list to select the course instance of the course for which you want to review L1 feedback.

This opens the course L1 Feedback page, as shown in the following screenshot:
