In this section, you configured a workflow that automatically imports new and updated users into your Prime account once a day from a CSV file that's been uploaded to the Extravault FTP service. All you need to do now is configure your internal user directory to export the CSV file once a day to the Extravault account, a few moments before Captivate Prime is scheduled to import the data.

This illustrates one of the possible approaches to integrating Captivate Prime with virtually any user directory solution that's used in your organization.

> **Automatic and manual CSV uploads are not compatible**
> Since you have configured a data source, manually importing CSV files using the process described in the *Importing users from a CSV file* section, earlier in this chapter, is no longer possible.
