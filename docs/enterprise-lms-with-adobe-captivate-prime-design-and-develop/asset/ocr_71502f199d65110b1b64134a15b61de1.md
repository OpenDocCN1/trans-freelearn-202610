# Creating Flexible Learning Programs

As discussed in the Creating course instances section, earlier in this chapter, learners do not enroll in courses but course instances. The same is true with learning programs. You can define instances for your learning programs, which is especially useful when one or more of the courses included in the learning program contains synchronous modules.

In this section, you will examine how course instances and learning program instances work together to give learners a smooth learning experience. The general workflow is as follows:

+   - Create several courses with multiple instances.
+   - Create a learning program and add some courses to it.
+   - Create instances of the learning program and map learning program instances to course instances.
+   - Enroll learners in the desired learning program instance.
