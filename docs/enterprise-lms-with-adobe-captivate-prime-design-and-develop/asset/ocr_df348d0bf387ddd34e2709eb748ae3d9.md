# Instances

An Instance allows you to offer a Course to different audiences at different times and locations. An Instance has its own Badges, feedback, and other settings. To create a new Instance of a Course click Add New Instance.

You will now enable L1 and L3 feedback for this course instance. Since it is the only course instance available for this particular course, it means you enable L1 and L3 feedback for the entire course.

+   6. Click the Feedback Enabled link, identified by the arrow in the preceding screenshot. This opens the feedback options for this particular course instance.

+   7. Toggle L1 Reaction Feedback on. This action displays a few additional options on the screen.

+   8. Type Do you have any other comments or suggestions about this course? In the Question 1 field.

```
Do you have any other comments or suggestions about this course?
```

Take some time to examine the other options available, but don't change any of them at this time.

+   9. Scroll down the page and also toggle L3 Behavior Change Feedback on.

Take the necessary time to examine the available L3 feedback options. Notice the question stem that is already present in the Question 1 field as well as Answer Format, which is set to Likert Scale. Also note that the Question 2 field is empty by default. Make sure you don't change any of these options at this time.
