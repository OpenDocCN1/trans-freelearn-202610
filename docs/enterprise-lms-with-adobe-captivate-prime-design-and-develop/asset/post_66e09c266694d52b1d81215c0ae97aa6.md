## Uploading user data with the Prime FTP connector

Captivate Prime is now ready to accept the CSV files that have been exported by your organization's directory to create and sync internal users. In this section, you will explore the CSV file that you will upload, get it ready, and upload it to Extra vault FTP by performing the following steps:

- 1. Open the users/importUsers.csv file using the spreadsheet application installed on your system.

As shown in the following screenshot, the CSV file contains seven columns and five rows of users (in addition to the header row at the top of the file). Normally, all these users are already present in your Prime account:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_210_0.png)

Figure 5.21 – The users/importUsers.csv file, as seen in a spreadsheet application
(Apple Numbers, in this example)

Before uploading this CSV file to ExtraVault’s FTP, it is necessary to adjust some of the data it contains. Note that these adjustments are only necessary because of the educational situation that this book has placed you in. When using this workflow in production, such adjustment is not needed.

- 2. Type your name in cell A2, your Prime admin email address in cell B2, and your city in cell F2.
- 3. Add the email addresses of all four remaining users in the Employee eMail column.
- Make sure you use the same email addresses that you used when you created these users earlier in this chapter.
- 4. Enter your Prime admin email address in cells G3 and G6. This means that you are defined as the manager of both Manager 01 and Instructor 01.
- 5. Enter the email address of Manager 01 in cells G4 and G5. This defines Manager 01 as the manager of both Learner 01 and Learner 02.

This configuration defines a three-level hierarchy where you are the General Manager and where Manager 01 manages a small team of two employees.

> **Defining managers**
> When importing the file, Captivate Prime reads it from top to bottom.
> Therefore, it is very important to define managers at the top of the file, before defining their team members: a user must exist in Captivate Prime before being defined as someone else’s Manager.

- 6. Save the CSV file when you're done.

> **Double-check the CSV file before uploading it**
> Remember that, depending on the regional settings of your system, the separator that's used in the CSV file may have been switched to a semicolon (;) instead of a comma (,). To fix this potential issue, open the CSV file in a text editor (such as Notepad on Windows or TextEdit on Mac) and use the *Find and Replace* feature of the text editor to replace all semicolons (;) with commas (,).

- 7. Open a new browser window and browse to https://primedev.extravault.com/.
- 8. Log in to your Extravault account using the username you received via email and the password you created earlier.
- 9. Once logged in, browse to the import/user/internal folder of your Extravault account.
- 10. Upload the users/internalUsers.csv file using either drag and drop or the Upload button in the top-right corner of the Extravault interface.

> **Note**
> When using this workflow in production, you will probably use an FTP client such as FileZilla to upload the CSV file to Extravault.

After completing this section, the CSV file will have been correctly uploaded to your Extravault account. The last step is to ask Captivate Prime to connect to your Extravault account and fetch this CSV file regularly. This is what you will do in the next section.

## Configuring a data source

There is one last piece you must configure for this workflow to be up and running. In this section, you will return to the administrator application and configure the periodic data import by Captivate Prime from your Extravault FTP account. Let's get started:

- 1. Make sure you are connected to your Prime account as an Administrator and that you are on the Administrator home page.
- 2. From the Administrator home page, click the Settings link located in the Configure section of the left sidebar. Then, click the Data Sources link located in the Integrations section of the left sidebar.

Once on the **Data Sources** page, you should see the Extravault FTP connection you configured in the previous sections listed as a data source, as shown in the following screenshot:

Note that if you configure additional connectors, such as a **Custom FTP** connection, a **Salesforce** connection, a **Workday** connection, and so on, these will appear as extra data sources on the **Data Sources** page.

- 3. Click the **Edit** link associated with your Extravault data source.
- 4. Select the **Enable Import** checkbox.
- 5. Also, select the **Enable Auto Sync** checkbox located in the **Sync Settings** section at the bottom of the page.
- 6. Click the **Sync Time** field and choose a suitable sync time.
- Typically, you would choose a time in the middle of the night, when you know few people are likely to be logged into your Prime account.
- 7. Finally, click the **Sync Now** link to trigger the synchronization process immediately. This allows you to test that everything is working correctly and that the daily automatic synchronizations are likely to succeed.
- 8. Don't forget to click the **Save** button in the top-right corner of the screen to save your changes.

After a few moments, you should receive a notification telling you that the CSV processing was successful, as shown in the following screenshot:

- 12. Click **Instructor 01** to open this user's details and confirm that you are the manager of this user.

In this section, you configured a workflow that automatically imports new and updated users into your Prime account once a day from a CSV file that's been uploaded to the Extravault FTP service. All you need to do now is configure your internal user directory to export the CSV file once a day to the Extravault account, a few moments before Captivate Prime is scheduled to import the data.

This illustrates one of the possible approaches to integrating Captivate Prime with virtually any user directory solution that's used in your organization.

> **Automatic and manual CSV uploads are not compatible**
> Since you have configured a data source, manually importing CSV files using the process described in the *Importing users from a CSV file* section, earlier in this chapter, is no longer possible.
