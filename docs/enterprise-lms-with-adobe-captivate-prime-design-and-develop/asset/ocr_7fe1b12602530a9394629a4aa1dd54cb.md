# Sharing Web pages

While browsing the internet, Learner 01 comes across the Wikipedia page on computer security. He/she finds it so insightful that he/she wants to share that page with the other learners participating in the Cybersecurity in the organization board.

This is such a common situation that Captivate Prime provides a unique mechanism that allows users to quickly post any URL they find interesting in any available discussion board.
