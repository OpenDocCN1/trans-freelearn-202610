Note that you can add multiple user groups to the filter as well as any combination of **Manager**, **Profile**, **User Group**, and **Content**. This allows a very large number of variations for this report.

+   9. Click the **Save** button located in the bottom-right corner of the **Add Report** dialog to add the reports to the default dashboard.

Thanks to the preceding steps, you have created an additional custom report that has been added to the default dashboard. Notice that you can use the same *date range* and *manager* filters discussed earlier to adjust the data displayed by the report. Remember that you may have thousands of users on your Prime account, so these filters are very handy in displaying just the data you want to see.

+   10. Click the drop-down arrow located in the top-right corner of the **Learning Time Spent for Internal Users** report.

The **Copy Report** dialog allows you to choose the dashboard you want to copy the report to. Since you have not created a custom dashboard yet, the only option available is to copy the report to the **Default Dashboard**.

+   12. Select the **Default Dashboard** option and click the **Copy** button.

A new custom report named **Copy of Learning Time Spent for Internal Users** appears on the default dashboard.

+   13. Click the drop-down arrow located in the upper-right corner of the **Copy of Learning Time Spent for Internal Users** report.
