
On this page, you can modify the default values that will be applied to all future course instances of the chosen course.

- 6. Toggle **L1 Reaction Feedback** on.
- 7. Type `Do you have any other comments or suggestions about this course?` in the **Question 1** field.
- 8. Scroll down the page and also toggle **L3 Behavior Change Feedback** on.

The other feedback-related options are exactly the same as those discussed in the *Enabling L1 and L3 feedback for a course instance* section earlier in this chapter.

- 9. Take some time to examine the other available options. Notice that you can also enable or disable badges by default.

Badges will be discussed in *Chapter 11, Badges and Gamification.*

- 10. When ready, click the **Save** button located in the upper-right corner of the screen.

From now on, any new course instance you create for this particular course will inherit the default values you just defined.

This is very useful to make sure that each course instance follows a basic set of rules and best practices. It also streamlines the creation of new course instances, making the job of administrators a little easier. Keep in mind that these are only default values. It means you can override these defaults for each new instance you create. In other words, Prime does not strictly enforce these settings when creating new instances. Also, the different values you just defined only apply to *future* course instances; existing course instances are not affected by these changes.

In the next section, you will review how you can activate L1 and L3 feedback by default on your Prime account and how you can customize the list of questions present on the L1 feedback form.

## L1 and L3 feedback at the account level

By default, L1 and L3 feedback are disabled on your Prime account. In previous sections, you learned how to enable L1 and L3 feedback for a specific course instance or by default for all future instances of a given course.

You will now review the L1 and L3 feedback options available at the account level. This will allow you to do the following:

- Turn L1 feedback on by default for any new course you create on your Prime account.
- Modify the questions displayed on the L1 feedback form.
- Modify when reminders are sent to learners (for L1 feedback) and managers (for L3 feedback).

Let's now review these items one by one in the following few sections.

## Turning L1 feedback on by default

Let's start by enabling L1 feedback by default on your Prime account using the following steps:

- 1. Log in to your Prime account as an administrator.
- 2. From the administrator home page, click the Settings link located at the end of the Configure section in the left sidebar.
- 3. Then, click the Feedback link located in the Basics section of the left sidebar.

As shown in the following screenshot, this takes you to the L1 Feedback tab of the Feedback Settings page:

![](img/5ceaefa2a9a737206c59f0b54e1a07d0_340_0.png)

Figure 9.7 – The L1 Feedback tab of the Feedback Settings page

- 4. Click the Edit link located in the upper-right corner of the screen.
- 5. Toggle the Enable L1 Feedback for newly created Course and Learning Program option on.
- 6. Click the Save button located in the upper-right corner of the screen.

From now on, new courses and learning programs you create on your Prime account will have L1 feedback enabled by default. It is important to keep in mind that this only affects *future* courses and learning programs. Existing courses and learning programs are not affected by this change.

> **Note**
> Like any other important change you make to such a workflow, it is important to communicate it properly to learners. After all, this additional feedback step is new to them as well. So, it is very important to tell learners that this feedback step is mandatory because many learners will ignore it if they have not been properly informed of the change.

It is also worth noting that L1 feedback is also available for learning programs. This will be discussed in more detail in a future section.
