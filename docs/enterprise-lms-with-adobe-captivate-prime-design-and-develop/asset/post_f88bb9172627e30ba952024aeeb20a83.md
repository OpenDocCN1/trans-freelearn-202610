
## Providing L1 Feedback as a Learner

Now that L1 feedback has been enabled for a course (actually, a *course instance*), you will log in to your Prime account as a learner, enroll in that course, and take it. If everything goes well, the system should prompt you to provide L1 feedback once you complete the course. Let's check this by using the following steps:

- 1. Open a new private window of your web browser (or use another browser altogether) and log in to your Prime account as *Learner 01*.
- 2. Once logged in, click the **Go To Catalog** link located in the **My Learning List** section of the learner home page.
- 3. Use the catalog features as described in *Chapter 6, Enrolling Users to Courses*, to enroll in the course for which you enabled L1 and L3 feedback in the previous section.

> **Tip**
> By default, courses are displayed from latest to earliest in the catalog, but don't hesitate to use the **Search** field in the upper-right corner of the screen to search for the appropriate course.

- 4. Once enrolled, the Fluidic Player opens and the course starts. Review all the modules included in the course. If using one of the courses available by default in a new Prime trial account, there should be no more than one or two videos to review.
- 5. When you have reviewed all the course material, close the fluidic player to return to the course overview page.

Now that you have completed the course as a student, it is time to provide L1 feedback. By default, *Learner 01* should receive an email from Captivate Prime asking him/her to provide L1 feedback for the course he/she just completed. A notification is also available in the notification area of Captivate Prime.

- 6. Click the notification icon located in the upper-right corner of the screen.

7. Click the **Provide Feedback** link for the course you just completed, as shown in the following screenshot:

## Providing L3 Feedback as a Manager

L3 feedback corresponds to the third level of Kirkpatrick's Four Levels model.
As a reminder, this is the Behavior level, which aims to measure whether the training leads to a change in learner's behavior once they return to their workplace.

In Captivate Prime, managers are responsible for submitting L3 feedback. After all, who better to measure a change in behavior after training than the employee's direct manager? Typically, L3 feedback should be submitted a few weeks after an employee has completed a training.

By default, Captivate Prime sends an email to an employee’s manager 45 days after course completion. This is why you will not be able to experiment with providing L3 feedback right away. The following screenshot illustrates the default L3 feedback form managers must complete. Now, let’s be honest! We all know that very few people log in to the LMS at the beginning of each workday. That’s why Captivate Prime also sends a reminder email to managers with a direct link to the appropriate L3 feedback form. In the previous few sections, you have reviewed the main principles behind L1 and L3 feedback. Let’s make a quick summary of what you have learned so far:

- L1 and L3 feedback are disabled by default on any new Prime account.
- Activating L1 and L3 feedback is done at the course instance level. This means that you can have some course instances with feedback enabled and other course instances of the same course with feedback disabled.
- By default, the L1 feedback form contains six predefined questions to which you can add up to two custom questions. This allows you to define questions specific to a course instance, such as questions about a specific instructor or a specific venue.
- L1 feedback is provided by the learner after course completion. L3 feedback is provided by the learner's manager. By default, L3 feedback is available to managers 45 days after a member of their team has completed a course.

In the next section, you will review the **instance defaults**, which allow you to define the default values of future course instances for a given course.

## Customizing Course Instance Defaults

Back in *Chapter 6, Enrolling Users to Courses*, you learned about course instances. Let's have a brief recap of what course instances are and what they allow you to do:

- Learners enroll in course instances rather than enrolling in courses per se.
- When creating a course, a default course instance is created along with it. This default instance is what learners actually enroll in. In most cases, this default course instance is sufficient.
- The main case where you want to create additional course instances is when the course includes time-limited synchronous activities, such as live or virtual class sessions. In such a case, course instances are what allow you to schedule multiple course occurrences with different instructors, in different locations, in different languages, and so on.

In previous sections, you learned that course instances are also the place where you decide to enable or disable L1 and/or L3 feedback.

In this section, you will examine how you can modify the default values of course instances. These default values apply to all the future course instances of a given course. Let's review this workflow hands-on using the following steps:

- 1. Log in to your Prime account as an administrator.
- 2. From the administrator home page, click the **Courses** link located in the **Learning** section of the left sidebar.
- 3. Hover over the course card for which you want to edit the default instance properties.
- 4. Click the **View Course** link to open the course overview page.
- 5. Next, click the **Instance Defaults** link located in the **Configure** section of the left sidebar.
