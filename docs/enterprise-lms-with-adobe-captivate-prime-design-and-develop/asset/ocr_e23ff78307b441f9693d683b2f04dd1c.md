This report provides information on the trainings of your Prime account that are considered *active*. Active trainings are trainings that are enrolled, viewed in the Fluidic Player, or completed within the given timeframe. By default, the **Active Trainings Report** shows data pertaining to the current month, but this can be changed using the **Date Range** drop-down menu:

+   5. Open the **Date Range** dropdown located above Active Trainings Report.
+   6. Choose any date range available and see how the report is immediately updated.
+   7. Open the **Date Range** drop-down again and select **This Month**, which is the default value.

Note that you can also filter this report by **User Group** using the very same technique as for the reports included in the **User Activity** dashboard discussed earlier.
