# Registering as an external user

Now that you have a working external registration profile, let's switch hats again and become, for a few moments, that external employee who needs to register to your Captivate Prime account. You will use this technique to create a user named Learner 03. Follow these steps:

+   1. Open a new private window in your web browser.
+   2. Navigate to the unique link of the external profile you created in the previous section.

> Tip
> If you don't have access to the unique link for the external registration profile anymore, go to the External Users page of the administrator application of your Prime account and hover over the external registration profile in the list to make two icons appear. The envelope icon allows you to resend the manager email, while the chain icon allows you to copy the link to the external registration profile to the clipboard.

+   3. Fill in the registration form to create a new user named Learner 03 that uses the email address you created for Learner 03 at the beginning of this chapter.
+   4. Click the Register button when you're done.

This last action creates a new external user in Captivate Prime. It also redirects that user to the Learner experience of your Prime account.
