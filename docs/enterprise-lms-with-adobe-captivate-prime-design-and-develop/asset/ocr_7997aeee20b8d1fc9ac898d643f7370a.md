# Enrolling in a course using the mobile app

Remember that the *Learner Experience in Adobe Captivate Prime* course is a required prerequisite before taking the *Fundamentals of cybersecurity* course. At this point, *Learner 03* has not yet enrolled in the *Learner Experience in Adobe Captivate Prime* course, so this user is not yet able to start the *Fundamentals of cybersecurity* course.

In this section, you will use the mobile app to search the course catalog, enroll *Learner 03* in the *Learner Experience in Adobe Captivate Prime* course, and review the video included in that course so that this learner meets the prerequisites for the *Fundamentals of cybersecurity* course:

+   1. Make sure you are logged in as *Learner 03* using the Captivate Prime mobile app.
+   2. Tap the **Course Catalog** icon located at the bottom of the screen.
+   3. Tap the **Search** icon in the upper-right corner of the screen to search for the *Learner Experience in Adobe Captivate Prime* course.
+   4. Tap the course when it appears in the list. This takes you to the course overview page.
+   5. Take some time to review the information available on the course overview page. When ready, tap the **Enroll** button. The **Enroll** button turns into a **Start** button.
+   6. Tap the **Start** button to begin the course. This action opens to the fluidic player embedded in the mobile app.
+   7. While reviewing the video, take some time to examine the features of the fluidic player. You should find the exact same icons as when reviewing the course on your desktop or laptop computer earlier in this chapter.
+   8. When done, tap the close icon in the upper-right corner of the fluidic player to return to the course overview page.

As you can see, the learning experience provided by the mobile app is very similar to the one you experienced using your web browser. This is another highlight of the fluidic player: it can be embedded in a mobile application or even on your own website. This ability will be further discussed in *Chapter 16, Exploring the Integration Admin Role.*

> **Enrolling using a QR code**
> 
> Another way to enroll in a course using the mobile app is by scanning a QR code. An administrator must print the QR code using the course **Instances** page of the administration area. They can then post these QR codes around the organization’s premises. Learners can then use the Captivate Prime mobile app to scan the QR code in order to enroll in the corresponding course. The **Scan QR Code** feature can be accessed using the hamburger icon located in the upper-left corner of the mobile app.
