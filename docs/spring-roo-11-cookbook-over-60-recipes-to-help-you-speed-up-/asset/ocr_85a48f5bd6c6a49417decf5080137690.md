# Scaffolding Spring Web MVC application for a one-to-many relationship

Spring Roo doesn't scaffold an HTML element for the one side of a one-to-many relationship. Let's look at this in the context of an example:

In the flight-app application, a Booking entity instance represents a booking on a flight by a customer. On a particular flight, many bookings are possible; therefore, the relationship between the Flight and Booking entities is one-to-many. The ch04_one_to_many.roo script that accompanies this book does the following:

+   - Creates Flight and Booking entities
+   - Creates a one-to-many relationship between Flight and Booking entities
+   - Creates controllers and JSPX views for the entities

Exit the Roo shell and delete the contents of ch04-recipe. Execute the ch04_one_to_many.roo script and run the generated Spring Web MVC application using maven (as described in the Packaging, deploying, and using Roo-generated Spring MVC application recipe).
