To use javap, you need to first set the PATH environment variable to point to the bin
directory of your Java SE installation, as shown here:

```
C:\> set PATH=%PATH%;C:\Program Files\Java\jdk1.6.0_23\bin
```

Now, go to the directory which contains your Roo project (ch02-recipes in our case) and
execute the javap command to view the details of the compiled Flight class, as
shown here:

```
C:\roo-cookbook\ch02-recipes> javap -classpath target\classes sample.roo.
flightapp.domain.Flight
```
