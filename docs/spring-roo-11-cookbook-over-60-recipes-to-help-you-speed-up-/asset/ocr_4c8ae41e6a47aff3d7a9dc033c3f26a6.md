The `<http>` element registers an implementation Spring Security's
`AccessDecisionManager`, which makes access decisions regarding web URL
access. An incoming web request is matched against the URL patterns specified
by the `<intercept-url>` elements in the order in which they appear within the
`<http>` element. If a match is found, it'll be used by `AccessDecisionManager`
implementation for making access decisions. As incoming web requests are matched
against the URL patterns (specified by the `<intercept-url>` elements) in the order
in which they appear within the `<http>` element, more specific URL patterns should
be declared before the more general URL patterns.
