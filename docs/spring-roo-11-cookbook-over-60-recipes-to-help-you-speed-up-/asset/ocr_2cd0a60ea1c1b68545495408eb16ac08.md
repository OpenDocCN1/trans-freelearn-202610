+   - Spring's ThreadPoolTaskExecutor configures a java.util.concurrent.ThreadPoolExecutor instance (an implementation of java.util.concurrent.Executor) with the thread pool size specified by the pool-size attribute value. The ${executor.poolSize} placeholder's value comes from the email.properties file.

+   - Add the executor.poolSize property to the email.properties file, as shown here:
+   
+   executor.poolSize=10
