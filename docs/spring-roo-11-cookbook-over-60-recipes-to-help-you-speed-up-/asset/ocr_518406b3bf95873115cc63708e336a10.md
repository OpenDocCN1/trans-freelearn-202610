# There's more...

Spring Web Flow provides support for associating model attributes with a view state, making it possible to create a flow consisting of form submissions. For instance, you can modify Customer flow such that the user first enters details in a customer form (which binds form field values to the `Customer` JPA entity), followed by address details (which binds form field values to the `Address` JPA entity), and in the end both `Customer` and `Address` entity instances are persisted in the database.
