# Getting ready

If you are using any IDE other than STS, then ensure that you install AJDT (AspectJ Development Tools).

Create directory C:\roo-cookbook\ch07-recipes\push-in and copy the ch07_web_app.roo script. Now, start the Roo shell from the push-in directory and execute the script using the script command. Executing the script will create a flight-app Spring Web MVC application.
