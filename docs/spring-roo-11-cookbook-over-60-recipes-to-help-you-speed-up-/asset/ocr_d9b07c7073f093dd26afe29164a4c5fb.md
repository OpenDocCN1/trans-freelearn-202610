# ## Introduction

In this chapter, we look at Roo commands that support sending e-mails via JavaMail API, sending and receiving JMS messages, configuring Spring Security for an application, deploying Spring and GWT applications to Google App Engine (GAE), and adding search capability to an application's domain model using Solr search server.
