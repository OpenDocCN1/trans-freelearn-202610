The following code shows the FlightDescription_Roo_Entity.aj AspectJ ITD file:

```
privileged aspect FlightDescription_Roo_Entity {

    declare @type: FlightDescription: @Entity;

    @PersistenceContext
    transient EntityManager FlightDescription.entityManager;

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "id")
    private Long FlightDescription.id;

    @Version
    @Column(name = "version")
    private Integer FlightDescription.version;

    ...
}
```

It is interesting to note that the primary key generation strategy is specified as
GenerationType.IDENTITY. In GAE, this means that the identifier value is not assigned to
the FlightDescription entity until the associated transaction completes or you explicitly
call the flush method of EntityManager.
