# # Web Application Development with GWT, Flex, and Spring Web Flow

In this chapter, we will cover:

+   - Scaffolding GWT applications from JPA entities
+   - Getting started with Flex application development
+   - Scaffolding a Flex application from JPA entities
+   - Getting started with Spring Web Flow

# ## Introduction

In the previous chapter, we saw that Roo scaffolds Spring Web MVC controllers and JSPX views from JPA entities that are in the application. In this chapter, we'll look at Roo commands that scaffold GWT and Flex front-ends from JPA entities. Additionally, in this chapter, we'll see how we can use Roo to add support for Spring Web Flow in our application.
