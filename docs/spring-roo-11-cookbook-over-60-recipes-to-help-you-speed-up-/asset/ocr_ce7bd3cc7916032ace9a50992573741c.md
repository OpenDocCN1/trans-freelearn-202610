# How it works...

As the output of executing the controller all command shows, controllers, views, and so
on, are created. To summarize, the following table describes the various directories that are
created in the flight-app Roo project:

| Directory | Description |
|---|---|
| sample\\roo\\
flightapp\web folder
in SRC_MAIN_JAVA | Contains the scaffolded controllers (and their ITDs) corresponding
to each JPA entity in the application. This folder is created
based on the value of the package argument of the controller
all command. |
| SRC_MAIN_WEBAPP\
WEB-INF\spring | Contains the web application context XML file for the
flight-app application that is loaded by Spring's
DispatcherServlet. The name of the web application
context XML file is webmvc-config.xml. |
| SRC_MAIN_WEBAPP\
images | Contains images used by the JSPX views generated by Roo. |
| SRC_MAIN_WEBAPP\
styles | Contains CSS stylesheets used by the JSPX views generated by
Roo. By default it contains two CSS stylesheets: standard.css
and alt.css. |
