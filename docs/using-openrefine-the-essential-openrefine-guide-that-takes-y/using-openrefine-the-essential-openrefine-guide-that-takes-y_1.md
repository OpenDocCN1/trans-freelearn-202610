# 序言

2008 年我加入 Metaweb Technologies, Inc. 时，我们正在认真构建 Freebase；实体一个接一个，事实一个接一个。现在你可能通过其最新形态 Google 的 Knowledge Graph 了解 Freebase，它为 www.google.com 上的“知识面板”提供支持。

构建“世界上所有事物的数据库”是一项艰巨的任务，仅靠机器和算法是不够的，即使原始公共领域数据大量存在。从多个来源获得的原始数据必须清理、规范化，然后与 Freebase 中已有的数据进行核对。即使是数据清理的第一步也无法完全自动化；需要人类读者的常识来判断如果名为 cost 的列中同时出现 0.1 和 10,000,000，它们很可能使用不同的单位（也许分别是百万美元和美元）。也需要人类读者来决定 UCBerkley 与 University of California in Berkeley, CA 相同，但与 Berkeley DB 不同。

如果这些错误频繁出现，我们还不如放弃或直接雇佣足够的人进行手工数据录入。但这些错误出现的频率足以成为问题，却又不足以让未处理过此类数据的人认为简单自动化就足够了。但亲爱的读者，你处理过数据，你知道它可能有多么不可预测地混乱。

我们想要加载到 Freebase 的每个数据集都成为编程与人工检查交替进行的迭代练习，导致硬编码转换规则，从将两位数年份转为四位数，到如果中间有逗号则交换名字和姓氏。对我们大多数程序员来说，这项练习很快就变得乏味，每次开始都令人痛苦。

因此，我们创建了 Freebase Gridworks，这是一款用于清理数据并使其准备好加载到 Freebase 的工具。我们将其设计为数据库-电子表格混合体；它像电子表格软件一样交互式，像数据库一样可编程。正是因为这种结合，Gridworks 成为此类工具的先驱。

在创建并使用 Gridworks 的过程中，我们意识到清理、转换和单纯玩弄数据至关重要且普遍有用，即使目标不是将数据加载到 Freebase。因此，我们重新设计了该工具使其更通用，并在 Google 收购 Metaweb 后以“Google Refine”的名称发布其第 2 版。

此后，Refine 在许多不同社区中得到广泛认可；数据记者、开放数据爱好者、图书管理员、档案员、黑客行动主义者，甚至是职业程序员和开发者。早期采用的传播主要通过口口相传、在黑客松和由其自身用户举办的非正式教程中进行。

经过早期采用者的验证，Refine 现在需要更有组织的努力来推广并成为一个成熟的产品，拥有可持续的社区。专家用户、开源贡献者和数据爱好者团体正在积极在巡回讲座和课堂上教授如何使用 Refine。来自 Free Your Metadata 团队的 Ruben 和 Max 已经迈出了下一步，将这些教程整合并将这些配方整理成这本 Refine 缺失的手册。

退一步看大局，我们可能会意识到混乱的数据不是任何人的个人问题，而更像是确保自己社区安全清洁。问题本身不大，但它对透明政府等重大问题有影响。混乱的数据阻碍分析并掩盖现实世界的问题，我们所有人都必须撸起袖子来做清理工作。

**David Huynh**

OpenRefine 原始创建者

# 前言

数据常常被称为“新黄金”，因为它在当今数据驱动的经济中具有巨大的价值。然而，我们更愿意把数据看作钻石。它们起初是粗糙的，但通过高超的技艺，可以被打磨成闪闪发光、对我们极具价值的资产。这正是本书所涵盖的内容：如何在 OpenRefine 中转换你的数据集，从而优化其质量，以便在现实世界中进行（重复）使用。

由于 OpenRefine 的功能非常丰富，新用户可能会感到不知所措，我们相信一本合适的指南能带来很大不同。本书将引导你从最初的步骤一步步走向你可能都不知道的、真正高级的操作。我们会花时间介绍 OpenRefine 的各个不同方面，最终你将掌握必要的技能，使自己的数据集焕然一新。本书从清理数据、修复小错误开始，最后以将你的数据集与其他数据集关联而结束，使它能够成为更大数据生态系统的一部分。

我们明白每个数据集都各不相同，但通过示例学习是最容易的。因此，我们选择了动力博物馆（Powerhouse Museum）数据集来演示本书中的技术。然而，由于并非所有步骤都适用于你的数据集，我们将不同的任务组织成“配方”的形式。就像普通食谱一样，你可以根据需要挑选所需的配方来实现目标。有些配方之间相互依赖，但这会在每章开头标明。

此外，本书中的示例数据集体现了一种健康的数据文化：动力博物馆的人们决定将数据上线，尽管他们知道数据仍存在一些质量问题。有趣的是，这并没有阻止他们这样做。事实上，也不应该阻止你；重要的是把数据拿出来。从那以后，数据质量有了显著提高，但我们为你提供的是旧版本，这样你就可以自己执行清理和关联操作。

我们相信这本书将解释所有必要的工具，帮助你让数据达到最佳状态。一旦你掌握了打磨的技艺，现在手中的原始数据钻石就会变成闪亮的钻石。

祝你在学习 OpenRefine 的过程中玩得开心！

Ruben 和 Max

## 本书涵盖的内容

第 1 章《深入 OpenRefine》教你 OpenRefine 的基本步骤，展示如何导入数据集以及如何在主界面中操作。

第 2 章《分析和修复数据》解释了如何了解你的数据集以及如何发现其中的错误。此外，你还会学习几种修复错误的技术。

第 3 章《高级数据操作》深入探讨数据集修复，演示 OpenRefine 提供的一些更复杂的数据操作。

第 4 章《关联数据集》通过单个术语的调和以及全文本字段上的命名实体识别，将你的数据集与其他数据集关联起来。

附录《正则表达式与 GREL》介绍高级模式匹配和通用精炼表达式语言。

## 本书所需准备

本书不假设你具备任何先验知识；我们甚至会在第 1 章《深入 OpenRefine》中指导你完成 OpenRefine 的安装。

## 本书适合谁

本书适合任何处理数据的人，特别是大型数据集。如果你一直想知道如何深入了解数据中的问题、提高数据质量，或将其与其他数据集关联，那么这本书就是为你准备的。

本书不要求具备 OpenRefine 的先验知识，但如果你之前使用过 OpenRefine，你仍然能在本书中学到新东西。我们在后面的章节中介绍了几种高级技术，其中第 4 章《关联数据集》完全专注于数据集关联。
