# # What you need for this book

+   - A Linux workstation with a supported host system (see http://www.yoctoproject.org/docs/current/ref-manual/ref-manual.html#detailed-supported-distros)
+   - Packages required for the host system (see http://www.yoctoproject.org/docs/current/ref-manual/ref-manual.html#required-packages-for-the-host-development-system)
+   - The required versions of Git, tar, and Python (see http://www.yoctoproject.org/docs/current/ref-manual/ref-manual.html#required-git-tar-and-python-versions)
