```
$ cd meta-raspberrypi/recipes-devtools
$ mkdir gpio-pakt-book
```

In order that Bitbake find our recipe, we can put the different files in this folder, like this:

```
$ cd gpio-pakt-book
$ mv /home/packet/gpio-pakt.bb
$ mv /home/packet/gpio-pakt
```

The last step consists of integrating our recipe with the image. To do this, we can add the following variable to the conf/local.conf file:

```
IMAGE_INSTALL_append += " gpio-pakt"
```

Now, we can launch Bitbake, and then test our program on the Raspberry Pi:

```
$ bitbake rpi-basic-image
```

The following commands to be executed on the Raspberry Pi.

You can test the LED with these commands:

```
$ gpio_example led=1 (set gpio4 to 1)
$ gpio_example led=0 (set gpio4 to 0)
```

You can use this command to test the button:

```
$ gpio_example --button
Button was pressed !
```
