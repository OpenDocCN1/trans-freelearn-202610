# # Who this book is for

This book is intended for embedded software students, embedded Linux engineers, and embedded systems enthusiasts competent with the Raspberry Pi (or another ARM platform) who want to discover the Yocto Project.

This book is the ideal way to become proficient and broaden your knowledge in order to apply it to your embedded development.

If you are looking for a book to help you develop on the Raspberry Pi and the Yocto Project, this book is the one you need.
