# # Deploying the raspberry-pakt-image.bb image

Now comes the time when we can test our image and check its operation. To do this, we have to launch usual bitbake command, but this time with an argument-the name of our image, raspberry-pakt-image:

```
$ bitbake raspberry-pakt-image
Loading cache: 100%
|###############################################################################|
|###############################################################################|
|###############################################################################|
####| ETA:  00:00:00
```

Now, we have a 100% custom environment ( layer , recipe , and image ).
