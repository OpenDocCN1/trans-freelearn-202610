# # Material required for the project

You will need the following material for the project:

+   - A Raspberry Pi (any model will do)

The Raspberry Pi Zero requires that you either solder in a GPIO header or solder the wires directly to the GPIO pads

+   - Jumper cables (three are required)
+   - A one-channel 5V relay module
+   - A lamp (preferably a lamp you don't mind splitting and cutting the cable of)
+   - An external power supply (preferably 12V)

# Note

WARNING: This project requires basic knowledge of electrical circuits. We strongly discourage using high-voltage power if you don't have the knowledge or experience.
