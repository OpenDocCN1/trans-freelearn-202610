# # Software development kits (SDKs)

An SDK is a set of tools we can use outside **Yocto/OE**. These tools generally include a compiler, linker, debugger, libraries, and external headers. This set of compilation tools is called a **toolchain**. With the Raspberry Pi (or other embedded platforms), the toolchain is often composed of crossstools, which are tools executed on one architecture that produce a binary for use in another architecture.

The **Yocto/OE** build system can be used to generate a cross-compilation toolchain and matching sysroot folder for a target system.
