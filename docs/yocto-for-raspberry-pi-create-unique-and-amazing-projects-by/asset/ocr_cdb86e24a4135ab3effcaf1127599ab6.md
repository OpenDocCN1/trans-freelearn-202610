# # The core components

The core components (other available tools are optional) of the Yocto Project are:

+   - BitBake
+   - OpenEmbedded-Core
+   - Poky
+   - The BSP layer (meta-raspberry, meta-fsl-arm, meta-ti, meta-intel, meta-sunxi, and so on)
