# # Exploring Toaster

Toaster is a web interface for BitBake. The Yocto Project website describes it as follows:

> > "Toaster is an Application Programming Interface (API) and web-based interface to the
> > OpenEmbedded build system, which uses BitBake. Currently, Toaster collects and presents
> > information about your builds, which you can navigate and query using a web browser"
