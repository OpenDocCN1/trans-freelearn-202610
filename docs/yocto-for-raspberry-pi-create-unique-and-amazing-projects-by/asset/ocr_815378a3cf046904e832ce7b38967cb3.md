When all the physical connections are in place, we can check whether everything works by using the gpio_example binary again. At this point, our Raspberry Pi is probably hard to move, so we will use SSH to gain access to the board and turn the light on and off.

```
$ ssh root@192.168.x.x
root@raspberrypi2:~#
root@raspberrypi2:~# gpio_example --led=1
root@raspberrypi2:~# gpio_example --led=0
```

If everything has been set up in the correct way, you should see the light go on and off. In the next subsection, we will continue with controlling the light remotely by using a smartphone.
