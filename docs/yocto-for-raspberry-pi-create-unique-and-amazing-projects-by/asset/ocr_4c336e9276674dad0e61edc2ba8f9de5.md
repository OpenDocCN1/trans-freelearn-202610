# # Creating the environment

To separate the recipes of our layer, we will position our image recipe in a layer called recipe-core, where we will create our raspberry-packet-image.bb recipe file. Here are the results of our layer after creating it:

```
$ tree meta-packet_rpi/
meta-packet_rpi/
├── conf
│   └── layer.conf
├── COPYING.MIT
├── README
├── recipes-core
│   └── images
│       └── raspberry-packet-image.bb
├── recipes-custom
│   └── gpio-packet
│   │   ├── gpio-packet
│   │   │   ├── fix.patch
│   │   │   ├── gpio-example.c
│   │   │   └── gpio-packet.bb
├── recipes-example
│   └── example
│       └── example-packet-0.1
│       │   ├── example.patch
│   │   │   └── helloworld.c
│       └── example-packet_0.1.bb
├── recipes-example-bbappend
├── example-bbappend
│   └── example-packet-0.1
│   │   └── example.patch
│   └── example-packet_0.1.bbappend
```
