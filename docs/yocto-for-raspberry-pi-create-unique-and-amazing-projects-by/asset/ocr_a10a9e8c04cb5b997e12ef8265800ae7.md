# Deploying raspberry-pckt-image

Now that we have a functional application (webserver-pckt), we can add it to our custom image, raspberry-pack-image:

```
# Base this image on core-image-minimal
include recipes-core/images/core-image-minimal.bb
DESCRIPTION = "Image for raspberry-pi"
IMAGE_FEATURES += "ssh-server-dropbear splash"
# Include modules in rootfs
IMAGE_INSTALL += " \\
 kernel-modules \\
 gpio-pckt \\
 i2c-tools \\
 spitools \\
 nunchuck \\
 v4l-utils \\
 nodejs \\
 webserver-pckt \\
"
```

After doing this, we can start creating our image and then mount it on an SD card:

```
$ bitbake raspberry-pckt-image
```
