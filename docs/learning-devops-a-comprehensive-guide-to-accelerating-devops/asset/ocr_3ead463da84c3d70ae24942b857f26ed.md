Thus, the `main` endpoint (that is, the blue environment) has the maximum weight, which
is equivalent to 100% traffic.

Feature flags (also called feature toggles) allow us to dynamically enable or disable a
feature of an application without having to redeploy it.

done with a simple encapsulation using conditional `if` rules, as shown in the following
