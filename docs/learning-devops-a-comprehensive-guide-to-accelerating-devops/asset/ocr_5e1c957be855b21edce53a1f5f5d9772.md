In Azure Pipelines, there is the choice of either classic editor mode, which allows us
to configure the pipeline via a graphical interface, or YAML pipeline mode, which
involves using a **YAML Ain't Markup Language** (YAML) file that describes the
configuration of the pipeline.

In this lab, we will use the classic editor mode so that we can visualize the different
options and configuration steps.
