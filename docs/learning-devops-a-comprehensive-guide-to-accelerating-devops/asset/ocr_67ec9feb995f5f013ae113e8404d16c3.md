# # Using the Vault UI web interface

One of the interesting features of Vault is that, apart from the client-side tool that allows
you to perform all operations on the Vault server, Vault has a UI web interface that allows
you to manage secrets, but more visually and graphically.

To open and use the Vault web interface to visualize the secrets that we have created with
the client tool, we must follow these steps:

+   1. In a browser, enter the URL provided when starting the server—that is,
+   `http://127.0.0.1:8200/ui`, which is the default local Vault URL.
