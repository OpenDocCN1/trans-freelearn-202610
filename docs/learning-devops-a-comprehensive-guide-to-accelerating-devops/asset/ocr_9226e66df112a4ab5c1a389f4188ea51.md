# # Preparing Postman collections for Newman

As we have just seen, Newman is Postman’s client tool, and in order to work, it needs
the configuration of the collections, requests, and environments that we have created
in Postman.

That’s why, before running Newman, we will have to export Postman’s collection and
environments, and this export will serve as Newman’s arguments. So, let’s start exporting
the DemoBook collection that we created in Postman.

# ## Exporting the collection

The exporting of a Postman collection consists of obtaining a JSON file that contains all
the settings of this collection and the requests that are inside it.

It is from this JSON file that Newman will be able to run the same API tests as when we
ran them from Postman.

To do this export, perform the following tasks:

+   1. Go to the context menu of the collection that we want to export.

+   2. Choose the **Export** action.

+   3. Then, in the window that opens, uncheck the **Collection v2.1 (recommended)**
+   checkbox.

+   4. Finally, validate by clicking on the **Export** button.
