# # Versioning of the code with Git in Azure Repos

As we have mentioned, the first prerequisite for setting up a CI process is to have the application code versioned in an SVC, and we will do this in Azure Repos by following these steps:

+   1. To start our lab, we will create a new project; this operation has already been covered in _Chapter 6, Managing Your Source Code with Git_, in the _Starting with the Git process_ section.

+   2. Then, in Azure Repos, we will import code from another Git repository by using the **Import repository** option of the repository menu, as shown in the following screenshot:

![](bbox=[0.131, 0.33, 0.869, 0.554])

Figure 7.19 – Azure Repos Import repository menu
