The actions described in this `provisioners` section, which Packer will execute using
this template, are as follows:

+   1. Installs Ansible on the temporary VM.
+   2. On this temporary VM, the `ansible-local` provisioner runs the playbook
+   `playbookdemo.yml` that installs and starts NGINX. The documentation of
+   this provisioner is here: `https://www.packer.io/docs/provisioners/
+   ansible/ansible-local`.
+   3. The `clean.sh` script deletes Ansible and its dependent packages that are no
+   longer used.
+   4. Deprovisions the VM to delete the local user information.
