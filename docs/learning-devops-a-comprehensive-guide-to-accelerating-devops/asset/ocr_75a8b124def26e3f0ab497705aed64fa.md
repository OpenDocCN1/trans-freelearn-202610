# # Configuration and deployment in Kubernetes

**Kubernetes** is a container orchestrator – it is the technology that most embodies IaC
(in my opinion) because of the way it deploys containers, the network architecture (load
balancer, ports, and so on), and volume management, as well as how it protects sensitive
information, all of which are described in the YAML specification files.

Here is a simple example of a YAML specification file:

```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-demo
  labels:
    app: nginx
spec:
  replicas: 2
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
        - name: nginx
          image: nginx:1.7.9
          ports:
            - containerPort: 80
```

In the preceding specification file, we can see the name of the image to deploy (nginx),
the port to open (80), and the number of replicas (2).
