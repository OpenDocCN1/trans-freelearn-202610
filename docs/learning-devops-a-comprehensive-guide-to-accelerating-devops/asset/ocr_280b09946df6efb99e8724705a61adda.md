# # Important Note

For other ways to use dynamic inventories on Azure, you can consult the
Azure documentation at https://docs.microsoft.com/en-
us/azure/developer/ansible/dynamic-inventory-
configure?tabs=azure-cli.

By using a dynamic inventory, we can take full advantage of the scalability of the cloud
with an automatic VM configuration and without having to make any code changes.

In this section, we learned how to use a dynamic inventory in Azure by implementing
its configuration and doing the necessary script recovery, before executing this dynamic
inventory with Ansible.
