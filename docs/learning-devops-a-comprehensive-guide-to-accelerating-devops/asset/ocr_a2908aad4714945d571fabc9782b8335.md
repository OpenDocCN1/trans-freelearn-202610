# Creating a full pipeline definition in a YAML file

In the previous sections, we discussed the creation of a CI and CD pipeline in Azure DevOps using the UI, which has some advantages, but one of its inconvenient points is the difficulty to automate the creation of a pipeline for lots of projects.

To solve this problem, Azure DevOps has the possibility to write the entire pipeline definition (CI and CD) inside a YAML file that is saved in the repository.
