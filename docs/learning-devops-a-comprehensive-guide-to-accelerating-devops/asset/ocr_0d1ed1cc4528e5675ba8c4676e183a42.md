# Creating the VM

To create the VM, navigate to the folder in which we created the `Vagrantfile` file, and
run the following command:

```
vagrant up
```

The output is shown in the following screenshot:

![](bbox=[0.134, 0.399, 0.865, 0.777])

The execution of the preceding command performs the following steps:

+   1. Import the box from Vagrant Cloud.

+   2. Create a new VM in the hypervisor (in our case, this is VirtualBox).
