template, which uses Ansible.

It is also interesting to know that we can override the variables of our template when
executing the `packer build` command, as in the following example:

```
```
packer build -var 'image_version=0.0.2' azure_linux.json
```
```

We can pass all variables with the `-var` options to the `build` command.

So, with this option, we can change the name of the image without changing the content
of the template, and we can do this for all of the variables that are defined in our template.
