# # Installation via Docker

If we want to install SonarQube Community edition for tests or demonstration purposes,
we can install it via the official Docker image that is available from Docker Hub at
`https://hub.docker.com/_/sonarqube/`.
Be careful as this image uses a small integrated database that is not made for production.

# # Installation in Azure

If we have an Azure subscription, we can quickly access the entire SonarQube server
using the SonarQube VM from the Azure Marketplace. Follow these steps to create a
SonarQube VM in Azure:

+   1. In the Azure Marketplace, search and select the **SonarQube** image. The following
+   screenshot shows the SonarQube page of the Marketplace:
