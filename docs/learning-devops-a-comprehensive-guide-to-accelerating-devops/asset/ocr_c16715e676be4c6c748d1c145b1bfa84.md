# Figure 2.14 – Executing the terraform apply command

The output of the apply command displays all actions executed by Terraform, along with all changes and the impacted resources. It ends with a summary line that displays the sum of all added, changed, or destroyed resources.

> Important Note
> 
> For more information about the apply command line, please refer to the documentation at https://www.terraform.io/docs/ commands/apply.html.

Since the Terraform apply command has been executed correctly, we can check in the Azure portal whether the resources described in the Terraform code are present.
