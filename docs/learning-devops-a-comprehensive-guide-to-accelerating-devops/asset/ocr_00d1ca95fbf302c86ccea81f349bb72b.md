This information is important because it will help the repository’s target owner
quickly understand the objectives of the code changes included in this **pull request**.
In addition, from the right-hand panel, it is possible to select reviewers who will
be notified of the pull request by email. This will be done by the person who is in
charge of reviewing the code changes and validating or rejecting them.
