In the following lab, we will learn how to create a basic pipeline definition in a YAML file.
Here’s how to do this:

+   1. In Azure Repos, inside the DemoBook repository created previously, add a new file
+   named azure-pipeline.yml, with the following content:
+   trigger:
+   - master
+   pool:
+   vmImage: ubuntu-latest
+   steps:
+   - task: DotNetCoreCLI@2
+   displayName: "Restore"
+   inputs:
+   command: restore
+   projects: '**/*.csproj'
+   - task: DotNetCoreCLI@2
+   displayName: "build"
+   inputs:
+   command: 'build'
+   projects: '**/*.csproj'
+   arguments: '--configuration Release'

+   displayName: "Run tests"
+   inputs:
+   command: 'test'
+   projects: '**/tests/*.csproj'
+   arguments: '--configuration Release'
