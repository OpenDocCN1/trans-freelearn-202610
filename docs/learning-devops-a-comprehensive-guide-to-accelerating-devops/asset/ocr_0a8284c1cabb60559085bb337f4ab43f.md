Then we use a list of `provisioner` blocks of `shell` type to install the NGINX package

> Note
> The code source of this HCL template format is available at `https://
> github.com/PacktPublishing/Learning-DevOps-Second-
> Edition/blob/main/CHAP04/templates/.pkr.hcl`.

Finally, to execute Packer using an HCL template, we execute the following command to
download plugins:

```
packer init .pkr.hcl
```

Then we check the template syntax by running the `validate` command:

```
packer validate .pkr.hcl
```

Finally, we build the desired image by running this following command:

```
packer build .pkr.hcl
```

After the execution of the preceding command, the image will be created, exactly as we
have already seen with the JSON format.

> Note
> To migrate Packer templates from JSON format to HCL format, read this
> documentation: `https://learn.hashicorp.com/tutorials/
> packer/hcl2-upgrade`.
