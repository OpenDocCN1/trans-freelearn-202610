# # Instantiating a new container of an image

To instantiate a new container of our Docker image, we will execute the docker run
command in our Terminal, with the following syntax:

```
docker run -d --name demoapp -p 8080:80 demobook:v1
```

The -d parameter indicates that the container will run in the background. In the --name
parameter, we specify the name of the container we want. In the -p parameter, we indicate
the desired port translation. In our example, this would mean port 80 of the container
will be translated to port 8080 on our local machine. And finally, the last parameter of the
command is the name of the image and its tag.
