To contribute to the code of another repository, we will need to create a **fork** of the initial repository that we want to contribute to. A fork is a duplication of the initial repository that is performed in our GitHub account, thus creating a new repository in our account.

Follow these steps to learn how to create a fork of a repository:

+   1. First, navigate to the initial repository that you want to contribute to. Then, click on the **Fork** button at the top of the page, as shown in the following screenshot:

![](bbox=[0.148, 0.259, 0.859, 0.308])

Figure 16.4 – GitHub – forking a repository

+   2. After a few seconds, this repository will be forked and duplicated, along with all its content, in your account. By doing this, you get a new repository in your account that is linked to the initial repository, as shown in the following screenshot:

![](bbox=[0.132, 0.424, 0.869, 0.548])

Figure 16.5 – GitHub fork link

+   3. Now, you have an exact copy of the repository that you want to contribute to in your GitHub account. You are free to modify the code and commit your changes, all of which will be archived in your repository.

However, even if there is a link between the initial repository and the fork, the code for each repository is completely uncorrelated and the code isn’t synchronized automatically.

In this section, we learned how to create a GitHub repository or to make a fork of another repository so that we can contribute to it. Now, let’s learn how to propose code changes and merge our code into another repository using a pull request.
