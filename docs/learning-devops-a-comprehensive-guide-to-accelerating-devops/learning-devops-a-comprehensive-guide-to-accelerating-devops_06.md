# 第 1 部分：DevOps 和基础设施即代码

第一部分的目标是介绍 DevOps 文化，并提供基础设施即代码最佳实践的所有关键要点。本部分解释了 DevOps 在云基础设施中的应用，展示了使用 Terraform 进行配置和使用 Ansible 进行配置。然后，我们通过使用 Packer 对此基础设施进行模板化来进一步改进。

本部分包含以下章节：

- 第 1 章，DevOps 文化和基础设施即代码实践
- 第 2 章，使用 Terraform 配置云基础设施
- 第 3 章，使用 Ansible 配置 IaaS 基础设施
- 第 4 章，使用 Packer 优化基础设施部署
- 第 5 章，使用 Vagrant 编写开发环境
