## 前言

想象一下，你正在和几位朋友一起享用周五晚上的饮品，以庆祝周末的开始。突然，你的手机响了——你负责管理的一台服务器宕机了，而且必须在明天早上之前恢复运行。于是，你拖着疲惫的身体回到办公室，却发现过去几周里，一些日志文件的增长速度超过了平常，已经占满了硬盘。虽然这个场景非常简单，但大多数 IT 从业者在职业生涯中的某个阶段都遇到过类似情况。为了避免这类问题，本书将教你如何使用 Zabbix——一种开源的系统监控和报告解决方案——监控网络硬件、服务器和 Web 性能。

本书将指导你设置 Zabbix 中几乎所有的功能。通过循序渐进的说明，任何人都应该能够配置监控。你甚至可以说，这是一本 Zabbix 的“傻瓜指南”——但这只是因为我们每个人都会有无法理解某些内容的时候。为了不让你感到困惑，在本书中，我会尽量手把手地引导你、推动你前进，并极其详细地解释所有内容，让你完全不会感到沮丧。

## 本书涵盖的内容

*第 1 章，开始使用 Zabbix*，从零开始介绍 Zabbix 的安装，包括初始数据库、服务器和代理守护进程，以及运行在同一台机器上的 Web 前端。我们还将使用 PHP 访问数据库，并配置 Zabbix Web 前端。

*第 2 章，获取第一条通知*，介绍如何使用前端配置 Zabbix，以设置数据收集、在指定条件下触发事件，并针对单个数据源通过发送电子邮件通知我们。

*第 3 章，使用 Zabbix 代理和基本协议进行监控*，带你设置最常用、最基本的数据收集方法——Zabbix 代理和简单检查，例如 ICMP ping 以及直接检查 TCP 服务。

第 4 章，监控 SNMP 设备，教你如何设置业界标准的监控协议 SNMP。我们将探索由 Zabbix 发起轮询以及接收 SNMP 陷阱两种方式，从而监控各种设备，包括打印机、交换机、UPS 和路由器。

第 5 章，管理主机、用户和权限，介绍主机、用户和权限，包括主机组和用户组功能，以及它们对权限的影响。我们还将探讨相关主题，包括主机和主机组的维护。

第 6 章，使用触发器检测问题，介绍如何通过编写表达式来检测超出正常范围的值及其他情况，从而定义哪些条件值得关注。

第 7 章，对监控条件采取行动，帮助你了解如何响应触发器被触发的情况，例如发送电子邮件、启动外部脚本、在单独的缺陷跟踪系统中创建报告，甚至重启出现故障的服务。我们还将学习如何配置 Zabbix 中的升级操作，并了解滞后机制的工作方式。

第 8 章，使用模板简化复杂配置，告诉我们过去为何做得不够好，并教你如何使用模板改进配置。模板允许我们将统一配置应用到一组主机，同时使用用户宏为每台主机自定义阈值。我们还将探索模板嵌套功能，它可以在大型混合环境中创建非常灵活的配置。

第 9 章，使用图形和地图可视化数据，解释如何创建可视化元素来显示收集的数据，包括多种类型的图形和交互式网络地图。

第 10 章，使用屏幕和幻灯片放映可视化数据，帮助你配置能够收集并显示各种元素的屏幕，以及允许以自动方式循环显示多个屏幕的幻灯片放映。

第 11 章，高级监控项监控，探索使用外部、计算、聚合和自定义监控项类型来获取任意信息的更高级信息收集方式。

第 12 章，自动化配置，教你如何使用低级别发现来发现主机上的文件系统、网络接口和其他实体。在更高层面上，我们将探索通过网络发现和活动代理自动注册来自动管理主机的能力。

第 13 章，监控网页，带你使用 Zabbix 内置的 Web 场景功能，监控网页的可访问性、性能和可用性。

*第 14 章，监控 Windows*，介绍通过安装 Zabbix 代理、使用性能计数器以及通过 WMI 获取数据来监控 Windows。

*第 15 章，高级业务服务监控*，演示“IT 服务”功能。该功能允许将受监控的服务按树状结构组织，并计算 SLA 达标情况。我们将伪造一些数据，以了解该功能的实际效果。

*第 16 章，监控 IPMI 设备*，教你如何设置另一种业界标准协议 IPMI。我们将介绍模拟量和离散型 IPMI 传感器的监控。

*第 17 章，监控 Java 应用程序*，介绍如何设置并使用一个名为 Zabbix Java gateway 的独立守护进程，通过 JMX 获取基本信息。

*第 18 章，监控 VMware*，介绍内置的 VMware 监控支持。我们将探索自动发现和监控虚拟机管理程序及虚拟机的能力。

*第 19 章，使用代理监控远程位置*，探索被动和主动 Zabbix 代理的使用方式。这些代理代表 Zabbix 服务器收集数据，然后将数据传回服务器，有助于监控因防火墙限制而无法直接访问的远程位置，同时也能减轻 Zabbix 服务器的负载。

*第 20 章，加密 Zabbix 流量*，介绍 Zabbix 3.0 的主要新功能之一：能够对 Zabbix 服务器、代理、客户端以及 get 和 sender 工具之间的流量进行加密。

*第 21 章，深入处理数据*，帮助我们了解数据在 Zabbix 数据库中的存储细节，以及如何直接与数据交互；同时还将介绍如何使用 Zabbix 原生的 XML 导入和导出功能，更轻松地创建大量配置。我们还将开始学习 Zabbix API，以满足更高级的自动化需求。

*第 22 章，Zabbix 维护*，介绍 Zabbix 的升级过程、不同版本的各种组件如何相互协作，以及版本之间的数据库修补涉及哪些内容。我们还将探索可用的内部监控选项，讨论备份策略，并详细介绍 Zabbix 守护进程的所有配置参数。

*附录 A，故障排除*，介绍安装、连接、配置和其他方面的常见问题。

*附录 B，参与社区*，告诉我们并不孤单，Zabbix 监控解决方案背后有一个社区。我们可以通过 IRC、论坛和社区 Wiki 联系该社区。

## 本书所需条件

你至少需要一台 Linux 系统，也可以使用虚拟机。根据所讨论的具体功能，你可能还需要以下资源：

- 访问 SMTP（电子邮件）服务器
- 更多 Linux 系统
- 支持 SNMP 的设备
- 一台 Windows 系统
- 支持 IPMI 的设备
- 一个 Java 虚拟机
- 一个 VMware 实例

其中一些资源可以在同一台 Linux 主机上模拟。例如，运行 snmpd 或 Java VM，就可以在不使用单独系统的情况下尝试所有监控解决方案。

## 本书适合的读者

本书非常适合刚开始使用 Zabbix、并且希望创建简单监控报告的系统管理员。本书假设读者了解基本的系统管理任务。多年来，Zabbix 增加了相当多的新功能，其中许多 Zabbix 3.0 中新增的功能也会在本书中介绍，因此，即使是以前版本的资深用户，也应该能够从中找到新的信息。
