We need to define the `inventoryapi` route, which redirects to `ProductAPIController`. We will also need to define another route for `ProductController`. So, in the `modules.config.php` file of the Inventory module, we will add the following routes to the `routes` key:

```
'routes' => [
    'inventory' => [
        'type'     => Segment::class,
        'options'  => [
            'route'    => '/inventory'
                                [/:controller[/:action[/:key]]]',
            'defaults' => [
                'controller' => Controller
                    \\IndexController::class,
                'action'     => 'index'
            ],
        ],
    ],
    'inventoryapi' => [
        'type'     => Segment::class,
        'options'  => [
            'route'    => '/inventoryapi'
                                [/:controller[/:key]]'
        ],
    ],
],
```

> **Important note: RESTful controllers must not have a default action**
> 
> We must not define a default action when we use a RESTful controller. The reason is that the default action overrides the inference of the HTTP method.
