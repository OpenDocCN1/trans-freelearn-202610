Since IdentityManager has assumed responsibilities from IndexController, we need to refactor this controller class. Let us start with the IndexController constructor:

```
```php
private ?IdentityManager $identityManager;

public function __construct(IdentityManager
        $identityManager)
{
    $this->identityManager = $identityManager;
}
```
```

As you can see, instead of receiving two dependencies, now IndexController receives only the IdentityManager instance.

The IndexController->loginAction method will be more concise with the delegation of authentication for IdentityManager:

```
```php
public function loginAction()
{
    $nickname = $this->request->getPost('nickname');
    $password = $this->request->getPost('password');

    $logged = $this->identityManager->login($nickname,
        $password);

    return new JsonModel([
        'logged' => $logged
    ]);
}
```
```

Similarly, the IndexController->logoutAction method will have fewer lines of code:

```
```php
public function logoutAction()
{
    $this->identityManager->logout();

    return $this->redirect()->toRoute('inventory');
}
```
```

You should think of a controller class as a manager. A manager doesn’t do everything. They delegate tasks. A controller class should delegate responsibilities to model or view classes.
