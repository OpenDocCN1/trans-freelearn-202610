+   - @OA\RequestBody contains the definition for the fields of an HTML form.
+   - @OA\MediaType within @OA\RequestBody informs us of the value for the enctype attribute of an HTML form.
+   - @OA\Schema contains a set of form fields. Each field is defined by an @OA\Property annotation.
+   - @OA\Response informs us of the expected HTTP code and the description of the response.
+   - @OA\MediaType at the end informs us of the Content-Type header of the HTTP response.

