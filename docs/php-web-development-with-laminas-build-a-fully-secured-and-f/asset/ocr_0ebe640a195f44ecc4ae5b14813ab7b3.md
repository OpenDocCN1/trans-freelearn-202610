Currently, note that we have a method to get one product; however, we don’t have a method to get a list of products. No problem. We can add a method for this to the `ProductAPIController` class. The `AbstractRestfulController` superclass distinguishes between an HTTP `GET` request for one element and for a list by the key argument. If the HTTP `GET` request has no key argument, the `AbstractRestfulController` superclass executes the `getList` method. Then, we implement this method, which will look like this:

```
/**
 * @OA\Get(
 *     path="/inventoryapi/productapi",
 *     @OA\Response(response="200", description="get list of products"),
 *     @OA\MediaType(mediaType="application/json")
 * )
*/
public function getList()
{
    $resultSet = $this->productTable->getAll();
    $products = [];
    foreach($resultSet as $result){
        $products[] = $result->toArray();
    }
    return new JsonModel(['products' => $products]);
}
```

Now, we only need to write the annotation code blocks for each public controller method and run the `fsd` command, and we will have a complete API documentation page (Figure 12.8), which additionally allows us to test the requests for the whatsstore application.
