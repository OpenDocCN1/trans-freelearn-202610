Now, maybe you’re asking, “But how will the testLoginActionCanBeAccessed method ensure that a user can log in if this user does not exist?” At first, it does not ensure this. If the user exists, they will be redirected to the menu page. The test will fail at this moment, as often happens with tests in TDD.
