The search form will make an HTTP POST request to the IndexController default action of the Store module. Then, we need to modify the default action, the indexAction method, with the following implementation:

```
public function indexAction()
{
    $name = $this->getRequest()->getPost('name');
    $where = null;
    if (!empty($name)) {
        $where = new Where();
        $name = strtoupper($name);
        $where->like('products.name', "%$name%");
    }
    $products = $this->productTable->getAll($where);
    $form = new ProductForm();
    return new ViewModel([
        'form' => $form,
        'products' => $products
    ]);
}
```
