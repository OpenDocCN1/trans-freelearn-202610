```
$value = str_replace( '', '', $value);
$valueLength = strlen($value);
$repeated = (int) ($valueLength/2);
$n = $valueLength-1;
for($i=0;$i<$repeated;$i++) {
    $palindrome = ($value[$i] == $value[$n]);
    if (!$palindrome) {
        $this->messages[] = "{$value[$i]} is
        different of {$value[$n]}";
        return false;
    }
    $n--;
}
return true;
}
public function getMessages()
{
    return $this->messages;
}
}
```

As you can see, a validator class is a class that implements an isValid method, which receives an untyped value and returns true or false, and a getMessages method, which returns an array of error messages. So, you can create your own validator classes as per your needs and use them easily.
