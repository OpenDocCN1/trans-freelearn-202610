In this section, we will learn how to customize filters and validators and what the required methods for mapped models are.

On the home page of the tipsandtricks application, you will see a frame, similar to that in Figure 13.1, on the left-hand side, with samples of filter and validator customization for the model layer:

We will learn how the buttons of this frame work and understand how filters and validators are created with the Laminas framework.

In Chapter 8, Creating Forms and Implementing Filters and Validators, we learned how to use some filters and validators available in the laminas-filter and laminas-validator components. However, we are not limited to the implemented Laminas filters and validators. Both of these components have interfaces that allow us to implement customized filters and validators.
