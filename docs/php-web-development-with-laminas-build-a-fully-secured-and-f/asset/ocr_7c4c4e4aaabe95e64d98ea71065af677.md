The getApplication method will probably be necessary for several behavior test classes. If the same method appears in many different classes, this method can be centralized in a reusable unit of common code. In this case, this unit can be an abstract class.

We will create this class in our Generic module. So, create this class in the Generic module and a Context folder in the src folder. Then, create the abstract AbstractContext class in the Generic/src/Context folder with the File | New | Class menu.
