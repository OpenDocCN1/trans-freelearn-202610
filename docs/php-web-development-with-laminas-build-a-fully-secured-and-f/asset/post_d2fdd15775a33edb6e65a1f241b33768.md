## Testing the interaction between the web interface and API

For testing the product web pages, we need to adjust the Product and ProductTable classes. Why? Because of the relationship between products and discounts. To test the API, it was enough for the product model to have only the discount code, but to show the discount name on the product listing page, we need to recover the discount name.
