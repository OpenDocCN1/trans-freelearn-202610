As we know, a factory class needs to be defined in the `module.config.php` file of the module. Then, we add the following item to the `service_manager=>factories` key:

```
IdentityManager::class => Model\\IdentityManagerFactory::class
```

You may ask, “Why don’t you just use `IdentityManager` as the key?” The answer is that there is already an `IdentityManager` key for the Inventory module. So, here we have found a problem with using factory keys based on short aliases: name collision. Until now, we didn’t have this problem, but in case it arises, it is a good practice to use Full Qualified Class Names (FQCN) as keys to avoid name collision. In PHP, an FQCN is provided by the `class` static property of the class.
