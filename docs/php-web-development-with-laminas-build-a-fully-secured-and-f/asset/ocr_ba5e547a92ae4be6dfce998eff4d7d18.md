Figure 13.7 – JSON response generated by JsonModel

This response is generated by the IndexController->showJsonAction method, as follows:

```
public function showJsonAction()
{
    $simpleValue = 'a simple text';
    $list = ['apple', 'banana', 'coconut'];
    $car = new \stdClass();
    $car->color = 'red';
    $car->wheels = 4;

    return new JsonModel([
        'simple-value' => $simpleValue,
        'array' => $list,
        'object' => $car
    ]);
}
```

Since ViewJsonStrategy is enabled, the values injected into the JsonModel constructor are converted into JSON format and the content type of the HTTP response is configured for JSON.
