> **Source Code, Grass, and Rabbits**
> 
> There is something common among source code, grass, and rabbits: they can multiply very fast. But it is easier to lose control over source code than over grass or rabbits.

Let us take an example of duplicated code reduction using the output of phpcpd. If you observe the implementation of the getInputFilter method in Figure 12.1, there are repeated steps for each input: input creation, filter addition, and validator additions. We can create an extension of the Laminas\\InputFilter\\InputFilter class with a method that encapsulates these steps.
