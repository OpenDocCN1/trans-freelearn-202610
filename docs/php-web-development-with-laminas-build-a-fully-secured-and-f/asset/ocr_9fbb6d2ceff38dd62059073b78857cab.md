> Note – Behat arguments in definitions
> 
> The values identified as arguments in the feature files are mapped to context classes with the aid of the @Given, @When, and @Then annotations. These annotations inform whether the following method has or does not have an argument. If you change the value of an argument in a definition, you don’t need to change the implementation. For example, if the product price is changed in the productaddition.feature file, you don’t need to change anything in the ProductAdditionContext class. This avoids the need to make changes in classes if only a value from a rule has changed.
