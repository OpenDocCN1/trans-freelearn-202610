When you click on the remove button, the ProductBasketAPIController->delete method calls the ProductBasket->delete method, and the following is its source code:

```
public function delete(int $id): bool
{
    if (!isset($this->container->productBasket[$id])) {
        return false;
    }
    unset($this->container->productBasket[$id]);
    return true;
}
```
