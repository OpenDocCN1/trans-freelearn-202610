# Summary

In this chapter, we have learned how to use `laminas-db` to implement ORM.

There are ORM generation tools for PHP, such as **Doctrine**, that create classes for you from the database schema. However, code generation tools can sometimes produce unnecessary code, as well as taking control of ORM from the developer. With `laminas-db`, the developer has total control over ORM and can avoid superfluous code that code generation tools sometimes produce.

We gradually evolved the code base until we could use `laminas-mvc` to contain our code. We also kept best practices in mind to create the tests before creating the code to be tested. This experience with TDD will prepare us for the next challenges.

In the next chapter, we will increase the complexity level of web application development. We will start the implementation of an e-commerce project that allows us to explore many features provided by Laminas components.
