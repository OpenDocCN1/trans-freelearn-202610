As you should perceive, this web form won’t request successfully because the save .php file doesn’t exist. Let’s create it then:

# save.php

```
<?php
use School\SchoolClass;
require 'vendor/autoload.php';
$name = ($_POST['name'] ?? null);
$schoolClass = new SchoolClass(0, $name);
$schoolClass->save();
header('Location: index.php');
```

The content of save.php is very simple (after we have created the test for inserting). The file gets the value of the field name from the HTML form, sent via HTTP POST, and passes it to an instance of SchoolClass to persist the data into the classes table. In the next step, the file makes an HTTP request with a code of 302 through the header PHP function, which redirects to the index.php page.
