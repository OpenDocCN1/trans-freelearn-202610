
## 导入内容

我相信你在为页眉的标题和标语输入文本时已勾选了 **从模板导入内容** 按钮。我们现在将使用它，并将内容从 Artisteer 模板导入到 Joomla! 网站。请执行以下步骤：

- 1. 在 Joomla! 管理面板中，导航至 **扩展** | **模板管理器**。
- 2. 进入 **模板管理器** | **样式**，并在 **样式** 列中查找并点击你的模板。
- 3. 在 **模板管理器：编辑样式** 屏幕中，点击 **从模板导入内容** 按钮。
- 4. 在确认对话框中点击 **导入**。

![](img/7f889df2ffdb68108cff34d798a2b9a3_114_0.png)

点击导入按钮将内容从模板导入到 Joomla！

你在 Artisteer 中输入的所有内容都将被导入到 Joomla！水平菜单、垂直菜单、页脚和页面将自动创建并显示。甚至我们图片的 Lightbox 效果也能正常工作！

我们可以观察到内容导入的方式：

- 新建了一个名为 `Articles` 的分类。所有导入的文章（所有页面的文本）都已放入此新分类中。
- 创建了一个水平菜单的新模块，名称为 `Content/Horizontal Menu`，所有项目均为单篇文章类型。
- 创建了一个垂直菜单的新模块，名称为 `Content/Vertical Menu`，所有项目均为单篇文章类型。
- 创建了一个名为 `Content/Special Menu` 的菜单，但未关联任何模块。该菜单包含两个标准项目。第一个项目为分类博客类型，与精选分类中的文章相关联。第二个项目为单篇文章项目，目前未关联到任何文章。
- 页脚已作为新的自定义 HTML 模块导入，名称为 **Footer**，放置在 **position-27**。添加了一些新的空页面（作为没有内容的文章）。Joomla！不允许你保存空文章。因此，如果你尝试编辑并保持不变地保存它们，将会显示错误文本，提示你必须先输入一些内容。
- 所有图片都已放入 `Media` 中的 `template-content` 文件夹。
- 包含我们联系信息的一个区块已作为新的自定义 HTML 类型模块插入。

还请注意，菜单项目和文章的别名均未显示我们在 Artisteer 中输入的页面的标题或文件名。菜单别名是使用 *ct-menu-item-number* 模式创建的。

> 出于 SEO 目的，你应该修改导入文章和菜单项目中的别名。

## WordPress 模板

WordPress 是另一款非常流行的 CMS，使用 PHP 语言编写。

使用它，你需要一个支持 PHP 的托管账户以及访问一个 MySQL 数据库。

你也可以在 `wordpress.com` 域名上注册系统的免费实例。

该软件在 GPL 许可证下发布，你可以从官方项目页面 `wordpress.org` 免费下载。

WordPress 是 b2/cafelog 博客系统的继任者，最初也是一款博客平台。

随着时间的推移和新版本的发布，该系统已经成熟，现在可以被视为一个完整的 CMS 系统。

WordPress 与其他解决方案的区别在于其易用性和易于管理，使其成为初学者的最佳选择之一。

WordPress 不仅是一个非常用户友好的解决方案，而且其核心功能可以通过各种插件进行扩展（市场上既有免费也有商业的，数以千计），使该 CMS 成为一个可扩展的解决方案，适用于许多项目。在撰写本书时，可用的最新 WordPress 版本是 3.5.1。

## 导出 WordPress 模板

导出 WordPress 模板时，你必须选择 WordPress 作为目标平台。请确保在导出窗口中，模板字段中选择了 WordPress 主题。

![](img/7f889df2ffdb68108cff34d798a2b9a3_116_1.png)

导出 WordPress 主题

其余设置与 Joomla！的导出类似。请确保已勾选 ZIP 归档选项。这将允许你直接从 WordPress 管理面板安装模板。

你还可以点击 **选项** 按钮并设置 WordPress 特定设置。它们并不多。你可以定义菜单项中主页的文本，以及该项目是否应显示。

![](img/7f889df2ffdb68108cff34d798a2b9a3_117_0.png)

与 WordPress 相关的导出选项

导出 WordPress 模板后，就该将其安装到 CMS 中了：

- 1. 登录管理面板。
- 2. 从菜单导航至 **外观** | **主题**。
- 3. 点击 **安装主题** 选项卡（屏幕顶部）。
- 4. 点击 **上传** 链接。
- 5. 点击 **浏览** 按钮，指向导出的主题文件，然后点击 **立即安装**。

![](img/7f889df2ffdb68108cff34d798a2b9a3_117_1.png)

在 WordPress 中安装新模板

一段时间后，模板已安装，但如果我们想让它显示，就必须激活它。

- 6. 点击 **激活** 链接。如果刷新网站，你将看到它已使用我们的模板显示。

## 设置模板

现在，我们的模板已安装并激活，是时候设置它了。

## 标题和标语

我们要做的第一件事是为页面设置正确的标题和标语。为此，请执行以下步骤（我们假设你已登录 WordPress 控制面板）：

- 1. 从菜单导航至 **外观** | **主题**。
- 2. 找到你的模板并点击 **自定义** 链接。
- 3. 点击 **站点标题和标语** 选项。
- 4. 在 **站点标题** 字段中输入正确的标题，在 **标语** 字段中输入标语。

![](img/7f889df2ffdb68108cff34d798a2b9a3_118_0.png)

- 5. 点击 **保存并发布** 按钮。

## 自定义页脚

如果你的模板已导入并激活，你可以自定义网站的页脚。为此，登录管理面板并从左侧主菜单导航至 **外观** | **主题选项**。然后在主屏幕区域向下滚动并找到 **页脚** 部分。点击 **覆盖默认主题页脚内容** 并启用下面的字段。现在你可以输入你想要的页脚的任何内容。因为它不是所见即所得编辑器，所以你需要手动编写 HTML 标签。

![](img/7f889df2ffdb68108cff34d798a2b9a3_118_1.png)

## 导入内容

如果你在安装并激活模板后通过从 Artisteer 导出模板勾选了包含内容选项，将会询问你是否要从模板导入内容：

![](img/7f889df2ffdb68108cff34d798a2b9a3_119_0.png)

将内容从 Artisteer 生成的模板导入到 WordPress

根据你的需求，你可以决定将导入的内容添加到 WordPress 中已有的内容中，替换现有内容，或直接点击关闭按钮拒绝导入内容。我们点击替换导入内容。

一段时间后，我们的内容将被导入并放入 CMS。你可以刷新页面并看到内容可用且已显示。

我们可以看到内容已被导入并以以下方式显示：

- Artisteer 项目中的所有普通页面都已作为页面导入。所有页面的父级属性均已正确设置。网站结构得以保留。
- Artisteer 中的所有博客文章都已作为文章导入。所有文章都属于未分类分类。

已创建了两个菜单，即 Sample HMenu（水平菜单）和 Sample VMenu（垂直菜单）。页面和文章已与其它 CMS 系统的菜单相关联。

我们描述了 Joomla！和 WordPress 的安装和导入内容，因为它们都是非常流行的解决方案。然而，Artisteer 支持更多 CMS 系统，并且随着 Artisteer 4 中引入 SDK，有可能扩展支持的系统数量。我们可以预期支持的 CMS 数量将会增加。
