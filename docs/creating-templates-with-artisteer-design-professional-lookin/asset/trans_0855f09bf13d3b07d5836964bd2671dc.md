
## 导出模板

现在我们已经设计并保存了项目，是时候导出它了。要导出项目，请点击功能区快捷区域中的 **Export** 图标，或从菜单中选择 **File | Export | Website Template**。我们将以 **Website Template** 的形式导出项目。这意味着它将是一个静态的普通网站，不由任何 CMS 系统驱动。

![](img/7f889df2ffdb68108cff34d798a2b9a3_32_0.png)

导出项目

如以下屏幕截图所示出现的窗口中，我们需要设置一些参数：

![](img/7f889df2ffdb68108cff34d798a2b9a3_32_1.png)

在导出窗口中，您设置导出参数

- **Template**：这是一个可以更改为所需导出模板类型（CMS 系统）的字段。我们保持原样，使用 **Website Template**。
- **Export to:** 这是一个字段，您可以在其中确定是否要将其导出到 **Local**（作为硬盘上的文件）或 **FTP**（直接传输到您的 Web 服务器）。我们希望将其导出为 **Local**。
- **Folder Name:** 这是将会创建的文件夹名称，也是所有模板文件将被保存的位置。此名称不能包含空格和命名文件夹时禁止使用的字符（例如 \、/、? 等）。让我们删除默认值（**Untitled**）并输入 `myFirstTemplate`。
- **Path:** 这是创建文件夹的导航路径。点击浏览图标并选择您的桌面。

> 尽管 Windows 不区分大小写，Linux 却区分，而您的 Web 服务器很可能运行在 Linux 上。命名文件夹时，请注意输入的名称大小写。

下面还有两个附加选项：

- **ZIP archive:** 如果勾选此复选框，模板将不会保存在新文件夹中，而是作为 ZIP 压缩包保存，名称为你在 **Folder Name** 字段中输入的名称。此选项应为大多数 CMS 勾选。由于我们目前不导出到任何 CMS，因此我们保持此选项未勾选。
- **Include ARTX Project:** 如果此选项被勾选，二进制 Artisteer 项目文件将与其他模板文件一起保存。我建议你保持未勾选，因为我们已经保存了项目。

> 大多数 CMS 都提供通过其管理面板上传的 ZIP 压缩包形式的模板安装功能。如果你为 CMS 导出，你很可能会勾选此选项。

## 删除页脚注释

在点击 **Export** 按钮之前，我们导航到 **Options**（点击该按钮）。默认情况下，Artisteer 会在页脚插入一条注释，说明此模板是用 Artisteer 创建的。由于这是 Extensoft（Artisteer 的生产公司）的巧妙营销手段，在大多数情况下你不会想包含此类信息。

在 **Options** 窗口中，点击左侧最后一项（**Footnote**）并取消勾选 **Include a backward link to the Author** 和 **Include backward links to the CMS and the Artisteer** 选项，如以下屏幕截图所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_34_0.png)

从页脚中删除关于 Artisteer 的注释，即 Created with Artisteer

点击 **OK** 返回到上一个窗口，然后点击 **Export** 导出模板。过了一会儿，进程将完成，你将在桌面上找到一个新文件夹：`myFirstTemplate`。

恭喜！你刚刚在 Artisteer 中设计、保存并导出了你的第一个模板。打开此文件夹并双击 `index.html` 文件。过了一会儿，你将在默认浏览器中看到你的网站。

## 模板

在开始创建模板之前，我们必须先定义模板到底是什么。

一个 **template** 是网站的通用元素集合。你可能会问，什么是网站？一个 **website** 是关于某一特定主题的逻辑连接的网页集合。当我们谈论公司网站时，主题就是公司。对于个人网站，主题就是网站所关于的人，等等。

当然，你可以为每个子页面单独设计，每个页面采用不同的设计。虽然这可行，但这种解决方案会有几个严重的缺点。如下所列：

- 如果页面没有一致的设计和布局，访客可能会觉得被重定向到另一个网站而感到迷失
- 如果每个页面都有不同的、单独的菜单，位于不同的位置，在页面之间导航会很困难，访客不得不专注于如何导航而不是内容
- 网站整体上不会看起来统一

为了避免此类缺点（并且不让访客感到困惑），我们必须让所有子页面看起来相似。这是通过使用相同的图形元素（例如每个子页面上的公司标志）和相同的（或不同但在某种程度上一致的）布局来实现的。

但说所有子页面唯一应该共有的元素只是公司标志（对于公司网站而言）是不够的。网站中可以区分出许多作为共同部分的元素的组合。所有这些元素的组合就是一个模板。

![](img/7f889df2ffdb68108cff34d798a2b9a3_36_0.png)

> 你可能会觉得使用模板限制了设计师的创造力并降低了特定子页面的个性。虽然这是真的，但请记住，目标是创建一个好的网站，而不是单个子页面。而设计师的挑战是创建一个好且有个性的模板。你可以把它与汽车相比：所有汽车都有很多共同点。汽车都有四个轮子、驾驶员和乘客的空间、发动机、后备箱等等。但它们都长得一样吗？当然不是。现在想想保时捷的不同车型。它们看起来足够相似以让每个人都知道那是保时捷吗？我认为是的。这会让保时捷变得丑陋、不吸引人吗？嗯，我不介意开一辆！

## 网站的共同部分

是时候尝试区分网站的共同部分了。我们将把它们分为元素和属性。

元素是网站中独立存在的部分。我的意思是你可以替换它们，而这些更改不会影响网站的其余部分。元素的例子是页脚或菜单。你可以更改页脚的外观（颜色、字体或边框），但这不会影响菜单或其他任何元素。

属性是影响整个网站（所有元素）的东西。属性的例子是页面宽度。如果你决定让网站更宽或更窄，你可能需要重新设计所有元素以适应新的空间。想想前面提到的页脚。页脚通常与整个页面一样宽。如果你让网站更宽，你也必须让页脚更宽。
