
2. 为了实现我们的目标并使标题变蓝，我们需要覆盖 color 属性。定义如下：

```
.art-headline,
.art-headline a,
.art-headline a:link,
.art-headline a:visited,
.art-headline a:hover
{
    color: blue !important;
}
```

3. 我们可以将上述定义追加到 style.css 文件的末尾。我们也可以直接在 Artisteer 中于 Additional CSS styles: 字段中输入它，方法是导航到 Export | Options | CSS Options。结果相同且有效（标题为蓝色）。

4. 与其这样，我们来创建一个全新的文件并将其命名为 myStyles.css。

5. 在此文件中写入我们的定义并将其保存到导出的模板文件夹（OneDayBlue）中。在浏览器中查看网站。我们的修改尚未生效，因为我们还没有将文件与模板连接起来。

6. 要将文件与模板连接，请编辑 index.html 文件。在文件开头，你会找到连接 CSS 文件的行：

```
<!--[if lt IE 9]><script
src="http://html5shiv.googlecode.com/svn/trunk/html5.js"></script>
<![endif]-->
<link rel="stylesheet" href="style.css" media="screen">
<!--[if lte IE 7]><link rel="stylesheet" href="style.ie7.css"
media="screen" /><![endif]-->
<link rel="stylesheet" href="style.responsive.css" media="all">
```

7. 在步骤 6 给出的代码下方，添加以下行：

```
<link rel="stylesheet" href="myStyles.css" />
```

![](img/7f889df2ffdb68108cff34d798a2b9a3_151_0.png)

> 将自己的 CSS 文件与网页连接时的整体模式是 <link rel="stylesheet" href="path-to-your-file" />

8. 保存文件并在浏览器中刷新网站。现在，我们的 CSS 文件已连接到页面，我们的更改已应用。

如果你的网站包含多个网页，你就需要将 CSS 文件与每个页面连接。幸运的是，在 CMS 模板的情况下，通常只有一个主模板文件。

9. 使用此技术，你应记住一些规则，包括：

- **始终覆盖，切勿移除：** 在 CSS 中，每个元素可以被定义多次。后续定义相互补充。在冲突的情况下，最后一个定义具有最高优先级。不要从原始定义中移除属性，而是再次编写该定义并用新值覆盖特定属性。
- **将你的 CSS 文件作为最后一个连接：** 每个页面可以连接多个 CSS 文件。如果来自不同文件的定义发生冲突，则最后连接的文件中的定义将具有最高优先级。将你的文件作为最后一个连接，可以确保你的更改会覆盖 Artisteer 生成的原始定义。

## 复制网页

有时你需要对项目中已有的页面文章进行精确复制。这可能是当你想要有几个相似的页面，仅在某些细节上有所不同时。那么，与其手动逐个复制元素，不如复制源页面，修改细节，然后制作下一个页面。

不幸的是，你不能只用鼠标选择页面的内容然后按 Ctrl + C 来复制内容，因为这样做不会起作用。你只能在单个内容单元格内执行此操作。

解决方案非常简单：

- 1. 在要复制的页面中，在内容区域的任何位置单击。
- 2. 在功能区上单击 Edit 选项卡，然后在 Source 组中单击 HTML 按钮。
- 3. 选中 Edit whole Article HTML 字段。

![](img/7f889df2ffdb68108cff34d798a2b9a3_152_0.png)

- 4. 你会收到一条警告消息，内容为 **编辑后，内容将被合并到一个单元格中**；单击 **OK**。
- 5. 现在在 HTML 编辑器中你将看到页面（文章）的所有内容。用鼠标选择全部文本（或按 *Ctrl + A*），按鼠标右键，然后从内容菜单中选择 **Copy**（或直接按 *Ctrl + C*）将文本复制到剪贴板。
- 6. 单击 **OK** 按钮关闭 HTML 编辑器。
- 7. 创建一个新页面并在内容区域的任何位置单击。
- 8. 在功能区上单击 **HTML** 按钮。
- 9. 删除 HTML 编辑器中的所有内容并粘贴剪贴板中的代码（按 *Ctrl + V*，或按鼠标右键并从内容菜单中选择 **Paste**）。
- 10. 单击 **OK** 按钮关闭 HTML 编辑器。

你会注意到源文章的全部内容已被复制。

## 添加 Lightbox

此提示适用于 HTML 模板。如果使用 CMS，则应使用其中一个可用扩展。

Lightbox 效果是 Artisteer 的一个非常酷的功能，可让你用图片库丰富项目。但 Artisteer 的 Lightbox 没有真正的那么令人印象深刻。拥有一个带有真正的 Lightbox 的画廊不是很好吗？在本提示中，我将向你展示如何修改代码以获得带有真实 Lightbox 的画廊。在此示例中，我们将使用 `betterImageGallery.artx` 项目文件。

![](img/7f889df2ffdb68108cff34d798a2b9a3_153_0.png)

> Lightbox 是使用模态对话框显示图像的一组技术的通用名称。该名称源自 Lokesh Dhakar 创建的原始 JavaScript 插件（有关更多信息，请访问 http://lokeshdhakar.com/projects/lightbox/）。类似 Lightbox 的脚本以漂亮的边框显示图像，并带有导航控件和描述文本。

我们将使用基于 jQuery 库的 Lightbox2 效果。有许多类似 Lightbox 的效果可用，但这个效果功能强大且易于使用。Artisteer 为其自己的 Lightbox 效果使用 jQuery，并在导出项目时默认附加此库，因此使用基于此库的效果是个好主意。以下是我们的流程：

- 1. 在开始之前，我们需要准备一些额外的文件。Artisteer 将包含 jQuery 库，但我们需要我们的 Lightbox2 效果。你可以从其作者网站 `http://lokeshdhakar.com/projects/lightbox2/` 免费下载。前往此页面并下载文件。这将是一个 ZIP 压缩包，包含多个文件夹和文件。这些文件并非全部真正需要，但为简单起见，只需解压压缩包即可。你将获得一个 `Lightbox` 文件夹。
- 2. 安装包不仅包含必要的文件，还包含示例页面、jQuery 库和一些示例图像。如果只想要真正需要的内容，可以删除不必要的文件，只保留以下截图方案中显示的文件：
- 3. 我们需要的第二个资源是我们要在画廊中显示的图像。对于此示例，我已将简单的图像包准备到 ZIP 压缩包中。解压 `galleryImages.zip` 文件。你应该拥有包含八张简单图像的 `galleryImages` 文件夹。
- 4. 现在，当我们准备好所需的额外文件后，启动 Artisteer 并打开 `betterImageGallery.artx` 项目文件。你会看到它只是一个单页模板，内容区域中有八个空单元格。使用 Lightbox 的图像画廊概念是页面上显示图像缩略图。每个缩略图都是指向对应大图的链接。在没有 Artisteer 的情况下，我们需要准备图像缩略图，但我们不必担心这一点，因为 Artisteer 在将图像插入单元格时会正确调整每个图像的大小。

![](img/7f889df2ffdb68108cff34d798a2b9a3_154_0.png)

5. 在每个单元格中放置我们集合中的一张图像。你的项目应类似于以下截图所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_155_0.png)

我们画廊的初始状态，其中内容区域的单元格中有缩略图

6. 现在将项目导出到文件夹中，并将其命名为 `ImageGallery`。打开此文件夹并双击 `index.html` 文件以在浏览器中查看网站。

7. 默认情况下，每张图片都启用了 Lightbox 效果。由于我们将用另一个效果替换 Artisteer 的 Lightbox 效果，因此需要将其关闭。返回 Artisteer，对每张图像按鼠标右键，选择内容菜单中的 **Image Options** 选项，并在 **Image Options** 窗口中将 **Preview** 字段的值设置为 **No**。

![](img/7f889df2ffdb68108cff34d798a2b9a3_155_1.png)

我们需要为画廊中的每张图像关闭 Lightbox 效果

8. 再次以相同名称和位置导出项目，覆盖任何先前文件。
