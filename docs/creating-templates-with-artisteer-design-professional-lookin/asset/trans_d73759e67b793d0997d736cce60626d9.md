## 为特定模块设置样式

此提示适用于 Joomla! 模板。例如 `specialModule.artx` 文件。

此提示基于 Joomla! 中使用的标准技术，但在 Artisteer 的情况下，需要进一步解释。

这种情况很常见，你希望你的某个模块与其他模块看起来不同。例如，你可能希望登录模块或其他模块与其他模块区分开来。对于自定义 HTML 模块，你当然可以直接在模块中修改 HTML，但此提示允许你在不触碰 HTML 的情况下完成此操作，并且仅基于 CSS 修改。

> 此技术适用于从模板样式表获取 CSS 的模块。它不适用于单独渲染并带有自己样式的自定义扩展。在这种情况下，你必须查看特定扩展的源代码并相应地修改代码。

在我们的示例中，我们将区分登录模块，使其对访客更醒目。

在 Artisteer 中设计时，你无法使某个模块与其他模块不同，因为更改会传播到其他区块。这就是我们需要解决方案的原因。

我们正在处理带有内容的 `specialModule.artx` 项目。打开它并导出到 Joomla!。你的网站应如下截图所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_135_0.png)

示例网站，左右两列有两个相同的模块

该网站只有一个页面，采用三列布局，左右两列各有一个相同的模块。它们作为两个独立的自定义 HTML 模块导入，但都由 Artisteer 创建。我们的任务是在不修改其 HTML 的情况下区分第二个模块，具体如下：

- 1. 在 Joomla! 的管理面板中，导航到 **Extensions | Module Manager**。你将进入 **Module Manager** 中的 **Modules** 屏幕，其中将列出所有已安装的模块。找到并点击 **Second Block** 模块以进入其设置。
- 2. 在 **Module Manager: Module Custom HTML**（**Second Block** 模块设置）中，展开 **Advanced Options** 区域并找到 **Module Class Suffix** 字段。在此字段中，我们将输入合适的后缀。

3. 如以下截图所示，在 Module Class Suffix 字段中输入 _SpecialModule：

![](img/7f889df2ffdb68108cff34d798a2b9a3_136_0.png)

将 _SpecialModule 作为模块类后缀输入

4. 根据你在该字段中输入的 Module Class Suffix 名称，Joomla! 将搜索在模板 CSS 样式中定义的新类定义。它是按照 art-block + 空格 + clearfix + 你在字段中输入的内容 的模式进行的。

在我们的情况下，这意味着 art-block + _SpecialModule = art-block clearfix_SpecialModule

Joomla! 在渲染页面时，将在 CSS 样式表中查找 art-block clearfix_SpecialModule 定义。这意味着我们的区块将使用来自两个类的样式：art-block 和 clearfix_SpecialModule。

art-block 类最初由 Artisteer 定义。查看源代码中的此类并分析它。此类定义了区块的背景、边框和圆角。我们的区块将从两个类获取样式，这非常方便——我们无需从头定义一切，只需添加补充定义即可。更重要的是，因为我们的类定义在后面，我们的定义将覆盖来自 Artisteer 的原始定义。我们可以随时删除我们的类以恢复模板的原始外观。

5. 我们需要在 CSS 模板文件中添加我们的类。此文件名为 template.css，位于模板文件夹的 CSS 文件夹中。在编辑器中打开此文件，并在末尾写入：

```
/*** My Classes ***/
.clearfix_SpecialModule
{
border: 1pt solid red;
  background-color: #FFFF99;
}
```

我们已覆盖边框的宽度和颜色，并将背景颜色设置为淡黄色。保存文件并刷新页面。你应该会看到如下截图所示的内容：

![](img/7f889df2ffdb68108cff34d798a2b9a3_137_0.png)

右侧的区块与左侧的孪生兄弟看起来大不相同

6. 到目前为止，一切顺利。让我们执行下一步并更改文本的字体。在我们的类中添加另一行代码，使其如下所示：

```
.clearfix_SpecialModule
{
  border: 1pt solid red;
  background-color: #FFFF99;
  color: blue;
}
```

7. 保存更改，刷新页面，……什么也没发生！有些不对劲。撤销更改（从我们的类中删除最后的定义），然后让我们查看页面的源代码。显示我们区块的代码片段如下：

```
<div class="art-block clearfix_SpecialModule">
  <div class="art-blockheader">
    <h3 class="t">Second Block</h3>
  </div>
  <div class="art-blockcontent">
    <div class="custom_SpecialModule"  >
```

```
    <!--
    content of our block:
    <p> elements, image and list
    -->
    </div>
    </div>
    </div>
```

现在我们需要牢记以下规则：

- `DIV` 元素包含整个区块，属于以下两个类：
  - `art-block`
  - `clearfix_SpecialModule`（根据我们的后缀）
- 标题位于一个 `DIV` 元素内。该元素属于 `art-blockheader` 类。标题本身是一个 `h3` 元素，属于 `t` 类。
- 我们区块的内容位于一个 `DIV` 元素内。该元素属于 `custom_SpecialModule`（根据我们的后缀）类，并且位于另一个属于 `art-blockcontent` 类的 `DIV` 元素内。
