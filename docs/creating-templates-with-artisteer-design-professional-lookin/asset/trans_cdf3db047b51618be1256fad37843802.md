
- 4. 单击 **OK** 按钮返回到上一个窗口。再次单击 **OK** 按钮关闭窗口。
- 5. 单击我们的文本。你不需要选择整段文本，只要文本光标在文本中的某处闪烁即可。
- 6. 功能区的 **Edit** 选项卡应自动被选中。展开样式列表（你可以在 **Style and Font** 组中找到它）并选择 **Heading 6**。我们的文本样式将会改变并看起来像我们设计的那样。

![](img/7f889df2ffdb68108cff34d798a2b9a3_85_0.png)

![](img/7f889df2ffdb68108cff34d798a2b9a3_85_1.png)

> 我们已更改了 **Heading 6** 元素的定义并将其应用于 `Look at my latest projects...` 文本。在我们的情况下这是可以接受的，因为我们在项目中不使用完整的排版。如果我们网站内容的结构如此复杂，以至于需要全部六个标题级别，我们就不能浪费标题样式仅用于文本。相反，我们应该使用 **Paragraph** 样式设置文本，然后手动更改字体。设计标题级别的总体规则是，每个下一级应比上一级略小一些，以直观地说明标题的逻辑层次结构。

我们将修改段落文本并使其稍微大一些，与我们更改 **Header 6** 元素的方式相同。类似于 **Header 6** 元素，再次编辑排版，并在 **Typography** 窗口中将 **Default** 元素的字体大小设置为 **14 px**。

你可以同样修改排版的任何元素。创建良好的排版不是一项简单的任务，但它是整体模板的重要因素。

如果你以后想使用我们修改过的排版，可以使用 **Save Typography** 按钮以任意名称保存它。

**Fonts** 组中的最后一个按钮是 **Font Scale**。使用此按钮可以非常快速地一次性更改所有文本元素的大小。**Options...** 按钮会带你进入窗口，在那里你可以手动设置文本的比例。

## Color theme

我们已为模板选择了配色主题，但我们没有深入探讨这个话题。这是因为我们希望快速开始设计，同时也因为我们需要在更了解 Artisteer 的使用方法后才能处理这个问题。

配色主题是模板中使用的颜色集合。逻辑上它类似于字体集和排版。排版定义了各种模板元素中使用的文本，而配色主题则定义了它们的颜色。

要修改主题的颜色，可以使用位于 Paints 组中的三个按钮（我们仍在 Fonts & Colors 选项卡中）。这三个按钮以填充特定颜色的矩形形式出现，让你选择涂料的颜色。

Paints 是配色主题中使用的主要颜色。你可以将其视为整个配色主题构建的基础。Artisteer 中的每个配色主题都有三种涂料。

![](img/7f889df2ffdb68108cff34d798a2b9a3_86_0.png)

> 与特定涂料和模板元素之间没有固定的关系。例如，你不能说更改第二个涂料总会改变背景颜色。主题颜色的分布在各种模板中会发生变化。

使用最后一个标有 Adjust 的按钮，你可以更改配色主题中所有涂料的亮度和饱和度。可用选项分为四个组，其名称暗示了更改（Basic、Normal、Contrast 和 Pastel）。

如果你修改了配色主题中的涂料并且对更改感到满意，可以以任意名称保存它，并在未来的项目中使用。

## Footer

我们需要设计的最后一件事是页脚。所有适用于页脚的工具都位于 Footer 选项卡上——尽管你会发现在这方面并不那么明显。问题在于，许多你可以用 Footer 选项卡的工具定义的事情，也可以使用 Edit 选项卡上的类似工具实现。更重要的是，Edit 选项卡工具所做的设置优先级高于 Footer 选项卡工具所做的设置。例如，你可以使用 Footer 选项卡中的 Align 按钮将页脚文本右对齐，同时使用 Edit 选项卡中的对齐图标将同一文本左对齐。结果，文本将被左对齐。

![](img/7f889df2ffdb68108cff34d798a2b9a3_87_0.png)

> 如果 **Footer** 选项卡的设置与 **Edit** 选项卡的设置冲突，则 **Edit** 选项卡的设置具有更高的优先级。
> 
> 如果你觉得 **Footer** 选项卡中的选项完全不起作用，请检查是否已使用 **Edit** 选项卡中的工具设置了相同的属性。例如，如果你在 **Edit** 选项卡中设置了文本颜色，则使用 **Footer** 选项卡中的按钮更改它将没有任何效果，因为该属性已被来自 **Edit** 选项卡工具的优先级更高的设置覆盖。

**Footer** 选项卡上的工具分为两个组：**Layout** 和 **Footer Styles**。**Layout** 组中的第一个按钮 **Length and Position** 让你选择三种页脚类型之一。（为了更好地理解它们的工作原理，你可以使用 **Fill** 按钮暂时为整个页脚设置不同的背景颜色。）

**Inside Sheet** 页脚位于模板内部。页脚左侧、右侧和下方都有网站背景：

![](img/7f889df2ffdb68108cff34d798a2b9a3_87_1.png)

Inside Sheet 页脚：页脚下方和两侧都有背景

**Sheet Width, Screen Height** 页脚填充整个空间直至屏幕底部。页脚下方没有空余空间（背景）：

![](img/7f889df2ffdb68108cff34d798a2b9a3_88_0.png)

Sheet Width, Screen Height 页脚：页脚填充下方所有空间

**Page Width, Screen Height** 页脚填充内容下方所有空间，且宽如整个页面。页脚左侧、右侧和下方没有空余空间（背景）：

![](img/7f889df2ffdb68108cff34d798a2b9a3_88_1.png)

Page Width, Screen Height 页脚：页脚填充内容下方所有位置

**Margin** 按钮让你定义内容底部边缘与页脚顶部边缘之间的垂直空间。

对于我们的项目，选择 **Inside Sheet** 选项。

使用 **Fill** 按钮可以定义页脚面板的颜色。可用颜色列表展示了属于配色主题的颜色。你也可以单击 **More Colors...** 并自由地从完整调色板中选择。此列表上的最后一个按钮让你设置页脚面板的透明度。

对于我们的项目，选择第二行中的第一个颜色（来自 **Theme Colors** 组）并将透明度设置为 50%。

**Separator** 按钮让你定义分隔页脚的线的外观。你可以设置该线的宽度（**Weight**）、样式和颜色。

其余按钮你不应有任何问题，因为它们的行为类似于放置在其他选项卡上的类似工具。唯一让你惊讶的是当你单击 **Text** 按钮时。单击它，你将被重定向到功能区上的 **Edit** 选项卡！
