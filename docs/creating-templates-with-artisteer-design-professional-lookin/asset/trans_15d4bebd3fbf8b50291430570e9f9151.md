
幻灯片显示为两个容器，内部容器包含其自己的内部容器——特别是幻灯片。每个幻灯片都表示为一个 `<div>` 元素（在 `<header>` 部分中的 jQuery 脚本执行其工作之前）。

5. 要使每个幻灯片成为链接，我们将在每个幻灯片中添加一些基本的 JavaScript；具体来说，我们将处理 `onClick` 事件（换句话说，我们将定义当访客点击代表特定幻灯片的此 `<div>` 元素时应该发生什么）。由于这只是一个单行脚本，因此无需将其作为 `<script>` 元素在代码中分离。

我们将按照以下模式添加内容：

```
onclick=location.href('address_to_be_redirected_to')
```

例如：

```
onclick=location.href('www.google.com')
```

此 `onclick` 事件将把访客重定向到 www.google.com。

6. 让我们修改代码并添加链接：

```
<div class="art-slider art-slidecontainer79">
  <!-- The external container, containing the slideshow -->
  <div class="art-slider art-slidecontainer79">
    <!-- Slideshow container -->
    <div class="art-slider-inner">
      <!-- First slide. Link to: www.artisteer.com -->
      <div class="art-slide-item art-slide790"onclick="location.href='http://www.artisteer.com'"></div>
      <!-- Second slide. Link to: www.google.com -->
      <div class="art-slide-item art-slide791" onclick="location.href='http://www.google.com'"></div>
      <!-- Third slide. Link to: www.example.com -->
      <div class="art-slide-item art-slide792" onclick="location.href='http://www.example.com'"></div>
      <!-- Fourth slide. Link to www.packtpub.com -->
      <div class="art-slide-item art-slide793" onclick="location.href='http://www.packtpub.com'"></div>
    </div>
  </div>
</div>
```

7. 保存文件并在浏览器中查看。幻灯片现在充当链接。解决方案有效，但让鼠标指针指示存在链接会很有用。我们将通过一点 CSS 实现这一点，设置鼠标光标的外观。我们需要在每个幻灯片定义中添加以下文本：

```
style="cursor: pointer;"
```

8. 修改后，我们将有以下代码：

```
<!-- The external container, containing the slideshow -->
<div class="art-slider art-slidecontainer79">
    <!-- Slideshow container -->
    <div class="art-slider-inner">
        <!-- First slide. Link to: www.artisteer.com -->
        <div class="art-slide-item art-slide790"
onclick="location.href='http://www.artisteer.com'"
style="cursor: pointer;"></div>
        <!-- Second slide. Link to: www.google.com -->
        <div class="art-slide-item art-slide791"
onclick="location.href='http://www.google.com'"
style="cursor: pointer;"></div>
        <!-- Third slide. Link to: www.example.com -->
        <div class="art-slide-item art-slide792"
onclick="location.href='http://www.example.com'"
style="cursor: pointer;"></div>
        <!-- Fourth slide. Link to www.packtpub.com -->
        <div class="art-slide-item art-slide793"
onclick="location.href='http://www.packtpub.com'"
style="cursor: pointer;"></div>
    </div>
</div>
```

9. 好多了！我们应该做的最后一件事是添加提示以告知访客将被重定向到哪个页面。为此，我们需要在代表幻灯片的每个 <div> 中添加 title 参数，如下所示：

```
title="description of the link"
```

10. 我们的最终代码如下所示：

```
<!-- The external container, containing the slideshow -->
<div class="art-slider art-slidecontainer79">
    <!-- Slideshow container -->
    <div class="art-slider-inner">

onclick="location.href='http://www.example.com'"
```

11. 就这样。修改后，我们幻灯片中的每个链接都是指向另一个网页的链接。鼠标光标的形状是手形，这是超链接的典型特征。此外，还有简短的说明，说明您将被重定向到哪里。

## 从某些页面移除垂直菜单

此提示适用于 HTML 模板。一个示例项目将是 chapterTwo.artx 项目文件。

在 Chapter2《逐步模板》中，我们准备了一个带有水平菜单和垂直菜单的模板。水平菜单是我们网站的主菜单，显示与直接链接页面相关的项目，而垂直菜单是补充菜单，显示我们提供的详细信息。我们得出的结论是，组织菜单的最佳方式是仅在 Offer 页面的子页面上显示垂直菜单。这比在每个页面上显示我们提供的详细信息更好、更合乎逻辑。

不幸的是，Artisteer 不允许我们定义菜单应在哪些页面上显示，并且两个菜单都在每个页面上显示。解决此限制的方法是创建带有两个菜单的模板（如我们所做的那样），然后从我们不想显示它的页面中删除垂直菜单。这样我们将使垂直菜单充当水平菜单的子菜单。让我们开始：

- 1. 让我们再次从 *第 2 章，逐步模板* 导出项目，然后打开 `index.html` 文件（我们网站的首页）。
- 2. 现在查看 Artisteer 创建的文件。你将看到四个 `.html` 文件，它们是站点结构顶层的页面，即 `home`、`about me`、`offer` 和 `contact`。
- 3. **Offer** 页面的子页面位于名为 `Offer` 的单独文件夹中。文件夹和文件的结构反映了网站的逻辑结构。这使我们的任务更简单。位于 `Offer` 文件夹中的所有 `.html` 文件都应显示垂直菜单，而我们应将其从位于主项目文件夹中的 `.html` 文件中删除。
- 4. 让我们打开 `index.html` 文件并在代码中搜索垂直菜单。你会找到类似以下的内容：

```
<div class="art-vmenublockcontent">
<ul class="art-vmenu">
<li>
<a href="offer.html">Offer</a>
<ul>
<li>
<a href="offer/websites.html">Websites</a>
</li>
<li>
<a href="offer/wordpress.html">WordPress</a>
</li>
<li>
<a href="offer/joomla.html">Joomla!</a>
</li>
<li>
<a href="offer/dotnetnuke.html">DotNetNuke</a>
</li>
</ul>
</li>
</ul>
</div>
```

我们看到整个垂直菜单的主容器是一个 `<div>` 元素，其类为 `art-vmenublockcontent`。这是我们任务的关键信息。然后菜单项是一个列表。菜单项的下一级表示为该列表的下一级。

- 5. 要从页面中删除垂直菜单，只需删除主菜单容器及其所有内容（之前的代码）。现在，保存文件并在浏览器中刷新页面。我们看到垂直菜单已从 **HOME** 页面消失。
- 6. 太好了！现在，对其余的顶级站点重复整个操作，即 `about_me.html`、`offer.html` 和 `contact.html` 文件。
  结果，这些页面上不再有垂直菜单。
- 7. 因为我们没有触及 `Offer` 文件夹中的页面，所以 **Offer** 页面的子页面（**Websites**、**WordPress**、**Joomla!** 和 **DotNetNuke**）显示垂直菜单。
