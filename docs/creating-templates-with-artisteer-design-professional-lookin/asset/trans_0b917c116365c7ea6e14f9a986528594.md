
## 为项目添加额外的 CSS

本技巧适用于所有类型的模板。在本示例中，我们将使用 HTML 模板进行操作。

如果你需要向原始模板的样式表中添加一些自己的 CSS，可以直接从 Artisteer 中进行操作。此功能也可能很有用，如果你想修改原始 Artisteer 类。以下是本技巧的步骤：

- 1. 在本示例中，我们使用 AddCssToProject.artx 项目文件。打开它。这是我们在第 2 章《逐步模板》中看到的站点，但我在联系页面中添加了一个简单的联系表单。

在本示例中，我们将添加一些 CSS 定义以实现三个目标：
- 我们希望更改 CSS 类的默认 Artisteer 前缀。
- 我们希望在鼠标光标移动到图片上时区分图片（悬停效果）。此效果应仅适用于具有 Lightbox 效果的图片。
- 我们希望区分联系表单中的活动控件。

- 2. 要向生成的代码添加 CSS，请单击 Export 按钮，然后在 Export 窗口中单击 Options 按钮。在出现的 Options 窗口中，单击左侧的 CSS Options 面板。窗口右侧将显示可用的选项。你会看到有两个字段，即 CSS Prefix: 和 Additional CSS Styles:

CSS Prefix: 字段包含将用于命名导出模板中生成的 CSS 类的前缀。默认值是 art-。

![](img/7f889df2ffdb68108cff34d798a2b9a3_146_0.png)

- 3. 回顾我们在 *从头开始设置样式* 技巧中使用的标准类。我们使用的是 `art-block`、`art-nostyle` 和 `art-article` 类。其名称的第一部分就是你在该字段中输入的前缀。假设我在这里写 `jakub-`（取自我的名字）。在这种情况下，Artisteer 将生成类名，即 `jakub-block`、`jakub-nostyle` 或 `jakub-article`，而不是 `art-block`、`art-nostyle` 或 `art-article` 类。更改默认 CSS 类前缀不会改变代码中的任何内容，只是类名。那么为什么要这样做呢？有两个原因：
- 有时你可能想隐藏你是用 Artisteer 准备项目的事实。有些人认为 Artisteer 生成的模板比手工制作或使用其他工具制作的模板便宜。他们是否正确超出了本书的范围。如果你需要，可以将此前缀更改为其他任何内容。
- 你可能有一个在指定类名上运行的外部脚本。在这种情况下，调整模板代码中的名称可能比调整脚本中的名称更快。

- 4. **CSS Prefix:** 字段下方的 **Additional CSS styles:** 字段是一个文本区域，你可以在其中放置任何额外的 CSS 代码。此代码将被添加到 `style.css` 文件的末尾。不幸的是，没有代码编写支持，例如语法着色或至少更改字体，因此最好在外部编辑器中准备代码，然后在此处粘贴。

- 5. 好的，让我们在 **Additional CSS styles:** 字段中放入一些代码来实现我们的任务。我们希望在鼠标光标悬停在图片上时区分图片，并在控件处于活动状态时区分联系表单中的控件。将以下代码写入此字段：

/* hover pseudo-class for images
   We use opacity filter */
img:hover
{
    opacity : 0.4;
    filter: alpha(opacity=40);
}

/* and for inputs while they are focused.
   We set their background color as yellow */
input:focus
{
    background-color: yellow;
}
```

- 6. 单击 OK 按钮关闭窗口并导出模板。你将看到我们的代码成功运行，如以下屏幕截图所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_148_0.png)

活动输入元素用黄色背景区分

> 实际上你甚至不需要导出模板就可以观察到更改。我们的附加代码也在 Artisteer 界面中被解释。

唯一的问题是图像效果适用于所有图像，而不仅仅是具有 Lightbox 效果的图像。好吧，这是正确的，因为我们为所有图像定义了 hover 伪类。为了解决这个问题，我们必须知道启用了 Lightbox 效果的图片的类。查看我们主页的源代码，你会注意到该类称为 img.Lightbox。

- 7. 好的，那么让我们修改我们的代码：

```
img.art-Lightbox:hover
{
  opacity : 0.4;
  filter: alpha(opacity=40); /* msie */
}

input:focus
{
  background-color: yellow;
}
```

到目前为止，我们的解决方案按计划工作——我们为具有活动 Lightbox 效果的图片缩略图（图像库）提供了悬停效果，而联系表单上的控件在获得焦点时用黄色背景区分。我们修改了原始 Artisteer 创建的 `img.art-Lightbox` 类并为活动输入添加了伪类。

- 8. 如果你编辑导出模板中的 `style.css` 文件，你会看到我们的代码被适当的注释包围，显示修改的开始和结束。

在 **Additional CSS styles:** 字段中编写代码并不太舒适，你可能会想为什么要把代码放在这里而不是直接编辑导出文件的代码，或使用自己的附加 CSS 文件。我同意使用任何代码编辑器编写代码肯定更方便，但你应该记住使用本示例中描述的技术的一个优点，直接在 Artisteer 中操作也有一些优点。如果你直接将代码放入 Artisteer，你的代码将与 `.artx` 项目文件一起存储，这意味着你不必记住你的更改并在每次导出后重写它们，这对未来的更改很方便。这就是我认为如果更改不大并且你不必触及导出的其余代码，这可能是一种相当好的方法。

## 修改 CSS 文件的另一种方法

本技巧适用于所有类型的模板。一个例子是 `OneDayBlue.artx` 文件。

在 *从头开始设置样式* 和 *为项目添加额外的 CSS* 技巧中，我们修改了相关项目的 CSS 样式表。这些示例中的每一个都提出了解决问题的不同方法：
- 我们修改了一个导出的 CSS 模板文件
- 我们直接在 Artisteer 中添加了一些 CSS 定义

这些技术各有优缺点。如果你编辑导出的 CSS 文件，可以使用你喜欢的文本编辑器进行操作，该编辑器可能配备了许多使工作更舒适的工具（如代码高亮）。此外，在编辑导出的 CSS 文件时，你可以看到所有内容（模板中使用的 CSS 定义），而无需蒙眼编写。这种方法的缺点是，如果你使用 Artisteer（使用 GUI）修改项目并再次导出新版本，你的文件将被新文件覆盖，你的修改将丢失。你必须重写你的更改。

如果你直接在 Artisteer 中添加 CSS，你的修改将存储在 .artx 项目中。你可以多次修改项目并导出它，你的附加 CSS 代码将被保留。虽然这听起来像是一种更好的方法，但由于 Artisteer 缺乏编辑工具而在其中编写 CSS 的不便，以及你看不到其余代码的事实，这使得它非常不方便。

第三种方法是将所有修改写入并保存到单独的 CSS 文件中，然后将其与导出的其余文件连接起来。你可以将 CSS 文件的副本与 Artisteer 项目一起存储。如果你对 Artisteer 中的内容进行了更改，可以导出项目并再次将其与你的文件连接，所需的工作量和时间最少。这样，你就可以舒适地使用你喜欢的文本编辑器编辑 CSS 代码，并且在下一次导出时不会丢失你的工作。

让我们在实践中看看这种技术。打开示例文件（OneDayBlue.artx）并查看模板。这只是 Artisteer 的 Blank 模板，只有一个页面，页眉中有一个标准的橙色标题：

![](img/7f889df2ffdb68108cff34d798a2b9a3_150_0.png)

我们的任务并不令人惊讶。我们需要修改导出的 CSS 文件以使此文本变为蓝色。我们按如下方式操作：

- 1. 将此模板导出为 HTML 模板到 OneDayBlue 文件夹并编辑 style.css 文件。站点标题的 CSS 定义是：

```
.art-headline,
.art-headline a,
.art-headline a:link,
.art-headline a:visited,
.art-headline a:hover
{
font-size: 36px;
font-family: Arial, 'Arial Unicode MS', Helvetica, Sans-Serif;
font-weight: normal;
font-style: normal;
text-decoration: none;
text-shadow: 0px 2px 3px rgba(0, 0, 0, 0.3);
padding: 0;
margin: 0;
color: #FA6114 !important;
white-space: nowrap;
}
```
