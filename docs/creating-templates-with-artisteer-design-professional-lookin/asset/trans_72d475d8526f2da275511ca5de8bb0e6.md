
8. 知道了这一点，我们可以编写一些额外的定义，让我们的区块看起来更不一样。我们将把标题的颜色设置为绿色，以斜体样式显示内容文本，更改其字体样式，并为图片添加边框：

```
/*** My Classes ***/
.clearfix_SpecialModule
{
    border: 1pt solid red;
    background-color: #FFFF99;
}

.clearfix_SpecialModule .art-blockheader h3
{
    color: green;
}

.custom_SpecialModule p
{
    font-family: "Tahoma";
    font-style: italic;
}

.clearfix_SpecialModule .custom_SpecialModule img
{
    border: 1px solid #000000;
}
```

好的，我们已经实现了目标，让我们的区块看起来不同。但这种技术的最大优势是，在样式定义好之后，你可以将其用于任何模块，而无需额外工作。为了说明这一点，我们将从我们的 **Second Block** 中移除样式并将其应用到登录框：

- 1. 在管理面板中编辑 **Second Block** 模块并清空 **Module Class Suffix** 字段。**Second Block** 将再次看起来与 **First Block** 完全相同。
- 2. 创建 **Login** 模块并将其放置在右侧栏中 **Second Block** 的下方。显示该模块（**position-7**）。
- 3. 编辑你的 **Login** 模块的首选项，并在 **Module Class Suffix** 字段中输入 `_SpecialModule`（这就是我们的后缀）。
- 4. 保存更改并刷新网站。你会注意到 **Login** 模块已采用我们之前定义的样式。

## 从零开始设置样式

在之前的示例中，我们通过将我们的类与标准的 `art-block` Artisteer 类混合来设置 **Second Block** 的样式。但有时，你可能更感兴趣的是移除所有模板样式并从零开始设置某个模块的样式。为此目的，Artisteer 提供了一个名为 `art-nostyle` 的特殊类。该类的名称应为后缀的第一部分。

> > 事实上，当你使用 `art-nostyle` 类来组成你的后缀时，模块也会获得两个类的定义，即 `art-nostyle` 和你自己的（名称来自后缀）。但使用 `art-nostyle` 类会导致模块在省略模板样式的情况下显示，因此实际上效果就像模块根本没有样式一样。

在本示例中，我们将在项目中使用相同的 **Second Block**。步骤如下：

- 1. 如果你已根据之前的示例修改了模板 CSS 文件，请删除模板并重新安装一次。这将防止你的 `template.css` 文件变得杂乱。假设 **First Block** 和 **Second Block** 看起来相同，编辑 **Second Block** 模块属性，并在 **Module Class Suffix** 字段中输入 `art-nostyle MySpecialModule`。
- 2. 保存更改并刷新网站。你会看到我们的 **Second Block** 再次与 **First Block** 不同，但这次它看起来就像根本没有样式一样：

![](img/7f889df2ffdb68108cff34d798a2b9a3_141_0.png)

启用新后缀后，我们右侧栏中的 Second Block 完全没有定义的样式

> 这次我们在后缀中没有用 _ 字符开头我们的类名。我们没有这样做，因为当我们将后缀与其中一个预定义的 Artisteer 类（在本例中为 `art-nostyle`）组合时，单词 `clearfix` 不会被添加到我们的类名中。

![](img/7f889df2ffdb68108cff34d798a2b9a3_142_0.png)

- 3. 使用这种形式的后缀会导致 Joomla! 在渲染我们的 **Second Block** 时同时查找 `art-nostyle` 和 `MySpecialModule` 类。第一个是标准的 Artisteer 类。我们需要在 `template.css` 文件中添加第二个定义。但在这样做之前，让我们先看看生成的页面的源代码：

```
<!-- begin nostyle -->
<div class="art-nostyle MySpecialModule">
    <h3>Second Block</h3>
    <!-- begin nostyle content -->
        <div class="customart-nostyle MySpecialModule">
        <!--
content of our block:
<p> elements, image and list
        -->
        </div>
    <!-- end nostyle content -->
</div>
<!-- end nostyle -->
```

这次我们的任务更容易，因为 Artisteer 插入了注释，告知我们页面未样式化片段的开始和结束。整个区块位于一个 DIV 元素中，该元素属于两个类，即 `art-nostyle` 和 `MySpecialModule`（`class="art-nostyle MySpecialModule"`），根据我们在 Joomla! 中输入的后缀。区块的标题只是一个 h3 元素，没有任何类。我们的区块内容位于另一个 DIV 元素中，该元素也属于类 `custom art-nostyle` 和 `MySpecialModule`（`class="custom art-nostyle MySpecialModule"`）。我们希望组合样式，使我们的 **Second Block** 看起来与之前的示例相似。

- 4. 所以，让我们打开 `template.css` 文件并为我们的类添加定义。因为我们决定不扩展块元素的现有样式（`art-block` 类），而是自己设计一切，所以我们必须定义比上次更多的属性：

```
/*** My Classes ***/
/* Main container of our block */
.MySpecialModule
{
    /* rounded corners of main container */
    -webkit-border-radius: 6px 6px 0 0;
    -moz-border-radius: 6px 6px 0 0;
    border-radius: 6px 6px 0 0;
    /* margins, border and background color */
    margin: 7px;
    border: 1pt solid red;
    background-color: #FFFF99;
}

/* Block header */
.MySpecialModule h3
{
    padding: 12px 3px;
    color: green;
    font-size: 20px;
    font-family: Moul, Arial, 'Arial Unicode MS', Helvetica, Sans-Serif;
    font-weight: normal;
    margin: 0 5px;
}

/* Paragraph in block content */
.MySpecialModule p
{
    font-family: "Tahoma";
    font-size: 10pt;
    font-style: italic;
    line-height: 180%;
}

/* Image border */
.MySpecialModule img
{
    border: 1px solid #000000;
}

/* List inside block content */
.MySpecialModule ul
{
    margin-left: 10px;
}
```

```
.MySpecialModule ul li
{
  list-style-image: url('./images/blockbullets.png');
  margin: 10px 15px;
}
```

- 5. 保存更改，刷新网站，以下截图将会出现：

![](img/7f889df2ffdb68108cff34d798a2b9a3_144_0.png)

我们更改的当前状态

- 6. 一切似乎都相当不错，但我们不希望内部 DIV 元素周围有边框。此边框在我们的 .MySpecialModule 类中定义，我们必须为包含区块内容的 DIV 元素排除它（再次查看方案）。再次编辑 template.css 文件，并在末尾追加以下代码：

```
.customart-nostyle.MySpecialModule
{
  margin-top: 0;
  border: none;
}
```

- 7. 保存更改并刷新网站。就这样！我们通过将模块后缀与内置的 Artisteer art-nostyle 类结合，从零开始设置了 Second Block 的样式。

![](img/7f889df2ffdb68108cff34d798a2b9a3_145_0.png)

更改后的模板
