
## 1
## 认识 Artisteer

在本书中，你会看到你能够独自设计并制作一个专业水准的网站模板，而且不需要任何人的帮助。你不需要懂得绘画或编程。你也不必担心 HTML、CSS、PHP 以及所有那些复杂的东西。你所需要的只是你的 Artisteer 副本。

你可能会问，“What is Artisteer?”

### 什么是 Artisteer

Artisteer 是一个自动网页设计器。这是什么意思？简单来说，它是一款应用程序，即使你对绘画、编程、网络技术以及所有这些东西一无所知，也能让你制作出优秀的网站。有了 Artisteer，你可以设计你的网站，为其填充内容，最后生成可直接使用的 HTML/CSS 文件，然后上传到你的网络服务器（事实上，这也可以在 Artisteer 中完成）。你还可以自动生成任何布局的模板，专门用于几种知名 CMS 系统，如 Joomla!、Drupal、WordPress 或 DotNetNuke。与通常的做法相比，设计流程看起来完全不同。虽然你仍然拥有大量控制权，可以决定设计的许多方面，但绘图过程是自动完成的，不需要你具备任何图形技能，除了对页面上什么看起来好的良好眼光之外。而且它很快。确实非常、非常快。

Artisteer 是市场上同类产品的首款应用，至今仍是该类别中最好的工具之一。

## Artisteer 与其他软件工具的比较

因为 Artisteer 是一种新型工具，很难给出一个恰当的定义说明它是什么。有很多更简单的方式来说 Artisteer 不是什么。这将有助于避免对其应与什么进行比较产生任何混淆。如果我们考虑构建网站的典型流程，它通常包括以下几个阶段：

1. 首先，设计师准备设计方案。他通常使用图形编辑器工作。
2. 设计完成后，会对其进行详细分析，以确定哪些可以用 HTML/CSS 实现，哪些必须保留为图片。然后整个布局会被切片成小图片。
3. 网页开发人员用 HTML 语言准备布局，并借助 CSS 将每一张图片放置到正确的位置。为了展示网站的外观并能够选择合适的排版，内容位置通常会填入一些占位文字（例如，“`Lorem ipsum dolor sit amet...`”）。他通常使用代码编辑器来完成此操作。
4. 占位文字会被替换为目标内容。此任务通常借助 WYSIWYG 编辑器完成。在此阶段结束时，我们就拥有了一个完整的静态网站。
5. 如果网站应包含一些更复杂的元素，如照片库、花哨的工具提示、电影、表单等，或者如果它应被转换为 CMS 的模板，则需要编写额外的代码。这是程序员的工作，他使用客户端或服务器端语言（根据需要实现的目标）在代码编辑器中编写代码。

这种任务分配当然是相当假设性的，并且可能在不同的团队和公司中有所变化，但目标是向你展示整体流程。有时整个流程由一个人完成，但在较大项目中，每个阶段由一组人实现的情况并不少见。因此，我们谈论的是一个由各种专家组成的小组（团队）使用不同的工具，如图形编辑器、WYSIWYG HTML 编辑器、代码编辑器等。

- Artisteer 不是图形编辑器。在图形编辑器中，你必须手工设计所有内容，而在 Artisteer 中，所有元素（例如页眉、菜单等）都是根据你通过程序界面设置的参数自动生成的。图形编辑器提供 Artisteer 不具备的复杂工具来处理图片和照片。在图形编辑器中你可以创建任何图形，而在 Artisteer 中你唯一能设计的就是网站。
- Artisteer 不是 WYSIWYG 编辑器。在 **所见即所得** (**WYSIWYG**) 编辑器中，你可以像使用文字处理器（例如 MS Word）一样输入文字并将图形元素插入网站，应用程序会自动将所有内容转换为 HTML 代码。Artisteer 中的布局元素不仅仅是图形，它们高度交互，你对其有很大的控制权。你可以调整其大小、更改颜色、边框、位置以及外观和感觉的几乎任何其他方面。你的操作不会立即转换为 HTML。你使用的是二进制 Artisteer 项目（.artx 文件），只有当你按下 **导出** 按钮时，布局才会被导出。这意味着所有布局会一次性处理并生成 HTML/CSS/JavaScript/PHP 代码。但同时也可以说，使用 Artisteer 的方式实际上是 WYSIWYG 的——你看不到任何代码，但能看到最终设计。
- Artisteer 不是代码编辑器。你可以按下 **显示代码** 按钮查看将要生成的 HTML 文件（甚至可以更改它），但这不是你使用该应用程序的原生方式。原生方式是“point and click”。在代码编辑器中你编写代码并预览结果。在 Artisteer 中你修改结果并预览生成的代码。
- Artisteer 也不是预设计布局的集合，正如许多人所认为的那样。能够创建的独特布局没有上限，因为答案是无限的。确实，该程序包含有限数量的图形和预定义元素，例如菜单。但插入自己的图片并确定元素的几乎任何方面（大小、颜色、字体等）的可能性表明你是一个真正的设计师，而不仅仅是选择预定义选项中模板的人。

与 Artisteer 最相似的工具是其他网页构建应用程序。区别在于你可以更改和设置的内容。如我前面提到的，你可以在 Artisteer 中更改几乎所有内容。

## 谁可以使用 Artisteer

那么 Artisteer 面向谁？该程序的潜在受众非常庞大。我不能确定，但我感觉 Artisteer 创建者的意图是创建一个工具，让非图形和非技术人员能够创建完整且外观精美的网站。这会将 Artisteer 定位为爱好者和发烧友的工具，但用户范围要大得多。让我们从几个不同的角度来考虑这个问题。

### 爱好者

爱好者是因个人热情而想要拥有网站的人。这不是他的工作，也不是他的生意，他不会因此赚钱。它可能是一个在 Blogger 或 WordPress 上的私人博客，或只是一个简单的家庭网站，通常基于最便宜的主机服务。对于这样的人来说，由于成本原因，聘请专业的网页开发公司或自由职业者通常不是一个选择。通常，唯一可用的选择是尝试自己制作页面（结果会与其技能相符），或购买现成模板（接受大量网站看起来相同的事实）。Artisteer 为这样的人提供了第三种选择：购买该程序并独自制作一个独特且外观精美的网站。成本将低于市场上现成标准布局的通常价格。

### 设计师

设计师是一个具有艺术天赋的人，可以使用图形编辑器并为网页创建外观精美设计。在团队中，设计师通常做第一阶段的工作，创建网站整体概念的外观并准备图形。虽然设计师擅长绘画，但他/她不会编程。要创建网站，设计师需要网页开发人员的帮助。但有了 Artisteer，他/她可以设计模板并用自己定制的图形元素丰富它，这些元素他/她可以准备好。他/她甚至可以输入内容并将所有内容转移到 CMS 皮肤中，为最终用户提供完整解决方案。
