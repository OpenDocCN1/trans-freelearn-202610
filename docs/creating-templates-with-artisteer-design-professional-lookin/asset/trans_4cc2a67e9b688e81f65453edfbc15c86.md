
9. 打开此文件夹并双击 `index.html` 文件以在浏览器中显示我们的网站。确保画廊中任何缩略图的 Lightbox 效果均已禁用。如果您忘记为任何图片禁用此效果，请返回 Artisteer，禁用它，然后再次导出项目，覆盖之前导出的文件。

10. 打开导出模板的文件夹并进入 `images` 文件夹。这是标准 Artisteer 生成的模板文件夹，其中包含项目中使用的所有图形文件。请注意，在将图像插入项目时，Artisteer 不仅将原始图像的大小调整为目标尺寸（单元格），还制作了带缩略图的副本。我们现在拥有画廊中每个图像的两份副本，即缩略图（实际显示在单元格中），以及其对应的原始尺寸图像。生成的图像命名约定如下：

| 缩略图 | 原始图像（较大） |
|---|---|
| 1.jpg | 1-large.jpg |
| 2.jpg | 2-large.jpg |

- 现在是解释为什么我们必须导出模板两次的原因。任何放入 Artisteer 项目中的图像，其 **预览**（Lightbox 效果）属性默认设置为 **是**。在我们第一次导出项目时，此选项对所有图像都已启用。这使得 Artisteer 为每个图像创建缩略图，同时保留原始的较大图像（缩略图显示在页面上，而较大图像在 Lightbox 效果中显示）。然后我们为所有图像禁用了 Lightbox 效果并再次导出项目，覆盖文件。如果 Lightbox 效果被禁用，就没有必要保留较大图像，Artisteer 未将其包含在导出的文件中。大多数文件已被覆盖，但由于导出项目的位置未改变，旧文件仍然保留。您可以检查文件的创建日期。您会注意到较大图像稍微老一些，因为它们来自我们第一次导出，而较小的图像在第二次导出期间被覆盖。通过这种技巧，我们禁用了 Lightbox 效果，但仍然拥有每个图像的两个版本，即缩略图和原始尺寸。
- 现在是时候将我们的缩略图转换为指向其对应较大图像的链接了。

11. 在 Artisteer 中按住右鼠标按钮单击第一张图像，然后从内容菜单中选择 **编辑超链接...** 选项。这将打开 **图像选项** 窗口，其中 **链接** 选项卡已启用。在 **地址：** 字段中，我们需要输入当前缩略图对应的较大图像的相对路径（请查看上表以检查我们画廊中对应图像的名称）。

由于所有图像都存储在 `images` 文件夹中，我们需要根据模式 `Folder name/bigger-image-name` 以文件夹名称开头路径。

我们正在处理 `1.jpg` 文件（第一个缩略图），因此在这种情况下，我们应该输入 `images/1-large.jpg`。

![](img/7f889df2ffdb68108cff34d798a2b9a3_157_0.png)

我们输入原始尺寸图像的路径

对每个图像重复此过程。再次导出项目，覆盖之前导出的文件。

12. 在浏览器中打开我们的网站。画廊可以工作，尽管目前还没有 Lightbox 效果。当您单击缩略图时，您将被重定向到显示图像较大版本的页面。

> 如果此步骤出现问题（单击缩略图后显示错误而不是较大图像），请返回 Artisteer，编辑链接属性，并确保 **地址：** 字段的值不以 / 字符开头。如果是，请将其删除。出于某种原因，如果链接的地址以 / 开头，Artisteer 会在地址后添加 `.html`。例如：
> 
> - 正确：`images/1-large.jpg`
> - 错误：`/images/1-large.jpg`

13. 在我们启用 Lightbox2 效果之前（这需要我们修改导出的代码），让我们添加图片描述。Lightbox2 允许您为图像添加描述。假设我们想将文本 `This is the first image of our gallery` 作为第一个图像的描述。

14. 为此，按住右鼠标按钮单击第一个缩略图，然后再次从内容菜单中选择 **编辑超链接...** 选项。然后只需在 **图像选项** 窗口中的 **屏幕提示：** 字段中输入您的描述，如以下屏幕截图所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_158_0.png)

为图像添加描述

重复此过程，为每个图像提供适当的描述。

在 Artisteer 中我们可以做的最后一件事是为画廊中的任何链接设置正确的 rel 属性。Lightbox2 仅适用于具有设置 rel="Lightbox[galleryName]" 的图片。

> 此功能使页面上可以有多个画廊。每张图片都显示导航箭头，使用户可以切换到下一张或上一张图像。方括号中的 galleryName 标识图像属于特定画廊。您可以自行命名。如果页面上有多个画廊，请为每个图像在 rel 属性中设置适当的 galleryName。这将通知 Lightbox 特定画廊何时结束以及另一个画廊何时开始。

15. 为此，单击任何缩略图，然后单击功能区上的 **HTML** 按钮（它位于 **编辑** 选项卡上）。HTML 编辑器将出现，显示我们内容区域的源代码。查找我们第一个缩略图的链接（如果您不确定要查找的内容，只需查找缩略图的文件名）。找到看起来像以下的代码片段：

```
<a href="images/1-large.jpg" title="This is the first image of our gallery">
```

16. 将光标放置在 title 属性的右侧并添加：

```
rel="Lightbox[myGallery]"
```

17. 您现在应该有以下内容：

```
<a href="images/1-large.jpg" rel="Lightbox[myGallery]" title="This is the first image of our gallery">
```

18. 对我们画廊中的所有链接重复此操作（请记住我们有八张图像）。单击 OK 按钮关闭编辑器窗口。导出项目，覆盖之前导出的文件。

19. 最后一步是修改导出的代码并为我们的网站添加真正的 Lightbox 效果。打开导出项目的文件夹并将我们之前准备的整个 Lightbox 文件夹复制到此文件夹。然后编辑 index.html 文件并找到附加 jQuery 的代码部分。我们正在寻找以下行（文件开头附近）：

```
<script src="jquery.js"></script>
```

20. 在此行正下方（如果需要留出一些空间），放置以下代码：

```
<!-- we add Lightbox effect -->
<link rel="stylesheet" href="Lightbox/css/Lightbox.css" />
<script src="Lightbox/js/Lightbox.js"/>
<!-- end of our modifications -->
```

21. 保存文件并双击 index.html 文件。我们的画廊应该按预期工作，但关闭和加载图像缺失。要修复此问题，只需将 close.png 和 loading.gif 文件从 Lightbox/images 文件夹复制或移动到我们的模板 images 文件夹（从 ImageGallery/Lightbox/images 目录到 ImageGallery/images 目录）。

这就是要做的最后一件事。现在您应该可以看到我们的项目，具有漂亮的 Lightbox2 效果图像画廊，具有平滑的显示效果、导航箭头和图像描述
