## 导出 Joomla! 模板

导出 CMS 模板的方式与我们在上一章中完成的导出静态页面模板非常相似。

首先要做的是选择目标平台——本例中为 Joomla！为此，请单击功能区快速访问工具栏上导出按钮旁边的箭头（您也可以从菜单中选择 文件 | 导出 | Joomla 模板）。

![](img/7f889df2ffdb68108cff34d798a2b9a3_109_0.png)

导出窗口将如下所示：

![](img/7f889df2ffdb68108cff34d798a2b9a3_109_1.png)

设置以下字段：

- **Template: Joomla Template**（模板的目标平台）
- **Version: 2.5**（目标 Joomla! 版本）
- **Positions: position-1, p...**（区域命名约定。我们选择了较新的一个，是 Joomla! 1.6+ 的默认值）
- **FileName: MyJoomlaTemplate**（模板文件名）
- **Path: C:\Users\Jakub\Desktop**（创建文件的目标路径。在本例中为我的桌面）

**Path:** 下有三个重要的选项可以勾选：

- **ZIP archive**
- **Include ARTX Project**
- **Include Content**

勾选第一个选项 **ZIP archive** 会使生成的文件自动压缩为 ZIP 归档。您绝对应该勾选此选项，因为 ZIP 归档是 Joomla! 用于安装新模板所支持的正确格式。此类模板可以直接从 Joomla! 管理面板安装。

> 导出 Joomla! 时应始终勾选 **ZIP archive** 选项。

勾选 **Include ARTX Project** 选项会将原生 Artisteer 项目文件（`.artx`）添加到导出的文件中。这对安装或使用模板没有影响，选择由您决定。

最后一个选项（**Include Content**）是在 Artisteer 4.0 中引入的，允许您将 Artisteer 中输入的所有内容——页面、文本、菜单、图像和页脚——与模板一起导出。如果您的工作是构建整个网站，并且已在 Artisteer 中输入了最终内容，勾选此选项可能是一个好主意（这样您就无需再次在 Joomla! 中重新输入）。如果您的工作只是创建模板，您可能不会勾选此选项（尽管，提供示例内容以展示模板的潜力给最终用户，可能也是一个好主意）。

## 安装 Joomla! 模板

Artisteer 生成的模板的安装方式与任何其他模板完全相同。登录管理面板后，请执行以下操作：

1. 在菜单中导航至 **Extensions | Extension Manager**。
2. 在 **Upload Package File** 字段中，单击 **Browse** 按钮。
3. 在打开的对话框中，指向您的模板文件。
4. 单击 **Upload & Install**。

![](img/7f889df2ffdb68108cff34d798a2b9a3_110_0.png)

指向模板文件后，单击 Upload & Install 以安装模板

模板将从您的本地计算机发送到服务器（根据您的互联网连接质量可能需要一些时间），并将被安装。此操作结束时，将显示确认文本 **Installing template was successful**。

但是，刷新网站后您将看不到任何变化。我们的模板已安装，但未设置为显示（您可以在 Joomla! 中安装任意多个模板；甚至可以设置哪个模板用于显示哪个页面）。

我们的下一步将是激活我们的模板。

5. 将我们的模板设为默认：
   - 从菜单导航至 **Extensions | Template Manager**。您将被重定向到 **Template Manager: Styles** 屏幕。
   - 在列表中找到您的模板并单击右侧对应的星标（在 **Default** 列中）。图标（星标）将被填满，这意味着从此刻起我们的模板是默认模板。
6. 刷新页面。您将看到网站使用我们的模板显示，尽管一些关键元素，如菜单，未显示。别担心，我们很快会修复这个问题！

## 设置模板

是时候让我们的模板看起来像我们在 Artisteer 中设计的那样了。

### 标题和标语

我们将要显示的第一个缺失元素是页眉中的标题和标语。您在 Artisteer 中为标题和标语输入的文本不会随模板一起导出。导出的只是这些文本的样式（外观），但您必须在 Joomla! 中再次输入它们。让我们回到 Joomla! 管理面板并执行以下步骤：

1. 从菜单导航至 **Extensions | Template Manager**。我们将返回到 **Template Manager: Styles** 屏幕。
2. 在 Style 列区域单击您的模板。您将进入 **Template Manager: Edit Style** 屏幕。
3. 在右侧，您将看到 **Basic Options** 区域，其中包含 **Headline** 和 **Slogan** 字段。在其中输入适当的文本。
4. 单击工具栏上的 **Save** 按钮保存更改。

刷新页面后，您将看到标题和标语正在显示。

![](img/7f889df2ffdb68108cff34d798a2b9a3_112_0.png)

输入 Headline 和 Slogan 的文本

### 水平菜单

为 Artisteer 生成的模板创建水平菜单的方式与为 Joomla! 中任何其他模板创建水平菜单的方式相同。您唯一需要记住的是将其放置在 position-1 (user3) 区域。

> 如果您将水平菜单放置在其他区域，它会工作，但外观不会如设计。要使其看起来像 Artisteer 中的那样，您必须将其放置在 position-1 (user3) 区域。

### 垂直菜单

垂直菜单通常放置在左侧或右侧列中。创建垂直菜单比水平菜单涉及更多步骤，因为您必须为其定义模块后缀。

要正确显示垂直菜单，包括 Artisteer 中设计的整体外观，请执行以下步骤：

1. 创建一个新的垂直菜单模块。
2. 将菜单放置在目标区域（通常为左侧或右侧列）。
3. 编辑模块设置，并在模块管理器屏幕中展开高级选项区域。
4. 在 Module Class Suffix 字段中输入 `art-vmenu`。
5. 保存更改。

![](img/7f889df2ffdb68108cff34d798a2b9a3_113_0.png)

要正确显示垂直菜单，您必须将 Module Class Suffix 设置为 art-vmenu

### 页脚修改

最后需要修改的是我们网站的页脚。在 Artisteer 生成的模板中，您可以通过修改 position-27 (copyright) 区域来实现。我们需要做的就是创建一个新的 Custom HTML 类型的模块，并将其放置在此区域。我们的模块将成为新的网站页脚。让我们执行以下步骤：

1. 创建一个新的 Custom HTML 模块并将其标题设为：Footer。
2. 禁用模块标题的显示。
3. 将其放置在 position-27 (copyrights) 中。
4. 输入您希望在页脚中显示的文本。
5. 保存更改并启用新模块。

![](img/7f889df2ffdb68108cff34d798a2b9a3_113_1.png)

页脚模块设置

![](img/7f889df2ffdb68108cff34d798a2b9a3_113_2.png)

页脚中的示例文本——当然，您应该在此处放置您的数据

刷新页面后，您将看到我们的网站具有新的页脚，我们已经设计好了。
