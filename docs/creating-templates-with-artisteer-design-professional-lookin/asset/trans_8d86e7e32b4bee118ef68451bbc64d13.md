## 内容编辑 – Artisteer 或 CMS

我们已自动将 Artisteer 项目中的所有内容导入到 Joomla! 和 WordPress。 我们在 Artisteer 中准备的所有内容——即页面（带文字和图片）、菜单、菜单项和页脚——现在都存在并且在我们的 CMS 网站中正常工作。整个过程虽然简单快捷，但你可能会想知道最好的工作方式是什么：应该在 Artisteer 中准备所有内容然后导入到 CMS，还是安装空模板并直接在 CMS 中输入内容？

这个问题的答案并不那么明显。两种方法都可行，选择权在你。但你应该考虑每种方法的优缺点。以下是直接在 Artisteer 中准备内容的优缺点：

| 在 Artisteer 中准备内容的优点 | 在 Artisteer 中准备内容的缺点 |
|---|---|
| 可以非常快速完成，无需切换到 CMS 甚至安装它。你可以在拥有主机账户之前就进行操作。 | 内容是根据 Artisteer 设定的规则导入的。你别无选择，只能接受它们。例如，在 WordPress 中，所有文章都将被放入名为“未分类”的一个分类中。 |
| 只要内容仍在 Artisteer 项目中，它就保持平台无关（当然不包括特定平台的功能）。你可以在决定使用特定 CMS 之前准备好整个网站。 | 你无法设置一些重要属性，例如 Joomla! 中文章和菜单项的别名。它们是自动设置的。这对 SEO 地址有直接影响。如果你想修复它们，就必须手动在 CMS 中纠正。这需要时间。 |
| 如果你为他人准备网站，你可以在不触碰其系统的情况下准备好带内容的整个网站。你只需将整个网站导出为一个可安装的 ZIP 包即可。 | 你无法使用在 CMS 中安装的任何第三方扩展提供的功能，也无法使用已上传的图片。你在目标系统之外。 |
| 你可以为模板准备示例内容。 |  |

以下是直接在 CMS 中准备内容的优缺点：

| 直接在 CMS 中准备内容的优点 | 直接在 CMS 中准备内容的缺点 |
|---|---|
| 你可以使用 CMS 的全部功能，包括所有已安装的扩展和已上传的图片。 | Web 应用的响应速度不如桌面应用。你可能使用 Artisteer 编写一篇简单文章所需的时间会比使用 CMS 少一些。 |
| 你可以完全控制内容和 CMS 功能。你可以为文章和菜单项设置适当的别名，为各种文章分配各种分类，设置分类名称、上传图片的位置等等。 |  |
| 内容可以由一队人同时插入。 |  |

从上述分析可以得出的结论是，如果你制作一个简单的网站，或需要非常快速地完成某些工作，你可以在 Artisteer 中准备内容然后导入到 CMS 系统。如果你要构建一个相当复杂的网站，并且已经决定使用哪个 CMS，直接在 CMS 中输入内容是更好的选择。你将完全控制自己的工作。

### 幻灯片中的图片链接

此技巧适用于 HTML 模板。示例项目为 `slidesAsLinks.artx` 文件。

本技巧将展示如何修改幻灯片，使每张幻灯片或其中部分幻灯片链接到其他网站。

创建幻灯片时可定义特定图片，但无法将幻灯片设为链接。第一个想法当然是点击文章中的任意位置，然后在菜单中导航到 编辑 | HTML 以显示包含幻灯片的文章源代码，并在不退出程序的情况下进行修改。让我们开始。

- 1. 幻灯片位置会找到类似以下内容：

```
<div class="image-caption-wrapper" style="width: 55%;
float: left">
[collage_79]
</div>
```

![](img/7f889df2ffdb68108cff34d798a2b9a3_126_0.png)

### 下载示例代码

你可以在 http://www.packtpub.com 从账户下载所有已购买的 Packt 书籍的示例代码文件。如果你是在其他地方购买本书，可访问 http://www.packtpub.com/support 注册，以便将文件直接发送到你的邮箱。

- 2. 哎呀！看起来 Artisteer 并非以源代码形式呈现幻灯片，而是以特殊标签呈现。整个幻灯片以 [collage_79] 呈现（数字可能不同，但整体模式始终相同）。

- 3. 这样我们别无选择，只能导出模板然后编辑源代码。将模板导出为文件夹，并在文本编辑器中打开 index.html 文件。查找负责显示幻灯片的代码部分。你会找到类似以下内容：

```
<div class="art-slider art-slidecontainer79">
  <div class="art-slider-inner">
    <div class="art-slide-item art-slide790"></div>
    <div class="art-slide-item art-slide791"></div>
    <div class="art-slide-item art-slide792"></div>
    <div class="art-slide-item art-slide793"></div>
  </div>
</div>
```

- 4. 为使代码更清晰，我们添加一些注释：

```
<!-- The external container, containing the slideshow -->
<div class="art-slider art-slidecontainer79">
  <!-- slideshow container -->
  <div class="art-slider-inner">
    <!-- first slide -->
    <div class="art-slide-item art-slide790"></div>
    <!-- second slide -->
    <div class="art-slide-item art-slide791"></div>
    <!-- third slide -->
    <div class="art-slide-item art-slide792"></div>
    <!-- fourth slide -->
    <div class="art-slide-item art-slide793"></div>
  </div>
</div>
```
