# 第3部分

# 将AI集成到现有传统软件产品中

许多公司将踏上将AI和机器学习集成到其现有传统产品中的旅程，因为AI在各行业中提供的潜在竞争优势和战略影响力。

本书的第三部分将重点关注演进现有软件产品，使其目前不使用机器学习或深度学习也能利用AI。在上一部分中，我们讨论了构建AI原生产品以及该过程如何在数据、公司和战略角度上以最佳方式展开。运用同样的视角，我们现在将比较和对比该过程对于目前不利用AI的产品是如何展开的。到本部分结束时，我们将了解AI对各个公司及其所属行业的影响。我们还将看到产品设计和产品管理在为已作为传统软件产品推出的产品引入AI功能和能力时受到怎样的影响。与第2部分类似，我们将通过本部分中的不同案例研究来具体化这些概念。

本部分包含以下章节：

- 第12章，AI的上升潮流
- 第13章，行业趋势与洞察
- 第14章，将产品演进为AI产品
- 第15章，AI产品设计的角色
- 第16章，管理不断演进的AI产品
