Word2Vec being an estimator produces a Word2VecModel by accepting
dataset values composed of sentences or a sequence of words
together being represented as a document. The model generates a
fixed-size vector by transforming the document into the vector
using the average of all words in the document. Word2Vec is
popularly used for prediction, document similarity calculation,
and so on:
