# Transform operation

So far we have done transformation of DStreams, but not all operations of RDD are available in the DStream API. The transform operation overcomes such a limitation and allows RDD operations on the DStream. Assume a scenario where the DStream data can be joined with RDD and then some analytical operations can be applied on them. This exposes streaming data to a whole set of atypical operation available in the RDD and hence makes it extremely powerful.

As an example let's assume that we have a list of words whose weightage should be preferential when compared with other words. So now if we run our word count example, if the words from RDD exist in DStream then the count should reflect the summed up value from the RDD and the DStream:
