# mapEdges

Similar to mapVertices, mapEdges is used to transform edges. The following is the signature of mapEdges:

```
| mapEdges(scala.Function1<Edge<ED>,ED2> map, scala.reflect.ClassTag<ED2> evidence$4)
```

The graph object created previously has edges with the property of string type. In this example, we will transform the edge property to integer value equal in length to the string. The following is the definition of the transformation function:

```
| public class AbsFunc1 extends AbstractFunction1<Edge<string>,Integer> implements Se
| @Override
| public Integer apply(Edge<string> edge) {
| return edge.attr().length();
| }
```

Therefore, mapEdges can be executed as:

```
| graph.mapEdges(new AbsFunc1(), scala.reflect.ClassTag$.MODULE$.apply(Integer.class))
```
