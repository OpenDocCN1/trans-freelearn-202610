# Table Persistence

The saveAsTable function can be used to persist datasets in the Hive metastore as a table. By default, Spark creates a managed table at the path mentioned in configuration spark.sql.warehouse.dir. The various options of SaveMode and format remain the same, as discussed in the previous section.

```
| deptDf.write().mode(SaveMode.Overwrite).format("csv").saveAsTable("Department");
```
