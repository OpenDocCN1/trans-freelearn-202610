# # Built-in Sinks

Some of the common built-in sinks are as follows:

+   * **Console sink**: As shown in the preceding example, this sink helps to print output to the console. It is very useful for debugging purposes:

```
writeStream
.format("console")
.outputMode("complete")
.start()
```

+   * **Memory sink**: This sink helps us to write data into memory in the form of in-memory table. Like the console sink, it is also helpful for debugging purposes:

```
writeStream
.format("memory")
.queryName("tableName")
.outputMode("append")
.start()
```

+   * **File sink**: This sink helps to store output to an external location in the form of a file:

```
writeStream
.format("csv") // can be "orc", "json", "csv", etc.
.option("path", "path/to/destination/dir")
.outputMode("complete")
.start()
```
