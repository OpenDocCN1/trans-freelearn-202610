mapSideCombiner helps to reduce the network IO by combining the data belonging to a key within a partition before shuffling the data. The user can turn it off if required. For example, groupByKey turns off mapSideCombine, however reducyByKey/ FoldByKey/aggregateByKey performs mapSideCombine. Therefore, groupByKey performs more network shuffle than the others.
