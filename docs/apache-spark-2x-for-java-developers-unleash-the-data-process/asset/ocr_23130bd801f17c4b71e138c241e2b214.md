Hence it is always suggested to use `local[n]` configuration with `n` being greater than one or better still one can use `local[*]`. Similar logic can be extended to Streaming jobs running on clusters as well, the number of cores allocated to the Spark Streaming application must be more than the number of receivers.

+   Also add the following Maven dependency for working with Spark Streaming:

```
<dependency>
<groupId>org.apache.spark</groupId>
<artifactId>spark-streaming_2.11</artifactId>
<version>2.1.1</version>
</dependency>
```
