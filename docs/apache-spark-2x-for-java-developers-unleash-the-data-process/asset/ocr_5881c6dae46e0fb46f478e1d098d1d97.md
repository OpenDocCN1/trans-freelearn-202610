| Function | Description |
| :--- | :--- |
| count() | Returns a new DStream of single element RDDs by counting the number of elements in each RDD of the source DStream |
| reduce(func) | The aggregate function reduces the elements of a DStream while returning a new DStream of single element RDDs |
| reduceByKey(func, [numTasks]) | For a pair DStream RDD, it returns a new DStream of (K, V) pairs where the values for each key are aggregated using the given reduce function |
