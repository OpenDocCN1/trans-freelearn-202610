To use a filter, select the checkbox next to the name. You can select any number of entries under any number of columns to perform a filter. Each entry you select will be treated as an and in the query, so that if you select an entry called Alpha and one called Beta, the row must have both Alpha and Beta in it for it to be shown in the result set.

When you have selected all the needed filters, click on the Apply & Run button to apply the new filters. You can also click the Clear button to remove all the selected filters.
