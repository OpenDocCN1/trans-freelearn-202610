# Creating a bookmark

To create a new bookmark, you must run a query from the Logs page – refer to Chapter 6, Microsoft Sentinel Logs and Writing Queries, or, as we just saw, from the results of a livestream. While on the Hunting page, clicking the Viewing Results button in the query's details pane will open the Logs page, showing your results, as follows:

![](bbox=[0.115, 0.215, 0.85, 0.525])

Figure 11.11 – Viewing query results

You may have noticed that there are checkboxes to the left of each result. To create a new bookmark, select one or more checkboxes. When at least one checkbox has been selected, the Add bookmark link will be enabled in the result's header bar.
