# Feedback

This feature allows you to send feedback to Microsoft regarding the Logs page. If this is clicked, you can select what you were doing, whether you liked it or not, provide a description, and select whether it is OK for Microsoft to contact you.

This is a great way to provide feedback as to how well you feel a feature is working, or to request new features.
