
2. This entails looking at the StormEvents table and getting just one instance of each state. Use the distinct operator for this:

```
StormEvents
| distinct State
```

3. You will need to look at the DamageProperty field in the StormEvents table and make sure that the field is greater than 10,000 and less than 15,000:

```
StormEvents
| where DamageProperty >10000 and DamageProperty <15000
```

4. You have three out of the four columns needed in the StormEvents table already. The fourth column, the one for the total amount of damage, can be created by adding the DamageProperty column and the DamageCrop property. In the following answer, it is called TotalDamage but it really does not matter what you call it as long as you use the same name in the extend and project commands. Bonus points if you combined extend and project into one. While this is perfectly legal in KQL, if you want to use the variable again then extend will be needed as project just outputs the results:

```
StormEvents
| extend TotalDamage = DamageCrops + DamageProperty
| project State, DamageProperty, DamageCrops, TotalDamage
```
