**Important Note**
You may see a message stating **Investigation cannot be used to investigate this bookmark because some of the data related to this bookmark is no longer stored.** This can occur if the results that were stored in a bookmark have been deleted due to your data retention policy. Refer to *Chapter 2, Azure Monitor – Introduction to Log Analytics*, for information on setting your data retention policy.
