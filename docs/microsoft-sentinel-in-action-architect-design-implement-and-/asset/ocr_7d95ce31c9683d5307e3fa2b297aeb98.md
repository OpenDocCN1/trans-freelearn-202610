To use a saved group, enter a query like this:

```
Perf
| where Computer in (ListComputerGroups)
```

Substitute ListComputerGroups for the name of the query you just created. Again, do not worry about what this query means; it is just an example of how to use a saved group. It will make more sense after reading Chapter 5, Using the Kusto Query Language.
