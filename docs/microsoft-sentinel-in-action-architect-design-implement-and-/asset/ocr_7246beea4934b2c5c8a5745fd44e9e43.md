+   - **Rule threshold**: This determines how many occurrences of the query finding a result are required for an alert to be generated.
+   - **Event grouping**: This determines whether all the events go into a single alert or whether each event goes into its own alert.
+   - **Suppression**: This will state whether the analytic rule has been suppressed and, if so, for how long. This will take effect after triggering for the first time. This can be useful if you are testing a new rule. After it triggers the first time, you would want time to investigate the incident to make sure the analytic rule is working correctly before it triggers again, otherwise you could have several false positive incidents.
