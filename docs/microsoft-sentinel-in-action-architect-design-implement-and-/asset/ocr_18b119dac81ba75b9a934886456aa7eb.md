# Figure 11.5 – Hunting query details pane

At the very top of the page is the title of the query. Immediately under that is the name of who wrote the query. In this case, it is Microsoft, but if it is a query that you created, it will say Custom Queries. Next to that is the number of results for this query. On the right of that is the first data source that this query is using. If there is more than one data source for this query, you will need to hover your mouse over the more information icon to see them, as shown in Figure 11.4. Under that is the description of the query. This will provide you with information about how the query works and what it is looking for.

Under the Description field is the Created time field, which will tell you when this query was created. For any of the queries that came with Microsoft Sentinel, this will be when this Microsoft Sentinel instance was created.
