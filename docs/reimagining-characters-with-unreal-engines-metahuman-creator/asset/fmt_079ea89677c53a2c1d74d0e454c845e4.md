
# MetaHuman 下载与导出工作流

如果您的计算机屏幕能显示 4,000 像素宽度，则 8K 贴图将显示得非常充分。特别是，面部的 8K 贴图在 4K 显示器上显示特写绰绰有余。此外，请记住面部有多张贴图混合在一起，能提供更丰富的细节。Glenda 角色的组合贴图总计达 1.6 GB。

> **Note**
>
> 您可以在后期随时替换角色。因此，您可以使用角色的低分辨率代理完成整个制作流程，在进入灯光和渲染阶段时再替换为 8K 版本。这是一个非常简单的过程，下载和导出环节耗时最长。

## 下载注意事项

每当您关闭 `MHC` 或停止使用它时，您的角色随时可以从 `Bridge` 内部下载。如果 `Bridge` 处于打开状态且选中了您的角色，您会看到它不时更新，特别是在您关闭 `MHC` 会话后。

要更改下载设置，请点击 `Download Settings`，如 *Figure 2.48* 所示。您将看到两个标签页：`TEXTURES` 和 `MODELS`。

首先，让我们看看 `TEXTURES` 标签页：

![Figure 2.48: Textures settings](`image/B17878_02_48.jpg`)

Figure 2.48: Textures settings

`TEXTURES` 默认已勾选约一半的潜在贴图，这对大多数情况已足够。我们还可以额外选择 `Image format` —— 即 `JPEG`、`EXR` 或 `JPEG+EXR`。我强烈建议您坚持使用 `JPEG`，因为 `EXR` 文件大得多，会增加下载和处理时间，甚至可能导致 `Unreal` 中的性能问题。在大多数情况下，像素数据不足以证明使用 `EXR` 文件格式的合理性。

现在，让我们切换到 `MODELS` 标签页；这里有不同的选项：

![Figure 2.49: Models settings](`image/B17878_02_49.jpg`)

Figure 2.49: Models settings

因为这是 `Bridge`，所以在选择 3D 模型格式时，我们有 `Megascans` 和 `MetaHumans` 选项。我们只需关注 `MetaHumans` 下拉列表，它提供两种格式供选择：`UAsset` 和 `UAsset + Source Asset`。

选择 `UAsset + Source Asset` 将下载仅可在 `Unreal` 中读取的角色网格格式，以及更通用的 `FBX` 格式。这是最稳妥的选择，因为单独下载 `UAsset` 很可能导致导出过程失败。（我们也可以前往 `Export Settings` 为第三方 3D 软件提供更多选项，如果您只想在 `Maya`、`Houdini` 或 `Blender` 中使用 `MetaHuman`。）

查看完设置后，您可以点击 `Back` 按钮，然后点击 *Figure 2.47* 所示面板底部出现的绿色 `Download` 按钮。下载过程耗时相当长，因为 `MHC` 正在根据您的修改烘焙贴图、生成新网格、写出新的 `Unreal` 文件，同时还在为下载过程压缩和解压文件。

现在，让我们看看 `Export Settings` 选项。

## 导出注意事项

接下来，我们将查看 `Export Settings`（您可以在 *Figure 2.47* 的 `Downloads Settings` 下方找到它）。您将看到如下窗口：

![Figure 2.50: Export Settings](`image/B17878_02_50_new.jpg`)

Figure 2.50: Export Settings

要导出您的角色，请执行以下操作：

1.  将 `Export Target` 设置为 `Unreal Engine`。
2.  将 `Engine Version` 设置为您安装的版本，应为 **5.0** 版本。
3.  将 `Plugin Location` 设置为您安装 `Unreal` 的目录（选择此文件夹将允许 `Bridge` 自动安装插件）。
4.  在 `Default Project` 下选择您的项目文件夹位置作为默认位置。

> **Note**
>
> 如果您仅将角色导出为 `Unreal` 资产，后来希望将角色引入 `Maya`、`Blender` 或其他第三方应用程序，您可以从 `Bridge` 重新下载但更改导出设置，将 `Export Target` 设置为 `Maya` 或 `Blender`，*或者* 直接从 `Unreal` 使用 `Level Sequencer` 将角色导出为 `FBX`。

完成后，您可以在 *Figure 2.47* 所示的同一面板中找到 `Export` 按钮。

一种替代且推荐的将角色安全引入正确项目的方法是利用 `Unreal` 项目中的 `Bridge` 插件。此插件在 `UE5` 中默认启用。它是 `Bridge` 的迷你版，仅从 `Unreal` 内部启动。要从 `Unreal` 使用 `Bridge`，请导航到屏幕底部的 `Content` 文件夹并点击 `+ADD` 按钮。在这里，您将看到 `Add Quixel Content`；点击它。这两项均在 *Figure 2.51* 中高亮显示：

![Figure 2.51: Loading Quixel Bridge from within the Content folder in Unreal 5](`image/B17878_02_51.jpg`)

Figure 2.51: Loading Quixel Bridge from within the Content folder in Unreal 5

此时系统可能会要求您再次登录。使用您的 `Epic Games` 凭据登录后，您将看到您的 `MetaHuman` 内容和一个类似的界面，可在打开的 `Unreal` 项目中直接下载并添加角色。

这样做的优势是：减少将角色意外导出到错误项目文件夹的用户失误几率。此外，如果您的插件尚未安装，当您点击 `+ADD` 时触发的 `Quixel` 导入器将检查插件是否已安装，并会在屏幕右下角提示您后自动为您安装；我们将在本节中更详细地探讨这一点。

## 后台处理

`UE5` 会将已下载到您机器上的文件导入 `Unreal Engine`。简单来说，`Bridge` 将相关文件保存到 `Unreal` 项目的 `Content` 文件夹下名为 `MetaHumans` 的文件夹中。如果您未安装 `MetaHumans` 插件（如 `Hair Grooms` 插件），请别担心 —— 迷你 `Bridge` 插件会在导出步骤中自动安装它们，从而解决问题。

屏幕底部将出现关于所有 `MetaHumans` 相关插件的各种通知。它可能会要求您点击 `Enable Missing` 以启用缺失插件。请务必点击 `Enable Missing`，如 *Figure 2.52* 所示：

![Figure 2.52: Missing plugins and project settings](`image/B17878_02_52.jpg`)

Figure 2.52: Missing plugins and project settings

此外，`UE5` 还将计算蒙皮权重、编译着色器等。这将花费几分钟时间，在此期间您将无法使用 `Unreal Editor`。

完成后，请在 `UE5` 项目的 `Content Browser` 区域中寻找已创建的 `MetaHumans` 文件夹，如 *Figure 2.53* 所示。所有 `MetaHuman` 角色都将导入此文件夹；它们将在您首次执行导出流程时创建：

![Figure 2.53: The MetaHumans folder](`image/B17878_02_53.jpg`)

Figure 2.53: The MetaHumans folder

在该文件夹内，您将看到一个以您的角色命名的文件夹。打开它，您将看到角色的小缩略图。在我的例子中，它称为 `BP_Glenda`（`BP` 代表 `Blueprint`）。

*Figure 2.54* 显示我已将角色引入视口。我是通过将 `Blueprint` 直接拖放到视口中来实现的：

![Figure 2.54: Dragging and dropping the Blueprint](`image/B17878_02_54.jpg`)

Figure 2.54: Dragging and dropping the Blueprint

> **Note**
>
> 您可以随时编辑场景。在 *Figure 2.54* 中，我使用了空白模板，并将 `HDRI` 背景拖放到场景中，以获得一个简单但逼真的灯光设置。
