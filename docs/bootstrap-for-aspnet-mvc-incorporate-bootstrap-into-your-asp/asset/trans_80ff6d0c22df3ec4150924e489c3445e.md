## 前言

Twitter Bootstrap，简称为 Bootstrap，是互联网上领先的开源 CSS/HTML 和 JavaScript 框架。在发布后不久，它就成为 GitHub 上最受欢迎的项目。它变得如此受欢迎，以至于微软在 Build 2013 大会上宣布，Visual Studio 2013 中的所有 Web 应用项目模板将默认使用 Twitter Bootstrap。

Bootstrap 如此普及的主要原因之一是，它允许开发者——其中许多人以用户界面设计 notoriously 糟糕著称——只需付出相对较小的努力就能构建外观美观的网站。Bootstrap 还提供丰富的免费和商业模板、第三方组件、工具以及活跃且乐于助人的社区。

使用 CSS 框架，特别是 Bootstrap 与 ASP.NET MVC 结合是自然而然的。Bootstrap 处理排版、表单布局和用户界面组件，让开发者能够专注于他们擅长的领域，即编写代码。这一方面对于没有内部设计师的小型开发公司尤其有价值。Bootstrap 版本 3 引入了移动优先的方法，这意味着使用 Bootstrap 构建的所有网站都将自动响应式，并针对小屏幕设备进行优化。

### 本书涵盖内容

《Bootstrap for ASP.NET MVC》将带你逐步完成使用 Bootstrap 进行布局和用户界面的全功能 ASP.NET MVC 网站的创建过程。

第 1 章，Getting Started with ASP.NET MVC and Bootstrap，重点介绍如何开始使用 Bootstrap，从获取文件的位置、如何将其包含在项目中，到更详细地查看默认的 ASP.NET MVC 项目模板。我们还将研究 CSS 和 JavaScript 的捆绑和压缩的好处。

第 2 章，Using Bootstrap CSS and HTML Elements，检查各种 Bootstrap CSS 和 HTML 元素，如何将它们包含在 ASP.NET MVC 项目中，以及如何配置和使用它们的各种选项。

第 3 章，Using Bootstrap Components，将在第 2 章 Using Bootstrap CSS and HTML Elements 学到的知识基础上继续构建。本章仔细研究了导航、警告、进度条、按钮组和徽章等不同组件。

第 4 章，Using Bootstrap JavaScript Plugins，说明了 Bootstrap JavaScript 插件的使用。我们将尝试模态对话框、上下文下拉菜单、工具提示、按钮以及手风琴和轮播等用户界面组件。

第 5 章，Creating ASP.NET MVC Bootstrap Helpers，指导你通过创建 ASP.NET MVC 辅助方法 and 类来减少生成 Bootstrap 元素所需的 HTML 量。

第 6 章，Creating T4 Templates to Scaffold Bootstrap Views，转向更高级的主题，即创建 T4 模板以生成 Bootstrap 主题的脚手架视图。

第 7 章，Converting a Bootstrap HTML Template into a Usable ASP.NET MVC Project，展示了如何转换开源 HTML 模板并使其可用于 ASP.NET MVC。

第 8 章，Using the jQuery DataTables Plugin with Bootstrap，演示了如何使用强大的 jQuery DataTables 插件与 Bootstrap 和 ASP.NET 结合以显示表格数据。

第 9 章，Making Things Easier with the TwitterBootstrapMVC Library，研究了 TwitterBootstrapMVC 库，其中包含大量预构建的 HTML 助手，使在 ASP.NET MVC 中包含 Bootstrap 组件变得更容易。

附录，Bootstrap Resources，提供免费 Bootstrap 资源、主题和工具的列表。

### 你需要什么

为了充分利用本书，你需要 Visual Studio 2013 和一个现代浏览器。所有示例均使用 Visual Studio 2013、Google Chrome 和 Mozilla Firefox 进行测试。本书将对具有从入门级到高级的 ASP.NET MVC 开发经验以及有限的 Bootstrap 经验的人有所帮助。

### 本书适合谁

本书适合希望了解如何在项目中集成 Bootstrap 的 ASP.NET MVC 开发者。ASP.NET MVC 开发者也可以从涵盖高级主题的章节中受益，例如创建助手和使用 jQuery DataTables 插件。如果你对 ASP.NET MVC 和 Bootstrap 的经验有限，本书可以作为这些技术的入门读物。
