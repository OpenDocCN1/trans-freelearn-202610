# Using Bootstrap CSS and HTML Elements

To create four white/default buttons ranging from extra small to large, you'll implement the following HTML markup:

```
```html
<div class="row">
    <!-- Standard button -->
    <button type="button" class="btn btn-default btn-xs">Default Extra Small</button>
    <button type="button" class="btn btn-default btn-sm">Default Small</button>
    <button type="button" class="btn btn-default">Default</button>
    <button type="button" class="btn btn-default btn-lg">Default Large</button>
</div>
```
```

Button colors are also specified by a class name. The following is a list of available color class names:

+   - `btn-default`
+   - `btn-primary`
+   - `btn-success`
+   - `btn-info`
+   - `btn-warning`
