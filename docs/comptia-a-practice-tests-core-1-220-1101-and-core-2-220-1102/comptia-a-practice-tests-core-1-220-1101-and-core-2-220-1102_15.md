## 3.2 根据场景安装合适的内存

1. 正确答案是**B**。虚拟内存的主要目的是通过扩展可用内存来提高系统性能。当物理内存不足时，它允许计算机将硬盘或`SSD`的一部分用作额外的内存。虚拟内存的目的不是为文件和文档提供额外存储空间。虚拟内存作为可用内存的扩展，而非备份解决方案。虚拟内存与`CPU`和`GPU`无关。

2. 正确答案是**A**。在计算机系统中使用`DDR RAM`的主要原因是其提高的数据传输速率。`DDR RAM`可在时钟信号的上升沿和下降沿传输数据，与早期内存技术相比，有效地将传输速率提高了一倍。这种速度提升增强了系统性能和响应能力。`DDR RAM`不用于增加计算机系统的存储容量。`DDR RAM`并非用于能效；主要原因是提高数据传输速率。`DDR RAM`在一定程度上有助于降低延迟；但其主要目的是提高数据传输速率。

3. 正确答案是**D**。`SODIMM RAM`（小外形双列直插内存模块）因其紧凑的尺寸，是笔记本电脑和小型化电脑常用的内存模块类型。`DIMM RAM`（双列直插内存模块）是一种较大规格的内存模块，通常用于台式电脑。`RIMM RAM`（Rambus 直列内存模块）是一种较老的内存模块类型，曾用于要求高速内存访问和数据传输速率的高端工作站或服务器。`MicroDIMM RAM`是`DIMM RAM`的较小变体，常见于专用或小众设备中。

4. 正确答案是**C**。`ECC RAM`旨在检测和纠正内存错误，提高数据完整性。`ECC RAM`并非专门设计用于提供`CPU`和内存之间更快的数据传输。其主要重点是错误检测和纠正，而非提高传输速度。`ECC RAM`不增强图形处理能力。`ECC RAM`不增加内存的存储容量。

5. 正确答案是**B**。使用双通道内存的主要优势是更快的数据传输速率。它利用两个不同颜色的内存插槽，允许并行数据访问，提高整体系统性能。通常是一个黑色插槽和一个对比色，如蓝色、灰色或白色，取决于制造商。双通道内存不会直接增加内存的存储容量。双通道内存不会直接提高图形性能。双通道内存并不专门降低功耗。

6. 正确答案是**C**。使用四通道内存的主要优势是提高数据传输速率。它同时利用四个内存通道，增加带宽，加快内存与`CPU`之间的数据传输。四通道内存对存储没有任何影响。虽然四通道内存可为多任务场景带来一些好处，但这不是其主要优势。内存延迟更多受内存速度和时序等因素影响。

7. 正确答案是**A**。`DDR2`频率范围为 400 至 1,066 `MHz`，`DDR3`为 800 至 2,133 `MHz`，`DDR4`为 2,133 至 3,200 `MHz`。所有其他选项均错误。

8. 正确答案是**D**。`SSD`、`Intel Core i7` `CPU`和 16 GB `DDR4 RAM`的组合是游戏电脑的最佳选择，因为它提供更快的存储访问、高性能处理能力和充足的内存容量。`SSD`、`Intel Core i5`、8 GB `DDR4`提供了良好的平衡，但游戏首选更高端的`CPU`，如`Intel Core i7`。16 GB `DDR4 RAM`能提供更舒适的游戏体验。`SSD`因加载时间更快而优于`HDD`，而`AMD Ryzen 3` `CPU`和`DDR3 RAM`与其他选项相比，游戏性能较弱。

**正确答案：`A`**。将扫描作为文件上传到云端的文档存储和共享账户。使用扫描到云功能时，扫描的文档作为文件上传并保存在基于云的文档存储和共享账户上，如 OneDrive 或 Dropbox。所有其他选项均不正确。

## 16. 安全打印 (PIN 码释放)

**正确答案：`A`**。仅在授权用户插入 PIN 码时启用打印，确保用户在打印机旁，从而防止打印作业被发送到打印机后被遗忘。所有其他选项均不正确。
