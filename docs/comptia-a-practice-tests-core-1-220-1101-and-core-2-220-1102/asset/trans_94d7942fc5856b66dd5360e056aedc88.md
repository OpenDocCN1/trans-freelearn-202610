### 11.

### 12.

### 13.

### 14.
正确答案是 **C**。`organizational unit (OU)`（组织单位）是 `Active Directory` 域中的一个容器，可用于对相关对象（如用户、计算机和其他 OU）进行分组。OU 的主要目的是以反映组织结构的逻辑层次结构来组织和管理这些对象。OU 有助于将 `Group Policy`（组策略）、权限和管理任务应用于特定的一组对象。选项 A 不正确，因为物理位置通常由 `IP address`（IP 地址）或 `network subnet`（网络子网）等属性决定。选项 B 不正确，因为安全策略是在域级别或组级别定义的，而不是在 OU 级别。选项 D 不正确，因为 `domain name resolution`（域名解析）服务由 `Domain Name System (DNS)`（域名系统）提供，而不是由 OU 提供。

## 8.2 比较和对比无线安全协议和认证方法

### 1.
正确答案是 **B**。`Wi-Fi Protected Access 3 (WPA3)` 使用一种称为 `Simultaneous Authentication of Equals (SAE)`（对等实体同时认证）的安全握手过程。这取代了之前称为 `Preshared Key (PSK)`（预共享密钥）的方法。`WPA2` 使用基于 PSK 的旧安全标准。`Temporal Key Integrity Protocol (TKIP)`（临时密钥完整性协议）旨在在使用 `WPA` 和 `RC4` 加密时提高安全性。`Advanced Encryption Standard (AES)`（高级加密标准）是用于保护无线数据的默认加密强度。

### 2.
正确答案是 **C**。`Remote Authentication Dial-In User Service (RADIUS)`（远程认证拨号用户服务）也称为 `Authentication, Authorization, and Accounting (AAA)`（认证、授权和计费）服务。`RADIUS` 服务器允许 `Wi-Fi` 控制器转发来自客户端设备的认证请求。这些认证请求随后将被转发到目录服务。`WPS` 允许设备与 `Wi-Fi` 路由器配对，无需共享密钥或密码。`WEP Open` 不需要账户或密码（任何人都可以连接）。`WPA-PSK` 不使用 `Active Directory` 账户。

### 3.
正确答案是 **C**。`WPA2-AES` 提供最高级别的安全性。它使用 `AES 128-bit` 加密。`Wired Equivalent Privacy (WEP)`（有线等效保密）在 `WPA` 之前使用，现已不再使用。它已有 20 多年历史，关键在于它不安全。`WPA2-TKIP` 使用较旧的 `RC4` 加密算法。`Open Wi-Fi`（开放 Wi-Fi）网络不使用加密。

## 8.3 给定场景，使用适当的工具和方法检测、移除和预防恶意软件

### 1.
正确答案是 **B**。`Boot sector viruses`（引导扇区病毒）感染计算机系统硬盘的 `Master Boot Record (MBR)`（主引导记录）或引导扇区。当受感染的计算机启动时，病毒变为活动状态并可传播到系统的其他部分。选项 A 不正确，因为这种类型的驱动器不用于引导 `OS`（操作系统）。选项 C `network routers and switches`（网络路由器和交换机）不是引导扇区病毒的攻击目标。选项 D 更可能与社会工程学或密码攻击相关。

### 2.
正确答案是 **D**。`Keyloggers`（键盘记录器）能够记录用户在目标系统上敲击的每一个按键。攻击者利用它窃取登录凭据、敏感信息和支付卡号。选项 A、B 和 C 描述的是其他类型的恶意软件或攻击，因此它们是不正确的。

### 3.
正确答案是 **C**。`Ransomware`（勒索软件）是一种加密受害者数据文件使其无法访问的恶意软件。随后会勒索付款以换取解密密钥。选项 A、B 和 D 描述的是其他类型的攻击，因此它们是不正确的。

### 4.
正确答案是 **B**。`Rootkit`（Rootkit）会替换受权的 `OS` 可执行文件，从而能够阻止和干扰 `OS` 进程。当使用特权账户配置 `OS` 功能或服务时，Rootkit 可以覆盖这些操作。选项 A `Trojan`（特洛伊木马）通常不专注于像场景描述那样操纵或反转系统设置。虽然选项 C `Viruses`（病毒）会对计算机系统造成损害，包括干扰其正常运行，但它通常不以 `Windows Defender` 等安全设置为目标。病毒倾向于专注于复制和传播。虽然选项 D `Spyware`（间谍软件）可以禁用安全功能以便于其隐蔽活动，但间谍软件的主要目标是数据收集，而不是主动操纵系统设置。选项 E `Ransomware`（勒索软件）更关注加密文件并向受害者勒索钱财。

### 5.
正确答案是 **B**。`Rootkits`（Rootkit）难以移除，因为它们会替换关键系统文件并阻止移除恶意文件的尝试。完全擦除硬盘可确保不留下恶意文件。`Trojans`（特洛伊木马）、`Viruses`（病毒）和 `Spyware`（间谍软件）不需要擦除并重装 `OS` 驱动器。有效的反恶意软件套件应能检测并移除这些恶意文件和进程。

### 6.
正确答案是 **E**。`Ransomware`（勒索软件）要求支付费用以访问数据。勒索软件通常强迫用户或组织付款，因为重要的个人或业务数据已被攻击者加密。`Trojan`（特洛伊木马）随有用应用程序一起安装，隐藏在应用程序内部。`Rootkit`（Rootkit）会替换受权的 `OS` 可执行文件，从而能够阻止和干扰 `OS` 进程。`Virus`（病毒）是通常由用户点击电子邮件附件引入的恶意软件。`Spyware`（间谍软件）将在后台运行，窃取用户信息，包括密码。

### 7.
正确答案是 **C**。由于未提及特定的恶意软件类型，最佳方法是推广用户安全意识培训以涵盖广泛的威胁。所有其他选项仅涵盖特定的单一威胁类型。

### 8.
正确答案是 **B**。由于 `web browser`（Web 浏览器）是事件源头且有权访问网站，因此确保该活动非恶意是合理的。如果活动无害，则 `anti-virus`（防病毒）扫描可以确认这一点。禁用 Web 浏览器将造成极大干扰且无法解决问题。阻止 `ports 80 and 443`（端口 80 和 443）将造成极大干扰，因为所有 Web 流量均被阻断。重装 `OS`（操作系统）干扰极大，仅应作为最后手段使用。
