

# CompTIA A+ 练习题

## 练习题 (16-19)

### 16. 一名初级 IT 技术员不小心用尖刀切断了以太网电缆的末端。修复它需要哪三种工具？

1.  `Wire cutters`（剪线钳）、`crimping tool`（压线钳）和 `RJ45` 接头
2.  螺丝刀、绝缘胶带和 `RJ45` 接头
3.  电烙铁、热缩管和 `RJ45` 接头
4.  钳子、万用表和 `RJ45` 接头

### 17. 你正在搭建光纤网络，需要在 `SC` 和 `LC` 接头之间做出选择。哪种接头类型提供更高的密度，且常用于数据中心？

1.  `SC` 接头
2.  `LC` 接头
3.  `ST` 接头
4.  `FC` 接头

### 18. 以下哪种接口常用于以高速将外部存储设备连接到计算机？

1.  `USB 2.0`
2.  `HDMI`
3.  `eSATA`
4.  `VGA`

### 19. 使用 `DisplayPort` 作为视频接口的主要优势是什么？

1.  同时传输视频和音频
2.  兼容旧式显示设备
3.  支持 `4K` 及更高分辨率
4.  与其他接口相比成本更低

## 3.2 根据场景安装合适的 RAM

### 7. `DDR` RAM 是一种计算机内存，与早期的内存技术相比提供了更高的数据传输速率。以下哪个选项正确匹配了每个版本 `DDR` RAM 的最低速度？

## 3.3 根据场景选择并安装存储设备

### 1. 直接将 `M.2` 硬盘安装在主板上而不使用线缆的主要优势是什么？

3.  无线缆杂乱，连接更简单且更安全
4.  通过 `IDE` 接口兼容老旧系统

4.  `1 TB SATA SSD`
