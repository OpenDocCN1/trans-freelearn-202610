

## 1.2 移动设备故障排除

15. 一位律师拿着大量案卷离开法庭。他们绊倒了，不小心掉落了一些案卷以及放在顶部的手机。当律师捡起手机时，屏幕看起来没有碎，但 10 分钟后，当他们尝试从手机发送电子邮件时，邮件图标无响应。他们尝试访问的其他每个应用程序也是如此。你认为发生了什么？

    1. `数字化仪`（`digitizer`）损坏
    2. 没有电源
    3. `CPU` 出现问题
    4. 以上全部

16. 笔记本电脑上的 `触控板`（`touchpad`）无响应。你应该怎么做？（选择两项）

    1. 重启笔记本电脑
    2. 移除插入的外接鼠标
    3. 更新 `驱动程序`（`driver`）
    4. 关闭 `陀螺仪`（`gyroscope`）

## 1.3 给定场景，设置和配置移动设备的配件与端口

1. `iPhone 10` 充电器使用哪种类型的连接？

    1. `USB-B`
    2. `USB-A`
    3. `USB-C`
    4. `Lightning`

2. 用户试图将 `USB 3.0` 存储棒插入其旧的 `Windows 7` 笔记本电脑，但很难插入。以下哪项可能导致该问题？（选择两项）

    1. `USB 3.0` 驱动器具有不同的 `外形规格`（`form factor`）
    2. `USB 3.0` 驱动器倒置了
    3. 笔记本电脑没有 `USB 3.0` 端口
    4. `USB 3.0` 驱动器的端部损坏

3. `Samsung Galaxy` 手机使用哪种类型的连接？

    1. `USB`
    2. `USB-C`
    3. `Micro USB`
    4. `Mini USB`

4. 用户发现很难将手机充电器插入手机，于是从 `Amazon` 订购了一个新充电器。然而，插入新充电器时，情况依旧。似乎插不进去。以下哪项是该问题的原因和解决方案？

    1. 用户插入线缆的端口积聚了绒毛，他们需要使用 `压缩空气`（`compressed air`）清理
    2. 用户插入线缆的端口积聚了绒毛，他们需要对着端口吹气清理
    3. 用户插入线缆的端口积聚了绒毛，他们需要向端口喷射 `WD-40` 清理
    4. 用户插入线缆的端口积聚了绒毛，他们需要使用一根长 `粗针`（`darning needle`）清理

5. 用户走进商店购买了支持 `蓝牙`（`Bluetooth`）的耳塞，以便在健身房锻炼时听音乐。然而，当他们打开智能手机和耳塞时，发现听不到音乐。用户首先需要做什么来解决此问题？（选择两项）

    1. 在手机上安装 `驱动程序`（`driver`）
    2. 启用 `蓝牙`（`Bluetooth`）
    3. 配对设备
    4. 打开音乐

6. 具有 `DisplayPort` 的扩展坞为笔记本电脑用户提供以下哪种类型的功能？（选择三项）

    1. 键盘和鼠标
    2. `Wi-Fi`
    3. `以太网`（`Ethernet`）连接
    4. 扬声器
    5. `双显示器`（`Dual-monitor`）功能

7. 一名用户在家远程工作，15 分钟后将参加 `Zoom` 会议。不幸的是，当他们启动笔记本电脑时，发现家庭无线网络瘫痪。用户可以快速实施什么方案以便参加会议？选择所需工作量最小的解决方案。

    1. 前往 10 英里外的当地 `Starbucks` 使用他们的无线网络
    2. 使用 `以太网`（`Ethernet`）线缆将笔记本电脑直接连接到无线路由器
    3. 使用 `智能手机`（`smartphone`）创建 `热点`（`hotspot`）
    4. 重启无线路由器

8. 一位笔记本电脑用户向服务台投诉其笔记本电脑端口不多。他们希望为键盘、鼠标和 `VGA` 投影仪增加一系列额外端口。服务台如何以最少的管理工作量满足此请求？

    1. 安装 `KVM` 切换器
    2. 安装 `端口复制器`（`port replicator`）
    3. 安装双显示器
    4. 安装 `集线器`（`hub`）

9. 使用带有 `触控笔`（`touch pen`）的平板电脑时，出现错误行为，如光标移动不稳定。以下哪三项是你应采取的识别问题的第一步？

    1. 检查屏幕是否损坏
    2. 更换 `触控笔`（`touch pen`）电池
    3. 重新校准 `触控笔`（`touch pen`）
    4. 清洁触摸屏

10. `micro USB` 被哪种连接类型取代？

     1. `串口`（`Serial`）
     2. `Lightning`
     3. `USB-C`
     4. `并口`（`Parallel`）

11. `iPhone 14` 充电器使用哪种类型的连接？

     1. `USB-A`
     2. `USB-B`
     3. `USB-C`
     4. `Lightning`

12. 哪种接口使用九针 `RS-232` 硬件端口？

     1. `并口`（`Parallel`）
     2. `RJ45`
     3. `RJ11`
     4. `串口`（`Serial`）

13. 用户尝试连接 `Zoom` 会话，但选择视频选项时无法打开。他们随后转到桌面上的相机应用测试网络摄像头，但网络摄像头也无法打开。网络摄像头在前一天还能正常工作。应执行以下哪项操作来解决此问题？（选择两项）

     1. 确保在相机隐私设置中，已启用 `允许应用访问此相机`（`Allow apps to access this camera`）
     2. 拔下网络摄像头 `USB` 线缆并尝试另一个 `USB` 端口
     3. 关闭任何其他视频软件应用程序并打开网络摄像头，查看其是否能启动
     4. 购买另一个网络摄像头，因为网络摄像头已损坏

14. `Windows 10` 计算机上的触摸屏功能停止工作。技术人员应检查以下哪项？

     1. 屏幕上没有气泡
     2. `计算机设置`（`Computer settings`）
     3. `显示设置`（`Display settings`）
     4. `电源设置`（`Power settings`）

15. 在其台式计算机操作系统更新后，用户的网络摄像头不再工作。用户将在 45 分钟后参加 `Zoom` 会议。以下哪项应作为其解决问题的第一步？

     1. 赶紧去商店买另一个网络摄像头
     2. 重启计算机
     3. 重新安装网络摄像头软件，包括任何 `驱动程序`（`driver`）更新
     4. 更新 `操作系统`（`OS`）

16. 滑铁卢火车站的一位康沃尔馅饼摊主在接受非接触式刷卡支付时遇到困难。刷卡时，非接触式扫描仪无法读取卡片并处理交易。客户需要将卡片插入设备并输入 `PIN` 码才能付款。以下哪种技术出现了故障？

     1. `蓝牙`（`Bluetooth`）
     2. `无线`（`Wireless`）
     3. `NFC`（近场通信）
     4. `红外`（`Infrared`）

17. 销售团队的一名成员联系服务台，称其手机过热。以下哪项导致了这种情况？（选择三项）

     1. 屏幕破裂
     2. 将手机用作 `Wi-Fi 热点`（`Wi-Fi hotspot`）
     3. `电池`（`battery`）故障
     4. 使用廉价 `充电线`（`charging cable`）
     5. 几个过时的 `应用程序`（`applications`）一直保持打开状态

18. `Lightning` 线缆取代了以下哪种线缆类型？

     1. `Apple 30-pin connector`（Apple 30 针连接器）
     2. `Apple 20-pin connector`（Apple 20 针连接器）
     3. `Apple 25-pin connector`（Apple 25 针连接器）
     4. `USB-C`
