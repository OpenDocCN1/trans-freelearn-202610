### 4. 正确答案是 **B**。Oracle `VirtualBox` 运行在 `Type 2 hypervisor` 上，这意味着它必须运行在诸如 `Windows 10` 之类的操作系统之上。所有其他答案均不正确。`Type 1 hypervisor` 运行在裸金属虚拟平台上，意味着没有操作系统。示例包括 Microsoft 的 `Hyper-V`、VMware 的 `ESX Server` 和 Citrix 的 `XenServer`。不存在类型 3 或类型 5 的 hypervisor。

### 5. 正确答案是 **B**、**D** 和 **E**。`sandbox` 是一种虚拟机，用于隔离应用程序，以便安全地测试新软件、检查可能包含恶意软件的应用程序，并确保应用程序补丁不会对软件产生不利影响。所有其他答案均不正确。`sandbox` 不包含沙子；它与火灾无关。它测试软件而非硬件。

### 8. 正确答案是 **D**。`Cross-platform virtualization` 意味着软件应用程序在发布前会在多个操作系统上进行测试，每个操作系统都有其自身的资源限制。所有其他答案均不正确。在不同版本的 `hypervisors` 上安装应用程序并不是 `Cross-platform virtualization` 的描述。您无法将 `sandboxes` 组网，因为它们是隔离的虚拟机。如果您一次测试一个应用程序，您使用的是同一个操作系统，而不是 `Cross-platform virtualization`。

### 10. 正确答案是 **B** 和 **E**。实现教授目标的最简单方法是使用 `Virtual Desktop Infrastructure (VDI)`，这样每个学生的虚拟机都可以将其虚拟桌面体验设置为非永久性。这样，当学生注销时，镜像将恢复到原始镜像，而不保存任何更改。另一种方法是构建虚拟机并创建 `snapshots`，然后在课程之间重置。所有其他答案均不正确。使用 `ghost image` 可能需要长达 45 分钟来重新制作每个桌面的镜像，如果课间时间不足，这将不是一个有效的解决方案。进行数据备份在这种情况下无法解决任何问题。实施系统所需的时间可能与使用 `ghost image` 一样长。

### 11. 正确答案是 **C**。`Virtual machine sprawl` 是指未受管理的虚拟机被放置在虚拟网络上。它构成安全风险，因为未受管理的虚拟机可能未打补丁，攻击者可能利用它访问您的网络。所有其他答案均不正确。`System sprawl` 发生在服务器在虚拟环境中过度消耗宿主资源时。`sandbox` 是一种隔离的虚拟机，用于测试应用程序和软件补丁以及调查恶意软件。
