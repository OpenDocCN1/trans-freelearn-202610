## 通用安全概念

1.  **正确答案是 B。** 这将同时设置本地 NTFS 权限并在网络上共享文件夹。选项 A 不会在网络上共享文件夹。选项 C 涉及只读属性，可用于防止文件或文件夹被意外删除。选项 D 不会在网络上共享文件夹，且授予的权限多于所需。

2.  **正确答案是 A。** 所有必需的设置将随一个集中管理且可用的 Microsoft 账户一起保存。这还支持单点登录 (SSO)。该账户可通过 Windows 设置菜单启用。选项 B 是不可能的。选项 C 是糟糕的安全选择，仍只会创建本地账户。选项 D 仅同步浏览器设置，且要求用户创建 Microsoft 账户。

3.  **正确答案是 A、B。** 选项 A 确保如果主用户账户被攻破，攻击者将只有有限的权限。选项 B 确保特权账户仅在短时间内暴露。选项 C 不是推荐的最佳实践，原因如前所述。选项 D 行不通，因为标准用户不会拥有所需的特权。

4.  **正确答案是 B。** BitLocker To Go 旨在保护可移动介质。USB 驱动器将被加密，查看驱动器上的任何内容都需要 BitLocker 密码或智能卡。选项 A 需要安装第三方安全套件，尽管它支持类似功能。选项 C 不提供内置安全功能。选项 D 旨在防止对 Windows 设备进行未经授权的配置更改。

5.  **正确答案是 A。** EFS 可使单个文件或整个文件夹使用 AES 对称加密进行加密。加密文件夹的用户将是唯一能够解密该文件夹内文件的用户。可由所有者酌情添加其他用户。选项 B 不合适，因为它不允许数据所有者加密单个文件夹。选项 C 仅用于可移动介质。选项 D 设置权限但不加密数据。

6.  **正确答案是 B。** UAC 旨在防止未经授权的配置更改，并向用户提供使用管理员账户或批准该操作的选项。选项 A 会弹出与可疑文件相关的警报对话框。选项 C 不是答案，尽管如果系统检测到有风险的登录事件，可能需要额外的身份验证因素。选项 D 不是答案，因为用户是在网卡上进行配置更改，而非防火墙。

7.  **正确答案是 A。** 确保所有安全更新和防病毒定义保持最新非常重要。在本例中，系统未能保持最新，因此最佳操作是下载所有更新。选项 B 不是最佳解决方案，因为系统可能感染了未被检测到的更多恶意软件。选项 C 在处理恶意软件时不推荐；建议采取相反做法（删除所有还原点）以避免系统再次感染。选项 D 仅作为最后手段，或许是在尝试了所有其他补救途径之后。

8.  **正确答案是 C。** 当防火墙阻止对某端口的入站连接时，扫描器将显示该端口为“已筛选”状态。同时，我们可以看到该筛选端口与数据库应用程序 (MySQL) 相关联。选项 A 不是好选择，因为它会使服务器暴露在不需要的连接面前。选项 B 无效，因为问题似乎出在应用程序服务器上。选项 D 不是能解决问题的操作，因为没有证据表明应用程序是问题所在。

## 8.6 给定场景，配置工作站以满足安全最佳实践

1.  **正确答案是 A。** BitLocker 将保护静态数据。如果笔记本电脑被盗，窃贼需要知道 BitLocker 密码。如果他们输入错误的密码，系统将锁定攻击者。选项 B 仅保护操作系统文件，不保护敏感数据。选项 C 将阻止授权用户账户在核心工作时间之外使用。选项 D 将确保系统在未被活跃使用时注销。

2.  **正确答案是 B。** 最小权限策略旨在最小化当用户账户被攻破或滥用时可能造成的潜在损害或未经授权的访问。通过限制用户特权，该策略减少了攻击面，并限制了攻击者在系统或网络中横向移动的能力。“高级用户”是为向后兼容性提供的组。该组不授予任何特权。选项 C 禁用来宾账户，是良好的安全最佳实践，但并非完全符合题目要求。选项 D 重命名管理员账户，是良好的安全最佳实践，因为攻击者将不知道重命名后的管理员账户名。

3.  **正确答案是 B。** 包含姓名或出生日期等个人信息并非创建强密码的最佳实践，因为个人信息容易被猜测。选项 A 不是最强选项。字典单词可配合单个大写字符使用。不过，结合其他密码强化技术，可增加密码复杂度。选项 C 加入特殊字符和数字，可防范简单的密码猜测、字典攻击和彩虹表攻击。选项 D 指较长的密码，通常更安全，因为它增加了攻击者需要猜测的可能组合数量。然而，为达到最佳安全性，较长的密码还应包含多种字符类型（字母、数字和特殊字符）。

4.  **正确答案是 A。** UEFI 包含可通过鼠标或触摸输入访问的图形用户界面 (GUI)。这使得配置和管理系统设置（如启动选项和硬件配置）更加容易。这取代了旧的基本输入/输出系统 (BIOS)。为防止用户篡改任何设置，应设置密码。选项 B、C 和 D 指将要使用的密码强化措施。

5.  **正确答案是 D。** 密码管理器是一种软件应用程序或服务，可帮助您安全地存储和管理密码。它提供了一种便捷的方式来生成、存储和检索不同在线账户的复杂密码。密码管理器的主要目的是通过消除记住多个密码或使用弱且易猜测密码的需要来提高安全性。相反，您只需记住一个主密码，或使用生物识别（指纹或面部识别）等其他身份验证方法来解锁密码管理器。密码管理器还将使用加密来保护密码。

6.  **正确答案是 B。** 选项 B 将在薪资员工的其他成员在场时，限制承包商登录系统的能力。选项 A 将允许承包商随时登录。选项 C 无效，因为承包商将拥有分配的账户（绝不会将来宾账户用于特权角色）。选项 D 是良好的安全最佳实践，但不解决题目提出的问题。
