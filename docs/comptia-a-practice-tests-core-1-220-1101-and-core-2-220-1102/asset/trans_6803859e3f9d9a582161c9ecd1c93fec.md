# 第 5 章：硬件和网络故障排除

## 5.2 给定场景，排查与主板、内存、CPU 和电源相关的问题

1. 正确答案是 **B** 和 **D**。更换内存时，应始终关闭服务器电源并佩戴防静电腕带。这将防止你损坏内存。让机器进入待机模式或尝试热插拔内存都不是好主意，因为两者都可能损坏内存。

2. 正确答案是 **C**。持续的蜂鸣声意味着问题出在内存模块或内存控制器上。主板问题可能表现为无蜂鸣声或 1 长 2 短蜂鸣声。电源问题会没有蜂鸣声。显示适配器错误可能是 1 长蜂鸣声后跟 2、3 或 4 短蜂鸣声。

3. 正确答案是 **B**。在升级服务器 CPU 之前，你应该查阅制造商网站以确定主板的插槽类型。然后，搜索该插槽类型是否可以升级到更快的 CPU。备份数据、关闭电源和佩戴防静电腕带应在升级前完成。

4. 正确答案是 **A** 和 **D**。安装内存模块后，如果未被检测到，请检查 BIOS。如果在 BIOS 中看不到它们，计算机就无法读取它们；因此，重新插拔内存模块以查看是否可以被检测到。重启计算机无济于事，佩戴防静电腕带虽应遵守但无法检测内存。

5. 正确答案是 **A** 和 **D**。如果进行过维护，存储适配器线缆可能以错误的方向插入。尽管技术人员能听到风扇转动的声音，但电源（PSU）可能存在故障，导致无法向 CPU 发送“电源正常”信号。这两种故障都会阻止计算机执行开机自检（POST）。主板问题可能表现为无蜂鸣声或 1 长 2 短蜂鸣声。计算机技术人员在启动计算机时不连接显示器的可能性极小。

6. 正确答案是 **C**。计算机上的时钟时间使用芯片组的一部分实时时钟来保持时间、日期和日历的准确。实时时钟由 CMOS 电池供电，如果时钟不断走时不准，则需要更换电池。连接到计算机的电源线电源不影响计算机时钟。电源（PSU）不为实时时钟供电。获取 BIOS 更新不影响实时时钟。

7. 正确答案是 **B**。电容器吸收直流电压中的尖峰，并能暂时存储电荷。如果电容器故障，它会鼓包，如果不移除，它会爆炸并损坏计算机。CMOS 电池为实时时钟供电，而非电容器。电容器不存储数据；硬盘存储数据。
