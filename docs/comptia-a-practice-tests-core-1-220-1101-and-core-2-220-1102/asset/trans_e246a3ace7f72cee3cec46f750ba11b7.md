# 第 6 章：模拟考试：Core 1 (220-1101)

1. 正确答案是 **C**。与传统硬盘相比，M.2 支持更快的数据传输速率。M.2 是一种常用于固态硬盘 (SSD) 的外形规格，其数据传输速度比传统硬盘更快。M.2 支持 SATA 和 PCIe 接口。显卡通常使用 PCIe 外形规格。M.2 可用作启动设备。

2. 正确答案是 **A**。RAID 5 至少需要三块驱动器，并将数据和奇偶校验分布在多个驱动器上以提供容错能力。RAID 6 通过双重奇偶校验提供更高级别的容错能力。RAID 0 由于不带冗余的数据条带化而提供更高的读取性能。RAID 5 不需要专用的奇偶校验驱动器。

3. 正确答案是 **B**。安全数字卡 (SD) 常用于数码相机。SD 卡被广泛采用，并提供不同容量以存储照片和视频。紧凑型闪存卡 (CF) 过去很流行，但已在很大程度上被 SD 卡取代。记忆棒 (MS) 主要用于索尼设备。极数码卡 (xD) 较少见，用于较旧的奥林巴斯和富士胶片相机。

4. 正确答案是 **D**。ATX 主板支持双通道内存架构。双通道内存允许增加内存带宽并提高系统性能。ATX 主板同时支持 Intel 和 AMD 处理器。ATX 主板通常比 microATX 主板拥有更多扩展插槽。现代 ATX 主板使用 24 针 ATX 电源接口。

5. 正确答案是 **A**。安全启动是 UEFI 提供的一项安全功能。安全启动确保在系统启动期间仅加载受信任的操作系统引导加载程序和驱动程序。虽然 BIOS 密码是一项安全功能，但它并非 UEFI 所特有。CMOS 清除跳线不是 UEFI 提供的安全功能。TPM 是一个独立的硬件组件，提供安全存储和加密功能（如加密和数字签名）以增强整体系统安全性。
