4. **技术人员正在调查销售部门一台笔记本电脑的问题。`Windows Defender` 安全功能已关闭，当技术人员尝试重新启用这些功能时，设置会被恢复。哪种类型的恶意软件可能导致此问题？**
    1. 特洛伊木马

    3. 病毒
    4. 间谍软件
    5. 勒索软件

5. **安全人员正准备一组自动化操作，以协助服务台处理恶意软件事件。他们提议创建一些剧本（playbooks）来协助团队。其中一个场景要求擦除整个硬盘并重新安装 `OS`。哪种恶意软件类型需要采取此操作？**
    1. 特洛伊木马
    2. Rootkit
    3. 病毒
    4. 间谍软件

6. **用户致电服务台投诉，在打开同事发送的文件后，他们无法再访问任何本地文件夹。此外，他们看到弹出消息显示电话号码，并要求付款以修复问题。用户计算机上可能发生了什么？**
    1. 特洛伊木马
    2. Rootkit
    3. 病毒
    4. 间谍软件
    5. 勒索软件

7. **在公司网络上安装了一系列技术预防控制以降低恶意软件事件后，受感染系统减少了 90%。这些控制措施包括垃圾邮件过滤器、内容检查以及端点检测和响应（`EDR`）。除了这些技术控制外，以下哪项在进一步减少恶意软件事件方面最有效？**
    1. 关于 Rootkit 的用户教育
    2. 关于病毒的用户教育
    3. 关于常见威胁的用户教育
    4. 关于间谍软件的用户教育

8. **用户在收到 `Windows 10 操作中心` 的多条消息后致电服务台。这些消息似乎无害，且由 Web 浏览器生成。修复此问题的最佳操作是什么？**
    1. 禁用 Web 浏览器
    2. 执行完整的防病毒扫描
    3. 阻止端口 80 和 443 上的所有出站流量
    4. 删除并重新安装 `OS`

9. **近期大量垃圾邮件针对财务团队。这些邮件似乎来自真实的供应商，且通常包含重置登录详细信息的链接。采取什么措施最有助于减少这些事件？**
    1. 软件防火墙
    2. 反钓鱼培训
    3. 关于常见威胁的用户教育
    4. `OS` 重新安装

10. **用户从非官方的第三方互联网站点安装新视频驱动程序后，工作站出现异常行为。工作站运行缓慢，用户报告除了更新驱动程序外没有进行其他更改。采取什么操作能让技术人员最好地确定驱动程序是否导致该行为？**
     1. 将工作站重启进入恢复模式，选择 `疑难解答\高级选项\启动设置`，并选择启用 `安全模式`
     2. 执行完整的防病毒扫描
     3. 确保反恶意软件已更新
     4. 配置 `Windows 防火墙` 以阻止所有传出连接

11. **公司最近出现大量用户账户被盗用。这些账户属于工程团队，该团队使用有限数量的工程工作站进行热插拔（共享工位）。尽管已重置用户密码，但问题依然存在。账户被盗用的最可能原因是什么？**
     1. 远程访问特洛伊木马
     2. 替换关键 `OS` 文件的 Rootkit
     3. 工程工作站上的硬件键盘记录器
     4. 窃取用户凭据的加密货币挖矿程序

12. **一些用户最近从营销活动返回，带回了 `USB` 媒体上提供的数字宣传材料。服务台接到多个用户来电，抱怨应用程序加载缓慢，工作站运行极其缓慢。经调查，发现 `CPU/GPU` 活动运行在 100%。最可能影响用户的恶意软件类型是什么？**
     1. 间谍软件
     2. 加密货币挖矿程序
     3. 键盘记录器
     4. 引导扇区病毒

## 8.4 解释常见的社会工程学攻击、威胁和漏洞

1. **首席信息官（`CIO`）收到首席执行官（`CEO`）发来的电子邮件，要求提供机密信息。该邮件似乎源自 `CIO` 不认识的个人电子邮件地址。这可能是什么类型的攻击？**
    1. 网络钓鱼
    2. 垃圾箱搜寻
    3. 偷窥
    4. 鲸钓攻击/高层钓鱼

2. **用户从中央办公室打印机取走打印文件。尽管拥挤的打印室里有大量其他用户，但在排队等待后，用户成功输入密码拉取了打印任务。后来，用户收到警告，称使用相同凭据进行了可疑登录。可能发生了什么社会工程学事件？**
    1. 网络钓鱼
    2. 语音钓鱼
    3. 偷窥
    4. 鲸钓攻击/高层钓鱼

3. **一队承包商抵达现场，穿着印有知名支持承包商徽标的衬衫和夹克。承包商称他们是响应从银行数据中心关键服务器接收到的错误消息。没有生成支持呼叫的记录。可能的攻击载体是什么？**
    1. 尾随
    2. 冒充
    3. 垃圾箱搜寻
    4. 邪恶双子

4. **用户提交支持工单，抱怨 Wi-Fi 速度慢、本地映射驱动器和打印机不可用。在多次连接到互联网站点时，系统要求用户输入凭据。用户怀疑其在线账户可能已被盗用。可能的威胁载体是什么？**
    1. 尾随

    3. 垃圾箱搜寻
    4. 邪恶双子

5. **一名身穿高可见度夹克、手持包裹的快递员尾随员工进入无人值守的接待区。后来，发现笔记本电脑和平板电脑被报告丢失或被盗。这次安全漏洞的可能原因是什么？**
    1. 尾随

6. **一家在线零售商收到多起投诉，称客户无法访问该网站。经调查，工程师发现数千个远程连接到该网站的 Web 服务器。这些连接似乎不是真实客户登录网站。可能的威胁是什么？**
