

## 问题 6–10

6. 正确答案是 **B**。执行定期备份是软件部署变更管理最佳实践的一个示例。备份可确保在部署过程中出现任何问题或故障时能够恢复数据。选项 A 不正确，因为跳过测试阶段可能导致部署有缺陷的软件并引发潜在的系统中断。选项 C 不正确，因为在高峰时段实施变更会增加对用户的影响并影响系统可用性。选项 D 不正确，因为有效的用户沟通对于管理预期和确保平稳过渡至关重要。

7. 正确答案是 **B**。进行彻底的资产清单评估是硬件更换变更管理最佳实践的一个示例。它确保组织拥有关于现有硬件的准确信息，从而在更换过程中便于进行适当的规划和决策。选项 A 不正确，因为忽略用户反馈可能导致在硬件更换期间忽视重要的见解和需求。选项 C 不正确，因为在未测试的情况下实施变更可能导致部署有缺陷的硬件并引发潜在中断。选项 D 不正确，因为让利益相关者参与该过程对于他们在硬件更换期间的理解和支持至关重要。

8. 正确答案是 **C**。变更管理中回滚计划的目的是识别变更实施过程中可能出现的潜在问题，并概述在必要时恢复到先前状态的步骤。选项 A 不正确，因为回滚计划的目的不是阻止变更实施，而是在出现问题时提供应急计划。选项 B 不正确，因为记录变更实施的原因很重要，但这不是回滚计划的主要目的。选项 D 不正确，因为用户反馈在变更过程中很有价值，应予以考虑，而非排除在外。

9. 正确答案是 **C**。定期进行风险评估是管理变更相关风险的推荐做法。通过定期评估与变更相关的潜在风险，组织可以主动识别并缓解这些风险，以最大限度地减少负面影响。选项 A 不正确，因为完全避免风险评估可能导致忽视潜在风险及其后果。选项 B 不正确，因为在没有备份计划的情况下实施变更可能导致变更过程中出现意外问题和困难。选项 D 不正确，因为忽视风险缓解策略会使组织容易受到潜在风险的负面影响。

10. 正确答案是 **C**。针对目标受众定制信息是在变更管理期间向用户传达变更时的一个关键考量因素。不同用户可能具有不同水平的技术知识和关注点，因此定制沟通有助于确保他们的理解和接受。选项 A 不正确，因为提供模糊和笼统的信息可能导致用户困惑和误解。选项 B 不正确，因为过分强调变更的负面方面可能产生抵触情绪并阻碍用户接受。选项 D 不正确，因为将沟通推迟到变更实施之后会造成不确定性，并对用户对变更的准备度产生负面影响。

## 10.3 给定场景，实施工作站备份和恢复方法

1. 正确答案是 **A**。完整备份会创建所有数据和设置的完整副本，提供该特定时刻工作站的全面快照。此方法允许在数据丢失时进行完整恢复。选项 B 仅包含自上次完整备份以来更改的数据，而非特定时间点的所有数据。选项 C 仅包含自上次备份以来更改的数据，这可能是完整备份或增量备份，但它无法捕获特定时间点的所有数据。选项 D 不是标准备份方法。它指手动选择特定文件或文件夹进行备份，而非创建工作站的完整快照。

2. 正确答案是 **A**。裸机恢复涉及从完整备份中恢复整个工作站的操作系统、应用程序和数据，通常用于需要从头重建系统或迁移到新硬件的情况。选项 B 指从存储在云中的备份恢复数据或应用程序，但不涉及恢复整个工作站的硬盘驱动器。选项 C 侧重于恢复单个文件或文件夹，而非整个工作站的硬盘驱动器。选项 D 不是标准术语。增量备份用于仅恢复自上次备份以来更改的数据，而非整个系统。

3. 正确答案是 **A**。与其他备份存储介质相比，磁带驱动器提供更快的传输速率，但与其他选项相比，其成本往往较高。选项 B（外置硬盘驱动器）因其相对较快的传输速率和比磁带驱动器更高的成本效益而成为流行的备份介质。选项 C（网络附属存储 (NAS)）提供方便且可通过网络访问的备份解决方案，但其传输速率不会像磁带驱动器那样快。选项 D（云存储）具有成本效益且易于扩展，但与磁带驱动器相比传输速率较慢，尤其是在处理大量数据时。

4. 正确答案是 **B**。增量备份旨在仅备份自上次备份以来发生更改的数据。这种备份类型旨在减少备份时间并需要较少的存储空间。选项 A（差异备份）备份自上次完整备份以来更改的所有数据，不考虑之前的增量备份。选项 C（综合备份）是一种通过组合之前的完整备份和后续的增量备份来创建新完整备份的方法。它不直接解决仅备份自上次备份以来更改数据的问题。选项 D（持续备份）涉及在数据更改时实时备份，确保在发生故障时将数据丢失降至最低。它不区分完整备份和增量备份。

5. 正确答案是 **A**。祖父-父-子轮换方案涉及使用一组备份介质并按日循环使用它们。当介质集满时，最旧的备份会被覆盖。该方案提供了每日、每周和每月备份的组合。选项 B（汉诺塔）是一种备份轮换方案，它使用一组备份介质，但涉及基于特定规则的多级备份的更复杂轮换模式。选项 C（备份到磁盘）指将备份存储在基于磁盘的存储介质上，但未指定轮换方案。选项 D（备份到磁带）是一种利用磁带驱动器作为存储介质的备份方法，但不意味着特定的轮换方案。
