## 3.5 给定场景，安装或更换合适的电源

1. 正确答案是 **A**。模块化电源允许您拆卸并仅连接必要的线缆，最大限度地减少机箱内的线缆杂乱。这改善了气流，并便于维护和升级。所有其他选项均不正确。

2. 正确答案是 **A**。安装具有独立电源的双电源通过在电源故障时提供冗余备份，确保不间断供电。冗余电源不影响存储容量。冗余电源不增强 `CPU` 性能。冗余电源不改善网络连接。

3. 正确答案是 **A**。`3.3V`：橙色或黄色（通常用于主板、网卡和某些数字电路）；`5V`：红色（常用于 `USB` 端口、电源和各种外设）；`12V`：黄色或蓝色（常用于电源、`SATA` 接口和风扇）。所有其他选项均错误。

4. 正确答案是 **A**。`ATX` 主板通常使用 `20-pin` 或 `24-pin` 电源接口，为主板及其组件供电。这些主板广泛用于台式计算机，并提供各种扩展插槽和功能以适应不同的硬件配置。`Mini-ITX`（Information Technology eXtended）主板体积小巧，专为小型规格系统设计。`Micro-ATX` 主板是 `ATX` 主板的较小规格变体。`ITX`（Information Technology eXtended）主板，包括 `Mini-ITX` 和 `Nano-ITX` 变体，专为超紧凑型系统设计。

5. 正确答案是 **A**。模块化电源的主要优势是能够自定义线缆管理。使用模块化电源，您可以仅连接必要的线缆，从而使系统更整洁、有序。这改善了气流，提升了美观度，并简化了维护和升级。高效率不是模块化电源的主要优势。模块化电源不影响散热性能。模块化电源不提供更高的功率输出。

6. 正确答案是 **A**。在北美，电气设备的标准电压范围为 `110-120 VAC`（伏特交流电）。该电压范围常用于北美的住宅和商业应用，电源设计旨在在此范围内供电。另一方面，在欧洲和世界许多其他地区，电气设备的标准电压范围为 `220-240 VAC`。所有其他选项均错误。

7. 正确答案是 **A**。冗余电源通过在停电期间利用备用电源或 `UPS` 系统，确保不间断的电力流动，最大限度地减少停机时间，并保持办公室的生产力。冗余电源不会增加电源插座的数量。冗余电源与办公家具无关。备用发电机可以在停电时提供电力，但它们不被视为冗余电源系统。

8. 正确答案是 **B**。对于典型的台式计算机，额定功率约为 `500 W` 的电源通常已足够。这应能提供足够的电力来支持标准台式机配置中常见的 `CPU`、显卡、存储驱动器和其他外设。`300 W` 将无法提供足够的电力。`750 W`/`1,000 W` 将消耗比标准台式机更多的电力，通常用于游戏主机。
