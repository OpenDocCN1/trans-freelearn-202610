# 第 3 章：硬件

## 3.1 解释基本电缆类型及其连接器、特性和用途

1. 正确答案是 **A**。铜缆会受到信号衰减的影响，这指的是信号强度随距离增加而损耗。铜缆易受电磁干扰。这会降低速度，但不是主要限制。带宽限制主要影响网络的整体容量，但不直接影响数据传输速度。绝缘相关的问题更可能导致信号质量问题，而不是限制数据传输速度。

2. 正确答案是 **A**。光时域反射仪 (OTDR) 是一种用于故障排查和测试光纤电缆的工具。它向电缆发送光脉冲并测量反射，以识别任何问题，如断点或信号损耗。剪线钳用于剪切导线，不用于排查光纤电缆故障。以太网电缆测试仪用于验证以太网电缆的连通性和质量。万用表用于测量电路中的电压、电流和电阻。

3. 正确答案是 **A**。ST 连接器通常用于单模光纤电缆。其主要优势是低信号损耗，而非高数据速率。多模光纤用于高数据速率。它们使用具有卡口式设计的 ST 连接器，且易于安装。对于高密度网络，通常使用 LC (Lucent Connector) 连接器。LC 连接器是小型化连接器，在保持卓越性能的同时提供高密度连接。同轴电缆兼容各种连接器和设备，使其适用于不同应用。它们可轻松连接到电视、调制解调器、路由器、天线和视频摄像头等设备。
