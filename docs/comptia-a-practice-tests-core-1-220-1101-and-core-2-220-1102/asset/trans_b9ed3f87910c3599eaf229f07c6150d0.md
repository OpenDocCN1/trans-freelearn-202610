# 8.5 场景题：管理和配置 Microsoft Windows OS 基本安全设置

## 1. 文件夹共享权限配置

**管理员的任务是在用户的 Windows 10 笔记本电脑上配置 marketing 文件夹的权限。权限应允许营销团队对该文件夹拥有读取权限。管理员应配置什么以允许营销用户通过网络访问该文件夹？**

1.  将营销组的 NTFS 权限设置为读取
2.  选择共享文件夹并授予营销组读取网络访问权限
3.  选择文件夹属性并确保选中只读
4.  将营销组的 NTFS 权限设置为修改

## 2. 跨设备同步设置

**服务台接到一位家庭用户的来电，该用户希望在登录不同 Windows 设备时同步其偏好设置、主题和浏览器快捷方式。目前，用户在每台设备上都配置了唯一的本地账户。用户还希望所有设备使用单一账户。什么功能能满足用户的请求？**

1.  让用户创建一个 Microsoft 账户并在每台设备上启用它
2.  在当前设备上创建一个本地账户并将该账户复制到所有设备
3.  让用户在每台设备上使用默认来宾账户登录
4.  让用户登录 Edge 浏览器并启用同步选项

## 3. 特权账户最佳实践

**为一名标准用户分配了第二个特权账户，可在需要时用于重置其他用户的密码。该用户有权访问 Active Directory 用户和计算机 (ADUC) 控制台。在考虑使用这两个账户时，推荐的最佳安全实践是什么？(选择两项。)**

1.  始终使用标准用户账户登录工作站
2.  使用特权账户时使用“以管理员身份运行”选项
3.  始终使用特权用户账户登录工作站
4.  使用特权账户时使用“以标准用户身份运行”选项

## 4. 移动存储加密

**用户请求在可移动 USB 驱动器上存储敏感信息。公司政策规定所有可移动存储必须支持数据加密，且所有静态数据必须加密。可以使用什么 Windows 功能来满足公司政策？**

1.  Pretty Good Privacy (PGP)
2.  BitLocker To Go
3.  可扩展文件分配表 (exFAT) 文件系统
4.  用户账户控制 (UAC)

## 5. 文件夹级加密 (EFS)

**财务经理提交了一张支持工单。他们希望保护存储在 Windows 10 工作站上的敏感文件。文件包含客户详细信息，存储在单个文件夹中。为满足安全最佳实践，文件必须加密。支持技术人员可以配置什么来保护该文件夹？**

1.  为该文件夹启用加密文件系统 (EFS)
2.  为该文件夹启用 BitLocker 驱动器加密
3.  在该文件夹上启用 BitLocker To Go
4.  确保财务团队的 NTFS 权限设置为读取

## 6. 用户账户控制 (UAC)

**技术人员尝试在服务器的网络接口卡上手动设置 IP 地址。系统提示一个安全对话框，询问是否批准该应用程序对计算机进行更改。是什么可能需要此额外验证？**

1.  Windows Defender 防病毒
2.  用户账户控制 (UAC)
3.  多因素身份验证 (MFA)
4.  Windows Defender 防火墙

## 7. 恶意软件处理流程

**技术人员在系统上发现未知进程运行后，隔离了用户的 Windows 10 笔记本电脑。该进程被识别为恶意软件，并在许多防病毒供应商网站上有记录。用户已在一个无互联网访问的网络上使用该笔记本电脑 2 个月。技术人员接下来应该做什么？**

1.  更新 Windows Defender 定义文件并运行完整的防病毒扫描
2.  手动删除恶意文件并将笔记本电脑归还给用户
3.  使用系统还原恢复到上一个还原点
4.  擦除系统并执行全新的 Windows 安装

## 8. 防火墙规则配置 (MySQL 端口)

**最近安装的数据库应用程序已在部门服务器上配置并测试完成。部门用户无法通过网络连接到该应用程序。技术人员对服务器执行端口扫描并观察到以下输出：**

```
Nmap scan report for 192.168.0.22
Host is up (0.000086s latency).
Not shown: 994 closed ports
PORT     STATE    SERVICE
135/tcp  open     msrpc
139/tcp  open     netbios-ssn
445/tcp  open     microsoft-ds
514/tcp  open     shell
3306/tcp filtered  mysql
```

**技术人员接下来应该做什么以允许用户访问数据库应用程序？**

1.  在服务器上停用 Windows Defender 防火墙
2.  在用户的工作站上启用 Windows Defender 防火墙
3.  在服务器上添加防火墙规则以允许入站流量访问端口 3306
4.  在服务器上重新安装数据库应用程序并执行系统重启

# 8.6 场景题：配置工作站以满足安全最佳实践

## 1. 静态数据加密 (BitLocker)

**一位正在参加会议的高级经理需要确保存储在笔记本电脑上的机密数据在笔记本电脑关机时得到保护。什么能最好地保护静态数据？**

1.  BitLocker 全盘加密
2.  使用 Pretty Good Privacy (PGP) 加密系统文件
3.  限制登录时间
4.  使用超时/屏幕锁定

## 2. 最小权限原则

**管理员必须确保将用户账户添加到组中，仅授予执行分配任务所需的必要特权。什么最佳实践能确保用户不会变得过度特权化？**

1.  确保所有用户仅是高级用户组的成员
2.  实施最小权限策略
3.  确保来宾账户已禁用
4.  重命名默认管理员账户

## 3. 强密码策略反例

**以下哪项不是创建强密码的推荐做法？**

1.  使用大小写字母组合
2.  包含姓名或出生日期等个人信息
3.  包含特殊字符和数字
4.  至少八位长度

## 4. 禁用 Wake-on-LAN 的固化措施

**技术人员禁用了对 Wake-on-LAN (WoL) 网络支持的支持。这是所有公司笔记本电脑的要求。技术人员担心用户会直接将此功能重新开启。阻止此操作的最有效方法是什么？**

1.  启用统一可扩展固件接口 (UEFI) 密码
2.  确保用户密码设置了复杂性要求
3.  确保用户密码设置了过期要求
4.  确保用户密码设置了长度要求
