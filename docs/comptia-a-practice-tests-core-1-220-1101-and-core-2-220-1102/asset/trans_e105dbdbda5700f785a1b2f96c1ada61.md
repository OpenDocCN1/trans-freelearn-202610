# 第 2 章：网络

## 2.1 比较和对比 TCP 和 UDP 端口、协议及其用途

1. 正确答案是 **B**。`Secure Shell (SSH)` 用于安全远程访问。其他所有答案均不正确。`Telnet` 提供不安全的远程访问，`RDP` 使用端口 `3389`，是一种安全远程访问协议，仅可用于连接到 Microsoft 桌面/服务器，`SNMP` `161` 不安全，并提供网络设备的状态和报告。

2. 正确答案是 **B**。`Hypertext Protocol Secure (HTTPS)` 用于在 Web 服务器上建立安全会话。其他所有答案均不正确。`TFTP` 不安全，用于传输配置文件。`HTTP` 用于在 Web 服务器上建立不安全会话。`SSH` 用于安全远程访问。

3. 正确答案是 **A**。`Post Office Protocol (POP)` 是一种旧版邮件客户端，将电子邮件存储在本地，使用端口 `110`。其他所有答案均不正确。`IMAP` 是一种提供日记和日历、允许创建多个文件夹、与邮件服务器保持永久连接并使用 `TCP` 端口 `143` 的邮件客户端；`SMTP` 用于在邮件服务器之间传输电子邮件，使用 `TCP` 端口 `25`。

4. 正确答案是 **C**。`Server Message Block (SMB)` 使用端口 `445` 在 Windows 环境中进行文件和打印共享。但是，它仅限内部使用，不能在互联网上使用。其他所有答案均不正确。`NETBIOS`（端口 `137-139`）用于 Microsoft 的传统名称注册和解析。`67/68` 由 `DHCP` 用于自动分配 IP 地址。`389` 由 `LDAP` 用于通过查询和更新 X500 目录对象来管理目录服务。

5. 正确答案是 **B**。端口 `995` 是 `Secure Post Office Protocol (SPOP)` 使用的标准端口。其他所有答案均不正确。不安全的 `POP` 使用 `110`。安全的 `IMAP` 使用 `993`。不安全的 `IMAP` 使用 `143`。

6. 正确答案是 **C**。`User Datagram Protocol (UDP)` 是无连接的，可用于流式传输视频和音频。其他所有答案均不正确。`TCP` 是面向连接的，对于音频或流式视频来说太慢。`RDP` 用于对 Windows 服务器/桌面的安全远程访问。`TFTP` 是无连接的快速数据传输。通常由网络设备用于获取配置文件。

7. 正确答案是 **D**。`Simple Network Management Protocol (SNMP) v3` 是安全的，并使用 `UDP` 端口 `162`。其他所有答案均不正确。`SNMP` 使用 `UDP` 端口 `161` 但不安全。端口 `389` 由 `LDAP` 用于创建、管理和搜索目录服务。`POP`（不安全的邮件客户端）使用 `TCP` 端口 `110`。

8. 正确答案是 **B**。`File Transfer Protocol (FTP)` 端口 `21` 不安全，以明文传输数据。其他所有答案均不正确。`TFTP` 是 `FTP` 的 `UDP` 版本。`SSH` 是一种安全的远程管理方法。`FTPS` 是 `FTP` 的安全版本。

9. 正确答案是 **B** 和 **D**。`Hypertext Transfer Protocol (HTTP)` 使用端口 `80`，`Hypertext Transfer Protocol Secure (HTTPS)` 使用端口 `443`。其他所有答案均不正确。端口 `23` 由 `Telnet` 使用。端口 `110` 由 `POP` 使用。端口 `445` 由 `SMB` 使用。

10. 正确答案是 **D**。`Transmission Control Protocol (TCP)` 三次握手的正确顺序是 `SYN`，然后 `SYN-ACK`，最后 `ACK`。其他所有答案中的顺序均不正确。
