## 5.3 给定场景，排查并诊断存储驱动器和 RAID 阵列的问题

### 1. 兼顾快速读取访问和冗余的存储解决方案

一位客户致电 IT 支持公司，请求提供存储解决方案。该客户已购买三块 20 TB 硬盘，解决方案必须提供快速读取访问和冗余。以下哪种解决方案最适合实施？

1.  RAID 0
2.  RAID 1
3.  RAID 5
4.  RAID 6

### 2. 硬件 RAID 5 磁盘故障与热插拔风险

系统管理员收到来自其邮件服务器的警报，提示一块磁盘发生故障。他们登录服务器，发现只能看到五组磁盘中的四组。他们使用的是硬件 RAID 5 解决方案，因此可以热插拔更换故障磁盘。系统管理员在更换故障磁盘时会遇到什么风险（如果有）？

1.  RAID 5 具有冗余性，完全没有风险
2.  逐个拔出磁盘，查找故障磁盘的 SCSI ID
3.  查看 RAID 阵列，寻找亮红灯的磁盘
4.  如果移除了一块健康的磁盘，将会丢失所有数据

计算机技术人员正试图找出计算机无法启动的原因。他们取出硬盘并将其连接到安装了恢复软件的计算机上。他们能够看到数据。计算机技术人员接下来应该做什么？

1.  将磁盘放回计算机并从中启动
2.  使用磁盘管理格式化磁盘
3.  备份数据
4.  将磁盘放回计算机，然后安装恢复软件

### 5. 加密 USB 驱动器问题

一位经理正在使用其笔记本电脑工作，并插入一个包含多份机密 Excel 电子表格的加密 USB 驱动器。他们向帮助台提交了工单。一位支持技术人员到场解决问题。技术人员将如何解决该问题？

1.  他们将使用磁盘管理
2.  他们将把 USB 转换为 `NTFS`
3.  他们将在 C 盘上启用 BitLocker
4.  他们将在 USB 驱动器上启用 BitLocker

### 6. SMART 监控错误与磁盘管理状态对比

计算机技术人员从 SMART 监控接收到磁盘错误。计算机正常启动，但当他们查看磁盘管理时，显示所有磁盘均处于健康状态。导致此错误的原因是什么？

1.  磁盘管理未正常运行
2.  文件系统为 `NTFS`
3.  SMART 监控出现故障
4.  RAID 5 系统中缺少一块磁盘

### 7. 硬盘指示灯持续亮橙色

用户的计算机无法启动，他们注意到硬盘指示灯持续亮橙色。以下哪项可能导致此问题？

1.  计算机有内存问题
2.  硬盘驱动器存在硬件问题
3.  计算机有处理器问题
4.  SMART 监控已被禁用，导致计算机冻结

### 8. 读/写时间延长

计算机技术人员对计算机硬盘运行性能测试。测试显示磁盘遭受读/写时间延长的问题。技术人员接下来应该怎么做？

1.  启动 `Advanced > SMART settings > SMART self-test`
2.  运行随计算机提供的系统诊断程序
3.  更换新磁盘
4.  禁用 SMART 监控

### 9. RAID 5 降级状态（选择两项）

配置了 RAID 5 的计算机收到警报，提示其中一块磁盘处于降级状态。以下哪项导致了此错误，它如何影响磁盘上的数据？

1.  RAID 5 组中的一块磁盘需要格式化为 `NTFS`
2.  RAID 5 组中的一块磁盘已故障
3.  数据不再可用
4.  数据仍然可用

### 10. “缺少操作系统”错误

计算机技术人员启动计算机，收到错误消息“缺少操作系统”。以下哪项导致了此错误？

2.  计算机正在进行 Windows 更新
3.  包含操作系统的磁盘已故障
4.  CMOS 电池电量不足

### 11. 识别存储设备性能下降

如何判断存储设备的性能是否正在下降？

1.  将会有持续亮起的橙色指示灯
2.  检查 IOPS
3.  检查磁盘管理
4.  将会有闪烁的绿色指示灯

## 5.4 给定场景，排查视频、投影仪和显示器问题

### 1. 投影仪图像昏暗

技术人员被叫到教室，因为投影仪图像非常昏暗。以下哪项导致了该问题？

1.  逆变器损坏
2.  需要调整显示设置
3.  数字化器故障
4.  灯泡烧坏

### 2. 投影仪“无信号”错误

技术人员在会议室设置投影仪，收到提示“无信号”的错误。导致此问题的原因可能是什么？

1.  连接投影仪的线缆故障，需要更换
2.  投影仪的灯泡需要更换
3.  计算机的显示器损坏
4.  计算机需要将显示设置为 `extend this display`

### 3. 投影图像模糊

大学教授将笔记本电脑连接到剧院的投影仪。投影图像模糊。以下哪项导致了此问题？

1.  线缆有缺陷
2.  需要调整笔记本电脑显示设置
3.  需要调整投影仪镜头
4.  投影仪灯泡需要更换

### 4. HDCP 复制保护错误

演示者尝试播放笔记本电脑 DVD 中的视频。他们能听到声音，但投影仪上出现错误，提示“复制保护：DVI/HDMI 输出被阻止”。以下哪项导致了此问题？

1.  HDMI 线缆故障
2.  投影仪不兼容 HDCP
3.  需要调整显示设置
4.  DVD 播放器有问题

### 5. 笔记本电脑无法投影图像（选择两项）

计算机技术人员在报告厅将笔记本电脑连接到投影仪，但屏幕上未投影图像。他们返回车间拿来了已知工作正常的线缆。更换线缆后，他们收到“未找到信号源”错误。计算机技术人员接下来应该怎么做？

1.  更换投影仪的灯泡
2.  检查 HDMI 线缆的连接
3.  运行 `displayswitch.exe` 并选择“复制”或“扩展”
4.  在笔记本电脑上进入显示设置，选择多显示器，并复制这些显示器

### 6. 图像闪烁且有亮点（选择两项）

计算机技术人员被叫到即将举行演示的会议室。演示者告知技术人员图像先是闪烁，现在看起来像是在闪烁。计算机技术人员注意到屏幕边缘有一些亮点。是什么导致了此问题？

1.  检查两端的线缆连接器
2.  检查显示设置
3.  笔记本电脑的背光开始故障
4.  重启笔记本电脑

### 7. 视频音响无音频

会议室刚刚安装了一套新的电视和视频音响系统。电视用于播放演示笔记本电脑的视频。声音从笔记本电脑和电视传出，但视频音响没有产生任何音频。以下哪项导致了该问题？

1.  音响未开启
2.  音响音量太低
