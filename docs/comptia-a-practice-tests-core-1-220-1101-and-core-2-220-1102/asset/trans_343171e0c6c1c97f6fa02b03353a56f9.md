## 10.4 针对给定场景，使用常见安全程序

1. 正确答案是 **A**。佩戴 ESD（静电放电）腕带有助于防止静电损坏计算机组件。它可安全释放人体积累的静电。选项 B（在不关闭电源的情况下断开电源）可能导致硬件损坏并可能伤害个人。选项 C（用裸手触摸电路板）可能引入静电并损坏敏感组件。选项 D（站在潮湿表面上）增加触电风险，在使用计算机硬件时极具危险性。

2. 正确答案是 **A**。使用压缩空气清理风扇和散热器上的碎屑有助于维持正常气流并防止过热。重要的是要安全地清洁组件且不造成损坏。选项 B（使用磁性螺丝刀）可能损坏或干扰敏感电子元件。选项 C（在计算机附近存放液体）增加意外溢出的风险，可能导致设备损坏。选项 D（将计算机放置在不稳定的表面上）增加其跌倒或倾倒的几率，可能导致损坏。

3. 正确答案是 **C**。使用扎带或夹子固定线缆有助于保持工作区整洁有序，防止绊倒危险，并保护线缆免受拉扯或缠绕造成的损坏。选项 A（从远处拉扯线缆）会对连接器造成压力并可能损坏它。选项 B（急剧弯曲线缆）可能导致线缆断裂或连接器损坏。选项 D（留下松散缠绕的线缆）增加绊倒风险，并可能导致损坏或连接中断。
