## 7.7 Given a scenario, apply application installation and configuration concepts

3.  Install faster `CPUs`
4.  Install faster `HDDs`

### 3. 32 位应用在 64 位系统上的限制

1.  `32-bit` applications will be restricted to `32GB` of `RAM`
2.  `32-bit` applications do not support multi-threading
3.  `32-bit` applications will be restricted to `4GB` of `RAM`
4.  `32-bit` applications do not support multi-tasking

### 4. 应用兼容性快速修复
在将客户的 `Windows 8` 操作系统升级到 `Windows 10` 后，某应用程序无法启动。系统显示一条错误消息，指出该应用程序是为 `Windows 8` 编写的，与当前操作系统不兼容。支持技术人员可以提供什么作为该问题的快速修复？

1.  Contact the application vendor to investigate whether an updated version can be purchased
2.  Set the application compatibility setting to `Windows 8`
3.  Boot `Windows` into safe mode to run the application
4.  Set the application compatibility setting to `Windows 7`

### 5. 保护 CAD 应用免遭盗版
一家软件开发公司花费巨资设计了一款计算机辅助设计（`CAD`）应用程序。他们需要一种控制措施，以确保应用程序的每个副本仅在获得许可的工作站上运行。保护应用程序免遭盗版的**最有效**方法是什么？

1.  Make each customer agree to strict licensing requirements during installation
2.  Deploy an external hardware token for each copy of the application
3.  Make each customer sign an Acceptable Use Policy (`AUP`)
4.  Only sell the application to trustworthy customers
