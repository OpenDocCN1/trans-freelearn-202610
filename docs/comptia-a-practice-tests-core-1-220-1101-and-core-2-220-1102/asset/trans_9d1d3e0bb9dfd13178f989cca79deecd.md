

## 练习题

16. 如果在新安装的打印机中遇到纸张卡在定影器上的情况，你应该怎么做？

    1. 使用镊子或钳子小心地取出卡住的纸张
    2. 关闭打印机，待其冷却后，顺着纸路方向轻轻拉出纸张
    3. 忽略该问题并继续打印，因为它很可能会自行解决
    4. 联系打印机制造商或技术人员寻求帮助

17. 技术人员正在排查一个问题：复印件上出现纵向条纹，但直接发送到复印机的打印页面却能正常输出。导致此问题**最可能**的原因是什么？

    1. 打印头堵塞
    2. 定影器过热
    3. 扫描玻璃损坏
    4. 碳粉不兼容

18. 激光打印机持续打印出乱码文本，而非清晰可读的文本。导致此问题**最可能**的原因是什么？

    1. 打印机墨水或碳粉不足

    3. 打印机线缆或连接损坏
    4. 打印机设置不正确或字体兼容性问题

19. 在数字化项目中，以下哪种设备**最适合**捕获大量历史手写文档的电子图像？

20. 激光打印机在每张纸上都持续打印出一条从页面顶部延伸到底部的线条。导致此问题**最可能**的原因是什么？

21. 打印机在打印过程中发出研磨噪音。导致此问题**最可能**的原因是什么？

## 5.7 给定场景，排查有线和无线网络问题

1. 你的无线网络出现问题，无法为路由器选择特定信道。导致此问题**最可能**的原因是什么？

    1. 附近设备或网络的干扰
    2. 无线路由器固件过时
    3. 网络配置设置不正确
    4. 路由器信号强度不足

2. 你在无线网络上实施了 MAC 地址过滤，但一些设备仍能在不在批准名单的情况下连接。导致此问题**最可能**的原因是什么？

    1. 过滤列表中输入的 MAC 地址不正确
    2. 无线路由器固件过时
    3. 邻近无线网络的干扰
    4. 无线加密协议不兼容

3. 由于 IP 地址问题，无线客户端在网络中出现连接受限或无连接的情况，应采取什么措施来解决？

    1. 释放并续订 IP 地址
    2. 更新网络适配器驱动程序
    3. 调整无线信道
    4. 刷新计算机上的 DNS 缓存

4. 以下哪项最能描述无线通信中**授权频段**的用途？

    1. 供授权用户使用的保留频谱
    2. 公开可访问的频谱
    3. 为实验目的临时分配的频谱
    4. 供一般用途使用的非授权频谱

5. 在双路由器的无线网络设置中，可以采取什么措施来避免高延迟问题？

    1. 信道绑定
    2. 分离无线信道，每个信道使用自己的 IP 地址范围
    3. 使用有线连接
    4. 实施服务质量 (QoS)

6. 远程访问公司网络时，哪个选项能提供到公司局域网的安全连接？

    1. 虚拟专用网络 (VPN)
    2. 增强的互联网速度
    3. 公网 IP 地址分配
    4. 防火墙保护

7. 解决办公环境中无线连接频繁断开的一个可能方案是什么？

    1. 重新放置无线路由器位置
    2. 增加互联网带宽
    3. 禁用其他无线设备
    4. 更改无线加密方式

8. 使用 Wi-Fi 分析仪排查无线连接问题的目的是什么？

    1. 识别信号干扰源
    2. 提高 Wi-Fi 速度
    3. 更改 Wi-Fi 密码
    4. 扩大无线网络覆盖范围

9. 导致网络电话 (VoIP) 质量差的一个潜在原因可能是什么？

    1. 硬件过时
    2. 设备电量低
    3. 带宽不足
    4. 麦克风灵敏度不足

# 模拟考试：Core 1 (220-1101)

官方 CompTIA A+ Core 1 (220-1101) 认证考试给你 90 分钟完成测试。因此，建议在开始此模拟考试前设置一个计时器，以便很好地评估你的备考水平。

1. 关于 M.2 外形规格，以下哪项是正确的？

    1. M.2 仅支持 SATA 接口
    2. M.2 专门用于显卡
    3. 与传统硬盘相比，M.2 允许更快的数据传输速率
    4. M.2 不能用作启动设备

2. RAID 5 的一个特征是什么？

    1. 至少需要三块硬盘
    2. 提供最高级别的容错能力
    3. 相比 RAID 0 提供更高的读取性能
    4. 需要专用的奇偶校验盘

3. 以下哪种闪存卡格式常用于数码相机？

    1. CompactFlash (CF)
    2. Secure Digital (SD)
    3. Memory Stick (MS)
    4. eXtreme Digital (xD)

4. 关于 ATX 主板，以下哪项陈述是正确的？

    1. ATX 主板专为 Intel 处理器设计
    2. 与 microATX 相比，ATX 主板通常具有更少的扩展插槽
    3. ATX 主板使用 20 针 ATX 电源连接器
    4. ATX 主板支持双通道内存架构

5. 以下哪项是 UEFI (统一可扩展固件接口) 提供的安全功能？

    1. 安全启动
    2. BIOS 密码
    3. CMOS 清除跳线
    4. 可信平台模块 (TPM)

6. 在计算机中使用扩展声卡的主要好处是什么？

    1. 提高 CPU 性能
    2. 增强音频质量和功能
    3. 改善散热效率
    4. 扩大存储容量

7. 计算机系统中散热风扇的用途是什么？

    1. 提高显示分辨率
    2. 提供无线连接
    3. 调节组件温度
    4. 改善音质

8. 散热器在计算机中的功能是什么？

    1. 放大音频信号
    2. 提供额外存储空间
    3. 将热量从组件传导散发出去
    4. 提高网络性能

9. 主板连接器引脚 (connector headers) 用于什么？

    1. 存储系统配置设置
    2. 为 CPU 提供额外电力
    3. 连接外围设备
    4. 控制显示输出

10. 多插槽主板的一个关键特性是什么？

    1. 它们支持同时运行多块显卡
    2. 它们提供高级超频能力
    3. 它们可以容纳多个 CPU
    4. 它们提供广泛的扩展选项

11. 使用 PostScript 打印的主要优势是什么？

    1. 更快的打印速度
    2. 更高的打印分辨率
    3. 更高的色彩准确性
    4. 增强的打印机安全性

12. 打印中双面打印 (duplexing) 的主要好处是什么？

    1. 减少纸张浪费
    2. 更快的打印速度
