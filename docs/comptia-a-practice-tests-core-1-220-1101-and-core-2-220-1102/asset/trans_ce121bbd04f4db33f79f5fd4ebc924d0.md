# 第 4 章：虚拟化和云计算

## 4.1 总结云计算概念

1. 正确答案是 **B**。基础设施即服务 (IaaS) 是一种云计算服务模型，其中云服务提供商 (CSP) 仅提供硬件。当您想要将台式电脑迁移到云端时，这非常理想。为此，您需要安装操作系统、对其进行配置并打补丁。所有其他答案均不正确。软件即服务 (SaaS) 是一种供应商创建应用程序（如 Salesforce）并由公司租用该应用程序的模型。安全即服务 (SECaaS) 是一种公司通过外部来源提供云身份管理服务的模型。一个例子是 Okta，它可以提供 SAML 令牌。监控即服务 (MaaS) 是一种云服务提供商为您监控网络和服务器的模型。
