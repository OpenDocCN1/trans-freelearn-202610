

## 10.8 脚本安全

8.  正确答案是 **A**。消耗过多内存资源的脚本会使浏览器或系统过载，导致崩溃。当脚本未能妥善管理内存分配或未能释放已分配资源时，就会发生这种情况。选项 B、C 和 D 可能会导致性能问题，但与因资源处理不当导致崩溃无直接关系。

9.  正确答案是 **C**。从不受信任或未知来源下载脚本可能会无意中将恶意软件引入系统。选项 A 是一种良好的做法，因为信誉良好的脚本库通常会审核其内容，从而降低恶意软件的风险。选项 B 也是一种良好的做法，但它并不能直接解决无意中引入恶意软件的担忧。选项 D 是一种减轻潜在风险的有效方法，但它并不专门针对恶意软件的风险。

10. 正确答案是 **D**。执行脚本时，对关键系统设置的无意更改可能导致系统不稳定或故障。选项 A、B 和 C 是有意更改系统设置可能产生的积极结果。

11. 正确答案是 **C**。优化脚本中的资源使用有助于避免系统资源过载，并降低浏览器或系统崩溃的可能性。选项 A 和 B 与防止因资源处理不当导致的崩溃没有直接关系。事实上，提高脚本执行速度（选项 A）可能会加剧该问题。选项 D 过于极端，如果资源使用经过适当优化，则可能没有必要。

## 10.9 给定场景，使用远程访问技术

1.  正确答案是 **A**。`Microsoft Remote Assistance (MSRA)` 是此场景下应使用的适当远程访问技术。`MSRA` 允许技术人员远程连接到运行 Windows 操作系统的用户计算机。由于用户和技术人员连接到同一网络，因此可以使用 `MSRA` 进行故障排除和提供协助，而无需额外的配置或访问权限。对于选项 B，`VNC` 是一种常用于跨平台远程访问的远程访问技术。然而，在该场景中，由于技术人员和用户都使用 Windows 操作系统且位于同一网络上，使用 `MSRA` 将是更合适的选择。对于选项 C，`RDP` 是一种允许用户连接到远程计算机并像坐在其前面一样控制它的远程访问技术。虽然 `RDP` 常用于各种场景，但在这种技术人员和用户位于同一网络的特定情况下，`MSRA` 将是用于故障排除和协助的更合适选择。对于选项 D，`SSH` 是一种用于安全远程访问类 Unix 系统的网络协议。然而，在技术人员需要在同一网络上排查 Windows 计算机故障的场景中，`MSRA` 将是首选的远程访问技术，因为它专为 Windows 系统设计，并提供远程协助所需的功能。

2.  正确答案是 **D**。`远程监控和管理 (RMM)` 是远程监控和管理网络中多台设备最合适的远程访问技术。`RMM` 工具允许 IT 技术人员从集中位置主动监控设备的健康状况、性能和安全性。它们提供远程控制、软件部署、补丁管理和报告等功能，实现对远程设备的高效且有效的管理。对于选项 A，`VPN` 主要用于在远程用户和专用网络之间建立安全连接。对于选项 B，`RDP` 是一种允许用户访问和控制远程计算机的协议。对于选项 C，`Telnet` 是一种允许使用命令行界面远程访问设备的网络协议。

3.  正确答案是 **B**。`远程桌面协议 (RDP)` 使用户能够远程连接到并控制其办公室计算机，从而访问文件、应用程序和资源。选项 A，`虚拟专用网络 (VPN)`，用于在网络之间建立安全连接，并不一定用于远程访问单个计算机。选项 C，`Telnet`，是一种用于设备远程管理的网络协议，但它不提供图形化远程桌面访问。选项 D，`安全外壳协议 (SSH)`，是一种用于安全远程访问的加密网络协议，但它主要用于设备的命令行访问，而非完整的桌面访问。

4.  正确答案是 **A**。`远程桌面协议 (RDP)` 是访问 Windows 服务器最合适的远程访问技术，因为它提供图形化桌面访问和控制。选项 B，`文件传输协议 (FTP)`，主要用于在客户端和服务器之间传输文件，而非远程桌面访问。选项 C，`Telnet`，是一种用于远程管理的网络协议，但它不提供图形化远程桌面访问。选项 D，`安全外壳协议 (SSH)`，常用于安全命令行访问 Linux/Unix 服务器，但它可能无法提供对 Windows 服务器的图形化远程桌面访问。

5.  正确答案是 **C**。`安全外壳协议 (SSH)` 是使用命令行界面连接到 Linux 服务器最合适的远程访问技术，因为它提供安全的加密连接。选项 A，`Telnet`，以明文发送数据，这可能构成安全风险，并且不为远程访问提供加密。选项 B，`远程桌面协议 (RDP)`，主要用于图形化远程桌面访问，而非 Linux 服务器的命令行访问。选项 D，`虚拟专用网络 (VPN)`，用于在网络之间建立安全连接，但它不直接提供对 Linux 服务器的命令行访问。

6.  正确答案是 **A**。`虚拟专用网络 (VPN)` 是从远程网络安全访问家庭网络最合适的远程访问技术，因为它在用户设备和家庭网络之间创建了一条安全隧道。选项 B，`远程桌面协议 (RDP)`，主要用于网络内的远程桌面访问，由于网络配置要求，它可能不是从不同网络进行远程访问的最合适选项。选项 C，`Telnet`，不是一种安全的远程访问技术，由于缺乏加密且易受攻击，通常不建议用于远程访问目的。选项 D，`安全外壳协议 (SSH)`，通常用于安全命令行访问服务器，虽然它可用于远程访问，但 `VPN` 是从不同网络访问家庭计算机的更合适选择。

7.  正确答案是 **A**。`远程桌面协议 (RDP)` 通常默认使用端口 `3389` 来建立远程桌面连接。选项 B，`文件传输协议 (FTP)`，通常使用端口 `21` 作为控制连接，端口 `20` 作为数据连接，而非端口 `3389`。选项 C，`Telnet`，通常使用端口 `23` 建立远程终端连接，而非端口 `3389`。选项 D，`安全外壳协议 (SSH)`，通常使用端口 `22` 进行安全远程访问，而非端口 `3389`。

8.  正确答案是 **A**。`Apple Remote Desktop` 是 Apple 提供的用于远程访问 Mac 计算机的内置远程访问技术。选项 B，`虚拟网络计算 (VNC)`，是一种跨平台远程访问技术，可用于远程访问 Mac 计算机，但 `Apple Remote Desktop` 是专为 Mac 到 Mac 远程访问设计的内置解决方案。选项 C，`远程桌面协议 (RDP)`，主要用于基于 Windows 的远程访问，虽然 Mac 上有第三方客户端可用，但它不是内置解决方案。选项 D，`安全外壳协议 (SSH)`，用于安全命令行访问系统，不像 `Apple Remote Desktop` 那样提供图形化远程桌面访问。
