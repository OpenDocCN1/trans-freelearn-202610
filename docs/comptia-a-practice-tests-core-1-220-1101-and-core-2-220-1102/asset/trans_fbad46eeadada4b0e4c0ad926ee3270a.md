7.  正确答案是 **C**。调节组件温度。散热风扇用于在计算机系统内循环空气，散发 CPU、GPU 和电源等组件产生的热量。这有助于防止过热，并确保硬件的最佳性能和使用寿命。显示分辨率与散热风扇无关。无线连接通过其他组件（如网络适配器）实现。散热风扇不影响音质。

8.  正确答案是 **C**。散发组件热量。散热片是一种被动散热设备，可吸收并分散计算机组件（如 CPU 或 GPU）产生的热量。它由金属鳍片结构组成，增加了可用于热传递的表面积。散热片不参与音频信号放大。散热片并非为存储目的而设计。散热片不影响网络性能。
