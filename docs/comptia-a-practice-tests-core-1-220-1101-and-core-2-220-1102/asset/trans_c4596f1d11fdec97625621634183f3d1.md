# 模拟考试题

## 4.1 总结云计算概念

1. 如果您想将 100 台桌面迁移到云端，会使用哪种类型的云服务？

   1. SaaS
   2. IaaS
   3. SECaaS
   4. MaaS

2. 在哪种云模型中，公司大部分员工在本地工作，而移动销售团队在云端工作？

   1. 混合云
   2. 私有云
   3. 社区云
   4. 公有云

3. 一个组织正在扩张，需要增加存储空间和计算资源以满足客户需求。大多数员工作为远程工作者工作。以下哪项最能描述所需的云服务？

   1. PaaS
   2. SaaS
   3. IaaS
   4. DRaaS

4. 一家公司希望将其电子邮件和业务应用程序迁移到云端。将使用以下哪种云服务来实现该目标？

   1. PaaS
   2. SaaS
   3. IaaS
   4. MaaS

5. 首席执行官希望确保公司迁移到云端时，保留对专有数据存储和管理的完全控制权。哪种云模型最适合这种情况？

   1. 混合云
   2. 社区云
   3. 公有云
   4. 私有云

6. 云服务提供商 (CSP) 的销售人员试图向公司推销作为云套餐一部分的按量计费利用。以下哪项描述了他们正在销售的内容？

   1. 免费无限资源

   3. 仅为消耗的资源付费

7. 以下哪种云模型允许三所大学在云环境中共享资源？

   1. 私有云
   2. 公有云
   3. 社区云
   4. 混合云

8. 一公司将聘请两名顾问协助数据迁移。顾问将能够通过瘦客户机连接到公司分配的桌面，以防止任何人下载公司数据。每台桌面的配置必须保持一致。IT 团队将推出以下哪项以满足其需求并确保公司对数据拥有完全控制权？

   2. VDI
   3. 终端服务器

9. 一公司希望让其开发人员创建定制应用程序。这些应用程序将需要两台独立的服务器，一台用于 PHP，另一台用于 MySQL。他们应购买哪种云服务？

## 4.2 总结客户端虚拟化的各个方面

1. 哪种类型的管理程序运行在裸金属虚拟平台上？

   1. 类型 1
   2. 类型 2
   3. 类型 3
   4. 类型 4

2. 一家公司使用 VMware 的 ESX Server 提供其虚拟网络。它将运行五台数据库服务器，每台都需要增加 CPU 和内存。如何实现这一点？

   1. 资源池
   2. 系统蔓延
   3. 网络分段
   4. 按量计费

3. 攻击者访问了一个易受攻击的客户机计算机，并设法攻击了管理程序，导致虚拟网络完全故障。进行了哪种类型的攻击？

   1. 横向移动
   2. 虚拟机蔓延
   3. 快照
   4. 虚拟机逃逸

4. 适用于 Windows 10 的 Oracle VirtualBox 将运行在哪种类型的管理程序上？

   1. 类型 3
   2. 类型 2
   3. 类型 5
   4. 类型 1

5. IT 团队创建沙箱的**三个**主要原因是什么？

   1. 帮助防止火势蔓延
   2. 测试软件的新版本
   3. 测试新硬件
   4. 检查潜在包含恶意软件的应用程序
   5. 确保新软件补丁不会对业务应用程序产生不利影响
