

## 练习题 (7-14)

7. 正确答案是 D。使用 `DHCP 预留`，`IP 地址`会为由其 `MAC 地址` 标识的主机保留。所有其他答案均不正确。`DHCP 作用域` 是指 `DHCP 服务器` 可为特定子网分配的地址。`IP 地址租约` 期限无法自定义；所有人获得相同的租约期限。如果客户端拥有手动配置的静态地址，该主机将不会发送 `DHCPDISCOVER` 数据包以尝试从 `DHCP` 获取地址。

8. 正确答案是 A。`虚拟局域网 (VLAN)` 通常用于部门隔离或 `LAN` 内部隔离。所有其他答案均不正确。`代理服务器` 控制从内部网络到外部网络的访问。`防火墙` 用于控制内部和外部网络之间的访问。`路由器` 将多个外部网络连接在一起。

9. 正确答案是 C。`DMARC` 可验证传入的电子邮件，并具备检测和防止电子邮件欺骗的能力。因此，来自非法来源的任何邮件都可被阻止。所有其他答案均不正确。`内容过滤器` 由 `代理服务器` 或 `UTM 防火墙` 使用，以防止任何人访问包含不当内容的网站（如赌博网站）。`代理服务器` 控制传出请求，并具备缓存网站内容的能力。它还可通过阻止访问托管不当内容的网站来执行 URL 或内容过滤。

10. 正确答案是 A。`动态主机配置协议 (DHCP) 作用域` 是可分配给子网的一系列 `IP 地址`。所有其他答案均不正确。在 `DHCP 预留` 中，相同的 `IP 地址` 可分配给由其 `MAC 地址` 标识的同一主机。`DHCP 租约` 是指主机被分配 `IP 地址` 的有限时间。`DHCP 超级作用域` 允许将两个或多个作用域作为单个作用域使用，以增加子网中的 `IP 地址` 数量。

11. 正确答案是 A。`131.122.14.12` 是 `IPv4 地址`，因此使用 `A 记录`。所有其他答案均不正确。`AAAA 记录` 用于 `IPv6` 主机。`MX 记录` 用于邮件服务器。`发件人策略框架 (SPF) 记录` 用于证明邮件服务器的真实性以防止垃圾邮件。

12. 正确答案是 B。`DHCP 握手` 序列为 `DISCOVER`、`OFFER`、`REQUEST`、`ACK`（通常称为 `DORA`）。主机发送 `DHCPDISCOVER` 广播数据包以查找 `DHCP 服务器`。`DHCP 服务器` 回复 `DHCPOFFER`，其中包含 `IP 地址` 以及其他配置，如 `DNS 服务器` 和 `默认网关`。客户端随后回复 `DHCPREQUEST` 以接受该提供。`DHCP 服务器` 随后发送 `DHCPACK` 数据包，确认分配 `IP 地址`，租约期通常为 8 天。所有其他答案均不正确。

13. 正确答案是 D。`虚拟专用网络 (VPN)` 在外部位置和企业网络之间创建一条安全隧道。所有其他答案均不正确。`WAN` 是外部网络（例如互联网）。`SSL` 是一种加密传输中数据的方法，通常通过 Web 浏览器进行。`DHCP` 向主机动态分配 `IP 地址`。

14. 正确答案是 B、C 和 D。每家公司应在 `DNS` 中拥有一条作为 `TXT` 文件的 `SPF 记录`，用于标识获授权发送邮件的主机。`DKIM` 使用加密密钥验证发送电子邮件的邮件服务器是否获授权执行此操作。`DMARC` 检测并防范电子邮件欺骗。其余答案不正确。`无状态防火墙` 是一种非常基础的包过滤防火墙。

## 2.7 比较和对比互联网连接类型、网络类型及其特性

1. 正确答案是 C。互联网是 `广域网 (WAN)`，因为其覆盖巨大的地理区域。所有其他答案均不正确。`城域网 (MAN)`（如警方使用的网络）是覆盖一座城市的网络。`个人区域网 (PAN)` 由单人使用，例如 `蓝牙`。`局域网 (LAN)` 是局限于单一位置的网络（可能是整栋大楼，甚至单个房间），由一个或多个交换机连接。

2. 正确答案是 B。`卫星电话` 是唯一能在偏远地区通信的方法。所有其他答案均不正确。`有线调制解调器` 无法工作，因为没有电缆可供连接。`GPS` 用于导航，且仅通过卫星工作。在偏远地区的山上不会有任何 `无线接入点`。

3. 正确答案是 A。`光纤` 布线基于光脉冲工作，不受 `EMI` 影响，且非常安全。所有其他答案均不正确。`同轴电缆` 拥有多层防护以防止发射 `EMI`，但由于黑客可连接 `吸血鬼探针` 并接入电缆，因此它不安全。速度也非常慢。由于箔层，`STP` 可减少 `EMI`，但速度不如光纤快。`10-BASE-T` 是传统 `以太网` 电缆版本，可为 `UTP` 或 `STP`。然而，速度相当慢（10Mbps）。

4. 正确答案是 C。`iPhone 11` 是使用 `蜂窝` 通信的智能手机（因此称为“手机”）。所有其他答案均不正确。`DSL` 用于为 `SOHO` 提供互联网。`iPhone 11` 可使用 `无线` 连接，但这不是主要连接类型。`iPhone` 不是 `卫星` 通信设备。

5. 正确答案是 B 和 C。`WISP` 使用长距离固定无线技术连接客户和服务提供商。所有其他答案均不正确。`WISP` 既不制造调制解调器 `无线接入点`，也不监控带宽。

6. 正确答案是 A。`广域网 (WAN)` 是覆盖大地理区域的非安全网络。所有其他答案均不正确。`LAN` 是用户近距离聚集的安全高速网络，如大楼中的单层楼。`DMZ` 是位于 `LAN` 和 `WAN` 之间的边界网络。因为其中两个陈述是错误的，“以上皆是”也同样不正确。

7. 正确答案是 B。`动态主机配置协议 (DHCP) 服务器` 在机器启动时自动分配 `IP 地址`。它允许管理员根据用户的 `MAC 地址` 创建预留，确保该特定主机获得用于监控的 `IP 地址`。所有其他答案均不正确。`SMTP` 用于电子邮件而非 `IP 地址`。`SSL` 指通过 Web 浏览器传输中的安全数据。`DNS 服务器` 用于执行主机名到 IP 地址的名称解析。

8. 正确答案是 C。`无线局域网 (WLAN)` 用于无线连接多台设备。所有其他答案均不正确。`PAN` 是连接两台设备的个人网络，例如用户耳机与智能手机之间的 `蓝牙` 连接。`WAN` 是覆盖大地理区域的网络。

9. 正确答案是 A。`数字用户线路 (DSL)` 使用 `电话线` 作为通信信道。所有其他答案均不正确。`卫星` 通信不依赖电话。`光纤` 和 `有线调制解调器` 也不使用 `电话线`。
