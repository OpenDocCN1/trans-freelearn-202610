

## 6. Android 操作系统概述

正确答案是 **C**。Android 是由 Google 开发的开源（即免版税）操作系统。它于 2008 年首次发布，截至 2023 年，当前版本为 13（代号 Tiramisu）。Android OS 基于 Linux 内核，并支持主流 Linux 发行版中使用的许多安全功能。iOS 是一种专有的基于 Apple 的移动操作系统，最初仅用于 Apple 硬件，具体来说是 iPhone、iPod 和 iPad 的代码库。SUSE Linux 不用于移动设备或智能手机；它主要部署在数据中心服务器上。Windows Mobile 使用的是 Windows 桌面操作系统的修改版本。

## 7.9 给定场景，在多样化的操作系统环境中执行操作系统安装和升级

### 问题 1

正确答案是 **D**。预启动执行环境 (PXE) 允许计算机从网络接口卡 (NIC) 启动并访问网络上的服务。在这种情况下，技术人员可以使用介质创建 Windows 部署服务器，并从中心位置执行升级。从固态硬盘 (SSD) 启动不满足通过网络安装的要求。光驱和闪存驱动器可用于安装单个镜像，但无法解决跨网络升级多台计算机的问题。

### 问题 2

正确答案是 **D**。无人值守安装允许提供一个集中部署镜像，以及一个自动化设置文件（或无人值守脚本）。安装开始后，技术人员可以离开，让其自行完成。远程网络安装不满足自动化安装的要求。修复安装允许将有故障的计算机重新镜像回标准构建配置。全新安装不描述自动化过程。

### 问题 3

正确答案是 **C**。GUID 分区表 (GPT) 磁盘格式允许高达 18 EB（即 1880 万 TB）的分区大小。GPT 驱动器最多还可包含 128 个独立分区。ext4 在 Windows 上不受支持；它用于 Linux 文件系统。主引导记录 (MBR) 分区最大限制为 2TB，且每个磁盘最多支持四个分区。Apple 文件系统 (APFS) 在 Windows 计算机上不受原生支持。

### 问题 4

正确答案是 **D**。就地升级将允许客户保留所有受支持的应用程序并保留其设置。重要的是要检查他们当前使用的 Windows 版本是否支持就地升级。全新安装将不保留应用程序或设置。修复安装会将镜像重置为客户系统上当前 Windows 版本的默认值，旨在作为一种故障排除选项。无人值守安装不一定意味着将选择升级。

### 问题 5

正确答案是 **C**。Windows 10 是第一个支持功能升级的 Windows 操作系统（Windows 11 也支持功能升级）。功能升级通常每六个月发布一次，包含额外的功能和特性。在之前的 Windows 版本中，新功能和特性是通过 Service Pack 或临时版本交付的，例如从 Windows 8.0 升级到 8.1。Windows 7 和 Windows 8.1 不支持功能升级。

### 问题 6

正确答案是 **C**。镜像部署允许创建操作系统的自定义构建（以及任何所需的应用程序）。该镜像可以托管在 Windows 部署服务器上，所有新安装都将使用标准的集中式镜像。升级将保留当前的应用程序和设置（一些现有的台式机可能安装了不同的应用程序并配置不同）。全新安装并不总能确保应用相同的设置。修复安装用于将 Windows 计算机恢复到标准镜像，作为故障排除步骤。

### 问题 7

正确答案是 **B**。当从中央服务器通过网络安装镜像时，预计网络段上的总体流量会增加。重要的是要识别网络上任何不可接受的负载。只有当网络因额外流量而不堪重负时，对用户的影响才会成为问题。DHCP 需要在构建期间一次为 30 个工作站提供 IP 地址，因此这不应给 DHCP 服务器带来任何巨大负担。只有当网络在构建过程中遇到不可接受的额外流量时，对生产工作站的影响才会成为负面问题。

### 问题 8

正确答案是 **B, C**。统一可扩展固件接口 (UEFI) 取代了自 1980 年代原始 PC 系统以来在计算机系统中见到的原始基本输入输出系统 (BIOS)。支持 GPT 磁盘需要 UEFI。Windows 11 安装需要可信平台模块 (TPM) 的存在，以支持操作系统中现已标准化的某些安全功能。Windows 11 除需要 TPM 2.0 和 UEFI 支持外，还需要 4GB 内存和 1GHz 64 位处理器。

### 问题 9

正确答案是 **B**。修复安装允许修复启动问题，例如丢失或损坏的启动文件。如果 Windows 无法启动且自动修复功能失败，技术人员将看到高级选项菜单。此菜单提供的选项包括系统还原、系统映像恢复（如果您有备份）或运行启动修复。无人值守安装、镜像部署和远程安装不作为故障排除步骤。

### 问题 10

正确答案是 **B**。Windows PC 运行状况检查应用是免费的 Microsoft 下载工具，允许在升级前评估 Windows 计算机。评估后，该应用将提供给定升级的系统要求列表，并说明相关系统是否满足这些要求。虽然其他选项确实为技术人员提供了有用的信息，但它们不提供易于阅读的升级报告。

## 7.10 识别 macOS/桌面操作系统的常见功能和工具

### 问题 1

正确答案是 **C**。Mac 安装文件的标准文件扩展名是 DMG（源自 Disk iMaGe），取代了较旧的 IMG 文件格式。MSI 和 EXE 文件格式由 Windows 计算机使用。APK 文件是 Android 软件包文件，用于在运行 Android 操作系统的设备上部署应用程序。

### 问题 2

正确答案是 **B**。Mac Finder 应用程序允许用户查看所有受支持介质上的文件。钥匙串 用于支持单点登录 (SSO)，并允许跨多个站点进行透明身份验证。任务控制 用于在 Mac 上在不同工作区之间切换。资源管理器 是 Windows 功能。

### 问题 3

正确答案是 **B**。用于备份和还原数据文件的 Mac 功能是 时间机器。文件历史记录 和 Windows 备份 是仅在 Windows 操作系统上支持的功能。任务控制 不用于备份或还原文件。

### 问题 4

正确答案是 **A**。强制退出 菜单允许终止无响应的应用程序。任务管理器、任务列表和控制面板 都是仅在 Windows 计算机上可用的功能。

### 问题 5

正确答案是 **C**。文件保险箱 允许使用 128 位或 256 位高级加密标准 (AES) 加密 Mac 硬盘。启用该功能后，用户必须在系统启动前提供其密码。如果未提供密码，则磁盘将保持加密状态。iCloud 用于将 Apple 设备的数据同步到基于云的存储。钥匙串 用于在访问不同站点时管理多重身份。BitLocker 是 Windows 操作系统上使用的磁盘加密技术。
