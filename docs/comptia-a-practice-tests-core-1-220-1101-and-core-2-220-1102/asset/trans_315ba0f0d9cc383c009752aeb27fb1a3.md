

## 练习题 (15-18)

### 15. 正确答案是 C
当网络摄像头停止工作时，首先要尝试的是拔下它然后再插回去。如果这不起作用，则应彻底卸载它，并从制造商网站重新安装网络摄像头软件及任何最新更新。所有其他答案均不正确。当操作系统应用更新时，计算机很可能已作为更新的一部分重新启动过，因此再次重启不太可能有帮助。网络摄像头极有可能没有任何问题，而且用户可能没有足够时间去商店购买、设置新设备以赶在 Zoom 会议开始前准备好。无需更新操作系统，因为这已经完成了，且正是导致此问题的根本原因。

### 16. 正确答案是 C
NFC 用于银行卡支付类型，要求卡片必须在读卡器四英寸范围内，因此它会是所描述问题的根源。所有其他答案均不正确。蓝牙对于金融交易来说不够安全。非接触式卡不使用无线网络。红外线要求两个设备之间视线通道且无安全性；因此，它不用于金融交易。

### 17. 正确答案是 B、C 和 E
当手机发热时，可能是由于过度使用，例如长时间作为 Wi-Fi 热点使用。当电池接近使用寿命末期时，手机也会过热，此时电池也无法充满电，且电量会流失得非常快。同时打开太多应用程序会迫使 CPU 比正常情况下更努力地工作，特别是在应用程序过时的情况下，也会增加手机温度。所有其他答案均不正确。屏幕破裂不会导致手机发热，但可能导致屏幕无响应。劣质充电线会阻止手机电池充电。

### 18. 正确答案是 A
Apple 于 2012 年推出了可正反插的 Lightning 线缆，以取代 Apple 30-pin 接口。所有其他答案均不正确。不存在 20-pin 和 25-pin 接口。大多数 Android 手机使用 USB-C 接口。

## 1.4 给定场景，配置基本移动设备网络连接和应用程序支持

### 1. 正确答案是 B
大多数公司对其移动设备和无线路由器都有数据上限，一旦达到限额就需要充值/续费。所有其他答案均不正确。该区域必须有网络覆盖，因为该销售人员前一天晚上还能在线观看电影。MDM 解决方案会在发布前测试更新。公司极不可能错过手机话费缴纳，因为这对业务运营至关重要。

### 2. 正确答案是 B
密码是“您知道的东西”，指纹是“您本身的东西”。这是双因素认证的一个示例。所有其他答案均不正确。视网膜和指纹都是“您本身的东西”，密码和 PIN 都是“您知道的东西”，步态和刷卡都是“您做的事情”。

### 3. 正确答案是 A
如果新智能手机未安装 SIM 卡，用户将无法拨打任何电话或访问移动数据。所有其他答案均不正确。没有 SIM 卡无法开启移动数据。保护屏幕的膜不影响通话功能或移动数据。开启蓝牙不影响通话或移动数据。

### 4. 正确答案是 B
将 Apple Watch 与 iPhone 配对的最简单方法是使用 Apple Watch App。操作方法是将表盘对准手机摄像头，就像扫描二维码一样。所有其他答案均不正确。虽然可以通过输入六位数密码手动设置配对，但这不是最简单的方法。不能使用四位数密码手动配对设备；需要六位数。四位数密码仅用于访问 Apple Watch 本身。

### 5. 正确答案是 C
当日历应用程序不更新时，通常是因为密码未更新。更新公司密码应可解决该问题。所有其他答案均不正确。剩余电量对日历应用程序没有影响。重启手机不会对手机应用产生任何影响。远程擦除手机在此场景下无济于事，因为这会将设备恢复为出厂设置。

### 6. 正确答案是 B
基于全球移动通信系统 (GSM) 的手机具有可拆卸的 SIM 卡，可插入同一网络运营商的另一部手机中。所有其他答案均不正确。全球移动通信系统可配合蜂窝、无线和卫星通信工作，因此所有使用“仅”字眼的其他答案均为错误。

### 7. 正确答案是 C
MDM 解决方案允许您强制执行策略并向智能手机发送更新。远程擦除设备会将其恢复为出厂设置。所有其他答案均不正确。WPA2 PSK 意味着使用密码连接到无线网络。禁用蓝牙只会阻止蓝牙设备被使用。在公司手机上使用 VPN 仅保护来自手机的远程会话。它无法防止访问手机上的本地数据。

### 8. 正确答案是 B 和 C
MAM 解决方案用于为可处理公司数据的应用程序设置策略，并防止公司数据传输到个人设备。所有其他答案均不正确。移动设备管理 (MDM) 负责为移动设备打补丁，并在设备丢失或被盗时远程擦除它们，以防止数据泄露。

### 9. 正确答案是 B
三星 Galaxy 用户使用 Google Drive 作为其备份位置。所有其他答案均不正确。Gmail 是 Google 邮件应用程序。Knox 容器被三星用于在其手机上分隔个人和业务数据。Office 365 是微软产品。

### 10. 正确答案是 D
当用户从 Apple App Store 下载并安装应用程序时，需要其 Apple ID 和密码。如果安装失败，他们将需要重置密码。所有其他答案均不正确。Hotmail 账户用于访问微软产品。Gmail 账户用于访问 Google 产品。iPhone 密码用于访问 iPhone 本身。

### 11. 正确答案是 D
卫星通信设备连接地球上方的卫星，可在不存在手机基站的区域进行通信。所有其他答案均不正确。数字用户线路 (DSL) 需要使用分离器以同时启用电话和互联网。热点连接到无线或蜂窝运营商，在这种情况下无法使用。

### 12. 正确答案是 C
如果天气应用持续在后台运行，会耗尽 iPhone 电池。用户需要同时关闭恶劣天气通知并修改位置权限，以便手动输入他们想要获取结果的位置。所有其他答案均不正确。“使用 App 期间”位置服务仍会消耗电量。关闭位置服务不影响天气应用。它仅防止用户在进入不同国家/地区时收到通知。本地无线网络连接仅提供互联网，不会耗尽电量。更换新电池无法解决此问题。
