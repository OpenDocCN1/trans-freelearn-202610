
# 练习题：专业素养、沟通与安全基础

## 第一部分：专业素养与沟通技巧

1.  正确答案是 **C**。积极倾听并复述客户的顾虑，通过展示你理解他们的需求并积极投入寻找解决方案，体现了专业性。选项 A 打断客户，可能显得粗鲁和不屑一顾。选项 B 使用技术术语，会让客户困惑。选项 D 提供折扣或赠品，仅当符合公司政策和客户问题时才应考虑。

2.  正确答案是 **A**。保持眼神交流并点头表示赞同，是展示积极倾听和投入的非语言线索，属于专业沟通行为。选项 B 在移动设备上查看个人邮件，不专业且分散注意力。选项 C 压低声音说话，虽体现对他人的考虑，但不符合题目要求（非语言）。选项 D 使用俚语和非正式语言，在专业场合不合适。

3.  正确答案是 **C**。使用 `Dear [Recipient’s First Name],` 是商务邮件中称呼收件人最恰当、最专业的方式。选项 A 和 D 不够正式，可能无法传达必要的专业度。选项 C 称呼业务伙伴的方式异常，更可能用于法律承诺（如法院禁令）。

4.  正确答案是 **C**。利用视觉辅助、图表和插图，是向非技术受众传达复杂技术信息最有效的方式。选项 A、B、D 不正确，因为大量使用技术术语会让受众困惑，仅依赖书面文档可能难以理解，语速过快会让受众不堪重负并阻碍理解。

5.  正确答案是 **B**。选项 B 通过描述情况而非过度随意或评判性地表达，展示了专业语言的使用。选项 A、C、D 使用了不专业的语言，可能无法有效解决客户顾虑。

6.  正确答案是 **C**。在处理与客户的分歧或冲突时，提供替代方案和妥协体现了专业性。提高音量、责怪客户或忽视其顾虑都是不专业的，且会升级事态。

7.  正确答案是 **C**。积极倾听并尊重他人意见，是在与同事互动时恰当专业行为的示例。选项 A、B、D 会助长消极的职场氛围，属于不专业行为。

8.  正确答案是 **C**。举行一对一面谈是传递敏感或机密信息的最佳沟通方式。选项 A、B、D 可能泄露机密，且无法提供个性化的关注或支持。

9.  正确答案是 **B**。不说话时保持麦克风静音，是视频会议中保持专业性的示例。在镜头前进食、聊天消息中使用非正式语言、分享无关个人轶事，都是不专业的，且会干扰会议。

10. 正确答案是 **B**。设定切合实际的预期并提供进度更新，是管理客户预期的专业方法。过度承诺会导致失望，忽视客户请求不专业，在未解决顾虑的情况下转移客户可能被视为敷衍。

11. 正确答案是 **B**。使用强加密算法加密客户的敏感文件和文件夹，可确保其数据保持机密和受保护。选项 A 错误，因为定期与同事共享客户数据会破坏其机密性。选项 C 将客户机密数据上传至云存储服务，会增加未经授权访问的风险。选项 D 在未安全擦除硬盘的情况下处理客户电脑，可能导致其私人资料面临潜在数据泄露。

12. 正确答案是 **C**。在打印机上实施访问控制，可确保只有授权人员才能使用和访问客户的机密材料，从而维护其安全。选项 A 与其他技术人员共享打印机访问凭据，会增加未经授权访问客户机密材料的风险。选项 B 禁用日志功能，会妨碍追踪和调查潜在的隐私泄露。选项 D 在公共区域打印客户机密文件，会损害其隐私和机密性。

13. 正确答案是 **C**。选项 C 正确，因为在客户台式机上实施强密码策略并启用全盘加密，提供了额外的安全层，确保其材料的机密性。选项 A 创建具有无限制访问权限的共享用户账户，会破坏客户材料的机密性。选项 B 在未验证备份介质完整性和机密性的情况下执行数据备份，可能导致潜在数据泄露。选项 D 将客户机密文件存储在公开可访问的文件夹中，会使其面临未经授权的访问。

## 10.8 Identify the basics of scripting

1.  正确答案是 **C**。JavaScript 专为 Web 开发设计，允许在网站上实现动态和交互元素。Python、Bash 和 PowerShell 是常用的脚本语言，可用于安排自动化任务。

2.  正确答案是 **D**。PowerShell 是微软开发的脚本语言，用于 Windows 环境中的任务自动化和配置管理。Python、Bash 和 JavaScript 并非专为 Windows 自动化设计。

3.  正确答案是 **B**。Bash (Bourne Again SHell) 是类 Unix 操作系统的默认脚本语言，广泛用于系统管理任务。Python、JavaScript 和 PowerShell 不常用于此目的。

4.  正确答案是 **A**。Python 是一种多功能脚本语言，可用于各种用途，包括 Web 开发、任务自动化、科学计算和数据分析。虽然 Bash、JavaScript 和 PowerShell 有各自的特定用例，但 Python 提供了更广泛的应用范围。

5.  正确答案是 **C**。JavaScript 主要用于客户端脚本，允许在网页上实现动态和交互元素。Python、Bash 和 PowerShell 通常不用于此目的。

6.  正确答案是 **A**。错误处理不当可能导致意外后果，如引入恶意软件、更改系统设置或导致崩溃。通过实施适当的错误处理机制，脚本开发人员可以将风险降至最低，并确保脚本更安全地执行。选项 B、C、D 与上述风险无直接关联。

7.  正确答案是 **B**。实施输入验证和清理有助于防止通过用户输入注入恶意代码。它确保脚本仅处理预期且安全的输入，降低无意引入恶意软件的风险。定期更新杀毒软件（选项 A）有助于防范已知恶意软件，但不直接解决脚本相关的风险。选项 C 和 D 为不推荐的操作，且可能引入额外漏洞。
