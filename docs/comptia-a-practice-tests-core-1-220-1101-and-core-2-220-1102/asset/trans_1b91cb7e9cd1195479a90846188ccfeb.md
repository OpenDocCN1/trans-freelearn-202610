
# CompTIA CertMaster Labs 概览

## 虚拟工作台实验

**虚拟工作台实验**为学习者提供了宝贵的实践机会，在沉浸式 3D 环境中安装、配置和排查计算机硬件故障。每个场景都包含教程模式，通过分步说明引导学习者，帮助其理解和练习 3D 控制；探索模式允许学习者在沙箱环境中识别和操作硬件组件；以及辅助模式，分步引导学习者完成流程，在需要时提供帮助。这种实践环境使学习者能够学习 IT 的有形方面并获得真实经验。学习者可以探索台式机、笔记本电脑和外设的不同组件如何协同工作，并获得安装和配置计算机组件的不同流程的经验。

## 虚拟机实验

**虚拟机实验**利用虚拟机模拟服务器网络，使学习者能够获得在工作环境中会使用到的工具、应用程序和操作系统（如 `Microsoft Windows` 或 `Kali Linux`）的真实实践经验。学习者可以使用 `GNS3` 网络模拟器比较网络硬件，并使用 `OpenWRT` 配置家用路由器。

虚拟机实验也提供不同的模式：

### 辅助实验

**辅助实验**分步引导学习者完成任务，在 10-15 分钟的体验过程中提供评估和反馈，使学习者能够在活动进行过程中纠正任何误解。

### 应用实验

**应用实验**在 20-30 分钟的体验中呈现一系列目标导向的场景，涵盖多个主题，根据学习者成功完成每个场景的能力在活动结束时对其工作进行评分。因此，学习者被迫在没有既定步骤的情况下批判性地思考如何解决问题。目前，应用实验仅适用于虚拟机实验活动。

# 第 1 章：移动设备

## 简介

移动设备在工作场所大量存在，范围涵盖从笔记本电脑到平板电脑和智能手机。因此，IT 技术人员必须具备每种设备类型的工作知识，包括所用的存储以及从传统存储向现代存储迁移的方法。

此外，在您自己的职业生涯中，您可能需要为智能手机启用安全性，要求您设置多因素或生物识别认证、设置蜂窝通信和移动热点，或连接企业用户的蓝牙耳机。对于笔记本电脑咨询，无论是为工程部门订购新设备、安装新无线网卡，还是排查显示屏故障，您对笔记本电脑硬件、组件以及卡的类型和尺寸的理解对于确保您提供的支持可靠且有效至关重要。

在 CompTIA A+ Core 1 (`220-1101`) 考试中，领域 1.0 移动设备进一步细分为以下核心目标：

*   1.1 给定场景，安装和配置笔记本电脑硬件和组件
*   1.2 比较和对比移动设备的显示组件
*   1.3 给定场景，设置和配置移动设备的配件和端口
*   1.4 给定场景，配置基本的移动设备网络连接和应用程序支持

本章其余部分致力于实践。对于上述定义的每个概念，您将获得一系列问题，旨在测试您对官方认证考试指南中定义的每个核心 1 目标的知识。完成这些问题并确保理解其背后的概念后，您应该已完全准备好在 CompTIA A+ Core 1 (`220-1101`) 考试中做同样的事情。

## 练习考试题

### 1.1 给定场景，安装和配置笔记本电脑硬件和组件

1.  以下哪项是设置笔记本电脑或台式机使用生物识别读取器的最安全方法？

    1.  为使用该设备的人员设置笔记本电脑/台式机
    2.  设置笔记本电脑/台式机，以便财务部的每个人都能登录
    3.  允许其他部门访问笔记本电脑/台式机
    4.  为用户访问设置笔记本电脑并允许来宾访问

2.  一名硬件工程师将升级笔记本电脑的内存。在安装新内存之前，硬件工程师应首先完成以下哪项任务？

    1.  购买 `256 GB DDR3 RAM`
    2.  佩戴静电放电带采取防静电预防措施
    3.  检查主板的供电电压
    4.  为笔记本电脑的操作系统下载任何操作系统更新

3.  用户的笔记本电脑工作完全正常，但出于某种原因，当他们尝试在咖啡店使用时，它无法开机。用户确认电池已插好，但注意到电池上有一个小鼓包。以下哪项是导致此问题的最可能原因？

    1.  电源适配器故障
    2.  操作系统损坏
    3.  系统风扇不工作
    4.  电池因缺陷而失效，需要更换
