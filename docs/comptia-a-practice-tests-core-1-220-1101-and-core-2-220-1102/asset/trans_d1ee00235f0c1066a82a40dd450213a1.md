# 安全

## 简介

本章将测试考生对安全概念、程序和安全最佳实践的了解。威胁和威胁行为者不断变化，安全专业人员必须了解如何以不同方式识别和缓解威胁。需要保护的常见环境包括无线网络、**小型办公室/家庭办公室 (SOHO)** 网络、企业网络，以及保护远程访问至关重要的情况。移动设备和对 IoT 的支持也给安全专业人员带来了许多挑战。了解社会工程学带来的威胁很重要，这通常被称为黑客攻击人类（即以用户为目标）。为了缓解这些威胁，识别需要启用的正确控制并了解对特定威胁的正确响应非常重要。

为了在 CompTIA A+ Core 2 (220-1102) 认证考试中取得成功，考生必须熟悉以下目标：

*   8.1 总结各种安全措施及其目的
*   8.2 比较和对比无线安全协议和身份验证方法
*   8.3 给定场景，使用适当的工具和方法检测、删除和防止恶意软件
*   8.4 解释常见的社会工程学攻击、威胁和漏洞
*   8.5 给定场景，在 Microsoft Windows 操作系统中管理和配置基本安全设置
*   8.6 给定场景，配置工作站以满足安全最佳实践
*   8.7 解释保护移动和嵌入式设备的常用方法
*   8.8 给定场景，使用常见的数据销毁和处置方法
*   8.9 给定场景，在小型办公室/家庭办公室 (SOHO) 无线和有线网络上配置适当的安全设置
*   8.10 给定场景，安装和配置浏览器及相关安全设置

本章其余部分致力于实践。对于前面定义的每个概念，您将获得一系列问题，旨在测试您对官方认证考试指南中定义的每个核心 2 目标的了解。这些问题将测试考生关于如何在组织中实施安全最佳实践的知识。
