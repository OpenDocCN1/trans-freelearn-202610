

## 8.3 练习题（续：9–12）

### 9. 答案：**B**
正确答案是 **B**。电子邮件中发送的链接属于网络钓鱼攻击。在这种情况下，专门针对这类攻击的特定培训是最佳解决方案。防火墙不会阻止嵌入在电子邮件中的内容。关于常见威胁的用户教育不如专门针对网络钓鱼攻击的培训有效。`OS` 重装不是一个选项，因为 `OS` 并未被攻破。

### 10. 答案：**A**
正确答案是 **A**。`Windows 安全模式` 将允许系统使用最少的一组驱动程序启动。如果新安装的视频驱动程序已损坏或出现故障，则 `Windows 安全模式` 应能启动进入稳定的桌面环境。使用最新定义文件的防病毒扫描可能会揭示是否存在恶意代码。然而，在这种情况下，驱动程序损坏或不兼容的可能性存在。`Windows 防火墙` 可用于阻止传入和传出的网络连接，但无法验证驱动程序是否稳定。

### 11. 答案：**C**
正确答案是 **C**。由于受损账户与特定数量的工作站相关联，硬件可能是攻击载体。由于账户密码已重置，这将无效，因为 `键盘记录器` 会泄露新密码。`远程访问木马` 将允许攻击者保持对工作站的 `命令与控制` 访问，并可用于窃取信息。`Rootkit` 旨在拦截对系统服务的调用。`加密货币挖矿程序` 使用 `CPU`/`GPU` 周期来挖掘加密货币。

### 12. 答案：**B**
正确答案是 **B**。恶意 `加密货币挖矿程序` 可能通过 Web 浏览器或作为移动应用下载。该软件会窃取计算机资源以生成新的加密货币。这将针对高级显卡上的中央处理器 (`CPU`) 和图形处理器 (`GPU`)。`间谍软件` 用于收集用户或组织的私人信息。它可能会降低计算机速度，但不会专门针对 `CPU`/`GPU`。`键盘记录器` 将记录所有输入的按键并将它们存储在日志文件中。`引导扇区病毒` 将替换 `OS` 引导文件，在引导过程中启动恶意软件。

## 8.4 解释常见的社会工程学攻击、威胁和漏洞

### 1. 答案：**D**
正确答案是 **D**。当单个个体被锁定目标且该个体担任高级管理职位时，他们被视为“大鱼”。因此，`鲸钓攻击` 基于 `网络钓鱼`，但它是针对大鱼（担任高级职位的用户）的定向攻击。在这种情况下 `网络钓鱼` 不正确。选项 B 指从垃圾桶或垃圾罐中窃取可能包含有用情报的文档 (`翻垃圾桶`)。选项 C 指某人试目睹用户输入密码或 `PIN` 码 (`肩窥`)。

### 2. 答案：**C**
正确答案是 **C**。`肩窥` 很可能发生在拥挤的空间，当时攻击者可以近距离观察用户输入密码。选项 A 和 D 通常使用电子邮件链接强迫用户共享机密数据 (`网络钓鱼`/`短信钓鱼`)。选项 B 指从语音通话中获取信息 (`语音钓鱼`)。

### 3. 答案：**B**
正确答案是 **B**。由于承包商未通知就到达，这可能构成威胁。在这种情况下，他们通过穿着使其看起来像真正的支持承包商的服装来进行 `冒充`。选项 A 是指未经授权的人紧跟在有效用户后面，通过物理控制（如由 `RFID` 门禁卡控制的锁门）进入 (`尾随`)。选项 C 指从垃圾桶窃取文档 (`翻垃圾桶`)。选项 D 指放置恶意 `Wi-Fi` 接入点 (`邪恶双子`/`流氓接入点`)。

### 4. 答案：**D**
正确答案是 **D**。`邪恶双子` 指一种欺骗性的恶意无线网络，旨在模仿合法网络。它本质上是一个 `流氓接入点`，看起来像受信任的 `Wi-Fi` 网络，但由攻击者建立，意图拦截敏感信息或进行其他恶意活动。由于该接入点未连接到合法的受信任网络，`映射驱动器` 和 `共享打印机` 将无法访问。选项 A、B 和 C 是其他社会工程学攻击的示例。

### 5. 答案：**A**
正确答案是 **A**。`尾随` 是指未经授权的人假装成员工、送货员或访客，试图通过紧跟授权员工通过受控访问点（如带门禁卡的门或安检站）进入安全区域。选项 B、C 和 D 是其他类型的社会工程学。

### 6. 答案：**A**
正确答案是 **A**。在 `DDoS` 攻击中，目标网络或系统变得过载，无法处理合法用户请求，从而有效地拒绝为合法用户提供服务。`DDoS` 攻击可能涉及数千个连接。`僵尸网络` 可用于生成大量流量。选项 B 不涉及数千个连接，因为 `DoS` 可能由单个恶意主机创建。选项 C 指没有补救措施或补丁的漏洞 (`零日漏洞`)。选项 D 涉及攻击者伪造另一真实主机的电子邮件地址、`IP` 地址或 `MAC` 地址 (`欺骗`)。

### 7. 答案：**A**
正确答案是 **A**。`中间人攻击` 指一种网络攻击，攻击者获得控制权或将自己插入两个网络实体之间的通信路径中。这使他们能够拦截、修改或阻断在这些实体之间流动的网络流量，从而窃听敏感信息、操纵数据或中断通信。这种攻击也称为 `中间人攻击` (`MiTM`)。选项 B 指为组织工作、怀有恶意或培训不足从而构成威胁的用户 (`内部威胁`)。选项 C 和 D 用于攻击者针对 `Web 应用服务器` 上传脚本或操纵 `数据库服务器` 时（通常试图未经授权访问系统）。

### 8. 答案：**C**
正确答案是 **C**。`XSS` 攻击的主要目标是操纵网站内容并与用户会话交互。如果脚本可以上传到 `Web 服务器`，则其他用户在使用 `浏览器` 访问该网站时将自动运行该脚本。恶意载荷通过尖括号 `<>` 来识别。选项 A 涉及使用伪造的网络身份 (`欺骗`)。选项 B 将使用 `SQL` 语言特有的不同语法 (`SQL 注入`)。`零日攻击` 描述的是没有可用补丁的漏洞。

### 9. 答案：**D**
正确答案是 **D**。`零日攻击` 用于描述没有可用补丁的漏洞。选项 A、B 和 C 在本章的其他问题中有描述。

### 10. 答案：**C**
正确答案是 **C**。在 `SQL 注入` 攻击中，攻击者利用 `Web 应用程序` 输入字段中的漏洞来操纵应用程序 `数据库` 执行的 `SQL` 查询。在这种情况下，攻击者在登录字段中输入了恶意输入，从而改变了应用程序执行的 `SQL` 查询。条件 `‘1’ = ‘1’` 恒为真，因此攻击者本质上是通过操纵查询以返回任意用户名和密码组合的结果来绕过身份验证过程。选项 A，`暴力破解攻击`，涉及尝试所有可能的用户名和密码组合，直到找到正确的组合。此日志条目不表明重复的登录尝试或尝试各种组合。选项 B，`字典攻击`，类似于 `暴力破解攻击`，但涉及尝试常用密码或字典单词列表。选项 D，`跨站脚本` (`XSS`)，涉及将恶意脚本注入 `Web 应用程序`，然后由其他用户执行。它不直接涉及未经授权的登录尝试或像所提供的日志条目中那样操纵 `数据库` 查询。
