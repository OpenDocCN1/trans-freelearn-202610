### 6. 管理员必须确保薪资团队受聘的合同人员仅在其他员工在场时才能登录网络。确保强制执行这一点的最有效方法是什么？

1. 在核心工作时间之外限制用户权限
2. 将承包商的登录时间限制在核心工作时间
3. 在所有承包商的工作站上禁用来宾账户
4. 确保承包商账户在三次尝试失败后被锁定

### 7. 在安全意识简报期间，用户被给予密码攻击的示例。以下哪项是“暴力破解”密码的常用方法？

1. 猜测常用密码或短语
2. 利用软件漏洞
3. 拦截网络流量
4. 反复尝试不同的字符组合

### 8. 管理员担心攻击者可能通过在登录提示符处使用字典攻击来访问用户账户。哪项安全设置最有效？

1. 强制执行最小密码长度为 10 个字符
2. 将承包商的登录时间限制在核心工作时间
3. 在所有工作站上禁用来宾账户
4. 确保账户在三次尝试失败后被锁定

### 9. 一位高级经理在重要演示期间遇到问题后提交了支持工单。该经理插入存储卡以访问演示材料，结果一个电影文件开始播放。支持技术人员可以采取什么措施来解决该工单？

1. 配置存储卡的自动播放设置
2. 阻止访问外部媒体
3. 配置可移动驱动器的自动播放设置
4. 确保 `Windows Movie Player` 被禁止播放

### 10. 以下哪项是维护密码安全的最佳实践？

1. 与受信任的家庭成员或朋友共享密码
2. 在多个账户中使用相同的密码
3. 频繁更改密码
4. 将密码写在纸上并放在显眼的地方

### 11. CISO 必须确保公司遵守推荐的最佳安全实践。CISO 发现有时用户的笔记本电脑在用户不在工位时会显示个人身份信息（`PII`）和知识产权（`IP`）。保护工作站最有效的控制措施是什么？

4. 使用线缆锁将笔记本电脑固定在桌子上

## 8.7 解释保护移动和嵌入式设备的常用方法

### 1. 管理员遵循最佳实践，确保公司发放的移动设备启用了预防性控制，以在设备丢失或被盗时确保存储数据的隐私。哪两项设置最有效？

1. 限制性防火墙设置
2. 始终开启的 `VPN` 连接
3. 具有至少 10 个字符密码的屏幕锁定
4. `BYOD` 可接受使用策略
5. 全盘加密（`FDE`）

### 2. 以下哪项陈述准确描述了自带设备（`BYOD`）特有的安全顾虑？

1. `BYOD` 设备与企业应用程序的兼容性有限
2. `COBO` 设备可能危及员工隐私和个人数据
3. `BYOD` 通过丢失或被盗的设备增加了未经授权的数据访问风险
4. `COBO` 设备更容易受到网络钓鱼攻击和社会工程学攻击

### 3. `Windows Defender Firewall` 中哪种网络位置类型提供最高级别的安全性？

1. 家庭
2. 公共
3. 域
4. 工作
