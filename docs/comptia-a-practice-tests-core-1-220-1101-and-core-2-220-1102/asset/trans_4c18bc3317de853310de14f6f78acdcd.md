2. 一名技术人员正在帮助用户配置其家用路由器。该无线路由器是新的，尚未配置。首先，技术人员希望使用互联网服务提供商 (ISP) 提供的正确 IP 地址配置网络接口。他们应该选择哪个配置选项？

    1. 创建 `DHCP` 预留
    2. 配置静态 `WAN` IP
    3. 启用 `UPnP`
    4. 配置 `屏蔽子网` (或译为：隔离子网/DMZ)

3. 一位家庭用户在将其 PlayStation 游戏主机连接到互联网游戏服务时遇到困难。用户认为路由器可能阻止了游戏主机访问互联网服务。哪项功能将允许用户访问互联网游戏服务？

    1. 在路由器上禁用 `内容过滤`
    2. 在路由器上禁用 `DHCP`
    3. 在路由器上启用 `UPnP`
    4. 部署 `屏蔽子网`

4. 一家小型印刷店想要托管一个 `FTP` 服务器，以允许客户上传文档，随后作为服务的一部分进行打印。打算使用一台可访问互联网的计算机。该印刷店仅有一个 `SOHO` 无线路由器。哪项功能将允许安全地托管此服务？（选择两项。）

    1. 配置 `IP 过滤` 以保护面向客户的 `FTP` 服务器
    2. 配置 `屏蔽子网` 以放置面向客户的计算机
    3. 在路由器上配置 `固件更新`
    4. 配置 `端口转发` 以将来自互联网的流量路由到 `FTP` 服务器

5. 一名技术人员正在帮助用户配置其 `Wi-Fi` 家用路由器。该无线路由器是新的，尚未配置。技术人员希望保护设备免受未经授权连接的威胁。哪两项设置最有效？（选择两项。）

    1. 禁用 `SSID` 广播
    2. 启用 `屏蔽子网`
    3. 启用 `来宾访问`
    4. 更改默认密码

6. 购物中心的一家销售网点在无线网络上遇到延迟。员工抱怨在手机和平板电脑上演示功能时，设备显示页面非常缓慢。技术人员注意到附近有许多其他无线网络。什么可能为获得更高质量的无线信号提供解决方案？

    1. 禁用 `SSID` 广播
    2. `加密设置`
    3. 禁用 `来宾访问`
    4. 更改 `信道`

7. 一名网络技术人员正在协助一家咖啡店为客户建立无线网络。该店打算将 `通行密钥` 打印在销售小票上，以便客户可以访问免费 `Wi-Fi`。技术人员受命保护网络安全，以便只有合法客户能够安全地使用该网络。哪项安全设置最符合这些要求？

    1. 启用 `WPA3-SAE`
    2. 启用 `WEP-PSK`
    3. 启用 `WPA2-TKIP`
    4. 启用 `WPA2-AES`

## 8.10 给定场景，安装和配置浏览器及相关安全设置

1. 一名技术人员正在建议一位需要协助安装 Web 浏览器的客户。为便于使用，用户倾向于下载并安装一个随默认操作系统未预装的浏览器。技术人员可以向用户提供哪两条建议以确保安全安装？

    1. 确保从可信来源下载浏览器
    2. 下载后，检查文件大小是否与供应商网站上的文件大小相同
    3. 确保下载带有密码管理器的浏览器
    4. 下载后，检查 `哈希值` 是否与供应商网站上发布的值相同

2. 一家公司希望允许用户查看未自动翻译成用户母语的网站。目前，用户抱怨需要将内容复制粘贴到文字处理应用程序中进行翻译。公司可以做些什么来最好地帮助用户？

    1. 添加 `语言翻译器` 作为 `浏览器扩展`
    2. 安装支持语言翻译的新浏览器
    3. 确保浏览器支持 `HTML5`
    4. 在 `Windows 设置菜单` 中添加对其他语言的支持

3. 一名服务台操作员被分配了一张由用户提交的支持工单，用户抱怨网页加载时间过长，且页面内似乎显示了大量广告内容。什么将是加快用户浏览器显示网页速度的最佳解决方案？

    1. 启用 `弹出窗口拦截器`
    2. 清除 `浏览数据缓存`
    3. 启用 `隐私浏览模式`
    4. 启用 `广告拦截器`

4. 一位客户询问支持技术人员如何确定银行网站值得信任。他们被告知可以制作模仿真实网站的假冒网站。什么能确保网站值得信任？

    1. 使用 `HTTPS` 连接时，网站将显示 `挂锁` 图标
    2. 使用 `HTTP` 连接时，确保存在 `受信任证书`
    3. 使用 `HTTPS` 连接时，网站将显示 `安全评级`
    4. 确保始终使用 `隐私浏览模式` 进行连接

# 9 软件故障排除

## 简介

为了成功通过 A+ 认证考试，考生必须了解用于执行有效软件故障排除的最佳实践方法。

在排查桌面环境故障时，对 Windows 操作系统有扎实的理解是关键要求。技术人员必须能够解读系统消息，并使用正确的技术响应常见错误和事件。台式计算机仍然是现代办公环境的主力，在支持这些平台上的用户时，应遵循正确的故障排除方法。

技术人员必须了解正确的主动方法，以确保系统保持优化且无恶意软件。这包括及时部署操作系统补丁和操作系统更新。

## 9.1 给定场景，排查常见 Windows 操作系统问题

1. 以下哪项是 Windows 中 `BSOD` (蓝屏死机) 错误的常见原因？

    1. 过时的 `设备驱动程序`
    2. 超频的 `CPU`
    3. 磁盘空间不足
    4. 不正确的 `BIOS 设置`

2. 以下哪项操作有助于解决由故障 `RAM` 引起的 `BSOD` 错误？

    1. 清洁计算机的 `散热风扇`
    2. 更新 `防病毒软件`
    3. 更换 `RAM 模块`
    4. 重新安装 `操作系统`

3. `BSOD` 上显示的 `STOP 错误代码` 的目的是什么？

    1. 指示错误的 `严重程度`
    2. 识别错误的具体 `原因`
    3. 告知用户可用的 `系统更新`
