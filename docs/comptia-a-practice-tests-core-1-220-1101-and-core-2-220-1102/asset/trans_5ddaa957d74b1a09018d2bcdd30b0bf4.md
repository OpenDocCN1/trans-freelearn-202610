
# 故障排除练习题

## 5.1 故障排除方法论

1.  系统管理员收到服务台的工单，要求处理首席执行官的打印机。秘书说打印机无法打印，指示灯在闪烁，他们认为是打印纸的问题。系统管理员首先应该做什么？

    1.  验证打印机的完整系统功能
    2.  测试理论以确定打印机问题的原因
    3.  识别打印机的问题
    4.  制定行动计划以解决邮件服务器问题

2.  初级管理员因在工作时间给 Exchange 服务器打补丁而受到 IT 经理的口头警告。这导致服务器重启，600 名用户无法访问电子邮件长达 15 分钟。以下哪项最能描述该初级管理员的行为？

    1.  补丁管理
    2.  与用户沟通不畅
    3.  违反标准操作程序
    4.  制定行动计划

3.  用户的笔记本电脑出现问题，二线支持技术人员已到场。支持技术人员知道他们必须尝试识别问题。支持技术人员首先应该做什么？（选择两项）

    1.  备份所有数据
    2.  询问用户是否进行过任何近期更改
    3.  询问用户事件发生前在做什么
    4.  在供应商网站上搜索指导

4.  系统管理员花费 4 小时识别并实施了解决方案。然后系统管理员实施了修复并测试了完整功能。管理员接下来应该做什么？

    1.  建立可能原因理论
    2.  实施预防措施
    3.  在呼叫中心数据库中记录发现、行动和结果
    4.  测试理论以确定原因

5.  系统管理员确定用户的笔记本电脑屏幕分辨率错误。他们认为最近的 Windows 更新导致了该问题。他们刚刚执行了故障排除过程中的哪个阶段？

    1.  建立可能原因理论
    2.  识别问题
    3.  制定行动计划
    4.  测试理论以确定原因

## 5.2 给定场景，排查主板、内存、CPU 和电源相关问题

1.  在 Windows Server 2022 上更换随机存取存储器 (RAM) 时应采取哪些安全预防措施？（选择两项）

    1.  热插拔内存
    2.  关闭电源
    3.  将机器置于待机模式
    4.  佩戴防静电腕带

2.  用户向服务台提交工单，称其台式计算机无法启动。技术人员到达后重启计算机，计算机持续发出蜂鸣声。以下哪项是台式计算机的问题？

    1.  主板问题
    2.  内存问题
    3.  电源问题
    4.  显卡问题

3.  计算机技术人员需要升级 AutoCAD 计算机中的中央处理器 (CPU)。他们首先应该做什么？

    1.  关闭电源
    2.  在制造商网站上搜索插槽类型
    3.  佩戴防静电腕带
    4.  备份数据

4.  计算机技术人员刚在台式计算机中安装了额外的内存，但未被识别。计算机技术人员接下来应该做什么？（选择两项）

    1.  检查计算机的 BIOS
    2.  佩戴防静电腕带
    3.  重启计算机
    4.  重新插拔内存模块

5.  计算机技术人员从客户服务部门收到一台台式计算机。客户服务技术人员称该台式计算机最近由二线技术人员进行过维护。他们将计算机接通市电，但打开台式计算机时屏幕黑屏。他们能听到内部风扇在转动，所以知道台式计算机有电。以下哪项可能导致此错误？（选择两项）

    1.  存储适配器线缆方向安装错误
    2.  主板错误
    3.  计算机显示器未开启
    4.  故障电源单元 (PSU)

6.  用户向服务台投诉其计算机上的时间不准确。她在过去一周内已更改时间两次，但计算机时钟仍然走慢。系统管理员到场并确认时钟时间不准确。系统管理员应采取什么措施来纠正该问题？

    1.  更换计算机电源线
    2.  更换 PSU
    3.  更换互补金属氧化物半导体 (CMOS) 电池
    4.  在制造商网站上搜索是否有 BIOS 更新

7.  计算机技术人员正在对台式计算机进行年度维护。检查主板时，他们发现一个电容鼓包。他们将计算机带回维修室更换电容。主板上的电容有什么作用？

    1.  电容循环气流
    2.  电容防止电源浪涌
    3.  电容存储数据
    4.  电容用于为实时时钟供电

8.  用户获得一台运行 Windows 10 的新笔记本电脑。他们向服务台提交工单，称指纹阅读器在最近的 Windows 更新后不再工作。以下哪项是下一步？

    1.  更新 BIOS
    2.  清除可信平台模块 (TPM)
    3.  还原系统映像
    4.  重启笔记本电脑

9.  计算机技术人员正在诊断台式计算机的问题。重启计算机时，他们听到 1 声长鸣，随后是 2 声短鸣。计算机技术人员将问题诊断为？

    1.  主板问题
    2.  正常 POST
    3.  电源问题
    4.  显卡问题

10.  计算机技术人员被叫到客户服务部门，因为一台台式计算机没有电源。计算机技术人员按下电源按钮，没有反应，也听不到内部风扇的声音。在诊断问题时，计算机技术人员应执行以下哪些操作？（选择三项）

     1.  检查插座是否开启
     2.  更换内存模块
     3.  更换电源线
     4.  将台灯插入电源插座

12.  用户向服务台报告称从计算机中闻到烧焦味。服务台技术人员告诉用户立即关闭计算机并拔掉墙上的电源插头。以下哪项可能导致烧焦味？（选择所有适用项）

    1.  CPU 风扇不工作
    2.  散热器安装不当
    3.  PSU 过热
    4.  风扇通风口被灰尘堵塞

13.  以下哪项可能导致计算机运行“缓慢”？

    1.  键盘未插入
    2.  最近的配置错误
    3.  鼠标未连接
    4.  计算机没有 CPU

    3.  硬盘问题
