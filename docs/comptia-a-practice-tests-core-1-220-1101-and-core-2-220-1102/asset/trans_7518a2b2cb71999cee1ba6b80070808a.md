## 7.11 识别 Linux 客户端/桌面操作系统的常见功能和工具

### 1. 正确答案是 **B, C**
要列出目录中的文件，可使用带有 `-l` 开关（用于长列表）的 `ls`（列表）命令，以显示目录内容的所有权限。要显示 `ls` 命令的所有可能选项，可使用 `ls --help`。`sudo chown` 允许将 `Employee-Reports` 文件的所有权从销售组更改为 `HumanResources` 组。查看已分配的其他权限，销售组似乎被错误地赋予了该文件的组所有权。`dir` 是 Windows 命令，显示的输出相同。`sudo chown` 允许更改文件的所有权。`sudo chmod` 将重置文件或目录的权限。`pwd`（当前工作目录）将显示当前正在处理命令的目录。`sudo mv` 将把文件移动到不同位置。

### 2. 正确答案是 **D**
使用 `sudo` 命令，用户可以访问超级用户账户的特权。系统将提示他们输入自己的用户密码。也可以使用 `su` 命令切换到一个活跃的账户。有关这两个命令的更多信息，请使用给定的命令并附加 `--help` 开关。`pwd` 显示当前工作目录。`grep` 用于搜索文本字符串。`Samba` 是一个互操作性套件，允许 Windows 平台从 Linux 计算机访问共享文件。

### 3. 正确答案是 **C**
Linux `top` 命令显示实时活动进程。`PID` 是进程 ID 号，`USER` 是任务所有者，`PR` 和 `NI` 显示任务优先级，`VIRT` 和 `RES` 显示内存使用情况。其他重要值包括 `%CPU`（显示 CPU 使用率）和 `%MEM`（显示每个进程使用的内存）。`nano` 是 Linux 系统上的文本编辑器。`dig` 用于向名称服务器发送 DNS 查询。`ps` 用于列出 Linux 系统上正在运行的进程，但显示的资源使用详细程度不如 `top` 命令。

### 4. 正确答案是 **D**
`rm` 命令（也称为删除命令）用于从 Linux 系统中删除文件和目录。该命令支持其他开关，例如 `-r`（递归），允许连同文件一起删除目录。输入 `rm --help` 查看所有选项。`chmod` 允许更改文件和目录的权限。`man` 用于显示命令的手册页（例如 `man rm` 将显示删除命令的详细信息）。`df` 是磁盘空闲命令，显示文件系统信息。

### 5. 正确答案是 **C**
`df` 的输出显示存储位置（硬盘）上还剩多少未使用的空间。`ps` 和 `top` 显示正在运行的进程。`ip` 用于配置网络接口的设置。

### 6. 正确答案是 **B**
`SSH`（安全外壳）将允许技术人员使用安全链接访问远程终端会话。`SSH` 使用对称加密来保护传输数据的机密性。`RDP` 用于 Windows 操作系统以访问 Windows 主机的桌面。`telnet` 不安全；恶意用户可能能够拦截网络流量并访问数据详情。`cp` 命令可用于在不同 Linux 主机之间复制文件，但不安全。

### 7. 正确答案是 **C**
`man` 命令以手册的形式显示帮助，通常比在 `CLI` 命令后输入 `--help` 命令提供更多详细信息。其他解释均为错误。

### 8. 正确答案是 **D**
在 Linux Ubuntu 服务器上安装 `samba` 服务将允许 Windows 计算机使用原生服务和应用程序访问 Linux 服务器上的文件和打印机，方式与它们连接到其他 Windows 计算机相同。Windows 使用一种称为服务器消息块 (`SMB`) 的 Microsoft 协议，也称为通用互联网文件系统 (`CIFS`)，通过网络访问共享内容。`samba` 支持相同的协议。`telnet` 用于访问远程系统的 `CLI`，但不允许在系统之间传输文件。Windows 10 工作站不运行 `samba` 服务，因为它们已支持创建到共享资源的持久连接（使用映射驱动器）所需的网络协议。Windows 文件和打印机共享是 Windows 操作系统原生的，无法安装在 Linux 系统上。
