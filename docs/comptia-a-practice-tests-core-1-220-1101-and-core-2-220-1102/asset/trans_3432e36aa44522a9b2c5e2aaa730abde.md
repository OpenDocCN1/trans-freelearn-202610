

## 9.1 排查常见操作系统问题（第 4-21 题）

### 第 4 题
提供数据恢复说明

### 第 5 题
用户提交支持工单，称其 Windows 计算机在使用几分钟后持续关机，且未显示任何错误消息。以下哪项是导致此问题**最可能**的原因？

1.  电源故障
2.  过热
3.  病毒或恶意软件感染
4.  主板故障

### 第 6 题
用户致电服务台，称遇到一个错误，提示某 Windows 服务未启动。以下哪项是 Windows 服务无法启动的**最可能**原因？

1.  磁盘空间不足
2.  设备驱动程序过时
3.  服务配置不正确
4.  软件安装不兼容

### 第 7 题
技术人员正在响应用户支持工单。用户遇到与内存可用性低相关的错误消息。以下哪些操作有助于解决 Windows 中的低内存警告？（选择两项。）

1.  关闭不必要的应用程序
2.  删除临时文件
3.  向系统添加更多 RAM
4.  升级处理器

### 第 8 题
以下哪项警告**最可能**表明 Windows 计算机存在系统不稳定？

1.  `The system has detected a critical error and will shut down in 1 minute.`
2.  `Your anti-virus software has expired. Please renew your subscription.`
3.  `A new update is available for your web browser. Click here to install.`
4.  `Low disk space. Free up some space to optimize system performance.`

### 第 9 题
技术人员正在排查一台 Windows 台式计算机，该计算机在启动期间显示错误消息 `No OS found`。最可能的原因是什么？

1.  Windows 操作系统丢失或损坏
2.  硬盘未正确连接或已损坏
3.  计算机的 BIOS 设置不正确
4.  计算机感染了病毒

### 第 10 题
用户报告登录 Windows 计算机时配置文件加载缓慢。以下哪项可能是原因？

1.  系统资源不足
2.  用户配置文件损坏
3.  网络连接问题
4.  设备驱动程序过时

### 第 11 题
以下哪些因素可能导致 Windows 中的时间漂移问题？

1.  时区设置不正确
2.  恶意软件感染
3.  硬件时钟故障
4.  断电

### 第 12 题
应使用以下哪种方法通过 Windows 服务管理控制台重启服务？

1.  右键单击服务，选择“停止”，然后选择“启动”
2.  右键单击服务，选择“重新启动”
3.  双击服务，从工具栏中选择“重新启动”
4.  右键单击服务，选择“暂停”，然后选择“继续”

### 第 13 题
关于重启对无响应应用程序的影响，以下哪项陈述是正确的？

1.  重启系统会将所有正在运行的应用程序重置为默认配置设置
2.  重启系统对无响应的应用程序没有影响
3.  重启系统**可能会强制关闭**无响应的应用程序
4.  重启系统会自动修复无响应应用程序的任何问题

### 第 14 题
如果应用程序启动后立即崩溃，应首先检查什么？

1.  应用程序的系统要求
2.  计算机上的可用磁盘空间
3.  杀毒软件设置
4.  兼容性模式设置

### 第 15 题
在最近的操作系统更新后，用户的计算机无法启动并显示 `boot device not found` 错误消息。以下哪项是导致故障的**最可能**原因？

1.  引导加载程序损坏
2.  CPU 过热
3.  硬盘空间不足
4.  BIOS 设置不正确

### 第 16 题
用户的计算机在安装新的杀毒软件后频繁出现蓝屏死机 (BSOD) 错误。为排查该问题，应采取以下哪项操作？

1.  卸载杀毒软件
2.  升级计算机的 RAM
3.  重新安装操作系统
4.  更换显卡

### 第 17 题
用户的计算机反复提示安装最新的操作系统更新，但在安装过程中遇到错误。可采取以下哪些步骤来解决操作系统更新失败的问题？

1.  清除临时文件并重试更新
2.  安装不同的 Web 浏览器
3.  升级计算机的电源
4.  提高屏幕分辨率

### 第 18 题
如果技术人员需要回滚不成功的更新，执行以下哪项操作很重要？

1.  重新安装最新更新
2.  禁用自动更新
3.  创建系统还原点
4.  增加系统资源

### 第 19 题
当 Windows 计算机无法启动并显示蓝屏死机 (BSOD) 时，技术人员应采取什么排查步骤？

1.  重启计算机并再次尝试
2.  使用系统还原回滚到之前的正常工作状态
3.  重新安装所有第三方应用程序
4.  更新计算机的 BIOS

### 第 20 题
计算机技术人员应在何时考虑运行 Windows 系统文件检查器？

1.  遇到硬件驱动程序问题时
2.  安装新软件更新后
3.  遇到频繁的应用程序崩溃时
4.  执行磁盘碎片整理前

### 第 21 题
在命令提示符中用于启动 Windows 系统文件检查器的命令是什么？

1.  `sfc /scanfile`
2.  `sfc /verifyonly`
3.  `sfc /scannow`
4.  `sfc /restorehealth`

### 第 22 题
技术人员何时可能考虑使用 Windows 重置映像作为排查步骤？

1.  当特定软件应用程序无法正常启动时
2.  当计算机的互联网连接不稳定时
3.  当计算机频繁崩溃并出现蓝屏错误时
4.  当需要调整计算机的显示分辨率时

## 9.2 给定场景，排查常见个人计算机 (PC) 安全问题

### 第 1 题
用户无法从其个人计算机 (PC) 访问网络。服务台技术人员应采取以下哪项步骤来排查此问题？

1.  检查物理网络连接和线缆
2.  更新杀毒软件
3.  重新安装操作系统 (OS)
4.  增加 PC 的 RAM

### 第 2 题
用户频繁收到桌面警报，警告潜在的安全威胁，但这些警报均为误报。技术人员应采取以下哪项步骤来解决此问题？

1.  更新杀毒软件
2.  调整防火墙设置
3.  使用杀毒程序运行全面系统扫描
4.  将误报文件从杀毒扫描中排除

### 第 3 题
用户报告其 PC 上的个人文件被篡改、丢失或重命名。以下哪项安全问题**最可能**导致此情况？

1.  网络钓鱼攻击
2.  勒索软件感染
3.  Rootkit 安装
4.  网络入侵者未经授权的访问

### 第 4 题
用户提交服务工单，称在其 PC 的操作系统 (OS) 中遇到不需要的通知。技术人员应采取以下哪项步骤来排查此问题？

1.  禁用启动程序
2.  更新 BIOS
3.  重新安装操作系统
4.  使用注册表清理工具清理注册表

### 第 5 题
用户在尝试为其 PC 安装操作系统 (OS) 更新时遇到失败。技术人员应采取以下哪项步骤来解决此问题？

1.  暂时禁用杀毒软件
2.  重启 PC 并尝试再次安装更新
3.  从头重新安装操作系统
