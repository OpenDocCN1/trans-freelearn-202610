### 11. 在隐私和政策概念的背景下，以下哪项最能描述受监管数据？

1.  受政府法规和限制约束的数据
2.  公众可自由访问的数据
3.  未采用任何加密或安全措施存储的数据
4.  在组织内部员工间共享的数据

### 12. 哪类数据被视为个人身份信息 (PII)？

1.  社交媒体帖子和评论
2.  个人的姓名和地址
3.  公开可用的公司信息
4.  非敏感的电子邮件通信

### 13. 以下哪项描述了处理信用卡交易时的一个关键关注点？

1.  确保数据可用性
2.  保抁持卡人数据安全
3.  维护准确的财务记录
4.  最大化交易速度

### 14. 以下哪项是个人政府颁发信息的示例？

1.  社交媒体账户用户名
2.  驾驶执照号码
3.  Wi-Fi 网络密码
4.  家庭住址

### 15. 以下哪项最能描述数据保留要求？

1.  处理数据所需的时间量
2.  存储和管理数据的策略和程序
3.  数据备份的频率
4.  数据在网络上的传输速度

## 10.7 给定场景，使用恰当的沟通技巧和专业素养

### 1. 当服务台人员与客户沟通时，哪种沟通技巧体现了专业性和同理心？

1.  打断客户以提供快速解决方案
2.  使用专业术语以确立专业性
3.  积极倾听并复述客户的顾虑
4.  提供折扣或赠品以解决问题

### 2. 以下哪项是反映专业性的非语言沟通示例？

1.  保持眼神接触并点头表示赞同
2.  在移动设备上查看个人邮件
3.  压低声音以避免打扰他人
4.  使用俚语和非正式语言

### 3. 在商务邮件中，以下哪项是称呼收件人最恰当的方式？

1.  `Hey [收件人名字]，`
2.  `Dear [收件人名字]，`
3.  `To whom it may concern，`
4.  `Hi there，`

### 4. 以下哪种沟通方式最适合向非技术受众传达复杂的技术信息？

1.  大量使用技术术语和首字母缩略词
2.  仅提供详细的书面文档
3.  利用视觉辅助、图表和插图
4.  语速飞快以确保涵盖所有信息

### 5. 以下哪项是在客户沟通中恰当使用专业语言的示例？

1.  “你的电脑完全搞砸了”
2.  “你的设备遇到了一些技术困难”
3.  “你的机器表现怪异”
4.  “你的电脑坏了”

### 6. 与客户交谈时，以下哪项是处理分歧或冲突的专业方式？

1.  提高音量以显示主导地位
2.  责怪客户导致问题
3.  提供替代解决方案和妥协方案
4.  忽视客户的顾虑

### 7. 以下哪项是在与同事互动时恰当专业行为的示例？

1.  议论其他团队成员
2.  窃取他人工作成果
3.  积极倾听并尊重他人意见
4.  在公开论坛批评同事

### 8. 以下哪种沟通方式最适合传递敏感或机密信息？

1.  在团队会议上公开宣布
2.  向全体员工发送群发邮件
3.  举行一对一的面对面会议
4.  在公共布告栏张贴信息

### 9. 以下哪项是在虚拟会议中保持专业性的示例？

1.  在镜头前进食
2.  不发言时保持麦克风静音
3.  在聊天消息中使用非正式语言和缩写
4.  分享无关的个人轶事

### 10. 与客户沟通时，以下哪项是管理其预期的专业方法？

1.  过度承诺以确保客户满意
2.  设定切合实际的预期并提供进度更新
3.  忽略客户请求以避免冲突
4.  将客户转介至不同的支持渠道

### 11. 技术人员应采取以下哪项行动，以妥善处理存储在台式计算机上的客户机密和私人资料？

1.  定期与同事共享客户数据以供协作
2.  使用强加密算法加密客户的敏感文件和文件夹
3.  将客户的机密数据上传至云存储服务以进行备份
4.  在未安全擦除硬盘的情况下处置客户的计算机

### 12. 在处理打印机上的客户机密材料时，技术人员应采取以下哪项措施以维护安全？

1.  与其他技术人员共享打印机的访问凭据以便于故障排除
2.  禁用打印机的日志记录功能以防止潜在的隐私泄露
3.  在打印机上实施访问控制以限制未经授权的使用
4.  在公共区域打印客户的机密文件以便快速获取

### 13. 技术人员正在帮助客户保护其台式计算机安全。技术人员必须实施最佳实践来保护客户的机密材料。哪项提供了最佳解决方案？

1.  为客户及其同事创建一个具有无限制访问权限的共享用户账户
2.  定期执行数据备份，但不验证备份介质的完整性和机密性
3.  为客户的台式机实施强密码策略并启用全盘加密
4.  将客户的机密文件存储在公开可访问的文件夹中以便于协作
