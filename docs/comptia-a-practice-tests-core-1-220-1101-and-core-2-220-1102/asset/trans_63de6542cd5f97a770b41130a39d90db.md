

# 第 8 章：网络与安全

## 第 8 章复习题

1. 正确答案是 **D**。小型办公室/家庭办公室（`SOHO`）路由器上的固件更新具有多种用途。首先，它们旨在提高路由器的整体性能和稳定性，确保其平稳高效地运行。其次，固件更新可以引入新功能，增强路由器的能力。最后，也是最重要的，固件更新通常会解决安全漏洞和错误，提供必要的补丁以防范潜在的攻击或未经授权的访问。保持固件为最新版本对于保护网络和连接的设备至关重要。单独来看，选项 A、B 和 C 都无法完全回答该问题。

2. 正确答案是 **B**。静态广域网（`WAN`）`IP`，也称为静态公网 `IP`，是分配给通过广域网连接到互联网的设备或网络的固定互联网协议（`IP`）地址。选项 A 可能是内部网络上使用的内容，以便打印机始终获得相同的地址。选项 C 允许为内部设备（如游戏主机）添加防火墙例外。只有当有面向互联网的服务（如 `FTP` 服务器）需求时，才需要选项 D。

3. 正确答案是 **C**。`UPnP` 是一种协议，允许网络上的设备相互发现和通信，而无需用户执行手动配置。这简化了诸如在线游戏的端口开放、访问打印机、媒体服务器和智能电视等任务。选项 A 用于阻止包含不当内容的网页和电子邮件。在这种情况下，选项 B 不会影响防火墙规则。选项 D 不是必需的。

4. 正确答案是 **B**。屏蔽子网允许一个半安全区域，可在其中放置一台加固的主机服务器。该服务器将通过防火墙从互联网访问，也可从内部网络访问。端口转发将确保外部客户发送到 `WAN` `IP` 地址的请求被正确路由到屏蔽子网上的 `FTP` 服务器。在这种情况下，选项 A 不太有用，因为我们在屏蔽子网中不会有多个 `IP` 地址。选项 C 肯定能确保路由器运行最新固件，但并不能为该问题提供解决方案。

5. 正确答案是 **A, D**。如果不广播路由器的 `MAC` 地址和分配的无线网络标识符，攻击者将不得不使用专业设备来检测网络的存在。网络设备制造商在产品上使用标准的默认管理员账户名和密码。这些应始终被更改。选项 B 不是必需的，因为没有面向互联网的 `FTP` 或 `WWW` 服务器的需求。在这种情况下不需要选项 C，且会降低路由器的安全性。

6. 正确答案是 **D**。在可能部署多个无线接入点的区域，值得调查是否有未使用的信道或拥塞较小的信道。使用 2.4 GHz 范围的无线控制器只有三个非重叠信道可选。在这种情况下，其他选项都侧重于安全性，而非信号的速度或强度。

7. 正确答案是 **A**。在咖啡店等小型企业中，通常会与客户共享密钥以提供免费 Wi-Fi 访问。最安全的方法是使用对等实体同时认证（`SAE`）。这使用 `AES` 256 位加密并防止针对密钥的暴力破解攻击。选项 B 不安全，因为 `WEP` 已被弃用。`WPA2` 是旧标准且不支持 `SAE`，因此选项 C 和 D 不正确。

## 8.10 给定场景，安装并配置浏览器及相关安全设置

1. 正确答案是 **A, D**。安装新软件时，建议始终使用可信站点。例如，如果用户想要下载 `Google Chrome`，最好访问供应商站点，而不是第三方未知站点。许多软件供应商会发布下载文件的哈希值或校验和。这可以使用用户工作站上的哈希工具进行验证。选项 B 不那么重要，因为恶意下载文件的大小可能与真实文件相同。选项 C 描述了一个有用的功能，但不能确保可信的软件下载和安装。

2. 正确答案是 **A**。添加语言翻译器作为浏览器扩展是公司帮助用户将网站翻译成其母语的最方便、最用户友好的解决方案。浏览器扩展（如 `Google Translate`）允许用户直接在浏览器中翻译网页内容，而无需将内容复制粘贴到单独的应用程序中。选项 B 指的是浏览器扩展，可以提供相同的功能，而无需用户切换到新浏览器。虽然对 `HTML5` 的支持对现代网页浏览很重要，但选项 C 并不直接解决将网站翻译成用户母语的问题。选项 D，在 Windows 设置菜单中添加对额外语言的支持，与网站翻译问题无关。

3. 正确答案是 **D**。通过启用广告拦截器，浏览器将能够更快地渲染和显示网页。选项 A 已不再真正有效，因为广告内容嵌入在页面内，尽管它可以阻止建议主机系统可能有多个恶意文件的虚假弹窗。选项 B 和 C 并非设计用于阻止广告。

4. 正确答案是 **A**。浏览安全网站时，客户端浏览器会显示一个挂锁符号，以向用户表明该站点拥有有效证书。选项 B 不正确，因为 `HTTP` 协议不使用证书。选项 C 不正确，因为不使用评级。选项 D 允许在不保留历史记录的情况下浏览，这与问题无关。

# 第 9 章：软件故障排除

## 9.1 给定场景，排查常见 Windows 操作系统问题

1. 正确答案是 **A**。过时的设备驱动程序是 Windows 中 `BSOD` 错误的常见原因。当驱动程序不是最新时，它们可能与 `OS` 冲突，导致系统不稳定和崩溃。选项 B、C 和 D 也可能导致系统问题，但过时的设备驱动程序被专门认为是更频繁地触发 `BSOD` 错误的原因。

2. 正确答案是 **C**。故障 `RAM` 会导致 `BSOD` 错误，最有效的解决方案是更换故障 `RAM` 模块。清洁计算机的散热风扇（选项 A）可能防止过热问题，但不会直接解决 `RAM` 相关错误。更新防病毒软件（选项 B）与 `RAM` 错误无关。重新安装操作系统（选项 D）是一个更广泛的故障排除步骤，通常不需要用于解决 `RAM` 相关的 `BSOD` 错误。

3. 正确答案是 **B**。`BSOD` 上显示的 `STOP` 错误代码旨在帮助识别错误的具体原因。它提供十六进制错误代码，并通常包含有助于故障排除和解决问题的附加信息。选项 A、C 和 D 并不能准确反映 `STOP` 错误代码的目的。
