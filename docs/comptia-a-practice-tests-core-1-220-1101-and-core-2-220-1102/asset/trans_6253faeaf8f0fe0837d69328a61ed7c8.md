## 模拟考试：Core 2 (220-1102)

最后一章旨在为考生提供包含 93 道题的真实模拟考试。官方 CompTIA A+ Core 2 (220-1102) 认证考试允许用 90 分钟完成所有题目。本模拟考试旨在涵盖以下所有 CompTIA 认证目标：

*   为最终用户安装、配置和维护计算机设备、移动设备和软件
*   根据客户要求维护组件
*   理解网络基础并应用基本网络安全方法以缓解威胁
*   正确且安全地诊断、解决和记录常见的硬件和软件问题
*   应用故障排除技能并使用适当的沟通技巧提供客户支持
*   理解脚本编写、云技术、虚拟化和企业环境中多操作系统部署的基础知识

为了准确衡量您的知识水平，建议您给自己 90 分钟完成所有 90 道题（或将其分解为每 30 分钟完成 30 道题的模块）。

## 模拟考试题目

1.  您正在排查一部表现异常的智能手机，例如运行缓慢、数据使用量过大和出现意外弹窗广告。您怀疑它可能感染了恶意软件。解决此问题的最合适的第一步是什么？

    1.  对智能手机执行恢复出厂设置
    2.  下载一款流行的防病毒应用并运行全盘扫描
    3.  将智能手机与互联网断开连接
    4.  更新智能手机的操作系统和所有应用

2.  某银行组织的管理层正在审查变更管理文档。团队需要了解流程中使用的正确步骤。变更获批后，下一步是什么？

    1.  最终用户验收
    2.  进行风险分析
    3.  向相关方传达变更
    4.  执行沙箱测试

3.  用户报告在 `Windows 10` 操作中心遇到零星的、看似非恶意的广告通知。这些通知表明广告源自网络浏览器。技术人员实施的**最有效**解决方案是什么？

    1.  禁用浏览器向操作中心发送通知的功能
    2.  对计算机执行全面的防病毒扫描
    3.  关闭操作中心内的所有通知
    4.  将特定网站的通知从“允许”类别移至“阻止”

4.  经理报告员工经常忘记其移动设备和应用程序的密码，导致提交的服务台工单数量激增。系统管理员应采取什么措施将工单数量降至最低？

    1.  启用多因素认证
    2.  提高登录失败阈值
    3.  取消复杂密码要求
    4.  实施带有生物识别功能的单点登录系统

5.  服务台技术人员正在响应一张似乎表明存在 Rootkit（根工具包/隐藏型恶意软件）的服务工单。为了解决疑似 Rootkit 安装问题，以下哪个选项**最有效**？

    1.  更新应用程序
    2.  使用反恶意软件
    3.  重新安装操作系统
    4.  还原文件

6.  技术人员受命重新部署闲置的无线接入点用于新仓库。这些设备自 2015 年以来一直存放在仓库中。技术人员必须确保它们配置了最安全的无线网络设置。考虑到设备的年龄，哪种配置能为技术人员提供最安全的实施？

    1.  `WPA3` 配合 `AES-128`
    2.  `WPA2` 配合 `AES`
    3.  `WPA3` 配合 `AES-256`
    4.  `WPA2` 配合 `TKIP`

7.  呼叫中心技术人员接到一位家庭用户的来电，寻求关于更新 `Windows` 的指导。他们希望确保在向客户提供最新 `Windows` 版本时，自己运行的就是该版本。技术人员应采取的适当行动是什么？
