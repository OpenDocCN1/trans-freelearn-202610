## 1.2 对比移动设备的显示组件

### 1. 以下哪项描述了 `digitizer`（数字化屏/触控屏）的功能？

1.  将 `DC` 电源转换为 `AC` 电源
2.  可支持 `2000:1` 的 `contrast ratio`（对比度）
3.  控制 `LCD` 显示器的亮度设置
4.  安装在移动设备上的一块玻璃，用于使 `touchscreen`（触摸屏）发挥作用

### 2. 智能手机使用以下哪项来改变屏幕方向？

1.  `Bezel`（边框）
2.  `Digitizer`（数字化屏）
3.  `Accelerometer`（加速度计）
4.  `Gyroscope`（陀螺仪）

### 3. 连接到笔记本电脑的外置 `webcam`（摄像头）已开启，但未生成图像。以下哪项可解决此问题？

1.  重启计算机并重试
2.  购买新摄像头
3.  卸载后重新安装摄像头软件，并确保从制造商网站获取最新的 `drivers`（驱动程序）
4.  将摄像头插入另一个 `USB port`（USB 接口）

### 4. `inverter`（逆变器/高压板）的用途是什么？

1.  将 `AC` 转换为 `DC` 电源
2.  启用 `touchscreen`（触摸屏）功能
3.  将 `DC` 转换为 `AC` 电源
4.  提高低光条件下的可读性
