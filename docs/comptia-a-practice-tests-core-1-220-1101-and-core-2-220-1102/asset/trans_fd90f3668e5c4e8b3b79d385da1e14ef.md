
# 2. 网络

## 简介

现代技术的特点日益体现为设备间的互联互通。这意味着，为了跟上这一进步并提供一致且有效的支持，IT 专业人员必须具备网络概念的实用知识，范围涵盖从 `IP` 地址到不同类型的无线网络。

你需要知道不同应用程序使用哪些端口，以便在防火墙上打开这些端口并允许它们通信。IT 管理员还需要知道如何在用户无法连接到网络时排查故障，无论问题源头是 `DNS` 还是 `IP` 错误。无线网络是日常生活的常见组成部分，拥有知识和经验以确定哪种类型的无线网络最适合特定场景至关重要。本章的练习测试将检验你应用前期学习所获信息的能力。

在 CompTIA A+ Core 1 (`220-1101`) 认证考试中，领域 2.0 网络占评估的 20%，因此是学生成功备考的关键组成部分。该领域进一步细分为以下核心目标：

*   **2.1** 对比传输控制协议 (`TCP`) 和用户数据报协议 (`UDP`) 的端口、协议及其用途
*   **2.2** 对比常见网络硬件
*   **2.3** 对比无线网络协议
*   **2.4** 总结网络主机提供的服务
*   **2.5** 给定场景，安装和配置基本的有线/无线小型办公室/家庭办公室 (`SOHO`) 网络
*   **2.6** 对比常见网络配置概念
*   **2.7** 对比互联网连接类型、网络类型及其特性
*   **2.8** 给定场景，使用网络工具

本章其余部分专注于实践。针对上述定义的每个概念，你将获得一系列问题，旨在测试你对该领域官方认证考试指南所定义的每个核心 1 目标的掌握程度。完成这些问题并确保理解其背后的概念后，你应该已完全准备好应对 CompTIA A+ Core 1 (`220-1101`) 考试中的同类题目。

## 练习考试题目

### 2.1 对比 TCP 和 UDP 端口、协议及其用途

1.  系统管理员需要使用一种协议对网络设备进行安全远程访问。他们应该使用以下哪项？
    1.  `Telnet` `TCP port 23`
    2.  `SSH` `TCP port 22`
    3.  `RDP` `TCP port 3389`
    4.  `SNMP` `UDP port 161`

2.  当在线商店提醒你正被重定向到安全服务器时，URL 中应显示什么协议？
    1.  `TFTP`
    2.  `HTTPS`
    3.  `HTTP`
    4.  `SSH`

3.  以下哪种邮件客户端会下载邮件、将其存储在本地计算机上，且不在邮件服务器上保留副本？
    1.  `POP`
    2.  `IMAP`
    3.  `SMTP`
    4.  `SSH`

4.  Windows 操作系统中用于文件和打印共享的应用程序协议是以下哪项？
    1.  `137-139`
    2.  `67/68`
    3.  `445`
    4.  `389`

5.  以下哪个标准端口由安全邮局协议 (`POP`) 使用？
    1.  `110`
    2.  `995`
    3.  `993`
    4.  `143`

6.  以下哪种协议是无连接的，并用于流式传输视频或音频？
    1.  `TCP`
    2.  `RDP`
    3.  `UDP`
    4.  `TFTP`

7.  以下哪个端口由可提供所有网络设备状态和报告的协议的安全版本使用？
    1.  `161`
    2.  `389`

8.  以下哪种协议使用 `TCP ports 20/21` 并以明文传输数据？

    2.  `FTP`
    3.  `SSH`
    4.  `FTPS`

9.  以下哪些是 `HTTP` 和 `HTTPS` 流量的默认端口？（选择两项）

    2.  `80`
    3.  `110`
    4.  `443`
    5.  `445`

10. `TCP` 是面向连接的，并使用三次握手。握手的正确顺序是什么？

    2.  `SIGNAL`, `CONNECT`, `ACKNOWLEDGE`
    3.  `SYN-ACK`, `ACK`, and `SYN`

11. 系统管理员正在设置新防火墙，需要允许 `SMTP` 流量通过。必须为入站流量启用以下哪个 `TCP` 端口？
    1.  `21`

12. 以下哪个标准端口由安全 `IMAP` 使用？
    1.  `993`
    2.  `110`
    3.  `995`
    4.  `143`

13. 以下哪项是不安全的远程访问协议，其密码可能被协议分析器窃取？
    1.  `SSL`
    2.  `SSH`
    3.  `Telnet`

### 2.2 对比常见网络硬件

`QTYPE: MCQ-MULTI_ANSWER`

1.  初级网络管理员被要求识别配线架的正面和背面。以下哪项描述是正确的？（选择两项）
    1.  配线架的正面是公司布线在绝缘位移连接器 (`IDC`) 处终结的地方
    2.  配线架的背面是公司布线在绝缘位移连接器 (`IDC`) 处终结的地方
    3.  配线架的正面有预接线的 `RJ45` 端口
    4.  配线架的背面有预接线的 `RJ45` 端口

2.  云服务提供商 (`CSP`) 需要能够使用脚本快速预配服务器和网络。哪种网络类型提供此功能？
    1.  广域网 (`WAN`)
    2.  局域网 (`LAN`)
    3.  软件定义网络 (`SDN`)
    4.  存储区域网络 (`SAN`)

3.  哪种类型的防火墙可以执行 URL 过滤、内容过滤和恶意软件检查？
    1.  无状态防火墙
    2.  基于主机的防火墙
    3.  有状态防火墙
    4.  统一威胁管理 (`UTM`)

4.  安装在客户家中的光网络终端 (`ONT`) 的用途是什么？

    3.  `ONT` 将电信号转换为光信号

5.  以下哪项允许主机通过插入交换机的以太网线为设备供电？

6.  以下哪种网络设备用于减小 `LAN` 中广播域的大小？

9.  哪种交换机开箱即用、通电即可工作、具有 4 或 8 个端口，并用于极小型网络？
