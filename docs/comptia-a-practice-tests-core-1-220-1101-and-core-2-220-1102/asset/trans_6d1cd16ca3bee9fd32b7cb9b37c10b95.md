

## 5.4 给定场景，排查显示器常见故障

4. 正确答案是 **B**。高带宽数字内容保护 (HDCP) 允许内容源（如 DVD/蓝光光盘）在显示适配器和显示器及/或音响系统不支持 HDCP 且无法通过播放源进行身份验证时禁用自身。如果 HDMI 线缆故障，则会出现“无信号”错误。无需调整显示设置，因为投影仪上有输出。如果 DVD 播放器有问题，则不会有声音。

5. 正确答案是 **C** 和 **D**。如果更换为已知良好的线缆后出现“未找到信号源”错误，我们需要将笔记本电脑投影到投影仪。如果我们运行 `displayswitch.exe` 命令，则有四个投影选项，我们应该选择“复制”或“扩展”，然后笔记本电脑的图像就会出现在计算机屏幕上。我们也可以从笔记本电脑上的显示设置完成此操作。选择“多显示器”，然后选择“复制这些显示器”或“扩展这些显示器”。无需更换投影仪灯泡，因为错误正在显示出来。既然线缆刚刚更换过，就无需检查 HDMI 线缆连接。

6. 正确答案是 **A** 和 **C**。当从笔记本电脑使用投影仪时，如果连接器在两端都未连接牢固，屏幕会闪烁。闪烁、闪光图像或边缘周围的亮点表明背光正在失效。检查显示设置或重启笔记本电脑无法解决任何问题，因为是硬件错误导致了该问题。

7. 正确答案是 **C**。HDMI-ARC 允许将电视的音频发送到外部音响系统。如果我们不使用此端口，则音响条将无法从电视接收任何音频。音响条没有电源的可能性不大。音响条没有音量控制；音量由电视遥控器控制。视频分辨率与声音无关。

8. 正确答案是 **C**。当显示器出现粉色或紫色变色时，很可能是由故障或松动的线缆引起的。显示器烧屏会在屏幕上显示前一个图像的残影。此处的颜色覆盖了整个屏幕。故障显卡会导致屏幕闪烁，但在这种情况下，屏幕没有闪烁。灯泡烧毁会导致屏幕变暗。

9. 正确答案是 **B**。当光标不断漂移时，你需要校准屏幕来修复它。屏幕变色将是视频线缆问题。未提及显卡驱动程序更新；因此，回滚驱动程序不是一个选项。更改屏幕分辨率无法修复此问题；它只会改变屏幕的大小。

10. 正确答案是 **B** 和 **C**。投影仪过热，这就是它间歇性重启的原因。我们首先要检查风扇是否工作，是否有灰尘或障碍物阻止风扇工作，以及通风口是否没有灰尘或障碍物。你可能会检查电源线是否插好，但此时不应更换线缆。投影仪显示分辨率不是导致重启的原因。

11. 正确答案是 **A**。显示器烧屏是指前一个图像保留在屏幕上或显示为残影。坏点是指屏幕可能冻结，并可能出现黑色区域。故障线缆会导致闪烁。笔记本电脑死机可能会导致“无信号”错误。

12. 正确答案是 **C**。测试输出分辨率主要是为了确保系统的输出与各种显示设备兼容。显示设备可以有不同的分辨率和功能，测试有助于确认系统能够适应这些设备并正常运行。它确保输出正确缩放、对齐且兼容，避免图像失真或内容被切断等问题。色彩表现的准确性和图像质量的优化是次要考虑因素，但主要关注点是与各种显示设备的兼容性。它不能提升系统性能。

13. 正确答案是 **C**。显示设置是正确答案，因为显示设置通常包含触摸屏校准和启用触摸输入的选项。电池状态不正确，因为电池状态不会直接影响触摸屏功能。网络连接不正确，因为网络连接不影响触摸屏功能。键盘设置不正确，因为键盘设置不直接涉及触摸屏功能。

## 5.5 给定场景，排查移动设备常见故障

1. 正确答案是 **B**。CMOS 电池是正确答案，因为故障或耗尽的 CMOS 电池会导致计算机无法保留 BIOS 设置，从而导致 POST 错误。RAM 模块会发出持续的蜂鸣声。硬盘驱动器问题通常会导致启动错误或无法访问数据，但不会直接影响 POST 过程。显卡问题可能导致显示相关问题，但不会直接影响 POST 过程。

2. 正确答案是 **C**。PoE 供电器可以通过以太网线缆为网络设备供电，解决电源相关问题。检查线缆连接有助于解决物理连接问题，但无法为网络设备供电。重置网络设置无法为设备供电，且可能无法解决电源相关问题。重启网络设备无法解决电源问题。

3. 正确答案是 **C**。当手机过热时，手机电池有缺陷。运行资源密集型应用可能会导致一些发热，但过热更可能是由于电池缺陷。暴露在阳光直射下可能会导致一些发热，但不太可能导致过热。过时的操作系统可能导致性能问题，但与过热没有直接关系。

4. 正确答案是 **D**。如果手机进液受损，你需要专业维修服务来维修手机。手机进液后开机可能会导致短路并造成进一步损坏。虽然用大米吸湿是常见建议，但它并不能有效彻底干燥手机内部组件。使用吹风机会引入热量，可能会进一步损坏手机内部组件。

## 5.6 给定场景，排查并解决打印机故障

1. 正确答案是 **A**。双面打印可自动在纸张两面打印。打印机的打印速度不一定影响纸张用量。所用纸张类型（再生纸与否）不直接影响打印机的纸张用量。较大的纸盒可减少加纸频率，但无法解决纸张过度使用的问题本身。

2. 正确答案是 **C**。打印机的定影单元工作不正常，因为它将文字定影在纸上。劣质墨盒可能影响打印质量，但不太可能导致打印文字不粘在纸上。使用不兼容的纸张可能影响打印质量，但不会导致此问题。打印机的温度设置不可调，而是基于特定的打印要求。
