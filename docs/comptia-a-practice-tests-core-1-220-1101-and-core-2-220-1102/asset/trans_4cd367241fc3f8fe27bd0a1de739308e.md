# 第 8 章：安全

## 8.1 总结各种安全措施及其目的

1. 正确答案是 **A**。运动传感器主要设计用于检测其范围内的任何移动。它们常用于安全系统中，以识别未经授权的个人或物体的存在、触发警报或激活其他安全措施。选项 B 描述的是 HVAC 系统（暖通空调系统）。选项 C 描述的是音频检测。选项 D 描述的是光敏传感器。

2. 正确答案是 **B**。软令牌是基于软件的安全令牌，可生成一次性密码 (OTP) 以在登录过程中验证用户身份。它们常用于逻辑安全系统，以提供额外的安全层。软令牌生成在短时间内有效的唯一密码，确保只有授权用户才能访问敏感信息或执行特定操作。选项 A（生成安全密码）不正确，因为软令牌主要不用于密码生成。它们专注于身份验证方面，而非密码创建。选项 C（加密数据）不正确，因为软令牌不直接处理数据加密。其主要功能是验证用户身份，而非加密数据。选项 D（阻止恶意网站）不正确，因为软令牌并非设计用于阻止或防止访问网站。它们专门用于用户身份验证，无法阻止恶意网站。

3. 正确答案是 **C, E**。BYOD 策略允许制定标准和指南，以规范使用个人设备访问业务系统。移动设备管理 (MDM) 允许团队管理和配置各种移动设备。选项 A、B 和 F 旨在增强身份验证过程中的安全性。选项 D 旨在物理保护硬件。

4. 正确答案是 **A, F**。物理控制旨在防止未经授权访问设施和信息系统。访问控制前室强制用户进入一个小空间（仅设计容纳一人），并通过联锁门来实施安全控制。用户必须提供身份验证，才能被允许通过第二扇门。门锁可防止未经授权的用户获得访问权限。警报、视频监控和运动传感器可检测到入侵，但无法阻止未经授权访问服务器室。防撞柱有助于防止机动车辆冲撞或冲破外围围栏或岗亭进行入侵。

5. 正确答案是 **C, E**。检测控制可让安保人员知晓那些逃避了物理安全控制的入侵行为。这被称为纵深防御。视频监控和运动传感器可让安保团队检测到未经授权的入侵。访问控制前室、工牌读取器、设备锁和门锁都被视为预防控制。

6. 正确答案是 **A**。要支持双因素认证 (2FA)，不能选择来自同一组的另一个因素。智能卡是一种物理设备；它属于“你拥有的东西”。视网膜扫描仪和掌纹扫描仪都被视为生物识别技术，即“你是谁”。它们与指纹阅读器属于同一类别。运动探测器不是一种身份验证方法。

7. 正确答案是 **E**。磁力计是可检测隐藏金属物体的设备。该技术可部署在数据中心的入口处。设备也可贴上标签，以便在磁力计上触发警报。访问控制前室旨在确保只有授权人员才能进入设施。在本例中，我们需要额外的控制措施。视频监控可能无法识别隐藏（在夹克或其他衣物下）的设备。照明用于确保视频监控有效。设备锁是个不错的选择，但本例中的要求是检测控制（警报）。

8. 正确答案是 **A**。将用户添加到具有安全限制的组将遵循最小权限原则。ACL 用于确保访问权限仅授予正确的用户或组。结合安全组使用时，将确保只有正确的安全组才能访问数据。将用户添加到受限组不属于 MFA 的一部分。组织单位 (OU) 是一种管理控制，在将组策略设置应用于不同业务单元时非常有用。

9. 正确答案是 **A, D**。主文件夹为每个用户提供托管在中央服务器上的唯一存储位置。主文件夹通过登录脚本分配。选项 B（安全组管理）通常不是在用户登录系统时执行的。选项 C（多因素认证）旨在通过使用两个或更多因素来保护身份验证。选项 E（组织单位）用于管理 Active Directory 服务中的对象。

10. 正确答案是 **B, E**。MFA 要求用户在登录其用户帐户时使用两个或更多身份验证因素。主要有三组：你知道的东西、你拥有的东西和你是谁。在本例中，用户使用了他们知道的东西（密码）和一个硬件令牌来生成基于 HMAC 的一次性密码。这属于你拥有的东西。选项 A 与良好的帐户管理相关。选项 C 和 D 对 MFA 有效，但并非本例中所描述的内容。
