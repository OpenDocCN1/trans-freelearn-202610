
## 10.2 Explain basic change-management best practices

1. A company is updating operational procedures and will adopt change management. Which of the following best describes a basic change-management best practice?

    1. Implementing changes without proper planning
    2. Communicating changes only after they have been implemented
    3. Documenting changes thoroughly
    4. Ignoring user feedback

2. Which of the following is a key element of change management?

    1. Minimizing user involvement
    2. Avoiding communication with stakeholders
    3. Assessing and managing risks
    4. Rushing the implementation process

3. Which of the following is a recommended practice for managing user resistance during change implementation?

    1. Ignoring user concerns
    2. Providing clear communication and training
    3. Limiting user access to system documentation
    4. Implementing changes abruptly without prior notice

4. Which of the following best describes the purpose of a change advisory board (CAB)?

    1. Approving all changes without review
    2. Monitoring the progress of change implementation
    3. Evaluating and prioritizing proposed changes
    4. Limiting user involvement in the change process

5. Which of the following is a common risk associated with change management?

    1. Improved system performance
    2. Increased user satisfaction
    3. Temporary service disruptions
    4. Enhanced security measures

6. Which of the following is an example of a change management best practice for software deployments?

    1. Skipping the testing phase
    2. Performing regular backups
    3. Implementing changes during peak hours
    4. Avoiding user communication

7. Which of the following is an example of a change management best practice for hardware replacements?

    1. Ignoring user feedback
    2. Conducting a thorough inventory assessment
    3. Implementing changes without testing
    4. Excluding stakeholders from the process

8. Which of the following best describes the purpose of a rollback plan in change management?

    1. Preventing any changes from being implemented
    2. Documenting the reasons for change implementation
    3. Identifying potential issues and their resolutions
    4. Excluding user feedback during the change process

9. Which of the following is a recommended practice for managing change-related risks?

    1. Avoiding risk assessment altogether
    2. Implementing changes without backup plans
    3. Conducting regular risk assessments
    4. Ignoring risk mitigation strategies

10. Which of the following is a key consideration when communicating changes to users during change management?

     1. Providing vague and general information
     2. Overemphasizing the negative aspects of the changes
     3. Tailoring the message to the target audience
     4. Delaying communication until after the changes are implemented

    1. Tape drive
    2. External hard drive
    3. Network-attached storage (NAS)

    1. Differential backup
    2. Incremental backup
    3. Synthetic backup

    1. Grandfather-father-son

    1. Incremental backup
    2. Differential backup
    3. Snapshot backup
    4. Full backup

    1. Mirroring

    1. Cloud-based backup

9. Which workstation backup method captures an exact copy of the workstation’s operating system, applications, and data, allowing for quick restoration to a functional state?

    1. Image backup
