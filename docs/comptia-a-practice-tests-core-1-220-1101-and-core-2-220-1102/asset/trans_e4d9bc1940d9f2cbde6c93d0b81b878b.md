

# 练习题

### 第 14 题
正确答案是 **C**。`Rapid elasticity`（快速弹性）将允许玩具公司根据需求即时增加和减少云资源。所有其他答案均不正确。`Clustering`（集群）意味着两台服务器共享同一个仲裁磁盘，其中一台通常处于活动状态，另一台处于被动状态，即处于待机状态，等待活动服务器故障以便接管。`Shared resources`（共享资源）意味着云提供商拥有一个资源池，可以即时分配给不同的公司。它们不为任何特定个人保留。`Metered utilization`（计量利用）意味着 `CSP`（云服务提供商）将为客户生成一个仪表板，以便他们监控资源（如存储、`CPU` 核心和带宽）的成本和消耗。

### 第 15 题
正确答案是 **A**。公司可以在自己的网络上托管 `private cloud`（私有云），确保即使互联网中断，云数据仍然可用。所有其他答案均不正确。`community cloud`（社区云）允许一个或多个实体共享存储成本和资源。它由 `CSP` 维护并通过互联网访问。对于 `SaaS`（软件即服务），公司开发一个由其他公司租用并通过互联网访问的应用程序。`public cloud`（公有云）使用 `multi-tenant`（多租户）基础设施，通过互联网访问公有云。如果没有互联网连接，这三种方式都无法访问云数据。

### 第 16 题
正确答案是 **B**。`Virtual Desktop Infrastructure (VDI)`（虚拟桌面基础设施）提供桌面。与此相关的云服务是 `Desktop as a Service (DaaS)`（桌面即服务），其中 `CSP` 提供 `VDI`（即提供桌面）。所有其他答案均不正确。`Software as a Service (SaaS)`（软件即服务）是指供应商已经创建了应用程序（例如 `Office 365`、`Salesforce` 或 `GoldMine`），您以其默认格式使用它。对于 `Platform as a Service (PaaS)`（平台即服务），`Cloud Service Provider (CSP)`（云服务提供商）提供一个应用程序，以便公司提供其自己的定制应用程序，例如 `MySQL`、`PHP`、`Azure`、`Oracle Database` 和 `Google App Engine` 等。`Infrastructure as a Service (IaaS)`（基础设施即服务）是一种服务类型，其中 `CSP` 提供硬件，如服务器、计算机、交换机和防火墙。然后客户安装软件并对其进行配置和修补。

### 第 17 题
正确答案是 **B**。`private cloud`（私有云）模型称为 `single-tenant`（单租户），因为该云中仅托管一个实体。它也可以托管在公司的基础设施上。所有其他答案均不正确。在 `hybrid cloud`（混合云）中，公司拥有本地环境以及云环境。`community cloud`（社区云）托管来自同一行业的多家共享资源的公司。`Public cloud`（公有云）模型称为 `multi-tenant`（多租户），因为 `CSP` 在同一服务器上托管许多不同的公司。

### 第 18 题
正确答案是 **A** 和 **D**。`Software as a Service (SaaS)`（软件即服务）是一种云服务类型，公司开发应用程序并以 `pay-as-you-go`（按需付费）模式出租。您的员工可以通过 Web 浏览器访问该应用程序。`Office 365` 提供内置的电子邮件解决方案，`Spotify` 是一个音乐平台。所有其他答案均不正确。`Azure developer tools`（Azure 开发工具）是 `Platform as a Service (PaaS)`（平台即服务）的一个示例，因为这些工具为您提供了一个开发环境，您可以在其中构建自己的移动应用程序。`Home Depot` 是一家销售 DIY 产品的实体店。

### 第 19 题
正确答案是 **A**。`Virtual Desktop Infrastructure (VDI)`（虚拟桌面基础设施）允许将单独的虚拟桌面分配给每位顾问。`VDI` 使用具有相同配置的虚拟桌面池，从而保持一致的桌面。由于数据处理是在虚拟桌面上完成的，因此数据可防止被盗。这使其具有安全性。顾问只需要一台运行 `thin client`（瘦客户端）（即仅使用鼠标点击和键盘敲击）的低规格机器即可访问它。所有其他答案均不正确。`SaaS` 是一种云服务，公司开发应用程序由其他公司租用并通过互联网访问。公司无法完全控制桌面。`Virtual Private Network (VPN)`（虚拟专用网络）是一种在互联网上创建隧道的解决方案；它不提供桌面。`Remote Desktop Protocol (RDP)`（远程桌面协议）是微软提供的一种解决方案，用于为管理员提供到 `Windows` 桌面或服务器的远程连接。

### 第 20 题
正确答案是 **D**。`File synchronization`（文件同步）是云存储的一项自动化优势，允许在不同设备（如智能手机和平板电脑）之间共享文件。所有其他答案均不正确。多个用户可以同时访问内容。`Resource exhaustion`（资源耗尽）意味着计算机资源（如 `CPU` 核心、`RAM` 或磁盘空间）即将耗尽。`Dynamic resource allocation`（动态资源分配）意味着可根据需要为主机分配资源；这与云存储无关。`File sharing`（文件共享）不是自动化过程；通过映射驱动器访问文件。

### 第 21 题
正确答案是 **B**。虚拟桌面位于虚拟主机上，如果没有网络连接，则无法访问桌面。所有其他答案均不正确。在 `VDI` 环境中，没有任何内容复制到本地桌面。`Snapshots`（快照）是恢复来宾计算机的一种更快方法。`Citrix` 连接非常快，因为它是 `thin client`（瘦客户端），意味着它仅使用鼠标点击和键盘敲击；这是一个优势。由云提供商提供灾难恢复也是一个优势。

### 第 22 题
正确答案是 **D**。`Infrastructure as a Service (IaaS)`（基础设施即服务）提供硬件，以便公司将所有 10 台服务器和 50 台桌面迁移到云中，尽管他们仍需安装操作系统并进行配置和修补。所有其他答案均不正确。`Platform as a Service (PaaS)`（平台即服务）为开发人员提供创建自己定制软件和移动应用程序的工具。`Software as a Service (SaaS)`（软件即服务）提供现成的软件（例如 `M365`）或通用应用程序，如 `GoldMine` 和 `Salesforce`。`Monitoring as a Service (MaaS)`（监控即服务）允许云提供商持续监控您的网络和应用程序。对于给定场景中描述的迁移，最后这三项服务均不合适。

### 第 23 题
正确答案是 **B**。`Rapid elasticity`（快速弹性）支持根据需求即时增加或减少云资源。所有其他答案均不正确。`Rapid deployment`（快速部署）描述了快速弹性，但作为一个概念并不存在于本考试中。`load balancer`（负载均衡器）控制对 Web 服务器阵列的访问，以给客户提供更快的浏览体验。`Metered utilization`（计量利用）意味着 `CSP` 将为客户生成一个仪表板，以便他们监控存储、`CPU` 核心和带宽等资源的消耗。

## 4.2 总结客户端虚拟化的各个方面

### 第 1 题
正确答案是 **A**。`Type 1 hypervisor`（1型管理程序）运行在 `bare-metal`（裸金属）虚拟平台上。这意味着没有操作系统。示例包括 `Microsoft Hyper-V`、`VMware ESX Server` 和 `Citrix XenServer`。所有其他答案均不正确。`Type 2 hypervisors`（2型管理程序）运行在软件上（例如 `Windows 10`）。不存在 `Type 3` 或 `Type 4 hypervisors`。

### 第 2 题
正确答案是 **A**。可以创建一个包含额外 `RAM` 和 `CPU` 核心的 `resource pool`（资源池），并将其分配给数据库资源池，以便数据库服务器能按场景描述利用它们。所有其他答案均不正确。`System sprawl`（系统蔓延）意味着虚拟环境中的服务器消耗超过了主机资源。`Network segmentation`（网络分段）仅划分网络；不管理资源。`Metered utilization`（计量利用）被云用于为额外资源的消耗收费。
