

# 问题 84-93

## 84. 你正在为一个小型办公室设置一个新的无线网络。哪种无线加密方法提供最高级别的安全性？

1. `Wired Equivalent Privacy (WEP)`（有线等效隐私）
2. `Wi-Fi Protected Access (WPA)`（Wi-Fi 保护访问）
3. `Wi-Fi Protected Access 2 (WPA2)`（Wi-Fi 保护访问 2）
4. `Wi-Fi Protected Setup (WPS)`（Wi-Fi 保护设置）

## 85. 客户的计算机在启动时显示“未找到可启动设备”错误。你应该首先检查以下哪项？

1. `Boot sequence in BIOS`（BIOS 中的启动顺序）
2. `RAM modules`（内存模块）
3. `Graphics card drivers`（显卡驱动程序）
4. `Internet connectivity`（互联网连接）

## 86. 用户的智能手机无法连接到公司的 Wi-Fi 网络。其他设备连接正常。你应该首先检查什么？

1. `Bluetooth settings`（蓝牙设置）
2. `Network password`（网络密码）
3. `Cellular data usage`（蜂窝数据使用量）
4. `App updates`（应用更新）

## 87. 你正在 Microsoft Outlook 中为用户设置一个新的电子邮件账户。如果你希望电子邮件可从多台设备访问，并在它们之间保持邮件同步，应该使用哪种协议？

3. `Internet Message Access Protocol (IMAP)`（互联网消息访问协议）
4. `Hypertext Transfer Protocol (HTTP)`（超文本传输协议）

# 解答

## 1.1 给定场景，安装和配置笔记本硬件和组件

### 1. 正确答案是 `A`。生物识别读取器应仅为该设备的用户在每台笔记本或台式机上进行设置。在会计部门，每台设备应仅有一人拥有访问权限。所有其他答案均不正确。会计部门的某些用户可能处理更敏感的数据，因此建议不要让所有人都能访问他们的笔记本/台式机。其他部门的员工不应被允许访问任何会计部门的设备。访客是来自其他公司的人员，不应被授予访问任何公司资源的权限。

### 2. 正确答案是 `B`。`RAM` 易失性，你需要佩戴静电放电带以保护 `RAM` 免受静电影响。所有其他答案均不正确。`DDR RAM` 用于台式机，而 `SODIMM` 用于笔记本电脑。只有在遇到电源问题时才会检查电源电压。操作系统更新与 `RAM` 升级无关。

### 3. 正确答案是 `D`。当笔记本在工作中使用时，电源线很可能插在电源插座上并从市电取电。因此，此场景中问题最可能的来源是电池。所有其他答案均不正确。如果设备在插入市电时工作正常，问题不太可能是电源适配器。如果操作系统损坏，笔记本仍会通电但显示蓝屏死机。如果系统风扇作为辅助气流的冷却装置，其故障会导致计算机过热并崩溃，而不是无法启动。

### 4. 正确答案是 `D`。`Small Outline Dual In-Line Memory Module (SODIMM)`（小型双列直插内存模块）体积更小、更薄，以便安装在空间受限的笔记本电脑中。所有其他答案均不正确。`Dual In-Line Memory Module (DIMM)`（双列直插内存模块）通常称为 `RAM` 条，尺寸约为 `SODIMM` 的两倍，用于台式计算机、工作站和服务器。`Double Data Rate 3 (DDR3) RAM`（双倍数据率 3 内存）比笔记本电脑常用的 `SODIMM` 更大，尽管现在也有 `SODIMM` 版本。`Synchronous Dynamic Random Access Memory (SDRAM)`（同步动态随机存取存储器）比 `SODIMM` 更大，用于台式计算机。

### 5. 正确答案是 `B`、`C`、`D` 和 `E`。将 `Solid-State Drive (SSD)`（固态硬盘）安装到笔记本电脑时，必须先关闭系统，然后断开电源线并取出电池。你必须通过佩戴 `Electrostatic Discharge (ESD)`（静电放电）腕带来为自己接地，以保护组件免受身体静电的影响。其余答案选项不正确。清理桌面虽好，但不是安全预防措施。

### 6. 正确答案是 `B` 和 `C`。iPhone 10 使用 `Touch ID`（触控 ID），iPhone 11 使用 `Face ID`（面容 ID）。所有其他答案均不正确。iPhone 无法使用指纹或静脉 ID，后者是掌纹扫描的另一种叫法。

### 7. 正确答案是 `C`。当电池寿命终结时，它将无法充满电，也无法长时间保持电量。它也会有过热的倾向。所有其他答案均不正确。数字化屏是手机前面用于触摸屏的玻璃，即使损坏也不会导致手机发热。如果数据线故障，将无法充电，但手机也不会发热。当 iPhone 电池设置为低电量模式时，耗电量减少，手机因此应更凉爽。

### 8. 正确答案是 `B`。只有当 `DHCP` 客户端无法从 `DHCP` 服务器获取 IP 地址时，才会获得 `Automatic Private IP Address (APIPA)`（自动专用 IP 地址）。这可能是由于联系 `DHCP` 服务器的网络问题，或服务器 IP 地址耗尽所致。所有其他答案均不正确。`DNS` 用于主机名到 IP 地址的名称解析。`NETBIOS` 是一种遗留的 Microsoft 名称解析协议。如果他们使用的是静态 IP 地址，则 `DHCP Enabled`（已启用 DHCP）将设置为 No。

### 9. 所有答案选项均正确。第一阶段是对 `HDD` 进行完整备份，以防万一出现问题。此后，你将移除不打算迁移的任何冗余数据，调整数据分区大小使其小于 `SSD` 的大小，克隆旧的 `HDD` 分区，关闭笔记本电脑并移除旧的 `HDD`，安装并初始化 `SSD`，最后将克隆的数据恢复到 `SSD` 上。
