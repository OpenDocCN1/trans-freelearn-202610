## 2.4 总结网络主机提供的服务

**1.** 正确答案是 **C**。`DHCP`（动态主机配置协议）服务器为每个主机分配 IP 地址，应首先检查此项。所有其他答案均不正确。域控制器对主机进行身份验证。`DNS` 服务器提供名称解析，如果无法访问网站，则可能是 DNS 问题。邮件服务器为用户提供电子邮件访问。

**2.** 正确答案是 **D**。当您有网络连接但无法访问任何网站时，意味着您无法访问 `DNS` 服务器。所有其他答案均不正确。如果您有互联网连接，则登录已成功。如果您有互联网连接，则 IP 地址有效。无需检查 Web 服务器位置，因为它不会改变。

**3.** 正确答案是 **B**。代理服务器可以进行网页缓存。所有其他答案均不正确。文件服务器存储文档。`UTM` 防火墙可提供内容过滤、URL 过滤和恶意软件检查。Web 服务器托管网站，但无法缓存页面。

**4.** 正确答案是 **C**。`SCADA` 网络是一种工业控制系统，可用于石油或天然气的生产。所有其他答案均不正确。不存在所谓的生产网络。局域网不用于石油或天然气生产，而是托管许多用户和设备。`MAN`（城域网）是城市内的网络，供警察、救护车或消防部门使用。

**5.** 正确答案是 **A** 和 **C**。`IoT` 设备需要访问互联网，通常归类为家庭自动化。许多家庭使用 Alexa 查询事实或播放音乐。智能电表可以告诉您用电量，同时更新您的能源供应商。所有其他答案均不正确。闹钟和耳机都不需要互联网访问。

**6.** 正确答案是 **A**、**C** 和 **D**。垃圾邮件网关使用 `SPF`、`DKIM` 和 `DMARC` 防止垃圾邮件进入您的网络。它还使用 `DLP` 防止 `PII` 和其他敏感信息离开您的网络，并过滤发往用户邮箱的传入邮件。然而，组织绝不会通过垃圾邮件网关发送垃圾邮件。

**7.** 正确答案是 **B**。负载均衡器可以处理大量 Web 流量并将其路由到利用率最低的主机。安装一个负载均衡器可确保所有 Web 服务器得到高效利用。所有其他答案均不正确。集群是两台共享仲裁磁盘以提供高可用性的服务器。代理服务器过滤出站流量并缓存网页。`DNS` 服务器提供主机名到 IP 地址的名称解析。

**8.** 正确答案是 **D**。邮件服务器使用 `SMTP`（简单邮件传输协议）通过 `端口 25` 传输电子邮件。所有其他答案均不正确。`DNS` 服务器使用 `端口 53`。`DHCP` 服务器使用 `端口 67/68`。代理服务器使用 `端口 8080`。

**9.** 正确答案是 **B**。Web 服务器托管网站，每个网站都有一个主页，客户可通过主页访问应用程序以及产品或服务的信息。所有其他答案均不正确。文件服务器是托管数据的内部服务。邮件服务器包含邮箱。`RADIUS` 服务器（也称为 `AAA` 服务器）为请求者提供身份验证。
