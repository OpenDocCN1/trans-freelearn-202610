## 10.2 解释基本的变更管理最佳实践

1.  正确答案是 **C**。详细记录变更是基本的变更管理最佳实践，因为它有助于保留所有修改的记录，如果出现问题，更容易跟踪和排查故障。选项 A 不正确，因为在没有适当规划的情况下实施变更可能导致意外后果和系统中断。选项 B 不正确，因为仅在变更实施后沟通变更会导致用户困惑和抵触。选项 D 不正确，因为忽略用户反馈可能导致忽视成功实施变更所需的重要见解和需求。

2.  正确答案是 **C**。评估和管理风险是变更管理的关键要素。通过识别潜在风险并实施适当的缓解策略，组织可以确保在变更实施期间实现更平稳的过渡。选项 A 不正确，因为用户参与在变更管理中至关重要，可收集反馈、解决顾虑并确保用户接受。选项 B 不正确，因为与相关方进行有效沟通对于管理预期并确保其理解和支持至关重要。选项 D 不正确，因为匆忙实施过程可能导致错误并忽略关键步骤，增加失败的可能性。

3.  正确答案是 **B**。提供清晰的沟通和培训是管理变更实施期间用户抵触情绪的推荐做法。通过让用户了解变更及其益处，并提供充分的培训，组织可以解决顾虑并增加用户接受度。选项 A 不正确，因为忽视用户顾虑会导致抵触情绪加剧，并对变更实施的成功产生负面影响。选项 C 不正确，因为限制用户访问系统文档会阻碍他们有效理解变更并适应变更。选项 D 不正确，因为在没有事先通知的情况下突然实施变更会导致用户困惑和抵触。

4.  正确答案是 **C**。**变更咨询委员会 (CAB)** 的目的是评估和确定拟议变更的优先级。CAB 确保变更与组织目标一致，评估其影响，并决定其实施优先级。选项 A 不正确，因为在不审查的情况下批准所有变更可能导致不受控制的修改和潜在中断。选项 B 不正确，因为虽然 CAB 可能监控变更实施的进度，但其主要目的是评估和确定拟议变更的优先级。选项 D 不正确，因为用户参与在变更过程中很重要，可收集反馈并确保成功采纳。

5.  正确答案是 **C**。暂时性服务中断是与变更管理相关的常见风险。实施变更有时会导致系统停机或中断，在过渡期间影响用户生产力。选项 A 不正确，因为提高系统性能是变更管理的潜在收益而非风险。选项 B 不正确，因为提高用户满意度是成功变更管理的预期结果。选项 D 不正确，因为加强安全措施通常是变更管理工作的积极成果。
