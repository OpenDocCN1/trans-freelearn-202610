

## 10.2 解释基本的变更管理最佳实践

1. 一家公司正在更新操作程序并将采用变更管理。以下哪项最能描述基本的变更管理最佳实践？

    1. 在没有适当规划的情况下实施变更
    2. 仅在变更实施后才进行沟通
    3. 详细记录变更
    4. 忽略用户反馈

2. 以下哪项是变更管理的关键要素？

    1. 将用户参与度降至最低
    2. 避免与利益相关者沟通
    3. 评估和管理风险
    4. 仓促进行实施过程

3. 以下哪项是在变更实施期间管理用户抵触情绪的推荐做法？

    1. 忽视用户顾虑
    2. 提供清晰的沟通和培训
    3. 限制用户访问系统文档
    4. 在没有事先通知的情况下突然实施变更

4. 以下哪项最能描述变更咨询委员会 (CAB) 的目的？

    1. 不经审查即批准所有变更
    2. 监控变更实施的进度
    3. 评估并确定建议变更的优先级
    4. 限制用户参与变更过程

5. 以下哪项是与变更管理相关的常见风险？

    1. 系统性能提升
    2. 用户满意度增加
    3. 临时服务中断
    4. 安全措施增强

6. 以下哪项是软件部署变更管理最佳实践的示例？

    1. 跳过测试阶段
    2. 执行定期备份
    3. 在高峰时段实施变更
    4. 避免用户沟通

7. 以下哪项是硬件更换变更管理最佳实践的示例？

    1. 忽略用户反馈
    2. 进行彻底的资产清查评估
    3. 在未测试的情况下实施变更
    4. 将利益相关者排除在流程之外

8. 以下哪项最能描述变更管理中回滚计划的目的？

    1. 防止实施任何变更
    2. 记录实施变更的原因
    3. 识别潜在问题及其解决方案
    4. 在变更过程中排除用户反馈

9. 以下哪项是管理变更相关风险的推荐做法？

    1. 完全避免风险评估
    2. 在没有备选计划的情况下实施变更
    3. 进行定期风险评估
    4. 忽略风险缓解策略

10. 在变更管理期间向用户传达变更时，以下哪项是关键考量因素？

     1. 提供模糊和笼统的信息
     2. 过分强调变更的负面影响
     3. 根据目标受众定制信息
     4. 推迟沟通直到变更实施后

## 10.3 给定场景，实施工作站备份和恢复方法

1. 哪种工作站备份方法涉及在特定时间点创建所有用户数据和设置的副本？

    1. 完全备份
    2. 差异备份
    3. 增量备份
    4. 选择性备份

2. 哪种工作站恢复方法涉及使用整个工作站硬盘驱动器的备份将系统恢复到其之前的状态？

    1. 裸机恢复
    2. 基于云的恢复
    3. 文件级恢复
    4. 增量恢复

3. 哪种备份存储介质提供最快的传输速率，但也是工作站备份成本最高的选项？

    1. 磁带驱动器
    2. 外置硬盘驱动器
    3. 网络附属存储 (NAS)
    4. 云存储

4. 哪种工作站备份方法仅备份自上次备份以来发生变化的数据，无论上次是完全备份还是增量备份？

    1. 差异备份
    2. 增量备份
    3. 综合备份
    4. 持续备份

5. 哪种备份轮换方案涉及使用一组备份介质并按日循环使用它们，当介质集满时覆盖最旧的备份？

    1. 祖父-父亲-儿子
    2. 汉诺塔
    3. 备份到磁盘
    4. 备份到磁带

6. 与其他备份方法相比，哪种工作站备份方法提供最快的恢复时间？

    1. 增量备份
    2. 差异备份
    3. 快照备份
    4. 完全备份

7. 哪种备份方法通过在不同备份介质上创建多个备份副本来确保数据冗余？

    1. 镜像
    2. 复制
    3. 归档
    4. 版本控制

8. 哪种备份方法通过在不同地理位置存储多个备份副本提供最高级别的数据保护？

    1. 基于云的备份
    2. 磁带备份
    3. 磁盘到磁盘备份
    4. 异地备份

9. 哪种工作站备份方法捕获工作站操作系统、应用程序和数据的精确副本，允许快速恢复到功能状态？

    1. 映像备份
    2. 文件级备份
    3. 增量备份
    4. 差异备份

10. 哪种工作站备份方法涉及在数据发生变化时实时自动备份，确保在发生故障时数据丢失最小？

     1. 持续备份
     2. 同步备份
     3. 手动备份
     4. 快照备份

## 10.4 给定场景，使用常见安全程序

1. 以下哪项是在计算机硬件上工作时的常见安全程序？

    1. 佩戴 ESD 防静电腕带
    2. 在不关闭电源的情况下断开电源
    3. 用裸手触摸电路板
    4. 站在潮湿的表面上

2. 在操作计算机设备时，应采取以下哪项安全预防措施？

    1. 使用压缩空气清理风扇和散热器上的碎屑
    2. 使用磁性螺丝刀固定组件
    3. 将液体存放在计算机附近以便随时取用
    4. 将计算机放置在不稳定的表面上

3. 处理计算机线缆时应遵循以下哪项安全措施？

    1. 从远处拉扯线缆以断开连接
    2. 尖锐地弯曲线缆以适应狭窄空间
    3. 使用扎带或夹子固定线缆
    4. 让线缆松散且纠缠在一起

4. 打开计算机机箱前应采取什么安全预防措施？

    1. 确保计算机已关闭并拔掉电源插头
    2. 戴手套以防止静电
    3. 使用金属工具打开机箱
    4. 将机箱放在柔软、有缓冲的表面上

5. 在操作计算机硬件时应做些什么以防止受伤？

    1. 遵循人体工程学实践
    2. 佩戴厚重的首饰和配饰
    3. 如果没有其他工具可用，则使用损坏的工具
    4. 跳过休息，长时间连续工作不休息

6. 清洁计算机内部时应采取哪项安全措施？

    1. 使用防静电吸尘器
    2. 将清洁溶液直接喷洒在组件上
    3. 在计算机通电时进行清洁
    4. 使用干布擦拭主板

7. 处置旧计算机设备时应采取哪项安全预防措施？

    1. 根据当地法规回收设备
    2. 在没有防护装备的情况下拆卸设备
    3. 将设备扔进普通生活垃圾
    4. 将设备存放在潮湿环境中

8. 使用高压设备时应遵循以下哪项安全预防措施？

    1. 佩戴绝缘手套和安全眼镜
    2. 独自工作以减少干扰
    3. 在高处作业时使用金属梯子
