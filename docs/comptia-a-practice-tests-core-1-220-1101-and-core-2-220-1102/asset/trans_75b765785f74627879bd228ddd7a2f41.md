## 2.6 比较和对比常见网络配置概念

1.  正确答案是 **A**。财务总监最有可能拥有 `APIPA` 地址，这就是他们无法连接到其他人的原因。检查 `DHCP` 服务器是否已分配 IP 地址。所有其他答案均不正确。简单网络管理协议 (`SNMP`) 监控网络设备的状态并创建报告。`RADIUS` 是控制网络访问的 AAA 服务器，但管理员已经在网络上。`DNS` 服务器将主机名转换为 IP 地址。

2.  正确答案是 **B**。上述地址是 `IPv6` 地址，需要 `AAA` 记录。所有其他答案均不正确。`A` 记录用于 `IPv4` 主机。`MX` 记录由邮件服务器使用。`TXT` 记录用于任何自由格式的记录，如 `SPF` 记录。

3.  正确答案是 **C**。Microsoft 动态主机配置协议 (`DHCP`) 服务器的默认租约期限为 8 天。所有其他答案均不正确。

4.  正确答案是 **A**。`MX` 记录用于邮件服务器。所有其他答案均不正确。`A` 记录用于 `IPv4` 主机。`AAAA` 记录用于 `IPv6` 主机。`SRV` 记录用于查找域控制器等服务。

5.  正确答案是 **C**。局域网 (`LAN`) 是内部安全网络。所有其他答案均不正确。广域网 (`WAN`) 跨越多个地理位置。城域网 (`MAN`) 由城市中的警察、救护车和消防部门使用。`CAN` 指校园区域网络，用于学术机构。
