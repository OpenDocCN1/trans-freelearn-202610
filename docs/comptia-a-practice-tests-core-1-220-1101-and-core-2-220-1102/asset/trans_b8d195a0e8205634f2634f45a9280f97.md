

# 第 6 章：网络基础

## 练习题 39-50

### 39. 正确答案是 **C**。与其他设备共享设备的互联网连接。
移动设备上的热点功能允许用户将其设备的蜂窝数据网络连接共享给其他设备，例如智能手机、平板电脑或笔记本电脑。这使得这些设备能够使用移动设备的数据连接访问互联网。热点功能并不一定意味着创建一个安全的网络。热点的使用与偏远地区的高速数据连接没有特定关系。热点的使用独立于自动连接到公共 Wi-Fi 网络。

### 40. 正确答案是 **C**。改善设备的通话和数据连接质量。
移动设备上的首选漫游列表 (PRL) 更新涉及更新首选网络及其相关设置的列表。这有助于改善设备的通话和数据连接质量，确保其在漫游时连接到最合适的网络。PRL 更新与国际漫游没有特定关系。网络安全协议独立于 PRL 更新。PRL 更新不会直接优化漫游时的电池使用；这通常由设备上的其他电源管理功能处理。

### 41. 正确答案是 **D**。公网地址分配给连接到互联网的设备。
这些地址在全球范围内唯一且可在互联网上路由，允许设备跨不同网络相互通信。

### 42. 正确答案是 **A**。USB 2.0 支持最高 480 兆比特每秒 (Mbps) 的数据传输速率。
它通常用于将各种外设（如键盘、鼠标、打印机和外部存储设备）连接到计算机。1 Gbps、5 Gbps 和 10 Gbps 均代表千兆以太网的数据传输速率。

### 43. 正确答案是 **C**。USB 3.0，也称为 USB 3.1 Gen 1，支持最高 5 吉比特每秒 (Gbps) 的数据传输速率。
1 Gbps、5 Gbps 和 10 Gbps 均代表千兆以太网的数据传输速率。

### 44. 正确答案是 **A**。LAN 是覆盖有限区域的网络，通常在一栋建筑或一个园区内。
它允许在该局域网内共享资源和设备间通信。WAN 是覆盖大地理区域的网络，例如互联网。PAN 是用于连接近距离个人设备的网络，例如蓝牙。MAN 是城市内的警察、救护车或消防队。（译者注：原文此处 MAN 解释为 Metropolitan Area Network 的恶搞/错误解释，译文保留原意）

### 45. 正确答案是 **B**。WAN 是跨越大地理区域并连接多个 LAN 的网络。
它实现了不同位置（如不同城市或国家的办公室）之间的通信和数据传输。LAN 是局限于小地理区域的网络。PAN 是用于连接近距离个人设备的网络，例如蓝牙。MAN 是城市内的警察、救护车或消防队。

### 46. 正确答案是 **B**。快速以太网，也称为 `100BASE-TX`，支持最高 100 兆比特每秒 (Mbps) 的数据传输速率。
它是一种常见的网络标准，用于住宅和中小型企业环境中的以太网连接。`10BASE-T` 是一种较旧的以太网标准，支持最高 10 Mbps 的数据传输速率。`1000BASE-T`（千兆以太网）支持最高 1 Gbps 的数据传输速率。`10GBASE-T`（10 吉比特以太网）支持最高 10 Gbps 的数据传输速率。

### 47. 正确答案是 **D**。10 吉比特以太网 (`10GBASE-T`)。
10 吉比特以太网支持最高 10 吉比特每秒 (Gbps) 的数据传输速率。它是一种高速以太网标准，用于企业网络和数据中心，为要求苛刻的应用提供更快的连接和更大的网络带宽。`10BASE-T` 是一种旧的以太网标准，支持最高 10 Mbps 的数据传输速率。`100BASE-TX` 支持最高 100 Mbps 的数据传输速率。`1000BASE-T`（千兆以太网）支持最高 1 Gbps 的数据传输速率。

### 48. 正确答案是 **B**。`Cat 5` 线缆支持最高 100 Mbps 的数据传输速率。
10 Mbps 代表较旧的以太网标准（如 `10BASE-T`）的数据传输速率。`Cat 5e` 线缆支持最高 1 吉比特每秒 (Gbps) 的数据传输速率。10 Gbps 超出了 `Cat 5` 线缆的能力范围，由较新的标准（如 `Cat 6` 和 `Cat 6a`）支持。

### 49. 正确答案是 **A**。`A 类` 私有地址范围是 `10.0.0.0 – 10.255.255.255`，它只能在内部使用，因为这些数据包会被互联网上的路由器丢弃。
`179.16.0.0 – 179.30.255.255` 和 `179.16.0.0 – 179.30.255.255` 是公网 IP 地址。`169.254.0.0 – 169.254.255.255` 是自动专用 IP 寻址 (APIPA)，它是网络协议（如 IPv4）的一项功能，允许设备在 DHCP（动态主机配置协议）服务器不可用时自动为自己分配 IP 地址。

### 50. 正确答案是 **C**。使用 APIPA 的设备将从范围 `169.254.0.0 - 169.254.255.255` 中为自己分配一个 IP 地址，确保在本地网络内的临时连接。
选项 A 不正确，因为 APIPA 地址不可全球路由。它表明计算机无法从 DHCP 获取 IP 地址。错误答案——APIPA 地址不可全球路由，也不分配公网 IP 地址。APIPA 用于单个网络内部，而非用于不同私有网络之间的通信。

# 第 7 章：操作系统

## 7.1 识别 Microsoft Windows 版本的基本功能

### 1. 正确答案是 **D**。BitLocker 驱动器加密要求在启动 Windows 操作系统之前输入额外的 BitLocker 密码。
如果成功输入，随后将向用户显示常规登录提示。BIOS 密码需要特殊的按键序列，例如 `Ctrl + D`，其目的是防止用户在启动时进入 BIOS/UEFI。Windows 隐私和安全不会在操作系统启动前要求提示。Windows 辅助功能通常用于配置 Windows 设置，以帮助有听力或视力障碍的用户。

### 2. 正确答案是 **A, D**。Windows 10 Home 面向个人使用，不提供面向企业/商业用户的支持功能。
ChromeOS 是一个简单易用的操作系统，不允许加入域。所有 Windows 专业版和企业版均支持加入域功能。

### 3. 正确答案是 **A, D**。Windows 10 专业版和企业版面向商业用途，支持包括安全功能在内的额外功能。
因此它们支持 BitLocker。旧版 Windows 需要企业版（或 Windows 7 旗舰版）许可证才能访问高级安全功能。Windows 家庭版无法访问 BitLocker。macOS 提供文件保险箱作为 Windows BitLocker 的替代方案。

### 4. 正确答案是 **A**。假设不存在兼容性问题，就地升级将以最少的管理工作量迁移所有用户设置和应用程序。
全新安装不会迁移设置和应用程序。用户设置需要单独备份，应用程序需要重新安装。

### 5. 正确答案是 **B**。由于经理使用的是个人电脑，极有可能该系统是从零售店购买的，默认的 Windows 操作系统版本将是家庭版。
BitLocker 驱动器加密至少需要 Windows 专业版。仅有 2GB 内存不会阻止启用 BitLocker。硬盘大小只有在没有足够空间创建一个小的未加密分区（100MB）时才会成为问题。BitLocker 在 Windows 的 32 位和 64 位版本上均受支持。
