**6. 一家减压床垫制造商拥有一个用于测试单元运动的遗留应用程序。它需要在 `Windows 98` 操作系统上运行，这是一个不再受支持的遗留系统。该公司正在将所有服务器更新为 `Server 2022`，桌面更新为 `Windows 11`，并计划外包遗留应用程序的重写工作，使其符合 `Windows 11` 要求。在此期间，制造商应该怎么做？（选择两项）**

**7. 使用 `二级地址转换 (SLAT)` 的目的是什么？**

**10. 一位大学教授每周教授 10 次计算机课程。教授希望确保在每节课结束时，有一个快速的解决方案为下一组学生设置好桌面。为此，他们计划构建一个操作系统的主镜像，以便推送部署，使所有桌面在学生注销后重置。教授应该实施以下哪种技术？（选择两项）**

**11. 以下哪项最能描述 `虚拟机蔓延`？**

**14. 公司的虚拟网络被 `流氓虚拟机` 淹没，这些虚拟机在其他 `虚拟机` 更新时未打补丁。这是一个安全风险，因为这些未受管理的设备可能被用来访问公司网络。公司现已聘请一位安全顾问来补救该情况。顾问最可能推荐以下哪项？（选择两项）**

**15. 网络管理员计划在其 `虚拟网络` 上部署另一台拥有 15 TB 内存和四路处理器的 `虚拟主机服务器`。然而，在构建 `主机服务器` 后，他们发现 `管理程序` 无法运行。以下哪项是解决此问题的最佳选择？**

**16. 为什么网络管理员在部署新 `虚拟主机服务器` 时要确保使用 `不间断电源 (UPS)`？（选择两项）**

**17. 使用 `容器虚拟化` 有什么好处？**

4.  它防止 `虚拟机逃逸`
