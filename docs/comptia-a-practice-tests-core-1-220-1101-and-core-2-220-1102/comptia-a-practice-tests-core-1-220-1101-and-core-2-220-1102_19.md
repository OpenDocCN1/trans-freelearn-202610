# 第 7 章：操作系统

## 7.1 识别 Microsoft Windows 版本的基本功能

## 7.2 给定场景，使用适当的 Microsoft 命令行工具

1. 正确答案是 **B**。`ipconfig /all` 将提供工作站网络接口的综合配置详细信息，显示 IP 地址、子网掩码、DHCP 服务器、DNS 设置等。`ping` 是一个有用的实用程序，但在这种情况下，它只会 ping 回环地址 (127.0.0.1)，不提供任何配置信息。`netstat` 将显示网络连接和监听端口。它也可用于显示以太网统计信息，但不会显示网卡配置设置。`hostname` 是一个仅显示工作站名称的命令。

2. 正确答案是 **A**。`robocopy`（可靠复制）旨在镜像大量数据。它支持复制其他属性，包括隐藏文件，并保留文件夹权限。它自 Vista 起已包含在 Windows `OS` 中。`copy` 命令并非设计为批量复制工具；它不保留权限。`xcopy` 不支持隐藏文件，也不保留文件夹权限。`cp` 命令是 Linux 命令（尽管它符合所请求的标准）。

3. 正确答案是 **D, E**。`nslookup`（名称服务器查找）用于向 DNS 服务器（即名称服务器）发送查询。问题中的输出来自 `nslookup www.google.com`。`tracert` 是 Windows 路由跟踪命令。它显示数据包转发到目标系统时的“跳数”。它可用于识别流量减慢的瓶颈。`ping` 可用于执行连接测试，但不显示跳数。`ipconfig` 用于显示网卡配置设置。`netstat` 用于显示本地计算机的网络连接和监听端口。`nbtstat`（NetBIOS 统计信息）用于显示与 NetBIOS 相关的信息。

4. 正确答案是 **C**。`RDP` 和组策略编辑器（`gpedit.msc`）都是仅包含在 Windows 专业版和企业版中的功能。该计算机并非运行 Linux，因为技术人员在安装第三方工具时会发现这一点。Windows 10 企业版将允许技术人员所需的功能。损坏的注册表不太可能在不影响用户计算机上其他服务的情况下导致这两个非常具体的问题。

5. 正确答案是 **A**。`ping` 将允许支持技术人员确定连接在何处失败。`ping` 命令可用于测试网关访问和远程（互联网）连接。`msconfig` 将显示启动过程中使用的配置。`nbtstat` 不允许技术人员测试网络上的连接。`nslookup` 如果技术人员正在排查名称解析问题将很有用，但通常会在 `ping` 之后使用。

6. 正确答案是 **C**。`nslookup` 可以将名称解析为 IP 地址（即正向查找），也可以将 IP 地址解析为名称（反向查找）。DNS 服务器需要配置指针记录（`PTR`）和反向查找区域以支持反向查找。`gpresult` 允许技术人员排查本地计算机上的组策略设置。`ipconfig` 用于显示本地网络配置设置（它不显示远程工作站配置设置）。`net user` 是一个用于管理本地用户账户的 Windows 命令。

7. 正确答案是 **A**。必须快速在多台工作站上停止 USB 访问。基于域的组策略将是推送此安全设置的最有效方法。为了立即更新，支持团队可以远程运行 `invoke-gpupdate` 或使用组策略管理控制台（`GPMC`）同时更新多台工作站，且干扰最小。实施本地安全策略更改将耗时较长。登录脚本会影响用户，因为他们都需要注销工作站并重新登录，登录脚本才会生效。可接受使用策略（`AUP`）是描述使用组织信息系统时预期行为的策略，并不能保证用户会遵守该预期行为。

8. 正确答案是 **C**。`gpresult` 将处理并输出当前的组策略设置，详细程度可由命令开关决定。`/Z` 是超详细输出（即最详细）。`ipconfig /all` 不会显示组策略设置。`netstat /e` 仅显示本地网络接口的以太网统计信息。`nslookup` 将使用 DNS 将注册名称解析为互联网协议 (IP) 地址。

9. 正确答案是 **A**。`netstat -p TCP`（`-p` 代表 protocol）允许显示当前的 TCP 或 UDP 连接。在本例中，所需的输出是 TCP 连接。请注意，开关可以组合使用。如果所需输出是连接和监听端口，则可使用 `netstat -a -p tcp`。`net use` 不支持此功能，因为它用于管理本地用户账户。`nslookup` 不用于显示连接和监听端口，而是用于 DNS 查找。`netstat -p UDP` 将仅显示 UDP 端口（而非 TCP 端口）。

10. 正确答案是 **B**。`gpresult` 将显示已部署到工作站的当前组策略。`nbtstat` 显示 NetBIOS 统计信息（而非组策略）。`nslookup` 用于查询 DNS 服务器。`gpupdate` 将处理任何新的和现有的组策略，但不会显示生成的设置。`tasklist` 是一个 Windows 命令，大致相当于 GUI 任务管理器的“进程”选项卡。

11. 正确答案是 **A**。`net use` 允许临时访问共享文件夹（在本例中，是到共享文件夹的持久驱动器映射）。选择正确的语法很重要。分配的驱动器号 `p:` 必须在 `\\server1\public` 位置之前定义。`tracert` 不用于映射驱动器。该命令的语法也不正确。`net use \\P` 将无法工作，因为语法错误。

### 13. 正确答案是 **C**。

## 7.3 给定场景，使用 Microsoft Windows 10 操作系统 (OS) 的功能和工具

### 1. 正确答案是 **A**。

`任务管理器` 的 `进程选项卡` 将显示所有正在运行的应用程序、后台进程和 Windows 进程。可以使用 `结束任务` 选项终止不需要的应用程序或进程。无法从 `任务管理器` 的 `启动` 或 `性能选项卡` 结束任务。直接编辑 `注册表` 绝不应成为结束任务的首选，因为它可能导致不可预测的结果。

### 2. 正确答案是 **D**。

蓝屏错误的原因将记录在 `事件查看器` 日志之一中，如果是硬件驱动程序问题，将在 `Windows 系统日志` 中找到。`SFC` 可用于确保 Windows 系统文件经过验证，但不会显示事件详细信息。`msconfig` 可用于排查启动过程，并可配置为在驱动程序不稳定时进入安全模式启动。`regedit` 是注册表编辑器，在本例中无用。`msinfo32`（系统信息）可作为收集配置信息的支持工具，但不会存储关于蓝屏事件的详细信息。

### 3. 正确答案是 **A**。

`任务计划程序` (`taskschd.msc`) 是配置后台任务的工具。此处可以查看已更改的任何设置。`设备管理器` (`devmgmt.msc`) 允许技术人员排查硬件故障。`任务计划程序` (`taskschd.msc`) 和 `性能监视器` (`perfmon.msc`) 可用于识别性能瓶颈。`证书管理器` (`certmgr.msc`) 用于管理本地用户和计算机证书以及受信任的证书颁发机构。

### 4. 正确答案是 **C**。

`性能监视器` 可配置为按计划运行，在一天中的特定时间捕获详细的性能数据。`计算机管理` 允许技术人员在本地或远程工作站上使用多种管理工具（用户和组管理服务）。`事件查看器` 日志可用于识别出错的应用程序或驱动程序。`任务管理器` 实时显示事件，需要支持技术人员交互式地监控计算机（不如 `性能监视器` 方便）。

### 5. 正确答案是 **A**。

`系统信息` (`msinfo32.exe`) 将显示硬件、软件、驱动程序等的综合清单。`资源监视器` (`resmon.exe`) 实时显示系统和网络性能数据。`系统配置` (`msconfig.exe`) 允许配置启动过程。`注册表编辑器` (`regedit.exe`) 不是查找此信息最简单的工具。

### 6. 正确答案是 **C, E**。

`磁盘清理` 将识别不需要的可删除文件，通过对硬盘进行碎片整理，技术人员将针对大文件优化文件片段。碎片整理实际上会移动数据，使大文件占用驱动器表面上连续的簇（这对 SSD 驱动器不是必需的）。无需在安全模式下启动计算机，因为系统并不不稳定，只是性能不足。当配置更改或新驱动程序需要时，可能需要重启计算机。没有理由安装任何设备驱动程序，因为没有报告硬件驱动程序问题。

### 7. 正确答案是 **B**。

如果有未使用的可用空间，`磁盘管理` 将允许扩展磁盘。`Diskpart` 也允许扩展磁盘；但是，它在命令提示符下运行，因此不是图形化的。`设备管理器` 显示控制器和磁盘驱动器的信息，但不允许调整磁盘大小。`磁盘清理` 不允许调整磁盘分区大小。

### 8. 正确答案是 **E**。

识别性能不佳的启动应用程序并将其禁用的推荐工具是使用 `任务管理器`。使用 `系统配置 | 启动选项` 禁用启动应用程序仅在旧版 Windows 中受支持。直接编辑 `注册表项` 通常不是最佳方法，而且在这种情况下，你不知道该禁用哪些启动应用。手动禁用当前列为已启用的所有启动任务并重启以检查启动时的问题解决情况是不必要的，因为启动影响由 Windows 测量，最好遵循答案 E 中的步骤来解决。

### 9. 正确答案是 **C**。

`任务管理器` 的 `性能选项卡` 将为技术人员提供系统整体性能的实时信息，并使技术人员能够识别明显的瓶颈。`任务计划程序` 允许重新安排高负载任务，但不会显示性能数据。`Windows 内存诊断` 是一种对物理内存执行健康检查的工具（例如，确定 RAM 模块上是否有任何单元损坏）。`磁盘碎片整理程序` 可针对高磁盘延迟运行，但不会显示实际的磁盘性能信息。

### 10. 正确答案是 **A**。

`certmgr.msc` 可用于管理计算机、用户和系统账户的证书。`受信任的根证书颁发机构` 存储区填充了受信任的根证书颁发机构。此列表可以手动修改，也可以使用组策略集中修改。使用 `regedit.msc` 从存储区中删除证书不是一个好选择，因为这可能导致不可预测的结果。`设备管理器` (`devmgmt.msc`) 不允许管理笔记本电脑上的证书。`证书吊销列表` (CRL) 由证书颁发机构用于发布他们已颁发但现已泄露/不受信任的证书，这在本例中不合适。

## 7.8 解释常见操作系统类型及其用途

### 问题 1
正确答案是 **A**。技术人员必须找到一种与两个操作系统都兼容的文件系统。`FAT32` 与许多常见操作系统兼容，包括 `Linux`、`macOS` 和 `Windows`。`ext4` 用于 `Linux`。`NTFS` 和 `exFAT` 没有 `FAT32` 那样广泛的支持，某些 `Linux` 操作系统可能无法读取它们。

### 问题 2
正确答案是 **A**。生命周期结束 (`EOL`) 的操作系统不再接收来自供应商的更新或安全补丁。问题不在于不兼容的操作系统，因为它仍可在硬件平台上运行。此处提出的问题更多关乎安全性和可靠性问题；它是 32 位操作系统这一事实并不重要。供应商可能会为重要客户提供延长支持（通常要求客户为此付费）。在本例中，不提供延长支持。

### 问题 3
正确答案是 **C**。`ChromeOS` 是一种基于流行的 `Chrome` 浏览器的轻量级操作系统。存在许多极简操作系统版本的示例，例如 `Windows IoT` 和 `Linux Lite`，据传 `Apple` 正在为 iPad 测试 `macOS` 的精简版。然而，这些都不是基于浏览器界面的。

### 问题 4
正确答案是 **C**。`Windows` 为跨单一供应商操作系统标准化所有服务器、工作站和移动设备提供了最佳解决方案。`Windows Server` 提供集中式数据中心服务，`Windows 11 Enterprise` 可用于托管桌面，`Windows Mobile` 可用于手持设备。`Linux` 用于提供数据中心服务，是一个非常强大的基于服务器的平台。也有用户友好的桌面版本，如 `Ubuntu`/`Red Hat`，但这些版本不支持智能手机或平板电脑。`iOS` 是 `Apple` 用于 iPhone 和 iPad 的操作系统。`ChromeOS` 仅限桌面端。

### 问题 5
正确答案是 **D**。`Linux` 操作系统使用扩展文件系统 (`ext`)，其第一版创建于 1992 年左右，支持 `2GB` 的存储限制。`ext2` 之后是 2001 年的 `ext3`，支持最大 `16TB` 的分区大小。`ext4` 于 2008 年左右推出，支持最大 `1EB` (`1,000,000 TB`) 的分区大小。`ext4` 文件系统还支持联机碎片整理，这对于维护高效的文件访问非常重要。`FAT32` 不用作 `Linux` 的核心文件系统。它用于可移动介质，最大卷大小为 `32GB`。`ext3` 不支持联机碎片整理或所需的卷大小。`NTFS` 是 `Windows` 文件系统。





## 6. Android 操作系统概述

正确答案是 **C**。Android 是由 Google 开发的开源（即免版税）操作系统。它于 2008 年首次发布，截至 2023 年，当前版本为 13（代号 Tiramisu）。Android OS 基于 Linux 内核，并支持主流 Linux 发行版中使用的许多安全功能。iOS 是一种专有的基于 Apple 的移动操作系统，最初仅用于 Apple 硬件，具体来说是 iPhone、iPod 和 iPad 的代码库。SUSE Linux 不用于移动设备或智能手机；它主要部署在数据中心服务器上。Windows Mobile 使用的是 Windows 桌面操作系统的修改版本。

## 7.9 给定场景，在多样化的操作系统环境中执行操作系统安装和升级

### 问题 5

正确答案是 **C**。Windows 10 是第一个支持功能升级的 Windows 操作系统（Windows 11 也支持功能升级）。功能升级通常每六个月发布一次，包含额外的功能和特性。在之前的 Windows 版本中，新功能和特性是通过 Service Pack 或临时版本交付的，例如从 Windows 8.0 升级到 8.1。Windows 7 和 Windows 8.1 不支持功能升级。

### 问题 6

### 问题 7

正确答案是 **B**。当从中央服务器通过网络安装镜像时，预计网络段上的总体流量会增加。重要的是要识别网络上任何不可接受的负载。只有当网络因额外流量而不堪重负时，对用户的影响才会成为问题。DHCP 需要在构建期间一次为 30 个工作站提供 IP 地址，因此这不应给 DHCP 服务器带来任何巨大负担。只有当网络在构建过程中遇到不可接受的额外流量时，对生产工作站的影响才会成为负面问题。

## 7.11 识别 Linux 客户端/桌面操作系统的常见功能和工具

### 1. 正确答案是 **B, C**

### 2. 正确答案是 **D**

### 3. 正确答案是 **C**
