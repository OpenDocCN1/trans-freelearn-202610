# 第 1 章：移动设备

## 练习题

13. 正确答案是 **B**。当手机设置为 `power conservation mode`（省电模式）时，电池只会充至 50-60%。如果电池消耗过快，智能手机可能会进入 `low power mode`（低电量模式），此时 `GPS` 将无法工作。关闭该模式可解决该问题。其他所有答案均不正确。启用 `Bluetooth`（蓝牙）仅允许蓝牙设备连接到手机。清洁触摸屏不影响 `GPS`。`GPS` 不使用 `Wi-Fi` 设置。

14. 正确答案是 **C**。如果代理关闭 `location services`（定位服务），将阻止手机的 `GPS` 位置被广播。其他所有答案均不正确。你无法将 `location services` 设置为暂停，也无法删除它们。

15. 正确答案是 **D**。你的 iPhone 备份到 `iCloud`。其他所有答案均不正确。Microsoft 使用 `Office 365`，Google 使用 `Google Drive`。Apple 两者均不使用。`Boot Camp` 是 Apple 产品，但其用途是托管第三方操作系统。

16. 正确答案是 **A**。在 `Windows 10` 中，当 `Bluetooth`（蓝牙）开启时，磁贴会变蓝。其他所有答案均不正确。关闭时磁贴为灰色。在 `Windows 10` 中，`Bluetooth` 磁贴永远不会显示为白色或绿色。

17. 正确答案是 **D**。`Data Loss Prevention (DLP)`（数据丢失防护）可防止某人发送包含 `PII`（个人身份信息）和敏感信息的电子邮件。如果发现模式匹配，它会阻止数据。其他所有答案均不正确。`legal hold`（法律保留）可防止用户从邮箱中删除电子邮件。`MailTips`（邮件提示）会在发送电子邮件前警告你诸如选择了大型通讯组列表等事件。`firewall`（防火墙）用于阻止进入或离开公司网络的流量。

18. 正确答案是 **C**。`GSM` 手机具有可拆卸的 `SIM` 卡，可用于同一运营商的另一部手机，而 `CDMA` 手机没有 `SIM` 卡，因为运营商内置了手机。其他所有选项均不正确。

19. 正确答案是 **B**。`Preferred Roaming List (PRL)`（首选漫游列表）是存储在你手机上的数据库。当手机连接到基站时会用到它。销售人员需要安装 `PRL` 更新，以在其智能手机上启用漫游数据。其他所有答案均不正确。`firmware`（固件）更新不会更新手机上的 `PRL` 数据库。开启 `location services`（定位服务）仅会广播手机的位置。重启智能手机在这种情况下无效。

20. 正确答案是 **C**。用户需要进入 `Settings`（设置），然后是 `Mobile Data`（移动数据），以启用 `4G` 数据连接。其他所有答案均不正确。`Wi-Fi calling`（Wi-Fi 通话）仅允许你在有 Wi-Fi 互联网连接的情况下从偏远地区通话。

21. 正确答案是 **A**、**C**、**D** 和 **E**。在 14 天免费试用期后，`Google Workspace` 订阅起价为每位用户 5.75 美元，允许访问许多应用程序、至少 30 GB 存储空间，以及最多 100 用户参与的视频会议。其他所有答案均不正确。你无法创建虚拟机，且 `live.com` 电子邮件地址用于 Microsoft 产品。

22. 正确答案是 **B**。`legal hold`（法律保留）意味着邮箱没有大小限制，且任何已删除的电子邮件都会保留在清除文件夹中。这可防止接受调查的用户删除电子邮件。其他所有答案均不正确。如果他们设置每天特定时间备份，将无法捕获已从“已删除项目”文件夹中移除的任何电子邮件。`forensic toolkit`（取证工具包）用于从计算机提取数据，无法提取已从“已删除项目”容器中删除的电子邮件。`Chain of custody`（证据保管链）指对证据进行装袋、贴标签和移交给处理数据的任何人，以向法官证明这是原始证据。

23. 正确答案是 **B**、**C** 和 **D**。如果你佩戴耳机，请进入 `Zoom`，然后依次选择 `Audio Settings`（音频设置）| `Microphone`（麦克风）| `Test mic`（测试麦克风）。测试 `Bluetooth`（蓝牙）连接时，如果你佩戴耳塞，请在手机上播放音乐。如果听到音乐，则表示已连接。如果你佩戴耳机，可以进入 `Zoom`，在 `Audio Settings` 下，依次选择 `Speaker`（扬声器）| `Test speaker`（测试扬声器）。其他所有答案均不正确。`Video Settings`（视频设置）下没有测试扬声器或麦克风的选项，因为它仅处理摄像头和视频。`Bluetooth` 连接仅在你使用 `Windows 10` 笔记本电脑时显示为蓝色，而非耳塞。
