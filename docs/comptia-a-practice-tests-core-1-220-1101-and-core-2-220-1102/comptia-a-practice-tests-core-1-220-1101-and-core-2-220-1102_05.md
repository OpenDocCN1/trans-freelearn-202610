# 5 硬件与网络故障排除

## 简介

理解硬件与网络故障排除的重要性对任何 IT 专业人员都至关重要。高效的故障排除能最大限度地减少停机时间、优化系统性能并延长硬件寿命。它能提升用户体验、保障数据与安全，并建立可靠和专业的声誉。此外，精通故障排除能为职业晋升打开大门，并让你有信心应对紧急情况。在本章中，你将获得解决各种硬件和网络挑战的实用知识，使你成为动态 IT 世界中熟练的问题解决者。

### 2. 硬件 RAID 5 磁盘故障与热插拔风险

系统管理员收到来自其邮件服务器的警报，提示一块磁盘发生故障。他们登录服务器，发现只能看到五组磁盘中的四组。他们使用的是硬件 RAID 5 解决方案，因此可以热插拔更换故障磁盘。系统管理员在更换故障磁盘时会遇到什么风险（如果有）？

1.  RAID 5 具有冗余性，完全没有风险
2.  逐个拔出磁盘，查找故障磁盘的 SCSI ID
3.  查看 RAID 阵列，寻找亮红灯的磁盘
4.  如果移除了一块健康的磁盘，将会丢失所有数据

### 5. 笔记本电脑无法投影图像（选择两项）

计算机技术人员在报告厅将笔记本电脑连接到投影仪，但屏幕上未投影图像。他们返回车间拿来了已知工作正常的线缆。更换线缆后，他们收到“未找到信号源”错误。计算机技术人员接下来应该怎么做？

4.  在笔记本电脑上进入显示设置，选择多显示器，并复制这些显示器

    2. 打印机的双面打印单元未正确设置

## 5.7 给定场景，排查有线和无线网络问题

1. 你的无线网络出现问题，无法为路由器选择特定信道。导致此问题**最可能**的原因是什么？

    1. 附近设备或网络的干扰

    3. 网络配置设置不正确
    4. 路由器信号强度不足

    1. 过滤列表中输入的 MAC 地址不正确
    2. 无线路由器固件过时
    3. 邻近无线网络的干扰
    4. 无线加密协议不兼容

3. 由于 IP 地址问题，无线客户端在网络中出现连接受限或无连接的情况，应采取什么措施来解决？

    1. 释放并续订 IP 地址
    2. 更新网络适配器驱动程序
    3. 调整无线信道
    4. 刷新计算机上的 DNS 缓存

4. 以下哪项最能描述无线通信中**授权频段**的用途？

    1. 供授权用户使用的保留频谱

    3. 为实验目的临时分配的频谱
    4. 供一般用途使用的非授权频谱

    1. 信道绑定
    2. 分离无线信道，每个信道使用自己的 IP 地址范围
    3. 使用有线连接
    4. 实施服务质量 (QoS)

6. 远程访问公司网络时，哪个选项能提供到公司局域网的安全连接？

    1. 虚拟专用网络 (VPN)

    4. 防火墙保护

    1. 重新放置无线路由器位置

    3. 禁用其他无线设备
    4. 更改无线加密方式

    4. 扩大无线网络覆盖范围
