# 第 1 章：移动设备

## 简介

移动设备在工作场所大量存在，范围涵盖从笔记本电脑到平板电脑和智能手机。因此，IT 技术人员必须具备每种设备类型的工作知识，包括所用的存储以及从传统存储向现代存储迁移的方法。

此外，在您自己的职业生涯中，您可能需要为智能手机启用安全性，要求您设置多因素或生物识别认证、设置蜂窝通信和移动热点，或连接企业用户的蓝牙耳机。对于笔记本电脑咨询，无论是为工程部门订购新设备、安装新无线网卡，还是排查显示屏故障，您对笔记本电脑硬件、组件以及卡的类型和尺寸的理解对于确保您提供的支持可靠且有效至关重要。

在 CompTIA A+ Core 1 (`220-1101`) 考试中，领域 1.0 移动设备进一步细分为以下核心目标：

*   1.1 给定场景，安装和配置笔记本电脑硬件和组件
*   1.2 比较和对比移动设备的显示组件
*   1.3 给定场景，设置和配置移动设备的配件和端口
*   1.4 给定场景，配置基本的移动设备网络连接和应用程序支持

本章其余部分致力于实践。对于上述定义的每个概念，您将获得一系列问题，旨在测试您对官方认证考试指南中定义的每个核心 1 目标的知识。完成这些问题并确保理解其背后的概念后，您应该已完全准备好在 CompTIA A+ Core 1 (`220-1101`) 考试中做同样的事情。
