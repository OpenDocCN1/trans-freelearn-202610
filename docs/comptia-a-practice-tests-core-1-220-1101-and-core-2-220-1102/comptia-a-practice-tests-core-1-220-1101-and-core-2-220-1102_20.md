## 8.2 比较和对比无线安全协议和认证方法

### 1.
正确答案是 **B**。`Wi-Fi Protected Access 3 (WPA3)` 使用一种称为 `Simultaneous Authentication of Equals (SAE)`（对等实体同时认证）的安全握手过程。这取代了之前称为 `Preshared Key (PSK)`（预共享密钥）的方法。`WPA2` 使用基于 PSK 的旧安全标准。`Temporal Key Integrity Protocol (TKIP)`（临时密钥完整性协议）旨在在使用 `WPA` 和 `RC4` 加密时提高安全性。`Advanced Encryption Standard (AES)`（高级加密标准）是用于保护无线数据的默认加密强度。

### 2.
正确答案是 **C**。`Remote Authentication Dial-In User Service (RADIUS)`（远程认证拨号用户服务）也称为 `Authentication, Authorization, and Accounting (AAA)`（认证、授权和计费）服务。`RADIUS` 服务器允许 `Wi-Fi` 控制器转发来自客户端设备的认证请求。这些认证请求随后将被转发到目录服务。`WPS` 允许设备与 `Wi-Fi` 路由器配对，无需共享密钥或密码。`WEP Open` 不需要账户或密码（任何人都可以连接）。`WPA-PSK` 不使用 `Active Directory` 账户。

### 3.
正确答案是 **C**。`WPA2-AES` 提供最高级别的安全性。它使用 `AES 128-bit` 加密。`Wired Equivalent Privacy (WEP)`（有线等效保密）在 `WPA` 之前使用，现已不再使用。它已有 20 多年历史，关键在于它不安全。`WPA2-TKIP` 使用较旧的 `RC4` 加密算法。`Open Wi-Fi`（开放 Wi-Fi）网络不使用加密。

## 8.4 解释常见的社会工程学攻击、威胁和漏洞

### 1. 答案：**D**
正确答案是 **D**。当单个个体被锁定目标且该个体担任高级管理职位时，他们被视为“大鱼”。因此，`鲸钓攻击` 基于 `网络钓鱼`，但它是针对大鱼（担任高级职位的用户）的定向攻击。在这种情况下 `网络钓鱼` 不正确。选项 B 指从垃圾桶或垃圾罐中窃取可能包含有用情报的文档 (`翻垃圾桶`)。选项 C 指某人试目睹用户输入密码或 `PIN` 码 (`肩窥`)。

### 2. 答案：**C**
正确答案是 **C**。`肩窥` 很可能发生在拥挤的空间，当时攻击者可以近距离观察用户输入密码。选项 A 和 D 通常使用电子邮件链接强迫用户共享机密数据 (`网络钓鱼`/`短信钓鱼`)。选项 B 指从语音通话中获取信息 (`语音钓鱼`)。

### 3. 答案：**B**
正确答案是 **B**。由于承包商未通知就到达，这可能构成威胁。在这种情况下，他们通过穿着使其看起来像真正的支持承包商的服装来进行 `冒充`。选项 A 是指未经授权的人紧跟在有效用户后面，通过物理控制（如由 `RFID` 门禁卡控制的锁门）进入 (`尾随`)。选项 C 指从垃圾桶窃取文档 (`翻垃圾桶`)。选项 D 指放置恶意 `Wi-Fi` 接入点 (`邪恶双子`/`流氓接入点`)。

### 4. 答案：**D**
正确答案是 **D**。`邪恶双子` 指一种欺骗性的恶意无线网络，旨在模仿合法网络。它本质上是一个 `流氓接入点`，看起来像受信任的 `Wi-Fi` 网络，但由攻击者建立，意图拦截敏感信息或进行其他恶意活动。由于该接入点未连接到合法的受信任网络，`映射驱动器` 和 `共享打印机` 将无法访问。选项 A、B 和 C 是其他社会工程学攻击的示例。

### 5. 答案：**A**
正确答案是 **A**。`尾随` 是指未经授权的人假装成员工、送货员或访客，试图通过紧跟授权员工通过受控访问点（如带门禁卡的门或安检站）进入安全区域。选项 B、C 和 D 是其他类型的社会工程学。

### 6. 答案：**A**
正确答案是 **A**。在 `DDoS` 攻击中，目标网络或系统变得过载，无法处理合法用户请求，从而有效地拒绝为合法用户提供服务。`DDoS` 攻击可能涉及数千个连接。`僵尸网络` 可用于生成大量流量。选项 B 不涉及数千个连接，因为 `DoS` 可能由单个恶意主机创建。选项 C 指没有补救措施或补丁的漏洞 (`零日漏洞`)。选项 D 涉及攻击者伪造另一真实主机的电子邮件地址、`IP` 地址或 `MAC` 地址 (`欺骗`)。

### 7. 答案：**A**

## 8.10 给定场景，安装并配置浏览器及相关安全设置

1. 正确答案是 **A, D**。安装新软件时，建议始终使用可信站点。例如，如果用户想要下载 `Google Chrome`，最好访问供应商站点，而不是第三方未知站点。许多软件供应商会发布下载文件的哈希值或校验和。这可以使用用户工作站上的哈希工具进行验证。选项 B 不那么重要，因为恶意下载文件的大小可能与真实文件相同。选项 C 描述了一个有用的功能，但不能确保可信的软件下载和安装。

2. 正确答案是 **A**。添加语言翻译器作为浏览器扩展是公司帮助用户将网站翻译成其母语的最方便、最用户友好的解决方案。浏览器扩展（如 `Google Translate`）允许用户直接在浏览器中翻译网页内容，而无需将内容复制粘贴到单独的应用程序中。选项 B 指的是浏览器扩展，可以提供相同的功能，而无需用户切换到新浏览器。虽然对 `HTML5` 的支持对现代网页浏览很重要，但选项 C 并不直接解决将网站翻译成用户母语的问题。选项 D，在 Windows 设置菜单中添加对额外语言的支持，与网站翻译问题无关。

3. 正确答案是 **D**。通过启用广告拦截器，浏览器将能够更快地渲染和显示网页。选项 A 已不再真正有效，因为广告内容嵌入在页面内，尽管它可以阻止建议主机系统可能有多个恶意文件的虚假弹窗。选项 B 和 C 并非设计用于阻止广告。

4. 正确答案是 **A**。浏览安全网站时，客户端浏览器会显示一个挂锁符号，以向用户表明该站点拥有有效证书。选项 B 不正确，因为 `HTTP` 协议不使用证书。选项 C 不正确，因为不使用评级。选项 D 允许在不保留历史记录的情况下浏览，这与问题无关。
