# 9 软件故障排除

## 简介

为了成功通过 A+ 认证考试，考生必须了解用于执行有效软件故障排除的最佳实践方法。

在排查桌面环境故障时，对 Windows 操作系统有扎实的理解是关键要求。技术人员必须能够解读系统消息，并使用正确的技术响应常见错误和事件。台式计算机仍然是现代办公环境的主力，在支持这些平台上的用户时，应遵循正确的故障排除方法。

技术人员必须了解正确的主动方法，以确保系统保持优化且无恶意软件。这包括及时部署操作系统补丁和操作系统更新。

对移动操作系统上支持软件应用程序的透彻理解也非常重要。

为了在 CompTIA A+ Core 2 (220-1102) 认证考试中取得成功，考生必须确保熟悉以下目标：

*   9.1 给定场景，排查常见 Windows 操作系统问题
*   9.2 给定场景，排查常见个人计算机 (PC) 安全问题
*   9.3 给定场景，使用恶意软件清除的最佳实践程序
*   9.4 给定场景，排查常见移动操作系统和应用程序问题
*   9.5 给定场景，排查常见移动操作系统和应用程序安全问题

本章其余部分致力于实践。对于前面定义的每个概念，您将获得一系列问题，旨在测试您对官方认证考试指南中定义的每个核心二代目标的了解。这些问题将评估考生关于如何支持和排查软件应用程序故障的知识。

## 9.3 给定场景，使用恶意软件清除的最佳实践程序

### 1. 恶意软件清除最佳实践程序
用户的计算机运行缓慢、频繁弹出广告并意外重启。经调查，你怀疑存在恶意软件。从计算机中清除恶意软件的最佳实践程序是什么？

    1. 将计算机从网络断开，使用更新的反恶意软件执行全系统扫描，并清除检测到的任何恶意软件
    2. 从计算机手动删除可疑文件和文件夹，然后重启以检查是否有进一步问题
    3. 重新安装操作系统以确保彻底清除所有恶意软件
    4. 忽略该问题，因为它可能只是系统的暂时故障

### 2. 更新反恶意软件的推荐做法
以下哪项是更新反恶意软件的推荐做法？

    1. 禁用自动更新以防止在重要任务期间中断
    2. 仅在操作系统提示时手动更新软件
    3. 将软件配置为自动且定期更新
    4. 卸载并重新安装软件以确保安装了最新版本

### 3. 调查恶意软件症状的重要性
为什么在进行清除过程之前调查和验证恶意软件症状很重要？

    1. 有助于确定恶意软件清除过程的成本
    2. 允许更准确地识别并选择适当的清除技术。
    3. 有助于估算清除恶意软件所需的时间
    4. 确保最终用户了解恶意软件的潜在风险

### 4. 预防未来恶意软件感染的最佳实践
技术人员必须遵循最佳实践程序以**最好地**预防未来的恶意软件感染。应遵循哪项最佳实践？

    1. 定期更新防病毒软件
    2. 禁用系统的用户账户控制 (UAC) 功能
    3. 与受信任的同事共享用户凭据
    4. 默认启用所有浏览器扩展和插件

### 5. 隔离受感染系统的目的
为什么在恶意软件清除过程中需要隔离受感染的系统？

    1. 防止恶意软件传播到其他系统
    2. 在 Windows 中禁用系统还原
    3. 为将来创建还原点
    4. 安排扫描并运行更新

### 6. 禁用系统还原的目的
在恶意软件清除期间在 Windows 中禁用系统还原的目的是什么？

    1. 防止恶意软件传播到其他系统
    2. 删除任何受感染的还原点
    3. 确保恶意软件在清除后无法再次感染系统
    4. 加快恶意软件清除过程

### 7. 禁用系统还原的效果
在恶意软件清除期间禁用系统还原会发生什么？

    1. 恶意软件立即从系统中删除
    2. 所有现有的还原点被删除
    3. 恶意软件被隔离并阻止执行
    4. 系统对进一步的恶意软件感染免疫

### 8. 最终用户教育的重要性

    1. 将恶意软件清除的责任转移给最终用户
    2. 提高最终用户的技术技能
    3. 最大限度地降低再次感染的风险并预防未来的恶意软件事件
