## 4.1 总结云计算概念

1. 正确答案是 **B**。基础设施即服务 (IaaS) 是一种云计算服务模型，其中云服务提供商 (CSP) 仅提供硬件。当您想要将台式电脑迁移到云端时，这非常理想。为此，您需要安装操作系统、对其进行配置并打补丁。所有其他答案均不正确。软件即服务 (SaaS) 是一种供应商创建应用程序（如 Salesforce）并由公司租用该应用程序的模型。安全即服务 (SECaaS) 是一种公司通过外部来源提供云身份管理服务的模型。一个例子是 Okta，它可以提供 SAML 令牌。监控即服务 (MaaS) 是一种云服务提供商为您监控网络和服务器的模型。

### 第 5 题

### 第 7 题

正确答案是 **C**。在社区云模型中，同一行业内的公司（例如一群律师事务所或医院）共享创建和共享资源的成本。每个行业都有自己的软件需求。私有云是单租户，不共享资源，因此比其他云模型能更好地控制存储的数据。公有云模型具有多租户基础设施，用户不共享创建资源的成本。在混合云中，公司既保留本地环境，又将部分资产存储在云端。

### 第 8 题

正确答案是 **B**。通过使用虚拟桌面基础设施 (VDI)，可以为每位顾问分配独立的虚拟桌面。VDI 使用具有相同配置的虚拟桌面池，从而保持桌面的一致性。由于数据处理在虚拟桌面上进行，因此可以保护数据免遭窃取。顾问只需要一台运行瘦客户端（即仅使用鼠标点击和键盘敲击）的极低配置机器即可访问。因此，公司完全保留了对数据的控制权。所有其他选项均不正确。一旦数据下载到 Surface 笔记本电脑（即外部设备）上，公司就会失去对数据的所有控制权。终端服务器是过去由瘦客户端访问的传统服务器，但这项技术现已过时。IaaS 仅提供硬件（例如虚拟桌面），但公司仍需安装操作系统，且可能无法提供一致的桌面。

### 第 9 题

正确答案是 **C**。借助平台即服务 (PaaS)，云服务提供商 (CSP) 提供应用平台，以便公司提供自己的定制应用程序，例如 MySQL、PHP、Azure、Oracle Database 和 Google App Engine 等。所有其他选项均不正确。对于软件即服务 (SaaS)，供应商已创建好应用程序，例如 Office 365、Salesforce 或 GoldMine。基础设施即服务 (IaaS) 是一种云服务，CSP 提供硬件，如服务器、计算机、交换机和防火墙。客户随后安装软件、进行配置和打补丁。私有云是单租户云模型，无法满足该公司的需求。

### 第 10 题

正确答案是 **D**。公有云模型被称为多租户，因为 CSP 在同一服务器上托管许多不同的公司。所有其他选项均不正确。私有云模型被称为单租户，因为该云中仅托管一个实体。因为它确保独占资源访问权并与其他所有人隔离，所以该租户完全控制其环境。在社区云模型中，同一行业的公司共享资源。混合云是指公司既拥有本地基础设施，也拥有云基础设施。

### 第 11 题

正确答案是 **B**。私有云模型将是这家律师事务所最合适的采购选择，因为作为其宿主服务器上的单租户，它可以让他们将数据完全与所有其他实体隔离开来。所有其他选项均不正确。公有云模型是多租户的，存在共享租户风险，即托管在同一服务器上的另一家公司能够访问他们的数据。混合云是一种模型，公司部分员工在本地工作，部分在云端工作，意味着并非所有公司数据都会迁移到云端。在社区云上，同一行业的公司共享成本和资源。与公有云模型一样，这意味着律师事务所将无法完全控制其所有迁移的数据。

### 第 12 题

正确答案是 **C**。共享资源意味着云提供商拥有一个硬件池，可分配给其任何客户。所有其他选项均不正确。动态资源分配意味着计算机或服务器可根据业务需求调整 CPU 或 RAM 等资源的分配。不存在备份池这一说法。系统蔓延是指服务器对资源的消耗超过了宿主虚拟环境中的可用资源。

### 第 13 题

正确答案是 **B**。高可用性意味着服务器经历极少的停机时间（五个 9），实际上实现了 99.999% 的正常运行时间。所有其他选项均不正确。VDI 是虚拟桌面池。集群意味着两台服务器共享同一个仲裁磁盘，其中一台通常处于活动状态，另一台处于被动状态；即处于待机状态，等待活动服务器故障以便接管。共享资源是云提供商数据中心中的一组硬件资源池，可分配给任何请求额外资源的客户。

正确答案是 **C**。`Rapid elasticity`（快速弹性）将允许玩具公司根据需求即时增加和减少云资源。所有其他答案均不正确。`Clustering`（集群）意味着两台服务器共享同一个仲裁磁盘，其中一台通常处于活动状态，另一台处于被动状态，即处于待机状态，等待活动服务器故障以便接管。`Shared resources`（共享资源）意味着云提供商拥有一个资源池，可以即时分配给不同的公司。它们不为任何特定个人保留。`Metered utilization`（计量利用）意味着 `CSP`（云服务提供商）将为客户生成一个仪表板，以便他们监控资源（如存储、`CPU` 核心和带宽）的成本和消耗。

## 4.2 总结客户端虚拟化的各个方面

### 第 1 题
正确答案是 **A**。`Type 1 hypervisor`（1 型管理程序）运行在 `bare-metal`（裸金属）虚拟平台上。这意味着没有操作系统。示例包括 `Microsoft Hyper-V`、`VMware ESX Server` 和 `Citrix XenServer`。所有其他答案均不正确。`Type 2 hypervisors`（2 型管理程序）运行在软件上（例如 `Windows 10`）。不存在 `Type 3` 或 `Type 4 hypervisors`。

### 第 2 题
正确答案是 **A**。可以创建一个包含额外 `RAM` 和 `CPU` 核心的 `resource pool`（资源池），并将其分配给数据库资源池，以便数据库服务器能按场景描述利用它们。所有其他答案均不正确。`System sprawl`（系统蔓延）意味着虚拟环境中的服务器消耗超过了主机资源。`Network segmentation`（网络分段）仅划分网络；不管理资源。`Metered utilization`（计量利用）被云用于为额外资源的消耗收费。




### 3. 正确答案是 **D**。`Virtual Machine (VM)` 逃逸是一种攻击类型，攻击者利用客户虚拟机攻击另一个客户虚拟机、`hypervisor` 或宿主机。所有其他答案均不正确。跳板攻击是一种攻击类型，攻击者获得对物理网络上计算机的访问权限，并攻击另一台计算机或服务器。`VM sprawl` 意味着未受管理的虚拟机已被添加到您的虚拟网络中。`snapshot` 是整个虚拟机的备份，当虚拟机出现问题时可以回滚。

### 4. 正确答案是 **B**。Oracle `VirtualBox` 运行在 `Type 2 hypervisor` 上，这意味着它必须运行在诸如 `Windows 10` 之类的操作系统之上。所有其他答案均不正确。`Type 1 hypervisor` 运行在裸金属虚拟平台上，意味着没有操作系统。示例包括 Microsoft 的 `Hyper-V`、VMware 的 `ESX Server` 和 Citrix 的 `XenServer`。不存在类型 3 或类型 5 的 hypervisor。

### 5. 正确答案是 **B**、**D** 和 **E**。`sandbox` 是一种虚拟机，用于隔离应用程序，以便安全地测试新软件、检查可能包含恶意软件的应用程序，并确保应用程序补丁不会对软件产生不利影响。所有其他答案均不正确。`sandbox` 不包含沙子；它与火灾无关。它测试软件而非硬件。

### 6. 正确答案是 **C** 和 **D**。可以构建一个虚拟机并安装旧版操作系统，随后安装旧版应用程序。然后可以在 `Windows 11` 桌面上安装 `Hyper-V` 并导入该虚拟机，从而使旧版应用程序得以运行。所有其他答案均不正确。该应用程序是为 `Windows` 操作系统构建的，因此不太可能在 `Linux` 操作系统上运行。`sandbox` 是一个隔离的虚拟机，不能用于运行旧版应用程序。`SQL Server` 是数据库服务器，不应在其上运行任何其他应用程序。

### 7. 正确答案是 **A**。当安装多个虚拟机（客户机）时，`Second Level Address Translation (SLAT)` 可提高虚拟内存的性能。所有其他答案均不正确。`SLAT` 与网络或处理器节流无关。它绝不会阻止虚拟内存被使用。
