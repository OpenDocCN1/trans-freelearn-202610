## 5.3 给定场景，排查并诊断存储驱动器和 RAID 阵列问题

### 1

正确答案是 **C**。`RAID 5` 至少使用三块磁盘，并提供快速的读取速度。使用 `RAID 5` 时，即使损坏一块磁盘，仍可保留数据。`RAID 0` 不提供容错或冗余。`RAID 1` 称为镜像。它仅使用 2 块磁盘，但不具备 `RAID 5` 的快速读取速度；它是冗余的，可以损坏一块磁盘。`RAID 6` 至少使用四块磁盘。它提供容错和冗余，因为可以损坏 2 块磁盘。

### 2

正确答案是 **D**。`RAID 5` 在仅有一个驱动器故障时仍可运行。如果你移除一块健康的磁盘，RAID 控制器将检测到两块驱动器故障，导致你丢失所有数据。尽管硬件 RAID 会以红色显示故障磁盘，但选项 C 并未回答所提的问题。`RAID 5` 存在风险：如果你从阵列中移除第二块磁盘，将导致数据丢失。在寻找 `SCSI ID` 时拔出一块健康的磁盘将导致数据丢失。

正确答案是 **C**。`SMART` 是一种自我监测、分析和报告技术工具，用于监控硬盘健康状况。当错误提示检测到即将发生故障时，磁盘已无法修复，你需要更换磁盘。所有其他选项均不可行。
