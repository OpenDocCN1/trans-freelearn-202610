# 第 9 章：软件故障排除

## 9.1 给定场景，排查常见 Windows 操作系统问题

1. 正确答案是 **A**。过时的设备驱动程序是 Windows 中 `BSOD` 错误的常见原因。当驱动程序不是最新时，它们可能与 `OS` 冲突，导致系统不稳定和崩溃。选项 B、C 和 D 也可能导致系统问题，但过时的设备驱动程序被专门认为是更频繁地触发 `BSOD` 错误的原因。

2. 正确答案是 **C**。故障 `RAM` 会导致 `BSOD` 错误，最有效的解决方案是更换故障 `RAM` 模块。清洁计算机的散热风扇（选项 A）可能防止过热问题，但不会直接解决 `RAM` 相关错误。更新防病毒软件（选项 B）与 `RAM` 错误无关。重新安装操作系统（选项 D）是一个更广泛的故障排除步骤，通常不需要用于解决 `RAM` 相关的 `BSOD` 错误。

3. 正确答案是 **B**。`BSOD` 上显示的 `STOP` 错误代码旨在帮助识别错误的具体原因。它提供十六进制错误代码，并通常包含有助于故障排除和解决问题的附加信息。选项 A、C 和 D 并不能准确反映 `STOP` 错误代码的目的。





### 4. 正确答案是 **B**

当计算机在短时间内持续关机且不显示错误消息时，过热是常见原因。过热可能是由于 CPU 风扇故障、通风不良或灰尘堆积导致的。电源故障（选项 A）不太可能导致无任何错误消息的持续关机。病毒或恶意软件感染（选项 C）通常表现为不同的症状，例如弹窗、系统变慢或意外行为，而不是持续关机。主板故障（选项 D）可能导致各种问题，但在这种场景下并非最可能的原因。

### 5. 正确答案是 **C**

Windows 服务无法启动的常见原因之一是服务配置不正确。如果服务未设置为自动启动，或其依赖项未正确配置，就可能发生这种情况。应检查服务配置以确保其设置正确。虽然选项 A（磁盘空间不足）会导致计算机出现各种问题，但它与服务无法启动没有直接关系。如果服务需要磁盘空间才能正常运行，它可能在运行后遇到问题，但这不是服务无法启动的主要原因。选项 B（设备驱动程序过时）可能导致硬件组件出现问题，但通常不是服务无法启动的原因。服务是独立于设备驱动程序及其功能的软件组件。选项 D（不兼容的软件安装）可能导致冲突和系统不稳定，但不太可能阻止 Windows 服务启动。虽然软件组件之间可能发生冲突，但这不是服务启动失败的常见原因。

### 6. 正确答案是 **A, C**

选项 A（关闭不必要的应用程序）可以通过释放这些应用程序占用的资源来释放内存。当系统内存不足时，关闭未使用或不必要的程序可以缓解该问题。选项 C（为系统添加更多 RAM）是解决内存不足警告的有效方法。增加物理 RAM 容量可为系统管理其工作负载提供更多内存。选项 B（删除临时文件）有助于释放磁盘空间，但不能直接解决内存不足警告。内存不足警告专门与 RAM 不足有关，而非磁盘空间。选项 D（升级处理器）是不正确的，因为内存不足警告与处理器没有直接关系。升级处理器可能会提高整体系统性能，但无法单独解决内存不足警告。

### 7. 正确答案是 **A**

此警告表明系统遇到可能导致不稳定的严重问题，即将关机。调查并解决此严重错误对于确保系统稳定性非常重要。选项 B（`您的防病毒软件已过期。请续订您的订阅。`）与系统不稳定没有直接关系。虽然出于安全目的保持防病毒软件最新很重要，但订阅过期不一定表示系统不稳定。选项 C（`您的 Web 浏览器有可用的新更新。单击此处安装。`）是 Web 浏览器更新的通知。虽然出于安全原因建议保持软件最新，但浏览器更新不太可能直接表明系统不稳定。选项 D（`磁盘空间不足。释放一些空间以优化系统性能。`）是与磁盘空间相关的警告，可能会影响系统性能。虽然磁盘空间不足长期来看可能影响系统稳定性，但它不是系统不稳定的直接指标。它更可能影响系统性能和存储容量。

### 8. 正确答案是 **B**

当计算机显示 `No OS found` 消息时，表明系统无法找到有效的操作系统。如果硬盘未正确连接或已损坏，可能会发生这种情况。在这种情况下，计算机无法访问启动操作系统所需的文件。其他选项（A、C 和 D）也可能导致启动相关问题，但不太可能直接导致 `No OS found` 错误。选项 A 不正确，因为如果 Windows 操作系统丢失或损坏，通常会显示与操作系统相关的错误，例如 `Windows Boot Manager error`。选项 C 不正确，因为 BIOS 设置不正确可能导致启动问题，但通常不会导致特定的错误消息 `No OS found`。选项 D 不正确，因为虽然病毒会导致各种问题，但不太可能直接导致 `No OS found` 错误。病毒通常影响操作系统的功能，而不是完全阻止其被检测到。

### 9. 正确答案是 **B**

损坏的用户配置文件会导致登录时配置文件加载缓慢。当用户配置文件损坏时，Windows 可能难以加载必要的设置和首选项，从而导致延迟。系统资源（选项 A）通常不是原因，除非计算机严重配置不足。网络连接问题（选项 C）通常会影响用户登录后访问网络资源的能力，但不太可能直接影响配置文件加载时间。过时的设备驱动程序（选项 D）可能导致各种问题，但与配置文件加载缓慢没有特定关联。

### 10. 正确答案是 **C**

硬件时钟故障可能导致时间漂移问题，因为系统可能无法准确跟踪时间的流逝。虽然不正确的时区设置（选项 A）会导致时间显示差异，但恶意软件感染（选项 B）通常不会直接影响系统时钟。停电（选项 D）可能会暂时干扰系统时钟，但不是持续时间漂移的常见原因。

### 11. 正确答案是 **B**

在 Windows 服务管理控制台中，您可以右键单击某项服务并选择 `Restart` 选项来重启该服务。选项 A（右键单击服务并选择 `Stop` 然后 `Start`）是不正确的，因为它先停止服务再启动，这与重启不同。选项 C（双击服务并从工具栏选择 `Restart`）是不正确的，因为双击服务通常会打开该服务的属性窗口，而不是重启选项。选项 D（右键单击服务并选择 `Pause` 然后 `Resume`）是不正确的，因为它暂停并恢复服务，但不执行重启操作。

### 12. 正确答案是 **C**

当系统重启时，所有正在运行的应用程序都会终止。这包括任何无响应的应用程序。重启提供了一个全新的开始，并有助于解决无响应应用程序的问题。重启不会重置配置设置（选项 A）。重启不会自动修复任何问题（选项 D）。选项 B 不正确，因为重启确实对无响应的应用程序有影响。

### 13. 正确答案是 **A**

当应用程序启动时立即崩溃，必须确保计算机满足该应用程序指定的最低系统要求。系统资源不足可能导致崩溃。检查可用磁盘空间很重要，但除非应用程序明确要求一定量的可用空间，否则这不是此场景下的第一步（选项 B）。查看防病毒软件设置是个好习惯，但通常不是应用程序启动即崩溃的主要原因（选项 C）。兼容性模式设置在应用程序以前能工作但在兼容性设置更改后停止工作时才相关。然而，当应用程序在启动时立即崩溃时，这不是初始步骤（选项 D）。





## 9.1 排查常见 Windows 操作系统问题

14. 正确答案是 **A**。“找不到启动设备”错误消息通常表明启动加载程序存在问题，该程序负责启动操作系统。损坏的启动加载程序可能发生在更新过程中或由于其他因素，导致系统无法正常启动。选项 B，CPU 过热，可能导致系统不稳定和意外关机，但与“找不到启动设备”错误没有直接关系。选项 C，硬盘空间不足，可能影响系统性能并阻止某些操作，但它不是此场景下启动失败的主要原因。选项 D，BIOS 设置不正确，可能影响系统功能，但不太可能导致提到的特定错误消息。

17. 正确答案是 **C**。回滚更新时，创建系统还原点非常重要。如果在回滚过程中出现任何问题，这允许您将系统恢复到之前的状态。系统还原点捕获系统的配置和设置，使您能够将其恢复到已知的正常工作状态。重新安装最新更新是错误的，因为回滚更新的目的是恢复到之前的版本，而不是重新安装最新更新（选项 A）。禁用自动更新是错误的，因为禁用自动更新并不能解决回滚更新的过程，它只是阻止未来的更新被自动安装（选项 B）。增加系统资源是错误的，因为它与回滚更新的过程无关。它涉及通过分配额外的硬件资源（如内存或 CPU）来提高系统性能，以解决性能问题（选项 D）。

18. 正确答案是 **B**。当 Windows 无法启动并显示蓝屏死机 (BSOD) 时，使用系统还原回滚到之前的正常工作状态是推荐的步骤。系统还原允许您将系统恢复到先前已知的良好配置，这有助于解决导致 BSOD 的问题。仅仅重启计算机（选项 A）可能无法解决根本问题。重新安装所有第三方应用程序（选项 C）并非必要，除非某个特定应用程序导致 BSOD。更新计算机的 BIOS（选项 D）应谨慎进行，仅在有明确迹象表明 BIOS 更新能解决 BSOD 问题时才执行。

19. 正确答案是 **C**。正确答案是选项 C，即遇到频繁的应用程序崩溃时。运行 Windows 系统文件检查器有助于识别和修复可能导致频繁崩溃的损坏系统文件。这是解决软件相关问题的一个排查步骤。虽然硬件驱动程序问题（选项 A）也可能导致问题，但最好通过更新或重新安装相应驱动程序来解决。运行文件检查与安装新软件更新（选项 B）没有直接关系，尽管它有助于确保更新后系统的稳定性。执行磁盘碎片整理（选项 D）与运行 Windows 系统文件检查器无关，因为碎片整理侧重于优化磁盘上的存储布局。

20. 正确答案是 **C**。在命令提示符中运行 `sfc /scannow` 命令将启动 Windows 系统文件检查器。此命令扫描所有受保护的系统文件，并用正确的 Microsoft 版本替换不正确的版本。`sfc /scanfile` 命令（选项 A）用于扫描特定文件。`sfc /verifyonly`（选项 B）仅验证系统文件的完整性，不进行任何修复。`sfc /restorehealth`（选项 D）用于使用 Windows Update 作为源来修复系统文件。

21. 正确答案是 **C**。当计算机因持续崩溃和蓝屏错误而无法正常工作时，Windows 重置映像可用作排查步骤。重置映像有助于消除可能导致系统不稳定的软件相关问题，提供一个全新且稳定的 Windows 安装。选项 A 不正确，因为当特定软件应用程序无法正常启动时，通常是与该特定应用程序相关的孤立问题。针对该应用程序的具体排查步骤（如重新安装或更新它）会更合适。选项 B 不正确，因为不稳定的互联网连接通常无法通过使用 Windows 重置映像来解决。排查网络设置、检查硬件连接或联系互联网服务提供商将更适合解决互联网连接问题。选项 D 不正确，因为调整显示分辨率不需要使用 Windows 重置映像。更改显示分辨率是一项配置设置，可以在操作系统内进行调整，无需完全重新安装系统。

## 9.2 给定场景，排查常见个人计算机 (PC) 安全问题

1. 正确答案是 **A**。排查网络连接问题的第一步是验证物理网络连接和线缆。这包括检查网线是否安全地插在 PC 和路由器或交换机上。通过确保物理连接完好，可以识别并解决与松动或故障连接相关的问题。更新杀毒软件（选项 B）与网络连接问题没有直接关系。重新安装操作系统（选项 C）是极端步骤，只有在所有其他排查步骤都失败时才应考虑。增加 PC 的内存（选项 D）不能直接解决网络连接问题。

2. 正确答案是 **D**。关于杀毒保护的虚假警报可能是由合法文件被标记为威胁引起的。通过从杀毒扫描中排除误报文件，警报将不再出现，用户可以区分真实威胁和误报。更新杀毒软件（选项 A）可能有助于提高其检测能力，但可能无法直接解决虚假警报问题。调整防火墙设置（选项 B）与杀毒软件引起的虚假警报无关。使用杀毒程序运行全盘扫描（选项 C）可能会检测到威胁，但不能专门解决误报警报。





3. 正确答案是 **B**。勒索软件感染是一种恶意软件，它会加密或篡改用户的文件，并勒索赎金以恢复访问权限。这与用户报告的文件被篡改、丢失或重命名的情况相符。网络钓鱼攻击（选项 A）通常涉及诱骗用户泄露敏感信息，不太可能直接影响文件完整性。Rootkit 安装（选项 C）和网络入侵者的未授权访问（选项 D）可能导致文件被篡改，但勒索软件感染是文件被篡改或被劫持的最常见原因。

4. 正确答案是 **A**。操作系统内的不需要的通知通常是由在启动时运行的不必要或恶意程序引起的。通过禁用启动程序，技术人员可以消除可能负责生成不需要通知的程序。更新 BIOS（选项 B）与操作系统通知无关。重装操作系统（选项 C）是一个激进的步骤，只有在其他故障排除方法失败时才应考虑。使用注册表清理工具清理注册表（选项 D）是不必要的，且可能无法直接解决不需要的操作系统通知问题。

5. 正确答案是 **B**。通常，操作系统更新失败的问题可以通过重启电脑并尝试再次安装更新来解决。这有助于重置可能阻止成功更新的临时故障或冲突。禁用防病毒软件（选项 A）在某些情况下可能暂时有帮助，但这不是首选步骤。重装操作系统（选项 C）只有在所有其他故障排除方法都失败时才应考虑。清除浏览器缓存（选项 D）与操作系统更新无关，无法解决此特定问题。

6. 正确答案是 **A**。广告软件或恶意软件感染通常会导致网络浏览器上出现随机或频繁的弹出广告。这些弹窗通常是不需要的，并可能引导至潜在有害的网站或下载。当浏览器检测到网站的安全证书存在问题时，会出现证书警告（选项 B）。虽然证书警告可能表明潜在的安全问题，但它们与广告软件或恶意软件感染没有直接关联。选项 C 重定向，是指网络浏览器自动导向到用户无意访问的其他网站。虽然这可能由恶意软件引起，但不一定单纯与广告软件或恶意软件感染有关。网速慢可能由多种因素引起，例如网络拥塞或互联网服务提供商的问题。虽然恶意软件感染可能影响网络性能，但它不是广告软件或恶意软件感染的特定症状（选项 D）。

7. 正确答案是 **C**。当与网站关联的安全证书过期时，浏览器会生成证书警告，以告知用户潜在的安全风险。确保网站拥有最新的安全证书非常重要。过时的浏览器有时会导致与新安全证书的兼容性问题，但它不是反复出现证书警告的最可能原因（选项 A）。虽然防火墙可以阻止安全连接，但不太可能导致反复出现证书警告（选项 B）。防火墙相关的问题通常会完全阻止访问安全网站，而不是生成证书警告。DNS 缓存投毒是指将不正确或恶意的信息插入 DNS 缓存的攻击。虽然这种攻击可能导致安全问题，但它不是反复出现证书警告的最可能原因（选项 D）。
