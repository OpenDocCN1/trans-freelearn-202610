# AI 中心
高级主题

在之前的章节中，我们看到了如何利用 **机器学习 (ML)** 来协助收据处理和邮件分类。虽然这些用例非常流行，但还有许多其他类型的用例可以应用 **命名实体识别 (NER)** 模型或自定义 ML 模型。

在本章中，我们将涵盖以下主题：

- 使用 AI Center 进行 **命名实体识别 (NER)**
- 将您自己的自定义模型部署到 AI Center

我们将介绍 NER 的概念，这项任务开启了我们可以将 ML 应用于的新类型用例。我们还将涉足将自定义 Python ML 模型部署到 AI Center，因为在许多情况下，组织拥有自己的预建 ML 模型，可以与 RPA 结合使用。

完成后，我们将了解如何利用 UiPath 的 NER 功能，以及如何将自己的自定义 Python 模型连接到 AI Center。

对于我们需要 NER 模型而不适合开源 NER 模型的 18 个实体，或需要重新训练的情况，我们可以使用 UiPath 即开即用的 CustomNamedEntityRecognition ML 模型（图 11.7）。

该 ML 包允许我们使用自己的数据集，这些数据集已预先标记（或标注）了我们需要提取的实体。这可以为许多不同类型的实体开启许多新的用例类型，例如以下内容：

- 保险用例 – 车辆实体
- 医疗保健 – 药物实体
- 零售 – 服装实体

使用此 ML 模型，我们需要提供一个预先标注了我们想要提取的实体的训练数据集。训练和评估数据集需要采用 CoNLL 格式，这可以使用名为 Label Studio 的工具完成。

![](img/05268897c8ac5d80eb3fead1cc8a822a_352_0.png)

Label Studio 是一个开源工具，可让您轻松标注音频、文本、图像等数据类型。使用 CustomNamedEntityRecognition ML 模型时，Label Studio 将用于将标注数据导出为 CoNLL 2003 格式。

## 为 AI Center 准备 Python 模型

在我们能够将 Python 模型部署到 AI Center 之前，有一些要求需要添加到 Python 模型中。这些要求可以分为为模型提供服务的要求和为模型训练的要求。

对于模型服务，每个 ML 包必须包含以下内容：

- 一个包含文件 `main.py` 的压缩文件夹。
- 在 `main.py` 中，必须实现两个函数：
  - `__init__(self)`：不带参数并加载模型
  - `predict(self, input)`：在模型服务时调用的函数，返回字符串
- 一个名为 `requirements.txt` 的文件，其中包含运行模型所需的依赖项。
