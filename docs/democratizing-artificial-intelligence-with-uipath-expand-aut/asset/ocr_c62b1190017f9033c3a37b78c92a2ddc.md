Once the package is uploaded, it will have an *undeployed* status. Our next step is to deploy the package by creating an ML skill:

+   1. Navigate to the **ML Skills** tab of AI Center.
+   2. Click **Create New** to create a new ML Skill.
+   3. When presented with the **Create New ML Skill** screen, provide the following:

+   * A skill name
+   * The *LinearRegression* package
+   * The most recent package version
