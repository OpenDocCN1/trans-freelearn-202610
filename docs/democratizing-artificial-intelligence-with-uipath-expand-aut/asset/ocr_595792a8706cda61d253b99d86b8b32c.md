For this use case, we are going to take an incremental approach to solving the pain points of the T&E team by using automation to read the contents of each receipt. By creating automation that can read receipts, we can tackle one of the tougher parts of the process, allowing us to expand to other tasks in the future, potentially automating the full end-to-end process through a series of automations.

Double-clicking into the read receipts task that we are automating, there is one large requirement to square away before creating the final future state – the fields we need to extract from each receipt. In the current state of the process, the analyst needs to note and confirm the following fields:

+   - Vendor Name
+   - Receipt Date
+   - Tax Amount
+   - Total Amount
