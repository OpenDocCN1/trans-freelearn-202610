The two products are as follows:

+   - **Unattended robots**: Unattended robots reside in virtual machines and run in the background. Unattended robots are used for rule-based, long-standing workflow automation use cases. They interact with humans via Action Center. In addition, AI skills can be added to unattended robots to perform cognitive tasks.
+   - **Attended Robots**: Attended robots work side by side with humans on their desktops and act as personal assistants to help with daily tasks. Humans access, schedule, and run attended automation in UiPath Assistant. The UiPath platform allows AI skills to be added to the unattended robots to perform cognitive tasks.
