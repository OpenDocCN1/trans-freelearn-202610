For documents that require OCR (such as scanned PDFs), an OCR engine can be used during the digitization process. OCR engines that are compatible with digitization in the UiPath Document Understanding framework are as follows:

+   - UiPath Document OCR
+   - OmniPage OCR
+   - Google Cloud Vision OCR
+   - Microsoft Azure Computer Vision OCR
+   - Microsoft OCR
+   - Tesseract OCR
+   - ABBYY Document OCR
