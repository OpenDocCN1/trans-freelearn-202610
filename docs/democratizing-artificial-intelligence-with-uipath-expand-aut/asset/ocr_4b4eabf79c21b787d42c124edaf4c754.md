# Summary

In this chapter, we covered building a cognitive automation use case with *UiPath Document Understanding*. In the construction of the use case, we leveraged the *UiPath Document Understanding Process template* to build in line with best practice following the *UiPath Document Understanding framework*. By having a full understanding of Document Understanding and the Document Understanding framework, we built a cognitive use case that can decipher receipts for the T&E team to use during their expense report review process.

In the next chapter, we will take another hands-on approach by working together to build the second of three use cases with UiPath. We will learn how to use UiPath's AI Center to classify emails.
