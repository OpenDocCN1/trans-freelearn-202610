+   - `in_Email`: To input an email address from the chatbot
+   - `out_SRNumber`: A random SRN we will output in the chatbot

+   2. Add a **Log Message** activity, with `in_Task` as the message and `Info` as the log level.
+   3. Add a **Switch** activity, with `in_Task` as the expression.
+   4. Create a case called `Upgrade_AppY`, with an `Invoke` workflow calling the `Upgrade_App` workflow we just created.
