Since we are building an attended use case, we need to ensure that Main-Attended.xaml is set as the main file. Every UiPath project needs to have a defined main file, usually called Main.xaml, but in this case, we need to set Main-Attended.xaml as our main file by following these steps:

+   1. Right-click on **Main-Attended.xaml** underneath the project pane of UiPath Studio.
+   2. Click **Set as Main** to set the file as the project's main file (*Figure 8.16*):
