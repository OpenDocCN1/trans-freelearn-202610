Within the **Digitize Document** activity, notice the **Input** and **Output** parameters:

+   - **Input:**
+     - **Document Path:** The full path of the document that the activity is set to digitize
+   - **Output:**
+     - **Document Text:** Outputting the string text of the digitized document
+     - **Document Object Model:** The corresponding DOM of the input file
