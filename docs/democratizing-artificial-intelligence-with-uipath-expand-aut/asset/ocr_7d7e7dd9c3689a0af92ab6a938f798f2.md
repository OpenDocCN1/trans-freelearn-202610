The **Computer Vision (CV)** package contains similar UI Automation activities used for traditional interface automation, such as **Click, Type Into, or Get Text**. The main difference between the CV activities is the use of the CV Screen Scope. Once a CV Screen Scope is placed into the workflow and a screen is targeted, you can use all the CV activities to build your automation, such as the following:

+   - CV Click
+   - CV Element Exists
+   - CV Get Text
