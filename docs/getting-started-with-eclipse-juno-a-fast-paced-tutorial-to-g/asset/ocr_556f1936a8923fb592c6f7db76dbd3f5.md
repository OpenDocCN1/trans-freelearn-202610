# Summary

As you have seen in this chapter, Eclipse provides a very good set of tools to developers interested in extending it. The plugin manifest editor makes it easier to start creating plugins by removing the need to know how to edit the plugin's configuration files. The plugins that are provided by Eclipse are very well-documented, and together with features such as the Plugin Spy, will get you going in no time.

Now that we have some basic understanding of how to develop extensions for Eclipse, in the next chapter we will find out how we can use all of the Eclipse's platform and infrastructure to develop our own client applications.
