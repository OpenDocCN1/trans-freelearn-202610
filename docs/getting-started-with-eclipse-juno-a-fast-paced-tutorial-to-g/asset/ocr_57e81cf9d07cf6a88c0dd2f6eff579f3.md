A lot of non-GUI-related improvements have also been made. For instance, now you can use the quick assist (Ctrl + 1) to turn an enhanced for loop into either an indexed for loop or an iterator-based loop. The option to transform a for loop into an indexed for loop is available for expressions that iterate over arrays or list-based types. The option to turn a for loop into an iterator-based for loop is only available for expressions of the type iterable. The following screenshot shows the new quick assist in action:
