# 前言

Processing 是一种开源编程语言，由 Casey Reas 和 Benjamin Fry 于 2001 年为 MIT 媒体实验室的美学与计算小组发明。该语言旨在作为视觉设计应用、媒体艺术、电子艺术和教学的速写本。

_Processing 2: 创意编程高手_ 将向你展示九个精彩的完整项目，教你如何超越基础，让你的程序能够看见、听见和感受。

这些项目将向你展示如何在 Processing 草图中使用 Kinect 传感器板或 Arduino 板等设备。

# 本书内容

_项目 1，罗密欧与朱丽叶_ 将帮助你学习如何制作一些纸板机器人，来表演莎士比亚《罗密欧与朱丽叶》中著名的阳台场景。我们将使用一对廉价扬声器和一些纸箱制作会说话的机器人，并学习如何在 Processing 中安装和使用文本转语音库。

_项目 2，火柴人舞蹈团_ 将帮助你创建一个由 Microsoft Kinect 控制的舞蹈团。舞者将通过 Kinect 骨骼追踪来控制。在我们成功控制一个火柴人后，将让越来越多的火柴人出现，直到拥有一个完整的舞蹈团，舞者们将跳出玩家所做的相同动作。

_项目 3，迪斯科舞池_ 将教我们如何播放音乐并创建一个对声音有反应的舞池，因为没有音乐就没有舞蹈。我们将学习如何使用 Processing-sound API 制作音频可视化器。然后我们将把 2D 可视化器转换为 3D 舞池，并邀请上一项目中的火柴人舞蹈团在上面跳舞。

Project 4，Smile-O-Mat，将帮助你创建一个应用程序，允许用户使用自定义用户界面创建与当前心情相符的笑脸。然后可以将此笑脸发布到社交网络，让你的朋友知道你当前的感受，因为有时候一张图片胜过 140 个字符。

Project 5，The Smile-O-Mat Controller，将帮助你使用 Arduino 生成一个自定义控制器板，并使用它来简化对上一项目中微笑机控制器的调整。对于控制器，我们将使用 Arduino 板，学习如何搭建一个简单的电子电路，然后学习如何将其与计算机连接。然后我们将使用控制器生成的输入参数来更改笑脸的表情，并将其发布到社交网络。

Project 6，Fly to the Moon，探索了 Processing 提供的不同模式，并教你如何为 Web 导出草图或将其作为 Android 应用运行。我们将从头开始创建一个类似登月舱的小游戏，并学习如何使其适应在不同硬件上运行以及使用不同输入设备。

Project 7，The Neon Globe，感叹，如果没有一个旋转的霓虹地球仪，统治世界的计划又算什么？在这里，我们将学习如何生成一个旋转的 3D 球体，并使用图像纹理和一些照明将其转换为旋转的地球仪。稍后我们将突出大洲边界，并使用 GLSL 滤镜使其发光。

Project 8，Logfile Geo-visualizer，将帮助我们学习如何在上一项目生成的旋转地球仪上可视化一些数据。我们将使用 Web 服务器日志文件作为输入，并学习如何在 Processing 中解析它。然后，我们将对数据进行地理编码，并使用页面请求的地理坐标在我们的地球仪上绘制一些内容。

Project 9，From Virtual to Real，将帮助我们学习如何将数学转化为实物。我们将学习如何释放数学函数的美感，并使用它们生成可打印的对象，如笔筒或花瓶。然后，我们将学习如何将对象导出为可输入 3D 打印机的格式。

# 本书所需内容

Project 2，The Stick Figure Dance Company，展示了如何使用 Kinect 创建一个由玩家动作控制的火柴人。要运行此示例，你需要一个 Kinect 传感器板及其电源适配器。

Project 5，The Smile-O-Mat Controller，使用 Arduino 板和一些电子元件来创建一个自定义硬件控制器。

在 Project 6，Fly to the Moon 中，我们将创建一个可在 PC、Web 浏览器和 Android 设备上运行的游戏。如果你想在真实设备而非模拟器上查看游戏，则需要一部 Android 手机或平板电脑。

Project 9，From Virtual to Real，展示了如何创建一个 3D 形状，并使用 3D 打印或在线 3D 打印服务将其转化为实物。
