## 关于作者

**尼古拉斯·格拉德沃尔** 于 1976 年出生于奥地利维也纳，并一直希望成为像吉罗·格耳鲁斯这样的发明家。当他得到第一台 Atari 时，他决定成为一名计算机程序员是他离那个梦想最近的途径。自那时起，他通过为几乎任何可编程设备编写程序来谋生，范围从 8 位微控制器到大型机。在空闲时间，他喜欢学习编程语言和操作系统的知识。

尼古拉斯自 2008 年起就使用 Processing，并编写了无数个草图和一些 Processing 库。

您可以在他的博客上查看他的一些作品，网址为 `http://www.local-guru.net/`。

## 关于审稿人

**Mag. 欧文·格拉德沃尔** 是一位退休顾问和前银行审计员，对编程、音乐和视频感兴趣。

**卡斯珀·坎珀曼** 是一位位于荷兰恩斯赫德的教师和创意程序员。他在萨克森应用科学大学的艺术与技术项目工作，教授交互设计、编程和物理计算等学科。

除了教学工作，Kasper 还设计和开发交互装置。他对光着迷，目前使用 Processing 和 Arduino 来原型设计和开发动态光物体。

您可以在 http://www.kasperkamperman.com 上查看他的项目。

> 我要感谢 Processing 开发团队创造了这个伟大的开源编程语言和环境。同时也要感谢本书的作者尼古拉斯·格拉德沃尔以及 Packt 出版社团队，审阅此书是一件令人愉快的事。

**蒂姆·普尔弗** 是来自德国波茨坦的界面设计专业学生。他在大学期间学习软件工程，为实现自己的创意提供了知识基础。他将 Processing 用作一种艺术媒介来构建自己的工具。他最近的一个项目是一个巨大的实时数据可视化软件，用于可视化全球作物产量。该软件专为在天象馆/全穹顶环境中观看而制作。

在另一个项目中，Tim 编写了一个程序，根据眼球图像的结构将其转换为独特的珠宝，并使用 3D 打印机打印出来。

他喜欢分享和自由文化的理念。2011 年，他创立了电子音乐网络厂牌 Yarn Audio，支持发布音乐的共享和混音。该网络厂牌的所有封面作品也均使用 Processing 生成。

> 我想感谢家人的支持，感谢 Isi 激励我做我现在所做的事，也感谢 Hanna 和 Paul 的精彩交谈和辣肉酱。

**R.A. 罗伯逊** 在 2008 年夏末发现了 Processing，随之而来的是生成艺术的乐趣。除了偶尔涉足 Quartz Composer 之外，Ross 发现 Processing 是进入过程化素养世界的入口，也是理解自然、社会和自身的一条道路。

在 Ross 成年生活的大部分时间里，他研究音乐和设计（正式和非正式），并在得克萨斯州奥斯汀担任了多年的专业合气道教练。此外，他还持有奥斯汀德克萨斯大学的文化人类学学士学位。尽管这些领域表面上迥异，但它们与编程作为多元语言汇聚在一起，其语法、句法、词汇和结构用于相互启发和增强。Ross 的工作一直致力于将这些元素统一为一种连贯的设计方式，旨在探索美、健康的含义，并培养出能够为所有人创造更美好世界的更好的人类。

Ross 是 Processing 奥斯汀聚会小组的创始人兼主持人，也是新兴的 Still Moving Designs 工作室的所有者。

作为一位旅行爱好者，Ross 很高兴将奥斯汀作为自己的家，他与可爱的配偶、伴侣和朋友 Catherine Parsoneault 博士居住于此。Ross 有三个成年孩子——Ehren、Calen（以及他迷人的新娘 Taylor）和 Raanan——他们无疑是他眼中这个星球上最有趣、最棒的人。对 Ross 来说，与这些了不起的人交谈和共同度过的时光，比天堂的吗那更胜一筹。
