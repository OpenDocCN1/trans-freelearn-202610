# # You Ready to go Gung HO? A Hotshot Challenge

We learned how to create a physical object that started life as a mathematical function and
a few lines of code, but of course, this is not limited to creating small vases for your favorite
flowers. Why don't you try one of the following ideas:

+   - Generate 3D printed jewelry.
+   - Create objects from various parts, which can be combined to form bigger objects.
+   - Use an additional input source for your function, such as stack exchange rates or
+   even an audio file!
+   - Use a Kinect to scan an object and create a printable shape from it.
