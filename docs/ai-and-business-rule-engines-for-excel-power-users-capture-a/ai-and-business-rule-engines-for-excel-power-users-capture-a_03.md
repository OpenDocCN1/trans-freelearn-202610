# 第 2 部分：

# 编写业务规则和决策模型——结合真实案例

本部分将基于我们之前看到的 Hello world 示例，介绍如何与同事协作构建实用的业务规则和决策模型，并将其与 Excel 连接以供日常使用。

本部分包括以下章节：

+   - *第 4 章，更多决策模型、业务规则和决策表*，扩展你对决策模型的认识，通过构建一个可运行的巧克力商店示例，展示更多可用工具。
+   - *第 5 章，使用 OpenShift Cloud 和 GitHub 共享与部署决策模型*，让我们的决策模型可供他人共享，使其他人能够在云端运行它们，并介绍如何使用在线工具与同事协作设计模型。
+   - *第 6 章，使用 Power Query 从 Excel 调用业务规则*，将 Excel 与我们的 AI、规则和决策表连接起来——使用 Excel 内置的 Power Query 工具。
