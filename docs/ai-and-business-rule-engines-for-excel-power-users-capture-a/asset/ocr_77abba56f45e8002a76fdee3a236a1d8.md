When the file has been fully downloaded, go to where you saved it, then double-click to open and run it. Again, it's worth remembering that some IT departments may block you from doing this. If this happens, you'll see an error message, and you will need to get in touch to request that they remove any blocks.

Even if you have permission to run it, Windows will double-check that you know what you are doing. On Windows 11, you will see a screen like in Figure 3.13; other versions of Windows will have something similar:
