**Boxed expressions and FEEL**
Typing a formula into a box like this should feel familiar – it’s very Excel-like. Not surprisingly, they are called **boxed expressions**. The language that boxed expressions use is called **Friendly Enough Expression Language (FEEL)** – a standard originally from Oracle. You’ll see in the next chapters that it is very powerful. But for the sake of this example, just understand that it is similar to, but not exactly the same as, Excel functions.
