Also on the top right, there is a new sync menu. Pulling and pushing are standard GitHub concepts that you’ll use a lot:

+   I. **Pull** is used when you want to take other people’s changes and download them to refresh your local copy
+   II. **Push** is used when you have made changes locally and you want to send them to GitHub to the main upstream repository
