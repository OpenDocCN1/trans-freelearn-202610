Designing a good REST API like this is an art – more information on the thinking and design choices made by the KIE team can be found at https://blog.kie.org/2020/08/kogito-2840-about-dmn-endpoints-on-kogito.html.

> **Note on security**
> There are a lot of endpoints exposed here that are useful in development, but not in a real-world deployment. Your network admin should allow access only to the endpoints(s) that you need to call.
