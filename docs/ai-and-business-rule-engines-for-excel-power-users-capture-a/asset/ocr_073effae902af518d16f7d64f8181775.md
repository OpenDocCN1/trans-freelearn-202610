# Sharing your repository

Since we set our repository as private, we need to invite our colleagues to collaborate with us:

+   1. Open your project (not personal) settings page on GitHub. You’ll find this under the project name (like on the far right of Figure 5.31):

![](bbox=[0.13, 0.215, 0.855, 0.285])

Figure 5.31 – Finding the project settings on GitHub

+   2. Once you see the project settings screen, click on the collaborator’s options, and you’ll have the option to invite colleagues like in Figure 5.32.

+   3. Of course, you will need to know their GitHub names. Once you invite them, they will have access to your repository (just this project).

![](bbox=[0.13, 0.43, 0.855, 0.785])

Figure 5.32 – Inviting other people to collaborate on decision models

Now that your colleagues have access, how do they collaborate with you on these decision models? What makes Git and GitHub so powerful is that there are a number of different workflows for you to do this, and which one is most appropriate for you is a matter of personal choice.
