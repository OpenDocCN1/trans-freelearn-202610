Four different ways to run the book’s samples might appear a lot, but every reader’s computer is different, and there are billions of combinations of hardware, software, and configuration that make it impossible to test them all.

For example, some organizations may block you from downloading and running an .exe file (which is needed for the first option, using KIE Sandbox). In this case, users may skip ahead and use the cloud approach to run the samples. By giving four alternative options, we make it much more likely that every reader will be able to run the samples.
