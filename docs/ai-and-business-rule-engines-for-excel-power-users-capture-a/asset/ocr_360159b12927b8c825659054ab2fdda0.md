5. The pom.xml file is the recipe book used by Maven to understand the kind of project we want to build. Open it in the VSCode editor. We’re going to modify it to tell Maven we want to include the Kogito scenario testing tool.

6. In pom.xml, look for the </dependencies> line. Replace it with the following line, so that there is still only one </dependencies> tag in the project:

```
<dependency> <groupId>org.kie.kogito</groupId>
<artifactId>kogito-scenario-simulation</artifactId>
<scope>test</scope> </dependency> </dependencies>
```

7. Press Ctrl + S to save this file.
