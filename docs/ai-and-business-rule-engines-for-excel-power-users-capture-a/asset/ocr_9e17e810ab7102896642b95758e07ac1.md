# Preparing our Excel output table

Our Excel output table is pretty simple, but it will automatically get picked up by some of the actions in Power Automate – so let’s walk through creating it step by step:

+   1. Start by opening Excel and creating a new spreadsheet.
+   2. Create two headers, ID and JSON.
+   3. Select the cells A1:B2 – then Insert tables. Click on My table has headers and then click OK to create the table.
+   4. Using the Table Design menu, give the table a name, as in Figure 8.14:
