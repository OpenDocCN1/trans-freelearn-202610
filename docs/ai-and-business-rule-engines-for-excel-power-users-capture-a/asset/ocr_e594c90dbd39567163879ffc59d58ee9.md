What is even more impressive is that while there is a Desktop version of VS Code, this screenshot was taken using VS Code running within the web browser (which automatically sets up the Azure cloud-hosted Codespaces to do the heavy lifting).

The final section of the screen (the bottom right) contains a lot of text. If you’ve used a terminal before (either on Linux, macOS, or Windows), this should be familiar.
