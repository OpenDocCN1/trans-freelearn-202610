
# Variants of DPO

A number of variants have emerged that preserve the core principles of DPO—direct preference optimization via contrastive supervision—while addressing practical limitations. These methods refine specific aspects of DPO such as its loss function, regularization scheme, or optimization dynamics. Below, we group these variants into thematic categories.

## Regularization and Constraint Variants

These methods modify how DPO constrains the new policy relative to the reference model.

`ORPO` (`Odds-Ratio Preference Optimization`): Removes the need for a frozen reference model by embedding the reference into an odds-ratio formulation, reducing compute and architectural complexity. See more here: [https://arxiv.org/pdf/2403.07691](https://arxiv.org/pdf/2403.07691).

`simPO` (`Similarity-based Preference Optimization`): Uses the model's own initial predictions as a soft baseline, allowing for reference-free optimization while maintaining conservative updates. See more here: [https://arxiv.org/abs/2405.14734](https://arxiv.org/abs/2405.14734).

`β-DPO`: Dynamically adjusts the KL penalty strength during training, increasing it when preference signals are weak or noisy and reducing it when they are strong. The paper [https://arxiv.org/pdf/2407.08639](https://arxiv.org/pdf/2407.08639) explains this method in details.

## Loss Structure Enhancements

These methods modify the DPO loss function to improve optimization behavior.

`IPO` (`Implicit Preference Optimization`): Replaces the Bradley-Terry transformation with an identity link function and incorporates regularization implicitly from preference data, reducing overfitting and reducing dependence on a fixed reference model. See more here: [https://arxiv.org/pdf/2310.12036](https://arxiv.org/pdf/2310.12036).

`CPO` (`Contrastive Preference Optimization`): Adds a supervised term to the DPO loss that explicitly increases the likelihood of the preferred output, addressing the concern that contrastive-only optimization may insufficiently reinforce winners. See more here: [https://arxiv.org/pdf/2401.08417](https://arxiv.org/pdf/2401.08417).

`KTO` (`Kahneman–Tversky Optimization`): Inspired by `Prospect Theory`, KTO introduces asymmetric treatment of gains and losses into the DPO objective, reflecting how humans weigh preference differently in practice (e.g., loss aversion). See more here: [https://arxiv.org/abs/2402.01306](https://arxiv.org/abs/2402.01306).

## Alignment Robustness and Multi-Objective Optimization

These methods introduce regularization or auxiliary objectives to reduce misalignment artifacts.

`R-DPO`: Penalizes undesirable behaviors like excessive verbosity or length bias, which arise when models learn to exploit preference signals. See more here: [https://aclanthology.org/2024.findings-acl.297.pdf](https://aclanthology.org/2024.findings-acl.297.pdf).

`LIFT-DPO`: Incorporates instruction-based regularization to teach the model when shorter answers are preferable, improving controllability. See more here: Following Length Constraints in Instructions [https://arxiv.org/html/2406.17744v1](https://arxiv.org/html/2406.17744v1).

`MODPO` (`Multi-Objective DPO`): Extends DPO to jointly optimize for multiple preference dimensions (e.g., helpfulness and harmlessness), typically through weighted or Pareto-optimized combinations of separate DPO objectives. See more here: Beyond One-Preference-Fits-All Alignment: Multi-Objective Direct Preference Optimization: [https://arxiv.org/abs/2310.03708](https://arxiv.org/abs/2310.03708).

`SafeDPO`: Treats safety as a hard constraint in the DPO process, enforcing refusal behavior or content filtering as part of the preference supervision. See more here: SafeDPO: A Simple Approach to Direct Preference Optimization with Enhanced Safety [https://openreview.net/forum?id=MoJSnVZ59d](https://openreview.net/forum?id=MoJSnVZ59d).

All these methods retain the `contrastive preference modeling` framework at the heart of DPO, but they adapt its structure to better suit real-world data, improve alignment stability, and expand its flexibility. They represent the evolution of DPO within its conceptual boundaries—not departures from it.

# Conceptually Distinct Direct Alignment Methods

Beyond variants of DPO, a growing number of direct alignment methods have emerged that share the goal of learning from human preferences, but do so using different modeling assumptions, feedback structures, or training paradigms. These methods depart from the original DPO framework and define new directions in preference-based fine-tuning.

## Listwise Preference Optimization

These methods go beyond binary pairwise supervision by learning from ranked lists of responses.

`RRHF` (`Reward-Ranked Fine-Tuning`): Trains the model to imitate the top-ranked outputs in a list of completions, using log-likelihood-based imitation rather than contrastive loss. No reference model or KL penalty is used. See here for more information: [https://arxiv.org/abs/2304.05302](https://arxiv.org/abs/2304.05302).

`RAFT`: Optimizes directly on sorted outputs using a listwise objective. This approach encourages the model to learn global response quality patterns, rather than just local pairwise preferences. See more here: [https://arxiv.org/pdf/2403.10131](https://arxiv.org/pdf/2403.10131).

## Unpaired Preference Learning

Some approaches remove the need for dispreferred comparisons altogether. `Unpaired Preference Optimization` uses only positive (thumbs-up) feedback, either by treating all other outputs as implicit negatives or learning a reward function indirectly. This departs from DPO's binary structure. See more here: [https://arxiv.org/pdf/2310.12036](https://arxiv.org/pdf/2310.12036).

## Self-Supervised and Self-Play Preference Learning

These methods generate or judge preference data using the model itself. For example, in `Self-Play Optimization` models generate competing outputs, and a separate judge model (or the model itself) selects the better one. Training proceeds by reinforcing the winning strategy. While this may use DPO-style optimization, it is conceptually closer to iterative self-training or comparison-based imitation. See more here: Self-Play Preference Optimization for Language Model Alignment: [https://arxiv.org/abs/2405.00675](https://arxiv.org/abs/2405.00675).
