

# 优势演员-评论家：使用基线减法进行方差缩减

原始策略梯度使用总回报（折扣奖励之和）来估计策略的梯度。由于环境的随机性和智能体动作的随机性，该回报可能具有高度的变异性。梯度估计中的高方差可能导致训练不稳定，即策略更新可能剧烈波动。这种不稳定性会使算法难以收敛到最优策略。由于更新具有噪声且可靠性较低，学习过程可能会很慢。

为了解决这个问题，不再对每个动作使用总折扣奖励，而是减去一个基线以减小方差。基线通常是预期回报的估计（例如价值函数），奖励与基线之间的差值称为优势。我们希望鼓励那些优于平均水平的动作。使用优势函数通过减小具有平均或预期奖励的动作的策略更新幅度来降低方差。进行基线减法的一种简单方法是将优势函数定义为：

这些概念是同策略 `RL` 算法的基础构建模块。请注意，从 `VPG` 到 `A2C` 再到 `GAE` 的发展历程是一个持续改进的过程，但这些早期的算法和概念不足以解决更具挑战性的问题，因为它们仍未完全解决稳定性问题。此外，它们需要大量的训练和超参数实验。

除了论文 *High-Dimensional Continuous Control Using Generalized Advantage Estimation* 中介绍的广义优势估计器外，过去几年中还出现了更复杂的想法，例如 Trust Region Policy Optimization（`TRPO`，信任区域策略优化）：[https://arxiv.org/abs/1502.05477](https://arxiv.org/abs/1502.05477) 和 Proximal Policy Optimization（`PPO`，近端策略优化）算法：[https://arxiv.org/abs/1707.06347](https://arxiv.org/abs/1707.06347)，它们有助于提高稳定性和降低对超参数调整的敏感度，且后两者（`TRPO` 和 `PPO`）还能保证单调收敛。通过讨论 `DQN`、`VPG`、`A2C`、`GAE`，我们已经涵盖了 `RL` 中各类变体算法最关键的基础构建模块，并已准备好理解更高级的 `PPO` 算法。我们将讨论 PPO 的应用，因为它在基于 `RLHF` 的模型微调最先进方法论中扮演着重要角色。
