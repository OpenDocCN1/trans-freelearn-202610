## Summary

In this chapter, we introduced you to main concepts of `RL`, provided a simple grid world example to help understand key concepts using one of the fundamental algorithms, `Q-learning`, then demonstrated how transfer learning and human feedback can help accelerate learning. While this is good for introduction, there are also more complex examples where `Q-values` may not be stored in tables but a neural network or similar function approximator might be necessary. `Q-learning` can become unstable, when scaled to continuous state-action space, and other policy learning algorithms will be necessary. We will cover some of these cases in following chapters. Note also that while we managed to get learning accelerated by using explicit reward feedback from human, on a large scale this can be expensive, and adequate tools for gathering human feedback might be necessary. More on that in the following chapters, but before we discuss that, we will begin by understanding the role of human feedback in `RL` from a general perspective, in the next chapter.

To accommodate readers interested in diving deeper, some relevant references have also been provided.In conventional `RL` methodology, as discussed in the previous chapter, a state-action-reward framework is utilized, necessitating the design of a reward function to define specific objectives. This function incentivizes the agent to maximize these objectives through its behavior. While it is feasible to design such functions for specific tasks, this capability is limited to well-defined tasks. As the scope of requirements and objectives expands, accurately defining the reward function becomes increasingly challenging. Inaccuracies within these functions or scenarios marked by distributional shifts can result in undesirable agent behavior, where the agent prioritizes achieving the objective regardless of consequences or takes actions leading to unforeseen outcomes in unseen scenarios. Such side-effects or unforeseen consequences may incur costs, potentially leading to safety hazards. Human intervention and alignment of models play crucial roles in addressing these challenges.
