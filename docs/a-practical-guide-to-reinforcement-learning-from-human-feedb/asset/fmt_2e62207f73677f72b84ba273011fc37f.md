
# Human Feedback in Q-Learning

The agent uses human feedback to improve its decision-making process. This can involve various learning algorithms tailored to incorporate human feedback effectively. In the grid world example, if the agent makes a move, the human might provide positive feedback (reward) for good moves or negative feedback (penalty) for bad moves. Instead of exploring the environment to learn this policy, the agent uses human-provided feedback to update its policy. Positive feedback encourages the agent to repeat similar actions in similar situations, while negative feedback guides the agent to avoid those actions. Over time, through iterative learning from human feedback, the agent refines its policy to make better decisions in the grid world.

To demonstrate how human feedback accelerates learning, we continue using the grid world problem. We add a new method called `q_learning_with_human_feedback()` to the `GridWorld` class, which is a modification of the `q_learning()` method. The additional input `human_feedback` provides a dictionary of rewards assigned by a human for specific scenario changes from a current state to a next state. For example, if the agent is in current state `(2,2)` and the next state is `(2,3)`, which is closer to goal `(5,5)`, the human would give a reward of `+1`. Conversely, if the current state is `(3,4)` and the agent moves to next state `(2,4)`, which is farther from the goal `(5,5)`, the human would give a reward of `-1`. This human feedback-based reward is added to the reward assigned in the Q-learning algorithm.

## Incorporating Human Feedback

After reward assignment as in snippets discussed previously, in step 4 **State Transition and Reward Assignment**, we reach the point to update the reward by incorporating human feedback. First, the code checks if human feedback is provided. If feedback for the transition from the current state to the next state is available, it updates the reward accordingly.

```
if human_feedback is not None:
    if state in human_feedback and next_state in human_feedback[state]:
        reward += human_feedback[state][next_state]
```

Here, we simply add the human feedback to the reward, but there can be numerous ways to incorporate human feedback, which we will see in the next chapter. After updating the reward, we continue the rest of the code similar to `q_learning()`, as before, until the end of the method where we return output.

## Comparison Execution Code

To allow comparison between Q-learning and Q-learning with human feedback, the previous plotting methods `plot_reward_comparison()` and `plot_comparison_metrics()` used in the TL section are reused and added to the `GridWorld` class. The labels and legends are updated accordingly. Execution code to instantiate and run the modified class and compare human feedback-based training with training from scratch using just Q-learning is as below. In this example, we collect human feedback in a dictionary where the keys are state tuples, and the values are dictionaries mapping next states to feedback values.

```
obstacle_positions = [(2, 3), (3, 1), (4, 3)]
grid_world = GridWorld(grid_size=(6, 6), obstacle_positions=obstacle_positions)
rewards, steps_per_episode, policy_progress = grid_world.q_learning(num_episodes=200, learning_rate=0.1, discount_factor=0.95, epsilon=0.1)
grid_world.plot_policy_progress(policy_progress)
human_feedback = {
    (2, 2): {(2, 3): 1},  # Positive feedback for transitioning from (2, 2) to (2, 3)
    (2, 3): {(2, 4): 1},  # Positive feedback for transitioning from (2, 3) to (2, 4)
    (2, 4): {(2, 5): 1},  # Positive feedback for transitioning from (2, 4) to (2, 5)
    (3, 4): {(2, 4): -1},  # Negative feedback for transitioning from (3, 4) to (2, 4)
    (4, 4): {(3, 4): -1},  # Negative feedback for transitioning from (4, 4) to (3, 4)
    (4, 5): {(5, 5): 1},  # Positive feedback for transitioning from (4, 5) to (5, 5)
}
rewards_hf, steps_per_episode_hf, policy_progress_hf = grid_world.q_learning_with_human_feedback(num_episodes=200, learning_rate=0.1, discount_factor=0.95, epsilon=0.1, human_feedback=human_feedback)
grid_world.plot_policy_progress(policy_progress)
grid_world.plot_rewards_comparison(rewards_hf, rewards)
grid_world.plot_comparison_metrics(rewards_hf, rewards, steps_per_episode_hf, steps_per_episode)
```
