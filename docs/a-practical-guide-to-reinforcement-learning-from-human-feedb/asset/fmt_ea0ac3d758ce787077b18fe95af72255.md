
# Fine-Tuning with LoRA Using PEFT Library

The `r` parameter controls the rank of the low-rank approximation, and `lora_alpha` controls the scaling of the updates. Fine-tuning can be applied for various tasks, and the `TaskType` class can help define the type of task the model is to be adapted for (e.g., text generation or classification). It therefore keeps the model architecture and fine-tuning process consistent with the target task specified. This can be simply applied as: `task_type = TaskType.CAUSAL_LM`.

Implementing fine-tuning with LoRA involves the following steps:

## 1. Load Pre-trained Model and Tokenizer

Specify the pre-trained model to be fine-tuned (e.g., `gpt2`), depending on where it needs to be used. Pass the model name to tokenizer and the automodel for causal language model, pad the tokenizer.

```
model_name = "gpt2"
tokenizer = AutoTokenizer.from_pretrained(model_name)
tokenizer.pad_token = tokenizer.eos_token
model = AutoModelForCausalLM.from_pretrained(model_name)
```

## 2. Define PEFT Configuration (LoRA)

Then, define the PEFT configuration for LoRA. The configuration can include task type, rank of LoRA matrices, alpha and dropout of LoRA, and the target modules where it is to be inserted.

```
peft_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,          # Rank of LoRA matrices
    lora_alpha=32,
    lora_dropout=0.1,
    target_modules=["c_attn"],  # Adjusted for GPT-2
)
```

Then, pass the configs and model to which the LoRA is to be applied.

```
model = get_peft_model(model, peft_config)
```

## 3. Prepare Custom Dataset

Now that the model is configured and structured, prepare a custom dataset, or use one of the open-source datasets. Here we will use a custom dataset and pass the dictionary to the method from `Dataset` class.

```
data = {"text": ["I love AI because", "ChatGPT helps with", "AI will revolutionize"]}
dataset = Dataset.from_dict(data)
```

We can write a tokenization function to specify padding and add labels for loss computations. The `tokenize_function` maps the dataset text to numerics as tokens and corresponding ids as labels.

```
def tokenize_function(example):
    tokenized = tokenizer(example["text"], padding="max_length", truncation=True, max_length=32)
    tokenized["labels"] = tokenized["input_ids"].copy()
    return tokenized
```

To do this mapping, the `map` method of dataset is used.

```
tokenized_dataset = dataset.map(tokenize_function, batched=True)
```

## 4. Define Training Arguments

At the same time, along with tokenized dataset, we can configure the training arguments. Here, we can define output directory, training batch size, number of epochs, logging, and saving strategy. Training parameters such as learning rate for training speed and accuracy and mixed precision setting for memory optimization (e.g., `fp16`) can also be set here. The `report_to` config is usually for specifying whether we want to plot data or record it for analysis using experimentation frameworks such as Weights and Biases. In the snippet below, we are just using `'none'`.

```
training_args = TrainingArguments(
    output_dir="./results",
    per_device_train_batch_size=2,
    num_train_epochs=3,
    logging_dir="./logs",
    save_strategy="no", 
    learning_rate=2e-4,
    fp16=True,
    report_to='none',
)
```

## 5. Fine-Tune the Model

After defining and setting up all the configs and the model, we can pass them to the `Trainer` method and train the model.

```
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
)
trainer.train()
```

Upon training completion, you have your pre-trained model fine-tuned. You now understand how to fine-tune a pre-trained model using PEFT library. For detailed implementation, you can check the notebook in the GitHub repository. The other approach of efficient fine-tuning using TRL library is using the SFT Trainer, which we will continue to explore next.

# LoRA Using SFT Trainer

Now that we know how to use PEFT library and apply LoRA for fine-tuning, we will discuss how to use SFT Trainer to apply LoRA, as this is how it will be integrated with RLHF-based fine-tuning also. SFT Trainer relies on PEFT library also for integrating the PEFT configs into the training. In the previous section on **Supervised Fine-Tuning Process Using Hugging Face TRL Library**, we used `training_args` and passed it to SFT Trainer. Using PEFT and LoRA also includes `peft_config` to SFT Trainer. When using PEFT library directly, we get the augmented model by using `get_peft_model` method from PEFT. But while using SFT Trainer for fine-tuning using LoRA, we don't have to do this step. We directly pass `peft_config` to the SFT Trainer. The model used is the pre-trained model retrieved from `AutoModelForCausalLM.from_pretrained(model_name)`. A snippet example is given next.

```
from trl import SFTConfig, SFTTrainer
trainer = SFTTrainer(
    model,
    train_dataset=tokenized_dataset2,
    args=SFTConfig(output_dir="/tmp", report_to='none'),
    peft_config=peft_config,
)
trainer.train()
```

At this point, you know how to use SFT for fine-tuning as well as how to apply LoRA using SFT and train (fine-tune) the pre-trained models, in addition to using PEFT library. After fine-tuning the models, it is necessary to evaluate the models, and once you have satisfactory model responses, it is ready for inference. We will discuss this next.

# Inference and Evaluate PEFT Models

After training, using the `eval` method, the trained model can be evaluated. Test using some `input_text`, tokenize it using the tokenizer function. Note that you may get a warning if the attention mask and the pad token id are not set. You need to explicitly provide `attention_mask` along with the input IDs during inference. Additionally, you should set `pad_token_id` explicitly for text generation.

```
model.eval()
input_text = "AI is transforming"
inputs = tokenizer(input_text, return_tensors="pt", padding=True).to("cuda")
output = model.generate(
    inputs["input_ids"],
    attention_mask=inputs["attention_mask"], 
    max_length=50,
    num_return_sequences=1,
    pad_token_id=tokenizer.eos_token_id
)
print(tokenizer.decode(output[0], skip_special_tokens=True))
```
