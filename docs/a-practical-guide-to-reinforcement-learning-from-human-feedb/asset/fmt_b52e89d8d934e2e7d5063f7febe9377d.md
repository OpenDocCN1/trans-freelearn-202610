### Datasets

Let's go through the steps of using the `datasets` library for data preparation. Using the `datasets` library, we can easily load the data, simplifying the data collection step. We will load only a subset of the dataset in order to demonstrate how to fine-tune and how it improves inference in this chapter. We will now load a subset of the "imdb" dataset (about 1000 samples), which is part of the `datasets` library from Hugging Face, from the popular Internet Movie Database (IMDB) source. Then, the data is split into 80% training data and 20% test data using the `train_test_split` method.

```
# Load dataset
dataset = load_dataset("imdb", split="train[:1000]")  # Sample a subset to keep it lightweight
dataset = dataset.train_test_split(test_size=0.2)  # Split into train and test
train_dataset, test_dataset = dataset['train'], dataset['test']

Each entry in the `DatasetDict` is a `Dataset` object that provides efficient access to the data, with functionalities for mapping, filtering, and processing. We use the train split and 1000 samples from within it to keep the training light. Next, we will check some samples and check the size of the training and test dataset.

### Tokenization

The tokenization process involves using specific tokenizer classes (like `BertTokenizer` or `GPT2Tokenizer`) that implement strategies such as subword tokenization (e.g., `WordPiece` or `Byte Pair Encoding`) to handle unknown words and reduce vocabulary size. Tokenizers also insert special tokens (like `[CLS]` for classification) and convert text into numerical identifiers corresponding to tokens in the model's vocabulary. They generate attention masks to indicate which tokens should be processed and segment identifiers to differentiate between input segments. Additionally, tokenizers can pad or truncate sequences to maintain consistent input lengths, making the transition from raw text to model-ready input efficient and effective for various NLP tasks. Here, we will use a particular tokenization class from the `transformers` library—the `AutoTokenizer` class, which allows you to load a tokenizer for a specified model. For this specific case, we specify to load the tokenizer for the `DistilBERT` model, a smaller and faster version of `BERT` that is uncased (i.e., it does not differentiate between uppercase and lowercase letters). The snippet below shows how to load the tokenization model and apply it to tokenize the data.

```
# Load tokenizer
tokenizer = AutoTokenizer.from_pretrained("distilbert-base-uncased")
# Tokenize the datasets
def tokenize_data(example):
    return tokenizer(example['text'], padding="max_length", truncation=True)
train_dataset = train_dataset.map(tokenize_data, batched=True)
test_dataset = test_dataset.map(tokenize_data, batched=True)
# Set format for PyTorch
train_dataset = train_dataset.rename_column("label", "labels").with_format("torch")
test_dataset = test_dataset.rename_column("label", "labels").with_format("torch")
```

The `tokenize_data` function uses the loaded tokenizer, finds the text values in the `text` field. The parameters `padding="max_length"` and `truncation=True` ensure that all tokenized outputs are of consistent length, padding shorter sequences to the maximum length and truncating longer ones. The `dataset.map` method applies the `tokenize_data` function to the entire dataset in a batched manner, meaning it processes multiple examples at once. This is efficient and speeds up the tokenization process.
