## Loading Datasets

Load the sample training and test datasets. In real applications, these will be large datasets, but for purpose of demonstration, we are loading only a small number of samples.

```python
train_dataset = load_dataset("imdb", split="train[:4%]")
eval_dataset = load_dataset("imdb", split="train[4%:5%]")
print(f"Train Data:{train_dataset}")
print(f"Eval Data:{eval_dataset}")
```

## Evaluation Function

We will use a custom evaluation function that can be passed to `SFTTrainer`. The `accuracy_score` and `f1_score` metrics are imported from sklearn library.

```python
# Evaluation function
def compute_metrics(pred):
    logits, labels = pred
    predictions = np.argmax(logits, axis=-1)
    accuracy = accuracy_score(labels, predictions)
    f1 = f1_score(labels, predictions, average="weighted")
    return {"accuracy": accuracy, "f1": f1}
```

## Training with SFTTrainer

`SFTTrainer` and `SFTConfig` can be implemented as below. This involves preparing configs and passing to the trainer. Note that we are using a specific model for fine-tuning—`facebook/opt-350m`. It is a model developed by Meta (formerly Facebook), as part of the OPT (Open Pretrained Transformer) series. It's a language model developed to demonstrate high-performance capabilities in various natural language processing (NLP) tasks such as text generation, completion, summarization and translation, as well as sentiment analysis. This is a good model to experiment with since it is one of the smaller models with 350 million parameters, yet useful for NLP tasks.

```python
training_args = SFTConfig(
    max_seq_length=512,
    output_dir="/tmp",
    report_to='none'
)
trainer = SFTTrainer(
    "facebook/opt-350m",
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    args=training_args,
    compute_metrics=compute_metrics
)
trainer.train()
```

## Evaluation After Fine-tuning

After training, the fine-tuned model can be evaluated using the `evaluate` method of the trainer.

```python
# Evaluation after fine-tuning
fine_tuned_results = trainer.evaluate()
print("Results after Fine-Tuning:", fine_tuned_results)
```

## Low-Rank Adaptation (LoRA) Technique

The basic idea behind Low-rank Adaptation (LoRA) technique is to fine-tune only a small number of model weights relevant for steering output to something closer to defined dataset for fine-tuning, instead of training the entire set of model weights. This reduction in training parameters leads to reduced memory requirements and total training cost. The small number of model weights are a decomposition of model weights update. A typical model fine-tuning of models we are discussing is in order of several millions to several billions. Using LoRA, the weight matrices are decomposed to low rank matrices, and training only these low rank matrices. The peft library is a relatively new in the huggingface ecosystem and specifically designed for making fine-tuning process of large language models more parameter-efficient. It incorporates methods such as LoRA (Low-Rank Adaptation) to modify models in a more resource-efficient manner. It has methods such as `get_peft_model` function, which is used to apply parameter-efficient fine-tuning techniques (like LoRA) to a model. The user has to only pass a pre-trained model to this function, relevant fine-tuning technique and corresponding configuration parameters, and it applies the specified fine-tuning technique, returning the modified model. The configuration parameters, in this case for LoRA, can be specified using the `LoraConfig` class. Using `LoraConfig`, you can define the specifics of how you want to apply LoRA to your model. These can be rank size, layers to apply, and target modules. In the below example,

```python
lora_config = LoraConfig(r=16, lora_alpha=32, target_modules=["attn.query", "attn.value"])
```
