
# Reinforcement Learning Fundamentals

RL is a paradigm of machine learning focused on how agents can learn to make decisions based on their interactions with the environment, to maximize specified cumulative rewards. In the context of artificial intelligence, an agent is any entity that perceives the environment and acts upon that environment, by making decisions autonomously. The agent learns through trial and error, receiving feedback in the form of rewards or penalties based on the states it reaches or remains in as a result of its actions. Over time, through this iterative process, the agent hones its decision-making abilities to maximize cumulative rewards.

## The State-Action-Reward Framework

RL is based on the `state-action-reward framework`, where agents interact with their environment to learn optimal decision-making strategies. Perception of the environment, its present state, is conveyed to the agent through sensors, enabling it to make informed decisions. **States** represent various attributes of the environment, providing crucial information for decision-making.

For instance, humans perceive the world through senses like vision, while robots may use cameras. These perceptions form the basis of states, encompassing objects, positions, and other environmental attributes. However, not all states are directly observable; hidden objects contribute to the present state but remain unobserved. Observations, therefore, represent the perceived states that agents utilize for decision-making. For the sake of conciseness, in our discussion, we will be using states as observations, since observations are expected to have all relevant states needed for decision making.

### Actions

Consider a robot navigating an environment based on camera inputs. It interprets images to decide **actions** such as moving right, left, or straight. These actions are executed using mechanisms like limbs or wheels. The agent employs decision-making processes, from simple rules to complex machine learning algorithms, to choose actions based on its perception of the environment.

### Rewards

In RL, agents aim to maximize cumulative **rewards** by selecting actions that lead to favorable outcomes. Rewards serve as feedback, guiding the agent's learning process. Through repeated interactions, the agent refines its decision-making abilities, leveraging the state-action-reward framework to achieve optimal performance in diverse environments. ## Core Concepts

At a given iteration or time, based on the **initial state** of the environment, the agent takes action to change the environment, transitioning it to state `s[t+1]`. For each iteration, this change in state, if desirable, is assigned a higher positive reward, incentivizing the agent to take such actions. The decision-making strategy that causes an agent to take the actions based on the current state is called the **policy**, usually notated as `π(s)`. The actions are input to the environment and cause the environment to alter or transition its states to the next state; the transition dynamics is usually represented as `*.*`. The transition dynamics is dictated by the environment and is not in our or agent’s control. Depending upon the environment, it can be stochastic or deterministic.

The estimate of expected cumulative reward over a sequence of states, starting from the initial state after following a particular policy is the **Value Function**, usually defined as `V(s)`, and is a function of states. When Value Function is for a particular action taken for a particular state, it is termed as **Action Value Function** or `Q` function.

# Understanding RL Algorithms

The main task of RL algorithms is to optimize the policy so that the agent takes optimal actions leading to desired states. To optimize the actions, RL algorithms employ a variety of innovative techniques, but at the core, they use a reward associated with the agent being in a particular state, to drive the policy to come up with actions that are desirable. The differences in algorithms are mainly related to how states, actions, and rewards are used, stored, processed, and applied to come up with optimal policies, and how agent interacts with the environment to come up with those policies. RL algorithms can be classified based on several criteria. Some common categorization are:

## Classification Criteria

### Model-Based vs Model-Free

**Model Based VS Model Free**: Model based algorithms involve learning a model of the environment and using it for planning actions. The model of the environment can be based on dynamic programming, monte carlo methods, or learning a transition model. On the contrary, model free algorithms do not model the environment, but directly learn by interaction with the environment. Examples of model free algorithms are `Q-learning`, `SARSA` and `Deep Q Networks` (`DQN`).

### Value-Based vs Policy-Based

**Value-based vs Policy-based**: Value based algorithms estimate the value of being in a particular state and taking a particular action, and aim at maximizing the value function. Policy based algorithms directly parameterize the policy and learn optimal policy using gradient ascent approaches. A hybrid method, combining value and policy based algorithms, is called `actor-critic` algorithm. It maintains an actor (policy) and a critic (value function), and uses both of them to learn from experiences, balancing the advantages of both.

### Temporal-Difference vs Monte-Carlo vs Dynamic Programming

**Temporal-Difference vs Monte-Carlo vs Dynamic Programming**: In temporal difference learning the value function is updated based on difference between current and future rewards. Conversely, in **Monte Carlo approach**, the values are estimated based on total observed returns over the course of entire episode (sequence of states in a single run), and values are updated once every episode. Considering that entire trajectory of episode needs to be completed before value is updated, this is a known weakness of the Monte Carlo approach. Dynamic programming involves decomposing the problem into subproblems, and iteratively solving the problems. While dynamic programming algorithms are fundamental in building algorithms and are useful for known domains and finite state-action spaces, their computational complexity, time and memory requirements, are not scalable to large state-action spaces, and not suitable for environments with uncertainties.

### On-Policy vs Off-Policy

**On-policy vs off-policy algorithms**: On-policy algorithms immediately follow the policy (take action), as the policy is being learned and updated. In case of off-policy algorithms, a target-policy is learned, while a separate policy (behavioral policy) is used for following the policy (by taking action).

### Single-Agent vs Multi-Agent

**Single-agent vs Multi-agent algorithms**: Single-agent algorithms involve a single-agent interacting in the environment learning to achieve a goal. Multi-agent algorithms involve multiple agents interacting with each other in the environment collaborating, competing against or contributing independently towards a goal or a set of goals. There is coordination and communication between these agents, and sometimes it is an integration of multiple single agents.

### Tabular RL vs Function Approximation RL

**Tabular RL vs Function Approximation RL**: `Tabular RL` stores values and policies in tables explicitly, while in `Function Approximation RL` function approximators or models like neural networks are used to estimate value functions or policies, enabling them to handle large or continuous state and action spaces efficiently. `Tabular RL` are generally good for developing RL algorithms or understanding and gaining intuition, but are limited to smaller state-action spaces due to nature of their table storing property.
