## Integration with PPO and Model Initialization

You will find that the trained behavioral cloning model based on human expert trajectories is successful in inference. This is expected for a problem like mountain car with limited stochasticity in states, apart from the amount introduced during simulation settings. Since the `Agent` model is exactly the same as that used for `PPO`, we initialize the agent before starting `PPO` training. This gives the model a head start with a good initial policy. It also makes `PPO` training more of a fine-tuning on the trained behavioral cloning based policy. The only change we have to make in the previous `PPO` training script is to load the checkpoint saved for behavioral cloning based training, and add a conditional statement:

We started with discussing what involves policy training, limitations of Q-learning for scenarios when continuous systems are involved.
