
# Before DPO: Pretraining

Before DPO, the networks are pretrained to imitate the synthetic action data, providing a strong initialization. We'll train our frame encoder and policy network to predict the correct steering action for each frame using supervised learning. This gives us:

* A **reference policy** for DPO training – a strong baseline.
* Pretrained networks that understand basic driving patterns.

## Behavioral Cloning Pretraining

The following snippet of code shows pretraining for behavioral cloning based initialization.

```
# Train encoder + policy_ref on frame->action supervised data (behavior cloning)
bc_epochs = 3
bc_batch = 64
dataset = torch.utils.data.TensorDataset(frames_all, actions_all)
loader = DataLoader(dataset, batch_size=bc_batch, shuffle=True)
opt = optim.Adam(list(frame_encoder.parameters()) + list(policy_ref.parameters()), lr=3e-4)
for ep in range(bc_epochs):
    total_loss = 0.0
    for xb, yb in loader:
        xb = xb.to(DEVICE); yb = yb.to(DEVICE)
        emb = frame_encoder(xb)
        logits = policy_ref(emb)
        loss = F.cross_entropy(logits, yb)
        opt.zero_grad(); loss.backward(); opt.step()
        total_loss += loss.item() * xb.size(0)
    print(f"BC epoch {ep+1}/{bc_epochs} loss: {total_loss/len(dataset):.4f}")
# Save a copy of reference policy logits function (we'll use it for KL)
policy_ref.eval()
frame_encoder.eval()
```

# Direct Preference Optimization (DPO) Training

**Direct Preference Optimization (DPO)** fine-tunes a policy using preference-labeled trajectory pairs. Unlike RLHF approaches that rely on an explicit reward model, DPO directly optimizes the policy to align with human preferences. We covered this in significant depth in *Chapter 10*. Here, we are applying the same for the motion control application.

Some important entities in our setup are as follows:

* **Reference policy**: The **behavior cloning (BC)** model, acting as the baseline as discussed in the last section.
* **Preference source**: Trajectory comparisons based on smoothness scores.
* **Loss function**: Binary cross-entropy on the probability of preferring one trajectory over another.
* **Regularization**: KL penalty to prevent the fine-tuned policy from drifting too far from the reference.

The training process follows these steps:

1. Sample pairs of trajectories from the dataset.
2. Score each trajectory using the preference function.
3. Optimize the policy to increase the likelihood of preferred trajectories.
4. Regularize with a KL term towards the reference policy.

We now walk through the implementation, breaking it into key stages.

## Step 1 — Initialize Policy and Hyperparameters

We start with a copy of the reference policy (BC based model) and prepare the optimizer and DPO hyperparameters.

```
policy_theta = SimplePolicy(emb_dim=128, num_actions=3).to(DEVICE)
policy_theta.load_state_dict(policy_ref.state_dict())
dpo_epochs = 6
dpo_lr = 1e-3
kl_coef = 0.02 # KL penalty towards reference
temp = 1.0 # temperature scaling
opt_theta = optim.Adam(policy_theta.parameters(), lr=dpo_lr)
```

### Freeze the Reference Policy

To keep the reference fixed during fine-tuning, we set `requires_grad` to `False`.

```
for param in policy_ref.parameters():
    param.requires_grad = False
```

Next, we define two helper functions used in DPO training.

## Step 2 — Utility Functions

Compute trajectory log-probabilities under a given policy, and the KL divergence between the trainable and reference policies.

```
def batch_traj_logprobs(policy, frames, actions):
    B,T,C,H,W = frames.shape
    emb = frame_encoder(frames.view(B*T,C,H,W).to(DEVICE))
    logits = policy(emb).view(B, T, -1)
    logp = F.log_softmax(logits, dim=-1)
    sel = logp.gather(2, actions.unsqueeze(-1).to(DEVICE)).squeeze(-1)
    return sel.sum(dim=1) # per-trajectory

def batch_kl_policy(p_theta, p_ref, frames):
    B,T,C,H,W = frames.shape
    emb = frame_encoder(frames.view(B*T,C,H,W).to(DEVICE))
    logp_theta = F.log_softmax(p_theta(emb).view(B,T,-1), dim=-1)
    p_ref_probs = F.softmax(p_ref(emb).view(B,T,-1).detach(), dim=-1)
    return F.kl_div(logp_theta, p_ref_probs, reduction='batchmean')
```

## Step 3 — Training Loop

Each batch contains paired trajectories (A, B) and a label (0 = A preferred, 1 = B preferred). We compute DPO loss and optionally apply a KL penalty.

```
for ep in range(dpo_epochs):
    total_loss = 0.0
    for idx in torch.randperm(len(pairs)).split(BATCH):
        batch = [(pairs[i], labels[i]) for i in idx]
      
        def prep(frames_actions):
            frames, acts = zip(*frames_actions)
            f = torch.stack([torch.tensor(fr/255.0).permute(0,3,1,2) for fr in frames])
            a = torch.stack([torch.tensor(ac, dtype=torch.long) for ac in acts])
            return f.to(DEVICE), a.to(DEVICE)
        A_frames, A_actions = prep([clips[ia] for (ia, ib), _ in batch])
        B_frames, B_actions = prep([clips[ib] for (ia, ib), _ in batch])
        logp_A = batch_traj_logprobs(policy_theta, A_frames, A_actions)
        logp_B = batch_traj_logprobs(policy_theta, B_frames, B_actions)
        logp_A_ref = batch_traj_logprobs(policy_ref, A_frames, A_actions)
        logp_B_ref = batch_traj_logprobs(policy_ref, B_frames, B_actions)
        targets = torch.tensor([1.0 if lab==0 else 0.0 for _, lab in batch], device=DEVICE)
        logits = ((logp_A - logp_A_ref) - (logp_B - logp_B_ref)) / temp
        loss_pref = F.binary_cross_entropy_with_logits(logits, targets)
        if kl_coef > 0:
            loss = loss_pref + kl_coef * 0.5 * (
                batch_kl_policy(policy_theta, policy_ref, A_frames) +
                batch_kl_policy(policy_theta, policy_ref, B_frames)
            )
        else:
            loss = loss_pref
        opt_theta.zero_grad()
        loss.backward()
        opt_theta.step()
        total_loss += loss.item() * len(batch)
    print(f"DPO Epoch {ep+1}/{dpo_epochs}, loss {total_loss/len(pairs):.4f}")
```
