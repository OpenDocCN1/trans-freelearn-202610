## Agent Class (`agent.py`)

The `Agent` class combines two main components: an `actor` and a `critic`. The `actor` suggests actions to take based on the current state of the environment, while the `critic` evaluates how good those actions are, providing feedback to improve future decision-making. We will go over all the methods from `Agent` class as follows.

### Initialization (`__init__` method)

The constructor takes a vectorized environment (`envs`) as input. This allows the agent to operate in either a single environment or multiple environments simultaneously. This method checks whether the environment is a vectorized one and extracts the shape of the observation and action spaces. The agent determines if the action space is discrete (e.g., selecting from a finite set of actions) or continuous (e.g., producing a range of values). This distinction affects how actions are sampled and evaluated. The following snippet shows the initialization method.

```python
def __init__(self, envs):
    super().__init__()
    if isinstance(envs, vector.VectorEnv):
        # Multi-environment case
        env_shape = envs.single_observation_space.shape
        env_action_shape = envs.single_action_space.shape
    else:
        # Single environment case
        env_shape = envs.observation_space.shape
        env_action_shape = envs.action_space.shape
    # Determine if the action space is discrete or continuous
    if len(env_action_shape) == 1 and env_action_shape[0] > 1:
        # Discrete action space
        self.is_discrete = True
        self.num_actions = env_action_shape[0]
    elif len(env_action_shape) == 1 and env_action_shape[0] == 1:
        # Single action case; could be treated as continuous
        self.is_discrete = False
    else:
        # Assume continuous action space
        self.is_discrete = False
```

### Critic Network

The `critic` is defined as a neural network that takes the state as input and outputs a single value, representing the estimated value of that state. This network has two hidden layers, each with 64 units and `Tanh` activation functions. The final layer outputs a single value, initialized with a standard deviation of 1.0 to control the variance of the output. A larger standard deviation allows for more variability in the value outputs, which is essential for:

*   **Flexibility in Value Estimation**: It provides the critic with the capacity to learn a wider range of value estimates. This is particularly important in environments where the range of possible state values can be quite large, e.g. continuous environments such as the continuous mountain car, or any of the continuous control environment in the gymnasium library.
*   **Preventing Early Convergence**: By allowing a higher variance initially, the critic can adapt better to the learning dynamics of the agent, which helps in distinguishing between good and bad actions more effectively during training.

```python
# Define the critic network
self.critic = nn.Sequential(
    self.layer_init(nn.Linear(np.prod(env_shape), 64)),
    nn.Tanh(),
    self.layer_init(nn.Linear(64, 64)),
    nn.Tanh(),
    self.layer_init(nn.Linear(64, 1), std=1.0),
)
```

### Actor Network

Similar structure to the critic but outputs the mean action. The last layer is initialized with a small standard deviation; a small value means that the actions sampled from the actor's output will be very close to the mean action. In practical terms, the agent will produce actions that are tightly clustered around this mean, leading to consistent and less variable actions.

```python
# Define the actor network
self.actor_mean = nn.Sequential(
    self.layer_init(nn.Linear(np.prod(env_shape), 64)),
    nn.Tanh(),
    self.layer_init(nn.Linear(64, 64)),
    nn.Tanh(),
    self.layer_init(nn.Linear(64, np.prod(env_action_shape)), std=0.01),
)
# For continuous action space
if not self.is_discrete:
    self.actor_logstd = nn.Parameter(torch.zeros(1, np.prod(env_action_shape)))
```

In practice, the combination of these two standard deviations of `actor` and `critic` supports a training process where the agent starts by exploring a wider range of actions and then gradually stabilizes around effective actions while still receiving diverse feedback on the value of different states.

### Handling Continuous Actions

For continuous actions, an additional parameter for the action's standard deviation is created. This allows the agent to model the uncertainty in continuous actions, which is important for effective sampling from the action distribution.

```python
# For continuous action space
if not self.is_discrete:
    self.actor_logstd = nn.Parameter(torch.zeros(1, np.prod(env_action_shape)))
```

Instead of directly using a standard deviation, the actor maintains a log standard deviation parameter, which allows for numerical stability (logarithmic values are less likely to result in numerical underflow when calculating probabilities) and flexibility (it can be adjusted during training, allowing the agent to learn to explore more if necessary).

### Methods

The `get_value` method takes a state as input and returns its estimated value from the critic network.

```python
def get_value(self, x):
    """Returns the value of the input state."""
    return self.critic(x)
```

The `get_action_and_value` method computes the action to take based on the current state and returns the selected action, which could be sampled (for exploration) or provided (for evaluation) using log probability of that action. This sampling can be useful for calculating the loss during training, the entropy of the action distribution, promoting exploration by encouraging the agent to take a diverse set of actions, and the value of the input state from the critic, providing feedback on how favorable that state is for the agent.
