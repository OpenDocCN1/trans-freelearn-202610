
## Training the Reward Model

### Training Loop

It iterates for a specified number of epochs (`num_epochs`). Each epoch represents a complete pass through the entire training dataset. Within each epoch, it shuffles the data (`data`) using `np.random.shuffle` to avoid biases during training. This ensures the model sees examples from the entire dataset in different orders throughout training. It processes the data in mini-batches (`batch_size`). Batching improves training efficiency by utilizing hardware resources better. Here, it iterates through the data in chunks of size `batch_size`. For each batch, it extracts the states, next states, and corresponding rewards from the current batch. It converts these data points into PyTorch tensors – states and next states are converted to floating-point tensors (`dtype=torch.float32`) as the model expects numerical inputs. Rewards are also converted to tensors for efficient computation. It zeroes the gradients accumulated in the optimizer (`optimizer.zero_grad()`) before each update. This is necessary to prepare for backpropagation in each step. It then feeds the state and next state tensors into the `RewardModel` to get the model's predicted rewards for the current state transitions. Using the predicted rewards, it calculates the MSE loss between the predicted rewards (`predictions`) and the actual rewards (`rewards`) using the criterion, and performs backpropagation. The calculated loss (`loss`) is backpropagated through the network to compute the gradients of the loss with respect to each model parameter. Then, it updates the model's weights using the optimizer (`optimizer.step()`) based on the computed gradients. This step adjusts the model's internal parameters to reduce the loss and improve its prediction accuracy. It also keeps track of the loss for each batch and appends it to a list `batch_losses`. After iterating through all batches in an epoch, it calculates the average loss (`avg_loss`) for that epoch. Then, it prints the current epoch number, total number of epochs, and the average loss for this epoch. This provides information on the training progress.

### Returning the Trained Model

After completing all epochs, the function returns the trained `reward_model`. This model has learned to predict rewards based on the simulated human feedback data. It can then be used by an RL agent to guide its decision-making process in the actual environment.

By iteratively training with the simulated human feedback, the `RewardModel` learns the relationship between state transitions and desired rewards. This knowledge allows the model to predict rewards for unseen states, enabling the RL agent to navigate the environment and achieve goals that are considered favorable by humans.

The `generate_human_feedback` function can be presented by a random function that generates states, next states and corresponding rewards by calling the `simulate_human_reward` function, as seen in the snippet here:

```python
def generate_human_feedback(grid_size, actions, goal_position, obstacle_positions, num_samples):
    # actions = [(0, 1), (0, -1), (1, 0), (-1, 0)]
    data = []
    for _ in range(num_samples):
        state = (np.random.randint(0, grid_size[0]), np.random.randint(0, grid_size[1]))
        action = actions[np.random.choice(len(actions))]
        next_state = (state[0] + action[0], state[1] + action[1])
        rewards = simulate_human_reward(state, next_state, goal_position, obstacle_positions)
        data.append((state, next_state, rewards))
    return data
```

Upon generating human reward and training the reward model, the main execution code uses the `torch.save` function to save the internal state dictionary (`state_dict()`) of the trained `reward_model` to a file named `reward_model.pth`. This file captures the learned weights and biases of the model, allowing it to be loaded and used later. The trained model is then saved for potential future use by an RL agent.

### Subclass with Neural Network-based Reward Model

The `GridWorldWithNNReward` class inherits from the `GridWorld` class and adds functionalities to use the trained reward model. First, it calls the parent class constructor to set up the grid world environment. It loads the pre-trained reward model from the specified path (`reward_model_path`) using the `load_reward_model` function. It sets the loaded model in evaluation mode (`model.eval()`) to disable dropout layers (if used) during prediction.

```python
# Subclass with Neural Network-based Reward Model
class GridWorldWithNNReward(GridWorld):
    def __init__(self, grid_size, obstacle_positions, reward_model_path):
        super().__init__(grid_size, obstacle_positions)
        self.reward_model = self.load_reward_model(reward_model_path)
        self.reward_model.eval()
```

### Loading the Reward Model

The `load_reward_model` function creates a new `RewardModel` instance with the same architecture as the trained model (`state_size`, `hidden_size`, `output_size`). It loads the weights and biases from the saved model file (`reward_model.pth`) using `torch.load`. Then, it returns the loaded model.

```python
    def load_reward_model(self, path):
        model = RewardModel(state_size=2, hidden_size=64, output_size=3)
        model.load_state_dict(torch.load(path))
        return model
```

### Updated Q-Learning with Neural Network Reward

The previous `q_learning` function is updated with the integration of the neural network-based reward model, as `q_learning_with_nn_reward`. The detailed function is available in the repository of Chapter 3, under the file name `q_learning_rm.py`. The changes involve converting states and next states to tensors. Then querying the trained reward model that was loaded, with the tensor state and next state, to get the predicted rewards for progress, safety, and goal efficiency. It combines these into a single reward value and clips the reward value to a defined range (e.g., -5 to 10) to avoid extreme outliers.

```python
tensor_state = torch.tensor(state, dtype=torch.float32).unsqueeze(0)
tensor_next_state = torch.tensor(next_state, dtype=torch.float32).unsqueeze(0)
rewards_nn = self.reward_model(tensor_state, tensor_next_state)
progress_reward, safety_reward, goal_efficiency_reward = rewards_nn.squeeze(0).detach().numpy()
reward = progress_reward + safety_reward + goal_efficiency_reward
reward = np.clip(reward, -5, 10)  # Clip reward
```
