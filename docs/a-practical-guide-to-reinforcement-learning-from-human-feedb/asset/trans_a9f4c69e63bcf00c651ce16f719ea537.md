

## RLCD

RLCD 通过正向和负向提示词生成对比响应。一个用于生成 RLCD 响应对的简单示例函数如下：

```python
def generate_response(prompt, max_length=50):
    inputs = tokenizer(prompt, return_tensors="pt")
    output = model.generate(**inputs, max_length=max_length, do_sample=True, temperature=0.7)
    return tokenizer.decode(output[0], skip_special_tokens=True)
```

```python
def rlcd_generate_preference_pair():
    pos_prompt = "Describe the weather in an optimistic way."
    neg_prompt = "Describe the weather in a depressing way."
    response_pos = generate_response(pos_prompt)
    response_neg = generate_response(neg_prompt)   
    return response_pos, response_neg  # Preference pairs
```

RLCD 通过提示词工程生成对比偏好对，为人工标注比较提供了一种可扩展的替代方案，减少了标签噪声并提高了对齐质量。然而，它仍然依赖奖励模型。简化对齐的下一步是完全绕过奖励建模——通过直接大模型对齐。

## 直接大模型对齐

虽然 **RLCD** 消除了对人工标注的需求，但它仍然需要精心设计提示词来生成对比对。此外，它依赖教师模型来指导学习过程，这增加了训练流水线的复杂性，如果教师模型没有完美对齐，可能会导致效率低下。DLMA 利用对比提示词对自动生成偏好数据，然后使用相同的对比方法进行评估以计算自奖励分数。该方法无需人工标注的偏好数据即可实现对齐，并且当与 **直接偏好优化 (DPO)** 结合时，在某些情况下优于传统的 RLHF。DPO 替换了策略优化中的强化学习步骤，将在第 10 章中详细讨论。DLMA 不需要显式奖励模型，而是通过对比评分来评估其自发生成的数据，使奖励建模过程变得隐式且自动化。自奖励机制为响应分配数值偏好分数，使模型能够在不依赖外部奖励的情况下微调自身。DPO 直接使用这些自发生成的偏好对对模型进行微调。与 RLHF 中的 PPO 不同，DPO 无需在线强化学习即可对齐模型，减少了不稳定性并简化了训练过程。要深入了解 DLMA 的实现，可以参考论文《Direct Language Model Alignment from Online Feedback》：[https://arxiv.org/abs/2402.04792](https://arxiv.org/abs/2402.04792)。要实现 DLMA 的偏好数据生成和评分，并与 RLCD 进行比较，可以按如下方式实现一个简单的片段。首先编写一个使用全序列对数概率计算自奖励分数的函数。`dlma_generate_and_score` 函数生成多个响应，并根据 token 对数概率分配自奖励分数。用于计算整个响应序列归一化对数概率分数的函数 `compute_log_prob` 有助于计算序列上的平均对数概率，该概率用作响应的分数。logits 计算首先忽略最后一个 token，因为它不用于输入 `outputs.logits[:, :-1, :]`。使用 `inputs.input_ids[:, 1:]` 移位标签以与 logits 对齐，然后使用 `torch.nn.functional.log_softmax` 计算对数概率 `log_probs`，这实际上将这些 logits 转换为**整个词表**上的对数概率（通过 `log_softmax` 转换的 logits）。`log_probs` 的 gather 方法有助于提取序列中每个位置**仅正确下一个 token** 的对数概率。

```python
def dlma_generate_and_score():
    prompt = "Describe the weather today, with extreme optimism or pessimism."
    response_1 = generate_response(prompt)
    response_2 = generate_response(prompt)
    def compute_log_prob(response):
        inputs = tokenizer(response, return_tensors="pt")
        with torch.no_grad():
            outputs = model(**inputs)
            logits = outputs.logits[:, :-1, :]
            labels = inputs.input_ids[:, 1:]
            log_probs = torch.nn.functional.log_softmax(logits, dim=-1)
            selected_log_probs = log_probs.gather(2, labels.unsqueeze(-1)).squeeze(-1) 
            return selected_log_probs.mean().item()
    score_1 = compute_log_prob(response_1)
    score_2 = compute_log_prob(response_2)
    return (response_1, score_1), (response_2, score_2)
```

我们取**平均对数概率**来为整体响应评分，给出一个**单一数字**作为**自奖励分数。** 你可以尝试本章目录下 github 仓库中的笔记本 `RLCD_DLMA_play.ipynb`。尝试更改提示词以获得另一个示例。请注意，DLMA 生成响应并对其进行评分，相比之下，RLCD 生成一对可以由另一个模型评分的响应。

## 自我改进方法

自我改进方法不使用显式反馈，而是基于生成的示例和自我评估进行自我改进。因此，除非经过精心设置和设计，它们可能具有潜在的不稳定性。但它们确实只需要极少的人工参与。

### 可回溯自回归推理

RAIN 代表一种方法，它使冻结的预训练 LLMs 能够在无需任何额外训练或参数更新的情况下改进对齐。该方法集成了自我评估和**回溯**机制，允许模型评估其自身的生成，并利用这些评估来指导回溯和重新生成以提高安全性。RAIN 的关键方面涉及在 token 集合上进行树搜索，并动态降低有害 token 集合的权重，从这些 token 集合向后回溯并向前生成其他 token，直到输出被自我评估为无害。该方法模仿了人类在说话前深思熟虑、权衡和反思后果的行为模式。值得注意的是，RAIN 在无需额外对齐数据或梯度计算的情况下运行，并在保持有用性的同时提高了 LLaMA 30B 的无害率。你可以在此查看更多：RAIN: Your Language Models Can Align Themselves without Finetuning: [https://arxiv.org/abs/2309.07124](https://arxiv.org/abs/2309.07124)。
