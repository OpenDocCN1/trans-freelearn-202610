```python
def interpretable_aesthetic_score(prompt):
    score = 0
    explanation = []
    if "minimalist" in prompt:
        score += 2
        explanation.append("minimalist: +2 (clean, simple)")
    if "cozy" in prompt:
        score += 2

    if "cluttered" in prompt:

    if "warm" in prompt:
        score += 1
        explanation.append("warm: +1 (welcoming)")
    if "luxurious" in prompt:
        score += 1
        explanation.append("luxurious: +1 (premium)")
    return score, explanation
```

## Creating Pairwise Preference Dataset for Training

Like previous chapters on RLHF and DPO, preference pairs differentiating good and bad examples are useful here. We use the scoring function to simulate human preferences across image pairs:

```python
pairs = []
num_pairs = 100
for _ in range(num_pairs):
    idx_a, idx_b = random.sample(range(len(prompts)), 2)
    score_a, explanation_a = interpretable_aesthetic_score(prompts[idx_a])
    score_b, explanation_b = interpretable_aesthetic_score(prompts[idx_b])
    preferred = idx_a if score_a >= score_b else idx_b
    if random.random() < 0.05:
        print(f"\nPrompt A: {prompts[idx_a]}\nScore: {score_a}\n{', '.join(explanation_a)}")
        print(f"Prompt B: {prompts[idx_b]}\nScore: {score_b}\n{', '.join(explanation_b)}")
        print(f"Preferred: {'A' if preferred == idx_a else 'B'}")
    pairs.append((idx_a, idx_b, preferred))
```

These pairs represent preference labels used for training a reward model. We then define a custom PyTorch dataset class to load image pairs and their preference labels:

```python
transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
])

class PreferenceDataset(Dataset):
    def __init__(self, pairs, prompts, transform):
        self.pairs = pairs
        self.prompts = prompts
        self.transform = transform

    def __len__(self):
        return len(self.pairs)

    def __getitem__(self, idx):
        idx_a, idx_b, preferred_idx = self.pairs[idx]
        img_a = Image.open(f"images/image_{idx_a}.png").convert("RGB")
        img_b = Image.open(f"images/image_{idx_b}.png").convert("RGB")
        img_a = self.transform(img_a)
        img_b = self.transform(img_b)
        label = 1 if preferred_idx == idx_a else 0
        return img_a, img_b, label
```

The preference pairs, prompts, and transform can be easily loaded into the dataset, and `torch` dataloader allows loading them in batches.

```python
dataset = PreferenceDataset(pairs, prompts, transform)
dataloader = DataLoader(dataset, batch_size=4, shuffle=True)
```

## Reward Model Setup and Architecture

For setting up the reward model and the training architecture, we begin by leveraging a pretrained `ResNet-18` as our image encoder. By replacing its final fully connected classification layer with an identity function, we retain the rich 512-dimensional feature representations from its penultimate layer.

```python
feature_extractor = models.resnet18(pretrained=True)
feature_extractor.fc = nn.Identity()
```

Unlike traditional feature extraction, we allow the full model to be fine-tuned — enabling our reward model to adapt more directly to aesthetic signals, even in earlier convolutional layers.

```python
for param in feature_extractor.parameters():
    param.requires_grad = True
```

Next, we define a small `reward head` that maps the 512-dimensional image embedding to a single scalar reward:

```python
reward_head = nn.Sequential(
    nn.Linear(512, 128),
    nn.ReLU(),
    nn.Linear(128, 1)
)
```

The full reward model can be instantiated as shown in the `RewardModel` class. We then stack a small MLP to output a scalar reward.

```python
class RewardModel(nn.Module):
    def __init__(self, backbone, head):
        super().__init__()
        self.backbone = backbone
        self.head = head

    def forward(self, x):
        features = self.backbone(x)
        return self.head(features)

reward_model = RewardModel(feature_extractor, reward_head).cuda()
```

## Learning from Pairwise Preferences

The reward model is trained using the pairwise preference loss. For each labeled pair of images (A preferred over B or vice versa), we compute their respective scores and penalize the model if the less preferred image receives a higher score.

```python
optimizer = optim.Adam(reward_model.parameters(), lr=1e-4)
epochs = 10
for epoch in range(epochs):
    running_loss = 0.0
    for img_a, img_b, label in dataloader:
        img_a = img_a.cuda()
        img_b = img_b.cuda()
        label = label.cuda().float()
        score_a = reward_model(img_a).squeeze()
        score_b = reward_model(img_b).squeeze()
        pref_diff = score_a - score_b
        loss = torch.mean(torch.relu(1.0 - (pref_diff * (2 * label - 1))))
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        running_loss += loss.item()
    print(f"Epoch [{epoch+1}/{epochs}], Loss: {running_loss/len(dataloader):.4f}")
```

This formulation allows the reward model to approximate the underlying aesthetic function used implicitly by human annotators. Once trained, the reward model can evaluate the aesthetic quality of unseen images.

```python
for i in range(3):
    img = Image.open(f"images/image_{i}.png").convert("RGB")
    img_tensor = transform(img).unsqueeze(0).cuda()
    score = reward_model(img_tensor).item()
    print(f"Image {i} score: {score:.2f} — Prompt: {prompts[i]}")
    display(img)
```
