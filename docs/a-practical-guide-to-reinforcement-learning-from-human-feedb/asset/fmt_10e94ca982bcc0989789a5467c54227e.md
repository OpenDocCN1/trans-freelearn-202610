
# Q-Learning Implementation

## Main Training Loop

### Episode Initialization

```
for episode in range(1, num_episodes + 1):
    state = self.start_position
    total_reward = 0
    steps = 0
    visited_states = [state]
```

### Action Selection

This code snippet implements the action selection mechanism using an epsilon-greedy strategy. With probability `epsilon`, a random action is chosen (exploration), and with probability `(1 - epsilon)`, the best-known action is selected (exploitation).

```
while state != self.goal_position:
    if np.random.rand() < epsilon:
        action = np.random.choice(self.num_actions)
    else:
        action = np.argmax(self.Q_values[self.state_to_index(state)])
```

### State Transition and Reward Assignment

This snippet computes the next state based on the current state and chosen action. It assigns a reward based on the outcome: a positive reward of `10` for reaching the goal, a negative reward of `-5` for hitting an obstacle, and a default penalty of `-1` for each step taken.

```
next_state = self.get_next_state(state, self.actions[action])
reward = -1
if next_state == self.goal_position:
    reward = 10
elif next_state in self.obstacle_positions:
    reward = -5
```

### Update Q-values

Here we update the Q-value for the current state-action pair using the Q-learning update rule. The target value is the reward plus the discounted maximum future reward, and the Q-value is updated to reduce the difference between the target and the current estimate.

```
target = reward + discount_factor * np.max(self.Q_values[self.state_to_index(next_state)])
self.Q_values[self.state_to_index(state), action] += learning_rate * (target - self.Q_values[self.state_to_index(state), action])
```

### State Transition, Update and Tracking

This snippet updates the total reward and steps for the current episode, transitions to the next state, and tracks the visited states.

```
total_reward += reward
state = next_state
steps += 1
visited_states.append(state)
```

### Tracking Reward and Steps

The below snippet adds total reward and the number of steps for the current episode to their respective lists for later analysis.

```
rewards.append(total_reward)
steps_per_episode.append(steps)
```

### Policy Checkpointing for Evaluation

This snippet stores the current policy at specified checkpoints. It uses the `get_optimal_policy` method for evaluation. It also prints progress information every 20 episodes for monitoring purposes.

```
if episode in policy_checkpoints:
    policy_progress.append((self.get_optimal_policy(), visited_states, episode))
if episode % 20 == 0:
    print(f"Episode {episode}/{num_episodes}, Total Reward: {total_reward}, Steps: {steps}")
```

### Return Output

Once all episodes are completed, the below line returns the collected rewards, steps per episode, and policy progress.

```
return rewards, steps_per_episode, policy_progress
```

## Optimal Policy Extraction

### get_optimal_policy Method

In order to help logging and checkpointing policy, a `get_optimal_policy` method is added. Here, every grid cell is assigned an argmax of Q-value as optimal policy, with invalid actions such as those when state is in goal position or obstacle position as `-1`. This function efficiently calculates the optimal policy for a grid-based environment considering the constraints of goal and obstacle states. The snippet below defines the `get_optimal_policy` function and initializes a matrix `optimal_policy` with the same dimensions as the grid. The matrix is filled with zeros and will store the optimal actions for each state.

```
def get_optimal_policy(self):
    optimal_policy = np.zeros(self.grid_size, dtype=int)
```

Then, the function iterates through each cell in the grid, treating each cell as a state. The nested loops ensure that every state in the grid is processed.

```
for i in range(self.grid_size[0]):
    for j in range(self.grid_size[1]):
        state = (i, j)
```

It then checks if the current state is the goal state or an obstacle state. If so, it sets the corresponding entry in `optimal_policy` to `-1`, indicating that these states have no applicable actions.

```
if state == self.goal_position:
    optimal_policy[i, j] = -1
elif state in self.obstacle_positions:
    optimal_policy[i, j] = -1
```

Once check for goal or obstacle state is cleared, the function collects valid actions by storing them in `valid_actions` list. It iterates through all possible actions, calculates the resulting next state, and checks if the next state is valid.

```
else:
    valid_actions = []
    for action in range(self.num_actions):
        next_state = self.get_next_state(state, self.actions[action])
        if self.is_valid_state(next_state):
            valid_actions.append(action)
```

To find the optimal policy, it uses the Q-values to find the action with the highest value. If there are no valid actions, it sets the entry to `-1`. It then returns the optimal policy.

```
if valid_actions:
    optimal_policy[i, j] = np.argmax([self.Q_values[self.state_to_index(state), a] for a in valid_actions])
else:
    optimal_policy[i, j] = -1  # No valid action
return optimal_policy
```

## Visualization and Tracking Progress

In order to track and visualize learning progress, three plotting methods are also added that show reward per episode, and number of steps taken by agent to reach goal state per episode and the policy progress.

### Rewards vs Episode

The below code plots rewards vs episode showing the performance of Q-learning algorithm.

```
def plot_rewards(self, rewards):
    plt.plot(rewards)
    plt.xlabel('Episode')
    plt.ylabel('Total Reward')
    plt.title('Q-learning Performance')
    plt.show()
```

The plot below in *Figure 1.2* shows Q-learning performance over all training episodes executed. Here x-axis is episodes, and y-axis is total episode reward. Initial sharp rise shows that policy converges in about 50 episodes.

### Number of Steps per Episode

Steps needed to reach the goal per episode can be plotted by implementing the code below. This visualization is to track how the number of iterations required to reach the goal reduces as the agent learns.

```
def plot_steps_per_episode(self, steps_per_episode):
    plt.plot(steps_per_episode)
    plt.xlabel('Episode')
    plt.ylabel('Steps')
    plt.title('Steps per Episode')
    plt.show()
    plt.tight_layout()
```
