
# Advantage Actor Critic: Variance Reduction using Baseline Subtraction

Vanilla policy gradients use the total return (sum of discounted rewards) to estimate the gradient of the policy. This return can be highly variable due to the stochastic nature of the environment and the agent's actions. High variance in the gradient estimates can lead to unstable training, where the policy updates can fluctuate wildly. This instability can make it difficult for the algorithm to converge to an optimal policy. Learning can be slow because the updates are noisy and less reliable.

To address this problem, instead of using the total discounted reward for each action, subtract a baseline to reduce variance. The baseline is typically an estimate of the expected return (e.g., the value function), and the difference between the reward and baseline is known as the advantage. We want to encourage actions that are better than average. Using the advantage function reduces variance by reducing the magnitude of policy updates for actions that have average or expected rewards. The value function is average expected return, and by using it as a baseline subtracted from total returns, makes sure that actions that lead to returns above average are considered. This new network is termed as the `Critic network`, and the policy network is termed the `Actor network`.

Incorporating the baseline subtraction trick using the advantage function `A(s,a)=R−V(s)` into the vanilla policy gradient algorithm reduces variance in the policy gradient estimates, leading to more stable and efficient learning. The addition of the value network (critic) allows the algorithm to better approximate the expected returns from each state, which results in more accurate policy updates.

These concepts are building blocks for on-policy `RL` algorithms. Note that the chronology of development from `VPG` to `A2C` to `GAE` has been a continuous improvement, and these early algorithms and concepts are not enough to solve more challenging problems, as they still do not resolve stability issues completely. Moreover, they require a large amount of training and experimentation of hyperparameters.

More sophisticated ideas have evolved over the last few years in addition to generalized advantage estimators introduced in the papers High-Dimensional Continuous Control Using Generalized Advantage Estimation: [https://arxiv.org/pdf/1506.02438](https://arxiv.org/pdf/1506.02438), e.g. Trust Region Policy Optimization (`TRPO`): [https://arxiv.org/abs/1502.05477](https://arxiv.org/abs/1502.05477) and Proximal Policy Optimization (`PPO`) Algorithms: [https://arxiv.org/abs/1707.06347](https://arxiv.org/abs/1707.06347) that help improve stability and sensitivity to hyperparameter tuning, and latter (`TRPO` and `PPO`) guarantee monotonic convergence also.
