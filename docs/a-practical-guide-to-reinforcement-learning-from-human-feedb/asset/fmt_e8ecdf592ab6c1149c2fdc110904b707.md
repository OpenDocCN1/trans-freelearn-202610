
# Constitutional AI Framework

The framework for implementing Constitutional AI involves first defining a set of core principles—a handful of foundational rules covering harm prevention, legality, fairness, and transparency. Some examples of such principles are:

- "Avoid promoting violence or illegal activities"
- "Maintain age-appropriate content"
- "Prioritize factual accuracy with source attribution"

At a more global level, these can be aligning with some organizational rules such as United Nations universal declaration of human rights: [https://www.un.org/en/about-us/universal-declaration-of-human-rights](https://www.un.org/en/about-us/universal-declaration-of-human-rights). These rules can be specific e.g. some product usage terms of services, copyright restrictions and allowances, lease agreements, or other specific constraints depending upon the AI model use case or application. While writing these rules, some hierarchy of rules can also be established so that in case of conflicts, a strict hierarchy of rules can help with decision making. An example of constitutional framework can be as shown here:

```yaml
principles:
- "Choose responses that prioritize human safety"
- "Avoid promoting illegal activities"
- "Maintain factual accuracy with citations"
- "Respect cultural sensitivities"
- "Protect personal privacy"
conflict_resolution:
  safety > privacy > accuracy
```

The constitutional rules are basis for the next steps in building the AI system that complies with these rules and improves harmlessness. The constitution provides the constraints for all the model alignment. The various stages of model training and refinement, specifically, the SL and RL stages are shown in Figure 9.1.

## Supervised Learning Stage

The supervised learning stage mainly consists of response generation, followed by AI critique and revision, after that iterative refinement of revised responses, the base model is fine-tuned. The response generation step involves using the base model to produce initial responses to diverse set of prompts, by applying topic-guided methods to ensure variety. Those responses are revised by deploying a critique model to evaluate responses against constitutional principles. During this step, the responses are evaluated in order to flag violations using the constitutional checklists, suggestions for revisions are generated, and responses are iteratively refined until final compliant response is acceptable. To aid you with visualizing how this can be implemented, see below snippet showing `ConstitutionalSL` class. For this, you can first import `AutoModelForCausalLM` and `AutoTokenizer` methods from `transformers` library as before. Initialize a base model, either one of the open source models from Hugging Face, or installing a base model you may have subscribed for. The class has a method `generate_with_critique()` that takes a prompt and generates raw response from the model. The `critique_prompt` string is an example prompt that checks the user prompt for any constitutional rule violations, suggests improvements, and calls the model to generate revised prompts.

```python
class ConstitutionalSL:
    def __init__(self, base_model="anthropic/claude-v2"):
        self.model = AutoModelForCausalLM.from_pretrained(base_model)
        self.tokenizer = AutoTokenizer.from_pretrained(base_model)
    def generate_with_critique(self, prompt):
       inputs = self.tokenizer(prompt, return_tensors="pt", padding=True, truncation=True, max_length=1024)
        raw_response_ids = self.model.generate(
            **inputs,
            max_length=1000,
            pad_token_id=self.tokenizer.eos_token_id,
            do_sample=True
        )
        raw_response = self.tokenizer.decode(raw_response_ids[0], skip_special_tokens=True)
        critique_prompt = f"""
        Critique this response against our constitution: {CONSTITUTION}
        Response: {raw_response}
        Identify violations and suggest improvements.
        """
        critique_inputs = self.tokenizer(critique_prompt, return_tensors="pt", padding=True, truncation=True, max_length=1024)
        critique_ids = self.model.generate(
            **critique_inputs,
            max_length=1000,
            pad_token_id=self.tokenizer.eos_token_id,  # Ensure pad_token_id is set
            do_sample=True
        )
        critique = self.tokenizer.decode(critique_ids[0], skip_special_tokens=True)
        revision_prompt = f"""
        Original prompt: {prompt}
        Critique: {critique}
        Provide improved response:
        """
        revision_inputs = self.tokenizer(revision_prompt, return_tensors="pt", padding=True, truncation=True, max_length=1024)
        improved_response_ids = self.model.generate(
            **revision_inputs,
            max_length=1000,
            pad_token_id=self.tokenizer.eos_token_id,  # Ensure pad_token_id is set
            do_sample=True
        )
        improved_response = self.tokenizer.decode(improved_response_ids[0], skip_special_tokens=True)
        return improved_response
```

The revised prompts help generate revised improved responses that are acceptable. These can now be used for fine-tuning the base model. Using the revised improved responses that are safe, the base model can be fine-tuned. An example implementation of `ConstitutionalSL` is added to the GitHub repository. The important aspect of the Constitutional AI method is integrating the new concept of constitutional aligned responses into fine-tuning and RLHF approach. Once the process of improving responses to be constitutionally aligned is completed, a dataset of such aligned responses can be collected and used in a supervised training loop to fine-tune a supervised learning model. An example training loop in the snippet below shows the function `sl_train_loop()`, a generic function for training the model. It first instantiates the constitutional model, and first generates revised response based on prompts in dataset. It uses standard cross-entropy loss with constitutional-compliant dataset to track fine-tuning progress, similar to standard training process.

```python
def sl_train_loop(dataset, num_epochs=3):
    constitutional_model = ConstitutionalSL()
   
    for epoch in range(num_epochs):
        for prompt in dataset:
            revised_response = constitutional_model.generate_with_critique(prompt)
           
            # Fine-tune with revised responses
            loss = constitutional_model.train_step(
                inputs=prompt,
                targets=revised_response
            )
            print(f"Epoch {epoch+1} Loss: {loss:.4f}")
```

Once the supervised model is fine-tuned, it can be used to generate response pairs. We will discuss this next.
