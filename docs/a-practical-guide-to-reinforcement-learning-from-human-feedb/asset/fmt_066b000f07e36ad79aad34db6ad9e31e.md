
# Visualize Policy Progress

To visualize clearly the trajectory of the agent as it takes steps towards the goal, until it reaches the goal, we implement the `plot_policy_progress` method. Here, the grid world is plotted with the entire trajectory traced by the agent. Such a trajectory can be visualized for every episode. But, only a few snapshots of episodes are enough to visualize progress. The below definition of the function and input sets up the figure with subplots, one for each checkpoint in the `policy_progress` list, by assigning `num_checkpoints`.

```
def plot_policy_progress(self, policy_progress):
    num_checkpoints = len(policy_progress)
    fig, axes = plt.subplots(1, num_checkpoints, figsize=(6*num_checkpoints, 6))
```

## Loop Through Checkpoints

Then, it starts a loop to process each checkpoint in `policy_progress`. It sets the title of each subplot to indicate the episode number.

```
for i, (policy, visited_states, episode) in enumerate(policy_progress):
    ax = axes[i]
    ax.set_title(f'Policy at Episode {episode}')
```

## Visual Representation of States

The function then iterates through each state in the policy grid. It sets the visual representation for the goal position, obstacles, start position, and other states, marking them with appropriate symbols and colors or styles.

```
for y in range(policy.shape[0]):
    for x in range(policy.shape[1]):
        state = (y, x)
        if state == self.goal_position:
            ax.text(x, self.grid_size[0] - y - 1, 'G', va='center', ha='center', fontsize=20)
            ax.add_patch(plt.Rectangle((x - 0.5, self.grid_size[0] - y - 1 - 0.5), 1, 1, color='lightgreen'))
        elif state in self.obstacle_positions:
            ax.text(x, self.grid_size[0] - y - 1, 'X', va='center', ha='center', fontsize=20)
            ax.add_patch(plt.Rectangle((x - 0.5, self.grid_size[0] - y - 1 - 0.5), 1, 1, color='lightgray'))
        elif state == self.start_position:
            ax.text(x, self.grid_size[0] - y - 1, 'S', va='center', ha='center', fontsize=20, color='red')
            ax.add_patch(plt.Rectangle((x - 0.5, self.grid_size[0] - y - 1 - 0.5), 1, 1, color='lightblue'))
        else:
            action = policy[y, x]
            ax.text(x, self.grid_size[0] - y - 1, self.action_symbols[action], va='center', ha='center', fontsize=20)
```

## Plotting the Agent Path and Configuring the Grid

The function then plots the path taken by the agent for each checkpoint, using lines to connect consecutive states. It also configures the grid lines and labels for the subplot to make the plot more readable.

```
for j in range(len(visited_states) - 1):
    x1, y1 = visited_states[j][1], self.grid_size[0] - visited_states[j][0] - 1
    x2, y2 = visited_states[j + 1][1], self.grid_size[0] - visited_states[j + 1][0] - 1
    ax.plot([x1, x2], [y1, y2], color='blue', linewidth=3)
    ax.set_xticks(np.arange(-0.5, policy.shape[1], 1))
    ax.set_yticks(np.arange(-0.5, policy.shape[0], 1))
    ax.grid(color='black', linestyle='-', linewidth=1)
    ax.set_xticklabels([])
    ax.set_yticklabels([])
    ax.set_xlabel('X')
    ax.set_ylabel('Y')
```


In the above q-learning implementation, the agent was able to learn how to reach the goal in a finite number of episodes. Visualization methods shown help to track learning progress. We use three obstacles and a grid size of 6 x 6, in this example. The training episodes required for convergence are ~50 for this problem, but this number can increase for a larger grid size or number of obstacles. Note that the `GridWorld` class allows parametrizing grid size and obstacle positions, making it convenient to modify the environment. We will use this parametrization in the following sections to explore strategies to improve learning progress.

## Designing Reward Functions and Transfer Learning

For the agent to learn desirable policy, in the Q-learning algorithm discussed in the preceding section, positive rewards are assigned to agents for desirable behavior, and negative rewards are assigned for undesirable behavior. In case of the gridworld problem, for every step taken by the agent, a negative reward `-1` assigned to the agent discourages it from taking more steps. Similarly, a large negative reward of `-5` assigned for every step agent takes that overlaps with the obstacles. A large negative reward helps with learning to avoid the obstacles. Finally, a large positive reward of `10` for reaching the goal encourages reaching the goal state. The reward assignment is itself the reward function, in this case, as restated below:

```
reward = -1
if next_state == self.goal_position:
    reward = 10
elif next_state in self.obstacle_positions:
    reward = -5
```

Notice that the reward function is discrete and works well for the grid world problem. There are cases where the reward function may need to be continuous. For example, if the grid has many cells e.g. *1000 x 1000*, with a few obstacles, a continuous reward with gradual increment as the agent gets closer to the goal will help in providing a meaningful result. If all rewards are `-1` except at the goal, the agent will wander longer. In such a case, we can redesign the reward assignment. One example is given below:

```
reward = -1 + np.exp(-0.1 * np.linalg.norm(np.array(state) - np.array(self.goal_position)))
if next_state in self.obstacle_positions:
    reward = reward - 5
```
