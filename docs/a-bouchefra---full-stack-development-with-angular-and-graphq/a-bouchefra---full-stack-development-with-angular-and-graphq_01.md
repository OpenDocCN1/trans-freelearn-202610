# 第 1 部分：设置开发环境、GraphQL 服务器和数据库

在本部分，我们将了解应用程序的架构和需求，并为全栈开发设置开发环境。我们还将使用 Express.js 和 Apollo 设置 GraphQL 服务器，并使用 TypeORM 连接 SQL 数据库以存储应用程序数据。

本节包含以下章节：

- 第 1 章，应用程序架构和开发环境
- 第 2 章，使用 Node.js、Express.js 和 Apollo 设置 GraphQL
- 第 3 章，使用 TypeORM 连接数据库
- 第 4 章，使用 Apollo Server 实现身份验证和图像上传
- 第 5 章，使用 Apollo Server 添加实时支持
