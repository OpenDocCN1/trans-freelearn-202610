Inside the body of the method, call the getCommentsByPostId() method of commentsService:

```
const qRef = this.commentsService
.getCommentsByPostId(e.postId);
```

Define the fetchMore() function, which simply wraps the fetchMore() method of the returned QueryRef object:

```
const fetchMore = () => {
  qRef.fetchMore({
    variables: {
      offset: this.comments
        .get(e.postId)?.result.length
    }
  })
}
```

Subscribe to the valueChanges Observable of the QueryRef object:

```
qRef
.valueChanges
.pipe(takeUntil(this.componentDestroyed))
.subscribe();
```

Pass the following observer object to the subscribe() method:

```
{
  next: (result) => {
    this.comments
      .set(
        e.postId,
        {
          result: result
            .data
            .getCommentsByPostId as Comment[],
          fetchMore: fetchMore
        });
  }
}
```
