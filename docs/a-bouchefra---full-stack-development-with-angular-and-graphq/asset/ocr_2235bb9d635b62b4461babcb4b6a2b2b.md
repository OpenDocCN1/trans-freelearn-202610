We use the `importDocumentNodeExternallyFrom` option, with `documentMode` set to `external` to import the base types generated with the `typescript-operations` plugin in their own file, which is `graphql-operations.ts` in our case, and we use the `importOperationTypesFrom` option to prefix them with the `Operations` prefix.

For more information, check out https://www.graphql-code-generator.com/docs/plugins/typescript-document-nodes.

This configuration was used to avoid generating the same basic types, document types, and GraphQL operations in each file. We create them once and import them from other files as needed. Check out all the available plugins at https://www.graphql-code-generator.com/docs/plugins/index.
