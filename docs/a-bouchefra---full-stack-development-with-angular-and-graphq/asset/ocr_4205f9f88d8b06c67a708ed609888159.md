In the submit() method, we check whether the password and password confirmation are the same and whether the form is valid.

If the form is not valid, we return from the method and set the errorMessage variable to a convenient error message. Next, we call the register() method of the injected authentication service, and then we subscribe to the returned Observable.

In the next handler of the observer object passed to the subscribe() method, which will be called if the subscription is successful, we retrieve the registered user ID from the registration response, display a success message using a snack-bar, then navigate to the user's profile using the navigateByUrl() method of the router.
