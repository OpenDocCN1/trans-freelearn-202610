get userFirstName() {

5. Make the following changes to the ngOnInit() method:

```
ngOnInit(): void {
  super.ngOnInit();
  const userObs = this.route.paramMap
    .pipe(
      switchMap((params: ParamMap) => {
        const userId = params.get('userId')!;
        return this.authService.getUser(userId);
      }),
      takeUntil(this.destroyNotifier)
    );
  userObs.subscribe({
    next: (userResponse) => {
      this.setProfileUser(userResponse.getUser);
      this.setIsAuthUserProfile();
    },
    error: (err) => super.handleErrors(err)
  });
}
```

We use the ActivatedRoute service to get the user ID from the profile URL, then we call the authentication service's getUser() method (manually injected into the base component), and subscribe to the returned observable to get the user identified by the user ID obtained.
