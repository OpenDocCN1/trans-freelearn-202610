8. Add the following method for hashing passwords in the server/src/graphql/resolvers.ts file:

```
const hashPassword = async (plainPassword: string):
Promise<string> => {
    return new Promise((resolve, reject) => {
        const bytes = crypto.randomBytes(16);
        const salt = bytes.toString("hex");
        crypto.scrypt(plainPassword, salt, 64,
        (error, buffer) => {
            if (error) reject(error);
            const hashedPassword =
                '${salt}:${buffer.toString('hex')}';
            resolve(hashedPassword);
        });
    })
};
```

We'll use this function to hash our passwords before saving them to the database using Scrypt – a salted hashing algorithm.
