```
}
}
},
```

We simply return the formatted `createdAt` date when the field is read using the `format()` method of the `timeago` object we just imported. You can learn more at https://timeago.org/.

Then, add a similar field policy to the Comment type:

```
Comment: {
    fields: {
        createdAt: {
            read(createdAt) {
                return timeago.format(createdAt)
            }
        }
    }
}
```

You can find out more about the `read()` function at https://www.apollographql.com/docs/react/caching/cache-field-behavior/#the-read-function.
