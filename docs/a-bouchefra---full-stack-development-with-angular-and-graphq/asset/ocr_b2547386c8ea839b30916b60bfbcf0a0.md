We can have a flat output of the JavaScript source files inside the dist/ folder without the src/ subfolder by changing the value of the rootDir property in the tsconfig.json file to src/:

```
{
  "compilerOptions": {
    "target": "es6",
    "module": "commonjs",
    "rootDir": "./src",
    "outDir": "./dist",
    "esModuleInterop": true,
    "strict": true
  }
}
```

Now, if we run our npm run build command again, we'll get the output in the dist/ folder without the src/ subfolder.
