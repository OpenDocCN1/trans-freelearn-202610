Simply open the src/app/app.module.ts file containing the application module to see this:

```
// [...]
import { AppComponent } from './app.component';

@NgModule({
  // [...]
  bootstrap: [AppComponent]
})
export class AppModule { }
```

The root component is also included in the src/index.html file, which is the file that gets downloaded when users visit your Angular application from a web browser:

```
<!doctype html>
<html lang="en">
<head>
  <!-- [...] -->
</head>
<body>
  <app-root></app-root>
</body>
</html>
```

Through its selector, you can see that the root component is being utilized exactly like a standard HTML tag. This instructs Angular to load the component and all of its descendant components into the DOM.

Open the app.component.ts file in the src/app directory. The root component should be defined using the following code:

```
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html',
  styleUrls: ['./app.component.css']
})
export class AppComponent {
```
