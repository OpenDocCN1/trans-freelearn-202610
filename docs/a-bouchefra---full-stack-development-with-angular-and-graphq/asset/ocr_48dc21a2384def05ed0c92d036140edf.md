17. Start with the register mutation to create a user with the provided information:

```
mutation {
  register(
    fullName: "Ahmed Bouchef ra"
    username: "ahmed.bouchefra"
    email: "ahmed@email.com"
    password: "123456789"
  ) {
    token
    user {
      id fullName username email password
    }
  }
}
```

This should create a user in the database and return the token, plus the ID, full name, and password of the saved user. The fullName, username, and email values submitted via the mutation parameters should be the same as the fields of the user's sub-selection, while the password value must be returned in an encrypted format.
