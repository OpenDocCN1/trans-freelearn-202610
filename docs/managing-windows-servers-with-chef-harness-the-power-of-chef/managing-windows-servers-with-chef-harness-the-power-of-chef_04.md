## 前言

欢迎阅读 *使用 Chef 管理 Windows 服务器*。本书旨在让你熟悉可帮助你使用 Chef 管理 Windows 主机的概念、工具和功能。在本书中，你将了解在 Windows 上使用 Chef 时的预期内容，如何开始使用它，以及 Chef 在管理 Windows 主机方面与 Linux 系统有何不同。书中包含了部署完整 .NET/IIS 应用程序堆栈、云集成以及一些关于开发和测试 Windows 和 Linux 主机异构网络的信息。

## 本书涵盖的内容

*第 1 章，Chef 和 Windows*，作为 Chef 对 Windows 支持的介绍，介绍了你可以在 Windows 平台上从 Chef 期望的功能类型，以及如何开始使用。

*第 2 章，安装客户端 – Chef 概念概述*，介绍了如何在 Windows 主机上安装客户端，以及 Chef 架构和术语的快速概述和其他重要信息，帮助你开始管理 Windows。

*第 3 章，Windows 特定资源*，向你介绍了通过 Chef 管理 Windows 所特有的资源。本章提供了每个资源的描述和示例，包括角色、功能、包安装程序、批处理脚本、Windows 注册表等更多内容。

*第 4 章，配置应用程序堆栈*，提供了配置完整应用程序堆栈（.NET 框架、IIS 配置、数据库服务器安装等）的实践指南，包括定义角色、设置配置数据、安装要求和配置应用程序。

第 5 章，使用 Chef 管理云服务，涵盖了与 AWS、Rackspace Cloud 和 Azure 等各种云提供商的集成。

第 6 章，超越基础，专注于异构网络中现有系统的集成，如何处理食谱和多个平台，测试，组织和发布食谱。

## 本书所需内容

本书期望你能够访问一些重要组件才能取得成功。为了执行本书中的示例，需要以下先决条件：

- 访问用于管理配置的 Chef 服务器；自托管安装或 Chef 托管账户均可
- 一个可安装软件（包括 knife）的工作站（Windows 或 Linux 主机）
- 你选择的文本编辑器

此外，如果你想尝试任何云计算示例，你需要一个你正在尝试的云托管提供商的账户。

## 本书适用人群

本书专为曾经接触过 Chef（无论是偶尔还是深入）的系统管理员设计。它涵盖了 Chef 的 Windows 特定方面，并期望你有一个可用的 Chef 服务器工作安装，无论是托管还是自行管理。需要具备某种编程语言（最好是 Ruby）的工作知识，才能从示例中获得最大收益并构建自己的食谱。
