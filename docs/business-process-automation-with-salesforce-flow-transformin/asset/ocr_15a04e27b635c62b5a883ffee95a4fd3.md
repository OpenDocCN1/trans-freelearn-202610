This is our business process flow:

+   1. The user goes to the account screen.
+   2. Access and run the screen flow.
+   3. If the shipping address is the same as the billing address, copy the billing address to the shipping address.
+   4. If not, collect and input the shipping address.
+   5. Save the record.
+   6. Display a success or error message on the screen.
