# Screen flow

Screen flows help us enable functionality, where users are able to perform their business processes interactively via the Salesforce interface, which enables an excellent user experience. These screen flows can be enabled via quick actions or from lightning pages.

Here are the steps to create a screen flow:

+   1. Create a screen flow using the Flow Builder tool.
+   2. Add elements – data, logical, and screen elements – based on your requirements.
+   3. Add resources that you plan to use on the canvas, such as variables, screen components, and elements.
+   4. Connect these elements manually when using the free-form style on the canvas, whereas, in auto-layout, they are connected automatically as you add the elements to the screen layout. Play around, and pick the element that suits your taste.
