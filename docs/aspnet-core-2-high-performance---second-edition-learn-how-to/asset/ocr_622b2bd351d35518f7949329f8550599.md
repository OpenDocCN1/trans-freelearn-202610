If we have a look at a site with a better configuration (https://emoncms.org/), we can see that it gets an A grade. You can get an A+ grade by using HSTS headers. Additionally, these headers avoid the overhead of a redirect. You may also be able to get your site embedded in a preloaded list shipped with browsers if you submit the domains to the vendors.
