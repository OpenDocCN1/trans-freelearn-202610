## 前言

> “计算机软件行业最令人惊叹的成就是，它持续抵消了计算机硬件行业稳定而惊人的进步。”
> 
> – 亨利·彼得罗夫斯基

我们生活在分布式系统时代。计算机已经从房间大小的工业大型机，缩小到比拇指指甲还小的嵌入式设备。然而，与此同时，我们每天构建、维护和使用的软件应用已经发展到无法衡量的程度。我们构建的分布式应用运行在遍布世界各地的虚拟机集群上，数十亿人每天依赖这些系统，例如电子邮件、聊天、社交网络、生产力应用和银行服务。我们一周七天、一天二十四小时在线，并且沉迷于即时满足。一代人之前，我们愿意等到周末之后支票兑现，或者允许 28 天送达。今天，我们期望即时反馈，为什么不呢？现代网络是实时的、即时的、按需的，并且构建在以光速在全世界传输的数据包之上；当它不是这样时，我们就会注意到。我们都有过那种沮丧的感觉……你知道，当你刚刚在页面上输入信用卡号购买昂贵的音乐会门票，而网站响应时间过长时。在分布式时代，性能和响应速度是提供卓越用户体验的基本组成部分。然而，对于一位试图按时交付下一个功能的开发者来说，性能往往是最具挑战性的需求之一。如何找到应用程序性能中的瓶颈？如何衡量这些问题的影响？如何分析它们，设计和测试解决方案及变通方法，并在生产环境中监控它们，从而确信它们不会再次发生？这本书给出了答案。在书中，James Singleton 对现代性能优化技术及其如何应用到你的 .NET 和 Web 应用中进行了务实、深入且均衡的探讨。James 从我们应该将性能视为系统核心功能这一前提出发，展示了如何使用 Glimpse、MiniProfiler、Fiddler 和 Wireshark 等性能分析工具来追踪导致性能问题的瓶颈和缺陷。他阐述了有效性能调优、监控、插桩背后的科学原理，以及在对运行中的系统进行更改以尝试提升性能时，使用准确且可重复的测量的重要性。

本书接着讨论了现代应用开发的几乎每一个方面：数据库调优、硬件优化、压缩算法、网络协议和对象关系映射器。对于每个主题，James 都描述了常见性能问题的症状，确定了这些症状的根本原因，然后描述了可用于在你自己应用中测量和修复这些根本原因的模式和工具。书中深入探讨了高性能软件模式，如异步方法和消息队列，并配有实际示例，展示如何在最新版本的 .NET 框架中实现这些模式。最后，James 展示了如何不仅将负载测试作为发布流程的一部分，还可以在生产环境中持续监控和测量系统，让你在潜在问题开始困扰最终用户之前就发现并修复它们。

当我在 Spotlight 与 James 共事时，他始终展现出非凡的知识广度，从 ASP.NET 到 Arduino，从 ReSharper 到电阻。某一天，他会用 ASP.NET 和 JavaScript 构建响应式前端界面；第二天，他会把微控制器接入星球大战玩具来制作构建监控器，或者想办法把浴室门锁连接到内网，这样我们骑自行车通勤的员工就能从办公桌前看到办公室淋浴间何时空闲。在 James 离开 Spotlight 之后，我一直关注他与 Cleanweb 和 Computing 4 Kids Education 的合作。他是那种真正理解技术的社会和环境影响的稀有开发者；无论是提供出色的用户交互，还是仅仅节约电力，提升系统性能都是让你的用户感到满意的绝佳方式。通过这本书，James 将他多年的实践经验和教训提炼成一本真正优秀的 .NET 开发者综合参考书，帮助那些想要理解如何构建响应迅速且可扩展应用的开发者。对于希望全面理解应用性能的新开发者来说，这是一个很棒的资源；而对前沿技术和模式的覆盖也意味着它同样适合那些希望确保自己不会落伍的经验丰富的开发者。买下它，阅读它，与你的团队分享，让我们一起让 Web 变得更好。

Dylan Beattie
系统架构师、REST 布道者、技术演讲者

## 关于作者

**James Singleton** 是一位英国软件开发人员、工程师和企业家，自 BBC Micro 时代就开始编写代码。他受过正式的电气与电子工程训练，但已在 .NET 软件开发领域专业工作近十年。他活跃于伦敦的初创企业社区，并为有环保意识的技术人员组织 Cleanweb London 活动。他运营着 Cleanweb Jobs (https://cleanwebjobs.com/)，旨在帮助开发人员、工程师、管理人员和数据科学家进入能够帮助应对气候变化和其他环境问题的岗位。他也进行公开演讲，并曾在许多本地用户组发表演讲，包括 Hacker News London 聚会。James 拥有电子工程与计算专业的一等荣誉学位，并曾在 FPGA 上设计并构建了自己的基本微处理器，以及运行在其上的自定义指令集。James 为许多开源项目做出贡献，也深受这些项目的影响，并且经常使用 Python、Ruby 和 Linux 等替代技术。他对 Microsoft 在 .NET 上采取的方向及其对开源实践的拥抱充满热情。他对硬件、环境和数字权利项目特别感兴趣，并且热衷于安全、压缩和算法。在编码或为书籍和杂志写作之余，他喜欢步行、滑雪、攀岩、旅行、酿造和精酿啤酒。James 通过在多个不同行业和职位工作获得了各种技能，从高性能证券交易所到视频编码系统。他曾担任业务分析师、顾问、测试人员、开发人员和技术架构师。从大型企业到初创公司，以及介于两者之间的许多地方，他拥有广泛的知识。他对构建高性能软件的最佳和最差方式都有第一手的经验。你可以在 https://unop.uk/ 阅读他的博客。
