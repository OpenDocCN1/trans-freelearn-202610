# CLI

From inside your virtual appliance, verify you are the root user and source the openrc file:

```
$ source openrc
```

TIP Typing openstack help flavor create will provide details on all available positional and optional arguments.

Using python-openstackclient, create a new flavor with ID 200, 512 MB of RAM, 1 GB primary disk, and 1 VPCU. The flavor will be public by default. Call the flavor awesome-flavor-cli.

```
$ openstack flavor create --id 200 --vcpus 1 --ram 512 --disk 1 "awesome-flavor-cli"
```
