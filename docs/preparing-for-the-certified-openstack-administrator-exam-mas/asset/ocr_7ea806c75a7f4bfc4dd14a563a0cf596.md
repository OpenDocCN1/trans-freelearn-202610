To exit the MySQL/MariaDB prompt, run the following:

```
MariaDB [(none)]> exit;
```

If we wanted to perform a SQL dump of a specific database, you can run this:

```
$ sudo mysqldump -h localhost --databases nova > nova.sql
```

To restore a SQL dump, run the following:

```
$ sudo mysql -h localhost < nova.sql
```
