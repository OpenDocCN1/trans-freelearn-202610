What if we wanted to limit container access to users within our OpenStack environment that reside within a specific project?

We can use the following syntax: --read-acl <project-uuid:user-uuid>

It's important that we use the UUID. In a multi-domain environment, this is the only way our system knows the specific project and user to which we are referencing.
