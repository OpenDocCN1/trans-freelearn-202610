## Exam objective - managing routers - east/west traffic

In the OpenStack world, routers are virtual network devices that provide layer-3 connectivity between subnets. Routers essentially provide routing for two types of scenarios, east/west and north/south traffic.

In this section, we will focus on understanding and creating east/west traffic scenarios. If two virtual machine instances are on two different subnets, they will not be able to communicate with each other unless there is a router to forward traffic between them. OpenStack users can create multiple networks and subnets and connect them with routers.
