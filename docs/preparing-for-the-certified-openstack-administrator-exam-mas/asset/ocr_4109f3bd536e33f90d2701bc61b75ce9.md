Let's use python-openstackclient to first allocate a desired floating IP address to the logistics project:

```
$ openstack floating ip create --floating-ip-address 172.16.1.100 provider-network-cli
```

Now that the logistics project owns the 172.16.1.100 address, we can easily assign it to instance1-cli by running the following command:

```
$ openstack server add floating ip instance1-cli 172.16.1.100
```
