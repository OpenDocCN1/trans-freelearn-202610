When creating subnets, users can specify a variety of parameters: the allocation pools that limit availability of which addresses in the subnet, a custom gateway address, a list of DNS servers, and individual host routes. We will discuss this in more detail in the upcoming section.

Multiple subnets can be associated with one Neutron network, but they all must have a unique CIDR range. To create multiple subnets with the exact same IP address range, create another network. This is known as **overlapping IPs**.
