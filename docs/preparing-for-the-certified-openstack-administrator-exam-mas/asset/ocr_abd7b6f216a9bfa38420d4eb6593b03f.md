# CLI

We must rely on the OpenStack CLI for adding and removing entries from the service catalog. Let's consider a scenario where an OpenStack administrator would be required to edit the catalog. Imagine the OpenStack infrastructure engineers have just installed a brand new service in the OpenStack environment. The service is Trove, which allows OpenStack users to easily create both relational and NoSQL databases. How are we going to let our OpenStack users know that they now have the ability to create these databases? By advertising it in the service catalog, of course!

In order to view the entire catalog, ensure you source your openrc file and run the following:

```
$ openstack catalog list
```
