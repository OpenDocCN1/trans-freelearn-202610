Let's begin by listing our current containers. We should be able to see our container-cli container we created in the previous section:

```
$ swift list
```

To view the ACLs for this container, run the following command:

```
$ swift stat container-cli
```

We should see output similar to Figure 8.8.

![](bbox=[0.18, 0.33, 0.77, 0.6])

Figure 8.8: Output from the 'swift stat' command shows no read or write ACLs set on the container

As you can see, the Read ACL and Write ACL are empty. This means that the container is currently private and only accessible to those with the admin or swiftoperator role.
