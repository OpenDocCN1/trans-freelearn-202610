Your OpenStack virtual appliance provided with this book is configured to use the QEMU hypervisor. If you attempt to boot a larger cloud image (such as Ubuntu or Centos), it will run slowly. Unfortunately, VirtualBox does not allow nested virtualization, even if you have virtualization extensions turned on in the BIOS of your laptop or desktop.
