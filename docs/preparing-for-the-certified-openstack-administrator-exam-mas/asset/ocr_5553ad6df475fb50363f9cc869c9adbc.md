Now that we've added a new rule to the default security group, let's create an entirely new security group and add a rule to it. Many OpenStack users create brand new security groups for specific instance roles. For example, it may be appropriate to create a new security group called `database-sg`. This security group could contain a rule that would only allow TCP ingress traffic from any instance that has the `webserver-sg` security group.
