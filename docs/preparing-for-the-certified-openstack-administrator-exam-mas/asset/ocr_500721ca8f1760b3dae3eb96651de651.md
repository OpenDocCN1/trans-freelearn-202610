# Authentication in action

Now that you have your OpenStack environment up and running, open up your web browser and navigate to the Horizon dashboard at https://192.168.56.101/horizon. The login screen is where you would submit the username and password provided to you by your OpenStack administrator. An OpenStack administrator needs to provision this account, along with a password, email address, and a few other options.
