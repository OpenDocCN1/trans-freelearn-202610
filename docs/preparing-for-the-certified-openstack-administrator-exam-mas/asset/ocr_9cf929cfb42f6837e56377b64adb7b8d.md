Ensure that you set both the OS_PROJECT_NAME and OS_TENANT_NAME variables:

```
export OS_PROJECT_NAME=<project-name>
export OS_TENANT_NAME=<project-name>
```

![](bbox=[0.07, 0.16, 0.15, 0.23])

Although python-openstackclient needs only the OS_PROJECT_NAME variable, some older clients may rely on the legacy OS_TENANT_NAME variable. We set it here for consistency.

After saving your file with the newly set variables, source the file to set the variables in the current Bash session:

```
$ source openrc-<project-name>
```

Before running any commands, verify that the variables have been set properly!

```
$ export | grep OS
```
