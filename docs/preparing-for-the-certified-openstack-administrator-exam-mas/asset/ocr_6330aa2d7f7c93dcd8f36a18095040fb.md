As you can see, the OpenStack administrator has loaded in the default templates. These metadata definition templates are available at `github.com/openstack/glance/etc/metadefs.`

A typical OpenStack user will be able to apply these loaded properties to resources they create in OpenStack. Here's an example: consider a multi-hypervisor OpenStack environment consisting of KVM, Hyper-V, and XEN hypervisors. If a user creates a Glance image, they could set metadata on that image to only allow booting it on a hypervisor compatible with the image file format.
