# Cinder Block-Storage Service

In the previous chapter, we discussed the Neutron networking service and the Neutron-related objectives on the Certified OpenStack Administrator exam. Now we will discuss Cinder. Cinder is the OpenStack block-storage service, and it allows users to create **persistent** volumes that can be mounted as devices by Nova virtual machine instances.

In this chapter, we will cover the following topics:

+   - About Cinder
+   - Exam objective - managing Cinder volumes
+   - Exam objective - attaching/detaching Cinder volumes from instances
+   - Exam objective - managing Cinder snapshots
+   - Exam objective - managing Cinder backups

After this chapter, you should have a solid understanding of Cinder and the skills necessary to successfully fulfill all Cinder-related objectives on the exam.
