+   12. **DNS Name Servers** (optional): This is an IP address list of DNS name servers to be announced to the instance. Providing no value will announce the DHCP server IP as the DNS server to all instances attached to the subnet. This can automatically provide resolution of instance hostnames within OpenStack to their respective IP addresses. For resolution of names outside OpenStack, I have set the internal DNS options to use Google DNS at 8.8.8.8. There are additional DNS options within `/etc/neutron/dhcp_agent.ini`. We will keep box **blank**.
+   13. **Host Routes** (optional): Any additional routes announced to the hosts. We will keep this **blank**.
+   14. Select **Create**.
