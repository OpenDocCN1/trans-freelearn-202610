# Exam objective - managing Cinder snapshots

Cinder supports volume snapshots that capture the current state of a volume. These are useful for providing backup protection and can also be used to instantiate new volumes that contain the exact data of the snapshot. Behind the scenes, Cinder snapshots are LVM snapshots that will reside in the same LVM volume group as the original logical volume. It's important to note that snapshots are not backups. Unlike Cinder snapshots, Cinder backups are stored off site. We will cover them in the next section. Let's walk through creating and restoring snapshots in the dashboard.
