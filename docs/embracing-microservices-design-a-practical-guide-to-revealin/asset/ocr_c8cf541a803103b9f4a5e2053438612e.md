# Offload security token validation to API gateway

There are various services in Azure where **Azure API Management** provides a **JWT** policy to validate the incoming token and route it to the backend microservice. You can set up Azure API Management with microservices hosted inside the **Azure Kubernetes Services (AKS)** cluster that allows the external traffic to reach Azure API Management and route it to the backend service inside a **VNET**.
