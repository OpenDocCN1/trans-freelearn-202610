Unit testing is definitely a shift-left best practice as it starts with the code and the code is about as left as you can get, as it all starts with writing testable, changeable code that meets the acceptance criteria of the business.

# Unit testing

Unit testing helps us meet the shift-left approach by moving the testing to the development phase and helps meet the automation portion as well. Developers need to embrace the use of unit testing by using methods such as **test-driven development (TDD)**, which prescribes writing the test first based on good acceptance criteria. The TDD process has a life cycle of writing a test that fails, then writing the code that makes the test pass, and finally, refactoring the test and the code.
