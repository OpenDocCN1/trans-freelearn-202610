## 关于 Packt Publishing

Packt，发音为 'packed'，于 2004 年 4 月出版了第一本书 *Mastering phpMyAdmin for Effective MySQL Management*，随后继续专注于出版针对特定技术和解决方案的高度聚焦的书籍。

我们的书籍和出版物分享了你的 IT 同行在适应和定制当今系统、应用程序和框架方面的经验。我们的解决方案型书籍为你提供定制你正在使用的软件和技术以完成工作的知识和能力。Packt 的书籍比你过去看到的 IT 书籍更具体、更少泛泛而谈。我们的独特商业模式使我们能够为你带来更聚焦的信息，让你获得你需要了解的更多内容，而非不需要的内容。

Packt 是一家现代而独特的出版公司，专注于为开发者、管理员和新手社区生产高质量、尖端书籍。有关更多信息，请访问我们的网站 www.packtpub.com。
