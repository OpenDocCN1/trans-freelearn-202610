
Dart 的 Mirrors 库提供以下三个用于内省的主要函数：

- `reflect`：该函数用于内省传入的参数实例，并将结果保存在 `InstanceMirror` 或 `ClosureMirror` 中。对于前者，我们可以调用 `reflectee` 属性的方法、函数，或获取和设置其字段；对于后者，我们可以执行该闭包。
- `reflectClass`：该函数反射类的声明并返回 `ClassMirror`。它持有作为参数传入的类型的完整信息。
- `reflectType`：该函数返回 `TypeMirror`，并反射一个类、`typedef`、函数类型或类型变量。

让我们看一下主要代码：

```dart
library test.framework;

import 'type_inspector.dart';
import 'test_case.dart';

main() {
  TypeInspector inspector = new TypeInspector(TestCase);
  List methods = inspector.getAnnotatedMethods('test');
  print(methods);
}
```

首先，我们创建了一个 `TypeInspector` 类的实例，并传入了可测试的类，也就是这里的 `TestCase`。然后，我们以注解名 `test` 调用了 `inspector` 的 `getAnnotatedMethods` 方法。执行结果如下：

[MethodMirror on 'testStart', MethodMirror on 'testStop']

`getAnnotatedMethods` 方法按照我们的要求找到了 `testStart` 和 `testStop` 方法，并忽略了 `TestCase` 类中的 `testWarmUp` 方法。

## 反射实战

我们已经看到内省如何帮助我们找到带有注解的方法。现在，我们需要调用每个被标记的方法来运行实际的测试。我们将通过反射来实现这一点。让我们创建一个 `MethodInvoker` 类来展示反射的实际应用：

```dart
library executor;

import 'dart:mirrors';

class MethodInvoker implements Function {
  // Invoke the method
  call(MethodMirror method) {
    ClassMirror classMirror = method.owner as ClassMirror;
    // Create an instance of class
    InstanceMirror inst =
        classMirror.newInstance(new Symbol(''), []);
    // Invoke method of instance
    inst.invoke(method.simpleName, []);
  }
}
```

由于 `MethodInvoker` 类实现了 `Function` 接口，并且拥有 `call` 方法，因此我们可以像调用函数一样调用它。为了调用方法，我们必须首先实例化一个类。每个 `MethodMirror` 方法都有一个 `owner` 属性，它指向层级结构中的拥有者对象。在我们的例子中，`MethodMirror` 的 owner 就是 `ClassMirror`。在前面的代码中，我们使用空的构造函数创建了该类的一个新实例，然后按名称调用了 `inst` 的方法。在这两种情况下，第二个参数都是空的方法参数列表。

现在，我们把 `MethodInvoker` 引入到主代码中。除了 `TypeInspector`，我们还创建了 `MethodInvoker` 的实例。我们逐个遍历这些方法，并将每个方法发送给 invoker。只有在没有异常发生时，我们才会打印 Success。为了防止当任意测试失败时程序终止，我们将 invoker 包装在 try-catch 块中，如下面的代码所示：

```dart
library test.framework;

import 'type_inspector.dart';
import 'method_invoker.dart';
import 'test_case.dart';

main() {
  TypeInspector inspector = new TypeInspector(TestCase);
  List methods = inspector.getAnnotatedMethods('test');
  MethodInvoker invoker = new MethodInvoker();
  methods.forEach((method) {
    try {
      invoker(method);
      print('Success ${method.simpleName}');
    } on Exception catch (ex) {
      print(ex);
    } on Error catch (ex) {
      print("$ex : ${ex.stackTrace}");
    }
  });
}
```

## 3. 对象的创建

在本章中，我们将讨论对象的创建。我们将了解如何依据编程世界的最佳实践来创建对象、何时创建，并为它们在 Dart 中找到合适的位置。这里介绍的各种技术将帮助我们在不同的业务场景中做出正确的选择。

在本章中，我们将介绍以下主题：

- 生成构造函数

- 命名构造函数
- 重定向构造函数

- 工厂构造函数

- 变量的初始化
- 语法糖

### 创建对象

**类**是对象的蓝图。根据类创建对象的过程称为实例化。对象可以通过 `new` 语句从类实例化，也可以通过反射实例化。它必须在使用前完成实例化。

类中包含一个构造函数，它在从类创建对象时被调用。它的名称始终与类名相同。Dart 定义了两类构造函数：生成构造函数和工厂构造函数。

### 生成构造函数

**生成**构造函数由构造函数名称、构造函数参数列表、重定向子句或初始化列表，以及可选函数体组成。实例化类时，Dart 总是先调用生成构造函数，如下面的代码所示：

```dart
class SomeClass {
  // Default constructor
  SomeClass();
}

main() {
  var some = new SomeClass();
}
```

如果没有定义构造函数，Dart 会隐式地为我们创建一个，如下所示：

```dart
class AnyClass {
  // implicit constructor
}

main() {
  var some = new AnyClass();
}
```

生成构造函数的主要目的是安全地初始化类的实例。这种初始化在类内部进行，并确保被实例化的对象始终处于有效状态。

### 带可选参数的构造函数

构造函数是类的一个方法，其参数用于指定类的初始状态或其他重要信息。构造函数中有必选参数和可选参数。可选参数可以是一组命名参数，也可以是一组位置参数。Dart 不支持方法重载，因此，拥有可选参数的能力会非常方便。

> Dart 不允许你将命名可选参数和位置可选参数组合使用。

让我们看看下面这个 `Car` 类构造函数，它带有可选位置参数：

```dart
// Class Car
class Car {
  String color;
  int weight;

  Car([this.color = 'white', this.weight = 1000]);
}
```

我们可以省略其中一个或全部参数来创建该类的对象，如下所示：

```dart
import 'car_optional_parameters.dart';

main() {
  var car = new Car('blue');
  var car2 = new Car();
}
```

让我们看看下面这个 `Car` 类构造函数，它使用了可选命名参数：

```dart
// Class Car
class Car {
  String color;
  int weight;

  Car({this.color:'white', this.weight:1000});
}
```

在下面的 main 代码中，我使用命名参数创建了该对象的一个实例：

```dart
import 'car_named_parameters.dart';

main() {
  var car = new Car(weight:750, color:'blue');
}
```

那么，哪种可选参数更好呢？我推荐使用命名参数，原因如下：

- 这里，你无需记住参数的位置
- 它能更好地说明这些参数的作用

### 命名构造函数

假设我们要创建一个 `Collection` 类，把所有数据存储在一个地方。我们可以这样做：

```dart
library collection;

// Collection class
class Collection {
  // We save data here
  List _data;

  // Default constructor
  Collection() {
    _data = new List();
  }

  // Add new item
  add(item) {
    _data.add(item);
  }

  // ...
}
```

在 main 方法的某处，我们创建了类的实例，并将数据添加到集合中：

```dart
import 'collection.dart';

var data = [1, 2, 3];

main() {
  var collection = new Collection();
  //
  data.forEach((item) {
    collection.add(item);
  });
}
```

将来我的集合以这种方式初始化的可能性很高。因此，如果能在 `Collection` 类中提供一个初始化方法，用来添加一组数据，那就太好了。解决方案之一是创建带命名参数的构造函数来管理初始化。如下面的代码所示，如果指定了可选参数，代码就会根据该可选参数的值创建一个新的集合：

```dart
library collection;

// Collection class
class Collection {
  // We save data here
  List _data;

  // Default constructor with optional [values] or [item].
  Collection({Iterable values:null, String item:null}) {
    if (item != null) {
      _data = new List();
      add(item);
    } else {
      _data = values != null ?
          new List.from(values) :
          new List();
    }
  }

  // Add new item
  add(item) {
    _data.add(item);
  }

  // ...
}
```

这种解决方案有*存在的理由*，但仅限于参数数量较少的情况。否则，即使是简单的变量初始化任务，也会变成非常复杂的代码。我为命名参数指定了两个可选项，其逻辑实在纠缠不清。很难传达 `values` 的含义。更好的方式是使用命名构造函数，如下面的代码所示：

```dart
library collection;

// Collection class
class Collection {
  // We save data here
  List _data;
```
