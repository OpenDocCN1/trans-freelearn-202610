

## 幻灯片概览

这为用户提供了幻灯片的视觉概览，如以下截图所示：

![](img/52c05b53a56abd53584e4fed738ed509_90_0.png)

演示幻灯片将在新的全屏 Div 元素中重新创建。其样式使用位于 `SlideShowApp` 构造函数中的 CSS 样式表中的 `fullScreen` 类进行设置：

```
overviewScreen = new DivElement();
overviewScreen.classes.toggle("fullScreen");
overviewScreen.onClick.listen((e) => overviewScreen.remove());
```

幻灯片的 HTML 将完全相同。为了缩小幻灯片，需要遍历幻灯片列表，获取 HTML 元素对象，并设置幻灯片的 CSS 类：

```
currentSlideShow.slides.forEach((s) {
  aSlide = s.getSlideContents();
  aSlide.classes.toggle("slideOverview");
  aSlide.classes.toggle("shrink");
  ...
```

当鼠标进入时，CSS 悬停类用于缩放幻灯片，以便可以聚焦查看幻灯片。这些类使用 `toggle` 方法设置，该方法在类不存在时添加，如果存在则移除。该方法有一个可选参数：

```
aSlide.classes.toggle('className', condition);
```

第二个参数名为 `shouldAdd`，如果始终添加类则为 `true`，如果始终移除类则为 `false`。

## 讲义备注

没有什么比给与会者一份实体讲义更好的了。这可以通过概览显示的一种变体来实现：

![](img/52c05b53a56abd53584e4fed738ed509_91_0.png)

与其复制概览代码，不如在方法声明中使用可选参数对该函数进行参数化。使用方括号 `[]` 将声明括起来，并指定默认值，如果未指定参数则使用默认值：

```
void buildOverview([bool addNotes = false])
```

演示概览显示调用它时不需要任何参数：

```
buildOverview();
```

讲义显示调用它时不需要任何参数：

```
buildOverview(true);
```

如果设置了此参数，则会为“备注”区域添加一个额外的 Div 元素，并调整 CSS 以利于打印布局。

## 比较可选位置参数和命名参数

`addNotes` 参数声明为可选位置参数，因此无需命名参数即可指定可选值。第一个参数与提供的值匹配。

为了提供更大的灵活性，Dart 允许可选参数被命名。考虑两个函数——第一个使用命名可选参数，第二个使用位置可选参数：

```
getRecords1(String query,{int limit: 25, int timeOut: 30}) {
}
```

```
getRecords2(String query,[int limit = 80, int timeOut = 99]) {
}
```

第一个函数可以通过更多方式调用：

```
getRecords1("");
getRecords1("", limit:50, timeOut:40);
getRecords1("", timeOut:40, limit:65);
getRecords1("", limit:50);
getRecords1("", timeOut:40);
```

```
getRecords2("");
getRecords2("", 90);
getRecords2("", 90, 50);
```

使用命名可选参数时，它们的提供顺序并不重要，并且优点是调用代码更清楚地表明所传递参数的用途。

## 进入全屏

到目前为止，幻灯片一直处于小屏幕模式，需要将其切换到 Web 浏览器中的 **IMAX** 等效模式——全屏模式。观众不想看到幻灯片编辑器或桌面——只想看到幻灯片。

要打开本章的示例代码项目，请在 WebStorm 中打开 `Presenter` 文件夹，然后打开 `slideshowapp.dart` 文件。

## 请求全屏

尽管 Web 浏览器的趋势是逐渐缩小屏幕控件的大小——这一趋势因 Chrome 浏览器而加速——但全屏 Web 应用仍被用户接受，并且各浏览器之间已经确定了标准。让我们看看下面的截图：

出于安全考虑，Web 浏览器会提示用户允许网站进入全屏模式，该模式会隐藏屏幕外的工具栏和状态栏。

![](img/52c05b53a56abd53584e4fed738ed509_96_0.png)

一旦进入全屏模式，用户会收到接管整个屏幕的域名的通知。Web 浏览器还将 Escape (Esc) 键设置为用户退出全屏模式的方式。几秒钟后，该通知会浮动离开屏幕，将指针移回屏幕顶部即可再次显示。

具体行为和位置可能因 Web 浏览器和操作系统而异。例如，Internet Explorer 往往会在页面底部显示通知。

![](img/52c05b53a56abd53584e4fed738ed509_96_1.png)

`requestFullscreen` 方法可用于大多数页面元素，但通常使用 div 作为容器。演示应用从 `SlideShowApp` 对象的构造函数中调用 `setupFullScreen` 方法。使用一个布尔标志来跟踪显示模式：

```
qs("#btnStartShow").onClick.listen((e) {
    isFullScreen = true;
    liveFullScreen
        .requestFullscreen()
        .focus()
        .classes.toggle("fullScreenShow")
        .style.visibility = "visible";
});
```

```
liveSlideID = 0;
updateLiveSlide();
}};
```

可以监听 `onFullscreenChange` 事件，以便单个元素能够监听状态变化。例如，当应用处于全屏模式时，工具栏可能不会出现。

当你点击 div 时，`isFullScreen` 标志被设置，请求全屏，并将输入焦点设置到 `liveFullScreen` 对象上。接下来，将 .css 文件设置在 div 上，并使其在屏幕上可见。最后，将 `liveSlideID` 设置为演示文稿的起点，并用幻灯片的内容更新显示。

## 为全屏更新界面

编辑器屏幕需要一个按钮来以全屏模式启动幻灯片。显示将是一个全新的元素，而不仅仅是编辑器预览的放大。

全屏将是一个 div 元素，填满整个窗口，并包含用于背景的子 div 元素，配有背景图像，以及当前正在显示的幻灯片。

## 为全屏更新键盘控制

这里需要一个与上一章为编辑器屏幕实现的事件监听器类似的事件监听器。键盘控制在 `SlideShowApp` 类的 `setupKeyboardNavigation` 方法中设置：

```
void setupKeyboardNavigation() {
    //Keyboard navigation.
    window.onKeyUp.listen((KeyboardEvent e) {
        if (isFullScreen) {
            if (e.keyCode == 39) {
                liveSlideID++;
                updateLiveSlide();
            } else if (e.keyCode == 37) {
                liveSlideID--;
                updateLiveSlide();
            }
        } else {
            //Check the editor does not have focus.
            if (presEditor != document.activeElement) {
                if (e.keyCode == 39) showNextSlide();
                else if (e.keyCode == 37) showPrevSlide();
```

```
else if (e.keyCode == 38) showFirstSlide();
else if (e.keyCode == 40) showLastSlide();
}
}
});
```

`isFullscreen` 标志用于确定演示应用处于哪种模式。在全屏模式下，根据按下的键和当前更新的显示幻灯片，`liveSlideID` 会递增或递减。

## 添加鼠标控制

点击鼠标按钮推进演示是一个相当常见的功能，我们的应用也应该支持这一点。这在 `setupFullscreen` 方法中实现：

```
liveFullscreen = qs("#presentationSlideshow");
liveFullscreen.onClick.listen((e) {
  liveSlideID++;
  updateLiveSlide();
});
```
