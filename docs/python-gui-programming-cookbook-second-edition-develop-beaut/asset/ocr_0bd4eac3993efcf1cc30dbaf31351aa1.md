# Installing the wxPython library

The wxPython library does not ship with Python, so in order to use it, we first have to install it.

This recipe will show us where and how to find the right version to install in order to match both the installed version of Python and the operating system we are running.

The wxPython third-party library has been around for more than 18 years, which indicates that it is a robust library.

# Getting ready

In order to use wxPython with Python 3.6 and above, we have to install the wxPython Phoenix version.
