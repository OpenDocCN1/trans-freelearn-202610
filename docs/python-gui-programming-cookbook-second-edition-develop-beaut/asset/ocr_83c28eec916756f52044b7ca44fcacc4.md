The important thing to notice here is that we create one axis, which is then used as the shared x and y axes for the other graphs within the chart. In this way, we can achieve a database-like layout of the chart.

We also add a grid and change its default line style. Even though we only display one plot in the chart, by choosing 2 for the number of subplots, we are moving the plot up, which results in an extra white space at the bottom of the chart. This first plot now only occupies 50% of the screen, which affects how large the grid lines of this plot are when being displayed.
