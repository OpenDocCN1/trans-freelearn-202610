We can verify that we have successfully installed Matplotlib by looking at our Python installation directory. After successful installation, the Matplotlib folder is added to site-packages. Depending upon where we installed Python, the full path to the site-packages folder on Windows can be:

```
C:\Python36\Lib\site-packages
```

![](bbox=[0.25, 0.23, 0.69, 0.57])

If you see the matplotlib folder added to the site-packages folder in your Python installation, then we have successfully installed Matplotlib.
