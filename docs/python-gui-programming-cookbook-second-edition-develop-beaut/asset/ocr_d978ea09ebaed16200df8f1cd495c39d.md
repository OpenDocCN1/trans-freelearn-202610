# # Creating beautiful charts using Matplotlib

This recipe introduces us to the `Matplotlib` Python module, which enables us to create visual charts using Python 3.6 and above.

The URL, `http://matplotlib.org/users/screenshots.html`, is a great place to start for exploring the world of Matplotlib, and it teaches us how to create many charts that are not presented in this chapter.
