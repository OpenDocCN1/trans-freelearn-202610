If you have more than one version of Python installed, it is a good idea to move Python 3.6 to the top of the list. When we type `pip install <module>`, the first version found in **System variables | Path** might be used and you might get some unexpected errors if an older version of Python is located above Python 3.6.

Let's run `pip install wheel` and then verify if it is successfully installed using `pip list`:

If you are really very used to Python 2.7 and insist on running the code in Python 2.7, you can try this trick. After everything is working with Python 3.6, you can rename the 3.6 `python.exe` to `python3.exe` and then have fun using both 2.7 and 3.6 by typing `python.exe` or `python3.exe` in a command window to run the different Python executables. It is a hack. If you really wish to go on this road, your are on your own, but it can work.
