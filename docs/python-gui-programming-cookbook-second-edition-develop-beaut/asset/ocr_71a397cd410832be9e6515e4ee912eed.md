# How it works…

In this recipe, we successfully installed the correct version of the wxPython toolkit that we can use with Python 3.6. We found the Phoenix project for this GUI toolkit, which is the current and active development line. Phoenix will replace the classic wxPython toolkit in time and is especially aimed at working well with Python 3.6.

After successfully installing the wxPython/Phoenix toolkit, we then created a GUI using this toolkit in only five lines of code.

We previously achieved the same results by using tkinter.
