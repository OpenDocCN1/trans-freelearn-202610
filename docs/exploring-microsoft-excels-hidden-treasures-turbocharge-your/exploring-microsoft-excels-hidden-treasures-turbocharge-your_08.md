# 第 3 部分：数据分析

根据 Microsoft 的说法，VLOOKUP 是使用频率第三高的工作表函数，仅次于 SUM 和 AVERAGE 函数。尽管很受欢迎，但 VLOOKUP 已经不够先进，因此现代需要一种名为 XLOOKUP 的现代查找函数。XLOOKUP 函数属于一类名为动态数组的新工作表函数，可以将结果溢出到所需的任意相邻单元格中。更棒的是，Excel 中几乎每个工作表函数现在都具有动态特性。本部分将深入探讨 Excel 的另外两个最近新增功能，即 LET 和 LAMBDA 函数，它们可以大大简化复杂公式。本部分最后将讨论 Power Query。Power Query 功能并非新事物，但大多数 Excel 用户都不知道这个无需代码的连接数据源的解决方案。Power Query 使您能够轻松地将结果转换为可刷新的连接，从而保护数据不被覆盖。

本部分包含以下章节：

- 第 10 章，查找和动态数组函数
- 第 11 章，名称、LET 和 LAMBDA
- 第 12 章，Power Query
