# Tip

If you encounter a situation where one field that you want to match on has a conflicting data type, such as text, you can convert the data by choosing another data type from the list. Errors will appear if you make an incorrect selection, such as trying to convert a column of words into whole numbers, but you won’t have any issue changing a text-based column of numbers into a numeric value. Such changes only affect the data in Power Query and do not affect the original data.
