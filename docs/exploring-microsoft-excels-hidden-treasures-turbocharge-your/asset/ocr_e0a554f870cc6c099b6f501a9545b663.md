+   2. In **Visual Basic Editor**, choose **View | Immediate Window** or press _Ctrl + G_ (_Ctrl + ⌘ + G_).

+   3. As shown in _Figure 8.18_, the **Immediate** window is a space where you can execute a single line of code without creating a formal macro. Type the following line of code into the **Immediate** window and then press _Enter_:

```
For each v in ActiveWorkbook.CustomViews: v.Delete: Next
```

Just like the macro for unhiding sheets, which we covered earlier in this chapter, this is a three-line macro condensed to a single line. `ActiveWorkbook.CustomViews` represents a collection of all **Custom Views** in the current workbook. `v` is a variable that stores the name of the **Custom View** currently being processed. `Delete` is a method that removes the view:
