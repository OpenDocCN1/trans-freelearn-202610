# # Nuance

When using the **Define Name** command to create a LAMBDA function, you must include the equals (=) sign at the start of the formula. When using **Advanced Formula Environment**, you must _omit_ the equal sign (=). In both cases, you'll also omit any **Parameters** that you have included in parentheses at the end of the formula.
