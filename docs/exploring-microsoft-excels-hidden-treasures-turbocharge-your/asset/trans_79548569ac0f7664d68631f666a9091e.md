# 提示

如果你遇到一种情况，即要匹配的某个字段存在数据类型冲突（例如文本），则可以从列表中选择另一种数据类型来转换数据。如果选择不正确（例如尝试将一列单词转换为整数），将出现错误，但将文本形式的数字列更改为数值不会有任何问题。此类更改仅影响 Power Query 中的数据，不影响原始数据。
