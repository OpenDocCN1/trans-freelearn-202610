# Nuance

RANDBETWEEN can only return integer values, which is why we must divide by 1,000.
If you’re using Microsoft 365 or Excel 2021, one alternative is to use RANDARRAY,
which has five arguments: rows, columns, min, max, and integer. In cell B1, you’d enter
=RANDARRAY(1,1,.05,.10,FALSE) to generate decimal values between 5% and 10%.
