Tip
Tread carefully with the Unlink command, as you cannot undo this action, nor will you be
able to undo any prior actions. If you unlink a query accidentally, you can right-click on the
query in the Queries & Connections task pane and then choose Load To, which will display
the Load To dialog box. Choose Table | New Worksheet, and then click OK to recreate the
data connection.

task pane.
