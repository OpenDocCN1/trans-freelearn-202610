# Nuance

Unlike typical Excel formulas, you can’t type over the results in a Data Table because the results
are provided by an array function. Results provided by array functions are banded together in
a one-for-all and all-for-one fashion that protects the integrity of the results.

Now, let’s see how we can create a Data Table that uses three inputs, even though the Data Table
dialog box only allows space for two.
