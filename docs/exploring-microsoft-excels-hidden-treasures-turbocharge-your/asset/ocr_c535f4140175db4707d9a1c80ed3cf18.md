In this case, 3 indicates that we want to sort based on the third column of the array.

The =SORT(SORT(B3:E12,3,-1),2) formula in cell Q3 of Figure 10.15 shows you how to sort
alphabetically by country and then in descending order by miles:

![](bbox=[0.1338, 0.1875, 0.8535, 0.4219])

In this case, the first sort, meaning the inside SORT function, sorts the list in descending order based
on miles. The outside SORT function arranges the list in alphabetical order by country since I specified
the second column as sort_index. The nuance is that the SORT functions must be nested in the
proper order to achieve the desired result.
