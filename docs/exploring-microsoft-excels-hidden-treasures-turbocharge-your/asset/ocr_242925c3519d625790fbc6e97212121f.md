# # Part 2: Spreadsheet Interactivity and Automation

This chapter will empower you with interactivity and automation techniques. Data validation provides interactivity, documentation, and internal control, but can be bypassed by savvy users. The Form Controls feature provides more controlled interactivity when necessary. Many users fail to notice the potential of Excel's What-If Analysis features, which can eliminate manual guesswork in a flash. The Table feature offers more automation potential than I could fit into the chapter. Custom Views is one of my favorite code-free automation solutions in Excel that can save you time in several ways. The final chapter, Excel Quirks and Nuances, explains how to avoid getting snared by tricky pitfalls in Excel.

The following chapters are included in this part:

+   - Chapter 5, Data Validation and Form Controls
+   - Chapter 6, What-If Analysis
+   - Chapter 7, Automating Tasks with the Table Feature
+   - Chapter 8, Custom Views
+   - Chapter 9, Excel Quirks and Nuances
