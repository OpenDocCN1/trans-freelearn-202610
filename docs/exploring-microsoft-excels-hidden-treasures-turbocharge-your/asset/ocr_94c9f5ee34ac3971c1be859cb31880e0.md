# Restoring legacy features

The term legacy feature is an epithet Microsoft uses for features that they consider have outlived
their useful life. Microsoft rarely removes a feature outright from the software. Typically, deprecated
commands get buried in the Commands Not in the Ribbon list, much like storing things in a basement
or cellar. Let’s see how to bring back a couple of features that you might have thought were long gone.
