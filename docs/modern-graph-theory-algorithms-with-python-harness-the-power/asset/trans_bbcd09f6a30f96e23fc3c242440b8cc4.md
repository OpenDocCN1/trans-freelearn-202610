**Bayes’ Theorem** 提供了一种通过将先验事件的概率与感兴趣的事件联系起来来计算条件概率的公式。我们可以通过以下公式计算事件 *A* 在事件 *B* 发生的条件下发生的概率：

P(A | B) = (P(A) * P(B | A)) / P(B)

这里，*P(A|B)* 是在事件 *B* 发生的情况下事件 *A* 发生的概率，*P(A)* 是事件 *A* 发生的概率，*P(B|A)* 是在事件 *A* 发生的情况下事件 *B* 发生的概率，而 *P(B)* 是事件 *B* 发生的概率。

为了更具体地说明，让我们回到我们的药物使用示例。我们将事件 *A* 称为尝试新药，事件 *B* 称为身处药物被使用的场所。事件 *B* 的概率为 100%，事件 *A* 发生时事件 *B* 的概率也是 100%。事件 *A* 的概率为 30%。让我们将这些值代入公式：

P(A | B) = (0.3 * 1) / 1

这给出了我们预期的 30%。然而，在概率论中，并非所有事件的概率都是 100%，并且随着条件事件的增加，许多计算会变得更加复杂。在现实世界的数据中，我们可能需要根据收集到的数据使用算法来估计这些概率。让我们继续讨论事件链，例如我们的药物使用示例。

## Causal pathways

条件概率可能涉及不止两个具有条件关系的感兴趣事件。**Causal pathways** 涉及条件概率链，可以像我们的药物依赖示例那样相对较短，也可以像导致疾病风险的蛋白质激活途径那样非常、非常长且复杂。

得益于 Bayes’ Theorem，我们可以将条件概率以分段的方式串联起来，直到所有条件概率都链接到最终的途径中。这对于估计众所周知的因果途径的效果大小和进展速率非常有效。然而，很多时候，我们并不知道导致感兴趣结果的确切事件序列，只是收集了大量我们认为与结果相关的数据。要分析这些数据，我们需要一个算法。幸运的是，已经存在这样一个算法。让我们深入探讨贝叶斯网络及其在因果途径挖掘中的应用。

## Bayesian networks

**Bayesian network** 将一组变量及其条件概率描绘为 **directed acyclic graph (DAG)**。未被边连接的顶点是条件独立的（彼此不依赖）。被边连接的顶点是条件依赖的。

**chain rule of probability** 允许我们将贝叶斯网络构建为条件概率的乘积。考虑事件 *A*、*B* 和 *C*。回到我们的药物使用示例，事件 *A* 可能是规律使用，事件 *B* 是尝试药物，事件 *C* 可能是身处药物环境。我们的因果链因此如下：

$$P(A, B, C) = P(A \mid B, C) * P(B \mid C) * P(C)$$

*P(A, B, C)* 指的是所有事件同时发生的概率。*P(A|B, C)* 指的是在 *B* 和 *C* 已发生的情况下 *A* 发生的概率。*P(B|C)* 是在 *C* 发生的情况下 *B* 发生的概率。因为这些事件通常是从数据中推断出来的，所以我们需要使用算法来估计联合概率分布 *P(A,B,C)*。通常，这是通过期望值计算使用期望最大化算法来完成的，该计算基于数据条件下的期望值。然后，算法在假设计算出的期望值是正确的情况下最大化完整似然。然后根据上一步计算的似然再次调整值。一旦期望值和似然收敛，算法就会停止。

现在我们知道了贝叶斯网络的基础知识，让我们转向一个教育数据示例，展示因果途径以及贝叶斯网络可以从中学习的数据集。

## Educational pathway example

贝叶斯概率和网络在教育研究中的常见用途之一。课程排序建立在先前知识之上，学生在先前知识条件下修读课程，必须先获得该先前知识，然后才能在当前课程中取得成功。先修课程允许教授要求学生在修读他们的课程之前先修读某些课程。进入大学然后进入研究生项目的资格取决于在上一教育阶段成功完成考试。因此，教育是一个贝叶斯网络自然出现的领域。让我们深入探讨一个示例。

## Outcomes in education

教育中的许多结果都是学生所修课程长序列的 culmination。例如，在南非和美国，希望从事法律实践的学生必须修读许多课程并通过最终考试后才能独立执业。通过考试依赖于课程学习的先前成功以及在实习和其他实践法律活动中获得的经验。大多数医学学位遵循类似的教育方法，课程学习、实践经验和最终考试的结合最终导致在该领域的专业地位。

了解这些途径中的关键里程碑和转折点可确保尽可能多的学生通过最终考试获得执照。然而，存在许多课程，并非所有学生在整个教育过程中都修读相同的课程。医学生可能会专注于与他们感兴趣的医学亚专业最相关的课程。法学生可能会在不同的法律实践分支中实习，以了解他们可能喜欢从事的法律类型。因此，数据通常是不完整的；加上项目规模小，这造成了困难的数据挖掘场景。
