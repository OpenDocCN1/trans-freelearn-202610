## 问题简介

埃博拉病毒是一种**丝状病毒**，是一种具有脂质包膜的单链核糖核酸（RNA）病毒。它于1976年首次被发现，属于**人畜共患**病毒——从受感染的动物宿主传播给人类。埃博拉病毒传播给人类的动物媒介目前尚不清楚。然而，该病毒通过直接接触体液在人与人之间传播，使一线医护人员和家庭照护者面临感染和传播病毒的高风险。

埃博拉病毒抑制免疫反应，抑制凝血，促进肾功能和电解质紊乱，并促进酸中毒。所有这些都导致血容量不足，进而在许多病例中引发器官衰竭和死亡。该病毒在非洲多个地区呈地方性流行，包括刚果盆地，大多数疫情都起源于此。在已知疫情中，病死率通常在40%至50%之间，这通常是由于农村地区缺乏输血和生命支持等支持性护理，而这些地区往往是初始病例的发生地。

疫情暴发期间，个人防护装备对于避免传播给医护人员以及由医护人员造成的传播至关重要。然而，在许多农村地区，医疗物资缺乏限制了医护人员的自我保护能力，从而促进了疾病的早期传播。此外，必须对病例进行隔离，以避免感染在诊所就诊的其他患者。图13.1展示了一位穿着个人防护装备的医生，在一家为隔离埃博拉患者而设立的诊所中工作：

2013年12月，埃博拉病毒最严重的一次疫情爆发始于几内亚盖凯杜省梅利安杜——一个病毒由此传播到几内亚及其邻国塞拉利昂和利比里亚的小镇。最终，病例传播到了意大利、马里、尼日利亚、塞内加尔、西班牙、英国和美国，其中几个国家报告了二代病例（主要是医护人员）。到疫情结束时，近30000人被感染，超过10000人死亡。到2016年疫情结束时，该病毒已多次变异，研究人员开发出一种疫苗，以扑灭疫情并限制其在全球以及几内亚科纳克里等大城市内的传播。基本再生数在利比里亚为1.20，在塞拉利昂为2.02，导致受影响的三个主要国家传播迅速，感染率居高不下。

2018年刚果民主共和国的埃博拉疫情影响了伊图里省、北基伍省和南基伍省，病例集中在贝尼、布滕博、卡特瓦、卡伦古塔、马巴拉科和曼迪马。到2020年，共发现超过3500例确诊和疑似病例，尽管当地和国际公共卫生工作者及时干预，并且有2014年西非埃博拉疫情期间研发的疫苗可用，仍有超过2200人死亡。从2018年底到2019年年中，基本再生数保持在1以上，表明存在持续的感染潜力。事实上，大多数病例确实发生在这个时间段。

由于城镇隔离和公共卫生工作者的及时干预，及时的干预将潜在感染人数限制在约16000人——而不是受影响省份中的1600万居民。边境监测措施限制了埃博拉向布隆迪和卢旺达等邻国的传播。然而，对国际援助人员的不信任、与M23叛军的持续冲突，以及暴力蔓延至治疗区域，使当地和国际援助组织的疫情应对复杂化。如果应对协调更好，安全威胁处理更得当，本可以防止传播并提高生存率。

虽然本章将侧重于模拟促进埃博拉病毒在刚果民主共和国各地区传播的网络，但我们将使用的方法可以扩展到处理与网络传播相关的任何类型的**偏微分方程（PDE）**模型。例如，对生态学和保护感兴趣的读者可能会考虑采用网络科学方法，模拟影响叶海龙、巴哈马锯鲨或苏卡达陆龟种群的毒素的地理传播；他们可能还想了解捕食者-被捕食者关系中的逃避或延迟。社会科学家可能会考虑政治意识形态在一个地区各国间的传播，或这样的模型：在社交媒体运动的推动下，人口层面的行为改变效应可能存在延迟，变化发生在较长时间内，或需要达到某个阈值才会显现效果。生物医学研究者可能会考虑细胞分化和形态发生背景下的化学梯度模型、癫痫发作通过大脑皮层的扩散，甚至肿瘤在大脑各区域生长的动态。农民可能希望考虑空间模型，在屏障资源有限的情况下，限制蝗虫或其他威胁作物的害虫的传播。
