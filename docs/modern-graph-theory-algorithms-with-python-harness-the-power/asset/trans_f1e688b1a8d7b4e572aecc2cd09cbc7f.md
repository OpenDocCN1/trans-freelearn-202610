# 序言

作为生命科学以及汽车、能源和高科技行业相关公司的首席技术官/首席信息官，我不断面临着从各种非结构化和半结构化数据源中创造有意义的数据洞察的挑战。十年前，我的先进分析和机器学习之旅取得了最大飞跃，当时我在职业生涯中受益于一次极具影响力的介绍。自从我与 Colleen Farrelly 合作构建基因组诊断平台时处理以本体为重点的数据科学需求以来，我对人工智能的方法得到了极大的提升。随后，我有幸参与了 Colleen Farrelly 的杰出著作《The Shape of Data》的编写工作，该书以其独特的方式深入探讨了如何结合几何和基于机器学习的算法以及支持的数据结构来创建复杂数据问题的强大拓扑表示，这深深吸引了我。

在这部同样引人入胜的续作《使用 Python 的现代图论算法》中，Colleen Farrelly 和 Franck Kalala Mutombo 带你进入网络科学潜能释放的下一个层次，通过深入探讨具体的图论方法来解决从生态到金融、时空销售和临床数据挑战等各种行业问题。可以很容易看出，为什么任何水平的数据科学从业者和读者都会发现每一章都极具价值，这得益于支持的 Python 库和代码示例以及基础的数学解释。

随着每一页的翻阅，我发现自己渴望通过将所呈现的学习内容应用于自己的业务需求来强化它们。作为图数据库的积极使用者，我非常享受对特定技术的实践讨论，例如第 12 章，展示了 Python 集成的相对简易性和开源解决方案的内置功能，这些功能可以在当今日益强大的可用工具集中得到利用。

这本全面的书籍提供了恰到好处、及时的基础概念，使数据科学家和软件工程师能够通过直接适用的结构良好的场景大幅提升其机器学习技术。每个一致的问题-解决方案分解都包括所需的数据整理、转换和建模方面的关键考虑。

此外，本书还为量子网络科学算法、神经网络架构作为图、层次网络和超图等新前沿领域的相关性提供了令人信服的引领。本书以简洁易懂的思维过程，为你提供了如何减少大型语言模型所需的大量参数化以及如何通过超图数据库等手段解决元数据管理这一关键方面的背景。

图论在当今对每个行业和科学领域都高度相关。无论挑战是提供预测建模或模拟，还是优化业务运营或临床结果等诸多需求，本书都是掌握这些关键现实世界挑战复杂性的不可或缺的指南。凭借触手可及的关键见解和 GitHub 仓库示例，你将瞬间转变为该领域的专家。《使用 Python 的现代图论算法》的探索是一本必读且令人愉悦的书籍。

Michael Giske

Inomo Technologies 董事长兼 B-ON 全球首席信息官

# 关于作者

**Colleen Molloy Farrelly** 是一位首席数学家、数据科学家和研究人员，擅长将数学应用于生物、医学、社会和物理科学。她还著有《The Shape of Data》。她曾在拉丁美洲、非洲、欧洲和亚洲指导、合著论文并与他人合作。

她现居美国佛罗里达州迈阿密，拥有迈阿密大学生物统计学硕士学位。她热衷于发展中国家的教育项目，并在 Women in Data Science、IEEE 会议、PyData 和 Applied Machine Learning Days 等会议上发表演讲。
