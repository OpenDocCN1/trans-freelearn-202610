# 本书涵盖内容

第 1 章，什么是网络？，介绍了网络的理论概念，并提供了现实世界应用中网络的多个示例，包括随机图的工作。我们还将开始使用 Python 的 igraph 和 NetworkX 包。

第 2 章，使用 NetworkX 和 igraph 将数据整理为网络，在第 1 章的基础上，通过三个现实世界数据的示例展示可被表述为网络数据的数据，并展示如何在 Python 中将数据转换为网络形式。我们将介绍涉及空间数据、时间数据和时空数据的问题，并探讨网络科学如何通过将数据转换为网络形式来解决这些问题。

第 3 章，人口统计数据，探索了两个使用发展中国家人口统计数据的现实项目，以了解网络结构和信息/传染病传播能力。我们将考虑朋友群的人口统计特征和网络属性，以了解这两种信息如何共同影响疾病传播。

第 4 章，交通数据，提供了交通网络的现实示例，并介绍了与最小路径和网络流相关工具。我们将考虑最优路由和到目的地的最短路径，包括从一个地点到另一个地点的多站路径。

第 5 章，生态数据，展示了生态网络的现实示例，并介绍了谱图理论工具，包括谱聚类和图拉普拉斯算子。

第 6 章，股票市场数据，检查了使用网络工具对股票市场数据进行分析的现实示例，包括波动率的基于边的中心性度量。我们将挖掘数据以寻找转折点，预示市场增长或市场崩盘的时期。

第 7 章，商品价格/销售数据，提供了两个关于商业数据在空间和时间上分析的现实示例，使用了之前在时间序列和空间数据应用中介绍的工具。我们将检查跨时间和空间的销售和定价趋势，以更好地了解消费者行为以及价格变化在时间和空间上的影响。

第 8 章，动态社交网络，介绍了一个随时间演化的社交网络数据集的现实示例，并分析其对传播过程如流行病和错误信息流动的脆弱性。我们将考虑影响生态社交网络对疾病传播脆弱性的因素。





第 9 章《网络机器学习》对基于网络的机器学习和深度学习进行了全面描述，包括使用监督学习、无监督学习和半监督学习的示例，以了解社交网络中的疾病风险。

第 10 章《路径挖掘》介绍了贝叶斯网络和利用教育数据示例进行因果路径挖掘，我们将看到课程顺序和表现如何影响学生成绩。

第 11 章《语言家族映射——本体论方法》涵盖了本体论以及本体之间的映射，使用来自尼罗-苏丹语系及其词汇变体的语言数据示例。

第 12 章《图数据库》介绍了图数据库 Neo4j，包括来自前几章的数据以及如何使用前几章介绍的图工具和 Neo4j 的查询语言查询 Neo4j。我们将看到图数据库和网络科学工具如何在数据科学中产生协同作用，以及高效的数据存储解决方案。

第 13 章《整合全书》将前几章的材料整合到一个最终项目中，分析来自伊图里和北基伍省的时空网络数据和人口统计数据，并使用广义估计方程来了解 2019 年埃博拉疫情的演变。

第 14 章《新前沿》介绍了量子图算法、神经网络优化的图论、层次网络和超图。
