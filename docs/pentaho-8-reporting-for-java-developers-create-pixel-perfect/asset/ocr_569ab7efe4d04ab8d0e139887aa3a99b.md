Set the `category-column` property to `PRODUCTLINE` and the `value-columns` property to `BUYPRICE`, directly in the `Common` group of the dataset panel. In the property panel, set to true the `3-D` property in the `General` group, set to false the `show-legend` property in the `Legend` group, and set to Show Labels the `show-item-labels` property in the `Values` group. Then press the OK button and preview the resulting report by pressing the eye (👁) icon. The following screenshot shows how the preview looks like for your first bar chart:

*It is always good practice to experiment by yourself with how the resulting chart changes according to different values of one (or more) property. As an exercise, try to change one (or more) property and see what happens to the Pentaho report using the preview. Don't worry about trying advanced settings, nothing bad can happen and you can only learn.*
