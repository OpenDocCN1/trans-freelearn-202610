As you can see, the formula is a dynamic calculation of a JavaScript source code, alerting with a string containing the result.

Another interesting example of interaction using dynamic URLs is visible by clicking the PRODUCT field (for each row). In this case, a Google page is opened in a different window, searching for the selected product.
