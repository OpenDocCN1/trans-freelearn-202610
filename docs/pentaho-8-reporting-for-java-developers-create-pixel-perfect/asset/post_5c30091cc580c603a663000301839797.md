
## Group Count

| Name | Type | Description |
|------|------|-------------|
| Group Name to Count | String | The name of the group that should be counted. If set to empty, counts all groups within a parent group. |
| Reset on Parent Group Name | String | The name of the group which resets the count. If set to empty, counts the subgroups of the entire report. |

## Sum Quotient

This function sums a dividend and a divisor, and then divides the two for the result value, using the Sum function to sum the values. The properties defined for this function are described in the following table, in addition to Reset on Group Name and Crosstab Column Filter:

| Name | Type | Description |
|------|------|-------------|
| Dividend Field | String | The field that holds the dividend of this division calculation. |
| Divisor Field | String | The field that holds the divisor of this division calculation. |
| Rounding Mode | Integer | Java's BigDecimal rounding mode. See Java's documentation for values. |
| Scale | Integer | The scale of the quotient returned. The default value is 14. |

| Name | Description |
|------|-------------|
| `Sum Quotient Percent` | This function is an extension of the `Sum Quotient` function, and simply multiplies the final result by 100. It shares the same properties as the `Sum Quotient` function. |
| `Calculation` | This function stores the result of a field calculated during the prepare run stage of report generation, allowing access later on in the report. The properties defined for this function are the same as introduced earlier: `Field Name`, `Reset on Group Name`, and `Crosstab Column Filter`. |
| `Sum for Page` | This function is identical to the `Count` function, but also resets at the beginning of each page. |
| `Count for Page (Running)` | This function is identical to the `Count` function, but maintains the value of the current number of rows in a dataset and resets at the beginning of each page. |

## Lookup

This function allows you to choose between different strings, a value based on key matching. The properties defined for this function are described in the following table, in addition to Field Name and Null Value:

| Name | Type | Description |
|------|------|-------------|
| Fall Back Value | String | If no keys match the field value, return this value. |
| Key Values | Array of strings | Values to compare with the field. Each key should have a corresponding text value. |
| Text Values | Array of Strings | It is a list of strings. A string is chosen from the list depending on which key matches the field value. |
| Ignore Case When Matching | Boolean | If set to true, ignores the case when making key comparisons. |

## Indirect Lookup

This function allows you to choose between different columns, a value based on key matching. The properties defined for this function are described in the following table, in addition to `Field Name`, `Key Values`, `Null Value`, and `Ignore Case When Matching`:

| Name | Type | Description |
|------|------|-------------|
| Fallback Forward-Field | String | If no keys match the field value, return this field's value. |
| Forwarding Field List | Array of Strings | It is a list of fields. A field is chosen from the list depending on which key matches the field value. |
