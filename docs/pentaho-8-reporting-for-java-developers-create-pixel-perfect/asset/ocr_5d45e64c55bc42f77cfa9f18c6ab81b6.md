# Series properties

In the following table you can see listed, the set of properties defined for series properties:

| Name | Type | Description |
|---|---|---|
| series-by-values | Array of strings | Specifies the values you are charting. Series are usually placed in the chart legend. |
| series-by-fields | Array of strings | Specifies the fields you are charting. Series are usually placed in the chart legend. |
| auto-generate-series | Boolean | If true, then when the items advance, no action is taken to accumulate data. This should only be used with a group specified so that when the groups advance, the data can be properly accumulated. |
