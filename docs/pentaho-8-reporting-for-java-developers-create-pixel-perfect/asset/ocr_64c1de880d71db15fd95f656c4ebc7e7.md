| FIND | Returns the index of the first occurrence of the search string in the text, starting at the index specified. The index parameter is optional. |
| DOLLAR | Rounds up the number to a specified number of decimals and formats the result as a text. |
| LEFT | Returns the left portion of a string up to length characters. |
| LEN | Returns the length of the text. |
| LIKE | Acts like the SQL LIKE function, comparing the first value to a regular expression. |
| LOWER | Returns the text in all lowercase. |
| MESSAGE | Formats the values using the given message format. |
| MID | Returns a substring within the Text, starting at Start and having the length of Length. |
| PROPER | Returns the input string with the first letter of each word converted to an uppercase. |
| QUOTETEXT | Quotes a text. |
| REPLACE | Replaces a portion of the Text, starting at Start and ending at Length, with New text provided. |
