To create `XPathDataFactory`, use the default constructor. To configure `XPathDataFactory`, you must specify an XML file, along with a set of XPath queries. For a good introduction to XPath, see http://www.w3.org/TR/xpath.

In the following table, some of the most relevant methods are introduced:

| Method | Description |
|---|---|
| `void setXqueryDataFile(String filename)` | `XPathDataFactory` uses Pentaho Reporting Engine's `ResourceManager` for loading the XPath file. To set the location of the XML file, use this method. |
| `void setQuery(String name, String xpath)` | Named queries may be added with this method. |

*There is no standard way to easily sort row data via XPath, so be sure to have your data in the correct order before loading it with `XPathDataFactory`. The inability to sort limits the capabilities of this `DataFactory`.*
