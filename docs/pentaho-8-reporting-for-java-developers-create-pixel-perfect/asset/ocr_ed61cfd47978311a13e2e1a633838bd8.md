By default, the Pentaho Business Analytics Platform distribution comes with an HyperSQL database (http://hsqldb.org/) instance to store configurations, data and everything that is requested to run correctly. By its nature, the HyperSQL database is not suggested for a production environment, but for now, it perfectly fits our purpose. If interested, Pentaho Business Analytics Platform can also run using the most common RDBMS and application servers. Refer to the official documentation for further details.
