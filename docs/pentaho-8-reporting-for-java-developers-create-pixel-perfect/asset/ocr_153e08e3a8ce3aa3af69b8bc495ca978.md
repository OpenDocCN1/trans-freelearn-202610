
To run the project, download the pentaho-reporting-data-source-pmd folder to your local machine, open a terminal, move into this folder, and execute the following commands in the given sequence:

```
mvn clean install
mvn package
java -jar target/dependency/jetty-runner.jar target/*.war
```

Then open a browser at http://localhost:8080, and you should see the Pentaho report in PDF format as a result.
