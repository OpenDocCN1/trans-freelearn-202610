# Line chart example

As an example, let's reuse the same data source we described for the bar chart. Starting from an empty report, select File | Page Setup and check Landscape in the Orientation panel. Then press the OK button and check the Do not change the layout option. Once confirmed, drag the chart (🖼) icon and drop it into the Report Header band. Stretch the chart element to cover the whole width of the page, and set to 450 the height property of the size & position group in the element properties panel.

By double-clicking on the chart element, the chart edit window will be shown. Select the line chart icon from the upper panel and set the category-column property to PRODUCTLINE and the value-columns property to BUYPRICE, directly in the Common group of the dataset panel. In the property panel, set to true the show-markers property and set to true the horizontal property, both available in the Options group. Last but not least, set to false the show-legend property in the Legend group, then press the OK button, and then preview the resulting report by pressing the eye (👁) icon.
