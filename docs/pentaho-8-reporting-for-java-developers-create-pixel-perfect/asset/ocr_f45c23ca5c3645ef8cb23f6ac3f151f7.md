# Ring chart

The ring chart is identical to the pie chart, except that it renders as a ring as opposed to a complete pie. In addition to sharing all the properties similar to the pie chart, it also defines the `section-depth` property (decimal) in the options set.

The `section-depth` property defines the percentage of the circle that will be filled with the ring chart. The larger the value, the less space there is in the center of the ring. Possible values are between 0.1 and 1, where 1 is equivalent to a pie chart.
