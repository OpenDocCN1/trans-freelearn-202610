# Group Header and Group Footer properties

The `Group Header` and `Group Footer` bands may appear for each defined group configured as part of the report. A grouping defined in a report is a set of identical values in one or more selected data columns. A new group is triggered when the values change in the defined group column(s).

![](bbox=[0.14, 0.34, 0.21, 0.39])

> *It's critical that columns defined as groupings are sorted appropriately before being passed into Pentaho Reporting, otherwise duplicate groups may appear in the rendered report.*

`Group Header` and `Footer` differ slightly from the common properties defined earlier, because the following properties are available in addition to the defaults: `repeat-header`, `sticky`, `page-header-left`, `page-header-center`, and `page-header-right`. `Group Header` and `Footer` have the `table` set as additional properties beyond the common set.
