Can you see that the `SampleData (Local)` data source is not available in the default installation of Business Analytics Platform? This is the reason why `my_first_report` will fail if executed. As an exercise, open the report directly from the Pentaho repository using Pentaho Report Designer, and change the data source to `SampleData`. Then publish the report again, replacing it into the Pentaho repository. As an alternative, delete it from the Pentaho repository and replace it with the one you can find in the https://github.com/fcorti/pentaho-8-reporting-for-java-developers repository, specifically, in the `Chapter 15 - Using reports in Pentaho Business Analytics Platform/my_reports` folder.
