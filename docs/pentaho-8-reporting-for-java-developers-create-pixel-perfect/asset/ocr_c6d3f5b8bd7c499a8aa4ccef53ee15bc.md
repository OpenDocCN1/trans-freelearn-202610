# Extended XY line chart example

As an example, start from the previous example (XY bar chart, XY line chart, or XY area chart) and edit the chart element, changing the chart type to extended XY line chart (from the upper panel, select the icon representing the target chart type). In the property panel, set the `ext-chart-type` property (in the `Options` group) to `StepChart` and press the OK button. Then preview the resulting report by using the eye (👁) icon.
