| Name | Type | Description |
|---|---|---|
| Export Descriptor | String | This property is used to determine whether the current report export type should disable page headers and footers. Its default value is `table`. |
| Hide Page Bands | Boolean | If set to true, hides page bands. |
| Disable Repeating Headers | Boolean | Disables any repeating group headers and footers. |

| Show Page Footer | This function hides the page footer except for the last page. It has no additional properties. |
