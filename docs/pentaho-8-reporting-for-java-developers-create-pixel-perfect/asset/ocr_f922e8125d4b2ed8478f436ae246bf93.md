| `ISNONTEXT` | Returns true if the value is not text. |
| `ISNUMBER` | Returns true if the value is a number. |
| `ISODD` | Returns true if the value is odd. |
| `ISREF` | Returns true if the value is a reference. |
| `ISTEXT` | Returns true if the value is a text type. |
| `LOOKUP` | Looks up an external value. This is the same as the square bracket operator as a result of the field selection (▦) icon. |
| `METADATA` | Returns a value from the `Meta-Data` attributes of the given field. |
| `NA` | Returns the error `NA`, Or `Not Available`. |
| `ROWCOUNT` | Returns the current row number of the given group. |
| `VALUE` | Converts a text string to a numeric value. |
