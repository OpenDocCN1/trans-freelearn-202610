Starting from here, the task is a simple editing of a property file, where you can add, modify, or delete the entries in the format `key=value`. As an example, you can check the following pairs:

```
title=My report
companyName=ACME, Inc.
```

![](bbox=[0.14, 0.408, 0.21, 0.459])

*Always double-check the keys you will manage in the resource files. Keys are case sensitive and must be exactly the same as those used into the report elements. If you misspell even a digit, the final content will not be shown and it's always a relevant loss of time to identify these kind of bugs.*
