Once you start the Pentaho Report Design Wizard, a model window appears, describing four steps:

+   1. Look and Feel, where you choose your preferred layout from a list of possible templates
+   2. Data Source and Query, where you define the dataset to use in your report
+   3. Layout Step, where you define grouping and fields to show in the report
+   4. Format Step, where you define the look and feel of each single item shown in the report
