To complete the life cycle of our report, as the last topic in this chapter, let's briefly discuss how to open a report from the filesystem. The task is not difficult to do and to understand. In addition to that, like the save task, opening a Pentaho report is not different from opening a regular file. To open a Pentaho report from the Report Designer, click on the File item in the menu and then select Open.... Select the .prpt file from the filesystem and click OK. That's all.

The report will be imported again into the Pentaho Report Designer and be ready to be modified and previewed again, as we discussed in the previous sections. As we saw for Save and Save As..., a folder icon (📁) is visible in the toolbar as a shortcut for the Open... feature of the upper menu.
