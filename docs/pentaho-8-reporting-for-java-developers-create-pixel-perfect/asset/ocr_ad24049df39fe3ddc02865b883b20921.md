# Common functions

The common functions include the most commonly used functions within Pentaho Report Designer:

This function evaluates a LibFormula formula defined later in this chapter. The following are properties of this function:

| Name | Type | Description |
|------|------|-------------|
| Formula | String | Formula to evaluate. By clicking on the ... button, the formula editor is shown. Check the section dedicated to the formula topic for details. |
| Dependency level | Integer | Used to determine the order in which to execute the function. |

This function returns the current page number. The following are properties of this function:

| Name | Type | Description |
|------|------|-------------|
| Page increment | Integer | The number by which to increase the count for each page |
| Start Page Number | Integer | The page from which to start counting |
