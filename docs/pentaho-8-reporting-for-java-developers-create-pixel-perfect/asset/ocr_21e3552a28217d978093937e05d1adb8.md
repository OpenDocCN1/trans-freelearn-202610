# User-defined formulas

In this category are all the functions developed with some kind of external contributions:

| Name | Description |
|---|---|
| ARRAYCONCATENATE | Concatenates the arrays. |
| ARRAYCONTAINS | Checks whether all given values are contained in the array. |
| ARRAYLEFT | Returns the first element or elements of an array. |
| ARRAYMIND | Returns a partial array of a given array. |
| CVSARRAY | Converts a CSV-text into an array. |
| CVSTEXT | Generates a comma-separated value list. If Doquoting is set to true, quotes all the strings. By default, the separator is a comma. This can be overridden by setting the separator parameter. By default, the strings are quoted using a double quote. This can be overridden by setting the Quote parameter. |
| DRILLDOWN | Creates a drill-down link to another report. This function implements the same as the link icon of the formula editor. The user interface of this function is more complex than the others and will enable you to define a drill-down with a URL, a Pentaho repository, or the report itself. Parameters can be passed to the target resource to customize the data. |
