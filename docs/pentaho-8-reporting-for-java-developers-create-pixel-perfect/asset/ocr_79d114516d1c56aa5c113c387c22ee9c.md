| on-key-down | This property renders an `onkeydown` HTML attribute on the currently defined element. It is a string of JavaScript that is executed in the browser when a user presses down a key. |
| on-key-pressed | This property renders an `onkeypress` HTML attribute on the currently defined element. It is a string of JavaScript that is executed in the browser when a user presses a key. |
| on-key-up | This property renders an `onkeyup` HTML attribute on the currently defined element. It is a string of JavaScript that is executed in the browser when a user releases a key. |
