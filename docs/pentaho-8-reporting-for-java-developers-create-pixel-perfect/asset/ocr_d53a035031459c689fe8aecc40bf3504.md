# Excel properties

This is a set of properties related to Microsoft Excel:

| Name | Type | Description |
|---|---|---|
| sheet-name | String | The name of the sheet to render the band. |
| format-override | String | The Excel cell data format string. |
| formula-override | String | The Excel cell data formula string. |
| wrap-text-override | Boolean | If true, wraps a text-based report element text within an Excel Cell. This value is inherited by text-based report elements within the band. |
| indentation-text | Integer | Number of characters for indentation. |
