# HTML-events properties

This set of properties is related to `HTML-events` raised when the report is generated in HTML format:

| Name | Type | Description |
|---|---|---|
| on-click | String | String used as formula in the HTML format |
| on-double-click | String | String used as formula in the HTML format |
| on-mouse-down | String | String used as formula in the HTML format |
| on-mouse-up | String | String used as formula in the HTML format |
| on-mouse-move | String | String used as formula in the HTML format |
| on-mouse-over | String | String used as formula in the HTML format |
| on-mouse-enter | String | String used as formula in the HTML format |
| on-mouse-out | String | String used as formula in the HTML format |
| on-key-down | String | String used as formula in the HTML format |
| on-key-pressed | String | String used as formula in the HTML format |
| on-key-up | String | String used as formula in the HTML format |
