# Bubble chart example

As an example, let's reuse the same data source we described for the bar chart. Starting from an empty report, change the orientation to landscape and set the chart element as described in the previous examples.

By double-clicking on the chart element, the chart edit window will be shown. Select the bubble chart icon from the upper panel and set the `x-value-columns` property to `BUYPRICE`, the `y-value-columns` and `z-value-columns` properties to `QUANTITYINSTOCK`, and the `series-by-field` property to `PRODUCTLINE`, directly in the dataset panel. In the property panel, set the `max-bubble-size` property (in the `Options` group) to `100`, then press the OK button and preview the resulting report by pressing the eye (👁️) icon.
