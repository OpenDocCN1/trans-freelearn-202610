# Including an existing Pentaho report

The very first task is to include `my_first_report` in the Java web application. Remembering that the `my_first_report.prpt` file contains everything that is requested to render the Pentaho report, create the path `pentaho-reporting-web-app/src/main/resources/reports` and copy the `my_first_report.prpt` file into it.

Believe it or not, but this is all you need to do to make the report available to the Java web application.
