# Menu and toolbar

The menu and toolbar contain useful functionalities to make building a report easier. Along with basic functionalities like saving, opening, and publishing, you have access to a lot of advanced features. Many of the options in the menu and toolbar are available as shortcut keys. The purpose of the Pentaho Report Designer's menu and toolbar is not different from a standard menu and toolbar. They contain all the available features, collected in a sequence of descriptions and icons, all clickable to complete a specific task.
