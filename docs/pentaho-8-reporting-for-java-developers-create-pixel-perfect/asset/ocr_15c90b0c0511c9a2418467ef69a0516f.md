# The XML data source

The XML data source is quite easy to understand and can be useful for exported data from external systems, if you don't want to use a database but want to use the data in a report. Once this data source type is selected, a modal window is

![](bbox=[0.3, 0.248, 0.713, 0.583])

shown, as follows:

Starting from the top, the first parameter is about pointing to an XML file. In this example, in particular, we are going to use the `steelwheels.mondrian.xml` file stored in the `report-designer/samples` folder.

![](bbox=[0.143, 0.732, 0.207, 0.777])

Unfortunately, this is what we have avail bundled in the Pentaho Reporting distribution and it's enough for our demonstrate an example of use of the XML data source.*
