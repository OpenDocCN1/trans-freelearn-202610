# Database formulas

This category of functions implements some SQL like functions, returning a logical type result:

| Name | Description |
|------|-------------|
| BEGINSWIDTH | Returns true if a string begins with another string |
| CONTAINS | Returns true if a string contains another string |
| ENDSWIDTH | Returns true if a string ends with another string |
| EQUALS | Returns true if two strings are equal |
| IN | Returns true if any of the subsequent arguments match the first argument |
| LIKE | Acts like the SQL LIKE function, comparing the first value to a regular expression |
