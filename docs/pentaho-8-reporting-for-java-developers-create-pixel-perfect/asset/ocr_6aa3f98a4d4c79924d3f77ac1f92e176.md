# Adding elements to the report

Now that you have set up all the bands for your report, you are ready to start adding elements. Unlike the previous classes and interfaces introduced for bands, all elements share a single class implementation, `Element`, and are created by element factories. The `Element` class is located in the `org.pentaho.reporting.engine.classic.core` package. The primary set of element factories is located in the `org.pentaho.reporting.engine.classic.core.elementfactory` package.

To use a factory, first instantiate the factory object and then configure the Java bean setters of the factory. Once you have built your element within the factory object, call `createElement()` to retrieve the `Element` instance, which you will then add to your report.
