# Excel properties

In this group of properties, the `Master Report` element does not provide the `page-header-*` properties and has a couple of additional specific properties:

| Name | Type | Description |
|---|---|---|
| `freezing-left-position` | String | The goal of this property is to provide to Pentaho Reporting Developers the ability to choose which panes, in Excel, they want to freeze |
| `freezing-right-position` | String | The goal of this property is to provide to Pentaho Reporting Developers the ability to choose which panes, in Excel, they want to freeze |
