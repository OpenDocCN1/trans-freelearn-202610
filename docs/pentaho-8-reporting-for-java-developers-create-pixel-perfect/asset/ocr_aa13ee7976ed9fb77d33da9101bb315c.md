# Anatomy of the Pentaho Reporting SDK

Before any further steps, let's introduce the directory structure of Pentaho Reporting SDK and a brief description of its content. A description of how the `PentahoReportingEngineSDK` folder looks is shown as follows:

```
PentahoReportingEngineSDK
|- documentation
|- licenses
|- samples
|- build-res
|- lib
|- source
|- sql
|- WebContent
|- META-INF
|- WEB-INF
```

Following are brief descriptions of the contents of each folder:

| Folder | Description |
|---|---|
| `PentahoReportingEngineSDK` | Root of Pentaho Reporting SDK. |
| `documentation` | Location where the `embedding_pentaho_reporting_engine` PDF file is located. |
| `licenses` | Contains text files with licensing information. |
| `samples` | The project directory for Eclipse, containing some samples |
