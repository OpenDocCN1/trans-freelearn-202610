### 关于审稿人

离开学校并从事过包括见习会计师和士兵在内的各种职业后，**Charles Thomas** 在 1990 年为一家他担任实验室主管的公司提供了软件解决方案。1992 年，他因公司裁员而失业，随后完成了进一步的软件培训（1994 年获得计算机研究 HNC 证书）。

自 1994 年以来，他一直参与处于“技术前沿”的项目，并且非常享受这些工作。在他的职业生涯中，他曾作为软件工程师在英国、欧洲、加拿大和美国为不同的公司工作（这些公司包括欧洲银行、GE（阿姆斯特丹）、Associated Newspapers / Daily Mail 和 HSBC）。他目前生活在英国并工作，根据有意公司的要求，以合同形式担任图形前端开发人员。

他还为 Packt Publishing 出版的《Instant RaphaelJS Starter》做过一次较小的审阅。

> 我想感谢 Tomás Alabés（最新 Raphaël 版本的主要协作者），感谢他提供有关 Raphaël 未来的信息，这些信息出现在本书的最后一章。

**Lee Turver** 是一位位于曼彻斯特的 PHP 开发人员，拥有近 10 年使用各种 Web 相关技术的经验。目前在西北地区一家领先的数字代理机构工作，为知名客户构建高质量解决方案。
