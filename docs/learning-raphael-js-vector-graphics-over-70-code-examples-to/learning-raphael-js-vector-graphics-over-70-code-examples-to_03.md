### 关于作者

**Damian Dawber** 是一名网页开发人员，致力于中型到大型电子商务网站以及定制网页和移动应用程序的开发。他同时使用前端和服务器端技术，曾为中小型企业直至富时 100 指数公司参与过各种项目。

他在接触到用于解决物理问题的编程后开始了自己的职业生涯，并从此决定每天编写代码。
