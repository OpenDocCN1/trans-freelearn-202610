You will notice that we have joined a straight line to the start point on each path.
This is because simply closing a Catmull-Rom curve will continue with the curvature
of the path and not give us a straight line. On clicking on a square, we animate the
curve to the end path as follows:

```
square.click(function() {
curve.animate({
path: pathEnd
}, 500);
});
```
