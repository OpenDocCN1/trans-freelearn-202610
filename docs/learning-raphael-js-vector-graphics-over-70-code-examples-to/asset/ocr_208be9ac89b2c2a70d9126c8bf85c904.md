# # Drawing Paths

The closepath command character is z and does not accept any parameters. Since in
the previous example we drew a straight line back to the end point, we could instead
close the path using the closepath command as follows:

```
```
var hexagon = paper.path(
 ['M', 250, 15,
 'l', sideLength, 0,
 x, y,
 -x, y,
 -sideLength, 0,
 -x, -y,
 'z' // in place of the line to (x, -y)
 ]
);
```
```

In this instance, the path’s start and end points are joined. Note that the closepath
command can be either uppercase or lowercase but this has no effect on its behavior.

# # Drawing curves

There are three types of curve path: quadratic Bézier curves, cubic Bézier curves,
and arcs. Bézier curves are curves defined between a start and end point but whose
direction we can determine by using control points, while arcs are a portion of the
circumference of an ellipse.

# # Quadratic Bézier curves

A quadratic Bézier curve is a curve between two points with a single control point.
To appreciate how quadratic Bézier curves are drawn, you should experiment with
the animated demo at http://www.jasondavies.com/animated-bezier/. As
shown here, the curve is drawn from a point P0 to a point P2 with a control point P1.
The control point P1 relative to P0 and P2 determines the extent to which the curve
bends: from start to finish, the curve starts off heading in the direction of the control
point P1 and then bends towards the end point P2 from the direction of P1.
