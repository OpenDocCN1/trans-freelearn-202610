Notice the anchor points on the circle. The leftmost point is used to control the width
of the circle, the topmost point controls the height while the rightmost point is used
to change the end point. Click-and-drag on the rightmost breakpoint: dragging
inside the circle draws a straight line from the end point to the start point while
dragging outside creates a segment.
