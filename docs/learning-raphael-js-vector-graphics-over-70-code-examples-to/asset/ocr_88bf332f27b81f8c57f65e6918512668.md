# # Embedding images

Raphaël allows us to embed bitmap (.jpg or .png) images into our canvas. It does so using the image method of the the Paper object. The following code demonstrates embedding a .jpg image:

```
```
var paper = Raphael('my-canvas', 600, 252);
paper.image('stella.jpg', 15, 15, 144, 192);
```
```

The .jpg image is included at (15, 15) and its width and height are scaled to 144px and 192px respectively.
