## 关于 Packt 出版社

Packt，发音为 'packed'，于 2004 年 4 月出版了其第一本书《掌握 phpMyAdmin 以实现有效的 MySQL 管理》，随后继续专注于出版针对特定技术和解决方案的高度聚焦图书。

我们的书籍和出版物分享了您的 IT 专业同行在适应和定制当今系统、应用程序和框架方面的经验。我们的解决方案导向图书为您提供知识和能力，以定制您正在使用的软件和技术来完成工作。Packt 图书比您过去见过的 IT 图书更具体、更不笼统。我们独特的商业模式使我们能够为您带来更聚焦的信息，让您获得更多需要知道的内容，而减少不需要知道的内容。

Packt 是一家现代且独特的出版公司，专注于为开发者、管理员和新手社区制作高质量、前沿的图书。如需更多信息，请访问我们的网站：www.packtpub.com。
