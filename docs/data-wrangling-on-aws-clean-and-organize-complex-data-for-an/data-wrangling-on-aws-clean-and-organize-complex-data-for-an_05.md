# 第 3 部分：AWS 数据管理与分析

在本部分，我们将探索用于有效数据管理与分析的必需 AWS 服务。第 5 章介绍了 Amazon S3，揭示了其作为数据存储和组织强大解决方案的潜力。第 6 章深入探讨了 AWS Glue，展示了这个强大的 ETL 服务如何自动化数据准备和转换工作流程。第 7 章介绍了 Amazon Athena，这是一种无服务器查询服务，使你能够直接在 Amazon S3 数据上通过 SQL 查询获取有价值的见解。最后，第 8 章探索了 Amazon QuickSight，这是一种快速商业智能服务，用于创建交互式仪表板和可视化，从而从你的数据中获取有价值的见解。

本部分包含以下章节：

- 第 5 章，使用 Amazon S3
- 第 6 章，使用 AWS Glue
- 第 7 章，使用 Athena
- 第 8 章，使用 QuickSight
