Click on **ADD FILTER** and choose the column/attribute from the dataset based on which the filter condition should be applied. Remember to choose the **Only this visual** option to avoid the date filter being applied to other visuals that we might create in this sheet. We will choose *After* for **Condition** and set the *Date* field to *2016/01/01*. We also have the option to choose a rolling window to keep looking at the latest data (visualize only the last 90 days of data). Once all options are chosen, click on **APPLY**.
