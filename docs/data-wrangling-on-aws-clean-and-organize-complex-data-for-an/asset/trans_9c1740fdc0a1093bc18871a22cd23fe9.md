## 贡献者

### 关于作者

**Navnit Shukla** 是一个充满激情的人，热爱技术。他在卢克瑙的 A.P.J. 阿卜杜勒·卡拉姆技术大学（前身为 U.P.T.U）攻读电子与通信工程，为他未来的事业奠定了基础。25 岁时，他跨越重洋来到美国，现在居住在南加利福尼亚州美丽的橙县，与他深爱的妻子和儿子住在一起。自 2009 年以来，他沉浸在世界 IT 领域，在行业内获得了丰富的经验和知识。在过去的四年里，他担任 **Amazon Web Services (AWS)** 的专家解决方案架构师 – 分析领域。在这个角色中，他负责协助各种规模的机构在动态的 AWS 云平台上设计、构建和无缝运行解决方案。除了职业追求之外，他与家人和朋友共度美好时光、探索新地方、创造珍贵回忆以及进行激动人心的冒险时，都能找到极大的乐趣。

> *我深深感谢那些在我旅途中一直陪伴在我身边、提供坚定支持的人。我向我所爱的妻子 Anchal Dubey 和我敬爱的父母致以衷心的感谢，他们的鼓励和信念对我无价。*

**Sankar M** 自 2007 年以来一直在 IT 行业工作，多年来专注于数据库、数据仓库和分析领域。作为一名专业的数据架构师，他帮助客户构建和现代化数据架构，并帮助他们构建安全、可扩展且高性能的数据湖、数据库和数据仓库解决方案。在加入 AWS 之前，他曾在多个客户那里工作，实施复杂的数据架构。

**Sam Palani** 拥有 18 年以上开发者、数据工程师、数据科学家、初创公司联合创始人和 IT 领导者的经验。他拥有工商管理硕士学位，并在信息技术领域具有双重专业背景。他的职业生涯跨越了 5 个国家，涉及金融服务、管理咨询和技术行业。他目前是 Amazon Web Services 的机器学习和 AI 高级领导，负责多个业务线、产品策略和思想领导。Sam 也是一位实践中的数据科学家，拥有多部出版物的作家，主要行业会议的演讲者，以及积极的开源贡献者。下班后，他喜欢远足、摄影、尝试美食和阅读。

### 关于审阅者

**Naresh Rohra** 是一位杰出的数据建模师和首席分析师，热衷于利用尖端技术的潜力从复杂的数据集中解锁有价值的洞察。凭借在数据建模领域十余年的经验，他成功地驾驭了数据整理和分析的动态环境，赢得了领先专家的名声。他出色地设计了与 OLTP 和 OLAP 系统相关的各种数据模型。他曾在 TCS、Cognizant 和 Tech Mahindra 等著名组织工作。

**Roja Boina** 是一位工程高级顾问。她为企业提供数据驱动的解决方案。她为自己那种“完成事情”的态度感到自豪。她喜欢定义需求、设计、开发、测试和交付后端应用程序，并通过可视化沟通数据。她非常热衷于成为一名 **Women in Tech (WIT)** 倡导者，并成为 WIT 社区的一部分。除了她朝九晚五的工作之外，她喜欢为非营利组织做志愿者，并指导 STEM 领域的女性同行。她相信拥有成长型思维。
