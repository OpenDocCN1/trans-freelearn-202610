You could also visualize the data using the matplotlib library and export it as an image. The following code snippet provides an example of visualizing the teams with the most sacks:

```python
# plotting values
import matplotlib.pyplot as plt
vis_data=output_data[(output_data["stat2"]=="SCK")].groupby(["team"])["stat1_val"].sum().sort_values(ascending=False)[:10]
vis_data=vis_data.to_frame()
ax=vis_data.plot.barh(color="red")
ax.bar_label(ax.containers[0])
ax.get_legend().remove()
plt.title('Team with highest sacks')
plt.xlabel('Sacks')
plt.ylabel('Team')
```
