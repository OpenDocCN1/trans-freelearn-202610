Watchful eyes will notice the id column is appended with _x for the sporting_event (left table) DataFrame and _y for the sport_team (right table) DataFrame. This is to avoid duplicate column names in the resulting dataset. Similar suffixes will be appended to other columns with similar names. We will have to make a note of this and use this name in the resulting DataFrame to access those columns.
