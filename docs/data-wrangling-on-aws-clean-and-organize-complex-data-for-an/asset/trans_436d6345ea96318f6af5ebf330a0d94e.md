## 介绍数据整理

为了使组织能够以数据驱动的方式为客户创造价值或做出更明智的业务决策，他们需要从不同的数据源收集大量数据，例如点击流、日志数据、交易系统和平文件，并将它们存储在不同的数据存储中，例如数据湖、数据库和数据仓库作为 **原始数据**。一旦数据存储在不同的数据存储中，就需要对其进行清理、转换、组织并从不同的数据源进行连接，以为下游应用程序提供更有意义的信息，例如机器学习模型提供产品推荐或查找交通状况。或者，它可以被业务或数据分析使用，以提取有意义的业务信息：

数据整理带来诸多优势：

- **增强数据质量：** 数据整理有助于提高数据的整体质量。它涉及识别和处理缺失值、异常值、不一致和错误。通过解决这些问题，数据整理可确保用于分析的数据准确可靠，从而产生更稳健、更值得信赖的结果。

- **提高数据一致性：** 原始数据通常来自各种来源或以不同格式存在，导致命名约定、测量单位或数据结构不一致。数据整理允许您标准化并协调数据，确保数据集中的一致性。一致的数据使信息更容易集成和比较，促进有效的分析和解释。

- **提高数据完整性：** 不完整的数据在分析和建模过程中会带来挑战。数据整理方法允许您通过应用诸如插补等技术来处理缺失数据，其中缺失值基于现有信息进行估计或填充。通过适当处理缺失数据，数据整理有助于确保数据集更完整，减少潜在偏差并提高分析的准确性。

- **促进数据集成：** 组织的数据通常分散在多个系统和来源中，使集成成为一项复杂任务。数据整理有助于合并和集成来自各种来源的数据，使分析人员能够使用统一的数据集。这种集成提供了数据的整体视图，使全面分析和洞察成为可能，而这些在处理碎片化数据时可能无法实现。

- **简化数据转换：** 数据整理提供工具和技术将原始数据转换为适合分析的格式。这种转换包括数据规范化、聚合、过滤和重新格式化等任务。通过简化这些流程，数据整理简化了数据准备阶段，为分析人员节省时间和精力，使他们能够更专注于实际分析和结果解释。

- **实现有效的特征工程：** 特征工程涉及创建新的派生变量或转换现有变量以提高机器学习模型的性能。数据整理为特征工程奠定了基础，通过以允许有意义转换的方式准备数据。通过执行诸如缩放、对类别变量进行编码或创建交互项等任务，数据整理有助于导出信息丰富的特征，增强模型的预测能力。

- **支持数据探索和可视化：** 数据整理通常涉及探索性数据分析 (EDA)，分析人员在正式建模之前获得数据见解并了解数据模式。通过清理和准备数据，数据整理能够进行有效的数据探索，帮助分析人员发现关系、识别趋势并使用图表、图形或其他视觉表示来可视化数据。这些探索步骤对于形成假设、做出数据驱动的决策和有效传达见解至关重要。
