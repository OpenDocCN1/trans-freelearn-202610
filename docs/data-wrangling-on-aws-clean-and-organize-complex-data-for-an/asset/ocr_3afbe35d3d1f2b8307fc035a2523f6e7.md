9. Rename the column.

During dataset analysis, it was discovered that some column names, such as **Phone No.**, end with a dot. To resolve this issue, the column should be renamed. To change a column name, select the column and click on the three dots, then choose the **Rename** option.

To update the column name, choose a new name. For example, **Phone No.** can be changed to **Phone**. Once the new name has been chosen, click on **Apply**.
