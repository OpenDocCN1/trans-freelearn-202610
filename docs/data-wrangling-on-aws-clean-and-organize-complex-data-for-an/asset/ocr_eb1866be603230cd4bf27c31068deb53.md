# Validation of data quality check with corrected dataset

Now, we need to validate the data quality check with the corrected dataset. Here are the steps to follow:

+   1. The first step is to create a dataset from the corrected dataset (you can follow the steps outlined earlier).

![](bbox=[0.132, 0.217, 0.853, 0.409])

Figure 2.61: Dataset list in AWS Glue DataBrew console

+   2. Next, we need to run a data quality rule against the data quality check. Follow these steps:

![](bbox=[0.151, 0.472, 0.833, 0.691])

Figure 2.62: Choosing the dataset

+   3. Choose **DQ Rules** and select the ruleset you created earlier.
+   4. Select **Duplicate** on the **Actions** menu.
+   5. Browse the newly created dataset on the associate dataset.
+   6. Click on **Create ruleset** at the end.
