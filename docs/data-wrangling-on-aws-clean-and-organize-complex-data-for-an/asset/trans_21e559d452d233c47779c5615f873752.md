## 前言

欢迎来到 AWS 数据整理的世界！在这本全面的书中，我们将探索数据整理这一令人兴奋的领域，并揭示利用 Amazon Web Services（AWS）进行高效、有效的数据操作和准备的巨大潜力。无论您是数据专业人士、数据科学家，还是对利用数据力量感兴趣的人，本书都将为您提供在 AWS 平台上精通数据整理所需的知识和工具。

数据整理，又称数据准备或数据清洗，是数据分析过程中的关键步骤。它涉及将原始数据转换为干净、结构化的格式，以便进行分析。随着数据的指数级增长和对数据驱动决策的需求日益增加，掌握数据整理的艺术对于从庞大而复杂的数据集中提取有价值的见解变得至关重要。

在本书中，我们将通过一系列章节引导您了解 AWS 上数据整理的各个方面。我们将探索各种 AWS 服务和工具，它们使您能够高效地操作、转换和准备数据以供分析。从 AWS Glue 和 Athena 到 SageMaker Data Wrangler 和 QuickSight，我们将深入研究这些服务的强大功能，并揭示它们从数据中解锁宝贵见解的潜力。

在整本书中，您将学习如何利用 AWS 的云基础设施和强大的数据处理能力来简化数据整理工作流程。您将发现实用技术、最佳实践和动手示例，这些将帮助您掌握应对现实世界数据挑战并从数据集中提取有意义信息的技能。

因此，无论您是刚刚开始数据整理之旅，还是希望扩展在 AWS 生态系统中的知识，本书都是您掌握 AWS 数据整理的全面指南。借助 AWS 的前沿技术和工具，准备好释放数据的力量并充分发挥其全部潜力吧。

让我们深入了解并开启一段激动人心的 AWS 数据整理之旅！

### 本书适合谁阅读

本书专为各类对掌握数据整理艺术、并希望借助 AWS 的强大力量进行高效数据处理和准备工作的读者而设计。本书适合以下读者：

- **数据专业人士：** 处理大型复杂数据集并希望提升其在 AWS 平台上数据整理技能的数据工程师、数据分析师和数据科学家
- **AWS 用户：** 已经熟悉 AWS 并希望探索可用于数据整理的各种服务和工具的个人
- **业务分析师：** 参与数据驱动决策和分析，需要掌握数据整理技能以从数据中获取宝贵见解的专业人士
- **IT 专业人士：** 希望扩展自己在 AWS 平台上数据整理知识的技术爱好者和 IT 从业人员

虽然具备数据整理或 AWS 的相关经验会有所帮助，但本书为初学者提供了扎实的基础，并逐步深入到更高级的主题。熟悉基本编程概念和 SQL 会是一个优势，但并非必需。本书将理论讲解与实践示例和动手练习相结合，让不同背景和技能水平的读者都能轻松上手。

### 本书涵盖的内容

*第1章，数据整理入门：* 在开篇章节中，您将开启一段通往数据整理世界的旅程，并发现利用 AWS 进行高效、有效的数据操作和准备的力量。本章为您打下坚实的基础，概述了您将在全书中遇到的关键概念和工具。

*第2章，AWS Glue DataBrew 简介：* 在本章中，您将了解 AWS Glue DataBrew 在数据整理和数据准备任务中的强大功能。本章将指导您如何利用 AWS Glue DataBrew 来清洗、转换和丰富数据，确保数据的质量和可用性，以便进一步分析。

*第3章，AWS SDK for pandas 简介：* 在本章中，您将接触到 AWS Data Wrangler 在 AWS 平台上进行数据整理任务的多功能能力。本章将让您全面了解 AWS Data Wrangler，以及它如何帮助您高效地操作和准备数据以供分析。

*第4章，SageMaker Data Wrangler 简介：* 在本章中，您将了解 Amazon SageMaker Data Wrangler 在 Amazon SageMaker 生态系统中处理数据整理任务的能力。本章将为您提供知识和技能，以便利用 Amazon SageMaker Data Wrangler 的强大功能，为机器学习项目高效地预处理和准备数据。

*第5章，使用 Amazon S3：* 在本章中，您将深入探索 **Amazon Simple Storage Service（S3）** 的世界，了解其在存储、组织和访问数据方面的巨大潜力。本章将让您全面了解 Amazon S3，以及如何利用它进行有效的数据管理和操作。

*第6章，使用 AWS Glue：* 在本章中，您将深入了解 AWS Glue 的强大功能，这是 AWS 提供的一项完全托管的**提取、转换和加载（ETL）** 服务。本章将指导您如何利用 AWS Glue 来自动化和简化数据准备与转换工作流程。

*第7章，使用 Athena：* 在本章中，您将探索 Amazon Athena 的强大功能，这是一种无服务器查询服务，使您能够使用标准 SQL 查询直接分析 Amazon S3 中的数据。本章将指导您如何利用 Amazon Athena 从数据中获取宝贵见解，而无需复杂的数据处理基础设施。

*第8章，使用 QuickSight：* 在本章中，您将发现 Amazon QuickSight 的强大功能，这是 AWS 提供的一项快速、云驱动的**商业智能（BI）** 服务。本章将指导您如何利用 QuickSight 创建交互式仪表盘和可视化，从而从数据中获得宝贵见解。

*第9章，使用 AWS SDK for Pandas 构建端到端数据整理管道：* 在本章中，您将探索 AWS Data Wrangler 与 pandas（一个流行的 Python 数据操作与分析库）的强大组合。本章将指导您如何在 AWS Data Wrangler 中利用 pandas 操作，对数据集执行高级数据转换和分析。

*第10章，使用 SageMaker Data Wrangler 进行机器学习数据处理：* 在本章中，您将深入了解利用 AWS SageMaker Data Wrangler 的强大功能进行**机器学习（ML）** 数据优化的世界。本章将指导您如何利用 SageMaker Data Wrangler 为 ML 项目预处理和准备数据，从而最大化 ML 模型的性能和准确性。

*第11章，数据湖安全与监控：* 在本章中，您将了解 AWS 上的**身份与访问管理（IAM）**，以及 Data Wrangler 如何与 AWS 的安全功能紧密集成。我们将展示如何直接与 Amazon CloudWatch 日志交互、对日志执行查询，并将日志以数据帧的形式返回。
