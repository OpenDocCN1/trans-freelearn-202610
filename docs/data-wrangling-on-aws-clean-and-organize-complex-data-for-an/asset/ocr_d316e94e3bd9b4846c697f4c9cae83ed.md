+   * **Map charts** let us visualize a metric on a map using a geo field (zip code, state, county, etc.).
+   There are two types of map charts that can be created in QuickSight:

+   * **Point maps** show the metrics as points with different sizes – bigger-sized points for higher values and smaller-sized points for lower values
+   * **Filled maps** show the metrics in varying shades of colors – darker shades for higher values and lighter shades for lower values
