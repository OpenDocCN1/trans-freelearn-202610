In this example, we have seen the IF construct in its largest form: IF [...] THEN[...] ELSIF [...] ELSE[...] ENDIF;

However, shorter forms also exist, as follows:

+   - IF [...] THEN[...] ELSE[...] ENDIF;
+   - IF [...] THEN[...] ENDIF;
