```
forumdb=> truncate table temp_categories ;
TRUNCATE TABLE
```

The TRUNCATE command deletes all data in a table. As you can see here, the temp_categories table is now empty:

```
forumdb=> select * from temp_categories;
pk | title | description
----+-------+-------------
(0 rows)
```

Here is some key information about the TRUNCATE command:

+   - TRUNCATE deletes all the records in a table similar to the DELETE command.
+   - In the TRUNCATE command, it is not possible to use where conditions.
+   - The TRUNCATE command deletes records much faster than the DELETE command.
