```
DO [ ALSO | INSTEAD ] { NOTHING | command | ( command ; command ... ) }
```

As we can see, the rule definition is extremely simple. There are three options that we have when we decide to use a rule:

+   - The ALSO option
+   - The INSTEAD option
+   - The INSTEAD NOTHING option

# The ALSO option

Suppose that, from the tags table, we want to copy all records with the field tag value starting with the letter a in the a_tag table:

+   1. First of all, let’s create a new table called 0_tags:

```
forumdb=> create table 0_tags (
  pk integer not null primary key,
  tag text,
  parent integer);
CREATE TABLE
```

+   2. Then let’s create the new rule as follows:

```
forumdb=> create or replace rule r_tags1
  as on INSERT to tags
  where NEW.tag ilike '0%' DO ALSO
  insert into 0_tags(pk,tag,parent)values (NEW.pk,NEW.tag,NEW.parent);
CREATE RULE
```

In the rule we have just defined, we simply told PostgreSQL that every time a record is inserted with a tag value that starts with the letter “O,” as well as being inserted into the tags table, it must also be inserted into the 0_tags table.

+   3. Now we perform the following query:

```
forumdb=> insert into tags (tag) values ('OpenBSD');
INSERT 0 1
```
