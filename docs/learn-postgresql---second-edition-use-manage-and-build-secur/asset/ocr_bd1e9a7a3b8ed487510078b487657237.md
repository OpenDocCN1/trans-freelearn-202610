The same query can be written in this way:

```
forumdb=> SELECT x, SUM(x) OVER w
  FROM (select generate_series(1,5) as x) V
  WINDOW w AS (ORDER BY x ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW);
  x | sum
  ----+-----
  1 | 1
  2 | 3
  3 | 6
  4 | 10
  5 | 15
  (5 rows)
```
