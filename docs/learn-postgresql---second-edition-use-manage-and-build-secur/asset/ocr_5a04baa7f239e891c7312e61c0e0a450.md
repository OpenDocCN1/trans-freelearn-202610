Thanks to the SETTINGS option, it is possible to understand if a query plan has been produced with a custom configuration of certain parameters and, therefore, better understand if such parameters have implications on the query plan.

The COSTS option, which is turned on by default, shows the costs part of a node. As an example, turning it off removes the startup and final costs, as well as the average width and the number of rows:

```
forumdb=> EXPLAIN (COSTS off) SELECT * FROM categories;

                    QUERY PLAN
-----------------------------
Seq Scan on categories
(1 row)

forumdb=> EXPLAIN (COSTS on) SELECT * FROM categories;

                    QUERY PLAN
-------------------------------------------------------------
Seq Scan on categories  (cost=0.00..1.05 rows=5 width=68)

(1 row
```

The TIMING option, which is on by default, shows the effective execution time when EXPLAIN is invoked with ANALYZE. In other words, setting TIMING to off means that the output of EXPLAIN will not show the time of the node execution.
