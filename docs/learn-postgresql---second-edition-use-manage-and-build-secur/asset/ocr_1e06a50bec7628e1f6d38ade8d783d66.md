# Detaching an existing partition

If we want to detach an existing partition from the parent table, we have to execute the following:

```
forumdb=> ALTER TABLE part_tags DETACH PARTITION part_tags_date_05_2023 ;
ALTER TABLE
```

As we can see here, the partition called part_tags_date_05_2023 has been detached from the part_tags parent table:

```
forumdb=> \d+ part_tags;
```
