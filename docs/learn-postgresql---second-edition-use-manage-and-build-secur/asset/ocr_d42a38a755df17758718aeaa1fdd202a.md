# Updating data

Now let's try updating some data:

+   1. If you wanted to change the Unix value to the Linux value, you would need to run the following statement:

```
forumdb=> update temp_categories set title='Linux' where pk = 2;
UPDATE 1
```

This statement will modify the Unix value to the Linux value in the title field for all rows of the temp_categories table that have pk=2, as seen here:

```
forumdb=> select * from temp_categories where pk=2;
pk | title |      description
----+-------+-----------------------------
 2 | Linux | Unix and Linux discussions
(1 row)
```

+   2. If you wanted to change the title value of all the lines for which the description value is Languages, you would need to run the following statement:

```
forumdb=> update temp_categories set title = 'no title' where description = 'Languages';
UPDATE 2
```
