# The EXISTS option

The EXISTS option can be used in conjunction with entity create or drop commands to check whether the object already exists. An example of its use may be combined with the CREATE TABLE or CREATE DATABASE command. We can also use this option when we create or drop sequences, indices, roles, and schemas.
