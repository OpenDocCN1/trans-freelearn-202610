No matter how much activity your cluster has done, and what size the resulting pgBadger files are, once you have a report, you can point your web browser to the local files (or serve the result via a web server). You will see the report shown below. The report provides a glance at the cluster activity, including the number of statements, the time spent serving those statements, and graphs showing the statement traffic with regard to the period of time:

![](bbox=[0.12, 0.22, 0.86, 0.62])

Figure 14.1: Initial page of the pgBadger dashboard

If you are using the Docker image for this chapter, you can point your web browser to the URL http://localhost:8080/first_report.html and you will be able to see the report.

At the top of the web page, there is a menu bar that includes several menus that allow you to look at different graphs and dashboards.
