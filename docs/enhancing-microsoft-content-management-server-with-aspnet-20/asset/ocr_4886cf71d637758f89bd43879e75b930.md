![](bbox=[0.328, 0.148, 0.672, 0.475])

5. Click **OK**, and on the **Confirm Attribute Change** dialog, select the **Apply changes to the selected items only** radio button and click **OK**.

![](bbox=[0.328, 0.548, 0.672, 0.715])

6. Close Windows Explorer.

Visual Studio will now ignore the content of the 'CMS' Virtual Directory when building websites, but the files will still be available to our MCMS applications. Remember to set the **Hidden** flag to all folders in the `IIS_CMS` directory if you install other third-party components into this folder in the future.
