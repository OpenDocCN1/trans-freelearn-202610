| Property | Value |

We have set the SiteMapDataSource to link to the site map provider that we built earlier: MCMSSiteMapProviderSummary. Note that as we don’t want the currently viewed channel to be displayed as part of the list, we have set the ShowStartingNode property to false.

4. Next, drag a TreeView control from the Navigation section of the toolbox and drop it anywhere in the content area. Give it the following property values:

By setting the MaxDataBindDepth property to 1, we have ensured that the TreeView control will never show more than one level of items. In this way, the list will always be flat. Also, we set ShowExpandCollapse to false to prevent the expandable plus [+] and minus [-] signs from appearing.

```
</DataBindings>
</asp:TreeView>
```

We have bound the tree view node to the Title, Url, and Description properties of the site-map node. In addition, by setting the FormatString to include the <li> tag, we have included a bullet to be printed next to each item.
