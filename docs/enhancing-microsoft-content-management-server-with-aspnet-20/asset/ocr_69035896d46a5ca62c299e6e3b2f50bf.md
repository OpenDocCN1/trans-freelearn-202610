6. Modify the authentication section to use Forms Authentication:

```
<authentication mode="Forms">
  <forms loginUrl="Login.aspx" />
</authentication>
```

# Creating a Login Page Using the Login Control

Now let’s go ahead and implement a login page allowing users to sign in, which will utilize the new ASP.NET 2.0 login controls.

+   1. Right-click the **TropicalGreen** website, and click **Add New Item**.
+   2. Select the **Web Form** icon, enter **Login.aspx** in the **Name** textbox and click **Add**. Ensure that the **Select Master Page** checkbox is not selected.

> Adding a `Login` control to a master page will work. Such an implementation is only appropriate for mixed authoring and read-only hosting scenarios that utilize Forms Authentication.

+   3. Switch to **Design** view.
+   4. From the toolbox **Login** tab, drag a **Login** control onto the design surface.
