## 摘要

在本章中，我们介绍了在您的业务中安装和运行 SugarCRM 的实际注意事项。要点如下：

- 比较按需服务与托管式、本地部署或共享服务器的优势。我们还比较了自行维护服务器的前期成本与支付按需服务月费的成本。我们还解释了按需服务或共享服务器提供的定制支持非常有限。
- 如果您选择在自己的服务器上部署 SugarCRM，则需要为服务器选择操作系统和硬件配置，并就服务器安全性和互联网连接带宽做出决策。
- 在 SugarCRM 服务器上使用 Windows 或 Linux 作为服务器操作系统，并了解了 LAMP 堆栈。我们还考察了 LAMP 堆栈的一些常见变体，包括 WAMP 和 WIMP。
- 就安全性而言，您应考虑使用 UPS（电池备份）、上锁的服务器机房、防火墙、VPN 和监控系统，以保护服务器免受入侵、盗窃或损坏。
- 您的办公室应至少拥有 1 兆比特的下载和上传速度的互联网连接。每 25 名员工大约需要 2 兆比特的下载速度，每 10 名并发远程 CRM 用户大约需要 1 兆比特的上传速度。
- 附录 A 和 B 分别包含了在 Linux 和 Windows Server 环境中实际安装 SugarCRM 的操作细节。
