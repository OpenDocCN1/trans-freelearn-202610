# # Create from vCard

On the **Contacts** tab there is a shortcut called **Create from vCard**. This feature lets
you create a contact quickly if you already have a vCard file available from your
contact. Many people these days tend to attach a vCard with their e-mails, so
this can be a really quick and handy form of data entry for new contacts.
