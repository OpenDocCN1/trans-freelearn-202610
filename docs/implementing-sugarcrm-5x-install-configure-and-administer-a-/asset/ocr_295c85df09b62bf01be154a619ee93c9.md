A final important point concerning relationships between the lower level items is
that they often represent one-to-one relationships. The Task and E-mail example that
was just explained highlights this quite well, as only one Task can be linked to any
given E-mail.

The modules in SugarCRM Community Edition 5.5 are grouped in the

| Group header tab name | Modules |
|---|---|

| Support | Cases, Accounts, Contacts |
