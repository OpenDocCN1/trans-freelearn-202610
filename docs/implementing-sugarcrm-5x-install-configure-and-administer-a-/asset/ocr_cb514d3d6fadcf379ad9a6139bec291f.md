# # Main panel and subpanels

Examining the Accounts Detail screen reveals a block of general information about the account at the top and a series of blocks of information below containing related information, such as Activities, History, Contacts, Opportunities, Leads, Cases, and so on.

The block of general information at the top is referred to as the main panel and is shown in the following screenshot:

![](bbox=[0.101, 0.232, 0.916, 0.559])

The blocks of related information below the main panel are called subpanels. So we see a subpanel for Activities, one for History, another for Contacts, and so on as shown in the following figure:
