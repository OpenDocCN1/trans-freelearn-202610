The process of creating a custom index will vary slightly depending on your selected database platform. If you are unsure about the process, refer to the MySQL and Microsoft SQL server documentation, located at the following websites:

+   - http://dev.mysql.com/doc/refman/5.0/en/index.html
+   - http://msdn.microsoft.com/en-us/library/ms130214 (v=SQL.90).aspx

Our example assumes that we are working with the **Accounts** module and are using a custom field named **custom\_c** to store the match key value, for which we have created a custom index.
