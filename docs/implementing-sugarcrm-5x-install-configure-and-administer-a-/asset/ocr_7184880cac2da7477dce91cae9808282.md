# # Model-View-Controller (MVC)

SugarCRM's architecture utilizes the MVC design model which in turn makes it a
highly customizable application. The goal of this model is to separate the various
components of the system into functional areas, including the data (Model), user
interface aspects (View), and database operations (Controller). It was first introduced
in the 5.0 release of SugarCRM and has made the system significantly more
customizable.

Some of the potential changes you could make include the following:

+   • Custom list, detail, and edit screens with special behaviors

+   • Addition or removal of buttons on the various views

+   • Creation of dependent drop-downs

+   • Insertion of custom JavaScript

+   • Suppression of specific subpanels

+   • Conditional styling of data

programming capabilities. Let us take a look at a couple of quick examples so you
