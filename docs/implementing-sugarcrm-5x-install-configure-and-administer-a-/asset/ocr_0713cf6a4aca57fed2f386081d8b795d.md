The forecasting process begins with the definition of the forecasting periods — typically,
financial quarters, or months. This is done in the **Administrator** area of the system.

Once the forecasting periods have been defined, each sales person can set their
forecast commitments by using the **Forecasts** tab. Upon entry, this module shows the
forecast history. This displays a list of the time periods available to the user, and all
historical commitments that the user has made for those time periods. An example is
shown in the following image:
