Let us learn a little more about the e-mail capabilities of SugarCRM. Hover on the
**Collaboration** tab and click on the **Emails** link to access the e-mail client.

The e-mail client requires some configuration before it can be used to send or
receive e-mails. Email settings can be defined by hovering over the **Activities** tab,
selecting **Emails**, and then clicking on the **Settings** button. You will need to know
your e-mail server connection information in order to complete the process.
