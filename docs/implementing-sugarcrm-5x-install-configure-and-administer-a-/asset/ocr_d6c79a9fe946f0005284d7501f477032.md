It is best to visualize the layout of the form that will be produced as one similar to
the edit or detail view layouts. Fields can appear next to each other, horizontally or
vertically, but only within one of two columns. Most organizations prefer the vertical
approach, which is the technique we will apply. However, feel free to experiment.
