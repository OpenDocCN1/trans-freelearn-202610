Now back to the topic of selecting an appropriate distribution.

A quick search on the internet for information on which distribution is best will surely
yield a long list of results. There are many differing opinions on the qualities that make
one distribution better than others, so much so that it becomes less than helpful.

We are going to sidestep that discussion. Our example will utilize the CentOS
distribution, Version 5.4, for a couple of important reasons.

First, CentOS is based on the Red Hat Enterprise Linux distribution, arguably
the most popular distribution in use today. The importance of this point is not
that one should follow the crowd, but that a large user community represents
widespread support.
