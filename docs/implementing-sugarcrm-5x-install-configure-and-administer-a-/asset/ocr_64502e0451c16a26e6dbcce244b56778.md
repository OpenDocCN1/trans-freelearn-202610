# # E-mail templates

Email templates can be referenced when composing an e-mail (notice the Use Templates field on the Compose Email screen in the previous screenshot). When you create an e-mail template, you can insert variable placeholders for information, such as First Name, Last Name, Address, or Email. The saved template can then be applied and the variable placeholders are then filled with real data extracted from the linked account or contact record. This is especially helpful in scenarios where the e-mail is intended for one or more individuals, or sent through an e-mailing campaign for bulk marketing (discussed later in this book), as it personalizes each message so the recipient is left with the impression that the conversation is only with them and not just a part of a mass e-mail.
