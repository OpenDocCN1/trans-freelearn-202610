# # Formatting visuals

You might want to change the color of a specific visual or change the color of a specific
data point within a visual. In other cases, you might want to apply formatting settings
based on specific conditions. In this section, you will learn how to do the following:

+   - Edit the colors of a specific visual.
+   - Apply conditional formatting.
