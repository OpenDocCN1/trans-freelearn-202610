# ## 3. Next, we will create a manifest file, which defines which files need to be imported into QuickSight. We can have more than one file, but in this example and for simplicity, we will import a single file. Open a text editor and create a manifest.json file. Copy the following, replacing the highlighted values with the values from your environment:

```
{
"fileLocations": [
{
"URIs": [
"s3://data-lake-xxxxxxxxxx/samples/sample.csv"
]
}
]
}
```

# ## 4. Next, we will create an S3 data source in QuickSight. Log in to QuickSight as an Author user and click Datasets, and then click Create. Select S3 from the list of available sources. Next, name your data source, and upload the manifest file.
