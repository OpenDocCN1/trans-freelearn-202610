You might notice that the time is displayed in the epoch format, which is not what the end user would expect. For that reason, we will need to covert the date into a format that is understandable by the end user. To change the format, we will use the `formatDate` function. You can locate the function by expanding the **Functions** menu on the right-hand side menu and selecting `formatDate`. The function expects two arguments:

+   • The date column
+   • The format expressed as a string

In our example, we will use the `dd MMM yyyy` format, and therefore, the function will be `formatDate(${DateStart},'dd MMM yyyy')` for the start date and `formatDate(${DateEnd},'dd MMM yyyy')` for the end date.
