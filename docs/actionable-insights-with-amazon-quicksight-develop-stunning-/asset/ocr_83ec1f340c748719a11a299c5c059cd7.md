# # Automating the ingestion of an Amazon S3 data source

In this section, we will configure a simple application that will automatically refresh an **Amazon SPICE** data source when the underlying S3 data is updated. With this approach, instead of waiting for a scheduled refresh (which would introduce delays), we will trigger a refresh as soon as new data is available (which will minimize delays). For this example, we will use a sample `.csv` file, which will be configured as an S3 data source in QuickSight. Then, we will configure a Lambda function that will be triggered by S3 notifications. The Lambda function will call the `createIngestion` function of the QuickSight API, which will result in QuickSight importing the new dataset into SPICE. # # Creating an S3 dataset

Let’s begin by creating a sample dataset. We will need to create a `.csv` file and a manifest file:

+   1. First, open a text editor and create a `sample.csv` file. Copy the following as its content:
+   
+      "Name","Age"
+      "George","54"

+   2. Upload the file into the S3 data lake you created in _Chapter 1, Introducing the AWS Analytics Ecosystem_. Create a folder named `samples` under your data lake bucket, or simply use the `s3 cp` CLI command to upload your `.csv` file:
+   
+      `$aws s3 cp sample.csv s3://<data-lake-xxxxxxxx>/samples/`
