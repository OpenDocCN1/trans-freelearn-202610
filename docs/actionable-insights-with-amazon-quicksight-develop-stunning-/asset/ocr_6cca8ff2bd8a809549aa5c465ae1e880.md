# # 2 Introduction to Amazon QuickSight

In this chapter, we will introduce **Amazon QuickSight** and we will define its main
components. We will discuss fundamental architectural topics such as networking and
storage, and look closely at the different editions of Amazon QuickSight and understand
the different options available during account creation. Finally, we will walk through
a step-by-step guide to set up a QuickSight account, and configure the QuickSight
permissions to access data in a data lake.

To summarize, in this chapter, we will cover the following:

+   - Introducing Amazon QuickSight
+   - Introducing QuickSight editions and user authorization options
+   - Setting up Amazon QuickSight

# ## Technical requirements

The only thing you will need for this chapter is an AWS account.
