7. Next, we have .NET CLR version. Click on the dropdown menu and select .NET Version V2.0.50727. This .NET CLR version supports 2.0 and 3.5 framework websites.

8. Next, we have the Managed pipeline mode dropdown menu. We can select from Integrated or Classic mode. We will select the Integrated managed pipeline mode in this example.

9. You can also select the auto-start option while creating the application pool. Select Start application immediately so that once the application pool is created, it starts automatically. # How it works...

Application pools process one or more web applications. We created an application pool, for which we have to set the website property to update configurations. You may set the property of the framework to one that your web application supports.
