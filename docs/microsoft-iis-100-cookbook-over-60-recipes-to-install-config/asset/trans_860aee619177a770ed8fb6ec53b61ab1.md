## 要记录的回收事件

在回收应用程序池时可以生成事件日志条目。选择要记录的回收事件。

可配置的回收事件：

- 定期时间间隔
- 计划时间
- 虚拟内存使用
- 私有内存使用
- 请求数

运行时回收事件：

- 按需
- 配置更改
- 不健康的 ISAPI

19. 在“要记录的回收事件”窗口中，我们可以生成回收事件的日志。
