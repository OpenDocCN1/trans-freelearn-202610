## 简介

健康和诊断提供了一种基础设施，用于监控、管理和排查 Web 服务器、站点和应用程序的健康状况。

其优势在于详细的跟踪事件，可在完整的请求和响应过程中跟踪请求。为了启用这些跟踪事件的收集，IIS 服务器可以配置为基于经过的时间或错误响应代码，自动捕获特定请求的完整跟踪日志，格式为 XML。
