## 12 保护 IIS 10.0 上的网站

在本章中，我们将介绍以下操作：

- 了解 IIS 10.0 上可用的安全功能
- 配置 IIS 10.0 上的安全设置
- URL 授权和身份验证
- IP 地址和域限制
- 测试 IIS 10.0 上的安全性

### 简介

Web 服务器安全性（IIS 服务器）、网站安全性和应用程序安全性可用于配置 IIS 服务器，以保护自身和网站。

以下是 IIS 服务器中可用的安全选项：

- 计算机密钥
- 身份验证
- 授权规则
- IP 地址和域限制
- ISAPI 和 CGI 限制
- 服务器证书
- 请求筛选
- IIS 管理器权限和 IIS 管理器用户
- NTFS 权限

我们可以为需要安全托管的网站或 Web 应用程序在 IIS 服务器上安装和配置安全组件。

在本章中，我们将从 IIS 10.0 的一些安全信息开始。如果你愿意，可以尝试更多安全选项。这里我们将介绍几个重要的部分。

### 了解 IIS 10.0 上可用的安全功能
