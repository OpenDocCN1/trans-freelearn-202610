# Configuring the website IP

In this recipe, we are going to configure the website IP 172.16.15.61. The default website IP was 172.16.15.60; we will configure a different IP to access the website over this newly configured IP.

# Getting ready

To step through this recipe, you will need a running IIS 10 instance, one static IP address, and an administrator user account for editing properties and files.

# How to do it...

+   1. Open Server Manager on Windows Server 2016. Click on the Tools menu and open IIS Manager.
+   2. Expand the IIS server (WIN2016IIS). We get the listed application pools and sites.
+   3. Select the website v4mysite.com, click on the Binding option, and you will see the Site Bindings details of Host Name, Port, and IP Address, as shown in this figure:
