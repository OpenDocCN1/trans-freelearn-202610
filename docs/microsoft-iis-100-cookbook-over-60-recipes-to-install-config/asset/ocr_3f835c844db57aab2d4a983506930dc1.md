# How it works..

Throughout this recipe, we configured the port of the website mysite.com, which had the default port of 80. We had an overview of the default port of mysite.com and added the new port 8080, after which we accessed the website from the URL mysite.com through the newly added port 8080.

You can also configure a different port as per the availability of servers.
