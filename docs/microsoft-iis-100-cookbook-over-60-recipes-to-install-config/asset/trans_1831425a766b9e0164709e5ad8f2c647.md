## 简介

我们可以使用数字证书和诸如安全套接字层（SSL）之类的技术，基于公钥加密构建安全的基础设施。

要发布安全的网站或 Web 应用程序，我们需要两样东西：

- 1. HTTPS（安全）端口 443
- 2. SSL 证书

HTTPS 是一种安全通信通道，用于在客户端计算机和服务器之间交换信息。它使用 SSL。

要在 IIS 中启用 SSL，必须先创建一个证书，用于对网络上传输的信息进行加密和解密。IIS 自带证书请求工具，可用于向证书颁发机构发送证书请求。此工具简化了获取证书的过程。
