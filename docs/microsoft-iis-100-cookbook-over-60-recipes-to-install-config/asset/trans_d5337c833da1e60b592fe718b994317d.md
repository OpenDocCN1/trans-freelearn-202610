## How it works...

在本食谱中，我们对通配符主机进行了概述，也称为子域名或子域。我们有一个父域名 `learningpoint.co.in`，并创建了 `demo.learningpoint.co.in`。我们可以使用不同的名称为父域名创建无限个通配符主机。对于通配符主机，无需支付任何额外费用即可进行注册。如果您拥有父域名，则可以创建无限个通配符主机。

## Getting ready

要逐步完成本食谱，您需要一个正在运行的 IIS 10.0 实例。您应已创建通配符主机。您还应具有管理员权限。

## How to do it...

- 1. 登录 Windows Server 2016 并进入服务器管理器。
- 2. 单击工具菜单并打开 IIS 管理器。
- 3. 从连接面板展开 IIS 服务器 (WIN2016IIS)。我们列出了应用程序池和站点。
- 4. 展开站点文件夹，您将看到列出的站点--mysite.com、v2mysite.com、v4mysite.com--并且您将获得通配符主机 ssl.v2mysite.com 和 demo.v2mysite.com：

![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_183_0.png)

- 5. 选择 demo.v2mysite.com 以从操作面板获取 demo.v2mysite.com 通配符主机的属性。
- 6. 转到操作面板，您将看到编辑权限。这用于提供或拒绝访问通配符主机的内容目录。您可以从操作窗格管理此权限。您可以进入通配符主机的内容目录，右键单击目录以打开属性弹出窗口并选择安全选项卡。在这里，您可以编辑访问级别并拒绝权限。
- 7. 现在，我们有绑定选项；我们已经知道如何更改任何网站的绑定。以下操作可通过绑定选项执行：为任何网站或通配符主机添加、删除和编辑 IP、端口、协议、主机名和 SSL 证书绑定。
- 8. 基本设置... 与网站的基本设置相同，因为通配符主机也是主网站的子网站。在这里，您可以找到有关基本设置更清晰的信息：

![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_184_0.png)

- 9. 如前一屏幕截图所示，我们有通配符主机 demo.v2mysite.com 的站点名称、应用程序池和物理路径。我们可以设置任何目录作为物理路径。
- 10. 让我们现在来看一下高级设置：

![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_184_1.png)

- 11. 在 **高级设置** 中，就像网站设置一样，我们有应用程序池、网站 ID（您创建的网站数量，也称为站点索引的唯一顺序号）、通配符主机的名称、物理路径和物理路径凭据（如果您已设置）。我们将其保留为默认值。物理路径凭据的登录类型可以根据物理路径凭据的配置为明文、网络、批处理或交互式。我们没有使用任何凭据，因此我们使用默认设置。**预加载已启用** 用于使应用程序池始终运行。
- 12. 在 **高级设置** 的 **行为** 部分，我们有 **已启用协议**，默认选项类型为 **HTTP**，以及 **失败请求跟踪** 选项，可让我们跟踪网站或通配符主机的跟踪日志。在 **限制** 中，我们可以应用设置以限制同时访问通配符主机的用户数量。
- 13. 让我们转到通配符主机 **ssl.v2mysite.com**。我们已经为其配置了绑定：HTTPS 协议和 SSL 证书。
- 14. 进入 IIS 管理器并单击 **ssl.v2mysite.com**。转到 **操作** 面板并单击 **基本设置...** 您将获得 **基本设置** 窗口：

![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_185_0.png)

- 15. 让我们验证 **ssl.v2mysite.com** 的站点应用程序池和通配符主机（子域名）设置。应用程序池与站点名称相同，如前一幅图所示。

![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_186_0.png)

- 17. 您可以看到 ssl.v2mysite.com 应用程序池版本为 4.0。我们还可以选择 IIS 10.0 上 Windows Server 2016 中可用的任何其他类型的应用程序池。您可以通过单击应用程序池下拉列表来检查可用应用程序池的列表，您将获得在 IIS 10.0 中创建的应用程序池列表。
- 18. 让我们继续检查默认文档设置。单击我们创建的任何通配符主机并进入功能视图。找到默认文档，双击打开它，并检查文件名 default.aspx，我们将在通配符 ssl.v2mysite.com 中访问它。
