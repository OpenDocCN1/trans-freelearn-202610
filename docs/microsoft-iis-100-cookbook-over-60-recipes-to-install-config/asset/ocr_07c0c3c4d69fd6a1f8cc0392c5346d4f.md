6. Now you have the option to choose a log file Format; the default selected is W3C. Now we have to enable one of the protocols.

7. Click on the Select fields... option, and you will get the W3C Logging Fields window, as shown here:

![](bbox=[0.217, 0.205, 0.775, 0.702])

8. You have to mark the checkbox for Protocol Version. Protocol Version will generate the log file entry for HTTP/1.1 and HTTP/2. Server Request will generate a site-wise log file for the website and also log the protocol version to the log file as per the client's requested protocol version. You can see the details of this log at C:\inetpub\logs\LogFiles.
