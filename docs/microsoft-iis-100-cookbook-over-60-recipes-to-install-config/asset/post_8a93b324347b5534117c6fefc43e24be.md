### Configuring the website IP

In this recipe, we are going to configure the website IP 172.16.15.61. The default website IP was 172.16.15.60; we will configure a different IP to access the website over this newly configured IP.

### Getting ready

To step through this recipe, you will need a running IIS 10 instance, one static IP address, and an administrator user account for editing properties and files.

### How to do it...

- 1. Open Server Manager on Windows Server 2016. Click on the **Tools** menu and open **IIS Manager**.
- 2. Expand the IIS server (WIN2016IIS). We get the listed application pools and sites.
- 3. Select the website v4mysite.com, click on the **Bindings** option, and you will see the **Site Bindings** details of Host Name, Port, and IP Address, as shown in this figure:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_115_0.png)

- 4. **v4mysite.com** has the existing IP `172.16.15.60`; it might even be `*`.
- 5. Click on the **Edit** button, and you will get the **Edit Site Binding** property window:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_116_0.png)

- 6. You have to add the new IP `172.16.15.61`, leave the port as 80, and the Host name as it is.
- 7. Click on the **OK** button. Now we set the IP for the website binding property. Let's make the required changes in the configuration for the IP `172.16.15.61` so that it will work for the website **v4mysite.com**.
- 8. Click on Start, go to **Settings**, and click on **Network and Sharing Center**.
- 9. Now, you have to click on **Change adapter settings**:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_117_0.png)

- 10. You will get the network connections window. In this window, we get the Ethernet (server network port) property:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_117_1.png)

- 11. Right-click on **Ethernet**, and you will get the property context menu of **Ethernet** (Ethernet is the default name; you can rename it), as shown in this screenshot:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_118_0.png)

- 12. In the Ethernet properties, you will get IP version 4 (TCP/IPv4). We are using IP version 4, so we will configure only TCP/IPv4. If you have a TCP/IPv6 IP address, you can use the TCP/IPv6 protocol.
- 13. Click on the **Properties** button:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_119_0.png)

- 14. You have to add the new IP here.
- 15. Click on the **Add** button, and enter 172.16.15.61. It will also ask you to define your subnet. We will add the subnet mask 255.255.255.0 (the given subnet mask is the default). Click on the **OK** button. Click on OK a few more times until you close the Ethernet properties.
- 16. Now you've configured the new IP for your website and IIS Server that will recognize the additional IP address for the IIS server. You have to configure the IP address, which option is available under the Advanced TCP/IP Settings property of the IP Settings tab. In the IP Settings tab, we can add multiple IPs on the same IIS Server, which we can use to dedicate to each website.

### How it works...

Once we configure the dedicated IP for our website, we have to perform the configuration of TCP/IP protocol settings. We have to add the new IP. The IIS 10 server will check whether the IP is active and configured. Now you can access the website v4mysite.com on IP 172.16.15.61.

### Deploying websites

In this recipe, we will deploy three websites, namely, mysite.com, v2mysite.com, and v4mysite.com. In our case, we already have these sites ready for deployment, but in your case, you have to create your own, or you can use any available older version to upload under the appropriate site folder, which we've learned in our previous examples.

### Getting ready

To step through this recipe, you will need a running IIS 10 instance, and websites mysite.com, v2mysite.com, and v4mysite.com configured. You need three sets of website application files as per our demonstration or HTML pages with an administrator user account.

### How to do it...

- 1. Open Server Manager on Windows Server 2016. Click on the **Tools** menu and open **IIS Manager**.
- 2. Expand the IIS server (WIN2016IIS). We get the listed application pools and sites; inside the Sites folder, we have three websites created, namely, mysite.com, v2mysite.com and v4mysite.com.
- 3. Select mysite.com, go to the **Actions** panel, click on **Basic Settings**, and check the physical path of mysite.com. You will get the physical path of mysite.com.
- 4. The mysite.com physical path is `C:\inetpub\mysite`:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_121_0.png)

- 5. Follow the previous steps to copy `v2mysite.com` to the appropriate folder.
- 6. Open the IIS Manager, go to the **Connections** panel, right-click on **v2mysite.com** under the **Sites** menu in the left-hand panel, and click on **Explore**. It will open the physical path of `v2mysite.com`:

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_121_1.png)

  ![](img/1e026bc33e65e0f63d5e9b5081b6d8c8_123_0.png)

### How it works...

In steps 1 to 9, we opened the three different types of physical paths of each website, and we uploaded the website files. In step 10, we know from where to make settings for your home page or default page.
