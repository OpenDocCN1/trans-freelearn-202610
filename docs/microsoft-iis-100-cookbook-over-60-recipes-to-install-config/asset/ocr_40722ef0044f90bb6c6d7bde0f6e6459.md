+   9. We can now see that we have listed all available file names in IIS Server. Marked `default.htm`.
+   
+   10. Now we are going to create a file named `v5mysite.htm` in the **Default Document** settings. Write the command `Get-IISConfigSection -SectionPath "system.webServer/defaultDocument" | Get-IISConfigCollection -CollectionName "files" | New-IISConfigCollectionElement -ConfigAttribute @{"Value" = "v5mysite.htm"}` and press *Enter*, and you will get the filename `v5mysite.htm` added to the **Default Document**.
