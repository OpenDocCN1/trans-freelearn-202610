The IP is 172.16.15.60 in this case, but in your case, it may be different. Find out your FTP server's IP address to configure the FileZilla FTP client tool to get access. The IP can be obtained in various ways, but one of them is to open Command Prompt and run ipconfig. You will get all of your IPs listed; pick the IPv4 one.
