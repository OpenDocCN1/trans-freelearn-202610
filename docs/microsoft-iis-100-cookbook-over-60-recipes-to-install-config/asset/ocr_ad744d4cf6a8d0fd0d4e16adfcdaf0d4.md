We are installing to our local machine, so leave Select a server from the server pool with the current machine selected and click on Next. 7. Now we have to select the role from the Select server roles wizard. Check the box next to Web Server (IIS). Doing this may open up a new pop-up window advising that additional features are required; simply click on the Add Features button to install them as well. Click on Next on the Select server roles menu once this is complete.
