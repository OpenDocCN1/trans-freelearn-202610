# Creating the Placeholder Control

To create the RSS aggregation placeholder control, we will create a new placeholder in the TropicalGreenControlLib project.

+   1. Load the Tropical Green solution in Visual Studio .NET.
+   2. Right-click on the TropicalGreenControlLib project and select Add | Add Class.
+   3. Name the new class RssReaderPlaceholderControl.cs and click OK.
+   4. Import the following namespaces:

