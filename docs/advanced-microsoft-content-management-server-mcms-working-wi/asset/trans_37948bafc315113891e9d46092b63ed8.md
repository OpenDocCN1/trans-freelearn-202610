    string regExpForAllTags = "<[>^]*>";

在上面的示例中，我们验证了 HtmlPlaceholderControl，并且仅当其包含超过 50 个字符的文本时才保存其内容。但是，您是否注意到常规占位符控件的内容仍然被保存？我们只是阻止了 HtmlPHWithValidation 的内容被保存。页面的其余部分继续保存回存储库。
