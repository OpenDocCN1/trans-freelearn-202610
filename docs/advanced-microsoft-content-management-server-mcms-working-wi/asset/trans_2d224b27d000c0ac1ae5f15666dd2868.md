### 检索已保存的内容

要显示存储的内容，必须先将其检索出来。计划如下：

- 首先准备三个数组，用于存储附件的 URL、图标和显示文本。
- 接下来，从底层 `XmlPlaceholder` 中检索已保存的 XML。
- 获得 XML 后，我们从标签中提取附件信息，并将其存储到已准备好的数组中。
- 最后，将内容重新加载到所有已上传附件的表格中。
