

## 创建新的 MCMS Web 入口点

我们现在已在虚拟服务器上创建了 SharePoint 门户。现在需要配置 MCMS 以使用我们的虚拟服务器作为 MCMS Web 入口点。

1. 通过指向 开始 | 所有程序 | Microsoft Content Management Server | Server Configuration Application 启动服务器配置应用程序。
2. 单击 Web 选项卡以查看所有虚拟服务器并管理其 MCMS 配置。

![](img/442e26bf28f2df81fbf8dff3478f88e3_516_0.png)

3. 你可以看到，我们的新虚拟服务器 portal.tropicalgreen.net 未配置为 MCMS。单击 Configure 按钮以编辑列出的虚拟服务器。
4. 将 MCMS 列中我们虚拟服务器的下拉菜单设置为 Yes – Read Write。单击对话框和配置页面的 OK。

我们现在拥有一个 SharePoint 门户，并且已配置新的虚拟服务器作为 MCMS Web 入口点。然而 MCMS 目前不会接收任何请求，因为 SharePoint 会消耗发往我们虚拟服务器的所有 URL。

## 在 MCMS 站点中利用 SharePoint Portal 搜索

Connector 包含三个增强 MCMS 模板的控件。其中两个控件用于收集搜索查询信息并在提交到 SPS 后显示查询结果：

- **SearchInputControl**：SearchInputControl 显示一个输入表单，用户可以在其中输入要搜索的关键字。
- **SearchResultControl**：SearchResultControl 负责获取 SearchInputControl 中提交的关键字和高级属性，构建查询并调用 SPS Search 服务。控件然后获取来自 Search Service Web 服务的响应并显示搜索结果。

Connector 包含的第三个搜索控件是：

- **SearchMetaTagGenerator**：此控件为 MCMS 帖子属性和自定义属性生成 HTML META 标签信息。它与 XML 映射文件和命令行实用程序结合使用来配置 SharePoint 索引器。这允许用户为搜索功能实现基本分类法。

用于生成 META 标签的标准和自定义属性使用名为 SearchPropertyCollection.xml 的 XML 文件和名为 SearchPropertiesSetup.exe 的控制台应用程序进行管理，该应用程序使用 XML 文件定义的高级属性配置 SharePoint Portal Server 搜索。

SearchPropertyCollection.xml 文件可在以下目录中找到：
C:\Program Files\Microsoft Content Management Server\Server\IIS_CMS\WssIntegration.

SearchPropertiesSetup.exe 实用程序程序可在以下目录中找到：
C:\Program Files\MCMS Connector for SharePoint Technologies\WSS\Bin.

如果 SharePoint Portal Server 和 MCMS 位于不同的物理服务器上，则 SearchPropertyCollection.xml 文件需要在两台服务器上都存在。SearchInputControl 在 MCMS 服务器上使用此 XML 文件，而 SearchPropertiesSetup.exe 实用程序在 SharePoint Portal Server 上使用该文件。

为了使用 SPS 作为 MCMS 站点的搜索引擎，需要进行一些配置。这涉及在 SPS 中创建新的内容源、源组和源范围。幸运的是 Microsoft 包含另一个名为 SearchSetup.exe 的命令行实用程序程序，该程序为 MCMS 站点中的所有顶级频道在 SPS 中创建新的内容源和站点路径规则。

SearchSetup.exe 实用程序程序可在以下目录中找到：C:\Program Files\MCMS Connector for SharePoint Technologies\WSS\Bin.

有关 MCMS 和 SharePoint Portal Server 搜索集成的更多信息，请参阅第 5 章，Searching MCMS with SharePoint。

## 将 MCMS 内容集成到门户站点

通过利用 Connector 中包含的单个 Web 部件，你可以在 SharePoint 门户中显示帖子列表。Page Listing Web Part 以六种不同的列表格式显示指定频道中的帖子。以下三种格式在 Web 部件中硬编码：

- **Page Summary List View**：此视图显示所有帖子，带有简短标题（或显示名称）、描述、上次修改时间戳和摘要图像。这是 Web 部件的默认视图。每个项目都链接到帖子的发布 URL。

- **Basic List View**：Basic List View 以列表形式显示帖子，每个帖子都有重要性图标和简短标题（或显示名称）。

- **Detailed List View：** 与 Page Summary List View 非常相似，此视图不显示摘要图像，但会添加帖子所有者、上次修改帖子的用户以及帖子的状态（是否已发布）。

Web 部件为另外三个视图提供了条目，这些视图未随 Connector 提供。这些视图可以由站点开发人员添加并完全根据其需求定制。有关为 Page Listing Web Part 创建自定义视图的更多信息，请参阅第 6 章，*Publishing Content Between MCMS and SharePoint*。

## 在 MCMS 站点中发布 SharePoint 文档库文档

Connector for SharePoint Technologies 涵盖的最后一个集成点是在 MCMS 帖子中发布 SharePoint（WSS 或 SPS）文档库的文档。连接器随附一个新的占位符定义和一个新的占位符控件：**SharePointDocumentPlaceholder** 定义和 **SharePointDocumentPlaceholderControl**。开发人员可以将 **SharePointDocumentPlaceholder** 定义添加到模板定义中，并将 **SharePointDocumentPlaceholderControl** 添加到模板文件中以显示来自 SharePoint 文档库的文件。

占位符以文档名称列表的形式显示文档，并链接到实际文档。如果文件类型在 Microsoft Windows Server 中注册，Connector 将生成图标。否则 Connector 会为文件类型生成默认图标。你还可以通过在样式表中指定值来覆盖文件类型使用的图标。

列表的呈现完全可通过 XSLT 样式表自定义，这些样式表用于将 SharePoint 文档库中文档的属性和内容转换为 HTML。

有关 **SharePointDocumentPlaceholder** 和 **SharePointDocumentPlaceholderControl** 的更多信息，请参阅第 6 章，*Publishing Content Between MCMS and SharePoint*。

## 包含的附加实用程序

除了 Connector for SharePoint Technologies 提供的 SharePoint Web 部件、服务器控件和 MCMS 占位符以允许内容集成外，Microsoft 还包含额外的 SharePoint Web 部件和命令行实用程序来帮助你配置 SharePoint 并管理你的 MCMS 网站。

Connector 中包含以下两个管理 SharePoint Web 部件，以帮助 MCMS 站点作者、编辑和审核员维护其 MCMS 站点：

- **Pages in Production Web Part：** 此 Web 部件显示当前用户正在处理但尚未发布的帖子，这与 MCMS 中的“Production Manager”对话框相当。
- **Pages Waiting for Approval Web Part：** 此 Web 部件显示 MCMS 站点上等待批准的所有帖子，这与 MCMS 中的“Approval Assistant”对话框相当。
