# Summary

In this chapter, we learned how to use the PAPI to manage template galleries, templates, and resources. We provided several enhancements to CMS Explorer, including dialogs to create template galleries, templates, and resources. We also showed how templates can be submitted (or checked in), copied, and moved programmatically. Another feature that we explored was the replacement of existing resources, where the file contents of a resource can be replaced while preserving its GUID and URL. Finally, we looked at how objects can be deleted from the content repository using the PAPI.

As you can see the PAPI not only provides you with the basic tools to create websites managed by MCMS but also allows you to customize it to meet just about all kinds of unique business requirements.
