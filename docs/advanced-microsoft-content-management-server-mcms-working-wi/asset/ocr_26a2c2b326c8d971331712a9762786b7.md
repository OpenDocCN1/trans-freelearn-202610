# Connected Postings

Connected pages are two different copies of a posting object that share the same placeholder values. Because connected postings share placeholder definitions and values, any changes to the properties of one posting will be reflected in all its connected postings.

Let's create a Create Connected Posting dialog:

+   1. Add a web form named `CreateConnectedPosting.aspx` to the CMSExplorer project.
+   2. Drag and drop `Styles.css` onto the web form.
+   3. Toggle to HTML view and add the following table consisting of six rows between the `<form>` tags.
+   4. Switch back to Design view. Drag and drop the following controls from the Web Forms section of the Toolbox.

```

<table>
<tr>
    <td colspan="2">
        <h1>Create Connected Posting</h1>

<tr>
