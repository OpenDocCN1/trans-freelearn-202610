# What is the SharePoint Web Part Tool Pane?

The SharePoint Web Part Tool Pane is a task pane on a SharePoint Web Part Page used to add Web Parts from Web Part galleries, and to modify custom and common Web Part properties.

# Why are the Web Parts we installed in the Virtual Server Gallery?

When you install a Web Part, you are installing it to a specific virtual server. Even when you elect to install it in all sites or in the Global Assembly Cache, the additions are made to each virtual server to tell the SharePoint portal (or site(s)) within that virtual server that it can use the Web Part.
