## 技巧 10：如何让框架（Frames）和内嵌框架（IFrames）在模板文件中正常工作

框架（Frames）提供了一种便捷的方式，让网站的某些部分在用户浏览不同页面时保持静态。内嵌框架（IFrames）通常用作页面内的小窗口，以显示来自其他站点的内容。虽然框架为“粘性”导航问题提供了方便的解决方案，但它给任何网页设计带来的额外复杂性，往往成为许多开发者的痛点。

MCMS 网站也是如此。框架和内嵌框架在模板文件中无法完美工作。在“实时”（Live）和“编辑站点”（Edit Site）视图之间切换时，会出现 JavaScript 错误，具体以下情况：

- 模板文件中嵌入的框架或内嵌框架链接到另一个站点。
- 作者正在处理的 MCMS 页面位于另一个网站的框架或内嵌框架中。

好消息是，这两个问题都可以解决。

- 如何构建回收站
- 如何处理指向已删除资源的链接
- 如何生成资源依赖关系报告
- 如何直接从模板文件更新发布的属性
- 如何将不友好的 URL 重写为友好 URL
- 如何使用网站部署 API 导出资源库项目
- 如何配置 Web 作者控制台对话框的位置和大小
- 如何让框架和内嵌框架在模板文件中正常工作
