Another way of aggregating raster layers, bypassing the necessity to construct a loop, is with the `stackApply` function. Similar to the way in which `tapply` can be used to apply a function on different portions of a vector (as we discussed in *Chapter 3, Working with Tables*), the function `stackApply` has been defined to apply a function on different portions of layers in a multiband raster. Analogous to `tapply`, the main three parameters of `stackApply` are as follows:

+   - The input multiband raster (x)
+   - A vector of indices defining the layers grouping (indices)
+   - The function to be applied on each group (fun)

Unlike `tapply`, the indices vector must be composed of consecutive integers, starting with 1. An additional parameter of `stackApply` is `na.rm`, which controls whether NA values are removed from calculations.

For example, we can calculate the monthly NDVI means as follows:

```
> month_means = stackApply(r,
+ indices = dates$month,
+ fun = mean,
+ na.rm = TRUE)
```

As in the previous example, we will name the layers of the result `month_means`:

```
> names(month_means) = month.abb
```

> The character vector `month.abb` is a predefined one in R; it holds the three-letter abbreviated month names: "Jan", "Feb", "Mar", and so on.

We can visualize the result with `levelplot`:

```
> levelplot(month_means, par.settings = RdBuTheme, contour = TRUE)
```
