## Part 2

## Image Enhancement and Restoration Techniques

*Part 2* 侧重于使用经典和现代计算方法提高图像质量并重建退化的视觉数据。它首先介绍基于强度的变换和基于直方图的增强技术，包括对比度拉伸、均衡化、感知增强和色彩校正方法。

该部分随后探讨了基于导数的图像处理，其中梯度和二阶导数用于边缘检测、结构分析和多尺度表示。诸如拉普拉斯算子、Canny 边缘检测、尺度空间分析和基于金字塔的表示等技术展示了图像信息如何在不同的空间分辨率下进行分析。

本部分的一个主要重点是将图像恢复表述为逆问题。读者将学习经典方法，如维纳滤波、Tikhonov 正则化和贝叶斯恢复模型，以及用于去噪、去模糊和图像修复的现代基于深度学习的方法。从解析到数据驱动的恢复方法的转变贯穿始终。

到本部分结束时，读者将能够增强退化图像、使用导数分析结构内容，并使用经典优化和现代深度学习框架对恢复问题进行建模。

本部分包含以下章节：

- *Chapter 7, Image Enhancement*
- *Chapter 8, Image Enhancements Using Derivatives*
- *Chapter 9, Image Restoration: Inverse Problems in Imaging*
