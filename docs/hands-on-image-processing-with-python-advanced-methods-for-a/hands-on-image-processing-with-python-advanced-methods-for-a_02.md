## Part 1

## Foundations of Digital
Image Processing

第一部分构建了本书后续所有主题所需的数学、算法和计算基础。它从数字图像的基础知识开始，包括表示、采样、量化、图像形成，并逐步过渡到使用 Python 进行实际图像操作。读者将使用 NumPy、PIL、OpenCV 和 scikit-image 等核心编程工作流程来读取、转换和可视化图像。然后，本部分发展出对空间域和频域分析的坚实理论和应用理解。主题包括傅里叶变换、离散卷积、相关、滤波理论，以及图像的空间表示和频谱表示之间的关系。重点在于理解图像结构如何使用数学算子进行分析和修改。

最后，介绍了经典的图像增强和滤波技术，包括平滑、锐化和基本恢复概念。到本部分结束时，读者将对数字图像处理所需的数学原理和实用工具都有坚实的基础，并为更高级的计算机视觉和深度学习概念做好准备。

本部分包含以下章节：

- *Chapter 1, Getting Started with Digital Image Processing*
- *Chapter 2, Image Manipulation*
- *Chapter 3, More Image Manipulation*
- *Chapter 4, Sampling and Fourier Transform*
- *Chapter 5, Convolution and Spatial/Frequency Domain Filtering*
- *Chapter 6, Frequency Domain Filtering*
