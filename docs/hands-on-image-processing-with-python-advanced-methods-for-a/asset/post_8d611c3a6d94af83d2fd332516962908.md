
For each type, the implementation will use **Ideal**, **Butterworth**, and **Gaussian** filtering methods. Now, let’s understand each type of filter and demonstrate how useful they are in image processing.

## Low-pass filter (LPF)

This filter allows only the low frequencies from the frequency domain representation of the image (obtained with DFT) and blocks all high frequencies beyond a cut-off value. The image is reconstructed with inverse DFT (IDFT), and since the high-frequency components correspond to edges, details, noise, and so on, LPF tends to remove these. The following table summarizes common LPFs along with their mathematical formulations, characteristics, advantages, and limitations.

| Filter Type | Mathematical Expression | Characteristics | Pros | Cons |
|---|---|---|---|---|
| **Ideal LPF (ILPF)** | $H(u,v)=\begin{cases}1,&D(u,v)\leq D_0\\0,&D(u,v)>D_0\end{cases}$ | Sharp transition, removes all high frequencies above $D_0$ | Strong smoothing effect, simple to implement | Causes blurring artifacts due to sudden cutoff |
| **Butterworth LPF (BLPF)** | $H(u,v)=\frac{1}{1+(D(u,v)/D_0)^{2n}}$ | Smooth transition controlled by order $n$ | Less blurring compared to Ideal LPF, adjustable smoothness | Higher computational cost compared to Ideal LPF |
| **Gaussian LPF (GLPF)** | $H(u,v)=e^{-D^2(u,v)/(2D_0^2)}$ | Very smooth transition, no ringing artifacts | No ringing artifacts, best for natural image smoothing | Weaker attenuation of high frequencies compared to ILPF and BLPF |

Where we have $D(u,v)=\sqrt{(u-u_0)^2+(v-v_0)^2}$ is the Euclidean distance from the origin $(u_0,v_0)$ in the frequency domain.

- $D_0$ is the cut-off frequency
- $n$ is the order of the Butterworth filter.

First, let’s start by implementing a couple of the filters described in the preceding table.

### Ideal, Butterworth, and Gaussian LPFs

The following code implements the preceding LPFs in the **frequency domain**, and applies them one by one to a noisy input image, **removing random noise** added to the input image and achieving smoothing (**denoising**) effects by removing high-frequency components (**noise**):

```python
def ideal(sz, D0):
    h, w = sz
    u, v = get_grid(w, h)
    return dist(u,v) < D0


def gaussian(sz, D0):
    h, w = sz
    u, v = get_grid(w, h)
    return np.exp(-(dist(u,v)**2/(2*D0**2)))


def butterworth(sz, D0, n=2):
    h, w = sz
    u, v = get_grid(w, h)
    return 1 / (1 + (dist(u,v)/D0)**(2*n))

def apply_filter(f, func, arg_dict):
    F = fp.fftshift(fp.fft2(f))
    H = func(**arg_dict)
    G   =  H * F
    g   =  np.abs(fp.ifft2(G))
    g = g / g.max()
    return F, H, G, g
```

Let’s break it down step by step. Here is what the preceding code does:

- The `ideal()` function implements ILPF, with cut-off frequency D0: frequencies inside radius D0 are kept, and others are set to zero. This creates a hard cut-off, which can cause ringing artifacts (the **Gibbs phenomenon**).
- The `gaussian()` function implements GLPF. The frequency attenuation follows a smooth exponential decay. This avoids the ringing artifacts seen in the Ideal LPF.
- The `butterworth()` function implements BLPF. It has a more gradual transition than the Ideal LPF but sharper than Gaussian. The n parameter controls the filter order: higher n means a sharper transition.
- The `apply_filter()` function applies a filter function in the frequency domain to an image (with the convolution theorem, G(u, v) = F(u, v)H(u, v)). The function is flexible and supports different filter types using kwargs (arg_dict) and passes the required parameters to the corresponding filter functions dynamically. The next table describes the input arguments to the function:

| Parameter | Type | Description |
|---|---|---|
| f | numpy.ndarray | Input image (grayscale, stored as a 2D array). |
| func | function | A filtering function (e.g., ideal, gaussian, or butterworth). |
| arg_dict | dict | Keyword arguments (kwargs) passed to the filter function. |

- It first transforms the image using FFT, applies a filter mask, and then converts it back. The following table shows the return values from the apply_filter() function:

| Output | Description |
|---|---|
| F | Original frequency spectrum of the image (before filtering). |
| H | The applied filter in the frequency domain. |
| G | Filtered frequency spectrum (after applying H). |
| g | Final processed image after inverse FFT (low-pass filtered image). |

- The `dist()` function computes Euclidean distance from the center (h/2, w/2).
- The `get_grid(w, h)` function generates a frequency grid centered at (h/2, w/2), with the `np.meshgrid()` function. It is essential for frequency-based image filtering in Fourier space.

```python
def dist(u, v):
    return np.sqrt(u**2 + v**2)

def get_grid(w, h):
    return np.meshgrid(
        range(-int(np.floor(w/2)), int(np.ceil(w/2))), \
        range(-int(np.floor(h/2)), int(np.ceil(h/2))))
```

The following code block shows the application of LPF on the cameraman grayscale image, with different frequency cut-off values, F.

```python
im = np.array(Image.open('images/cameraman.jpg').convert('L'))
freq = fp.fft2(im)
(h, w) = freq.shape
half_w, half_h = int(w/2), int(h/2)
snrs_lp = []
ubs = list(range(1,30,3))

for u in ubs:
    freq = fp.fftshift(np.copy(freq))
    freq_low = np.copy(freq)
    freq_low[half_h-u:half_h+u+1,half_w-u:half_w+u+1] = 0
    freq -= freq_low # select only first 20x20 (low) frequencies
    im_rec = fp.ifft2(fp.ifftshift(freq)).real # reconstruction
    snrs_lp.append(psnr(im, im_rec)) # append SNR for cutoff u
    plt.subplot(2, 5, u//3+1), plt.imshow(im, cmap='gray')
    plt.axis('off'), plt.title('F = ' + str(u), size=15)
```
