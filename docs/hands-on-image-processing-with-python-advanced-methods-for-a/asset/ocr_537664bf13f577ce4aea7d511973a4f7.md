# Smoothing with the Gaussian blur filter

The Gaussian blur filter is also a linear filter but, unlike the simple mean filter, it takes the weighted average of the pixels inside the kernel window to smooth a pixel (the weight corresponding to a neighbor pixel decreases exponentially with the distance of the neighbor from the pixel). The Gaussian blur filter performs convolution with a Gaussian kernel:

g = f * h_σ

where h_σ is the Gaussian kernel with standard deviation σ

+   - Larger σ → wider kernel → stronger smoothing
+   - Noise is progressively removed
+   - Image details are increasingly blurred

A 5 × 5 Gaussian kernel is obtained by sampling the 2D Gaussian:

h(i,j) = 1/(2πσ²) exp( - (i² + j²)/(2σ²) ),      i,j ∈ −2,−1,0,1,2

For the commonly used case σ ≈ 1, the normalized 5 × 5 kernel is:

h = 1/273 [1 4 7 4 1; 4 16 26 16 4; 7 26 41 26 7; 4 16 26 16 4; 1 4 7 4 1]

Notes

+   - The kernel is symmetric and separable
+   - The normalization factor (273) ensures: Σ_{i,j} h(i,j) = 1
+   - Larger values near the center give higher weight to nearby pixels, producing smooth, natural blurring

The following code shows how the PIL.ImageFilter.GaussianBlur() can be used to smooth a noisier image with different radius parameter values for the kernel:

```
im = Image.open('images/mandrill_spnoise_0.2.jpg')
for radius in range(1, 4):
    im_smoothed = im.filter(ImageFilter.GaussianBlur(radius))
    # plot the smoothed image here, for the blur-radius of GaussianBlur
```
