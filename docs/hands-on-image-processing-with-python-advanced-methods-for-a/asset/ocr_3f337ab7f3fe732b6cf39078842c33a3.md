where αₜ = 1 − βₜ and βₜ are a small variance schedule controlling the amount of noise added at each step. A remarkable property of DDPMs is that an image at any timestep can be sampled directly from the original image:

q(xₜ|x₀) = 𝓝(xₜ; √ᾱₜ x₀, (1 − ᾱₜ)I)

where ᾱₜ = ∏ₛ=1ᵗ αₛ (which determines how much of the original image remains at timestep t). Equivalently,

xₜ = √ᾱₜ x₀ + √(1 − ᾱₜ) ε,      ε ∼ 𝓝(0, I)

This equation shows that every noisy image is simply a weighted combination of the original image and Gaussian noise. The following code simulates a forward diffusion process of a DDPM by progressively corrupting an image with Gaussian noise.

# Noise Schedule: The next code uses a linear variance schedule:

```
T = 1000
betas = np.linspace(1e-4, 0.02, T)
alphas = 1 - betas
alpha_bar = np.cumprod(alphas)
```

The sequence βₜ determines how rapidly information is destroyed. Early timesteps introduce only slight perturbations, whereas later timesteps progressively overwhelm the image with noise.

# Visualizing Forward Diffusion: The forward diffusion process is implemented using the following code (Images at selected timesteps are generated using the closed-form diffusion equation:

xₜ = √ᾱₜ x₀ + √(1 − ᾱₜ) ε, ε ∼ 𝓝(0, I),

implemented as:

```
noise = np.random.randn(*img.shape)
xt = (np.sqrt(alpha_bar[t]) * img + np.sqrt(1-alpha_bar[t]) * noise)
```

Here, img corresponds to the original image x₀, while noise represents a Gaussian noise sample ε. At t = 0, the image is nearly unchanged. As t increases, the contribution of the image decreases and the contribution of noise increases and visual structure gradually disappears until the image becomes indistinguishable from Gaussian noise. The resulting visualization illustrates the trajectory x₀ → x₅₀ → x₁₀₀ → ⋯ → x₉₉₉, demonstrating how diffusion transforms a natural image into pure noise.
