The next code snippet demonstrates the color enhancement, obtained using the function enhance_rgb() which extracts the RGB channels, computes the per-pixel maximum with np.maximum(), and applies the nonlinear enhancement (c/m)^f m, and assigns the enhanced values back to the image channels. The parameter f=4 controls the enhancement level. The demonstration loads an RGB Ishihara image using imread(), applies enhancement with enhance_rgb(), converts both original and enhanced images to grayscale using color.rgb2gray(), and visualizes them with plot_images(). The enhanced grayscale image reveals digits that are barely visible in the grayscale version of the original image.

```
def enhance_rgb(im, f=4):
    r, g, b = im[...,0], im[...,1], im[...,2]
    m = np.maximum(np.maximum(r, g), b)
    im[...,0], im[...,1], im[...,2] = (r/m)**f*m, (g/m)**f*m, \
                                    (b/m)**f*m
    return im

im = imread('images/Ishihara.png')
im_en = enhance_rgb(im)
plot_images([im, color.rgb2gray(im), im_en, color.rgb2gray(im_en)], \
            ['original', 'grayscale from original', 'enhanced image', \
             'grayscale from enhanced'])
```
