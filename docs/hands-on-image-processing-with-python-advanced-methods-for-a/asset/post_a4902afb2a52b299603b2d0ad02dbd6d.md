
# Federated learning (Privacy-Preserving Deep Learning) for distributed image classification

Traditional deep learning assumes that all training data is collected and stored on a central server. In many real-world applications such as hospitals, mobile devices, banks, and autonomous vehicles, sharing raw data may be impossible due to privacy, legal, or security constraints.

Federated Learning (FL) addresses this challenge by allowing multiple clients to collaboratively train a model without sharing their local data. Instead of transmitting images, each client trains a local model and sends only model updates (weights or gradients) to a central server.

Server ← Model Updates ← Clients

The server aggregates the updates and distributes the improved global model back to all clients.

Mathematical Formulation: Assume there are K clients. Client k owns local dataset D_k = (x_i, y_i) and minimizes its local objective:

F_k(w) = 1/|D_k| Σ_{(x,y)∈D_k} L(f(x; w), y)

where w = network parameters, L = classification loss, f = CNN model.

The global optimization problem becomes:

F(w) = Σ_{k=1}^K |D_k|/N F_k(w)

where N = Σ_{k=1}^K |D_k| is the total number of samples.

Federated Averaging (FedAvg): The most widely used federated learning algorithm is Federated Averaging (FedAvg). Each client trains locally and produces weights w_1, w_2, ..., w_K. The server computes w_global = 1/K Σ_{k=1}^K w_k and redistributes the averaged model. This simple averaging procedure allows all clients to benefit from collective learning while keeping their data private.

Imagine five hospitals (A, B, C, D, E) each owning medical images. Hospital A, B, and C never share images. Instead, each hospital trains a local CNN and sends only learned parameters to a central server. The server averages the parameters and creates a stronger global model that has indirectly learned from all hospitals without ever seeing their raw data.

## Local Client Training
Each client trains independently using its local dataset.

```
def local_train(model, loader):
    pred = model(x)
    loss = criterion(pred, y)
    loss.backward()
```

The client never exposes its images to any other client or the server. Only learned weights are shared.

## Federated Aggregation
After local training, the server aggregates the client models using FedAvg.

```
def fedavg(weights):
    avg = copy.deepcopy(weights[0])
    for key in avg.keys():
        for i in range(1, len(weights)):
            avg[key] += weights[i][key]
        avg[key] /= len(weights)
    return avg
```

Conceptually,

$w_{global} = \frac{1}{K} \sum_{k=1}^{K} w_k$

The resulting model becomes the new global model.

## Federated Training Loop
Training proceeds through multiple communication rounds.

```
for r in range(rounds):
    local_weights = []
    for client_loader in clients:
        w = local_train(local_model, client_loader)
    global_model.load_state_dict(fedavg(local_weights))
```

Each round consists of
- Sending the global model to clients
- Local client training
- Aggregating client models
- Updating the global model

This process repeats until convergence.

## What Is an Adversarial Example?
Let $x$ denote an input image and $f(x)$ the prediction of a neural network. An adversarial image is constructed as:

$$x_{adv}=x+\delta$$

where $\delta$ is a small perturbation chosen specifically to maximize the model’s classification error. Although $|\delta|$ is extremely small, the resulting prediction may change dramatically.

### Why Do Adversarial Attacks Work?
Neural networks operate in very high-dimensional spaces. Even tiny perturbations applied across thousands of pixels can accumulate into a large change in the network’s decision boundary. Intuitively, imagine standing near the edge of a cliff. A tiny push may be enough to move you across the boundary. Similarly, an image may lie close to a classification boundary, allowing a small perturbation to change the predicted class.

### White-Box vs Black-Box Attacks
- **White-Box Attack:** The attacker knows model architecture, parameters and gradients. FGSM is a classic white-box attack because it directly uses model gradients.
- **Black-Box Attack:** The attacker only observes outputs or probabilities and does not have access to internal model details. Such attacks are often more realistic in practice.

## Fast Gradient Sign Method (FGSM)
One of the simplest and most influential adversarial attacks is the **Fast Gradient Sign Method (FGSM)** proposed by Ian Goodfellow and colleagues. FGSM uses the gradient of the classification loss with respect to the input image. Given loss $J(\theta,x,y)$, the adversarial image is:

$$x_{adv}=x+\epsilon\,\operatorname{sign}(\nabla_xJ(\theta,x,y))$$

where $x$ = original image, $y$ = true label, $\theta$ = model parameters, $\epsilon$ = attack strength, and $\nabla_xJ$ = gradient of loss w.r.t. image pixels. The sign operation forces each pixel perturbation to move in the direction that maximally increases classification error.

The gradient tells us: “Which direction should each pixel move to increase the network’s loss most rapidly?” Instead of performing many optimization iterations, FGSM takes a single step in that direction. The perturbation therefore becomes $\delta=\epsilon\,\operatorname{sign}(\nabla_xJ)$ which is computationally inexpensive yet highly effective.
