# Image Preprocessing: The image is resized and converted to tensors.

```
img = transform(img)
img = img * 2 - 1
```

The pixel values are scaled from [0,1] to [−1,1] to match the preprocessing expected by the model.

# Computing the Input Gradient: The core step of FGSM is computing the gradient of the loss with respect to the input image.

```
image.requires_grad = True
output = model(image)
loss = nn.CrossEntropyLoss()(output, label)
loss.backward()
```

Mathematically, g = ∇ₓJ(θ,x,y) measures how sensitive the loss is to each image pixel.

# Signed Gradient Perturbation: FGSM keeps only the sign of the gradient.

```
perturbations = image.grad.sign()
```

This corresponds to sign(∇ₓJ), where each pixel receives a perturbation of either +1 or −1, depending on which direction increases the loss.

# Visualizing the Perturbation: The perturbation image reveals where the attack intends to modify pixels.

```
plt.imshow((perturbations.squeeze().numpy().transpose(1,2,0)+1)/2)
```

Although the perturbation appears structured, its magnitude is typically very small when scaled by ε.
