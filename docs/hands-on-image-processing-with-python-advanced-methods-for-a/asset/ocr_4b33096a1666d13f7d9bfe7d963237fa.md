Let us walk through the key functions and code blocks from the above demo, explaining their roles and subtleties:

+   - **make_gaussian_psf**: Builds a Gaussian point-spread function.
+   - **hogbom_clean**: Implements the iterative CLEAN algorithm, finds the peak in the residual image, subtracts a scaled version of the PSF, and accumulates “clean components” (delta functions at source locations).
+   - **Restoring beam**: Approximates the PSF main lobe with a small Gaussian for a smoother final image.
+   - Here is the workflow:
+     1. Load ground-truth image.
+     2. Blur with PSF and add noise → dirty image.
+     3. Apply CLEAN iterations → clean components + residual.
+     4. Restore final image by convolving clean components with restoring beam + residual.

**Mean squared error (MSE)** is computed before and after restoration.

In practice, CLEAN requires careful parameter choices: the loop gain (γ) is usually kept small (0.05–0.3) for stability, with more iterations needed at lower gains; stopping thresholds should be set a few times the noise standard deviation; and the PSF must be large enough to capture sidelobes, with a Gaussian restoring beam approximating its central lobe for visually pleasing results. Computationally, naive convolution makes CLEAN expensive, scaling with the PSF size and iteration count, but FFT-based methods, Clark CLEAN, and batch subtraction strategies provide major speedups.
