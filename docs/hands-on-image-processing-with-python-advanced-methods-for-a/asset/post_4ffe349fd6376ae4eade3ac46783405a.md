## Image enhancement with histogram processing

Histogram processing techniques provide a better method for altering the dynamic range of pixel values in an image so that its intensity histogram has a desired shape. As we have seen, image enhancement by the contrast stretching operation is limited in the sense that it can apply only linear scaling functions.

### Histogram sliding (translation)

Sliding adds or subtracts a constant to every pixel, shifting brightness uniformly while preserving contrast. Mathematically, it can be expressed as:

`I' = I + Δ`

The next code snippet implements the above histogram modification methods:

```
def histogram_stretching(image):
    min_val, max_val = np.min(image), np.max(image)
    stretched = 255 * (image - min_val) / (max_val - min_val)
    return stretched.astype(np.uint8)

def histogram_shrinking(image, target_range=(100, 200)):
    min_val, max_val = np.min(image), np.max(image)
    shrunk = (image - min_val) / (max_val - min_val) * \
            (target_range[1] - target_range[0]) + target_range[0]
    return shrunk.astype(np.uint8)

def histogram_sliding(image, shift_value=30):
    slid = np.clip(image + shift_value, 0, 255)
    return slid.astype(np.uint8)

image = cv2.imread('images/mandrill.jpg')
image = cv2.cvtColor(image, cv2.COLOR_BGR2LAB)
stretched_image = image.copy()
shrunk_image = image.copy()
slid_image = image.copy()
i = 0 # only stretch the intensity channel L, the very first channel
stretched_image[...,i] = histogram_stretching(stretched_image[...,i])
shrunk_image[...,i] = histogram_shrinking(shrunk_image[...,i])
slid_image[...,i] = histogram_sliding(slid_image[...,i])
image = cv2.cvtColor(image, cv2.COLOR_LAB2RGB)
stretched_image = cv2.cvtColor(stretched_image, cv2.COLOR_LAB2RGB)
shrunk_image = cv2.cvtColor(shrunk_image, cv2.COLOR_LAB2RGB)
slid_image = cv2.cvtColor(slid_image, cv2.COLOR_LAB2RGB)
plt.imshow(np.hstack((image, stretched_image, shrunk_image, slid_image)))
```

## Fuzzy logic–based image enhancement

We already explored widely used traditional image contrast enhancement methods such as Histogram Equalization (HE) and Contrast-Limited Adaptive Histogram Equalization (CLAHE). These approaches are often global, inflexible, or susceptible to noise. Fuzzy logic provides a powerful alternative, especially useful in uncertain or imprecise contexts such as natural scene images, where pixel intensity classifications (e.g., “dark”, “medium”, “bright”) are inherently vague.

Fuzzy logic mimics human reasoning by handling degrees of truth rather than binary decisions. It works by:

- Defining fuzzy sets that represent linguistic categories
- Using membership functions to associate input values with these fuzzy sets
- Creating fuzzy rules to infer outputs

In image contrast enhancement, a pixel’s intensity may not be strictly dark or bright; it may be partially both. Fuzzy logic accommodates this by assigning degrees of membership to different classes, allowing more nuanced processing.

### Contrast enhancement using fuzzy logic with the Mamdani system

In this section, let us explore contrast enhancement using fuzzy logic based on a Mamdani Fuzzy Inference System (FIS). Fuzzy logic simulates human reasoning by enabling partial truth values between 0 and 1. In image enhancement, pixel intensities can be interpreted through fuzzy sets like dark, medium, and bright. Fuzzy rules then map these input sets to output intensity corrections such as darker, enhanced, or brighter.

#### Mamdani FIS

The Mamdani system is a widely used fuzzy inference mechanism that uses min-max operations for rule evaluation and aggregation, and centroid defuzzification to obtain crisp output values. The Mamdani FIS consists of four steps:

- **Fuzzification:** Convert input (pixel intensity) into degrees of membership. Given a pixel intensity value, fuzzification maps it to degrees of membership based on membership functions (MFs, e.g., triangular or Gaussian):

  `μ_dark(I), μ_medium(I), μ_bright(I)`

- **Rule evaluation:** Use fuzzy rules and logical operations (usually min for AND) to evaluate the outcome. Apply min operation to infer the output fuzzy set from the antecedent:

  `μ_output(z) = max_i [ min( μ_input(I), μ_rule_i(z) ) ]`

  The firing strength of each rule is determined using the min operator, and the final aggregated fuzzy output is computed using the max operator. Let us define the following Fuzzy rules:

  - R₁: IF intensity is dark THEN output is darker
  - R₂: IF intensity is medium THEN output is enhanced
  - R₃: IF intensity is bright THEN output is brighter

- **Aggregation:** Combine the outputs of all rules (typically using max)
