# Class-conditional image generation with Conditional Generative Adversarial Networks (cGANs)

**Generative Adversarial Networks (GANs)**, proposed by Ian Goodfellow and colleagues in 2014, are among the most influential generative models in modern machine learning. A GAN consists of two competing neural networks: a **generator** *G*, which synthesizes images from random noise, and a **discriminator** *D*, which attempts to distinguish real images from generated ones. Through this adversarial game, the generator gradually learns to produce increasingly realistic samples.

The original GAN learns the data distribution *p(x)*, but it offers little control over what type of image is generated. For example, when trained on *Fashion-MNIST*, a standard GAN may generate shirts, shoes, dresses, or bags, but cannot be instructed to synthesize a specific category. **Conditional Generative Adversarial Networks (cGANs)** overcome this limitation by conditioning both the generator and discriminator on additional information such as class labels, attributes, or text descriptions.

**Training Dataset:** *Fashion-MNIST* is a benchmark image dataset containing **70,000 grayscale 28 × 28 images across 10 clothing categories** (e.g., T-shirt, trouser, dress, sneaker, and bag), and it is particularly well suited for demonstrating cGANs because the discrete class labels enable clear visualization of **class-conditional image generation**, allowing the model to synthesize specific clothing categories on demand while remaining computationally inexpensive to train.

**Conditional Adversarial Learning:** In a cGAN, the generator receives both a latent vector *z* and a condition *y*: *x̂ = G(z, y)*.

Similarly, the discriminator evaluates image-label pairs: *D(x, y)*.

The objective becomes:

min_G max_D 𝔼_{x ~ p_data}[log D(x, y)] + 𝔼_{z ~ p_z}[log(1 − D(G(z, y), y))]
