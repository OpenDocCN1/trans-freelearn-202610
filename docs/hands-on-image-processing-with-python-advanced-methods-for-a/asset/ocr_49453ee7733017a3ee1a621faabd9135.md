The depth map predicted from a single image using DPT provides a dense per-pixel *geometric cue* that can be directly leveraged to lift 2D scene information into 3D space, naturally paving the way for point cloud generation and full 3D reconstruction.

# Point cloud generation and 3D reconstruction

Once depth is estimated, the 2D image can be lifted into 3D space by back-projecting each pixel into camera space, where each pixel $(u, v)$ with depth $D(u, v)$ is converted into a 3D point using the inverse camera projection model. Concretely, assuming pinhole camera geometry, the depth value provides the missing scale needed to recover spatial coordinates: each pixel is first normalized with respect to the camera intrinsics (focal length and principal point), and then scaled by its depth to obtain $(X, Y, Z)$ in 3D space. This establishes a direct one-to-one mapping between image pixels and 3D points, forming the basis of a point cloud.

A point cloud is a set of 3D points:

$$P = \{(X_i, Y_i, Z_i)\}_{i=1}^{N}$$

Each point stores spatial coordinates and RGB color.
