$G(x,y) = \max_{(s,t)\in N(x,y)} I(s,t) - \min_{(s,t)\in N(x,y)} I(s,t)$

(which measures how much **intensity variation** exists **locally** around a pixel), followed by a thresholding, which identifies **flat regions (low gradient)** as markers. Next the connected components labeling (with the function `label()` from `scipy.ndimage` module) assigns unique IDs.

+   4. **Gradient computation:** The function `rank.gradient()` produces a **topographic surface**. Thin edges (small disk) ensure precise boundaries.

+   5. **Watershed transformation:** This is implemented using the function `watershed()` from `skimage.segmentation` module. Flooding starts from markers. Boundaries form at high-gradient ridges.

+   6. **Visualization:** The Original image, the Gradient map, the Marker map, and the Final segmentation overlay images are plotted side-by-side with matplotlib, as shown in the next code snippet:

```
from scipy import ndimage as ndi
from skimage.filters import rank
from skimage.util import img_as_ubyte

image = img_as_ubyte(rgb2gray(imread('images/earth.png')[..., :3]))
denoised = rank.median(image, disk(2))
markers = rank.gradient(denoised, disk(5)) < 20 # threshold
markers = ndi.label(markers)[0]
gradient = rank.gradient(denoised, disk(2))
labels = watershed(gradient, markers)
# display image, gradient, markers and labels overlayed side-by-side here
```
