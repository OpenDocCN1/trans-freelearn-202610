## SDXL-Turbo text-to-image generation

SDXL-Turbo generates images directly from textual prompts with extremely few diffusion steps.

```
pipe_t2i = AutoPipelineForText2Image.from_pretrained("stabilityai/sdxl-turbo")
prompt = """A futuristic cyberpunk city at sunset, cinematic lighting, ultra detailed"""
image = pipe_t2i(prompt, guidance_scale=0, num_inference_steps=2).images[0]
```

Unlike conventional diffusion models that often require 20–50 denoising iterations, SDXL-Turbo employs **Adversarial Diffusion Distillation (ADD)**, enabling generation in only 1–4 denoising steps while maintaining surprisingly high visual quality. The function `pipe_t2i()` can generate an image (given a text prompt) in a fraction of a second on modern GPUs, making SDXL-Turbo suitable for interactive applications such as rapid concept generation, real-time design exploration, and creative prototyping.

*Figure 13.25 – Text-to-image generation with SDXL-turbo*

The example generates a futuristic cyberpunk city using a textual description, demonstrating the remarkable efficiency of distilled diffusion models.

> **Note**
>
> The SDXL examples use two closely related pipelines: **Text-to-Image** (`pipe_t2i`) and **Image-to-Image** (`pipe_i2i`). The text-to-image pipeline generates an image from pure random noise and a text prompt: $x_0 = G(y)$ where $y$ denotes the prompt and $G$ represents the diffusion model. No input image is provided, so the model has complete freedom to synthesize a new scene.

## Typography generation

One of the major improvements of SDXL is its enhanced ability to render readable text within generated images. The following prompt requests a conference poster containing a title and topic list:

```
prompt = """
Professional conference poster.
Title:
COMPUTER VISION 2026
"""

image = pipe_t2i(prompt, guidance_scale=0, num_inference_steps=40).images[0]
```

The model synthesizes both the visual layout and the embedded text simultaneously. Although generated typography may still contain occasional spelling errors, SDXL represents a substantial improvement over earlier diffusion models that struggled to render coherent text.

## Prompt sensitivity

Diffusion models are highly sensitive to prompt wording. Consider the sequence:

```
prompts = ["A cat", "A realistic cat", "A realistic Persian cat",
"A realistic Persian cat sitting on a sofa"]
image = pipe_t2i(prompt, guidance_scale=0, num_inference_steps=2).images[0]
```

As semantic constraints are progressively added, the generated images become increasingly specific. This illustrates that prompts define a trajectory within the learned latent space, and richer descriptions typically produce outputs more closely aligned with user intent.

## Speed-quality tradeoff

The number of denoising steps directly affects generation quality:

```
prompt = "A futuristic robot"
steps = [1,2,4,8]
for s in steps:
    img = pipe_t2i(prompt, num_inference_steps=s, guidance_scale=0).images[0]
```

Fewer steps produce images rapidly but may exhibit artifacts or reduced detail. Increasing the number of steps generally improves visual fidelity at the cost of additional computation. SDXL-Turbo is specifically optimized to preserve quality even when very few diffusion iterations are used.

## Seed exploration

Diffusion models generate images from random latent noise. Different random seeds produce different samples while preserving the prompt semantics.

```
seeds = range(6)
for ax, seed in zip(axes, seeds):
    generator = torch.Generator(device="cuda").manual_seed(seed)
    img = pipe_t2i(prompt, num_inference_steps=2, guidance_scale=0,
                   generator=generator).images[0]
```

The resulting images exhibit variations in pose, composition, lighting, and object appearance, demonstrating the stochastic nature of diffusion-based generation.

## Image-to-image refinement with SDXL-Turbo

A useful workflow is to first generate a rough concept and then refine it through *image-to-image diffusion*.

**Stage 1 – Concept Creation:** The text-to-image (pipe_t2i) pipeline is used to generate the

```
concept_prompt = """fantasy dragon city, flying dragons, ancient towers,
 fantasy landscape, concept art, cinematic lighting"""
pipe_t2i = AutoPipelineForText2Image.from_pretrained("stabilityai/sdxl-turbo",
    torch_dtype=torch.float16,
    variant="fp16")
concept = pipe_t2i(prompt=concept_prompt, num_inference_steps=4).images[0]
```

**Stage 2 – Refinement:** The image-to-image pipeline (pipe_i2i) starts from an existing image and modifies it according to a text prompt:

$$x_{out} = G(x_{in}, y)$$

where $x_{in}$ is the input image and $y$ is the textual instruction (*text prompt*).

```
detail_prompt = """highly detailed fantasy dragon city, ultra detailed
architecture,
    cinematic lighting, fantasy masterpiece, sharp focus, intricate textures"""
pipe_i2i = AutoPipelineForImage2Image.from_pretrained("stabilityai/sdxl-turbo",
    torch_dtype=torch.float16,
    variant="fp16")
refined = pipe_i2i(prompt=detail_prompt, image=concept, strength=0.35).images[0]
```

The first stage establishes the overall design, while the second stage introduces architectural details, textures, lighting effects, and higher visual fidelity. This hierarchical workflow is widely used in concept art, game design, and architectural visualization.

## Face restoration

Image-to-image diffusion can also restore degraded photographs:

```
face_image = Image.open('child.jpg').convert('RGB')
result = pipe_i2i(prompt="""restore photograph, preserve face identity""",
    image=face_image, strength=0.35).images[0]
```

The prompt instructs the model to remove scratches, improve sharpness, and enhance image quality while preserving facial identity, pose, and scene content. Such restoration capabilities have become valuable for archival image enhancement and photograph recovery.

The edge map acts as a structural constraint during generation.

```
result = pipe_i2i(prompt=style_prompt, image=image, control_image=control_image).images[0]
```

Using prompts (style_prompt) such as: “Anime illustration” or “Convert to watercolor painting”, the model changes only the rendering style while preserving object layout, pose, perspective, and scene composition. This demonstrates the ability of ControlNet to disentangle image structure from visual appearance.

## Diffusion-based super-resolution

Diffusion models can also perform image upscaling:

```
pipe=StableDiffusionUpscalePipeline.from_pretrained(\
    "stabilityai/stable-diffusion-x4-upscaler")
upscaled = pipe(prompt="high quality photograph", image=low_res_image).images[0]
```

Rather than simply interpolating pixels, the diffusion model synthesizes plausible high-frequency details, producing sharper and more realistic high-resolution images.
