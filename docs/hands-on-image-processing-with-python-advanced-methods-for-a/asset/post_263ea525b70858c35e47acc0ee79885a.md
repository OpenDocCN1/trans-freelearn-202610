## Data preparation and training strategies

The following implementation pipeline addresses these challenges through patch-based training, label encoding, class-balancing strategies, and data augmentation to enable robust segmentation of large, heterogeneous satellite imagery:

- 1. **Patch-based training:** To overcome memory limitations, the large satellite images are divided into smaller patches (PATCH=512). The function `extract_patches()` extracts non-overlapping patches of size 512 × 512 from both the RGB image and the segmentation mask.

Mathematically,

$$P_{ij}=I[x_i:x_i+P, y_j:y_j+P],$$

where P = 512 denotes the patch size. This transforms the training dataset into thousands of smaller samples (Total patches: 5318). Patch-based training offers several advantages, such as reduced GPU memory consumption, increased dataset size, improved stochastic diversity, and easier mini-batch optimization.

- 2. **Color-Based Mask Encoding:** The dataset stores semantic masks as RGB color images rather than integer labels. Example:

| RGB Color | Semantic Class |
|---|---|
| (0,255,0) | Vegetation |
| (255,0,0) | Buildings |
| (0,0,255) | Water |

The next code snippet builds a mapping (`COLOR_MAP`). The encoding operation converts RGB masks into categorical label tensors:

$$M(x,y) \in \{0,1,\ldots,C-1\}$$

The conversion is performed using: `label[(mask==c).all(axis=-1)] = i`. This produces integer-valued segmentation masks suitable for neural network training.

- 3. **Class-imbalance compensation:** Class imbalance is addressed using median-frequency balancing.

Let $f_c = \frac{N_c}{\sum_k N_k}$ denote the frequency of class $C$, where $N_c$ is the number of pixels belonging to class $C$.

The class weight is defined as:

$$w_c = \frac{\operatorname{median}(f)}{f_c + \epsilon}$$

implemented as: class_weights = median / (freq + 1e-6). Rare classes, therefore, receive larger weights. A rare class receives a higher weight, while dominant classes receive much smaller weights. This significantly improves segmentation quality for thin or infrequent structures.

- 4. **Data augmentation:** Remote sensing datasets are typically limited in size. Data augmentation artificially increases training diversity. The pipeline uses Albumentations (HorizontalFlip, VerticalFlip, RandomRotate90, RandomBrightnessContrast), these augmentations improve invariance to orientation, illumination, seasonal variations and sensor noise. Mathematically, augmentation samples transformations T ~ P(T) and generates Ĩ = T(I) thus, approximating a larger training distribution.

The segmentation model is instantiated with `smp.MAnet()`. The architecture combines: ResNet34 encoder, U-Net decoder, and Attention aggregation modules. Let's consider them in detail.

The encoder extracts hierarchical feature maps: F₁, F₂, ..., Fₗ, where deeper layers contain increasingly semantic representations. The pretrained ResNet34 encoder was originally trained on the ImageNet dataset, enabling transfer learning from natural-image representations.

The decoder progressively upsamples the latent features:

```
F_{l-1} = U(F_l),
```

where U denotes upsampling.

Skip connections fuse encoder and decoder representations:

```
ĤF_i = [F_i^{enc}, F_i^{dec}]
```

preserving fine spatial details.

Mixed-attention modules adaptively weigh important spatial regions and channels. Attention coefficients are learned as:

```
A = σ(WF + b),
```

where F denotes feature maps, W are learnable parameters and σ is the sigmoid function.

The refined feature representation becomes:

```
F' = A ⊙ F
```

where ⊙ denotes elementwise multiplication. This allows the network to focus on semantically important regions such as roads, water boundaries, and buildings.

The Dice coefficient measures overlap between prediction and ground truth.

For prediction (P) and ground truth (G), Dice(P, G) = 2|P∩G| / |P|+|G|.

The Dice loss is therefore L_Dice = 1 − Dice(P, G). Dice loss is especially effective for imbalanced segmentation problems because it directly optimizes region overlap.

The training objective combines weighted cross-entropy and Dice loss. Mathematically,

$$\mathcal{L} = \lambda \mathcal{L}_{CE} + (1-\lambda)\mathcal{L}_{Dice},$$

with $\lambda = 0.5$. This hybrid formulation combines:

- Pixel-wise classification accuracy
- Region-level overlap optimization

The network is optimized using **AdamW**, which decouples weight decay from adaptive gradient estimation. Gradient clipping is additionally employed with the function `clip_grad_norm_()`. This prevents exploding gradients by enforcing $\|\nabla\theta\|_2 \leq 1$, thus stabilizing optimization.

The scheduler reduces the learning rate when optimization stagnates with the function `torch.optim.lr_scheduler.ReduceLROnPlateau`. If validation loss plateaus, the learning rate becomes:

$$\eta_{t+1} = 0.5\eta_t$$

Adaptive scheduling improves convergence near local minima.

Here, the training loss decreases steadily. This indicates successful convergence. The decrease in Dice-based loss implies increasing overlap between predicted and ground-truth regions.

The trained model is saved using the function `torch.save()`. This stores model weights, optimizer state, and training epoch, allowing training to resume later without loss of optimizer statistics.

Large satellite images cannot be processed directly due to GPU memory limitations. The solution is tiled inference. The image is padded. Each patch is segmented independently:

$$\hat{S}_{ij} = f_{\theta}(P_{ij})$$

The predicted patches are then stitched together. Finally, padding is removed. This reconstructs the segmentation map for the entire satellite image. Now, refer to the next code snippet:
