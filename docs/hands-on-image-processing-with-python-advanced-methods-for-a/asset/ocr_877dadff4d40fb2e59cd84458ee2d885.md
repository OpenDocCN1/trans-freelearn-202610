where $f_x, f_y$ = focal lengths and $c_x, c_y$ = optical center. These equations invert the camera projection model.

+   - **Generating the point cloud:** This function `depth_to_pointcloud()` iterates through image pixels, converts depth into 3D coordinates, stores RGB colors and constructs an Open3D point cloud.
+   - **Multi-view fusion:** Multiple views improve geometric coverage. The code processes a list of images given by `image_paths`. Each image produces a point cloud (pcd) with the function `depth_to_pointcloud()`, which needs an image and the corresponding depth map. The clouds are merged: `combined += pcd`
+   - **Voxel downsampling:** Performed with the method `voxel_down_sample()`, voxelization reduces redundancy and noise. Instead of millions of points, neighboring points are aggregated into voxel cells.
+   - **Normal estimation:** The method `estimate_normals()` computes the surface normals, approximate local geometry, and are essential for mesh reconstruction, rendering, lighting, and surface analysis.
+   - **Interactive 3D visualization:** As shown in the next code snippet, Open3D visualization is replaced with Plotly (so that it’s easy to run from a Colab notebook), using the following line of code: `o3d.visualization.draw_geometries = draw_geometries` (refer to GitHub). Plotly enables browser-based rendering, zooming, rotation, and interactive exploration.

The complete reconstruction pipeline becomes:

$I \rightarrow D \rightarrow P \rightarrow S,$

where $I$ = RGB image, $D$ = depth map, $P$ = point cloud, and $S$ = reconstructed scene. This bridges 2D vision and 3D geometry. Now, refer to the following code:

import open3d as o3d

def depth_to_pointcloud(color, depth):
    h, w = depth.shape
    fx, fy, cx, cy = w / 2, h / 2, 500, 500  # Camera intrinsics (approximate)
    points, colors = [], []
    for y in range(h):
        for x in range(w):
            z = depth[y, x]
            if z <= 0:
                continue
            X, Y = (x - cx) * z / fx, (y - cy) * z / fy
            points.append([X, Y, z])
            colors.append(color[y, x] / 255.0)
    pcd = o3d.geometry.PointCloud()
    pcd.points = o3d.utility.Vector3dVector(np.array(points))
    pcd.colors = o3d.utility.Vector3dVector(np.array(colors))
    return pcd
