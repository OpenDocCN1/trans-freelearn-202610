The multiclass Dice score is computed for each class. The final score is:

$$\mathrm{Dice}_{\mathrm{mean}} = \frac{1}{C}\sum_{c=1}^{C} \mathrm{Dice}_c$$

A Dice score close to 1 indicates excellent segmentation overlap.

Predicted label masks are converted back to RGB colors, using the function `decode_mask()`. This produces interpretable land-cover maps where each semantic category is displayed using a distinct color.

Typical visualizations include the original satellite image, ground-truth mask, and predicted segmentation map side-by-side. Such qualitative analysis is crucial because segmentation quality often depends on boundary precision and regional consistency rather than numerical metrics alone.
