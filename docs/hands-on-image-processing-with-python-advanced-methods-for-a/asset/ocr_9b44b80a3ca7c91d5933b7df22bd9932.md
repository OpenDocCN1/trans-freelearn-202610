These models eliminate the need for large, labeled datasets, enable rapid benchmarking and provide strong generalization via transfer learning.

# Fully convolutional networks

Fully convolutional networks (FCNs) represent the foundational architecture for semantic segmentation by eliminating fully connected layers and replacing them with convolutional operations. Let the encoder network extract hierarchical features:

$$F = \phi(I) \in \mathbb{R}^{h \times w \times C}$$

Instead of flattening $F$, FCNs apply a $1 \times 1$ convolution:

$$Z = W * F \in \mathbb{R}^{K \times h \times w}$$

This produces class-wise score maps, which are then upsampled:

$$\hat{Y} = \text{Upsample}(Z)$$

The final prediction at pixel $p$ is:

$$\hat{y}_p = \operatorname{argmax}_k \operatorname{softmax}(Z)_k(p)$$

**Skip connections:** To recover spatial detail, FCNs combine features from different depths:

$$F_{\text{fused}} = F_{\text{deep}} + \sum_{l} \alpha_l F_l$$

where $F_l$ are intermediate feature maps. Here, deep layers → semantic understanding, shallow layers → spatial precision, whereas fusion → accurate dense predictions.

**Limitations:** Blurry boundaries due to repeated downsampling and limited multi-scale context modeling.
