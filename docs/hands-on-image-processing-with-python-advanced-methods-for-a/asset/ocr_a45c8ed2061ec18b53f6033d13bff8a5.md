Figure 9.11 – Denoising with InstructIR

Finally, we can use gradio to build a UI for guided restoration:

```
import gradio as gr

def restore_image(image, prompt):
    image, restored_image = ins.restore_img(image, prompt, False)
    return (255*restored_image / restored_image.max()).astype('uint8')

iface = gr.Interface(fn=restore_image, inputs=['image', 'text'],
    outputs='image')
iface.launch()
```

This allows users to upload an image and type instructions like “remove the blur and make it look sharp”.

Here are the key insights:

+   - InstructIR unifies image priors and language priors, allowing flexible, user-controlled restoration.
+   - Unlike blind restoration, it uses semantic cues from instructions.
+   - Beyond denoising or deraining, it enables restoration + retouching + editing in a single framework.
