# Binary Cross-Entropy Loss: Because the task contains only two classes, the network is trained using binary cross-entropy:

ℒ = −y log(ŷ) − (1 − y) log(1 − ŷ),

where y ∈ {0,1} is the ground-truth label.

The optimization objective is:

θ* = argmin_θ Σ_{i=1}^N ℒ_i

which is solved using the Adam optimizer:

```
transfer_learning_model.compile(optimizer=Adam(learning_rate=1e-4), # compile
loss='binary_crossentropy', metrics=['accuracy'])
```
