Latent Space Interpolation: A key property of StyleGAN is that the latent space is semantically smooth. Given two latent codes (z₁, z₂), interpolation is defined as:

```
z(α) = (1 − α)z₁ + αz₂,      α ∈ [0,1]
```

This produces gradual semantic transitions such as identity morphing, pose transitions and expression blending.

The next code snippet generates two seed-based latent vectors and linearly interpolates between them across multiple steps, feeding each interpolated vector into StyleGAN to visualize a smooth transition between synthetic face images produced by the generator.

```
z1 = torch.from_numpy(np.random.RandomState(100).randn(1,G.z_dim)).to(device)
z2 = torch.from_numpy(np.random.RandomState(500).randn(1,G.z_dim)).to(device)
for alpha in np.linspace(0,1,9):
    z = (1-alpha)*z1 + alpha*z2
    img = G(z, torch.zeros([1,G.c_dim], device=device))
```

Unlike pixel-space interpolation, latent interpolation preserves realism because the generator maps the linear latent manifold to a nonlinear image manifold.

### Local Latent Perturbation and Manifold Structure

Local exploration of the latent space is performed by perturbing a center latent vector:

$$z' = z + \Delta z$$

where only selected dimensions are modified:

```python
delta[0] = (i-grid//2)*0.5
delta[1] = (j-grid//2)*0.5
z = center + delta
```

Early latent dimensions often control **global attributes** (pose, gender, lighting). Small perturbations reveal that StyleGAN3 encodes a **locally smooth manifold**, supporting controllable synthesis.

### Style Mixing in StyleGAN3

StyleGAN introduces a **style-based generator architecture**, where different layers control different levels of abstraction. The synthesis process is:

$$w=f(z),\quad x=G_s(w)$$

Style mixing replaces subsets of latent styles:

$$w_l^{(mix)}=\begin{cases}w_l^{(A)}, & l<k\\ w_l^{(B)}, & l\ge k\end{cases}$$

The equation defines StyleGAN style mixing where early layers ($l<k$) use style from latent $A$ and later layers ($l\ge k$) use style from latent $B$, producing a hybrid image combining coarse structure from $A$ and fine details from $B$.

This is implemented with the following code, which performs StyleGAN style mixing by generating latent vectors from row and column seeds, combining early-layer styles from one vector with later-layer styles from another, and synthesizing a grid of synthetic face images to visualize controlled semantic feature transfer.

```python
W_row, W_col = [], []
for s in [10,20,30]:
    z = torch.from_numpy(np.random.RandomState(s).randn(1,G.z_dim)).to(device)
    W_row.append(G.mapping(z, None))
for s in [100,200,300]:
    z = torch.from_numpy(np.random.RandomState(s).randn(1,G.z_dim)).to(device)
    W_col.append(G.mapping(z, None))

for r in range(3):
    for c in range(3):
        w = W_row[r].clone()
        w[:,8:] = W_col[c][:,8:]
        img = G.synthesis(w)
```

The function $G.mapping()$ transforms a random latent vector $z$ from the input latent space $Z$ into an intermediate latent representation $w$ in the disentangled latent space $W$, where semantic attributes such as pose, facial structure, and texture become more independently controllable. Here the early layers → coarse structure (pose, face shape), whereas later layers → fine texture (skin, hair, lighting). This enables **semantic disentanglement without supervision.**

## StyleGANEX: High-fidelity inversion and identity editing

While StyleGAN3 focuses on unconditional synthesis, StyleGANEX extends StyleGAN into a real-image editing and inversion framework, combining *GAN inversion*, encoder-based latent prediction, feature-level optimization, and face alignment pipelines. It is particularly designed for **real-world face editing, reconstruction, and morphing.**

The StyleGANEX setup involves cloning the official repository, which provides the pretrained models, inversion framework, and latent editing tools required for high-fidelity face reconstruction, manipulation, and morphing.


**GAN Inversion Problem:** Given a real image $x$, GAN inversion aims to find a latent code $w$ such that:

$$w^* = \underset{w}{\operatorname{argmin}}\; \mathcal{L}(G(w), x),$$

where $\mathcal{L}$ is a reconstruction loss (pixel + perceptual) and $G$ is the pretrained generator. StyleGANEX improves this by optimizing latent code $w$, intermediate features $f$ and stochastic noise maps $n$, where $\phi(\cdot)$ is a perceptual feature extractor (typically VGG).

**Decoding Inverted Face Representations:** The function decode() uses the pSp decoder (built upon the StyleGAN generator) to reconstruct a face image from its latent code, intermediate features, and noise maps, and converts the output into a displayable RGB image.

```python
def decode(model, w, f, noise):
    with torch.no_grad():
        img, _ = model.decoder([w], input_is_latent=True,
            first_layer_feature=f, noise=noise)
    img = (img.clamp(-1,1) + 1) * 127.5
    img = img.permute(0,2,3,1)[0].cpu().numpy().astype(np.uint8)
    return Image.fromarray(img)
```

**Face Morphing via Latent Interpolation:** First, both faces are aligned and inverted into the W⁺ latent space, producing latent representations w₁ and w₂. The morphing sequence is then created by linearly interpolating between these latent codes:

$$w(\alpha) = (1 − \alpha)w_1 + \alpha w_2,    \alpha \in [0,1]$$

Each interpolated latent vector is decoded by the pSp/StyleGAN generator to produce an intermediate face image, and the resulting frames are assembled into an animated GIF. The relevant code is:

```python
w1, f1, n1, _, _ = invert(img1, psp, lm, inv_steps)
w2, f2, n2, _, _ = invert(img2, psp, lm, inv_steps)
frames = []
for a in np.linspace(0, 1, steps):
    w = (1-a)*w1 + a*w2
    frames.append(np.array(decode(psp, w, f1, n1)))
imageio.mimsave("morph.gif", frames, fps=15)
```

Here, invert() maps each face into the StyleGAN (W⁺) latent space, w = (1 − a)w1 + a * w2 performs latent interpolation, decode() reconstructs the corresponding face image, and mimsave() combines all generated frames into a smooth morphing animation. This produces temporally smooth face transformations, forming a continuous trajectory in latent space rather than pixel space. The resulting sequence illustrates the semantic continuity of the StyleGAN latent manifold, where facial identity changes gradually (from the left face to the right face) while preserving photorealism.

**StyleGAN3** learns a *pure generative manifold*: $z \to x$, whereas **StyleGANEX** learns an *invertible semantic mapping*: $x \leftrightarrow w \leftrightarrow x'$. Together, they represent two complementary paradigms in modern generative vision: synthesis-first (StyleGAN3) and reconstruction-and-editing-first (StyleGANEX).

Building on these two complementary paradigms of generation and editing, the next method introduces how pretrained generative priors can further be leveraged for image restoration tasks.

## GFPGAN: Blind face restoration using Generative Facial Priors

**Generative Facial Prior GAN (GFPGAN)** is a face restoration framework that combines a restoration network with a pretrained StyleGAN prior to recover realistic and identity-preserving facial details from degraded images. Unlike conventional enhancement methods that operate purely at the pixel level, GFPGAN leverages a learned facial manifold to reconstruct plausible facial structures.

Given a degraded image $y$, $y = D(x) + n$, where $x$ is the unknown high-quality face image, $D(\cdot)$ denotes an unknown degradation process, and $n$ represents noise, the goal is to estimate the restored image $\hat{x} = R(y)$. GFPGAN constrains the reconstruction using a pretrained StyleGAN generator, $x_G = G(w)$, where $w$ is a latent representation in the StyleGAN latent space. The model combines reconstruction, perceptual, adversarial, and identity-preservation losses to generate visually realistic faces while maintaining facial identity.
