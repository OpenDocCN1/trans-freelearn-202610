# Mask classification transformers: Mask2Former

Mask2Former formulates segmentation as a set prediction problem, predicts mask–class pairs:

$\{(M_i,c_i)\}_{i=1}^{N}$

where $M_i$ is a predicted soft/binary mask and $c_i$ is its class label. Instead of independent pixel classification as in CNN-based segmentation,

$\hat{y}(x,y)=\underset{k}{\operatorname{argmax}}\,P_k(x,y)$,

the final label at pixel $(x,y)$ is obtained from the highest-confidence mask prediction:

$\hat{y}(x,y)=c_{i^*},\quad i^*=\underset{i}{\operatorname{argmax}}\,M_i(x,y)$

This unifies semantic, instance, and panoptic segmentation within a single transformer-based framework using global attention-based token interactions instead of only local CNN receptive fields. Training uses Hungarian matching with a composite set-prediction loss:

$\mathcal{L}=\lambda_{cls}\mathcal{L}_{cls}+\lambda_{mask}\mathcal{L}_{mask}+\lambda_{dice}\mathcal{L}_{dice},$

where $\mathcal{L}_{cls}$ is classification loss, $\mathcal{L}_{mask}$ is pixel-wise mask loss (e.g., BCE), and $\mathcal{L}_{dice}$ is Dice overlap loss. This formulation improves global consistency, reduces duplicate predictions, and yields sharper segmentation boundaries.
