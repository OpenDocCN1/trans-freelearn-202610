# Controlling the field of view with Knew

The Knew matrix can be modified to control the Field of View (FOV) of the undistorted image:

+   - Scaling Knew down results in a wider FOV but introduces black borders (padding)
+   - Scaling Knew up narrows the FOV but provides a tighter crop of the central region

This is useful when adjusting for different display targets (e.g., full-frame versus cropped output).
