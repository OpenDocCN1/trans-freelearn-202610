The DFT assumes that an image repeats periodically in both horizontal and vertical directions. As a result, sharp intensity changes at image boundaries create discontinuities that introduce unwanted high-frequency artifacts, often appearing as strong vertical and horizontal lines in the shifted frequency spectrum. This smooth transition minimizes boundary discontinuities and suppresses spectral artifacts before computing the DFT.

There are many windowing functions available in the `skimage.filters` module’s `window()` function, which accepts the windowing function name and the associated parameters, if any. ## Ringing artifact

**Ringing artifacts** are visual distortions commonly seen in digital image processing, particularly when dealing with sharp transitions or edges in an image. These artifacts manifest as oscillations or ripples near the edges of objects and are a direct consequence of the Fourier transform used in image analysis. Understanding how these artifacts arise and how to mitigate them is crucial when processing images for scientific or practical applications.

To illustrate the concept, consider a simple binary image that consists of a white circle at its center on a black background. This kind of binary image has sharp transitions between black and white regions—exactly the kind of edge where ringing artifacts tend to appear.

### Generating a binary image with a circle

Let’s first generate a 2D binary image f₁ of size 256 × 256 with a circle of radius r = 20 pixels in the center, using the following code snippet. The circle centered at (x₀, y₀) is defined by the equation (x − x₀)² + (y − y₀)² = r², where r is the radius. In this case, the circle is centered at (128, 128), which is in the middle of the image grid:

```python
N, r = 256, 20
f1 = np.zeros((N, N))
x, y = np.meshgrid(np.arange(N), np.arange(N))
f1[(x - N/2)**2 + (y - N/2)**2 <= r**2] = 1
```

This image will serve as the input to our DFT. The ringing artifact becomes apparent when we compute the DFT of this sharply defined shape.

### Applying the DFT

The next step is to compute the DFT of this image (using the next line of code) and visualize its frequency spectrum. The DFT provides insight into how different frequency components contribute to the image. In regions with sharp transitions (such as the edge of our binary circle), high-frequency components are dominant, which leads to ringing artifacts:

```python
F1 = np.fft.fft2(f1)
```

### Visualizing the DFT

Now, if you visualize the original image (f1) along with the magnitude of the DFT spectrum (np.fft.fftshift(F1)), you should obtain a figure like the next one (use cmap='nipy_spectral'). The binary image contains sharp transitions from black to white at the boundary of the circle. The corresponding frequency spectrum reveals high-frequency content due to the sharp edges of the circle. This high-frequency information leads to oscillations or ringing near the edges when the image is transformed back to the spatial domain, as shown in the following figure, which is the output you get by running the previous code snippet. These ringing artifacts are caused by the sharp cutoff of the circle.

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_225_0.png)

*Figure 4.44 – Ringing artifact with DFT*

These ringing artifacts occur because of the **Gibbs phenomenon**—a result of truncating high-frequency components in the Fourier domain. When an image contains sharp transitions, the Fourier series struggles to represent those edges accurately, causing overshooting and oscillations.

## Smoothing the image to avoid ringing artifacts

One way to reduce the ringing artifacts is by smoothing the sharp edges in the image. This can be achieved by applying a Gaussian filter to the image, which blurs the sharp transitions, leading to a reduction in high-frequency content.

### Applying a Gaussian filter

A Gaussian filter is a low-pass filter that smooths the image by reducing high-frequency components. The `gaussian()` function from the `skimage.filters` module is used here with a standard deviation to smooth the binary circle image, as shown in the following code snippet:

```python
f2 = gaussian(f1, 10)
F2 = np.fft.fft2(f2)
```

### Observations after applying the Gaussian filter

Now, visualize the new image (f2) with the blurred center, along with the magnitude of its DFT spectrum (with `plot_spectrum(np.fft.fftshift(F2))`). As can be seen from the next figure, the image now has blurred edges due to the Gaussian filter. The sharp transitions between black and white pixels are softened.

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_225_1.png)

*Figure 4.45 – Removing the ringing artifact with a Gaussian low-pass filter*

The Fourier spectrum of the smoothed image, F2, shows fewer high-frequency components. As a result, the ringing artifacts present in F1 are no longer visible in F2, as shown in the next figure, which visualizes the spectrum of the new image. Ringing does not occur since the circle cutoff is gentle.

### Mathematical explanation of ringing

The Gibbs phenomenon occurs when there is a sharp discontinuity in a signal (in our case, the edges of the circle). The Fourier series representation of such a signal converges to the correct function value everywhere except near the discontinuity, where it overshoots and oscillates, leading to ringing artifacts.

When we apply a Gaussian filter, the smoothing reduces the sharpness of the edge, decreasing the amount of high-frequency content in the Fourier transform, which helps mitigate the ringing.

## Linearity and distributivity

**Linearity** means the DFT of a combined image is the same as the sum of the DFTs of the individual images, while **distributivity** means you can apply the DFT to parts of the image separately and then combine the results, yielding the same final outcome. Let’s first understand and demonstrate the linearity property (i.e., the fact that the DFT of a sum of two signals is equal to the sum of the individual DFTs of the signals), as shown in the following figure – a property useful for removing additive noise from an image.

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_226_0.png)

*Figure 4.46 – Linearity of DFT*

The following code snippet demonstrates the linearity property:

```python
f1 = imread('images/cat1.png', True)
f2 = imread('images/cat2.png', True)
F1, F2 = np.fft.fft2(f1), np.fft.fft2(f2)
F = F1 + F2
f_hat = np.fft.ifft2(F)
# plot images (f1, f2), spectrums (F1, F2, F), reconstructed image f_hat
```
