# HPF with scipy.fftpack

A simple high-pass filter (HPF) can be implemented using `scipy.fftpack.fft2()` by computing the 2D FFT of the image, suppressing low-frequency components near the center of the shifted spectrum with `fftshift()`, and then reconstructing the image using `ifft2()` and `ifftshift()`. Since high-frequency components mainly represent edges and fine details, removing low frequencies suppresses smooth intensity variations and emphasizes edge-like structures in the output image.
