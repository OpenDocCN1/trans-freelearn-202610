Beyond GAN-based frameworks—including cGANs, CVAEs, CycleGAN, StyleGAN, and GFPGAN—a complementary and equally seminal paradigm in modern generative AI is *diffusion models*, which have emerged as a foundational approach for high-fidelity image synthesis through iterative denoising.

## Denoising Diffusion Probabilistic Models (DDPMs)

Diffusion models have emerged as one of the most successful generative modeling paradigms, powering modern image synthesis systems such as Stable Diffusion, Imagen, and DALL-E. Unlike GANs, which learn to generate images through adversarial training, **Denoising Diffusion Probabilistic Models (DDPMs)** learn to gradually reverse a stochastic noise process. The central idea is remarkably simple: an image is progressively corrupted by adding Gaussian noise until it becomes pure noise, and a neural network is trained to invert this process and reconstruct the original image.

DDPMs consist of two complementary processes:

- **Forward Diffusion** (noise addition)
- **Reverse Diffusion** (noise removal)

Together, these processes define a Markov chain that transforms images into noise and then reconstructs images from noise.

## Forward diffusion process

The forward process gradually destroys image information by adding Gaussian noise over $T$ timesteps. Starting from a clean image $x_0$,

$$q(x_t \mid x_{t-1}) = \mathcal{N}\left(x_t; \sqrt{\alpha_t}x_{t-1}, (1-\alpha_t)I\right)$$

where $\alpha_t = 1 - \beta_t$ and $\beta_t$ are a small variance schedule controlling the amount of noise added at each step. A remarkable property of DDPMs is that an image at any timestep can be sampled directly from the original image:

$$q(x_t|x_0) = \mathcal{N}\left(x_t; \sqrt{\bar{\alpha}_t} x_0, (1-\bar{\alpha}_t)I\right)$$

where $\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$ (which determines how much of the original image remains at timestep $t$). Equivalently,

$$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1-\bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

This equation shows that every noisy image is simply a weighted combination of the original image and Gaussian noise. The following code simulates a forward diffusion process of a DDPM by progressively corrupting an image with Gaussian noise.

### Noise Schedule

The next code uses a linear variance schedule:

```
T = 1000
betas = np.linspace(1e-4, 0.02, T)
alphas = 1 - betas
alpha_bar = np.cumprod(alphas)
```

The sequence $\beta_t$ determines how rapidly information is destroyed. Early timesteps introduce only slight perturbations, whereas later timesteps progressively overwhelm the image with noise.

### Visualizing Forward Diffusion

The forward diffusion process is implemented using the following code. Images at selected timesteps are generated using the closed-form diffusion equation:

$$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1-\bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

implemented as:

```
noise = np.random.randn(*img.shape)
xt = (np.sqrt(alpha_bar[t]) * img + np.sqrt(1-alpha_bar[t]) * noise)
```

Here, `img` corresponds to the original image $x_0$, while `noise` represents a Gaussian noise sample $\varepsilon$. At $t = 0$, the image is nearly unchanged. As $t$ increases, the contribution of the image decreases and the contribution of noise increases and visual structure gradually disappears until the image becomes indistinguishable from Gaussian noise. The resulting visualization illustrates the trajectory $x_0 \rightarrow x_{50} \rightarrow x_{100} \rightarrow \cdots \rightarrow x_{999}$, demonstrating how diffusion transforms a natural image into pure noise.

*DDPMs* provide a fundamentally different approach to image generation than GANs. Instead of learning a direct mapping from latent vectors to images, they learn a sequence of denoising operations that gradually transform random noise into realistic samples. Their training objective is stable, their latent representations are highly expressive, and they consistently achieve state-of-the-art image quality.

The forward diffusion process progressively corrupts an image according to:

$$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon,$$

while the reverse diffusion process learns to estimate and remove the noise component $\epsilon_\theta(x_t,t)$, thereby reconstructing images from pure noise. This simple yet powerful idea forms the foundation of modern diffusion-based generative AI systems.

## Latent Diffusion Models

The original **Denoising Diffusion Probabilistic Models (DDPMs)** perform the diffusion process directly on image pixels. Although highly effective, pixel-space diffusion is computationally expensive because high-resolution images contain millions of values. **Latent Diffusion Models (LDMs)** address this limitation by performing diffusion in a compressed latent representation learned by a **Variational Autoencoder (VAE)** rather than in pixel space. This idea forms the foundation of modern diffusion systems such as Stable Diffusion.

Given an image $x$, the encoder $E$ maps it to a latent representation $z = E(x)$, where $z$ is significantly smaller than the original image. Diffusion is then applied to $z$ instead of $x$.

After denoising, a decoder $D$ reconstructs the image: $\hat{x} = D(z)$. For example, a $512 \times 512 \times 3$ image contains 786,432 pixel values, whereas the Stable Diffusion VAE compresses it to a latent tensor of size $(4, 64, 64)$ containing only 16,384 values—approximately 48 times smaller. This dramatically reduces memory usage and computational cost.

### Variational autoencoder for latent compression

The Stable Diffusion VAE is loaded using:

```
vae = AutoencoderKL.from_pretrained("stabilityai/sd-vae-ft-mse").to(device)
```

An image is encoded into the latent space and reconstructed.

```
latent = vae.encode(x).latent_dist.sample()
recon = vae.decode(latent).sample
```

The encoder compresses the image into a low-dimensional latent representation, while the decoder reconstructs the image from this representation. The reconstruction closely resembles the original image, as shown in the next figure, demonstrating that the latent space preserves most visually important information despite its much lower dimensionality.

> **Note**
>
> Mathematically, the encoder predicts a Gaussian latent distribution $q_\phi(z|x) = \mathcal{N}(\mu(x), \sigma^2(x))$, from which a latent sample is drawn using the **reparameterization trick**:
>
> $z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$

### Latent space interpolation

Latent interpolation is useful in practice, since it enables smooth transitions between different semantic concepts, allowing controlled generation and revealing the *continuity* and *structure* of the learned latent space before introducing the code.
