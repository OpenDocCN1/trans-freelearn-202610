
## Variance thresholding

Let $\mathcal{L}(x,y)$ be the Laplacian-transformed image. Then the **variance of the Laplacian** is computed as:

$$Var_{\mathcal{L}} = \frac{1}{N}\sum_{i=1}^{N}(\mathcal{L}_i-\mu)^2$$

Where:
- $N$ is the number of pixels
- $\mathcal{L}_i$ are Laplacian pixel values
- $\mu$ is the mean of $\mathcal{L}$

Set a threshold $T$ such that:

**Blurry** $\Longleftrightarrow Var_{\mathcal{L}} < T$

The threshold $T$ depends on image size, content, and application. A commonly used heuristic is between 50 and 150.

```python
def variance_of_laplacian(image):
    lap = cv2.Laplacian(image, cv2.CV_64F)
    return lap.var()


def apply_box_blur(image, ksize=15):
    return cv2.blur(image, (ksize, ksize))


def apply_gaussian_blur(image, ksize=15, sigma=5):
    return cv2.GaussianBlur(image, (ksize, ksize), sigma)


def detect_blur(image, threshold=100.0):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    var_lap = variance_of_laplacian(gray)
    is_blurry = var_lap < threshold
    return is_blurry, var_lap

# Load and resize image
img_path = 'images/parrot.jpg'
original = cv2.imread(img_path)
original = cv2.resize(original, (400, 400))
# Apply filters
blur_box = apply_box_blur(original, ksize=15)
blur_gaussian = apply_gaussian_blur(original, ksize=15, sigma=5)
# Create image dictionary
images = {
"Original": original,
"Box Blur": blur_box,
"Gaussian Blur": blur_gaussian
}
# Display results
plt.figure(figsize=(8, 3))
for i, (title, img) in enumerate(images.items()):
    is_blur, score = detect_blur(img)
    label = f"{title}\nLaplacian Var: {score:.2f} → {'Blurry' if is_blur else 'Sharp'}"

    plt.subplot(1, 3, i+1)
    plt.imshow(cv2.cvtColor(img, cv2.COLOR_BGR2RGB)), plt.title(label)
```

## Effects of noise on gradient computation

Derivative filters computed using finite differences are quite sensitive to noise. As we saw in the last chapter, the pixels in an image that have very different intensity values from their neighbors are generally the noise pixels. In general, the more the noise, the larger the change in intensity, and the stronger is the response obtained with the filters. The next code block adds some Gaussian noise to the image to see the effects on the gradient. Let us again consider a single row (row 0, precisely) of the image, and let us plot the intensity as a function of the x location:

As we can see, adding random noise to the input image has a high impact on the (partial) derivatives and the gradient magnitude; the peaks corresponding to the edges become almost indistinguishable from the noise, and the pattern gets destroyed.

Smoothing the image before applying the derivative filter should be helpful, as it removes the high-frequency components likely to be noise and forces the (noisy) pixels (that are different from their neighbors) to look more like their neighbors. This gives rise to the LoG filter (if we use the second-order derivative filter) that we shall explore later in this chapter.

## Classical enhancement using derivatives

This section covers traditional enhancement techniques such as unsharp masking and entropy-based contrast enhancement. Practical Python implementations using PIL, OpenCV, and scipy.optimize illustrate how derivatives can enhance image contrast and detail.

## Unsharp masking

Unsharp masking is a technique to sharpen images, where a blurred version of an image is subtracted from the image itself. The typical blending formula used for unsharp masking is as follows:

sharpened = original + (original − blurred) × amount

Here, amount is a parameter. The next few sections demonstrate how to implement this filter with the functions from the ndimage module of scipy in Python.

### With PIL.ImageFilter

Python Imaging Library (PIL), through its ImageFilter module, offers a convenient UnsharpMask filter, as demonstrated with the following code snippet:

```
# Load image
image = Image.open("images/me.jpg").convert("RGB")
# Apply Unsharp Mask from PIL
sharpened_pil = image.filter(\    ImageFilter.UnsharpMask(radius=2, percent=150, threshold=3))
# Display image and sharpened_pil here
```

The function ImageFilter.UnsharpMask() accepts the following parameters:
- radius: Standard deviation (sigma) of the Gaussian blur kernel. A higher value means more blurring. The radius controls how much detail is considered low-frequency (i.e., to be removed).
- percent: Amount of sharpening applied, scaled in percentage (e.g., 150 means 150%). The percent amplifies the extracted detail layer.
- threshold: Minimum brightness change that will be sharpened. Helps reduce sharpening of noise. The threshold suppresses changes in flat regions, avoiding noise amplification.

### With OpenCV-Python

OpenCV-Python provides a more flexible and transparent way to implement unsharp masking using Gaussian blur and linear blending, as demonstrated in the next code snippet:

```
# Load image
img = cv2.imread("images/me.jpg")
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
# Apply Gaussian Blur
blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=2)
# Unsharp Mask
alpha = 1.5
sharpened_cv = cv2.addWeighted(img, 1 + alpha, blurred, -alpha, 0)
sharpened_cv_rgb = cv2.cvtColor(sharpened_cv, cv2.COLOR_BGR2RGB)
# Display img_rgb and sharpened_cv_rgb here
```

Here is how the above code works:
- cv2.GaussianBlur blurs the image using a Gaussian kernel
- cv2.addWeighted() performs the blending operation; with I and B representing the original and the blurred image, sharpened = (1 + α) · I − α · B, where α = 1.5 enhances the details

This approach gives more control over the blur and blend operations compared to the PIL method, making it ideal for experimentation and advanced applications.

## Entropy-based contrast enhancement with scipy.optimize

Among various enhancement techniques, contrast enhancement plays a pivotal role, especially for images with poor lighting or low dynamic range. This section introduces a principled method of contrast enhancement by maximizing the entropy of the image using gamma correction.

Entropy is a measure of randomness or information content in an image. An image with higher entropy typically exhibits richer textures and more evenly distributed intensities. Thus, enhancing an image by maximizing entropy can lead to more visually appealing and information-rich representations.

### Gamma correction

As explained in the earlier chapters, Gamma correction is a nonlinear transformation defined by:

$$I_{enhanced}(x,y)=I(x,y)^\gamma$$

where:
- $I(x,y) \in [0,1]$ is the normalized pixel intensity
- $\gamma$ is the correction factor
- $\gamma < 1$ brightens the image
- $\gamma > 1$ darkens the image

Gamma correction alters the contrast in a nonlinear way, making it suitable for images with non-uniform lighting or histogram distributions.

### Entropy of an image

The Shannon entropy of an image is defined as:

$$H(I)=-\sum_{i=0}^{255}p(i)\log_2 p(i)$$

where:
- $p(i)$ is the probability (normalized histogram count) of the intensity value $i$
- The summation is over all possible intensity levels

Entropy provides a quantitative measure of information content. Higher entropy generally means more contrast and texture variability.

### Methodology: maximizing entropy via gamma

The key idea is to find an optimal gamma value that enhances the contrast of the image such that the entropy of the resulting image is maximized.

This is formulated as a 1D optimization problem.

$$\gamma^*=\arg\max_{\gamma\in\Gamma}H(I^\gamma)$$
