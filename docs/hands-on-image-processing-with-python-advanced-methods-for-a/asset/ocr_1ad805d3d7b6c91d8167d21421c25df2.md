def encode(self, x, y):
    y = self.label_fc(F.one_hot(y, NUM_CLASSES).float())
    h = self.encoder(torch.cat([x, y], dim=1))
    return self.mu(h), self.logvar(h)

def reparameterize(self, mu, logvar):
    std = torch.exp(0.5 * logvar)
    return mu + torch.randn_like(std) * std

def decode(self, z, y):
    y = self.label_fc(F.one_hot(y, NUM_CLASSES).float())
    return self.decoder(torch.cat([z, y], dim=1))

def forward(self, x, y):
    mu, logvar = self.encode(x, y)
    z = self.reparameterize(mu, logvar)
    return self.decode(z, y), mu, logvar

```

**Conditioning on Class Labels:** Class labels are first converted to one-hot vectors and projected into a continuous embedding space (`self.label_fc`). The label embedding is concatenated with the image features in the encoder and with the latent vector in the decoder. This conditioning mechanism enables the model to learn class-specific latent distributions and generate images belonging to a desired Fashion-MNIST category.

**Encoder:** The encoder receives a flattened 28 × 28 image together with the embedded class label. Rather than directly producing a latent vector, the encoder predicts the parameters of a Gaussian distribution:

$$\mu = f_\mu(x,y), \log \sigma^2 = f_\sigma(x,y)$$

**Reparameterization Trick:** Sampling directly from a Gaussian distribution would prevent gradients from propagating through the network. The VAE therefore uses the reparameterization trick. Mathematically,

$$z = \mu + \sigma \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I)$$

This formulation preserves differentiability and enables end-to-end training using backpropagation.

**Decoder:** The decoder reconstructs the image from the latent code and class embedding. Generation is performed as:

$$\hat{x} = D(z,y),$$

Where $D$ denotes the decoder network.
