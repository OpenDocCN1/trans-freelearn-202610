The function `tfds.load()` automatically downloads (if needed), prepares, and loads the CIFAR-100 dataset as TensorFlow data pipelines, while also returning dataset metadata such as class names, image shape, and dataset size.

```
import tensorflow_datasets as tfds
from tf_explain.core.grad_cam import GradCAM
gpus = tf.config.experimental.list_physical_devices('GPU')
(ds_train, ds_test), ds_info = tfds.load('cifar100', split=['train', 'test'],
                                      shuffle_files=True, as_supervised=True, with_
info=True)
```

The model first predicts the image class and then **Grad-CAM** backpropagates gradients from the predicted class to the final convolutional layers to generate a class-activation heatmap showing which image regions contributed most to the decision. Comparing heatmaps from the *baseline* and *attention-enhanced* CNNs provides an **Explainable AI (XAI)** visualization that helps interpret *why* a prediction was made and whether the model is focusing on the target object rather than irrelevant background regions, as demonstrated by the next code.

```
y_pred = model.predict(img[None])  # Prediction
pred_class = np.argmax(y_pred)
explainer = GradCAM()  # Grad-CAM explanation
heatmap = explainer.explain([img], None), model, class_index=pred_class,
                              image_weight=0.8)
plt.imshow(heatmap)  # Visualization
```
