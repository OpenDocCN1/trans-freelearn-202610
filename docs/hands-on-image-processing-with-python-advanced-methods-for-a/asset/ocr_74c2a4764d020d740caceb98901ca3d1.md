Once the raw edge probability map is computed using the structured edge detector, it often contains thick or blurry edges, especially where the underlying structure in the image is smooth or ambiguous. To make these edges sharper, thinner, and more localized, we apply two important post-processing steps: orientation maps and NMS.

# Using orientation maps and NMS

The function computeOrientation() estimates the local edge orientation map (or gradient direction) at each pixel where an edge is detected. The logical question that arises is, why orientation?

To suppress non-edge responses while preserving edge structure, we need to know which direction the edge lies in (e.g., vertical, horizontal, diagonal). This allows us to perform directional suppression, i.e., compare a pixel to its neighbors along the direction perpendicular to the edge.

The computeOrientation() function produces a single-channel floating-point matrix (same width and height as the image), where each pixel stores the orientation angle θ of the edge (in radians, usually [0, π]).
