# Local object editing

Specific objects can be modified through natural-language instructions.

```
prompt = """Change the yellow car to red. Preserve everything else."""
```

Unlike traditional segmentation-based methods, GPT Image performs localized editing through semantic understanding of the scene.

![](bbox=[0.242, 0.221, 0.809, 0.425])

*Figure 13.51 – Local object (car) editing with GPT-image*

Applications include product customization, virtual prototyping, and design exploration.

# Object removal

Unwanted objects can be removed without explicitly supplying masks, as demonstrated below:

```
prompt = """Remove the person from the image. Keep everything else unchanged."""
```

The model reconstructs the hidden background and fills the removed region consistently. This is a generalized form of *semantic inpainting*, as shown in the next figure:
