# Caution

When resizing an image, it is important to preserve the aspect ratio (the ratio of width to height) if you want to avoid distortion. You can preserve the aspect ratio by specifying just one dimension (e.g., width or height) and computing the other accordingly. While this is not a concern for scaling both dimensions by the same factor, it would be good to caution you for general cases.

To preserve the aspect ratio automatically during resizing, one common approach is to compute the second dimension accordingly, as done with the resize_preserve_aspect_ratio() function:

```
def resize_preserve_aspect_ratio(im, target_width, resample=Image.BILINEAR):
    """
    resize an image to a given width while preserving the aspect ratio.
    """
    aspect_ratio = im.height / im.width
    target_height = int(target_width * aspect_ratio)
    return im.resize((target_width, target_height), resample)

# usage:
im_resized = resize_preserve_aspect_ratio(im, target_width=300)
```
