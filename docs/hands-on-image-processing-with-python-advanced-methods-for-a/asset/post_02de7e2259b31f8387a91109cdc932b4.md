
where $y_i$ is the ground-truth edge mask for patch $x_i$.

At each split node in the tree, the goal is to choose a split function $\theta$ that maximizes information gain. For structured outputs, this requires defining a proper distance metric $d(y_i, y_j)$ between masks. Dollár and Zitnick propose using a low-dimensional embedding of edge patches into binary labels via clustering.

Let $\phi(y_i) \in R^k$ be such an embedding, and define entropy over clusters:

$$H(S) = -\sum_{c=1}^{C} \frac{|S_c|}{|S|} \log\left(\frac{|S_c|}{|S|}\right)$$

The split function $\theta$ is chosen to maximize the information gain:

$$\Delta H = H(S) - \sum_{j \in \{L,R\}} \frac{|S_j|}{|S|} H(S_j)$$

where $S_L, S_R$ are the left and right child node subsets split by $\theta$.

## Inference and edge map aggregation

During inference, a sliding window is used to extract overlapping patches, and each patch is passed through the forest. The predicted edge maps from all trees are averaged and aggregated over the image to produce the final dense edge map.

Let $T$ be the number of trees and $E_t(x)$ be the predicted edge map from tree t, then the aggregated edge response at pixel $i$ is:

$$E(i) = \frac{1}{T} \sum_{t=1}^{T} E_t(i)$$

Post-processing steps such as non-maximum suppression or edge thinning can be applied.

Structured edge detection has been successfully applied in object proposal generation, semantic segmentation, stereo matching, medical image boundary detection, and optical flow preprocessing.

Its ability to capture local structure and context makes it especially useful for complex natural scenes. Let's use opencv-python ximgproc library functions to demonstrate how it works. ## Using orientation maps and NMS

The function computeOrientation() estimates the local edge orientation map (or gradient direction) at each pixel where an edge is detected. The logical question that arises is, why orientation?

To suppress non-edge responses while preserving edge structure, we need to know which direction the edge lies in (e.g., vertical, horizontal, diagonal). This allows us to perform directional suppression, i.e., compare a pixel to its neighbors along the direction perpendicular to the edge.

The function computeOrientation() produces a single-channel floating-point matrix (same width and height as the image), where each pixel stores the orientation angle θ of the edge (in radians, usually [0, π]).

The function `edgesNms()` computes **non-maximum suppression (NMS)**, which is a classical technique used to thin out wide edge responses by retaining only the local maxima in the direction orthogonal to the edge.

Suppose you have a wide fuzzy edge. You want to keep only the strongest pixel value across the edge width, i.e., the center of the edge. This is done by comparing each pixel’s edge strength with its neighbors along the direction perpendicular to the edge. If the pixel is not the local maximum, it is suppressed to zero.

Let $E(x,y)$ be the edge-strength and $\theta(x,y)$ the orientation. For each pixel $(x,y)$, we compute:

$$E'(x,y)=\begin{cases} E(x,y), & E(x,y)>E(x',y')\land E(x,y)>E(x'',y'')\\ 0, & \text{otherwise}\end{cases}$$

where $(x',y')$ and $(x'',y'')$ are neighbors of $(x,y)$ along the gradient direction (i.e., orthogonal to the edge direction $\theta$).

## Guided filtering for edge enhancement (OpenCV-Python)

Guided filtering, introduced by He et al. (2010), provides a fast and edge-preserving way to smooth images and refine details. Unlike bilateral filters, guided filtering avoids expensive iterative operations and is highly suitable for real-time and edge-aware smoothing tasks. Let’s explore the mathematical foundation of guided filtering, its practical applications, and provide a complete Python implementation using OpenCV’s cv2.ximgproc.guidedFilter.

A **guided filter** performs edge-preserving smoothing by using a guidance image (usually the original image) to control how another image (the source) is smoothed. It assumes that the output is a linear transform of the guidance image in a local window, making it well-suited for tasks like:

- Edge-aware denoising
- Detail enhancement
- HDR compression
- Image matting
- Depth map refinement

Given:

- **Input image I**: grayscale or color (used as guidance)
- **Source image p**: the image to be filtered (e.g., gradient, mask, etc.)
- **Output q**: the filtered result

For each local window ωₖ, the output qᵢ at pixel i ∈ ωk is modeled as a **linear transform** of the guidance image:

qᵢ = aₖ Iᵢ + bₖ, ∀i ∈ ωk

where

- aₖ, bₖ: linear coefficients constant in ωₖ
- Iᵢ: pixel intensity at position i

The coefficients aₖ, bₖ are estimated by minimizing the following cost function:

E(aₖ, bₖ) = Σᵢ∈ωₖ ((aₖ Iᵢ + bₖ − pᵢ)² + ε aₖ²)

where:

- ε: regularization parameter to control smoothness (prevents overfitting)

The second term encourages smaller gradients of q.

The solution to the optimization is:

aₖ = [ (1/|ω|) Σᵢ∈ωₖ Iᵢ pᵢ − μₖ p̄ₖ ] / [ σₖ² + ε ]
bₖ = p̄ₖ − aₖ μₖ

Where:

- μₖ, σₖ²: mean and variance of I in ωk
- p̄ₖ: mean of p in ωₖ

Then the output image q is obtained by averaging all q_i values using a box filter.

Let's now explore an edge enhancement application using guided filtering with opencv-python using the following code snippet:

```
from cv2.ximgproc import guidedFilter
# Load grayscale image and resize for faster processing
img = cv2.imread('images/we.jpg', cv2.IMREAD_GRAYSCALE)
img = cv2.resize(img, (256, 256))
# Normalize to float32 [0, 1]
img_float = img.astype(np.float32) / 255.0
# Step 1: Compute gradient magnitude
grad_x = cv2.Sobel(img_float, cv2.CV_32F, 1, 0, ksize=3)
grad_y = cv2.Sobel(img_float, cv2.CV_32F, 0, 1, ksize=3)
grad_mag = np.sqrt(grad_x**2 + grad_y**2)
# Step 2: Apply guided filter (guide = original image, input = grad_mag)
radius = 8
eps = 1e-3  # Regularization term
grad_mag_smooth = guidedFilter(guide=img_float, src=grad_mag, \
                                radius=radius, eps=eps)
# Step 3: Edge enhancement by subtraction
enhanced_edges = grad_mag - grad_mag_smooth
enhanced_edges = np.clip(enhanced_edges, 0, 1)
# Display img, grad_mag and enhanced_edges side-by-side here
```
