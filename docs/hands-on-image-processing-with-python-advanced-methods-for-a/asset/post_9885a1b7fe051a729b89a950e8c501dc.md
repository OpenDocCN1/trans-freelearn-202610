from skimage.transform import warp

def translate(xy, t_x, t_y):
    xy = xy.copy() # avoid modifying input in place

    xy[:, 1] -= t_y

## Applying rotation to an image with warp()

If an image is rotated by angle θ counterclockwise, for all possible pixels in the rotated output image (x, y), the corresponding points in the input image (u, v) can be found with the following equations:

u = x.cosθ − y.sinθ

v = x.sinθ + y.cosθ

Orthogonal geometric transformation is a transformation whose matrix Q has orthogonal unit-length vectors as columns (or rows), satisfying QᵀQ = I, which means it preserves distances, lengths, and angles; examples include rotation (check R(θ)ᵀR(θ) = I) and reflection transformations, e.g., reflection about the x−axis is represented by the matrix R = [1 0; 0 −1].

### With the transformation function

The following code block shows how to use the warp() function to rotate an image, using the rotate() transformation function. Rotation using warp() is done relative to the origin (top left corner) of the input image:

```
def rotate(xy, theta):
    theta = np.deg2rad(theta) # np.pi/180*theta # degree to radian
    x_new = xy[:, 0]*np.cos(theta) - xy[:,1]*np.sin(theta)
    y_new = xy[:, 0]*np.sin(theta) + xy[:,1]*np.cos(theta)
    xy[:, 0], xy[:, 1] = x_new, y_new
    return xy
# create a dictionary for rotation parameters, with angle theta in degrees
im_rot = warp(im, rotate, map_args={'theta':10})
```

**Note**

To avoid this, you can pad the image or apply a centered rotation by adjusting the coordinates (as done with the `rotate_centered()` function shown in the following code). Alternatively, you could use the `skimage.transform.rotate()` function, which handles centered rotation (rotates about the image center) and padding internally for better visual preservation of the image content:

## Applying an affine transformation to an image

An affine transformation is a more general transformation that includes scaling, rotation, translation, shearing, and reflection. It allows for non-uniform scaling, shearing, and reflection, in addition to the components of a similarity transformation. The affine transformation can be decomposed into four fundamental transformations: scaling, rotation, shear, and translation, hence it has six parameters: scaling factors along the $x$ and $y$ axes, a rotation angle, translation along the $x$ and $y$ axes, and a shearing factor. A similarity transformation is an affine transformation with uniform scaling.

Each transformation can be represented as an independent matrix:

- **Scaling matrix:**
  
  $S = \begin{bmatrix} s_x & 0 & 0 \\ 0 & s_y & 0 \\ 0 & 0 & 1 \end{bmatrix}$
  
  Here, $s_x$ and $s_y$ control the scaling/stretching along the $x$ and $y$ axes, respectively.

- **Rotation matrix:**
  
  $R = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}$
  
  Here, $\theta$ is the rotation angle (counterclockwise).

- **Shear matrix:**
  
  $H = \begin{bmatrix} 1 & sh_x & 0 \\ sh_y & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix}$

Here, $sh_x$ and $sh_y$ introduce shearing (horizontal and vertical skewing).

- **Translation matrix:**

```
$$T = \begin{bmatrix}1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1\end{bmatrix}$$
```

Here, $t_x$ and $t_y$ shift the image horizontally and vertically.

The final transformation is the combination of scaling, rotation, shear, and translation:

```
$$T_A = T \cdot H \cdot R \cdot S$$
```

Let's expand this:

```
$$T_A = \begin{bmatrix}s_x \cos\theta + sh_y \sin\theta & -s_y \sin\theta + sh_x \cos\theta & t_x \\ s_x \sin\theta + sh_y \cos\theta & s_y \cos\theta + sh_y \sin\theta & t_y \\ 0 & 0 & 1\end{bmatrix} = \begin{bmatrix}a & b & t_x \\ c & d & t_y \\ 0 & 0 & 1\end{bmatrix}$$
```

Here, $a, b, c,$ and $d$ represent the parameters (e.g., $a = s_x \cos\theta + sh_x \sin\theta$) for the scaling/rotation in the $x$-direction, shear in the $x$-direction, shear in the $y$-direction, and scaling/rotation in the $y$-direction.
