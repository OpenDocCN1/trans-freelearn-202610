
## Retouching and outpainting

While inpainting focuses on filling missing or masked regions of an image, and editing focuses on direct manipulation of content, retouching and outpainting represent two complementary yet distinct paradigms in generative image processing:

- Retouching is the process of enhancing or refining existing image content — improving details, correcting imperfections, adjusting lighting, or even stylistically modifying an image while preserving its core structure. It is widely used in photography, advertising, and art, where the goal is not to replace content but to refine it.
- Outpainting, on the other hand, goes beyond the original image boundary by generating plausible new content outside the given frame. It extends the canvas while keeping semantic and stylistic consistency. Outpainting has become particularly popular with diffusion models such as Stable Diffusion and DALL·E, as they are capable of generating coherent scene extensions based on the input context.

Both techniques rely on image-to-image translation principles, where the input image is encoded into a latent representation, modified under the guidance of a text prompt, and decoded back into pixel space.

## Retouching

Retouching is essentially a constrained form of image-to-image translation where the input and output should remain largely similar, except for enhanced or corrected details. Formally, let I be the input image and z = E(I) its latent encoding using an autoencoder E. A diffusion process perturbs this latent with controlled noise:

```
z_t = sqrt(alpha_t) z + sqrt(1 - alpha_t) epsilon,   epsilon ~ N(0, I)
```

where t is the diffusion timestep and alpha_t controls noise level.

During retouching, we choose a low noise strength (small t), meaning the diffusion model primarily preserves the original structure of I. The model then denoises z_t guided by a textual condition c (prompt):

```
z_hat_0 = D_theta(z_t | c)
```

where D_theta is the denoising UNet. Finally, the latent is decoded back into image space:

```
I_hat = G(z_hat_0)
```

The key parameter is strength; if strength → 0, this is almost identical to the original image (minimal retouch), whereas strength → 1 means significant changes (closer to editing). This makes retouching a continuous trade-off between enhancement and transformation. The next code snippet provides an implementation for image retouching:

## Outpainting

Outpainting extends an image beyond its original boundaries while maintaining visual and semantic coherence. Unlike inpainting (filling holes inside the image), outpainting works on a new canvas space. Mathematically, consider an input image *I* defined over a domain Ω ⊂ ℝ². Outpainting extends *I* to a larger domain Ω′ ⊃ Ω. The diffusion model fills Ω′\Ω (the new region) using:

$$\hat{I}(x)=\begin{cases}I(x), & x\in\Omega\\G_\theta(z,c), & x\in\Omega'\\Omega\end{cases}$$

where G<sub>θ</sub> generates new pixels conditioned on the context of *I* and the prompt *c*.

Let’s now understand the code in detail. Here are the steps:

- **Pipeline loading:** We use StableDiffusionInpaintPipeline because outpainting is technically a form of inpainting on newly added regions.
- **Canvas expansion:** The image is embedded into a larger white canvas with extra space added above and below. These blank areas are where new content will be synthesized.
- **Mask creation:** Mask = white where content is preserved (the original image) and Mask = black where new content is generated (the padded regions). This ensures only the new regions are synthesized.
- **Diffusion process:** strength=0.3 allows a moderate level of creativity while keeping context intact. guidance_scale=7.5 balances adherence to the text prompt and realism.
- **Result:** The model extrapolates the image vertically. The output contains a plausible continuation of the gallery scene, consistent in lighting and perspective.

The next table summarizes the key differences between retouching and outpainting:

| Dimension | Retouching | Outpainting |
|---|---|---|
| **Goal** | Enhance/refine existing image without altering main content. | Extend the image beyond its original boundaries. |
| **Input** | Original image + prompt. | Original image, expanded canvas, and mask. |
| **Mask usage** | Not required (applies to whole image). | Required (defines extended regions). |
| **Math view** | Constrained diffusion with low noise (preserve structure). | Diffusion-based generation in extended domain Ω′\Ω. |
| **Applications** | Portrait retouching, contrast enhancement, photo improvements. | Creative scene expansion, panoramic views, storyboarding. |
