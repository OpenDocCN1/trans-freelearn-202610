
return next_layer, skip_connection

def upsampling_block(expansive_input, contractive_input, n_filters=32):
    up = Conv2DTranspose(n_filters, kernel_size = 3, strides=(2,2),
                         padding='same')(expansive_input)
    merge = concatenate([up, contractive_input], axis=3)
    conv = Conv2D(n_filters, kernel_size = 3, activation='relu',
                  padding='same',
                  kernel_initializer=tf.keras.initializers.HeNormal())(merge)
    conv = Conv2D(n_filters, kernel_size = 3, activation='relu',
                  padding='same',
                  kernel_initializer=tf.keras.initializers.HeNormal())(conv)
    return conv

def unet_model(input_size=(96, 128, 3), n_filters=32, n_classes=23):
    inputs = Input(input_size)
    #contracting path
    cblock1 = conv_block(inputs, n_filters)
    cblock2 = conv_block(cblock1[0], 2*n_filters)
    cblock3 = conv_block(cblock2[0], 4*n_filters)
    cblock4 = conv_block(cblock3[0], 8*n_filters, dropout_prob=0.3)
    cblock5 = conv_block(cblock4[0],16*n_filters, dropout_prob=0.3, \
                         max_pooling=None)
    # expanding path
    ublock6 = upsampling_block(cblock5[0], cblock4[1], 8 * n_filters)
    ublock7 = upsampling_block(ublock6, cblock3[1], n_filters*4)
    ublock8 = upsampling_block(ublock7,cblock2[1] , n_filters*2)
    ublock9 = upsampling_block(ublock8,cblock1[1], n_filters)
    conv9 = Conv2D(n_filters, 3, activation='relu', padding='same',
                   kernel_initializer='he_normal')(ublock9)
    conv10 = Conv2D(n_classes, kernel_size=1, padding='same')(conv9)
    model = tf.keras.Model(inputs=inputs, outputs=conv10)
    return model

unet = unet_model((img_height, img_width, num_channels))

@tf.keras.utils.register_keras_serializable()
class MeanIoUWrapper(tf.keras.metrics.MeanIoU):
    def __init__(self, num_classes, name="mean_iou", **kwargs):
        super().__init__(num_classes=num_classes, name=name, **kwargs)
    def update_state(self, y_true, y_pred, sample_weight=None):
        y_pred = tf.argmax(y_pred, axis=-1)
        y_true = tf.squeeze(tf.cast(y_true, tf.int32), axis=-1)
        return super().update_state(y_true, y_pred, sample_weight)

## U-Net with ResNet18 backbone using segmentation_models_pytorch

Modern segmentation systems often use pretrained encoders to improve convergence speed, feature quality, and generalization. Instead of training the encoder from scratch, pretrained CNN backbones are reused. This approach is known as encoder–decoder transfer learning.

The next code snippet demonstrates semantic segmentation using a U-Net model with a pretrained ResNet18 encoder implemented through segmentation_models_pytorch (SMP), which provides production-ready architectures such as U-Net, FPN, PSPNet and DeepLabV3+ with interchangeable backbones.

A custom PyTorch Dataset class loads and preprocesses Lyft-Udacity road-scene images and masks using Albumentations, while DataLoader enables efficient batching and GPU training. The model smp.Unet(encoder_name="resnet18") uses a pretrained ResNet18 encoder for transfer learning, where residual connections improve gradient flow and feature extraction. The decoder reconstructs dense segmentation masks from hierarchical semantic features.

Training uses nn.CrossEntropyLoss() with forward propagation, backpropagation, and optimizer updates, while segmentation quality is evaluated using Pixel Accuracy, Mean IoU, and Dice Coefficient. Predictions are converted into semantic labels using torch.argmax() and visualized with Cityscapes-style color mapping. Compared to a custom TensorFlow U-Net, the SMP implementation is more scalable, faster to train, and better suited for real-world deployment due to pretrained encoders and industrial-grade abstractions. Now, refer to the code snippet:
