
This removes small variations in the gradient while preserving strong edges, since the guidance image contains edge location info.

## Edge detection with anisotropic diffusion

Anisotropic diffusion is a powerful image processing technique that smooths an image while preserving edge structures. Introduced by Perona and Malik (1990), it overcomes the limitations of linear (isotropic) diffusion by adapting the diffusion strength based on the local image gradient. This makes it ideal for edge-preserving smoothing and edge detection.

## Perona–Malik anisotropic diffusion

Let I(x, y, t) denote an image evolving over time t. The classical isotropic diffusion (heat equation) is:

∂I/∂t = ∇ · (∇I)

Anisotropic diffusion modifies this as:

∂I/∂t = ∇ · (c(x, y, t) · ∇I)

Where:

- ∇I: image gradient (measures local change)
- c(x, y, t): diffusion coefficient that controls the amount of smoothing

The function c(·) is typically chosen to inhibit diffusion at edges:

c(∇I) = exp( - (∇I / K)² ) or c(∇I) = 1 / (1 + (∇I / K)² )

- K: edge threshold parameter; controls sensitivity to edges
- Small gradients (homogeneous regions): high c → more smoothing
- Large gradients (edges): low c → edge preservation

The next code snippet demonstrates how edge detection works better with anisotropic diffusion. Here are the key functions:

- anisotropic_diffusion(...) from medpy performs Perona-Malik smoothing.
- niter: number of diffusion iterations.
- kappa: contrast parameter K to suppress diffusion at edges.
- gamma: time step size (should be ≤ 0.25 for stability).
- option: chooses the conductivity function c(·).

The smoothed image is passed to a standard Sobel filter to extract enhanced edges with reduced noise.

## Deep learning-based edge detection

While classical detectors such as Sobel, Prewitt, and Canny are fast and intuitive, they rely on manually designed filters and often fail in scenarios with complex textures, lighting changes, or noise. Deep learning, particularly convolutional neural networks (CNNs), has brought about a paradigm shift in edge detection. Instead of manually engineering filters, deep models learn them directly from annotated datasets, making them more adaptable to real-world scenarios. This section introduces two prominent deep learning-based edge detectors, Holistically-Nested Edge Detection (HED) and Pixel Difference Network (PiDiNet), and demonstrates their usage via pretrained models available on Hugging Face.

## Edge detection as a learning problem

Let \(I:\Omega\to\mathbb{R}^3\) be a color image defined over the spatial domain \(\Omega\subset\mathbb{R}^2\). The goal of edge detection is to learn a mapping \(F_\theta(I)=E\), where \(E:\Omega\to[0,1]\) represents the probability of an edge at each pixel. The learning problem is formalized as a binary classification task for each pixel, with a loss function such as binary cross-entropy:

$$\mathcal{L}=-\sum_{x\in\Omega}\left[y(x)\cdot\log E(x)+(1-y(x))\cdot(1-\log E(x))\right]$$

where \(y(x)\in[0,1]\) is the ground truth edge label.

### Holistically-nested edge detection

**Holistically-nested edge detection (HED)** is a fully convolutional neural network that uses deep supervision to extract multi-scale edge features. It is based on the VGG-16 architecture, with side outputs from multiple convolutional layers. Each side output \(E_s\) is an intermediate edge map. These are fused using learnable weights \(\alpha_s\):

$$F_\theta(I)=\sigma\left(\sum_{s=1}^{S}\alpha_s\cdot E_s\right)$$

where \(\sigma\) is a sigmoid activation. This multi-scale fusion ensures both fine and coarse edge details are preserved. Think of HED as a committee of experts, each looking at different image scales. Their combined opinion results in a robust edge map.

### Pixel difference network

**Pixel difference network (PiDiNet)** is designed for lightweight and real-time edge detection. Inspired by traditional gradient operators (like Sobel), PiDiNet learns pixel difference kernels within a deep network. Instead of using complex dilation or attention, PiDiNet uses difference convolutions initialized to mimic classical filters.

$$G(x,y)=\sum_{i,j}K_{ij}\cdot I(x+i,y+j)$$

where \(K\) is a trainable kernel initialized to highlight pixel intensity differences. PiDiNet learns to compute smart differences between pixels, similar to Sobel but more flexible and data-driven.

From an intuitive standpoint, the key difference between HED and PiDiNet lies in what they learn and how they allocate computational effort. HED learns edges as a multi-scale semantic concept, where deeper layers capture object-level boundaries and shallower layers capture fine details, making it particularly effective in complex natural scenes with texture, occlusion, and varying illumination. In contrast, PiDiNet focuses on efficient local intensity differences, closely resembling classical gradient operators but with learned flexibility, which allows it to approximate edge responses with far fewer parameters and significantly lower computational cost.

In other words, HED prioritizes representation richness and global context, while PiDiNet prioritizes efficiency and local precision. This distinction explains why HED typically produces more semantically meaningful edges at the expense of speed, whereas PiDiNet offers a strong trade-off between accuracy and real-time performance, especially in resource-constrained environments.
