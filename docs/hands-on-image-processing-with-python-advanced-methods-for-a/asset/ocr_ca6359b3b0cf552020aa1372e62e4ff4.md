**Tikhonov regularization** provides a deterministic, variational approach to image restoration, balancing fidelity to data with smoothness priors. It is simpler than Wiener filtering but less adaptive. It serves as a gateway to more advanced priors like TV, sparse priors, and modern deep priors.

If the ratio $S_η/S_f$ is approximated by a constant $λ$, Wiener and Tikhonov become mathematically similar. Thus, Wiener is statistical/Bayesian, while Tikhonov is variational/regularization-based. The next code snippet implements the Tikhonov restoration and compares it with the Wiener restoration, and for visual comparison, we will plot the restored images side-by-side:

```
```python
from skimage import color, data, img_as_float, restoration
from scipy.signal import convolve2d as conv2
from numpy.fft import fft2, ifft2, fftshift

im = color.rgb2gray(img_as_float(data.astronaut()))  # Load image
im = im[50:300, 150:400]  # crop
n = 15
psf = np.ones((n, n)) / n**2  # Blur with PSF
blurred = conv2(im, psf, 'same')
np.random.seed(0)  # Add Gaussian noise
noisy = blurred + 0.05 * np.random.standard_normal(blurred.shape)

def tikhonov_restore(noisy, psf, lam=0.01):  # Tikhonov Restoration
    psf_padded = np.zeros_like(noisy)
    psf_padded[:psf.shape[0], :psf.shape[1]] = psf
    psf_padded = fftshift(psf_padded)
    H = fft2(psf_padded)
    G = fft2(noisy)
    H_conj = np.conj(H)
    F_hat = (H_conj / (np.abs(H)**2 + lam)) * G
    f_hat = np.real(ifft2(F_hat))
    return np.clip(f_hat, 0, 1)

tikhonov_restored = tikhonov_restore(noisy, psf, lam=0.01)
wiener_restored, _ = restoration.unsupervised_wiener(noisy, psf)
```
