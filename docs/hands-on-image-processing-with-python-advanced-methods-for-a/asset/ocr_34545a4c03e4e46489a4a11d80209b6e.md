# Background blurring with MediaPipe + DeepLabV3 (TFLite)

This application demonstrates real-time foreground–background separation using a lightweight model suitable for mobile and edge devices. The system uses MediaPipe with a TensorFlow Lite version of DeepLabV3 to perform semantic segmentation efficiently. Given an image I(x, y), the model predicts a category mask:

S(x, y) ∈ {0,1}

where S(x, y) = 1 → foreground (person/object) and S(x, y) = 0 → background. We then apply:

I_final(x, y) = { I(x, y), if S(x, y) = 1; Blur(I(x, y)), otherwise }

This produces a portrait-style background blur, similar to video conferencing tools.

The next code snippet demonstrates background blur using MediaPipe’s high-level vision tasks API. A vision.ImageSegmenter loaded with a DeepLabV3 TFLite model performs pixel-wise semantic segmentation to generate a category mask separating foreground from background. The mask is thresholded into a binary mask, the background is blurred using Gaussian filtering, and the final image is created by blending the sharp foreground with the blurred background. The resulting pipeline is then exposed through a simple Gradio interface, allowing users to upload images and interactively visualize the original image, segmentation mask, and background-blurred result.

```
# run in colab
from mediapipe.tasks.python import vision
base_options = python.BaseOptions(model_asset_path="deeplabv3.tflite")
options = vision.ImageSegmenterOptions(
    base_options=base_options, output_category_mask=True)
segmenter = vision.ImageSegmenter.create_from_options(options)

def segment_and_blur(img):
    mp_image = mp.Image(image_format=mp.ImageFormat.SRGB, data=img)
    result = segmenter.segment(mp_image)
    mask = result.category_mask.numpy_view().squeeze()
    binary_mask = (mask > 0.2).astype(np.uint8) * 255
    binary_mask_rgb = np.stack([binary_mask]*3, axis=-1)
    blurred = cv2.GaussianBlur(img, (55, 55), 0)
    condition = mask > 0.1
    final = np.where(condition[..., None], img, blurred)
    return img, binary_mask_rgb, final

with gr.Blocks() as demo:

    with gr.Row():
        input_img = gr.Image(type="numpy", label="Upload Image")
```
