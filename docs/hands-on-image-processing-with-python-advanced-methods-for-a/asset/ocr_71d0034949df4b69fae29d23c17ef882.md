Here, upscale=2 doubles the image resolution, while arch="clean" selects the lightweight restoration architecture.

**Face Restoration:** The core restoration step is:

```
_ , _ , restored_img = restorer.enhance(img, paste_back=True)
```

The enhance() function detects facial regions, restores facial details using the generative prior, and inserts the enhanced faces back into the original image. The complete restoration function can be reduced to:

```
def restore_image_gfpgan(img):
    restorer = GFPGANer(model_path='experiments/pretrained_models/GFPGANv1.3.pth', \
                        upscale=2, arch="clean")
    _, _, restored_img = restorer.enhance(img, paste_back=True)
    return restored_img
```
