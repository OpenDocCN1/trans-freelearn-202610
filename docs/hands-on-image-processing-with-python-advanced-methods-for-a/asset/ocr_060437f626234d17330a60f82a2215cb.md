# Note

If the training PSNR continues to improve while the test PSNR plateaus or begins to decline, this is a strong indicator of overfitting in the FFN. To mitigate overfitting, consider techniques such as early stopping, regularization (e.g., increasing dropout), and so on. Dropout randomly disables neurons during training and can help improve generalization; if overfitting is observed, try increasing the dropout rate moderately. Also, note that during inference (e.g., image reconstruction), the model uses the full-resolution test data, and no dropout is applied.
