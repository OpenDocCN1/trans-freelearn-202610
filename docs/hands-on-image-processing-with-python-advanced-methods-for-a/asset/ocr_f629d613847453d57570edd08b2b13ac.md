# Getting the darker/lighter of two images

The next code snippet computes the **lighter** of two images by comparing pixel values, using the `ImageChops.lighter(im1, im2)` method, which makes a pixel-wise comparison between two images, `im1` and `im2`, and keeps the maximum value for each RGB channel, effectively selecting the brighter **pixel** at each position:

```
im1 = Image.open("images/parrot.png")
im2 = Image.open("images/hill.png").convert('RGB') \
                         .resize((im1.width, im1.height))
lighter(im1, im2).show()
```
