+   The apply_filter() function applies a filter function in the frequency domain to an image (with the convolution theorem, G(u, v) = F(u, v)H(u, v)). The function is flexible and supports different filter types using kwargs (arg_dict) and passes the required parameters to the corresponding filter functions dynamically. The next table describes the input arguments to the function:

| Parameter | Type | Description |
|---|---|---|
| f | numpy.ndarray | Input image (grayscale, stored as a 2D array). |
| func | function | A filtering function (e.g., ideal, gaussian, or butterworth). |
| arg_dict | dict | Keyword arguments (kwargs) passed to the filter function. |

+   The dist() function computes Euclidean distance from the center (h/2, w/2).

+   The get_grid(w, h) function generates a frequency grid centered at (h/2, w/2), with the np.meshgrid() function. It is essential for frequency-based image filtering in Fourier space.

```
def dist(u, v):
    return np.sqrt(u**2 + v**2)

def get_grid(w, h):
    return np.meshgrid(
        range(-int(np.floor(w/2)), int(np.ceil(w/2))), \
        range(-int(np.floor(h/2)), int(np.ceil(h/2)))
```
