# Inverting/negating an image

Inverting or negating an image involves reversing the colors of the pixels—turning light areas dark, and vice versa. The inversion is typically performed by subtracting the pixel values from the maximum intensity value (e.g., 255).

For any grayscale image, I, with, pixel values in the range [0, L] (where L is the maximum intensity value, typically 256 for an 8-bit image), the inverted image is defined as:

I_inverted(x, y) = (L − 1) − I(x, y), ∀ pixel positions (x, y)

To invert a color image, each color channel needs to be inverted independently. Let’s demonstrate how the inversion operation can be implemented with the Image.point() function in the next code snippet:

```
im = Image.open("images/pepper.webp")
im_t = im.point(lambda x: 255 - x)
```
