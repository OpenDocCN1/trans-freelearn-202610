# A Gradio app for interactive text-guided segmentation

The next code snippet builds a Gradio app that uses CLIPSeg to perform text-guided semantic segmentation, generating a binary mask for any object described by the user’s prompt and overlaying it on the image. Here, a natural-language prompt directly produces a pixel-wise mask.

The function segment_with_clipseg() converts the image and text prompt into aligned embeddings and uses CLIPSeg to predict pixel-wise logits indicating how strongly each pixel matches the queried concept. The logits are converted into probability masks using sigmoid activation, resized to the original image size, and thresholded to obtain a binary segmentation mask. The create_overlay() function highlights detected regions on the original image, while the Gradio interface provides an interactive app where users upload an image and enter a text prompt (e.g., “car”) to generate the corresponding segmentation mask and overlay visualization.

```
def segment_with_clipseg(image_pil, text):
    inputs = clipseg_processor(
        text=[text], images=[image_pil],
        padding=True, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = clipseg_model(**inputs)
    logits = outputs.logits[0]  # (H, W)
    mask = torch.sigmoid(logits).cpu().numpy() # logits -> mask
    mask = cv2.resize(mask, (image_pil.size[0], image_pil.size[1]))
```
