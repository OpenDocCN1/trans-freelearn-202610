Let’s now transition to another couple of important discrete transforms with orthonormal basis vectors, namely, the discrete cosine and Walsh-Hadamard transforms.

# Discrete cosine and discrete Walsh-Hadamard transforms

The DCT and Walsh-Hadamard transforms are separable orthogonal transforms that generalize the DFT using different basis functions. Let’s now understand how to implement matrix-based computations for these two transformations.

# The discrete cosine transform (DCT)

The 2D DCT is widely used in image compression because it concentrates most image energy into a few low-frequency coefficients. The forward and inverse DCT are defined in the following figure. Unlike the DFT, the DCT assumes an even-symmetric extension of the signal, giving it a periodicity of 2N.

g(x, y, u, v) = α(u) α(v) cos[(2x + 1)uπ / 2N] cos[(2y + 1)vπ / 2N]

α(u) = 1/√N, when u = 0 = √(2/N) ∀ u = 1, 2, ... N - 1

DCT
C(u, v) = α(u) α(v) Σ_{x=0}^{N-1} Σ_{y=0}^{N-1} f(x, y) cos[(2x + 1)uπ / 2N] cos[(2y + 1)vπ / 2N]

Inverse DCT
f(x, y) = Σ_{u=0}^{N-1} Σ_{v=0}^{N-1} α(u) α(v) C(u, v) cos[(2x + 1)uπ / 2N] cos[(2y + 1)vπ / 2N]
