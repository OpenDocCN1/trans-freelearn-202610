# Figure 4.5 – B-spline curves of order 4

The next code adds salt noise to the image by randomly setting approximately 15% of the pixels to white (1) and then smooths the noisy image using a cubic spline filter of order 3.

```
from scipy.ndimage import spline_filter
im_orig = imread('images/lady.png', True)
im = im_orig.copy()
h, w = im.shape
x, y = np.arange(h), np.arange(w)
# Corrupt few pixel values
np.random.seed(11)
mask = np.random.random(im.shape) > 0.85
im[mask] = 1
sp_filter = spline_filter(im, order=3, mode='nearest')
f, ax = plt.subplots(1, 3, sharex=True, figsize=(15,7))
for ind, data in enumerate([[im_orig, "original image"],
                            [im, "noisy image (salt)"],
                            [sp_filter, "denoised (spline filter)"]]):
    ax[ind].imshow(data[0], cmap='gray'), ax[ind].set_title(data[1])
```

Here, `np.random.random(im.shape)` generates uniformly distributed random values in [0,1], and the condition `> 0.85` selects approximately 15% of the pixels for corruption.
