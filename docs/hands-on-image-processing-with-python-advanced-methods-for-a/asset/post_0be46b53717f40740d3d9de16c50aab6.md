## MaskCLIP: Language-aligned segmentation

Contrastive Language–Image Pretraining (CLIP) learns a shared embedding space for images and text by training two encoders with a contrastive loss: matching image–caption pairs are pulled together while mismatched pairs are pushed apart, enabling zero-shot recognition by comparing similarity scores.

MaskCLIP extends segmentation into the vision–language domain, combining ideas from CLIP and segmentation transformers, by aligning dense image features (pixel/region embeddings) with text embeddings, so each pixel (or mask) is assigned the label whose text description is most similar, effectively enabling text-driven, open-vocabulary segmentation without explicit per-class training.

Here’s the mathematical perspective. Let the image embedding be F = E_I(I) and text embedding be T = E_T(t).

Then segmentation becomes:

S(x, y) = argmax_c ⟨F_{x,y}, T_c⟩

i.e., pixel–text similarity matching.

Although MaskCLIP is conceptual, it can be approximated using Mask2Former. The next code demonstrates universal/panoptic segmentation using pretrained Mask2Former components, where Mask2FormerImageProcessor.from_pretrained() prepares images through resizing and normalization, and `Mask2FormerForUniversalSegmentation.from_pretrained()` loads learned weights (e.g., COCO panoptic). The forward pass `model(**inputs)` generates mask logits and class scores for predicted regions, while `processor.post_process_panoptic_segmentation()` converts raw outputs into a dense segmentation map $S$ assigning a unique segment ID to each pixel. The function `get_vibrant_mask(segmentation)` colorizes segment IDs with distinct RGB values for visual interpretability (refer to GitHub) and overlay blending $I_{\mathrm{overlay}} = 0.5I + 0.5S_{\mathrm{color}}$ combines segmentation masks with the original image to simultaneously visualize scene content and predicted regions.

```python
from transformers import (
    Mask2FormerImageProcessor, Mask2FormerForUniversalSegmentation)
processor = Mask2FormerImageProcessor.from_pretrained(\
    "facebook/mask2former-swin-large-coco-panoptic")
model = Mask2FormerForUniversalSegmentation.from_pretrained(\
    "facebook/mask2former-swin-large-coco-panoptic").to(device)
image = Image.open("images/men_beach2.jpg").convert("RGB")
inputs = processor(images=image, return_tensors="pt").to(device)
with torch.no_grad(): outputs = model(**inputs)
target_size = [image.size[::-1]]                    # Post-Process
result = processor.post_process_panoptic_segmentation(\
    outputs, target_sizes=target_size)[0]
segmentation = result["segmentation"].cpu().numpy()
seg_color = get_vibrant_mask(segmentation) # Colorize Seg-Map, refer GitHub
image_np = np.array(image) # Create Overlay
overlay = (image_np * 0.5 + seg_color * 0.5).astype(np.uint8)

```
