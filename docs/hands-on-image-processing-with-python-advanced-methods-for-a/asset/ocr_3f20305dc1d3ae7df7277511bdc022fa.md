As α varies from 0 to 1, the generated image smoothly transitions between two Fashion-MNIST categories through interpolation of the class-conditioning vector, demonstrating the continuity of the learned conditional latent space.

**Within-Class Latent Traversal:** Unlike *cross-class* traversal, which transitions between different semantic categories (e.g., “sneaker” to “ankle boot” in the last example), *within-class* traversal keeps the class label fixed (e.g., 7 for Sneaker in the next code snippet) and, by *interpolating* between *latent vectors*, the CVAE generates smooth variations of the same object category, demonstrating that the learned latent space captures continuous intra-class attributes such as *shape* and *style*:

```
x1 = img_sneaker.view(1,-1).to(device)
x2 = img_bag.view(1,-1).to(device)
y1 = torch.tensor([7], device=device) # Sneaker
y2 = torch.tensor([8], device=device) # Bag
mu1,_ = model.encode(x1, y1)
mu2,_ = model.encode(x2, y2)

for i,a in enumerate(np.linspace(0,1,15)):
    z = (1-a)*mu1 + a*mu2
    out = model.decode(z, y1)
```
