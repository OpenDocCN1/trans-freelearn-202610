This minimizes the standard *classification loss* $L_{sup} = -\sum_i y_i \log p_i$ where $p_i$ denotes the **predicted class probability**.

**Pseudo-Labeling:** The SSL model first predicts labels for unlabeled samples. It predicts a *probability distribution* and assigns a *pseudo-label* equal to the most confident class:

$\hat{y} = \arg\max_k p(k|x_u)$

```
weak_logits = model_ssl(X_u)
probs = F.softmax(weak_logits, dim=1)
max_probs, pseudo_labels = probs.max(dim=1)
```

Only high-confidence predictions ($p_{max} \geq \tau$) are retained.

```
mask = max_probs >= 0.7
```

Intuitively, the model says: “I am sufficiently confident that this image belongs to class K, so I will temporarily treat it as a labeled example.”

**Consistency Regularization:** These *pseudo-labels* are treated as temporary targets for a strongly augmented version of the same image. A *stronger augmentation* is created by adding *noise*. *FixMatch* assumes that *small perturbations* should not change the predicted class.

```
noise = torch.randn_like(X_u) * 0.05
strong_logits = model_ssl(X_u + noise)
loss_unsup = F.cross_entropy(strong_logits[mask], pseudo_labels[mask])
```

The model is then encouraged to produce the same prediction for both versions. The **unsupervised consistency loss** is:

$L_u = CE(f(x_u^{strong}), \hat{y})$

where $\hat{y}$ = *pseudo-label* from the weakly augmented image, $x_u^{strong}$ = strongly augmented image, $CE(\cdot)$ = cross-entropy. Intuitively, if an image is classified as “7”, the prediction should remain “7” even after small perturbations.

**Combined Objective:** The final SSL objective combines *supervised* and *unsupervised losses*:

```
loss = loss_sup + lambda_u * loss_unsup
```

Mathematically, $L = L_{sup} + \lambda_u L_{unsup}$ where $\lambda_u$ controls the contribution of unlabeled data. Intuitively, the model acts as its own teacher: confident predictions on unlabeled samples become pseudo-labels, and the network is trained to produce the same prediction even after perturbations, allowing it to learn from large amounts of unlabeled data.

**Performance Evaluation:** Classification accuracy is computed on the test set.

```
preds = model(X).argmax(dim=1)
acc = (preds == y).float().mean()
```
