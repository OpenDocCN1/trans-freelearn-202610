Efficient data loading is implemented using tf.data.Dataset, enabling batching, caching, prefetching, and parallel processing. The preprocessing pipeline loads images and masks, normalizes intensities into [0,1], and resizes them while preserving label integrity using nearest-neighbor interpolation.

The U-Net encoder repeatedly applies convolution, ReLU activation, and max pooling. Pooling progressively reduces spatial resolution while increasing semantic abstraction. Skip connections concatenate encoder and decoder features:

D_l = Concat(U_l, E_l),

preserving fine boundary information. The decoder uses Conv2DTranspose for learnable upsampling and reconstructs detailed segmentation masks. The final 1×1 convolution acts as a pixel-wise classifier, mapping feature channels into class logits:

Z ∈ ℝ^{H×W×C},

followed by softmax probability estimation:

P(c | x, y) = e^{z_c} / Σ_k e^{z_k}
