Similarly, reconstruction with *zero phase* or *random phase* fails to recover meaningful spatial information, as shown in the next figure.

# FFT with the scipy.fft module

`scipy.fft` (introduced in SciPy 1.4.0) is the recommended FFT library because it provides a more consistent API, improved performance, and backward compatibility compared to `numpy.fft` and the older `scipy.fftpack`. To compare the execution speed of different 2D FFT implementations, benchmarking experiments were performed using `np.fft.fft2()`, `scipy.fftpack.fft2()`, and `scipy.fft.fft2()` on the `cameraman.jpg` image.
