# Frequency Domain Filtering

In this chapter, we will explore how images can be filtered in the **frequency domain**, a powerful alternative to spatial filtering that often yields faster and more flexible results for certain tasks. Instead of performing convolution directly in the spatial domain, we will transform images into the frequency domain using the Fourier transform, apply filters, and then transform the results back. We will explore a few filtering techniques (that can be implemented with convolution using kernels, such as box kernels or Gaussian kernels) in the frequency domain, such as **high-pass**, **low-pass**, **band-pass**, and **band-stop** filters, and show how to implement them with Python libraries using practical examples.

Starting with the basic question—what is a filter?—we will then study different types of frequency domain filters and how their behavior affects image components such as noise, edges, and fine textures. Both ideal and more practical filters like **Butterworth** and **Gaussian** will be introduced. You will also learn how to perform these operations with tools such as `scipy.fftpack`, `scikit-image`, and `fourier_gaussian`. Additionally, we will examine how the **signal-to-noise ratio (SNR)** varies with filter parameters like cutoff frequency and use frequency-based filters for tasks like **image denoising** and **periodic noise removal.**

In the latter part of the chapter, we shift toward modern deep learning applications and explore **Fourier Feature Networks (FFNs)**—a class of neural networks that leverage frequency information to overcome smoothness bias and improve function approximation. We will discuss their motivation, architecture, and implementation, including how **Fourier-based positional encodings** help encode high-frequency signals. The chapter concludes with a hands-on FFN implementation using JAX.
