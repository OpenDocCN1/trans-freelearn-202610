$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V,$$

where $Q=XW_Q$: Queries (what we are looking for), $K=XW_K$: Keys (what exists), and $V=XW_V$: Values (information to aggregate). **Transformer-based models represent a fundamental shift in image segmentation—from local convolutional reasoning to global context modeling via attention.** This paradigm originates from the seminal work “Attention Is All You Need” by Ashish Vaswani et al. # Mathematical foundations: Self-attention and tokenized image representation

Transformer-based segmentation models such as DPT, DETR, **SegFormer**, and Mask2Former share a unified theoretical backbone rooted in the transformer paradigm introduced in Attention Is All You Need and extended to vision in **Vision Transformer (ViT)**.

While early works such as **SETR** demonstrated that a *pure ViT* can be used for dense prediction, modern architecture (**DPT, SegFormer, Mask2Former**) significantly improve upon this baseline by addressing its limitations in spatial resolution and efficiency. This section establishes the mathematical and conceptual foundation necessary to understand these models.

**Dense Prediction:** Semantic segmentation is defined as a dense mapping:

$$S:\Omega\subset\mathbb{R}^2\to\mathcal{C},$$

where $\Omega$ is the image domain and $\mathcal{C}$ is the set of semantic classes. The objective is to assign a label to every pixel, requiring global reasoning (scene-level understanding) and local precision (fine boundaries).

**From Images to Tokens: Patch Embedding:** Let the input image be:

$$I\in\mathbb{R}^{H\times W\times 3}$$

The steps that are essential for patch embedding are:

+   - **Patch Partitioning:** The image is divided into non-overlapping patches of size $P\times P$: $N=\frac{HW}{P^2}$. Each patch is flattened:

$$x_i\in\mathbb{R}^{P^2C}.$$

+   - **Linear Projection (Patch Embedding):** Each patch is projected into a latent space:

$$z_i=Ex_i+b,\quad E\in\mathbb{R}^{D\times P^2C}\text{ and }z_i\in\mathbb{R}^{D}.$$

$$Z_0=[z_1,\ldots,z_N]\in\mathbb{R}^{N\times D}$$
