```
from skimage.transform import warp

def translate(xy, t_x, t_y):
    xy = xy.copy() # avoid modifying input in place
    xy[:, 0] -= t_x
    xy[:, 1] -= t_y
    return xy

im = imread('images/monalisa.jpg')
# create a dictionary for translation parameters (map_args)
im_trans = warp(im, translate, map_args={'t_x':-100, 't_y':50}, \
                    order=1)
```

# Applying rotation to an image with warp()

If an image is rotated by angle θ counterclockwise, for all possible pixels in the rotated output image (x, y), the corresponding points in the input image (u, v) can be found with the following equations:

u = x.cosθ − y.sinθ

v = x.sinθ + y.cosθ

Orthogonal geometric transformation is a transformation whose matrix Q has orthogonal unit-length vectors as columns (or rows), satisfying QᵀQ = I, which means it preserves distances, lengths, and angles; examples include rotation (check R(θ)ᵀR(θ) = I) and reflection transformations, e.g., reflection about the x−axis is represented by the matrix R = [1 0; 0 −1].

# With the transformation function

The following code block shows how to use the warp() function to rotate an image, using the rotate() transformation function. Rotation using warp() is done relative to the origin (top left corner) of the input image:

```
def rotate(xy, theta):
    theta = np.deg2rad(theta) # np.pi/180*theta # degree to radian
    x_new = xy[:, 0]*np.cos(theta) - xy[:,1]*np.sin(theta)
    y_new = xy[:, 0]*np.sin(theta) + xy[:,1]*np.cos(theta)
    xy[:, 0], xy[:, 1] = x_new, y_new
    return xy
# create a dictionary for rotation parameters, with angle theta in degrees
im_rot = warp(im, rotate, map_args={'theta':10})
```
