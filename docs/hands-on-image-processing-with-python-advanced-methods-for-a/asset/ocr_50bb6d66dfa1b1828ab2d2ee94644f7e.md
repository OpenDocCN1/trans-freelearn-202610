The KL term prevents weight distributions from becoming excessively complex and acts as a Bayesian regularizer.

**Monte Carlo Prediction:** A single forward pass provides one sampled model. Multiple forward passes approximate the predictive distribution.

```
def forward_mc(model, x, samples=3):
    outputs = []
    for _ in range(samples):
        outputs.append(model(x))
    return torch.stack(outputs).mean(0)
```

Mathematically,

$$p(y|x) \approx \frac{1}{N} \sum_{i=1}^{N} p(y|x,W_i)$$

where $W_i$ are sampled weight realizations. Asking multiple slightly different networks to vote on the prediction generally yields more reliable estimates.

**Comparing Bayesian and Deterministic Networks:** The experiment trains both.

```
bnn = BayesianNN()

```

on the handwritten-digit dataset from sklearn.datasets:

```

using two fully connected layers.

The Bayesian network generally trains more slowly and may achieve slightly lower accuracy because it learns an entire distribution of weights rather than a single optimal solution. Example output:

```
Deterministic NN Accuracy: 0.9694
Bayesian NN Accuracy:      0.8833
```

This reduced accuracy is often offset by improved uncertainty estimation.

**Uncertainty Estimation:** The most important advantage of a Bayesian network is that it quantifies prediction confidence.

```
mean_probs, uncertainty = predict_mc(bnn, X_test[:5])
```

where mean_probs = average prediction and uncertainty = prediction standard deviation.

```
pred = mean_probs[i].argmax().item()
