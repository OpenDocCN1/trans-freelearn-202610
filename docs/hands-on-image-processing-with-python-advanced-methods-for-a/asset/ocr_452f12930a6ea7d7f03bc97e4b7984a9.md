Let’s now understand the code in detail. Here are the steps:

+   - **Pipeline loading:** We use StableDiffusionInpaintPipeline because outpainting is technically a form of inpainting on newly added regions.
+   - **Canvas expansion:** The image is embedded into a larger white canvas with extra space added above and below. These blank areas are where new content will be synthesized.
+   - **Mask creation:** Mask = white where content is preserved (the original image) and Mask = black where new content is generated (the padded regions). This ensures only the new regions are synthesized.
+   - **Diffusion process:** strength=0.3 allows a moderate level of creativity while keeping context intact. guidance_scale=7.5 balances adherence to the text prompt and realism.
+   - **Result:** The model extrapolates the image vertically. The output contains a plausible continuation of the gallery scene, consistent in lighting and perspective.
