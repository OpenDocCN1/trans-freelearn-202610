Given an image $x$, the encoder $E$ maps it to a latent representation $z = E(x)$, where $z$ is significantly smaller than the original image. Diffusion is then applied to $z$ instead of $x$.

After denoising, a decoder $D$ reconstructs the image: $\hat{x} = D(z)$. For example, a $512 \times 512 \times 3$ image contains 786,432 pixel values, whereas the Stable Diffusion VAE compresses it to a latent tensor of size $(4)$ containing only 16,384 values—approximately 48 times smaller. This dramatically reduces memory usage and computational cost.

# Variational autoencoder for latent compression

The Stable Diffusion VAE is loaded using:

```
vae = AutoencoderKL.from_pretrained("stabilityai/sd-vae-ft-mse").to(device)
```

An image is encoded into the latent space and reconstructed.

```
latent = vae.encode(x).latent_dist.sample()
recon = vae.decode(latent).sample
```

The encoder compresses the image into a low-dimensional latent representation, while the decoder reconstructs the image from this representation. The reconstruction closely resembles the original image, as shown in the next figure, demonstrating that the latent space preserves most visually important information despite its much lower dimensionality.

> **Note**
> 
> Mathematically, the encoder predicts a Gaussian latent distribution $q_\phi(z|x) = \mathcal{N}(\mu(x), \sigma^2(x))$, from which a latent sample is drawn using the **reparameterization trick**:
> 
> $z = \mu + \sigma \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$

# Latent space interpolation

Latent interpolation is useful in practice, since it enables smooth transitions between different semantic concepts, allowing controlled generation and revealing the *continuity* and *structure* of the learned latent space before introducing the code.
