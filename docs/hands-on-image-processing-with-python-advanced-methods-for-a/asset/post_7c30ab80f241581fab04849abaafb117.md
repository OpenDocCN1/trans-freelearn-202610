## Image denoising with LPF

Image denoising is a fundamental task in image processing and computer vision, aiming to recover clean images from their noisy counterparts. Noise can degrade an image due to factors such as sensor errors, low-light conditions, or transmission errors. The goal of denoising is to reconstruct the original signal, making it useful for downstream tasks such as object detection, medical imaging, or image enhancement.

The next example demonstrates how to denoise a noisy *moonlanding* image, first by blocking the Fourier high-frequency components using an LPF with FFT.

```python
im = plt.imread('images/moonlanding.png').astype(float)
im_fft = fp.fft2(im)
```

**Filtering in the frequency domain:** The next code block shows how to reject a set of high frequencies and implement an LPF to attenuate noise (which corresponds to high-frequency components) from an image.

```python
# Copy the original spectrum and truncate coefficients.
# Define the fraction of coefficients (in each direction)
keep_fraction = 0.1
im_fft_filtered = im_fft.copy()
# Set r and c to the number of rows and columns of the array.
r, c = im_fft.shape
# Set rows with indices between
# r*keep_fraction and r*(1-keep_fraction) to 0
im_fft_filtered[int(r*keep_fraction):int(r*(1-keep_fraction))]=0
# Similarly with the columns
im_fft_filtered[:, \
                int(c*keep_fraction):int(c*(1-keep_fraction))]=0
```

**Reconstructing the final image:** The next code snippet shows how to reconstruct the image with IFFT from the filtered Fourier coefficients.

```python
# Reconstruct image from filtered spectrum,
# keep only real part for display.
im_denoised = fp.ifft2(im_fft_filtered).real
# plot im, im_denoised and the spectrums im_fft, im_fft_filtered
```

While low-pass filters are useful for smoothing images and removing high-frequency noise, there are cases where we want to do the opposite—highlight fine details and edges by suppressing low-frequency content. This is where high-pass filters come into play, which we’ll explore next.

## High-pass filters (HPFs)

This filter allows only high frequencies from the frequency domain representation of the image (obtained with DFT) and blocks all low frequencies beyond a cut-off value. The image is reconstructed with inverse DFT, and since the high-frequency components correspond to edges, details, noise, and so on, HPFs tend to extract or enhance them. The following table summarizes common HPFs along with their mathematical formulations, characteristics, advantages, and limitations.

| Filter Type | Mathematical Expression | Characteristics | Pros | Cons |
|---|---|---|---|---|
| Ideal HPF (IHPF) | $H(u,v)=\begin{cases}0, & D(u,v)\leq D_0\\1, & D(u,v)>D_0\end{cases}$ | Sharp transition, removes all low frequencies below $D_0$ | Strong filtering effect, simple to implement | Causes ringing artifacts (Gibbs effect) due to the sudden cutoff |
| Butterworth HPF (BHPF) | $H(u,v)=\frac{1}{1+\left(\frac{D_0}{D(u,v)}\right)^{2n}}$ | Smooth transition controlled by order $n$ | Less ringing compared to Ideal HPF, adjustable sharpness | Higher computational cost compared to Ideal HPF |
| Gaussian HPF (GHPF) | $H(u,v)=1-e^{-\frac{D^2(u,v)}{2D_0^2}}$ | Very smooth transition, no ringing artifacts | No ringing artifacts, best for natural image processing | Weaker attenuation of low frequencies compared to IHPF and BHPF |

Let’s start by implementing the GHPF described in the preceding table.

### Ideal, Butterworth, and Gaussian HPFs

The following code snippet implements the **Gaussian High-Pass Filter (GHPF)** in the **frequency domain** (implementations for IHPF and BHPF will be similar and are left as an exercise) and applies it to a brick input image. It removes low-frequency content, keeping sharp edges and fine details, and is used for image sharpening and edge enhancement:

```python
def gaussian(sz, D0):
    h, w = sz
    u, v = get_grid(w, h)
    return 1 - np.exp(-dist(u,v)**2/(2*D0**2))
```

The function `gaussian()` implements GHPF, removes low **frequencies**, and keeps high **frequencies** (sharpening). This avoids ringing artifacts compared to Ideal HPFs. Let’s break it down step by step.

The next code snippet first loads the standard **“brick”** image from `skimage.data`, then applies the **Gaussian High-Pass Filter (GHPF)** with a cut-off frequency, $D_0 = 20$.

```python

f = data.brick()
F, H, G, g = apply_filter(f, gaussian, {'sz':f.shape, 'D0':20})
# plot original noisy image (f) and the output (g) obtained # with GHPF here
```

While high-pass filters are effective for preserving fine details by removing low-frequency components, sometimes we want to isolate and retain only a specific range of frequencies. This brings us to the band-pass filter, which targets frequencies within a defined band—let’s take a closer look.

## Band-pass filters (BPFs)

A band-pass filter allows frequencies within a specific range to pass through while blocking those outside that range, enhancing or suppressing certain image details (useful for feature extraction). The ideal BPF (IBPF) is given by the following:

\[
H_{\text{BPF}}(u,v) = 
\begin{cases}
1, & \text{if } D_1 \le D(u,v) \le D_2\\
0, & \text{otherwise}
\end{cases}
\]

Similarly, we can define the Butterworth and Gaussian BPF (left as an exercise).

### With a DoG kernel

A Difference of Gaussian (DoG) kernel can be used as a BPF to allow the frequencies in a certain band and discard all other frequencies. The following code block shows how the DoG kernel can be used with `fftconvolve()` to implement a BPF:

```python
im = img_as_float(plt.imread('images/tigers.jpeg'))
x = np.linspace(-10, 10, 15)
kernel_1d = np.exp(-0.005*x**2)
kernel_1d /= np.trapz(kernel_1d) # normalize the sum to 1
gauss_kernel1 = kernel_1d[:, np.newaxis] * \
                kernel_1d[np.newaxis, :]
kernel_1d = np.exp(-5*x**2)
kernel_1d /= np.trapz(kernel_1d) # normalize the sum to 1
gauss_kernel2 = kernel_1d[:, np.newaxis] * \
                kernel_1d[np.newaxis, :]
DoGKernel = gauss_kernel1[:, :, np.newaxis] - \
            gauss_kernel2[:, :, np.newaxis]
im_out = signal.fftconvolve(im, DoGKernel, mode='same')
# plot the images im, im_out here
```
