
which measures the compatibility between the image and the supplied class label:

```
class Discriminator(nn.Module):
    def __init__(self):
        super().__init__()
        self.emb = nn.Embedding(NUM_CLASSES, 256)
        self.conv = nn.Sequential(
            nn.utils.spectral_norm(nn.Conv2d(1,64,4,2,1)),
            nn.LeakyReLU(0.2),
            nn.utils.spectral_norm(nn.Conv2d(64,128,4,2,1)),
            nn.LeakyReLU(0.2))
        self.fc = nn.Linear(128*7*7, 256)
        self.out = nn.Linear(256,1)

    def forward(self, x, y):
        h = self.conv(x).view(x.size(0), -1)
        h = self.fc(h)
        proj = (h * self.emb(y)).sum(1, keepdim=True)
        return self.out(h) + proj
```

The discriminator extracts image features h(x) and computes projection proj, corresponding to

D(x,y) = f(h(x)) + h(x)^T e(y)

The first term measures image realism, while the projection term measures agreement between image features and the supplied class label. This mechanism significantly improves class-conditional generation. GAN training is often unstable because of adversarial optimization dynamics, which can cause vanishing/exploding gradients, an overly strong discriminator, oscillatory training, and mode collapse (where the generator produces only a few repetitive samples instead of capturing the full data distribution). To stabilize training, spectral normalization nn.utils.spectral_norm() is applied, which constrains the discriminator's Lipschitz constant and prevents unstable gradient growth.

Once training stability is improved using techniques such as the Exponential Moving Average (EMA), the next step is to evaluate the quality of the generated outputs.

## Exponential Moving Average (EMA) Generator
GAN parameters can fluctuate considerably during training. To obtain smoother and more reliable samples, an EMA generator is maintained.

```
G_ema = Generator().to(device)
G_ema.load_state_dict(G.state_dict())

def ema_update(beta=0.999):
    with torch.no_grad():
        for p, p_ema in zip(G.parameters(), G_ema.parameters()):
            p_ema.data.mul_(beta)
            p_ema.data.add_(p.data*(1-beta))
```

The EMA model is used during evaluation and image generation. The update

$$\theta_{EMA}=\beta\theta_{EMA}+(1-\beta)\theta,$$

where $\beta=0.999$ is implemented with: `p_ema.data.mul_(beta).add_(p.data * (1 - beta))`.

The EMA generator is used for evaluation and sample generation because it typically produces sharper and more stable results.

## Evaluating Image Quality with FID
The model is evaluated using the Fréchet Inception Distance (FID), a standard metric for generative models. Given feature distributions $(\mu_r,\Sigma_r)$ for real images and $(\mu_g,\Sigma_g)$ for generated images, the FID score is:

$$FID=\lVert\mu_r-\mu_g\rVert_2^2+\operatorname{Tr}(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2})$$

Lower FID values indicate that the generated images more closely resemble the real data distribution. The implementation periodically computes FID.

```
from torchmetrics.image.fid import FrechetInceptionDistance
fid_metric = FrechetInceptionDistance(feature=64).to(device)
```

FID measures the similarity between the distributions of real and generated images and is one of the most widely used metrics for generative models.

```
def compute_fid(real, fake):
    fid_metric.reset()
    fid_metric.update(real, real=True)
    fid_metric.update(fake, real=False)
    return fid_metric.compute().item()

fid_score = compute_fid(real_fid, fake_fid)
```

and automatically saves the best-performing model.

Adversarial Training: Training alternates between discriminator and generator updates using the hinge-loss objective. For each minibatch, the generator first produces class-conditioned fake images, which are used to update the discriminator.

```
LATENT_DIM = 128
z = torch.randn(real.size(0), LATENT_DIM, device=device)
fake = G(z,y).detach()
d_loss = (F.relu(1-D(real,y)).mean() + F.relu(1+D(fake,y)).mean())
opt_d.zero_grad(); d_loss.backward()
opt_d.step()
A new batch of fake images is then generated to update the generator.
z = torch.randn(real.size(0), LATENT_DIM, device=device)
fake = G(z,y)
g_loss = -D(fake,y).mean()
```

```
opt_g.zero_grad(); g_loss.backward()
opt_g.step()
ema_update()
```

## Hinge Loss
Instead of the original GAN loss, the implementation uses *hinge loss*:

$$L_D = \mathbb{E}[\max(0,1 - D(x, y))] + \mathbb{E}[\max(0,1 + D(G(z, y), y))]$$

And

$$L_G = -\mathbb{E}[D(G(z, y), y)]$$

(in the above code d_loss and g_loss). Hinge loss generally provides more stable optimization and better sample quality than binary cross-entropy.

After each epoch, the EMA generator is evaluated using the Fréchet Inception Distance (FID), visualizations are generated, and the best-performing model is saved. To improve convergence, cosine annealing learning-rate schedules gradually decrease the learning rate during training.

```
sched_g = torch.optim.lr_scheduler.CosineAnnealingLR(opt_g, EPOCHS)
sched_d = torch.optim.lr_scheduler.CosineAnnealingLR(opt_d, EPOCHS)
```

## Class Transition in the Conditional Latent Space
The following functions demonstrate how a trained cGAN can smoothly transform one Fashion-MNIST category into another by interpolating between their learned class embeddings while keeping the latent vector fixed.

Embedding Interpolation: The function class_transition() generates a sequence of images by interpolating between the embeddings of two classes while keeping the latent vector fixed, thereby visualizing a smooth semantic transition between categories.

```
def class_transition(class_a, class_b, steps=15):
    z = torch.randn(1, LATENT_DIM, device=device)
    emb_a = G.emb(torch.tensor([class_a], device=device))
    emb_b = G.emb(torch.tensor([class_b], device=device))
    imgs = []

    with torch.no_grad():
        for alpha in np.linspace(0, 1, steps):
            emb = ((1 - alpha) * emb_a + alpha * emb_b)
            img = generate_from_embedding(G, z, emb)
            imgs.append(img.cpu())
    return imgs
```

Image Generation from an Interpolated Embedding: The function generate_from_embedding() bypasses the label embedding layer and directly synthesizes an image from a latent vector and an arbitrary (possibly interpolated) class embedding. The interpolated embedding is concatenated with a fixed latent vector and passed through generator, producing an image corresponding to the intermediate semantic state:

```
def generate_from_embedding(G, z, emb):
    x = G.fc(torch.cat([z, emb], dim=1))
    x = x.view(-1, 256, 7, 7)
    return G.net(x)
```

### Transition Sequence
A sequence of intermediate embeddings is generated, producing a smooth visual transition between two Fashion-MNIST categories. For example,

```
images = class_transition(7, 9)
```

creates a gradual transformation from **Sneaker** (class 7) to **Ankle Boot** (class 9), illustrating that the learned conditional embedding space captures meaningful semantic relationships between clothing categories.
