where $s(x,y)$ is the true signal and $n(x,y)$ is additive noise, then linear smoothing reduces the variance of $n(x,y)$ by averaging neighboring pixels. Blurring is therefore commonly used as a *pre-processing step* to remove small, irrelevant details and noise prior to higher-level analysis.

The box filter is the simplest linear smoothing operator, where all weights are equal:

$$h(i,j)=\frac{1}{(2k+1)^2},\qquad \forall(i,j)$$

Thus, the filtered image becomes:

$$g(x,y)=\frac{1}{(2k+1)^2}\sum_{i=-k}^{k}\sum_{j=-k}^{k}f(x-i,y-j)$$

The box filter has the following effect:

+   - Each pixel is replaced by the local **mean**
+   - Reduces random noise via averaging
+   - Causes **edge blurring**, since sharp transitions are smoothed

A more advanced linear filter uses a Gaussian kernel:

$$h(i,j)=\frac{1}{2\pi\sigma^2}\exp\left(-\frac{i^2+j^2}{2\sigma^2}\right)$$

leading to:

$$g(x,y)=\sum_{i=-k}^{k}\sum_{j=-k}^{k}h(i,j)f(x-i,y-j)$$

Here, the weights decrease exponentially with distance, giving more importance to nearby pixels, and produce smoother and more natural blur than the box filter.

Increasing kernel size $(2k+1)$ or Gaussian standard deviation $\sigma$:

+   - Increases smoothing
+   - Reduces noise variance
+   - But also removes fine details
