## Point-wise intensity transformations

A point-wise intensity transformation applies a transfer function *T* to each pixel *f(x, y)* in an image, producing *g(x, y) = T(f(x, y))* or *s = T(r)*, where *r* and *s* are the input and output gray levels. It is a memoryless operation. Each output pixel depends only on its corresponding input value. Though it neither adds nor recovers information, it enhances visual appearance or highlights features, making it a common preprocessing step in image enhancement.

The following figure shows the point processing, as well as the mask/kernel processing (for spatial filters that consider neighborhood pixels also for transformation, as we have already seen):

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_306_0.png)

*Figure 7.1 – Point-wise pixel intensity transformation*

Some popular intensity transformations are Image negatives, color space transformation, log/power-law transformation, contrast stretching, scalar quantization, and thresholding. We already discussed a few of them in *Chapter 1*. Here, we will start with a log transformation on a colored RGB image using PIL and then discuss a few transformations that we have not yet covered.

## Log transform

The log transformation is very useful when we need to compress or stretch a certain range of gray-levels in an image; for example, in order to display the Fourier spectrum (where the DC component value is much higher than the others, so that without the log transform, the other frequency components almost always cannot even be seen). The point transformation function for a log transform is of the following general form:

$s = T(r) = c\log(1+r)$

where c is a constant. Refer to the GitHub notebook for the implementation of the function `plot_hist()` to plot the histogram for the color channels of the input image. Let’s now apply a log transform using the PIL image module’s `point()` function and observe the impact of the transformation on the histograms of different color channels for the given RGB image, using the next lines of code:

```
```python
im = im.point(lambda i: 255*np.log(1+i/255))
im_r, im_g, im_b = im.split()
```
```
