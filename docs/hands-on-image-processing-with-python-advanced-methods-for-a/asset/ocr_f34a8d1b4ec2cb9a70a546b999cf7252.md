# Point transformation on a multi-channel image

For a color image, the point transformation function needs to be applied to each of the color channels separately and independently. We can use the point() function to apply an arbitrary transformation to each pixel (in all bands) for an RGB image, too, as demonstrated in the next code snippet. Let’s dive deeper to understand the code step by step:

+   The first application of the point() method applies the non-linear transformation s = r tan(r) to each pixel value r in the image. It produces highly distorted intensity values across all RGB channels, leading to unnatural and chaotic color shifts.

+   The second one applies a binary thresholding function separately to each channel. It converts the RGB input image into a posterized high-contrast version, where each color channel is either fully on (255) or fully off (0), creating a stark representation of the original colors based on the specified threshold.

+   For the next transform, the image is first converted to grayscale using convert('L'). Then, a lookup table (LUT) is generated by shifting the values of the [0, 1, 2, ..., 255] array to the right by 115 positions, using np.roll(). Then, the .point() method is applied to this LUT to remap the grayscale values. This creates a circular-shifted grayscale image. The pixel intensities are shifted so that darker areas may become brighter, and brighter areas may become darker. It’s as though the intensity values are “wrapped around,” shifting the visual appearance.

+   The last point transformation uses the ImagingCore.point_transform() method, which applies a linear transformation to each pixel, r, from the input image, which can be expressed in the form s = a × r + b, to obtain the output pixel s, with scale a and offset b as parameters. Here, the image is first copied (with the copy() method), and its mode is changed to floating point mode, using the .convert('F') method. Then, the point_transform() method is applied, and it linearly scales the pixel values by a factor of 3 and then shifts them by -100. This results in a significant brightening of the image, as every pixel is amplified and offset by a constant value.
