Mask2Former introduces a paradigm shift: instead of labeling pixels → it predicts objects as masks, instead of local decisions → it performs global reasoning and instead of separate models → it provides a unified framework. Mask2Former does not ask “what is this pixel?”; instead, it asks “what objects exist in the scene, and where are their masks?” The following table shows the evolution of deep segmentation models:

| Model Type | Key Idea | Limitation Addressed |
|---|---|---|
| SETR | Pure ViT | Lacks spatial detail |
| DPT | Multi-scale fusion | Improves localization |
| DETR | Query-based reasoning | Object-centric modeling |
| SegFormer | Hierarchical transformer | Efficiency + scalability |
| Mask2Former | Unified segmentation | Generalizes all tasks |

# Segmenting images from cityscape and ADE20 Dataset with pretrained OneFormer

Recent advances in transformer-based segmentation have led to unified architectures capable of handling multiple segmentation tasks, semantic, instance, and panoptic, within a single model. One such model is OneFormer, which extends the idea of mask classification (as in Mask2Former) by introducing task-conditioned segmentation, enabling a single network to generalize across datasets and segmentation paradigms. OneFormer learns “what to segment” (task) and “how to segment” (mask prediction) simultaneously. This allows cross-dataset generalization, multi-task learning and reduced model redundancy.
