The next code snippet demonstrates face morphing by gradually transforming a younger face image (im1) into an older one (im2) through iterative variation of α from 0 to 1 using np.linspace(). At each step, the blended image is visualized with plt.imshow().

```
im1 = mpimg.imread("images/me_young.jpg")
im2 = mpimg.imread("images/me_now.jpg")
i = 1
for alpha in np.linspace(0,1,18):
    plt.subplot(3,6,i), plt.imshow((1-alpha)*im1 + alpha*im2)
    i += 1
```

# Removing illumination pattern using image division

Dividing one image by another can be used to enhance certain features of the image. Consider the following example with np.divide(); you can use the cv2.divide() function from OpenCV-Python too (try on your own). As demonstrated with the next code snippet, the division operation removes the illumination pattern from the input image.

```
img1 = cv2.imread('images/board_illum_pat.png', 0)
img2 = cv2.imread('images/pattern.png', 0)
out = np.divide(img1.astype(float), img2.astype(float)+0.001) #no div by 0
out = out / (out.max() + epsilon) # 0-1 normalization
out = (255*out).astype('uint8')  # for visualization: scale in [0,255]
plt.imshow(np.hstack((img1, img2, out))), plt.axis('off')
```
