# Note

The block size of `(4, 3)` assumes the input image dimensions are divisible by 4 and 3, respectively.

If this condition is violated, `downscale_local_mean()` pads the image (with `cval=0`, i.e., zero values by default), which introduces black borders. You can manually pad the image or adjust the block size accordingly if needed for broader compatibility.
