scikit-image provides these three main blob detection functions based on different scale-space techniques:

+   - blob_log(): The LoG filter enhances circular blob-like regions by applying a second-order derivative (Laplacian) after Gaussian smoothing. It provides accurate results but is computationally expensive.
+   - blob_dog(): The DoG, a fast approximation of LoG, implemented by subtracting two images blurred with different Gaussian kernels. It's less precise but much faster and more effective for most practical cases (used in SIFT).
+   - blob_doh(): The DoH is better for detecting corner-like blobs. This method uses the Hessian matrix of second-order partial derivatives to detect blob-like structures, especially useful in detecting corner-shaped blobs.

The following code compares all three methods:

```
from skimage.feature import blob_dog, blob_log, blob_doh
image = plt.imread('images/sunflowers.jpg')
image_gray = 1-rgb2gray(image) # detect white blobs
blobs_log = blob_log(image_gray, max_sigma=30, min_sigma=5, \
                    num_sigma=7, threshold=0.175)
# Compute radii in the 3rd column.
blobs_log[:, 2] = blobs_log[:, 2] * np.sqrt(2)
blobs_dog = blob_dog(image_gray, max_sigma=30, min_sigma=5, threshold=0.1)
blobs_dog[:, 2] = blobs_dog[:, 2] * np.sqrt(2)
blobs_doh = blob_doh(image_gray, max_sigma=30, min_sigma=5, threshold=0.01)
blobs_list = [blobs_log, blobs_dog, blobs_doh]
colors = ['blue', 'magenta', 'red']
titles = ['Laplacian of Gaussian', 'Difference of Gaussian', \
          'Determinant of Hessian']
sequence = zip(blobs_list, colors, titles)
fig, axes = plt.subplots(1, 3, figsize=(10, 3), sharex=True, sharey=True)
ax = axes.ravel()
for idx, (blobs, color, title) in enumerate(sequence):
    ax[idx].set_title(title)
    ax[idx].imshow(image)
    for blob in blobs:
        y, x, r = blob
        c = plt.Circle((x, y), r, color=color, linewidth=2, fill=False)
        ax[idx].add_patch(c)
    ax[idx].set_axis_off()
```
