# Vision–language large language model integration (LLaVA via Ollama)

Next, send the segmented object (image crop) to a vision–language model like LLaVA via an API call (`requests.post`), where the image is encoded and paired with a text prompt. The model then performs multimodal inference, i.e., jointly processes visual features and language, to generate a natural-language description of the segmented object. Mathematically,

$$\mathrm{Description}=g_{\phi}(M\odot I),$$

Where $g_{\phi}$ is a multimodal large language model (LLM).

Hence, SAM + LLaVA = “Segment → Understand → Describe” pipeline.

Prerequisite: Install and run Ollama (ollama serve) with the LLaVA model pulled, along with required Python libraries (e.g., requests).

```
```python
# ollama serve
# ollama pull llava
# Send to Ollama (LLaVA)
with open("images/object_crop.jpg", "rb") as f:
    img_base64 = base64.b64encode(f.read()).decode("utf-8")
response = requests.post("http://localhost:11434/api/generate",
    json={"model": "llava",
          "prompt": "Describe this segmented object in detail.",
          "images": [img_base64],
          "stream": False})
