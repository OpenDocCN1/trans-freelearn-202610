
The KL term prevents weight distributions from becoming excessively complex and acts as a Bayesian regularizer.

**Monte Carlo Prediction:** A single forward pass provides one sampled model. Multiple forward passes approximate the predictive distribution.

```
def forward_mc(model, x, samples=3):
    outputs = []
    for _ in range(samples):
        outputs.append(model(x))
    return torch.stack(outputs).mean(0)
```

Mathematically,

$$p(y|x) \approx \frac{1}{N} \sum_{i=1}^{N} p(y|x,W_i)$$

where $W_i$ are sampled weight realizations. Asking multiple slightly different networks to vote on the prediction generally yields more reliable estimates.

```

```

```

```

where mean_probs = average prediction and uncertainty = prediction standard deviation.

Although full Bayesian neural networks provide principled uncertainty estimation by learning distributions over weights, their computational cost motivates efficient approximations such as Monte Carlo Dropout, which we shall explore next.

## MC dropout: A practical Bayesian approximation

True Bayesian neural networks can be computationally expensive. An elegant approximation is Monte Carlo Dropout, proposed by Yarin Gal and colleagues. The key idea is to keep dropout active during inference:

```
class MCDropoutNN(nn.Module):

    def __init__(self):
        ...
        self.dropout = nn.Dropout(0.3)

    def forward(self, x):
        x = self.dropout(x)
        return self.fc2(x)
```

and perform multiple stochastic forward passes:

```
model.train()    # keep dropout active
for _ in range(20):
    logits = model(x)
```

Each pass effectively samples a different network.

**Monte Carlo Dropout Prediction:** The function mc_dropout_predict() performs multiple stochastic forward passes with dropout enabled (for complete code refer to GitHub), then returns the average class probabilities (mean_probs) as the prediction and the variability (uncertainty) as a measure of the model's confidence.

```
mean_probs, uncertainty = mc_dropout_predict(mc_model, X_test)
```

The predictive mean is $\bar{p} = \frac{1}{N} \sum_{i=1}^{N} p_i$ and uncertainty is estimated from the sample variance:

$\sigma^2 = \frac{1}{N} \sum_{i=1}^{N} (p_i - \bar{p})^2$

This produces uncertainty estimates without explicitly learning weight distributions.


The *Bayesian neural network* provides the most principled treatment of uncertainty by learning *probability distributions over weights*, whereas *MC Dropout* approximates *Bayesian inference* through *stochastic dropout sampling*. Although deterministic networks often achieve slightly higher classification accuracy, *Bayesian* approaches provide valuable *confidence estimates* that can reveal ambiguous, noisy, or out-of-distribution inputs.

In summary, Bayesian neural networks transform image classification from predicting a single answer to predicting a distribution of plausible answers, enabling uncertainty-aware decision making. MC Dropout offers a practical approximation that retains many Bayesian benefits while requiring only minor modifications to a standard neural network.

## Image classification with semi-supervised learning

In many real-world applications, obtaining large quantities of labeled images is expensive and time-consuming, whereas unlabeled images are abundant. **Semi-Supervised Learning (SSL)** addresses this challenge by learning from a small labeled dataset together with a much larger unlabeled dataset. The central idea is that the unlabeled samples contain valuable information about the underlying data distribution that can improve classification performance.

Intuitively, SSL mimics human learning: a student may learn from a few annotated examples and then infer labels for many additional examples based on similarity and consistency.

**FixMatch – Learning from Unlabeled Images:** FixMatch is a *semi-supervised learning* method that iteratively improves a model by repeatedly generating pseudo-labels from weakly augmented unlabeled images using the current network, but only when predictions are highly confident. These pseudo-labels are then used to train the model on strongly augmented versions of the same images, enforcing consistency under perturbations. Intuitively, it is a self-reinforcing loop where the model learns from “reliable guesses first” and gradually refines both its predictions and its use of unlabeled data during standard end-to-end training.

The next python demonstration implements a simplified version of FixMatch, one of the most influential SSL algorithms (for complete code refer to GitHub). The model is first trained on a small, labeled subset and then generates **pseudo-labels** for *unlabeled* images. Only 10% of the training samples are treated as labeled:

```
num_labeled = int(0.1 * len(X_train))
X_l = torch.tensor(X_train[:num_labeled])
y_l = torch.tensor(y_train[:num_labeled])
X_u = torch.tensor(X_train[num_labeled:])
```

Here **Labeled set:** $(X_l, y_l)$ and **Unlabeled set:** $X_u$.

**Classification Network:** A simple fully connected neural network is used:

```
class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(64,128)
        self.fc2 = nn.Linear(128,10)

    def forward(self,x):
        return self.fc2(F.relu(self.fc1(x)))
```

The network maps the 64-dimensional digit vector to one of 10 digit classes.

**Supervised Learning Baseline:** The baseline model is trained using only the labeled subset.

```
logits = model_sup(X_l)
loss = F.cross_entropy(logits, y_l)
```

This minimizes the standard *classification loss* $L_{sup} = -\sum_i y_i \log p_i$ where $p_i$ denotes the **predicted class probability**.

**Pseudo-Labeling:** The SSL model first predicts labels for unlabeled samples. It predicts a *probability distribution* and assigns a *pseudo-label* equal to the most confident class:

$\hat{y} = \arg\max_k p(k|x_u)$

```
weak_logits = model_ssl(X_u)
probs = F.softmax(weak_logits, dim=1)
max_probs, pseudo_labels = probs.max(dim=1)
```

Only high-confidence predictions ($p_{max} \geq \tau$) are retained.

```
mask = max_probs >= 0.7
```

Intuitively, the model says: “I am sufficiently confident that this image belongs to class K, so I will temporarily treat it as a labeled example.”

**Consistency Regularization:** These *pseudo-labels* are treated as temporary targets for a strongly augmented version of the same image. A *stronger augmentation* is created by adding *noise*. *FixMatch* assumes that *small perturbations* should not change the predicted class.

```
noise = torch.randn_like(X_u) * 0.05
strong_logits = model_ssl(X_u + noise)
loss_unsup = F.cross_entropy(strong_logits[mask], pseudo_labels[mask])
```

The model is then encouraged to produce the same prediction for both versions. The **unsupervised consistency loss** is:

$L_u = CE(f(x_u^{strong}), \hat{y})$

where $\hat{y}$ = *pseudo-label* from the weakly augmented image, $x_u^{strong}$ = strongly augmented image, $CE(\cdot)$ = cross-entropy. Intuitively, if an image is classified as “7”, the prediction should remain “7” even after small perturbations.

**Combined Objective:** The final SSL objective combines *supervised* and *unsupervised losses*:

```
loss = loss_sup + lambda_u * loss_unsup
```

Mathematically, $L = L_{sup} + \lambda_u L_{unsup}$ where $\lambda_u$ controls the contribution of unlabeled data. Intuitively, the model acts as its own teacher: confident predictions on unlabeled samples become pseudo-labels, and the network is trained to produce the same prediction even after perturbations, allowing it to learn from large amounts of unlabeled data.

**Performance Evaluation:** Classification accuracy is computed on the test set.

```
preds = model(X).argmax(dim=1)
acc = (preds == y).float().mean()
```
