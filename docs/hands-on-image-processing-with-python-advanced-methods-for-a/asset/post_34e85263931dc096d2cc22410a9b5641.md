## YOLO (YOLOv8 / YOLOv11): A single-stage formulation

Modern instance segmentation architectures such as **YOLO-based segmentation models** adopt a **single-stage formulation, enabling real-time inference** while maintaining competitive accuracy. In this section, we explore **YOLO-based instance segmentation** using the **Ultralytics YOLO11 segmentation model** and examine its theoretical foundations and practical implementation. Later, we shall contrast its design choices and performance characteristics with the **classical two-stage Mask R-CNN architecture**.

- **From detection to segmentation: YOLO Perspective:** Traditional YOLO (You Only Look Once), introduced by Joseph Redmon, was originally designed for object detection:

  $$f_{\theta}(I) \rightarrow \{(b_i, c_i, s_i)\}_{i=1}^{N},$$

  where $b_i$: bounding box, $c_i$: class and $s_i$: confidence.

- **Extension to instance segmentation:** YOLO segmentation models extend this formulation to include pixel-level masks:

  $$f_{\theta}(I) \rightarrow \{(b_i, c_i, s_i, M_i)\}_{i=1}^{N},$$

  where $M_i \in [0,1]^{H\times W}$ is the predicted mask.

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_530_0.png)

*Figure 10.26 – Instance segmentation with the 11th generation Nano variant of the YOLO segmentation model*

**Why is YOLO fast?** YOLO avoids the **Region Proposal Network (RPN)** and Per-ROI computation. Instead, it performs:

Single Forward Pass ⇒ All Predictions

This leads to O(1) inference per image and highly optimized GPU usage.

**Practical observations:** Masks may be slightly less precise than Mask R-CNN, but they are excellent for real-time applications (Autonomous driving, Video analytics, Surveillance). Unlike Mask R-CNN, YOLO does **not predict full-resolution masks directly**. Instead, it uses a low-rank mask approximation. This reduces computational complexity:

O(HW) → O(K + HW), where K ≪ HW.

YOLO-based instance segmentation represents a major shift toward unified architectures, real-time performance and scalable deployment. Together with Mask R-CNN, it completes the spectrum of instance segmentation techniques, where Mask R-CNN → **Accuracy-focused** and YOLO → **Speed-focused**. Instance segmentation bridges the gap between detection and segmentation by providing object-level understanding and pixel-level precision.

Mask R-CNN remains a foundational method due to its elegant formulation and strong performance, while modern YOLO-based methods push toward real-time applications.

## Transformer-based segmentation

Transformer architectures have fundamentally reshaped image segmentation by replacing convolutional inductive biases with **global self-attention mechanisms**. Unlike CNN-based segmentation, which relies on local receptive fields, transformer-based models explicitly model **long-range dependencies**, enabling superior scene understanding.

Given an input image \(I \in \mathbb{R}^{H\times W\times 3}\), transformer-based segmentation models aim to learn a mapping:

$$f_\theta: I \to \mathcal{Y},\quad y \in \mathbb{Z}^{H\times W}$$

where each pixel is assigned a semantic or instance label. At the core of all transformer models lies the **scaled dot-product attention:**

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V,$$

where $Q=XW_Q$: Queries (what we are looking for), $K=XW_K$: Keys (what exists), and $V=XW_V$: Values (information to aggregate). **Transformer-based models represent a fundamental shift in image segmentation—from local convolutional reasoning to global context modeling via attention.** This paradigm originates from the seminal work “Attention Is All You Need” by Ashish Vaswani et al. (2017), and was extended to vision by Alexey Dosovitskiy et al. (2021).

### Mathematical foundations: Self-attention and tokenized image representation

Transformer-based segmentation models such as DPT, DETR, **SegFormer**, and Mask2Former share a unified theoretical backbone rooted in the transformer paradigm introduced in Attention Is All You Need and extended to vision in **Vision Transformer (ViT)**.

While early works such as **SETR** demonstrated that a *pure ViT* can be used for dense prediction, modern architectures (**DPT, SegFormer, Mask2Former**) significantly improve upon this baseline by addressing its limitations in spatial resolution and efficiency. This section establishes the mathematical and conceptual foundation necessary to understand these models.

**Dense Prediction:** Semantic segmentation is defined as a dense mapping:

$$S:\Omega\subset\mathbb{R}^2\to\mathcal{C},$$

where $\Omega$ is the image domain and $\mathcal{C}$ is the set of semantic classes. The objective is to assign a label to every pixel, requiring global reasoning (scene-level understanding) and local precision (fine boundaries).

**From Images to Tokens: Patch Embedding:** Let the input image be:

$$I\in\mathbb{R}^{H\times W\times 3}$$

The steps that are essential for patch embedding are:

- **Patch Partitioning:** The image is divided into non-overlapping patches of size $P\times P$: $N=\frac{HW}{P^2}$. Each patch is flattened:

  $$x_i\in\mathbb{R}^{P^2C}.$$

- **Linear Projection (Patch Embedding):** Each patch is projected into a latent space:

  $$z_i=Ex_i+b,\quad E\in\mathbb{R}^{D\times P^2C}\text{ and }z_i\in\mathbb{R}^{D}.$$

  Stacking all tokens:

  $$Z_0=[z_1,\ldots,z_N]\in\mathbb{R}^{N\times D}$$

- **Equivalent Convolution View:** This is equivalent to: Conv2D($P,P$), which is mathematically identical to linear projection per patch, revealing that transformers begin by converting images into token sequences: Patch → token, Image → sequence, Transformer → global reasoning engine. Unlike CNNs, which operate locally (relying on convolutional inductive bias: locality and translation equivariance), transformers allow all patches to interact directly (via global context modeling).

- **Positional encoding:** Transformers lack inherent spatial awareness; to make them permutation invariant, positional information needs to be injected:

  $$Z_0 \leftarrow Z_0 + E_{pos},\quad E_{pos} \in \mathbb{R}^{N\times D}$$

  Design choices vary: e.g., *ViT* / *DPT* has *learnable embeddings*, *Swin* has *relative positional bias*, whereas *SegFormer* removes explicit *positional encoding*. The position tells the model: “Where is this patch located in the image?” Without it, spatial structure is lost. Without positional encoding, a pixel at the **top-left** is indistinguishable from one at the **bottom-right**. Positional encoding restores **geometry**, enabling object boundaries, spatial relationships and scene layout understanding.

- **Self-Attention (Core Mechanism):** The fundamental operation is:

  $$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

  This equation tells us: Each token decides how much it should “*pay attention*” to every other token. Think of each token as a patch of the image.

  From: $Z \in \mathbb{R}^{N\times D}$, we compute:

  $$Q=ZW_Q,\quad K=ZW_K,\quad V=ZW_V.$$

  The next table explains the meaning Q, K and V:

  | Symbol | Meaning | Intuition |
  |---|---|---|
  | Q (Query) | “What am I looking for?” | Each token asks a question |
  | K (Key) | “What do I contain?” | Each token describes itself |
  | V (Value) | “What information do I provide?” | Actual content |

  *Table 10.2: Query–Key–Value in a transformer*

This enables global interaction, where each patch queries all other patches, measures similarity and aggregates relevant information. Thus, every pixel can “see” the entire image. It can be thought of as a conversation between pixels, each patch asks a question (**Query**), compares with all other patches (**Key**) and gathers relevant information (**Value**). This enables **context-aware segmentation**, unlike CNNs that rely on local neighborhoods.

Next figure illustrates the **Scaled Dot-Product Attention mechanism**, where input tokens are transformed into **Query (Q), Key (K), and Value (V)** vectors. It shows how similarity scores $(QK^T)$ are computed, scaled, normalized via softmax, and used to produce a **weighted sum of values**, enabling each token to attend to the most relevant parts of the input.
