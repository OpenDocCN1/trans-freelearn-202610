Thus, the dirty image is interpreted as a superposition of shifted PSFs. CLEAN is a greedy algorithm that finds the largest remaining PSF-shaped contribution, subtracts a scaled copy of the PSF, and records the corresponding delta (clean component).

# Högbom CLEAN

Let $r^{(0)} = g$ be the initial residual (the dirty image). At iteration $t$:

+   - Find the peak (maximum absolute) residual:
+   
+     $(p_t, q_t) = \arg\max_{(i,j)} |r^{(t)}[i,j]|$
+   
+     Let $s_t = r^{(t)}[p_t, q_t]$ be the signed peak value.
+   - Add a scaled delta component to the clean-component map $c$:
+   
+     $c[p_t, q_t] \leftarrow c[p_t, q_t] + \gamma\, s_t$
+   
+     where $0 < \gamma \le 1$ is the loop gain.
+   - Subtract the PSF, centered at $(p_t, q_t)$, scaled by $\gamma s_t$, from the residual:
+   
+     $r^{(t+1)} \leftarrow r^{(t)} - \gamma s_t \cdot \text{shift}(h, p_t, q_t)$

Iterate until either the peak falls below a threshold $\tau$ (typically related to the noise level) or a maximum number of iterations is reached. After termination, compute the restored image by convolving the clean components $c$ with a smooth restoring beam $b$ (often a Gaussian approximating the main lobe of the true PSF), and add the final residual:

$\hat{f} = (c * b) + r^{(T)}$

This two-term combination preserves the clean, point-like structure (from $c * b$) and the low-amplitude extended flux left in the residual.

Here’s why CLEAN works:

+   - **Greedy matching to PSF shape:** CLEAN explicitly matches and removes PSF-shaped patterns, reducing sidelobe confusion that can hide weaker sources.
+   - **Loop gain:** $\gamma$ controls stability. Using $\gamma < 1$ prevents over-subtraction and stabilizes the algorithm in noise; small $\gamma$ leads to slower but safer convergence.
+   - **Restoring beam:** It replaces the often complicated (and possibly noisy) PSF main lobe with a smooth beam to produce visually interpretable images and avoid amplifying high-frequency noise.
+   - **Sparsity prior:** CLEAN effectively imposes a sparsity prior (point sources) by constructing image from discrete deltas; this is why CLEAN performs well on sparse astronomical scenes but less well on smoothly varying extended objects.

Mathematically, **CLEAN** is closely related to matching pursuit and greedy sparse approximation (we shall explain in the next section): at each step, CLEAN selects the dictionary atom (a shifted PSF) that best matches the residual and subtracts it with a coefficient $\gamma s_t$.
