## Displaying an image with matplotlib.pylab

The imshow() function from matplotlib.pylab is widely used to display images represented as NumPy ndarray objects. It supports optional arguments such as cmap for colormaps, interpolation for controlling pixel interpolation, and aspect for adjusting the image aspect ratio. The command axis('off') removes axis ticks and labels for cleaner visualization.

Interpolation methods determine how pixel values are estimated when image pixels do not align exactly with display pixels, which is especially important for small or resized images. Common interpolation methods include 'nearest', 'bilinear', 'bicubic', 'gaussian', and 'lanczos' (you will learn more about them in Chapters 2 and 3). The next code snippet demonstrates the effect of different interpolation methods by displaying the same image with multiple interpolation options using imshow(), plt.subplots(), and plt.tight_layout().

## Colormaps

A colormap (cmap) defines a mapping from scalar data values to colors, enabling visualization of intensity variations in images, particularly useful for grayscale or single-channel images where pixel values are represented as colors. In practice, a 3-channel image is first converted to a 2D grayscale representation (e.g., by averaging across channels using np.mean(..., axis=-1)), and then different colormaps are applied to visualize intensity distributions, often accompanied by a colorbar (plt.colorbar()) that indicates the mapping between color values and pixel intensities.

```
im = plt.imread('images/cameraman.jpg')
im_gray = np.mean(im, axis=-1)
i = 1
for cmap in ['viridis', 'inferno', 'coolwarm', 'Spectral', 'jet', \
    'nipy_spectral', 'hot', 'Blues']:
    plt.subplot(1,8,i), plt.imshow(im_gray, cmap=cmap, aspect='auto')
    plt.axis('off')
    i += 1
plt.colorbar(label='Intensity')
plt.tight_layout(); plt.show()
```

## Reading, saving and displaying an image using scikit-image

The scikit-image library is a collection of algorithms for image processing. While it primarily focuses on image processing tasks rather than I/O operations, you can use other libraries such as Imageio or Matplotlib in conjunction with scikit-image for reading, saving, and displaying images. Here is the example code block:

```
```python
from skimage.io import imread, imread_collection, imshow_collection
from skimage import color


def min_max_normalize(im, low=0, high=255):
    """Normalizes the pixel values of the image im to the specified
    [low, high] range using min-max scaling"""
    return ((high-low)*(im-im.min())/(im.max()-im.min())).astype(np.uint8)

im = imread("images/parrot.png")  # read image, provide the correct path
print(im.shape, im.dtype, type(im), im.max(), im.min())
# (362, 486, 3) uint8 <class 'numpy.ndarray'>
im_gray = imread("images/parrot.png", as_gray=True)  # read grayscale image
im_gray = min_max_normalize(im_gray)
im_gray = color.gray2rgb(im_gray)
```
```

```
hsv = color.rgb2hsv(im) # from RGB to HSV color space
hsv[:, :, 1] = 0.5 # change the saturation
im_hsv = min_max_normalize(color.hsv2rgb(hsv)) # from HSV back to RGB
print(im_hsv.dtype)
# uint8
imsave('images/parrot_hsv.png', im_hsv)
im_hsv = imread("images/parrot_hsv.png")
plt.imshow(np.hstack((im, im_gray, im_hsv))); plt.axis('off'); plt.show()
```

In the above code, the function imread() from skimage.io reads images as NumPy ndarray objects. With the default as_gray=False, images are loaded as uint8 arrays with pixel values in [0,255], whereas as_gray=True loads grayscale images as float64 arrays with values in [0,1]. The custom min_max_normalize() function performs min-max normalization to scale image intensities to a specified range, typically [0,255].

The grayscale image is converted to a three-channel image using gray2rgb(), and RGB-to-HSV color conversion is performed using skimage.color.rgb2hsv().

Next, the saturation channel is modified while preserving hue and value, demonstrating how saturation controls color vividness: high saturation produces rich colors, low saturation produces muted colors, and zero saturation yields grayscale images. The modified HSV image is converted back to RGB using hsv2rgb(), saved with skimage.io.imsave(), and visualized side-by-side using np.hstack() and plt.imshow(). The following figure shows the output of the code snippet, the input image, the grayscale image, and new image with changed saturation side-by-side:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_47_0.png)

Figure 1.8 – Displaying an image in RGB, grayscale, and HSV color space with skimage

Note: The HSV channel representations differ between skimage.color.rgb2hsv() and OpenCV's cv2.cvtColor(..., cv2.COLOR_RGB2HSV) primarily in their scaling conventions: in scikit-image, all three channels—Hue, Saturation, and Value—are represented as normalized floating-point values in the range [0.0, 1.0], whereas OpenCV uses integer-based scaling where Hue is mapped to [0, 179] (corresponding to 0–360° but stored at half resolution for 8-bit representation), and both Saturation and Value are stored in the range [0, 255]. Thus, scikit-image adopts a unit-interval continuous representation, while OpenCV uses an 8-bit integer representation with different scaling factors across channels.
