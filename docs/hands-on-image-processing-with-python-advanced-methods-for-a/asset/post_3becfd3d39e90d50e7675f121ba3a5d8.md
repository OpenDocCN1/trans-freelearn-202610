## Adding a watermark to an image

A watermark is a recognizable image or pattern that is superimposed onto another image, typically for branding or copyright purposes. Watermarks are often semi-transparent and placed in a corner or across the center of an image to discourage unauthorized use or to identify the creator of the image.

The next code snippet adds the Packt logo image to the parrot cover image, using the following steps:

+   1. First, both the original input (cover) and watermark images are converted to RGBA mode.
+   2. The watermark image is resized and pasted on a blank image and, subsequently, a semi-transparent alpha layer (with α = 128).
+   3. Finally, the alpha_composite() function is used to combine the alpha channels of the original and the watermark images. The watermarked output produced is shown in the next figure.

Now, refer to the following code snippet:

```
cover_image = Image.open('images/parrot.jpg').convert('RGBA')
watermark = Image.open('images/packt.png')\
    .resize((100, 50))\
.convert('RGBA')
layer = Image.new('RGBA', cover_image.size, (0, 0, 0, 0))
layer.paste(watermark, (325, 225))

# Create a copy of the layer
layer2 = layer.copy()
# Put alpha on the copy
layer2.putalpha(128)
# merge layers with mask
layer.paste(layer2, layer)

watermarked_image = Image.alpha_composite(cover_image, layer)
watermarked_image.convert('RGB')
```

## Blending two images with a mask

The next code snippet blends a butterfly image (im) with its own inverted version (im_inv) using a (horizontal) intensity gradient transparency mask (grad_mask), with the Image.composite() method. Here are the key steps.

First, a 1D gradient array (grad_mask) is created with np.linspace(), and the np.tile(grad_mask, (h, 1)) function is used to repeat the 1D gradient array across rows to create a 2D horizontal intensity gradient mask, where the pixel values range from 0 (fully transparent) to 255 (fully opaque).

The Image.composite(im, im_inv, grad_mask) method is used to blend im and im_inv based on the transparency mask, grad_mask, making one side more like the original and the other more like the inverted version.

The **Hard Light** blend mode applies the **Multiply** blend mode to darker pixels and the **Screen** blend mode to lighter pixels. The blend equation is as follows:

```
$$C_{out}=\begin{cases}2C_{base}C_{blend}, & C_{blend}\le 0.5\\1-2(1-C_{base})(1-C_{blend}), & C_{blend}>0.5\end{cases}$$
```

If the blend pixel is dark ($C_{blend}\le 0.5$), the **Multiply** mode is applied, resulting in darker tones. Otherwise, the **Screen** mode is applied, resulting in brighter tones. The effect is that it increases contrast—bright areas become more intense, and dark areas deepen.

The **Soft Light** blend mode provides a subtle directional lighting effect, making dark areas darker and light areas lighter, but with a smoother transition. The blend equation is as follows:

```
$$C_{out}=\begin{cases}C_{base}-(1-C_{base})C_{base}(1-2C_{blend}), & C_{blend}\le 0.5\\C_{base}+D(C_{base})(2C_{blend}-1), & C_{blend}>0.5\end{cases}$$
```

where

```
$$D(C_{base})=\begin{cases}\frac{16C_{base}^{2}+3C_{base}}{19}, & C_{base}\le 0.25\\\sqrt{C_{base}}, & C_{base}>0.25\end{cases}$$
```

If the blend pixel is dark ($C_{blend}\le 0.5$), it burns the shadows, making them darker. Otherwise, it dodges highlights, making them brighter. The effect is similar to **Hard Light** but with smoother, less intense transitions.

The **Overlay** blend mode is similar to **Hard Light**, but instead of the blend image determining the effect, the base image controls it. The blend equation is as follows:

```
$$C_{out}=\begin{cases}2C_{base}C_{blend}, & C_{base}\le 0.5\\1-2(1-C_{base})(1-C_{blend}), & C_{base}>0.5\end{cases}$$
```

If the base pixel is dark ($C_{blend}\le 0.5$), it darkens the image using **Multiply** blending. Otherwise, it lightens the image using **Screen** blending. The effect is that the contrast increases, but the base image controls the effect intensity. The next figure summarizes the differences between the algorithms:

| Blend Mode | Dark Pixels Behavior | Light Pixels Behavior | Contrast Effect |
|---|---|---|---|
| Hard Light | Darker (Multiply) | Lighter (Screen) | High contrast |
| Soft Light | Subtly darker | Subtly lighter | Soft transitions |
| Overlay | Darker (Multiply) | Lighter (Screen) | Strong contrast, but base-driven |

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_134_0.png)

*Figure 2.44 – Comparing blend mode algorithms*

These blending techniques are commonly used in photo editing for dynamic lighting adjustments and artistic effects.

## With blend_modes

The next code snippet demonstrates blending two images with the soft_light algorithm at different opacities using the blend_modes library. The imgviz library is used to add an alpha channel to an image. The blend_modes.soft_light() method applies soft light blending, controlled by the opacity (α) parameter. For each pixel, the soft_light blend formula is applied as follows:

C_out = (1 − α) · C_base + α · F_soft−light(C_base, C_blend)

Here, $F_{soft-light}$ is the soft_light blending function. The foreground image (im2) is softly blended onto the background (im1) with increasing opacity, creating subtle lighting effects. A higher opacity means the foreground contributes more to the final blend, while a lower opacity makes it more transparent:

```
import blend_modes, imgviz
i = 1
plt.figure(figsize=(15,5))
for opacity in [0.3, 0.5, 0.8]:
    blended_img_float = blend_modes.soft_light(
        imgviz.rgb2rgba(np.array(im1)).astype(float),
        imgviz.rgb2rgba(np.array(im2)).astype(float),
        opacity)
    plt.subplot(1,3,i), plt.imshow(np.uint8(blended_img_float))
    plt.axis('off'), plt.title(f'opacity={opacity}', size=20)
    i += 1
plt.suptitle('Blending with soft-light algorithm with blend_modes', \
    size=25)
```
