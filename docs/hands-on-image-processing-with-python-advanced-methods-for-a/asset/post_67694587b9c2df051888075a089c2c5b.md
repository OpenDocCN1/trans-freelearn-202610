
## Image classification with attention networks

Conventional CNNs process every feature map and image region with equal importance. Humans, however, naturally focus on the most informative parts of a scene—for example, a cat’s face rather than the background grass. Attention mechanisms attempt to mimic this behavior by automatically learning **what features to emphasize and where to look**, leading to improved classification accuracy and interpretability.

### CNN with channel and spatial attention

Consider looking at a bird image. Some feature maps may respond strongly to feathers, beaks, or wings, while others may contain little useful information. Channel attention learns which feature maps are important, whereas spatial attention identifies the image regions most relevant to the classification decision.

Given a feature tensor $F \in \mathbb{R}^{H\times W\times C}$, channel attention computes $F' = M_c(F) \odot F$, while spatial attention further refines the features as $F'' = M_s(F') \odot F'$.

**Channel Attention:** Intuitively, channel attention acts like a volume control for feature maps: useful channels are amplified while less informative channels are attenuated, as demonstrated in the next code. Intuitively, GlobalAveragePooling2D asks “which features are consistently present across the entire image?”, while GlobalMaxPooling2D asks “which features appear most strongly anywhere in the image?”, and together they provide complementary cues for computing channel importance.

```
```python
class ChannelAttention(tf.keras.layers.Layer): # for complete code refer to GitHub

    def call(self, inputs):
        avg_pool = tf.keras.layers.GlobalAveragePooling2D()(inputs)
        avg_pool = self.shared_layer_one(avg_pool)
        avg_pool = self.shared_layer_two(avg_pool)
        max_pool = tf.keras.layers.GlobalMaxPooling2D()(inputs)
        max_pool = tf.keras.layers.Reshape((1,1,filters))(max_pool)
        max_pool = self.shared_layer_one(max_pool)
        max_pool = self.shared_layer_two(max_pool)
        attention = tf.keras.layers.Add()([avg_pool,max_pool])
        attention = tf.keras.layers.Activation('sigmoid')(attention)
        return tf.keras.layers.Multiply()([inputs, attention])
```

## Image classification with vision transformer (ViT)

CNNs analyze images using local receptive fields. Vision Transformers instead treat an image as a sequence of small patches, analogous to words in a sentence. Self-attention allows every patch to interact directly with every other patch, enabling the model to capture long-range relationships. For N image patches,

Attention(Q, K, V) = softmax( (Q K^T) / sqrt(d) ) V

In these examples, we shall use the transformers library (developed by Hugging Face) which provides easy access to state-of-the-art pretrained Transformer models for vision, language, and multimodal tasks. It lets us download, preprocess, and run inference with pretrained Transformer-based vision models using only a few lines of code, without implementing the architectures from scratch. A pretrained ViT model can be loaded as:

```
from transformers import ViTImageProcessor, ViTForImageClassification
processor = ViTImageProcessor.from_pretrained("google/vit-base-patch16-224")
model = ViTForImageClassification.from_pretrained("google/vit-base-patch16-224", output_attentions=True)
```

Using the pretrained ViT model in inference mode (`model.eval()`), the input image is converted into patches and processed to obtain both class predictions (classification scores: logits) and self-attention maps (attentions), which can subsequently be visualized to reveal the image regions that most influenced the model’s decision.

```
```python
model.eval()
inputs = processor(images=image, return_tensors="pt")  # Forward pass
with torch.no_grad():
    outputs = model(**inputs, output_attentions=True)
logits = outputs.logits
attentions = outputs.attentions
```
