# Converting between data types

```
im_float = im.astype(np.float32) / 255.0 # Normalize float [0, 1]
print("Float dtype:", im_float.dtype)
print("New range:", im_float.min(), "to", im_float.max())
# Float dtype: float32
# New range: 0.0 to 1.0
```

# Caution: overflow and clipping

When operating on uint8 images, be careful with arithmetic operations:

```
bright = im + 100 # Wrong: causes overflow if dtype is uint8
```

This will wrap around (e.g., 250 + 100 = 94) due to overflow.

Here is the correct approach:

```
bright = np.clip(image.astype(np.int16) + 100, 0, 255).astype(np.uint8)
```

The following is even better:

```
im_float = im.astype(np.float32) / 255.0
bright_float = np.clip(im_float + 0.4, 0.0, 1.0)
```

# Binary masks with Boolean images

In image segmentation or thresholding, you often generate Boolean masks, as shown in the next code snippet:

```
gray = rgb2gray(image)  # Returns float image [0, 1]
mask = gray > 0.5        # Boolean mask
print("Mask dtype:", mask.dtype)  # Output: bool
# Mask dtype: bool
```

# Pro tip

Use skimage.img_as_float and skimage.img_as_ubyte for safe conversions:

```
from skimage import img_as_float, img_as_ubyte
im_float = img_as_float(im)  # converts safely to float [0,1]
im_uint8 = img_as_ubyte(im_float)  # converts safely back to uint8
```

Remember that OpenCV-Python primarily works with NumPy arrays for image processing. Here’s a mapping of some common OpenCV data types to their corresponding NumPy data types:

+   - cv2.CV_8U (8-bit unsigned integer): numpy.uint8
+   - cv2.CV_32F (32-bit floating-point): numpy.float32
+   - cv2.CV_64F (64-bit floating-point): numpy.float64
