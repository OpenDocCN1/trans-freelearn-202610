The corrupted image and interpolation data are generated using the next code snippet:

```
im = imread('images/lady.png', as_gray=True)
h, w = im.shape
x, y = np.arange(h), np.arange(w)
np.random.seed(11)
mask = np.random.random(im.shape) > 0.6 # corrupt some values
im[mask] = np.nan
np.sum(mask) / np.prod(mask.shape) # prop corrupted
valid_mask = ~np.isnan(im)
coords, values = np.array(np.nonzero(valid_mask)).T, im[valid_mask]
```

Here, `mask` randomly selects corrupted pixels, `valid_mask` identifies uncorrupted pixels, `coords` stores the coordinates of valid pixels, and `values` contains their intensity values. These known samples are then used for interpolation. The following helper function reconstructs the image by evaluating the interpolator at every pixel location:

```
def get_inpainted(coords, values, im_shape, interpolator):
    return interpolator(list(np.ndindex(im_shape))).reshape(im_shape)

im_inpainted_lin = get_inpainted(coords, values, im.shape, \
    interpolate.LinearNDInterpolator(coords, values, fill_value=0))
im_inpainted_nn = get_inpainted(coords, values, im.shape, \
    interpolate.NearestNDInterpolator(coords, values))
im_inpainted_rbf = get_inpainted(coords, values, im.shape, \
    interpolate.RBFInterpolator(coords, values, neighbors=50))
```

Here, LinearNDInterpolator estimates missing pixels using local linear relationships, NearestNDInterpolator copies the nearest valid intensity value, and RBFInterpolator reconstructs pixels from weighted radial basis functions. Since RBF interpolation requires solving large linear systems whose memory and computational cost grow approximately quadratically with the number of known pixels, interpolation over large images can become expensive. The neighbors=50 parameter restricts interpolation to local neighborhoods, significantly reducing memory usage and computational complexity for large images.

The mean squared error (MSE) between the original and inpainted (reconstructed) images is computed using the get_MSE() function to quantify the reconstruction accuracy and compare the algorithms:

```
def get_MSE(im_orig, im_inpainted):
    return np.linalg.norm(im_orig - im_inpainted)**2 / np.prod(im_orig.shape)
```
