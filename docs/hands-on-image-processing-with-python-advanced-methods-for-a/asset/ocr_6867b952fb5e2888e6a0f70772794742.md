Here, the pretrained model adapts its learned visual features to the task of vehicle-damage segmentation. During training, YOLO jointly optimizes localization, classification, and segmentation-mask losses to improve pixel-level damage prediction.

Damage Segmentation and Severity Estimation: After training, the best-performing checkpoint is loaded.

```
best_model = YOLO("runs/segment/train-7/weights/best.pt")
```

Inference is performed on a test image:

```
results = best_model(test_image)
```

The model returns segmentation masks corresponding to detected damage regions. The total damaged area is estimated by counting mask pixels.

```
masks = results[0].masks.data.cpu().numpy()
for mask in masks:
    area = np.sum(mask > 0.5)
    total_damage += area
```

Mathematically, if M(x, y) denotes a binary damage mask, A = Σₓ,ᵧ M(x, y) gives the damaged area in pixels. The area is then mapped to a severity category:

```
if total_damage < 5000:    severity = "Minor"
elif total_damage < 20000:  severity = "Moderate"
else:                       severity = "Severe"
```

Although simplistic, this rule-based approach demonstrates how segmentation outputs can be converted into insurance-relevant metrics.
