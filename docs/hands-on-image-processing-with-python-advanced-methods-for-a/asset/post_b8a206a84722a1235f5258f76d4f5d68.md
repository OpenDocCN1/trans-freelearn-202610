- **Loading and preprocessing the image**
  
  The image file (e.g., cat.jpg) is loaded using imageio, and only the first three color channels (RGB) are used. The image data is normalized in the FourierFeatNet class to ensure values are between 0 and 1 for efficient training.

- **Class definition (FourierFeatNet):**
  
  The FourierFeatNet class encapsulates the entire process of constructing and training the FFN. It performs the following tasks:

- **Initialization (`__init__()`):**
  - **Input normalization:** The image, img, is normalized by dividing its pixel values by the maximum value in the image.
  - **Fourier features (B):** The Fourier feature mapping matrix B is provided as an argument. It can vary based on the choice of Fourier mapping (e.g., Gaussian features).
  - **Train/test split:** The data is split into a lower-resolution training set and a full-resolution test set using train_test_split(). This allows the network to train on downsampled data and test on the full-resolution image.

- **Fourier feature mapping (`map_input()`):**
  - The input coordinates are transformed using a Fourier feature mapping. If no mapping matrix (B) is provided, the pixel coordinates are used directly. If B is provided, the input coordinates x are projected onto a higher-dimensional space: 2πx·Bᵀ.
  - The sine and cosine of these projections are concatenated to create the final mapped input. This Fourier feature mapping allows the network to better capture high-frequency information in the image, which is crucial for reconstructing detailed images.

- **Network architecture (`build_network()`):** The neural network architecture is built using the stax module from JAX. The network consists of the following:
  - Several dense layers with ReLU activations (standard layers in fully connected neural networks)
  - A final dense layer with a Sigmoid activation that outputs 3 channels (RGB) with values in the range [0, 1], representing the pixel values of the reconstructed image

- **Training the network (`train_model()`):** The main training process occurs in the train_model() function. It performs the following steps:
  - Model prediction and loss calculation

- **Model prediction** (`model_pred()`): The predicted output (reconstructed image) is computed by applying the network's learned parameters to the Fourier-mapped input coordinates.
- **Loss function** (`model_loss()`): The loss is defined as the **mean squared error** (MSE) between the predicted and ground-truth pixel values: $loss = \frac{1}{2} mean((prediction - ground\ truth)^2)$
- **PSNR calculation** (`model_psnr()`): PSNR is a standard metric for image reconstruction quality. By now, you should be familiar with it. Higher PSNR values indicate better reconstruction quality. It is computed using the formula: $(PSNR = -10 \cdot log_{10}(2 \cdot loss))$.
- **Optimization**: The Adam optimizer is used to update the network parameters. The gradients of the loss function are computed using grad(`model_loss`), and the optimizer adjusts the parameters based on the gradient information. The training proceeds for `iters` iterations (2,000 in this case).
- **Training loop**
  - For each iteration, the model updates the parameters using the Adam optimizer.
  - Every 25 iterations, the training PSNR, test PSNR, and predicted images are recorded. These values are used to monitor the performance of the network during training.
  - The function returns a dictionary containing:
    1. `state`: The final learned parameters of the network.
    2. `train_psnrs`: A list of training PSNR values over iterations.
    3. `test_psnrs`: A list of test PSNR values.
    4. `pred_imgs`: Predicted images over time during training.
    5. `xs`: The iteration steps at which PSNR values were recorded.

class FourierFeatNet:
    def __init__(self, img, B, num_layers, num_channels):
        self.I = img / img.max()
        self.B, self.L, self.C = B, num_layers, num_channels
        self.train_test_split()
        self.build_network()
    def train_test_split(self):
        # Create input pixel coordinates in the unit
        # square
        coords = np.linspace(0, 1, self.I.shape[0], \
                            endpoint=False)
        x_test = np.stack(np.meshgrid(coords, coords), -1)
```

```
self.test_data = [x_test, self.I]
self.train_data = [x_test[::2, ::2], self.I[::2, ::2]]

# Fourier feature mapping
def map_input(self, x):
    if self.B is None:
        return x
    else:
        x_proj = (2.*np.pi*x) @ self.B.T
        return np.concatenate([np.sin(x_proj), \
                               np.cos(x_proj)], \
                               axis=-1)

# JAX network definition
def build_network(self):
    layers = []
    for i in range(self.L-1):
        layers.append(stax.Dense(self.C))
        layers.append(stax.Relu)
        layers.append(stax.Dense(3))
        layers.append(stax.Sigmoid)
    self.FFN = stax.serial(*layers)

# Train model with given hyperparameters and data
def train_model(self, learning_rate, iters):
    init_fn, apply_fn = self.FFN[0], self.FFN[1]
    model_pred = jit(lambda params, x: apply_fn(params,\
                    self.map_input(x)))
    model_loss = jit(lambda params, x, y: .5 * np.mean(\
        (model_pred(params, x) - y) ** 2))
    model_psnr = jit(lambda params, x, y: \
        -10 * np.log10(2.*model_loss(params, x, y)))
    model_grad_loss = jit(lambda params, x, y: \
        grad(model_loss)( params, x, y))
    opt_init, opt_update, get_params = \
        optimizers.adam(learning_rate)
    opt_update = jit(opt_update)
    _, params = init_fn(rand_key, (-1, \
        self.map_input(self.train_data[0]).shape[-1]))
    opt_state = opt_init(params)
```

```python
train_psnrs = []
test_psnrs = []
pred_imgs = []
xs = []
for i in tqdm(range(iters), desc='train iter', leave=False):
    opt_state = opt_update(i, \
        model_grad_loss(get_params(opt_state), \
        *self.train_data), opt_state)
    if i % 25 == 0:
        train_psnrs.append(model_psnr(\
            get_params(opt_state), *self.train_data))
        test_psnrs.append(model_psnr(\
            get_params(opt_state),\
            *self.test_data))
        pred_imgs.append(model_pred(\
            get_params(opt_state), \
            self.test_data[0]))
    xs.append(i)
return {
    'state': get_params(opt_state),
    'train_psnrs': train_psnrs,
    'test_psnrs': test_psnrs,
    'pred_imgs': np.stack(pred_imgs),
    'xs': xs,
}

The next code compares different Fourier feature mappings stored in `B_dict` to study their effect on image reconstruction. `B_dict['none'] = None` uses only the raw pixel coordinates without Fourier encoding, while `B_dict['basic'] = np.eye(2)` applies a simple identity mapping that preserves the original coordinates. Three Gaussian Fourier feature mappings, `B_dict['gauss_{scale}']`, are created using a random Gaussian matrix `B_gauss` scaled by factors 1, 10, and 100, enabling the network to capture image structures at different frequency ranges. The input image is normalized and, for each mapping in `B_dict`, a FourierFeatNet model with 4 layers and 256 channels is trained for 2000 iterations using a learning rate of 10⁻⁴. The outputs from all mappings are stored for later comparison of reconstruction quality and frequency representation capability.

```
```python
num_layers, num_channels = 4, 256
learning_rate = 1e-4
iters = 2000
mapping_size = 256

B_dict = {}
