> **Note**
> 
> The `img_as_ubyte()` function converts the normalized float image `[0,1]` produced by `rgb2gray()` into an 8-bit (`uint8`) image `[0,255]`, which is the expected input format for `skimage.filters.rank.median()`.
> 
> **Advantages:** Precise boundary localization and it naturally incorporates edge information.
> 
> **Limitations:** Sensitive to noise → over-segmentation, requires good marker selection.

Moving from marker-based watershed segmentation, which focuses on using gradient-driven flooding guided by carefully defined markers to separate regions, we now transition to a practical application where segmentation is combined with morphological operations to solve a real-world vision task—counting coins using segmentation and morphology.

# Counting coins with segmentation and morphology

Counting objects in an image is a fundamental task in computer vision, often applied in **industrial inspection**, **medical imaging**, and **robotics**. In this section, we focus on counting coins in an image using image segmentation and morphological operations.

# Problem formulation

Given a grayscale or RGB image $I(x,y)$ containing multiple coins, we want to determine the **number of individual coins** $N_c$. We can estimate number of coins with $N_c = \max(L)$ where $L$ is the labeled segmentation map. This can be formalized in terms of the following pipeline:

+   1. **Thresholding/Binary segmentation:** Separate foreground (coins) from background.
+   2. **Morphological processing/Cleaning** (opening, closing, distance transform, watershed): Clean the mask, refine segmentation, separate touching coins, if any.
+   3. **Distance transform:** Computes distance of each foreground pixel to nearest background. Mathematically,
+   
+      $$D(x,y)=\min_{(x',y')\in\mathrm{background}}\lVert(x,y)-(x',y')\rVert$$
+   
+   4. **Watershed separation:** Splits touching objects using topographic flooding from markers.
+   5. **Connected component labeling:** Assign a unique label to each connected coin, identifies each coin.
+   6. **Counting:** Compute the number of unique labels.
+   7. **Binary segmentation:** Thresholding produces mask $M$ from a grayscale image $I$:
+   
+      $$M(x,y)=\begin{cases}1, & I(x,y)>T\\0, & I(x,y)\le T\end{cases}$$
+   
+      where $T$ is a threshold value, to be computed using Otsu’s method.
