While a band-pass filter allows a specific range of frequencies to pass through, the opposite approach—blocking a selected frequency band—can be equally important in many applications. This leads us to the band-stop filter, which we’ll explore next.

## Band-stop/band-reject (notch) filter (BSF/BRF)

This filter blocks/rejects a few chosen frequencies from the frequency domain representation of the image (obtained with DFT), hence the name. This filter is particularly useful for removing periodic noise from images. The ideal BRF is given by the following:

H_BSF(u, v) = { 0, if D1 ≤ D(u, v) ≤ D2
1, otherwise }

Similarly, we can define the Butterworth and Gaussian BRF (left as an exercise).

## The Gaussian band-stop filter

The Gaussian band-stop filter (GBSF) can be defined as follows:

```
H_BS(u, v) = e^(-D²(u,v)/(2D_L²)) ( 1 - e^(-D²(u,v)/(2D_H²)) )
```

Here's a breakdown of the equation:

+   1. Low-pass component:

```
H_LP(u, v) = e^(-D²(u,v)/(2D_L²))
```

+   - Passes low frequencies
+   - Attenuates high frequencies

+   2. High-pass component:

```
H_HP(u, v) = 1 - e^(-D²(u,v)/(2D_H²))
```

+   - Removes very low frequencies
+   - Allows mid-range frequencies to pass

## Effect

They selectively allow and suppress frequencies as follows:

+   - Allows mid-range frequencies (band frequencies) to pass
+   - Blocks very low frequencies (removes slow variations)
+   - Blocks very high frequencies (removes noise)

Here are the steps to implement the GBSF, as shown in the following table:

| Step | Operation | Effect |
|---|---|---|
| 1 | Compute FFT | Converts image to frequency domain |
| 2 | Define frequency grid | Creates a frequency coordinate system |
| 3 | Compute distance D² | Measures how far each frequency is from the center |
| 4 | Create Gaussian bandpass filter | Allows mid-range frequencies, removes very low & high frequencies |
| 5 | Apply filter | Multiplies filter with Fourier-transformed image |
| 6 | Compute inverse FFT | Converts filtered image back to spatial domain |
| 7 | Extract real part | Removes complex values |

Figure 6.21 – Steps to compute a Gaussian band-stop filter

The following code snippet implements the preceding steps:

```
def gaussian_bandpass_filter(image):
    # Assumes input is a 2D grayscale image
    image_freq = np.fft.fftshift(np.fft.fft2(image))
    m, n = np.shape(image_freq)
    u0, v0 = int(n/2), int(m/2) # Find the center
    u, v = np.meshgrid(range(n), range(m))
    DL, DH = 5, 9
    D2 = (u-u0)**2+(v-v0)**2 # Squared Euclidean distance from
                            # the center
    gaussian_filter = np.exp(-0.5*D2/DL**2) * \
                      (1 - np.exp(-0.5*D2/DH**2))
    # Apply the filter
    fourier_transform = image_freq * gaussian_filter
    rec_image = np.fft.ifft2(np.fft.ifftshift(\
                              fourier_transform))
    return rec_image

im = imread('images/heart.png', as_gray=True)
# im = im / im.max()
im_rec, F, G = gaussian_bandpass_filter(im)
im_rec = im_rec.real
# plot original noisy (im) and reconstructed images (im_rec)
```

While traditional frequency domain filters such as the band-reject filter are useful for suppressing unwanted frequencies, recent advancements in machine learning have leveraged frequency representations in more powerful ways. One such innovation is the Fourier Feature Network, which uses frequency-based encodings to enhance learning in neural networks. Let’s dive into how it works next.

## Fourier Feature Networks

Fourier Feature Networks (FFNs) enhance neural networks by incorporating Fourier-based positional encodings to better represent high-frequency details in signals such as images and 3D scenes. Traditional MLPs are biased toward learning low-frequency smooth patterns, often producing blurry outputs and failing to capture sharp edges or textures. FFNs address this limitation by transforming the input coordinates x ∈ ℝ^d into a higher-dimensional frequency-rich representation using sinusoidal mappings:

γ(x) = [sin(2πBx), cos(2πBx)]

where B is typically a randomly sampled Gaussian frequency matrix spanning multiple frequency scales. More generally,

γ(x) = [sin(B₁x), cos(B₁x), ..., sin(Bₙx), cos(Bₙx)]

Instead of directly feeding x into the network, the model learns: I(x)~MLP(γ(x)), allowing the network to model both coarse and fine structures effectively. The sinusoidal encoding forces the network to attend to multiple spatial frequencies, overcoming the inherent low-frequency bias of standard neural networks. The idea is motivated by Fourier analysis, where signals are decomposed into sinusoidal frequency components.

FFNs are widely used in applications such as Neural Radiance Fields (NeRF), where Fourier features help reconstruct photorealistic 3D scenes with sharp textures and edges, and in image super-resolution, where they improve recovery of fine spatial details. Their main advantages include improved high-frequency representation, flexibility across 2D and 3D tasks, and enhanced neural field modeling. However, Fourier encoding increases computational complexity, and the choice of the frequency matrix (B) significantly affects performance and remains an active research area.
