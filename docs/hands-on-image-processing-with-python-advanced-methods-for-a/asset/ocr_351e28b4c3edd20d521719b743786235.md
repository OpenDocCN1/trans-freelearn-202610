**Why is YOLO fast?** YOLO avoids the **Region Proposal Network (RPN)** and Per-ROI computation. Instead, it performs:

Single Forward Pass ⇒ All Predictions

This leads to O(1) inference per image and highly optimized GPU usage.

**Practical observations:** Masks may be slightly less precise than Mask R-CNN, but excellent for real-time applications (Autonomous driving, Video analytics, Surveillance). Unlike Mask R-CNN YOLO does **not predict full-resolution masks directly**. Instead, it uses: Low-rank mask approximation. This reduces computational complexity:

O(HW) → O(K + HW) where K ≪ HW.

YOLO-based instance segmentation represents a major shift toward unified architectures, real-time performance and scalable deployment. Together with Mask R-CNN, it completes the spectrum of instance segmentation techniques, where Mask R-CNN → **Accuracy-focused** and YOLO → **Speed-focused**. Instance segmentation bridges the gap between detection and segmentation by providing object-level understanding and pixel-level precision.

Mask R-CNN remains a foundational method due to its elegant formulation and strong performance, while modern YOLO-based methods push toward real-time applications.

# Transformer-based segmentation

Transformer architectures have fundamentally reshaped image segmentation by replacing convolutional inductive biases with **global self-attention mechanisms**. Unlike CNN-based segmentation, which relies on local receptive fields, transformer-based models explicitly model **long-range dependencies**, enabling superior scene understanding.
