## Image classification with Swin Transformer

A limitation of standard Vision Transformers is that global attention becomes computationally expensive for large images. Swin Transformers address this issue by restricting attention to local windows while gradually exchanging information between neighboring windows. One may think of Swin Transformers as combining the locality of CNNs with the flexibility of Transformer attention. Instead of global attention complexity, Swin Transformers achieve approximately linear complexity, through hierarchical window-based attention.

The following code snippet uses a pretrained Swin Transformer to first classify a parrot image and then to predict the most likely object class. To explain the prediction, gradients of the predicted class score are backpropagated to the input image, producing a saliency map that highlights pixels most influential to the decision; the resulting heatmap is then overlaid on the original image for visualization, as demonstrated using the next code snippet:

outputs = model(**inputs)    # Forward pass
```

```

## Few-shot learning

Traditional supervised image classification requires hundreds or thousands of labeled examples per class. In contrast, **few-shot learning (FSL)** aims to learn new categories from only a handful of labeled examples. Formally, in an *N*-way *K*-shot task, the model must classify among *N* classes using only *K* labeled examples per class. FSL is particularly important in domains where annotated data is scarce, such as medical imaging, remote sensing, and industrial inspection.

Intuitively, few-shot learning resembles human learning: after seeing only a few examples of a new bird species, a person can often recognize similar birds in future images. Modern FSL systems achieve this capability by learning transferable visual representations rather than memorizing class labels.

## Few-shot learning with DINOv2

DINOv2 is a self-supervised Vision Transformer trained without class labels. Instead of learning explicit categories, DINOv2 learns powerful visual embeddings that can be reused for downstream tasks. A simple few-shot classifier can be constructed using class prototypes: In this example, the classification head is removed and the network is used purely as a feature extractor that maps each image to a high-dimensional embedding vector.

```
```python
model = timm.create_model('vit_base_patch14_dinov2.lvd142m', pretrained=True)
model.reset_classifier(0)  # use embeddings
```
```

```
The embedding function computes a feature vector f(x) for each image.
with torch.no_grad():
    emb = model(x)
```

**Prototype-Based Few-Shot Classification:** A small support set containing only a couple of examples per class is provided.

```
support_set = {"dog": ["dog1.png", "dog2.png"],
               "cat": ["cat1.png", "cat2.png"]}
```

For each class, embeddings are averaged to form a **prototype** (class representative):

$$p_c = \frac{1}{N_c}\sum_{i=1}^{N_c} f(x_i)$$

```
embs = [get_embedding(p) for p in paths]
prototypes[cls] = torch.stack(embs).mean(0)  # prototype construction
```

Intuitively, a prototype acts as the “center” of a class in the embedding space.

**Similarity-Based Prediction:** The query image is embedded and compared against all class prototypes using **cosine similarity**:

$$\operatorname{sim}(q,p_c)=\frac{q^T p_c}{\lVert q\rVert\lVert p_c\rVert}$$

as implemented using the following code.

```
query_emb = get_embedding("lab.png")
sim = F.cosine_similarity(query_emb, proto, dim=0)
```

The predicted class is simply the prototype with the highest similarity:

$$\hat{c}=\arg\max_c \operatorname{sim}(q,p_c)$$

Unlike conventional supervised embeddings, DINOv2 learns general-purpose visual representations through *self-supervised* **teacher–student** training on multiple augmented views of unlabeled images, where the student learns to match the teacher’s **prototype-based semantic representations**, encouraging images with similar underlying visual content to occupy nearby regions of the feature space while remaining invariant to appearance changes.

A Labrador image therefore produces an embedding closer to the **dog prototype** than the **cat prototype**, even though only a few support examples are available. In essence, few-shot learning becomes a **nearest-prototype search in embedding space**, leveraging the powerful visual knowledge learned during large-scale self-supervised pretraining.
