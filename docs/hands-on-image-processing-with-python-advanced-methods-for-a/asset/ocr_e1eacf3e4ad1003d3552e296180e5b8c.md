Here, $L$ is the number of different intensity values, as in these examples:

+   - $L = 256$ for an 8-bit grayscale image (pixel values in $[0,255]$)  
+   - $L = 2$ for a floating-point image normalized to $[0,1]$

# Note

If the image pixel values are not already scaled appropriately, a normalization step (e.g., mapping to $[0,1]$ or $[0,255]$) should be performed before applying the inversion formula to avoid incorrect results.

In general, a **transfer function** defines how an input image’s pixel values are transformed into output pixel values. It is a function that maps each input intensity $I_{in}$ to an output intensity $I_{out}$:

$$I_{out}=T(I_{in})$$

Here, $T$ is the transfer function that dictates how pixel intensities are modified. The transfer function for **inversion** is as follows:

$$I_{out}=T(I_{in})=L-1-I_{in}$$

We can simply use the `invert()` function from the `skimage.util` module to get the negative of an image, as shown in the following code:

```
```python
from skimage.util import invert
im = im / im.max()  # normalize in the range [0,1]
np.allclose(1 - im == invert(im))
# True
```
