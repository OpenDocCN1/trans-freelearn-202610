A **guided filter** performs edge-preserving smoothing by using a guidance image (usually the original image) to control how another image (the source) is smoothed. It assumes that the output is a linear transform of the guidance image in a local window, making it well-suited for tasks like:

+   - Edge-aware denoising
+   - Detail enhancement
+   - HDR compression
+   - Image matting
+   - Depth map refinement

Given:

+   - **Input image I**: grayscale or color (used as guidance)
+   - **Source image p**: the image to be filtered (e.g., gradient, mask, etc.)
+   - **Output q**: the filtered result

For each local window ωₖ, the output qᵢ at pixel i ∈ ωk is modeled as a **linear transform** of the guidance image:

qᵢ = aₖ Iᵢ + bₖ, ∀i ∈ ωk

where

+   - aₖ, bₖ: linear coefficients constant in ωₖ
+   - Iᵢ: pixel intensity at position i

The coefficients aₖ, bₖ are estimated by minimizing the following cost function:

E(aₖ, bₖ) = Σᵢ∈ωₖ ((aₖ Iᵢ + bₖ − pᵢ)² + ε aₖ²)

where:

+   - ε: regularization parameter to control smoothness (prevents overfitting)

The second term encourages smaller gradients of q.

The solution to the optimization is:

aₖ = [ (1/|ω|) Σᵢ∈ωₖ Iᵢ pᵢ − μₖ p̄ₖ ] / [ σₖ² + ε ]
bₖ = p̄ₖ − aₖ μₖ

Where:

+   - μₖ, σₖ²: mean and variance of I in ωk
+   - p̄ₖ: mean of p in ωₖ
