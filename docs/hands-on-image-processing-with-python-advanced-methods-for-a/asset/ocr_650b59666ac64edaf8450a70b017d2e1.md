# YOLO (YOLOv8 / YOLOv11): A single-stage formulation

Modern instance segmentation architectures such as **YOLO-based segmentation models** adopt a **single-stage formulation, enabling real-time inference** while maintaining competitive accuracy. In this section, we explore **YOLO-based instance segmentation** using the **Ultralytics YOLO11 segmentation model** and examine its theoretical foundations and practical implementation. Later, we shall contrast its design choices and performance characteristics with the **classical two-stage Mask R-CNN architecture**.

+   - **From detection to segmentation: YOLO Perspective:** Traditional YOLO (You Only Look Once), introduced by Joseph Redmon, was originally designed for object detection:
+   
+     $$f_{\theta}(I) \rightarrow \{(b_i, c_i, s_i)\}_{i=1}^{N},$$
+   
+     where $b_i$: bounding box, $c_i$: class and $s_i$: confidence.
+   
+   - **Extension to instance segmentation:** YOLO segmentation models extend this formulation to include pixel-level masks:
+   
+     $$f_{\theta}(I) \rightarrow \{(b_i, c_i, s_i, M_i)\}_{i=1}^{N},$$
+   
+     where $M_i \in [0,1]^{H\times W}$ is the predicted mask.
