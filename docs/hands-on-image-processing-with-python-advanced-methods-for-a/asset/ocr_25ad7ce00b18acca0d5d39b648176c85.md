# RGB to YUV

Similarly, we can convert from an RGB to a YUV color space using the following code, with the color.rgb2yuv() function:

```
im_yuv = color.rgb2yuv(im)
imsave('images/parrot_yuv.png', (255*im_yuv).astype(np.uint8))
```

# RGB to CMYK

In contrast to RGB (which is an additive colorspace), CMYK is a subtractive color spectrum. This means that these inks mask colors on a lighter background (such as white paper). The CMYK ink subtracts the red, green, and blue from white light and leaves the cyan, magenta, and yellow. Black is the absence of color. RGB colors may look great on screen, but they will need to be converted to CMYK color space before supplying your art files to your printer.
