# Fuzzy logic–based image enhancement

We already explored widely used traditional image contrast enhancement methods such as Histogram Equalization (HE) and Contrast-Limited Adaptive Histogram Equalization (CLAHE). These approaches are often global, inflexible, or susceptible to noise. Fuzzy logic provides a powerful alternative, especially useful in uncertain or imprecise contexts such as natural scene images, where pixel intensity classifications (e.g., “dark”, “medium”, “bright”) are inherently vague.

Fuzzy logic mimics human reasoning by handling degrees of truth rather than binary decisions. It works by:

+   - Defining fuzzy sets that represent linguistic categories
+   - Using membership functions to associate input values with these fuzzy sets
+   - Creating fuzzy rules to infer outputs
