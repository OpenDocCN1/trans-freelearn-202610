
## Image Preprocessing

The image is resized and converted to tensors.

```python
img = transform(img)
img = img * 2 - 1
```

The pixel values are scaled from [0,1] to [−1,1] to match the preprocessing expected by the model.

## Computing the Input Gradient

The core step of FGSM is computing the gradient of the loss with respect to the input image.

```python
image.requires_grad = True
output = model(image)
loss = nn.CrossEntropyLoss()(output, label)
loss.backward()
```

Mathematically, $g = \nabla_x J(\theta, x, y)$ measures how sensitive the loss is to each image pixel.

## Signed Gradient Perturbation

FGSM keeps only the sign of the gradient.

```python
perturbations = image.grad.sign()
```

This corresponds to $\operatorname{sign}(\nabla_x J)$, where each pixel receives a perturbation of either +1 or −1, depending on which direction increases the loss.

## Visualizing the Perturbation

The perturbation image reveals where the attack intends to modify pixels.

```python

```

Although the perturbation appears structured, its magnitude is typically very small when scaled by ε.

**Generating Adversarial Images:** The attack is applied using several perturbation strengths:

```python
epsilons = [0, 0.01, 0.1, 0.2]
```

The adversarial image is generated as:

```python
adv_x = input_tensor + eps * perturbations
```

corresponding to $x_{adv} = x + \epsilon \cdot \operatorname{sign}(\nabla_x J)$. Larger values of $\epsilon$ produce stronger attacks.

**Valid Pixel Constraints:** After perturbation, the image must remain within the valid pixel range.

```python
adv_x = torch.clamp(adv_x, -1, 1)
```

This prevents pixels from exceeding allowable values.

**Typical Behavior:** For $\epsilon = 0$, the network correctly predicts *giant panda*. As $\epsilon$ increases through 0.01 → 0.1 → 0.2, the *prediction confidence* decreases and eventually shifts to an incorrect class, even though the image remains visually recognizable as a panda to humans. This illustrates the remarkable fragility of deep neural networks. This vulnerability is especially critical in safety-sensitive applications such as medical imaging, autonomous driving, and surveillance systems, where small, imperceptible perturbations can lead to confidently wrong decisions with potentially severe real-world consequences.

## Defending Against Adversarial Attacks

Several strategies have been proposed:

- **Adversarial Training:** Train using adversarial examples:

  $$L = L(x) + L(x_{adv}),$$

  making the network more robust
- **Defensive Distillation:** Smooths decision boundaries and reduces sensitivity
- **Input Denoising:** Attempts to remove adversarial perturbations before classification
- **Certified Defenses:** Provide mathematical guarantees of robustness within a bounded perturbation region

## Applications of Adversarial Learning

Although originally viewed as a security threat, adversarial examples are now widely used not only for evaluating model robustness but also for improving it through adversarial training, in addition to applications in model debugging, explainable AI, security testing, autonomous vehicle safety and medical AI validation.

Intuitively, the network transforms pixels into a compact numerical signature that captures shapes, textures, object parts, and semantic information.

**Building the Image Database:** All images in the dataset are passed through the feature extractor.

## Why Dimensionality Reduction?

Deep CNN embeddings are often very high-dimensional. To reduce storage and accelerate similarity search, the code applies Principal Component Analysis (PCA):

```python
pca = PCA(n_components=500)
pca.fit(features)
pca_features = pca.transform(features)
```

PCA projects the original feature vector $f$ into a lower-dimensional space:

$$z = W^T f$$

where $W$ contains the principal eigenvectors of the feature covariance matrix. The resulting compressed feature vector (z) preserves most of the discriminative information while significantly reducing memory and computation requirements.

**Querying the Search Engine:** Given a query image, its feature vector is extracted.

```python
img, x = load_image("images/guitar.jpg")
feature = feat_extractor.predict(x).ravel()
pca_feature = pca.transform(feature.reshape(1,-1))
```

The query embedding is then compared with every image in the database using cosine distance.

```python
similar_idx = [distance.cosine(pca_feature, feat) for feat in pca_features]
```

*Cosine similarity* measures the angle between feature vectors:

$$\operatorname{sim}(a,b) = \frac{a^T b}{\lVert a \rVert \lVert b \rVert}$$

**Computational Complexity:** Let *N* = number of database images and *d* = feature dimension. A brute-force search requires *O(Nd)* operations per query. For very large image collections, approximate nearest-neighbor methods such as *FAISS*, *Annoy* or *ScaNN* can reduce retrieval time from seconds to milliseconds.

## Object detection

**Object detection** extends image classification by simultaneously identifying **what objects are present and where they are located**, thereby combining image classification with spatial localization.

$x_D = \{(c_i, b_i, s_i)\}_{i=1}^{N}$, $b_i = (x_i, y_i, w_i, h_i)$; $f(x) \rightarrow \{(c_i, b_i)\}_{i=1}^{N}$

### Intersection over Union (IoU)

IoU = Area(B_pred ∩ B_gt) / Area(B_pred ∪ B_gt).

For example, instead of simply predicting Dog, the model outputs Dog together with a bounding box surrounding the dog. Multiple objects can be detected simultaneously, each with its own class and location.

### Object detection with RetinaNet

In this section, we shall use a pretrained RetinaNet-ResNet50-FPN model from PyTorch, trained on the COCO dataset, to detect multiple objects without additional training.

RetinaNet - a One-Stage Detector: RetinaNet is a highly influential one-stage detector that combines:

- A ResNet50 backbone for feature extraction
- A Feature Pyramid Network (FPN) for multi-scale detection
- Focal Loss to handle class imbalance

The key innovation is Focal Loss:

$$FL(p_t) = -(1 - p_t)^\gamma \log(p_t)$$

where $p_t$ is the predicted probability of the correct class. Easy examples contribute less to the loss, forcing the network to focus on difficult objects.

You can think of RetinaNet as scanning the image at multiple resolutions using the FPN and proposing candidate objects everywhere. Focal Loss then suppresses the overwhelming number of easy background regions, allowing the detector to concentrate on true objects. The result is an accurate detector capable of identifying multiple objects and their locations in a single forward pass.

**Loading a Pretrained Model:** The detector is loaded with pretrained COCO weights.

