**Adjusting brightness:** Brightness adjustment uniformly shifts luminance values:

$L'(x,y)=\operatorname{clip}(L(x,y)+\beta,0,255)$

where the *shift parameter* $\beta>0$ brightens the image and $<0$ darkens it. The function `adjust_brightness()` implements this by adding a shift value to the L channel in Lab colorspace (`im_lab[...,0]`) and constraining the result with `np.clip()`, as shown in the following code snippet:

```
```python
from skimage.color import rgb2lab, lab2rgb


def adjust_brightness(im, shift):
    im_lab = rgb2lab(im)
    im_lab[...,0] = np.clip(im_lab[...,0] + shift, 0, 255)
    im_out = lab2rgb(im_lab)
    return (255*im_out/im_out.max()).astype(np.uint8)
```
```

**Adjusting contrast:** Contrast refers to the difference in intensity between the light and dark areas of an image. Contrast adjustment scales luminance differences:

$L'(x,y)=\operatorname{clip}(\alpha L(x,y),0,255)$

where $\alpha>1$ increases contrast and $0<\alpha<1$ decreases it. The `adjust_contrast()` function multiplies the *L-channel* by the scaling factor before reconversion to RGB.

```
```python
def adjust_contrast(im, scale):
    im_lab = rgb2lab(im)
    im_lab[...,0] = np.clip(im_lab[...,0] * scale, 0, 255)
    im_out = lab2rgb(im_lab)
    return (255*im_out/im_out.max()).astype(np.uint8)
```

```
