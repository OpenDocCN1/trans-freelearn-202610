## Ensemble segmentation

Combines multiple segmentation outputs for improved robustness:

S = S₁ ∩ S₂  or  S₁ ∪ S₂.

Different methods capture different properties: edge-based → boundaries, region-based → homogeneity, whereas superpixels → structure. Combining them reduces errors. The next code snippet demonstrates how to implement ensemble segmentation in Python. Here are the steps:

- 1. Preprocessing: Convert the input image to grayscale
- 2. Edge-based segmentation (Watershed): Use the function sobel() from skimage.filters module to compute edges and highlight boundaries. Define seeds, run watershed and produce segmentation S₁
- 3. **Superpixel segmentation (SLIC + Graph Cut):** Use the function `slic()` from `skimage.segmentation` to generates superpixels first and then build RAG and use *normalized cut* to minimize: `cut(A,B)/assoc(A,V)`, to produce segmentation S₂.
- 4. **Combine segmentations:** Use the function `join_segmentations()` to compute S = S₁ ∩ S₂, it keeps agreement between methods, as shown in the next code snippet:

```
from skimage.segmentation import slic, join_segmentations, watershed
coins = (255*rgb2gray(data.astronaut())).astype('uint8')
edges, markers = sobel(coins), np.zeros_like(coins)
foreground, background = 1, 2
markers[coins < 30.0] = background
markers[coins > 150.0] = foreground
ws = watershed(edges, markers)
seg1 = label(ws == foreground)
seg2 = slic(coins, n_segments=200, max_num_iter=160, \
            sigma=1, compactness=0.75, channel_axis=None, start_label=0)
g = graph.rag_mean_color(coins, seg2, mode='similarity')
seg2 = graph.cut_normalized(seg2, g)
segj = join_segmentations(seg1, seg2)

```

## Deep learning for image segmentation

In contrast to the classical methods explored earlier, where segmentation relied on handcrafted features, thresholds, and heuristic rules, deep learning learns hierarchical representations directly from data. Convolutional and transformer-based architectures model complex spatial patterns, enabling robust segmentation under variations in illumination, scale, texture, and occlusion.

Formally, the mapping $F_\theta$ is parameterized by a deep network with parameters $\theta$, optimized over a dataset $\{(I_i, Y_i)\}_{i=1}^N$ by minimizing a loss function:

$\mathcal{L}(\theta) = \sum_{i=1}^N \ell\left(F_\theta(I_i), Y_i\right)$

where $\ell$ measures the discrepancy between predicted and ground-truth segmentation masks (e.g., cross-entropy, Dice loss).

A key distinction from classical pipelines is that feature extraction and decision-making are unified within a single end-to-end trainable model. This allows the network to automatically learn multi-scale, context-aware features that are difficult to engineer manually.

The three paradigms considered in this part differ in the level of granularity at which predictions are made:

- - Semantic segmentation assigns a class label to each pixel without distinguishing between object instances.
- - Instance segmentation differentiates between individual object instances of the same class.
- - Panoptic segmentation unifies both, providing a complete scene understanding by labeling both “things” (countable objects) and “stuff” (amorphous regions).

This part of the chapter will develop the theoretical foundations, architectural principles, and practical implementations of these paradigms, highlighting how deep models have redefined the state-of-the-art in image segmentation. ### Fully convolutional networks

Fully convolutional networks (FCNs) represent the foundational architecture for semantic segmentation by eliminating fully connected layers and replacing them with convolutional operations. Let the encoder network extract hierarchical features:

$$F = \phi(I) \in \mathbb{R}^{h \times w \times C}$$

Instead of flattening $F$, FCNs apply a $1 \times 1$ convolution:

$$Z = W * F \in \mathbb{R}^{K \times h \times w}$$

This produces class-wise score maps, which are then upsampled:

$$\hat{Y} = \text{Upsample}(Z)$$

The final prediction at pixel $p$ is:

$$\hat{y}_p = \operatorname{argmax}_k \operatorname{softmax}(Z)_k(p)$$

**Skip connections:** To recover spatial detail, FCNs combine features from different depths:

$$F_{\text{fused}} = F_{\text{deep}} + \sum_{l} \alpha_l F_l$$

where $F_l$ are intermediate feature maps. Here, deep layers → semantic understanding, shallow layers → spatial precision, whereas fusion → accurate dense predictions.

**Limitations:** Blurry boundaries due to repeated downsampling and limited multi-scale context modeling.
