The file app.py serves as the main application script for your interactive image enhancement tool built with Streamlit. It ties together user input (via Streamlit) and backend processing (via the image_enhancement module) to build a responsive and intuitive GUI for trying different image enhancement techniques interactively. Here’s a concise breakdown of what it does.

The Python script app.py creates a graphical web interface that allows users to:

+   - Upload an image
+   - Choose an image enhancement method from a list
+   - Optionally adjust method-specific parameters (like number of bins or alpha)
+   - See real-time visual comparison between the original and enhanced images

The following table summarizes the key functions, as shown in the next code snippet:

| Section | Functionality |
|---|---|
| `st.file_uploader(...)` | Lets the user upload an image |
| `Image.open(...), cv2.cvtColor()` | Reads and converts the image for processing |
| `image_enhancement.IE(...)` | Initializes the image enhancement engine (from a separate Python module) |
| `st.selectbox(...)` | Lets the user choose an enhancement algorithm (enables model selection) |
| `st.slider(...)` | Lets the user tune parameters dynamically for selected methods |
| Conditional if-elif block | Applies the chosen enhancement method to the uploaded image |
| `cv2.cvtColor(...)` again | Converts the result from BGR to RGB for proper display in Streamlit |
| `st.columns(...) + st.image(...)` | Shows both original and enhanced images side by side |

*Table 7.7 – Summary of the key functions in app.py*

This is how it works (high-level flow):

+   1. User uploads image
+   2. User selects enhancement method
+   3. Optional sliders appear (if the method requires parameters)
+   4. App processes image using the selected enhancement method
+   5. Original and enhanced images are displayed side by side
