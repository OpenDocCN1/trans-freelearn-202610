### Image derivatives

We can compute the (partial) derivatives of a digital image using finite differences. In this section, let us discuss how to compute the image derivatives, the gradient, and the Laplacian, and why they are useful.

#### Derivatives and gradients

The following figure shows how to compute the partial derivatives of an image I (which is a function f(x, y)), using finite differences (with forward and central differences, the latter one being more accurate), which can be implemented using convolution with the kernels shown. The diagram also defines the gradient vector, its magnitude (which corresponds to the strength of an edge), and direction (perpendicular to an edge). Locations where the intensity (gray level value) changes sharply in an input image correspond to the locations where there are peaks/spikes (or valleys) in the intensity of the first-order derivative(s) of the image.

In other words, the peaks in gradient magnitude mark the edge locations, and we need to threshold the gradient magnitude to find edges in an image, as shown in the following figure:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_376_0.png)

Figure 8.1 – Partial derivatives and gradient of image

The following code block shows how to compute the gradient (along with the magnitude and the direction) with the convolution kernels shown previously, with the gray-scale chess image as input:

```python
def compute_grads(im):
    im_x = np.clip(signal.convolve2d(im, ker_x, mode='same'), 0, 1)
    im_y = np.clip(signal.convolve2d(im, ker_y, mode='same'), 0, 1)
    im_mag = np.sqrt(im_x**2 + im_y**2)
    im_dir = np.arctan(im_y / (im_x + eps))
    return im_x, im_y, im_mag, im_dir

eps = 1e-6
```

```python
ker_x, ker_y = [[-1, 1]], [[-1], [1]]
im = rgb2gray(imread('images/chess.png'))
im_x, im_y, im_mag, im_dir = compute_grads(im)
```

If you run the above code and plot the images side by side, you should obtain a figure like the following:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_377_0.png)

Figure 8.2 – Image gradient (partial derivatives) and the edges

The above figure shows the output of the preceding code block. As can be seen from the partial derivatives in the x and y directions, they detect the vertical and horizontal edges in the image, respectively. The gradient magnitude shows the strength of the edges at different locations in the image. Also, if we pick all the pixels from the original image corresponding to a single row (row 0, for instance), we can see a square wave (corresponding to alternating white and black intensity patterns), whereas the gradient magnitude for the same set of pixels has spikes (a sudden increase/decrease) in intensity, and these correspond to the (vertical) edges.

#### The Laplacian

It has been shown by Rosenfeld and Kak that the simplest isotropic derivative operator is the Laplacian, which is defined as shown in the following figure. The Laplacian approximates the second derivative of an image and detects edges. It is an isotropic (rotationally invariant) operator and the zero-crossings mark edge location; we shall discuss more about that later in the chapter. In other words, in locations where we have spikes/peaks (or valleys) in the first-order derivative(s) of an input image, we have zero-crossings in the corresponding locations of the second-order derivative(s) of the input image, as explained in the next figure:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_378_0.png)

Figure 8.3 – The second order derivatives and the Laplacian

#### Properties of the Laplacian

Here are a few useful properties of the Laplacian:

- ∇²f(x,y) (Laplacian) is a scalar (unlike the gradient, which is a vector)
- A single kernel (mask) is used to compute the Laplacian (unlike the gradient, where we usually have two kernels, the partial derivatives in the x and y directions, respectively)
- Being a scalar, it does not have any direction and hence, we lose the orientation information
- ∇²f(x,y) is the sum of the second-order partial derivatives (the gradient represents a vector consisting of the first-order partial derivatives), but the higher the order of the derivative, the more the increase in noise
- Laplacian is very sensitive to noise. Hence, the Laplacian is always preceded by a smoothing operation (for example, with a Gaussian filter); otherwise, the noise can be greatly aggravated

The following code snippet shows how to compute the Laplacian of an image using convolution with the kernel shown previously:

```python
ker_laplacian = [[0,-1,0],[-1, 4, -1],[0,-1,0]]
im = rgb2gray(imread('images/chess.png'))
im_lap = np.clip(signal.convolve2d(im, ker_laplacian, mode='same'), 0, 1)
```

If you run the above code and plot the images side by side, you should obtain a figure like the following:

The above figure shows the output of the preceding code snippet. As can be seen, the Laplacian output also finds the edges in the image.

#### Blur detection using the Laplacian variance

Blurring is one of the most fundamental spatial operations in image processing. It’s used both intentionally (e.g., for artistic effects or preprocessing) and unintentionally (e.g., due to poor focus or motion during capture). In many computer vision applications, detecting whether an image is blurred or not is a critical step—for instance, in quality assurance, autofocus systems, medical imaging, or preprocessing pipelines where high-frequency details are essential.

This section explores an efficient, no-reference (blind) technique for detecting blur in an image using the variance of the Laplacian operator. We will explain the mathematical intuition, apply common spatial filters (box and Gaussian), and present a well-commented Python implementation that demonstrates the technique step by step.

Blurring removes high-frequency content like edges and fine details. The Laplacian operator, being a second-order derivative, is sensitive to these sharp transitions. By applying the Laplacian and computing the variance of the resulting image, we can measure the level of detail:

- High variance → many edges → sharp image
- Low variance → few edges → blurry image

In 2D, the discrete Laplacian operator is typically represented as:

`ℒ = [[0, 1, 0], [1, -4, 1], [0, 1, 0]]`

It highlights regions of rapid intensity change.
