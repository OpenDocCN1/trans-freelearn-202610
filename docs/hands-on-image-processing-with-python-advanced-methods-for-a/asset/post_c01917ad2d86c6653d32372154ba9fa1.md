Using the preceding table, let’s compute the basis images for DCT and the Walsh transform (you can try for the other similar transforms in the same manner). As shown in the next code snippet, the dct() and walsh() functions compute the g(x,y,u,v) (forward) basis function for the DCT and the Walsh transforms, respectively:

```
def dct(x, y, u, v, N):
    def alpha(a): # Normalization
        return np.sqrt(1/N) if a==0 else np.sqrt(2/N)
    return alpha(u)*alpha(v)*np.cos(((2*x+1)*(u*np.pi))/(2*N))* \
           np.cos(((2*y+1)*(v*np.pi))/(2*N))

def walsh(x, y, u, v, N):
    def b(i, x):
        return (x >> i) & 1
    n = int(np.log2(N))
    return (-1)**np.sum([(b(i,x)*b(n-1-i,u)+b(i,y)*b(n-1-i,v)) \
                        for i in range(n)]) / N
```

The get_basis_image() function computes the (u,v)-th basis image (basis vector) for the transform specified by the forward transformation kernel g(x,y,u,v), for given frequency indices u,v and image size N.

```
def get_basis_image(u, v, g, N):
    basis_image = np.zeros((N,N))
    for x in range(N):
        for y in range(N):
            basis_image[x,y] = g(x, y, u, v, N)
    return basis_image
```

The get_all_basis_images() function computes all basis functions for that particular transform. The basis vectors can be used to compute the forward transform quickly, by dividing the input image into N × N blocks and performing convolution on each block with the N × N precomputed basis vectors (left as an exercise):

Let’s move on and explore a few properties of DFT that can turn out to be very useful.

## Properties of DFT

Understanding the properties of the DFT allows for more efficient computation and insight into how frequency information is represented in both one-dimensional signals and two-dimensional images.

### Separability

2D DFT is a separable and symmetric unitary transform. The following figure shows how 2D DFT computed by applying two successive 1D DFTs along the rows and columns, where the input f is a 2D signal of dimension M × N, and the output F is the DFT output:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_220_1.png)

Figure 4.39 – Separability of 2D DFT

Using separability, 2D DFT can be rewritten as:

$$F(u, v) = \sum_{x=0}^{M-1} \left[ \sum_{y=0}^{N-1} f(x,y) e^{-j2\pi v y / N} \right] e^{-j2\pi u x / M}$$

Showing that the transform can first be computed along one axis and then along the other. Using the Cooley–Tukey FFT algorithm, a 1D FFT of length N requires only $O(N\log N)$ operations instead of the naïve $O(N^2)$.

Hence, the total complexity of a 2D FFT of size $M \times N$ becomes $O(MN\log M + MN\log N)$. For a square image of size $N \times N$, this simplifies to $O(N^2\log N)$, which is significantly faster than the naive direct 2D DFT implementation requiring $O(N^4)$ operations.

The next code demonstrates separability, where the fft2_sep() function is implemented using two successive calls of 1D FFTs with np.fft.fft(), and the result is compared with the one obtained using np.fft.fft2(). The nearly identical execution times and zero error confirm both the correctness and efficiency of the separable FFT implementation.

```
def fft2_sep(f):
    return np.fft.fft(np.fft.fft(f).T).T

f = imread('images/lena.jpg', True)
%timeit F_sep = fft2_sep(f)
%timeit F = np.fft.fft2(f)
print(np.linalg.norm(F_sep - F))
# 0.0
plot_spectrum(np.hstack((np.fft.fftshift(F_sep), np.fft.fftshift(F))))
```

### Periodicity and windowing

The DFT inherently assumes that the signal repeats periodically in both the spatial and frequency domains. For a 2D signal, the DFT and its inverse are periodic with period:

F(u, v) = F(u + N, v) = F(u, v + N) = F(u + N, v + N)

The Fourier transform also exhibits conjugate symmetry since $F(u,v) = F^*(-u,-v)$ or, more interestingly, $|F(u,v)| = |F(-u,-v)|$.
