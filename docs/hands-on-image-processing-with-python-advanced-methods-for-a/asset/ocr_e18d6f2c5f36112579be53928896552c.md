# Typography generation

One of the major improvements of SDXL is its enhanced ability to render readable text within generated images. The following prompt requests a conference poster containing a title and topic list:

```
prompt = """
Professional conference poster.
Title:
COMPUTER VISION 2026
"""

image = pipe_t2i(prompt, guidance_scale=0, num_inference_steps=40).images[0]
```

The model synthesizes both the visual layout and the embedded text simultaneously. Although generated typography may still contain occasional spelling errors, SDXL represents a substantial improvement over earlier diffusion models that struggled to render coherent text.

# Note

Although SDXL-Turbo is optimized for 1–4 denoising steps, typography generation may sometimes benefit from additional iterations because text requires highly precise spatial structure; however, improvements beyond a few steps are not guaranteed since the model was trained primarily for ultra-fast low-step inference.

# Prompt sensitivity

Diffusion models are highly sensitive to prompt wording. Consider the sequence:

```
prompts = ["A cat", "A realistic cat", "A realistic Persian cat",
"A realistic Persian cat sitting on a sofa"]
image = pipe_t2i(prompt, guidance_scale=0, num_inference_steps=2).images[0]
```
