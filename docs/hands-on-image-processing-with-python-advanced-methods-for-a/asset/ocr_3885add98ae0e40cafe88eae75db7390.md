# α—compositing two images

α-compositing blends two images using their alpha (transparency) values, determining how much of each image contributes to the final pixel color. Given a foreground image, F, and a background image, B, each with RGBA values, the resulting image, C, is computed using alpha blending. Here are the steps explaining how it's computed:

+   1. Alpha normalization: First, the alpha values of the foreground, α_F, and background, α_B, are normalized between 0 and 1: α_F' = α_F / 255 and α_B' = α_B / 255
+   2. Composite alpha calculation: The resulting alpha, α_C (transparency of the final image), is computed as: α_C = α_F' + α_B'(1 − α_F').
+   3. Blended color calculation: For each color channel (R, G, and B), the final composite color, C, is computed as follows:
+   C = (F · α_F' + B · α_B'(1 − α_F')) / α_C
