
interpolated intensity is computed as a weighted average of neighboring pixels, with weights proportional to the relative distances from the target point.

For a target point $(x, y)$ surrounded by neighboring pixels $Q_{11}, Q_{12}, Q_{21}, Q_{22}$, the interpolated value is:

```
$f(x,y) = \frac{Q_{11}(x_2 - x)(y_2 - y) + Q_{21}(x - x_1)(y_2 - y) + Q_{12}(x_2 - x)(y - y_1) + Q_{22}(x - x_1)(y - y_1)}{(x_2 - x_1)(y_2 - y_1)}$
```

where $(x_1, y_1)$ and $(x_2, y_2)$ define the surrounding integer grid coordinates. The weights sum to one, ensuring intensity normalization. Bilinear interpolation produces smoother transitions than nearest-neighbor interpolation, although slight blurring may occur during large magnification.

## Bicubic interpolation

Bicubic interpolation extends cubic interpolation to two dimensions and generally produces smoother results than bilinear interpolation. Instead of four neighboring pixels, bicubic interpolation considers a $4 \times 4$ neighborhood (16 pixels) and estimates intensities using cubic polynomials. For 1D interpolation, the cubic polynomial is expressed as:

```
$p(x) = ax^3 + bx^2 + cx + d$
```

In 2D, bicubic interpolation applies cubic interpolation along both spatial directions:

```
$f(x, y) = \sum_{i=0}^{3} \sum_{j=0}^{3} a_{ij} x^i y^j$
```

where $a_{ij}$ are coefficients computed from the surrounding 16 pixels. Bicubic interpolation generates smoother and more visually natural images, particularly for large upsampling factors, although it is computationally more expensive and may introduce ringing artifacts near sharp edges.

## Note

In practice, bicubic interpolation can be implemented using various techniques for computing interpolation weights, including the following: **Lagrange polynomials**: Offer exact polynomial fits through data points. However, they can become numerically unstable for large intervals and are rarely used in high-performance applications.

- **Cubic splines**: Use *piecewise cubic polynomials* that guarantee the continuity of the function and its first and second derivatives. They are preferred when smooth transitions across pixel boundaries are critical.

- **Cubic convolution kernels**: Widely used in practice (e.g., in OpenCV and SciPy) due to their good trade-off between computational efficiency and visual quality. A common example is the *keys cubic convolution kernel*, used in `cv2.INTER_CUBIC`.

## Spline interpolation

Spline interpolation computes new pixel values using piecewise polynomial functions, producing smooth transitions across the image. Unlike nearest-neighbor or bilinear interpolation, splines preserve continuity in both slope and curvature, making them suitable for high-precision image reconstruction and geometric transformations. In 1D, cubic spline interpolation fits a cubic polynomial between consecutive data points:

$S_i(x) = a_i + b_i(x - x_i) + c_i(x - x_i)^2 + d_i(x - x_i)^3$

where $a_i$, $b_i$, $c_i$ and $d_i$ are coefficients for the interval $[x_i, x_{i+1}]$. These coefficients are determined by enforcing continuity constraints such that the spline passes through all data points and its first and second derivatives remain continuous at the interval boundaries, ensuring smooth changes in intensity and curvature. Boundary conditions, such as natural splines ($S''(x) = 0$) at the endpoints, further constrain the solution and stabilize the interpolation near image boundaries. In 2D image interpolation, spline functions are extended along both the $x$- and $y$-directions to generate a smooth interpolated surface over the image grid.

Different interpolation methods involve trade-offs between computational complexity, smoothness, and reconstruction quality. **Nearest-neighbor interpolation** is computationally fastest and simplest to implement, but it often produces blocky and jagged artifacts, making it suitable for real-time rendering, segmentation masks, and discrete labels. **Bilinear interpolation** provides smoother intensity transitions with moderate computational cost, although noticeable blurring may occur during high upscaling. **Bicubic interpolation** generates smoother and more natural-looking images and is widely used in high-quality image resizing and photo editing, but it is computationally slower and may introduce ringing artifacts near sharp edges. **Spline interpolation** produces highly smooth reconstructions with continuous derivatives, making it particularly suitable for medical imaging, scientific visualization, and geometric transformations, although at significantly higher computational complexity. Now, let's demonstrate the impact of interpolation methods used to increase the size of an image with upsampling.

## Upsampling and interpolation with Scipy

The scipy.interpolate module can reconstruct an approximate image from sparsely sampled pixels using interpolation. In the following implementation, the function create_interpolated_image() randomly selects nsamples pixel locations from image, extracts their intensity values, and uses scipy.interpolate.griddata() to estimate the remaining pixel values over the complete image grid (Y, X) using linear interpolation:

```
def create_interpolated_image(nsamples):
    ix = np.random.randint(im.shape[1], size=nsamples)
    iy = np.random.randint(im.shape[0], size=nsamples)
    samples = im[iy,ix]
    int_im = interpolate.griddata((iy, ix), samples, (Y, X))
    return int_im
```

> **Important**
> 
> scipy.interpolate.griddata() returns NaN for grid points outside the convex hull of the sampled points, which may produce blank regions when sample density is low.

NearestNDInterpolator performs nearest-neighbor interpolation by assigning the value of the closest valid pixel. LinearNDInterpolator performs piecewise linear interpolation by triangulating the input samples using the Qhull convex-hull algorithm and applying barycentric interpolation within each triangle. RBFInterpolator reconstructs missing values using radial basis functions (RBFs). An RBF is a scalar-valued function φ(x, c), which depends only on the distance from a reference point (center c), that is, the value of the RBF at x is φ(|| x − c ||). A popular RBF is the Gaussian function:

```
φ(r) = e^(-r² / (2σ²))
```

where r = || x − c || denotes the Euclidean distance from the center point c and σ controls the spread or smoothness of the basis function.

The default kernel in RBFInterpolator is the thin-plate spline kernel:

```
φ(r) = r² log(r)
```

The RBF interpolant is expressed as a weighted sum (linear combination) of radial basis functions centered at known data points together with a polynomial term:

```
f(x) = Σᵢ₌₁ᴺ wᵢ φ(|| x − yᵢ ||) + P(x)
```

where yᵢ are the known sample locations, wᵢ are interpolation weights, and P(x) is a low-degree polynomial of a specified degree, used for stability and smoothness, as shown in the next figure. Equivalently, the interpolant can be written in matrix form as:

```
f(x) = K(x, y) a + P(x) b
```

where K(x, y) is the matrix whose entries are φ(|| x − yᵢ ||), P(x) is the matrix of polynomial basis functions (monomials), and the coefficient vectors a and b are obtained by solving a system of linear equations.

The corrupted image and interpolation data are generated using the next code snippet:

```
im = imread('images/lady.png', as_gray=True)
h, w = im.shape
x, y = np.arange(h), np.arange(w)
np.random.seed(11)
mask = np.random.random(im.shape) > 0.6 # corrupt some values
im[mask] = np.nan
np.sum(mask) / np.prod(mask.shape) # prop corrupted
valid_mask = ~np.isnan(im)
coords, values = np.array(np.nonzero(valid_mask)).T, im[valid_mask]
```

Here, `mask` randomly selects corrupted pixels, `valid_mask` identifies uncorrupted pixels, `coords` stores the coordinates of valid pixels, and `values` contains their intensity values. These known samples are then used for interpolation. The following helper function reconstructs the image by evaluating the interpolator at every pixel location:

```
def get_inpainted(coords, values, im_shape, interpolator):
    return interpolator(list(np.ndindex(im_shape))).reshape(im_shape)

im_inpainted_lin = get_inpainted(coords, values, im.shape, \
    interpolate.LinearNDInterpolator(coords, values, fill_value=0))
im_inpainted_nn = get_inpainted(coords, values, im.shape, \
    interpolate.NearestNDInterpolator(coords, values))
im_inpainted_rbf = get_inpainted(coords, values, im.shape, \
    interpolate.RBFInterpolator(coords, values, neighbors=50))
```

Here, LinearNDInterpolator estimates missing pixels using local linear relationships, NearestNDInterpolator copies the nearest valid intensity value, and RBFInterpolator reconstructs pixels from weighted radial basis functions. Since RBF interpolation requires solving large linear systems whose memory and computational cost grow approximately quadratically with the number of known pixels, interpolation over large images can become expensive. The neighbors=50 parameter restricts interpolation to local neighborhoods, significantly reducing memory usage and computational complexity for large images.

The mean squared error (MSE) between the original and inpainted (reconstructed) images is computed using the get_MSE() function to quantify the reconstruction accuracy and compare the algorithms:

```
def get_MSE(im_orig, im_inpainted):
    return np.linalg.norm(im_orig - im_inpainted)**2 / np.prod(im_orig.shape)
```
