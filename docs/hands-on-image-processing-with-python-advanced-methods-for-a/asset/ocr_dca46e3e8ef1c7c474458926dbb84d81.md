# FFT with the numpy.fft module

Using the numpy.fft module, the 2D DFT of an image can similarly be computed with fft2(), while ifft2() reconstructs the image from its Fourier coefficients, as in the next code. The magnitude spectrum, |F(u, v)|, typically concentrates at low frequencies, whereas the phase, ∠F(u, v), encodes important structural and spatial information. The Fourier coefficients are complex-valued and can be expressed as:

$$F(u,v)=|F(u,v)|e^{j\angle F(u,v)},$$

allowing reconstruction from magnitude and phase separately using IDFT.

```
```python
im1 = rgb2gray(imread('images/house.png'))
im2 = rgb2gray(imread('images/house2.png'))
freq1, freq2 = np.fft.fft2(im1), np.fft.fft2(im2)
im1_hat, im2_hat = np.fft.ifft2(freq1).real, np.fft.ifft2(freq2).real
