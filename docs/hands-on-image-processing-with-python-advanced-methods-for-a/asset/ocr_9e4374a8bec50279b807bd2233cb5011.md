# With `scikit-image.transform.ProjectiveTransform`

In `scikit-image`, `ProjectiveTransform` is a class that represents a 2D projective transformation, which can be used to perform geometric transformations on images, such as rotation, scaling, translation, and skewing. You create an instance of `ProjectiveTransform` by providing a transformation matrix:

+   - The transformation matrix (3x3) can also be estimated using the `estimate()` method of `ProjectiveTransform`. It estimates the transformation matrix, *M*, from a set of corresponding points (from the source and destination images). The parameters are determined with the total least-squares method. The number of source and destination coordinates must match. Also note that the coordinates must be rearranged from (x, y) to (y,x) format first. Finally, use the `inverse()` method to return a transform object representing the inverse.
+   - The `warp_perspective()` function in the next code snippet (defined with **type annotations**) again implements the homography. It uses `ProjectiveTransform` to map source image pixels to a new perspective defined by destination points, using the following steps:
+     - It first estimates the projective transform (`inverse_map`) from the set of matching points, `src_pts` and `dst_pts`, from the sources and destination images, respectively.
+     - Then, it uses the inverse transformation to obtain the source coordinates corresponding to each point in the destination image. It warps a mesh grid of destination coordinates back to the source using the inverse transform (it also clips the coordinates).
