
Here are the key steps:

Read the input image and **downsample** it for efficiency. Use the function `felzenszwalb()` from the `skimage.segmentation` module to implement **graph-based segmentation**. Here is how it works under the hood:

- **1. Building graph:** The image is first modeled as an undirected graph

  $$G=(V,E),$$

  where $V$ represents pixels (each pixel is a node), $E$ represents edges between neighboring pixels (e.g., 4- or 8-connectivity) and $w(i,j)$ represents edge weight measuring dissimilarity (e.g., color/intensity difference).

- **2. Formation of components:** Initially, each pixel forms its own component:

  $$C_i=\{i\}.$$

  Edges are sorted in **non-decreasing order of weight**, and components are iteratively merged following a greedy strategy (similar to building a Minimum Spanning Tree).

- **3. Inter-component dissimilarity:** Minimum edge weight connecting the two components $C_1$ and $C_2$ is:

  $$D(C_1,C_2)=\min_{i\in C_1,\,j\in C_2} w(i,j)$$

  which can be used as a measure of inter-region similarity.

- **4. Merge criterion:** Merge $C_1$ and $C_2$ if the following condition holds:

  $$D(C_1,C_2)\leq\min(\operatorname{Int}(C_1)+\tau(C_1),\ \operatorname{Int}(C_2)+\tau(C_2)),$$

  where $\operatorname{Int}(C)=\max_{e\in MST(C)}w(e)$ refers to the internal difference of component $C$ (intra-region variation), defined as the **maximum edge weight inside the MST** (Minimum Spanning Tree) of $C$, so that small $\operatorname{Int}(C)\rightarrow$ very homogeneous region and large $\operatorname{Int}(C)\rightarrow$ more variation inside region.

  $\tau(C)=\frac{k}{|C|}$ is an adaptive threshold, $k$ is the scale parameter controlling segmentation granularity and $|C|$ is the number of pixels in component $C$.

- **5. Component growth:** Start with **single-pixel components**. Merge neighboring components if they are similar (low edge weight) and their internal variation is small. Larger components require stronger evidence to merge due to $\tau(C)$. Components grow adaptively from pixels into regions, ensuring that merging stops at perceptually meaningful boundaries, yielding efficient and edge-preserving segmentation. Use the function `quickshift()` to implement segmentation with mode-seeking clustering. It treats each pixel as a point in joint spatial–color space $(x,y,I)$ and performs **kernel density estimation (KDE)**:

  $$p(z)=\sum_i K\left(\frac{\lVert z-z_i\rVert^2}{h^2}\right),$$

  where $z=(x,y,I)$: feature vector, $K$: kernel (e.g., Gaussian) and $h$: bandwidth (controls neighborhood size). Each pixel is then linked to its nearest neighbor with higher density, forming a tree; clusters (segments) emerge as pixels converge to the same density mode (local maximum). Pixels “shift” toward high-density regions, grouping into segments without specifying the number of clusters.

Use functions `watershed()` and `slic()` to implement watershed segmentation and SLIC superpixelation, respectively, as shown in the next code snippet:

## Variational and energy-based segmentation

Variational methods formulate image segmentation as an **energy minimization problem**, where the goal is to find an optimal partition (or representation) that balances **data fidelity** and **regularity**:

$$E = E_{\text{data}} + \lambda E_{\text{regularization}},$$

where $E_{\text{data}}$: ensures similarity to the observed image, $E_{\text{regularization}}$: enforces smoothness or structural constraints and $\lambda$: trade-off parameter. These methods are deeply rooted in the **calculus of variations**, leading to **Euler–Lagrange PDEs** and iterative optimization.

### Chan–Vese active contours

The Chan–Vese model is a **region-based active contour method** that does **not rely on image gradients**, making it robust to weak or missing edges.

- **Energy functional:**

  $$E(c_1, c_2, C) = \mu \cdot \text{Length}(C) + \lambda_1 \int_{\text{inside}(C)} |I - c_1|^2 dx + \lambda_2 \int_{\text{outside}(C)} |I - c_2|^2 dx,$$

  where $C$: contour (segmentation boundary), $c_1, c_2$: mean intensities inside/outside, $\mu$: smoothness weight, $\lambda_1, \lambda_2$: data fidelity weights.

- **Level set formulation:** The contour $C$ is represented implicitly using a **level set function** $\phi(x, y)$:

  $$C = \{(x, y) \mid \phi(x, y) = 0\}$$

  Using the Heaviside function $H(\phi)$, the energy becomes:

  $$E(\phi) = \mu \int |\nabla H(\phi)| dx + \lambda_1 \int |I - c_1|^2 H(\phi) dx + \lambda_2 \int |I - c_2|^2 (1 - H(\phi)) dx$$

- **Euler–Lagrange evolution:** Minimization leads to the following gradient update,

  $$\frac{\partial \phi}{\partial t} = \delta(\phi) \left[ \mu \text{div}\left(\frac{\nabla \phi}{|\nabla \phi|}\right) - \lambda_1 (I - c_1)^2 + \lambda_2 (I - c_2)^2 \right]$$

The next code snippet implements the Chan–Vese segmentation: use the function `chan_vese()` from the `skimage.segmentation` module. The key parameters are `mu` (smoothness, controls contour regularity), `lambda1`, `lambda2` (region fitting weights), `init_level_set` (initial contour, here a checkerboard), and `extended_output` (the function returns the segmentation mask, and optionally the level set function and energy history when `extended_output=True`). As shown in the next code snippet, it returns a tuple of 3 elements: segmentation (`cv[0]`: final binary mask, 1 → inside region, 0 → outside region), level set function (`cv[1]`: the final implicit contour $\phi(x, y)$, zero level defines the boundary) and energy evolution (`cv[2]`: list of energy values over iterations, used to monitor convergence).

### Mumford–Shah functional

The Mumford–Shah model is a **foundational variational framework** for segmentation and edge detection.

- **Functional definition:**

  $$E(u,\Gamma)=\int_{\Omega}|I-u|^2dx+\lambda\int_{\Omega\setminus\Gamma}|\nabla u|^2dx+\nu|\Gamma|,$$

  where $u(x)$: piecewise smooth approximation of image, $\Gamma$: edge set (discontinuities) and $|\Gamma|$: length of edges. Here, **Data term**: fidelity to image (1st term), **Smoothness term**: piecewise smooth regions (2nd term) and **Edge term**: penalizes boundary complexity (3rd term). The algorithm balances **denoising + segmentation + edge detection**.

- **Ambrosio–Tortorelli approximation:** Direct minimization is difficult, so it’s approximated by introducing auxiliary variable $v(x)$:

  $$E(u,v)=\int\left[\beta(u-f)^2+\alpha v^2|\nabla u|^2+\frac{1}{2}\left(\rho|\nabla v|^2+\frac{(1-v)^2}{\rho}\right)\right]dx,$$

  where $v(x)\approx 0$ at edges, $v(x)\approx 1$ in smooth regions and $\rho\to 0$: sharp edge approximation.

- **Euler–Lagrange PDEs:**

  $$\frac{\partial u}{\partial t}=\nabla\cdot(v^2\nabla u)-\frac{\beta}{\alpha}(u-f),\qquad \frac{\partial v}{\partial t}=\nabla^2v-\frac{2\alpha|\nabla u|^2v}{\rho}-\frac{v-1}{\rho^2}$$
