Convert rgb `[0,255]` to cmy `[0,1]`. Extract out black component k. Finally, the CMYK values to a desired range of `[0, CMYK_SCALE]` for storage or processing.

```python
RGB_SCALE, CMYK_SCALE = 255, 100

def rgb2cmyk(x):
    r, g, b = x[...,0], x[...,1], x[...,2]
    c, m, y = 1 - r / RGB_SCALE, 1 - g / RGB_SCALE, 1 - b / RGB_SCALE
    min_cmy = np.minimum(np.minimum(c, m), y)
    c, m, y, k = (c - min_cmy) / (1 - min_cmy), \
                  (m - min_cmy) / (1 - min_cmy), \
                  (y - min_cmy) / (1 - min_cmy), min_cmy
    return np.dstack((c * CMYK_SCALE, m * CMYK_SCALE, y * CMYK_SCALE, \
                      k * CMYK_SCALE))

def colorize(im, hue, saturation=1):

## Creating color pop effect with HSV manipulation

The color pop effect creates a dramatic appearance by converting most of an image to grayscale while preserving selected colors. This technique is conveniently implemented in the HSV color space, where reducing the saturation channel to zero produces grayscale regions.

The next code snippet converts an RGB image to HSV, filters pixels based on hue values, and sets the saturation channel to zero for all regions except selected colors. Since orange-like colors typically have low hue values, preserving pixels with hue ≤ 0.09 retains human skin tones while converting the remaining regions to grayscale. The modified HSV image is then converted back to RGB to obtain the final color pop effect.

```
im = imread('images/me.jpg')
im = im / im.max()  # normalize
im_hsv = color.rgb2hsv(im)
im_gray = im_hsv.copy()
im_gray[...,1] = 0  # set saturation of the pixels to 0
im_gray = color.hsv2rgb(im_gray) # creates grayscale image
im_hsv[im_hsv[...,0] > 0.09,1] = 0 #set all but skin pixel saturation to 0
im_out = color.hsv2rgb(im_hsv) # creates RGB image with all but
# skin pixels grayed out (popping the skin pixels out)
plt.imshow(np.hstack((im,im_gray,im_out)))
```

## Color enhancement in the RGB color space

One way to enhance color contrast in the RGB color space is to increase the separation between dominant and weaker color channels, making colors appear more vivid and visually distinguishable.

In this section let us use the transformation c′ = (c/m)^f m on an RGB image for enhancement of color, where c ∈ {r, g, b}, m = max(r, g, b) and f controls enhancement strength here. When a channel already

has maximum intensity (c = m), it remains unchanged, while lower-valued channels are suppressed further for f > 1, increasing inter-channel contrast.

The next code snippet demonstrates the color enhancement, obtained using the function enhance_rgb() which extracts the RGB channels, computes the per-pixel maximum with np.maximum(), and applies the nonlinear enhancement (c/m)^f m, and assigns the enhanced values back to the image channels. The parameter f=4 controls the enhancement level. The demonstration loads an RGB Ishihara image using imread(), applies enhancement with enhance_rgb(), converts both original and enhanced images to grayscale using color.rgb2gray(), and visualizes them with plot_images(). The enhanced grayscale image reveals digits that are barely visible in the grayscale version of the original image.

```
def enhance_rgb(im, f=4):
    r, g, b = im[...,0], im[...,1], im[...,2]
    m = np.maximum(np.maximum(r, g), b)
    im[...,0], im[...,1], im[...,2] = (r/m)**f*m, (g/m)**f*m, \
                                    (b/m)**f*m
    return im

im = imread('images/Ishihara.png')
im_en = enhance_rgb(im)
plot_images([im, color.rgb2gray(im), im_en, color.rgb2gray(im_en)], \
            ['original', 'grayscale from original', 'enhanced image', \
             'grayscale from enhanced'])
```
