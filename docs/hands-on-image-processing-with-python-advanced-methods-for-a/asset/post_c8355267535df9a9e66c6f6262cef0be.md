# Changing the image quality/resolution of a JPEG image

The following code demonstrates how the quality parameter of the Image.save() method controls JPEG compression quality and file size. JPEG uses lossy compression to reduce storage by discarding image details that are less perceptible to the human eye. Internally, Pillow converts the image from RGB to YCbCr color space, applies chroma subsampling (for example, 4:2:0), divides the image into 8 × 8 blocks, and applies the Discrete Cosine Transform (DCT). Intuitively, the DCT converts image blocks into frequency components, concentrating most visual information into low-frequency coefficients while fine details correspond to high frequencies. Lower quality settings quantize these high-frequency components more aggressively, producing smaller files but introducing artifacts such as blocking, blurring, and ringing. We shall revisit the DCT and its mathematics in detail in Chapter 4.

The code saves the image with quality values 95, 20, 5 and 1, demonstrating the trade-off between visual fidelity and compression ratio. Higher quality preserves details, whereas lower quality increases compression and visible degradation. File sizes and compression ratios are computed using os.path.getsize() to quantitatively compare storage efficiency.

```
im = Image.open('images/parrot.jpg')
qualities = [95, 20, 5, 1]
for quality in qualities:
    im.save(f"images/parrot_{quality}.jpg", quality=quality)
plt.imshow(np.hstack([imread(f"images/parrot_{quality}.jpg") \
    for quality in qualities]))
```

You can compare the compressed file sizes (in kilobytes), or the compression ratio (the ratio of the original file size to the compressed file size), to demonstrate the trade-off between JPEG quality and compression, which will help you quantitatively understand the compression trade-off, using the following code snippet.

original_size = os.path.getsize("images/parrot.jpg")
for quality in qualities:

# Why is the compression ratio < 1 when re-saving a JPEG at quality 95?

The original JPEG might already be highly compressed. Most images downloaded from the web or captured by phones/cameras are already saved with an optimal trade-off between quality and size—often at a quality setting around 75-85, or even lower.

When using Image.save() with a PNG image, the quality parameter will be ignored since PNG uses lossless compression. To control PNG file size, use the compress_level parameter (0-9) instead of the quality parameter, where higher values apply stronger compression.

# Deforming an image

The next code snippet applies a wave-like geometric (sinusoidal mesh) deformation to the image, creating a wave-like ripple distortion effect. It uses `ImageOps.deform()` and a custom `WaveDeformer` class. The `transform()` method modifies pixel coordinates with a sinusoidal function, creating horizontal ripple distortions. The `transform_rectangle()` method applies this mapping to the four corners of a rectangular image patch, while `getmesh()` divides the image into a grid of rectangles (gridspace=20), computes their deformed positions, and returns the mesh mapping required by `ImageOps.deform()`. Applying the deformation produces a smooth, organic warping effect that resembles ripples, water waves, or heat distortion:

```
```python
class WaveDeformer:

    def transform(self, x, y):
        y = y + 20*np.sin(x/15)
        return x, y

    def transform_rectangle(self, x0, y0, x1, y1):
        return (*self.transform(x0, y0),
                *self.transform(x0, y1),
                *self.transform(x1, y1),
                *self.transform(x1, y0),
                )

    def getmesh(self, img):
        self.w, self.h = img.size
        gridspace = 20
        target_grid = []
        for x in range(0, self.w, gridspace):
            for y in range(0, self.h, gridspace):
                target_grid.append((x, y, x + gridspace, \
                                    y + gridspace))
        source_grid = [self.transform_rectangle(*rect) \
                       for rect in target_grid]
        return [(t for t in zip(target_grid, source_grid))]

im = Image.open('images/monalisa.jpg')
im_deformed = ImageOps.deform(im, WaveDeformer())
plt.imshow(
    np.hstack((np.array(im), np.array(im_deformed)))
)
plt.axis('off')
```
