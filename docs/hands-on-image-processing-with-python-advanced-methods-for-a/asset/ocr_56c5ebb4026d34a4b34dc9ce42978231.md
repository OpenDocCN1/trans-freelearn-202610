# More Deep Learning Methods for Image Segmentation

Building upon classical and deep-learning-based segmentation techniques discussed in the last chapter, this chapter continues exploring the next generation of deep learning approaches that emphasize flexibility, generalization, and real-world deployment. We begin with promptable foundation models such as SAM and MaskCLIP, which enable segmentation through minimal user input or textual guidance, followed by vision–language and diffusion-based methods that bridge semantics and generative modeling.

The chapter then transitions to practical applications, demonstrating how segmentation is used in tasks like background manipulation and object detection with industrial-grade frameworks. A dedicated focus is placed on training custom models, including U-Net variants and modern backbones, extending further to domain-specific applications such as medical imaging (MRI, CT) and remote sensing with multi-source satellite data. Finally, we address 3D segmentation and visualization, along with a rigorous treatment of evaluation metrics (IoU, Dice, mAP), equipping the reader with both theoretical understanding and practical tools to design, train, and assess segmentation systems across diverse real-world scenarios.

In this chapter, we will learn about the following key topics:

+   - Promptable foundation models for image segmentation
+   - Depth estimation and 3D scene understanding from a single image
+   - Practical applications of image segmentation
+   - Training a custom segmentation model
+   - 3D segmentation of liver CT images with Swin-UNETR
+   - Remote sensing: Multi-source satellite imagery segmentation with mixed-attention UNet
+   - Segmentation evaluation metrics
