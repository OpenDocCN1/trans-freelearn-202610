## Image manipulation with scikit-image

scikit-image is a collection of algorithms for image processing and computer vision that is built on top of NumPy, SciPy, and Matplotlib. It provides a variety of functions for image manipulation, filtering, and analysis. Here are some common image manipulation tasks that can be performed using scikit-image.

### Inverting an image

Image inversion means **flipping the intensity values** of each pixel. If an image has pixel intensities ranging from 0 (black) to \(L - 1\) (white), the inversion formula is as follows:

$$I_{neg}(x,y) = L - 1 - I(x,y)$$

Here, \(L\) is the number of different intensity values, as in these examples:

- \(L = 256\) for an 8-bit grayscale image (pixel values in \([0,255]\))
- \(L = 2\) for a floating-point image normalized to \([0,1]\)

> **Note**
>
> If the image pixel values are not already scaled appropriately, a normalization step (e.g., mapping to \([0,1]\) or \([0,255]\)) should be performed before applying the inversion formula to avoid incorrect results.

In general, a **transfer function** defines how an input image’s pixel values are transformed into output pixel values. It is a function that maps each input intensity \(I_{in}\) to an output intensity \(I_{out}\):

$$I_{out}=T(I_{in})$$

Here, \(T\) is the transfer function that dictates how pixel intensities are modified. The transfer function for **inversion** is as follows:

$$I_{out}=T(I_{in})=L-1-I_{in}$$

We can simply use the `invert()` function from the `skimage.util` module to get the negative of an image, as shown in the following code:

```python
from skimage.util import invert
im = im / im.max()  # normalize in the range [0,1]
np.allclose(1 - im, invert(im))
# True
```

### Inverse warping and geometric transformation using the warp() function

Geometric image transformations modify the spatial arrangement of image pixels to perform operations such as translation, rotation, scaling, shearing, affine, and projective transformations. These operations are widely used in image registration, alignment, rectification, perspective correction, object tracking, and panorama stitching. In scikit-image, the `skimage.transform.warp()` function performs inverse warping by mapping output pixels back to corresponding locations in the input image using a transformation matrix or transformation function.

The `warp()` function accepts several important parameters: `image` specifies the input image; `inverse_map` defines the transformation as a callable function, transformation object (such as AffineTransform), or a 3×3 homogeneous transformation matrix; `map_args` passes additional parameters to the transformation function; `output_shape` controls the size of the transformed image; and `order` determines interpolation quality (for example, nearest-neighbor, bilinear, or bicubic interpolation).

#### Applying translation to an image

The `skimage.transform.warp()` function from the scikit-image library is a versatile function that can apply various geometric transformations. The function performs a transformation on an image by mapping input coordinates to output coordinates using a transformation matrix or a function. The basic operation of `warp()` can be expressed as \(I'(p') = I(T^{-1}(p'))\). Here, \(I(p)\) is the original image at coordinates \(p = (x, y)\), and \(I'(p')\) is the transformed image at the new coordinates \(p' = (x', y')\).

\(T^{-1}(p')\) is the inverse of the transformation applied, meaning that for each pixel in the output image at location \(p'\), the function computes the corresponding coordinates in the original image, \(p\), by applying the inverse transformation, \(T^{-1}\).

#### Translation of an image

A translation moves every pixel in the image by a constant displacement in both the `x` and `y` directions. Mathematically, the translation can be expressed using a transformation matrix.

##### Transformation matrix for translation

The translation operation is represented by a simple 3x3 transformation matrix:

$$T = \begin{bmatrix}1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1\end{bmatrix}$$

Here, \(t_x\) is the horizontal translation (shift along the \(x\) axis), and \(t_y\) is the vertical translation (shift along the \(y\) axis).

For a point, \(p = (x, y)\), in the original image, its new position, \(p' = (x', y')\), after translation is given by the following:

$$\begin{bmatrix}x'\\y'\\1\end{bmatrix}=\begin{bmatrix}1 & 0 & t_x\\0 & 1 & t_y\\0 & 0 & 1\end{bmatrix}\begin{bmatrix}x\\y\\1\end{bmatrix}$$

This simplifies to \(x' = x + t_x\), \(y' = y + t_y\).

So, each pixel at \((x, y)\) in the original image moves to \((x + t_x,\ y + t_y)\) in the translated image.

##### Inverse transformation

The `warp()` function uses inverse transformation to compute the original coordinates of each pixel in the output image. It works by mapping every output pixel back to a location in the input image, ensuring there are no gaps or overlaps—a process known as inverse mapping or backward warping. This approach is essential for geometric transformations such as translation, rotation, scaling, and more, allowing accurate reconstruction without missing data.

Specifically, the inverse mapping ensures that, for each output pixel \((x, y)\), the function computes the corresponding input pixel \((x', y') = (x - t_x,\ y - t_y)\) using the inverse of the applied transformation matrix.

If a forward mapping (direct transform) were used instead, output pixels might not be filled properly (causing holes) and multiple input pixels could map to the same output pixel (causing overlaps), necessitating complex interpolation and resampling. In contrast, inverse mapping ensures every output pixel is assigned a value by sampling the correct location in the input image, often with interpolation (e.g., bilinear or bicubic) to handle non-integer mappings.
