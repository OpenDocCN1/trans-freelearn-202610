+   - `output = simple_lama(image, mask)`: This single call does the heavy lifting. Internally, it typically executes the following steps:
+     a. **Preprocessing:**
+       - Convert PIL images to NumPy arrays.
+       - Normalize the image (e.g., to [0,1] or [-1,1]).
+       - Convert mask to binary float mask in [0,1].
+       - Possibly pad/crop the image to dimensions compatible with the network (e.g., multiples of 8 or 32). Good wrappers, pad, and later remove padding.
+     b. **(Optional) Multi-scale/coarse-to-fine setup:** LaMa variants may build multi-scale inputs or resize to lower resolution for efficiency and then refine. The wrapper might do this automatically for large inputs.
+     c. **Forward pass through the model:**
+       - Convert to PyTorch tensors, move to device.
+       - `with torch.no_grad(): out = model(inp, mask)`: single forward pass producing restored tensor.
+       - Core model uses U-Net/encoder-decoder with Fourier-style global operations in some layers.
+     d. **Postprocessing:**
+       - Convert output tensor to image domain (clamp, convert to uint8).
+       - Crop/remove padding added in preprocessing.
+       - Return a PIL image or NumPy array.

The function `plot_inpainted(image, mask, output)` visualizes the original input, mask overlay, and output. This helps inspect seams and plausibility.

When using LaMa for inpainting, ensure the mask is binary (0 for keep, 255 for hole) and invert it if results look strange; feathering the mask edges with a Gaussian blur helps achieve smoother blending at boundaries. Although LaMa is resolution-robust, large images may still exceed GPU memory, so consider tiling with overlaps, using multi-scale options, or running on CPU (slower but more memory-flexible).

For faster inference, use a GPU with device='cuda' and float16 if supported, while CPU remains viable for moderate sizes. To improve quality, adjust mask feathering, crop with a larger context, or apply post-process color matching for better integration. Finally, evaluate results with metrics like PSNR, SSIM, LPIPS, or FID when ground truth exists, but rely heavily on visual inspection since inpainting quality is often subjective.

In terms of strengths, LaMa is excellent for large holes, complex semantics, and high-resolution editing. Robust to mask size (trained or designed to generalize across resolutions). Single-shot inference (fast relative to iterative optimization methods).
