## Stochastic halftoning (random dithering)

One way to reduce the false contour artefacts in thresholding (binary quantization) is to add uniformly distributed white noise to the input image prior to quantization. Specifically, to each input pixel of the grayscale image $f(x,y)$, we add an independent uniform $[-128,128]$ random number (can be represented as an independent uniform random variable $n(x,y)\sim U(-\Delta,\Delta)$), and then apply thresholding. This can be expressed as:

$$g(x,y)=1(f(x,y)+n(x,y)\geq T)$$

where $1(\cdot)$ represents the indicator function which equals 1 if the condition is true and 0 otherwise, T is the threshold, and $\Delta$ controls the noise amplitude (e.g., $\Delta=128$ for 8-bit images).

This technique is commonly referred to as **random dithering**, and can be considered a simple form of **halftoning**, where noise is used to break up large uniform regions and simulate intermediate gray levels through spatial variation.

Instead of forcing all pixels into rigid black-or-white regions (which creates banding), the added noise causes neighboring pixels to randomly flip across the threshold. When viewed at a distance, these random patterns are perceived by the human visual system as smooth gray levels, thereby reducing visible contour artifacts.

## Dithering

While random noise addition (as discussed in halftoning) reduces visible banding, it does so in an unstructured manner. More generally, **dithering** refers to techniques that deliberately modify pixel values prior to or during quantization so that the resulting quantization error is distributed spatially, rather than concentrated in large uniform regions. This redistribution helps break up artificial patterns such as false contours and produces the perceptual illusion of intermediate gray levels. Dithering can be implemented in different ways, including **random dithering**, **ordered dithering**, and **error diffusion methods**, each offering a different trade-off between visual quality and computational complexity.

## Floyd–Steinberg dithering with error diffusion

The Floyd–Steinberg algorithm performs dithering by diffusing quantization error forward in the scan direction, ensuring that local errors are compensated by future pixel decisions. It pushes (adds) the residual quantization error of a pixel onto its neighboring pixels, to be dealt with later. It spreads the quantization error out according to the distribution shown in the following figure, as a map of the neighboring pixels:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_316_1.png)

*Figure 7.9 – Spreading quantization error with Floyd-Steinberg error-diffusion dithering*

In the previous figure, the current pixel is represented with a star (*) and the blank pixels represent the previously-scanned pixels. The algorithm scans the image from left to right and top to bottom. It sequentially quantizes the pixel values one by one; each time, the quantization error is distributed among the neighboring pixels (yet to be scanned), while not affecting the pixels that already got quantized. If several pixels have been rounded downward, it becomes more likely that the following pixel will be rounded upward by the algorithm so that the average quantization error is close to zero.

Let $f(x,y) \in [0,1]$ denote the input grayscale image and $g(x,y) \in \{0,1\}$ the binarized output.

At each pixel $(x,y)$, we define $\tilde{f}(x,y)=f(x,y)+e(x,y)$ where $e(x,y)$ is the accumulated error propagated from previously processed pixels.

Here are the key steps:

- **Quantization step:** The pixel is quantized to the nearest palette value (for binary images, threshold at $T=0.5$ is):
  
  $$g(x,y)=1\bigl(\tilde{f}(x,y)\ge T\bigr)$$

- **Quantization error:** The quantization error at $(x,y)$ is:
  
  $$\varepsilon(x,y)=\tilde{f}(x,y)-g(x,y)$$

- **Error diffusion:** This error is distributed to neighboring unprocessed pixels according to fixed weights:
  
  $$e(x+1,y)\mathrel{+}=\frac{7}{16}\varepsilon(x,y),\quad e(x-1,y+1)\mathrel{+}=\frac{3}{16}\varepsilon(x,y)$$
  $$e(x,y+1)\mathrel{+}=\frac{5}{16}\varepsilon(x,y),\quad e(x,y+1)\mathrel{+}=\frac{1}{16}\varepsilon(x,y)$$

- **Conservation property:** The weights satisfy $\frac{7}{16}+\frac{3}{16}+\frac{5}{16}+\frac{1}{16}=1$, ensuring that the total quantization error is conserved and redistributed, rather than lost

Unlike random dithering, which introduces *stochastic noise*, Floyd–Steinberg uses deterministic, structured error redistribution, leading to:

- Better preservation of image structure
- Reduced noise appearance
- Higher perceptual quality

Next, the Python code implements FS dithering. Listed below are the key tasks performed in the code:

1. **Color quantization (find_closest_palette_color)**: This function maps a pixel to its closest value from a reduced set of gray levels. For num_colors = k, the function creates a palette with gray levels at equal steps between 0 and 255: $step = \frac{255}{k-1}$. So, the pixel intensity is rounded to the nearest of these k gray levels.
2. **Dithering (get_dithered_image)**: The algorithm visits each pixel and quantizes it to the nearest palette gray level. It computes the quantization error:
   
   $error = original - quantized$
   
   and distributes the error to neighboring pixels based on fixed weights, as shown in the pseudocode. This error diffusion gives the illusion of intermediate intensities even when the image is limited to only k gray levels.
3. **Final quantization and clipping**: After error diffusion, the image is again quantized to exactly k gray levels. Pixel values are clipped to [0, 255] and cast to uint8.
4. **Validation**: The code prints the unique gray levels in the dithered image using np.unique(dithered). This confirms that the output adheres to the expected k palette levels.

Now, refer to the next code snippet:

```
def find_closest_palette_color(old_pixel, num_colors=2):
    step = 255 / (num_colors - 1)
    return np.round(old_pixel / step) * step

def get_dithered_image(image, num_colors):
    dithered = np.copy(image)
    h, w = dithered.shape
    for x in range(h):  # Floyd-Steinberg Dithering
        for y in range(w):
            old_pixel = dithered[x, y]
            new_pixel = find_closest_palette_color(old_pixel, num_colors)
            dithered[x, y] = new_pixel
            quant_error = old_pixel - new_pixel
            if y + 1 < w:
                dithered[x, y + 1] += quant_error * 7 / 16

To summarize:

- The algorithm processes pixels in a **causal scan order** (left-to-right, top-to-bottom).
- Already quantized pixels remain unchanged.
- Future pixels are **biased by past errors**, encouraging compensation. If earlier pixels were rounded down, future pixels tend to round up. This maintains the **local average intensity**, producing visually smooth results without banding.
