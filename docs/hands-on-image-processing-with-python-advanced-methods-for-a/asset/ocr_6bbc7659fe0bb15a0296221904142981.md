# MaskCLIP: Language-aligned segmentation

Contrastive Language–Image Pretraining (CLIP) learns a shared embedding space for images and text by training two encoders with a contrastive loss: matching image–caption pairs are pulled together while mismatched pairs are pushed apart, enabling zero-shot recognition by comparing similarity scores.

MaskCLIP extends segmentation into the vision–language domain, combining ideas from CLIP and segmentation transformers, by aligning dense image features (pixel/region embeddings) with text embeddings, so each pixel (or mask) is assigned the label whose text description is most similar, effectively enabling text-driven, open-vocabulary segmentation without explicit per-class training.

Here’s the mathematical perspective. Let the image embedding be F = E_I(I) and text embedding be T = E_T(t).

Then segmentation becomes:

S(x, y) = argmax_c ⟨F_{x,y}, T_c⟩

i.e., pixel–text similarity matching.
