# More edge detectors with scikit-image

There are quite a few different edge detection operators used in image processing algorithms; all of them are discrete (first or second order) differentiation operators, and they try to approximate the gradient of the image intensity function (for instance, the Sobel operator, which we discussed previously). The kernels shown in the following diagram are a few popular ones used for edge detection. For example, popular derivative filters approximating the first order image derivatives are Sobel, Prewitt, Scharr, and Roberts filters, whereas a derivative filter approximating the second order derivatives is the Laplacian:

Figure 8.10 – Prewitt, Sobel, Scharr, Roberts, and Laplacian (edge detection) kernels

As discussed in the scikit-image documentation, the finite-difference approximations of the gradient computed by different operators are different. For example, the Sobel filter in general performs better than the Prewitt filter, whereas the Scharr filter results in less rotational variance than the Sobel filter. The following code block applies different edge detector filters on the Golden Gate grayscale image and shows the gradient magnitudes obtained:

```

edges_rob = filters.roberts(im)
edges_sch = filters.scharr(im)
edges_sob = filters.sobel(im)
edges_pre = filters.prewitt(im)
edges_lap = np.clip(filters.laplace(im), 0, 1)
```
