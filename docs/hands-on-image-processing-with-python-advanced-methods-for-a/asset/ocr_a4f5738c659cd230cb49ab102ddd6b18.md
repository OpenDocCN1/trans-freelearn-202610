# Converting from one color space to another

We can convert from one color space to another using library functions. For example, the code in the following subsection converts an RGB color space to an HSV color space image, using the `color.rgb2hsv()` function.

# RGB to HSV

HSV color space is often preferred for tasks such as color filtering or object tracking because it’s easier to isolate color properties. The next figure compares the RGB and HSV color spaces. The RGB cube (left) represents colors as combinations of red, green, and blue intensities, forming a cube where each axis corresponds to one color channel. The HSV cylinder (right) models color more in line with human perception, with *Hue* (color type) as the angle, *Saturation* (color intensity) as the radius, and *Value* (brightness) as the height, as shown in the next figure:

![](bbox=[0.25, 0.338, 0.792, 0.526])

*Figure 1.20 – RGB versus HSV color space*

We can convert the RGB image to HSV color space using the next code snippet, using the `color.rgb2hsv()` function. The next figure shows the parrot HSV image, created by running the following code snippet:

```
im = imread("images/parrot.png")
im_hsv = color.rgb2hsv(im)
# plot 3 channels of im_hsv here (e.g., im_hsv[...,0]) side-by-side here
```
