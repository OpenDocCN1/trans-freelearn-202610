
**Limitations:** Training remains computationally intensive, mode collapse can still occur (mode collapse occurs when a GAN generator learns to produce limited varieties of samples while ignoring large portions of the true data distribution), and FID does not perfectly correlate with human perception.

Overall, cGANs provide strong controllability and high-fidelity sample generation through adversarial learning, but their training complexity and instability motivate alternative probabilistic approaches such as CVAEs, which we introduce next for more stable but smoother conditional generation.

## Conditional image generation with Conditional Variational AutoEncoder (CVAE)

While cGANs generate images through an adversarial game between a generator and a discriminator, **Variational Autoencoders (VAEs)** learn a probabilistic latent representation of the data and generate new samples by decoding latent vectors drawn from a learned distribution. A **Conditional Variational Autoencoder (CVAE)** extends the VAE by incorporating class labels into both the encoder and decoder, enabling controlled image generation. Given a latent variable $z$, image $x$, and class label $y$, a CVAE models the conditional distribution $p_\theta(x|z,y)$, allowing images from a desired category to be synthesized by specifying the label $y$.

Unlike GANs, which may suffer from mode collapse, CVAEs explicitly regularize the latent space to follow a known prior distribution, typically a standard Gaussian. This results in a smooth and interpretable latent manifold that supports interpolation, visualization, and semantic manipulation.

**CVAE Architecture:** The architecture consists of three main components:

- **Encoder:** maps an image-label pair $(x,y)$ to a latent distribution
- **Reparameterization Layer:** samples a latent code $z$
- **Decoder:** reconstructs the image conditioned on both $z$ and $y$

The encoder predicts the mean and variance of the latent distribution:

$q_\phi(z|x,y) = \mathcal{N}(\mu(x,y), \sigma^2(x,y)),$

Where $\mu$ and $\sigma$ are learned by neural networks. The decoder models $p_\theta(x|z,y)$, which reconstructs or generates images conditioned on the latent code and class label. The CVAE class in the next code snippet implements a Conditional Variational Autoencoder that learns a class-conditioned latent representation of Fashion-MNIST images:

def reparameterize(self, mu, logvar):
    std = torch.exp(0.5 * logvar)
    return mu + torch.randn_like(std) * std

def decode(self, z, y):
    y = self.label_fc(F.one_hot(y, NUM_CLASSES).float())
    return self.decoder(torch.cat([z, y], dim=1))

    mu, logvar = self.encode(x, y)
    z = self.reparameterize(mu, logvar)

**Conditioning on Class Labels:** Class labels are first converted to one-hot vectors and projected into a continuous embedding space (`self.label_fc`). The label embedding is concatenated with the image features in the encoder and with the latent vector in the decoder. This conditioning mechanism enables the model to learn class-specific latent distributions and generate images belonging to a desired Fashion-MNIST category.

**Encoder:** The encoder receives a flattened 28 × 28 image together with the embedded class label. Rather than directly producing a latent vector, the encoder predicts the parameters of a Gaussian distribution:

$$\mu = f_\mu(x,y), \log \sigma^2 = f_\sigma(x,y)$$

**Reparameterization Trick:** Sampling directly from a Gaussian distribution would prevent gradients from propagating through the network. The VAE therefore uses the reparameterization trick. Mathematically,

$$z = \mu + \sigma \odot \epsilon, \qquad \epsilon \sim \mathcal{N}(0, I)$$

This formulation preserves differentiability and enables end-to-end training using backpropagation.

**Decoder:** The decoder reconstructs the image from the latent code and class embedding. Generation is performed as:

$$\hat{x} = D(z,y),$$

Where $D$ denotes the decoder network.

**CVAE Loss Function:** The CVAE objective combines reconstruction accuracy with latent-space regularization. The reconstruction term ensures faithful data generation, while the KL-divergence regularizes the latent space to follow a smooth prior distribution, enabling meaningful interpolation and sampling in the CVAE framework.

```
def cvae_loss(recon, x, mu, logvar):
    recon_loss = F.binary_cross_entropy(recon, x, reduction="sum")
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + BETA * kl
```

The complete loss is:

$$L = L_{\text{recon}} + \beta L_{\text{KL}},$$

where $L_{\text{recon}} = -\sum_i x_i \log \hat{x}_i + (1 - x_i)\log(1 - \hat{x}_i)$ and $L_{\text{KL}} = D_{KL}(q_\phi(z|x,y) \| \mathcal{N}(0,I))$.

The hyperparameter $\beta$ controls the trade-off between reconstruction fidelity and latent-space smoothness.

**Adversarial-Free Training:** Unlike GANs, CVAEs require only a single network and do not involve a discriminator. This contrasts with the adversarial training paradigm used in cGANs, where a generator and discriminator compete, highlighting CVAEs as a more stable but typically less sharp alternative within the broader family of conditional generative models. Training therefore consists of a standard forward and backward pass:

```
recon, mu, logvar = model(x, labels)
loss, recon_loss, kl = cvae_loss(recon, x, mu, logvar)
loss.backward()
optimizer.step()
```

This makes CVAEs considerably easier and more stable to train than GANs, although the generated images are often slightly blurrier.

**Class-Conditional Image Generation:** After training, images can be generated by sampling a latent vector and specifying a class label.

```
z = torch.randn(1, LATENT_DIM)
for cls in range(10):
    label = torch.tensor([cls]) # same_z_different_labels

## Cross-Class Conditional Traversal:

By fixing a latent vector *z* and linearly interpolating between two class labels, the decoder generates a smooth semantic transition from a *sneaker* to an *ankle boot*. This experiment isolates the effect of class conditioning and demonstrates that the CVAE can continuously blend object categories while preserving the underlying latent style. The next code performs a **class-conditioning interpolation** while keeping the latent vector *z* fixed. The semantic transition is driven entirely by the changing class label embedding:

$$x_{\alpha}=D(z,(1-\alpha)y_1+\alpha y_2)$$

```
# Encode one sneaker and one bag
z = torch.randn(1, LATENT_DIM, device=device)
y1 = torch.tensor([7], device=device)  # Sneaker
y2 = torch.tensor([9], device=device)  # Ankle Boot
y1_hot = F.one_hot(y1, NUM_CLASSES).float()  # One-hot labels
y2_hot = F.one_hot(y2, NUM_CLASSES).float()

with torch.no_grad():
    for a in enumerate(np.linspace(0,1,15)):
        y = (1-a)*y1_hot + a*y2_hot       # Label interpolation
        img = model.decode(z, y)
        img = img.view(28, 28).cpu()
