# Colorizing a grayscale image with a vintage look

Let’s define the colorize() function, which adds the color of the given hue to a grayscale image. By default, the saturation is set to 1 so that the colors pop. The saturation is tuned down (e.g., 0.3) to give it a vintage look, using different hue values obtained with the np.linspace() hue gradient:

```
def colorize(im, hue, saturation=1):
    hsv = color.rgb2hsv(im)
    hsv[:, :, 1], hsv[:, :, 0] = saturation, hue
    return color.hsv2rgb(hsv)

im = gray2rgb(imread('images/man.png', as_gray=True))
hue_rotations = np.linspace(0, 1, 6)
fig, axes = plt.subplots(nrows=1, ncols=7, sharex=True, sharey=True)
axes[0].imshow(im); axes[0].set_title('grayscale')
for ax, hue in zip(axes.flat[1:], hue_rotations):
    tinted_im = colorize(im, hue, saturation=0.3)
    ax.imshow(tinted_im, vmin=0, vmax=1); ax.set_axis_off()
```

The preceding code reads an input image as a grayscale image, uses the gray2rgb() function to convert the image to an RGB image, then applies different hue-based colorizations using the HSV color space.
