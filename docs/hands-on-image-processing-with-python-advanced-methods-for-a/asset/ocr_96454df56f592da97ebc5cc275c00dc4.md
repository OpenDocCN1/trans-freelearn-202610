# Note

Swin-UNETR offers a key advantage over traditional CNN-based approaches by capturing long-range spatial dependencies through self-attention, whereas CNNs are inherently limited by local receptive fields. This allows Swin-UNETR to model global 3D contextual relationships in CT volumes more effectively, leading to improved structural consistency in complex anatomical segmentation.

The pretrained BTCV segmentation bundle predicts 14 abdominal organ classes, including liver, spleen, kidneys, pancreas, stomach, aorta, and gallbladder. The model is initialized using SwinUNETR() with parameters such as in_channels=1, out_channels=14, and feature_size=48, while pretrained anatomical weights are loaded using torch.load() and model.load_state_dict(). Medical image preprocessing includes orientation normalization using Orientation(axcodes="RAS"), voxel resampling using Spacing(pixdim=(1.5,1.5,2.0)), Hounsfield-unit intensity normalization using ScaleIntensityRange(), and spatial padding using pad32() to ensure compatibility with transformer window sizes.

Since full-volume inference exceeds GPU memory limits, inference is performed using sliding_window_inference(), which partitions the CT volume into overlapping 3D patches and merges predictions smoothly. The network outputs voxel-wise logits for 14 organ classes, which are converted into probabilities using torch.softmax() and final segmentation labels using .argmax(1).

The code extracts liver-containing axial slices using np.where(seg==6) and visualizes original CT slices, segmentation maps, overlays, and liver spotlight renderings. The complete run_inference() pipeline performs NIfTI loading, preprocessing, transformer inference, softmax classification, and organ segmentation automatically. Finally, measure.marching_cubes() converts volumetric segmentation masks into polygonal meshes for smooth 3D anatomical surface reconstruction and visualization. The reconstructed 3D mesh enables intuitive visualization of anatomical structures in clinical planning, allowing surgeons and researchers to better understand organ morphology, spatial relationships, and patient-specific geometry for preoperative assessment and simulation.
