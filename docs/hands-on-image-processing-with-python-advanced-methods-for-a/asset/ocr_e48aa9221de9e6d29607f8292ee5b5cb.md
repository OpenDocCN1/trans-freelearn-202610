# What is an image? Mathematical and digital representation

An image can be modeled as a two-dimensional function, where each coordinate pair $(x,y)$ maps to an intensity value $f(x,y) \in \mathbb{R}$ (or $\mathbb{Z}$) representing visual information. In the single-channel case (e.g., binary or grayscale images), each pixel stores one intensity value, while in multi-channel images such as RGB, each spatial location is represented as a vector $f(x,y) = (r(x,y), G(x,y), B(x,y))$.f(x,y)

A **pixel (pel or picture element)** is the smallest unit of an image, storing either a scalar intensity (grayscale, e.g., 0–255) or a tuple of channel values in color images, and images are organized as discrete grids of these pixels. **Color spaces** define different representations of color information, such as RGB, HSV, CMYK, or grayscale, with RGB representing each pixel as a three-component vector in red, green, and blue channels.f(x,y)

An image is represented in a computer as a **multidimensional numerical array** that encodes visual information in discrete form. A grayscale image is typically stored as a 2D matrix $I \in \mathbb{R}^{H\times W}$, where each element represents pixel intensity, while a color image (e.g., RGB or YUV) is stored as a 3D tensor $I \in \mathbb{R}^{H\times W\times C}$, with $C$ channels such as $C = 3$ for RGB. This representation arises from the process of **image digitization**, which involves two steps: **spatial sampling**, where continuous coordinates $(x,y)$ are discretized into a grid of pixels, and **amplitude quantization**, where intensity values are mapped to finite levels, typically integers in [0,255] or normalized floating-point values in [0,1].f(x,y)
