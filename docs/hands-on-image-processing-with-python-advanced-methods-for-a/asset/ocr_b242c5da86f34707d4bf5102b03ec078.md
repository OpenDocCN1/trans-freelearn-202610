**CNN Classifier:** A lightweight CNN is used for image classification.

```
class CNN(nn.Module):
    def forward(self,x):
        f = self.features(x)
        return self.classifier(f)
```

The architecture consists of convolution layers for feature extraction, max-pooling for spatial reduction and fully connected layers for classification.

**Local Client Training:** Each client trains independently using its local dataset.

```
def local_train(model, loader):
    pred = model(x)
    loss = criterion(pred, y)
    loss.backward()
```

The client never exposes its images to any other client or the server. Only learned weights are shared.

**Federated Aggregation:** After local training, the server aggregates the client models using FedAvg.

```
def fedavg(weights):
    avg = copy.deepcopy(weights[0])
    for key in avg.keys():
        for i in range(1, len(weights)):
            avg[key] += weights[i][key]
        avg[key] /= len(weights)
    return avg
```

Conceptually,

$w_{global} = \frac{1}{K} \sum_{k=1}^{K} w_k$

The resulting model becomes the new global model.

**Federated Training Loop:** Training proceeds through multiple communication rounds.

```
for r in range(rounds):
    local_weights = []
    for client_loader in clients:
        w = local_train(local_model, client_loader)
    global_model.load_state_dict(fedavg(local_weights))
```

Each round consists of

+   - Sending the global model to clients
+   - Local client training
