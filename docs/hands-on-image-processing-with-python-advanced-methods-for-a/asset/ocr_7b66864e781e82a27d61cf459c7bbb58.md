```
results = []
for person, g_emb in gallery.items():
    sim = F.cosine_similarity(q_emb, g_emb, dim=0).item() # similarity with a face g
    results.append((person, sim))
```

The identity with the highest similarity score is selected; scores below a threshold are labeled as Unknown.

```
results = sorted(results, key=lambda x: x[1], reverse=True)
top_results = results[:top_k]
best_person, best_score = top_results[0]
if best_score < threshold: final_label = "Unknown"
```

This is essentially few-shot face recognition, since only a few gallery images are needed per identity.

# Improving recognition with Siamese fine-tuning

The current implementation relies on generic ImageNet features extracted by a pretrained ResNet18. Recognition performance can often be improved by fine-tuning the encoder using contrastive loss, triplet loss, or modern face-recognition objectives such as ArcFace. For example, the contrastive loss is given by:

L = y D² + (1 − y) max(0, m − D)²

where D denotes the embedding distance and m is a margin. Such metric-learning approaches pull matching faces closer together while pushing different identities farther apart, producing substantially more discriminative embeddings.
