**Generating Adversarial Images:** The attack is applied using several perturbation strengths:

```
epsilons = [0, 0.01, 0.1, 0.2]
```

The adversarial image is generated as:

```
adv_x = input_tensor + eps * perturbations
```

corresponding to $x_{adv} = x + \epsilon.\operatorname{sign}(\nabla_x J)$. Larger values of $\epsilon$ produce stronger attacks.

**Valid Pixel Constraints:** After perturbation, the image must remain within the valid pixel range.

```
adv_x = torch.clamp(adv_x, -1, 1)
```

This prevents pixels from exceeding allowable values.

**Top-5 Prediction Visualization:** For each adversarial image, the code displays the perturbed image, the predicted class, and the top-5 ImageNet probabilities.

```
preds = decode_predictions(output)
```

This allows us to observe how increasing perturbation strength changes the network’s confidence.

**Typical Behavior:** For $\epsilon = 0$ the network correctly predicts: *giant panda*. As $\epsilon$ increases: 0.01 → 0.1 → 0.2 the *prediction confidence* decreases and eventually shifts to an incorrect class, even though the image remains visually recognizable as a panda to humans. This illustrates the remarkable fragility of deep neural networks. This vulnerability is especially critical in safety-sensitive applications such as medical imaging, autonomous driving, and surveillance systems, where small, imperceptible perturbations can lead to confidently wrong decisions with potentially severe real-world consequences.
