## Drawing bounding boxes

The Image.getbbox() method calculates the smallest bounding box that contains all non-zero (or non-black) pixels in a binary image. The bounding box is returned as a 4-tuple: (left, upper, right, lower). The next code loads a grayscale horse image and uses getbbox() to locate the object region, and ImageDraw.Draw() with draw.rectangle() overlays a red rectangular outline of width 3 around the detected bounding box. del draw deletes the drawing context object to free resources and release memory after drawing operations are complete. Now, refer to the next code block:

```
from PIL import ImageDraw
im = Image.open('images/horse.png').convert('L')
im = im.convert('RGB')
draw = ImageDraw.Draw(im)
draw.rectangle(im.getbbox(), fill = None, outline ="red", width = 3)
del draw
im
```

## The alpha (α) channel and blending images

The alpha channel in an image is an additional channel that represents the transparency or opacity of each pixel. It is often used in images with varying levels of transparency, allowing for smooth blending of the image with a background or other images.

The alpha channel is an integral part of the RGBA color model, where each pixel is represented by four components: red, green, blue, and alpha. The PNG image format supports alpha channels, making it a popular choice for images that require transparency. JPEG, on the other hand, does not support alpha channels.

The alpha channel allows images to have pixel-level transparency, making it possible to create smooth transitions between the image and a background.

An alpha value of 0 indicates complete transparency, meaning the pixel is fully see-through. An alpha value of 255 (or 1.0 for floating-point images) indicates full opacity, making the pixel fully visible.

## Converting a JPG to a transparent PNG image

A JPG image can be converted to a transparent PNG by adding an alpha channel with `convert("RGBA")`, generating a grayscale mask from the original image, and using `putalpha()` to assign transparency values. In the example, `ImageChops.invert()` inverts the grayscale mask so darker regions become transparent and lighter regions remain visible, after which the image is saved as a PNG file supporting transparency. The next code snippet reads a black-and-white JPG image of birds and saves it as a transparent PNG image:

## α-blending two images

The blend() function can be used to create a new image by interpolating between two given images (of the same size), using a constant, α. Both images must have the same size and mode. The output image is given by:

out = image₁.(1.0 − α) + image₂.α

If α is 0.0, a copy of the first image is returned. If α is 1.0, a copy of the second image is returned.

The next code snippet shows an example:

```
im1 = Image.open("images/parrot.png")
im2 = Image.open("images/hill.jpg")
# if two images have different modes, must be converted to the same mode
im2 = im2.resize((im1.width, im1.height), Image.BILINEAR)
# if two images have different sizes, must be converted to the same size
im = Image.blend(im1, im2, alpha=0.5).show()
```

## α—compositing two images

α-compositing blends two images using their alpha (transparency) values, determining how much of each image contributes to the final pixel color. Given a foreground image, F, and a background image, B, each with RGBA values, the resulting image, C, is computed using alpha blending. Here are the steps explaining how it's computed:

- 1. Alpha normalization: First, the alpha values of the foreground, α_F, and background, α_B, are normalized between 0 and 1: α_F' = α_F / 255 and α_B' = α_B / 255
- 2. Composite alpha calculation: The resulting alpha, α_C (transparency of the final image), is computed as: α_C = α_F' + α_B'(1 − α_F').
- 3. Blended color calculation: For each color channel (R, G, and B), the final composite color, C, is computed as follows:
- C = (F · α_F' + B · α_B'(1 − α_F')) / α_C
