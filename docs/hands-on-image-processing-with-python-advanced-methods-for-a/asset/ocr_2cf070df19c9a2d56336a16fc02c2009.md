def shades_of_gray(img, p=6):
    img = img.astype(np.float32)
    rgb_power = np.power(img, p)
    mean_power = np.mean(rgb_power, axis=(0, 1))
    illuminant = np.power(mean_power, 1/p)

    balanced = img * scale

# Linear noise smoothing

Linear (spatial) filtering operates by computing a weighted sum of pixel intensities over a local neighborhood. Let $f(x,y)$ denote the input image and $g(x,y)$ the filtered output. A linear filter is defined as:

$$g(x,y)=\sum_{i=-k}^{k}\sum_{j=-k}^{k} h(i,j)f(x-i,y-j)$$

Where $h(i,j)$ is the filter kernel (mask) of size $(2k+1)\times(2k+1)$, the operation corresponds to 2D discrete convolution, written compactly as $g=f*h$. Linear filtering is widely used for **noise suppression (smoothing)** because it attenuates high-frequency components of the image. If the observed image is modeled as:
