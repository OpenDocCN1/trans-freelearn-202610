# Changing image brightness and contrast

Gamma correction is a non-linear adjustment applied to the pixel values of an image (we shall discuss it in detail in the next chapter). It can be used to adjust the brightness of the image. A gamma value greater than 1 brightens the image, while a gamma value less than 1 darkens it. The following code snippet demonstrates how the `skimage.exposure.adjust_gamma()` function can be used to apply gamma correction to the input image. In this case, `gamma=1.5` indicates a brightening effect.

Contrast stretching is a linear operation that expands the range of pixel values in an image, effectively increasing the contrast. The `skimage.exposure.rescale_intensity()` function is used for contrast stretching. In the next code snippet, the `in_range()` parameter to this function defines the lower and upper percentiles of the input data that will be stretched. In this case, pixel values in the range of 20% to 80% of the original data will be stretched to fill the entire dynamic range (0 to 1):

```
from skimage import exposure
im = imread('images/parrot.jpg')
im = im / im.max() # normalize to have values in range [0,1]
brightened_image = exposure.adjust_gamma(im, gamma=1.5)
contrast_stretched_image = exposure.rescale_intensity(im, \
                                in_range=(0.2, 0.8))
plot_images([im, brightened_image, contrast_stretched_image], \
            ['original', 'brightened', 'contrast stretched'])
```

# Inverse warping and geometric transformation using the warp() function

Geometric image transformations modify the spatial arrangement of image pixels to perform operations such as translation, rotation, scaling, shearing, affine, and projective transformations. These operations are widely used in image registration, alignment, rectification, perspective correction, object tracking, and panorama stitching. In scikit-image, the `skimage.transform.warp()` function performs inverse warping by mapping output pixels back to corresponding locations in the input image using a transformation matrix or transformation function.
