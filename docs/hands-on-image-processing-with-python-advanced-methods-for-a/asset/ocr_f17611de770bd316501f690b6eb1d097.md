# Face recognition with FaceNet

In practice, specialized face-recognition models such as FaceNet are preferred over generic image classifiers. FaceNet is trained directly on face images using triplet loss and learns a highly discriminative embedding space in which Euclidean or cosine distance corresponds to facial similarity.

```
from facenet_pytorch import InceptionResnetV1
model = InceptionResnetV1(pretrained='vggface2').eval()  # Pretrained FaceNet
embedding = model(face_tensor)
```

The function get_embedding() preprocesses a face image, passes it through the pretrained face encoder in inference mode (torch.no_grad()), and returns a normalized embedding vector representing that face. The gallery embeddings are then compared with the query embedding using cosine similarity, and the identity with the highest similarity score is selected as the predicted match.

```
def get_embedding(path):
    img = transform(Image.open(path).convert("RGB")).unsqueeze(0)
    with torch.no_grad():
        emb = model(img)
    return F.normalize(emb, dim=1)

gallery = {  # face images
    "Dad": get_embedding("images/dad.jpg"),
    "Me": get_embedding("images/me.jpg"),
    "Mom": get_embedding("images/mom.jpg")}
query = get_embedding("images/query.png")

scores = { name: F.cosine_similarity(query, emb).item()
           for name, emb in gallery.items()}
prediction = max(scores, key=scores.get)
```

Unlike the few-shot ResNet18 example, FaceNet is already optimized for face recognition and therefore typically achieves significantly higher accuracy without additional training, while also producing much more discriminative similarity scores with better separation between matching and non-matching faces, as can be seen from the following figure.
