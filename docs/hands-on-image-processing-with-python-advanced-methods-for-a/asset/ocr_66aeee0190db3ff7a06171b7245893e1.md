where $y_i$ is the ground-truth edge mask for patch $x_i$.

At each split node in the tree, the goal is to choose a split function $\theta$ that maximizes information gain. For structured outputs, this requires defining a proper distance metric $d(y_i, y_j)$ between masks. Dollár and Zitnick propose using a low-dimensional embedding of edge patches into binary labels via clustering.

Let $\phi(y_i) \in R^k$ be such an embedding, and define entropy over clusters:

$$H(S) = -\sum_{c=1}^{C} \frac{|S_c|}{|S|} \log\left(\frac{|S_c|}{|S|}\right)$$

The split function $\theta$ is chosen to maximize the information gain:

$$\Delta H = H(S) - \sum_{j \in \{L,R\}} \frac{|S_j|}{|S|} H(S_j)$$

where $S_L, S_R$ are the left and right child node subsets split by $\theta$.

# Inference and edge map aggregation

During inference, a sliding window is used to extract overlapping patches, and each patch is passed through the forest. The predicted edge maps from all trees are averaged and aggregated over the image to produce the final dense edge map.

Let $T$ be the number of trees and $E_t(x)$ be the predicted edge map from tree t, then the aggregated edge response at pixel $i$ is:

$$E(i) = \frac{1}{T} \sum_{t=1}^{T} E_t(i)$$

Post-processing steps such as non-maximum suppression or edge thinning can be applied.

Structured edge detection has been successfully applied in object proposal generation, semantic segmentation, stereo matching, medical image boundary detection, and optical flow preprocessing.

Its ability to capture local structure and context makes it especially useful for complex natural scenes. Let's use opencv-python ximgproc library functions to demonstrate how it works.
