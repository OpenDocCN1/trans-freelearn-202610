# Comparing smoothing with box and Gaussian kernels using scipy.ndimage

Linear filtering can also be performed using functions from the scipy.ndimage module, which provides efficient implementations of convolution-based smoothing.

When applied to images corrupted by impulse (salt-and-pepper) noise, linear filters such as box and Gaussian smoothing produce limited improvement. This is because impulse noise violates the additive noise assumption.

f(x, y) = { 0 or 1,    with probability p
               s(x, y),    otherwise }

In such cases, averaging spreads extreme pixel values into neighboring regions, leading to blur without effective noise removal. This limitation motivates the use of nonlinear filters (e.g., median filtering), discussed in subsequent sections.
