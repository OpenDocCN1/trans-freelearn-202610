**Note**

The chosen region contains closely spaced vertical stripes, making it rich in high-frequency content. When downsampled, such textures are prone to aliasing, where the fine detail exceeds the sampling rate and causes distorted patterns (*Moire effects*) to appear. This occurs because high-frequency details are misrepresented at lower resolutions.

# Convolution-based resizing (resampling) with PIL

The most suitable way to resize an image is **convolution-based resampling** (we shall discuss *convolution* shortly). It preserves image quality during resizing by reconstructing the image through convolution with an interpolation kernel:

$$g(x,y)=f(x,y)*h(x,y)$$

where $f(x,y)$ is the input image, $h(x,y)$ is the reconstruction filter (kernel), and * denotes convolution. Ideal reconstruction uses the **sinc** kernel, while the **Lanczos** kernel provides a practical approximation with good detail preservation and reduced aliasing.

As demonstrated in the next code snippet, the input image is repeatedly downsampled with nearest-neighbor interpolation using `PIL.Image.resize()`, to progressively smaller resolutions. The parameter `resample=Image.NEAREST` selects the nearest input pixel without considering neighboring pixels, while `box=crop_coords` specifies the rectangular ROI to crop before resizing. This is useful when you’re interested in downsampling only a portion of the image (such as a high-frequency region) without having to crop it first.

```
for factor in range(4,20,4):
    im_rsz = im.resize((int(im.width/factor), int(im.height/factor)), \\
                       resample=Image.NEAREST, box=crop_coords)
    plt.imshow(im_rsz), plt.axis('off')
```

If you run the preceding code snippet, you should obtain a figure like the next one. As the sampling rate decreases below the *Nyquist* limit, high-frequency stripe patterns become improperly reconstructed, producing *checkerboard* and *Moire* aliasing artifacts.
