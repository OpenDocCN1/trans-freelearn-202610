
The original image is **reconstructed** using the **inverse FFT**:

```
im_rec = fp.ifft2(freq).real
im_rec = im_rec / im_rec.max()
```

The .real operation removes small imaginary numerical errors introduced during computation. Reconstruction error is measured using the **Frobenius norm**:

‖ f − f_rec ‖_F = √[ Σ_{x,y} ( f(x,y) − f_rec(x,y) )² ]

which can be implemented as: np.linalg.norm(im - im_rec).

Image quality is further verified using peak_signal_noise_ratio() (PSNR), where larger values indicate better reconstruction quality, while np.allclose(im, im_rec) confirms that the reconstructed image is numerically close to the original image. Since all Fourier coefficients are retained, **FFT** followed by **IFFT** reconstructs the image with negligible information loss.

```
from skimage.metrics import peak_signal_noise_ratio as psnr
print(f'PSNR for the reconstructed image = {psnr(im, im_rec)}')
# PSNR for the reconstructed image = 2.0237227738013224    assert(np.
allclose(im, im_rec)) # original and recons images should be close

## Plotting the frequency spectrum

Since Fourier coefficients are complex-valued, the frequency spectrum is typically visualized using their magnitudes |F(u, v)|. The coefficient F(0,0), called the DC component, represents the average image intensity and usually dominates the spectrum To improve the visibility of weaker frequency components in the Fourier spectrum, logarithmic scaling is commonly applied using:

D₁(u, v) = 20 log₁₀ (0.01 + |F(u, v)|)

which compresses the large dynamic range of the DFT magnitude and avoids numerical instability from log(0); alternatively, a linear mapping, D₂(u, v) = min(|F(u, v)| + 100,255), can be used to enhance visibility through intensity shifting and clipping.

Using the separability theorem, the Fourier transform of a 2D rectangle of size a × b centered at the origin is product of two (normalized) sinc functions:

```
F(u, v) = absinc(au)sinc(bv)
```

where sinc(x) = sin(πx)/(πx). Thus, the DFT of an image containing a white square produces a sinc-like spectrum, which can also be derived mathematically using the definition of continuous Fourier transform together with the separability theorem, as illustrated in the next figure.

```

```
