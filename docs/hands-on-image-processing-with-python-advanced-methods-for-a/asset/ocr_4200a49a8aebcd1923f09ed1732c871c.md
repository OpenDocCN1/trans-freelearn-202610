Figure 13.35 – Identity preserving pose-guided image generation with ip-adapter and controlnet

The installation stage loads Stable Diffusion v1.5, the OpenPose ControlNet model, and the IP-Adapter weights. The pipeline then attaches the IP-Adapter attention layers and sets their influence using set_ip_adapter_scale(). During inference, the OpenPose image is supplied through the image argument, the identity reference through ip_adapter_image, and the text prompt specifies the desired appearance. The diffusion model fuses all three conditioning sources to generate photorealistic portraits that preserve identity while conforming to the target pose.

# Image generation with DALL·E 2 and DALL·E 3 APIs

OpenAI’s DALL·E family of models enables high-quality text-to-image generation from natural language descriptions. Given a textual prompt y, the model learns a conditional distribution p(x|y), where x denotes the generated image. DALL·E 2 introduced powerful text-guided image synthesis and variation generation, while DALL·E 3 significantly improved prompt understanding, compositional reasoning, scene coherence, typography, and adherence to detailed instructions. These models are widely used for concept art, advertising, product visualization, storytelling, architectural design, and creative content generation.

To use the API, create an account on OpenAI Platform(https://platform.openai.com/?utm_source=chatgpt.com), generate an API key from the dashboard, add billing credits, and note that image generation is usage-based with costs depending on the model (e.g., DALL·E 2 vs. DALL·E 3), image resolution, and number of images generated.
