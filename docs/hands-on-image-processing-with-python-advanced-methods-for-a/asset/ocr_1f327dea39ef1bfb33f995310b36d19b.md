From the preceding figure, although the *phase* of an image appears to be less informative (quite random), it contains very important information about the image. The next code demonstrates that replacing the original phase with another image’s phase or with a random phase severely distorts reconstruction, while preserving phase with altered magnitude still retains recognizable image structure, indicating that phase carries crucial spatial information. Random phase textures are generated using a fractional Brownian field (FBF) model with the PyAFBF library, where the Hurst parameter $H \in (0,1)$ controls texture roughness ($H \approx 0$: noisy texture, $H \approx 1$: smooth texture). The experiments further show that both magnitude and phase are important for accurate image reconstruction, although phase generally contributes more strongly to perceptual image structure.

The next code snippet uses the PyAFBF library to generate a *fractional Brownian field (FBF)*, a stochastic texture model commonly used to simulate natural patterns such as clouds, terrain, and rough surfaces. The function `tbfield('fbf')` initializes the FBF model, while the Hurst index $H \in (0,1)$ controls texture smoothness: H=0 produces highly random noise-like textures, whereas H=1 generates smooth correlated textures; here, H=0.2 creates moderately rough patterns. The parameter is set using `Z.hurst.ChangeParameters()`, and `Z.NormalizeModel()` normalizes the statistical properties of the generated field. The simulated random texture is obtained with `Z.Simulate()` and reshaped to input shape:

#!pip install PyAFBF==0.1.7  image==0.2.6
from afbf import tbfield
N, H = 256, 0.2  # image size and Hurst index in (0, 1).
Z = tbfield('fbf') # define the field and change param of Hurst function
Z.hurst.ChangeParameters(np.array([[H]])); Z.NormalizeModel()
Z = Z.Simulate() # simulate the field
random_image = Z.values.reshape(512, 512) # reshape image
plt.imshow(random_image, cmap='gray'), plt.axis('off')
