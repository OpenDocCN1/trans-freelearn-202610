
As we have seen earlier, filters modify pixel values using mathematical transformations such as color mapping, gamma correction, and convolution. Filters typically involve the following:

- **Color transformations:** Adjust RGB values using a transformation matrix:

$$
\begin{bmatrix}R'\\G'\\B'\end{bmatrix}=M\times\begin{bmatrix}R\\G\\B\end{bmatrix}+B
$$

Here, $M$ is a transformation matrix and $B$ is a bias vector.

- **Gamma correction:** Adjust the brightness using $I' = I^\gamma$, where $\gamma$ controls brightness.

- **Convolution filters:** Apply a kernel, $K$, to enhance features:

$$
I'(x,y)=\sum_{i=-k}^{k}\sum_{j=-k}^{k}I(x-i,y-j)K(i,j)
$$

Here, $K$ is a filter kernel (e.g., Gaussian blur or sharpening).

## Image formation — sampling and quantization

Image formation fundamentally involves **sampling** and **quantization**. Sampling is a spatial operation that selects image pixels to change image resolution, while quantization reduces the number of intensity or color levels used to represent an image. These operations form the basis of image resizing, compression, and digital image representation. Sampling can be used to increase or reduce the size of an image, with upsampling and downsampling, respectively.

## Upsampling

An image may be viewed as a discrete sampling of a continuous 2D intensity function f(x, y). Upsampling increases image resolution (size) by generating additional pixels at locations where intensity values are unknown. Since these values are unavailable in the original image, they must be estimated using aggregate statistics such as the mean, or interpolation techniques based on neighboring pixels. Interpolation attempts to reconstruct a continuous approximation of the underlying image signal while preserving visual smoothness and structural continuity. Given sampled image points f(x_i, y_i), interpolation estimates the intensity value at arbitrary spatial locations (x, y). Common interpolation techniques include nearest-neighbor, bilinear, bicubic, and spline interpolation.

## Nearest-neighbor interpolation

Nearest-neighbor interpolation is the simplest upsampling technique. The unknown pixel value in the resized image is assigned the value of the closest pixel in the original image:

I'(x', y') = I(x, y)

where (x, y) is the nearest pixel location in the original image corresponding to the resized coordinates (x', y'). Coordinate mapping is performed using the scaling factors s_x and s_y:

x = round( x' / s_x ),    y = round( y' / s_y )

where round() selects the nearest integer coordinate. For example, doubling image dimensions replicates neighboring rows and columns.
