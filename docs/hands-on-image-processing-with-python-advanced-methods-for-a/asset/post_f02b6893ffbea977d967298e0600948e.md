
One important property of latent representations is their continuity. Images can be smoothly morphed by interpolating between latent vectors. Two images are first encoded:

```
z1 = vae.encode(x1).latent_dist.mean
z2 = vae.encode(x2).latent_dist.mean
```

Intermediate latent codes are generated by linear interpolation.

```
z = (1-a)*z1 + a*z2
```

where \(z_\alpha = (1 - \alpha)z_1 + \alpha z_2, \quad 0 \le \alpha \le 1.\) Each interpolated latent is decoded to produce an image. The resulting sequence reveals a smooth semantic transition between the two objects, demonstrating that nearby points in latent space correspond to visually related images. Such continuity is one of the key reasons latent spaces are well suited for diffusion-based image generation.

## Understanding latent diffusion

In a latent diffusion model, Gaussian noise is added to latent vectors rather than to pixels:

\[
z_t = \sqrt{\bar{\alpha}_t}z_0 + \sqrt{1 - \bar{\alpha}_t}\epsilon, \quad \epsilon \sim \mathcal{N}(0,I)
\]

A neural network then learns to predict and remove this noise, progressively recovering the clean latent representation. To illustrate the effect of latent degradation, the latent representation is artificially scaled:

```
noisy = latent * (step / 1000)
img = vae.decode(noisy).sample
```

As the latent magnitude decreases, the decoded image gradually loses structure and detail. This experiment provides intuition for latent diffusion: information is progressively corrupted in latent space and later recovered through denoising.

## Image editing with InstructPix2Pix

While Stable Diffusion generates images from text alone, many practical applications require editing an existing image according to a textual instruction. Examples include changing an object’s appearance, modifying artistic style, altering lighting conditions, or converting sketches into realistic photographs. InstructPix2Pix addresses this problem by learning to follow natural language editing instructions while preserving the content and structure of the input image.

Given an input image \(x\) and a textual instruction \(c\), the objective is to generate an edited image \(y = F(x, c)\), where \(F(\cdot)\) represents the learned image-editing model. Unlike text-to-image generation, the goal is not to create a new image from scratch but to transform an existing image according to the instruction.

### InstructPix2Pix Architecture

InstructPix2Pix is built upon the Stable Diffusion framework and performs diffusion-based image editing. The model receives:

- An input image
- A textual editing instruction
- A noisy latent representation

The text instruction is encoded using a language encoder: \(c = T(\text{instruction})\), while the input image is mapped into a latent representation using a Variational Autoencoder (VAE): \(z = E(x)\). A diffusion U-Net then performs iterative denoising conditioned on both the image latent and the instruction embedding: \(\epsilon_\theta(z_t, t, c)\). The final edited image is reconstructed using the VAE decoder: \(\hat{y} = D(z_0)\). Because the model is conditioned on both image content and text instructions, it can preserve the overall scene while modifying only the requested attributes.

## Structure-guided image generation with ControlNet

While text-to-image models such as Stable Diffusion can generate highly realistic images from textual prompts, they often provide limited control over the spatial structure of the generated content. ControlNet addresses this limitation by introducing additional conditioning signals, such as edges, depth maps, segmentation masks, human poses, or sketches, enabling precise control over image composition while preserving the generative capabilities of diffusion models.

Given a control signal \(c\) (e.g., an edge map) and a text prompt \(y\), ControlNet models the conditional distribution \(p(x|c, y)\), allowing image generation to be guided simultaneously by structural information and semantic instructions.

### ControlNet Architecture

ControlNet extends Stable Diffusion by adding a trainable branch that processes external control signals. The original Stable Diffusion U-Net remains largely unchanged, while the ControlNet branch extracts structural information and injects it into the denoising process.

Let \(z_t\) denote the noisy latent representation at timestep \(t\). The denoiser becomes \(\epsilon_\theta(z_t, t, c, y)\), where \(z_t\) is the noisy latent, \(c\) is the control image, and \(y\) is the text prompt. The generated image is therefore constrained not only by textual semantics but also by the supplied geometric structure.

### Extracting Edge Guidance

The demonstration uses a horse image as input and extracts a Canny edge map.

```
gray = cv2.cvtColor(np.array(input_image), cv2.COLOR_RGB2GRAY)
edges = cv2.Canny(gray, 100, 200)
```

The Canny detector computes image gradients and identifies significant intensity discontinuities, producing an edge representation that captures the object’s shape and pose while discarding texture and color information. The edge map is then converted into a three-channel image:

```
edges = cv2.cvtColor(edges, cv2.COLOR_GRAY2RGB)
```

This edge image serves as the structural conditioning signal supplied to ControlNet.

### Loading the ControlNet Model

A ControlNet model trained on Canny edge maps is loaded using:

```
controlnet = ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-canny")
```

This network has learned how edge structures correspond to realistic image content and can therefore preserve object geometry during generation. The ControlNet model is then integrated with Stable Diffusion:

```
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    controlnet=controlnet)
```

The resulting pipeline combines semantic guidance from text prompts with structural guidance from edge maps.
