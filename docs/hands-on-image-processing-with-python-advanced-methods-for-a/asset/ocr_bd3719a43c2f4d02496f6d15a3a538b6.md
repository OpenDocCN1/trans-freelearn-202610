# **Cross-Class Conditional Traversal:**

By fixing a latent vector *z* and linearly interpolating between two class labels, the decoder generates a smooth semantic transition from a *sneaker* to an *ankle boot*. This experiment isolates the effect of class conditioning and demonstrates that the CVAE can continuously blend object categories while preserving the underlying latent style. The next code performs a **class-conditioning interpolation** while keeping the latent vector *z* fixed. The semantic transition is driven entirely by the changing class label embedding:

$$x_{\alpha}=D(z,(1-\alpha)y_1+\alpha y_2)$$

```
# Encode one sneaker and one bag
z = torch.randn(1, LATENT_DIM, device=device)
y1 = torch.tensor([7], device=device)  # Sneaker
y2 = torch.tensor([9], device=device)  # Ankle Boot
y1_hot = F.one_hot(y1, NUM_CLASSES).float()  # One-hot labels
y2_hot = F.one_hot(y2, NUM_CLASSES).float()

with torch.no_grad():
    for a in enumerate(np.linspace(0,1,15)):
        y = (1-a)*y1_hot + a*y2_hot       # Label interpolation
        img = model.decode(z, y)
        img = img.view(28, 28).cpu()
```
