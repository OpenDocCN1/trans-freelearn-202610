## Applying point transformations

As described earlier, point transformation in image processing refers to operations that modify the intensity (or color) of each pixel individually, without considering the pixel's neighborhood. The transformation is defined by a mathematical function applied to each pixel value of the input image to produce a new value in the output image. The general form of a point transformation can be written as follows:

$I_{output}(x,y) = T\left(I_{input}(x,y)\right)$ or, in short, $s = T(r)$

Here, we have the following:

- $r(x, y) = I_{input}(x, y)$ is the intensity of the pixel at location $(x, y)$ in the input image
- $T(.)$ is the transformation (transfer) function applied to the pixel
- $s(x, y) = I_{output}(x, y)$ is the resulting intensity of the pixel at location $(x, y)$ in the output image

Here, we explore a couple of transformations that apply a transfer function to each single pixel value from the input image to obtain the corresponding pixel value for the output image, using the Image.point() method. Each pixel has a value between 0 to 255, inclusive.

### Log transformation

Logarithmic transformation is a nonlinear point operation used to compress the dynamic range of an image while enhancing details in darker regions. It is defined as follows:

$I_{output}(x, y) = c \cdot \log\left(1 + I_{input}(x, y)\right)$

Here, c is a scaling constant.

The next line of code uses the point() method to apply a lambda transformation independently to each pixel intensity x. The pixel values are first normalized to the range [0,1] using x/255 transformed with log(1 + x/255) to avoid the undefined log(0), and finally rescaled back to the 0-255 range. This operation brightens dark pixels, compresses high intensities, and reduces the overall intensity range of the image.

```
im_g.point(lambda x: 255*np.log(1+x/255)).show()
```

### Power-law transformation

The power-law transformation for an image can be described mathematically as follows:

$s = c \cdot r^{\gamma}$

Here, we have the following:

- $r$ is the input pixel intensity (normalized between 0 and 1)
- $s$ is the output pixel intensity after the transformation
- $c$ is a constant that typically normalizes the result, often set to 1 (for simplicity) or 255 if the image is in 8-bit depth

Let’s look at the explanation:

- $\gamma$ is the gamma value, which controls the degree of transformation
- If $\gamma < 1$, the transformation enhances the contrast in the darker regions of the image (brightens the image)
- If $\gamma > 1$, the transformation reduces the contrast in the darker regions (darkens the image)
- If $\gamma = 1$, the image remains unchanged

The point() method applies this transformation independently to each pixel intensity, as demonstrated by the following line of code with γ = 0.6:

```
im_g.point(lambda x: 255*(x/255)**0.6).show()
```

### Point transformation on a multi-channel image

For a color image, the point transformation function needs to be applied to each of the color channels separately and independently. We can use the point() function to apply an arbitrary transformation to each pixel (in all bands) for an RGB image, too, as demonstrated in the next code snippet. Let’s dive deeper to understand the code step by step:

- The first application of the point() method applies the non-linear transformation s = r tan(r) to each pixel value r in the image. It produces highly distorted intensity values across all RGB channels, leading to unnatural and chaotic color shifts.
- The second one applies a binary thresholding function separately to each channel. It converts the RGB input image into a posterized high-contrast version, where each color channel is either fully on (255) or fully off (0), creating a stark representation of the original colors based on the specified threshold.
- For the next transform, the image is first converted to grayscale using convert('L'). Then, a lookup table (LUT) is generated by shifting the values of the [0, 1, 2, ..., 255] array to the right by 115 positions, using np.roll(). Then, the .point() method is applied to this LUT to remap the grayscale values. This creates a circular-shifted grayscale image. The pixel intensities are shifted so that darker areas may become brighter, and brighter areas may become darker. It’s as though the intensity values are “wrapped around,” shifting the visual appearance.
- The last point transformation uses the ImagingCore.point_transform() method, which applies a linear transformation to each pixel, r, from the input image, which can be expressed in the form s = a × r + b, to obtain the output pixel s, with scale a and offset b as parameters. Here, the image is first copied (with the copy() method), and its mode is changed to floating point mode, using the .convert('F') method. Then, the point_transform() method is applied, and it linearly scales the pixel values by a factor of 3 and then shifts them by -100. This results in a significant brightening of the image, as every pixel is amplified and offset by a constant value.

Now, refer to the next code snippet:

```
from PIL import Image
import numpy as np
import matplotlib.pyplot as plt

im = Image.open('images/parrot.jpg')
im1 = im.point(lambda x: x*np.tan(x))
im2 = im.point(lambda x: 255 if x > 128 else 0)
im3 = im.convert('L').point(np.roll(np.arange(256), 115))
im4 = im.copy()
im4.im = im4.convert('F').getdata().point_transform(3,-100)
im4 = im4.convert('L').convert('RGB')

plt.imshow(np.hstack((im1, im2, im3.convert('RGB'), im4)), plt.axis('off')
plt.title('point transforms with PIL Image and ImagingCore', size=15)
```

### Inverting/negating an image

Inverting or negating an image involves reversing the colors of the pixels—turning light areas dark, and vice versa. The inversion is typically performed by subtracting the pixel values from the maximum intensity value (e.g., 255).

For any grayscale image, I, with, pixel values in the range [0, L] (where L is the maximum intensity value, typically 256 for an 8-bit image), the inverted image is defined as:

I_inverted(x, y) = (L − 1) − I(x, y), ∀ pixel positions (x, y)

To invert a color image, each color channel needs to be inverted independently. Let’s demonstrate how the inversion operation can be implemented with the Image.point() function in the next code snippet:

```
im = Image.open("images/pepper.webp")
im_t = im.point(lambda x: 255 - x)
#im_t.show()
```
