# Applying interpolation

Now, you will see how the same function, ndimage.zoom(), can be used to zoom into an image of bricks twice with spline interpolation of different orders:

```
im = imread('images/ bricks_small.jpeg')
n = 2
interp_images = []
for k in range(1,5):
    # no zoom on color channel, spline interpolation order = k
    zoomed_im = ndimage.zoom(im, (n,n,1), mode='nearest', \
                             order=k)
    interp_images.append(zoomed_im)
    interp_images.append(interp_images[-1]-interp_images[0])
plt.imshow(np.hstack(interp_images)), plt.axis('off')
```

If you run the preceding code snippet, you should obtain something like the following figure. It shows that the output image obtained with spline interpolation of order is a much better approximation of the resized image (much sharper, hence it contains much more detail) than the one obtained with order 1.

# Applying wave distortion

The following code snippet applies a sinusoidal distortion to the Mona Lisa image using the scipy.ndimage.map_coordinates() function, creating a visually interesting effect by modifying the y coordinates of the image pixels based on a sinusoidal function of the x coordinates. Here are the key steps:

+   - The np.meshgrid() function is used to create a grid of coordinates representing pixel locations in the original image.
+   - The coordinates are modified by adding a sinusoidal distortion based on the coordinates.
+   - The map_coordinates() function from scipy.ndimage is used to map the pixel values from the original image to the distorted coordinates. It is used to interpolate the pixel values from the distorted coordinates, resulting in the final distorted image.
