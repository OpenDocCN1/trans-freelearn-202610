# Intersection over Union metric

The Intersection over Union (IoU) metric, also called the Jaccard Index, measures the overlap between the predicted region and the ground-truth region:

IoU = |Y ∩ Ŷ| / |Y ∪ Ŷ|

Where Y ∩ Ŷ denotes the intersection (common pixels) and Y ∪ Ŷ denotes the union (all pixels belonging to either mask).

Using confusion matrix terms,

IoU = TP / (TP + FP + FN)

Where IoU = 1 is perfect segmentation, IoU = 0 means no overlap. Higher IoU indicates better localization and boundary agreement. IoU penalizes both false positives and false negatives, making it one of the most reliable metrics for semantic segmentation.

IoU is widely used in medical image segmentation, autonomous driving, satellite image analysis, organ and tumor segmentation, and benchmark datasets such as Cityscapes and Pascal VOC. For multiclass segmentation, the IoU is computed independently for each class and averaged:

mIoU = 1/C Σ_{c=1}^C IoU_c

where C is the number of classes.

# Dice Coefficient

The Dice Similarity Coefficient (DSC) measures the similarity between two sets and is particularly popular in medical imaging:

Dice = 2|Y ∩ Ŷ| / (|Y| + |Ŷ|)

In terms of confusion matrix quantities,

Dice = 2TP / (2TP + FP + FN)

The Dice coefficient is closely related to IoU:

Dice = 2·IoU / (1 + IoU)

and conversely,

IoU = Dice / (2 − Dice)
