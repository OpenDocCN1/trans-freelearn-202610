
## Cropping an image

Cropping an image means defining a smaller rectangular area within the original image and extracting pixel values from that area to create a new image. The cropped image, \(I_{crop}\ (W_c \times H_c)\), can be created by selecting pixels from the top left \((x_1,y_1)\) to the bottom right \((x_2,y_2)\) in the original image, \(I_{W\times H}\), and can be mathematically defined as follows:

$$I_{crop}(i,j)=I(x_1+i,y_1+j),\ \forall(0\leq i\leq W_c\land 0\leq j\leq H_c)$$

where \(W_c=x_2-x_1\) and \(H_c=y_2-y_1\)

We can use the `crop()` method with the desired rectangle defined by the *(left, top, right, bottom)* coordinates as an argument to the function, to extract the desired region defined by the rectangle coordinates as a new image object, as shown in the following code:

```python
im = Image.open("images/parrot.png")
im_c = im.crop((175,75,320,200))
im_c.save("images/parrot_cropped.jpg")
im_c.show()
```

## Resizing an image

In order to increase or decrease the size of an image, we can use the `resize()` function, which internally upsamples or downsamples the image, respectively.

### Resizing to a larger image

When resizing an image to a larger size, interpolation is essential to estimate the pixel values in between the original pixels to avoid a blocky, pixelated appearance. Without interpolation, each original pixel would simply be duplicated, creating a poor-quality image with visible pixelation.

Consider the following example, as shown in the next figure, where a 2 × 2 input image is to be enlarged to a 3 × 3 output image. Note that there are five pixels in the target image that are not known and need to be computed using an interpolation method (e.g., nearest-neighbor algorithm).

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_109_0.png)

*Figure 2.17 – Enlarging an image with upsampling/interpolation*

The next code snippet demonstrates how the `resize()` function can be used to enlarge a small brick image (of size 150 × 100), both width and height by a factor of 5, to obtain an output image of size 25 times larger than the input image, using bilinear interpolation (an upsampling technique).

The `Image.BILINEAR` argument is used as the resampling filter to the `resize()` function. It provides smoother results for enlarging images by averaging neighboring pixels. Details about how it works will be described in Chapter 3. A new blank RGB image, `im_concat`, is created with a width twice that of the enlarged image and a height the same as the enlarged image. The original image, `im`, is pasted at (0,0), and the enlarged image, `im_large`, is placed beside it at (im_large.width, 0). The final concatenated image is then displayed using the default viewer:

```python
im = Image.open("images/bricks_small.jpeg")
print(im.width, im.height)
# 150 100
im.resize((im.width*5, im.height*5), Image.BILINEAR) \
    .save('images/bricks_large.jpeg')

im_large = Image.open("images/bricks_large.jpeg")
print(im_large.width, im_large.height)
# 750 500
im_concat = Image.new('RGB', (2*im_large.width, im_large.height))
im_concat.paste(im, (0,0))
im_concat.paste(im_large, (im_large.width,0))
im_concat.show()
```

If you run the preceding code snippet, you should obtain an output like the following figure, with the small input image and the large resized image placed side by side:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_110_0.png)

*Figure 2.18 – Upsampling (enlarging image) with PIL*

### Resizing to a smaller image

Downsampling reduces an image's dimensions by decreasing the number of pixels, representing visual information in a smaller space. It is commonly used to save storage, reduce bandwidth, and create thumbnails. The process merges multiple pixels into one, which can cause jagged edges, moiré patterns, and detail loss—known as aliasing. Anti-aliasing is a technique used to prevent distortion, or aliasing, when reducing an image's size.

Now, let us do the reverse operation as done in the last example—that is, start with a large image of the Victoria Memorial Hall (of size 720 × 540) and create a smaller image.

The next code snippet shows how the `resize()` function can be used to shrink both height and width by a factor of 5 to resize it to an output image of size 25 times smaller than the input image, using anti-aliasing, implemented with the `Image.Resampling.LANCZOS` filter. (Note that the `Image.ANTIALIAS` filter for anti-aliasing has been removed from PIL from version 10.0.0.) The details of how it works will be described in Chapter 3:

```python
im = Image.open("images/victoria_memorial.png")
im.resize((im.width//5, im.height//5), \
    Image.Resampling.LANCZOS).save('images/victoria_memorial_small.png')
im_small = Image.open("images/victoria_memorial_small.png")
im_concat = Image.new('RGB', (2*im.width, im.height))
im_concat.paste(im, (0,0))
im_concat.paste(im_small, (im.width,0))
im_concat.show()
```

### Caution

When resizing an image, it is important to preserve the aspect ratio (the ratio of width to height) if you want to avoid distortion. You can preserve the aspect ratio by specifying just one dimension (e.g., width or height) and computing the other accordingly. While this is not a concern for scaling both dimensions by the same factor, it would be good to caution you for general cases.

To preserve the aspect ratio automatically during resizing, one common approach is to compute the second dimension accordingly, as done with the `resize_preserve_aspect_ratio()` function:

```python
def resize_preserve_aspect_ratio(im, target_width, resample=Image.BILINEAR):
    """
    resize an image to a given width while preserving the aspect ratio.
    """
    aspect_ratio = im.height / im.width
    target_height = int(target_width * aspect_ratio)
    return im.resize((target_width, target_height), resample)

# usage:
im_resized = resize_preserve_aspect_ratio(im, target_width=300)
```

## Pixelating an image

Pixelation is performed by first selecting the image region to be pixelated, then dividing it into fixed-size pixel blocks, replacing all pixels within each block by a representative value (typically the average color), and finally reconstructing the image so that fine details are replaced by coarse block-like structures. We can reduce an image's resolution and then scale it back up to create a pixelated effect; it is implemented with the `pixelate()` function in the next code snippet. It works as follows:

- Downsampling: The image is resized to a smaller version using bilinear interpolation (`Image.BILINEAR`), reducing details while preserving some smoothness.
- Upsampling: The small image is scaled back to the original size using nearest-neighbor interpolation (`Image.NEAREST`), which enlarges each pixel block, creating a blocky, pixelated look.

Refer to the next code snippet:

```python
def pixelate(im, factor):
    # Resize down smoothly
    im_small = im.resize((im.width//factor, im.height//factor), \
                          resample=Image.BILINEAR)
    # Scale back up using NEAREST to original size
    return im_small.resize(im.size, Image.NEAREST)

im = Image.open("images/parrot.png")
plt.figure(figsize=(15,6))
plt.imshow(np.hstack([np.array(im)] + \
                    [np.array(pixelate(im, factor)) for factor in [16,32]]))
```

## Anonymizing a face

Now, let's apply the pixelation to a part of the image, for example, the face region in the input Mona Lisa image, where we want to hide the details. The pixelation effect can be applied to the region of interest (ROI) using NumPy slicing.
