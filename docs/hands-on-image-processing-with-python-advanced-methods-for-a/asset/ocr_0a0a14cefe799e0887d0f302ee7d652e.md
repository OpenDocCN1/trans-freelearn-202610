# With PIL.ImageFilter

Python Imaging Library (PIL), through its ImageFilter module, offers a convenient UnsharpMask filter, as demonstrated with the following code snippet:

```
# Load image
image = Image.open("images/me.jpg").convert("RGB")
# Apply Unsharp Mask from PIL
sharpened_pil = image.filter(\    ImageFilter.UnsharpMask(radius=2, percent=150, threshold=3))
# Display image and sharpened_pil here
```

The function ImageFilter.UnsharpMask() accepts the following parameters:

+   - radius: Standard deviation (sigma) of the Gaussian blur kernel. A higher value means more blurring. The radius controls how much detail is considered low-frequency (i.e., to be removed).
+   - percent: Amount of sharpening applied, scaled in percentage (e.g., 150 means 150%). The percent amplifies the extracted detail layer.
+   - threshold: Minimum brightness change that will be sharpened. Helps reduce sharpening of noise. The threshold suppresses changes in flat regions, avoiding noise amplification.

# With OpenCV-Python

OpenCV-Python provides a more flexible and transparent way to implement unsharp masking using Gaussian blur and linear blending, as demonstrated in the next code snippet:

```
# Load image
img = cv2.imread("images/me.jpg")
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
# Apply Gaussian Blur
blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=2)
# Unsharp Mask
alpha = 1.5
sharpened_cv = cv2.addWeighted(img, 1 + alpha, blurred, -alpha, 0)
sharpened_cv_rgb = cv2.cvtColor(sharpened_cv, cv2.COLOR_BGR2RGB)
# Display img_rgb and sharpened_cv_rgb here
```

Here is how the above code works:

+   - cv2.GaussianBlur blurs the image using a Gaussian kernel
+   - cv2.addWeighted() performs the blending operation; with I and B representing the original and the blurred image, sharpened = (1 + α) · I − α · B, where α = 1.5 enhances the details

This approach gives more control over the blur and blend operations compared to the PIL method, making it ideal for experimentation and advanced applications.
