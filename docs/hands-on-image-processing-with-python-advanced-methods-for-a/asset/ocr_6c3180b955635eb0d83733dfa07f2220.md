# Separating the RGB channels of an image

We can use the `split()` function to separate the channels of a multi-channel image, as shown in the following code for an RGB image:

```
```python
ch_r, ch_g, ch_b = im.split() # split RGB image into 3 channels: R, G and B
plt.figure(figsize=(18,6))
plt.subplot(1,3,1); plt.imshow(ch_r, cmap=plt.cm.Reds); plt.axis('off')
plt.subplot(1,3,2); plt.imshow(ch_g, cmap=plt.cm.Greens); plt.axis('off')
plt.subplot(1,3,3); plt.imshow(ch_b, cmap=plt.cm.Blues); plt.axis('off')
# show the R, G, B channels separately
```
```

# Combining multiple channels of an image

We can use the `merge()` function to combine the channels of a multi-channel image, as shown in the following code, where the color channels obtained by splitting the parrot RGB image are merged after swapping the red and blue channels:

```
```python
im = Image.merge('RGB', (ch_b, ch_g, ch_r)) # swap the red and blue channels
im.show()
```
