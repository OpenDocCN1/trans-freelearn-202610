# Image manipulation with scipy.ndimage

The scipy.ndimage module provides various functions for image manipulation. It is part of the SciPy library and is built on top of NumPy. Here are some common image manipulation tasks that can be performed using scipy.ndimage.

# Applying affine transformation

We can use the affine_transform() function and provide the 3x3 transformation matrix (in homogeneous coordinates) and the offset to carry out the transformation, as shown in the following code block:

```
from scipy.ndimage import affine_transform
im = imread("images/parrot.png")
transformed = affine_transform(im,
    [[np.cos(np.pi/4),np.sin(np.pi/4), 0],
     [-np.sin(np.pi/4),np.cos(np.pi/4), 0],
     [0,0,1]],
    offset = [-im.shape[0]/2+75,
              im.shape[1]/2-50, 0],
    output_shape=im.shape)
plt.imshow(transformed), plt.axis('off')
```

# Zooming

Zooming in and zooming out in the context of image processing refers to operations that change the apparent size of an image. These operations involve adjusting the spatial resolution of the image to make it appear larger or smaller on a display:

+   - Zooming in: Also known as magnification or enlargement, this involves making the image appear larger on the display by increasing its spatial resolution. Details in the image become more visible, and the image occupies a larger portion of the screen or canvas. Zooming in is often used to closely examine the fine details of an image or to focus on a specific region of interest.
