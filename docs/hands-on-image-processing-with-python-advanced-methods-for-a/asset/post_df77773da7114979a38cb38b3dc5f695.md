def make_gaussian_psf(size, sigma):
    assert size % 2 == 1, "psf size should be odd"
    ax = np.arange(-(size // 2), size // 2 + 1, dtype=float)
    xx, yy = np.meshgrid(ax, ax)
    psf = np.exp(-(xx**2 + yy**2) / (2.0 * sigma**2))
    psf /= psf.sum()
    return psf

def hogbom_clean(
    dirty, psf, gain=0.1, niter=1000, threshold=1e-4, verbose=False
):
    dirty = dirty.astype(np.float64)
    residual = dirty.copy()
    clean_components = np.zeros_like(dirty)
    psf_flipped = psf  # psf is symmetric in many cases
    for i in range(niter):
        peak_idx = np.unravel_index(np.argmax(residual), residual.shape)
        peak_val = residual[peak_idx]
        clean_components[peak_idx] += gain * peak_val
        delta = np.zeros_like(dirty)
        delta[peak_idx] = gain * peak_val
        sub = convolve2d(
            delta, psf_flipped, mode='same', boundary='fill', fillvalue=0.0)
        residual = residual - sub
    g_sigma = max(0.5, PSF_SIGMA / 2.0)
    g_size = (
        psf.shape[0]
        if psf.shape[0] % 2 == 1
        else psf.shape[0] + 1
    )

    restoring_beam = make_gaussian_psf(g_size, g_sigma)
    restored = (
        convolve2d(clean_components, restoring_beam, mode='same')
        + residual
    )
    return restored, clean_components, residual

                img_gray,

img = prepare_image('images/phangs.jpg', max_dim=368)

Let us walk through the key functions and code blocks from the above demo, explaining their roles and subtleties:

- **make_gaussian_psf**: Builds a Gaussian point-spread function.
- **hogbom_clean**: Implements the iterative CLEAN algorithm, finds the peak in the residual image, subtracts a scaled version of the PSF, and accumulates “clean components” (delta functions at source locations).
- **Restoring beam**: Approximates the PSF main lobe with a small Gaussian for a smoother final image.
- Here is the workflow:
    1. Load ground-truth image.
    2. Blur with PSF and add noise → dirty image.
    3. Apply CLEAN iterations → clean components + residual.
    4. Restore final image by convolving clean components with restoring beam + residual.

**Mean squared error (MSE)** is computed before and after restoration.

In practice, CLEAN requires careful parameter choices: the loop gain (γ) is usually kept small (0.05–0.3) for stability, with more iterations needed at lower gains; stopping thresholds should be set a few times the noise standard deviation; and the PSF must be large enough to capture sidelobes, with a Gaussian restoring beam approximating its central lobe for visually pleasing results. Computationally, naive convolution makes CLEAN expensive, scaling with the PSF size and iteration count, but FFT-based methods, Clark CLEAN, and batch subtraction strategies provide major speedups.

Classical Högbom CLEAN also has limitations: it assumes sparse point sources and struggles with extended structures, PSF mismatch, or poor stopping rules, often producing artifacts or biases. To address this, many variants exist, such as Clark and Cotton–Schwab CLEAN for efficiency and wide-field imaging, multi-scale and wavelet CLEAN for extended sources, and more recent formulations that integrate sparse recovery, regularization, or Bayesian priors for improved robustness.

Inverse and Wiener filters operate globally in the frequency domain and assume linear models with smooth priors; they are suited for extended smooth signals but can struggle with sidelobe confusion and strongly non-Gaussian noise. CLEAN is greedy/spatial, explicitly modeling discrete point sources and iteratively subtracting PSF-shaped patterns: it excels when the scene is sparse, and the PSF has strong sidelobes. From a signal-processing view, CLEAN ≈ matching pursuit with the dictionary = {shifted PSF atoms}; the restoring beam is analogous to post-processing the sparse code with a smoother basis function. CLEAN is an illuminating example of how algorithmic assumptions (sparsity, point sources) shape the form and success of restoration algorithms.

## Image restoration with sparse representations

Sparse representations build on the observation that natural-image patches lie near a low-dimensional manifold and can be approximated by a sparse linear combination of a small number of prototype atoms. Dictionary learning + sparse coding, therefore, offer a powerful and interpretable approach to denoising and other restoration tasks.

We extract overlapping patches $x_i \in \mathbb{R}^{p^2}$ from an image and assume each patch admits a sparse linear model in a dictionary $D \in \mathbb{R}^{p^2 \times K}$:

$$
x_i \approx D \alpha_i \text{ with } \| \alpha_i \|_0 \le s,
$$

where $\alpha_i$ is a sparse code and $s$ (sparsity) is the number of nonzeros allowed. For a fixed dictionary $D$, the sparse coding problem for a patch $x$ is

$$
\min_{\alpha} \| x - D \alpha \|_2^2 \quad \text{s.t.} \quad \| \alpha \|_0 \le s,
$$

which is NP-hard in general. Orthogonal Matching Pursuit (OMP) is a greedy algorithm that approximates this by iteratively selecting the dictionary atom most correlated with the current residual and then performing orthogonal projection to update coefficients. OMP yields a fast, widely used approximate solution and is what transform_algorithm='omp' implements.

Dictionary learning jointly estimates $D$ and sparse codes $A = [\alpha_1, ..., \alpha_N]$ by solving:

$$
\min_{D,A} \| X - D A \|_F^2 \text{ s.t. } \forall i \| \alpha_i \|_0 \le s,
$$

typically with alternating minimization:

- Fix $D$, compute sparse codes $A$ (e.g., OMP).
- Fix $A$, update $D$ (e.g., least-squares, column normalization).

sklearn.decomposition.DictionaryLearning implements this alternating strategy (a MOD-like/online implementation).

## Why zero-mean patches?

Many dictionary learning pipelines remove the DC (mean) from each patch before training. This decouples low-frequency (mean/brightness) from texture information and lets atoms focus on structure (edges, patterns). Re-adding the patch mean after reconstruction preserves the correct brightness.

The next code snippet implements a patch-based dictionary-learning denoising. Here are the steps:

- Load a grayscale image and add Gaussian noise.
- Extract overlapping patches from the noisy image (and from the clean image for dictionary training).
- Learn a dictionary $D$ from clean patches (subset).
- Zero-mean patches and use OMP to compute sparse codes for noisy patches.
- Reconstruct patches $\hat{x}_i = D\hat{\alpha}_i$ and re-add the patch means.
- Recompose the image by averaging overlapping patch reconstructions.

This is a classic pipeline (Elad & Aharon style) that removes noise by projecting local patches onto the learned low-dimensional manifold.
