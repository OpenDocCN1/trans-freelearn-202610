# Creating color pop effect with HSV manipulation

The color pop effect creates a dramatic appearance by converting most of an image to grayscale while preserving selected colors. This technique is conveniently implemented in the HSV color space, where reducing the saturation channel to zero produces grayscale regions.

The next code snippet converts an RGB image to HSV, filters pixels based on hue values, and sets the saturation channel to zero for all regions except selected colors. Since orange-like colors typically have low hue values, preserving pixels with hue ≤ 0.09 retains human skin tones while converting the remaining regions to grayscale. The modified HSV image is then converted back to RGB to obtain the final color pop effect.

```
im = imread('images/me.jpg')
im = im / im.max()  # normalize
im_hsv = color.rgb2hsv(im)
im_gray = im_hsv.copy()
im_gray[...,1] = 0  # set saturation of the pixels to 0
im_gray = color.hsv2rgb(im_gray) # creates grayscale image
im_hsv[im_hsv[...,0] > 0.09,1] = 0 #set all but skin pixel saturation to 0
im_out = color.hsv2rgb(im_hsv) # creates RGB image with all but
# skin pixels grayed out (popping the skin pixels out)
plt.imshow(np.hstack((im,im_gray,im_out)))
```
