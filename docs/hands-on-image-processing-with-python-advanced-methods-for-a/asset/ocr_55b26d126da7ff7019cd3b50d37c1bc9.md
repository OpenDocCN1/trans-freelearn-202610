# With `scipy.signal`

The `scipy` library’s signal module’s `convolve2d()` function can be used to apply 2D convolution to an image. Let us apply convolution on an image (first a grayscale image and then to an RGB color image) with a kernel (also called a filter, or a point-spread function – PSF sometimes) using this function.

Convolution on grayscale Images (SciPy)

Let’s now demonstrate two fundamental operations in image processing: **blurring** an image (the grayscale cameraman image is used as an input image here) with a box blur filter and **detecting edges** with the Laplace kernel, implemented using 2D convolution, using the following code snippet. Here is a detailed explanation of the relevant parts of the code that you’ll find below:

+   1. **Defining the box blur kernel**
+      - A box blur kernel is created, which is a 3x3 matrix of ones. Dividing by 9 **normalizes** the kernel so that the sum of all values in the kernel is 1. This ensures that the convolution does not amplify the brightness of the image.
+      - This kernel, when applied to the image, averages the pixel values within a 3x3 neighborhood, effectively creating a smoothing or blurring effect.
+   
+   2. **Defining the Laplace edge detection kernel**
+      - The **Laplace kernel** is used to perform **edge detection**. It detects changes in intensity by calculating the second derivative of the image. The kernel highlights regions where the intensity shifts significantly, which typically correspond to edges.
+      - In this kernel, the central pixel has a negative weight of -4, while its neighboring pixels in the four cardinal directions have a weight of +1. This arrangement emphasizes rapid changes in pixel intensity (i.e., edges).
+   
+   3. **Applying convolution to the image:**
+      - `signal.convolve2d()` convolves the grayscale image `im` with the kernels. Convolution slides the kernel over the entire image, replacing each pixel with the weighted average of its neighbors, thereby computing the convolved image.
+      - `blur_box_kernel` applies smoothing/blurring to the input image, and the result is stored in `im_blurred`.
+      - `edge_laplace_kernel` computes the difference in pixel intensity between a pixel and its neighbors, highlighting areas where the intensity changes abruptly (i.e., edges).
