
The diffusion model consists of the following processes (we shall explore more on this in the last chapter).

1. **Forward (noising) process**: A diffusion model defines a forward Markov chain that progressively corrupts a clean image $x_0$ into noise:

$$
q(x_t \mid x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}\,x_{t-1},\,\beta_t I),
$$

for timesteps $t = 1, ..., T$.

Closed form:

$$
x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1-\bar{\alpha}_t}\,\epsilon, \quad \epsilon \sim \mathcal{N}(0,I),
$$

where $\alpha_t = 1 - \beta_t$ and $\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$.

2. **Learned reverse (denoising) process**: A neural network $\epsilon_\theta(x_t, t, \text{cond})$ is trained to predict the added noise $\epsilon$. Sampling uses a learned reverse step to recover $x_{t-1}$ from $x_t$. One popular update (simplified) is:

$$
\hat{x}_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}}\,\epsilon_\theta(x_t, t, \text{cond})\right) + \sigma_t z,
$$

with $z \sim \mathcal{N}(0,I)$ and $\sigma_t$ a schedule-dependent noise term.

To steer sampling toward a condition (e.g., a text prompt $p$), **classifier-free guidance** forms an adjusted noise prediction:

$$\epsilon_{\text{guided}} = \epsilon_\theta(x_t, t \mid \text{cond}) + w\big(\epsilon_\theta(x_t, t \mid \text{cond}) - \epsilon_\theta(x_t, t \mid \emptyset)\big)$$

## How inpainting works conceptually with Stable Diffusion

*Stable Diffusion inpainting (which we shall revisit in chapter 13) typically operates in latent space:*

- The image is encoded to a latent $z_0$ by a **variational autoencoder (VAE)**:

$$
z_0 = \text{Enc}(x_0)
$$

- To inpaint only masked regions, the pipeline constructs a noisy latent in which only the masked region is noised, while the known unmasked region is preserved (or used as conditioning). A common approach produces a fully noised latent $z_T$ consistent with masked region, or combine the original latent in unmasked areas and a noisy latent in masked areas:

$$
z_t = z_t^{\text{noisy}} \odot \text{mask} + z_0 \odot (1 - \text{mask})
$$

so the model only needs to generate plausible content inside mask while keeping the rest unchanged.

- The denoiser UNet $\epsilon_\theta$ is conditioned on text (prompt) and also on the masked image representation (or explicit mask channels), so it knows which pixels to modify.
- After the denoising loop, the final latent is decoded by the VAE decoder:

$$
\hat{x}=\operatorname{Dec}(\hat{z}_0)
$$

In practice, the pipeline implementation details vary (exact latent mixing, whether the model accepts the masked image as extra channels or via cross attention). The key idea: only generate inside the mask; keep unmasked content consistent.

In practice, effective inpainting with diffusion models requires careful setup and tuning. Masks typically follow the convention `white = replace, black = keep`, and must align with the image. The prompt strongly influences the generated region, so combining scene context with style cues improves realism. Key parameters include `guidance_scale` (6–10 typical, balancing prompt faithfulness and realism), `num_inference_steps` (20 for previews, 50–100 for quality), and fixed seeds for reproducibility.

GPU memory can be managed with float16, CPU offload, or VAE slicing, though CPU-only inference is slow. Artifacts may appear as seams, inconsistent lighting, or hallucinated geometry, mitigated by feathered masks and strong contextual prompts. Compared to CNN-based methods like DeepFill (fast, structure-preserving, ideal for small holes), diffusion inpainting excels at semantic edits and novel content generation guided by text.

A good workflow involves careful mask preparation, resizing to 512×512 (or tiling), iterative prompt/seed exploration, and light post-processing (color matching, blending). Finally, ethical use requires respecting licensing, copyright, and dataset limitations.

## Inpainting with LaMa

**Large Mask Inpainting (LaMa)**, often described as *resolution-robust large mask inpainting with Fourier convolutions*, is a modern inpainting method designed to synthesize plausible content for very large holes while preserving high-resolution detail and global coherence. Unlike small-hole patching or local-propagation methods, LaMa gives the model a global receptive field (via frequency-domain / Fourier-style operations) so it can reason about long-range structure, lighting, and scene semantics, and it does so in a way that remains robust across resolutions.
