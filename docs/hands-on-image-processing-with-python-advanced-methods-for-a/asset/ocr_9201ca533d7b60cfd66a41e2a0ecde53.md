Despite effective patching, attention fusion, and class-imbalance handling, remote sensing segmentation remains challenging due to high-resolution complexity, multi-sensor variability, and severe class imbalance, motivating specialized architectures like Mixed-Attention U-Net for improved global context modeling and fine-detail preservation.

The MAnet architecture provides several important advantages:

+   - Improved contextual reasoning
+   - Enhanced boundary localization
+   - Better small-object detection
+   - Efficient encoder-decoder fusion
+   - Robustness to class imbalance

Attention mechanisms are particularly useful in remote sensing because satellite scenes contain highly heterogeneous spatial structures spanning multiple scales.

Mixed-attention satellite segmentation systems are widely used in land-cover classification, flood mapping, crop monitoring, wildfire assessment, urban expansion analysis, military reconnaissance, coastline extraction, road-network detection, and environmental surveillance. These systems form a critical component of modern geospatial AI pipelines.

# Segmentation evaluation metrics

Evaluating the quality of a segmentation model is as important as designing the model itself. In semantic and instance segmentation, the predicted mask Ŷ must be compared against the ground-truth mask Y to quantify how accurately the model identifies object boundaries and semantic regions.

Let $Y \subseteq \Omega$ denote the set of pixels belonging to the true object region, and let $\hat{Y} \subseteq \Omega$ represent the predicted segmentation region, where $\Omega$ is the image domain.

For binary segmentation, each pixel belongs either to the foreground or background class. The comparison between true and predicted classes is commonly expressed using the confusion matrix quantities:

+   - **True Positive (TP):** correctly predicted foreground pixels
+   - **False Positive (FP):** background pixels incorrectly predicted as foreground
+   - **False Negative (FN):** foreground pixels missed by the model
+   - **True Negative (TN):** correctly predicted background pixels

These quantities form the basis of most segmentation metrics.
