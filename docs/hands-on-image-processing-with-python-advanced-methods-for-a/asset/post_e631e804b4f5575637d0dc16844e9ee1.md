## Computing the cumulative distribution function of an image

For a random variable $X$, the **cumulative distribution function (CDF)** $F_X(x)$ is defined as follows:

$$F_X(x) = P(X \leq x)$$

Here, we have the following:

- P denotes the probability
- X is the random variable
- x is a specific value that X can take

These are the properties of CDF:

- **Non-decreasing:** The CDF is always non-decreasing. As you move to higher values of x, the probability of X being less than or equal to x cannot decrease.
- **Right-continuous:** The CDF is right-continuous, meaning that for any value of x, the function approaches F_X(x) from the right.
- **Limits:** As x → −∞, F_X(x) → 0, and x → ∞, F_X(x) → 1.
- **Range:** The CDF ranges from 0 to 1.
- The CDF is used for various purposes, including probability calculation, quantile determination, and distribution characterization.
- CDFs play a key role in **histogram equalization** (we shall explore this in a later chapter on image enhancement), where the CDF is used to remap image intensities to achieve a more uniform histogram and enhance the contrast of an image.

We can compute the CDF of each of the color channels separately, for a given RGB image, with the cumulative_distribution() function from the skimage.exposure module, as shown in the following code.

This code snippet plots the cumulative distributions for each of the R, G, and B channels. It uses LaTeX for prettier text rendering (matplotlib.rcParams['text.usetex'] = True) and labels the CDF curves clearly. The label parameter assigns a name to each plot curve, and legend() displays these labels on the plot to identify the curves:

```
import matplotlib

## Cropping an image

As we saw earlier, cropping an image refers to the process of removing unwanted portions or regions from an image, keeping only the desired part. This is done by selecting a specific rectangular or non-rectangular region within the original image and discarding the rest.

The `skimage.util.crop()` function allows for selective cropping along different dimensions, and the `copy=False` parameter ensures that the cropped region is a view into the original image without making a copy, as demonstrated in the next code snippet.

The first argument to the function is the input image (here, the RGB color Mona Lisa image).

The cropping is defined by the second argument, `((50,100),(50,50),(0,0))`, which represents the cropping parameters for each dimension. `crop_width` (which should be a sequence of integer tuples) represents the number of pixel values to remove from the edges of each axis. `((before_1, after_1), ... (before_N, after_N))` specifies the unique crop widths at the start and end of each axis. `((before, after), ...)` specifies a fixed start and end crop for every axis. Note that the color channel should not be cropped, that’s why the crop width for the last axis in the image array is `(0,0)`.

In this example, the cropping coordinates were specifically chosen to isolate the eye region of the Mona Lisa, illustrating how targeted cropping can extract a region of interest from an image:

```
from skimage.util import crop

im = imread('images/monalisa.jpg')
im_cropped = crop(im, ((250, 975), (280, 350), (0,0)), copy=False)
print(im.shape, im_cropped.shape)
# (1280, 846, 3) (30, 171, 3)
plot_images([im, im_cropped], ['original', 'cropped'], figsize=(6,5))
```

**Python Imaging Library (PIL)** was the original library for image processing in Python; **Pillow** is a fork of PIL, created to maintain and extend its functionality for newer Python versions. Pillow retains the core features of PIL while adding compatibility improvements, bug fixes, and performance enhancements, making it the go-to option for image processing in Python today. In this book, we shall refer to this library as PIL, although actually, Pillow will run under the hood due to its compatibility and support.
