
Let’s explore these concepts:

- First, let’s understand the `mode` argument and its possible values, for the convolution of an *M × N* input image with an *m × n* kernel:
  - `mode='full'`: This is the default mode, in which the output is the full discrete linear convolution of the input. It returns the full 2D convolution, including all border effects.
    - Output shape: *(M + m − 1, N + n − 1)*.
  - `mode='valid'`: This ignores edge pixels and only computes for those pixels with all neighbors (pixels that do not need zero-padding). The output image size is less than the input image size for all kernels (except 1 × 1). It returns only those parts of the convolution that are computed without zero-padding. Output size: *(M − m + 1, N − n + 1)*, assuming *M ≥ m* and *N ≥ n*.
  - `mode='same'`: The output image has the same size as the input image; it is centered with regards to the `'full'` output. It returns the central part of the convolution that is the same size as the first input. Output shape: *(M, N)*.

The next figure illustrates the difference between different 2D convolution *modes* with a 5×5 input image and a 3×3 kernel:

![](img/ebc2ad05fd41bdb1531c3dba43fbf8d5_239_0.png)

*Figure 5.3 – 2D convolution with modes valid, same, and full*

- The `boundary` argument is a flag indicating how to handle image boundaries. The parameter controls how the image is extended at the borders during convolution. Possible values are as follows:
  - `fill`: Pad input arrays with `fillvalue` (default 0). Use when edge information beyond the original image is not required.
  - `wrap`: Circular boundary conditions, values on the left *wrap* to the right, and top and bottom, and vice versa. Use when working with periodic or cyclic data (e.g., textures that tile). You want continuity at the borders, such as for some Fourier-based applications.
  - `symm`: Symmetrical boundary conditions – pad the image by reflecting the data symmetrically at the edges. It enables smooth extension with mirror symmetry at the boundaries. Use it to preserve edge-continuity and to avoid creating edges at the image boundaries. It is often the safest and most natural choice for general image processing.

The next table summarizes the boundary conditions:

| boundary | Description | When to Use |
|---|---|---|
| `'fill'` | Constant padding (default 0) | When simulating zero outside or ignoring edges |
| `'wrap'` | Periodic wrapping | For cyclic or tiling images |
| `'symm'` | Symmetric reflection | To avoid edge artifacts; best for general cases |

The `fillvalue` argument is an optional value to fill padded input arrays with; the default value is 0.

## Warning

> When using `scipy.signal.convolve2d`, especially for tasks such as edge detection, improper choice of `mode` and `boundary` parameters can lead to edge effects—artificial distortions near image borders. To preserve image dimensions and reduce artifacts, use `mode='same'` along with an appropriate boundary strategy such as `'symm'` (symmetric reflection) or `'wrap'` (periodic extension). Avoid the default `'fill'` with `fillvalue=0` unless zero-padding is explicitly desired, as it may introduce false edges.

## To color an (RGB) image

With `scipy.signal.convolve2d()`, we can sharpen an RGB image as well, using an appropriate filter (kernel). We have to apply the convolution separately for each color channel. Let's use the Taj Mahal image, with the emboss kernel and the Scharr edge detection complex kernel, with the help of the following code snippet:

```python
im = imread('images/tajmahal.jpg')
im = im / im.max()
print(np.max(im)) # pixels scaled to have values in [0,1]
# 1.0
emboss_kernel = np.array([[-2,-1,0],[-1,1,1],[0,1,2]])
edge_schar_kernel = np.array([[-3-3j, 0-10j, +3-3j],\
    [-10+0j, 0+0j, +10+0j],\
    [ -3+3j, 0+10j, +3+3j]])
im_embossed = np.ones(im.shape)
im_edges = np.ones(im.shape)
# apply filters across each color channel separately
for i in range(3):
    im_embossed[...,i] = np.clip(signal.convolve2d(im[...,i], \
        emboss_kernel, mode='same', boundary="symm"), 0, 1)
for i in range(3):
    im_edges[:,:,i] = np.clip(np.real(signal.convolve2d(im[...,i],
                            edge_schar_kernel, mode='same', boundary='symm')), 0, 1)
# plot image im, im_embossed and im_edges here
```

> **Note**
> 
> Unlike common edge detection kernels (e.g., the *Sobel* operator), which uses two separate kernels to compute horizontal (`G_x`) and vertical (`G_y`) gradients (we shall discuss more about image enhancement with derivatives in *Chapter 7*), the *Scharr* operator can be combined into a *single complex kernel*:
> 
> `G_x = [[−3, 0, +3], [−10, 0, +10], [−3, 0, +3]]`
> 
> `G_y = [[−3, −10, −3], [0, 0, 0], [+3, +10, +3]]`
> 
> The complex kernel `K = G_x + iG_y` enables detection of both *horizontal* (real part) and *vertical* (imaginary part) edges in a *single convolution*. The output encodes edge strength (via magnitude) and orientation (via phase), making this approach both compact and efficient.

## With scipy.ndimage

With `scipy.ndimage.convolve()`, we can sharpen an RGB image directly (we do not have to apply the convolution separately for each image channel). Use the `victoria_memorial` image with 3 × 3 sharpen, **emboss**, and **lighten** kernels defined in the following code snippet, which applies these three different convolution kernels to an image and visualizes the results using matplotlib. The following three kernels – `sharpen_kernel`, `emboss_kernel`, and `lighten_kernel` – are used to compute a sharpened, an embossed, and a lightened image, respectively, as described here:

- The sharpened image enhances the edges and details
- The embossed image gives the image a 3D effect
- The lightened image increases the brightness of the image

These filters are commonly used in image processing for enhancing visual features or applying artistic effects. Here is the code snippet illustrating that:

```python
im = imread('images/victoria_memorial.png') # read as float
im = im / im.max()
sharpen_kernel = np.array([[0, -1, 0], [-1, 5, -1], [0, -1, 0]]) \
    .reshape((3, 3, 1))
emboss_kernel = np.array([[-2,-1,0],[-1,1,1],[0,1,2]]) \
    .reshape((3, 3, 1))
lighten_kernel = (np.array([[0,0,0], [0,12,0], [0,0,0]]) / 9) \
    .reshape((3, 3, 1))

im_sharp = np.clip(ndimage.convolve(im, sharpen_kernel,
    mode='nearest'), 0, 1)
im_emboss = np.clip(ndimage.convolve(im, emboss_kernel,
    mode='nearest'), 0, 1)
im_light = np.clip(ndimage.convolve(im, lighten_kernel,
    mode='nearest'), 0, 1)
# plot im_sharp, im_emboss and im_light here
```

Let's go through each part of the preceding code snippet in detail:

- Defining the convolution kernels: Three kernels are defined here. Each of them is a 3 × 3 matrix:
  - Sharpen kernel: This kernel sharpens the image by highlighting edges. The center pixel value is increased (5), and surrounding pixels are subtracted to enhance contrast.
  - Emboss kernel: This kernel gives the image an embossed effect, making it look as though it has depth. The kernel emphasizes diagonally adjacent pixels to create a 3D-like effect.
  - Lighten kernel: This kernel increases the brightness of the center pixel by distributing a higher value over a small area. The division by 9 smooths the effect by averaging the center value.
- Applying the kernels using convolution:
  - `ndimage.convolve(im, kernel, mode='nearest')`: This applies a convolution between the image and the specified kernel (sharpen, emboss, or lighten). Convolution works by sliding the kernel over the image and computing the sum of the products of the kernel and the underlying pixels.
  - `mode='nearest'`: This ensures that the borders of the image are handled by copying the nearest pixel values to avoid artifacts at the edges.
  - `np.clip(..., 0, 1)`: After convolution, the pixel values might exceed the range of [0,1]. The `np.clip()` function ensures that all pixel values are clipped (restricted) to remain between 0 and 1. This keeps the pixel values valid for displaying as a grayscale image (0 = black, 1 = white).
