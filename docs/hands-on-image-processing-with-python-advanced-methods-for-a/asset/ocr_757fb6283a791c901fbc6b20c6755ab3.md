The training objective combines weighted cross-entropy and Dice loss. Mathematically,

$$\mathcal{L} = \lambda \mathcal{L}_{CE} + (1-\lambda)\mathcal{L}_{Dice},$$

with $\lambda = 0.5$. This hybrid formulation combines:

+   - Pixel-wise classification accuracy
+   - Region-level overlap optimization

The network is optimized using **AdamW**, which decouples weight decay from adaptive gradient estimation. Gradient clipping is additionally employed with the function `clip_grad_norm_()`. This prevents exploding gradients by enforcing $\|\nabla\theta\|_2 \leq 1$, thus stabilizing optimization.

The scheduler reduces the learning rate when optimization stagnates with the function `torch.optim.lr_scheduler.ReduceLROnPlateau`. If validation loss plateaus, the learning rate becomes:

$$\eta_{t+1} = 0.5\eta_t$$

Adaptive scheduling improves convergence near local minima.

Here, the training loss decreases steadily. This indicates successful convergence. The decrease in Dice-based loss implies increasing overlap between predicted and ground-truth regions.

The trained model is saved using the function `torch.save()`. This stores model weights, optimizer state, and training epoch, allowing training to resume later without loss of optimizer statistics.
