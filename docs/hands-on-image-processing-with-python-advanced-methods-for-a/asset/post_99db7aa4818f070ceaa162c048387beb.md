
## With scipy.signal

The `normalized_cross_correlation()` function, in the following code block, implements Normalized Cross-Correlation (NCC) for template matching by computing the mean and standard deviation of the template and corresponding image patches, zero-centering the template, and evaluating similarity using `signal.correlate2d()`. The numerator is obtained from the cross-correlation between the image and the zero-mean template, while the denominator normalizes the result using the product of the template and local image standard deviations. This normalization makes NCC largely invariant to intensity scaling and contrast variations. The resulting NCC correlation map contains values close to 1 at locations that best match the template, enabling more robust matching than standard cross-correlation.

```
def normalized_cross_correlation(image, template):
    # Compute means
    template_mean = np.mean(template)
    image_mean = signal.correlate2d(image, \
        np.ones(template.shape), mode='valid') / template.size
    # Compute zero-mean template
    template_zero_mean = template - template_mean
    # Compute numerator: cross-correlation of zero-mean
    #               template with image
    numerator = signal.correlate2d(image, template_zero_mean, \
                    mode='valid')
    # Compute denominator: standard deviations
    image_std = np.sqrt(signal.correlate2d(image**2,
        np.ones(template.shape), mode='valid')
        / template.size - image_mean**2)
    template_std = np.std(template)
    # Avoid division by zero
    denominator = image_std * template_std
    denominator[denominator == 0] = 1e-10  # prevent NaN
    # Compute NCC
    ncc = numerator / denominator
    return ncc

ncc = normalized_cross_correlation(face_image, template_image)
# plot cc and ncc images side-by-side
```

### The convolution theorem

The convolution theorem says that convolution in an image's spatial domain is equivalent to a simple multiplication in the frequency domain and vice versa:

### Convolving with a Gaussian blur kernel

As discussed earlier, an image is convolved with a Gaussian blur kernel smoothing/removing noise from the image. It typically removes high-frequency components (e.g., noise) from an image and hence acts as a low-pass filter (LPF).

This behavior is governed by the Gaussian function: G(x) = 1/√(2πσ²) e^(-x²/(2σ²)) for 1D, and extended to 2D as G(x,y) = 1/(2πσ²) e^(-(x²+y²)/(2σ²)). The 2D Gaussian is separable, meaning it can be efficiently computed as the outer product of two 1D kernels as G(x,y) = G(x) · G(y). This reduces the computational cost and is widely used in practice.

Let's start by visualizing the frequency spectrum magnitude of a Gaussian kernel.

#### Note

With `scipy.signal.windows.gaussian(M, std)`, we need to manually specify both the kernel size (`M`) and the standard deviation (`std`). This provides fine-grained control and transparency over the filter shape. The kernel is typically normalized and applied via convolution. In contrast, `scipy.ndimage.gaussian_filter(input, sigma)` automatically generates the Gaussian kernel internally based on the given standard deviation `sigma`, determines an appropriate kernel size for you, and applies it to the given image `input` array. This function is simpler to use and more efficient for multi-dimensional data but provides less visibility into the kernel itself.
