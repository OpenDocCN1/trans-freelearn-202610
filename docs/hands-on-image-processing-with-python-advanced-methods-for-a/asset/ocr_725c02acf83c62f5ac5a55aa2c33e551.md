The next code snippet demonstrates matrix-based DCT computation using scipy.fftpack.dct(). The DCT matrix D is generated from an identity matrix with norm='ortho', producing orthonormal cosine basis vectors. For an image f, the forward transform is computed as C = DfD^T, and the inverse reconstruction as f_c = D^T C D.

```
f = imread('images/lena.jpg', True) # assumption: a square NxN image
D = fp.dct(np.eye(f.shape[0]), norm='ortho', axis=0)
C = D@f@D.T
f_c = D.T@C@D
# now plot f, D, C and f_c side-by-side
```
