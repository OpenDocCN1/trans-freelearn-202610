# Who this book is for

This book is for students, researchers, engineers, and practitioners in computer vision, machine learning, and deep learning who want to build a strong foundation in image processing and advance to modern vision systems, including image classification, object detection, segmentation, generative AI, and state-of-the-art (SOTA) deep learning models. It is intended for Python developers and applied scientists who want to move beyond black-box usage and understand the underlying mathematical principles, algorithms, and implementations using tools such as NumPy, OpenCV, PyTorch, and TensorFlow. A basic understanding of Python, linear algebra, and probability is assumed, while prior exposure to machine learning or image processing is helpful but not required.

# What this book covers

Chapter 1, Getting Started with Digital Image Processing, introduces the fundamentals of digital image representation, sampling, quantization, and image I/O using Python, along with core libraries such as PIL, OpenCV, and scikit-image for reading, writing, and displaying images.

Chapter 2, Image Manipulation, concerns advanced image manipulation using NumPy, PIL, and scikit-image, including geometric transformations, intensity operations, blending, compositing, alpha masking, histogram analysis, drawing primitives, and multi-channel image processing.

Chapter 3, More Image Manipulation, shows how to perform advanced image processing across multiple libraries such as OpenCV, SciPy, PIL, and scikit-image, covering LUT-based transformations, color effects, geometric warping, homography, fisheye correction, interpolation, and image-based visual effects.

Chapter 4, Sampling and Fourier Transform, explores image formation through sampling and quantization, including upsampling, downsampling, aliasing, interpolation, and a rigorous introduction to frequency-domain analysis using DFT, FFT, DCT, and Walsh-Hadamard transforms with their mathematical properties.

Chapter 5, Convolution and Spatial/Frequency Domain Filtering, explains convolution theory in both spatial and frequency domains, including correlation, template matching, Gaussian filtering, the convolution theorem, and practical implementations using SciPy, OpenCV, and PyTorch, along with 2D and 3D convolution concepts.
