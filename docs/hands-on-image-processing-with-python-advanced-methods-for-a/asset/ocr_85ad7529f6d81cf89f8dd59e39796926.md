# Image Enhancement

In this chapter, we shall explore a broad range of image enhancement techniques, from classical pixel-based transformations to modern deep learning models, aimed at improving visual quality and emphasizing important features. Unlike image restoration, enhancement methods do not rely on explicit degradation models but instead focus on refining contrast, reducing noise, and enhancing details.

We begin with point-wise intensity transformations, histogram-based contrast adjustment, and dithering algorithms, followed by linear and nonlinear smoothing techniques such as Gaussian, median, bilateral, and non-local means filtering. The chapter also covers fuzzy logic-based contrast enhancement and wavelet-domain image fusion. To make the concepts hands-on, an interactive Streamlit app demonstrates these enhancement techniques on user-provided images. Finally, we demonstrate advanced deep learning-based enhancement methods, including low-light correction, denoising, dehazing, and super-resolution using pretrained models.

The key topics to be covered in this chapter are as follows:

+   - Point-wise intensity transformations
+   - Tone and perceptual enhancement
+   - Image enhancement with histogram processing
+   - Fuzzy logic-based image enhancement
+   - Linear noise-smoothing
+   - Non-linear noise smoothing
+   - Wavelet-based image fusion and enhancement
+   - Image enhancement with deep learning models
