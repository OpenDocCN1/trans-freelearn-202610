**Prototype-Based Few-Shot Classification:** A small support set containing only a couple of examples per class is provided.

```
support_set = {"dog": ["dog1.png", "dog2.png"],
               "cat": ["cat1.png", "cat2.png"]}
```

For each class, embeddings are averaged to form a **prototype** (class representative):

$$p_c = \frac{1}{N_c}\sum_{i=1}^{N_c} f(x_i)$$

```
embs = [get_embedding(p) for p in paths]
prototypes[cls] = torch.stack(embs).mean(0)  # prototype construction
```

Intuitively, a prototype acts as the “center” of a class in the embedding space.

**Similarity-Based Prediction:** The query image is embedded and compared against all class prototypes using **cosine similarity**:

$$\operatorname{sim}(q,p_c)=\frac{q^T p_c}{\lVert q\rVert\lVert p_c\rVert}$$

as implemented using the following code.

```
query_emb = get_embedding("lab.png")
sim = F.cosine_similarity(query_emb, proto, dim=0)
```

The predicted class is simply the prototype with the highest similarity:

$$\hat{c}=\arg\max_c \operatorname{sim}(q,p_c)$$

Unlike conventional supervised embeddings, DINOv2 learns general-purpose visual representations through *self-supervised* **teacher–student** training on multiple augmented views of unlabeled images, where the student learns to match the teacher’s **prototype-based semantic representations**, encouraging images with similar underlying visual content to occupy nearby regions of the feature space while remaining invariant to appearance changes.

A Labrador image therefore produces an embedding closer to the **dog prototype** than the **cat prototype**, even though only a few support examples are available. In essence, few-shot learning becomes a **nearest-prototype search in embedding space**, leveraging the powerful visual knowledge learned during large-scale self-supervised pretraining.
