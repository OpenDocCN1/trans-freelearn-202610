Where:

+   - $I_{p_0}(x, y)$ is the intensity value at the $p_0$ percentile within the neighborhood $N(x, y)$
+   - $I_{p_1}(x, y)$ is similarly the value at the $p_1$ percentile

The difference between these percentile values captures the **range of intensity variations**, focusing on meaningful local contrasts while ignoring minor fluctuations or outliers.
