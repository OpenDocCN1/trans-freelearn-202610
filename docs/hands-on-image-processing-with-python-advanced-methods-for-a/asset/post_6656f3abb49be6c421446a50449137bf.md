## Image Segmentation: From Classical Methods to Deep Learning

**Image segmentation** is a foundational problem in computer vision that focuses on decomposing an image into semantically or structurally consistent regions. Unlike **image classification**, which summarizes an entire scene with a single label, or **object detection**, which represents objects using coarse spatial abstractions such as bounding boxes (we shall explore both of them in the next chapter), segmentation provides a dense and fine-grained interpretation of visual content by assigning labels at the pixel level. This pixel-wise reasoning enables a richer representation of scene structure, bridging low-level visual cues with high-level semantic understanding, and serving as a critical step in applications ranging from medical imaging to scene parsing and interactive vision systems.

Formally, given an image $I: \Omega \subset \mathbb{R}^2 \to \mathbb{R}^c$, segmentation seeks a partition:

$$\Omega = \bigcup_{k=1}^{K} R_k, \quad R_i \cap R_j = \emptyset$$

where each region $R_k$ corresponds to a semantically or structurally meaningful entity.

Segmentation techniques have evolved dramatically. Early approaches relied on intensity statistics, gradients, morphology, and variational calculus, whereas modern approaches leverage convolutional neural networks, transformers, diffusion models, and foundation models. This chapter is divided into two major parts: classical image segmentation and deep learning based segmentation.

In this chapter, we will learn the following topics:

- Classical image segmentation
- Deep learning for image segmentation

Together, they provide unified theoretical and practical treatment.

### Classical image segmentation

Classical segmentation methods rely on explicit mathematical modeling of intensity distributions, spatial continuity, edge information, region homogeneity and energy minimization principles. These approaches are interpretable, computationally efficient, and form the theoretical backbone of modern deep learning models. We group the topics into conceptual blocks.

### Threshold-based segmentation

Thresholding is one of the most fundamental and interpretable approaches in image segmentation. It partitions the intensity space into disjoint regions such that pixels within each region share similar gray-level characteristics. While classical thresholding methods separate an image into two classes (**foreground/background**), many real-world images contain **multiple semantic regions**, motivating **multi-level thresholding**.

### From binary Otsu to multi-Otsu thresholding

The classical Otsu’s method (proposed by Nobuyuki Otsu in 1979) determines an optimal threshold by maximizing the **between-class variance**:

$$\sigma^2_{\text{between}} = \omega_0(\mu_0 - \mu_T)^2 + \omega_1(\mu_1 - \mu_T)^2$$

where $\omega_i$ is the probability (weight) of class $i$, $\mu_i$ is mean intensity of class $i$ and $\mu_T$ is the global mean intensity of the image.

The optimal thresholds are obtained by solving:

(t₁*, …, tₖ₋₁*) = argmaxₜ₁,…,ₜₖ₋₁ ∑ᵢ₌₁ᴷ ωᵢ (μᵢ − μ_T)²

This is equivalent to maximizing **inter-class variance**, which implicitly minimizes **intra-class variance** due to:

σ²_total = σ²_within + σ²_between

### Computational considerations

A brute-force search over all threshold combinations has complexity:

O(L^{K−1}),

where L is number of gray-levels. The complexity increases exponentially with number of classes K. Practical implementations (such as in scikit-image) use dynamic programming or histogram precomputation to significantly reduce computational cost.

Multi-Otsu essentially models the histogram as a mixture of K clusters. It tries to find thresholds that best separate these clusters. It works best when histogram is multi-modal.

The next code snippet uses scikit-image implementation to demonstrate the Multi-Otsu algorithm. It computes optimal intensity thresholds based on the specified number of desired classes. By default, the number of classes is set to three, which results in two optimal threshold values partitioning the histogram into three distinct regions. These thresholds are visualized as vertical red lines on the intensity histogram in the figure below, clearly indicating the separation between classes.

The function threshold_multiotsu() from the module skimage.filters computes optimal thresholds.

Default behavior: K = 3 classes and returns K − 1 = 2 thresholds: [t₁, t₂]. Internally it computes histogram (p(i)), searches threshold combinations and maximizes between-class variance. The function np.digitize() assigns each pixel to a class:

Class 0: I ≤ t₁, Class 1: t₁ < I ≤ t₂ and Class 2: I > t₂.

**Histogram and Thresholds:** Histogram approximates the PMF p(i). Red lines = optimal thresholds and peaks correspond to different regions (e.g., background, object, highlights). Thresholds lie between peaks. Finally the segmented regions are displayed with pseudo-colors, each color corresponds to a class. This produces a label map, as shown:

```
from skimage import data
from skimage.filters import threshold_multiotsu
image = data.camera()
thresholds = threshold_multiotsu(image)
regions = np.digitize(image, bins=thresholds)
```
