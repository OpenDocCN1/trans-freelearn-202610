### Zooming

Zooming in and zooming out in the context of image processing refers to operations that change the apparent size of an image. These operations involve adjusting the spatial resolution of the image to make it appear larger or smaller on a display:

- Zooming in: Also known as magnification or enlargement, this involves making the image appear larger on the display by increasing its spatial resolution. Details in the image become more visible, and the image occupies a larger portion of the screen or canvas. Zooming in is often used to closely examine the fine details of an image or to focus on a specific region of interest.
- **Zooming out:** Also known as reduction, this involves making the image appear smaller on the display by decreasing its spatial resolution. The entire image is visible on the screen, but details may become less distinguishable. The image occupies a smaller portion of the screen or canvas. Zooming out is useful when you want to get an overview of the entire image or when dealing with large datasets where a reduced representation is sufficient.

The following code block demonstrates how to use the `zoom()` function from the `scipy.ndimage` module to zoom in and then crop a portion of the image using NumPy ndarray slicing.

Note that the `zoom_in_factor` is set to 2, indicating that we want to double the size of the image in both dimensions.

Also note that there is no zoom on the color channel. `zoom=(2,2,1)` means that the zoom_factor value along the color channel is 1. Also, the order of the **spline interpolation** used in the following code snippet is 1.

User can use a zoom value of less than 1 for zooming out (by down-sampling).

### Applying wave distortion

The following code snippet applies a sinusoidal distortion to the Mona Lisa image using the scipy.ndimage.map_coordinates() function, creating a visually interesting effect by modifying the y coordinates of the image pixels based on a sinusoidal function of the x coordinates. Here are the key steps:

- The np.meshgrid() function is used to create a grid of coordinates representing pixel locations in the original image.
- The coordinates are modified by adding a sinusoidal distortion based on the coordinates.
- The map_coordinates() function from scipy.ndimage is used to map the pixel values from the original image to the distorted coordinates. It is used to interpolate the pixel values from the distorted coordinates, resulting in the final distorted image.
