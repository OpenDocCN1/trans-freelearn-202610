The function `edgesNms()` computes **non-maximum suppression (NMS)**, which is a classical technique used to thin out wide edge responses by retaining only the local maxima in the direction orthogonal to the edge.

Suppose you have a wide fuzzy edge. You want to keep only the strongest pixel value across the edge width, i.e., the center of the edge. This is done by comparing each pixel’s edge strength with its neighbors along the direction perpendicular to the edge. If the pixel is not the local maximum, it is suppressed to zero.

Let $E(x,y)$ be the edge-strength and $\theta(x,y)$ the orientation. For each pixel $(x,y)$, we compute:

$$E'(x,y)=\begin{cases} E(x,y), & E(x,y)>E(x',y')\land E(x,y)>E(x'',y'')\\ 0, & \text{otherwise}\end{cases}$$

where $(x',y')$ and $(x'',y'')$ are neighbors of $(x,y)$ along the gradient direction (i.e., orthogonal to the edge direction $\theta$).
