## Color correction with white balance algorithms

White balancing aims to ensure that whites in the scene appear white in the image, compensating for the color temperature of the light source. Here are a few popular algorithms:

- **Gray world**: Assumes average reflectance is gray, i.e., average R, G, B intensities should be equal under neutral illumination, and scales each channel to equalize its average with the global average: $scale_c = \frac{avg_{gray}}{avg_c}$.
- **White balance (Channel-wise Percentile Clipping)**: Adjusts each R, G, B channel independently and clips the lowest and highest percentiles (e.g., 0.05% and 99.95%) to remove outliers. It rescales pixel values to [0, 255] range linearly:
  
  $$channel = \left(\frac{I - min}{max - min}\right) \times 255,$$
  
  and removes shadows and highlights per channel to normalize brightness
- **White-patch**: Assumes the brightest pixel in each channel should represent white and scales each channel so its maximum intensity becomes 255 ($scale_c = \frac{255}{max_c}$).
- **White-patch percentile variant**: Same idea as white-patch, but uses the 95th percentile instead of absolute maximum. It is more robust to noise or isolated specular highlights.
- **Shades of gray (Minkowski norm)**: Generalizes gray-world by computing **Minkowski norm** of RGB intensities:
  
  $$Wc = \left(\frac{1}{N}\sum_{i=1}^{N} (I_c(i))^p\right)^{\frac{1}{p}}$$

It is more adaptable across diverse lighting conditions ($p \approx 6$ works well in practice). It normalizes each channel by this estimated illuminant.

The next code snippet demonstrates *white balance correction* using the classic algorithms listed above, each aiming to neutralize color casts in images by adjusting RGB channels to simulate ideal lighting (white light):

    return channel

## Linear noise smoothing

Linear (spatial) filtering operates by computing a weighted sum of pixel intensities over a local neighborhood. Let $f(x,y)$ denote the input image and $g(x,y)$ the filtered output. A linear filter is defined as:

$$g(x,y)=\sum_{i=-k}^{k}\sum_{j=-k}^{k} h(i,j)f(x-i,y-j)$$

Where $h(i,j)$ is the filter kernel (mask) of size $(2k+1)\times(2k+1)$, the operation corresponds to 2D discrete convolution, written compactly as $g=f*h$. Linear filtering is widely used for **noise suppression (smoothing)** because it attenuates high-frequency components of the image. If the observed image is modeled as:

$$f(x,y)=s(x,y)+n(x,y)$$

where $s(x,y)$ is the true signal and $n(x,y)$ is additive noise, then linear smoothing reduces the variance of $n(x,y)$ by averaging neighboring pixels. Blurring is therefore commonly used as a *pre-processing step* to remove small, irrelevant details and noise prior to higher-level analysis.

The box filter is the simplest linear smoothing operator, where all weights are equal:

$$h(i,j)=\frac{1}{(2k+1)^2},\qquad \forall(i,j)$$

Thus, the filtered image becomes:

$$g(x,y)=\frac{1}{(2k+1)^2}\sum_{i=-k}^{k}\sum_{j=-k}^{k}f(x-i,y-j)$$

The box filter has the following effect:

- Each pixel is replaced by the local **mean**
- Reduces random noise via averaging
- Causes **edge blurring**, since sharp transitions are smoothed

A more advanced linear filter uses a Gaussian kernel:

$$h(i,j)=\frac{1}{2\pi\sigma^2}\exp\left(-\frac{i^2+j^2}{2\sigma^2}\right)$$

leading to:

$$g(x,y)=\sum_{i=-k}^{k}\sum_{j=-k}^{k}h(i,j)f(x-i,y-j)$$

Here, the weights decrease exponentially with distance, giving more importance to nearby pixels, and produce smoother and more natural blur than the box filter.

Increasing kernel size $(2k+1)$ or Gaussian standard deviation $\sigma$:

- Increases smoothing
- Reduces noise variance
- But also removes fine details

The following sections illustrate how to apply linear noise smoothing on images, first using the `PIL.ImageFilter` class and then using the `scipy.ndimage` module’s filter functions.

## Smoothing with the Gaussian blur filter

The Gaussian blur filter is also a linear filter but, unlike the simple mean filter, it takes the weighted average of the pixels inside the kernel window to smooth a pixel (the weight corresponding to a neighbor pixel decreases exponentially with the distance of the neighbor from the pixel). The Gaussian blur filter performs convolution with a Gaussian kernel:

g = f * h_σ

where h_σ is the Gaussian kernel with standard deviation σ

- Larger σ → wider kernel → stronger smoothing
- Noise is progressively removed
- Image details are increasingly blurred

A 5 × 5 Gaussian kernel is obtained by sampling the 2D Gaussian:

h(i,j) = 1/(2πσ²) exp( - (i² + j²)/(2σ²) ),      i,j ∈ −2,−1,0,1,2

For the commonly used case σ ≈ 1, the normalized 5 × 5 kernel is:

h = 1/273 [1 4 7 4 1; 4 16 26 16 4; 7 26 41 26 7; 4 16 26 16 4; 1 4 7 4 1]

Notes

- The kernel is symmetric and separable
- The normalization factor (273) ensures: Σ_{i,j} h(i,j) = 1
- Larger values near the center give higher weight to nearby pixels, producing smooth, natural blurring
