## IP-Adapter and ControlNet for identity-preserving pose-guided generation

One limitation of text-to-image diffusion models is that they cannot reliably preserve the appearance of a specific person while simultaneously controlling pose and composition. Two recent conditioning mechanisms address this problem. **IP-Adapter (Image Prompt Adapter)** injects visual information from a reference image into the diffusion model, while **ControlNet** imposes structural constraints such as edges, depth maps, segmentation masks, or human poses. By combining both methods, it becomes possible to generate images that preserve a person’s identity while following a desired pose.

**IP-Adapter:** Traditional Stable Diffusion relies solely on text embeddings. IP-Adapter extends the conditioning mechanism by extracting visual features from a reference image and injecting them into the diffusion U-Net through additional cross-attention layers. Let *T* denote the text embedding and *I* the image embedding extracted from a vision encoder. The diffusion model becomes ε<sub>θ</sub>(z<sub>t</sub>, t, T, I),

where z_t is the noisy latent representation. Consequently, generation is guided by both textual and visual information. The IP-Adapter is loaded into the Stable Diffusion pipeline using:

```
pipe.load_ip_adapter("h94/IP-Adapter", subfolder="models", weight_name="ip-adapter_sd15.bin")
pipe.set_ip_adapter_scale(0.8)
```

The parameter ip_adapter_scale controls the influence of the reference image. Larger values increase identity preservation, while smaller values provide greater freedom for the text prompt.

ControlNet: Although IP-Adapter preserves appearance, it does not explicitly constrain image geometry. ControlNet introduces an auxiliary network that conditions diffusion on structural signals. Given a control image c, the denoising process becomes ε_θ(z_t, t, T, c). In this example, the control signal is an OpenPose skeleton describing the desired body pose:

```
controlnet = ControlNetModel.from_pretrained("lllyasviel/control_v11p_sd15_openpose")
```

The OpenPose image acts as a geometric blueprint, forcing the generated subject to follow the specified pose while remaining consistent with the text prompt.

## Combining Identity and Pose Constraints: The complete pipeline combines three conditioning sources:

- Text prompt – controls semantic content
- Reference image (IP-Adapter) – preserves identity and appearance
- OpenPose skeleton (ControlNet) – constrains body pose

The Stable Diffusion pipeline is constructed as:

```
pipe = StableDiffusionControlNetPipeline.from_pretrained("runwayml/stable-diffusion-v1-5",
    controlnet=controlnet, torch_dtype=torch.float16)
```

Generation is then performed using:

```
images = pipe(prompt="professional portrait photograph",
    image=openpose_image, ip_adapter_image=reference_image,
    num_inference_steps=30, guidance_scale=7.5, num_images_per_prompt=4).images
```

Here, openpose_image provides pose information, while reference_image supplies facial appearance and identity cues. The resulting images inherit the facial characteristics and visual style of the reference image while adopting the pose encoded by the OpenPose skeleton. Unlike ordinary text-to-image generation, which often changes identity across samples, the combined IP-Adapter and ControlNet framework enables controlled synthesis where identity and pose can be manipulated independently. This capability is particularly valuable for avatar generation, virtual photography, digital humans, character animation, fashion visualization, and pose-guided portrait synthesis.

## Image generation with DALL·E 2 and DALL·E 3 APIs

OpenAI’s DALL·E family of models enables high-quality text-to-image generation from natural language descriptions. Given a textual prompt y, the model learns a conditional distribution p(x|y), where x denotes the generated image. DALL·E 2 introduced powerful text-guided image synthesis and variation generation, while DALL·E 3 significantly improved prompt understanding, compositional reasoning, scene coherence, typography, and adherence to detailed instructions. These models are widely used for concept art, advertising, product visualization, storytelling, architectural design, and creative content generation.

## Generating Images with DALL·E 2: DALL·E 2 creates images directly from text prompts.

```
resp = client.images.generate(model="dall-e-2", prompt=prompt,
    size="1024x1024", n=1)
```

The model receives a textual description and generates one or more images consistent with the prompt. In the demonstration, multiple generations are requested for the same prompt to visualize output diversity. Because image generation is stochastic, repeated executions often produce different interpretations of the same description. The helper function generate_dalle2() creates a base image and two additional variations for each prompt.

```
def generate_dalle2(prompt):  # DALL-E 2 generator
    resp_base = client.images.generate(model="dall-e-2",
                                    prompt=prompt, size="1024x1024",  n=1)
    base_img = get_image(resp_base.data[0].url)
    resp_vars = client.images.generate(model="dall-e-2",
                                    prompt=prompt, size="1024x1024",  n=2)
    var1 = get_image(resp_vars.data[0].url)
    var2 = get_image(resp_vars.data[1].url)
    return base_img, var1, var2
```
