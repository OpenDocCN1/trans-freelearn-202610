## Who this book is for

This book is for students, researchers, engineers, and practitioners in computer vision, machine learning, and deep learning who want to build a strong foundation in image processing and advance to modern vision systems, including image classification, object detection, segmentation, generative AI, and state-of-the-art (SOTA) deep learning models. It is intended for Python developers and applied scientists who want to move beyond black-box usage and understand the underlying mathematical principles, algorithms, and implementations using tools such as NumPy, OpenCV, PyTorch, and TensorFlow. A basic understanding of Python, linear algebra, and probability is assumed, while prior exposure to machine learning or image processing is helpful but not required.

## What this book covers

Chapter 1, Getting Started with Digital Image Processing, introduces the fundamentals of digital image representation, sampling, quantization, and image I/O using Python, along with core libraries such as PIL, OpenCV, and scikit-image for reading, writing, and displaying images.

Chapter 2, Image Manipulation, concerns advanced image manipulation using NumPy, PIL, and scikit-image, including geometric transformations, intensity operations, blending, compositing, alpha masking, histogram analysis, drawing primitives, and multi-channel image processing.

Chapter 3, More Image Manipulation, shows how to perform advanced image processing across multiple libraries such as OpenCV, SciPy, PIL, and scikit-image, covering LUT-based transformations, color effects, geometric warping, homography, fisheye correction, interpolation, and image-based visual effects.

Chapter 4, Sampling and Fourier Transform, explores image formation through sampling and quantization, including upsampling, downsampling, aliasing, interpolation, and a rigorous introduction to frequency-domain analysis using DFT, FFT, DCT, and Walsh-Hadamard transforms with their mathematical properties.

Chapter 5, Convolution and Spatial/Frequency Domain Filtering, explains convolution theory in both spatial and frequency domains, including correlation, template matching, Gaussian filtering, the convolution theorem, and practical implementations using SciPy, OpenCV, and PyTorch, along with 2D and 3D convolution concepts.

Chapter 6, Frequency Domain Filtering, details frequency-domain filtering techniques including low-pass, high-pass, band-pass, and notch filters using Ideal, Butterworth, and Gaussian formulations, with applications in denoising, periodic noise removal, and Fourier feature representations.

Chapter 7, Image Enhancement, covers point-wise intensity transformations, histogram processing, contrast enhancement, dithering, fuzzy logic-based enhancement, color correction, denoising techniques, wavelet methods, and modern deep learning-based enhancement models including Zero-DCE, BM3D, and EDSR.

Chapter 8, Image Enhancements Using Derivatives, explains derivative-based image processing including gradients, Laplacian operators, edge detection (Sobel, Canny, LoG, DoG, compass filters), anisotropic diffusion, structured and ridge-based detection, multiscale pyramids, and deep learning-based edge detection methods.

Chapter 9, Image Restoration: Inverse Problems in Imaging, provides a rigorous treatment of image restoration, including deconvolution, Wiener filtering, Tikhonov regularization, Bayesian formulations, CLEAN algorithms, sparse representations, and modern deep learning-based restoration and inpainting methods such as NAFNet, LaMa, and diffusion models.

Chapter 10, Image Segmentation: From Classical Methods to Deep Learning, explains segmentation techniques ranging from thresholding, watershed, superpixels, and variational methods to deep learning approaches, including FCNs, DeepLab, Mask R-CNN, YOLO-based segmentation, and transformer-based models such as SegFormer, Mask2Former, and DETR.

Chapter 11, More Deep Learning Methods for Image Segmentation, explores promptable and multimodal segmentation models such as SAM and CLIP-based methods, vision–language integration, monocular depth estimation, 3D reconstruction, medical and remote sensing segmentation, and evaluation metrics like IoU, Dice, and mAP.

Chapter 12, Image Classification and Object Detection, details image classification and detection using CNNs, transfer learning, Vision Transformers, few-shot and zero-shot learning, self-supervised learning, adversarial robustness, OCR pipelines, face recognition, and real-world applications including AR filters, deepfakes, and industrial inspection systems.

Chapter 13, Generative AI in Image Processing and Computer Vision, explores generative modeling from GANs and VAEs to diffusion models and large-scale foundation models, including Stable Diffusion, ControlNet, DALL·E, and GPT-based image systems, along with applications in image synthesis, editing, inpainting, restoration, multimodal reasoning, and domain-specific generation across science, medicine, and industry.

## To get the most out of this book

Readers should have a basic understanding of Python programming, foundational machine learning and deep learning concepts, and a basic understanding of large language models. Familiarity with computer vision workflows and AI model APIs is helpful. A basic background in linear algebra, calculus, and optimization will significantly aid understanding of the theoretical and mathematical sections. This book assumes readers have some experience with AI development environments and are comfortable working with APIs.

To run the examples, access to a Python environment is required. Most of the code in this book was developed and tested on Windows 11 x64 with Python 3.12+. For deep learning and generative AI experiments requiring acceleration, execution was primarily carried out on Google Colab (on T4 GPU) or a local setup using an NVIDIA GeForce RTX 3050 GPU (6 GB VRAM). A GPU with 8 GB of VRAM is recommended for the smooth running of many of the GenAI models.

A Kaggle account is useful for downloading datasets used across chapters, and a Hugging Face account/API token is recommended for accessing pretrained models and transformer-based pipelines. For generative AI chapters, an OpenAI API key with credits is required for DALL·E, GPT-image, and multimodal vision-language API examples.
