Here, the processor converts both image and text into aligned embeddings, the model predicts per-pixel logits, and sigmoid activation converts them into probability masks. After thresholding, a binary segmentation mask is obtained and blended with the original image for visualization.

# Depth estimation and 3D scene understanding from a single image

Human vision naturally infers depth, geometry, and spatial relationships from monocular observations. In computer vision, recovering three-dimensional structure from a single RGB image is a highly ill-posed inverse problem because multiple 3D scenes may project to the same 2D image. Recent transformer-based deep learning models have dramatically improved monocular depth estimation by learning geometric priors from massive datasets. Once dense depth is estimated, the image can be lifted into 3D space to generate point clouds, reconstruct scenes, and perform semantic 3D understanding. This section demonstrates a complete pipeline for monocular depth estimation, point cloud generation, multi-view fusion, and semantic 3D reconstruction using state-of-the-art transformer architectures.

# From image to depth: Monocular depth estimation

Monocular depth estimation predicts a dense depth map $D: \Omega \to \mathbb{R}^{+}$, where $\Omega \subset \mathbb{R}^{2}$ denotes the image domain and $D(x,y)$ represents the estimated distance from the camera to the pixel $(x,y)$. Unlike stereo vision or LiDAR, monocular depth estimation relies entirely on learned geometric cues such as perspective distortion, texture gradients, object scale priors, occlusions, shadows, semantic context, etc. Modern transformer-based models learn these relationships end-to-end.

# Dense Prediction Transformer

The demo uses the pretrained model `intel/dpt-large`, which is based on the Dense Prediction Transformer (DPT) architecture. DPT combines Vision Transformers (ViTs), multi-scale feature fusion, and dense prediction decoding. Unlike CNNs with limited receptive fields, transformer models model global image dependencies through self-attention.

For image tokens, $X = x_1, x_2, \ldots, x_N$, self-attention computes:

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^{T}}{\sqrt{d}}\right)V.$$

where $Q$ = query matrix, $K$ = key matrix, $V$ = value matrix and $d$ = embedding dimension. This enables the network to reason globally about scene geometry.

The model predicts a dense depth tensor:

$$\hat{D}=f_{\theta}(I),$$

where $I$ = RGB image, $f_{\theta}$ = transformer depth network and $\hat{D}$ = predicted depth map.
