Here are the key reasons why convolution is performed on an image and why it is essential in image processing:

+   - **Mathematical foundation:** Convolution mathematically combines the input image with the kernel in a way that extracts or suppresses certain features
+   - **Computational efficiency:** Most image processing algorithms, especially those in computer vision, heavily rely on convolution due to its simplicity and efficiency
+   - **Versatility:** Convolution is a universal operation that can be adapted for various tasks by simply changing the kernel, allowing for a wide range of effects and transformations on an image

It is widely used in image processing and deep learning for feature extraction and filtering. In this section, we shall use convolution to apply a general-purpose filter effect on an image. This is done to achieve various effects with appropriate kernels on an image, such as smoothing, sharpening, and embossing, and in operations such as edge detection. However, depending on whether the convolution is performed in the spatial or frequency domain, the computational efficiency can vary significantly.

# Spatial domain convolution

The core of a 2D spatial convolution involves sliding a **kernel** (or filter) over an image to compute a **weighted sum** of the pixel intensities around each location. Mathematically, for an image of size M × N and a **filter** (kernel) K of size k × k, the convolution at a pixel position is computed as follows:

O(x, y) = Σₘ Σₙ K(m, n) · I(x − m, y − n)

While straightforward, this method becomes computationally expensive for large images or large kernel sizes, as the number of operations grows quadratically with the kernel size.

**Time complexity (spatial domain):** The time complexity for spatial domain convolution is O(k²MN), where k is the kernel size, and M × N is the image size. For small kernel sizes (e.g., 3x3 or 5x5), this is manageable, but for large kernels, the cost becomes prohibitive.

# Frequency domain convolution

In the frequency domain, convolutions can be performed more efficiently using the **convolution theorem**, which states that convolution in the spatial domain is equivalent to element-wise multiplication in the frequency domain. The steps are as follows:

+   - Transform the image I and kernel K into the frequency domain using the **Fast Fourier Transform (FFT)**.
+   - Multiply the Fourier-transformed image and kernel elementwise.
+   - Inverse the FFT to convert the result back to the spatial domain.

Mathematically, if F denotes the Fourier transform, the convolution is computed as follows:

F(I * K) = F(I) · F(K)

The major advantage here is that the FFT can compute convolutions more efficiently, especially for large kernels, because the FFT reduces the time complexity of convolution from quadratic to near-linear.
