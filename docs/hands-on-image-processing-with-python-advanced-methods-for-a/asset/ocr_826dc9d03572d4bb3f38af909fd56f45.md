interpolated intensity is computed as a weighted average of neighboring pixels, with weights proportional to the relative distances from the target point.

For a target point $(x, y)$ surrounded by neighboring pixels $Q_{11}, Q_{12}, Q_{21}, Q_{22}$, the interpolated value is:

```
$f(x,y) = \frac{Q_{11}(x_2 - x)(y_2 - y) + Q_{21}(x - x_1)(y_2 - y) + Q_{12}(x_2 - x)(y - y_1) + Q_{22}(x - x_1)(y - y_1)}{(x_2 - x_1)(y_2 - y_1)}$
```

where $(x_1, y_1)$ and $(x_2, y_2)$ define the surrounding integer grid coordinates. The weights sum to one, ensuring intensity normalization. Bilinear interpolation produces smoother transitions than nearest-neighbor interpolation, although slight blurring may occur during large magnification.

# Bicubic interpolation

Bicubic interpolation extends cubic interpolation to two dimensions and generally produces smoother results than bilinear interpolation. Instead of four neighboring pixels, bicubic interpolation considers a $4 \times 4$ neighborhood (16 pixels) and estimates intensities using cubic polynomials. For 1D interpolation, the cubic polynomial is expressed as:

```
$p(x) = ax^3 + bx^2 + cx + d$
```

In 2D, bicubic interpolation applies cubic interpolation along both spatial directions:

```
$f(x, y) = \sum_{i=0}^{3} \sum_{j=0}^{3} a_{ij} x^i y^j$
```

where $a_{ij}$ are coefficients computed from the surrounding 16 pixels. Bicubic interpolation generates smoother and more visually natural images, particularly for large upsampling factors, although it is computationally more expensive and may introduce ringing artifacts near sharp edges.

# Note

In practice, bicubic interpolation can be implemented using various techniques for computing interpolation weights, including the following: **Lagrange polynomials**: Offer exact polynomial fits through data points. However, they can become numerically unstable for large intervals and are rarely used in high-performance applications.

+   - **Cubic splines**: Use *piecewise cubic polynomials* that guarantee the continuity of the function and its first and second derivatives. They are preferred when smooth transitions across pixel boundaries are critical.

+   - **Cubic convolution kernels**: Widely used in practice (e.g., in OpenCV and SciPy) due to their good trade-off between computational efficiency and visual quality. A common example is the *keys cubic convolution kernel*, used in `cv2.INTER_CUBIC`.

# Spline interpolation

Spline interpolation computes new pixel values using piecewise polynomial functions, producing smooth transitions across the image. Unlike nearest-neighbor or bilinear interpolation, splines preserve continuity in both slope and curvature, making them suitable for high-precision image reconstruction
