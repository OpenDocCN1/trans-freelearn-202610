# Downsampling with NumPy

The next code snippet demonstrates downsampling artifacts, where a 70 × 70 high-frequency region containing narrow vertical stripes is cropped from a shirt image of size 419 × 600. The selected crop region is displayed on the original image using cv2.rectangle(), which draws a red rectangle from the top-left to bottom-right crop coordinates. Here, constrained_layout=True automatically adjusts subplot spacing to prevent overlap (ensuring an optimal layout), while aspect='auto' allows Matplotlib to scale the image to fit the subplot dimensions.

The cropped high-frequency region is extracted using NumPy array slicing. Here, cropping is performed by indexing the image array as:

I_c(x, y) = I(x + x_0, y + y_0)

where (x_0, y_0) denotes the top-left crop coordinate. Because the selected region contains closely spaced vertical stripes (high-frequency content), downsampling can produce visible Moiré patterns (artifacts rising from aliasing) when the sampling frequency becomes insufficient to represent the high-frequency image content (violates the Nyquist criterion). This example illustrates why low-pass filtering is essential before reducing image resolution.

```
im = Image.open("images/shirt.jpg")
crop_coords = (0, 200, 70, 270)
plt.figure(figsize=(10,5), constrained_layout=True)
plt.subplot(121), plt.imshow(cv2.rectangle(np.array(im).copy(), \
    crop_coords[:2], crop_coords[-2:], (255,0,0), 2), aspect='auto') plt.
title(f'original image ({im.height} x {im.width})')
plt.subplot(122), plt.imshow(np.array(im)[crop_coords[1]:crop_coords[3], \
    crop_coords[0]:crop_coords[2]], aspect='auto')
```
