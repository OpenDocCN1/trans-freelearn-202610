First, download the CarDD (Car Damage Detection) dataset from Kaggle and extract it into the local dataset/directory, providing the vehicle images and corresponding damage annotations required for training and evaluating the YOLOv8 segmentation model.

```
!kaggle datasets download -d nasimetemadi/car-damage-detection
!unzip -q car-damage-detection.zip -d dataset
```

Import the Ultralytics YOLO framework and load the pretrained YOLOv8 Nano Segmentation (YOLOv8n-seg) model, which has been trained on the COCO dataset and serves as the starting point for transfer learning and fine-tuning on the vehicle damage segmentation task:

```
from ultralytics import YOLO
model = YOLO("yolov8n-seg.pt")
```

Compared to YOLOv5, YOLOv8 offers anchor-free detection, improved feature extraction, better accuracy–speed trade-offs, and stronger performance on small objects.

Dataset Preparation and Annotation Conversion: The CarDD dataset is provided in COCO format, whereas YOLOv8 segmentation requires annotations in YOLO polygon format. The most important part of the preprocessing pipeline converts COCO segmentation masks into normalized polygon coordinates, using the function convert_coco_to_yolo_seg(); refer to GitHub to find the complete code. The code needs to be run on Colab / GPU. For each annotation, the polygon vertices are extracted and normalized:

```
x, y = largest_seg[i] / w, largest_seg[i + 1] / h
```

This transforms pixel coordinates into normalized coordinates in the range ([0,1]), making the annotations resolution-independent. The converted labels are then written into YOLO segmentation files:

```
line = f"{cls_id} " + " ".join(map(str, points))
```

A dataset configuration file is subsequently generated.

```
with open("damage_seg.yaml", "w") as f:
    f.write(yaml_text)
```

The YAML file specifies training and validation image paths together with the damage categories used by YOLOv8.

Training the YOLOv8 Segmentation Model: The segmentation network is initialized using a pretrained YOLOv8 model (download from):

```
model = YOLO("yolov8n-seg.pt")
```

Train/fine-tune the pretrained YOLOv8 segmentation model on the CarDD dataset. Training may take several minutes to hours depending on the GPU and Colab workload; please be patient and wait for the training process to finish completely before continuing.

```
model.train(data="damage_seg.yaml", epochs=30, imgsz=640, batch=8)
```
