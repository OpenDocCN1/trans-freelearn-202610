## Edge detection with the LoG filter

The following describes the steps in edge detection with a LOG filter:

- First, the input image needs to be smoothed (by convolution with the Gaussian filter)
- Then, the smoothed image needs to be convolved with the Laplacian filter to obtain the output image as:

$$\nabla^2(I(x,y) * G(x,y))$$

- Finally, the zero-crossings from the image obtained in the last step need to be computed, as shown in the following figure:

## Edge detection with Marr-Hildreth zero-crossing

Computing the zero-crossings in the LoG-convolved image (to detect edges as a binary image) was proposed by Marr and Hildreth. Identification of the edge pixels can be done by viewing the sign of the LoG-smoothed image by defining it as a binary image. The algorithm to compute the zero-crossing is as follows:

- 1. First, convert the LoG-convolved image to a binary image by replacing the pixel values with 1 for positive values and 0 for negative values.
- 2. In order to compute the zero-crossing pixels, we need to simply look at the boundaries of the non-zero regions in this binary image.
- 3. Boundaries can be found by finding any non-zero pixel that has an immediate neighbor that is zero.

4. Hence, for each pixel, if it is non-zero, consider its eight neighbors; if any of the neighboring pixels is zero, the pixel can be identified as an edge. The implementation of this function is left as an exercise. The following code block detects the edges of the same zebra image with zero-crossings

```
def any_neighbor_opposite_sign(img, i, j):
    '''Check if any neighbor has opposite sign'''
    current = img[i, j]
    for k in range(-1, 2):
        for l in range(-1, 2):
            if k == 0 and l == 0:
                continue  # skip center pixel
            neighbor = img[i + k, j + l]
            if current * neighbor < 0:  # sign change
                return True
    return False

def zero_crossing(img):
    '''Detect zero-crossings in Laplacian-filtered image'''
    out_img = np.zeros_like(img, dtype=np.uint8)
    for i in range(1, img.shape[0] - 1):
        for j in range(1, img.shape[1] - 1):
            if any_neighbor_opposite_sign(img, i, j):
                out_img[i, j] = 255
    return out_img

## Scale-space blob detection with LoG, DoG, and DoH (scikit-image)

In image processing, space refers to the 2D domain of image coordinates, typically representing pixel intensities. Scale, on the other hand, refers to the level of detail at which an image is analyzed. At fine scales (small values of σ, the standard deviation of a Gaussian filter), image features like small edges and textures are preserved. At coarse scales (larger σ), fine details are suppressed, and only larger structures are retained. This multi-scale representation of an image is referred to as the scale-space.

## Why use scale space?

Objects in real-world scenes can appear at various sizes depending on distance, perspective, or zoom level. Traditional feature detectors operating at a single scale may fail to identify objects that do not match the assumed size. Scale-space theory solves this by analyzing the image across multiple scales, ensuring that features of all sizes can be detected. One of the key applications of scale-space is blob detection, where we aim to identify regions in the image that differ in properties (e.g., intensity/brightness or texture) compared to surrounding areas. These blobs can vary in size, making a multi-scale approach essential. The filters used, LoG, DoG, and Determinant of Hessian (DoH), are grounded in multiscale analysis and differential geometry.

scikit-image provides these three main blob detection functions based on different scale-space techniques:

- blob_log(): The LoG filter enhances circular blob-like regions by applying a second-order derivative (Laplacian) after Gaussian smoothing. It provides accurate results but is computationally expensive.
- blob_dog(): The DoG, a fast approximation of LoG, implemented by subtracting two images blurred with different Gaussian kernels. It's less precise but much faster and more effective for most practical cases (used in SIFT).
- blob_doh(): The DoH is better for detecting corner-like blobs. This method uses the Hessian matrix of second-order partial derivatives to detect blob-like structures, especially useful in detecting corner-shaped blobs.

The following code compares all three methods:

```
from skimage.feature import blob_dog, blob_log, blob_doh
image = plt.imread('images/sunflowers.jpg')
image_gray = 1-rgb2gray(image) # detect white blobs
blobs_log = blob_log(image_gray, max_sigma=30, min_sigma=5, \
                    num_sigma=7, threshold=0.175)
# Compute radii in the 3rd column.
blobs_log[:, 2] = blobs_log[:, 2] * np.sqrt(2)
blobs_dog = blob_dog(image_gray, max_sigma=30, min_sigma=5, threshold=0.1)
blobs_dog[:, 2] = blobs_dog[:, 2] * np.sqrt(2)
blobs_doh = blob_doh(image_gray, max_sigma=30, min_sigma=5, threshold=0.01)
blobs_list = [blobs_log, blobs_dog, blobs_doh]
colors = ['blue', 'magenta', 'red']
titles = ['Laplacian of Gaussian', 'Difference of Gaussian', \
          'Determinant of Hessian']
sequence = zip(blobs_list, colors, titles)
fig, axes = plt.subplots(1, 3, figsize=(10, 3), sharex=True, sharey=True)
ax = axes.ravel()
for idx, (blobs, color, title) in enumerate(sequence):
    ax[idx].set_title(title)
    ax[idx].imshow(image)
    for blob in blobs:
        y, x, r = blob
        c = plt.Circle((x, y), r, color=color, linewidth=2, fill=False)
        ax[idx].add_patch(c)
    ax[idx].set_axis_off()
