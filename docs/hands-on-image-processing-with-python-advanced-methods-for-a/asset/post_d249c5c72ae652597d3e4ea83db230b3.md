
where Γ is the search range. We can solve this optimization problem using `scipy.optimize.minimize_scalar`, minimizing the negative entropy.

The following Python code demonstrates the entire pipeline on a grayscale image using OpenCV, scikit-image, and SciPy. Here are the steps:

- **Image normalization:** Required for applying gamma transformation in the [0, 1] range
- **Entropy function:** Histogram-based global entropy computation
- **Gamma optimization:** A scalar function optimization is performed in a bounded interval (0.1 to 5.0)
- **Visualization:**
  - The original and enhanced images are displayed
  - The local entropy map is computed using a 2D sliding window (via `skimage.filters.rank.entropy`) to illustrate spatial contrast variations

Now, refer to the next code snippet:

```python
from skimage.filters.rank import entropy
from skimage.morphology import disk
from scipy.optimize import minimize_scalar

# Load and resize grayscale image
img = cv2.imread('images/moon.jpg', cv2.IMREAD_GRAYSCALE)
img = cv2.resize(img, (256, 256)) # standard size for visualization
# Normalize image to [0, 1]
img_norm = img / 255.0

# Define entropy computation
def compute_entropy(image):
    hist, _ = np.histogram(image, bins=256, range=(0, 1), density=True)
    hist += 1e-12 # to avoid log(0)
    return -np.sum(hist * np.log2(hist))

# Define gamma enhancement
def enhance_with_gamma(image, gamma):
    return np.power(np.clip(image, 0, 1), gamma)

# Objective function for optimization
def objective(gamma):
    enhanced = enhance_with_gamma(img_norm, gamma)
    return -compute_entropy(enhanced) # minimize negative entropy

# Find optimal gamma
res = minimize_scalar(objective, bounds=(0.1, 0.75), method='bounded')
optimal_gamma = res.x
enhanced_img = enhance_with_gamma(img_norm, optimal_gamma)
# Convert to 8-bit image
img_out = (enhanced_img * 255).astype(np.uint8)
entropy_map = entropy(img_out, disk(5))
# Visualization: plot img, img_out and entropy_map here
```

### Compass edge detector

While classical edge detectors like Sobel and Prewitt estimate intensity changes along horizontal and vertical directions, Compass Edge Detectors exploit multiple orientations to detect edges more effectively in a directionally adaptive manner.

One such compass operator is the Kirsch operator, which computes the edge magnitude in eight compass directions (N, NE, E, SE, S, SW, W, NW), highlighting the maximum directional response at each pixel. This chapter dives into the theory, mathematics, and Python implementation of the Kirsch Compass Edge Detector.

- `kirsch_edge_detection()`:
  - Converts the image to grayscale
  - Applies each of the Kirsch kernels to the image using OpenCV’s `filter2D`
  - Stacks the eight resulting filtered images into a 3D NumPy array
  - Uses `np.max(..., axis=0)` to retain the maximum response at each pixel across directions
- **Final output:** An edge map highlighting edges in all directions using the strongest directional response

Now, refer to the next code snippet:

```python
def kirsch_kernels():
    g = [
        np.array([[5, 5, 5], [-3, 0, -3], [-3, -3, -3]]),  # North
        np.array([[-3, 5, 5], [-3, 0, 5], [-3, -3, -3]]),   # NE
        np.array([[-3, -3, 5], [-3, 0, 5], [-3, -3, 5]]),   # East
        np.array([[-3, -3, 5], [-3, 0, 5], [-3, 5, 5]]),    # SE
        np.array([[-3, -3, -3], [-3, 0, -3], [5, 5, 5]]),    # South
        np.array([[-3, -3, -3], [5, 0, -3], [5, 5, -3]]),    # SW
        np.array([[5, -3, -3], [5, 0, -3], [5, -3, -3]]),    # West
        np.array([[5, 5, -3], [5, 0, -3], [-3, -3, -3]])     # NW
    ]
    return g

def kirsch_edge_detection(image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    kernels = kirsch_kernels()
    edge_maps = [cv2.filter2D(gray, -1, k) for k in kernels]
    kirsch_response = np.max(np.stack(edge_maps), axis=0)
    return kirsch_response

# Load image
image = cv2.imread("images/goldengate.jpg")
image = cv2.resize(image, (400, 400))
# Detect edges
kirsch_edges = kirsch_edge_detection(image)
# Display image and kirsch_edges here
```

### Interactive percentile gradient-based edge detection

While traditional methods such as Sobel, Prewitt, or Canny detect abrupt changes in intensity, rank-based filters, particularly percentile-based gradient filters, offer robust alternatives for noise-resilient edge detection. This section introduces percentile-based gradient computation using the `skimage.filters.rank.gradient_percentile` function and provides a fully interactive demo powered by Gradio.

Conventional gradient filters compute differences using fixed kernels, which may be sensitive to noise and intensity variation. Rank-based filters mitigate this by working with **rank statistics** (like medians and percentiles) within a local neighborhood. This makes them more robust to:

- Illumination changes
- Outliers and noise
- Blurred edges

#### Local percentile gradient

Let $I(x,y)$ be the grayscale image, and $N(x,y)$ denote the neighborhood around the pixel $(x,y)$. Define:

- $p_0$: lower percentile (e.g., 10%)
- $p_1$: upper percentile (e.g., 90%)

Then the **percentile gradient** magnitude at the pixel $(x,y)$ is:

$$G(x,y)=I_{p_1}(x,y)-I_{p_0}(x,y)$$
