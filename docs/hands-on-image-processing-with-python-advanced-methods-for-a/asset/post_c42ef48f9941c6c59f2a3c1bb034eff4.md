## Guided image restoration with InstructIR

Classical and deep learning–based image restoration methods rely on explicit priors or end-to-end learned models trained for specific degradations such as denoising, deblurring, deraining, or super-resolution. However, real-world degradations are diverse, overlapping, and often subjective in how they should be removed. For instance, what one user considers “restoration” (e.g., removing raindrops) another may consider “editing” (e.g., making the photo look cinematic).

**Instruction-based image restoration (InstructIR)** addresses this gap by introducing guided restoration via natural language prompts. Instead of requiring precise degradation models or blind priors, users can *describe in text* what they want, e.g., “remove the raindrops but preserve the background”, and the model learns to align visual restoration with these instructions. This represents a paradigm shift: image restoration as a multi-modal conditional generation problem, where both image and text guide the output.

As discussed, in standard image restoration, i.e., classically, we model degradation as:

$$y = Hx + n$$

In most restoration methods, the goal is to estimate $x$ given $y$. In InstructIR, the problem is reformulated as conditional inference:

$$\hat{x} = f_{\theta}(y,t)$$

where $y$ = degraded image, $t$ = textual instruction embedding (derived from prompt), $f_\theta$ = restoration model with parameters $\theta$, $\hat{x}$ = restored image. Thus, restoration is not only conditioned on the image but also on user intent through natural language.

For language-vision alignment, the system uses the following components:

- **Language encoder:** A pretrained language model $g_\phi$ encodes the instruction prompt into an embedding $z_t = g_\phi(t)$, where $z_t \in \mathbb{R}^d$.
- **Instruction head:** A linear/nonlinear projection $h_\psi$ maps the language embedding into a space aligned with degradations:
  
  $$e_t, d_t = h_\psi(z_t)$$
  
  where $e_t$ is the instruction embedding and $d_t$ the predicted degradation type.
- **Restoration network:** The core image restoration backbone $f_\theta$ (a NAFNet-like U-Net with attention) receives both the degraded image and text embedding:
  
  $$\hat{x} = f_\theta(y, e_t)$$

InstructIR optimizes a joint objective:

$$\mathcal{L} = \lambda_{rec} \cdot \|x - \hat{x}\|_1 + \lambda_{per} \cdot \mathcal{L}_{perceptual}(\hat{x}, x) + \lambda_{deg} \cdot \mathcal{L}_{cls}(d_t, d^*)$$

where $\|x - \hat{x}\|_1$ ensures pixel fidelity, $\mathcal{L}_{perceptual}$ improves perceptual quality and $\mathcal{L}_{cls}$ ensures degradation prediction matches ground-truth type. This design allows the model to balance fidelity, perception, and instruction adherence.

- Unlike blind restoration, it uses semantic cues from instructions.
- Beyond denoising or deraining, it enables restoration + retouching + editing in a single framework.

The following table provides a comparison between the classical prior and deep learning prior-based image restoration methods:

| Aspect | Classical priors (Tikhonov, TV, Sparse) | Deep restoration (NAFNet) | Instruction-based (InstructIR) |
|---|---|---|---|
| Formulation | Optimization + hand-crafted prior | Learned mapping $y \rightarrow x$ | Learned mapping with text $(y,t) \rightarrow x$ |
| Flexibility | Low (fixed prior) | Medium (task-specific) | High (instruction-guided) |
| User control | Indirect (tuning λ, priors) | None (fixed mapping) | Direct via natural language |
| Generalization | Limited to modeled degradations | Good if seen in training | Strong (handles unseen degradations via prompts) |
| Data need | Low | High | Very high (multi-modal) |
| Interpretability | High | Medium | Lower (black-box, prompt-driven) |
| Typical output | Conservative, smooth restoration | Benchmark-level clean images | Restoration + enhancement |

Classical priors are useful for interpretable, principled restoration but struggle with realism. NAFNet and similar networks dominate benchmarks for well-defined degradations. InstructIR represents a new paradigm, shifting from *task-specific* restoration to user-guided, multi-purpose restoration, bridging restoration and interactive image editing.

## Stable Diffusion-based inpainting with DeepFill

This section explains how modern diffusion models (Stable Diffusion) are used for image inpainting, contrasts them with older CNN inpainting (e.g., DeepFill), and walks through the supplied demo code line-by-line. You’ll get the math behind diffusion, how conditional inpainting works, what the pipeline is doing under the hood, and practical tips for quality, speed, and artifacts.

**DeepFill (classic CNN inpainting)** (e.g., Yu *et al.*, 2018/2019) used encoder–decoder networks with contextual attention or partial convolutions to synthesize missing pixels from the surrounding context. These methods are fast and work well for many structured holes, but can struggle with highly unconstrained content or global semantics.

**Diffusion-based inpainting (Stable Diffusion)** treats inpainting as conditional generative sampling: the model is trained to denoise a noisy image (or latent) conditioned on a prompt and a masked image, allowing it to synthesize high-quality, semantically plausible content that matches text guidance and global scene cues. Diffusion methods often produce more photorealistic, globally consistent results at the cost of heavier compute.
