# Few-shot face recognition with deep face embeddings (Siamese network)

Face recognition can be formulated as a metric-learning problem in which images are mapped into an embedding space such that faces of the same person lie close together while different identities lie far apart. Unlike conventional classification, new identities can be added simply by storing their embeddings without retraining the model, as demonstrated by an example here (for complete code refer to GitHub).

# Note

Face recognition is one of the most successful applications of Siamese Network learning. Classical Siamese Networks (such as FaceNet) train two identical encoders jointly using contrastive or triplet losses to learn a similarity-preserving embedding space. In contrast, the example here uses a pretrained ResNet18 encoder that was not trained in a Siamese fashion; however, recognition is still performed by comparing embeddings with a similarity metric, following the same fundamental principle underlying Siamese-network-based face recognition.

FaceEncoder uses a pretrained ResNet18 backbone (rather than a classically Siamese-trained network) to extract facial features and converts them into normalized 128-dimensional embeddings, while the forward() method generates these embeddings for similarity-based face recognition.

```
# Improving recognition with Siamese fine-tuning

The current implementation relies on generic ImageNet features extracted by a pretrained ResNet18. Recognition performance can often be improved by fine-tuning the encoder using contrastive loss, triplet loss, or modern face-recognition objectives such as ArcFace. For example, the contrastive loss is given by:

L = y D² + (1 − y) max(0, m − D)²

where D denotes the embedding distance and m is a margin. Such metric-learning approaches pull matching faces closer together while pushing different identities farther apart, producing substantially more discriminative embeddings.

# Face recognition with FaceNet

In practice, specialized face-recognition models such as FaceNet are preferred over generic image classifiers. FaceNet is trained directly on face images using triplet loss and learns a highly discriminative embedding space in which Euclidean or cosine distance corresponds to facial similarity.

```
from facenet_pytorch import InceptionResnetV1
model = InceptionResnetV1(pretrained='vggface2').eval()  # Pretrained FaceNet
embedding = model(face_tensor)
```

The function get_embedding() preprocesses a face image, passes it through the pretrained face encoder in inference mode (torch.no_grad()), and returns a normalized embedding vector representing that face. The gallery embeddings are then compared with the query embedding using cosine similarity, and the identity with the highest similarity score is selected as the predicted match.

```
def get_embedding(path):
    img = transform(Image.open(path).convert("RGB")).unsqueeze(0)
    with torch.no_grad():
        emb = model(img)
    return F.normalize(emb, dim=1)

gallery = {  # face images
    "Dad": get_embedding("images/dad.jpg"),
    "Me": get_embedding("images/me.jpg"),
    "Mom": get_embedding("images/mom.jpg")}
query = get_embedding("images/query.png")

scores = { name: F.cosine_similarity(query, emb).item()
           for name, emb in gallery.items()}
prediction = max(scores, key=scores.get)
```

Unlike the few-shot ResNet18 example, FaceNet is already optimized for face recognition and therefore typically achieves significantly higher accuracy without additional training, while also producing much more discriminative similarity scores with better separation between matching and non-matching faces, as can be seen from the following figure.

# Bayesian neural networks for image classification

Conventional neural networks learn a single deterministic value for each weight. In contrast, a Bayesian Neural Network (BNN) models each weight as a probability distribution, allowing the network to estimate not only a prediction but also its uncertainty. This is particularly important in safety-critical applications such as medical imaging, autonomous driving, and remote sensing, where knowing *how confident* a prediction is can be as important as the prediction itself. Intuitively, instead of asking “What is the best weight?”, a Bayesian network asks “What range of weights are plausible given the data?”

**Bayesian Neural Networks:** In a deterministic network, weights are fixed: $W = w$ whereas in a Bayesian network each weight is represented by a distribution:

$$W \sim \mathcal{N}(\mu, \sigma^2)$$

where $\mu$ and $\sigma$ are learned during training. The predictive distribution is obtained by marginalizing over all possible weights:

$$p(y|x, D) = \int p(y|x, W),\,p(W|D),\,dW$$

where $D$ denotes the training data. Since this integral is intractable for deep networks, approximate methods such as **Variational Inference**, **Monte Carlo Sampling**, and **MC Dropout** are commonly used.

**Bayesian Linear Layer:** The key idea is to replace *deterministic weights* with *Gaussian-distributed weights*.

```
```python
class BayesianLinear(nn.Module):
    def forward(self, x):
        weight_std = torch.exp(0.5 * self.weight_logvar)
        weight = self.weight_mu + weight_std * torch.randn_like(weight_std)
        return F.linear(x, weight, bias)
```
```

During every *forward* pass, a *new weight* sample is drawn from the learned distribution. Consequently, two evaluations of the same image may produce slightly different predictions. Instead of committing to a single model, the network effectively evaluates many plausible models and combines their predictions.

**Variational Learning and KL Regularization:** Training optimizes both classification accuracy and uncertainty estimation. The loss combines cross-entropy and a KL-divergence penalty:

$$L = L_{CE} + \beta D_{KL}(q(W)\|p(W)),$$

where $L_{CE}$: classification loss, $q(W)$: learned posterior, $p(W)$: prior distribution, and $D_{KL}$: complexity penalty. In the implementation:
```
