# Image denoising with LPF

Image denoising is a fundamental task in image processing and computer vision, aiming to recover clean images from their noisy counterparts. Noise can degrade an image due to factors such as sensor errors, low-light conditions, or transmission errors. The goal of denoising is to reconstruct the original signal, making it useful for downstream tasks such as object detection, medical imaging, or image enhancement.

The next example demonstrates how to denoise a noisy *moonlanding* image, first by blocking the Fourier high-frequency components using an LPF with FFT.

```
```python
im = plt.imread('images/moonlanding.png').astype(float)
im_fft = fp.fft2(im)
```
```

**Filtering in the frequency domain:** The next code block shows how to reject a set of high frequencies and implement an LPF to attenuate noise (which corresponds to high-frequency components) from an image.

```
```python
# Copy the original spectrum and truncate coefficients.
# Define the fraction of coefficients (in each direction)
keep_fraction = 0.1
im_fft_filtered = im_fft.copy()
# Set r and c to the number of rows and columns of the array.
r, c = im_fft2.shape
# Set rows with indices between
# r*keep_fraction and r*(1-keep_fraction) to 0
im_fft_filtered[int(r*keep_fraction):int(r*(1-keep_fraction))]=0
# Similarly with the columns
im_fft_filtered[:, \
                int(c*keep_fraction):int(c*(1-keep_fraction))]=0
```
```

**Reconstructing the final image:** The next code snippet shows how to reconstruct the image with IFFT from the filtered Fourier coefficients.

```
```python
# Reconstruct image from filtered spectrum,
# keep only real part for display.
im_denoised = fp.ifft2(im_fft_filtered).real
# plot im, im_denoised and the spectrums im_fft, im_fft_filtered
