# Few-shot face recognition with deep face embeddings (Siamese network)

Face recognition can be formulated as a metric-learning problem in which images are mapped into an embedding space such that faces of the same person lie close together while different identities lie far apart. Unlike conventional classification, new identities can be added simply by storing their embeddings without retraining the model, as demonstrated by an example here (for complete code refer to GitHub).

# Note

Face recognition is one of the most successful applications of Siamese Network learning. Classical Siamese Networks (such as FaceNet) train two identical encoders jointly using contrastive or triplet losses to learn a similarity-preserving embedding space. In contrast, the example here uses a pretrained ResNet18 encoder that was not trained in a Siamese fashion; however, recognition is still performed by comparing embeddings with a similarity metric, following the same fundamental principle underlying Siamese-network-based face recognition.

FaceEncoder uses a pretrained ResNet18 backbone (rather than a classically Siamese-trained network) to extract facial features and converts them into normalized 128-dimensional embeddings, while the forward() method generates these embeddings for similarity-based face recognition.
