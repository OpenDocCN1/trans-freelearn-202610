# Image classification with Swin Transformer

A limitation of standard Vision Transformers is that global attention becomes computationally expensive for large images. Swin Transformers address this issue by restricting attention to local windows while gradually exchanging information between neighboring windows. One may think of Swin Transformers as combining the locality of CNNs with the flexibility of Transformer attention. Instead of global attention complexity, Swin Transformers achieve approximately linear complexity, through hierarchical window-based attention.

The following code snippet uses a pretrained Swin Transformer to first classify a parrot image and then to predict the most likely object class. To explain the prediction, gradients of the predicted class score are backpropagated to the input image, producing a saliency map that highlights pixels most influential to the decision; the resulting heatmap is then overlaid on the original image for visualization, as demonstrated using the next code snippet:

```
model = SwinForImageClassification.from_pretrained(
    "microsoft/swin-base-patch4-window7-224")
outputs = model(**inputs)    # Forward pass
```
