**Principal Component Analysis:** A common dimensionality reduction approach is Principal Component Analysis (PCA), which seeks orthogonal directions of maximum variance. Given centered observations $X = [x_1, x_2, ..., x_n]^T$, PCA computes the covariance matrix $C = \frac{1}{n} X^T X$ and finds eigenvectors $C v_i = \lambda_i v_i$. The leading eigenvectors define the projection directions that preserve maximum variance. Although PCA is computationally efficient, it is a linear transformation and often fails to preserve nonlinear structures present in image datasets.

**t-Distributed Stochastic Neighbor Embedding (t-SNE):** t-SNE, introduced by van der Maaten and Hinton (2008), is a nonlinear dimensionality reduction technique designed specifically for visualization. For each pair of samples $x_i$ and $x_j$, a probability distribution is defined in the original space:

$p_{j|i} = \frac{\exp\left(-\frac{|x_i - x_j|^2}{2\sigma_i^2}\right)}{\sum_{k \neq i} \exp\left(-\frac{|x_i - x_k|^2}{2\sigma_i^2}\right)}$

The low-dimensional embedding points $y_i$ define another probability distribution:

$q_{ij} = \frac{(1 + |y_i - y_j|^2)^{-1}}{\sum_{k \neq l} (1 + |y_k - y_l|^2)^{-1}}$

using a Student's t-distribution.

The optimal embedding minimizes the Kullback-Leibler divergence:

$KL(P||Q) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$

through gradient descent. Unlike PCA, t-SNE focuses on preserving local neighborhood relationships rather than global variance.
