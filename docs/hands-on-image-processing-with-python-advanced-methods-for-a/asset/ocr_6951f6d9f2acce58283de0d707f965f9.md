# Applying convolution in the frequency domain

In this section, we will see more applications of convolution with images using Python modules such as scipy.signal and scipy.ndimage. Let’s start with the famous convolution theorem and see how the convolution operation becomes easier and computationally more efficient in the frequency domain using the theorem.

# The convolution theorem

The convolution theorem says that convolution in an image spatial domain is equivalent to a simple multiplication in the frequency domain and vice versa:
