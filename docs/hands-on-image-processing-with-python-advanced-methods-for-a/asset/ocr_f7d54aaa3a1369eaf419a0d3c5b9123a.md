The PCA projection typically exhibits substantial overlap between digit classes because linear projections cannot effectively separate complex manifolds. The t-SNE embedding, however, reveals distinct clusters corresponding to the digits 0–9. This experiment illustrates an important principle in modern computer vision: images belonging to the same semantic category often lie on low-dimensional manifolds embedded within a much higher-dimensional space.

# Visualizing deep features from VGG16

The previous example applied t-SNE directly to raw image pixels. Modern deep learning systems rarely operate in pixel space. Instead, images are transformed into discriminative feature embeddings learned by convolutional neural networks. To demonstrate this concept, we use a pretrained VGG16 network and visualize features extracted from the Animal-10 dataset.

**Feature Extraction with VGG16:** The pretrained VGG16 network contains several fully connected layers near its output. The penultimate layer, denoted FC2, produces a 4096-dimensional feature vector:

f = f_VGG16(x) ∈ ℝ⁴⁰⁹⁶

which captures semantic image content. Rather than using the final classification output, these feature vectors are extracted and used as image descriptors. The feature extractor is created as follows:

```
model = VGG16(weights='imagenet')
feat_extractor = Model(inputs=model.input,
    outputs=model.get_layer("fc2").output)
Each image is resized and forwarded through the network.
feat = feat_extractor.predict(x).ravel()
features.append(feat)
```
