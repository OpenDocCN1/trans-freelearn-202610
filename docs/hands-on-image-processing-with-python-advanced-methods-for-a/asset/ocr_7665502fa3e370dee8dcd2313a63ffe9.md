# Bayesian interpretation of Wiener filtering and Tikhonov regularization

Image restoration can also be framed in a Bayesian inference setting, where the goal is to recover the most probable clean image f given the degraded observation g. We assume the degradation model:

```
g = Hf + η
```

with additive Gaussian noise η ~ N(0, σ²I). Thus, the likelihood is:

```
p(g | f) ∝ exp( - 1/(2σ²) || Hf - g ||² )
```

Priors and estimation strategies include the following:

+   - **Wiener filtering:** Bayesian MMSE (expectation) estimation
+     - Assumes both signal f and noise are Gaussian with known covariances.
+     - The **MMSE** estimator is:
+       
+       \hat{f}_{Wiener} = E[f | g]
+     
+     - Leads to the classical Wiener filter solution in the frequency domain.
+     - Interpretation: finds the *expected image* given the noisy observation, optimal under Gaussian assumptions.
+   - **Tikhonov regularization:** Bayesian MAP estimation
+     - Assumes a Gaussian prior on the image:
+       
+       p(f) ∝ exp( - λ/2 || Lf ||² )
