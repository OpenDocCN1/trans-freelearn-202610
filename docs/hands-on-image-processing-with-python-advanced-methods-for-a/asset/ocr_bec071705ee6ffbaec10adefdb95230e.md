**CVAE Loss Function:** The CVAE objective combines reconstruction accuracy with latent-space regularization. The reconstruction term ensures faithful data generation, while the KL-divergence regularizes the latent space to follow a smooth prior distribution, enabling meaningful interpolation and sampling in the CVAE framework.

```
def cvae_loss(recon, x, mu, logvar):
    recon_loss = F.binary_cross_entropy(recon, x, reduction="sum")
    kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + BETA * kl
```

The complete loss is:

$$L = L_{\text{recon}} + \beta L_{\text{KL}},$$

where $L_{\text{recon}} = -\sum_i x_i \log \hat{x}_i + (1 - x_i)\log(1 - \hat{x}_i)$ and $L_{\text{KL}} = D_{KL}(q_\phi(z|x,y) \| \mathcal{N}(0,I))$.

The hyperparameter $\beta$ controls the trade-off between reconstruction fidelity and latent-space smoothness.

**Adversarial-Free Training:** Unlike GANs, CVAEs require only a single network and do not involve a discriminator. This contrasts with the adversarial training paradigm used in cGANs, where a generator and discriminator compete, highlighting CVAEs as a more stable but typically less sharp alternative within the broader family of conditional generative models. Training therefore consists of a standard forward and backward pass:

```
recon, mu, logvar = model(x, labels)
loss, recon_loss, kl = cvae_loss(recon, x, mu, logvar)
loss.backward()
optimizer.step()
```

This makes CVAEs considerably easier and more stable to train than GANs, although the generated images are often slightly blurrier.

**Class-Conditional Image Generation:** After training, images can be generated by sampling a latent vector and specifying a class label.

```
z = torch.randn(1, LATENT_DIM)
for cls in range(10):
    label = torch.tensor([cls]) # same_z_different_labels
    img = model.decode(z, label)
```
