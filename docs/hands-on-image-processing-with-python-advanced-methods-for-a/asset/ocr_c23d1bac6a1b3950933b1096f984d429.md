# Wiener filtering — a statistical solution

The Wiener filter introduces statistical estimation by treating restoration as a minimum mean square error (MMSE) estimation problem:

```
F̂(u, v) = argmin_F E[ |F(u, v) − F̂(u, v)|² ]
```

The closed-form solution for the Wiener filter in the frequency domain is:

```
F̂(u, v) = H*(u, v) / (|H(u, v)|² + S_η(u, v)/S_f(u, v)) G(u, v)
```

where H*(u, v) = complex conjugate of H(u, v), S_η(u, v) = power spectral density (PSD) of noise and S_f(u, v) = PSD of the original image. The term S_η(u, v)/S_f(u, v) is the inverse signal-to-noise ratio (SNR). We need to bear in mind:

+   - When noise is low, S_η ≪ S_f, the filter behaves like an inverse filter.
+   - When noise is high, it suppresses noisy frequencies.

Thus, Wiener provides a bias-variance tradeoff between detail preservation and noise suppression. However, in real-world scenarios, the terms S_η(u, v) and S_f(u, v) are not known in advance:

+   - Noise PSD S_η(u, v): Requires knowledge of the statistical distribution of sensor or channel noise, which is rarely available.
+   - Image PSD S_f(u, v): Depends on the content of the original image (textures, edges, etc.), which we do not have access to.

Thus, directly applying the above equation is not feasible for most practical image restoration problems.

# Unsupervised Wiener filtering

The unsupervised Wiener filter addresses this by estimating both S_η(u, v) and S_f(u, v) from the observed degraded image itself. The key idea is that, under the degradation model G(u, v) = H(u, v)F(u, v) + N(u, v), we can exploit statistical assumptions about the noise and the structure of the signal to approximate the unknown power spectra. Let's estimate the PSDs. The observed power spectrum is:

```
S_g(u, v) = E[|G(u, v)|²] = |H(u, v)|² S_f(u, v) + S_η(u, v).
```

This provides a direct relationship between the observed degraded image spectrum and the unknown PSDs.

Noise estimation: If the noise is assumed to be white Gaussian noise, then S_η(u, v) can be approximated as a constant across frequencies:

```
S_η(u, v) ≈ σ_η²
```
