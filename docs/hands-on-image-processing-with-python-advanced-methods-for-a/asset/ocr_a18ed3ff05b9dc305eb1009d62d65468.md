# Translation of an image

A translation moves every pixel in the image by a constant displacement in both the x and y directions. Mathematically, the translation can be expressed using a transformation matrix.

# Transformation matrix for translation

The translation operation is represented by a simple 3x3 transformation matrix:

```
$$T = \begin{bmatrix}1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1\end{bmatrix}$$
```

Here, $t_x$ is the horizontal translation (shift along the $x$ axis), and $t_y$ is the vertical translation (shift along the $y$ axis).

For a point, $p = (x, y)$, in the original image, its new position, $p' = (x', y')$, after translation is given by the following:

```
$$\begin{bmatrix}x'\\y'\\1\end{bmatrix}=\begin{bmatrix}1 & 0 & t_x\\0 & 1 & t_y\\0 & 0 & 1\end{bmatrix}\begin{bmatrix}x\\y\\1\end{bmatrix}$$
```

This simplifies to $x' = x + t_x$, $y' = y + t_y$.

So, each pixel at $(x, y)$ in the original image moves to $(x + t_x,\ y + t_y)$ in the translated image.

# Inverse transformation

The warp() function uses inverse transformation to compute the original coordinates of each pixel in the output image. It works by mapping every output pixel back to a location in the input image, ensuring there are no gaps or overlaps—a process known as inverse mapping or backward warping. This approach is essential for geometric transformations such as translation, rotation, scaling, and more, allowing accurate reconstruction without missing data.

Specifically, the inverse mapping ensures that, for each output pixel $(x, y)$, the function computes the corresponding input pixel $(x', y') = (x - t_x,\ y - t_y)$ using the inverse of the applied transformation matrix.

If a forward mapping (direct transform) were used instead, output pixels might not be filled properly (causing holes) and multiple input pixels could map to the same output pixel (causing overlaps), necessitating complex interpolation and resampling. In contrast, inverse mapping ensures every output pixel is assigned a value by sampling the correct location in the input image, often with interpolation (e.g., bilinear or bicubic) to handle non-integer mappings.
