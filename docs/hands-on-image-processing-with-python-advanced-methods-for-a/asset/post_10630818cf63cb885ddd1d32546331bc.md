### Visualizing high-dimensional image features with t-SNE

Before training image classifiers or object detectors, it is often useful to understand how images are represented in feature space. Deep neural networks transform an image into a high-dimensional embedding vector whose geometry encodes semantic information. Images belonging to similar categories tend to cluster together, whereas unrelated images occupy distant regions of the feature space.

Unfortunately, these feature vectors may contain hundreds or thousands of dimensions and cannot be visualized directly. Dimensionality reduction techniques such as Principal Component Analysis (PCA) and t-Distributed Stochastic Neighbor Embedding (t-SNE) provide a mechanism for projecting high-dimensional representations into two-dimensional space while preserving important structural relationships and visualizing them in 2-D (or 3-D). Visualization helps build intuition about how neural networks organize and separate visual concepts in feature space, making learned representations easier to interpret and analyze.

This section demonstrates how t-SNE can be used to visualize both raw image representations and deep features extracted from pretrained convolutional neural networks.

### MNIST embeddings with t-SNE

The MNIST dataset consists of 70,000 grayscale handwritten digit images of size 28 × 28. Each image may be viewed as a vector in a 784-dimensional space x ∈ ℝ⁷⁸⁴. Although humans can easily distinguish digits, the distribution of handwritten digits in a 784-dimensional space is difficult to interpret directly.

**Principal Component Analysis:** A common dimensionality reduction approach is Principal Component Analysis (PCA), which seeks orthogonal directions of maximum variance. Given centered observations $X = [x_1, x_2, ..., x_n]^T$, PCA computes the covariance matrix $C = \frac{1}{n} X^T X$ and finds eigenvectors $C v_i = \lambda_i v_i$. The leading eigenvectors define the projection directions that preserve maximum variance. Although PCA is computationally efficient, it is a linear transformation and often fails to preserve nonlinear structures present in image datasets.

**t-Distributed Stochastic Neighbor Embedding (t-SNE):** t-SNE, introduced by van der Maaten and Hinton (2008), is a nonlinear dimensionality reduction technique designed specifically for visualization. For each pair of samples $x_i$ and $x_j$, a probability distribution is defined in the original space:

$$p_{j|i} = \frac{\exp\left(-\frac{|x_i - x_j|^2}{2\sigma_i^2}\right)}{\sum_{k \neq i} \exp\left(-\frac{|x_i - x_k|^2}{2\sigma_i^2}\right)}$$

The low-dimensional embedding points $y_i$ define another probability distribution:

$$q_{ij} = \frac{(1 + |y_i - y_j|^2)^{-1}}{\sum_{k \neq l} (1 + |y_k - y_l|^2)^{-1}}$$

using a Student's t-distribution.

The optimal embedding minimizes the Kullback-Leibler divergence:

$$KL(P||Q) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

through gradient descent. Unlike PCA, t-SNE focuses on preserving local neighborhood relationships rather than global variance.

**MNIST Visualization:** The following example randomly selects 10,000 MNIST images and compares PCA and t-SNE projections. Only the essential code is shown below (for complete code refer to GitHub).

```python
X, y = fetch_openml('mnist_784', version=1, return_X_y=True)
X = X.values / 255.0
idx = np.random.choice(len(X), 10000)
X, y = X[idx], y[idx]
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X)
tsne = TSNE(n_components=2, perplexity=40, random_state=0)
X_tsne = tsne.fit_transform(X)
```

The PCA projection typically exhibits substantial overlap between digit classes because linear projections cannot effectively separate complex manifolds. The t-SNE embedding, however, reveals distinct clusters corresponding to the digits 0–9. Digits with similar visual appearance, such as 4 and 9 or 3 and 5, may appear closer together, whereas visually distinct classes occupy separate regions.

This experiment illustrates an important principle in modern computer vision: images belonging to the same semantic category often lie on low-dimensional manifolds embedded within a much higher-dimensional space.

### Visualizing deep features from VGG16

The previous example applied t-SNE directly to raw image pixels. Modern deep learning systems rarely operate in pixel space. Instead, images are transformed into discriminative feature embeddings learned by convolutional neural networks. To demonstrate this concept, we use a pretrained VGG16 network and visualize features extracted from the Animal-10 dataset.

**Feature Extraction with VGG16:** The pretrained VGG16 network contains several fully connected layers near its output. The penultimate layer, denoted FC2, produces a 4096-dimensional feature vector:

$$f = f_{VGG16}(x) \in \mathbb{R}^{4096}$$

which captures semantic image content. Rather than using the final classification output, these feature vectors are extracted and used as image descriptors. The feature extractor is created as follows:

```python
model = VGG16(weights='imagenet')
feat_extractor = Model(inputs=model.input,
    outputs=model.get_layer("fc2").output)
```

Each image is resized and forwarded through the network.

```python
feat = feat_extractor.predict(x).ravel()
features.append(feat)
```
