# Interpolation methods in cv2.remap()

The interpolation argument in cv2.remap() controls how pixel values are computed for non-integer mapped coordinates. You can choose based on the trade-off between speed and output quality:

| Method | Speed | Quality | Use When... |
|---|---|---|---|
| cv2.INTER_NEAREST | Fastest | Low | Speed is critical, or for discrete masks |
| cv2.INTER_LINEAR | Balanced | Good | General-purpose image remapping |
| cv2.INTER_CUBIC | Slow | High | Image quality is a top priority |

For fisheye correction, cv2.INTER_LINEAR offers a good balance, but use cv2.INTER_CUBIC if edge smoothness matters (e.g., for publication-quality visuals).
