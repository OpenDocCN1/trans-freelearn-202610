# Semantic 3D fusion

Depth alone provides geometry but not semantic meaning. Semantic segmentation assigns a category label: $S(x,y) \in \{1,\ldots,C\}$ to each pixel. Combining depth and segmentation enables semantic 3D mapping, scene understanding, robotics, autonomous navigation, and AR/VR reconstruction.

The next code snippet uses nvidia/segformer-b0-finetuned-ade-512-512. As mentioned earlier, SegFormer combines hierarchical transformers and efficient decoding. And multi-scale fusion without positional encoding. $\text{outputs} = \text{seg\_model}(**\text{inputs})$ produces segmentation logits:

$L \in \mathbb{R}^{C \times H \times W}$

The final segmentation map is:

$S(x,y) = \underset{c}{\operatorname{argmax}}\; L_c(x,y)$
