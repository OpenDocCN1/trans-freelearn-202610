Let’s convert an image from RGB to CMYK using the `rgb2cmyk()` function, as in the following code snippet. First extract the R, G, and B channels from the input image. Convert rgb `[0,255]` to cmy `[0,1]`. Extract out black component k. Finally, the CMYK values to a desired range of `[0, CMYK_SCALE]` for storage or processing.

```
```python
RGB_SCALE, CMYK_SCALE = 255, 100

def rgb2cmyk(x):
    r, g, b = x[...,0], x[...,1], x[...,2]
    c, m, y = 1 - r / RGB_SCALE, 1 - g / RGB_SCALE, 1 - b / RGB_SCALE
    min_cmy = np.minimum(np.minimum(c, m), y)
    c, m, y, k = (c - min_cmy) / (1 - min_cmy), \
                  (m - min_cmy) / (1 - min_cmy), \
                  (y - min_cmy) / (1 - min_cmy), min_cmy
    return np.dstack((c * CMYK_SCALE, m * CMYK_SCALE, y * CMYK_SCALE, \
                      k * CMYK_SCALE))

im = plt.imread('images/rgb_cmyk_t.png')
im_cmyk = rgb2cmyk(im)
