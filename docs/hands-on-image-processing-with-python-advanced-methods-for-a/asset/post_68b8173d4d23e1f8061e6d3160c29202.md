
## Fourier-domain solution

If we assume circular convolution and use $L=I$, the problem simplifies in Fourier domain. The equation becomes:

$$\hat{F}(u,v)=\frac{H^*(u,v)}{|H(u,v)|^2+\lambda}G(u,v)$$

This looks strikingly similar to the Wiener filter:

- **Wiener denominator:** $|H|^2+S_\eta/S_f$
- **Tikhonov denominator:** $|H|^2+\lambda$

Tikhonov replaces the statistical ratio $S_\eta/S_f$ with a constant $\lambda$, providing **deterministic control over smoothness**.

Here’s the bias–variance trade-off:

- If $\lambda\to 0$, the equation reduces to the inverse filter, amplifying noise.
- If $\lambda$ is very large, the filter suppresses all high frequencies → overly smoothed result.
- Choosing $\lambda$ balances fidelity to observation (keep details) and smoothness prior (suppress noise).

Thus, Tikhonov embodies a bias–variance **trade-off** in image restoration.

## Beyond identity prior

If $L$ is a gradient operator (∇), then the prior penalizes roughness, leading to the classical smoothing prior. This is equivalent to minimizing:

$$\|h*f-g\|_2^2+\lambda\|\nabla f\|_2^2$$

which is connected to diffusion-based denoising (akin to a quadratic smoothness prior). Other priors can be plugged in:

- Laplacian operator → penalizes high second derivatives.
- Edge-preserving priors (non-quadratic norms) → link to Total Variation (TV) regularization.

Thus, Tikhonov is the prototype of a much broader family of variational restoration methods. Let’s do a comparison to Wiener filtering:

| Aspect | Tikhonov | Wiener |
|---|---|---|
| Formulation | Variational minimization | Statistical estimation |
| Assumptions | No explicit noise model, constant penalty | Requires noise and signal PSD |
| Adaptivity | Global, deterministic | Adaptive to local frequency SNR |
| Pros | Simple, tunable, mathematically elegant | Adaptive, robust to noise |
| Cons | Needs λ tuning, oversmooths | Requires noise statistics (or estimation) |

*Table 9.1 – Comparing Tikhonov regularization with Wiener filtering*

**Tikhonov regularization** provides a deterministic, variational approach to image restoration, balancing fidelity to data with smoothness priors. It is simpler than Wiener filtering but less adaptive. It serves as a gateway to more advanced priors like TV, sparse priors, and modern deep priors.

If the ratio $S_\eta/S_f$ is approximated by a constant $\lambda$, Wiener and Tikhonov become mathematically similar. Thus, Wiener is statistical/Bayesian, while Tikhonov is variational/regularization-based. The next code snippet implements the Tikhonov restoration and compares it with the Wiener restoration, and for visual comparison, we will plot the restored images side-by-side:

```python
from skimage import color, data, img_as_float, restoration
from scipy.signal import convolve2d as conv2
from numpy.fft import fft2, ifft2, fftshift

im = color.rgb2gray(img_as_float(data.astronaut()))  # Load image
im = im[50:300, 150:400]  # crop
n = 15
psf = np.ones((n, n)) / n**2  # Blur with PSF
blurred = conv2(im, psf, 'same')
np.random.seed(0)  # Add Gaussian noise
noisy = blurred + 0.05 * np.random.standard_normal(blurred.shape)

def tikhonov_restore(noisy, psf, lam=0.01):  # Tikhonov Restoration
    psf_padded = np.zeros_like(noisy)
    psf_padded[:psf.shape[0], :psf.shape[1]] = psf
    psf_padded = fftshift(psf_padded)
    H = fft2(psf_padded)
    G = fft2(noisy)
    H_conj = np.conj(H)
    F_hat = (H_conj / (np.abs(H)**2 + lam)) * G
    f_hat = np.real(ifft2(F_hat))
    return np.clip(f_hat, 0, 1)

tikhonov_restored = tikhonov_restore(noisy, psf, lam=0.01)
wiener_restored, _ = restoration.unsupervised_wiener(noisy, psf)
```

Tikhonov requires manual tuning of λ, smooths noise effectively but may oversmooth details and is simpler and deterministic. Wiener estimates noise-to-signal ratio adaptively, often preserves details better and is more practical in real-world cases when noise stats are unknown.

## Bayesian interpretation of Wiener filtering and Tikhonov regularization

Image restoration can also be framed in a Bayesian inference setting, where the goal is to recover the most probable clean image f given the degraded observation g. We assume the degradation model:

$$g = Hf + \eta$$

with additive Gaussian noise $\eta \sim N(0, \sigma^2 I)$. Thus, the likelihood is:

$$p(g \mid f) \propto \exp\left( -\frac{1}{2\sigma^2} \| Hf - g \|^2 \right)$$

Priors and estimation strategies include the following:

- **Wiener filtering:** Bayesian MMSE (expectation) estimation
  - Assumes both signal f and noise are Gaussian with known covariances.
  - The **MMSE** estimator is:

    $$\hat{f}_{\text{Wiener}} = E[f \mid g]$$

  - Leads to the classical Wiener filter solution in the frequency domain.
  - Interpretation: finds the *expected image* given the noisy observation, optimal under Gaussian assumptions.
- **Tikhonov regularization:** Bayesian MAP estimation
  - Assumes a Gaussian prior on the image:

    $$p(f) \propto \exp\left( -\frac{\lambda}{2} \| Lf \|^2 \right)$$

  - The **Maximum A Posteriori (MAP)** estimator is:

    $$\hat{f}_{\text{Tikhonov}} = \arg\max_f p(f \mid g)$$

  - Equivalent to minimizing:

    $$\|Hf-g\|^2 + \lambda\|Lf\|^2$$

  - Interpretation: finds the *most probable image* given the observation, balancing fidelity with a smoothness prior.

Key insight:

- Wiener filter = Bayesian MMSE → averages over all possible solutions.
- Tikhonov regularization = Bayesian MAP → picks the single most likely solution.

This distinction helps explain why Wiener filtering is tightly linked to *second-order statistics* (covariances), while Tikhonov is more general and naturally extends to other priors (e.g., TV, sparsity).

## Deconvolution with the CLEAN algorithm

CLEAN is a classical deconvolution algorithm that was invented in radio astronomy to reconstruct sky brightness distributions from interferometric measurements (synthesized images or “dirty maps”) where the instrumental point-spread function (PSF), called the dirty beam, has strong sidelobes. The original algorithm (Högbom, 1974) models the sky as a sparse set of point sources and then iteratively subtracts scaled and shifted copies of the PSF from the dirty image to build a set of clean components. A final “restoring beam” (a smoothed / idealized PSF) is convolved with the clean components and added to the residuals to produce the restored image. CLEAN’s greedy, matching-pursuit style makes it robust at recovering sparse, point-like structure, and it remains a foundational method and conceptual baseline for many modern deconvolution schemes.

Start from the discrete degradation model used earlier for deconvolution:

$$g[i,j] = (h * f)[i,j] + \eta[i,j],$$

where $g$ is the observed dirty image, $h$ is the PSF (dirty beam), $f$ is the unknown true image, and $\eta$ is noise. CLEAN assumes the true image $f$ is well approximated by a sparse linear combination of point sources (delta functions):

$$f[i,j] \approx \sum_k a_k\,\delta[i-p_k,\,j-q_k]$$

with amplitudes $a_k$ and positions $(p_k,q_k)$. Convolving this model with $h$ gives:

$$(h * f)[i,j] \approx \sum_k a_k\,h[i-p_k,\,j-q_k]$$

Thus, the dirty image is interpreted as a superposition of shifted PSFs. CLEAN is a greedy algorithm that finds the largest remaining PSF-shaped contribution, subtracts a scaled copy of the PSF, and records the corresponding delta (clean component).

### Högbom CLEAN

Let $r^{(0)} = g$ be the initial residual (the dirty image). At iteration $t$:

- Find the peak (maximum absolute) residual:

  $$(p_t, q_t) = \arg\max_{(i,j)} |r^{(t)}[i,j]|$$

  Let $s_t = r^{(t)}[p_t, q_t]$ be the signed peak value.
- Add a scaled delta component to the clean-component map $c$:

  $$c[p_t, q_t] \leftarrow c[p_t, q_t] + \gamma\, s_t$$

  where $0 < \gamma \le 1$ is the loop gain.
- Subtract the PSF, centered at $(p_t, q_t)$, scaled by $\gamma s_t$, from the residual:

  $$r^{(t+1)} \leftarrow r^{(t)} - \gamma s_t \cdot \text{shift}(h, p_t, q_t)$$

Iterate until either the peak falls below a threshold $\tau$ (typically related to the noise level) or a maximum number of iterations is reached. After termination, compute the restored image by convolving the clean components $c$ with a smooth restoring beam $b$ (often a Gaussian approximating the main lobe of the true PSF), and add the final residual:

$$\hat{f} = (c * b) + r^{(T)}$$

This two-term combination preserves the clean, point-like structure (from $c * b$) and the low-amplitude extended flux left in the residual.

Here’s why CLEAN works:

- **Greedy matching to PSF shape:** CLEAN explicitly matches and removes PSF-shaped patterns, reducing sidelobe confusion that can hide weaker sources.
- **Loop gain:** $\gamma$ controls stability. Using $\gamma < 1$ prevents over-subtraction and stabilizes the algorithm in noise; small $\gamma$ leads to slower but safer convergence.
- **Restoring beam:** It replaces the often complicated (and possibly noisy) PSF main lobe with a smooth beam to produce visually interpretable images and avoid amplifying high-frequency noise.
- **Sparsity prior:** CLEAN effectively imposes a sparsity prior (point sources) by constructing image from discrete deltas; this is why CLEAN performs well on sparse astronomical scenes but less well on smoothly varying extended objects.

Mathematically, **CLEAN** is closely related to matching pursuit and greedy sparse approximation (we shall explain in the next section): at each step, CLEAN selects the dictionary atom (a shifted PSF) that best matches the residual and subtracts it with a coefficient $\gamma s_t$.
