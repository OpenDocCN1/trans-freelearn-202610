Here, $sh_x$ and $sh_y$ introduce shearing (horizontal and vertical skewing).

+   - **Translation matrix:**

```
$$T = \begin{bmatrix}1 & 0 & t_x \\ 0 & 1 & t_y \\ 0 & 0 & 1\end{bmatrix}$$
```

Here, $t_x$ and $t_y$ shift the image horizontally and vertically.

The final transformation is the combination of scaling, rotation, shear, and translation:

```
$$T_A = T \cdot H \cdot R \cdot S$$
```

Let's expand this:

```
$$T_A = \begin{bmatrix}s_x \cos\theta + sh_y \sin\theta & -s_y \sin\theta + sh_x \cos\theta & t_x \\ s_x \sin\theta + sh_y \cos\theta & s_y \cos\theta + sh_y \sin\theta & t_y \\ 0 & 0 & 1\end{bmatrix} = \begin{bmatrix}a & b & t_x \\ c & d & t_y \\ 0 & 0 & 1\end{bmatrix}$$
```

Here, $a, b, c,$ and $d$ represent the parameters (e.g., $a = s_x \cos\theta + sh_x \sin\theta$) for the scaling/rotation in the $x$-direction, shear in the $x$-direction, shear in the $y$-direction, and scaling/rotation in the $y$-direction.

Let's now apply an inverse transformation to the image obtained by applying the similarity transformation last time. Note that, this time, we shall apply affine transform (by instantiating an object of the skimage.transform.AffineTransform class) instead, with the inverse of the earlier transformation matrix (computed using the np.linalg.inv() function), using the next few lines of code:

```
im_tformed = imread('images/monalisa_sim.png')
tform = AffineTransform(np.linalg.inv(matrix_sim))
im_recon_affine = warp(im_tformed, tform.inverse)
matrix_affine = tform.params

print(matrix_affine)

```

# Note

In general, when working with arbitrary transformation matrices, it's safer to use np.linalg.pinv() to handle potential singularities. However, since SimilarityTransform guarantees a valid affine matrix in typical usage, we use np.linalg.inv() directly here.
