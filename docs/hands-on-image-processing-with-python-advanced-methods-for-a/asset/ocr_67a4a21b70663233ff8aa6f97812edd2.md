+   - `from simple_lama_inpainting import SimpleLama`: This imports a convenience wrapper class around a pretrained LaMa model. The wrapper hides the boilerplate: loading weights, device selection (CPU/GPU), input preprocessing, model forwarding, and postprocessing to produce a PIL/NumPy image.
+   - `simple_lama = SimpleLama()`: This instantiates the wrapper. Typical things happening inside the constructor:
+     - Load the LaMa network architecture,
+     - Download/load pretrained weights if needed,
+     - Decide device (cuda if available, else cpu),
+     - Set evaluation mode (`model.eval()`),
+     - Set numerical precision (float32 or float16) and optionally memory optimizations.
+   
+   Some wrappers accept arguments like `device='cuda'`, `half=True`, or `model_variant='original'` to control performance and memory.

+   - `image = Image.open(img_path)`: Loads the RGB input (PIL.Image). LaMa expects a 3-channel RGB image; sizes can vary but often are padded/rescaled internally to match model constraints.
+   - `mask = Image.open(mask_path).convert('L')`: Loads mask and converts to single channel (L). Important mask conventions:
+     - Typically, 255 (white) indicates the hole to inpaint, and 0 black indicates keep.
