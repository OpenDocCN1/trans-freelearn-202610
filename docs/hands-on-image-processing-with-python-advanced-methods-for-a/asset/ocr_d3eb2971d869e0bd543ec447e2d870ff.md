# 2D and 3D convolution with PyTorch

As discussed, convolution is one of the most fundamental operations in deep learning and image processing, allowing us to detect and filter features such as edges, textures, and other patterns. The main difference between 2D and 3D convolutions lies in their dimensionality and how they interact with image data. In this section, let us aim to understand the underlying concepts in depth, along with their mathematical formulations and practical code examples. Start with the next table, which summarizes 2D and 3D convolutions:

| Feature | 2D Convolution | 3D Convolution |
|---|---|---|
| Dimensions | Operates on height × width | Operates on height × width × depth |
| Channels | Channels processed independently | Channels processed jointly |
| Example Use Cases | Edge detection, texture analysis | Video frame filtering, MRI/CT volumetric analysis |
| Computational Cost | Lower | Higher |
| Captures | Spatial features | Spatial + depth/temporal features |
