
The total loss is:

$$L_{total} = \lambda_{spa} L_{spa} + \lambda_{exp} L_{exp} + \lambda_{col} L_{col} + \lambda_{tv} L_{tv}$$

The proposed network (DCE-Net) is lightweight and fully convolutional, built with seven convolutional layers, ReLU activations, and skip connections to preserve spatial information.

**Input:** RGB low-light image

**Output:** A stack of 3 × n channels for α_t, for each of the 3 color channels over n iterations.

Final layer uses tanh activation to constrain output α_t ∈ [−1,1].

For the forward pass logic, the network predicts n separate α_t maps, each with 3 channels. These are split along the channel axis to apply the enhancement curve iteratively. Iteratively refine the image x using the enhancement curve. Store intermediate results if needed (e.g., 4th and 8th iterations).

### Why does this work?

- The enhancement curve is adaptive per-pixel, learned via CNN
- Iterative application allows progressive refinement
- Loss terms encourage exposure correction, color balancing, and structure preservation without needing supervision
- The network is compact (less than 100k parameters) and runs fast on GPUs or even mobile devices

```
import torch, torchvision, torch.nn as nn
from pathlib import Path

class DCENet(nn.Module):
    def __init__(self, n=8, return_results=[4, 6, 8]):
        super().__init__()
        self.n = n
        self.ret = return_results
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, padding=1, bias=True)
        self.conv2 = nn.Conv2d(32, 32, kernel_size=3, padding=1,
            bias=True)
        self.conv3 = nn.Conv2d(32, 32, kernel_size=3, padding=1,
            bias=True)
        self.conv4 = nn.Conv2d(32, 32, kernel_size=3, padding=1,
            bias=True)
        self.conv5 = nn.Conv2d(64, 32, kernel_size=3, padding=1,
            bias=True)
        self.conv6 = nn.Conv2d(64, 32, kernel_size=3, padding=1,
            bias=True)
        self.conv7 = nn.Conv2d(64, 3 * n, kernel_size=3, padding=1,
            bias=True)
        self.relu = nn.ReLU(inplace=True)
        self.tanh = nn.Tanh()

    def forward(self, x):
        out1 = self.relu(self.conv1(x))
        out2 = self.relu(self.conv2(out1))
        out3 = self.relu(self.conv3(out2))
        out4 = self.relu(self.conv4(out3))
        out5 = self.relu(self.conv5(torch.cat((out4, out3), 1)))
        out6 = self.relu(self.conv6(torch.cat((out5, out2), 1)))
        alpha_stacked = self.tanh(self.conv7(torch.cat((out6, out1), 1)))
        alphas = torch.split(alpha_stacked, 3, 1)
        results = [x]
        for i in range(self.n):
            x = x + alphas[i] * (torch.pow(x, 2) - x)
            if i + 1 in self.ret: results.append(x)
        return results, alpha_stacked

device = torch.device('cuda:0') # Run on GPU (e.g., google colab)
model = DCENet(return_results=[4, 8])
model.load_state_dict(torch.load('models/8LE-color-loss2_best_model.pth',
                map_location='cuda:0', weights_only=False)['model'])
model.to(device)
```

## Denoising with multi-axis MLP

Traditional methods like Gaussian filtering, wavelet shrinkage, and BM3D have proven effective to a certain extent, but deep learning-based methods now lead the state-of-the-art (SOTA). One such model is **Multi-Axis MLP (MAXIM)** developed by Google Research, which has demonstrated impressive performance on real-world denoising benchmarks such as **Smartphone Image Denoising Dataset (SIDD)**.

MAXIM (Tao et al., 2022) is a general-purpose image restoration framework built using a novel architecture that integrates:

- **MAMLP** to enable global receptive field learning
- **Local and global operations** to capture both fine and coarse features
- **Hierarchical encoder-decoder architecture with skip connections**

MAXIM represents a new class of neural architectures leveraging MLPs for dense image prediction tasks like denoising. Its strong performance on SIDD and other benchmarks demonstrates its real-world relevance.

MAXIM architecture highlights include:

- **MLP-based processing:** Unlike convolutional architectures, MAXIM replaces self-attention or convolutions with multi-axis MLP layers for efficient processing
- **Cross-gating mechanisms:** Help in better feature fusion from the encoder and decoder
- **Multi-scale Hierarchical Decoder:** Reconstructs fine details progressively

MAXIM variants (e.g., MAXIM-S3) are designed to be lightweight and fast, while still providing top-tier performance. ## Haze removal using dark channel prior

Outdoor photography often suffers from reduced visibility due to haze, fog, or atmospheric scattering. Haze affects both color fidelity and contrast, making object detection and scene understanding more difficult. In this section, we will explore a powerful and widely used image dehazing method called **Dark Channel Prior (DCP)**.

Originally proposed by He, Sun, and Tang in their influential 2009 paper, this technique makes use of a simple yet profound observation about haze-free images: most local patches in haze-free outdoor images contain some pixels with very low intensity in at least one color channel. This statistical prior, the dark channel, forms the basis of an effective haze removal algorithm.

The formation of a hazy image is commonly modeled by the atmospheric scattering model:

$$I(x) = J(x) \cdot t(x) + A \cdot (1 - t(x))$$

where:

- $I(x)$: Observed hazy image at pixel $x$
- $J(x)$: Scene radiance (true image to be recovered)
- $A$: Global atmospheric light (typically a 3-channel RGB vector)
- $t(x)$: Medium transmission describes the portion of light not scattered and reaching the camera

The goal of dehazing is to recover $J(x)$ given $I(x)$.

### Dark channel prior

Consider the dark channel of an image $I$, where

- $\Omega(x)$: A local patch centered at pixel $x$
- $I^c(y)$: Intensity of color channel $c$ at pixel $y$
