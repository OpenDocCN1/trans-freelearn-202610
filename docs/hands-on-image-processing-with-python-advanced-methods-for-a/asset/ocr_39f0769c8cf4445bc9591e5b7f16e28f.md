where $y$ = degraded image, $t$ = textual instruction embedding (derived from prompt), $f_\theta$ = restoration model with parameters $\theta$, $\hat{x}$ = restored image. Thus, restoration is not only conditioned on the image but also on user intent through natural language.

For language-vision alignment, the system uses the following components:

+   - **Language encoder:** A pretrained language model $g_\phi$ encodes the instruction prompt into an embedding $z_t = g_\phi(t)$, where $z_t \in \mathbb{R}^d$.
+   - **Instruction head:** A linear/nonlinear projection $h_\psi$ maps the language embedding into a space aligned with degradations:
+   
+     $$e_t, d_t = h_\psi(z_t)$$
+   
+     where $e_t$ is the instruction embedding and $d_t$ the predicted degradation type.
+   - **Restoration network:** The core image restoration backbone $f_\theta$ (a NAFNet-like U-Net with attention) receives both the degraded image and text embedding:
+   
+     $$\hat{x} = f_\theta(y, e_t)$$

InstructIR optimizes a joint objective:

$$\mathcal{L} = \lambda_{rec} \cdot \|x - \hat{x}\|_1 + \lambda_{per} \cdot \mathcal{L}_{perceptual}(\hat{x}, x) + \lambda_{deg} \cdot \mathcal{L}_{cls}(d_t, d^*)$$

where $\|x - \hat{x}\|_1$ ensures pixel fidelity, $\mathcal{L}_{perceptual}$ improves perceptual quality and $\mathcal{L}_{cls}$ ensures degradation prediction matches ground-truth type. This design allows the model to balance fidelity, perception, and instruction adherence.
