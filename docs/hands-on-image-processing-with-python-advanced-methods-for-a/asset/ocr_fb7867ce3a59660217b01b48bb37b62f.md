# Generating Images with DALL·E 2: DALL·E 2 creates images directly from text prompts.

```
resp = client.images.generate(model="dall-e-2", prompt=prompt,
    size="1024x1024", n=1)
```

The model receives a textual description and generates one or more images consistent with the prompt. In the demonstration, multiple generations are requested for the same prompt to visualize output diversity. Because image generation is stochastic, repeated executions often produce different interpretations of the same description. The helper function generate_dalle2() creates a base image and two additional variations for each prompt.

```
def generate_dalle2(prompt):  # DALL-E 2 generator
    resp_base = client.images.generate(model="dall-e-2",
                                    prompt=prompt, size="1024x1024",  n=1)
    base_img = get_image(resp_base.data[0].url)
    resp_vars = client.images.generate(model="dall-e-2",
                                    prompt=prompt, size="1024x1024",  n=2)
    var1 = get_image(resp_vars.data[0].url)
    var2 = get_image(resp_vars.data[1].url)
    return base_img, var1, var2
```

# Generating Images with DALL·E 3: DALL·E 3 is accessed similarly.

```
resp = client.images.generate(model="dall-e-3", prompt=prompt,
size="1024x1024")
```

A similar helper function generate_dalle3(prompt) generates three independent realizations of the same prompt. Compared with DALL·E 2, DALL·E 3 generally produces better prompt adherence, improved spatial reasoning, more coherent object relationships, higher visual realism, superior typography and text rendering and more accurate interpretation of complex instructions.
