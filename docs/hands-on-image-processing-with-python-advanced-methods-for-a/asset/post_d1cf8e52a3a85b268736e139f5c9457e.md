
**Adjusting brightness:** Brightness adjustment uniformly shifts luminance values:

$L'(x,y)=\operatorname{clip}(L(x,y)+\beta,0,255)$

where the *shift parameter* $\beta>0$ brightens the image and $<0$ darkens it. The function `adjust_brightness()` implements this by adding a shift value to the L channel in Lab colorspace (`im_lab[...,0]`) and constraining the result with `np.clip()`, as shown in the following code snippet:

```
```python
from skimage.color import rgb2lab, lab2rgb


def adjust_brightness(im, shift):
    im_lab = rgb2lab(im)
    im_lab[...,0] = np.clip(im_lab[...,0] + shift, 0, 255)
    im_out = lab2rgb(im_lab)
    return (255*im_out/im_out.max()).astype(np.uint8)
```
```

**Adjusting contrast:** Contrast refers to the difference in intensity between the light and dark areas of an image. Contrast adjustment scales luminance differences:

$L'(x,y)=\operatorname{clip}(\alpha L(x,y),0,255)$

where $\alpha>1$ increases contrast and $0<\alpha<1$ decreases it. The `adjust_contrast()` function multiplies the *L-channel* by the scaling factor before reconversion to RGB.

```
```python
def adjust_contrast(im, scale):
    im_lab = rgb2lab(im)
    im_lab[...,0] = np.clip(im_lab[...,0] * scale, 0, 255)
    im_out = lab2rgb(im_lab)
    return (255*im_out/im_out.max()).astype(np.uint8)
```
```

## Simple image morphing with cross-dissolving

A basic form of image morphing can be achieved using α-blending, where two aligned images are combined through linear interpolation. Given two images I₁ and I₂, the intermediate morphed image is computed as:

$$I_{\alpha}=(1-\alpha)I_1+\alpha I_2,\qquad \alpha\in[0,1].$$

The next code snippet demonstrates face morphing by gradually transforming a younger face image (im1) into an older one (im2) through iterative variation of α from 0 to 1 using np.linspace(). At each step, the blended image is visualized with plt.imshow().

```
im1 = mpimg.imread("images/me_young.jpg")
im2 = mpimg.imread("images/me_now.jpg")
i = 1
for alpha in np.linspace(0,1,18):
    plt.subplot(3,6,i), plt.imshow((1-alpha)*im1 + alpha*im2)
    i += 1
```

## Applying a sepia color filter

A sepia filter applies a warm brownish-yellow tone to an image, producing a vintage appearance similar to early photographs. The effect is achieved by transforming the RGB channels using a sepia transformation matrix. The next code snippet demonstrates sepia filter, it defines a function sepia_filter() that takes a normalized RGB image I(x, y) ∈ [0,1] and applies the transformation using np.dot():

I_sepia = I · S^T

where S is the 3 × 3 sepia matrix:

S = [[0.393 0.769 0.189], [0.349 0.686 0.168], [0.272 0.534 0.131]]

Here, np.dot(im, sepia_matrix.T) performs matrix multiplication between each RGB pixel vector and the sepia matrix, converting the original colors into sepia tones. Since the transformation may generate values outside the valid RGB range, np.clip(...,0,1) constrains intensities to [0,1]. Next code first reads and normalizes the input image, applies sepia transformation, and plots original and sepia-filtered images side-by-side.

```
def sepia_filter(im):
    return np.clip(np.dot(im, np.array([[0.393, 0.769, 0.189], \
                                         [0.349, 0.686, 0.168], \
                                         [0.272, 0.534, 0.131]]).T), 0, 1)

im = imread('images/sea_beach.jpg')
im_out = sepia_filter(im / im.max())
plt.imshow(np.hstack((im, im_out))), plt.axis('off')
```
