# Figure 4.42 – Repeated image

The DFT assumes that an image repeats periodically in both horizontal and vertical directions. As a result, sharp intensity changes at image boundaries create discontinuities that introduce unwanted high-frequency artifacts, often appearing as strong vertical and horizontal lines in the shifted frequency spectrum. To reduce these effects, **windowing** is applied by multiplying the image with a smooth tapering function *w(x, y)* that is close to 1 at the center and gradually decreases to 0 near the edges. This smooth transition minimizes boundary discontinuities and suppresses spectral artifacts before computing the DFT.

There are many windowing functions available in the `skimage.filters` module’s `window()` function, which accepts the windowing function name and the associated parameters, if any. Let’s apply the parzen windowing function (you can try other functions too) on the input image and compute the DFT. Observe that, this time, we obtain the desired output:
