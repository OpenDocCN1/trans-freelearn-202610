Here is the pipeline:

+   1. Feature Extraction → $f_i$
+   2. Training Labels → $y_i$
+   3. Classifier Training
+   4. Pixel-wise Prediction

The next code snippet implements classification-based segmentation, here are the steps:

+   1. **Load image and define training labels:** Extract a subregion from a skin image (downloaded with `data.skin()`) for training and initialize label map $y_i$, regions are manually annotated: each integer $k$ = class label (sparse labeling → reduces annotation effort).
+   2. **Feature extraction:** $f_i = [I_i, \text{texture}_i, \text{multi-scale responses}]$

The function `partial()` creates a new function with some arguments pre-filled. Multi-scale Gaussian filtering captures structures at different scales (at **different levels of detail**):

These are image features computed at multiple spatial scales (resolutions):

+   - $F = \{f_{\sigma_1}(I), f_{\sigma_2}(I), ..., f_{\sigma_n}(I)\}$, where $\sigma$ = scale (e.g., Gaussian blur level)
+   - Small scale → fine details (edges, texture)
+   - Large scale → coarse structures (shapes, regions)

Typical features: intensity, edges (gradients), texture (Laplacian, Hessian) computed at different Gaussian scales.

Why is it useful? Because objects appear differently at different sizes: detect small objects → small scale and detect large objects → large scale.
