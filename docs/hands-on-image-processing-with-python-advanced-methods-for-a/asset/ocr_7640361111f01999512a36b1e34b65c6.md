# The LoG filter with scipy.ndimage

The `scipy.ndimage` module’s `gaussian_laplace()` function can also be used to implement LoG, as shown in the following code snippet. It demonstrates how `scipy.ndimage` can be used to apply the Laplacian of Gaussian (LoG) operator at different scales to observe multi-scale behavior:

```
```python
img = rgb2gray(imread('images/zebras.jpg'))
fig = plt.figure(figsize=(20,12))
plt.gray() # show the filtered result in grayscale
plt.subplot(331), plt.imshow(img), plt.axis('off')
plt.title('input image', size=15)
for sigma in range(1,9):
    plt.subplot(3,3,sigma+1)
    img_log = ndimage.gaussian_laplace(img, sigma=sigma)
    plt.imshow(np.clip(img_log,0,1)), plt.axis('off')
    plt.title('LoG with sigma=' + str(sigma), size=20)
