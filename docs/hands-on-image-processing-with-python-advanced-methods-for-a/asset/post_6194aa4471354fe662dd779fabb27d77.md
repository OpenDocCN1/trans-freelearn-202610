## Segmentation evaluation metrics

Evaluating the quality of a segmentation model is as important as designing the model itself. In semantic and instance segmentation, the predicted mask Ŷ must be compared against the ground-truth mask Y to quantify how accurately the model identifies object boundaries and semantic regions.

Let $Y \subseteq \Omega$ denote the set of pixels belonging to the true object region, and let $\hat{Y} \subseteq \Omega$ represent the predicted segmentation region, where $\Omega$ is the image domain.

For binary segmentation, each pixel belongs either to the foreground or background class. The comparison between true and predicted classes is commonly expressed using the confusion matrix quantities:

- **True Positive (TP):** correctly predicted foreground pixels
- **False Positive (FP):** background pixels incorrectly predicted as foreground
- **False Negative (FN):** foreground pixels missed by the model
- **True Negative (TN):** correctly predicted background pixels

These quantities form the basis of most segmentation metrics.

## Intersection over Union metric

The Intersection over Union (IoU) metric, also called the Jaccard Index, measures the overlap between the predicted region and the ground-truth region:

IoU = |Y ∩ Ŷ| / |Y ∪ Ŷ|

Where Y ∩ Ŷ denotes the intersection (common pixels) and Y ∪ Ŷ denotes the union (all pixels belonging to either mask).

Using confusion matrix terms,

IoU = TP / (TP + FP + FN)

Where IoU = 1 is perfect segmentation, IoU = 0 means no overlap. Higher IoU indicates better localization and boundary agreement. IoU penalizes both false positives and false negatives, making it one of the most reliable metrics for semantic segmentation.

IoU is widely used in medical image segmentation, autonomous driving, satellite image analysis, organ and tumor segmentation, and benchmark datasets such as Cityscapes and Pascal VOC. For multiclass segmentation, the IoU is computed independently for each class and averaged:

mIoU = 1/C Σ_{c=1}^C IoU_c

where C is the number of classes.

## Dice Coefficient

The Dice Similarity Coefficient (DSC) measures the similarity between two sets and is particularly popular in medical imaging:

Dice = 2|Y ∩ Ŷ| / (|Y| + |Ŷ|)

In terms of confusion matrix quantities,

Dice = 2TP / (2TP + FP + FN)

The Dice coefficient is closely related to IoU:

Dice = 2·IoU / (1 + IoU)

and conversely,

IoU = Dice / (2 − Dice)

### Note

Dice ranges from 0 to 1. Higher Dice indicates stronger overlap. Dice is more sensitive to small structures than IoU. This property makes Dice particularly effective for tumor segmentation, lesion detection, vessel segmentation, and brain MRI analysis.

## Dice loss

Deep learning models often optimize the Dice loss:

```
L_Dice = 1 − Dice
```

or its differentiable soft version:

```
L_Dice = 1 − (2 Σ_i p_i g_i + ε) / (Σ_i p_i + Σ_i g_i + ε)
```

where p_i is the predicted probability, g_i is the ground-truth label and ε prevents division by zero. Dice loss is highly effective for imbalanced datasets where the foreground occupies only a small image region.

## Pixel accuracy

Pixel accuracy measures the proportion of correctly classified pixels:

```
Accuracy = correct pixels / total pixels
```

For binary segmentation,

```
Accuracy = (TP + TN) / (TP + TN + FP + FN)
```

Pixel accuracy evaluates global classification correctness but may be misleading for highly imbalanced datasets. Sometimes it may happen that the accuracy is high, but the segmentation is completely useless because the object is never detected. Therefore, pixel accuracy should not be used alone for segmentation evaluation.

## Mean pixel accuracy

For multiclass segmentation, we have:

```
Mean Accuracy = (1/C) Σ_{c=1}^C TP_c / (TP_c + FN_c)
```

where C is the number of semantic classes.

## Mean Average Precision

The Mean Average Precision (mAP) metric is widely used in instance segmentation and object detection, particularly for models such as Mask R-CNN, YOLO, and Detectron2. Unlike semantic segmentation metrics, mAP evaluates both:

- Localization quality
- Classification correctness

## Precision and recall

Precision is defined as:

Precision = TP / (TP + FP)

while recall is:

Recall = TP / (TP + FN)

A prediction is considered correct if its IoU exceeds a threshold, commonly: IoU ≥ 0.5. This criterion is often written as AP₅₀.

## Average precision

For a given class, the precision-recall curve is computed across different confidence thresholds. The average precision (AP) is the area under this curve:

AP = ∫₀¹ p(r) dr,

where p(r) is precision as a function of recall.

Mean Average Precision: The mean across all classes gives:

mAP = 1/C Σ_{c=1}^C AP_c

## COCO-style mAP

The COCO benchmark evaluates AP across multiple IoU thresholds: {0.50,0.55,0.60,...,0.95} and averages them:

mAP_coco = 1/10 Σ_{t=0.50}^{0.95} AP_t

This produces a more stringent evaluation than using only AP₅₀.
