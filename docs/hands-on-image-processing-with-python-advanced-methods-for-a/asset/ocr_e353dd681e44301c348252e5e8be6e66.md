During training, the objective minimizes reconstruction error:

$$\mathcal{L}_{depth} = \frac{1}{N} \sum_{i=1}^{N} |D_i - \widehat{D}_i|$$

or scale-invariant losses such as:

$$\mathcal{L}_{si} = \frac{1}{N} \sum_{i} d_i^2 - \frac{1}{N^2} \left(\sum_{i} d_i\right)^2$$

where $d_i = \log D_i - \log \widehat{D}_i$.

The processor (DPTImageProcessor) handles normalization, resizing and tensor conversion. The model (DPTForDepthEstimation) performs transformer-based depth prediction. The model is moved to GPU for acceleration.

# Depth estimation pipeline

The get_depth() function handles the complete inference pipeline: converting the image into PyTorch tensors (return_tensors="pt"), moving tensors to GPU, running the transformer model without gradient computation (torch.no_grad()), resizing the predicted depth map back to the original image size using bicubic interpolation, and normalizing the depth values into the range ([0,1]) for visualization. Finally, Matplotlib displays the original image and the estimated depth map side-by-side. Here are the steps:

+   1. **Image processing:** processor(images=image, return_tensors="pt") converts the RGB image into normalized PyTorch tensors.
+   2. **Forward pass:** outputs = model(**inputs). The transformer predicts: outputs.predicted_depth, which is a dense depth tensor.
+   3. **Upsampling:** The transformer internally predicts depth at lower resolution using the function torch.nn.functional.interpolate(). Bicubic interpolation (mode="bicubic") restores the original image resolution.
+   4. **Normalization:** The min-max normalization maps depth values to [0,1] for visualization.

The resulting depth map highlights the following:

+   - Nearby objects → brighter
+   - Distant objects → darker
