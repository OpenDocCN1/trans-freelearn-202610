
## Text-guided semantic segmentation with vision–language models

Modern segmentation is no longer restricted to fixed label sets. By leveraging vision–language alignment and generative modeling, we can directly segment objects using natural language prompts (e.g., “car”, “sky”, “person wearing a hat”). This paradigm builds on models like CLIP and extends toward generative frameworks such as diffusion models, where segmentation emerges as a conditional generation problem.

From text to segmentation masks: Given an image $I \in \mathbb{R}^{H\times W\times 3}$ and a text prompt $t$, we aim to predict a segmentation mask:

$S(x,y) = p(m = 1 \mid I, t), \quad S: \Omega \to [0,1]$

where $\Omega \subset \mathbb{R}^2$ is the image domain and $S(x,y)$ represents the probability that pixel $(x,y)$ belongs to the concept described by $t$.

**Vision–language alignment:** Using a joint embedding space:

$z_I = f_\theta(I), \quad z_t = g_\phi(t)$

Segmentation is driven by similarity:

$S(x,y) \propto \langle z_I(x,y), z_t \rangle$

This allows open-vocabulary segmentation, where labels are not fixed during training.

### CLIPSeg: Practical text-to-mask segmentation

CLIPSeg combines CLIP-style embeddings with a lightweight decoder to generate pixel-wise masks conditioned on text prompts. The processor tokenizes text and preprocesses images, while the model predicts segmentation logits corresponding to pixel-wise relevance to the queried concept. The logits are converted into probabilities using the sigmoid function:

$S(x,y) = \sigma(\text{logits}(x,y))$

where $S(x,y) \in [0,1]$ represents the probability that pixel $(x,y)$ belongs to the queried object. The `interpolate()` function upsamples the predicted mask back to the original image resolution for pixel-level alignment. Now, refer to the following code snippet:

```python
from transformers import CLIPSegProcessor, CLIPSegForImageSegmentation
processor = CLIPSegProcessor.from_pretrained("CIDAS/clipseg-rd64-refined")
model = CLIPSegForImageSegmentation.from_pretrained(
    "CIDAS/clipseg-rd64-refined").to(device)
url = "https://images.unsplash.com/photo-1492144534655-ae79c964c9d7"
image = Image.open(requests.get(url, stream=True).raw).convert("RGB")
prompt = "car"
inputs = processor(text=prompt, images=image, return_tensors="pt") \
    .to(device)
with torch.no_grad():
    outputs = model(**inputs)  # Inference
mask = outputs.logits.unsqueeze(1)

mask = torch.sigmoid(mask)
mask = torch.nn.functional.interpolate(mask,
    size=image.size[::-1], mode="bilinear", align_corners=False)
mask_np = mask[0, 0].cpu().numpy()
# Plot image and mask_np images Side-by-Side
```

Then, a segmentation head (transformer/decoder) predicts a mask conditioned on the text. The model does not “classify pixels” in the traditional sense. Instead, it answers a question at each pixel: Does this pixel belong to the concept described by the text?

### A Gradio app for interactive text-guided segmentation

The next code snippet builds a Gradio app that uses CLIPSeg to perform text-guided semantic segmentation, generating a binary mask for any object described by the user’s prompt and overlaying it on the image. Here, a natural-language prompt directly produces a pixel-wise mask.

The function segment_with_clipseg() converts the image and text prompt into aligned embeddings and uses CLIPSeg to predict pixel-wise logits indicating how strongly each pixel matches the queried concept. The logits are converted into probability masks using sigmoid activation, resized to the original image size, and thresholded to obtain a binary segmentation mask. The create_overlay() function highlights detected regions on the original image, while the Gradio interface provides an interactive app where users upload an image and enter a text prompt (e.g., “car”) to generate the corresponding segmentation mask and overlay visualization.

```python
def segment_with_clipseg(image_pil, text):
    inputs = clipseg_processor(
        text=[text], images=[image_pil],
        padding=True, return_tensors="pt").to(device)
    with torch.no_grad():
        outputs = clipseg_model(**inputs)
    logits = outputs.logits[0]  # (H, W)
    mask = torch.sigmoid(logits).cpu().numpy()  # logits -> mask
    mask = cv2.resize(mask, (image_pil.size[0], image_pil.size[1]))
    mask = (mask > 0.5).astype(np.uint8) * 255  # Threshold
    return mask

def create_overlay(image_np, mask):
    overlay = image_np.copy()
    overlay[mask > 0] = [255, 0, 0]
    return cv2.addWeighted(image_np, 0.7, overlay, 0.3, 0)

def process(image, text):
    image_np = np.array(image.convert("RGB"))
    mask = segment_with_clipseg(image, text)
    overlay = create_overlay(image_np, mask)
    return mask, overlay

import gradio as gr

demo = gr.Interface(
    fn=process,
    inputs=[gr.Image(type="pil"), gr.Textbox(label="Text Prompt")],
    outputs=[gr.Image(label="Mask"), gr.Image(label="Overlay")],
    title="⚡ Text-to-Semantic Segmentation (CLIPSeg)"
)
demo.launch()
```

Here, the processor converts both image and text into aligned embeddings, the model predicts per-pixel logits, and sigmoid activation converts them into probability masks. After thresholding, a binary segmentation mask is obtained and blended with the original image for visualization.

## Depth estimation and 3D scene understanding from a single image

Human vision naturally infers depth, geometry, and spatial relationships from monocular observations. In computer vision, recovering three-dimensional structure from a single RGB image is a highly ill-posed inverse problem because multiple 3D scenes may project to the same 2D image. Recent transformer-based deep learning models have dramatically improved monocular depth estimation by learning geometric priors from massive datasets. Once dense depth is estimated, the image can be lifted into 3D space to generate point clouds, reconstruct scenes, and perform semantic 3D understanding. This section demonstrates a complete pipeline for monocular depth estimation, point cloud generation, multi-view fusion, and semantic 3D reconstruction using state-of-the-art transformer architectures.

### From image to depth: Monocular depth estimation

Monocular depth estimation predicts a dense depth map $D: \Omega \to \mathbb{R}^{+}$, where $\Omega \subset \mathbb{R}^{2}$ denotes the image domain and $D(x,y)$ represents the estimated distance from the camera to the pixel $(x,y)$. Unlike stereo vision or LiDAR, monocular depth estimation relies entirely on learned geometric cues such as perspective distortion, texture gradients, object scale priors, occlusions, shadows, semantic context, etc. Modern transformer-based models learn these relationships end-to-end.

### Dense Prediction Transformer

The demo uses the pretrained model `intel/dpt-large`, which is based on the Dense Prediction Transformer (DPT) architecture. DPT combines Vision Transformers (ViTs), multi-scale feature fusion, and dense prediction decoding. Unlike CNNs with limited receptive fields, transformer models model global image dependencies through self-attention.

For image tokens, $X = x_1, x_2, \ldots, x_N$, self-attention computes:

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^{T}}{\sqrt{d}}\right)V.$$

where $Q$ = query matrix, $K$ = key matrix, $V$ = value matrix and $d$ = embedding dimension. This enables the network to reason globally about scene geometry.

The model predicts a dense depth tensor:

$$\hat{D}=f_{\theta}(I),$$

where $I$ = RGB image, $f_{\theta}$ = transformer depth network and $\hat{D}$ = predicted depth map.
