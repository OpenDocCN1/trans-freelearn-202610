
- **Multi-Stage Hierarchical Encoder** Produces feature maps at multiple resolutions. The encoder outputs are combined (via multi-scale feature fusion) as:
  
  $$F = \operatorname{concat}(F_1, F_2, F_3, F_4)$$
  
- **No Positional Encoding** (a key innovation—spatial information is implicitly preserved).
  
- **Lightweight MLP Decoder** Efficiently fuses multi-scale features, so that the final segmentation prediction is:
  
  $$\hat{Y} = \operatorname{MLP}(F)$$

This design avoids heavy decoders (e.g., U-Net style), preserves spatial detail and reduces computation significantly. Thus, a SegFormer can be understood as a *CNN-like hierarchical feature extractor implemented using transformers, combined with a simple yet powerful decoder.*

Let’s now demonstrate semantic segmentation with the next code snippet which uses the pretrained model **nvidia/segformer-b0-finetuned-ade-512-512**. Here **processor** (AutoImageProcessor) converts the image into normalized tensors, handles resizing, padding, and batching.

$$\hat{Y}(x,y) = \operatorname{argmax}_c\ \operatorname{logits}_c(x,y)$$

## Mask classification transformers: Mask2Former

Mask2Former formulates segmentation as a set prediction problem, predicts mask–class pairs:

$\{(M_i,c_i)\}_{i=1}^{N}$

where $M_i$ is a predicted soft/binary mask and $c_i$ is its class label. Instead of independent pixel classification as in CNN-based segmentation,

$\hat{y}(x,y)=\underset{k}{\operatorname{argmax}}\,P_k(x,y)$,

the final label at pixel $(x,y)$ is obtained from the highest-confidence mask prediction:

$\hat{y}(x,y)=c_{i^*},\quad i^*=\underset{i}{\operatorname{argmax}}\,M_i(x,y)$

This unifies semantic, instance, and panoptic segmentation within a single transformer-based framework using global attention-based token interactions instead of only local CNN receptive fields. Training uses Hungarian matching with a composite set-prediction loss:

$\mathcal{L}=\lambda_{cls}\mathcal{L}_{cls}+\lambda_{mask}\mathcal{L}_{mask}+\lambda_{dice}\mathcal{L}_{dice},$

where $\mathcal{L}_{cls}$ is classification loss, $\mathcal{L}_{mask}$ is pixel-wise mask loss (e.g., BCE), and $\mathcal{L}_{dice}$ is Dice overlap loss. This formulation improves global consistency, reduces duplicate predictions, and yields sharper segmentation boundaries.

The following code snippet demonstrates universal segmentation using Mask2Former for semantic, instance, and panoptic segmentation with pretrained transformer models. The function colorize() assigns visually distinct HSV-based colors to segmentation masks, ensuring clear separation between neighboring regions and object instances. ## Segmenting images from cityscape and ADE20 Dataset with pretrained OneFormer

Recent advances in transformer-based segmentation have led to unified architectures capable of handling multiple segmentation tasks, semantic, instance, and panoptic, within a single model. One such model is OneFormer, which extends the idea of mask classification (as in Mask2Former) by introducing task-conditioned segmentation, enabling a single network to generalize across datasets and segmentation paradigms. OneFormer learns “what to segment” (task) and “how to segment” (mask prediction) simultaneously. This allows cross-dataset generalization, multi-task learning and reduced model redundancy.
