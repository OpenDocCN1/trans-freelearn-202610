For translation, as explained previously, the inverse transformation matrix T⁻¹ is as follows:

```
T⁻¹ = [[1, 0, -tₓ], [0, 1, -tᵧ], [0, 0, 1]]
```

For all possible pixels in the translated output image (x, y), the corresponding points in the input image (u, v) can be found with the following equations:

```
u = x - tₓ
v = y - tᵧ
```

Here, tₓ and tᵧ denotes translations along the x and y axes, respectively (and x(u, v) = x, y(u, v) = y). Refer to the original and the transformed axes shown in the next figure:
