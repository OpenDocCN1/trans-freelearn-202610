# With opencv-python

The code snippet in this section performs template matching using the opencv-python cv2.matchTemplate() function with NCC and visualizes the result. Here's a breakdown of the following code:

+   - Convert the grayscale images to uint8 (0-255 range) as cv2.matchTemplate() expects this data type
+   - Applying template matching
+     - Use zero-mean NCC (cv2.TM_CCOEFF_NORMED) to match template_image within face_image.
+     - Output a correlation map, where values range from -1 to 1. Higher values indicate stronger matches.
+   - Visualizing the correlation map: Display the NCC result using a heatmap (cmap='afmhot'), where brighter regions indicate better template matches.

Here's the next code snippet:

```
import cv2
ncc2 = cv2.matchTemplate(face_image.astype(np.uint8), \
                        template_image.astype(np.uint8), \
                        method=cv2.TM_CCOEFF_NORMED)
# Plot the NCC result
plt.imshow(ncc2, cmap='afmhot'), plt.axis('off');
```
