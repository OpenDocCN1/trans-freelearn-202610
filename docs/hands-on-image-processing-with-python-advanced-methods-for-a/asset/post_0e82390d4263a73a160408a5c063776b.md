# Class-conditional image generation with Conditional Generative Adversarial Networks (cGANs)

**Generative Adversarial Networks (GANs)**, proposed by Ian Goodfellow and colleagues in 2014, are among the most influential generative models in modern machine learning. A GAN consists of two competing neural networks: a **generator** *G*, which synthesizes images from random noise, and a **discriminator** *D*, which attempts to distinguish real images from generated ones. Through this adversarial game, the generator gradually learns to produce increasingly realistic samples.

The original GAN learns the data distribution *p(x)*, but it offers little control over what type of image is generated. For example, when trained on *Fashion-MNIST*, a standard GAN may generate shirts, shoes, dresses, or bags, but cannot be instructed to synthesize a specific category. **Conditional Generative Adversarial Networks (cGANs)** overcome this limitation by conditioning both the generator and discriminator on additional information such as class labels, attributes, or text descriptions.

**Training Dataset:** *Fashion-MNIST* is a benchmark image dataset containing **70,000 grayscale 28 × 28 images across 10 clothing categories** (e.g., T-shirt, trouser, dress, sneaker, and bag), and it is particularly well suited for demonstrating cGANs because the discrete class labels enable clear visualization of **class-conditional image generation**, allowing the model to synthesize specific clothing categories on demand while remaining computationally inexpensive to train.

**Conditional Adversarial Learning:** In a cGAN, the generator receives both a latent vector *z* and a condition *y*: *x̂ = G(z, y)*.

Similarly, the discriminator evaluates image-label pairs: *D(x, y)*.

The objective becomes:

min_G max_D 𝔼_{x ~ p_data}[log D(x, y)] + 𝔼_{z ~ p_z}[log(1 − D(G(z, y), y))]

Thus, the discriminator must determine not only whether an image is realistic but also whether it matches the supplied condition. In this example, y corresponds to one of the ten Fashion-MNIST classes, allowing the model to generate specific clothing categories on demand.

**Generator Architecture:** The generator embeds the class label, concatenates it with the latent vector, projects the result into a feature tensor, and upsamples it to a 28 × 28 Fashion-MNIST image.

```
class Generator(nn.Module):
    def __init__(self):
        super().__init__()
        self.emb = nn.Embedding(NUM_CLASSES, 128)
        self.fc = nn.Sequential(
            nn.Linear(LATENT_DIM + 128, 7*7*256),
            nn.ReLU()
        )
        self.net = nn.Sequential(
            nn.ConvTranspose2d(256,128,4,2,1),
            nn.ReLU(),
            nn.ConvTranspose2d(128,64,4,2,1),
            nn.ReLU(),
            nn.Conv2d(64,1,3,1,1),
            nn.Tanh()
        )

    def forward(self, z, y):
        y = self.emb(y)
        x = torch.cat([z,y], dim=1)
        x = self.fc(x).view(-1,256,7,7)
        return self.net(x)
```

The __init__() method constructs the network architecture by defining its layers and trainable parameters, while the forward() method implements the computations performed during a forward pass from input to output. The generator first converts the class label into a learnable embedding with nn.Embedding(). The embedding captures semantic information about each category and transforms the discrete label into a continuous vector representation. The latent vector and class embedding are then concatenated with torch.cat(). Mathematically,

$$h = [z; e(y)]$$

This combined representation is projected into a low-resolution feature map and progressively upsampled using transposed convolutions which increase the spatial resolution from 7 × 7 → 14 × 14 → 28 × 28. Finally, a Tanh activation generates normalized grayscale images.

**Projection Discriminator:** A naïve approach to conditioning is to concatenate labels with image features. Modern cGANs often use a Projection Discriminator, which provides stronger conditioning. The discriminator extracts image features and computes a projection score :

$$h(x)^T e(y)$$
