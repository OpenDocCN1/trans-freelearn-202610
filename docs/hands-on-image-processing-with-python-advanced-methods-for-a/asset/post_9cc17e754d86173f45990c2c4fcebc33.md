
3. **Add noise:** Add zero-mean Gaussian noise with std `sigma`, using the next code. Clipping ensures valid intensities:

   ```
   sigma = 0.08
   rng = np.random.RandomState(random_state)
   noisy = img_gray + rng.normal(scale=sigma, size=img_gray.shape)
   noisy = np.clip(noisy, 0.0, 1.0)
   ```

4. **Extract overlapping patches:** The next code snippet achieves the following:

   - The function `view_as_windows()` produces all patches with the given step. Patches are vectorized as rows for learning and coding.
   - Also obtain `patches_clean` from the clean image for dictionary training (more robust than training on noisy patches).

   Now, refer to the next code:

   ```
   from skimage.util import view_as_windows
   p = patch_size
   windows_clean = view_as_windows(noisy, (p,p), step=stride)
   n_rows, n_cols, _, _ = windows_clean.shape
   num_patches = n_rows * n_cols
   patches_clean = windows_clean.reshape(num_patches, p*p)
   ```

5. **Subsample training patches and zero-mean:** Subsampling avoids memory blow-up, as performed using the next code snippet. Zero-mean patches let the dictionary learn the structure, not DC.

   ```
   n_train = min(n_samples_for_dict, num_patches)
   train_idx = rng.choice(num_patches, size=n_train, replace=False)
   train_patches = patches_clean[train_idx]
   train_means = train_patches.mean(axis=1, keepdims=True)
   train_patches_zm = train_patches - train_means
   ```

6. **Dictionary learning (sklearn):** The next code snippet does the following:

   - `DictionaryLearning.fit()` alternates between sparse coding (OMP) and dictionary update.
   - `dl.components_` are rows (atoms); we transpose to get columns $D$.
   - Normalize columns to unit norm to stabilize coding.

   Refer to the next code snippet:

   ```
   dl = DictionaryLearning(n_components=n_atoms,
       transform_algorithm='omp', transform_n_nonzero_coefs=sparsity,
       random_state=random_state, n_jobs=-1, verbose=1, max_iter=200)
   dl.fit(train_patches_zm)
   D = dl.components_.T
   col_norms = np.linalg.norm(D, axis=0)
   D /= np.maximum(col_norms, 1e-12)
   ```

7. Denoising: Patch means and sparse coding. Next, use the next code snippet to:

   - Perform sparse coding (OMP) with sparsity nonzeros using transform().
   - Reconstruct each patch as a linear combination of selected atoms + re-add mean.

   Refer to the next code:

   ```
   patch_means = patches.mean(axis=1, keepdims=True)
   patches_zm = patches - patch_means
   codes = dl.transform(patches_zm)  # batch OMP
   recon_patches_zm = codes.dot(D.T)
   recon_patches = recon_patches_zm + patch_means
   ```

8. Reconstruct whole image by overlap-averaging: Finally, reconstruct the image:

   - Overlapping patches are summed; weight_image counts overlaps. Dividing yields the average. A simple but effective aggregation strategy.
   - A better practice is Gaussian weighting per patch to emphasize center pixels and reduce blockiness.

   Refer to the next code:

   ```
   recon_image = np.zeros_like(noisy, dtype=np.float64)
   weight_image = np.zeros_like(noisy, dtype=np.float64)

   k = 0
   for i in range(n_rows):
       for j in range(n_cols):
           patch = recon_patches[k].reshape(p, p)
           row, col = i * stride, j * stride
           recon_image[row:row+p, col:col+p] += patch
           weight_image[row:row+p, col:col+p] += 1.0
           k += 1

   reconstructed = recon_image / np.maximum(weight_image, 1e-8)
   reconstructed = np.clip(reconstructed, 0.0, 1.0)
   ```

9. Metrics and saving: Report PSNR before/after to quantify denoising improvement, using the next code snippet:

   ```
   psnr_noisy = peak_signal_noise_ratio(img_gray, noisy)
   psnr_rec = peak_signal_noise_ratio(img_gray, reconstructed)
   io.imsave("images/noisy.png", (noisy*255).astype(np.uint8))
   io.imsave("images/reconstructed.png", (reconstructed*255).astype(np.uint8))
   ```

In practice, sparse-representation image restoration involves careful choices and trade-offs: small patches (e.g., 8×8) with moderate overlap (stride 1–4) balance structure capture and computation; overcomplete dictionaries (K ≥ p²) encourage sparsity and sharper reconstructions; and sparsity level controls the bias–variance trade-off, with lower values denoising more aggressively but risking detail loss.

Dictionaries trained on clean patches outperform noisy ones, though iterative denoise-then-train schemes can help when only noisy data are available. Zero-mean preprocessing and thoughtful aggregation (e.g., Gaussian weighting) are crucial to avoid seams. While Dictionary Learning and OMP are computationally intensive, parallelization, batching, and online updates improve scalability.

Enhancements such as K-SVD, block-matching (BM3D), plug-and-play learned priors, or multi-scale dictionaries further improve performance. Implementation stability requires dictionary column normalization, safe divisions, careful boundary handling, memory management, and reproducibility via fixed random seeds.

Now, let’s summarize the sparse dictionary-based learning/denoising method:

- Extract overlapping patches $x_i$ of size $p \times p$.
- Subsample clean patches and compute zero-mean versions for training.
- Learn dictionary $D$ via alternating minimization (sparse coding + dictionary update) with OMP.
- For each noisy patch, subtract the mean, compute the OMP code $\hat{\alpha}_i$ ($\leq s$ nonzeros).
- Reconstruct patches $\hat{x}_i = D\hat{\alpha}_i + \text{mean}$.
- Recombine patches by weighted averaging to obtain the restored image.

## Image restoration with deep learning

While traditional image restoration methods rely on explicit degradation models (e.g., Wiener filtering, Tikhonov regularization, CLEAN, or sparse coding with OMP), deep learning approaches instead learn implicit priors from large datasets. The degradation function H (e.g., blur + noise) is often unknown or too complex to be modeled analytically. Deep neural networks learn a mapping fθ: g ↦ f̂, where g is the degraded input, f̂ is the restored output, and θ are trainable parameters learned from data.

This approach is data-driven and has been shown to outperform hand-crafted priors in many tasks, including denoising, deblurring, deraining, super-resolution, and inpainting. Unlike classical inverse methods, deep learning can jointly handle noise suppression, detail recovery, and perceptual quality enhancement without explicitly knowing the degradation operator.

Among the latest models, Nonlinear Activation Free Network (NAFNet) has emerged as a powerful architecture for image restoration tasks, including denoising.

### Image Denoising with NAFNet

The noisy observation model is:

g = f + n

where f is the clean image, n ~ N(0, σ²I) is additive Gaussian noise and g is the observed noisy image.

The goal is to estimate f̂ that minimizes expected error:

f̂ = argmin_f̂ E[‖f − f̂‖²]

Here’s the deep learning perspective. Instead of solving via explicit priors, we train a parametric network fθ that minimizes empirical risk:

θ* = argmin_θ Σ_{i=1}^N ‖f_i − fθ(g_i)‖²

where (f_i, g_i) are training pairs of clean/noisy images. This is equivalent to learning the Bayesian MMSE estimator from data.

### NAFNet architecture

The following are the key features:

- No nonlinear activations (e.g., ReLU, GELU) → replaced by simple gating and multiplicative interactions.

- Simplicity: convolution, layer normalization, simple multiplication (“gated linear units”).

- Performance: achieves SOTA in denoising (SIDD dataset), super-resolution, and deraining with fewer FLOPs.

Mathematically, the NAFBlock replaces nonlinearities with:

y = x + Conv₂( σ( LN(Conv₁(x)) ) ⊙ Conv₃(x) )

where ⊙ is elementwise multiplication, and LN is layer normalization. This reduces complexity while retaining representation power, making the network efficient and stable.
