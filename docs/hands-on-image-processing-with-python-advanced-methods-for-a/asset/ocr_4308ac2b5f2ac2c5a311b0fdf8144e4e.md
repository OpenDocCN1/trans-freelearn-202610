# Power-law transform

As we have already seen, this point transform (the transfer function) is of the general form:

$$s = T(r) = c.r^\gamma$$

where c is a constant) on a grayscale image using the PIL.Image.point() method in Chapter 1, let’s apply a power-law transform on an RGB color image with scikit-image this time, and then visualize the impact of the transform on the color channel histograms.

```
```python
im = img_as_float(imread('images/cheetah.png'))
γ = 2.5 # try different values here and observe the impact
im_trans = im**γ
```
```

If you run the above code snippet and plot the images and corresponding RGB channel histograms, you should obtain the following figure, which shows the color channel histograms before and after the power-law transform, along with the original and transformed images:

![](bbox=[0.144, 0.437, 0.856, 0.584])

Let pixel values be normalized in the range [0,1]. The effect of γ depends critically on whether it is less than or greater than 1 (as shown in the next table and the figure).

+   - When γ < 1, the transformation expands lower intensity values, making dark regions brighter and improving visibility in shadows
+   - Conversely, when γ > 1, the transformation compresses lower intensities, causing the image to appear darker overall

| Gamma | Curve shape | effect |
|---|---|---|
| γ < 1 | Above diagonal | Brightens shadows |
| γ = 1 | Straight line | No change |
| γ > 1 | Below diagonal | Darkens image |
