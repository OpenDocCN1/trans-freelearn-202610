After exploring interpolation for upsampling, we now examine **downsampling**, where image resolution is reduced while minimizing detail loss and aliasing artifacts.

# Downsampling

Downsampling reduces image resolution by decreasing the number of pixels. A smaller image can be generated either by systematically discarding pixels (for example, removing alternate rows and columns) or by computing each output pixel as an aggregate of multiple neighboring pixels from the original image.

If $I(x, y)$ denotes the original image, a simple downsampling operation with factor $k$ is:

$I_d(x, y) = I(kx, ky)$

where $I_d(x, y)$ is the downsampled image. This reduces resolution by retaining one pixel for every $k$ pixels in each spatial direction.

# The sampling theorem (Nyquist-Shannon theorem)

The Nyquist–Shannon theorem states that a continuous band-limited signal can be perfectly reconstructed if the sampling frequency is at least twice the highest frequency present in the signal: $f_s \ge 2f_{\max}$ where $f_s$ is the sampling frequency and $f_{\max}$ is the maximum signal frequency. In images containing high-frequency textures or edges, insufficient sampling causes loss of information and reconstruction errors.
