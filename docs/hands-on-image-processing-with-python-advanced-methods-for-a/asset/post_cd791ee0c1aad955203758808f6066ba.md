## Nonlinear noise smoothing

Nonlinear (spatial) filters, like linear filters, operate on local neighborhoods by sliding a kernel (mask) across the image. However, unlike linear filtering, which computes a weighted sum, non-linear filters apply a **nonlinear function** to the pixel values within the neighborhood.

Let *f(x, y)* denote the input image and 𝒩ₓ,ᵧ the neighborhood centered at (x, y). A general nonlinear filter can be expressed as: **g(x, y) = Φ({f(s, t) | (s, t) ∈ 𝒩ₓ,ᵧ})**, where Φ(·) is a nonlinear operator (e.g., median, mode, max, etc.). Nonlinear filters are more powerful than linear filters; for example, in terms of suppression of non-Gaussian noise such as spikes, and for edge/texture preserving properties. Some examples of nonlinear filters are median, bilateral, non-local means, and morphological filters.

The **median filter** replaces each pixel with the median value of its neighborhood:

$$g(x,y) = \operatorname{median} f(s,t) \mid (s,t) \in \mathcal{N}_{x,y}$$

The median filter

- Requires **ordering (ranking)** of intensities within the neighborhood
- Selects the **middle value** instead of averaging
- Robust to outliers because extreme values do not affect the median significantly

Salt-and-pepper noise can be modeled as:

$$f(x,y) = \begin{cases} 0, & \text{with probability } p/2 \\ 1, & \text{with probability } p/2 \\ s(x,y), & \text{Otherwise} \end{cases}$$

Since impulse noise introduces **extreme outliers**, the median operator effectively removes them:

$$\text{median}0,,s(x,y),,1 \approx s(x,y)$$

Its properties are as follows:

- Nonlinear: median(a + b) ≠ median(a) + median(b)
- Preserves edges better than linear averaging
- May introduce **patchy regions** for large kernel sizes

The **mode filter** replaces each pixel with the most frequent intensity value in the neighborhood.

$$g(x,y) = \text{mode} f(s,t) \mid (s,t) \in \mathcal{N}_{x,y}$$

This filter is suitable when pixel values are **clustered**, it encourages **region homogeneity**, and Increasing kernel size increases smoothing but reduces texture detail.

**Max and Min filters** are based on extreme-value selection:

$$g_{\max}(x,y) = \max f(s,t) \mid (s,t) \in \mathcal{N}_{x,y},...,g_{\min}(x,y) = \min f(s,t) \mid (s,t) \in \mathcal{N}_{x,y}$$

- **Max filter** removes *pepper noise* (dark impulses)
- **Min filter** removes *salt noise* (bright impulses)
- Max and min filters correspond to grayscale morphological operations

Dilation: $g(x,y) = \max_{\mathcal{N}_{x,y}} f(s,t)$

Erosion: $g(x,y) = \min_{\mathcal{N}_{x,y}} f(s,t)$

The next table provides a summary of the comparison between linear and non-linear filters:

| Property | Linear filters | Nonlinear filters |
|---|---|---|
| Operation | Weighted sum | Nonlinear function |
| Noise model | Gaussian | Impulse/non-Gaussian |
| Edge preservation | Poor | Better |
| Robustness to outliers | Low | High |

*Table 7.5 - Comparison between linear and non-linear filters*

Nonlinear filters are particularly effective when noise deviates from Gaussian assumptions. By relying on **order statistics or extrema**, they suppress outliers while preserving important image structures such as edges and textures.

## Smoothing (denoising) with scikit-image

The scikit-image library also provides a set of non-linear filters in the restoration module. In the following sections, we will discuss a couple of such very useful filters, namely bilateral and non-local means filters.

### Using the bilateral filter

The bilateral filter performs edge-preserving smoothing by combining spatial proximity and intensity similarity in its weighting scheme. Let f(x, y) denote the input image. The filtered output g(x, y) at pixel (x, y) is given by:

g(x,y) = 1/W(x,y) Σ_{(s,t)∈N_{x,y}} exp(-((x-s)²+(y-t)²)/(2σ_s²)) exp(-((f(x,y)-f(s,t))²)/(2σ_r²)) f(s,t)

- (s, t) ∈ N_{x,y} are neighboring pixels
