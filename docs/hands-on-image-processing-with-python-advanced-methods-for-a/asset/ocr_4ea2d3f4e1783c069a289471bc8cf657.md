The function $G.mapping()$ transforms a random latent vector $z$ from the input latent space $Z$ into an intermediate latent representation $w$ in the disentangled latent space $W$, where semantic attributes such as pose, facial structure, and texture become more independently controllable. Here the early layers → coarse structure (pose, face shape), whereas later layers → fine texture (skin, hair, lighting). This enables **semantic disentanglement without supervision.**

# StyleGANEX: High-fidelity inversion and identity editing

While StyleGAN3 focuses on unconditional synthesis, StyleGANEX extends StyleGAN into a real-image editing and inversion framework, combining *GAN inversion*, encoder-based latent prediction, feature-level optimization, and face alignment pipelines. It is particularly designed for **real-world face editing, reconstruction, and morphing.**

**GAN Inversion Problem:** Given a real image $x$, GAN inversion aims to find a latent code $w$ such that:

$$w^* = \underset{w}{\operatorname{argmin}}\; \mathcal{L}(G(w), x),$$

where $\mathcal{L}$ is a reconstruction loss (pixel + perceptual) and $G$ is the pretrained generator. StyleGANEX improves this by optimizing latent code $w$, intermediate features $f$ and stochastic noise maps $n$.
