# Structure-guided image generation with ControlNet

While text-to-image models such as Stable Diffusion can generate highly realistic images from textual prompts, they often provide limited control over the spatial structure of the generated content. ControlNet addresses this limitation by introducing additional conditioning signals, such as edges, depth maps, segmentation masks, human poses, or sketches, enabling precise control over image composition while preserving the generative capabilities of diffusion models.

Given a control signal c (e.g., an edge map) and a text prompt y, ControlNet models the conditional distribution p(x|c, y), allowing image generation to be guided simultaneously by structural information and semantic instructions.

ControlNet Architecture: ControlNet extends Stable Diffusion by adding a trainable branch that processes external control signals. The original Stable Diffusion U-Net remains largely unchanged, while the ControlNet branch extracts structural information and injects it into the denoising process.

Let z_t denote the noisy latent representation at timestep t. The denoiser becomes ε_θ(z_t, t, c, y), where z_t is the noisy latent, c is the control image, and y is the text prompt. The generated image is therefore constrained not only by textual semantics but also by the supplied geometric structure.

Extracting Edge Guidance: The demonstration uses a horse image as input and extracts a Canny edge map.

```
gray = cv2.cvtColor(np.array(input_image), cv2.COLOR_RGB2GRAY)
edges = cv2.Canny(gray, 100, 200)
```

The Canny detector computes image gradients and identifies significant intensity discontinuities, producing an edge representation that captures the object’s shape and pose while discarding texture and color information. The edge map is then converted into a three-channel image:

```
edges = cv2.cvtColor(edges, cv2.COLOR_GRAY2RGB)
```

This edge image serves as the structural conditioning signal supplied to ControlNet.

Loading the ControlNet Model: A ControlNet model trained on Canny edge maps is loaded using:

```
controlnet = ControlNetModel.from_pretrained("lllyasviel/sd-controlnet-canny")
```

This network has learned how edge structures correspond to realistic image content and can therefore preserve object geometry during generation. The ControlNet model is then integrated with Stable Diffusion:

```
pipe = StableDiffusionControlNetPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5",
    controlnet=controlnet)
```

The resulting pipeline combines semantic guidance from text prompts with structural guidance from edge maps.
