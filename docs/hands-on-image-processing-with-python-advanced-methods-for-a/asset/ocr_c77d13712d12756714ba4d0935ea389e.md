These ringing artifacts occur because of the **Gibbs phenomenon**—a result of truncating high-frequency components in the Fourier domain. When an image contains sharp transitions, the Fourier series struggles to represent those edges accurately, causing overshooting and oscillations.

# Smoothing the image to avoid ringing artifacts

One way to reduce the ringing artifacts is by smoothing the sharp edges in the image. This can be achieved by applying a Gaussian filter to the image, which blurs the sharp transitions, leading to a reduction in high-frequency content.

# Applying a Gaussian filter

A Gaussian filter is a low-pass filter that smooths the image by reducing high-frequency components. The `gaussian()` function from the `skimage.filters` module is used here with a standard deviation, to smooth the binary circle image, as shown in the following code snippet:

f2 = gaussian(f1, 10)
