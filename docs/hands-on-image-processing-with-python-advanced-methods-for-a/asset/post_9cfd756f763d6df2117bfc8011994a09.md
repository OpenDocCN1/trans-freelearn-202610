### Filtering in the frequency domain

If we remember from the image processing pipeline described in *Chapter 1*, the immediate next step after image acquisition is image preprocessing. Images are often corrupted by random variations in intensity and illumination, or have poor contrast, and therefore can’t be used directly and need to be enhanced. This is where filters are used.

#### What is a filter?

Filtering refers to transforming pixel intensity values to reveal certain image characteristics such as the following:

- **Enhancement:** This image characteristic improves contrast
- **Smoothing:** This image characteristic removes noise
- **Template matching:** This image characteristic detects known patterns

The filtered image is described by a discrete convolution and the filter is described by an *n × n* discrete convolution mask.

Frequency domain filtering is a fundamental technique in image processing that manipulates an image’s frequency components to achieve various effects, such as smoothing, sharpening, and noise reduction. Unlike spatial domain filtering, which directly operates on pixel values, frequency domain filtering transforms an image into the frequency domain using the Fourier transform. This allows us to selectively enhance or suppress certain frequency components based on the desired outcome.

In this section, we shall explore different frequency domain filters, including **Ideal, Butterworth, and Gaussian filters**, and their applications. These filters help in controlling image details, enhancing features, and suppressing unwanted noise. We will implement these filters using libraries such as `scipy` and `scipy.ndimage`, demonstrating their effects on real images.

### Types of frequency domain filters

From the perspective of the frequency domain, a filter can be one of the following four types:

- **Low-pass filter** (for blurring and noise reduction)
- **High-pass filter** (for edge enhancement and sharpening)
- **Band-pass filter** (extracting specific frequency ranges for feature analysis)
- **Band-stop (notch) filter** (removing specific frequency noise, e.g., periodic interference)
