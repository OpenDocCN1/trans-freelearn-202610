# Note

Because federated learning optimizes models on heterogeneous local data with constrained communication, it loses some global statistical efficiency compared to centralized training, but still remains close because all clients collectively approximate the same underlying data distribution. The federated model gradually approaches centralized performance despite never accessing centralized data.

**Confusion Matrix Analysis:** Classification performance can be analyzed using a confusion matrix.

```
cm = confusion_matrix(y_true, y_pred)
```

The matrix reveals frequently confused clothing categories, strong classes, weak classes, and error patterns learned through federated training. A nearly diagonal matrix indicates good classification performance.
