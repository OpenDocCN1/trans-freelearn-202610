# Ideal, Butterworth, and Gaussian LPFs

The following code implements the preceding LPFs in the **frequency domain**, and applies them one by one to a noisy input image, **removing random noise** added to the input image and achieving smoothing (**denoising**) effects by removing high-frequency components (**noise**):

```
```python
def ideal(sz, D0):
    h, w = sz
    u, v = get_grid(w, h)
    return dist(u,v) < D0


def gaussian(sz, D0):
    h, w = sz
    u, v = get_grid(w, h)
    return np.exp(-(dist(u,v)**2/(2*D0**2))


def butterworth(sz, D0, n=2):
    h, w = sz
    u, v = get_grid(w, h)
    return 1 / (1 + (dist(u,v)/D0)**(2*n))
def apply_filter(f, func, arg_dict):
    F = fp.fftshift(fp.fft2(f))
    H = func(**arg_dict)
    G   =  H * F
    g   =  np.abs(fp.ifft2(G))
    g = g / g.max()
    return F, H, G, g
```
```

Let’s break it down step by step. Here is what the preceding code does:

+   - The `ideal()` function implements ILPF, with cut-off frequency D0: frequencies inside radius D0 are kept, and others are set to zero. This creates a hard cut-off, which can cause ringing artifacts (the **Gibbs phenomenon**).
+   - The `gaussian()` function implements GLPF. The frequency attenuation follows a smooth exponential decay. This avoids the ringing artifacts seen in the Ideal LPF.
+   - The `butterworth()` function implements BLPF. It has a more gradual transition than the Ideal LPF but sharper than Gaussian. The n parameter controls the filter order: higher n means a sharper transition
