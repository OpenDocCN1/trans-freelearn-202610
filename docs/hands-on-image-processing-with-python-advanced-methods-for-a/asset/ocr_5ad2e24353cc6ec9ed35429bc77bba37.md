NearestNDInterpolator performs nearest-neighbor interpolation by assigning the value of the closest valid pixel. LinearNDInterpolator performs piecewise linear interpolation by triangulating the input samples using the Qhull convex-hull algorithm and applying barycentric interpolation within each triangle. RBFInterpolator reconstructs missing values using radial basis functions (RBFs). An RBF is a scalar-valued function φ(x, c), which depends only on the distance from a reference point (center c), that is, the value of the RBF at x is φ(|| x − c ||). A popular RBF is the Gaussian function:

```
φ(r) = e^(-r² / (2σ²))
```

where r = || x − c || denotes the Euclidean distance from the center point c and σ controls the spread or smoothness of the basis function.

The default kernel in RBFInterpolator is the thin-plate spline kernel:

```
φ(r) = r² log(r)
```

The RBF interpolant is expressed as a weighted sum (linear combination) of radial basis functions centered at known data points together with a polynomial term:

```
f(x) = Σᵢ₌₁ᴺ wᵢ φ(|| x − yᵢ ||) + P(x)
```

where yᵢ are the known sample locations, wᵢ are interpolation weights, and P(x) is a low-degree polynomial of a specified degree, used for stability and smoothness, sas shown in the next figure. Equivalently, the interpolant can be written in matrix form as:

```
f(x) = K(x, y) a + P(x) b
```

where K(x, y) is the matrix whose entries are φ(|| x − yᵢ ||), P(x) is the matrix of polynomial basis functions (monomials), and the coefficient vectors a and b are obtained by solving a system of linear equations.
