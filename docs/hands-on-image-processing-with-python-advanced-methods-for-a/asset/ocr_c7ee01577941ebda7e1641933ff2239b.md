The next code snippet demonstrates simple image darkening using NumPy thresholding and image I/O with Matplotlib. The image is first normalized to the [0,1] range, copied using `copy()`, and darkened by setting all pixel values below the threshold 0.5 to 0 using Boolean indexing: `im_dark[im_dark < 0.5] = 0`. Lower threshold values darken more pixels. The darkened image is then saved with `mpimg.imsave()`, reloaded with `mpimg.imread()`, and displayed side-by-side with the original image using `np.hstack()` and `plt.imshow()`. The `[..., :3]` operator ensures that only the RGB channels are retained if an alpha channel exists.

```
```python
im = im / im.max()  # 0-1 normalize
im_dark = im.copy()
im_dark[im_dark < 0.5] = 0      # make the image look darker
mpimg.imsave("images/hill_dark.png", im_dark)  # save the dark image
im_dark = mpimg.imread("images/hill_dark.png")[..., :3]  # 1st 3 color channels
plt.imshow(np.hstack((im, im_dark)), plt.axes('off'))
plt.title('original and the darkened image', size=20)
