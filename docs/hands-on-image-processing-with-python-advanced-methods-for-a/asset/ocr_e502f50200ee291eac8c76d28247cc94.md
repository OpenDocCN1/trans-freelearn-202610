# Note

Kullback–Leibler (KL) divergence measures how different one probability distribution is from another: KL(Q,‖P) = Σₓ Q(x) log Q(x)/P(x). It quantifies how much information is “lost” when we use the approximation Q instead of the true distribution P. In CRF mean-field inference, we iteratively update Q to approximate P(X | I): a decreasing KL divergence indicates that Q is getting closer to the true distribution P, i.e., the algorithm is converging.

Why CRF works well? It refines coarse segmentation and aligns labels with object boundaries – sharpens boundaries and preserves fine structures. It removes isolated noisy predictions. The next table provides a comparison between the last two graph-based methods for segmentation:

| Method | Key Idea | Strength |
|---|---|---|
| GrabCut | Graph cuts + GMM | Interactive segmentation (through Global optimization) |
| CRF | Probabilistic graphical model | Boundary refinement (through Context-aware refinement) |

Table 10.1: Grabcut vs. CRF method for image segmentation

While GrabCut performs interactive, data-driven segmentation through global energy minimization using color models, CRFs refine the segmentation output by enforcing spatial and contextual consistency at the pixel level, leading to sharper and more coherent object boundaries.

# Learning-based classical segmentation

This class of methods bridges classical image processing and machine learning, where segmentation is formulated as a supervised learning problem. Instead of relying purely on thresholds or gradients, these approaches learn decision boundaries from data using engineered features.

# Segmentation using classification

Trainable segmentation treats each pixel as a feature vector and predicts its label using a classifier. Given an image I(x, y).

We extract features:

fᵢ = φ(I, xᵢ, yᵢ),

where: fᵢ ∈ ℝᵈ: feature vector at pixel i and φ(·): feature extraction function (intensity, texture, etc.). the segmentation problem becomes:

ŷᵢ = argmaxₖ P(yᵢ = k | fᵢ).

Random Forest Classifier: A Random Forest is an ensemble of decision trees:

P(yᵢ = k | fᵢ) = 1/T Σₜ=1ᵀ Pₜ(yᵢ = k | fᵢ),

where T: number of trees and each tree partitions feature space using axis-aligned splits.
