# Promptable foundation models for image segmentation

Traditional segmentation models are trained to map an image $I \in \mathbb{R}^{H \times W \times 3}$ directly to a dense label map $S: \Omega \subset \mathbb{R}^2 \to \mathcal{C}$ where $\mathcal{C}$ is a fixed set of classes. In contrast, **promptable foundation models** redefine segmentation as a **conditional prediction problem**, where the output depends not only on the image but also on an external **prompt** $p$:

$$S(x, y \mid p) = f_\theta(I, p),$$

where the prompt $p$ can take multiple forms: sparse points, bounding boxes, text descriptions and coarse masks. This paradigm introduces **interactive, zero-shot, and generalizable segmentation**, where a single model can segment arbitrary objects without retraining.

# Segment Anything Model

The **Segment Anything Model (SAM)** is a large-scale vision foundation model trained on billions of masks. It performs **prompt-driven segmentation** using points, boxes, or masks as guidance. SAM decomposes segmentation into three components:

+   - Image encoder: $F = E_I(I), \quad F \in \mathbb{R}^{N \times D}$
+   - Prompt encoder: $P = E_p(p)$
+   - Mask decoder: $M = D(F, P)$

Final prediction:

$$M(x, y) = \sigma\left(f_\theta(I, p)\right),$$

where $\sigma$ is a sigmoid function producing a binary mask. Thus, SAM learns a universal segmentation function conditioned on prompts, rather than fixed classes.
