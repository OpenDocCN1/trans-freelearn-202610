# Rotation

Rotating the input image by an angle implies rotating the spectrum by the same angle , as shown in the following figure:

f(r, θ) ↔ F(ω, φ)
f(r, θ + α) ↔ F(ω, φ + α)
rotated by an angle α

Figure 4.48 - Rotation property for DFT

The following code snippet demonstrates this property:

```
from scipy.ndimage import rotate
im = imread('images/box.png', True)
F = np.fft.fftshift(np.fft.fft2(im))
im_rot = rotate(im, 45)
F_rot = np.fft.fftshift(np.fft.fft2(im_rot)) # rotated spectrum
```
