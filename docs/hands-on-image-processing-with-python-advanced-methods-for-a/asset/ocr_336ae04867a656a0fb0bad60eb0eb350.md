# With PIL

The next code snippet superimposes two images using different blending modes to create different lighting effects, as described previously, using the following method from ImageChops:

+   - hard_light enhances contrast by applying a mix of Multiply and Screen blending—bright areas get brighter, and dark areas get darker
+   - soft_light is a more subtle version of hard_light, simulating soft directional lighting by dodging or burning pixels based on the foreground
+   - overlay is similar to hard_light but with background-driven intensity—bright regions become even brighter while dark regions deepen

Now, refer to the next code snippet:

```
im1 = Image.open("images/scene.jpg")
im2 = Image.open("images/turtle.jpeg").convert('RGB') \
    .resize((im1.width, im1.height))

im_hard = hard_light(im1, im2)
im_soft = soft_light(im1, im2)
im_overlay = overlay(im1, im2)
plt.imshow(np.hstack((im_hard, im_soft, im_overlay))), plt.axis('off')
```

# With blend_modes

The next code snippet demonstrates blending two images with the soft_light algorithm at different opacities using the blend_modes library. The imgviz library is used to add an alpha channel to an image. The blend_modes.soft_light() method applies soft light blending, controlled by the opacity (α) parameter. For each pixel, the soft_light blend formula is applied as follows:

C_out = (1 − α) · C_base + α · F_soft−light(C_base, C_blend)
