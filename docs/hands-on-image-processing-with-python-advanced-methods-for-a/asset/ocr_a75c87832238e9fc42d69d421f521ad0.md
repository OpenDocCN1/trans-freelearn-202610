# DFT with matrix multiplication

Although FFT libraries such as numpy.fft and scipy.fft are commonly used in practice, the 2D DFT can also be expressed elegantly using matrix multiplication with Fourier basis matrices, as illustrated in the next figure.

For a square image X ∈ ℂ^{N×N}, the DFT is computed as F = W f W, and the IDFT is computed as f̂ = W^H F W^H, where W is the Fourier matrix generated from complex roots of unity, and, where W^H is the Hermitian adjoint.

Separability of the 2D DFT
F(k,ℓ) = 1/√N Σ_{n=0}^{N-1} [ 1/√M Σ_{m=0}^{M-1} f(m,n) e^{-j2π (k m / M)} ] e^{-j2π (ℓ n / N)}

matrix notation
2D DFT forward transform    F = (W_M f) W_N
M x M   N x N

f(m,n) = 1/√N Σ_{ℓ=0}^{N-1} [ 1/√M Σ_{k=0}^{M-1} F̂(k,ℓ) e^{j2π (k m / M)} ] e^{j2π (ℓ n / N)}

W_M(m,k) = 1/√M e^{-j2π (m k / M)}
W_N(n,l) = 1/√N e^{-j2π (n l / N)}

matrix notation
2D DFT inverse transform    f = (W_M^* f) W_N^*
M x M   N x N

This matrix formulation generalizes naturally to other orthogonal image transforms such as the DCT and Walsh–Hadamard transform. The next code snippet implements the 2D DFT and IDFT using Fourier matrix multiplication for square images (M = N). The DFT_matrix() function constructs the symmetric Fourier matrix W with either the standard normalization used by np.fft.fft2() or symmetric 1/√N normalization, and returns the properly normalized inverse matrix when inverse=True. W^H F W^H With square-root normalization, the Fourier matrix becomes unitary, satisfying:

W W^H = I ⇒ W^{-1} = W^H

which shows that the Fourier basis vectors are orthonormal.

The code first loads and normalizes a grayscale image, computes a reference DFT with np.fft.fft2(), and then computes the transform using the Fourier matrix W (as F = W @ X @ W). The reconstruction is similarly performed with the inverse Fourier matrix W_I (as X_hat = W_I @ F @ W_I). Comparisons with NumPy's fft2() and ifft2() show negligible numerical error, confirming the correctness of the implementation.
