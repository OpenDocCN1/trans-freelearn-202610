

## 前言

数据管理需求已从传统的关系型存储演变为关系型与非关系型存储并存，而现代化的信息管理平台需要支持所有类型的数据。为了从任意数据中获取洞察，你需要一个平台，该平台能够跨关系型、非关系型和流数据提供完整的数据管理能力，同时能够无缝地在一种数据类型与另一种数据类型之间移动数据，并且能够监视和管理所有数据，无论其数据类型或数据结构如何。Apache Hadoop 是广泛认可的大数据工具，类似地，当谈到 RDBMS 时，SQL Server 2012 可能是最强大的内存和动态数据存储与管理系统。本书帮助读者弥合 Hadoop 和 SQL Server 之间的差距，换句话说，就是弥合非关系型和关系型数据管理世界之间的差距。本书重点介绍了 SQL Server 丰富的商业智能（Business Intelligence）套件中可用的数据集成和可视化解决方案，以及它们与 Apache Hadoop 和 Hive 之间的无缝通信。

## 本书内容

- 第 1 章，大数据和 Hadoop 简介，向读者介绍大数据和 Hadoop 世界。本章解释了大数据解决方案的必要性、当前的市场趋势，并使用户能够在即将发生的数据爆炸中领先一步。
- 第 2 章，使用 Sqoop – SQL Server Hadoop 连接器，介绍了基于开源 Sqoop 的 Microsoft SQL Server Hadoop 连接器。本章解释了基本的 Sqoop 命令，用于在 SQL Server 和 Hadoop 之间导入/导出文件。
- 第 3 章，使用 Hive ODBC 驱动程序，解释了如何使用开放数据库连接（ODBC）接口从 Hadoop 和 Hive 消费数据。本章展示了如何创建一个 SQL Server 集成服务（Integration Services）包，使用 Hive ODBC 驱动程序将数据从 Hadoop 移动到 SQL Server。
- 第 4 章，使用 SQL Server Analysis Services 创建数据模型，展示了如何从 SQL Server Analysis Services 消费来自 Hadoop 和 Hive 的数据。读者将学习如何使用 Hive ODBC 驱动程序从 SQL 到 Hive 创建链接服务器，并构建 Analysis Services 多维模型。
- 第 5 章，使用 Microsoft 自助式商业智能工具，向读者介绍 SQL Server 2012 商业智能套件中提供的丰富的自助式 BI 工具集。本章解释了如何通过几次鼠标点击快速轻松地构建针对 Hadoop 数据强大的可视化功能。

## 阅读本书所需条件

以下是运行本书示例的软件先决条件：

- 配置了 Hive 0.9 的 Apache Hadoop 1.0 集群
- 安装了集成服务（Integration Services）和分析服务（Analysis Services）的 SQL Server 2012
- Microsoft Office 2013

## 本书适合谁

本书适合熟悉 Hadoop 及其支持技术，并愿意将其技能与 Microsoft SQL Server 2012 商业智能套件进行交叉融合的读者。读者将学习如何在这两个生态系统之间集成数据，以便在可视化数据时提供更有意义的洞察。本书还让读者一窥 SQL Server 和 Excel 中可用的自助式 BI 工具，以及如何利用它们在几次点击内生成强大的数据可视化。

## 1. 大数据和 Hadoop 简介

突然之间，大数据成为了热门话题。从大型企业级到小型初创公司，每家公司都为大�据提供了资金。过去几年中，存储和硬件成本大幅降低，使企业能够存储和分析数据，而之前这些数据由于存储和处理挑战而被丢弃。就数据世界而言，从未有像现在这样令人兴奋的时代。我们看到显著趋势的融合正在从根本上改变行业，并在社交、移动、高级分析和机器学习等领域开启了技术创新的新纪元。我们正在目睹数据爆炸，其中我们试图从中获取洞察的数据种类具有全新的规模和范围。在本章中，我们将深入了解什么是大数据，以及在实施大数据解决方案时 Apache Hadoop 框架如何在其中发挥作用。阅读完本章后，你将能够理解：

- 什么是大数据，为什么是现在
- 对大数据的业务需求
- Apache Hadoop 框架

### 大数据 – 有什么大不了的？

关于大数据有很多讨论——估计世界上数字信息的总量每五年增长十倍，其中 85% 的数据来自新的数据类型，例如传感器、RFID、Web 日志等。这为那些利用这些新数据来识别新机遇和创新领域的企业提供了巨大的机会。
