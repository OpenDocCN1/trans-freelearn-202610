# Installing the SQL Server-Hadoop Connector

The following steps need to be performed in order to install SQL Server-Hadoop Connector:

+   1. Log in to your cluster NameNode using a user credential, which has the permission to install files.
+   2. Extract the archive with the command: `tar -zxvf sqoop-sqlserver-1.0.tar.gz`. This will create `sqoop-sqlserver-1.0` directory in the present working directory.
+   3. Ensure that the `MSSQL_CONNECTOR_HOME` environment variable is set to the absolute path of the `sqoop-sqlserver-1.0` directory.
+   4. Change directory (cd) to the `sqoop-sqlserver-1.0` and run the shell script `install.sh` without any additional arguments.
+   5. Installer will copy the connector jar and configuration files under existing Sqoop installation directory.

# The Sqoop import tool

You're now ready to use SQL Server-Hadoop Connector and import data from SQL Server 2012 to HDFS. The input to the import process is a SQL Server table, which will be read row-by-row into HDFS by Sqoop. The output of this import process is a set of files containing a copy of the imported table. Since the import process is performed in parallel, the output will be in multiple files.
