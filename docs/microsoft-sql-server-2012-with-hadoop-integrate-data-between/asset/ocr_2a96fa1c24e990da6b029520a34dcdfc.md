The driver comes in two flavors, 64 bit and 32 bit, so please make sure that you download and install the appropriate driver depending upon the bit configuration of your client application. In my case, since I am going to use the driver from 32 bit applications as Visual Studio, I have used the 32 bit flavor of the driver. Once, installation of the driver is complete, you can confirm the installation status by checking if you have the Hive ODBC driver present in the ODBC Data Administrator's list of drivers as shown in the following screenshot:

![](bbox=[0.215, 0.268, 0.785, 0.635])

In case you are on 64 bit Windows and you are using a 32 bit ODBC driver, you have to launch the ODBC Data Source Administrator from C:\Windows\SysWow64\odbcad32.exe.
