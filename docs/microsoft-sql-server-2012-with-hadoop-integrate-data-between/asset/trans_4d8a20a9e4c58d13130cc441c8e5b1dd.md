

## HDFS

Hadoop 分布式文件系统是对主机操作系统文件系统的程序级抽象。它负责在集群上存储数据。数据被拆分为块并分布在集群中的多个节点上。

## MapReduce

MapReduce 是一种用于使用计算机集群上的分布式计算处理大型数据集的编程模型。MapReduce 包含两个阶段：将数据划分为大量独立的处理单元（称为 Map），然后将这些独立进程产生的结果合并为统一的结果集（称为 Reduce）。在 Map 和 Reduce 之间，会发生 shuffle 和 sort。Hadoop 集群在系统上成功配置后，具有以下基本组件：

## NameNode

这也称为集群的 Head Node/主节点。主要来说，它在处理分布在各节点上的数据期间保存 HDFS 的元数据；它跟踪节点中每个 HDFS 数据块。

> NameNode 是 Hadoop 集群中的单点故障。

## Secondary NameNode

这是一个可选的节点，你可以在集群中拥有它以在 NameNode 宕机时备份 NameNode。如果配置了 Secondary NameNode，它会定期保存 NameNode 配置的快照，以便在需要时作为备份使用。然而，切换到 Secondary NameNode 并没有自动方式；如果主 NameNode 宕机，需要人工干预。这本质上意味着如果 NameNode 宕机，你的集群会出现明显的停机时间。

## DataNode

这些是集群中存储实际 HDFS 数据块的系统。数据块在多个节点上进行复制，以提供容错和高可用性解决方案。

## JobTracker

这是在 NameNode 上运行的服务，用于管理 MapReduce 作业并分发各个任务。

## TaskTracker

这是在 DataNodes 上运行的服务，用于实例化并监控提交的各个 Map 和 Reduce 任务。

此外，还有许多 Hadoop 的支持项目，每个项目都有其独特的目的，例如，向 Hadoop 系统提供输入数据、用于在 Hadoop 之上进行即席查询的数据仓库系统等等。以下是一些值得提及的项目：

## Hive

Hive 是主 Apache Hadoop 项目的支持项目，是 MapReduce 之上的抽象，它允许用户在不开发 MapReduce 应用程序的情况下查询数据。它为用户提供了一种类 SQL 的查询语言，称为 Hive 查询语言（HQL），用于从 Hive 存储中获取数据。这使得具有 SQL 技能的人更容易快速适应 Hadoop 环境。

## Pig

Pig 是 MapReduce 的另一种抽象，使用名为 PigLatin 的数据流脚本语言。这受到了已有脚本技能的程序员的青睐。你可以在名为 Grunt 的命令行 Pig shell 中交互式运行 PigLatin 语句。你也可以将一系列 PigLatin 语句组合成脚本，然后作为一个单元执行。这些 PigLatin 语句由 Pig 解释器用于生成 MapReduce 作业，并在 HDFS 数据上执行。

## Flume

Flume 是 Hadoop 之上的另一个开源实现，它为数据在生成时进入 HDFS 提供数据摄取机制。

## Sqoop

Sqoop 提供了将数据导入和导出到关系数据库表（例如 SQL Server）和 HDFS 的方法。

## Oozie

Oozie 允许创建 MapReduce 作业的工作流。这对从事工作流和通信基础解决方案的开发人员来说很熟悉。

## HBase

HBase 是 Hadoop 数据库，一种 NoSQL 数据库。它是 Hadoop 之上的另一种抽象，提供了对 HDFS 数据的近实时查询机制。

## Mahout

Mahout 是一个机器学习库，包含聚类和分类算法。机器学习研究的一个主要重点是自动学习识别复杂模式并基于数据做出智能决策。

## 使用 Sqoop – SQL Server Hadoop 连接器

**Sqoop** 是一个开源 Apache 项目，可促进 Hadoop 与任何传统 **关系数据库管理系统（RDBMS）** 之间的数据交换。它在内部使用 MapReduce 框架执行导入/导出操作，并且通常是集成关系和非关系数据存储的常见选择。

Microsoft SQL Server Connector for Apache Hadoop（SQL Server-Hadoop 连接器）是一个基于 Sqoop 的连接器，专门为 SQL Server 与 Hadoop 之间高效的数据传输而设计。该连接器针对双向批量数据传输进行了优化，不支持在导入或导出时对数据进行广泛的格式化或转换。阅读本章后，你将能够：

- 安装和配置 Sqoop 连接器
- 从 SQL Server 导入数据到 Hadoop
- 从 Hadoop 导出数据到 SQL Server
