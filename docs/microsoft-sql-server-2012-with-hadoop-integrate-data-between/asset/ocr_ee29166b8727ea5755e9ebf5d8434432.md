You can use the OpenQuery Transact-SQL command to connect to the data source, run the query on the Hadoop cluster, and return the results to SQL Server.

# # Using OpenQuery

The following Transact-SQL script illustrates how to query the `facebooksights` Hive table we created earlier using the SQL Linked Server:

```
SELECT * FROM OpenQuery([LINKTOHIVE], 'SELECT * FROM facebooksights;')
```

So prior to jumping in to the Business Intelligence project, we would create a view in our SQL database based on the Linked Server query.

# ## Creating a view

The following Transact-SQL creates the view from the `OpenQuery` statement we used previously:

```
Create View KeyMetrics AS  SELECT * FROM OpenQuery([LINKTOHIVE], 'SELECT * FROM facebooksights;')
```
