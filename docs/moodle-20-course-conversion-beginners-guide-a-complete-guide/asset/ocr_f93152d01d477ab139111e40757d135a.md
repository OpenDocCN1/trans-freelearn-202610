# Adding students to groups

This can be achieved in two ways:

+   - I manually add students to the group
+   - The students enroll on the course and automatically join their group

Let's look at the first of these now.

# Time for action – manually adding students to a group

+   1. Return to the course front page and select Groups from the Administration block.
+   2. Click on the name of the group you want to add members to and press the Show members for group button.
+   3. Press the Add/remove users button.
+   4. Select the users you want to add into the group (you can select more than one at a time) and press the Add button:
