# Time for action – converting a crossword to Moodle

1. First, create your crossword with JCross:

![](bbox=[0.176, 0.212, 0.826, 0.618])

2. We next need to export the crossword as a SCORM activity. From the JCross main menu select File then slide down to Create Scorm 1.2 Package.

3. Back in your Moodle course, in the correct week I need to click on the Add an activity... drop-down and select SCORM package.
