# What just happened?

We've just created a new group, albeit so far with no one in it. As with most things in Moodle you aren't committing yourself when you specify configuration settings. When configuring groups there are usually two settings that I return to once the group has some members:

+   - I start leaving the group description blank and then ask the group, when they first get together, how they would like to describe themselves. If the course is converted to be entirely online then we'll either have a chat or (more usually) I'll start a forum discussion.
