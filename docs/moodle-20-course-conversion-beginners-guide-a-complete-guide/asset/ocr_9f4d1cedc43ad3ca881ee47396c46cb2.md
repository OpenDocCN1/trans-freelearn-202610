# Editing a wiki page

The page we have been presented with is basically the first page of the wiki. All pages will be linked from this "front page", as it were. Therefore, it is sometimes best to think of this initial page as a contents page, and perhaps even structure it as such. How do you edit it? Simply type in the text you want using the Editor in the usual way.

> Remember that because we are using the Moodle Editor to edit wiki pages, you can make wiki pages engaging and entertaining by using the skills and experience you have gained as you have been working through this book.
