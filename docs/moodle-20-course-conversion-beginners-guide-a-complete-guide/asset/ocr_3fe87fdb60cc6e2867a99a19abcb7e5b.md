I've just restructured my course gradebook to include two categories, "Marks for practical" and "Marks for Moodle Activities". # Have a go hero – including custom outcomes

Not only can you add in custom grades but you can also include custom outcomes; vital if you are converting a course that judges student achievement using attainment targets or learning descriptors.

> Hint on including custom outcomes
> Before you start specifying attainment targets in your gradebook you will need to create custom scales. Check out Chapter 6, Managing Student Work for details.

Return to the Edit categories and items page. Press the Add outcome item button. See if you can add a custom outcome to your gradebook. Remember that you will need to create and configure a custom outcome before you start.

# Backup and Restore

We are nearly at the end of our journey together and the very last thing I want to happen now is that you lose all of your work (and mine!). Return to your course front page and look down the options in the Settings block under Course administration. Two options listed are Backup and Restore. Choose Backup (we'll look at restoring shortly) and let's get all the hard work we've done so far backed up; it's better to be safe than sorry.
