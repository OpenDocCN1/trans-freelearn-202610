# 关于作者

**Ian Wild** 是在线学习领域公认的权威，尤其在 Moodle 方面。在私营行业工作的十五年里——主要担任通信技术研究员——Ian 最终专注于为盲人、视障、诵读困难和计算障碍的计算机用户设计和开发无障碍辅助与学习辅助工具，同时兼职担任数学和科学辅导老师。由于只是兼职教学，他与学生相处的时间无法达到自己所希望的程度。这一点，再加上他在通信技术方面的背景，激发了他对虚拟学习环境的长期兴趣。

Ian 是 Heavy Horse Limited（`http://www.heavy-horse.co.uk`）的创始合伙人之一，这家技术公司定期为英格兰和威尔士各地的客户提供电子学习平台开发和部署方面的咨询。

Ian 是同样由 Packt Publishing 出版的《*Moodle 1.9 数学*》一书的作者。他还担任过《*Moodle 1.9 多媒体*》和《*使用 Moodle 2.0 进行科学教学*》的技术审校。

我衷心希望这本书对您有所帮助，就像我撰写它时一样乐在其中。我必须特别感谢我的朋友、同事和家人在我编写这第二版期间所给予的耐心。你们的帮助和支持弥足珍贵。感谢大家。
