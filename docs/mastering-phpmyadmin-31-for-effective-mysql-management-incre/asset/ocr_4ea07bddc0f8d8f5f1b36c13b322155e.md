# Multi-row editing

The multi-row edit feature enables us to use checkboxes on the rows we want to edit, and use the Edit link (or the pencil-shaped icon) in the With selected menu. The Check All / Uncheck All links can also be used to quickly check or uncheck all the boxes. We can also click anywhere on the row's data to activate the corresponding checkbox.

![](bbox=[0.23, 0.44, 0.77, 0.54])

This brings up an Edit panel containing all the chosen rows. The editing process may continue while the data from these rows is seen, compared, and changed.

> When we mark some rows with the checkboxes, we can also perform two other actions on them—delete (see the Deleting Many Rows section in this chapter) and export (see Chapter 7).
