# PDF

Since version 2.8.0, it's possible to create a PDF report of a table by exporting in PDF. This feature works on only one table at a time, and we must click the **Save as file** checkbox for normal operation. We can add a title for this report, and it also gets automatically paginated. In versions 2.8.0 to 2.8.2, this export format does not support non-textual (BLOB) data as in the book table. If we try it in this table, it will produce the wrong results.

# Microsoft Excel 2000

This export format directly produces an .x1s file suitable for all software that understand the Excel 2000 format. We can specify which string should replace a NULL value. The **Put field names in the first row** option, when activated, generates the table's column names as the first line of the spreadsheet. Again, the **Save as file** checkbox should be checked. This produces a file, where each table's column becomes a spreadsheet column.
