# Changing repository data

In case the MIME type for the uploaded data was not interpreted correctly, it's possible to modify it by clicking this link and typing in the correct type. Note that this feature is a work in progress in version 3.1.1.

Finally, when editing this row, we'll see a **Remove BLOB Repository Reference** option. Putting a check mark on this option and saving the row tells the PBMS engine to forget about this reference, eventually eliminating the BLOB data from the repository.

# Summary

MySQL 5.0's new features helped the product comply with standards. Even though phpMyAdmin has limited support for these features (especially lacking a syntax-oriented editor), it has a basic set of features to work with views, routines, triggers and information_schema, and to display profiling information. phpMyAdmin also supports MySQL 5.1 partitions and events, the PBXT storage engine, and BLOB streaming.
