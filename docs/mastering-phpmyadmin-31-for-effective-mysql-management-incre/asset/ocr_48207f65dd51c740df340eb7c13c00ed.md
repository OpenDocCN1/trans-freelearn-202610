# FULLTEXT Indexes

This special type of index allows for fulltext searches. It is supported only on MyISAM tables for the VARCHAR and TEXT fields. We can use the Fulltext quick link in the fields list or go to the index management panel and choose Fulltext in the drop-down menu.

![](bbox=[0.44, 0.73, 0.56, 0.77])

We add a FULLTEXT index on the description field, so that we are able to locate a book from words present in its description.
