# Exporting for PDF schema

In Chapter 15, we'll see how to produce a PDF schema for a subset of our database. We can import the co-ordinates of tables from such a schema into the Designer's workspace, and conversely export them to the PDF schema. The Import/export coordinates top icon is available for that purpose.
