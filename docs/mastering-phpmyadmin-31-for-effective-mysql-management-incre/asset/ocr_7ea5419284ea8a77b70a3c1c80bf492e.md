# Summary

This chapter covers how to install the necessary infrastructure for keeping special metadata (data about tables), and how to define relations between both InnoDB and non-InnoDB tables. It also examines the modified behavior of phpMyAdmin (when relations are present) and foreign keys. Finally, it covers the Designer feature, column-commenting, and how to obtain information from the table. Chapter 12 will cover the means of entering SQL commands, which are useful when the phpMyAdmin's interface is not sufficient to accomplish what we need.
