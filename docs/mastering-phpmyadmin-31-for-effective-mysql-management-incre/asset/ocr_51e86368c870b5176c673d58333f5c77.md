# Deleting all the rows in a table

To completely erase all the rows in a table (leaving its structure intact), we go to the Database view and click on the database name in the left panel. We then click on the trash can icon located on the same line as the table we want to empty:

![](bbox=[0.17, 0.43, 0.83, 0.53])

We get a message confirming the TRUNCATE statement (the MySQL statement used to quickly empty a table). For our exercise, we won't delete this precious data!

Emptying a table can also be done in Table view with the Empty link located on the top menu:

![](bbox=[0.17, 0.64, 0.83, 0.68])

> Deleting data, either row-by-row or by emptying a table, is a permanent action. No recovery is then possible except by using a backup.
