# Executing bookmarks by browsing the pma_bookmark table

This feature is available only to users who can directly see the pma_bookmark table. This is the default name given when the linked-tables infrastructure is installed. In a multi-user installation, this table is usually located in a database invisible to unprivileged users. Browsing this table displays a new Execute bookmarked query button, which triggers the execution of the query:

![](bbox=[0.175, 0.285, 0.825, 0.455])

We can now click the pencil icon to open the Edit page for a specific row to see the query's complete text.
