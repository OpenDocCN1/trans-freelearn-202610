# Search criteria by field—query by example

The main use of the Search panel is to enter criteria for some fields so as to retrieve only the data we are interested in. This is called query by example because we give an example of what we are looking for. Our first retrieval will concern finding the book with ISBN 1-234567-89-0. We simply enter this value in the isbn box and choose the Operator '='.
