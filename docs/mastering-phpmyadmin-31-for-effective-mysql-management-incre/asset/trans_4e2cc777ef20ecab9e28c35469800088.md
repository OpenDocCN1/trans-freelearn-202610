## PDF 中的关系模式

在第 11 章中，我们定义了 book 表和 author 表之间的关系。这些关系用于各种外键功能（例如，在插入模式下获取可能值的列表）。现在我们将研究一个功能，该功能使我们能够以流行的 PDF 格式为我们的表生成自定义关系模式。该功能要求已正确安装和配置链接表基础设施，如第 11 章所述。

## 向模型添加第三个表

为了获得更完整的模式，我们现在将向数据库中添加另一个表 country。以下是其导出文件：

```sql
CREATE TABLE IF NOT EXISTS `country` (
  `code` char(2) NOT NULL,
  `description` varchar(50) NOT NULL,
  PRIMARY KEY (`code`)
) ENGINE=MyISAM DEFAULT CHARSET=latin1;

INSERT INTO `country` (`code`, `description`) VALUES
('ca', 'Canada'),
('uk', 'United Kingdom');
```

我们现在将此表链接到 author 表。首先，在 country 表的关系视图中，我们指定要显示的字段。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_254_0.png)

然后，我们在 **作者** 表中添加一个 **国家代码** 列（类型和大小与 **国家** 表的 code 列相同），并在 **关系视图** 中将其链接到新创建的 **国家** 表。我们必须记住点击 **保存** 才能记录该关系。对于本示例，无需为作者输入任何国家数据，因为我们只关注关系模式。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_255_0.png)

## 编辑 PDF 页面

每个关系模式称为一个 **页面**。我们可以通过在 **数据库视图** 的 **操作** 子页面中点击 **编辑 PDF 页面** 来创建或编辑页面。

## 页面规划

在 phpMyAdmin 3.1.x 版本中，关系模式不能跨多个数据库。但即使只使用一个数据库，表的数量也可能很大。以清晰的方式表示各种表关系可能具有挑战性。这就是为什么我们可能会使用多个页面，每个页面显示一些表及其关系。

我们还必须考虑最终输出的尺寸。在信纸大小的纸张上打印会减少显示所有表并仍保持可读模式的空间。

## 创建新页面

由于没有现有页面，我们需要创建一个。由于我们的最重要的表是 book，我们也将此页面命名为 **book**。

我们将选择希望在关系模式中看到的表。我们可以逐个选择每个表。然而，为了良好开端，建议勾选相应的 **自动布局** 复选框。这样做会将数据库中的所有相关表放入要包含在模式中的表列表中。然后它会生成适当的坐标，以便表以螺旋布局出现，从模式中心开始。这些坐标以毫米为单位表示，其中 (0, 0) 位于左上角。然后我们点击 **Go.**。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_256_0.png)

## 编辑页面

现在我们得到一个包含三个不同部分的页面。第一个是主菜单，我们可以在其中选择要工作的页面（从下拉菜单中选择）。我们也可以删除所选页面。我们最终也可以创建第二个模式（页面）。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_256_1.png)

下一部分是表放置部分。我们现在可以看到 **自动布局** 功能的好处——我们已经选择了三个表，并填入了 (X, Y) 坐标。我们可以添加一个表（在最后一行），删除一个表（使用复选框），并更改坐标（表示每个表在模式上的左上角位置）。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_257_0.png)

为了帮助设置精确坐标，JavaScript 启用的浏览器提供了一个可视编辑器。为了控制此编辑器的可用性，以下参数（默认设置为 TRUE）可用：

```
$cfg['WYSIWYG-PDF'] = TRUE;
```

编辑器在点击 Toggle scratchboard 按钮一次时出现，再次点击该按钮时消失。我们可以通过“拖放”在草稿板上移动表，坐标会相应更改。草稿板上表的显示为最终 PDF 输出提供了大致指导。有些人更喜欢在草稿板上只看到表名（不带每个列名）。这可以通过取消勾选 Column names 复选框并点击 Save 来实现。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_257_1.png)

> 当我们对布局满意时，必须点击 **保存**。

## 显示页面

屏幕的最后一部分是 PDF 报告生成对话框。现在我们创建了页面，**显示 PDF 模式** 也可在数据库视图的 **操作** 子页面中使用。我们将从 Operations 页面查看此对话框，因为该页面的选项集更完整。

![](img/cb8c75b631b4e1f7afe5a0d39becfda9_258_0.png)

可用选项如下：

- **显示网格**：模式将具有显示坐标的网格层。
- **显示颜色**：表之间的链接、表名和特殊列（主键和显示字段）将以颜色显示。
- **显示表的尺寸**：表标题中每个表的视觉尺寸（例如 32x30）将显示。
- **以相同宽度显示所有表**：所有表将使用相同的宽度显示。（通常，宽度会根据表的长度和列名自动调整。）
- **数据字典**：本章前面介绍过的数据字典将包含在报告开头。
- **仅显示键**：不显示未定义索引的列。
- **数据字典格式**：在此选择字典的打印方向。
- **纸张大小**：更改此项会影响模式和草稿板尺寸。

在 config.inc.php 中，以下参数定义了可用的纸张尺寸和默认选择：

```php
$cfg['PDFPageSizes'] = array('A3', 'A4', 'A5', 'letter', 'legal');
$cfg['PDFDefaultPageSize'] = 'A4';
```

以下截图显示了生成的报告的最后一页（模式页）在 PDF 格式中的样子。前四页包含数据字典，并具有附加功能。在每一页中，都可以通过点击表名到达模式，而在模式中，可以通过点击相应表到达数据字典中的每一页。

箭头指向相应的外表。如果选择了 Show color，主键以灰色显示，显示字段以黑色显示。
