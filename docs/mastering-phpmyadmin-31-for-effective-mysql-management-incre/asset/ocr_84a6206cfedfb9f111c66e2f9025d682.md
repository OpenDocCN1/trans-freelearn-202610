The MySQL documentation explains valid characters for the table and field names (if we search for Legal names). This may vary depending on the MySQL version. Usually, any character that is allowed in a file name (except the dot and the slash) is acceptable in a table name, and the length of the name must not exceed 64 characters. The 64-character limit exists for field names as well, but we can use any character.

We enter our field names under the Field column. Each field has a type, and the most commonly used types are located at the beginning of the drop-down list.
