# Non-standard-conforming queries

Let's try another query, which works correctly in MySQL: SELECT * FROM book WHERE language = 'en'. Sending it to the Validator produces the following report:

![](bbox=[0.185, 0.215, 0.815, 0.535])

Each time the Validator finds a problem, it adds a message such as {error: 1} at the point of the error and adds a footnote in the report. This time, the language column name is non-standard. Hence, the Validator tells us that it was expecting an identifier at this point. Another non-standard error is reported about the use of a LIMIT clause, which was added to the query by phpMyAdmin.
