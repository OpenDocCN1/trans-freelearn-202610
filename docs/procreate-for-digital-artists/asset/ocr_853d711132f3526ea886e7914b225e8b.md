# Using reference images for inspiration

To create realistic scenery, using reference images can greatly help in bringing your ideas to life on canvas. Don't feel discouraged about relying on references – they're an excellent learning tool for illustrators to improve their drawing skills. Observing real-life objects and surroundings helps us better understand details and techniques. References are also particularly useful for mastering lighting, as well as improving composition and atmosphere in your background illustrations. In this walkthrough, we'll focus on using reference images to guide the creation of sketches and base colors for background artwork.
