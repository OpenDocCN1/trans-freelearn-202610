# Using light and shadow to illustrate a bright afternoon scene

To create a bright afternoon scene, we need to focus on the placement of the light source and the intensity of the sunlight. Generally, the light source will be coming from upper and higher angles from the objects. We will have to use bright highlights for the lighting, but we must make sure we do not overdo it, as it will overshadow the main subject or focal point of the illustration. By following this walkthrough, we can learn how to maintain balanced lighting for an afternoon atmosphere and successfully illustrate a background scene.

# Following the steps

+   1. Sketch out a background drawing and prepare an afternoon color palette.
