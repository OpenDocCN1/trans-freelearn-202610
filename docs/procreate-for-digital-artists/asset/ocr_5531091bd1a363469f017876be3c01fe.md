# Getting started with background composition

Composition in art means arranging subjects in an illustration to make it look balanced and lively. This can be achieved by understanding how to place objects, colors, and textures in a way that guides the viewer’s eyes, creates feelings, and shares a message. By focusing on these elements, we can make artwork that connects with people. However, as artists, we often struggle to create good compositions for background illustration. In this walkthrough, we’ll learn about depth composition techniques to help us in creating a well-balanced and eye-catching background illustration.
