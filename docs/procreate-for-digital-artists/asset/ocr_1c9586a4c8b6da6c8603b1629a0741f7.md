# Mastering lighting and shading in the easiest way

The easiest way to master lighting and shading is by using blending modes such as **Add**, **Multiply**, and **Soft Light**. The **Add** blending mode can be used for lighting while **Multiply** can be used for shading purposes. The **Screen** blending mode can be used for adding reflected light. Usually, we will encounter a problem where we are unsure how to add the shadow and what colors we will need to use. By using this technique, we can easily add lighting, shadow, and reflected light to our drawing.
