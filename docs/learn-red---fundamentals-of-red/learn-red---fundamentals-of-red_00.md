# 前言
本书介绍 Red 编程语言和环境。它强调其特定特性，例如紧凑性和全栈能力。Red 与其他语言不同。它以不同的方式对待编程，也许没有大多数主流语言中你所期望的那些花哨的东西。相反，它为你提供了更好的思考工具和完成工作的工具。本书将帮助你快速上手这项新的令人振奋的技术。
本书已准备好 0.6.4 版本。所有代码示例均在此版本下测试通过。
## 本书适合谁
本书面向希望学习 Red 的软件开发人员和架构师，因为它简洁、灵活、表达力强，更具体地说，是其在 GUI 应用和区块链/智能合约编程方面的可能性。假设读者具备基本概念的知识和任何编程语言的经验。
## 本书涵盖内容
第 1 章, *Red 的使命*, 讨论了 Red 的主要特性，并激励读者踏上他们的 Red 之旅。
第 2 章, *设置开发环境*, 教导读者如何在系统上安装 Red 并开始使用 Red 控制台以及在开发环境中使用代码文件。
第 3 章, *使用单词、值和类型*, 介绍了 Red 程序的基本构建块——单词和值。我们讨论了 Red 中可用的不同类型。
第 4 章, *代码控制结构*, 重点介绍块、值和单词如何通过条件、循环结构和选择进行求值。本章还向您展示如何在 Red 中进行错误处理。我们通过开发一个猜数字游戏在整章中对此进行说明。
第 5 章, *使用序列和块*, 帮助您理解块和序列构成了 Red 代码的基础。在 Red 中开发主要意味着使用块，因此我们将学习这一点。
第 6 章, *使用函数和对象,* 讨论如何使用函数和对象使代码更紧凑、更易读。



第 7 章, *使用文件*, 帮助你学习如何将文件用作数据存储。我们将研究读写文件，无论是数据文件还是代码文件。我们将通过一个持续的示例来展开这一主题，即下载货币汇率*.*

第 8 章, *解析数据*, 探索了一种名为 `parse` 的首个 Red 方言，其专门用于分析数据流。我们将其应用于从之前存储的汇率中获取有意义的信息。

第 9 章, *构建视觉界面*, 介绍了第二种 Red 方言，用于构建跨平台图形用户界面。它基于 第 5 章, *使用序列和块*, 以及 第 7 章, *使用文件*, 来为我们的汇率下载构建一个视觉前端，我们还将开发一个基本联系人数据存储应用。

第 10 章, *高级 Red*, 探讨了使用响应式编程构建高度响应式应用的强大功能。你将对这一切的基础层有所了解，即 `Red/System`。此外，你将了解如何与操作系统交互并使用一些高性能数据类型。此外，还讨论了 Red 在区块链编程世界中的未来。最后，我们讨论了我们面前的前景，并提供一些提示以加深读者的 Red 知识。

# 使用的约定

本书在全文中使用了多种文本约定。

`CodeInText`: 表示文本中的代码词、数据库表名、文件夹名、文件名、文件扩展名、路径名、虚拟 URL、用户输入和 Twitter 句柄。以下是一个示例："控制台可执行文件构建在 `/home/user/.red` 文件夹内，名称格式为 `console-yyyy-m-dd-nnnnn`。"

代码块设置如下：

```
Red [
    Name-Of-Info: "Value of Info"
    Name-Of-Info2: "Value of Info2" 
    ...
]
```

当我们希望引起你对代码块中特定部分的注意时，相关行或项目会以粗体显示：

```
a: [1 2 3]
b: copy a
b ;== [1 2 3]
append a 4
a ;== [1 2 3 4]
b ;== [1 2 3]
```

你可以在每个部分附带的 codefile 中找到代码。每个代码片段的开头，你会看到：

```
;-- see ChapterNN/codefile.red:
```

这意味着该片段位于代码下载中的文件 `ChapterNN/codefile.red` 中（其中 NN 从 01 到 10），以及之后显示的代码片段，直到指示新的 codefile 为止。

在本书中，我们将 program、script、app 或 application 作为同义词使用，因为 Red 源文件可以被编译或解释。

我们在 `;==` 之后显示一段代码的返回值，如 `a: 5 ;== 5`，因为 `\==` 是 Red 控制台的显示方式，而前缀 `;` 使其在脚本中成为注释。

我们选择使所有程序在控制台中无需错误即可立即运行。然而，某些代码明确用于让你看到某些错误。这些代码用注释标出：`\*\*\* Script Error …`。只需删除该行开头的注释 (`;`) 符号即可使错误发生。

以 `#include` 开头的行也一样，只需取消注释即可编译程序。

任何命令行输入或输出都写成如下形式：

```
$ sudo apt-get update
```

**粗体**：表示新术语、重要单词或你在屏幕上看到的单词。例如，菜单或对话框中的单词在文本中以这种方式出现。以下是一个示例：

"从菜单中，打开 File | Run。"

警告或重要说明以这种方式出现。技巧以这种方式出现。
