
```
if error? try [4 < "abc"][
    print "Wrong input, enter an integer!"
    quit ; or: continue
]
```

我们也可以使用 `either error? try`：

```
either error? try [4 < "abc"][
    print "Wrong input, enter an integer!"
    quit ; or: continue
 ][
    ; everything ok, now we can proceed
 ]
```

你可以使用 `probe` 词来了解更多关于发生的错误的详细信息：

```
if error? err: try [4 < "abc"] [probe err]
```

这会产生以下输出，在调试时很有用：

```
make error! [
    code: 339
    type: 'script
    id: 'invalid-compare
    arg1: 4
    arg2: "abc"
    arg3: none
    near: none
    where: '<
    stack: 77629472
]
*** Script Error: cannot compare 4 with "abc"
*** Where: <
*** Stack: probe
```

# 创建和捕获错误

在可能发生运行时错误的情况下，你可以使用 `cause-error` 自己引发特定的错误。例如：

```
m: 10
if n = 0 [ cause-error 'math 'zero-divide [] ]
print m / n
```

当 `n` 为 `0` 时，这一行会生成 `*** Math Error: attempt to divide by zero`。当进入一个 `n` 参数可能为 `0` 的函数，并在函数中想对 `n` 进行除法时，这可能很有用。

请注意它需要字面词 `'math` 和 `'zero-divide`，描述错误的类型和名称；第三个参数是一个参数块，可以为空。除了 `cause-error` 之外，你也可以遇到 `make error! [math zero-divide]` 或甚至 `make error! 400`。它们的作用都一样——使用该名称或代码生成错误。

只有当你想让程序停止并显示错误信息时才使用 `cause-error`。

总之，为了在 Red 中正确处理错误，请一起使用 `try`、`if error?`、`cause-error` 和 `error!` 对象。

`catch - throw` 短语用于控制代码流程，正如本章的 `Catch and throw` 部分所见，而不是用于错误处理。

# 使用系列和块

正如你现在所知，Red 中几乎所有内容都写在 `[]` 内。这些表示块，它们是一种系列。块和系列构成了 Red 代码的基础；事实上，如果你查看 [第3章](#6609439d-2797-41d5-97e3-5b2efe61d4bb.xhtml) 中的类型层次结构，`Using Words, Values, and Types`，块也是一种 `series!` 类型。`series!` 类型除了块之外还包含许多其他常见类型，例如字符串、文件、二进制值、标签、电子邮件、图像等。这就是为什么用于块系列的函数和操作可以应用于其他类型的值。例如，字符串本质上是字符的系列，因此用于操作块系列的技术也可以用于字符串操作。

在本章中，我们将学习如何使用系列。我们将学习如何将系列视为具有头部和尾部以及移动索引的东西。我们将学习如何从系列中获取信息，如何遍历它、搜索、排序和更改它。这些操作是 Red 开发人员的核心工作，掌握系列的使用是获得 Red 熟练度的核心技能！

本章将涵盖以下主题：

* 导航和遍历系列
* 从系列获取信息

## 系列和块

让我们看一个例子。字母 `A B C D` 包含在块 `[A B C D]` 中。来自其他编程语言的人可能更习惯于 *lists* 或 *arrays* 这样的术语。这些与系列非常相似。在 Red 中，多维数组可以用嵌套块表示。如果你想要更正式的定义，我们可以说系列是 *一组有序的项目*，可以是值（数据）或词（代码）。在前面的例子中，项目是词 `A B` 等（它们不是字符串或字符），并且它们必须在程序运行时获得一个值。在 Red 中，你可以像操作数据一样轻松地操作代码。

=> 现在回答 `Questions` 部分的问题 1。

由于系列是有序的，其中的每个项目都可以通过一个数字来引用——它的 `index`。Red 中的索引从 `1` 开始计数，因此前面系列中索引为 `3` 的项目是 `C`。在字符串系列 `"Good dog!"` 中，索引 `4` 的项目是 `#"d"` 字符。还有 `empty series`，它没有任何元素——`[]` 或 `""`。
