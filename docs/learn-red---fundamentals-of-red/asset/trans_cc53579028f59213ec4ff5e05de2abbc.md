# 前言
本书介绍 Red 编程语言和环境。它强调其特定特性，例如紧凑性和全栈能力。Red 与其他语言不同。它以不同的方式对待编程，也许没有大多数主流语言中你所期望的那些花哨的东西。相反，它为你提供了更好的思考工具和完成工作的工具。本书将帮助你快速上手这项新的令人振奋的技术。
本书已准备好 0.6.4 版本。所有代码示例均在此版本下测试通过。
## 本书适合谁
本书面向希望学习 Red 的软件开发人员和架构师，因为它简洁、灵活、表达力强，更具体地说，是其在 GUI 应用和区块链/智能合约编程方面的可能性。假设读者具备基本概念的知识和任何编程语言的经验。
## 本书涵盖内容
[第 1 章](#b2834a1f-ebba-49f2-9d61-4bdfdf8a5702.xhtml), *Red 的使命*, 讨论了 Red 的主要特性，并激励读者踏上他们的 Red 之旅。
[第 2 章](#e7b0526e-a6dd-4c51-abc8-81b1dfdc8460.xhtml), *设置开发环境*, 教导读者如何在系统上安装 Red 并开始使用 Red 控制台以及在开发环境中使用代码文件。
[第 3 章](#6609439d-2797-41d5-97e3-5b2efe61d4bb.xhtml), *使用单词、值和类型*, 介绍了 Red 程序的基本构建块——单词和值。我们讨论了 Red 中可用的不同类型。
[第 4 章](#d6a19492-2244-47dc-a52e-64b113c7ce0a.xhtml), *代码控制结构*, 重点介绍块、值和单词如何通过条件、循环结构和选择进行求值。本章还向您展示如何在 Red 中进行错误处理。我们通过开发一个猜数字游戏在整章中对此进行说明。
[第 5 章](#35fe4037-dd49-406f-b90b-217052b1d33f.xhtml), *使用序列和块*, 帮助您理解块和序列构成了 Red 代码的基础。在 Red 中开发主要意味着使用块，因此我们将学习这一点。
[第 6 章](#5c76066d-61d4-4dbd-b5db-902ae9e9991c.xhtml), *使用函数和对象,* 讨论如何使用函数和对象使代码更紧凑、更易读。
