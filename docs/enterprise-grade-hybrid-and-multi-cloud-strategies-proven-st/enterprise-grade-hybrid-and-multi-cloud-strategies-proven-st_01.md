# 前言



在过去十年里，**云技术**已从仅仅另一种部署平台演变为数字颠覆的引擎。随着人工智能、增强现实、虚拟现实、边缘计算和量子计算等现代技术不断建立在云的敏捷性、可扩展性和弹性所奠定的基础之上，云已成为一个不可或缺的平台，不仅推动 IT 转型，也推动业务转型。拥抱云使企业能够更快创新、更高效地交付新能力，并在动态的全球市场中保持竞争优势。

企业规模的云采用是一段旅程，并可能带来诸多挑战，包括从何开始、识别合适的 workload 以及选择合适的云战略。有一些资源从目标云平台的角度提供了带有倾向性的云战略观点。本书旨在采取提供商和平台无关的视角，并将提出一套指导性框架、战略和最佳实践，帮助企业构建开放、敏捷且现代化的云就绪企业。

基于我在多个行业与多家企业在数字化转型项目中工作的丰富经验，本书将深入探讨云转型的各个方面，以及企业如何利用云作为推动创新和引领创新的工具。
