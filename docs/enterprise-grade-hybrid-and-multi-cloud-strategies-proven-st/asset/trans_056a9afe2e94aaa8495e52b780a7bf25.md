

*   **遵守数据主权和数据驻留要求**：根据企业性质，遵守当地法规以及数据驻留和数据主权要求至关重要。从头开始架构应用程序以满足合规要求，往往能节省大量时间和精力；例如，在面向公共部门的安全云区域中托管工作负载，并利用机密**虚拟机**（**VM**）防止内存数据泄露。
*   **补偿性控制**：在云端的共享责任模型下，组织应努力通过技术补偿性控制、合同保护和第三方认证来降低风险。例如，利用云原生安全控制对静态数据和传输中数据进行加密可作为一种技术补偿性控制，而**业务伙伴协议**（**BAA**）或**云数据处理附录**（**CDPA**）可作为合同保护 *\[6\]*。
*   **风险保护计划**：最后，企业还可以利用网络保险计划，更好地了解、修复风险，并实现高水平的安全态势。
*   **安全审计和评估**：定期开展渗透测试，以识别和解决网络基础设施中的漏洞。使用自动化漏洞扫描工具，定期评估云环境的安全态势。

## 自动化云资产管理

拥有准确的资产清单，并充分了解所有云资产及其关系，对企业安全至关重要。随着团队开始构建应用程序或将工作负载迁移到云端，资产管理可能迅速变得复杂且难以管控。使用**基础设施即代码**（**IaC**）工具（如 Terraform）自动化资产管理，有助于满足企业安全最佳实践。安全团队还必须专注于实施自动化资产监控和告警，以监控资产的不合规情况和偏离安全蓝图的行为。在混合云部署模型的背景下，企业还可以利用现有的**安全信息和事件管理**（**SIEM**）系统作为**单一视图**（**SPOG**），以管理和监控整个企业的资产。

## IAM

**IAM** 是保护企业资源的关键组件，特别是在多云和混合云环境中，资源分布在本地数据中心和云服务提供商（CSP）之间。实施有效的 IAM 实践有助于组织管理用户访问、保护敏感数据并确保合规。以下是一些 IAM 最佳实践：

*   **集中式身份管理（IdM）**：实施一个跨越本地和云环境的集中式 IdM 系统。这种集中化有助于简化用户预配、取消预配和访问管理流程，同时也能安全地集中管理身份。
*   **实施破玻璃应急程序**：云中的破玻璃应急程序是指一种紧急访问机制，在发生锁定等紧急情况时，授予临时的特权访问权限以访问云中的关键系统或数据。此程序通常保留用于高度敏感的操作，或在其他访问方法不可用时使用。它通过严格的安全控制来实施，以防止未经授权的使用。一旦激活，破玻璃应急程序允许指定人员绕过正常的访问限制，从而使他们能够快速解决关键问题或降低风险。
*   **通过单点登录（SSO）联合访问**：使用安全的联合协议，如**安全断言标记语言**（**SAML**）或**开放授权**（**OAuth**），实现本地和云环境之间的身份联合，允许用户一次性认证并无缝访问资源。
*   **启用 MFA**：强制要求访问关键系统和数据时使用 MFA。这增加了一层额外的安全保障，即使凭证泄露，也能降低未经授权访问的风险。
*   **保护超级管理员账户**：避免使用现有用户账户，为超级管理员访问创建新账户。确保破玻璃应急程序有完善的文档记录，启用 MFA，并结合物理安全令牌和备用账户使用。
*   **记录所有活动**：确保所有云活动均被记录并集成到集中式 SIEM 中。这也有助于审计访问并满足合规要求。
*   **实施最小权限原则（PoLP）**：过度授权用户访问权限通常是与云资源配置错误及内部威胁风险相关的首要安全风险。在整个组织中采用 PoLP 或**即时**（**JIT**）访问策略。实施针对特权访问的强有力控制，如会话录制和监控，可降低未经授权操作的风险。
*   **自动化策略控制**：利用云原生工具自动审查访问策略、权限和不必要的特权，以便及时将安全风险降至最低。

## 网络安全

将网络扩展到传统数据中心之外会对网络安全产生影响。本地网络通常具有明确、可预测的网络边界或边界，更容易通过网络防火墙、**入侵检测系统**（**IDS**）和物理路由器进行保护。确保强大的网络安全，特别是在混合云环境中，对于保护敏感数据、保持合规和防范网络威胁至关重要。保护混合云网络的一些最佳实践如下：

*   **分段和微分段**：将网络划分为多个段，以隔离不同类型的数据和服务。如果一个网段被攻破，这能限制攻击者的横向移动。实施微分段以应用细粒度的访问控制，特别是在多层应用程序中。这限制了各个工作负载之间的通信。
*   **致力于零信任网络**：零信任安全模型意味着默认不信任任何人，无论他们从何处访问网络，除非伴随其他层级的访问检查，如身份检查、上下文或受信任设备。
*   **保护跨云连接**：使用**虚拟专用网络**（**VPN**）或专用连接（如 Google Cloud Interconnect、AWS Direct Connect 或 Azure ExpressRoute）确保本地和云环境之间的安全连接。使用 TLS/SSL 等协议加密 Web 流量，使用 IPsec 加密站点到站点 VPN，以保护传输中的数据。
*   **保护云边界**：利用纵深防御（DiD）网络安全策略，在不同层级定义网络防火墙策略和规则，以允许或拒绝网络流量。
*   **自动化网络流量检查**：利用云原生工具，如云 IDS、基于 ML 的**下一代防火墙**（**NGFW**）、防火墙规则日志记录和流量镜像，来检查、监控和保护云中的工作负载。
*   **应用安全**：部署**Web 应用防火墙**（**WAF**）以保护 Web 应用免受常见安全威胁和漏洞的侵害。通过适当的身份验证、授权和加密来保护 API，防止未经授权的访问和数据泄露。
*   **网络监控和日志记录**：实施持续的网络监控，以及时发现异常和潜在安全事件。集中管理本地和云环境的日志，以全面了解网络活动。
*   **实施云访问安全代理（CASB）**：实施集中式 CASB 解决方案，特别是在混合云和多云部署中，以监控和管理云服务的使用，并确保合规和数据安全。
