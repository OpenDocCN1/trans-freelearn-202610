
在混合云环境中保护应用安全对于保护敏感数据、确保合规性以及维护业务运营的完整性至关重要。组织在云端开发应用时采用分层安全方法，并将安全实践**左移**，这至关重要。以下是在混合云或多云环境中应用安全的一些最佳实践：

- **实施安全应用开发最佳实践**：培训开发人员掌握安全编码实践，并利用自动化 DevOps 工具缓解应用代码中的常见漏洞，例如注入攻击、缓冲区溢出和**跨站脚本攻击**（**XSS**）。

- **使用安全加固的虚拟机或容器镜像**：强制执行策略，仅利用安全加固的虚拟机镜像和容器镜像进行应用开发和部署。利用云原生产品，如屏蔽虚拟机。

- **自动化应用发布**：由于复杂的应用开发环境错综复杂，手动部署、更新和修补它们非常困难，尤其是在遵循一致的安全要求时。自动化部署流水线可以消除人为错误、标准化开发反馈循环、实现快速产品迭代并保障应用发布安全。

- **实施 DevOps 安全**：特别是在云原生应用开发中，攻击者可能会破坏 CI/CD 流水线，从而影响整个技术栈。建立最佳实践，如二进制授权、保护制品或容器注册表、容器镜像漏洞扫描、加密容器镜像，以及在 CI/CD 流水线中进行签名验证。

- **补丁管理**：通过实施稳健的补丁管理流程，使所有应用组件、框架和库保持最新安全补丁。组织必须为补丁频率、优先级、漏洞扫描和测试程序制定明确准则，并实施自动化补丁管理工具以简化和加速部署流程。

- **依赖项扫描**：定期扫描第三方库和依赖项中的已知漏洞。解决并更新应用堆栈中的任何易受攻击组件。此外，建立流程验证第三方组件——尤其是开源组件——保持最新并符合企业安全标准。

- **实施动态应用安全测试 (DAST)**：使用 DAST 工具模拟真实攻击场景，并在运行时识别漏洞。

# 数据安全

云中数据安全的重要性怎么强调都不为过，因为组织越来越依赖云服务来存储、处理和管理其数据。实施强有力的安全措施以防范不断演变的威胁、确保合规性并维护数据信任，势在必行。以下是企业可采用的一些最佳实践，以保护混合云环境中的数据：

- **数据分类**：根据敏感度和法规要求对数据进行分类，并根据分类应用相应的安全措施。利用自动化工具在数据生命周期早期对数据进行分类和保护。

- **实施全面的数据治理**：数据治理是一系列流程的组合，确保数据被编目、保护、准确、可用且可获取。建立稳健的数据治理实践，包括数据管理性和数据生命周期管理。基于数据引力，实施数据治理最佳实践，如数据编目、自动元数据收集和企业数据质量检查，以识别和整理数据资产。

- **数据加密**：加密本地环境与云环境之间传输过程中的数据。实施专为数据分类设计的加密机制。例如，针对**联邦信息处理标准**（**FIPS**）140-2 3 级数据安全，利用**硬件安全模块**（**HSM**）进行密钥管理。

- **实施数据丢失防护 (DLP)**：部署 DLP 解决方案以监控、检测和防止未经授权的敏感数据访问和传输。实施数据掩码和遮盖技术以保护敏感信息，并使用令牌化用令牌替换敏感数据，降低处理和存储关键信息的相关风险。

- **备份和灾难恢复 (DR)**：实施关键数据的定期备份，并确保**灾难恢复计划**（**DRP**）包含数据恢复程序。纳入将任务关键型数据备份到不可变、版本控制、冗余存储中的程序，以缓解和防止勒索软件等攻击。

- **数据保留策略**：定义并强制执行数据保留策略，以确保定期清除不必要的数据，降低暴露风险。

- **使用密钥管理器管理机密**：集中采用密钥管理解决方案来存储和保护机密，如应用凭据、数据库密码、API 密钥、账号密钥和 TLS 证书。实施最佳实践，如自动密钥轮换策略。

# 数据主权和数据驻留

数据主权和数据驻留要求通常基于区域性和行业特定法规。不同组织可能有不同级别的要求。随着应用和数据跨越本地环境和云端，了解并管控数据如何以及在何处存储、访问和处理以符合法规要求非常重要。一些最佳实践包括：

- **确保数据主权**：对于有数据主权要求的企业，控制并防止云提供商访问数据至关重要。一些技术包括将加密密钥存储和管理在本地密钥管理器中、授予对密钥请求和访问的细粒度访问控制，以及保护使用中的数据。

- **管理运营主权**：在目标云环境中实施策略，如保障计划，以确保企业工作负载仅部署在特定区域和可用区，并根据地理位置和认证限制云人员访问，以符合法规。

- **管理软件主权**：软件主权是指无论目标环境如何，都能快速部署或迁移软件应用的能力。这是一项重要的 DevOps 实践和考量，以确保软件主权得以维持。

- **管理数据驻留**：数据驻留是指企业静态数据的存储位置。这包括确保数据仅在授权区域存储、备份和复制。
