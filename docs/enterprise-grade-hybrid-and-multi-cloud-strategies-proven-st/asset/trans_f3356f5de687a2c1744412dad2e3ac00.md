

如果以**国家标准与技术研究院**（**NIST**）维护的**国家漏洞数据库**（**NVD**）中所发布的**通用漏洞与暴露**（**CVE**）数量来衡量，我们会发现仅在过去 7 年中，CVE 数量就增长了惊人的 4.5 倍。根据数据，2016 年 NVD 平均每周发布约 100 个 CVE，而到 2023 年这一数字跃升至每周 450 个 CVE *\[2\]* *\[3\]*。

安全是每个人的事，对于现代企业而言尤其关键，因为随着云计算的普及，现代技术的获取已变得大众化。在网络威胁日益复杂化的时代，为企业构建安全优先的云架构是一项至关重要的任务。

企业在采用云计算时通常会遇到的一个共同挑战，是云引入的共享责任模型。清晰理解共享责任模型，对于保护云中的应用工作负载和数据安全极为重要。由于共享责任模型可能因每个**云服务提供商**（**CSP**）、服务模型以及所使用云服务的不同而各有独特定义，这一任务往往颇具挑战性。

在深入探讨安全控制之前，我们先回顾一下组织在云转型过程中面临的一些常见挑战。根据 *Pandemic 11* 报告，以下是组织在云安全方面面临的首要担忧 *\[4\]*：

1. 身份、凭据、访问和密钥管理不足
2. API 和接口不安全
3. 云配置错误以及变更控制不当
4. 缺乏云安全战略和架构
5. 软件开发实践不安全

除此之外，企业还面临以下由外部威胁向量进一步加剧的挑战：

- **云服务的持续变化**：由于云服务具有动态特性，新服务不断更新和发布，企业必须保持警惕。为了跟上步伐，组织必须建立相应的流程和安全控制，以对照基线安全配置进行验证和测试，从而满足不断变化的要求并保持合规。
- **利用多个服务层**：企业的工作负载通常跨越多种服务类型。这要求在兼顾整体工作负载安全需求的同时，对每种服务类型的安全控制进行统一和验证。例如，支付处理服务可能利用多种服务类型（计算基础设施、API 平台和支付网关 SaaS），同时需要满足**支付卡行业**（**PCI**）合规义务。
- **数据安全**：随着企业数据从本地环境扩展到云端，数据安全成为企业的一个关键决策点。根据监管要求和数据引力，安全组织必须确定数据加密密钥的管理位置，这一点至关重要。
- **外部威胁**：随着新的安全漏洞和**高级持续性威胁**（**APT**）持续增加，这可能构成重大挑战。例如，暴力破解/**分布式拒绝服务**（**DDoS**）攻击、恶意软件或勒索软件攻击，以及**中间人**（**MITM**）攻击，都可能成为企业必须防范的新攻击向量。

让我们探讨企业在构建云基础时必须考虑的一些基础安全原则。

## 基础安全原则

对希望利用云计算优势同时确保数据和应用程序安全的企业来说，构建安全的云环境极为关键。通过实施基础安全原则，组织可以建立稳固的安全态势，保护数据和应用程序，并与内外部利益相关者建立信任。让我们进一步了解这些原则：

- **着陆区设计**：云服务部署最基础的方面是着陆区设计。着陆区定义了组织云部署的基础方面，如组织策略、互联互通、资源管理、安全、网络以及**身份和访问管理**（**IAM**）。在组织开始在云上部署工作负载之前，健全的着陆区设计必不可少。同样重要的是，将着陆区设计模块化，并在考虑可扩展性和增长需求的前提下进行适配。
- **零信任架构（ZTA）**：云中的零信任安全是一种消除云环境内隐式信任的综合方法 *\[5\]*。零信任不假设网络内的用户或设备值得信赖，而是要求对所有访问请求进行持续验证和认证。这通过**多因素认证**（**MFA**）、最小权限访问和微隔离等机制实现。通过将访问限制在必要范围内，零信任最小化攻击面，从而降低入侵风险。
- **风险评估**：定期进行正式风险评估至关重要，以确保组织的安全要求既满足内部安全义务，也满足外部安全义务。这提供了风险摘要以及组织检测和应对安全威胁的能力。一些最佳实践包括利用**云安全联盟**（**CSA**）的**云控制矩阵**（**CCM**）和**互联网安全中心**（**CIS**）基准进行风险评估。
- **定义并采用安全蓝图**：自动化是跟上不断变化的安全态势的关键。安全组织的主要职责之一是为云中的一些常见部署定义安全蓝图。这些蓝图可以标准化企业资产部署，同时支持更快的部署和集中治理。
- **分层安全设计/左移安全策略**：企业必须采用分层的**纵深防御**（**DiD**）安全设计，利用应用程序或工作负载每一层的安全功能来限制攻击向量。另一种策略是在开发和部署阶段融入安全最佳实践；例如，测试应用程序代码中的安全问题、在部署期间扫描容器镜像、自动扫描以及检测配置错误和安全反模式。
- **自动化部署和安全监控**：通过自动化部署来消除手动部署活动中的人为错误，不仅能提高开发和部署速度，更重要的是能改善组织的安全态势。同样，投资自动化工具来扫描基础设施漏洞并自动化扫描**持续集成/持续部署**（**CI/CD**）管道，也是一项安全最佳实践。
- **用于安全自动化的机器学习（ML）**：机器学习在增强企业云安全方面发挥着关键作用，它为威胁检测、**事件响应**（**IR**）和整体风险管理提供了高级能力。随着云环境变得更加复杂、动态和互联，基于机器学习的安全自动化可以帮助实现高级威胁检测、**用户与实体行为分析**（**UEBA**）以及零日预测分析，并改善云中工作负载的整体安全性。
