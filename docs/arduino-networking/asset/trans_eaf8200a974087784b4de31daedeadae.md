现在，我们将修改界面，以便你可以使用 Web 浏览器从任何地方控制继电器。在 JavaScript 文件中，你需要定义你的 Teleduino API 密钥：

```javascript
var key = "yourAPIKey";
```

然后，我们需要修改命令参数以符合 Teleduino API，并同时提及密钥，如以下代码所示：

```javascript
window.onload = function() {
  $.get( "command.php", {
    key: key, command: "definePinMode&pin=7&mode=1"} );
}
```

另外，我们还需要为按钮点击时调用的函数修改命令参数并提及密钥：

```javascript
if (clicked_id == "1"){
  $.get( "command.php", {
    key: key, command: "setDigitalOutput&pin=7&output=1"} );
}
```

在 PHP 文件中，我们现在需要获取两个参数，即来自 Teleduino 的命令和 API 密钥：

```php
$key = $_GET['key'];
$command = $_GET['command'];
```

我们还需要修改服务 URL，如以下代码所示：

```php
$service_url = 'http://us01.proxy.teleduino.org/api/1.0/328.php?k=' . $key . '&r=' . $command;
$curl = curl_init($service_url);
```

其余文件与上一节中所示完全相同。

## 摘要

在本章中，我们将继电器与 Arduino 板和以太网扩展板连接起来，以便远程控制。为此，我们采用了两种不同的方法，各有优缺点。首先，我们保持本地化，并从本地网络内控制继电器。此解决方案的优点在于，即使你的互联网连接中断，项目仍可正常工作。

然后，我们使用专用 Web 服务从任何地方控制继电器。这显然是后一种方法的优势；但是，如果你的以太网扩展板未连接到互联网，则无法工作。

本章的主要收获如下：

- 首先，我们为项目选择了不同的组件，并将它们组装起来，以便可以从 Arduino 板控制设备（例如台灯）。
- 然后，我们编写了第一个草图来测试项目，只需简单地打开和关闭继电器。
- 随后，我们基于刚刚组装好的硬件构建了第一个应用程序。我们使用了一个专用库，以便 Arduino 板能够通过以太网扩展板从网络接收命令。我们还构建了一个简单的基于 Web 的界面，以便你可以从在计算机上运行的图形界面控制继电器。
- 最后，我们使用名为 Teleduino 的 Web 服务从世界任何地方控制继电器。我们还修改了图形界面，以便可以从任何地方控制继电器。

在下一章中，我们将采用另一种方法，使用以太网扩展板将 Arduino 项目连接到物联网。我们将在 Arduino 板上进行一些测量，并将这些数据直接发送到云服务。使用此服务，我们将能够实时监控来自板子的测量数据，无论身在世界哪个地方。

## 第 5 章。使用 Xively 实现物联网

在本书的前几章中，当使用以太网扩展板在 Arduino 板上进行测量时，我们主要保持本地化。例如，我们将一些测量数据发送回计算机上的数据库，并在那里显示测量结果。

在本章中，我们将采取不同的方法。我们将把以太网扩展板集成到物联网视角中。这意味着，我们将不再在本地网络内本地记录测量数据，而是自动将测量数据发送到名为 Xively 的云服务。Xively 网站的目的是存储来自你设备的数据，并在其网站上显示这些数据。这样，你的数据将随时可用，并可以从任何地方访问。

本章的主要收获如下：

- 首先，我们将围绕以太网扩展板和 DHT11 温湿度传感器构建本项目的硬件。
- 然后，我们将在 Xively 网站上创建一个帐户。我们还将配置此帐户，以便可以使用 Arduino 以太网扩展板将测量数据发送到该帐户。
- 当帐户正确设置后，我们将使用帐户信息（例如 Xively API 密钥）来构建本项目的 Arduino 草图。
- 最后，我们将草图上传到 Arduino 板并进行测试。我们将检查数据是否已正确发送到 Arduino 板，并在浏览器中实时可视化记录的数据。

## 硬件和软件要求

在硬件方面，你当然需要 Arduino 以太网扩展板和一个 Arduino 板（例如 Arduino Uno）。

你还需要一个传感器来测量一些数据。由于本书主要介绍如何使用以太网扩展板，而非如何从传感器进行测量，你可以选择任何传感器。

我选择了 DHT11 传感器，这是一种数字温湿度传感器。我选择这个传感器是因为它非常便宜且易于与 Arduino 连接。除了 DHT11 传感器外，你还需要一个 4.7k 欧姆电阻。

你还需要一个面包板和一些跳线，以便在传感器和以太网扩展板之间建立连接。

在软件方面，你首先需要的是用于与之前选择的传感器进行连接的库。由于我为本项目选择了 DHT11 传感器，你需要从 https://github.com/adafruit/DHT-sensor-library 下载并安装 DHT 库。

要安装 Arduino 库，只需将下载文件的内容解压到主 Arduino 文件夹的 libraries 文件夹中（如果该文件夹不存在，则创建它）。

在本项目中，你需要连接的唯一东西是 DHT11 传感器和电阻。你可以通过查看以下示意图来了解需要建立的不同连接的概览：
