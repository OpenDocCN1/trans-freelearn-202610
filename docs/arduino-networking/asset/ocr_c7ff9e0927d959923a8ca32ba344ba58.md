function will actually take the data as an argument and plot it with the options we defined before:

```
function onDataReceived(series) {
    var data = [];
    data.push(series);
    $.plot("#placeholder", data, options);
}
```

All this code is contained in the update() function, and this function is called continuously (every 10 milliseconds) so that the plot is always updated when a new data point comes in:

```
setTimeout(update, 10);
```

Finally, at the end of the script, we call this function once to get the graph started:

```
update();
```
