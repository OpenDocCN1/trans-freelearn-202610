## 前言

Arduino 是一个用于快速创建精彩电子项目的出色平台。使用 Arduino 平台，即使是非专家也可以将传感器、执行器和显示器连接在一起，构建为日常生活提供即时应用的复杂项目。

但是，当这些项目被连接起来时，效果会更好，也就是说，它们具有与其他设备通信的方式，而不一定是与其他 Arduino 板通信。有许多方法可以将 Arduino 项目彼此连接，并连接到计算机等其他设备：WiFi、XBee、Bluetooth 和 Ethernet。本书将完全专注于如何使用这项最新技术来创建连接 Arduino 项目的精彩项目。

与无线解决方案相比，使用 Ethernet 有几个优势：速度快、成本低，并且你可以在互联网上找到大量相关帮助。对我来说，最重要的是 Arduino 的 Ethernet 库文档非常完善，并且随 Arduino 软件内置。它的硬件对应物 Arduino Ethernet 扩展板也制作精良，并得到 Arduino 社区的良好支持。

在本书中，我们将通过六个精彩的项目来了解如何使用 Ethernet 扩展板和 Ethernet 库。我们将从最基础的内容开始，了解如何将 Ethernet 扩展板连接到你的本地网络和 Web。然后，我们将从 Ethernet 扩展板向你本地网络上的服务器发送数据。最后，我们将通过构建几个直接连接到 Web 的项目，将 Ethernet 扩展板集成到“物联网”框架中。

## 本书内容概述

第 1 章“探索 Arduino Ethernet 扩展板”介绍了 Arduino Ethernet 扩展板，向你展示如何设置好一切，以便你在下一章轻松构建更多精彩的应用。我们将把 Ethernet 扩展板连接到你的路由器，并确保它可以访问 Web。

第 2 章“将数据发送到 Web 服务器”解释了如何将温湿度传感器连接到 Arduino 开发板，并使用 Ethernet 扩展板将这些数据持续发送到运行在你计算机上的 Web 服务器。我们还将在 Web 服务器上实时绘制这些数据，以便你可以在浏览器中可视化查看。

第 3 章“数据记录站”使用与上一章相同的硬件，但我们将使 Arduino Ethernet 更加独立。我们将把开发板测量的数据本地记录到 SD 卡上，并创建一个在 Ethernet 扩展板上运行的 Web 服务器，以便你本地网络中的任何设备都可以访问它。

第 4 章“从任何位置控制对象”介绍了如何将继电器模块连接到我们的 Arduino 和 Ethernet 扩展板硬件，以便它可以通过网络进行控制。我们将首先从本地网络内部控制此继电器模块，然后使用专用服务来实现从任何位置控制此继电器。作为示例，我们还将把一盏灯连接到此继电器模块。

第 5 章“与 Xively 结合的物联网”继续介绍云端连接项目，通过将 Ethernet 扩展板与名为 Xively 的云服务进行接口连接。使用此服务，我们将能够将项目测量的数据发送到 Web，并从世界任何地方实时在 Xively 网站上监控它。

第 6 章“在 Google Docs 中记录数据”使用 Web 服务 Temboo 将 Ethernet 扩展板与更多 Web 服务（如 Google Docs 或 Gmail）进行接口连接。例如，我们将使用 Arduino 开发板进行测量，并自动将这些结果记录到 Google Docs 电子表格中，该表格可以从世界任何地方访问。

## 本书所需内容

要完成本书中的所有项目，你需要多种硬件和软件组件。当然，你也可以只阅读项目描述来学习。但是，我强烈建议你亲自动手做这些项目，以真正了解如何使用 Arduino Ethernet 扩展板来构建精彩的网络应用。

所需硬件组件在每章开头有详细说明。但是，所有项目中你真正需要的是一块 Arduino 开发板。

本书的所有项目均基于 Arduino Uno 开发板：

http://arduino.cc/en/Main/arduinoBoardUno

对于本书的所有项目，你还需要 Arduino Ethernet 扩展板：

http://arduino.cc/en/Main/ArduinoBoardEthernet

在软件方面，有一些软件我们将在本书的所有章节中使用。我们在所有章节中使用的第一个软件是你需要安装的 Arduino IDE。你可以从以下网址下载：

http://arduino.cc/en/main/software

Ethernet 库本身包含在 Arduino IDE 中，因此你不需要自己安装。还有几个外部库你需要，但这些库会在相关章节中详细说明。

你还需要在计算机上运行一个 Web 服务器来完成其中一些项目。我建议使用集成了 Web 服务器和数据库，并为你处理所有细节的软件。

如果你使用 Windows，我建议使用 EasyPHP：

http://www.easyphp.org/

如果你使用 OS X，我建议使用 MAMP：

http://www.mamp.info/

对于 Linux，你可以按照以下链接中提供的说明安装 Web 服务器：

http://doc.ubuntu-fr.org/lamp

请确保此时服务器正在运行；我们将在本书的多个项目中使用它。
