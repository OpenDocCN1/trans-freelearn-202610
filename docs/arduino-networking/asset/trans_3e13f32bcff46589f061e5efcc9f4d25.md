## 关于作者

**马可·施瓦茨** 是电气工程师、企业家和博客作者。他拥有法国 SUPELEC 的电气工程与计算机科学硕士学位，以及瑞士 EPFL 的微工程硕士学位。

他在电气工程领域拥有超过 5 年的工作经验。他的兴趣集中在电子学、家庭自动化、Arduino 和 Raspberry Pi 平台、开源硬件项目以及 3D 打印方面。

他运营着多个关于 Arduino 的网站，包括 Open Home Automation 网站（http://www.openhomeautomation.net/），该网站致力于使用开源硬件构建家庭自动化系统。

他还撰写了另一本书《使用 Arduino 的家庭自动化》，由 Amazon Digital Services, Inc. 出版，这是一本自出版的 Kindle 电子书。他还撰写了一本关于如何使用 Arduino 构建物联网项目的书，名为《使用 Arduino Yun 的物联网》，由 Packt Publishing 出版。

## 关于审稿人

**瑞安·邓恩** 是解决方案架构师，专注于 Web 技术和企业级部署。他目前居住在美国堪萨斯州南堪萨斯城。

他拥有堪萨斯州立大学的计算机科学学士学位和堪萨斯大学的工商管理硕士学位。他曾为多个组织工作，职业生涯涉及电子商务、数字营销、SEO、教育、安全和移动等多个行业。

他从事 Web 技术工作超过 10 年，在此期间，他始终对技术保持中立态度，从而积累了广泛的经验。作为解决方案架构师，他管理解决方案部署的各个方面，包括分析、网络架构、系统架构、创意设计和开发。

我有一个妻子 Crystal 和两个孩子。由于他们的支持，我得以追求自己对技术的热爱，并对他们的爱永远心怀感激。

**菲利普·梅休** 拥有北卡罗来纳州立大学的计算机科学理学学士学位。他是 Rextency Technologies LLC 的创始人兼管理负责人，该公司位于北卡罗来纳州斯泰茨维尔。他的主要专长在于软件应用性能测试和监控。

**汤姆·奥康纳** 是经验丰富的系统架构师和 DevOps 工程师。他居住在英国西米德兰兹。在过去 8 年里，他曾为从电子商务到视觉特效等多种公司工作，现在是他创立的公司的所有者，该公司为无线网络设计和安装提供系统咨询。

他在自己的网站上写技术博客，既提供教程文章，也分享他最近的工作进展。在过去 10 年中，他大部分时间在 Windows、Linux 和 Unix 系统上工作，积累了广泛的技能和经验，最近还具备设计和构建高性能计算机系统的经验。

他也是英国 DevOps 社区的活跃成员，以及 www.serverfault.com 的社区版主，在那里向广大受众展示他的专业知识和技能。

**克里斯扬尼斯·里尼埃克斯** 是数字交互媒体专业人士，从事涉及平面设计、动画、用户界面设计、投影映射、编程和电子学的项目工作。他的项目成果通常是网站、游戏、硬件原型或交互式装置。他还在创意编码和投影映射领域举办研讨会。他目前最有趣的项目之一是开发一个用于 Raspberry Pi 上投影映射的 openframeworks 插件——ofxPiMapper。

他还是赫尔辛基媒体实验室（阿尔托大学艺术、设计与建筑学院）的硕士生，目前正在撰写与 ofxPiMapper 投影映射软件项目相关的硕士论文。

克里斯扬尼斯与同事 Irina Spicaka 共同经营一家名为 CodeBark 的小型数字媒体公司（www.codebark.com）。他们还共同开发了一个名为 Creative Coding for Live Audio and Visuals（www.cc4av.info）的平台，该平台作为与电子视听文化相关的各种活动和研讨会的占位平台。

他还在与柏林 Fab Lab 合作，在柏林时大部分时间都在那里度过。
