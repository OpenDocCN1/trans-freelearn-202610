We can export in the **MP4** format, which has several options, such as **Quality**, **Frames per second**, and **Resolution**. But I recommend using the second option, **Images**, as shown in the following screenshot:

Exporting a set of images instead of an entire movie

As you can see, you have the same options, plus the additional ones that allow you to export the render passes that you can use later in Photoshop or Gimp.
