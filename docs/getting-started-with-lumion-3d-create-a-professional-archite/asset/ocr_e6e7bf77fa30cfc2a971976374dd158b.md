# # Setting up the weather

Once we are happy with the landscape and water, we can start paying attention to details. We can start by using the **Weather** menu. Again, this menu is pretty self-explanatory. We can change the direction of the sun and its height, change the type of clouds from the nine given types, and adjust the slider to create a clear sky or an overcast day, as shown in the following screenshot:

![](bbox=[0.176, 0.267, 0.823, 0.374])

The Weather menu where we can control the sun and the sky

There isn't much we can do in this section, and if we want to add some special weather conditions such as rain and snow, we can do that later in the photo or video mode.
