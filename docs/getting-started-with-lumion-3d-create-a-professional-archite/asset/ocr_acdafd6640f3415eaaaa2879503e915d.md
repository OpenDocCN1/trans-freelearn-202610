We are going to look at the most important aspects in the Properties menu to help you understand how you can tweak the material. Let's have a look at the following screenshot:

![](bbox=[0.253, 0.207, 0.746, 0.427])

The properties are as follows:

+   - **Scale**: It's a really important aspect when configuring the material because we can change the scale of the texture, and everything can have the correct proportion. If we are using our own texture with a specific texture mapping, we need to set this value to 0.
+   - **Reflection Colorize**: Use the material color to tint the reflections. In order to understand this setting, take a look at the following screenshot. From the left to the right, there is an increment of 50% starting from 0%. Can you spot the difference in the screenshot?
