# The Invisible material

Use this material to make something invisible in your scene. I found this material useful to hide something inside Lumion. In that way, I don't need to spend time going back, for example, to SketchUp, delete the object, and export and import in Lumion. If I want to hide something, for example, a wall, a window, or an entire model, I can do it by applying this material. It's a time saver.
