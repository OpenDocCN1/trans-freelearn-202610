# Creating a heightmap

In *Chapter 1, What is Lumion?*, we mentioned that we can use a heightmap texture to do the hard work for us. Lumion can read this heightmap that has information of how we want the landscape to be, and translates this 2D information into a 3D terrain. However, Lumion has some limitations because the editable part of the terrain in Lumion is a square of 2048 x 2048 m. When we create a heightmap, we need to keep in mind that the texture will be stretched to the fullest extent of the square.
