# Summary

In this chapter you learned how to prepare a CAD drawing in a way that it can be easily imported to any application as the base for modeling. You found out how important it is to add detailing to your model and how this helps to improve realism. You discovered some places where you can find free and paid models, and finally, learned a few common traps in modeling as well as how to avoid them. It is very important to take time to ensure that objects have good geometry and detailing. Of course, each project is different. In large projects, we need to have good management of the geometry so that we do not run the risk of creating a heavy scene. In the next chapter, you will learn how to create materials inside Lumion and your own textures using Photoshop or Gimp.
