## 前言

《Lumion 3D入门指南》以友好直观的方式向您展示如何开始使用Lumion工具创建专业的建筑可视化作品。本书引导您完成所有初始步骤，并包含一个快速入门教程，让您能够立即开始使用Lumion并渲染场景。本书的其余部分在此知识基础上，通过逐步讲解向您介绍更多工具，不仅帮助您开始使用Lumion，还帮助您迈出建筑可视化的第一步。您将学习如何使用Lumion的材质和模型、如何构图场景，以及如何导出图像或视频。

## 本书涵盖的内容

*第1章，什么是Lumion？*，将总体概述Lumion，让您了解为什么要使用Lumion，以及通过这个应用程序我们能获得怎样的最终质量。然后，您将在快速入门教程的帮助下开始使用Lumion，学习创建精美建筑可视化的基础知识。

*第2章，准备场景*，将帮助您识别和纠正一些常见错误，从而避免Lumion中的问题。您将学习如何清理和使用CAD图纸开始建模，如何提高真实感，以及在哪里可以找到适合场景使用的精美模型。

*第3章，创建材质*，将帮助您学习如何使用和调整Lumion提供的500多种即用型材质。最后，您将了解在哪里可以找到纹理，以及如何准备这些纹理以便与Lumion材质一起使用。

*第4章，使用Lumion*，将解答您的许多疑问；这也是乐趣开始的时候。您的3D模型应该已经准备好导出了。您该怎么做？需要特殊插件吗？如何在Lumion中导入模型？所有这些问题以及更多内容都将在本章中得到解答。导入模型后，您将开始使用图层和其他菜单在Lumion中组织场景。

*第5章，构建环境*，将帮助您开始为场景添加细节。您将学习如何雕刻地形和更改天气，然后开始使用Lumion附带的大量模型填充场景。您还将学习如何使用特殊效果和声音为场景增添独特魅力。

*第6章，准备渲染*，将教您什么是构图、如何让场景更具吸引力，以及如何使用照片和视频模式导出2D元素。

*第7章，后期制作*，将帮助您学习如何为Lumion输出的结果增添特殊效果。通过使用Photoshop或Gimp，您将学习图像色彩校正的一些关键技巧。您将学习如何使用图层蒙版、混合模式和调整图层。

## 本书所需环境

基础知识包括：Lumion免费版、Photoshop或Gimp。Lumion团队建议使用以下最低配置：

- Windows XP、Vista、7、8（32位和64位）以及DirectX 9.0c或更高版本
- 系统内存：3 GB
- 显卡：NVIDIA GeForce GTS 450或ATI/AMD Radeon HD 4890（至少1500 PassMark分数），至少1 GB专用显存（非共享系统内存）

## 本书适合的读者

本书适合所有级别的Lumion用户，尤其适合那些没有建筑可视化经验、希望在该领域迈出第一步的读者。本书还可以帮助中级用户通过不同技巧改进工作流程。无论您是业余爱好者、专业建筑师还是设计师，本书都将帮助您开始使用Lumion创建3D可视化作品。
