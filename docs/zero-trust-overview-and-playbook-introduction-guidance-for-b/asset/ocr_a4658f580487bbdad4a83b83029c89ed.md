+   - **Integrate security early**: Keep security teams plugged closely into application teams that are developing new assets in a DevOps/DevSecOps manner. This ensures new business capabilities meet current security standards when they release (and steadily improve with each iteration of those processes). This is sometimes called *shift left*—a reference to integrating security earlier into timelines.
