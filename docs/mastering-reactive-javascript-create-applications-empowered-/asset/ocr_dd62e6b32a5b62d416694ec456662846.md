We can change this code to take only a few elements from the infinite Observable. This way it will finish:

```
Rx.Observable
  .forkJoin(
    Rx.Observable.fromPromise(Promise.resolve(1)),
    Rx.Observable.interval(100).take(5)
  ).subscribe((k)=>console.log(k));
```

Now if you run this code, you will see the following output:

[ 1, 4 ]

This contains the value 1 propagated by the first Observable and the value 4, which is the last element (as we took 5 from the interval()) propagated by the second Observable.
