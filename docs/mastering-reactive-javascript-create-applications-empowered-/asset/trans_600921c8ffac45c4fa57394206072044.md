## 精通响应式 JavaScript

如果你处理大量数据时遇到困难，并且不知道如何提高代码可读性，那么响应式编程就是适合你的解决方案。它让你能够描述代码在变化发生时的行为，并使处理实时数据变得更容易。本书将教你什么是响应式编程，以及如何使用它来编写更好的应用程序。

本书从响应式编程的基础开始，介绍什么是 Reactive Extensions，以及如何在 JavaScript 中使用它并结合使用 Bacon 的一些响应式代码。接下来，你将了解 Observable 和 Observer 是什么，以及何时使用它们。

继续，你将探索 RxJS API，了解数据流量的问题，并了解如何缓解它。你还将学习其他重要的操作符，这些操作符可以帮助提高代码可读性，并将了解如何使用 transducers 来组合操作符。

在本书结尾，你将获得使用 RxJS 的实践经验，并将使用客户端和服务器上的 RxJS 创建一个实时网络聊天室，为你提供掌握 RxJS 的完整方案。

## 你将学到：

- 了解使用 RxJS 的函数式响应式编程基础
- 以线性内存消耗处理连续的数据流
- 过滤、分组并对系统中的变化做出反应
- 了解如何处理数据流量
- 组合操作符以创建新的操作符，并在多个 Observable 中使用它们以避免代码重复
- 探索 transducers 并了解它们如何提高代码可读性
- 使用 Retry 和 Catch 操作符检测并从 Observable 中恢复错误
- 创建你自己的响应式应用程序：实时网络聊天
