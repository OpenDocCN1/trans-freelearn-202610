![](bbox=[0.03, 0.15, 0.95, 0.51])

As you can see in the diagram, no intermediate observable is created; the same code can be implemented using the map() and filter() operators of observables, but it would add the creation of an extra observable, decreasing your code performance.

If we decided to implement the same code using the operators map() and filter() instead of a transducer, we could use the following code:

```
var mapFunction = (i)=>i+1;
var filterFunction = (i)=>i&2===0;

Rx.Observable
.of(1,2,3,4)
.map(mapFunction)
.filter(filterFunction)
.subscribe((i)=>console.log(i));
```
