Do not forget to start the Redis server as we are using it to communicate the messages. If you do not start your Redis server you will see an error like this:

![](bbox=[0.22, 0.13, 0.81, 0.28])

So, do not forget to run the Redis server.

After starting the Redis server, and running our node application, we can already see the `web chat` application on the browser for the first time, so enter `http://localhost:3000` into your browser and you will see the application running:
