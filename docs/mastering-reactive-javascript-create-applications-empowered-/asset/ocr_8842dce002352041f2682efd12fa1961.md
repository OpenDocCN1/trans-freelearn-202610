As we expect, the output is as follows:

```
John Doe
Mary Jane
```

And for the last, we can use the same code with other forms of iterables such as Set ():

```
var namesObservable = Rx.Observable.of('John', 'Mary');

var lastNamesArray = new Set(['Doe', 'Jane']);

namesObservable
.zipIterable(
  lastNamesArray,
  (name,lastName) => name + ' ' + lastName
).subscribe((k)=>console.log(k));
```

The zipIterable() operator is similar to the zip() operator. It only makes it easier to interoperate observables and regular iterables.
