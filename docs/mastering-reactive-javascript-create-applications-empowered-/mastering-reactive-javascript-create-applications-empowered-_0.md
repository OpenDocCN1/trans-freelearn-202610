## 前言
创建一个实时应用程序来处理成千上万个实时数据源听起来很难吗？不再如此。学习一些响应式编程，你将能够扩展你的边界，创建利用实时数据的应用程序，而不会影响性能。

## 本书涵盖的内容
第 1 章，《什么是响应式？》，解释了响应式编程的基础知识以及它与命令式编程的比较，并展示了一些示例用法。

第 2 章，《第一次响应》，使用 bacon.js 介绍了事件流和操作符的基础知识。

第 3 章，《充满变化的世界 - 响应式扩展来救援》，本章我们探讨观察者和可观察对象的定义和类型。

第 4 章，《转换数据 - Map、Filter 和 Reduce》，涵盖了函数式响应式编程中最基本和最重要的操作符。

第 5 章，《世界变化太快 - 处理背压的操作符》，解释了不同技术来缓解接收数据速度快于处理速度的问题。

第 6 章，《源太多？ - 合并可观察对象》，教你如何组合不同的数据源以创建新的数据源。

第 7 章，《出了问题 - 测试和处理错误》，解释了如何在可观察对象中处理错误以及如何使用函数式响应式编程测试程序。

第 8 章，《关于操作符的更多内容》，展示了一些未纳入前几章的重要操作符。

第 9 章，《组合》，解释了什么是转导器以及为什么应该使用它。

第 10 章，《实时服务器》，构建了作为函数式响应式编程示例的 Web 聊天应用程序的后端部分。

第 11 章，《实时客户端》，构建了作为函数式响应式编程示例的 Web 聊天应用程序的前端部分。
