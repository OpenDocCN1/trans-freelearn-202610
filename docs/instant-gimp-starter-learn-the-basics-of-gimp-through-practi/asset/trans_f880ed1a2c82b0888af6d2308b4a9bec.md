
![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_27_0.png)

绘图中的每个填充都由图层分隔，以便可以修改每个图层而不影响其他图层。您还可以指定单个图层的透明度。

## 绘制海报

海报是一种传达有力信息的绘画。海报通常包含文字信息和图像来补充信息。海报可能只包含非常有限的颜色。我们将逐步制作以下海报：

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_28_0.png)

要制作海报，请按照以下步骤操作：

- 1. Create a new file by clicking on File | New (or keyboard shortcut Ctrl + N), and you'll be presented by this new file menu:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_29_0.png)

让我们使用适合 A4 打印的设置；为此绘图选择 A4（300ppi）模板。它将是一个大画布，尺寸为 2480 x 3508 像素。大画布意味着创建的图像将是高分辨率图像，适合打印。低分辨率会导致打印时图像模糊且锯齿状。

- 2. Click on the Text Tool option to start putting text on the canvas. The setting of the text can be modified at the tool options. Here, I choose Rockwell font.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_29_1.png)

3. Now let's write PEN on the canvas. Click-and-drag to form a rectangle on the canvas. Type PEN at the placeholder, as shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_30_0.png)

4. Make another two rectangles for & and Pencil.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_31_0.png)

您应该已创建了三个文字图层；您的图层菜单应如下屏幕截图所示：

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_31_1.png)

现在让我们尝试绘制一支简单的钢笔。操作如下：

- 1. To make a geometrical shape, we could use the selection where you begin by forming a rectangle selection, and put a stroke to the selection, as shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_32_0.png)

2. This requires a few steps to form the fountain pen shape, as shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_33_0.png)

上一个屏幕截图包含一个矩形、一个圆形和一个旋转的正方形。每个都需要使用矩形、圆形和正方形形成的选区。然后，对选区应用描边以形成形状。

- 3. Rotating the square is a bit tricky. Use the **Rotate Tool** option to do so. Create a square selection first (*Ctrl* + drag to form a square), click on the **Rotate Tool** option, and click-and-drag the selection of the square to 45 degrees. You may also use the rotate menu box; this way the rotation is more precise. Refer to the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_34_0.png)

4. Complete the outline with the **Pencil Tool** option. Click a start point, and hold the *Alt* key to draw a straight line. Use the edges on the strokes for your guide to make a fountain pen tip.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_35_0.png)

5. Now you should be getting used to forming geometrical shapes. Remove unnecessary lines using Eraser Tool option. Use the Bucket Fill Tool option to fill in with colors.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_36_0.png)

6. To draw a pencil on the other side is simpler than a fountain pen. The basic shape to form is shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_37_0.png)

7. Notice, there are two circles; they were generated by clicking on the round selection tool, and holding Ctrl + Shift while dragging the cursor from the tip of the pencil.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_37_1.png)

8. Erase the unneeded lines, and start filling the drawing with colors. It should look like the image shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_38_0.png)

9. Now let's paint the background that I would like to look like a triangular gradient design. Using the lasso tool, in orderly fashion, click at the top-right corner, bottom-left corner, top-left corner, and finally click the top-right corner where we started; a triangular selection is formed.

10. Set up a gradient fill to have settings like the following, and drag from top-left corner to the center of the drawing:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_39_0.png)

- 11. Repeat the same process for the other half.
- 12. To quickly invert the selection, to select the other half, press Ctrl + I.

13. Rearrange the words using the Move Tool option, so they align in the center of the poster. Now we have a poster ready for print!

## 绘制信息图

信息图如今随处可见；它们提供图表来可视化信息。信息图与海报不同。虽然许多人认为它们看起来相同，但信息图以精确的方式呈现数据的可视化。绘图的精确度非常重要。我们将创建一个信息图来教育人们了解非洲动物。

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_40_0.png)

这是计划。我一直在网上浏览并找到了一些关于非洲动物的有趣事实。以下表格显示了我找到的事实：

|  | Giraffe | Elephant | Baboon | Lion | Cheetah |
|---|---|---|---|---|---|
| Speed | 32 mph | 25 mph | 30 mph | 50 mph | 70 mph |
| Height | 16 ft | 10 ft | 1.8 ft | 5.5 ft | 4 ft |

我还为每种动物找到了一些剪贴画以复制到 GIMP 中。使用您的 Internet 浏览器，前往 http://www.freecipartnow.com/animals。我想以 A4 大小的图像创建此文档。为此，请按照以下步骤操作：

- 1. Click on **File | New**, and create an A4 size canvas.
- 2. Drag the picture into the canvas.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_41_0.png)

3. If the image does not have a visible alpha channel, please add one from the layer content menu:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_42_0.png)

4. Remove the other surroundings, so that we are left with the shape of a baboon.

5. Resize the picture so that the picture is proportionate with the other pictures. Use information from the table to set the height. I represent 1.8 feet with 18 mm, as 1 foot is represented as 10 mm.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_42_1.png)

6. Select the shape with a magic wand so that it is easier to work with. Add a gradient to fill the shape and stroke the outline. The result should look like the image shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_43_0.png)

7. Repeat the process for lion, cheetah, elephant, and giraffe.

8. Now for the speedometer, draw a basic guide, as shown in the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_44_0.png)

9. On the top of another layer, create radii of the circles. These will be the levels on the speedometer.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_44_1.png)

10. This enables the layer to be copied and rotated to fill other quadrants.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_45_0.png)

11. After the second quadrant, rotate to fill up until the third quadrant merge all three quadrants. Refer to the following screenshot:

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_45_1.png)

现在我们有一个接近完成的 speedometer：

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_46_0.png)

12. Clean up the speedometer and put the labels for each level.

![](img/a7d4ab10f584c5ec31bcd98067c9f4ab_46_1.png)
