# HTML—IDs and classes

We can refer to specific elements in two primary ways: via an ID or class name(s).

# HTML IDs

Every HTML element can have a single ID. The ID is unique, and no elements should share the same ID. For example,

```
<div id='map_element'></div>
```

With this code, we're creating a div element with an ID of 'map'—no other element (be it a div or otherwise) should have the same ID. So, IDs are very useful when we want to refer to one specific element. We've used the ID property to specify the div that our maps should appear in (via <div id='map_element'></div> and specifying map_element when instantiating our map object).
