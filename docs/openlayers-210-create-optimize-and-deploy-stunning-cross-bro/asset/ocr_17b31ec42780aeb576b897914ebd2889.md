In this case, OpenLayers requests more tiles because the total map area is outside what you can see (called the Viewport). The tiles are all still 256 x 256 pixels, but now tiles lie outside of the map's visible range. Any time the user moves their map to a new area (by zooming or panning), OpenLayers figures out how many tiles it needs to get, the extent for each tile, and where to place them.
