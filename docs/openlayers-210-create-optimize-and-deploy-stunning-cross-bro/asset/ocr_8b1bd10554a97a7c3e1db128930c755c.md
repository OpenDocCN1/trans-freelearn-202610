# What Just Happened?

We just created a map using Google Maps, WMS, and Vector layers. We also have an **EditingToolbar** control hooked up to the vector layer object, which will let us create points and polygons in the vector layer. Any points or polygons (also called **features**) we create will be in the map's projection, `EPSG:900913`, and line up with the Google Map layer below it.
