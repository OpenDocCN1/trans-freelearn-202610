5. This new panel allows you to enter dates to use for since-until filtering.

6. Type any date and time into the boxes, or use the C buttons to bring up calendar controls which can be used instead.

7. When the user clicks the Filter button in this panel, it calls a protected function, listFilterCallback(), in the class that CustomGraphContainerController extends, and passes it the dates entered and the IDs of the Graph Object and connection that the List Renderer represents.

This means that CustomGraphContainerController inherits that function, so we can make it create a new GraphRequest for this Graph Object and connection, using those dates.

8. So, open CustomGraphContainerController.as and override the function:

```
override protected function listFilterCallback(a_objectID:String, a_connectionType:String, a_since:String, a_until:String):void
{
    super.listFilterCallback(a_objectID, a_connectionType, a_since, a_until);
}
```
