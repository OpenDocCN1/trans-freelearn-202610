It works just as we'd expect. (Remember, HTTPRequestor is passing the access token as a parameter to all Graph URLs requested.)

Take a look at what's loaded when we request the user profile:

Notice that the Graph URLs in the connections list already have the access_token parameter filled in. The Visualizer's code doesn't use these Graph URLs – it constructs them using the form https://graph.facebook.com/<id_of_object>/<name_of_connection> – but this knowledge may come in useful for your own projects.

As you can see from the Visualizer, the friends connection Graph List only includes very basic information: the users' IDs and names. However, much more information is loaded in the full Graph Objects of your friends – though the exact amount depends on your friends' privacy settings.
