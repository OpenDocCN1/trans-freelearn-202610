Everything's in place, but how do we post the message from the Visualizer to our actual Facebook Wall?

# Request methods

Publishing a message to a user's Wall isn't any more complex than filtering information from it—we use the Graph URL, https://graph.facebook.com/me/feed, and pass it two parameters:

+   - The access token, and
+   - The message to post

The difference comes in how we pass those parameters. We cannot simply load the URL anymore. Try it yourself: browse to https://graph.facebook.com/me/feed?access_token=«access_token»&message=Hello. It will return your feed in JSON format, but won't post to it.

We still use a URLLoader and a URLRequest, but we use a different request method.

# What's a request method?

An HTTP request method is a way of telling the web server what kind of action we want it to take when we ask it for a page or some other resource.

By default, an AS3 URLRequest uses an HTTP request method called GET; this is a "safe" method, so-called because it doesn't ask the server to change any information, merely to pass some back—which is all what we've needed up to this point in the book.
