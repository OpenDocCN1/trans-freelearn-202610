Okay, it's not a lot, but it proves that we've been successfully authorized, and can see more information than before we had an access token.

Try accessing your list of friends without an access token:

```
https://graph.facebook.com/«your_username»/friends
{
  "error": {
    "type": "OAuthAccessTokenException",
    "message": "An access token is required to request this resource."
  }
}
```

Absolutely nothing. Now, with an access token (replace «your_access_token» with the actual access token):

```
https://graph.facebook.com/«your_username»/friends?access_token=«your_access_token»
{
```
