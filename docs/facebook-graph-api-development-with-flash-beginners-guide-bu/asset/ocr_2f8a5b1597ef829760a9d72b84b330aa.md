These "entity relationship" lines don't connect *fields* in the database tables; they connect entire tables, *using* the fields as a "key". Remember the rule of reading the verbs from left to right. If we used "is" as the verb, it would say, "The photo is the specified album" which is clearly wrong.

We can't connect the two tables directly because their relationship is through another entity. Let me show you what I mean:

![](bbox=[0.28, 0.26, 0.72, 0.45])

We've now got three tables (photo, album, user) and four relationships:

+   - The photo belongs to the specified album
+   - The photo is a cover of the specified album
+   - The photo belongs to the specified user
+   - The user owns the specified album

So we can get the URLs of all of a specific user's photos using this query:

```
SELECT src
FROM photo
WHERE owner = «user's ID»
```
