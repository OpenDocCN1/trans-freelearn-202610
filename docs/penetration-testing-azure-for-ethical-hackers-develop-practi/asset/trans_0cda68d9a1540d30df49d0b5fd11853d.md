## 前言

欢迎阅读《面向道德黑客的 Azure 渗透测试》。本书将介绍在 Azure 环境渗透测试期间可以使用的各种技术和攻击。无论您是希望在云领域获得优势的经验丰富的渗透测试人员，还是刚刚进入渗透测试领域的新手，本书都能为您提供有价值的信息。

我们将从介绍 Azure 服务和平台的整体架构开始本书。第一部分将涵盖渗透测试期间常用的服务及其支持服务。我们将在此为本书其余的攻击奠定基础，因为攻击通常利用这些服务的架构和配置，这与更传统的协议和代码相关渗透测试攻击形成对比。

然后，我们将介绍如何创建和配置一个有漏洞的测试环境，以便您遵循书中的练习。对于有构建和维护订阅经验的人来说，这可能是一个复习章节，但请记住，这些初始信息将贯穿本书的其余内容。

本书的中间部分将介绍您在渗透测试期间会使用的攻击和技术。本部分特定攻击的实用性会因您而异，因为您在 *正常* 渗透测试中可能不会遇到我们涵盖的所有服务和配置。作为参与过数百个 Azure 订阅的渗透测试人员，我们希望能够在核心服务（公司正在使用的）以及容易受到攻击利用的服务方面，为您提供很好的参考。

对于攻击部分，我们将根据订阅权限级别（读者、贡献者等）和拥有这些权限的单个服务可用的攻击来分解各个攻击。由于不同的权限允许不同的攻击，我们将从较基本的只读攻击开始，逐步转向更高级（更大权限）的攻击。

本书的最后一章重点介绍 Azure 环境中的持久化。在渗透测试期间，您可能会发现自己需要保持对 Azure 环境某些部分的访问权限。我们将回顾多种在 Azure 环境中隐藏的技巧。
