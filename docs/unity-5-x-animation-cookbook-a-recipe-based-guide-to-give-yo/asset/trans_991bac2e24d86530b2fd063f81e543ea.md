19. 我们将使用附加到摄像机的简单脚本来检测身体部位的命中。 创建一个新脚本并将其命名为 `Shoot.cs`。 在此脚本的 `Update()` 函数中，我们不断从摄像机的前向轴发射射线。 我们使用带有 **LayerMask** 参数的 `Physics.Raycast()` 实现。 这使我们只能命中具有适当图层的碰撞体。 如果我们命中了这样的碰撞体，我们将检查它是否附加了 `BodyPart.cs` 组件。 如果是，我们将屏幕上的 UI 文本设置为我们命中的身体部位的名称：

```
Transform cameraTransform = Camera.main.transform;

if (Physics.Raycast(cameraTransform.position,
cameraTransform.forward, out hit, maxDistance,
bodyPartsLayer))
```

```
{
    BodyPart p =
    hit.collider.gameObject.GetComponent<BodyPart>();
    if (p != null)
    {
        bodyPartText.text = "Hit body part: " +
        p.bodyPartName;
    }
    else
    {
        bodyPartText.text = "No body part was hit";
    }
}
else
{
    bodyPartText.text = "No body part was hit";
}
```

## 它是如何工作的...

我们使用 Unity 的 **Hierarchy** 将碰撞体附加到角色骨架中的骨骼上。 这样我们就可以检查这些身体部位的碰撞并通过脚本对其做出反应。 为了使本配方简单，我们只在 UI 上显示命中的身体部位名称，但您可以轻松实现对特定身体部位命中的复杂反应。 例如，您可以为头部射击实现额外的伤害，甚至是复杂的伤口系统。

## 还有更多...

我们已使用 `Physics.Raycast()` 方法介绍了命中检测，这对于瞄准身体部位或快速移动的投射物很有用。 但您也可以同样轻松地在近战中实现身体部位检测。 您需要做的就是在 `BodyPart.cs` 脚本或附加到武器的新脚本中实现 `void OnCollisionEnter(Collision collision)` 方法（它需要具有 **Collider** 和设置为 **Is Kinematic** 的 **Rigid Body** 组件）。 然后您必须检查进入的碰撞对象是否附加了适当的脚本或标签，以确定是否击中了身体部位。

## 使用 Animation Events 触发声音和视觉效果

本配方展示了一种简单、通用的方法，使用 Animation Events 播放不同的声音和视觉效果。

### 准备工作

开始时，您需要有一个带有循环动画的角色：Jump。 我们还需要一个音效和一个粒子系统。 我们需要一个透明的 DustParticle.png 纹理用于粒子系统。 它应类似于一个小尘云。 您可以打开提供的示例 Unity 项目并转到 Chapter 07 Special effects\Recipe 01 Using animation events to trigger sound and visual effects 目录。 在 Rigs 目录中，您将找到所有需要的动画，而在 Resources 文件夹中，您将找到所有其他必要资源。 当您播放游戏时，您将看到一个角色正在播放 Jump 动画。 着陆时它还会播放音效和粒子效果。

### 如何操作...

要使用 Animation Events 播放声音和视觉效果，请按照以下步骤操作：

- 1. 导入带有 Jump 动画的角色。
- 2. 在导入设置中，动画选项卡中，选择 Jump 动画。
- 3. 使其循环。
- 4. 转到事件部分。
- 5. 在预览部分中拖动时间线并单击添加事件按钮。 编辑动画事件窗口将出现，如以下屏幕截图所示：

![](img/616a75b593bef4212f618360fceea442_221_0.png)

编辑动画事件窗口

- 6. 在 **函数** 字段中输入 `Sound`，在 **字符串** 字段中输入 `Jump`。 这将在附加到角色的脚本中调用 **Sound** 函数，并将 **Jump** 单词作为字符串参数传递给它。
- 7. 创建另一个动画事件。 将 **函数** 字段设置为 **Effect**，将 **字符串** 字段设置为 **Dust**。
- 8. 应用 **导入设置**。
- 9. 为角色创建一个 Animator Controller，其中仅包含 **Jump** 动画。
- 10. 将角色放置在场景中。
- 11. 将控制器附加到角色的 Animator 组件。
- 12. 为角色附加一个 **音频源** 组件。
- 13. 取消选中 **播放时唤醒** 选项。
- 14. 创建一个空游戏对象并将其命名为 **Dust**。
- 15. 为其添加一个 **粒子系统** 组件。 这将是我们尘埃效果。
- 16. 按如下方式设置 **粒子系统** 的参数：
  - **持续时间** 为 1 秒
  - **开始生命周期** 为 0.5 秒
  - **开始速度** 为 0.4
  - **开始大小** 随机介于两个常数之间：1 和 2
  - **开始颜色** 为浅棕色
  - **发射 | 速率** 为 0
  - **发射 | 爆发** 为一次爆发，时间设置为 0，**最小值** 和 **最大值** 设置为 5
  - **形状 | 形状** 为球体
