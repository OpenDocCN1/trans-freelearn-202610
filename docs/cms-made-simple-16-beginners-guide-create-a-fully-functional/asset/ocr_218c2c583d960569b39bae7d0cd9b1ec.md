# Using keywords in page alias and image files

Using keywords in page aliases that are used to create unique URLs for the website is a simple way to improve its search ranking. A page alias is generated by default from the title of the page, but you can change it afterwards. In the admin console, open any page for editing, and switch to the **Options** tab. Find the **Page Alias** field, and change it to suit your desired search words or phrases.
