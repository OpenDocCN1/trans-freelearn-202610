# Time for action – sending mails to registered customers

Let's create our first newsletter that will be sent to the visitors of the website. You have to create one or more test users with different valid e-mail addresses to be able to control how the messages will be delivered. Do not use real e-mail addresses, unless you want them to get test messages at this point.

+   1. In the admin console, click on **Extensions | Newsletter Made Simple**.

+   2. Click on the **Create a List** link, and enter the fields, as shown in the following screenshot:

![](bbox=[0.29, 0.34, 0.71, 0.53])

+   3. Click on **Submit**.

+   4. Switch to the **Users** tab. At the bottom of the page, click on the **Add User** link, and add two or more users. Assign them to the group **Public Newsletter**, as shown:

![](bbox=[0.31, 0.63, 0.7, 0.87])
