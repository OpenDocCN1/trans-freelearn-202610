# Time for action – protecting the service desk

Now, let us protect the Service Desk page so that its main content can only be viewed by registered members. If the user is not logged in, only the login form should be shown.

+   1. In the admin console, open the Service Desk page for editing (Content | Pages).
+   2. Click on the Options tab, and mark the page to be not cachable and not searchable, as shown in the following screenshot:
+   3. Switch to the Main tab, and fill in the content field, as shown in the following screenshot:
+   4. Click on Apply.
+   5. View the page as a logged in user as well as a logged out user.
