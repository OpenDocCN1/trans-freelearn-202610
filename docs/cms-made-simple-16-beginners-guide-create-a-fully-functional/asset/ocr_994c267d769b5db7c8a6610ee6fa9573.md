# Time for action – activating search and replace function

There is a useful plugin that can search the entire contents of a page and replace all instances of a word or phrase with something different. Let's see how we can activate this plugin in TinyMCE.

+   1. In the admin console, click on **Extensions | TinyMCE WYSIWYG**.
+   2. Click the **Plugins** tab.
+   3. Select the checkbox beside the plugin called **searchreplace**, as shown in the following screenshot:

![](bbox=[0.227, 0.363, 0.777, 0.618])

+   4. Click the **Save plugins** button.
+   5. Switch to the **Profiles** tab.
+   6. In the **Advanced backend profile settings** section, add the words **search, replace** to the **Toolbar 3** field, as shown in the following screenshot:
