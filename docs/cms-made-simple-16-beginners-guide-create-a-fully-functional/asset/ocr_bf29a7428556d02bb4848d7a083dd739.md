In the admin console, click on **Extensions | TinyMCE WYSIWYG**, and choose the **Plugins** tab. Select the plugin with the name **media**, and click **Save plugins**. Then switch to the **Profiles** tab. There are three sections:

+   - **Backend profile settings**: Settings for editors of the website
+   - **Advanced backend profile settings**: Settings for the administrator of the website
+   - **Frontend profile settings**: Settings for the usage of the WYSIWYG editor on the frontend, for example, if your visitors can add news articles to the website

The button for inserting embedded media is called **media** and can be added to any **Toolbar** of any profile depending on your individual needs. For example, to make the button available to the editor of the website and to the administrator in the first line of the toolbar, add the word **media** at the very end of the field **Toolbar 1** in both profiles, as shown in the following screenshot:
