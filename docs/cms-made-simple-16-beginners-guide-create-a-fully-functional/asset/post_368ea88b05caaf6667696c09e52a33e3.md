# PAGE RANKING ALGORITHMS IN GAMING - EVE Online

By: Ing. Tomáš Fabián

Abstract — The PageRank algorithm, originally developed by Larry Page and Sergey Brin for ranking web pages in search engines, has found applications in various domains beyond the World Wide Web. This paper explores the application of PageRank algorithms in the context of gaming, specifically focusing on the massively multiplayer online role-playing game (MMORPG) EVE Online. The unique player-driven economy and complex player interactions make EVE Online an ideal candidate for applying graph-based ranking algorithms to analyze player influence, system importance, and economic flow within the game universe.

EVE Online presents a persistent world where players engage in mining, trading, manufacturing, and combat. The game's universe consists of interconnected star systems, forming a natural graph structure. By applying PageRank to this graph, we can identify the most influential systems in terms of economic activity and strategic importance. This analysis provides insights into player behavior patterns and can assist in game balance adjustments and content development.

The methodology involves constructing a directed graph of the EVE Online universe, where nodes represent star systems and edges represent travel routes between them. The standard PageRank algorithm was adapted to incorporate game-specific metrics such as player traffic, trade volume, and combat frequency. The resulting rankings were compared against known important systems in the game, showing significant correlation with player population distribution and market activity.

In conclusion, PageRank algorithms offer a robust framework for analyzing player-driven virtual worlds. The application to EVE Online demonstrates the versatility of graph-based ranking methods in gaming environments, providing valuable insights for game developers and researchers studying virtual economies.

### What just happened?

You have created a new summary template for the news articles. The summary template includes an ordered list of the news articles, and each article is linked to the detail view. Then, you have added a Smarty tag in the template below the sidebar menu. You have used the parameter `summarytemplate` to specify exactly what template should be used to display the summary view of the news articles in this place. If you do not use the parameter, then the default template is used. In the standard installation of CMS Made Simple, the **Sample** template is taken by default. You can change the default template by clicking on the icon with the red cross in the column **Default** in the list of templates (**Content | News | Summary Templates**).

You can edit existing templates or create new custom templates. If you use the module for different tasks such as job opportunities, announcements, and company blog, you can create as many templates as you need. You can also specify which template should be used to display the output of the module at the place where the tag is called. An example call for displaying job opportunities on the website can be:

```smarty
{news summarytemplate="Jobs" detailtemplate="Job"
     category="Vacancies"}
```

For the preceding example, you should create a summary template with the name **Jobs** and a detail template with the name **Job**. You also need a **Vacancies** category where you add at least one job opportunity.
