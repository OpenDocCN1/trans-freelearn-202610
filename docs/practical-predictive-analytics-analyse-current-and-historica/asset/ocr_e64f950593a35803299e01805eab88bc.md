+   • Support vector machines are useful in situations in which you have high dimensional data. High dimensional data comes into play when you have a large number of variables appearing in the data, and you have chosen to use all or most of them in the model, without first applying some sort of data reduction technique. This can often occur as you apply analysis to some real-time data in raw form, in which case models need to be applied in split-second time.
