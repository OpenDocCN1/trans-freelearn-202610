+   - numClasses: This applies to the number of outcomes; in our case, it is 2.
+   - maxDepth: How deep would you like the decision tree to go? For illustrative purposes, we will set it to 2 levels deep, but for real-world problems, you should attempt to go a bit deeper. Remember, if you go too deep, the model will overfit.
+   - maxBins: In sparkR, you can go no more than 32 bins.
