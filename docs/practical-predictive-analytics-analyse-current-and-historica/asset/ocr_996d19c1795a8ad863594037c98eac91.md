We can see from the plot that males churn quicker than females. This is indicated by the matrix plot in the first row and third column. Note that a boxplot is produced since a continuous variable (`tenure`) is being compared with a categorical variable (`gender`). The matrix plot is a great way to quickly observe the single variable distribution as well as the pairwise plots. Single variable intersections that are continuous typically show density plots for that variable. For example, monthly charges (row 4, column 4) is clearly normally distributed with an average monthly charge of about $240. For count variables, barcharts are typically shown.
