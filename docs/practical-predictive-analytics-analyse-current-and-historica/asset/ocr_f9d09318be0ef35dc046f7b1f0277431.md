As mentioned earlier, the AUC is used for comparing models. Here is the AUC for the logistic model using only Age as a factor:

```
model2 <- glm(as.factor(Survived) ~ Age, data=titanic, family="bi
pred <- prediction(predict(model2), titanic$Survived)
perf <- performance(pred,"tpr","fpr")
plot(perf,main="AUC for Logistic Regression Titanic Model - Age O
abline(a=0,b=1)
```

We can see immediately that this single variable model has little predictive power. The AUC curve is similar to the preceding random diagonal reference line, which indicates no predictive power.
