Databricks notebooks contain the written code in the cell in the upper pane, followed by any output in the lower cell, similar to the tutorial code for the 'diamonds' data which is displayed next.

To run the current cell, simply click on the triangle icon on the right.

+   When the cell has run, you will be able to view your output below your code. That could be a plot or the output from the console. Always check for error messages and warnings, especially if the output is not what you expect.

+   Also note that there are some situations where no output at all is produced. That may be okay, but be sure to check the timestamp on the output cell to make sure the cell was actually run:
