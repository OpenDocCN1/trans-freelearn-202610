First, map each of the sales treatment to numeric variables:

```
Treatment_num <- as.integer(combined$Treatment)
```

Next, we can use the R table function simply to see how the two marketing campaigns have been mapped to numeric. Campaign A maps to number 1 and campaign B maps to number 2.

```
table(combined$Treatment,Treatment_num)
```

```
> table(combined$Treatment,Treatment_num)
```

| | Treatment_num |
|---|---|---|
| | 1 | 2 |
| Campaign A | 100 | 0 |
| Campaign B | 0 | 100 |

Now, run a biserial plot. You can restrict the x axis to the values 1 or 2, since you know in advance that there are only two values:

```
ggplot (combined,aes(x=as.integer(Treatment_num), y=Sales))
+ geom_point(size=1.5,shape=1)
+ geom_smooth(method=lm)
+ scale_x_continuous (breaks=c(1,2))
+ ggtitle("Point BiSerial Correlation of Campaign with Sales")
+ labs (x="Campaign Number",y="Sales")
```
