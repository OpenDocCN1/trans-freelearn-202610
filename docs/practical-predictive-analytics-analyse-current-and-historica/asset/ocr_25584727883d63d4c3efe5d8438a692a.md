# Indexing the classification features

Indexing is used to optimize data access and supply the parameters to specific machine learning algorithms in an acceptable format.

We will be incorporating the race variable into the decision tree model, so the first step is to determine what the different values of race are. Â We will do this by again using SQL to count the frequency by race. Â Notice we can say either "Group by Race" or "Group by 1" which is a shorthand reference to the first column specified in the select statement (which is race):

```
%python
dfx = spark.sql("SELECT race,count(*) FROM stopfrisk group by 1")
dfx.show()
```

Observe that there are eight values, Q, B, U, Z, A, W, I, and P:

| Q | 5090 |
| B | 11950 |
| U | 122 |
| Z | 298 |
| A | 1103 |
| W | 2514 |
| I | 77 |
| P | 1409 |
