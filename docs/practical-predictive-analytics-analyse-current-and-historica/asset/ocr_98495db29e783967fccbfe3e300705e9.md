# # Graphically displaying the clusters

We can plot the clusters in many different ways. The first thing you would want to look at would be histograms of the cluster segments. Remember, k-means likes to see approximately equal clusters:

```
#usually but now always the middle cluster is the average cluster
par (mfrow=c(1,3) )
hist(clusters3)
hist(clusters5)
hist(clusters7)
```
