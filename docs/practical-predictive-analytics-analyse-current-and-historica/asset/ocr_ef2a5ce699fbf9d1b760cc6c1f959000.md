The next step is to apply the power transformation to your existing data and assign the results to a new vector, y:

```
y<-bcPower(x,p$lambda) # Box-Cox transformation
```

The histogram of the new data (histogram of y in the following image) shows that the data has been transformed to a normal distribution, and the QQ plot, which measures normality, shows a nice straight line:

```
qqnorm(y)
# Normal probability plot for transformed variable
hist(y)
```
