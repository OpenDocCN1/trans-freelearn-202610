To store your App Analytics CSV file, you can create a dedicated dataset. Following this, a CRM Analytics dataflow can be built to connect your LMA packages with App Analytics logs.

# Visualizing your data using CRM Analytics

CRM Analytics enables you to create lenses, **key performance indicators** (**KPIs**), and dashboards for data visualization. Lenses offer a graphical exploration of data in a dataset and form the building blocks for dashboard queries.

# Creating a CRM Analytics dashboard

A dashboard can be created using your dataset and lenses, offering a visual representation of your data that simplifies interpretation and understanding.
