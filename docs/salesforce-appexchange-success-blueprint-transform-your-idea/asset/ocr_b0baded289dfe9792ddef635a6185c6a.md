# Ensuring customers use the latest package version

In the realm of Salesforce AppExchange application development and release management, there exists a golden rule: “Always ensure your customers are using the latest version of your application.” This is not merely a recommendation but a crucial aspect of maintaining app integrity, delivering a consistent UX, and minimizing security risks.

Push upgrades, as previously discussed, are an invaluable tool to effortlessly implement this rule. By automating the process of delivering updates directly to your customers’ orgs, push upgrades relieve customers of the responsibility of manually installing new package versions. Not only does this ensure all customers are using the most current and secure version of your application, but it also enhances the overall customer experience by eliminating the hassle of manual updates.
