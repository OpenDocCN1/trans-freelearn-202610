# Monitoring push upgrade results

To effectively manage push upgrades, it’s crucial to monitor their results. There are a few ways to do this, as follows:

+   - **Push Upgrade API**: This is a programmatic way to retrieve information about your push jobs, and it’s an effective method for large-scale or automated operations.
+   
+   - **Package Visualizer**: This is a comprehensive tool designed to provide ISVs with the ability to manage their applications more efficiently. Package Visualizer contains a feature that allows you to monitor push upgrade results, along with other crucial information about your packages.
