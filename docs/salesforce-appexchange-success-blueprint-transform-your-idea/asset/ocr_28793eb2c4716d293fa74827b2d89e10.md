+   - **Salesforce Code Analyzer**³: Uses multiple rule engines to scan your code, including Apex, Visualforce, JavaScript, and TypeScript. +   - **Checkmarx**: Scans solutions hosted on the platform, including Apex code, Visualforce elements, and Lightning components. As of 2023, when I’m penning this book, it’s a compulsory component of the security review process. Hence, any findings should either be addressed or noted as false positives. Looking ahead, it’s conceivable that Salesforce Code Analyzer might fully take over its role in the future.
