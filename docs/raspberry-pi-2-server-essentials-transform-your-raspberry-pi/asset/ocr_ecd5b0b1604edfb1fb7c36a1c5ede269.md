# Installing apps

While logged in as admin via the WebGUI, you can click on the top-left link, which is next to the ownCloud icon. A drop-down menu will appear, and you will see a button to add apps:

![](bbox=[0.253, 0.315, 0.747, 0.548])

The free edition comes with basic file support and some nice extras. The Enterprise edition comes with official support for **Calendar**, contact management, and synchronization.

On this page, you will see a list-enabled official apps, such as the picture or PDF viewers. There a few more apps that are disabled; to view them click on the **Not Enabled** menu item on the right-hand side.

No need to worry about the lack of apps though, as ownCloud was designed to be extensible. There is a massive collection of user made apps that you can install for free from https://apps.owncloud.com.

On the apps page, click on the cog icon in the bottom-left corner, and enable **Experimental Apps** to allow third-party apps to be installed.

If you experience any problems with viewing or starting downloaded apps, you may need to set the **www-data** owner on the folders that you will be creating.
