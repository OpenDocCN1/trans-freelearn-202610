# Discharge curves

When a battery cell starts to deplete, the voltage it provides drops a lot faster in the last 10% of its capacity. Looking at this graph, you can easily understand what this curve looks like at various discharge rates. If we used a 5V battery source, the Raspberry Pi would only run for about 60% of the batteries, power as it will soon drop below the 4.9V required for stable operation.
