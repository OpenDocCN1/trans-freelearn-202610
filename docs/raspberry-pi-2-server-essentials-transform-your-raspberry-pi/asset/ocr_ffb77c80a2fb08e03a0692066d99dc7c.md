> Amps = Watts / Volts (I = W/E)

+   - 60 watts / 240 volts = 0.25 amps (this is a light bulb)
+   - Once you know how many amps you need to transfer, you can use an American Wire Gauge (AWG) table to check the size of cable that you will require over the distance needed:
