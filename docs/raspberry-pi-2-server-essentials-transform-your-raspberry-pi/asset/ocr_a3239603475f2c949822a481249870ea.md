Then, you can flash the image onto an 8 GB minimum SD card from your Linux machine:

```
sudo dd bs=1m if=Flash.img of=/dev/<you_SD_card>
```

Or you can use Win32 DiskImager to burn the image from Windows, as described in Chapter 1, Getting Started with the Raspberry Pi for Rasbpian.

# The first boot

Insert your SD card, plug in a wired internet connection and an HDMI display, and turn on the power. The first boot will take a few minutes with some screen flashing and strange looking graphics or text. It will automatically reboot, and you will see a screen with a language selection. If you don't have a keyboard hooked up, the default (English) will get connected automatically; and then, you will see a screen similar to this one:

![](bbox=[0.175, 0.403, 0.825, 0.688])

On this screen, you will see the IP address assigned to the Raspberry Pi. You can type the IP with the port 8080 address into your browser, and you will be presented with a web GUI.

The default username is administrator and the password is p@ssw0rd.
