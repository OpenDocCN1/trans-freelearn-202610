This virtual host is configured to run on port 80, but in a virtual directory. The application in this virtual directory runs on its own thread, separate from anything else running on port 80. # Installing SQLite

SQLite3 is a self-contained, easy-to-install, lightweight transactional database. The product's website boasts that it is the most deployed database in the world. As we know from Wikipedia, it is actually the most deployed database on embedded devices, which still leaves MySQL as the most used database. None of this really matters to us because both these databases are very good at what they do, except that SQLite is a better choice if you are looking for much better performance on your Raspberry Pi 1:

```
sudo apt-get install sqlite3 php5-sqlite
```
