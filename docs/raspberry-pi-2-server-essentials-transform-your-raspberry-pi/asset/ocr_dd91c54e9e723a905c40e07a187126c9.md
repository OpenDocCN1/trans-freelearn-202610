# Installing the Java Hard-Float

We will need to go to https://jdk8.java.net/download.html, accept the terms, and copy the link to the Linux ARM 32bit for this. Now, we need to download the file, ignoring any certificate problems:

```
```
sudo wget --no-check-certificate <URL>
```
```

Then, enter these lines into the console and replace <filename> with the latest file you that have downloaded:

```
```
mkdir -p /opt
sudo tar zxvf <filename> -C /opt
sudo /opt/jdk????/bin/java -version
