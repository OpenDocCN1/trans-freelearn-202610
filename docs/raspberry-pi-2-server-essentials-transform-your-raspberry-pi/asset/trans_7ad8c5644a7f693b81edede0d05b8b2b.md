
## 3 配置额外功能

Broadcom 芯片上有一些额外功能，可以直接使用或通过购买额外许可证激活。其中许多功能未有文档记录，是由在各种 Raspberry Pi 项目上工作的开发者或爱好者发现的。

在本章中，您将学习如何保持 Raspberry Pi 保持最新状态，以及如何使用 GPU 的额外功能。

### 更新 Raspberry Pi

Raspberry Pi 本质上具有三个软件层：闭源的 GPU 启动过程、引导加载程序（也称为固件）和操作系统。在本书撰写时，我们无法更新 GPU 代码。但也许有一天，Broadcom 或硬件黑客会告诉我们如何做到这一点。

这就剩下固件和操作系统软件包了。Broadcom 会定期以预编译的二进制文件向 Raspberry Pi 基金会发布固件更新，后者再将其发布给公众。基金会和其他社区成员负责 Raspbian，并通过 aptitude 仓库发布更新；这就是我们获取所有精彩应用程序的地方。

保持固件和软件包的最新状态至关重要，这样您才能从 Broadcom 芯片的错误修复以及新功能或改进功能中受益。

Raspberry Pi 2 使用 ARMv7，而 Pi 1 使用 ARMv6。建议使用最新版本的 Raspbian 发布版以受益于速度提升。得益于升级到 ARMv7，它现在还支持标准的 Debian 硬浮点软件包和其他 ARMv7 操作系统，例如 Windows IoT Core。

### 更新固件

更新固件过去曾是一个相当复杂的过程，但由于 GitHub 上一位化名为 Hexxeh 的用户，我们有了一些代码可以自动为我们完成此操作。您不需要像 `apt-get update` 那样频繁运行它，但如果您不断升级操作系统，如果建议这样做或您遇到新功能或不稳定问题时，可能需要运行它。

`rpi-update` 命令现在作为 Raspbian 映像的标准组件包含在内，我们可以简单地运行以下命令：

```
sudo rpi-update
```

过程完成后，您需要重新启动 Raspberry Pi 以加载新的固件。

### 更新软件包

保持 Raspbian 软件包为最新状态也很重要，因为许多更改可能会与固件中发布的修复程序一起工作。首先，我们将更新源列表，该列表会将软件包列表及其版本下载到 aptitude 缓存中。然后，我们将运行 `upgrade` 命令，该命令将比较已安装的软件包并比较其依赖关系，然后相应地下载并更新它们：

```
sudo apt-get update
```

```
sudo apt-get upgrade
```

> 更新某些软件包如果库中有重大更改，可能会破坏您现有的自定义代码或应用程序。如果您正在运行自定义代码，在更新之前应始终查看发行说明，看看是否需要在代码中进行更改。

### 更新发行版

我们可能会发现，运行固件更新过程和软件包更新并不总是能解决特定问题。

如果您使用的是 `debian-armhf` 等发行版，可以使用以下命令而无需重新设置一切：

```
sudo apt-get dist-upgrade
```

```
sudo apt-get install raspberrypi-ui-mods
```

### 结果

如果您有一个长期运行或生产项目将独立运行，不建议不时登录来更新软件包。在 Linux 中，配置系统后让其在长时间内无需任何软件维护运行是可以接受的。您应该注意关键更新，并评估是否需要安装它们。例如，考虑 SSH 中的重大 Heartbleed 漏洞。如果您有一台 Raspberry Pi 直接连接到公共互联网，这将需要立即采取行动。

Windows 用户习惯于频繁更新，很少出现问题。但在 Linux 中，运行更新会更新您的软件和操作系统组件，这可能会与其他自定义软件不兼容。例如，您使用了一个开源 CMS 网络应用程序来托管一些文章。它专门为 PHP 版本 x 设计，但升级到版本 y 也需要整个 CMS 系统升级。有时，较不受欢迎的开源来源可能需要几个月的时间才能重构代码以使用最新的 PHP 版本，因此他们可能在不知情的情况下升级到最新的 PHP 或部分破坏您的 CMS。

一种解决方法是克隆您的 SD 卡并在一张卡上执行更新。如果遇到任何问题，您可以轻松返回并使用另一张 SD 卡。

一个名为 CentOS 的发行版试图通过每年发布一次更新来解决这个问题。其目的是确保每个人都有足够的时间在您进行完整更新时测试他们的软件，而不会出现最小或甚至没有破坏性更改。不幸的是，CentOS 没有 ARM 支持，但您可以遵循这一指导原则，在需要时更新软件包。

### 硬件看门狗

硬件看门狗是一个数字时钟，需要在达到特定时间之前定期重新启动。

就像电视剧《迷失》中一样，岛上隐藏着一个死人开关，需要定期按下；否则，将开始一个未知事件。就 Broadcom GPU 而言，如果开关未被按下，则意味着系统已停止响应，反应事件是重新启动 Raspberry Pi 并重新加载操作系统，希望至少暂时解决该问题。

Raspbian 包含一个用于处理看门狗硬件的内核模块——默认情况下处于禁用状态——。一个在软件层上运行的可配置守护进程会通过内核模块向看门狗发送定期事件（例如按下按钮），称为心跳。

### 启用看门狗和守护进程

要让一切正常运行，我们需要做以下几件事：

- 1. 在控制台中添加以下内容：
  ```
  sudo modprobe bcm2708_wdog
  sudo vi /etc/modules
  ```
- 2. 在文件中输入文本行 bcm2708_wdog。然后通过按 Esc 并输入 :wq 命令保存并退出。
- 3. 接下来，我们需要安装守护进程，该守护进程每 10 秒发送一次心跳信号。我们使用 chkconfig，将其添加到启动过程中，然后启用它，如下所示：
  ```
  sudo apt-get install watchdog chkconfig
  sudo chkconfig --add watchdog
  chkconfig watchdog on
  ```
- 4. 现在我们可以配置守护进程以执行简单检查。编辑以下文件：
  ```
  sudo vi /etc/watchdog.conf
  ```
- 5. 通过删除哈希（#）字符取消注释行 max-load-1 = 24 和 watchdog-device。最大负载意味着完成任务需要 24 个 Pi 在 1 分钟内。在正常使用中，这永远不应该发生，只有在 Raspberry Pi 挂起时才会真正发生。
- 6. 现在您可以使用此配置启动看门狗。每次更改某些内容时，您都需要重新启动看门狗：
  ```
  sudo /etc/init.d/watchdog start
  ```

配置文件中还有一些其他示例可能引起兴趣。

### 测试看门狗

在 Linux 中，您可以使用命令行上的 & 字符轻松将函数放入单独的线程中，在新进程中运行。利用此功能以及一些匿名函数，我们可以发出非常粗糙但有效的系统停止。这是测试看门狗守护进程是否正常工作的快速方法，不应用于停止 Raspberry Pi。它被称为 fork 炸弹，许多操作系统都容易受到此攻击。

看似随机的字符序列实际上是创建其他新匿名函数的匿名函数。这是一个无休止且不可控的循环。它很可能采用炸弹这个名字，因为一旦开始就无法停止。即使您尝试杀死原始线程，它也会创建多个需要被杀死的线程。根本不可能停止，最终它会将系统炸入关键状态，也称为堆栈溢出。输入这些字符到命令行并按 Enter：

```
: () { : | : & } ; :
```

按 Enter 后，Raspberry Pi 应在大约 30 秒后重新启动，但可能需要长达一分钟。

### 启用额外解码器

Broadcom 芯片实际上具有用于编码和解码其他几种知名格式的额外硬件。Raspberry Pi 基金会未包含这些许可证，因为他们希望将成本降至最低，但他们已包含 H.264 许可证。这使您可以在电视上观看高清媒体、使用网络摄像头模块或转码媒体文件。

他们确实为用户提供了一种购买单独许可证的方式，如果您想使用这些额外编码器或解码器。

在撰写本文时，使用这些硬件编解码器的唯一项目是 XBMC 维护的 OMXPlayer 项目。最新的 Raspbian 软件包已包含 omx 软件包。

### 购买许可证

您可以前往 http://www.raspberrypi.com/license-keys/ 购买许可证，每个设备只能使用一次。按照网站上的说明获取您的许可证密钥。
