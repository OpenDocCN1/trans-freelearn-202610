## 简介

欢迎阅读 *Instant Backbone.js Application Development*。本书将指导您完成下载和安装 Backbone.js 及其依赖库的步骤，运行一个简单的 Hello World 应用以确认安装，最后介绍各类代码分类，以便您构建一个简单的联系人管理器。您甚至还将构建一个快速服务器应用来持久化数据。
