This might not be the best approach to analyzing an email and seeing whether or not it’s a phishing attack, but it has the advantages of isolating the sentence from the rest of the email context and doing a sort of blind test against a referential. It also has the drawback of dissolving the context at the same time.

The semantic search here reveals that out of the 1,677 emails that have been selected in our dataset, 448 were spam, which represents a score of 27% just for this specific portion of text. Now, can we conclude that this is spam? Not at this stage.

So, we really have two options:

+   - We can run a query with the entire email corpus. The challenge with this method is that it will restrict the numbers of similar emails drastically if it’s not standard spam.
+   - Alternatively, we can run the same query here for a different overlapping portion of text and build up a global score.
