# An Elastic Cloud quick start

From now on, you will need a sandbox where you will be able to run the example in this book. You need to have a running Elasticsearch instance and a Kibana instance. The shortest and best path for that is using Elastic Cloud. If you haven’t done so yet, sign up at https://cloud.elastic.co.

Once done, log in and go ahead and create a new deployment by clicking on the Create Deployment button:
