# Plugin code

The plugin must comply with the OpenAI documentation to be validated and installed in ChatGPT. We will start by looking at the repository structure, and then go on to the creation of some necessary files as well as the implementation code to achieve our goal.

# Repository structure

The repository structure is simple, as shown in the following screenshot:

![](bbox=[0.27, 0.26, 0.69, 0.44])

Figure 10.13: ChatGPT plugin repository structure

Let’s break down the structure:

+   - The main service code is in app.py
+   - The plugin’s logo (logo.png) is what will be displayed in the ChatGPT plugin store
+   - The plugin manifest is stored in the ai-plugin.json file under the .well-known directory
+   - The OpenAPI descriptor is contained in the openapi.yaml file

Note that we use a Dockerfile here as an asset to deploy the plugin. The plugin deployment platform can vary based on what you have available; I am using Google Cloud Compute. You will need to pick your preferred deployment platform or cloud provider. The plugin code deployment is beyond the scope of this book. Now, let’s take a look at the code that exposes our API.
