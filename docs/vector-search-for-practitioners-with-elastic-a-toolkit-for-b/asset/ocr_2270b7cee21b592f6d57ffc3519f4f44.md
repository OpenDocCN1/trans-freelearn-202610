# Approach 2—generating human-understandable descriptions and vectorizing these descriptions

In this approach, a model is used to generate human-understandable descriptions of raw logs. These descriptions are then vectorized using a general-purpose language model (such as BERT or GPT) that has been trained on a large corpus of general text data. The resulting embeddings capture the semantic content of the descriptions derived from the original logs. We can see this process depicted in Figure 7.2.

# Pros
