# Expected results

Once the PII redaction pipeline has been configured and set up in Elasticsearch, the expected results are as follows:

+   - When the NER model identifies an entity, that entity will be replaced with the corresponding entity type enclosed in angle brackets. For example, if the NER model identifies a person’s name, it will be replaced with <PERSON>.
+   - When a regex pattern matches a value, that value will be replaced by the term <redacted>. This ensures that sensitive information, such as phone numbers and SSNs, is never visible in the processed data.
