The number of hidden units in a hidden layer is a hyperparameter of the network, and it can have a significant impact on a network's performance. A larger number of hidden units will benefit NLP use cases, since it allows the network to learn more complex representations of the input data. However, it makes the network more computationally expensive to train and evaluate.
