使用 `Inset` 为齿轮添加细节

**4.** 进入 `Edit`（编辑）模式，我们可以开始将这个圆柱体塑造成我们需要的齿轮。隐藏神器的顶部和底部部分，以便你只能看到我们正在处理的部分。选择前面的多边形并按 `I` 进行 `Inset`（内插）操作。我做了一个 `5cm` 的 `Inset`。然后我们将再次 `Inset` `5cm`。完成后，对背面的多边形做同样的操作： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_16.jpg)

删除两侧中间的多边形环

**5.** 选择我们刚创建的中间多边形环并按 `Delete`（删除）。当询问删除什么时，从菜单中选择 `Faces`（面）。就像之前一样，对背面做同样的操作： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_17.jpg)

使用 `Bridge Edge Loops`（桥接边循环）创建更多细节

**6.** 是时候使用 `Bridge Edge Loops` 工具了！从 12 点钟位置开始，选择内侧多边形上的第一条边及其对应的外侧多边形上的边。按 `W` 并选择 `Bridge Edge Loops` 工具。看那个漂亮的新多边形！现在对圆周上每隔一条边做同样的操作。和之前一样，在齿轮的背面也做同样的操作。在下一步中，我们将构建齿轮的内部多边形：

### 提示

如果创建这些新多边形时出了问题，别担心。只需按 `Ctrl + Z` 撤销并重试！

![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_18.jpg)

使用 `Bridge Edge Loops` 创建齿轮形状的内部部分

**7.** 为齿轮臂添加内部多边形是一个四步骤的过程。我们需要使用 `Bridge Edge Loops` 工具在每个孔中创建四个多边形以封闭部件内部： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_19.jpg)

挤出并缩放以在齿轮中心创建更多细节

**8.** 齿轮中心旨在看起来像是托住一枚奖章或护身符，这是另一个分多步、少量进行的操作。选择齿轮正面的中心多边形并向外 `Extrude`（挤出）。接下来，将其 `Scale`（缩小）一点点，开始为将要嵌入的孔创建一个边缘： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_20.jpg)

挤出并倒角中心以完成细节

**9.** 现在，对多边形进行 `Inset`（内插）以创建边缘的顶部。通过向内挤出多边形一点并 `Scaling`（缩小）它来创建边缘的其余部分。最后，向外 `Extrude`（挤出）并对多边形进行 `Bevel`（倒角）以完成形状： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_21.jpg)

使用单独挤出添加齿轮齿

**10.** 没有齿的齿轮算什么？要创建齿，我们要 `Extrude`（挤出）齿轮外侧与内侧臂对齐的多边形。我们可以一次性选择所有多边形，并从 `Tools`（工具）面板中选择 `Extrude Individual`（单独挤出）。这允许我们挤出每个多边形，使齿轮齿大小一致。之后，只需将齿端的每个多边形 `Scale`（缩小）一点点。我将每个缩放了 `0.75`： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_22.jpg)

将背面多边形向外挤出一点，为齿轮连接神器创建位置

**11.** 到了最后润色的时候了！选择背面多边形并向外 `Extrude`（挤出）以创建一个齿轮可以旋转的柱子。这将为齿轮安装在神器底部创建一个良好的接触点。

为了打开，神器使用活塞来抬起盖子。设计要求在物体底部周围间隔放置七个活塞。我们在这里要偷个懒，只创建一个活塞，然后复制它来创建另外六个。

关于 3D 建模，我学到两件大事。第一是聪明工作比努力工作更重要。第二是有时我们构建东西只是为了让它们看起来很酷！

既然活塞本身是圆的，我们再次从老朋友圆柱体开始。让我们开始吧！

# 活塞建模

**1.** 创建一个新圆柱体。我将我的设置为 `32` 个 `Vertices`（顶点），`3.75cm` `Radius`（半径），以及 `15cm` 的 `Depth`（深度）： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_23.jpg)

从圆柱体开始，使用 `Loop, Cut, and Slide`（循环切割滑移）添加两个新的边循环

**2.** 为了创建更宽的中间部分，选择所有中间的多边形并使用 `Loop, Cut, and Slide` 工具在中心周围添加两个新的边循环。再次点击以确认切割。现在点击 `Tools` 面板中 `Extrude` 下拉菜单并选择 `Region (Vertex Normals)`（区域（顶点法线））。这将使所有多边形从中心向外均匀挤出。

**3.** 让我们把底部弄圆。`Extrude`（挤出）活塞的底部多边形，然后对其使用 `Bevel`（倒角）工具。这应该会给我们一个漂亮的圆头： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_24.jpg)

为活塞添加边缘

**4.** 为了增加细节，给活塞顶部加个边缘，就像我们对齿轮正面做的那样。将顶部多边形 `Extrude`（挤出）一点点，然后 `Inset`（内插）一点，最后将多边形 `Extrude`（挤出）回活塞内部： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_25.jpg)

创建一个新圆柱体并定位它，使其看起来像是从底部活塞部件延伸出来的

**5.** 现在活塞必须伸展以将盖子抬得足够高，以便里面那个阴险的东西能出来。我们可以通过创建一个伸缩部分来抬起盖子来实现这一点。你可能会觉得这听起来很难，但记住，要聪明工作，别笨干。我们可以通过创建第二个圆柱体从第一部分延伸出来来创建这个部分。创建一个 `32` 个 `Vertices`（顶点），`3cm` `Radius`（半径），`13cm` `Depth`（深度）的圆柱体。将其与我们活塞的底部对齐。你可以按 `Z` 切换到线框视图以获得更好的视野。再次按 `Z` 返回实体视图： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_26.jpg)

完成的活塞

**6.** 为了将其升得足够高，我们需要给活塞添加几个更多的部分。获取第一部分并 `Duplicate`（复制）它。然后向上移动以与最后一部分的顶部对齐。最后将其缩放至 `0.75`。要制作下一部分，重复上述步骤。你会得到三个部分，当它们向下移动时，会整齐地嵌套在一起。当我们为神器开合制作动画时，我们将展开和压缩这些部分，以产生它伸缩向外的错觉。

**7.** 为了完成活塞，`Duplicate`（复制）我们创建的第一个部分并使其成为顶部： ![在 Blender 中使用多种形状](OEBPS/Images/BO5189_06_27.jpg)

在神器周围复制活塞，使总共有七个

**8.** 所有活塞部件完成后，抓取你完成的活塞并在神器周围以等距间隔 `Duplicate`（复制）它，类似于图片中的样子。

活塞就做完了！只剩下最后一组主要部件需要完成了，在我看来它们是最有趣的：触手！设计要求触手用作手柄和腿，赋予神器一种异世界的感觉。为了制作这些怪诞的创造物，我们将使用 `Bezier Curve`（贝塞尔曲线）和一些修改器的组合，沿着路径复制一段触手。这还有一个额外的好处，就是让它们灵活且易于摆姿势。
