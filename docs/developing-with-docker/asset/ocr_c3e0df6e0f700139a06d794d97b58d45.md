When started, you can access the default nginx welcome page at your host machine local address and mapped port 8080 by using the link http://localhost:8080.

![](bbox=[0.1, 0.17, 0.9, 0.42])

As an alternative to the ps command, you can execute the port command, using the container ID as a parameter (the ID that Docker has given back during the container startup) to determine what ports have been mapped. The following is the port in my case:

```
docker port
 e1926dc061c5125b5aa3fd2685bcda4cf26ee99def4b2a1ae5e53721b88231c1
```

As a result, Docker will output the mapping, saying that port number 80 from the container has been mapped to the port number 8080 on the host machine:
