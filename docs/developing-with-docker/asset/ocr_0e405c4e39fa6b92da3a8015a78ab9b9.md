The /etc/hosts linking is persistent – if you restart the source container and it will be given a new IP address, the linked container's /etc/hosts files will be automatically updated with the source container's new IP address.

The second important thing that will happen when creating a link, is the transfer of some exposed environment variables from the container we are linking to. Take a look at our linked Ubuntu container; it magically knows a lot about the location and setup of the linked MySQL database, all thanks to the --link option (and of course, thanks to the properly defined MySQL image, exposing this information):
