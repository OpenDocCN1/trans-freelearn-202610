At first, let's verify if the virtualized Linux machine is working properly, by executing the command:

```
docker-machine ls
```

ls stands for list command and lists the virtual machines configured on your Windows. The currently running machine will have a star in the ACTIVE column and the status Running in the STATUS column:

![](bbox=[0.1, 0.27, 0.9, 0.38])

Next, execute the following command to run the image:

```
docker run hello-world
```

This will give you the same output as in Kitematic:
