Our application is now packaged as a `helloDocker-0.1.0.jar` file in the target directory of the project. Let's do the trial run and execute the command:

```
java -jar target/helloDocker-0.1.0.jar
```

The spring application will boot and present some log output on the console:

By default, Spring Boot applications listen to HTTP requests on port 8080; we will expose this port to the Docker image in a while. At the same time, enter the http://localhost:8080 in your web browser, to verify that our application actually works properly and responds to HTTP requests.
