This will pull the image tagged 1.0 from the someOfficialImage official repository located on someRegistry.com. You can also shorten the command by omitting the user or organization name completely. Our command will then look just like this:

```
docker pull someRegistry.com/someOfficialImage:1.0
```

As you remember, if you do not provide a registry hostname, Docker will default to its own official registry, the Docker Hub.

Now we should have a full understanding of what the image name consists of. It should be easier to precisely locate an image to pull. You can find public repositories and images from Docker Hub in two ways. You use the Docker Hub website or you can use the Docker command-line tool to run the docker search command. Let's search for an image now.
