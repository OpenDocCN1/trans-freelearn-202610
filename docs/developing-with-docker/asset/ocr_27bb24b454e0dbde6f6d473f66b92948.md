# Packaging Angular.js application

In this example, we are going to create a simple Angular.js application which runs on node.js runtime. For the purpose of clarity of example, we are not going to introduce any tests. As it was the case with SpringBoot application, our Angular.js application will be as simple and tiny as possible. We are going to understand how to containerize it instead of diving into Angular.js development. Of course, you are more than welcome to get to know Angular.js if you haven't done this already; it's a wonderful technology. Before you start, you will need to have node.js installed. You can get the installer from node.js website at https://nodejs.org/en/.

First, let's divide the structure of our application in two parts. The first one will be frontend, will all the static resources such as Java Scripts and HTML files. The second one will be node.js backed, actually serving our frontend files and responding to HTTP request. The folder structure, having the angular-docker-example as a parent directory, would initially look similar to the following screenshot:

![](bbox=[0.24, 0.52, 0.78, 0.58])

We are going to use Bower to manage third-party JavaScript libraries. Bower uses the bower.json file in which you define all the application that need to run. At this time, we only need a single angular.js dependency. Here's our little application's minimal bower.json file:

```
```json
{
  "name": "hello-docker-angular ",
  "ignore": [
    "**/*",
    "node_modules",
    "bower_components"
  ],
  "dependencies": {
    "angular": "~1.5"
  }
}
```
