Starring a repository serves the same purpose as stars on the GitHub—it’s a way to show that you like a repository. Stars function also has an easy way of bookmarking your favorite repositories. As of the time of writing this book, the ubuntu repository was the most starred one. Let’s begin with account creation.

# Docker Hub account
