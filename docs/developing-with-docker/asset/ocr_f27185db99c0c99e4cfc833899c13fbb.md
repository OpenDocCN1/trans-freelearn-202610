If you click on the **Launch Instances** button, the start process begins and the status will be shown:

![](bbox=[0.1, 0.16, 0.9, 0.4])

You can also check the status of your AWS instance by picking **Instances** from the **Management Console** menu. It's a handy page, useful to manage all your instances. The status page will list all your cloud machines, their status such as running or stopped, and also their public IP that you can use to log into the instance:

![](bbox=[0.1, 0.51, 0.9, 0.62])

Our newly created instance seems to be running fine, so let's try to log into its shell. Head to the directory you previously saved the keys to that was generated by Amazon, and execute the following commands:

```
chmod 400 MY_EC2.pem.txt
ssh -i MY_EC2.pem.txt ec2-user@52.58.22.247
```
