The `docker exec` can be a little confusing with the `docker attach` command we have already mentioned when learning about the detached containers. It's worth noting, that the `docker attach` isn't for running an extra thing in a container, it's useful for attaching to the running process. Also, if the main process is a shell, then we can run a new process using attach. The `docker exec`, on the other hand, is specifically designed for running new things in a container that is already started.
