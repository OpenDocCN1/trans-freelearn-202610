# 第 1 部分 – 企业架构基础与实施
在本第一部分中，您将了解 **企业架构**（EA）的关键核心基础组件以及如何将其与 AWS 云相关联。本书的这一部分将帮助您通过构建正确的核心基础，将 EA 架构原则和域应用于 AWS 云。

如果您需要了解 EA 核心基础的基本概念或希望了解其重要性，关于核心基础的前三章将帮助您做出决策并实现业务价值。通过此，您将学习如何实现业务敏捷性。您将更好地解释架构的构建模块，以推导出由架构和解决方案构建模块共同驱动的解决方案。

EA 基础和实施帮助您实现运营效率并帮助您定义核心基础的成功。

组织通常难以跟上不断发展的技术。因此，创新和增长过程会放缓。向前发展的途径是通过实施 EA，使组织在业务流程中导航以实现期望的业务成果。因此，现在比以往任何时候都更需要一个结构良好且经过深思熟虑的业务敏捷模型。

到这些章节结束时，您将能够通过构建核心基础来执行 EA 策略。您将更能够处理系统内持续进步带来的不断适应需求。此外，了解执行策略的核心基础背景也很有帮助。



您将更深入了解企业架构领导力原则中的业务动态，以及如何建立正确的核心基础。

本书的这一部分包含以下章节：

-   *第1章，企业IT架构构建的核心基础*
-   *第2章，定义核心基础以及如何正确实现*
-   *第3章，将企业架构应用于AWS云*
