## 前言
为了构建基于云的系统，您必须了解决策的利弊。您可以使用 AWS Well-Architected Framework 来帮助您在利弊之间保持平衡。利用该框架的六大支柱和 SAFe 策略，您将学习如何设计和运营可靠、安全、高效、经济且可持续的系统。本书阐明了企业架构的重要性、它如何融入 AWS 以及与 SAFe 的关系。到本书结束时，您将了解如何在 AWS 云上应用 SAFe 与企业架构原则，并结合云和 SAFe，在 EA 设置下实现/应用最佳实践。

## 本书适合谁
本书是面向有经验和非经验的 IT 架构师的参考资料，他们希望了解 EA 与 SAFe 方法论在 AWS 云中的实际应用。如果您是一名 IT 专业人士，有兴趣学习如何将 EA 原则应用于 AWS 云，特别是采用敏捷方法，那么本书将证明极其有用。

## 本书涵盖内容
- 第 1 章《构建企业 IT 架构的核心基础》提供了对 EA 核心基础及其需求的基本理解。它探讨了核心基础如何帮助实现业务价值，以及组织如何实现最高业务敏捷性和核心基础作用。我们将进一步解释架构的构建模块以推导出解决方案构建模块。到本章结束时，您将对利用核心 EA 组件实现运营效率有所了解。
- 第 2 章《定义核心基础以及如何做对》深入探讨 EA 所有权、角色和职责的基础，并结合推导出 EA 实践的领导原则概述。体现无效核心基础的方式、构建、优化和执行企业正确的核心基础。IT 参与模式、设定 EA 目标和优先级。最后，我们将了解从 EA 资产中实现业务价值所涉及的内容。
- 第 3 章《将企业架构应用于 AWS 云》探讨 EA 在云中的作用及其与 AWS 的一致性。它可以对云采用以及与云采用相关的任何项目产生积极影响。本章介绍适用于云和架构领域的 EA 原则，以及如何在支持 EA 的前提下设置 AWS 服务，以及 EA 的哪些角色和职责在 AWS 中发挥主要作用。
- 第 4 章《企业架构的可用框架》重点关注了解 EA 可以在何处以及如何实施的重要性、当前可用的框架以及何时使用它们。EA 以何种方式为行业做出贡献，其目标是什么？我们将讨论 EA 使用的工具和软件，包括应用组合管理和 EA 工具。架构的当前、目标和过渡状态的识别将随后是 EA 在数字化转型背景下的解释。
- 第 5 章《AWS 指导性框架》涵盖为企业制定框架以确保 EA 启动并朝正确方向发展，并确定 EA 的薄弱领域。本章重点了解 AWS 指导性框架，包括 MRA、CAF 和 WAR，并与 TOGAF 等框架保持一致。还讨论了就绪评估流程、先决条件和下一步。
- 第 6 章《TOGAF 框架在 AWS 中的实践》在 AWS 背景下探讨 TOGAF 架构域和云生态系统，并回顾参考架构和模型。本章深入探讨在 AWS 云转型中处理 TOGAF ADM 每个阶段的方法。我们将确定系统的非功能方面，包括安全性、可靠性、运营卓越、性能效率和成本优化。
- 第 7 章《将敏捷框架与企业架构对齐并扩展》考察在整个企业中选择 IT 计划并深入探讨驱动架构构建模块和解决方案构建模块的策略。本章讨论并解释基础设施的方法，包括本地、云和混合实施和应用。此外，我们将讨论 SAFe 如何很好地契合 EA，将 EA 和 SAFe 与任何业务保持一致，以及它如何满足 AWS 云客户的需求。
- 第 8 章《SAFe 在 AWS 云迁移中的实施》深入探讨云迁移以及组织应从何处开始其旅程。我们将从特定行业的角度审视云的含义，并确定它是否会是正确的选择或采用策略。谈到云转型，采用敏捷或 SAFe 如何提供帮助？本章进一步缩小到可确保云迁移在 SAFe 敏捷性下取得成功的步骤。
- 第 9 章《建立企业架构实践》主要关注 EA 启用就绪度。本章介绍了解建立 EA 实践的过程和流程。此外，确定了所有者，并为每个所有者确定了工作流程以及角色和职责。本书的这一部分还解释了 EA 建模语言，并提供有关 ArchiMate 的更多详细信息，以及将推动企业 EA 路线的最佳实践和架构原则。
- 第 10 章《结论》旨在总结所有前一章。它关联各章的流程顺序并将其统一起来。本章还重点介绍关键 AWS 框架、TOGAF 9.x 概述与 ADM，以及 SAFe 如何与 TOGAF 和 AWS 保持一致。
