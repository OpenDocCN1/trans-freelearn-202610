# 第 3 部分 – SAFe 在企业架构与云中

随着本书进入后半部分，重点主要在于学习 **规模化敏捷框架**（**SAFe**）的概念和术语，并理解 SAFe 原则如何应用于企业架构（EA）和云计算总体上，特别是 AWS。云到云迁移也可能给结构松散的组织带来多重挑战，例如停机和适应新的云环境。将云应用程序带回本地数据中心涉及将其从云迁移到本地服务器。

公司领导者和利益相关者往往在将 The Open Group Architecture Framework 付诸实施后发现难以推进。因此，在整个企业范围内选择 IT 计划并决定推动架构构建块和解决方案构建块的策略至关重要。这些章节解释了基础设施的策略，包括本地、云和混合实施与应用。

最困难的事情之一是以一种富有成效的方式开始旅程，从而带来创新和增长。本书的这一部分将确定云是否适合您。如果是，那么您应该从哪里开始？

讨论 SAFe 方法、先决条件以及成功增值迁移成果的实现是这些章节的主要目标之一。一旦成功实施，云迁移的好处将非常明显，包括高可扩展性、更好的性能和出色的数字体验。

总体而言，您应该期望了解更多关于云采用和迁移框架的知识。确保迁移成功在有效策略和生产力方面可以成为真正的游戏规则改变者。

本书的这一部分包含以下章节：
- *第 7 章，将敏捷框架与企业架构对齐并扩展*
- *第 8 章，SAFe 在 AWS 云迁移中的实施*
