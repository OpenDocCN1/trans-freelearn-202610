
-   **供应商锁定：** 如果你被锁定，你可能会依赖你的云服务提供商。如果你的系统全部使用单一厂商的工具开发，更换厂商可能会很困难。

基于客户反馈和团队节奏，敏捷史诗具有灵活的范围并使用客户反馈。

为了开发团队取得成功，史诗应该包含其所需的所有资源。在工作层级方面，它们处于顶层。除了为评估史诗提供上下文之外，了解每个史诗如何融入其他敏捷结构也很重要。

## 不断变化的业务影响 IT 格局

企业必须轻松评估业务格局的变化如何影响 IT 格局，以及这些变化如何影响其运营、客户体验和增长能力。对这些影响的理解可以帮助推动转型进程向前发展。IT 架构师在确保 IT 基础设施精简且敏捷以处理即将到来的业务转型项目方面发挥着至关重要的作用。

组织的企业架构由其业务需求指导。他们负责定义信息、业务和技术在组织内部的流动方式等事项。为了保持竞争力，公司更加关注云计算、物联网和 **机器学习（ML）** 等新兴技术。

人、数据和技术可以结合起来，为 IT 组织提供对其相互关系的全面理解。所有者、设计师和建设者在设计过程中对组织整体进行全面审视。它旨在从整体视角提供企业视图，而非依赖正式文档。

为了有效实施 EAP 策略，至关重要的是要考虑业务流程、组织结构和信息技术方面的最新变化。将讨论组织的各个方面，例如标准语言和最佳实践，以及如何集成或消除流程。拥有可靠、及时和高效的业务信息至关重要。

你可以确信的一件事是数据资产将呈指数级增长。可扩展的企业架构、流程和服务将变得越来越重要。需要回答的关键问题是我们的资产管理工具是否能随我们的资产自动扩展。

要在企业架构中取得成功，拥抱协作并突出你的努力的价值。让组织各部分的利益相关者参与你的工作至关重要——并确保他们也能从中受益。利益相关者应使用数据做出更有效的战略决策。为他们提供他们应期望的信息。在当今世界，企业架构师专注于优化和定制业务能力以实现目标或交付预期结果。通过将业务能力作为投资组合来处理，我们可以帮助组织投资于正确的能力。这种数字化转型促使组织想出新的方法来跟上数字曲线以保持竞争力。通过使用基于结果的架构，这些组织能够应对数字化转型的影响。利用这些新颖的方法，使得从传统到数字 EA 的转变成为可能。

此外，似乎创建领域专家社区的趋势，而不是单一的 EA 团队，正在转变。为了使企业架构取得成功，必须能够让组织内的多个业务部门和 IT 团队协作、进行讨论并考虑不同的架构方法和观点。由于敏捷工作者的数量不断增加，EA 在治理方面也发挥了更重要的作用。它传统上仅用于项目团队和解决方案，并由企业架构委员会管理。采用灵活治理模型的企业架构促进协作，使企业架构能够融入公司的文化。在传统的 EA 交付物形式中，静态文档难以维护和更新，因为它不稳定。由于数字企业架构的演进，中央存储库可以随着时间的推移作为驱动企业敏捷性的事实来源而得到更新和维护。数字企业架构通过创新管理在培养组织的创新文化方面发挥着至关重要的作用。这里强调颠覆性或增量性变化。如果数字 EA 想要成为数字变革引擎，它必须拥有一个管理良好的创新流程。
