
## 摘要

那些痴迷于客户需求并始终领先一步以跟上最新行业趋势的组织，了解企业成功的关键。由企业架构（EA）推动的、对云中工作负载的业务规划、设计和实施的一致且全面的策略，是前进的正确方式。每家公司都有一套各利益相关方必须遵守的准则和法规。此外，随着时间的推移，技术进步对于推动公司迈向成长和创新至关重要。

云为企业架构提供了充分的自由去尝试新技术，因为它提供了更好的合规性、安全性和工作负载管理。基于假设的不利情况来制定下一步策略的商业技巧之一被证明相当富有成效。

用于指导架构开发的某些原则需要与组织自身定义的架构能力保持良好一致。这些原则是根据其特征、影响以及在不同情况下的理由来定义的，如本章所述。

下一章重点关注新的数字环境，该环境需要对企业架构进行更具适应性的概念化以实现预期影响。数字化转型对企业架构有影响，我们将对此进行探讨。

### 具有目标的企业架构用例

在合适的人手中，企业架构师可以帮助其公司驾驭数字化转型，这可能为其组织带来长期的实质性益处。这将使他们的公司能够确保符合法规。例如，考虑 **欧洲联盟（EU）** 的 **《通用数据保护条例（GDPR）》**。

该法规对终端用户个人数据管理施加了多项新规则。未遵守 GDPR 的公司将被罚款最高达 2000 万欧元或上一财年全球年营业额的 4%。为了证明 GDPR 合规性，企业架构师需要确保所有相关数据以清晰简洁的方式收集和呈现。

业务架构师能够在三个特定领域创造价值：推动增长、确保合规以及降低复杂性。组织必须不断创新以保持竞争力。组织在实施关键 **信息技术（IT）** 趋势时常遇到困难——例如微服务、**物联网（IoT）** 和云迁移——这些趋势有可能增加其市场份额。除了加速 **上市时间（TTM）**、创造新的收入来源、降低硬件成本和减少昂贵的复杂性外，这些趋势对公司来说可能极具价值。未来，企业架构师将能够支持其公司的数字化转型，如果做得正确，这可能带来成本降低和利润增加。

过去几年中 IT 的无限制增长导致了重复系统的出现，这些系统带来了多重弊端和重叠功能。这些系统生成不一致且过于复杂的数据。企业架构师登场。他们的角色是直面这些问题，通过提供管理并降低复杂性的路线图，从而直接有助于降低成本。

作为顶级架构师，**企业架构师** 负责企业架构设计。因此，他们的职责范围很广。在企业架构中，IT 资产和业务流程与一套指导原则一起映射，这些原则有助于推动关于业务战略及其如何通过 IT 表达的持续讨论。

**解决方案架构师** 比专注于特定应用的 **应用架构师** 高一级。解决方案架构师关注解决方案，而企业架构师关注整个组织。**应用架构师** 专注于一个功能。这些角色很少与客户互动，因此不需要太多业务经验。随着经验的积累，许多解决方案架构师会成长为企业架构师。

一个基础扎实且与业务目标和技术战略高度一致的有效企业架构可以为组织带来巨大益处。以下是企业架构的一些更具体的目标：
- **业务运营：**
  - 降低业务运营成本
  - 更敏捷的组织和工作流程
  - 可在整个组织中访问的共享业务能力
  - 降低变更管理成本
  - 提高业务生产力以确保更高效率
- **数字化转型与 IT 运营：**
  - 通过增强的数字能力扩展企业的覆盖范围
  - 通过整合所有企业组件确保统一的环境
  - 降低软件开发、支持和维护费用
  - 提高应用的可移植性比例
  - 便捷的系统和网络管理以及改进的互操作性
  - 关于关键企业问题的更好沟通
  - 轻松升级系统组件
- **更好的 IT 投资：**
  - 消除业务和 IT 中的复杂元素
  - 当前业务和 IT 网络的更高 **投资回报率（ROI）**
  - 更轻松地外包业务和 IT 解决方案
  - 新的、风险更低的投资、问责制和更有效的成果
- **更快、更简单、更便宜的采购：**
  - 在连贯的计划中提供可访问的采购管理信息，以简化采购决策过程
  - 更快的采购流程，在保持架构一致性的同时提升整体速度和灵活性
  - 多供应商开放系统的能力
  - 增强获取更经济、IT 和业务能力的机会

系统的价值在需求更高的地方更容易被认可。企业架构也是如此；它在为简化高度复杂的 IT 环境而努力的大型企业中发挥最有效的作用。缺乏多样化能力的业务模式产生了对有效企业架构的关键需求。
