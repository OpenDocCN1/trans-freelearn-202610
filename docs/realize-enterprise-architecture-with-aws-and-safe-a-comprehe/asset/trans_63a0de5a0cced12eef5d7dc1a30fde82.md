## 贡献者

### 关于作者

**Rajnish Harjika** 是一位技术精湛、以目标为导向的 IT 领导者，也是 TOGAF 9.1 实践者，拥有 25 多年的成功经验，带领高绩效团队从构思到交付设计和构建前沿解决方案。他在交付能够大幅提升效率和技术卓越性的数字和云转型方面拥有深厚历史。他能够通过比较当前和目标架构、监控合规性并实施关键安全措施来减轻并显著降低风险。Rajnish 在为业务转型、数字化转型和云转型提供战略咨询方面具有丰富的专业知识。

### 关于审阅者

**Vibhu Kuchhal** 是一名企业架构师，热爱利用各种架构工具和技术协助利益相关者解决业务问题。他经常协助客户理清现有业务、技术和能力投资，并帮助优化期望的转型。Vibhu 拥有丰富的实施范式和技术工作经验，并曾领导团队为客户交付大规模转型。

Vibhu Kuchhal 目前担任 Telstra Purple 的管理顾问，该组织将人置于为组织解决实际问题的中心，使其能够以目的性地交付出色的数字化转型。
