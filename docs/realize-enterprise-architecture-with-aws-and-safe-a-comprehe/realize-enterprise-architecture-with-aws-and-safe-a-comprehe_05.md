# Part 2 – 企业架构框架

展望未来，了解企业架构最流行的框架是我们希望在本节中实现的目标。你应做好准备，深入探讨面向架构师的 AWS 框架、实际应用场景中的开放集团架构框架（TOGAF）以及就绪评估流程。

重新定义和设计整个组织结构可能是一项令人紧张的任务，但高超的技能和正确的分步策略可以帮助促进这一过程。通过深入了解企业架构的目标以及业界已证实有效的益处，你将学会通过跨企业协作来实现数字化转型。

大多数专业人士发现为企业制定框架以确保企业架构能够启动并朝着正确方向发展是一项挑战。为此，AWS 提供了指导性框架，包括迁移就绪评估、云采用框架和 Well-Architected 评审，并将其与 TOGAF 等框架保持一致。

通过了解企业云旅程的当前状态及其业务目标的结果，你将确定其迁移到云的业务目标。

在本部分结尾，本书解释了在 AWS 云转型期间处理 TOGAF 架构开发方法每个阶段的过程。此处的目的是探索云的非功能性架构方面。

尽管如此，本部分以最简单却至关重要的管理教训作结——领导力在企业架构中发挥着重要作用。没有什么比拥有一位具有激励作用并通过行动树立正确榜样的领导者更有帮助的了。

本书本部分包含以下章节：
- *第4章，企业架构的可用框架*
- *第5章，AWS 指导性框架*
- *第6章，TOGAF 框架在 AWS 中的实践*
