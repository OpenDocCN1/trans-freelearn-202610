+   - as_ul

This renders the form fields as list items (li) inside either a ul or ol element. Like with as_table, the containing element (<ul> or <ol>) is not created by Django and must be added by you:

```
<form method="post">
    <ul>
        {{ form.as_ul }}
    </ul>
</form>
```
