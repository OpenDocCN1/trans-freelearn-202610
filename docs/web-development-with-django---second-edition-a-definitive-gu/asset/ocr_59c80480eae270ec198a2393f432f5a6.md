Here, we have used an empty string again for the URL path. So, when http://0.0.0:8000/ is invoked, after getting routed from bookr/urls.py into bookr/reviews/urls.py, this pattern invokes the welcome_view view function.

5. After making changes to the two files, we have the necessary URL configuration ready to call the welcome_view view.
