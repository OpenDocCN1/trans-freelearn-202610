4. Instead of iterating over the raw `request.POST` `QueryDict` (in which all the data is strings), we will iterate over the form’s `cleaned_data`. This is a normal dictionary and contains the values converted into Python objects. Replace the `for` line and `print` line with these two:

```
for name, value in
    form.cleaned_data.items():
        print("{}: ({}) {}".format(name,
        type(value), value))
```

We don’t need to use `getlist()` anymore since `cleaned_data` has already converted multi-value fields into lists.
