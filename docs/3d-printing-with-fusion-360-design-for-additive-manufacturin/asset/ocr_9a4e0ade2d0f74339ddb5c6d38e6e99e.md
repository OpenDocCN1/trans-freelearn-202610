As you can also see in *Figure 8.3*, the increment Fusion 360 uses during this free part motion has three significant figures for any translation or rotation. If we wanted to change the precision with which we translate or rotate components using the drag and drop technique, we would need to go back to our preferences dialog and change the general precision from the default, which is **0.123**, to either a less precise or more precise option.
