If you look back at Figure 9.6, you can see an icon with a blue checkmark in a gear next to the body preset named Medium. This icon indicates that this body preset is the default preset. If you select a preset that is not the default preset, you can right-click on it and make it a default preset, as shown in Figure 9.7. If you were to make this change to this print setting, any subsequent additive setup you create using this print setting would automatically assign Medium 1 as the body preset to all components within that setup.
