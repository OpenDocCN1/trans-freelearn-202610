Another way you can access the machine library is by creating a manufacturing setup. To create an additive manufacturing setup, you can open any Fusion 360 design document and switch to the Manufacture workspace. Since we set our preferences to default to the ADDITIVE tab when using the Manufacture workspace in the previous section, we will automatically be in the ADDITIVE tab.
