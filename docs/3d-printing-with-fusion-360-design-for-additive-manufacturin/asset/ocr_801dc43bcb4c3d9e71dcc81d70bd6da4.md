Figure 3.1 shows a microphone assembly and a stand. This model is made up of several bodies with individual names, and we will refer to them by those names throughout this section.

Let’s imagine we are a designer who is tasked with coming up with a new version of the **Connection-left** and **Connection-right** bodies for this microphone stand. Those bodies were originally created using the **LOFT** command within Fusion 360, and they are shown in green in Figure 3.1. These connection arms connect the base to **Mount-right** and **Mount left**, which are represented in yellow in the same figure:

Using existing bodies that are present in this Fusion 360 design, we can start this exploration by turning off the visibility of the bodies named **Connection-left** and **Connection-right**. Then, we can access the **Automated Modeling** command within the **AUTOMATE** panel.

Next, we can select the four faces we wish to connect to create a new geometry and select **Generate Shapes**, as shown in Figure 3.2. Note that this figure was captured by turning the opacity of all visible bodies down to 50% to better display the four selected faces.
