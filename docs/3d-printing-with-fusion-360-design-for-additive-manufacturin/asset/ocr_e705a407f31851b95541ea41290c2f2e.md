If you seek a more traditional workflow to open your CAD or mesh files, you will want to have Fusion 360 installed on your computer. You can download and install Fusion 360 from the following link: https://www.autodesk.com/content/autodesk/global/en/products/fusion-360/trial-intake.

Once Fusion 360 is installed and started, you can access the File dropdown and select Open. When you do, you will be greeted with the Open dialog. As shown in Figure 1.4, select the Open from my computer... option within this dialog, and you will be able to select from a list of supported mesh and CAD file types, as shown in Figure 1.5:
