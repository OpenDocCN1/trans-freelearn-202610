As mentioned previously, Fusion calculates the recoater clearance percentage for each time step. You can visualize a simplified version of these results at each time step by switching your result type to **Local Recoater Risk**. This result type presents the recoater clearance percentage using a legend resembling a traffic light color contour of red, yellow, and green. Any recoater clearance above 80% is represented as **Low** risk for a recoater crash. If the recoater clearance is below 80% but above 40%, Fusion will highlight those elements as **Medium** risk for a recoater crash. Any clearance below 40% will be highlighted as **High** risk for a recoater crash and will be colored in red.
