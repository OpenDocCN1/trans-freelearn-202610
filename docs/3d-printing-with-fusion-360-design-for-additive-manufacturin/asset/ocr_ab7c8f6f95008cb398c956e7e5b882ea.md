# Extrusion

The input fields within the Extrusion subsection of a given body preset control which extruder is used for printing bodies within an additive setup and certain settings associated with that extruder. If we are creating an additive setup using a 3D printer with a single extruder, we will only see the subheadings called Extrusion and Extruder 1 when editing the print setting for that setup, as shown in Figure 9.8. Only when editing a print setting associated with a multi-extruder printer can we see additional extruder subheadings in this dialog.
