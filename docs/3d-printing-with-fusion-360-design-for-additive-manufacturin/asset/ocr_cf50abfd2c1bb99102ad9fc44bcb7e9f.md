Once we have a new surface body created, we can utilize the boundary fill command, which is accessible in both the **SURFACE** and **SOLID** tabs under the create panel. Using the boundary fill command, as shown in Figure 2.33, we can select our solid and surface body as tools and rectangle select all the cells we wish to encapsulate.

Figure 2.33 – Using the Boundary fill command to remove the engraving

The boundary fill command is similar to the fluid volume command in that it creates new solids. But this command also allows us to join those new solid bodies to our existing solid body. Once the boundary fill command is complete, we will have eliminated the engraving. We no longer need the surface patch or surface body we created, which means we can select and delete it from the browser, as shown in Figure 2.34.
