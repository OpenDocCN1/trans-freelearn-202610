# Figure 7.8 – Fusion 360's library of machines filtered for Additive

Using the search bar in the top-left corner of the machine library, we can also search for a specific machine. In *Figure 7.9*, after typing MK3 into the search field, we see the three FFF printers from the machine vendor Prusa Research. We can select the specific printer we wish to use for our additive setup, press **Select** in the bottom-right corner of the **Machine Library** dialog, and proceed to the **Print Settings** selection.

Alternatively, as shown in *Figure 7.9*, after selecting our printer, we can right-click and copy it, so that we can paste it into one of many locations within **My machines**, such as **Cloud**, **Local**, and **Linked**.
