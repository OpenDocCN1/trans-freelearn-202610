Another important preference I would like to highlight can be found under the **API** section of the **Preferences** dialog. In the preferences for scripting and programming, Fusion 360 shows **Default Path for Scripts and Add-Ins** as shown in *Figure 7.3*. We will not be changing this path in this chapter. However, seeing this path gives us a clear indication of where Fusion 360 saves custom assets, such as machine files and print setting files and posts. As highlighted in *Figure 7.3*, any machine or print setting file you save into your local folder automatically gets stored in your user profile within the `AppData\Roaming\Autodesk\` folder within the appropriate subfolder, such as `machines` or `PrintSettings`.
