After creating both of these support structures, we can select them from the browser. If you right-click on the selected support actions, Fusion will display a new menu, as shown in Figure 14.12. Within this menu, we can select Store as Template, which will bring up the Store as template dialog. In this dialog, we can name our template and type a custom description. We can also choose whether to store this template in our Local template library or the Cloud template library.
