In addition, you can reduce the input values for **Maximum Edge Length**, which would create smaller lines, and **Aspect Ratio**, which would create a mesh body with more uniform-looking triangles. The **Preview** checkbox within the tessellate dialog gives you a visual representation of the meshed outcome, as well as a numerical count for the number of triangles the mesh body will have.

Once a solid body has been tessellated, it will be consumed in the new mesh body, which will also be marked with a new icon within the browser. When tessellating solid bodies, every face of the solid body will be a unique face group within the mesh body. If you want to visualize the face groups of a mesh body, you can toggle the **Display Mesh Face Groups** option within the **INSPECT** panel, as shown in *Figure 5.3*.
