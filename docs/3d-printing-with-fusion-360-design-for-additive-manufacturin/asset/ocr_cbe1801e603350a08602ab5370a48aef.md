Now that we've highlighted how to make changes to a print setting within our local Print Setting Library, it is time for us to assign this print setting to our active additive setup. As shown in Figure 9.16, we can select the ADDITIVE setup, right-click, and edit it. When we are editing the setup, we can choose a new print setting. We will have to navigate to the Local folder, within the My print settings section of Print Setting Library, and choose the print setting we recently customized called PLA (Direct Drive) - CUSTOMIZED and press Select and OK to finish editing the setup.
