# Exporting models directly to non-Fusion 360 slicers

So far, we have demonstrated how models can be sent to PreForm and Netfabb, which are both explicitly available options, assuming that you have those software options installed, for the **Print Utility** dropdown menu. If you are using a slicer that is not available within the **Print Utility** dropdown, you can choose the **Custom** option and point to the executable for the slicer of your choice within the **Open** dialog accessible after selecting the folder icon next to the **Application** option.
