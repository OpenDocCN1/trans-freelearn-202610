# Lines to polygons

+   1. Create a table with lines grouped by common ID:
+   2. Register the new table as spatial:

```
--Create table grouping lines with shared stfid into polygons
CREATE Table census_line2poly AS
SELECT stfid,ST_Polygonize(geom) as geom
FROM census_pts2lines
GROUP BY stfid;
```

```
--Register the new table's geometry so QGIS knows its a spatial layer
SELECT
RecoverGeometryColumn('census_line2poly','geom',3358,'POLYGON',2);
```

> Some SQL interfaces can run multiple SQL statements in a row, separated by a semicolon. However, there are also many interfaces that can only perform one query at a time. Generally, run one query at a time unless you know your software supports multiple queries; otherwise, this may fail or silently only run the first query.

> Double dashes (-- ) is the SQL character for a comment line. It is used to include descriptive text that is ignored in a query.

# How it works...

Based on the common identifier specified in GROUP BY, the SQL statement aggregates multiple points into a new geometry of the type specified. After creating the new geometry and saving the results to a table, registration of the spatial metadata allows Spatialite and QGIS to know the table is a spatial layer.

```
--Register the new table's geometry so QGIS knows its a spatial layer
SELECT
RecoverGeometryColumn('census_pts2lines','geom',3358,'LINESTRING',2);
```
