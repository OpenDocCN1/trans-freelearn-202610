# Adding map grids and frames

Other common features of maps are grids and frames. Every map item can have one or more grids. Click on the + button in the Grids section to add a grid. The Interval and Offset values have to be specified in map units. We can choose between the following Grid types:

+   - A normal Solid grid with customizable lines
+   - Crosses at specified intervals with customizable styles
+   - Customizable Markers at specified intervals
+   - Frame and annotation only will hide the grid while still displaying the frame and coordinate annotations

For Grid frame, we can select from the following Frame styles:

+   - Zebra, with customizable line and fill colors, as shown in the following screenshot
+   - Interior ticks, Exterior ticks, or Interior and exterior ticks for tick marks pointing inside the map, outside it, or in both directions
+   - Line border for a simple line frame
