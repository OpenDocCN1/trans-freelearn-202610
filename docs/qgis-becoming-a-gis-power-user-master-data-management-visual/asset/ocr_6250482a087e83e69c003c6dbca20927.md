# Getting ready

For this recipe, you will need a Geopackage file, often the extension is `.gpkg`. There should be a `naturalearthexample.gpkg` file in the provided sample data.

You'll also need GDAL 1.11 or newer; if you have QGIS 2.6 or newer, this probably came with a new enough GDAL. If you don't have a new enough GDAL, consider upgrading QGIS, which usually bundles newer versions.

> Want to check what versions you have? In QGIS, open Help | About | About.

# How to do it...

+   1. Open the **Add Vector** dialog.
+   2. Click on the **Browse** button and select the `naturalearthexample.gpkg` file:
+   3. Now, back in the main dialog, click on **Open**.
+   4. This should prompt you, asking which layers you want to add from the database:
