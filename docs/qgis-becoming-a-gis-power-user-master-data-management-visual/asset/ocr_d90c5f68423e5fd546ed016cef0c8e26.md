# Adding the data to the map

The downloaded data must be added to the QGIS project to verify that it has been downloaded and to further work on the data from within QGIS. Perform the following steps:

+   1. Navigate to **Layer** | **Add Layer** | **Add Vector Layer**.
+   2. Select `c4/data/output/newark_osm.osm` as the **Source**.
+   3. Click on **Select All** from the **Select vector layers...** dialog.
+   4. Click on **OK**.
+   5. You should now see the data displayed, looking similar to the following image:
