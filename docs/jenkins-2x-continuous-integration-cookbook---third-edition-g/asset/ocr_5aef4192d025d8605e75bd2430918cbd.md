# Target practice with WebGoat

The top 10 list of security defects can at times seem difficult to understand. If you have some spare time and would like to practice against a deliberately insecure application, you should try WebGoat ([https://www.owasp.org/index.php/Category:OWASP_WebGoat_Project](https://www.owasp.org/index.php/Category:OWASP_WebGoat_Project)).

WebGoat is well-documented with a hints system and links to video tutorials; it leaves little room for misunderstanding the attacks.
