# How to do it...

+   1. Open the Jenkins dashboard.
+   2. Click on New Item.
+   3. Enter an item name.
+   4. Select a template Maven project.
+   5. Click on OK:

![](bbox=[0.117, 0.252, 0.883, 0.596])

+   6. Go to the Source Code Management section and select Git.
+   7. Provide the Repository URL.
+   8. Provide Credentials.
+   9. In the Build section, the Root POM name will be already available.
+   10. Maven has its own set of goals and we can execute any one of those goals based on requirements. These steps are demonstrated in this next screenshot:

![](bbox=[0.117, 0.729, 0.882, 0.872])

+   11. Click on Save.
