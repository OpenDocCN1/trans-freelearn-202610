# # How to do it...

+   1. Go to the Jenkins dashboard and click on Manage Jenkins.
+   2. Click on Configure system and find the SonarQube section.
+   3. Click on Add SonarQube.
+   4. Provide the Name, Server URL, and Server version.
+   5. Paste the token value in Jenkins and save it:

![](bbox=[0.122, 0.239, 0.742, 0.58])

+   6. Go to Global Tool Configuration and configure Add SonarQube Scanner:

![](bbox=[0.126, 0.63, 0.877, 0.891])

+   7. Now, you are ready for the static code analysis of the project.
