# # Getting ready

Download the latest stable FitNesse JAR from [http://fitnesse.org/FitNesseDownload](http://fitnesse.org/FitNesseDownload). Install the FitNesse plugins for Jenkins from [https://wiki.jenkins-ci.org/display/JENKINS/FitNesse+Plugin](https://wiki.jenkins-ci.org/display/JENKINS/FitNesse+Plugin).
