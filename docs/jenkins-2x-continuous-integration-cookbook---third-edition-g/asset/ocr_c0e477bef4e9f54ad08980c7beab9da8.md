# There's more...

The following table describes the default location of `JENKINS_HOME` in different operating systems:

| Operating system | $JENKINS_HOME location |
|---|---|
| Windows | C:\Program Files (x86)\jenkins
or c:\Users\<USER>\.jenkins |
| Mac OSX | Macintosh HD/Users/Shared/Jenkins |
| Ubuntu/Debian | /var/lib/jenkins |
| Red Hat/CentOS/Fedora | /var/lib/jenkins |
| OpenSUSE | /var/lib/jenkins |
| FreeBSD | /usr/local/etc/jenkins |
| OpenBSD | /usr/local/etc/jenkins |
