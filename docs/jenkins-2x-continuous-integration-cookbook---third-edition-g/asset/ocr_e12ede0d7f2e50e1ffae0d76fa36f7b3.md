# # How to do it...

Let's install Jenkins now by following these steps:

+   1. Go to [https://jenkins.io](https://jenkins.io).

+   2. Click on Download, as shown in the following screenshot:

![](bbox=[0.117, 0.234, 0.882, 0.588])

+   2. Download the latest Windows package from Jenkins, available at:
+   http://mirrors.jenkins.io/windows/latest.

+   3. Click on the package and follow the step-by-step instructions to install it.
