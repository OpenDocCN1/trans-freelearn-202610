# Cucumber reports

# JSON Report Location

Report Path

The path relative to the workspace of the json reports generated by cucumber e.g. target - leave empty to scan the whole workspace.

File Include Pattern

**/cucumber.json

Default include pattern is "**/*.json".

File Exclude Pattern

Nothing is excluded by default.

Limit for trends

0

How many last builds is displayed in trends section. Set to zero so no limit will be applied
