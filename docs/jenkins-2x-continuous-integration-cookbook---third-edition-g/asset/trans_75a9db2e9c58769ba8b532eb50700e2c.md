## 关于作者

**Mitesh Soni** 是一位热爱学习的 IT 行业从业者，拥有 10 年经验。他是 SCJP、SCWCD、VCP、IBM UrbanCode 和 IBM Bluemix 认证专业人士，也是认证 Scrum 大师。他热爱 DevOps 和云计算，也对 Java 编程感兴趣。他认为设计模式非常迷人。他相信一图胜千言。

他偶尔为 etutorialsworld.com 贡献内容。他喜欢和孩子们玩耍，摆弄他的相机，并在 Indroda Park 拍照。他沉迷于拍照，却不了解太多技术细节。他生活在圣雄甘地家乡的首府。

**Alan Mark Berg**, BSc, MSc, PGCE，自 1998 年以来一直担任阿姆斯特丹大学中央计算机服务部的首席开发人员。他目前在一项创新工作组中工作，该工作组加速了新颖且令人兴奋的服务的创建。在他那极其稀缺的业余时间里，他从事写作。Alan 拥有学士学位、两个硕士学位、教学资格和质量保证认证。他还与 Packt Publishing 合著了两本关于 Sakai (http://sakaiproject.org) 的书籍，Sakai 是一款备受成功的开源学习管理平台，被全球数百万学生使用。他曾获得多个奖项，包括 Sakai 奖学金和 Sakai 教学创新奖 (TWSIA)。

Alan 喜欢与人才合作；这迫使他提升自己的能力。这种动力就是 Alan 喜欢在充满活力的开源兴趣社区中工作的原因。截至撰写本文时，他是 Apereo 基金会的董事会成员，并担任其学习分析倡议 (https://confluence.sakaiproject.org/display/LAI/Learning+Analytics+Initiative) 的社区负责人。

在之前的职业生涯中，Alan 曾担任 QA 总监、技术作家、互联网/Linux 课程作者、产品线开发官和教师。他喜欢亲手构建、粘合系统、探索数据并将其转化为可操作的资讯。他通过破坏各种开发和验收环境并在技术机遇的绿野中横冲直撞来保持敏捷。
