# Getting ready...

+   1. Go to the Jenkins dashboard and click on Manage Jenkins. Go to Manage Plugins and in the Available tab find the SonarQube plugin.
+   2. Click on Install without restart:

![](bbox=[0.125, 0.22, 0.7, 0.455])

+   3. Go to the Jenkins dashboard and click on Manage Jenkins.
+   4. Click on Configure system and find the SonarQube section.
+   5. Now, let's go to SonarQube to get the token to integrate Jenkins and SonarQube.
+   6. Once SonarQube is up and running, open the browser at http://localhost:9000 to visit the SonarQube dashboard:

![](bbox=[0.115, 0.575, 0.745, 0.815])

+   7. Click on Login and give the default username and password as admin and default to log in as an administrator.
