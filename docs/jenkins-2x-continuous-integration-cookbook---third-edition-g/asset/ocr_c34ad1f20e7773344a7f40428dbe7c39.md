# # How to do it...

+   1. To allow sign up and access to only logged in users, go to Manage Jenkins | Configure Global Security.
+   2. In the Access Control section, click on Jenkins' own user database and select Allow users to sign up:

![](bbox=[0.117, 0.222, 0.667, 0.682])

+   3. So, this is how we can create users and allow users to sign up, as well as to access Jenkins.
