# # There's more...

+   - To start the Jenkins service, execute:
+   
+     ```
+     sudo service jenkins start
+     ```
+   
+   - To stop the Jenkins service, execute:
+   
+     ```
+     sudo service jenkins stop
+     ```
+   
+   - To restart the Jenkins service, execute:
+   
+     ```
+     sudo service jenkins restart
+     ```
