# # Getting ready

Install the Jenkins sounds plugin ([https://wiki.jenkins-ci.org/display/JENKINS/Jenkins+Sounds+plugin](https://wiki.jenkins-ci.org/display/JENKINS/Jenkins+Sounds+plugin)). Make sure that you have a compliant web browser installed, such as a current version of Firefox or Chrome.

For more details of HTML5 compliancy in browsers, consider reviewing: [http://en.wikipedia.org/wiki/Comparison_of_layout_engines_%28HTML5%29](http://en.wikipedia.org/wiki/Comparison_of_layout_engines_%28HTML5%29).
