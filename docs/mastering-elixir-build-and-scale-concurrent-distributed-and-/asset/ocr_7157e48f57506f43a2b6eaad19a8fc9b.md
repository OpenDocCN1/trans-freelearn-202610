+   - A supervisor may be supervising other supervisors, which generates a supervision tree. A supervision tree is an important component of fault-tolerant systems, since it allows us to minimize the effects of an error, for instance, when we're able to fix an error closer to the leaves of a tree. When this is not possible, the errors are bubbled up through the tree, making the application consistent so that it doesn't leave dangling processes.
