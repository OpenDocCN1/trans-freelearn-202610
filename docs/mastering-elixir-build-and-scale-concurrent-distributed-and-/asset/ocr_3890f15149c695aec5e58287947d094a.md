We also didn't get a timeout, since we didn't wait for any response from the server:

```
iex> GenServer.cast(echo, {:hi_again, :echo})
Echo on #PID<0.467.0>: {:"$gen_cast", {:hi_again, :echo}}
:ok
```

By using the GenServer behaviour, we get better error reporting for free when the process ends abnormally. We also get a default child_spec definition so that we can easily place our GenServer processes under a supervision tree. To look at the full list of callbacks, we can check the possible completions suggested by IEx, starting with the Calculator module:

```
iex> Calculator.<tab>
child_spec/1 code_change/3 handle_call/3 handle_cast/2
handle_info/2 init/1 terminate/2
```
