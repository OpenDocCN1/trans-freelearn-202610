In the previous query, we had to manually join the Owner, MediaOwners, and Media schemas, before telling Ecto to preload the files field with the associated Media rows. We will now create the exact same query, but using the Ecto.assoc/2 construct, which will handle the inner join for us.

The Ecto.assoc/2 function receives an existing struct, such as the owner we have been using, and the association we want to fill, and returns the corresponding query.
