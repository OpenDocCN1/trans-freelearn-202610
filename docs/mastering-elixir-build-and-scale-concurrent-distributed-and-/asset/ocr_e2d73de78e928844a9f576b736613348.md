As you can see from this code, both format and credo tasks will be run when we execute mix lint. Be warned that these aliases don't appear in the list returned by mix help:

```elixir

defmodule ElixirDrip.Umbrella.Mixfile do
  use Mix.Project

  def project do
    [
      # ...
      aliases: aliases()
    ]
  end

  defp deps do
    [
      # ...
    ]
  end

  defp aliases do
    [
      "lint": ["format", "credo"]
    ]
  end

```

This alias definition was just an example to show how easy it is to define your own aliases. If you need to create a Mix task from scratch, you can define a new module whose name starts with the Mix.Tasks. prefix. This module needs to use the Mix.Task module and define a run/1 function:

```
```elixir
defmodule Mix.Tasks.MyCustomTask do
  use Mix.Task

  def run(_args), do: IO.puts("Hello from custom task")
end
```
