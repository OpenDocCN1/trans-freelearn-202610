Besides the timestamp, the JSON response will get us the host name, the node name, and the list of nodes the current node is connected to. A controller needs a route to handle requests, so let's implement ours:

```
$ cat apps/elixir_drip_web/lib/elixir_drip_web/router.ex
defmodule ElixirDripWeb.Router do
  use ElixirDripWeb, :router
  # ...
  get("/health", ElixirDripWeb.HealthController, :health)
  # ...
end
```

We are routing /health GET requests to the :health action in HealthController. Notice that we aren't associating any pipeline (such as :api or :logger) to this route entry because we don't need any authentication or logging logic to be performed before we respond to the request. This endpoint will be used constantly by Kubernetes to assess how healthy the pod container running the application is.
