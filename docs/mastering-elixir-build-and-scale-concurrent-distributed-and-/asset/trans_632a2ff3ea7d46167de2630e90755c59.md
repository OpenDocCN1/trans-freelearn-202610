## 关于作者
**André Albuquerque** 是 Onfido 的软件工程师，在银行业工作七年后加入。他拥有 Instituto Superior Técnico 分布式系统和软件工程硕士学位，并在银行业期间获得经济学硕士学位。他目前使用 Elixir 和 Ruby 开发 Onfido 的微服务，每天学习如何通过从一开始就应用正确的工具和合理的编码实践来让应用程序评分和扩展。业余时间，他喜欢自己制作键盘、打篮球，并与妻子和儿子共度时光。

> *谢谢你，Caixinha，愿意和我一起踏上这段疯狂的旅程，谢谢 Paulo，你是我希望能找到的那种导师。对所有 Onfido 的同事来说，和你们一起成长是一种乐趣。*

> *如果没有我家人和朋友的爱与支持，这本书就不可能实现。*

> *Ana 和 José，能在我的生命中有你们，我感到无比幸运。*

**Daniel Caixinha** 是 Onfido 的软件工程师，在那里他使用 Elixir 构建能够处理业务高速增长的弹性系统。毕业于 Instituto Superior Técnico 后，他加入了初创公司世界，主要使用 Ruby，但也有机会尝试 Elixir。加入 Onfido 后，他有机会更认真地使用 Elixir，这使他爱上了函数式编程，尤其是 Elixir。除了构建 Elixir 应用外，他还推动 Elixir 的使用，也是里斯本 Elixir meetup 的成员。

> *首先，本书献给我的灵魂伴侣 Raquel 和我的儿子 Gabriel。没有你们的爱，这本书就不可能实现。我还要感谢 Onfido 总体上，特别是两个人：André，和我一起在前线奋斗；Paulo，他让我坚信我能写书。最后但绝对不是最不重要的，我要感谢我的父母一直支持我变得更好。*

## 关于审阅者
