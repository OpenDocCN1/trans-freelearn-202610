```
users = Data.users()

pretty_users = users
|> Flow.from_enumerable(max_demand: 1)
|> Flow.map(&Data.set_name_domain(&1))
|> Flow.map(&Data.set_full_name(&1))
|> Flow.map(&Data.set_country(&1))
|> Flow.map(&Data.set_preferences(&1))
```

Due to its lazy nature, Flow doesn't immediately enumerate the collection. To force execution of the pending Flow operations, we will have to pass its result to an eager function, such as Enum.to_list/1. Notice how we are doing just that, by passing the value of the pretty_users variable of the preceding search.exs script to the Enum.to_list/1 function:
