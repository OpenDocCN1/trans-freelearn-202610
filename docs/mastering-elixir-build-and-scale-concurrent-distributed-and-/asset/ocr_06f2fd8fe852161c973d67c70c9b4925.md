To use the same module to streamline the Notifier stage definition, it will be just a matter of passing :consumer as the type option when we use the Pipeliner.Consumer module:

defmodule ElixirDrip.Storage.Pipeline.Notifier do
  require Logger

  @dummy_state []

  use ElixirDrip.Pipeliner.Consumer, type: :consumer

  @impl ElixirDrip.Pipeliner.Consumer
  def prepare_state([]) do
    Logger.debug("#{inspect(self())}: Streamlined Pipeline Notifier started.")
  end

  @dummy_state
end
  # ...
end
