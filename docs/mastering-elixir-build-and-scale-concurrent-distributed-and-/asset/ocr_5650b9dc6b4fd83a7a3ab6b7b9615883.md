Our ElixirDrip users will also be able to share their media with other users. Each time a file is shared, we will need to update the media-users association. This time however, we will directly manipulate the MediaOwners join schema:

```
$ cat apps/elixir_drip/lib/elixir_drip/storage/storage.ex
defmodule ElixirDrip.Storage do
  # ...
  def share(user_id, media_id, allowed_user_id) do
    with {:ok, :creator} <- is_creator?(user_id, media_id) do
      %MediaOwners{}
      |> Changeset.cast(%{user_id: allowed_user_id, media_id: media_id}, [:user_id, :media_id])
      |> Repo.insert()
    else
      error -> error
    end
  end
end
```
