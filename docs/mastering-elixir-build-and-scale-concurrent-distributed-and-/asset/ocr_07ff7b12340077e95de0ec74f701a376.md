This will trigger the download pipeline, which entails downloading the file from Google Cloud Storage, decrypting it, and storing its contents in memory. The final step is the notifier, which will call the GenServer module we've seen before. This module will in turn broadcast the "download" event to the channel of the current user, providing the link to download the file.
