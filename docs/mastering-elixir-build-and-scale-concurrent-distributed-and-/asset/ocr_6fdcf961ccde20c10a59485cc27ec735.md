The macros inside the CleanAccess module manipulate the counter_var in the CleanAccess context, but, as we can observe, the counter_var never leaks to the caller context. When you are creating your own macros, consider whether you really need to access the caller context, or whether you are able to do as we did here, and simply define those variables in the context of the module defining the macros.
