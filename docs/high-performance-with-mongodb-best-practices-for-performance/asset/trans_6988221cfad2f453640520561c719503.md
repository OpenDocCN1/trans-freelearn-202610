## 贡献者

### 关于作者

**Asya Kamsky** 是 MongoDB 的首席 KnowItAll，自 2012 年起在那里工作。在发现 MongoDB 之前，她在多个初创公司花费了近二十年时间，强迫关系型数据库做它们从未被设计来做的事情，其中大多数公司没人记得。Asya 在软件开发、数据库以及告诉人们他们做错了什么方面拥有丰富的背景。

**Ger Hartnett** 是 MongoDB 产品性能团队的首席工程师，他热爱解决引人入胜的优化和扩展挑战。在加入 MongoDB 之前，他创立了一家构建项目沟通平台的初创公司（该平台存在扩展问题）。在此之前，他在 Intel 负责嵌入式软件的架构和调优，并在那里合著了一本书。更早之前，他在 Tellabs、Digital 和 Motorola 等公司开发系统。

**Alex Bevilacqua** 是 MongoDB 开发者体验的首席产品经理。在 2018 年加入 MongoDB 之前，他曾担任软件工程师和系统架构师，使用多种语言、技术和框架实施解决方案。除了对编程的热情已超出工作时间之外，Alex 通常会与他的一个孩子一起出现在场馆里，他们两个都打代表队冰球。

### 关于审阅者

**Keith Smith** 是一位系统和存储专家，在操作系统和数据基础设施方面拥有数十年的经验。他的总部位于美国，曾在 Sun Microsystems、NetApp 和 MongoDB 等公司做出创新贡献。Keith 的职业生涯始于设计实时 UNIX 系统，后来在哈佛大学构建可扩展操作系统，并在那里获得博士学位。他的工作涵盖对象存储、元数据目录和文件系统架构。自 2020 年以来，他一直领导 MongoDB 的存储引擎开发。Keith 热衷于可扩展系统，继续推动数据存储技术的边界。

**John Page** 是一名全栈工程师，于 2013 年加入 MongoDB。此后，他担任多个专注于开发生命周期各阶段客户成功的资深技术职务。在加入 MongoDB 之前，他在执法和美国军方为法律部门构建文档数据库系统工作了 18 年。John 受过地质学家训练，可以在野外找到硅、从原始组件组装计算机，并编写从操作系统和数据库到前端和文档的一切内容。

**James Kovacs** 是 MongoDB 数据库体验部门的工程总监。他专注于客户端库、对象文档映射器、框架集成和 AI/ML。他拥有超过 25 年的专业软件工程经验，在此期间曾在各种公司和行业工作。当不在键盘前时，你可以在他玩桌游/TTRPG、在厨房烹饪美味的素食，或在道场教授空手道时找到他。

**Stephanie Eristoff** 是 MongoDB 存储执行团队的软件工程师，她于 2024 年加入。她在时序集合和索引的性能测试方面拥有经验，并为性能和查询执行团队做出了贡献。工作之外，Stephanie 喜欢烘焙、跑步和骑自行车。

**Katya Kamenieva** 是 MongoDB 的产品经理，自 2019 年以来一直在推动聚合框架、变更流和其他功能的改进。她的重点是增强用户在 MongoDB 中与数据交互的方式。工作之外，她是两个年幼女儿的妈妈，通过安静的时光、一杯好咖啡、瑜伽和水彩画找到心灵平静。

**Jawwad Asghar** 是 MongoDB 的软件工程师，自 2022 年以来一直是性能团队的关键成员。他通过为多样化和需求苛刻的客户用例优化数据库性能来推动数据库的变更。在加入 MongoDB 之前，他在机车行业担任控制软件工程师工作了 10 年。工作之外，他喜欢在纽约市骑自行车、露营和去上州徒步。

**Alice Doherty** 是 MongoDB 的软件工程师，于 2023 年加入产品性能团队。她在为客户和内部工程团队根除独特性能问题方面拥有宝贵经验，并推动 MongoDB 产品性能改进。工作之外，Alice 喜欢保持活跃、烹饪和任何户外冒险。

**Linda Qin** 是 MongoDB 的高级技术服务工程师。她于 2013 年加入 MongoDB，此后一直从事技术支持团队工作。Linda 专注于问题诊断和性能调优，在分片方面拥有深厚专业知识。她还参与开发工具以简化诊断并提高效率。工作之外，Linda 喜欢烹饪和丛林徒步。

**Matt Panton** 是 MongoDB 的产品经理。自 2022 年加入以来，Matt 专注于为关键分布式系统功能（如分片和复制）提供改进。他的工作重点是使 MongoDB 可扩展且具有弹性。工作之外，Matt 喜欢踢足球、跑步和烹饪。

**Sebastien Mendez**（但称他为 Seb）是 MongoDB 查询执行团队的首席工程师。过去，他曾以“rakiz”的名义活跃于演示场景，破解 Z80 汇编演示，在他的 Amstrad CPC 6128 上创建磁盘杂志，并组织编程聚会。在探索多个行业后，Seb 发现了对数据处理的热情——构建持久层、查询引擎和高度可配置的流式数据管道。今天，他专注于 MongoDB 的变更流，帮助围绕可观测性、性能和新功能塑造其路线图。工作之外，Seb 喜欢电子游戏、阅读科幻和奇幻小说、摆弄 Arduino，并收集流行文化 T 恤。
