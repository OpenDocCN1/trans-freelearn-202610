# There's more...

After creating the stored procedures the last step for a new module is to connect it to the database. The recipe Connecting a module to the database demonstrates how to create the procedures to support the database and business logic layers.

# Connecting a module to the database

To connect the wizard-generated code to the module's database table, we must go through the project code and substitute the placeholder called Content with our fields and data types.

# Getting ready

To follow along with this recipe you must have completed these previous recipes:

+   - Creating a new module with the Starter Kit
+   - Creating a database table with keys
+   - Creating stored procedures

# How to do it...

+   1. Start by launching your preferred development tool (Visual Studio or Visual Web Developer Express).
+   2. Look for Recent Projects shown on the left side of the screen. Click on Employee to load the project.
+   3. Look under the Solution Explorer on the right side of the screen, expand the folder called Components and double-click on DataProvider.vb.
