# Installing the DNN 5 Starter Kit

In this recipe we will download and install the DNN 5 Starter Kit. The Starter Kit will generate a near complete DNN module based only on a module name. The module it creates will still need editing, but it will save us a lot of typing.

# Getting ready

The Starter Kit requires Visual Studio or Visual Web Developer Express Edition. To install Visual Web Developer 2010 Express for your development environment see the previous recipe Installing Visual Web Developer 2010 Express.

# How to do it...

+   1. Go to http://dotnetnuke.codeplex.com.
+   2. Click on the Downloads tab at the top of the page.
+   3. Look for the Visual Studio Starter Kit link on the left side and click on the link.
