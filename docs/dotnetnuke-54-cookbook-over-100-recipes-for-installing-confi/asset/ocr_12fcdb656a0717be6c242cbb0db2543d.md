4. A form template will display showing the basic audit columns. To add your own columns, click on the Add New Column link.

![](bbox=[0.112, 0.13, 0.888, 0.512])

5. Define the first column:

+   - Title: Department #
+   - Type: Integer
+   - Required: Checked
+   - Display on List: Checked
+   - Restricted Form Field: Unchecked
+   - Searchable: Unchecked

6. You can add a help message by scrolling down to the Advanced Column Options and adding the following text:

+   - Help Text: Provide the unique identification number for this department.
