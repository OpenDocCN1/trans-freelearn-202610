# # Showing a thumbnail image in a Datagrid

Datagrids are a flexible control that can display a variety of information. In this recipe, we will see how to display a small thumbnail image in the Datagrid based on information in the Employee table.

# ## Getting ready

In this recipe we will extend the Datagrid that we created in *Chapter 6*. To follow along you should have successfully completed and deployed the project *Displaying a Datagrid with filter controls*.

# ## How to do it...

+   1. First prepare some thumbnail images to display. Generally 64x64 is a good size but you can experiment and see what looks good. To keep it simple, name them images based on the employee name—first initial, and last name with .PNG extension.
+   
+   2. Now we need to upload the images to the DNN site. Log in as Host user (`syshost` in our examples).
+   
+   3. Look under the **Admin** menu and select **File Manager**. Make sure **Portal Root** appears on the left side:
+   
+   4. Type **SiteImages** in the folder name textbox and click on **Add Folder**.
+   
+   5. Click on the **Upload** link.
