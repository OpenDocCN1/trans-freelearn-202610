12. The wizard will prompt for the ZIP file (called the extension package).

![](bbox=[0.107, 0.272, 0.895, 0.445])

13. Click on the Browse button and select the file Employee_01.00.00_Install.zip. Click on Open then click on Next.

![](bbox=[0.275, 0.521, 0.727, 0.76])

14. The wizard will display your module information. Click on Next.

15. The wizard will display your Release Notes. Click on Next.

16. At the license page, check Accept License? and click on Next.

17. Now the install script will run, creating the table and the stored procedures for the module. At the end you should see the message "Installation successful".
