+   8. For the **User name** and **Password**, use the username and password that created the database (in *Chapter 1* this was `DNN5User` and `DNN5User2010`).
+   9. Check **Save my Password**.
+   10. In the **Connect to database** section, select the name of the DotNetNuke database you created when DNN was installed (DotNetNuke5 in these examples).
+   11. Click on the **Test Connection** button.
+   12. If you do not see a **Test connection succeeded** message, check if you have typed the correct server name and DNN database name for your site.
+   13. Click on **OK** to create the database connection.
