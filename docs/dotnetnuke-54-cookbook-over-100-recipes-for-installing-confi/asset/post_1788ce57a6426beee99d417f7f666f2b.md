## Introduction

As the world gets smaller everyday the ability for a website to support multiple languages becomes more important. Fortunately, DNN provides foreign language support through a process called Localization.

DNN localization is built on the foundations of the .NET framework localization tools. As one language is often used in more than one country, foreign languages in .NET are organized by a locale code which is a combination of the language code and the country code. For example, the code `fr-CA` represents French spoken in Canada. `Fr-FR` represents French spoken in France.
