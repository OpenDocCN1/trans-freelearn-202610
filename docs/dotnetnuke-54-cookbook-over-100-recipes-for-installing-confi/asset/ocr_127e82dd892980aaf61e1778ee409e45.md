# Getting ready

To create a security role you need either the host or Portal Administrator login. To decide what security roles you need think about the different types of users accessing the site. For example, if you have a news site you may create a group called Contributors. By creating a security role for this group you can give them access to edit content that a normal user would not have.

# How to do it...

+   1. Begin by logging in as the Portal Administrator (`sysadmin` in our examples).
+   2. Look at the Control Panel and make sure you are in Edit mode.
+   3. Look under the **Admin** menu and select **Security Roles**.
+   4. This page will display all the security roles you currently have.

![](bbox=[0.105, 0.382, 0.895, 0.495])

+   5. Click on the link labeled **Add New Role** (or select it from the action menu).
