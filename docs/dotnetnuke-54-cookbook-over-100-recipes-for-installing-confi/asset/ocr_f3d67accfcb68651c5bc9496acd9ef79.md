4. Find Allowable File Extensions. This list affects both the files available to download and the files allowed for upload. For example, if you want to upload a JPG for the HTML module the extension has to be listed here. Review the list and remove any extensions you will not support on your site.

5. Click on Update to save your changes.

6. Log out as host and log in as the Portal Administrator (sysadmin in our examples).

7. Navigate to a blank page (such as Useful Documents created in the recipe Creating and organizing pages in Chapter 2).

8. Look at the Control Panel and make sure you are in Edit mode.

9. From the Control Panel, pick the Common Tasks tab and select the Documents module from the drop-down list.

10. Choose ContentPane from the drop-down list and click on the Add Module button.

11. The Documents module will now appear on your blank page and show the current list of available documents. Before we add a document, let's edit the settings of the module.

12. Hover over the Documents module menu and select Settings.

13. Scroll down to the Documents Module Settings.
