# How it works...

We can bind a drop-down list control directly to a DNN list. This allows the host user to add values to the list without having to redeploy the module.

# There's more...

As we bind to the list when the page is displayed, you can add more values to the DNN list and they will automatically appear in the drop-down list when the page is refreshed.

# Populating a drop-down list from a stored
procedure

In this recipe we will see how to populate a drop-down list from a stored procedure. This is similar to binding to a DNN list, but now we can use any data stored in the database for the list.

# Getting ready

To follow along with this recipe you must have completed the following recipes:

+   - *Creating stored procedures* (from *Chapter 4*)
+   - *Populating a drop-down list from a DNN list*

+   1. Start by launching the Development Tool and loading the Employee project.

+   3. Find the table and the salary control you added from the previous recipe. Look for the two placeholders and replace them with this label and control code so the HTML table now looks like this:
