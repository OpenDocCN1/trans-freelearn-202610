4. The first thing you'll notice is the Control Panel across the top of the page. It contains useful tools to maintain the site divided into four categories: Common Tasks, Current Page, Admin, and Host. Some of these tools are also available under the host or admin menus, but they're easier to find here in the Control Panel.

![](bbox=[0.105, 0.17, 0.895, 0.595])

5. Click on Admin to display the Admin tasks and click on the Site Settings icon in the upper-left corner.

6. This presents the Site Settings form. This is a typical data entry form in DNN. You have fields with labels, but also titles such as Basic Settings with little minus signs next to them. These are collapsible panels. You can hide parts of the form by clicking on the minus sign. You'll also see small Help icons next to all the fields. Clicking on these might provide more information about the field.
