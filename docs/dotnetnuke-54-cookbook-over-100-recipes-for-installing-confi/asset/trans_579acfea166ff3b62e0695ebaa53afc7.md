-   - **Page_Load 过程**
     在 .NET 框架中，当 Web 表单加载时，会发生一个名为 `Page_Load` 的特殊事件。该事件经常用于在用户控件显示之前准备数据。在本章中，你将看到使用 `Page_Load` 事件填充下拉列表或准备数据网格的示例。在 `Page_Load` 例程内部，常见的做法是检查页面是否正在回发到服务器。这告诉你页面是首次查看，你可以据此填充控件。
