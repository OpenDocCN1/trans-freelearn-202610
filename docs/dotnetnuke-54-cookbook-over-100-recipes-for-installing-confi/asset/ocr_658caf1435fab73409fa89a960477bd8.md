+   12. Next, open the `EmployeeInfo.vb` file.

+   13. Find the **Public Properties** section and add the read-only property `ImageURL` that returns the URL of the images we upload (based on employee name):

```
' public properties

Public ReadOnly Property ImageURL() As String
    Get
        Return "~\\Portals\\_default\\SiteImages\\" + _
               _EmpFirstName.Substring(0, 1) + _EmpLastName + ".png"
    End Get
End Property

Public ReadOnly Property ContactInfo() As String
    Get
        Return _EmpFirstName + " " + _EmpLastName + " Hired: " +
                                      FormattedHireDate()
    End Get
End Property
```
