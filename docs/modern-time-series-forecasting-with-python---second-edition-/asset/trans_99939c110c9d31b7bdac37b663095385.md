
# 机器学习在时间序列中的基础

## 超参数

几乎所有机器学习模型都有几个与之相关的超参数。`Hyperparameters`（超参数）是模型的参数，它们不是从数据中学习得来的，而是在训练开始前设定的。例如，正则化的权重就是一个超参数。大多数超参数要么帮助我们控制模型的容量，要么对模型施加正则化。通过控制容量、正则化或两者兼施，我们可以在欠拟合和过拟合模型之间的边界上游走，从而得到一个`just right`（恰到好处）的模型。

## 验证集与交叉验证

但既然这些超参数必须在算法之外设定，我们该如何估计最佳超参数呢？虽然这不是核心`learning process`（学习过程）的一部分，但我们也是从数据中学习超参数的。但如果我们仅使用训练数据来学习超参数，它只会选择最大可能的模型容量，导致过拟合。这时我们就需要一个`validation set`（验证集），即训练过程无法访问的那部分数据。但当数据集较小（不是成百上千个样本）时，单一验证集上的表现无法保证公平的评估。在这种情况下，我们依赖`cross-validation`（交叉验证）。通用的技巧是在原始数据集的不同子集上重复训练和评估过程。一种常见的方法称为`k-fold cross validation`（k折交叉验证），即将原始数据集划分为`k`个大小相等、不重叠且随机的子集，然后在所有其他子集上训练后对每个子集进行评估。如果您想了解交叉验证技术，我们在`Further reading`（延伸阅读）部分提供了一个链接。本书后面也会涉及这个话题，但会从时间序列的角度出发，这与标准的交叉验证方式有几处不同。

# 时间序列预测作为回归

## 时间序列预测作为回归

时间序列，正如我们在第1章*Introducing Time Series*（时间序列简介）中所见，是按时间顺序获取的一组观测值。通常，时间序列预测旨在尝试预测这些观测值在未来会是什么。给定任意长度历史的观测序列，我们预测任意长度的未来。

我们看到回归，即预测连续变量的机器学习，作用于一个示例数据集上，每个示例都是一组输入特征和目标。我们可以看到，回归的任务是根据一组输入预测单个输出，这从根本上与预测不兼容，后者给定一组历史值，要求预测未来值。时间序列与机器学习回归范式之间的这种根本不兼容性，就是我们无法直接将回归用于时间序列预测的原因。

此外，根据定义，时间序列预测是一个外推问题，而回归大多时候是一个内插问题。外推通常更难用数据驱动方法求解。回归问题中的另一个关键假设是用于训练的样本是`independent and identically distributed`（独立同分布，`IID`）。但时间序列也打破了这一假设，因为时间序列中后续的观测值表现出相当大的依赖性。

然而，为了使用机器学习中的各种技术，我们需要将时间序列预测转化为回归问题。幸运的是，有方法可以将时间序列转化为回归，并通过特征向机器学习模型引入一些记忆来克服`IID`假设。让我们看看如何做到这一点。

### 时间延迟嵌入

我们在第4章*Setting a Strong Baseline Forecast*（建立强基线预测）中讨论了`ARIMA`模型，并看到了它是如何作为一个自回归模型工作的。我们可以利用相同的概念将时间序列问题转化为回归问题。让我们使用下图使概念更清晰：

![Figure 5.6 – Time series to regression conversion using a sliding window](media/5.6.jpg)

**图 5.6 – 使用滑动窗口将时间序列转换为回归**

假设我们有一个带有时间步的时间序列。假设我们在时间`t`，拥有一个历史长度为`L`的时间序列。因此，我们的时间序列看起来会像图中那样，`media/file159.png`是时间序列中最新的观测值，`media/file161.png`等是随着我们向后推移时间的观测值。在理想情况下，当我们预测时，`media/file161.png`中的每个观测值都应以所有先前的观测值为条件。但这不切实际，因为`L`可以任意长。我们通常限制预测函数仅使用序列中最近的`M`个观测值，其中`M < L`。这些被称为有限记忆模型或`Markov models`（马尔可夫模型），`M`称为自回归阶数、记忆大小或感受野。

因此，在时间延迟嵌入中，我们假设一个任意长度`M < L`的窗口，并通过在时间序列长度上滑动窗口来提取固定长度的子序列。

在图中，我们采用了一个记忆大小为3的滑动窗口。因此，我们可以提取的第一个子序列（如果我们从最近的开始向后推）是`media/file163.png`。而`media/file164.png`是紧随该子序列之后的观测值。这成为我们数据集中的第一个示例（图中表格的第1行)。现在，我们将窗口向左滑动一个时间步（向后推移时间）并提取新的子序列`media/file164.png`。相应的目标将变为`media/file163.png`。当我们移回时间序列的开头时，我们重复这个过程，在滑动窗口的每一步，我们向数据集添加一个示例。

最终，我们得到了一个对齐的数据集，具有固定向量大小的特征（将等于窗口大小）和单个目标，这正是典型机器学习数据集的样子。

现在我们有了一个包含三个特征的表，让我们也给这三个特征赋予语义含义。如果我们看图中表格最右边的列，可以看到该列中的时间步总是落后于目标一个时间步。我们称之为`Lag 1`（滞后1）。从右数第二列总是落后于目标两个时间步，这称为`Lag 2`。推广开来，包含落后于目标`n`个时间步的观测值的特征，我们称为`Lag n`。

这种利用`time-delay embedding`（时间延迟嵌入）从时间序列到回归的转换，以一种标准回归框架可利用的方式编码了时间序列的自回归结构。我们考虑将回归用于时间序列预测的另一种方法是执行`regression on time`（时间回归）。
