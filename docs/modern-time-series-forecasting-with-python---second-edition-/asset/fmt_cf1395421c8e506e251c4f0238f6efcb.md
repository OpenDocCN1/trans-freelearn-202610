## 理解机器学习基础

在开始将机器学习用于时间序列之前，让我们花些时间确立什么是机器学习，并建立一个框架来演示它的作用（如果你已经非常熟悉机器学习，可以跳过这部分，或者继续跟随我们复习概念）。1959年，Arthur Samuel 将机器学习定义为“一个无需显式编程就能让计算机获得学习能力的研究领域”。传统上，编程是一种范式，我们在其中知道一组执行动作的规则/逻辑，该动作作用于给定数据以获得我们想要的输出。但是，机器学习颠覆了这一点。在机器学习中，我们从数据和输出开始，让计算机告诉我们实现从数据获得期望输出的规则：

**Figure 5.1 – Traditional programming versus machine learning**

机器学习中有许多种问题设置，如监督学习、无监督学习、自监督学习等，但我们将坚持使用监督学习，因为它是最流行且最适用于本书内容的一种。

让我们从小处着手，逐步构建完整的示意图，它封装了监督机器学习问题的大多数关键组件：

![Figure 5.2 – Supervised machine learning schematic, part 1 – the ideal function](media/file142.jpg)

**Figure 5.2 – Supervised machine learning schematic, part 1 – the ideal function**

正如我们已经讨论的，我们希望从机器学习中获得的是从数据中*学习*并得出一组规则/逻辑。数学中对逻辑/规则最接近的类比是函数，它接受输入（此处为数据）并提供输出。数学上可以写为：

```
y = g(X)
```

其中 `X` 是特征集合，`g` 是**理想目标函数**（*Figure 5.2* 中标记为 **1**），它将 `X` 输入（示意图中标记为 **2**）映射到目标（理想）输出 `y`（示意图中标记为 **3**）。理想目标函数在很大程度上是一个未知函数，类似于我们在第 1 章 *Introducing Time Series* 中看到的**数据生成过程**（**DGP**），它不在我们的控制范围内。

![Figure 5.3 – Supervised machine learning schematic, part 2 – the learned approximation](media/file144.jpg)

**Figure 5.3 – Supervised machine learning schematic, part 2 – the learned approximation**

但我们希望计算机*学习*这个理想目标函数。这个理想目标函数的近似用另一个函数 `h` 表示（**4** 在示意图中），它接受相同的特征集合 `X`，并输出预测目标（**5** 在示意图中）。`θ` 是 `h` 函数的参数（或模型参数）：

![Figure 5.4 – Supervised machine learning schematic, part 3 – putting it all together](media/file147.jpg)

**Figure 5.4 – Supervised machine learning schematic, part 3 – putting it all together**

现在，我们如何找到这个近似函数 `h` 及其参数 `θ`？通过示例数据集（**6** 在示意图中）。监督机器学习问题的前提是我们能够收集一组示例，展示特征 `X` 和相应的目标 `y`，这在文献中也称为*标签*。正是从这组示例（数据集）中，计算机*学习*近似函数 `h` 和最优模型参数 `θ`。在前面的图表中，唯一真正的未知实体是理想目标函数 `g`。因此，我们可以使用训练数据集 `D` 来获得数据集中每个样本的预测目标。我们已经知道所有示例的理想目标。我们需要一种方法来比较理想目标和预测目标，这就是**损失函数**（**7** 在示意图中）的作用。损失函数告诉我们用近似函数 `h` 偏离真实情况有多远。虽然 `h` 可以是任何函数，但通常从一组已知的函数类中选择，`H` 是可以拟合数据的有限函数集合。这类函数就是我们通俗所说的**模型**。例如，`h` 可以从所有线性函数或所有基于树的函数中选择，等等。从 `H` 中选择 `h` 是通过超参数（由建模者指定）和模型参数 `θ`（从数据中学习）的组合完成的。

剩下的就是遍历不同的函数，找到使损失最小的最佳近似函数 `h`。这个优化过程我们称之为**训练**。

让我们也看看几个关键概念，它们将在我们后续的所有讨论中都很重要。
