Ensure that RabbitMQ is not running as a Windows service in the background as it utilizes the same network ports as ActiveMQ. To ensure that ActiveMQ is running, you may access the admin console in the browser by using http://localhost:8161/admin. The default user ID and password is admin and admin respectively.
