The Azure Service Bus can be created in the Azure portal by first creating the Service Bus namespace as shown in the following screenshot:

![](bbox=[0.266, 0.189, 0.734, 0.445])

We can create the Service Bus Queues, Topics, and Relays in the Azure portal, and we can also manage the Service Bus through Visual Studio after it is initially created in the Azure portal. The Service Bus will use a primary key and connection string to be accessed, not too dissimilar to a connection string to SQL database.
