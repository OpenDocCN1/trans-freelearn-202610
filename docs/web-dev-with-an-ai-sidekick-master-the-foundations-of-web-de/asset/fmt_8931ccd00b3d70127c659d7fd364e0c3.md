# Official TypeScript Resources

Here are the official, authoritative TypeScript resources you should know about. These are maintained by Microsoft and the TypeScript teams, so start with them before using blog posts or forum answers.

## TypeScript Handbook

This is the primary learning resource. It is structured, progressive, and written by the TypeScript team. The handbook explains not just syntax, but why features exist and how they are meant to be used. For most readers, this should be the first stop after this chapter.

[https://www.typescriptlang.org/docs/handbook/intro.html](https://www.typescriptlang.org/docs/handbook/intro.html)

## TypeScript Documentation

This is the entry point for all official TypeScript documentation. From here, you can access the handbook, configuration options, compiler details, and guides for different environments.

[https://www.typescriptlang.org/docs/](https://www.typescriptlang.org/docs/)

## TypeScript Playground

This is an interactive, browser-based editor that lets you experiment with TypeScript without installing anything. It shows TypeScript code on the left and the generated JavaScript on the right, which is excellent for reinforcing the "types disappear at runtime" concept.

[https://www.typescriptlang.org/play](https://www.typescriptlang.org/play)

## TypeScript Compiler Options

This page documents every compiler option in `tsconfig.json`. You do not need this immediately, but it becomes invaluable as soon as you want to tighten or relax rules in real projects.

[https://www.typescriptlang.org/tsconfig](https://www.typescriptlang.org/tsconfig)

## TypeScript GitHub Repository

This is the source of truth for the language itself. Issues, release notes, design discussions, and breaking changes all appear here first. Advanced readers will eventually end up here when they want to understand design decisions or track upcoming features.

[https://github.com/microsoft/TypeScript](https://github.com/microsoft/TypeScript)

## Release Notes (per TypeScript version)

This is useful for understanding how the language evolves. TypeScript moves quickly, and this page helps you see what changed and why.

[https://www.typescriptlang.org/docs/handbook/release-notes/overview.html](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)

# Chapter 7: SQL – Managing Data

Web pages can survive a bit of ugliness. Data models are less forgiving. Once your data is duplicated, inconsistent, or badly related, the whole application starts paying for it.

This chapter introduces SQL and relational databases using SQLite and a small sample database. The goal is not to turn you into a database administrator. It is to help you understand how structured data is stored, related, queried, and changed.

You will start with the basic ideas behind relational databases: tables, rows, columns, keys, relationships, `NULL`, and constraints. Then you will set up SQLite, inspect the sample database, and write real queries with `SELECT`, `WHERE`, `ORDER BY`, `JOIN`, `GROUP BY`, and `HAVING`. After that, you will modify data with `INSERT`, `UPDATE`, and `DELETE`, look at transactions, and finish with a practical introduction to indexes and performance.

By the end of this chapter, you should understand how relational databases store and connect related facts. Learning SQL syntax is important, but the bigger skill is learning to ask precise questions about data: what exists, how pieces relate, what must always be true, and what the application needs to answer.

In this chapter, we will cover the following topics:

- Introduction to SQL and databases
- Setting up SQLite and a sample database
- Writing queries and joining tables
- Modifying data
- Improving performance with indexes

## Introduction to SQL and Databases

We should start by answering the obvious question.

### What Is a Database?

SQLite, PostgreSQL, MySQL, and SQL Server are database engines. SQL is the common language you use to talk to them. Each engine has its own extensions and quirks, but the core SQL concepts are shared.

A database is an organized system for storing data so it can be retrieved, updated, and kept consistent over time. In a relational database, data is stored in tables. Each table represents one kind of thing. For example, films, TV shows, actors, or episodes.
