

具体工具会不断更迭，但你在此练就的习惯将长存：将功能视为一个完整的系统来审视。数据从何而来？存储在何处？谁有权修改？出故障时会发生什么？一旦你能回答这些问题，编写、审查和修复代码就会变得更加容易。

最重要的是，你已经练习了一种学习方式，它将在工具演进的过程中持续助你一臂之力。具体的框架和模型会变，但你理解问题、将其拆解、并驾驭 AI 而不让它替你思考的能力将永存。

读完这本书不是终点，而是你拥有了足够多的拼图碎片、可以开始构建属于你自己的东西的起点。

# 接下来做什么

如果你对前端感兴趣：

*   构建一个小型作品集网站
*   学习一个框架（React、Vue）
*   探索无障碍访问和性能优化

如果你对后端感兴趣：

*   使用 Django REST Framework 构建 API
*   深入学习认证与安全
*   部署一个拥有真实用户的项目

如果你对全栈和部署感兴趣：

*   为 TallyApp 扩展分析、认证和支付功能
*   添加测试和 CI/CD
*   探索扩展与缓存

如果你对 AI 辅助开发感兴趣：

*   尝试 Agent 工作流
*   故意对比不同模型
*   构建一个使用 AI API 的工具

在转向另一本书或课程之前，先构建一些属于你自己的东西。它不需要庞大或复杂，只需真实且与*你*相关：

*   一个个人网站
*   一个你会用到的简单工具
*   一个增加了新功能的 TallyApp 变体

你从一个完成的小项目中学到的，将多于从三个被放弃的大项目中学到的。

# 祝你好运！

祝你在所有 Web 开发项目中一切顺利。AI 工具将持续演进，但你清晰思考、设计系统和评估方案的能力，将始终是你作为开发者技能的基石。

在学习过程中将 AI 作为助手，而非学习的替代品。让它为你解释、对比、测试并挑战你的工作。让它为你节省样板代码的时间。但不要让它决定你要构建什么，也不要让它判断结果是否足够好。这种判断权依然掌握在你手中。

所以，去构建别的东西吧。保持规模小，保持真实，并持续追问它是*如何*以及*为什么*工作的。

这才是你变强的途径。
