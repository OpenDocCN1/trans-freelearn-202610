# 前言

计算机科学作为一门学科从未停止发展。教授它往往让人感觉像是在试图跟上一个不断自我重塑的学科的步伐。近年来，人工智能的快速崛起使这一挑战进一步加剧。在许多方面，AI 使计算机科学教学变得前所未有地既容易又困难。容易是因为教师和学生可用的工具异常强大。困难是因为这些工具可能会掩盖我们试图教授的最基本原理。

在课堂上，仅仅向学生介绍编程语言和框架是不够的。我们必须帮助他们驾驭一个 AI 辅助开发司空见惯的生态系统。学生会尝试代码生成工具，并在遇到困难时依赖它们。他们可能在完全理解变量、程序流程或所用技术之前，就依靠这些工具生成可行的解决方案。虽然这能加快进度，但往往导致学生无法解释他们的代码为何有效。作为教育者，我们的责任是确保学生不将正确的输出误认为是真正的理解。

Mark Price 的 .NET 书籍一直是 Greenhead College 编程图书库中广受欢迎的藏书。他的书籍结构尊重学习者的旅程，在精心搭建概念阶梯的同时，仍紧贴现代真实世界的开发实践。清晰的解释、精心挑选的示例，以及对循序渐进构建理解的高度重视，使他的书籍成为我在入门和中级编程课程中使用过的最可靠资源之一。它们在支持学生完成大型课程项目方面被证明特别有效，在这些项目中，信心和清晰度与技术正确性同等重要。

随着 AI 辅助开发的兴起，格局再次发生变化。问题不再是学生是否应该使用 AI 工具，而是如何负责任且有效地使用它们。这就是为什么像*与 AI 副驾驶一起进行 Web 开发*这样的书显得如此及时。本书没有无视 AI 或将其视为捷径，而是直接回应了教育者当前面临的张力：如何拥抱这些工具，同时确保它们增强学习而非取代学习。

我期望这本书能延续 Mark Price 以往作品的优势。如果以他贯穿写作中对待框架和语言那种审慎深思的心态来对待 AI，这本书将帮助学生不仅开发出功能性的解决方案，还能获得真正的理解。这种在能力与理解之间的平衡，正是教育工作者和学习者在软件开发新时代所需要的。

*Stephen Wood*

*Greenhead College 计算机科学系主任*

# 关于作者

Mark J. Price 拥有超过 30 年向各类学习者教授编程和技术科目的经验。他广泛指导过不同阶段的学生，从学龄学习者和学徒到经验丰富的专业人士，帮助他们建立实用技能和技术自信。

除了软件开发工作，Mark 还教授数学和计算机，专注于使复杂的概念清晰易懂。他的教学风格强调理解系统如何运作，而非死记硬背语法，以便学习者能在实际情境中应用知识。

Mark 拥有计算机科学学士学位，职业生涯大部分时间致力于开发课程、撰写书籍，并支持学习者从基础概念进阶到构建完整、可运行的项目。
