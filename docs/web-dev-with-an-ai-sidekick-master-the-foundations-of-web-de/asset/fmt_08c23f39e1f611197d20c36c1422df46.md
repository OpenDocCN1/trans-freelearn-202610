# Strings in more depth

Strings appear everywhere in Python programs. User input, file contents, URLs, JSON data, HTML, error messages, and configuration values are all strings. Because they are so common, Python provides a rich set of features for working with them. Understanding strings well pays off immediately, especially in web and data-related code.

A `string` in Python is an immutable sequence of characters. Immutable means that once a string is created, it cannot be changed in place. Any operation that appears to modify a string is actually creating a new one, as shown in the following code:

```
text = "hello"
text.upper()
print(text)
```

This prints `hello`, not `HELLO`, because `upper()` returns a new string and leaves the original unchanged. To change the original text, you must assign the result of calling the `upper()` function to the `text` variable, as shown in the following code:

```
text = text.upper()
print(text)
```

Now `text` refers to the new string. This immutability is a design choice that makes strings safer and more predictable.

## Creating strings

Python provides several ways to create strings. You have already seen single-quoted and double-quoted strings, as shown in the following code:

```
name = "Alice"
city = 'London'
```

Both forms are equivalent. Use whichever makes the string easier to read, especially when it contains quotation marks.

For multi-line text, Python supports `triple-quoted strings`, as shown in the following code:

```
message = """Hello,
This is a multi-line string.
Goodbye."""
```

These are useful for long messages, documentation, or embedded text blocks.

## F-strings

One of the most important Python features is `f-strings`. F-strings provide a clear and readable way to embed values directly into strings, as shown in the following code:

```
name = "Alice"
age = 30
message = f"{name} is {age} years old"
print(message)
```

The `f` prefix tells Python to evaluate expressions inside curly braces. This approach is clearer and less error-prone than string concatenation, especially as strings become more complex.

F-strings can include expressions, not just variable names, as shown in the following code:

```
price = 9.99
quantity = 3
total = f"Total: {price * quantity}"
```

## String methods

Python strings come with many built-in methods for common tasks. You do not need to memorize them all, but a few are worth learning early.

The `lower()` and `upper()` methods change case:

```
text = "Python"
text.lower()   # "python"
text.upper()   # "PYTHON"
```

The `strip()` method removes whitespace from the start and end of a string:

```
raw = "  hello  "
clean = raw.strip()
```

This is especially useful when dealing with user input.

The `split()` method breaks a string into a list of substrings:

```
csv = "red,green,blue"
colors = csv.split(",")
```

The opposite operation is `join()`, which combines a list of strings into a single string, as shown in the following code:

```
colors = ["red", "green", "blue"]
result = ",".join(colors)
```

## Indexing and slicing strings

Strings can be indexed and sliced, just like lists:

```
word = "Python"
word[0]      # "P"
word[1:4]    # "yth"
word[-1]     # "n"
```

Slicing creates new strings and never modifies the original.

## Substrings

Another common task is checking whether a string contains a value or starts or ends in a particular way, as shown in the following code:

```
email = "user@example.com"
"@" in email
email.startswith("user")
email.endswith(".com")
```

These operations read cleanly and avoid fragile manual parsing.

## User input starts as a string

It is also important to understand that input from the user always starts as a string:

```
age = input("How old are you? ")
```

If you need a number, you must convert it explicitly, as shown in the following code:

```
age = int(age)
```

Failing to do this is one of the most common beginner mistakes and a frequent source of `TypeError` and `ValueError` exceptions.

## Strings are immutable

At this point, you should think of strings as immutable building blocks. You create them, transform them, combine them, and pass them around, but you never alter them in place. Python’s string tools are designed to make these transformations readable and safe.

As you move into file handling, web development, and APIs, strings will dominate your code. Being comfortable with f-strings and a handful of core string methods will make that work feel straightforward rather than fiddly.

# Functions and classes

As your programs grow beyond a few lines, repeating the same logic over and over quickly becomes painful. Functions solve this problem. A `function` is a named block of code that performs a specific task. Once defined, you can call it as many times as you like. This makes programs easier to read and easier to change.

## Defining functions

In Python, functions are defined using the `def` keyword, followed by the function name, a pair of parentheses, and a colon. The function body is indented, like any other block, as shown in the following code:

```
def greet():
    print("Hello, Python")
```

This code defines a function called `greet`. Nothing happens yet. Defining a function does not run it. To execute the code inside the function, you must call it by name, as shown in the following code:

```
greet()
```

When Python reaches this line, it jumps into the function, runs the indented block, and then returns to where it left off.
