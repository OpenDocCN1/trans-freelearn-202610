# 变换和动画

`Transforms` 和 `animation` 让 CSS 从布局走向了动态设计。谨慎使用时，它们能增加清晰度和反馈；滥用时，会让页面显得抖动且令人疲惫。这里的目标是控制，而非炫技。

本节介绍核心概念，而不让你的网站变成嘉年华。

## CSS 变换

变换让你在视觉上改变元素，而不影响其周围的布局。这一点比听起来更重要。

经过变换的元素：

* 在视觉上移动、旋转或缩放
* 仍在文档流中占据其原始空间

这就是为什么变换比 `margin` 或 `position` 更适合视觉效果。

最常见的变换函数如表 3.1 所示：

| 变换函数 | 说明 |
| --- | --- |
| `translate()` | 移动元素 |
| `scale()` | 调整元素大小 |
| `rotate()` | 旋转元素 |
| `skew()` | 倾斜元素 |

表 3.1：变换函数及其作用

让我们看一个代码示例：

```css
.card {
  transform: translateX(20px);
}
```

这会将应用了 `.card` 类的任何元素向右移动 20 像素，但其他元素的表现就像什么都没动一样。

你可以组合变换：

```css
.card {
  transform: translateY(-4px) scale(1.02);
}
```

顺序很重要。函数从左到右依次应用。

当与交互（如悬停按钮）结合时，变换特别酷：

```css
.button {
  transition: transform 0.2s ease;
}
.button:hover {
  transform: translateY(-2px);
}
```

这会在悬停时创建一个微妙的“上浮”效果，没有布局重排，也没有副作用。

**良好实践**：如果交互导致页面跳动或重排，很可能是用错了工具。

**思考**：为什么变换比使用 `margin` 或 `position` 更适合动画？

## `transition` 属性

过渡控制 CSS 变化随时间发生的方式。没有它们，状态变化是瞬间完成的：

```css
.card {
  transition: background-color 0.3s ease;
}
```

现在当背景颜色变化时，它会平滑地动画过渡。

你可以过渡多个属性：

```css
transition: transform 0.2s ease, box-shadow 0.2s ease;
```

**良好实践**：并非所有属性都适合过渡。最适合的有：`transform`、`opacity`、`box-shadow`、`background-color`。除非你知道为什么，否则避免为 `width`、`height`、`top` 或 `left` 等布局属性添加动画。

**思考**：哪些 CSS 属性可以安全地添加动画以获得性能，为什么？

## 关键帧动画

过渡响应状态变化。动画在自己的时间线上运行：

```css
@keyframes fade-in {
  from {
    opacity: 0;
  }
  to {
    opacity: 1;
  }
}
```

像这样应用它：

```css
.modal {
  animation: fade-in 0.3s ease;
}
```

这在元素出现时运行一次。

动画可以循环、反向、暂停并改变速度曲线。例如：

```css
.spinner {
  animation: spin 1s linear infinite;
}
@keyframes spin {
  to {
    transform: rotate(360deg);
  }
}
```

这仅用四行 CSS 就实现了一个完整的加载旋转器。

## 时序函数与真实感

时序函数塑造运动的手感。

常见值包括：`linear` 表示匀速，`ease` 表示缓慢开始和结束，`ease-in` 表示仅缓慢开始，`ease-out` 表示仅缓慢结束。

大多数 UI 交互应使用 `ease` 或 `ease-out`。`linear` 运动感觉机械。如果运动感觉不对，通常是时序问题，而非距离问题。

## 减少动画与无障碍

一些用户偏好较少的动画。CSS 允许你尊重这一点：

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none;
    transition: none;
  }
}
```

良好使用动画的指南：

* 使用动画解释变化。如果某物出现、消失或移动，动画能让它感觉是有意的。
* 保持时长短。大多数 UI 动画应在 150ms 到 300ms 之间。
* 少动画。一个移动的元素能吸引注意力。五个就是噪音。
* 从不无目的地添加动画。如果移除动画不会让界面变差，它可能就不该存在。

动画应帮助用户理解刚刚发生了什么。如果它仅因看起来酷而存在，它会迅速过时。

# 总结

在本章中，我们学习了以下内容：

* CSS 将表现与结构分离，并使用由选择器和声明组成的规则应用样式
* 外部样式表是跨页面管理和复用样式的首选方式
* 层叠根据特异性和顺序决定应用哪些样式
* 类可复用，且比 ID 更适合样式设置
* 每个元素都遵循盒模型：内容、内边距、边框和外边距
* 简写属性遵循一致的上右下左模式
