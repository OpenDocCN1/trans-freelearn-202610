
# 与 AI 副驾驶一起进行 Web 开发

《与 AI 副驾驶一起进行 Web 开发》通过利用交互式 AI 的力量，重新发明了初学者学习编程的方式。这本综合指南将静态的教科书体验转变为与您的 AI 编程伙伴的双向对话。您不再只是阅读代码，而是会提示 AI 解释概念、生成示例，并即时帮您解决问题。这就像拥有一位全天候可用的导师。

结果是一个高度引人入胜的学习旅程，能适应您的问题和需求。您可以毫无顾虑地问“愚蠢”的问题，获得即时澄清，并接受根据您的节奏量身定制的分步指导。这是一种引人入胜的快速学习编程的方式，让编程变得更易上手、更有成就感。通过利用 OpenAI 的 ChatGPT、Google 的 Gemini 等 AI 模型，本书将最新的 AI 技术变成您的私人编程导师和合作者。

## 适读人群

本书面向对 Web 开发感到好奇、并对利用 AI 学习编程技能和构建完整项目的可能性感到兴奋的完全初学者。本书非常适合：

*   首次探索编程的学生
*   转行进入技术领域、需要友好切入点的人
*   被传统教科书或视频课程压得喘不过气来的自学者
*   想要构建交互式 Web 项目的创意工作者、设计师或作家
*   有应用创意但缺乏正规训练的爱好者或企业家
*   对 AI 着迷并想知道它如何帮助自己学编程的任何人

它特别吸引那些偏好动手实践、注重实用学习，并重视在编码时能用自然语言提问的人。

## 需要什么前置知识？

无。本书假设您在编程、Web 开发或使用 AI 工具方面零基础。如果您会打开浏览器并遵循说明，就已经准备好了。早期章节会引导您完成每一步，包括如何注册 ChatGPT、安装带有 GitHub Copilot 等各种扩展的 VS Code，甚至如何有效地与 AI 对话。随后，本书会讲解网页如何构建和样式化、如何绘制图形、什么是变量、什么是循环，甚至如何托管您完成的 Web 项目。它从零开始，构建到一个完整的网站。

## 本书内容

让我们简要回顾一下您可以从本书中期待什么。

### 第 1 部分：前端 Web 开发

第 1 部分在专门的章节中介绍用于构建网页可见部分的主要技术，每章都为交互式学习而构建。您将从 Web 的基石开始：用于图形的 HTML、CSS 和 SVG，然后进阶到 JavaScript 及其类型化超集 TypeScript。

每章都以友好的方式介绍核心概念，并立即邀请您通过与 AI 聊天来实践。例如，学习 HTML 时，您会让 AI 生成一个简单的网页结构，然后通过提示词进行调整。这样，您就能亲身体验 HTML 定义含义和结构。

在 CSS 章节中，您将为页面添加样式，并了解 CSS 如何控制布局、颜色、间距和排版，从而加深对 CSS 描述元素应如何在屏幕、纸张或其他媒体上渲染的理解。

JavaScript 让您的网页活起来，您将与 AI 协作使页面具有交互性，这反映了 JavaScript 作为核心 Web 语言的角色，而 TypeScript 被作为一种为 JavaScript 添加静态类型以实现更安全编码的扩展而引入。

每章都包含练习，您会让 AI 工具解释、修改或调试小示例。每章以测验结束以巩固知识，并提供精选的官方文档链接列表供进一步参考，鼓励您将查阅权威来源作为学习的一部分。

### 第 2 部分：后端 Web 开发

然后我们在专门的章节中涵盖所有基本的后端 Web 开发技术，每章同样为交互式学习而构建。您将探索与 SQL 的数据库交互，深入 Python 编程，掌握 Django Web 框架，并熟悉用于自动化的 `Bash` 命令行脚本。

在 *第 1 部分* 和 *第 2 部分* 结束时，您将牢固掌握从前端到后端的整个 Web 技术栈，所有这些都通过与 AI 聊天机器人并肩进行的动手实践获得。

### 第 3 部分：调查项目

现在掌握了基础知识，您将踏上一个激动人心的毕业项目：使用 Django、现代 Web 技术，并在每一步都有 AI 助手协助，开发一个调查创建 Web 应用。本书的这一部分是一个基于项目的教程，分为几章，反映真实的开发工作流。

在规划阶段，您将在 Django 中设计应用的功能和数据模型，AI 将帮助头脑风暴模型字段和关系。我们将使用 `Docker` 容器设置专业开发环境，在本地运行 Django 和数据库，确保每个人都能使用相同的设置跟随学习。

本书提供了使用 OpenAI Codex 或 Anthropic Claude Code（尖端的 AI 驱动编码环境）构建项目的详细说明。我们将展示 Codex 或 Claude Code 如何将 AI 无缝集成到编码工作流中，以便您可以使用指令编写代码，并让 AI 起草代码，而您则进行审查、测试和修改。通过这个 AI 增强的过程，您将实现调查应用的所有关键功能：

*   创建包含多种问题类型（文本、多选、评分等）的调查
*   让用户提交回答
*   构建用于管理调查的管理界面
*   在动态表格和图表中显示结果

在此过程中，您将练习 AI 辅助调试和测试：例如，为 Django 视图编写单元测试。

我们强调有效的提示技巧以从 AI 获得有用的输出，同时也提醒 AI 的怪癖以及如何验证和修正 AI 生成的解决方案。

项目章节还突出了工具之间的协作。例如，使用 `Git` 版本控制（配合 GitHub 或本地）来管理 AI 建议的更改，并使用 `Docker` 进行本地实时测试。

在最后的项目章节中，我们将指导您将完成的应用部署到生产环境。在整个部署过程中，AI 副驾驶可以协助编写 `Dockerfile` 或 `.gitignore` 文件等任务。

在 *第 3 部分* 结束时，您将构建一个全栈 Web 应用，并在规划、编码、测试和部署期间练习使用 AI 工具。这是一个值得放入作品集的项目，它巩固了您在 *第 1 部分* 和 *第 2 部分* 学到的一切，并教您这些部分如何在真实应用中相互连接。

更重要的是，您将体验一种构建软件的新范式：与 AI 伙伴一起编码。
