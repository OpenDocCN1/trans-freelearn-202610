# Working with forms and inputs

So far, your page has been *read-only*. Forms are how a user types information into a page and sends it somewhere, like a contact form, login screen, newsletter signup, checkout, and so on.

At the center of this is the `<form>` element, which wraps your input controls (text boxes, dropdowns, buttons) and defines how the browser should submit the data.

In this section, you're going to:

1. Create a new page called `contact.html` with a contact form
2. Link to it from your `index.html` **About Me** page

## Create contact.html

In VS Code, create a new file in the same folder as `index.html`: `contact.html`.

Paste this in:

This HTML file is available from the following link: [https://github.com/markjprice/web-dev-ai/blob/main/Code/Chapter02/about-me-webpage/contact.html](https://github.com/markjprice/web-dev-ai/blob/main/Code/Chapter02/about-me-webpage/contact.html)

```
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <title>Contact Me</title>
  </head>
  <body>
    <h1>Contact Me</h1>
    <p>
      Use this form to send me a message. For now, it doesn't actually send email.
      It demonstrates how forms collect data and submit it to a server.
    </p>
    <form action="/contact" method="post">
      <h2>Your details</h2>
      <p>
        <label for="fullName">Full name</label><br>
        <input type="text" id="fullName" name="fullName" required>
      </p>
      <p>
        <label for="email">Email address</label><br>
        <input type="email" id="email" name="email" required>
      </p>
      <p>
        <label for="phone">Phone (optional)</label><br>
        <input type="tel" id="phone" name="phone">
      </p>
      <h2>Your message</h2>
      <p>
        <label for="topic">Topic</label><br>
        <select id="topic" name="topic">
          <option value="question">Question</option>
          <option value="feedback">Feedback</option>
          <option value="business">Business inquiry</option>
        </select>
      </p>
      <p>
        <label for="message">Message</label><br>
        <textarea id="message" name="message" rows="6" cols="40" required></textarea>
      </p>
      <h2>Preferences</h2>
      <p>
        Preferred contact method:
        <br>
        <input type="radio" id="contactEmail" name="preferredContact" value="email" checked>
        <label for="contactEmail">Email</label>
        <br>
        <input type="radio" id="contactPhone" name="preferredContact" value="phone">
        <label for="contactPhone">Phone</label>
      </p>
      <p>
        <input type="checkbox" id="newsletter" name="newsletter" value="yes">
        <label for="newsletter">Send me occasional updates</label>
      </p>
      <p>
        <button type="submit">Send message</button>
        <button type="reset">Clear form</button>
      </p>
    </form>
    <p>
      <a href="index.html">Back to About Me</a>
    </p>
  </body>
</html>
```

A few things to notice:

* The `<form>` has `action="/contact"` and `method="post"`
  * `action` is the URL the browser sends the form data to
  * `method="post"` sends the data in the request body; `get` (the default) appends it to the URL after `?`
* Every control that should be submitted has a `name="..."`. If you forget name, the value won't be included in the submitted data.
* Each text field is labeled using `<label for="...">` that matches the input's `id`. This improves both usability and accessibility.

## Link to the contact form from index.html

Open your existing `index.html` and add a link somewhere sensible, for example, under your `Useful link` section or near the bottom.

For example:

```
<h2>Contact</h2>
<p>
  Want to get in touch?
  <a href="contact.html">Go to my contact form</a>.
</p>
```

Because `contact.html` is in the same folder as `index.html`, a simple **relative link** like just the HTML filename works. Alternatively, you could specify an **absolute link** using a full URL: `https://example.com/contact.html`.

An absolute link is the full address of a resource, like a web page, that works regardless of the current page's location. A relative link is a shorter address based on the current page's location. If I am in Alaska and I want to send a letter to someone in Scotland, I would need to use their full, or absolute, address. If I wanted to send a letter to someone on my street, I could hand it to a neighbor and ask them to give it to "Bob at number 23." This is their address relative to another address on the same street. To send it to someone in the same city, we might need to use their street name too. To send it to someone in the same state, we would need to include their city name as well. A resource like a web page has one absolute address, and many relative addresses depending on how close you already are to their location.
