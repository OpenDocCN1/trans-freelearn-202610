
# 参考资料与资源

让我们回顾一下官方 HTML 文档和参考资料。

## MDN Web 文档（初学者应从此处开始）

MDN Web 文档是互联网上最好的 HTML 文档，适合学习和日常参考。它由 Mozilla 维护，浏览器厂商和 Web 社区共同贡献。

* 主页：[https://developer.mozilla.org/](https://developer.mozilla.org/)
* HTML 概览：[https://developer.mozilla.org/en-US/docs/Web/HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
* HTML 元素参考：[https://developer.mozilla.org/en-US/docs/Web/HTML/Element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element)
* 表单和输入元素：[https://developer.mozilla.org/en-US/docs/Learn/Forms](https://developer.mozilla.org/en-US/docs/Learn/Forms)、[https://developer.mozilla.org/en-US/docs/Web/HTML/Element/form](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/form) 和 [https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input)

MDN 之所以出色，是因为它是为人类而非律师编写的，示例简单明了，且解释了“为什么”而不仅仅是“是什么”。它与真实的浏览器行为保持同步。

**最佳实践**：如果初学者在学习 HTML 时只使用一个文档网站，那应该是 MDN。

## W3C HTML 规范（官方但不适合初学者）

**万维网联盟**（**W3C**）发布官方 HTML 规范。这是 HTML 在标准层面如何工作的正式定义。

* HTML 规范登录页面：[https://www.w3.org/TR/html/](https://www.w3.org/TR/html/)
* HTML 生活标准（WHATWG，见下文）：[https://html.spec.whatwg.org/](https://html.spec.whatwg.org/)

规范是为浏览器实现者编写的，如微软、谷歌和苹果的程序员，他们构建渲染引擎。它不是为了教授 HTML 而编写的。它晦涩、精确且不留情面。

这是参考资料，而非学习资料。你不会从头读到尾。只有在需要确切行为时才会查阅。

## WHATWG HTML 生活标准

现在大多数浏览器都遵循 WHATWG HTML 生活标准，它持续演进，而不是冻结在版本中。

HTML 生活标准：[https://html.spec.whatwg.org/](https://html.spec.whatwg.org/)

对于当前的浏览器行为，这是主要需要检查的规范。

同样，这不是给初学者读的。它用于检查边缘情况、消除歧义，以及理解浏览器实际如何行为。

## 初学者应如何实际使用这些资源

一种实用的方法是从 MDN 开始，构建一个小示例，仅在需要时查阅规范：

* 概念
* 示例
* 最佳实践

然后动手构建一些东西：

* 犯错
* 捣乱
* 修复它们

只有在那时，如果：

* 浏览器行为似乎古怪
* 你需要绝对精确
* 你好奇机制如何运作

才去浏览官方规范。

学习 HTML，请使用 MDN Web 文档。它以人类思维的方式解释 HTML。

W3C 和 WHATWG 规范定义了浏览器如何工作，但它们不是教学材料。请将它们视为参考手册，而非教程。

# 总结

在本章中，你学习了以下内容：

* HTML 描述内容的结构和含义，而非外观
* HTML 文档由元素构建，元素由标签和内容组成
* 属性提供配置元素行为的额外信息
* 标题创建页面的逻辑大纲，应反映含义而非外观
* 段落、列表、链接、图片和表格代表不同类型的内容
* 元素可以嵌套形成浏览器解释为树的层级结构
* 块级元素构建布局，而内联元素在文本中流动
* 语义化 HTML 提高了可访问性、搜索引擎理解和可维护性
* 表单允许用户输入数据并使用 `GET` 或 `POST` 提交到服务器
* 每个表单控件必须有名称才能包含在提交的数据中
* HTML 宽容且专为文档设计，不像 XML 等更严格的标记语言
* SVG 使用标记描述可缩放图形，可嵌入 HTML
* 良好的 HTML 为 CSS 样式和 JavaScript 交互创造了坚实的起点

## CSS 基础

CSS 存在的目的是控制表现：HTML 描述内容是什么，CSS 描述内容应该是什么样子。将这些关注点分离使网页更易于维护、重设样式和扩展。

在 [*第 2 章*](#02.xhtml#_idTextAnchor098) *HTML – 构建你的网页* 中，你使用标题、段落、链接、图片、列表、表格和表单创建了页面。此时，浏览器决定所有内容的外观。字体遵循浏览器默认值，间距基本，所有内容垂直堆叠。CSS 就是让你从浏览器手中夺回控制权，做出有意识的设计选择。

CSS 通过定义规则工作。每条规则说“选择这些元素”并“将这些样式应用到它们上”。一旦你理解了这句话，你就理解了 CSS 的核心。

## 向网页添加 CSS

有三种方法将 CSS 应用到 HTML。你在实际项目中会看到所有三种，但只有一种推荐用于大多数网站。它们是：

* **内联 CSS**：在元素级别定义样式。
* **内部 CSS**：在页面级别定义样式。
* **外部 CSS**：在网站级别定义样式。

让我们看看每种的例子。

**内联 CSS** 直接写在 HTML 元素上：

```
<p style="color: red;">This text is red.</p>
```

这行得通，但很乱。样式分散在你的 HTML 中，难以复用，维护痛苦。

**最佳实践**：除非在实验，否则避免使用内联 CSS。
