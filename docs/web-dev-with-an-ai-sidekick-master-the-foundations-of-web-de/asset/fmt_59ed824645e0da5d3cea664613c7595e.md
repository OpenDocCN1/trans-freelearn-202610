## Clean syntax using indentation

Python is a general-purpose language built around a simple idea: code should be readable.

It was created by Guido van Rossum and first released in 1991, which makes it older than Java, JavaScript, and even the web as we know it today. It feels modern because its design favors clarity over cleverness. That focus on readability is on purpose. Python assumes code will be read more often than it is written.

One of the first things people notice about Python is how little visual noise there is. Python avoids excessive punctuation and boilerplate. Instead of braces or keywords to mark blocks of code, Python uses indentation. That means the structure of your program is visible at a glance:

* When something is nested, it is indented.
* When it ends, the indentation stops.

This forces consistency, but it also removes an entire category of errors that beginners often struggle with in other languages.

The official Python design philosophy, known as *The Zen of Python*, explicitly states that readability counts and that simple is better than complex. You can read it at the following link: [https://peps.python.org/pep-0020/](https://peps.python.org/pep-0020/)

## Professional Python

Python is often described as beginner-friendly, and that is true, but it leaves out something important. Python is not a beginner language that you leave behind later. It is used professionally across a wide range of industries, including web development, automation, scientific computing, data analysis, machine learning, game development, and system administration.

Companies such as Google, Netflix, and Spotify use Python extensively in production systems. That combination explains much of Python's appeal: it is easy to start with, but it does not trap you in beginner territory.

## A rich standard library

Another important aspect of Python is that it comes with a rich standard library. When you install Python, you already have access to tools for working with files, dates and times, text processing, networking, mathematics, and more. This is often summarized as "batteries included".

For beginners, this means you can do useful things quickly without installing extra packages. For experienced developers, it means fewer external dependencies and a more predictable development environment.

## Python is interpreted, not compiled

Python is also an interpreted language, which affects how you work with it. You write Python code in plain text files, and the Python interpreter executes that code directly. There is no separate compilation step that turns your code into a standalone executable file, as happens in languages like C or C++, before you can run your program.

This gives you a quick feedback loop. You write a small piece of code, run it, see what happens, and adjust. That tight loop is especially valuable when learning, because experimentation becomes cheap and mistakes are easy to recover from.

## A vast ecosystem

Python has a very large ecosystem. There are millions of Python developers worldwide, and an enormous amount of documentation, tutorials, libraries, and community support. If you encounter a problem, it is very likely that someone else has encountered it before and written about it. That support matters. Learning a language also means learning where to look things up, how to read documentation, and how to build confidence one small fix at a time. Python usually makes that learning process easier because it introduces complexity gradually.

## Installing Python

Before diving into Python's syntax, you need a working Python installation. Python may already be installed on your computer, depending on your operating system:

* On Windows, Python is not reliably installed by default. Some newer Windows versions include a stub that launches the Microsoft Store, which often confuses beginners. The safest approach is to explicitly check.
* On macOS, Python is usually installed, but historically it was Python 2, which is no longer supported. Recent macOS versions may include Python 3, but you should still verify the version.
* On Linux, Python 3 is almost always installed because many system tools depend on it. Even so, checking is still necessary.

You can read the Python 2 end-of-life notice at the following link: [https://www.python.org/doc/sunset-python-2/](https://www.python.org/doc/sunset-python-2/)

Checking Python is done from the command line, because it is often run at the command line. Open a terminal or command prompt and run the following command:

```
python --version
```

If that does not work, try explicitly running Python 3, as shown in the following command:

```
python3 --version
```

You should see something like the following output:

```
Python 3.14.2
```

If so, then Python is installed correctly and you are ready to proceed.

### What if Python is missing?

If you see an error such as `command not found` or a message pushing you to the Microsoft Store, then Python is either missing or not configured properly.

> **Warning!** Python 3 is required for this book. Python 2 reached end of life in January 2020 and should not be used for new projects.

To manually install Python, for all platforms, the official source of truth is the Python website, maintained by the Python Software Foundation. You can download Python from the following link:

[https://www.python.org/downloads/](https://www.python.org/downloads/)

> **Warning!** For Windows, download the official installer from [python.org](https://www.python.org/), not the Microsoft Store, and during installation, make sure `Add Python to PATH` is checked. That checkbox is the single most common source of beginner frustration. If Python is not on the PATH, typing `python` will not work from the command line.

For macOS, downloading the macOS installer from [python.org](https://www.python.org/) is the simplest option. Advanced users may prefer Homebrew, but beginners should not start there.

For Linux, Python 3 is usually already installed. If not, installation is done through the system package manager, such as `apt`, `dnf`, or `pacman`, depending on the distribution.

After installation, repeat the version check command to confirm success.
