## Example 2: Profile editor

Add the following code block to a file named `example2.js` that the `<script>` element at the bottom of the web page references:

```javascript
const nameInput = document.querySelector("#nameInput");
const moodSelect = document.querySelector("#moodSelect");
const btnApplyProfile = document.querySelector("#btnApplyProfile");
const profilePreview = document.querySelector("#profilePreview");
btnApplyProfile.addEventListener("click", () => {
  const name = nameInput.value.trim();
  const mood = moodSelect.value;
  const displayName = name === "" ? "Anonymous" : name;
  profilePreview.textContent = `${displayName} (${mood})`;
});
```

## Example 3: Adding, removing, and counting list items

This section is about programmatically creating DOM elements. It teaches:

* Using `createElement` to create new HTML elements
* Using `append` to add an HTML element to an existing parent
* Using `dataset` to store custom data
* Simple UI bookkeeping

Add the following code block to a file named `example3.js` that the `<script>` element at the bottom of the web page references:

```javascript
const todoInput = document.querySelector("#todoInput");
const btnAddTodo = document.querySelector("#btnAddTodo");
const todoList = document.querySelector("#todoList");
const todoCount = document.querySelector("#todoCount");
function updateCount() {
  const items = todoList.querySelectorAll("li");
  todoCount.textContent = 
    `${items.length} item${items.length === 1 ? "" : "s"}`;
}
function makeTodoItem(text) {
  const li = document.createElement("li");
  li.className = "pill";
  li.dataset.done = "false";
  const checkbox = document.createElement("input");
  checkbox.type = "checkbox";
  checkbox.setAttribute("aria-label", "Mark done");
  const span = document.createElement("span");
  span.textContent = text;
  const removeBtn = document.createElement("button");
  removeBtn.type = "button";
  removeBtn.textContent = "Remove";
  removeBtn.dataset.action = "remove";
  li.append(checkbox, span, removeBtn);
  return li;
}
btnAddTodo.addEventListener("click", () => {
  const text = todoInput.value.trim();
  if (text === "") return;
  todoList.append(makeTodoItem(text));
  todoInput.value = "";
  todoInput.focus();
  updateCount();
});
updateCount();
```

Refresh the web page and in the **3) Quick to-do list** box, enter a task description like `Comment my code`, click the **Add** button, and note that a new item is dynamically added to the list of items, as shown in *Figure 5.10*:

Figure 5.10: Adding items to a to-do list using the DOM

## Example 4: Event delegation

Event delegation means having one event handler for the whole list.

This is a common real-world technique. Instead of attaching listeners to every remove button and checkbox, you attach one listener to the parent unordered list element (`<ul>`) and inspect what was clicked.

This code example teaches:

* The concept of event bubbling
* Using `event.target` to identify the target of an event
* Using `closest`
* Class manipulation via `classList`

Add the following code block to a file named `example4.js` that the `<script>` element at the bottom of the web page references:

```javascript
const btnClearDone = document.querySelector("#btnClearDone");
function updateCount() {
  const items = todoList.querySelectorAll("li");
  todoCount.textContent = 
    `${items.length} item${items.length === 1 ? "" : "s"}`;
}
function syncDoneStyles(li) {
  const done = li.dataset.done === "true";
  li.classList.toggle("success", done);
}
todoList.addEventListener("click", (event) => {
  const target = event.target;
  if (target instanceof HTMLInputElement
    && target.type === "checkbox") {
    const li = target.closest("li");
    if (!li) return;
    li.dataset.done = String(target.checked);
    syncDoneStyles(li);
    return;
  }
  if (target instanceof HTMLButtonElement
    && target.dataset.action === "remove") {
    const li = target.closest("li");
    if (!li) return;
    li.remove();
    updateCount();
  }
});
btnClearDone.addEventListener("click", () => {
  const doneItems = todoList.querySelectorAll('li[data-done="true"]');
  for (const li of doneItems) {
    li.remove();
  }
  updateCount();
});
// Initialize styles for the starter item (if any)
for (const li of todoList.querySelectorAll("li")) {
  syncDoneStyles(li);
}
updateCount();
```

Refresh the web page and in the **3) Quick to-do list** box, remove the initial item, and then add three new items: `alpha`, `beta`, and `gamma`. Then select **alpha** and **beta** to show they are *done*, and click the **Clear done** button, as shown in *Figure 5.11*:

![](Images/B34553_05_11.png)

Figure 5.11: Selecting items as done in a to-do list using the DOM

Note the two *done* items are removed.

Next to the gamma item, click **Remove**, and note that the item is removed.

## Example 5: Toggling classes and hiding sections

This code example teaches:

* Using `classList.toggle` to switch CSS classes on and off
* How to show or hide elements via CSS

Add the following code block to a file named `example5.js` that the `<script>` element at the bottom of the web page references:

```javascript
const btnToggleTheme = document.querySelector("#btnToggleTheme");
const btnToggleTodo = document.querySelector("#btnToggleTodo");
const todoCard = document.querySelector("#card-todo").closest(".card");
btnToggleTheme.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});
btnToggleTodo.addEventListener("click", () => {
  if (!todoCard) return;
  todoCard.classList.toggle("hidden");
});
```

Refresh the web page and in the **4) Theme + visibility** box, click the **Show/Hide the to-do list** button, and note that it disappears. Then click the **Toggle theme** button and note that the entire page switches between a normal and a dark theme, as shown in *Figure 5.12*:

![](Images/B34553_05_12.png)

Figure 5.12: Selecting items as done in a to-do list using the DOM

The dark theme is defined in the `styles.css` file using a class named `.dark`. All the JavaScript needs to do is set the class on the `<body>` element, as shown in the following code: `document.body.classList.toggle("dark")`.

## Summary of DOM commands

Here is a concise reference summarizing the DOM methods, properties, and related APIs used across the DOM manipulation examples:

* `document.querySelector(selector)`: Returns the first element that matches a CSS selector, or `null` if none is found:

```javascript
document.querySelector("#statusText")
```

* `element.querySelector(selector)`: Searches only within that element’s descendants for a match:

```javascript
todoList.querySelectorAll("li")
```

* `element.querySelectorAll(selector)`: Returns a static list of all matching elements:

```javascript
todoList.querySelectorAll('li[data-done="true"]')
```

* `element.textContent`: Gets or sets the plain text inside an element:

```javascript
statusText.textContent = "Status: Waiting…"
```
