## 本章小结

在本章中，你学习了以下内容：

* AI 工具能显著加速学习，但前提是将其作为**导师**而非**代码生成器**使用
* 高效的 AI 学习取决于**请求解释**，而非仅仅索取解决方案
* 结构化方法（如学习循环）能带来更深层的理解
* 提示词质量直接影响学习效果
* 聊天机器人最适合解释和学习，而 Copilot 等工具最适合实际编码

* 如果没有刻意的流程，Token 使用量和成本会迅速成为问题，因此分层方法——简单任务用廉价模型，复杂推理用高级模型——最高效
* 开发者通常组合使用多种 AI 工具，而非依赖单一工具
* 人类判断依然关键，因为 AI 不能取代开发者判断；它只是将角色从**编写代码**转移到**评估和优化代码**

## 什么是 HTML？

HTML 代表 **HyperText Markup Language**（超文本标记语言）。听起来很吓人，但概念很简单。

HTML **不是**编程语言：

* 它不做决策
* 它不运行逻辑
* 它不计算任何东西

HTML **描述**网页上内容的结构和含义。

HTML 是页面的**结构**。它定义：

* 哪些文本是标题
* 哪些文本是段落
* 什么算作列表
* 链接指向何处
* 哪些图片属于该页面
* 表格数据如何组织

CSS 负责让页面**好看**。你将在 [第 3 章](#03.xhtml#_idTextAnchor154) *CSS —— 为你的网页添加样式* 中学习 CSS。本章请忽略外观，专注于内容**是什么**以及**如何结构化**。

JavaScript 负责让页面**具有交互性**。本章创建的网页将是静态的。在 [第 5 章](#05.xhtml#_idTextAnchor266) *JavaScript —— 让网页具有交互性* 中，你将编写 JavaScript 代码让它们“活”起来。

HTML 决定**事物是什么**。没有 HTML，Web 就只是一堆非结构化的文本流。

### HTML 由元素组成

HTML 通过 **标签** 形成 **元素**。标签是包裹在尖括号中的实际标记语法，例如 `<p>` 或 `</p>`，告诉浏览器如何解析内容。而元素则是包含开始标签、内容和结束标签的完整结构。

例如，`<p>Hello</p>` 是一个段落元素，由开始标签 `<p>`、文本 `Hello` 和结束标签 `</p>` 组成。标签是构建块，元素是由这些标签创建的完整结构。

大多数元素长这样：

```html
<p>This is a paragraph.</p>
```

* `<p>` 表示 **开始一个新段落**
* `</p>` 表示 **段落结束**
* 中间的所有内容都是段落的内容

在 HTML 中，**属性** 为元素提供额外信息，放在开始标签内。它们通常以键值对形式出现，如 `class="intro"` 或 `href="https://example.com"`，用于修改元素的行为或显示方式。

例如，在 `<a href="https://example.com">Visit</a>` 中，`href` 属性告诉浏览器链接指向何处。元素定义结构和含义，属性则细化或配置该元素的行为。
