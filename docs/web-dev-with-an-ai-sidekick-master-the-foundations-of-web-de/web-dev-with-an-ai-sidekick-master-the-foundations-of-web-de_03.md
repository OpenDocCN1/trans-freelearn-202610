# 第 1 部分：前端 Web 开发

在本书的第一部分，你将专注于用户在 Web 应用中看到和交互的内容。你将从 HTML 和 CSS 入手理解结构和样式，使用 SVG 处理图形，再深入 JavaScript 和 TypeScript 以添加行为。你无需立即掌握每个细节，目标是让前端代码变得可读、不再令人畏惧。

在此过程中，你将了解浏览器如何解析和渲染页面，样式与布局决策如何影响可用性，以及微小的逻辑片段如何塑造用户体验。读完这一部分，你应该能够构建和调整简单的 Web 用户界面，并理解前端技术如何与系统其余部分连接。

本部分包含以下章节：

* 第 2 章 —— **HTML —— 构建你的网页结构**
* 第 3 章 —— **CSS —— 为你的网页添加样式**
* 第 4 章 —— **SVG —— 绘制可缩放图形**
* 第 5 章 —— **JavaScript —— 让网页具有交互性**
* 第 6 章 —— **TypeScript —— 更安全的 JavaScript**
