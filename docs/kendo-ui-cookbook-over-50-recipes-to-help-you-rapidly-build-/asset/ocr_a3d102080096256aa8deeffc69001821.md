# ## There’s more...

The area charts that were built in the previous example connected the values by a straight line. You can customize this by specifying the style of line to be used. The possible values are step and smooth:

```
```
line: {
    style: 'smooth'
}
```
```

When you specify `smooth`, the values in the chart are connected by a smooth line, that is, a curved line that connects the two points such that the chart looks like a curved line drawn to connect all the points, shown as follows:

![](bbox=[0.291, 0.588, 0.729, 0.827])

When you specify the style of the line as `step`, the values on the chart are connected by a line at right angles.
