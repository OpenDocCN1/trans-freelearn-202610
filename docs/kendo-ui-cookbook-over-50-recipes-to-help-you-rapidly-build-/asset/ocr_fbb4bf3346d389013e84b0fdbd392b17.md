The other way to subscribe to the event is to add a listener using the bind method on the
chart object:

```
var chart = $('#chart').data('kendoChart');
chart.bind('seriesClick', function (e) {
    for (var i = 0, j = e.series.data.length; i < j; i++) {
        e.series.data[i].color = '#00F';
    }
    e.dataItem.color = '#F00';
    this.redraw();
});
```

The first line in the preceding code snippet gets a reference to the chart object. The chart
object is then used to subscribe to the seriesClick event. Now when the user clicks on a
particular column in the series, the callback function will be invoked.

> When the chart is refreshed or redrawn, an animation is shown while
> the chart is drawn. To disable the animation, specify the transitions
> property as false.
