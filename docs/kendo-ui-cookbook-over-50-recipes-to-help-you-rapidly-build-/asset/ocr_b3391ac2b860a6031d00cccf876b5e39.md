# Using the Application object to navigate to various views

When building a mobile application, you will have multiple views representing various states in
the application, that is, each state is represented by a View component in the application.
For example, when you click on a button, the current view is disposed and the new view
should be displayed. The Application object is used to navigate between various views in the
application. These views can be defined in the same HTML document or can be present as a
separate document (partials).
