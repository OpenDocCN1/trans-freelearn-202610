The final step is to create a ViewModel object that contains all the model attributes that will be consumed by the previously mentioned elements. It should also specify the onChangeHandler function, which will be called when the user changes the values in the dropdown or selects the stacked checkbox, as shown in the following code snippet:

```
var viewModel = kendo.observable({
chartType: 'area',
chartSkin: 'blueopal',
isStacked: false,
onChangeHandler: function (e) {
var chart = $('#chartArea').data('kendoChart');
chart.setOptions({
seriesDefaults: {
type: this.chartType,
stack: this.isStacked
},
theme: this.chartSkin
});
});
```
