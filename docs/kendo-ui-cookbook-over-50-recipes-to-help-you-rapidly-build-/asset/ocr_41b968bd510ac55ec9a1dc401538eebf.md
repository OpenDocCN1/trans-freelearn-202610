Now let's create a function that will accept the shape details, which includes the text that needs to be shown, the shape type, and the position of the shape on the diagram:

```
function createShape(textData, type, positionX, positionY) {

    return new kendo.dataviz.diagram.Shape({
        x: positionX,
        y: positionY,
        width: 100,
        height: 50,
        type: type,
        content: {
            text: textData,
            color: '#FFF'
        },
        background: '#00B'
    });
}
}
```

In the preceding code snippet, the createShape function accepts the mentioned arguments and returns an instance of shape, that is, kendo.dataviz.diagram.Shape. Now let's create a few shapes and add them to the diagram:
