```javascript
var app = new kendo.mobile.Application(document.body, {
    transition: "zoom"
});
```

这使得过渡效果可以应用于整个应用程序。

## 为移动应用程序添加触摸事件

Kendo UI Mobile 框架提供了各种 API 来处理基于触摸的事件。你构建的应用程序不仅应允许用户在触摸界面上执行常规选择事件，还应处理各种触摸手势，例如双击、滑动和拖放。在本示例中，我们将查看可以添加的各种触摸事件。

## 操作方法...

为了本示例的目的，让我们考虑上一示例中使用的相同布局，并向页面添加一个视图。此视图的内容将是一个触摸小部件，用于指定视图中启用触摸事件的区域：

```html
<div
data-role="view"
data-layout="defaultLayout">
<div
id="touchSurface"
data-role="touch"
data-enable-swipe="1"
data-touchstart="touchstart"
data-swipe="swipe"
data-tap="tap"
data-doubletap="doubletap"
data-hold="hold"
style="height: 200px;">

Touch Surface

</div>
</div>
```

除了将 data-role 属性设置为 touch 之外，该小部件还包含各种 data 属性，用于指定触摸事件处理程序。这包括 touchstart、swipe、tap、双击和 hold。分配给这些 data 属性的值是事件处理程序的名称。这些事件处理程序将在 script 标记中定义。请注意，有一个属性 data-enable-swipe 设置为 1，表示启用了滑动功能：

```javascript
var app = new kendo.mobile.Application();

function touchstart(event) {
console.log('Event - Touch Start' + " X=" + event.touch.x.location + " Y=" + event.touch.y.location);
}
function tap(event) {
console.log('Event - Tap');
}
function doubletap(event) {
console.log('Event - Double tap');
}
function hold(event) {
console.log('Event - Hold');
}
function swipe(event) {
console.log('Swipe direction ' + event.direction);
}
```

## 工作原理...

当用户触摸表面时，会调用 `touchstart` 事件。`touchstart` 事件处理程序中可用的事件对象可用于确定触摸触发的 x 和 y 坐标。当用户在屏幕上轻点（即从触摸屏上抬起手指）时，会调用 `tap` 事件。同样，当用户快速连续在屏幕上轻点两次时，会调用 `doubletap` 事件。如果用户触摸屏幕并在几秒钟内不抬起手指，则会触发 `hold` 事件。当用户将手指从左向右或从右向左滑动时，会触发 `swipe` 事件。事件对象上可用的 `direction` 属性可用于确定用户发起滑动的方向。事件顺序如下：

- 当用户触摸屏幕时，将触发 `touchstart` 事件
- 当用户在屏幕上轻点时，将触发 `tap` 事件
- 当应用程序识别到第二次轻点时，将在 `tap` 之后调用 `doubletap` 事件

在 `hold` 的情况下，将执行以下顺序：

- 将触发 `touchstart` 事件
- 当用户长时间将焦点保持在同一点上时，将触发 `hold` 事件

### 简介

Kendo UI Mobile 库包含大量可直接在移动应用程序中使用的小部件。这些小部件允许您通过配置以匹配您的需求来构建一些常见的移动相关工作流。一些常用的小部件包括 ListView、ScrollView、ActionSheet、TabStrip 和 Navbar。该库还提供了一个 SplitView 小部件，可用于平板电脑应用程序。

## Kendo UI Mobile 小部件

在本章中，我们将了解如何创建显示扁平或分层数据集合的 ListView；然后，讨论可用于实现某些工作流的配置选项，例如构建无限滚动列表。然后将使用 ActionSheet 小部件对选定的列表元素执行操作。我们还将了解如何使用 ScrollView 小部件创建类似画廊的应用程序。SplitView 小部件用于平板电脑，在单个页面上显示两个不同的视图并绑定它们之间的交互。

## 使用 ListView 小部件创建列表

ListView 小部件允许您在页面上显示项目列表。此列表可以是扁平的或分组的。列表值可以在 HTML 标记中指定，或者 ListView 小部件可以绑定到 DataSource 对象。在本示例中，我们将了解如何创建一个 ListView 小部件，其中列表值在标记中指定。

## 操作方法...

可以使用无序列表或有序列表创建 ListView 小部件。要创建 ListView 小部件，请将 listview 值分配给 data-role 属性：

```html
<ul data-role="listview">
<li>
 <a href="her.html">
  <img src="./images/her.jpg" />
  Her
 </a>
</li>
<li>
 <a href="gravity.html">
  <img src="./images/gravity.jpg" />
 </a>
</li>
<li>
 <a href="12_years_a_slave.html">
  <img src="./images/12_years_a_slave.jpg" />
  12 Years A Slave
 </a>
</li>
</ul>
```

前面的标记包含一个无序列表，其中每个列表元素包含一张图片和一段文本。当应用程序初始化时，页面中存在的小部件将根据分配给 `data-role` 属性的值进行初始化。

## 工作原理...

当您渲染页面时，ListView 小部件将在移动设备上构建和渲染，如下面的屏幕截图所示：

![](img/2a66507445090790d34dc5588b56b24c_142_0.png)

在这里，每个列表项包含一个 `anchor`（指向页面的超链接）元素，其 `href` 属性引用 `html` 页面。此外，它还包含一个右箭头，与列表中每个项目的右侧对齐。这表明用户可以单击以查看列表中特定项目的详细信息。

当您单击列表元素时，将导航到相应的页面。

![](img/2a66507445090790d34dc5588b56b24c_143_0.png)

ListView 小部件与 DetailsButton 小部件集成，后者可用于在列表中每个元素的右侧添加图标。此图标用于说明可以在列表项上执行的操作。

要为列表元素添加 detailbutton，请插入一个 data-role 属性设置为 detailbutton 的锚元素。此外，您需要指定 data-style 属性，该属性指定正在添加的详细按钮类型。详细按钮支持四种样式：contactadd、detaildisclose、rowinsert 和 rowdelete。

您还可以通过指定 data-icon 属性而不是 data-style 来添加自定义图标：

```html
<ul data-role="listview">
<li>
Contact Add
</li>
</ul>
```
