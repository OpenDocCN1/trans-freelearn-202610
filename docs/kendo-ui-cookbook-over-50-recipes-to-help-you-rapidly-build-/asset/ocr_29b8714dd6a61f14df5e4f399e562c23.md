Here, in the series definition, the aggregate field specifies sum as the aggregate function to be used; this means that the chart will plot the total business made by a restaurant over a period of time. The other possible values that can be assigned to the aggregate include avg, count, first, min, and max. There is also an option to provide a custom aggregator function, which would return a value that should be used to project the data.

The series option specifies the color for the series and the labels option is used to display the data value on the chart. When you display a single series, all options can be specified in the series option instead of using the seriesDefaults option.
