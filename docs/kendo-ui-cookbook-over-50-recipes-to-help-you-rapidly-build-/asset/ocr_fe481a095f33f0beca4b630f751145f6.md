The only difference between the two templates is the use of the k-alt class in
altRowTemplate. Notice that the first column (td class='details') contains the
movieName field as well as the rating. The next step is to specify these templates while
initializing the Grid:

```
rowTemplate:kendo.template($('\'#gridRowTemplate\').html()),

altRowTemplate:kendo.template($('\'#gridAltRowTemplate\').html())
```

The compiled templates are assigned to the rowTemplate and altRowTemplate attributes.
