The preceding code snippet looks for the—name field and filters out the elements in the list.  
In all the previous cases, the list is filtered out as and when the user starts to type in the  
search input field. If you would like the user to click on the search button, then specify the  
autoFilter option and set it to false:

```
$('#listViewContainer').kendoMobileListView({
    dataSource: actors,
    template: '#= name #',
    filterable: {
        "field": "name",
        "autoFilter": false,
        "operator": "contains"
    }
});
```

By setting the autoFilter property to false, the user will have to hit the search button to  
get the filtered list. This is useful when you are working with a long list and don't want the list  
to refresh on every key input.
