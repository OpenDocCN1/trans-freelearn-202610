

## 本地化文件上传器小部件

要本地化文件上传器小部件，请按如下方式指定本地化选项：

```javascript
$('#fileUpload').kendoUpload({
async: {
'saveUrl': '/fileUploadService/save',
'removeUrl': '/fileUploadService/remove',
'autoUpload': true
},
localization: {
select: 'Choose files...',
remove: 'Remove file',
retry: 'Retry upload',
headerStatusUploading: 'Uploading files...',
headerStatusUploaded: 'Complete'
}
});
```

在此，"Select Files..." 标签将被替换为 "Choose files..."；remove 和 retry 的提示将分别为 "Remove file" 和 "Retry upload"。在文件上传期间，将显示 "Uploading files..." 消息，一旦上传完成，将显示 "Complete" 消息。

## 使用拖放上传文件

文件上传器小部件支持将文件拖放到文件上传器小部件上。此功能在所有支持 HTML5 File API 的现代浏览器中均受支持。只有当小部件配置为异步上传文件时，此方法才可用。

当您尝试将文件拖放到上传器小部件上时，它会显示 **drop files here to upload** 消息。

![](img/2a66507445090790d34dc5588b56b24c_108_0.png)

放置文件后，文件将被添加到列表中，并异步上传到服务器。

## 监听文件上传事件

在 HTML5 出现之前，XmlHttpRequest 可用的唯一事件监听器是 `readystatechange` 事件监听器。在 HTML5 中，已向 `XmlHttpRequest` 接口添加了多个事件监听器：loadstart、progress、load、abort、error、timeout 和 loadend。在本示例中，我们将了解可以附加到文件上传器小部件的各种事件监听器以及这些事件执行的顺序。

## 操作方法

文件上传器小部件会显示正在上传的文件的进度，并在所有文件上传完成时显示状态为已完成。但是，在许多情况下，您可能希望附加监听器并监听各种事件：

```javascript
$('#fileUpload').kendoUpload({
    async: {
        'saveUrl': '/fileUploadService/save',
        'removeUrl': '/fileUploadService/remove',
        'autoUpload': true
    },
    cancel: function () {
        console.log('Cancel Event.');
    },
    complete: function () {
        console.log('Complete Event.');
    },
    error: function () {
        console.log('Error uploading file.');
    },
    progress: function (e) {
        console.log('Uploading file ' + e.percentComplete);
    },
    remove: function () {
        console.log('File removed.');
    },
    select: function () {
        console.log('File selected.');
    },
    success: function () {
        console.log('Upload successful.');
    },
    upload: function () {
        console.log('Upload started.');
    }
});
```

在前面的代码片段中，指定了各种事件处理程序：cancel、complete、error、success、progress、remove、select 和 upload。

## 工作原理

当您尝试使用文件上传器小部件上传文件时，各种回调处理程序将按以下顺序执行：

- 1. 当您选择一个文件或多个文件时，将执行 `select` 事件处理程序。
- 2. 当上传器小部件开始上传文件时，将执行 `upload` 事件处理程序。
- 3. 在文件上传期间，`progress` 事件将被连续调用。请注意，事件对象具有一个 `percentComplete` 属性，用于指示上传到服务器的文件大小。
- 4. 文件上传完成后，将执行 `success` 处理程序。
- 5. 如果正在上传多个文件，并且所有选定的文件都已上传，则将执行 `complete` 处理程序。
- 6. 如果用户在文件上传进行期间尝试取消上传，则将执行 `cancel` 事件。
- 7. 文件上传完成后，如果用户尝试通过单击叉号 (x) 图标从上传器小部件中删除已上传的文件，则将执行 `remove` 处理程序。
- 8. 当 `remove` 和 `cancel` 事件执行完成后，也会执行 `complete` 处理程序。

## Kendo UI Window

在本章中，我们将介绍以下示例：

- 通过将其配置为模态窗口来显示弹出窗口并阻止用户交互
- 自定义窗口的外观并包含操作按钮
- 使用 Window API 对窗口对象执行操作

### 简介

Kendo UI Window 小部件用于在弹出窗口或模态窗口中显示任何 HTML 内容。窗口内容显示在页面上的其他内容之上，并带有带关闭按钮的标题栏。内容可以是静态 HTML，也可以使用 Ajax 动态加载。页面中的任何 DOM 节点都可以初始化为窗口，也就是说，DOM 中任何元素的内容都可以包装在窗口内。此外，窗口可以调整大小、移动和关闭。

Kendo UI Window 小部件提供了多个配置选项，可用于自定义可以应用的操作以及小部件的外观。在本示例中，我们将首先了解如何创建弹出窗口并将其配置为模态。然后，我们将自定义窗口的外观并使用 API 对窗口对象调用操作。

## 通过将其配置为模态窗口来显示弹出窗口并阻止用户交互

在本示例中，我们将了解如何为页面中的 DOM 节点创建 Kendo UI 窗口。随后，我们还将了解如何通过指定页面的 URL 来异步加载窗口的内容。

### 操作方法

让我们创建一个包含一些文本的 div 元素，这些文本将显示在窗口中：

```html
<div id="window">
 Window content goes here...
</div>
```

下一步是在前面的 DOM 节点上调用 kendoWindow 函数：

```javascript
$("#window").kendoWindow();
```

使用 kendoWindow 函数初始化 DOM 节点后，您会注意到窗口中包含 div 元素中提到的文本并正在显示。请注意，这不会添加背景遮罩层。要添加背景遮罩层，应将窗口配置为模态。

窗口和模态之间的区别在于，在模态的情况下，会显示隐藏正文内容的背景遮罩层。要创建模态窗口，请将 modal 属性指定为 true：

```javascript
$("#window").kendoWindow({
 modal: true
});
```

默认情况下，modal 属性的值为 false，因此不会显示背景遮罩层。

### 工作原理

当您初始化任何 DOM 节点时，其内容将被包装在窗口中，如下面的屏幕截图所示：

![](img/2a66507445090790d34dc5588b56b24c_113_0.png)

窗口包含 **Window content goes here...** 文本，标题栏上有一个叉号 (x) 图标。如果将其初始化为模态窗口，则会向页面添加背景遮罩层，如下面的屏幕截图所示：

![](img/2a66507445090790d34dc5588b56b24c_114_0.png)

请注意，背景遮罩层是半透明的；它会显示页面中存在的文本，并突出显示窗口。这将阻止您与页面的其余部分进行交互。通常，只有在用户需要在继续下一步之前完成某个操作时，才会使用模态窗口。例如，在同一用户查看页面内容之前，可能会显示包含登录表单的模态窗口。

### 更多内容

模态窗口可以配置为在用户触发操作时打开。例如，单击按钮时可以显示模态窗口。此外，由于模态的内容是在用户在页面上触发操作时加载的，因此模态的内容可以在运行时使用 Ajax 加载。

### 在单击按钮时显示模态窗口

在前面提到的场景中，窗口或模态窗口在页面加载时显示。在大多数场景中，您可能希望仅在用户发起操作时才显示模态窗口。让我们假设当用户单击按钮时应显示模态窗口。

让我们按如下方式在页面上放置一个按钮：

```html
<button id="btn1">Click</button>
```

要隐藏模态窗口，请将 `visible` 属性设置为 `false`，如下所示：

```javascript
$('#window').kendoWindow({
    visible: false,
    modal: true
});
```
