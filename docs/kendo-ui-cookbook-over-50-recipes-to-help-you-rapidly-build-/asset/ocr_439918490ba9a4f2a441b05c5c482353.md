# There's more...

Note the look and feel applied to the Grid. Alternate rows in the Grid have different colors;
even the Grid header has a color applied to it. This is because of the inclusion of the kendo.
default.min.css style sheet. The library comes with several themes, which you can
apply by removing the reference to the default style sheet and then adding the reference to
one of the themes. For example, the library comes with the moonlight theme. By adding a
reference to kendo.moonlight.min.css, the look and feel of the Grid will change.
