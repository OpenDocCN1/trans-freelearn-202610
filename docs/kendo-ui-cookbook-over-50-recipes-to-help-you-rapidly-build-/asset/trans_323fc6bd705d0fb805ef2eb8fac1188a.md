## Kendo UI 食谱

Kendo UI 是一个一站式库，允许您使用 HTML5 和 JavaScript 为 Web 和移动平台构建应用程序。该库包含多个小部件，可让您快速构建引人注目的 Web 应用程序。使用 Kendo UI 库，利用现代 Web 技术为 Web 和移动平台构建 Web 应用程序现在变得轻而易举。本食谱包含可应用于日常项目的实用配方，并能轻松构建引人注目的应用程序。它将带您了解应用程序框架，然后引导您了解各种小部件，您可以在项目中以最小配置即用这些小部件。它还提供可用于为各种移动平台构建 Web 应用程序的配方，同时保持单一代码库。

## 本书将为您做什么...

- 掌握 Kendo UI 应用程序框架的基础知识
- 使用 Grid、TreeView、Editor、PanelBar、Modal Window 和 File uploader 等各种小部件，并根据业务要求自定义您的应用程序
- 为移动平台构建 Web 应用程序，并在 iOS、Android、BlackBerry 和 Windows Phone 8 上提供原生外观和感觉
- 利用图表和仪表板小部件等数据可视化组件，构建视觉效果引人注目且交互性强的应用程序
