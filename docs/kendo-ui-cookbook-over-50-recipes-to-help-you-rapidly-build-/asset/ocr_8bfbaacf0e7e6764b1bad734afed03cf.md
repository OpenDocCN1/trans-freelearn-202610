In this chapter, we will cover the following recipes:

# ## Introduction

The Kendo UI library provides several advance charting widgets that can be used to visualize data. These include the Stock Chart widget that shows you the stock price history of a particular stock, the Map widget that visualizes data on a map, the Gauge widget that creates a dashboard that contains gauge charts, Barcode and QRCode widgets that allow you to create codes that can be used to identify products, and the Diagram widget that creates diagrams that show you nested relationships between various entities. These are some of the advance charts in addition to the basic charts mentioned in the previous chapter.
