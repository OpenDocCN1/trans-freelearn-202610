Here, the async configuration specifies the three attributes: saveUrl, removeUrl, and autoUpload. The saveUrl property specifies the service URL where the files will be uploaded. The removeUrl property specifies the service URL that will handle the removal of the uploaded files. The Boolean autoUpload property specifies whether the files will be uploaded when they are selected by the user or when the user clicks on the Submit button. In this example, this is set to true, which means that the files will be uploaded to the server when the user selects the file.

When you select multiple files using the file uploader widget, each file is uploaded asynchronously. The client sends a POST request with the file data in the request payload. It uses the XmlHttpRequest object to send an asynchronous POST request to saveUrl.
