# # Kendo Ui PanelBar

In the preceding HTML markup, each list item contains the heading and content that needs
to be displayed when the user clicks on an item in the PanelBar.

> > The destinationData class used in the preceding code snippet is used

The final step is to initialize the PanelBar widget. To initialize, call the kendoPanelBar
