# Showing values on the chart as labels

The chart can be customized to show you the values on the chart at specific points. The labels
option is used to show you the value on the plotted chart:

```
seriesDefaults: {
type: 'area',
labels: {
visible: true,
format: '{0}%'
}
}
```
