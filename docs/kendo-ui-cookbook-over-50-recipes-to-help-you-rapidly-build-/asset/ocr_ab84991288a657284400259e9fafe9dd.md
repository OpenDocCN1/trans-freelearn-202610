To enable endless scrolling instead of adding the load more button, set the endlessScroll
attribute to true:

```
function initListView (e) {
    $('#listViewContainer').kendoMobileListView({
        dataSource: {
            transport: {
                read: '/movies/listService'
            },
            pageSize: 10
        },
        endlessScroll: true
    });
}
```
