By default, none of the elements in the hierarchy are expanded initially. To expand an element
when it is rendered, specify the expanded data attribute as true:

```
.
.
<li data-expanded="true">
Directory2
<ul>
<li>File3.txt</li>
<li>File4.txt</li>
</ul>
</li>
.
.
```

By specifying the data-expanded attribute as true, the element would expand to show
you the next-level elements in the hierarchy.
