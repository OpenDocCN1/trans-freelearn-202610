Here, the bindings for various model attributes such as chartType, chartSkin,
isStacked, dataset, and onChangeHandler are specified. The onChangeHandler
function is an event handler that handles change events from dropdowns and the input
checkbox. When one of these values change, the chart will be updated. The setOptions
function is used to specify the type and stack value in the seriesDefaults field and also
the theme to be used for the chart. The refresh function is then called to update the chart.
The dataSet attribute specifies the DataSource object to be used when plotting the chart.
