# # How it works...

Each element in the ListView widget has a right arrow (>), which indicates that an action can be invoked on the list element:

![](bbox=[0.355, 0.178, 0.669, 0.479])

When you tap on any of the list elements, the ActionSheet widget is shown. The widget slides from the bottom of the screen and lists the options or actions that the user can perform, as shown in the following screenshot:

![](bbox=[0.349, 0.576, 0.675, 0.905])
