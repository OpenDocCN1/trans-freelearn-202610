In the preceding code snippet, the mobileListViewInit function is used to initialize
the ListView widget. This function is invoked when the view that contains the ListView
widget is initialized. The view should specify the data-init attribute that refers to the
mobileListViewInit function as its value. The dataSource property is used to
provide the input data (that refers to the actors array), and it also specifies the group
property whose value is startsWith. Apart from the dataSource property, the list's
view initialization also contains the template and fixedHeaders properties. The
fixedHeaders property is used to fix the header for each list group when the user
scrolls the list.
