# # About the Author

**Sagar Ganatra** is a frontend architect from Bangalore, India. He is an expert in building web applications using modern web technologies such as HTML5, CSS3, Object-Oriented JavaScript, Kendo UI, jQuery, and JavaScript frameworks such as BackboneJS, RequireJS, and AngularJS. He also writes about these technologies in his blog at `http://www.sagar ganatra.com/`. This is his second book; his previous book is _Instant Kendo UI Mobile_, _Packt Publishing_, which was published in 2013. When he is not coding, he enjoys writing short stories, swimming, and reading books.
