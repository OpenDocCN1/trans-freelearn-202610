+   4. Click State/Province in the Data pane and select Geographic Role | Hexmap.xlsx.

+   5. Click Map | Background Layers and set the Washout (%) to 100%.

So why this effort? Because a grid map distributes the states evenly. If you did this without it, you wouldn’t be able to distinguish between states in close proximity and would miss some that are far away.

Thank you, Klaus, for this great tip! By the way, a hex map is not only applicable to the U.S. Try it with Europe, Africa, South America, or the Asia-Pacific (APAC) region as well! Whenever you work with variances in size, a grid map comes in handy.
