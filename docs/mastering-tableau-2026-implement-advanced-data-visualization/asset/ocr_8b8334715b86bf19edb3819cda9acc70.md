Real-world scenario: why would you want to use a window average? Because you want to smooth the outliers, for example. A window average provides a steady representation of your data. Single highs or lows will be removed. If you analyze stock prices, you will notice that prices can differ throughout the year! By using the window averages, or rather window standard deviations, as an early warning indicator, you will be able to see price jumps more clearly and can, as an investor, act upon them. Steady growth or decline will, however, fall into the moving bands. This is not achievable by using fixed bands.
