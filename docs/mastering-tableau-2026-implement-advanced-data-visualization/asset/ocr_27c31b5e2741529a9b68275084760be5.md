Perform the following steps:

+   1. Navigate to https://github.com/PacktPublishing/Mastering-Tableau-2026/tree/main/Chapter12 to locate and download the workbook associated with this chapter
+   2. Navigate to the Types of Events worksheet
+   3. Select Help | Settings and Performance | Start Performance Recording
+   4. Press F5 on Windows or Command + R on macOS to refresh the view
+   5. Select Help | Settings and Performance | Stop Performance Recording. A new dashboard will open:

# Figure 12.1: Performance summary

There are four main parts to be looked at:

+   - **Performance Summary** shows the amount of time the dashboard needed to execute all the steps that happened between step 3 (start performance recording) and step 5 (stop performance recording). The slider can be used to filter.
+   - **Timeline** shows which step happened when and how long it took.
