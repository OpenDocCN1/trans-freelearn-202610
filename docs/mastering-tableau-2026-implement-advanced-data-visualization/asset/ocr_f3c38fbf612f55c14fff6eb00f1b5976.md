# How to implement UPSERT in Prep:

+   1. **Input recent data**: Configure your input step to pull only recent records (say, the last 14 days where edits might occur)

+   2. **Write to temporary table**: Use an **Output** step to write to a staging table, not your final target

+   3. **Add custom SQL after output**: In the **Output** step's Custom SQL tab (look for the **After** section), write your MERGE statement:

```
MERGE INTO target_table AS target
USING temp_table AS source
ON (source.id = target.id)
WHEN MATCHED THEN
UPDATE SET target.value = source.value
WHEN NOT MATCHED THEN
INSERT (id, value) VALUES (source.id, source.value);
```

This approach gives you complete control over how data merges into your final destination. It’s a bit more advanced, but once you’ve set it up, it runs like a charm.
