The ZIP contains multiple CSV files. Here's what each file does:

| File | Purpose | Key fields |
|---|---|---|
| stops.txt | All train stop locations | stop_id, stop_name, stop_lat, stop_lon |
| routes.txt | Transit lines | route_id, route_short_name, route_type |
| trips.txt | Individual journeys on each route | trip_id, route_id |
| stop_times.txt | When each trip hits each stop | trip_id, stop_id, arrival_time, departure_time, stop_sequence |
| calendar.txt | Which days each trip runs | service_id, Monday, Tuesday, etc. |
| calendar_dates.txt | Exceptions (holidays, special service) | service_id, date, exception_type |
| frequencies.txt | Headway-based service (if used) | trip_id, start_time, end_time, headway_secs |
| transfers.txt | Connection times between stops | from_stop_id, to_stop_id, transfer_type |
| agency.txt | Transport companies | agency_name, agency_url |
| feed_info.txt | Metadata about the feed. | feed_publisher_name, feed_version |
