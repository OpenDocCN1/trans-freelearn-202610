
## Exporting data to a mobile phone

While developing a dashboard, Tableau Creator has the option to take a look at Device Designer or Device Preview. Whenever you are on a Dashboard tab, you can find it here:

![](img/66cf6b89349fda3581a4f196cb3c98a4_69_0.png)

Figure 1.50: Device Preview

Tableau comes with default phone settings. If needed, those defaults can be adjusted by clicking on Phone and then on the three dots. Once you're in Device Designer mode, select a Device type option, and you'll get choices of the most common models. Please be aware that you can only use the sheets that are in the default layout of your dashboard. If you want to add a default layout for a tablet, for example, go into Device Designer mode, select Tablet, and move the content so that the sheets you want to see on your tablet are within the device frame. Satisfied? Then add the new layout (highlighted in Figure 1.50) to the workbook. It will appear under the Default one in the top-left area. The user can now select the design needed whenever opening a workbook from Tableau Server.

Not only can your projects be viewed conveniently on a mobile device, but you can also work on them on the go using Tableau Mobile! We'll cover this in the next section.

## Tableau Mobile

To support flexible working, Tableau has created an app that can be downloaded from the App Store or from Google Play, called Tableau Mobile. Once installed on your phone and/or tablet, you will get the option to connect the app to Tableau Server or Tableau Online. Go ahead and publish the dashboard we created in this chapter, in the Building a dashboard section, to either of those two instances. If you have questions regarding the publishing, please see Chapter 13, Exploring Tableau Server and Tableau Cloud, for further instructions.

At the bottom of your landing page, click **Explore** to see all views you just published. Click on the **Building a Dashboard** view and see your previously created dashboard. The best part is yet to come. The dashboard is fully interactive, so try the drop-down filter or the **Medals** filter. Also, try to click on a mark and select **Keep Only**. By clicking on the workbook icon at the top right (the first icon from the left), all the other sheets you created will be visible, making it possible to switch between sheets:

![](img/66cf6b89349fda3581a4f196cb3c98a4_70_0.png)

Figure 1.51: Sheet selection

Now, if you click the three dots at the top right, even more options will appear, such as **Revert**, **Alert**, **Subscribe**, and so on. To learn more about the different options that are also available on Tableau Server, see _Chapter 13, Exploring Tableau Server and Tableau Cloud_. For now, we can conclude that Tableau Mobile makes it easy to check your favorite dashboards wherever you are.

## Follow-along dashboard using basics

To give you another chance to practice your Tableau skills, I have prepared the following exercise for you. Simply follow-along! We'll use the **Global CO2 Emissions by Country** dataset from **Our World in Data (OWID)**.

This dataset is great for practicing Tableau because it contains yearly CO2 emissions, population, and per-capita values across countries; perfect for learning comparisons, trends, and geographic visualization:

- 1. Go to the OWID CO2 dataset repository at https://github.com/owid/co2-data and download the CSV file.
- 2. Save the file locally on your computer. I called it OWID.csv.
- 3. Open Tableau Desktop.
- 4. On the start page, click Connect | To a File | Text File.
- 5. Select the downloaded OWID.csv file:

![](img/66cf6b89349fda3581a4f196cb3c98a4_71_0.png)

![](img/66cf6b89349fda3581a4f196cb3c98a4_71_1.png)

![](img/66cf6b89349fda3581a4f196cb3c98a4_71_2.png)

Need help adding data? Learn more

![](img/66cf6b89349fda3581a4f196cb3c98a4_71_3.png)

Figure 1.52: OWID.csv

- 6. Open a new worksheet and drag Year to the Columns shelf, drag Co2 to the Rows shelf, and name the worksheet Emission Trends.
- 7. To include only countries without any aggregations, such as all Organization for Economic Co-operation and Development (OECD) countries, please move ISO Code to the Filter shelf and deselect the Null value. Click on the filter again and select Apply to Worksheets | All Using This Data Source.

![](img/66cf6b89349fda3581a4f196cb3c98a4_72_0.png)

Figure 1.53: Emission Trends

You have now finished the first of three worksheets. A line chart shows emission trends.

- 8. Next, add a new worksheet and drag **Country** to the **Rows** shelf. Also, drag **Co2** to the **Columns** shelf. Then, drag **Year** to the **Filter** shelf, and filter for the most recent year (e.g., 2023). Make sure your **Year** pill is discrete (blue).
- 9. Now, sort the chart in descending order and give the worksheet the title **Top Emitters: <Year>**. By adding the <Year> variable to the header, the title will be auto-adjusted, depending on the year you select. The **ISO Code** filter is inherited from the **Emission Trends** worksheet since we applied the filter there to all worksheets using the OWID data:

![](img/66cf6b89349fda3581a4f196cb3c98a4_72_1.png)

- 11. Next, drag **Co2_per_capita** to **Color** and **Year** to the **Filter** shelf, and set the filter to the same year you used in the second worksheet, **Top Emitters**.
- 12. Adjust the color scale to highlight differences (e.g., darker colors = higher per-capita emissions). I called this worksheet World Emission: <Year>.
