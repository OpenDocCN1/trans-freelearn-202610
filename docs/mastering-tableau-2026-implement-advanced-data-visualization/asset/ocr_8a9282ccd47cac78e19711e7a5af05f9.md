**Note**
A note on Tableau Public

A common question from the community is whether Einstein Discovery can be used with Tableau Public. The short answer is that the live extension will not work in a Public workbook. However, as a workaround, you can use the Tableau Prep Prediction step to append predictions to your data and then save that augmented dataset for use in Tableau Public. While this creates a static snapshot rather than a live, interactive prediction, it still allows you to share the power of predictive analytics in your public portfolios.
