+   3. You now has the option to save the data to a file, and also to save it in Hyper file format as .hyper, as .xlsx (new in Tableau 2021.1), or as a .csv file.

+   4. Another option is to publish the newly generated data source directly to Tableau Server and make it available to other users. For this option, select **Publish as a data source** instead of **Save to File** from the dropdown.

+   5. A third option to save Prep output has been added to Tableau 2020.3 — writing the resulting data to an external database. If you want to do so, select the **Database** table option from the dropdown. At the time of writing, seven databases are compatible with the write-back functionality, but more will be added based on user demand.
