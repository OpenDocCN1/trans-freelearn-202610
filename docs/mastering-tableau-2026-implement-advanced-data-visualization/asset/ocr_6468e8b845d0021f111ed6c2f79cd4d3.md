# Follow-along dashboard

In this chapter's follow-along, we will connect to an OData feed, explore its data, build two basic visualizations, and combine them into a simple dashboard. Let's start! Follow these steps:

+   1. Open Tableau.
+   2. In the Data Source tab, under Connect, find To a Server and select OData.
+   3. In the OData URL field, enter the following: https://services.odata.org/V4/Northwind/Northwind.svc/.
+   4. Click Sign In (no credentials needed).
