接下来，让我们看看 Tableau 2021.1 引入的几项与 FIXED LOD 相关的新功能。

## 表范围表达式

编写 FIXED 表范围 LOD 表达式的快捷方式（等效于 {FIXED : MAX([Order Date])}）是：

```
{MAX([Order Date])}
```

如果在 Superstore 数据集上使用此计算，您将获得与编写以下内容完全相同的结果：

```
{FIXED : MAX([Order Date])}
```

无论您在视图中显示什么，此字段始终会从整个表中检索最新数据。很酷，对吧？
