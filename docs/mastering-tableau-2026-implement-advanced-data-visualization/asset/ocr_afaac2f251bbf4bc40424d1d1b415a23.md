The result is your very own emissions dashboard that shows a line chart comparing emissions over time for **International Organization for Standardization** (ISO) countries, and a bar chart of the top CO2-emitting countries for the latest year, with a filter option to select any other year present in the dataset. Finally, you have a world map highlighting per-capita emissions, which also serves as a filter when clicking on any given country.

This combination gives a holistic view of global emissions and allows interactive exploration. I hope you like it! Feel free to add some more functionality and upload it to your Tableau Public profile.
