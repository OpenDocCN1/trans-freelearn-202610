For our purposes, we will stick to using sheet selection to assist with creating dashboards that adhere to the design principles we’ve discussed.

In the Using pie charts sparingly section, we discussed pie charts and treemaps, and we noted that a treemap is a better visualization. However, people are often more comfortable with pie charts. As a compromise, in the first exercise, we will review an example that allows the end user to choose whether to see a pie chart or a treemap.
