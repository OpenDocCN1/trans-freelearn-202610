# Follow-along dashboard using relationships

We will now apply your relationship knowledge in a follow-along dashboard exercise. The dataset we will use is from a fictional music store called Chinook. We will work with artists, genres, sales, and employees.

Start this exercise by downloading the data from https://www.kaggle.com/datasets/anurag629/chinook-csv-dataset.

+   1. In Tableau, connect to the Artist.csv file first.
+   2. Now, drag the Album.csv file to the right side of the Artist.csv file until a noodle appears, linking both CSVs in a relationship. Use the ArtistId field as a connecting key between the two datasets.
