We'll build a dashboard with: A top filter bar, three KPI tiles (Sales, Profit Ratio, Avg Ship Days), a map of sales by state and a sales-over-time trend.

+   1. Open Tableau Desktop.

+   2. Connect to the Sample Superstore dataset.

+   3. Drag the Orders table onto the canvas.
+   We'll now mimic the KPIs in the Sample Superstore dashboard: Sales, Profit Ratio, and Avg Shipping Time.

+   4. Open a new worksheet, create a calculated field and set the default number format to Percentage:

```
Profit Ratio = SUM([Profit]) / SUM([Sales])
```

+   5. Create another calculated field:

```
Shipping Days = DATEDIFF('day', [Order Date], [Ship Date])
```

+   6. We'll now build three separate KPI sheets, then lay them out in a row. Open a new sheet and name it KPI – Sales

+   7. Drag Sales to Text on the Marks card

+   8. Change the mark type to Text

+   9. Click Text and then the three ... In the new window, type SUM(Sales) and behind it Sales

+   10. Format the SUM(Sales) to a bigger font (e.g. 20–28pt) and make it bold, use e.g. 15–20 for the word Sales.
