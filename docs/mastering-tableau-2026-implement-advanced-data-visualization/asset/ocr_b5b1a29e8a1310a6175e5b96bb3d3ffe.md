# What the GPU handles in Tableau:

+   - Map rendering (especially when zooming and panning)
+   - Scatterplots with thousands of marks
+   - Dashboard animations and transitions
+   - Visual effects like transparency and gradients

# Signs your GPU may be underpowered:

+   - Maps take noticeably longer to render than queries
+   - Scrolling or zooming feels "choppy"
+   - Dashboards with many marks render slowly even after the query completes

For a quick test, open a map-heavy dashboard on two different machines—one with integrated graphics (most laptops) and one with a dedicated GPU (gaming or workstation laptop). You'll often see dramatic differences in panning and zooming smoothness, even when query times are identical.

# Recommendation for Tableau developers:

+   - For standard bar charts, line charts, and crosstabs: integrated graphics are fine
+   - For map-heavy dashboards or large scatterplots: consider a machine with a dedicated GPU (NVIDIA or AMD)
+   - For presentation dashboards (rarely interacted with): GPU matters less than initial load time

> Note: Tableau Server rendering uses the server's GPU (if available). For enterprise deployments serving many map-heavy dashboards, GPU-equipped server nodes can significantly improve the user experience.

Now that we have our basics straight, let us take a look at a feature that can slow down your performance unintentionally and how to solve it. Our first on-the-fly technique is called auto updates.

Auto updates can be accessed either via the icon located on the toolbar, via Worksheet | Auto Updates, or by using the shortcut key F10 on Windows or Option + Command + 0 on Mac. Auto updates give the author the option of pausing/resuming auto updates for the worksheet and/or for filters and can come in very handy if you want to make multiple changes to your layout but want to avoid Tableau loading after every change because every load means a new query is sent to your underlying data source and has to be processed, which will cost processing power. You can simply pause the update, make your changes, and then run the update once.
