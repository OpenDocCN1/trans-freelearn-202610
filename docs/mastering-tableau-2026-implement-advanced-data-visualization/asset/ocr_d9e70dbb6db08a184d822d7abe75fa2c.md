Do you want to build fancy dashboards too, but your drawing skills are mediocre, just like mine? Don't worry!
This section will give you the tools to achieve it anyway. InterWorks has developed a tool similar to painting by
numbers – the perfect application to build polygons without drawing too much yourself. You can find it here:
https://cbstudio.interworks.com. All you need to do is find an image, upload it to the tool, and start
drawing along the lines.

For this exercise, I searched for an image of a bookshelf on the internet:

+   1. Open the free drawing tool from InterWorks and select the **Images** option:

+   2. Upload your image and select **Polygon** in the **I'M CREATING** section
