## 前言

本畅销 Tableau 指南的新版将教您如何在现代 BI 领域中利用 Tableau 的最新功能。本书更新了包含 Tableau Server、Tableau Cloud、Tableau Prep 和 Tableau Desktop 最新功能的新主题，并提供了最新的示例和解决现实世界挑战的方案，将带您从掌握基本 Tableau 概念一直到高级功能。

在本书中，您将学习如何将各种文件和数据库连接到 Tableau Desktop 和 Prep Builder。您将能够轻松执行数据准备和处理，通过实用的动手示例掌握复杂连接、空间连接、并集和数据混合。您还将掌握数据填充，并使用 Tableau Exchange 探索计算、映射和可视设计的其他专家级技术。

后面的章节将教您如何提升仪表板性能、连接到 Tableau Server 和 Tableau Cloud，并通过现实世界示例理解数据可视化。您还将学习自助分析、时间序列分析和地理空间分析等高级用例。此外，您将学习如何将 Tableau 与 Python 和 R 连接，将强大的编程功能直接带入您的 Tableau 工作流。

全新的第 15 章“Tableau AI、Pulse 和 Next 的智能时代”涵盖了 Tableau 的前沿内容：代理分析、Tableau Pulse、Tableau Next、Einstein Discovery 以及所有正在改变我们处理数据方式的 AI 驱动功能。所有其他章节均已完全更新，以反映最新功能。

读完本书后，您将掌握适用于现代分析时代的 Tableau。您将有信心应对数据分析领域中常见和高级的挑战。

## 本书适合人群

本书面向希望真正掌握 Tableau 的业务分析师、BI 专业人员和数据分析师。无论您是想解决复杂的数据科学问题，还是构建更好的商业智能仪表板，都能在这里找到实用的动手指导。

如果您之前使用过 Tableau，将更快掌握高级功能。但如果您是 Tableau 新手，也请不要担心；我设计了每一章，使其易于理解，配有清晰的解释和大量的跟随操作练习。您只需要好奇心和学习意愿。

## 本书内容

第 1 章“回顾基础”将带您了解入门所需的基本 Tableau 概念。您可以将其视为 Tableau 宇宙的友好引导。

第 2 章“准备数据”是一章偏理论的章节，将帮助您理解数据准备，从而自信地驾驭即使是最混乱的数据集。
