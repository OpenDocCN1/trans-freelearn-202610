# # Exporting data to a mobile phone

While developing a dashboard, Tableau Creator has the option to take a look at Device Designer or Device Preview. Whenever you are on a Dashboard tab, you can find it here:

![](bbox=[0.325, 0.15, 0.625, 0.44])

Figure 1.50: Device Preview

Tableau comes with default phone settings. If needed, those defaults can be adjusted by clicking on Phone and then on the three dots. Once you're in Device Designer mode, select a Device type option, and you'll get choices of the most common models. Please be aware that you can only use the sheets that are in the default layout of your dashboard. If you want to add a default layout for a tablet, for example, go into Device Designer mode, select Tablet, and move the content so that the sheets you want to see on your tablet are within the device frame. Satisfied? Then add the new layout (highlighted in Figure 1.50) to the workbook. It will appear under the Default one in the top-left area. The user can now select the design needed whenever opening a workbook from Tableau Server.

Not only can your projects be viewed conveniently on a mobile device, but you can also work on them on the go using Tableau Mobile! We'll cover this in the next section.

# # Tableau Mobile

To support flexible working, Tableau has created an app that can be downloaded from the App Store or from Google Play, called Tableau Mobile. Once installed on your phone and/or tablet, you will get the option to connect the app to Tableau Server or Tableau Online. Go ahead and publish the dashboard we created in this chapter, in the Building a dashboard section, to either of those two instances. If you have questions regarding the publishing, please see Chapter 13, Exploring Tableau Server and Tableau Cloud, for further instructions.
