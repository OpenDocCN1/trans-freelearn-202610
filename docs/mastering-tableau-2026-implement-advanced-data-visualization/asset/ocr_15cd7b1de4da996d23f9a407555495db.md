# What is new in version 2026.1?

The 2026.1 release is a huge step forward in Tableau's evolution, introducing enhancements that refine usability, expand connectivity, and deepen the platform's integration with AI-driven analytics. Building on the foundation of previous releases, this version focuses on delivering a more seamless and intelligent user experience.

In this section, we will explore the key updates and capabilities introduced in Tableau 2026.1, highlighting how they streamline workflows, improve collaboration, and bring analytics closer to everyday decision-making.

# Image export improvements

When exporting or creating subscriptions, Tableau 2026.1 introduces a new extension export services architecture that helps you load dashboards that use extensions and generate image outputs that match how you see your data when logged in. This ensures that your subscriptions, alerts, and downloads always look exactly as intended. Analysts and admins can simplify considerations around exports and automated jobs and provide a unified dashboard experience when users download them, access subscriptions and thumbnails, receive alerts, collaborate on Slack, and more.
