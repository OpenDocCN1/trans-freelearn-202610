```python
import pickle
import os

# Connect to TabPy
client = Client('http://localhost:9004/')

def sentiment_analyzer(review_texts):
    """
    Analyzes sentiment of customer reviews
    Returns: polarity score (-1 to 1) and subjectivity score (0 to 1)
    """
    import pandas as pd
    from textblob import TextBlob

    results = []
    for text in review_texts:
        if pd.isna(text) or text == "":
            results.append([0.0, 0.0]) # Neutral for empty reviews
        else:
            try:
                blob = TextBlob(str(text))
                polarity = blob.sentiment.polarity
                subjectivity = blob.sentiment.subjectivity
                results.append([polarity, subjectivity])
            except:
                # Fallback if TextBlob fails
                results.append([0.0, 0.0])

    return results

# Deploy function to TabPy
client.deploy('sentiment_analyzer',
              sentiment_analyzer,
              'Returns sentiment polarity and subjectivity for customer reviews',
              override=True)

print("Models deployed successfully!")
print("Check endpoints at: http://localhost:9004/endpoints")
```

## Common issues and fixes:

- Let's say your script returns error. It's possible that the TabPy server is not running. Check your terminal and restart TabPy.
- If the performance is slow, this could be because of too much data. Try adding data source filters, and aggregate some more.
- If the sentiment scores are all 0, the text field might be empty or null. Add in a data quality filter.

## If your dashboard feels slow, try these optimizations:

- 1. **Add data source filters**: Limit to last 12 months of reviews
- 2. **Use extracts instead of live connection**: Create a Tableau extract after Python processing
- 3. **Simplify scripts**: Move complex logic to deployed functions (faster than inline)
- 4. **Cache results**: For static analysis, run Python once and save results
