# Figure 1.26: Creating a URL action

This action will load the respective wiki page for each mineral whenever the user clicks on a mineral name in the Demand Minerals... worksheet. You have to make sure that the correct Web Page object is selected (wikipedia.org) and that the Base case (Wiki) field is inserted as a suffix to the Wikipedia URL. What this will do is enable the URL to change according to the selected value in the dashboard. In Figure 1.26, you can see an example below the URL, in blue: https://en.wikipedia.org/wiki/cobalt. This is the result when "cobalt" is selected. I created the Base case (Wiki) field from the original Base case field and changed uppercase to lowercase, as well as "Battery-grade graphite" to "graphite" to comply with the Wikipedia logic. In Chapter 13, Improving Performance, this topic will be discussed in more detail.

> In Tableau, filters are used to subset the underlying data based on certain conditions, while action filters allow users to interactively filter data by clicking on a visual element.
