The easiest way to install Python is by performing the following steps:

+   1. Use Anaconda with the Python 3.11 version (you will need at least Python 3.7): https:// www.anaconda.com. Any other Python interpreter will work too. To integrate Python and Tableau, some additional steps are needed:

+   2. Open, for example, Jupyter Notebook within Anaconda and write:

```
!pip install tabpy
```

Alternatively, execute the following command on the command line or Terminal (for Mac) in your Python directory:

```
pip install tabpy
```

+   3. Navigate to the directory where TabPy has been installed via the command line or Terminal (for Mac) and type tabpy into the command line or Terminal interface:

+   4. You are now connected to the tabpy server, which must remain open while running Tableau and Python combined

+   5. If you encounter any other issues with TabPy, for example, version incompatibilities, a quick Google search will go a long way
