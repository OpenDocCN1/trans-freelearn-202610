## 序言

生成式 AI 让许多人对 Tableau 等工具感到紧张。“AI 不会直接为我们构建仪表板吗？”我经常听到这种说法。说实话，对于简单的图表，也许会。但数据可视化从来不仅仅是关于构建图表。它关乎沟通。它关乎理解某人需要看到什么、为什么需要看到它，以及看到之后会做什么。AI 可以生成柱状图。它无法在利益相关者会议上坐下来，弄清楚哪些问题才真正重要。那种判断力需要练习。它需要系统化的学习。而这正是本书的用途。

《精通 Tableau》涵盖了非常广泛的内容。你从你预期的地方开始：工作表、仪表板、数据连接，以及经常让比应有范围更多的人绊倒的连续/离散区分。但它不会止步于此。关于数据准备和 Tableau Prep Builder 的章节有力地提醒我们，可视化之前的工作往往决定了当有人不可避免地问到一个你未计划的问题时，分析是否经得起考验。连接、混合、关系、数据垫片：这些在这里都得到了妥善处理，而不仅仅是一笔带过。

表计算章节是我特别想推荐给大家的一个。分区和寻址逻辑是大多数 Tableau 用户知道存在，但很少真正感到自如的主题之一。这里的方法，通过一、二、三维的游乐场建立直觉，正是我希望更多人学习它的方式。层次详细度计算也得到了类似深度的讲解。FIXED、INCLUDE 和 EXCLUDE 全都基于 Tableau 的计算顺序，这比大多数人意识到的要重要得多。

还有许多 Tableau 资源默默跳过的主题。数据密化。域完成和填充。自定义多边形。空间连接。集成 R 和 Python。性能调优。甚至有一节关于在 Tableau 中分析国际象棋比赛的内容，这种创造性的延伸会提醒你这个工具实际上有多灵活。

设计章节将一切汇集在一起：格式规则、色彩理论、布局模式，以及从筛选器操作到集合操作的每种操作类型的演示。以及关于 Tableau Server、Cloud 和数据治理的结尾部分，确保你思考你的工作如何超越桌面。

我制作了 600 多个 Tableau 视频。快速教程可以让你入门。但如果你想理解这个工具，拥有知道何时以及如何使用产品以及何时不使用的直觉，你需要更全面的东西。

这就是那本书。

*蒂姆·恩格韦纳*

内容创作者，五次 Tableau 首席专家和分析顾问

### 关于作者

玛琳·迈尔是一位成就卓著的数据策略家、作者和治理领导者，热衷于将复杂数据转化为值得信赖的可操作洞察。她将传统分析方法与机器学习、AI 和代理分析等现代方法相结合。

目前在瑞士再保险行业工作，玛琳担任数据治理负责人，她致力于通过强大的数据治理框架推动包括 AI 在内的数据计划。在这一职位上，她确保数据不仅可访问且高质量，而且可信且合规。她相信，没有可靠数据，最精巧的（AI）模型也是无用的，她每天都在努力弥合这一差距。

玛琳曾在德国、荷兰、美国、新加坡以及现在的瑞士等多个国家生活和工作，为她的工作带来了真正的全球视野。她跨文化的多样化经历塑造了她的协作和解决问题的方法。

玛琳的奉献精神、专业知识以及推动数据分析边界的承诺，使她成为该领域值得信赖的权威。通过她的写作、演讲活动以及在 Tableau 社区中的积极存在，她旨在赋予个人和组织力量，释放其数据资产的全部潜力。
