Think of the Tableau Exchange as the app store for your analytics environment. It is a curated hub where you can discover, evaluate, and deploy a wide range of pre-built assets that extend Tableau's native capabilities. As of the 2026.1 release, the Exchange has evolved to support the entire agentic analytics ecosystem, offering four main categories of assets:

| Category | Purpose | Example |
| :--- | :--- | :--- |
| Extensions | Custom applications that integrate directly into dashboards | Einstein Discovery Extension, natural language processors |
| Accelerators | Pre-built dashboards and workbooks for specific business functions | Sales forecasting templates, churn analysis dashboards |
| Connectors | Pre-built connections to external data sources | Salesforce, Google Analytics, Snowflake, AWS |
| Semantic Assets | Reusable metric definitions and business logic | Certified KPIs, industry-specific data models |

# The Einstein Discovery Extension

Since we discussed Einstein Discovery in the previous section, let’s explore how to actually obtain and configure it through the Exchange.

+   Installation steps:
+   
+   1. Navigate to the Tableau Exchange from within Tableau Cloud or your browser
+   2. Search for **Einstein Discovery** in the **Extensions** category
+   3. Review the extension details, including required licenses (Einstein Discovery in Tableau, Tableau CRM Plus, or Einstein Predictions)
+   4. Click **Install** and follow the prompts to add it to your Tableau site
+   5. Once installed, the extension appears in your Dashboard pane under **Extensions**

Map fields carefully by ensuring your Tableau fields match the input fields expected by your deployed Einstein model, test with sample data before rolling out to your organization by validating predictions on a subset of data, and set permissions to control which users can access the extension and which models they can query.

# Supporting AI innovation

Beyond the core platforms, the 2026.1 release brings AI-powered assistance to the authoring and learning experience.

In Tableau Desktop, you can now speed up the creation of custom color palettes while ensuring contrast and accessibility. By using the new Auto Generate button in the Custom Color Palette dialog, you can simply enter a few words or a short description (e.g., sunset over ocean) to instantly generate a new, accessible color scheme. This is a small but delightful example of how AI is weaving itself into every corner of the Tableau experience.
