For enterprises with legacy systems or industry-specific databases, this feature removes a major barrier to cloud adoption. You can now bring your existing connectors with you to Tableau Cloud.

# # Tableau app for Microsoft 365

You can now ensure your work is based on the latest data and insights with the **Tableau app for Microsoft 365**, generally available in Tableau Cloud and Tableau Server. In addition to the existing integration with Microsoft Teams, users can now embed their Tableau content directly into PowerPoint slides and Word documents to tell compelling stories with trusted data.

This integration brings Tableau's powerful visualizations directly into the tools you already use for presentations and reports. No more screenshots or manual updates; your embedded visualizations stay connected to the live data on Tableau Server.

# # SCIM agnostic to authentication protocol

For enterprise administrators, the 2026.1 release brings increased flexibility and simplified integration by extending **System for Cross-domain Identity Management (SCIM)** support on Tableau Cloud beyond SAML to include the modern **OpenID Connect (OIDC)** protocol. Cloud Administrators can now seamlessly select OIDC as an authentication method in the SCIM configuration. This makes user provisioning and identity management more flexible, especially for organizations that have adopted OIDC as their primary authentication protocol.
