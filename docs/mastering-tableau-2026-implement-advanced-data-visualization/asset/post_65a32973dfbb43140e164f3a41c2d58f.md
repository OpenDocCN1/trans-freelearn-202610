You will also require:

| Component | Recommendation |
| --- | --- |
| CPU (Processor) | Faster single-core speed matters more than more cores. Look for CPUs with high clock speeds (3.5GHz+). |
| RAM (Memory) | 8GB minimum, 16GB recommended for large datasets or complex dashboards. More RAM allows larger extracts to stay in memory. |
| SSD (Storage) | Upgrading from HDD to SSD can reduce workbook load times by 50-70%. Essential for working with local extracts. |
| Graphics Card (GPU) | Tableau uses GPU for map rendering and some visual effects. Integrated graphics work for most dashboards; dedicated GPU helps with large maps or many marks. |
| Network Connection | 100Mbps+ recommended for cloud data sources. Local extracts bypass network latency entirely. |
