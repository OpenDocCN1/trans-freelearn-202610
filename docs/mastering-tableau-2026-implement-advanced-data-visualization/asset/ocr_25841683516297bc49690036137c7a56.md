In the preceding screenshot, the Join worksheet has double the expected results. Why? Because a join first matches the common key (in this case, Salesperson/Sales Associate) and then aggregates the results. The more matches found on a common key, the worse the problem will become. If multiple matches are found on a common key, results will grow exponentially. Two matches will result in squared results, three will give cubed results, and so forth.
