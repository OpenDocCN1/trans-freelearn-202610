None of these changes will change the data source itself. Prep is like an in-between step, or a filter between the original data source and your Tableau Desktop. This table will take you through the options shown in Figure 3.10:

| Option | What it does | Example |
|---|---|---|
| Keep Only | Filters the data to show only rows containing the selected value. All other rows are hidden. | You select Germany in a Country column and choose Keep Only; you now see only German customers. |
| Exclude | Filters the data to remove all rows containing the selected value. | You select Germany and choose Exclude; you see all countries except Germany. |
| Edit Value | Changes the selected value to something else (a form of renaming or correcting). | You select Germny (misspelled) and choose Edit Value; you type Germany and all instances update. |
| Replace with Null | Replaces the selected value with a null (missing value). | You select Unknown and choose Replace with Null; all Unknown entries become empty/null. |

Table 3.1: Options to treat your data
