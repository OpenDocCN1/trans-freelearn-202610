# # Creating worksheets and dashboards

At the heart of Tableau are **worksheets** and **dashboards**. Worksheets contain individual visualizations, and dashboards contain one or more worksheets. Additionally, worksheets and dashboards may be combined into **stories** to communicate particular insights to the end user through a presentation environment. Lastly, all worksheets, dashboards, and stories are organized in **workbooks**, which can be accessed using Tableau Desktop, Server, Reader, or the Tableau Mobile app.

In this section, we'll consider how to create worksheets and dashboards. Our intention here is to communicate the basics, but we'll also provide some insights that may prove helpful to more seasoned Tableau users.

# # Tableau Public

At this point, I would like to introduce you to **Tableau Public** (https://public.tableau.com). It is a web-based collection of dashboards, as well as a creator's platform that allows you to design beautiful dashboards without a license or installation. Although it doesn't come with all the same features as **Tableau Desktop**, you can install the Tableau Public version to follow-along with most examples in this book.

Even if you do use Tableau Desktop, I recommend creating a Tableau Public profile for sharing all the dashboards you've created that you think the world shouldn't miss out on. The best part, however, is that you can download many of the ones created by others, open them in your own version of Tableau, and start learning and replicating. In summary, Tableau Public is a free option for developing dashboards but offers limited data source connectivity, and feature availability. However, it does provide an excellent platform for downloading and sharing visualizations.
