## 序言

生成式 AI 让许多人对 Tableau 等工具感到紧张。“AI 不会直接为我们构建仪表板吗？”我经常听到这种说法。说实话，对于简单的图表，也许会。但数据可视化从来不仅仅是关于构建图表。它关乎沟通。它关乎理解某人需要看到什么、为什么需要看到它，以及看到之后会做什么。AI 可以生成柱状图。它无法在利益相关者会议上坐下来，弄清楚哪些问题才真正重要。那种判断力需要练习。它需要系统化的学习。而这正是本书的用途。

《精通 Tableau》涵盖了非常广泛的内容。你从你预期的地方开始：工作表、仪表板、数据连接，以及经常让比应有范围更多的人绊倒的连续/离散区分。但它不会止步于此。关于数据准备和 Tableau Prep Builder 的章节有力地提醒我们，可视化之前的工作往往决定了当有人不可避免地问到一个你未计划的问题时，分析是否经得起考验。连接、混合、关系、数据垫片：这些在这里都得到了妥善处理，而不仅仅是一笔带过。

表计算章节是我特别想推荐给大家的一个。分区和寻址逻辑是大多数 Tableau 用户知道存在，但很少真正感到自如的主题之一。这里的方法，通过一、二、三维的游乐场建立直觉，正是我希望更多人学习它的方式。层次详细度计算也得到了类似深度的讲解。FIXED、INCLUDE 和 EXCLUDE 全都基于 Tableau 的计算顺序，这比大多数人意识到的要重要得多。

还有许多 Tableau 资源默默跳过的主题。数据密化。域完成和填充。自定义多边形。空间连接。集成 R 和 Python。性能调优。甚至有一节关于在 Tableau 中分析国际象棋比赛的内容，这种创造性的延伸会提醒你这个工具实际上有多灵活。

设计章节将一切汇集在一起：格式规则、色彩理论、布局模式，以及从筛选器操作到集合操作的每种操作类型的演示。以及关于 Tableau Server、Cloud 和数据治理的结尾部分，确保你思考你的工作如何超越桌面。

我制作了 600 多个 Tableau 视频。快速教程可以让你入门。但如果你想理解这个工具，拥有知道何时以及如何使用产品以及何时不使用的直觉，你需要更全面的东西。

这就是那本书。

## 本书内容

第 1 章“回顾基础”将带您了解入门所需的基本 Tableau 概念。您可以将其视为 Tableau 宇宙的友好引导。

第 2 章“准备数据”是一章偏理论的章节，将帮助您理解数据准备，从而自信地驾驭即使是最混乱的数据集。





- 第 3 章，使用 Tableau Prep Builder，介绍 Tableau Prep Builder，即 Tableau Desktop 不那么“小”的 ETL 兄弟产品。你将学会轻松清洁、塑形和合并数据。

- 第 4 章，了解连接、混合和数据结构，解答这个经久不衰的问题：关系、连接还是混合？你将学习在什么时候使用哪种方式。

- 第 5 章，介绍表计算，涵盖表计算的特殊魔力。这些强大函数使用数据顺序来分配排名、运行总和和移动平均。

- 第 6 章，利用 OData、数据密度化、大数据和 Google BigQuery，教你如何利用大数据解决方案并掌握数据密度化的概念，以实现更灵活的分析。

- 第 7 章，练习详细级别计算，帮助你解锁这个高级主题。你将学习如何更改数据的粒度，以进行精确、强大的计算。

- 第 8 章，超越基础，向你介绍高级可视化概念和 Tableau Exchange。在那里你将发现扩展程序、加速器和连接器，为你的工作簿注入强大动力。

- 第 9 章，使用地图，探索 Tableau 的原生映射功能及更多。你将使用自定义多边形、热图、分层地图和现实世界空间分析。

- 第 10 章，设计仪表板和可视化最佳实践，引导你了解格式化技术和设计原则，以最大限度地提升可视化的影响力和清晰度。

- 第 11 章，利用高级分析，通过三个动手跟练练习帮助你将分析技能提升到新水平：自助分析、时间序列分析和地理空间分析。

- 第 12 章，提升性能，涵盖从数据源到仪表板设计的各个性能方面。本章将赋予你创建加载速度快、用户友好的仪表板的能力。

- 第 13 章，探索 Tableau Server 和 Tableau Cloud，涵盖 Tableau Server 和 Cloud 的不同产品和功能。你还将探索 Ask Data、数据详情以及最新的 2026.1 功能。

- 第 14 章，集成编程语言，向你展示如何将 R 和 Python 与 Tableau 集成。这将解锁几乎无限的分析能力，从统计建模到情感分析。

- 第 15 章，Tableau AI、Pulse 和 Next 的智能时代，向你介绍 Tableau 的前沿领域。你将探索代理分析、Tableau Pulse、Tableau Next、Einstein Discovery，以及所有正在改变我们处理数据方式的 AI 驱动功能。

- 第 16 章，制定数据治理实践，介绍数据治理这一重要主题。你将学习如何遵守法规、记录数据，并使用 Tableau 的治理功能建立信任。

具备 Tableau 基础知识会让你领先一步，但我已将每一章设计得即使是初学者也能轻松上手。你的 14 天免费试用结束后需要 Tableau 许可证，做练习时请牢记这一点。话虽如此，本书中的大多数练习都可以使用 Tableau Public 完成，它完全免费，非常适合跟随学习和构建作品集。

根据 www.tableau.com，最新技术要求如下：

| Windows | 64 位 Windows (8, 10, 11) |
| --- | --- |
| | 2 GB 最小内存 (建议 8GB) |
| | 1.5 GB 最小可用磁盘空间 |
| | CPU 必须支持 SSE4.2 和 POPCNT 指令集 |
| Mac | macOS (Mojave, Catalina, Big Sur 11.4+) |
| | Intel 处理器 2 GB 最小内存 (建议 8GB) |
| | 1.5 GB 最小可用磁盘空间 |

你还需要：

| 组件 | 建议 |
| --- | --- |
| CPU (处理器) | 更快的单核速度比更多内核更重要。寻找主频较高的 CPU (3.5GHz+)。 |
| RAM (内存) | 最小 8GB，处理大型数据集或复杂仪表板建议 16GB。更多内存允许更大的数据提取保留在内存中。 |
| SSD (存储) | 从 HDD 升级到 SSD 可将工作簿加载时间缩短 50-70%。使用本地数据提取时必不可少。 |
| 显卡 (GPU) | Tableau 使用 GPU 进行地图渲染和某些视觉效果。集成显卡适用于大多数仪表板；独立 GPU 有助于处理大型地图或众多标记。 |
| 网络连接 | 云数据源建议 100Mbps+。本地数据提取完全绕过网络延迟。 |

你可能需要的其他安装（例如用于 Python 集成的 TabPy 或用于 R 的 Rserve）会在相关章节中提及。所有这些都是免费的，并且适用于 Windows 和 Mac。
