# Filtering data

The filter node in data recipes enables you to quickly filter your data to suit the use case. That is, you can remove rows of data that you want to exclude from your output dataset(s).

To filter your data, follow these steps:

+   1. Add a new node (as shown in *Figure 4.3*) to your recipe and select **Filter**.
+   2. Add filter conditions, as shown in *Figure 4.6*. If you choose to define a filter condition on a dimension column, you can select a filter value from the list.
+   3. Click on **Apply**.
+   4. Save the recipe.
