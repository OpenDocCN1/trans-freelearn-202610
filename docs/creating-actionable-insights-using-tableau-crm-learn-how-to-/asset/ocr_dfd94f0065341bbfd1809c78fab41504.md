# Managing TCRM access permissions

To ingest data and use it as a part of row-level security, you must have access to Salesforce data. Based on the permissions of the two systems of TCRM/Salesforce users, Tableau CRM gains access to Salesforce data. These two systems of TCRM/Salesforce users are as follows:

+   - Integration User
+   - Security User
