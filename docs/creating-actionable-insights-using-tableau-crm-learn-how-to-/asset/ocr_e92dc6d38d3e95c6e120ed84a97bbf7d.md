Note several things about this minimalist design:

+   - The user has **Quick Links** to take them to common places of interest.
+   - We made judicious use of white space to deliver a very simple layout.
+   - The three charts were chosen because each one represents the key metric for each area of the business.
+   - The heading for each tile is a TCRM link that takes the user to a detail page.
+   - There is nothing superfluous that might distract the user from the data story.
+   - A user can inspect this dashboard in under 30 seconds and decide whether they want to dive deeper or move on.

Now, you will see the importance of ease of use in dashboard design.

# A good dashboard is intuitive and easy to use

Great analytics design requires little or no instruction or training for use. It is truly intuitive – easy to understand or operate without explicit instruction. When a user sees an intuitive dashboard for the first time, they will know exactly what to do.
