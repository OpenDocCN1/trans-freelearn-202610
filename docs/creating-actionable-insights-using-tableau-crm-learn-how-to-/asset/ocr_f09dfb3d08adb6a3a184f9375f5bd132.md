# To Code or Not to Code?

One of the greatest challenges for Tableau CRM (TCRM) admins and developers is knowing when to code and when not to code. This causes a considerable amount of confusion. The purpose of this chapter is to guide you through how to determine when code is required by covering numerous practical examples.

Where code is required, examples of the sources will be given. However, please note that this book is not intended to be a detailed manual for Tableau CRM developers. Also, the code snippets given are, of necessity, often only small portions of the complete source code.

In this chapter, we will cover the following topics:

+   - When do you need code?
+   - You might not need to code if...
+   - Occasions of ambiguity
