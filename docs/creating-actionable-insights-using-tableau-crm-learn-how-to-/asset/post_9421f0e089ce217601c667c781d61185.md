Chapter 2, Developing Your First OOTB Analytics App in TCRM, provides you with step-by-step instructions on how to implement and configure TCRM from scratch, including all the basic setup requirements. You will learn about the definition, makeup, and application of an OOTB Analytics app in TCRM. You will then be guided in how to install the app, configure the app via the wizard, customize it, and test the analytics. Common obstacles and questions will also be addressed.

Chapter 3, Connecting Your Data Sources, explains the various capabilities and limitations of TCRM in bringing in data from Salesforce, flat files, data warehouses, and other sources. You will learn how to connect Salesforce data objects with TCRM and create datasets. You will also learn how to bring a flat file into TCRM.

Chapter 4, Building Data Recipes, defines and explains the process of creating a data recipe in TCRM. Then, beginning with the dataset created in Chapter 3, Connecting Your Data Sources, you will learn to apply filters, calculations, and transformations to that data in order to create a new dataset that meets the requirements of your business use case.

Chapter 5, Advanced ETL Using TCRM Data Prep, guides you on how to use the TCRM data flow editor to its full capability. This is where the more powerful ETL work is explained and demonstrated, teaching you how to combine multiple sources of data, perform complex transformations and calculations, and create accurate, complete datasets for analytics.

Chapter 6, TCRM Lenses – Diving into Your Data One Click at a Time, shows you what a lens is (essentially a query plus a visualization), and how it is a powerful tool for understanding, testing, debugging, and showcasing data. You will also learn how lenses are the building blocks of analytics dashboards in TCRM.

Chapter 7, Security in Tableau CRM, explains in detail how to secure your TCRM data. You will be given an overview of TCRM security and then walked through each of the tools available in TCRM to determine who sees what data.

Chapter 8, Building Your First TCRM Dashboard, walks you through the essentials of building a dashboard in TCRM using the dashboard editor by gathering and assembling the required components into a complete visualization.

Chapter 9, Advanced Dashboard Design and Build, guides you in how to take advantage of the more advanced features and capabilities of TCRM – including page animations, SAQL, bindings, and more. By the end of the chapter, you will have the tools to create a complex, advanced TCRM dashboard.

*Chapter 10, To Code, or Not to Code?*, guides you in how to determine when code is required, since one of the greatest challenges faced by TCRM developers is to know when to use code (JSON, SAQL), and when not to code.

*Chapter 11, Best Practices in Dashboard Design Using TCRM*, explains great dashboard design by explaining in detail what you ought to build, the established principles of effective dashboard design, and the best practices when designing, building, and deploying TCRM dashboards.

*Chapter 12, Embedding and Actioning Your Insights*, shows you how to go from great visuals to smart decisions. This chapter will explain how record actions in TCRM dashboards enable users to action data directly in CRM.
