First, what is a dataset? The following diagram provides a succinct definition:

# What is a Dataset?

A data repository (storage) similar to file system storage but with a proprietary format and Algorithms flattening the data with inverted indexes (for volume and speed).

![](bbox=[0.1, 0.27, 0.8, 0.45])

Figure 3.1 – What is a dataset?

A dataset is the building block for your analytics lenses and dashboards; it is the fountain of insights. As the old saying goes, garbage in, garbage out, and nowhere is this more accurate than in data analytics. As such, a great deal of your thought and effort when designing and building TCRM dashboards will be invested in the datasets that drive the metrics and visualizations.
