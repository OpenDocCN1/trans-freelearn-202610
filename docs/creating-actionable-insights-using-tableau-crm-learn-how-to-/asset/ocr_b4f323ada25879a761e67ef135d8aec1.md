# Using the Unique aggregation

The **Unique** aggregation is useful when you do not want to generate a total count of rows, but you do want to count the number of unique occurrences of a certain value.

For example, if you have a dataset that has a granularity of product-line items, you could count the number of occurrences of unique values of opportunities by record ID, and create a dataset that shows how many opportunities are associated with a certain product.
