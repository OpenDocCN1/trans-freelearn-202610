# Tips

First, if the dataset is in a different app than a dashboard or a lens, a TCRM user must be able to access both apps if he or she will view a lens or dashboard.
Second, deactivated users lose share and delete access to all apps they manage. Therefore, to make sure this does not happen, before deactivating the user, assign Manager access to at least one active user.

As a practical example, follow these steps to share a new private dashboard with a single user:

+   1. First, create a new app called **Private App**.
+   2. Now, create a new blank dashboard and save it to **My Private App** as **Private dashboard**.
+   3. To give access to an active user, Julie Chavez, open the **Share** dialog box and add Julie as a user with **Viewer** permission under **Invite others**.
+   4. Click on **Add**.
+   5. Click on **Save**.
