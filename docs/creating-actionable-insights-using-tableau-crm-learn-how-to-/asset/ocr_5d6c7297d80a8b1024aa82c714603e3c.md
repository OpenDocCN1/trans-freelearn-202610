# Adding a highlights panel to the sales dashboard

Now, it's time to add a highlights panel to your dashboard. This is useful to draw attention to key metrics and the dashboard filters. To do so, you can follow these steps:

+   1. Select the two chart widgets together by holding *Cmd* or *Ctrl* while clicking on each of them, then drag down a few rows to make room for the highlights panel.
+   2. Drag a **Container** widget onto the canvas.
+   3. Resize/enlarge the container, move the title text widget into the container, then make sure the container fills the space above the hero chart.
