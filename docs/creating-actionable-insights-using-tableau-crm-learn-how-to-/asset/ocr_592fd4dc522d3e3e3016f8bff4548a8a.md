Before you go any further, make some subtle changes to improve the dashboard aesthetics, as follows:

+   1. Click on **Edit** to edit the dashboard.
+   2. Click on the **Default** gear icon to open the dashboard settings.
+   3. Under **Background Color**, change **Grid** to White.
+   4. Select **Dashboard Properties** from the drop-down list at the top right of the dashboard editor.
+   5. Change the default widget background color to transparent by clicking on **Background Color**, selecting **Custom**, and dragging the transparency bar all the way to the left.
+   6. Add a default widget border with a transparent color, and a width and radius of 8.
+   7. Click **Save** to save the dashboard.
