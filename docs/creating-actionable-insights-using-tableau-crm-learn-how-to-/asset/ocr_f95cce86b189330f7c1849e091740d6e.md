# Query Mode

Now that you're confident with the Chart and Table Modes, the only mode left to understand is the powerful code-based analysis tool in TRCM lenses known as Query Mode. Query Mode utilizes Salesforce Advanced Query Language (SAQL) to query your data, as opposed to the declarative and low-code approaches we've examined so far.
