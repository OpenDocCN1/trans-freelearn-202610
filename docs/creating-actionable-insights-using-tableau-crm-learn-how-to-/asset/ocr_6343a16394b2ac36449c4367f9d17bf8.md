+   - Use of inappropriate number formats – showing the same KPIs in numbers and percentages can sometimes lead to misunderstandings.
+   - Each chart/widget should answer a unique and simple question – do not try to put all the information in one single chart.
+   - Forgetting the security aspect – aggregations in dashboards does not mean that users can access raw data in the datasets.
+   - No action framework – every dashboard should tell a story where, at the end, the user can take an action.
