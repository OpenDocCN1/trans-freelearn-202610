+   - How does TCRM provide value to your organization or clients?
+     This is an organization-specific answer.
+   - Does your organization excel at data analytics? If not, what is preventing it from doing so?
+     This is an organization-specific answer.

+   - What is a TCRM asset? Give one example.
+     A TCRM asset is any one of four key items: dashboard, story, lens, or dataset.

+   - How can a TCRM app be shared?
+     One of three ways:
+     - Give access via TCRM.
+     - Post to a Chatter feed.
+     - Share via the app URL.

+   - What is a TCRM lens?
+     A lens is a self-contained exploration of data; one query with a visualization or table.

+   - True or False – a TCRM app is restricted to standard, OOTB settings.
+     False.

+   - What is the purpose of the "Favorites" link on the side menu of the TCRM home page?
+     You can choose to favorite any TCRM asset, such as a dataset or lens, and add it to this list for ease of access.

+   - What do you do if the OOTB TCRM apps don’t meet your requirements, even after you have customized them?
+     TCRM is incredibly flexible and enables the custom development of assets.

+   - How do you turn on TCRM in a Salesforce environment?
+     You can enable TCRM by going to Setup | Analytics | Getting Started and switching it on.
