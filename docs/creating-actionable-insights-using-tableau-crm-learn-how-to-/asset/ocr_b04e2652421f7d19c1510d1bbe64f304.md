# Pivot table

You are most likely familiar with pivot tables; they are a common feature in tools such as spreadsheets. A pivot table is an interactive way to summarize data and analyze numerical data in detail. A pivot table is useful for doing the following:

+   - Subtotaling and aggregating numeric data, summarizing data by categories and subcategories.
+   - Expanding and collapsing different levels of data to focus on the results and drill down into the details at the summary level.
+   - Moving rows to columns or columns to rows (known as pivoting) to see varying summaries of your data.
+   - Filtering, sorting, grouping, and conditionally formatting the most useful and relevant subsets of data, enabling you to focus on the information you need.
