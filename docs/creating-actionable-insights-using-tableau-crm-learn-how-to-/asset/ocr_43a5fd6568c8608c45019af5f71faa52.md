# Buckets (complex)

Simple buckets can be created in the recipe builder; more complex use cases require code. The following example was used to create custom-formatted reference lines:

```
Name', 'Pushed' as 'Pushed', 'ForecastCategoryName' as 'ForecastCategoryName', sum('Amount') as 'sum_Amount';
```

```
q = order q by ('Account.Industry' asc, 'Account.Name' asc, 'StageName' asc, 'Account.Owner.Name' asc, 'Pushed' asc, 'ForecastCategoryName' asc);
```
