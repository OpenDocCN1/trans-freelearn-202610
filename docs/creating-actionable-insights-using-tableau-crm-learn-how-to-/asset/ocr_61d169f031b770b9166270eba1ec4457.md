+   - What is the purpose of app-level security in TCRM?

+   - How can you control TCRM security from Salesforce object and field access?

The administrator can configure permissions on Salesforce objects and fields to implement object-level and field-level security and therefore control access to Salesforce data. TCRM gains access to Salesforce data based upon the permissions of two system TCRM/Salesforce users: the Integration user and the Security user. Restricting access for these users via security profiles in Salesforce is how you can control TCRM security from Salesforce object and field access.
