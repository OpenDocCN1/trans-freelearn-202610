Perform the following steps to join data in a recipe:

+   1. Select the **Add Node** button (+) between two nodes or at the end of a recipe with at least one input node.
+   2. Select **Join**.
+   3. Choose which data to join and select which columns to include.
+   4. Click on **Next**.
+   5. Select the desired **Join Type**.
+   6. Change the **Join Keys** setting as required. Note that the recipe will add suggested keys from both sets of input data. You can use multiple keys (a maximum of five) to match records if required.
+   7. Enter a prefix (**API Name Prefix for Right Columns**) for the columns coming from the right data source. This will prevent API name conflicts between columns in the left and right data sources.
+   8. Select the columns in the **Columns** tab in the right-hand side panel to include in the recipe.
+   9. Click on **Preview** to preview all of the included columns and their data.
+   10. If you need to hide columns from the preview, click on the **Hide** button (E).
+   11. Click on **Apply** to add the node to the recipe.
+   12. **Save** the recipe.

# Outputting data from recipes

The output node writes recipe results to a TCRM dataset or an external system. The inputs required are as follows:

+   - **Write To**: Either to a dataset or a CSV file.
+   - **Dataset Display Label**.
+   - **Dataset API Name**.
+   - **App Location**.
