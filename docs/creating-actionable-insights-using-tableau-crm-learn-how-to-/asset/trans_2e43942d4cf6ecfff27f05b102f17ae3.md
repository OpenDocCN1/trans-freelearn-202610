## 索引

第2章“在TCRM中开发你的第一个OOTB分析应用”提供了从零开始实现和配置TCRM的分步说明，包括所有基本设置要求。完成后，TCRM环境将准备好安装、定制和创建TCRM分析应用。你将了解TCRM中OOTB分析应用的定义、构成和应用。然后，你将学习如何安装该应用、通过向导配置应用、定制应用以及测试分析。还将解答常见障碍和问题。

第3章“连接数据源”解释了TCRM在从Salesforce、平面文件、数据仓库和其他来源引入数据时的各种能力和限制。你将学习如何将Salesforce数据对象与TCRM连接并创建数据集。你还将学习如何将平面文件导入TCRM。

第4章“构建数据配方”定义并解释了在TCRM中创建数据配方的过程。然后，从第3章“连接数据源”中创建的数据集开始，你将学习如何对该数据应用筛选器、计算和转换，以创建满足业务用例需求的新数据集。

第5章“使用TCRM数据准备的进阶ETL”指导你如何充分利用TCRM数据流编辑器。这里将解释和演示更强大的ETL工作，教你如何组合多个数据源，执行复杂的转换和计算，并为分析创建准确、完整的数据集。

第6章“TCRM透镜——每次点击深入你的数据”向你展示什么是透镜（本质上是一个查询加一个可视化），以及它如何成为理解、测试、调试和展示数据的强大工具。你还将了解透镜如何成为TCRM中分析仪表板的构建块。

第7章“Tableau CRM中的安全性”详细解释了如何保护你的TCRM数据。你将获得TCRM安全性的概述，然后逐一了解TCRM中可用的每种工具，以确定谁可以看到哪些数据。

第8章“构建你的第一个TCRM仪表板”通过使用仪表板编辑器收集和组装所需组件，引导你完成在TCRM中构建仪表板的基本要素，最终形成一个完整的可视化。

第9章“高级仪表板设计与构建”指导你如何利用TCRM更高级的功能和能力——包括页面动画、SAQL、绑定等。到本章结束时，你将拥有创建复杂、高级TCRM仪表板的工具。

*第10章“编码，还是不编码？”*指导你如何确定何时需要代码，因为TCRM开发人员面临的最大挑战之一是知道何时使用代码（JSON、SAQL），何时不编码。

*第11章“使用TCRM进行仪表板设计的最佳实践”*通过详细解释你应该构建什么、有效仪表板设计的既定原则，以及设计、构建和部署TCRM仪表板的最佳实践，阐述了出色的仪表板设计。

*第12章“嵌入并执行你的洞察”*向你展示如何从出色的视觉呈现走向明智的决策。本章将解释TCRM仪表板中的记录操作如何使用户直接在CRM中执行数据操作。
