
## Summary

We have discussed the various web presentation patterns available when working with ASP.NET Web Forms application development. We also looked at what ASP.NET MVC has to offer and compared between the MVP pattern that we used in previous edition of this book and MVC. After multiple debates we eventually concluded that it is best to retain the MVP pattern for the presentation layer. In future if time permits, we will definitely look at an MVC based front end for our Fisharoo website.
