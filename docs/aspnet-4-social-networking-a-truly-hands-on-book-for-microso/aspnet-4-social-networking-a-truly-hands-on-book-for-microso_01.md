## 前言

社交网络已成为互联网的一大驱动力。许多人至少加入了某一个社交网络，但更常见的情况是，人们往往是许多不同社区的成员。因此，许多商界人士正试图利用这一潮流，争相搭建自己的社交网络。随着社交网络的持续发展，我们看到越来越多垂直领域的社区如雨后春笋般涌现，取代那些规模更大、包罗万象的网络，试图抢占一小块市场份额。

在本书中，我们将讨论构成当今大多数社交网络或在线社区的诸多方面和功能。我们不仅会讨论这些功能、它们的目的以及如何构建它们，还会从大规模企业级视角来审视这些功能的构建方式。目标是探讨如何以可扩展的方式创建社区。

## 本书涵盖内容

- *第1章，社交网络* 会让你了解本书的整体结构，即读者可以从本书中获得什么。
- *第2章，社区框架的企业级方法* 帮助你创建一套企业级框架，以满足大多数 Web 应用程序的需求。其中讨论了设计模式、最佳实践以及一些能简化工作的工具，还涵盖了错误处理和日志记录。
- *第3章，用户账户* 通过电子邮件验证系统和权限系统来确保安全，涵盖了注册和账户创建过程。它还涉及密码加密/解密技术。
- *第13章，扩展* 讨论了一些帮助你在社交网络上支持大量用户的概念。它首先介绍分层架构和 Web 场的一些关键概念，还讨论了创建和搜索索引数据的方法、优化数据检索和内容创建的方式，以及一些邮件排队概念。
- *附录* 讨论了 Microsoft ASP.NET MVP 和 MVC 模式，并解释了本书为何继续使用 MVP 模式。

## 阅读本书需要什么

本书介绍如何使用 Microsoft ASP.NET 4、Microsoft C# 4 和 Microsoft SQL Server 2008 构建社交网络。要有效使用本书，你需要安装 Microsoft Visual Studio 2010 和 Microsoft SQL Server 2008。本书大部分内容同样适用于 Microsoft Visual Studio 2010 的各种 Express 版本和 SQL Express，但你会发现，使用 Microsoft Visual Studio 2010 专业版会让你的工作流程更高效。由于我们不仅讨论 Microsoft ASP.NET，而是更关注社交网络功能所需的内容，因此有时我们会转向开源解决方案。本书中的所有示例都会清楚指出所需软件的获取位置，以及在我们演练示例时如何配置该软件。

## 本书适合的读者

本书面向希望构建企业级社交网络的 Microsoft ASP.NET 和 C# 开发人员，无论你是为自己的业务构建，还是作为为其他公司承接的合同项目。本书假定你之前有用 Microsoft ASP.NET 4、Microsoft C# 4、Microsoft SQL Server 2008 和 Microsoft Visual Studio 2010 开发 Web 应用程序的经验；它侧重于现有开发者感兴趣的主题，而不是为每个细节提供逐步示例。
