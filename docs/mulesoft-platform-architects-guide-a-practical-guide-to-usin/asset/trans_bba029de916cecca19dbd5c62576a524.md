

## 考试主题

*   私有和公共端点的功能监控
*   `Anypoint Monitoring` 日志记录选项
*   本地 `Mule Runtime` 的监控
*   高 `CPU` 和内存使用率的警报

*   API 治理：
    *   为部署到 `Runtime Fabric Manager`、`CloudHub 1.0` 和 `CloudHub 2.0`、本地环境等的应用程序启用 `API Manager`
    *   应用 API 策略，如速率限制、峰值控制和基本认证 – `LDAP`、`JWT` 验证、`IP` 允许列表和阻止列表等
    *   启用 `API Manager` 分析、警报、自定义仪表板等
    *   API 自动发现和 API 代理
    *   在 `Anypoint Platform` 中配置身份提供者和客户端提供者
    *   通过 `Anypoint Security` 在边缘保护 API

*   API 架构：
    *   基于 API 的连接性和事件驱动架构
    *   采用领域驱动设计和限界上下文的微服务
    *   熔断器模式

您准备考试所需了解的完整主题列表，可在 MuleSoft 培训网站上找到。

## 答多项选择题的策略

完整、仔细地阅读问题，并专注于问题中的关键词。读完问题后，尝试在不看选项的情况下思考答案会是什么。

使用排除法。排除那些可能与问题无关或完全不相干的错误选项。这样您将减少选项范围，最终可能只剩下一个选项，那便是正确答案。但也可能存在一种情况，即剩余不止一个选项。在这种情况下，请重读问题，并尝试从剩余选项中选择正确答案。

回答所有问题，因为没有扣分机制。确保不要在您不知道正确答案的问题上浪费时间；相反，请将其标记为复查，以便稍后重新审视该问题。如果您已回答某问题但对所选答案没有 100% 的把握，也可以在最后将该问题标记为复查。

时间非常重要，因此您需要在考试期间好好管理时间。您将有 120 分钟来回答 60 个问题，平均每题 2 分钟。尝试每题花费 1.5 分钟；这意味着答完所有题需 90 分钟，剩余的 30 分钟可用于检查或回答标记为复查的问题。

## 考试的系统要求

支持的操作系统为 `Windows` 和 `macOS`；不支持 `Linux`。请确保您的电脑上安装了 `Guardian Browser`，因为这是唯一支持的浏览器。需要一个功能正常的麦克风和高分辨率摄像头。

考试期间不支持多显示器或多屏幕。请确保考试当天拥有强大且稳定的互联网连接，因为考试是在线监考的，将需要屏幕共享并在您的机器上安装监考软件。

考试所需的最低带宽速度如下：

*   **下载**：1.5 MBPS
*   **上传**：1 MBPS

使用以下链接测试您的网速：

*   [www.speedcheck.org](https://www.speedcheck.org/)
*   [fast.com](http://fast.com)

不支持热点和网络共享。

考试期间请勿允许其他人使用您的网络连接，因为这会增加带宽占用。

以下设备/软件不受支持：`Google Chromebooks`、平板电脑（如 `iPads` 和 `Nexus`）、`Windows 10 S` 或 `Surface RT`，以及远程桌面软件（如 `TeamViewer` 和 `Chrome Remote Desktop`）。

请确保您的机器上没有打开其他软件。考试开始前必须关闭所有其他软件。

## 考试当天

终于到了考试当天，您将参加考试。请确保您已做好充分准备，并信心满满。请确保您已满足上一节提到的所有系统要求。请随身携带一两份官方身份证明，因为考试期间会检查这些证件以验证您的身份。

完成所有预检后，您可以开始考试，并将获得两小时完成考试时间。使用我们之前讨论的答多项选择题的策略。完成考试后，您需要提交。提交后，您将立即在屏幕上看到结果，状态为 **Pass**（通过）或 **Fail**（不通过）。还将显示您各部分的得分百分比。

如果您通过了考试，稍后将收到一封电子邮件确认。证书可从 MuleSoft 培训网站下载，并在收到电子邮件确认后自动生成。该证书自考试之日起两年内有效。

如果您考试不通过，可在 24 小时或更长时间后重新尝试。请确保在重考前针对得分最低的部分进行准备。

## 总结

MCPA – Level 1 考试在业界备受推崇，旨在验证架构师构建安全且有弹性的 MuleSoft 平台的能力。本章深入探讨了备考必备的核心主题，以及考试当天的系统要求。此外，我们还探讨了高效答多项选择题的有效策略，并明确了该考试的理想候选人画像。最后，我们提供了一组练习题，旨在帮助您熟悉考试的格式和复杂程度。

## 练习题

尝试回答以下问题：

1.  一个组织希望设置 MuleSoft 以部署 API。他们有一项要求：数据和元数据不应离开企业数据中心。托管运行时平面和控制平面的最佳选项之一是什么？

    1.  客户托管的 Mule 运行时平面和客户托管的 `Anypoint Platform PCE` 控制平面
    2.  MuleSoft 托管的运行时平面和客户托管的 `Anypoint Platform PCE` 控制平面
    3.  客户托管的 Mule 运行时平面和 MuleSoft 托管的 `Anypoint Platform` 控制平面
    4.  MuleSoft 托管的运行时平面和 MuleSoft 托管的 `Anypoint Platform` 控制平面

2.  一个组织正在使用 `CloudHub 1.0` 运行 MuleSoft API。部署在 `CloudHub 1.0` 上的 MuleSoft API 需要访问位于企业防火墙后面的服务或数据库。可以利用哪个选项从 `CloudHub 1.0` 安全连接企业数据中心？

    1.  位于企业防火墙后的服务和数据库可通过默认 `CloudHub 1.0` 设置访问。无需自定义平台。
    2.  在 `CloudHub 1.0` 中设置 `Anypoint Virtual Private Cloud`，并在 `Anypoint Virtual Private Cloud` 与企业数据中心之间创建 `VPN IPSec` 隧道。
    3.  在需要连接到企业防火墙后服务的应用程序上使用静态 IP 地址，并在企业数据中心防火墙中将该静态 IP 地址加入白名单。
    4.  无法从 `CloudHub 1.0` 连接位于企业防火墙后的服务。您需要在本地设置 Mule Runtime 以连接企业防火墙后的资源。

3.  一个组织部署了一个在 `CloudHub 1.0` 上使用 `Object Store v2` 的 API。另一个 API 部署在本地 `Mule Runtime` 上，想要访问 `Object Store v2` 中的数据。从运行在本地 `Mule Runtime` 上的应用程序访问 `CloudHub 1.0` 上的 `Object Store v2` 的最佳方式是什么？

    1.  使用 `Anypoint CLI`
    2.  使用 `Object Store Connector`
    3.  使用 `Object Store v2 REST API`
    4.  无法从本地 `Mule Runtime` 访问 `Object Store v2`
