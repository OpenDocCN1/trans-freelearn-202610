## 8. 一个组织拥有非 `MuleSoft` API，并希望使用 `Anypoint Platform API Manager` 进行管理。管理非 `MuleSoft` API 最具成本效益且高性能的解决方案是什么？

## 13. 一个组织在 `CloudHub` 上部署了 `MuleSoft` API。该 API 开始面临性能问题，即无法一次处理更多请求，且响应时间增加了延迟。作为架构师，你会建议什么解决方案来解决性能问题？

1. 通过增加工作器大小或为内存使用启用 `autoscaling policy` 来实现垂直扩展
2. 通过增加应用程序的工作器数量或为内存使用启用 `autoscaling policy` 来实现水平扩展
3. 通过增加应用程序的工作器数量或为 CPU 使用启用 `autoscaling policy` 来实现水平扩展
4. 通过增加工作器大小或为 CPU 使用启用 `autoscaling policy` 来实现垂直扩展

> **注意**
> `CloudHub` 默认未启用 `autoscaling` 功能。请联系您的 `MuleSoft` 客户代表。
