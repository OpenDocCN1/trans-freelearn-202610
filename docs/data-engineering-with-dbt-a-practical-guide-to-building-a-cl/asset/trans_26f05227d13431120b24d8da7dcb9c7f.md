

- `not_null`
- `dbt_utils.not_empty_string`
- **mutually_exclusive_ranges**: 该模型级宏测试按列分区时行是否创建正确的日期范围，让你验证范围不重叠、有或没有间隙，以及范围大小大于零。
- **get_column_values**: 该宏将模型中特定列的值加载为 Python 列表，而无需处理 Agate 表。
- **get_query_results_as_dict**: 该宏将 SQL 查询的结果加载为 Python 字典，这样你就无需处理 Agate 表。
- **date_spine**: 该宏生成 SQL 代码以在区间内生成连续的日期序列，根据所需的粒度（天、月等）。
- **union_relations**: 该宏允许你联合两个或多个关系（表或视图），对具有相同名称的字段进行对齐并为缺失的字段添加 null 列，从而简化对相似但列不完全相同且顺序不同的表的 UNION 操作。
- **star**: 该宏的基本行为是生成关系中列的逗号分隔列表，最终可带别名，并能够排除某些列。这可以用在通常的 SELECT * 代码的位置，以更好地控制你想要选择的列，即使在数据库不支持 SELECT * EXCLUDE (...) 构造的情况下也是如此。
  更高级的用法允许你为列名添加前缀或后缀。
- **generate_surrogate_key**: 该宏提供了一种跨数据库的方式来计算列列表的哈希值。这可以用作代理键或用于任何其他哈希的常见用途。
  我们将在宏中经常使用它来存储表的历史记录。

我们刚刚提供了一个非常简短的 dbt_utils 包中可用有用宏的列表，我们强烈建议你去 https://hub.getdbt.com/dbt-labs/dbt_utils/ 看一看。

## Codegen package

该包同样来自 dbt-labs，提供了许多有用的宏来生成常用代码片段的初始版本，以便你可以最大程度地减少输入数据库中已有的信息，尤其是名称的需要。

使用这些宏，你可以生成模式中表的源定义，将其复制粘贴到源 YAML 文件中，或者你可以生成一个骨架暂存模型或用于记录和测试一组模型的 YAML 代码。

预览以下代码将生成用于导入所选数据库中模式的关联的源文件的 YAML：

```
{{ codegen.generate_source('<schema>',database_name = '<database>') }}
```

你也可以使用 run-operation 命令运行宏，如下所示：

```
dbt run-operation generate_source --args '{"schema_name": "<schema>", "database_name": "<database>", "table_names":["table_1", "table_2"]}'
```

以下代码可用于生成描述和测试模型的 YAML：

```
{{ codegen.generate_model_yaml(model_name='<model>') }}
```

我们强烈建议使用这些宏或自行构建，以最大程度地减少无用的输入，减少输入列和关系名称时的错误，并专注于你需要添加以将数据转换为信息的逻辑。

在第 6 章中，我们提供了可运行的 SQL 查询示例，以同样的效果从数据库已有的源表元数据信息中生成模型所需的代码。

## Adding the dbt-utils package to our project

我们看到 dbt-utils 包具有许多有用的功能，所以让我们将其添加到我们的项目中，然后使用它来重构我们的代码以生成更好的代理键，取代我们迄今为止使用的简单字段拼接。

另外，预览此模型以确保一切按预期工作。

我们不必部署 STG 模型，因为它们是临时性的，所以让我们更新收集 STG 模型输出数据的快照。

我们没有更改 STG 模型的模式，所以我们可以直接运行快照，其效果是所有旧行都被带有新哈希码的行替换。

这无论如何也没什么意义，因为我们将用两个不同的键在表中表示同一个实体。继续使用旧历史的解决方案是重命名当前表或快照，以便只有一个使用当前键的活动快照表。然后，你以正确的方式在 REF 模型中引用这两个表。

就我们而言，由于快照不包含任何珍贵的历史，我们将直接删除快照表，这样运行快照将创建新表，其键基于哈希码。

让我们这样做：

1. 让我们删除旧的快照表：

```
DROP TABLE
  PORTFOLIO_TRACKING.SNAPSHOTS.SNSH_ABC_BANK_POSITION;
DROP TABLE
  PORTFOLIO_TRACKING.SNAPSHOTS.SNSH_ABC_BANK_SECURITY_INFO;
```

2. 运行快照以创建新表：

```
dbt snapshot
```
