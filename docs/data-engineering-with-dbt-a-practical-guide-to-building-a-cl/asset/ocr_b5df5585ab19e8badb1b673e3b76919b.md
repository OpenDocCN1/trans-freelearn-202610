# Loading from CSV files

Now that we have the technical objects needed to ingest our data set up, let’s look at the code to do the ingestion.

For each table that we want to ingest, we will create a file that will achieve the two remaining steps: creating the landing table and invoking the COPY INTO command.

The file to ingest each table will contain the following:

+   - A macro to create the landing table for the data of the table to be ingested
+   - A master macro that accepts the necessary parameters and orchestrates the two steps – that is, calling the macro to create the landing table and calling a library macro to run the COPY INTO command based on the input parameters
