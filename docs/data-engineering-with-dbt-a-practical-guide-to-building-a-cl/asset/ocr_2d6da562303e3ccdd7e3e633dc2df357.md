One important caveat of the loading pattern of the `save_history` macro is that it can handle one version per key, per load. This is simple to achieve by using a QUALIFY clause in the STG model and let pass through only the most recent version we have in the inputs.

This solution is simple to code, very resilient, and easy to test, but it cannot be used when we need to keep a reliable audit of the changes as our QUALIFY clause might remove some intermediate versions.
