# Setting up your first repository for dbt

Whether you have just created your GitHub account or you have had one for a long time with many repositories, it is now time to create a new repository for your first dbt project:

> **Important note**
> 
> A dbt project is the main unit of organization for code and configuration that work together to accomplish one goal, and every dbt project is hosted in its own git-based repository.
> 
> The good news is that you can have as many projects as you like in dbt, and in GitHub, you can create as many repos as you wish, too.
