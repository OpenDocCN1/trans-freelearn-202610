

## Jinja 分隔符

在处理 Jinja 时，首先要理解也是最重要的一点是，如何从输出上下文（代码原样输出）切换到 Jinja 上下文（逻辑控制流程和输出），以及如何从 Jinja 生成输出，使其成为发送到数据库的代码的一部分。

在 dbt 模型中编写的文本被视为要发送到数据库的 SQL 代码，除非你使用此处描述的分隔符进入 Jinja 上下文：

- `{% ... %}` 用于开始和结束 Jinja 语句。

语句是你在 Jinja 中用来控制执行流程的控制结构。例如 if 条件语句、for 循环、宏定义、set 赋值和过滤器。

- `{{ ... }}` 用于包围 Jinja 表达式，表示将结果打印出来。

Jinja 表达式与 Python 表达式非常相似，包括多种类型的字面量、数学运算、比较和逻辑运算，以及其他一些运算符，包括调用 Python 方法的能力。

- `{# ... #}` 用于包围 Jinja 注释，可用于将某些 Jinja 代码从求值/输出中排除。

- 需要注意的是，一旦进入 Jinja 上下文，你就不再需要分隔符，可以直接使用表达式而无需额外的大括号。

在接下来的章节中，我们将更详细地描述一些最常用的元素。

## Jinja 表达式

与 Python 一样，表达式允许你使用字面量、变量、函数和运算符来计算值。然后你可以使用表达式的结果，将结果存储在变量中，作为函数的输入，或者直接打印出来。

在这里，我们可以看到不同类别的一些示例：

- Jinja 字面量示例：

```text
'Hello World' or "Hello World"   -- String literals
42 or 42.24 or 42E3               -- Numeric literals
true / false                       -- Boolean literal
['list', 'of', 'objects']          -- List literal
('tuple', 'of', 'values')          -- Tuple literal
{'dict': 'of', 'key': 'and', 'value': 'pairs'}
        -- Dictionary literal
```

你可以用双花括号将它们包围起来打印出来，例如 `{{ 'Hello World' }}` 或 `{{ 42.24 }}`，这将会打印出这些值。

- **使用数学运算符的示例：**

```text
{{ 1 + 1 }} or {{3-1}} or {{7 // 3}}  -- all print 2
{{ 1 / 2 }}                         -- prints out 0.5
{{ 3*2 }} or {{ 20 % 7 }}            -- all print out 6
{{ 2**3 }}                            -- prints out 8
```

数学运算符是通常的四种算术运算符（+、-、* 和 /），它们执行浮点运算，此外还有 // 整数除法、% 取模或余数，以及 ** 幂运算符。

- **使用比较运算符的示例：**

```text
{{ 42 == 42 }} or {{ 42 != 24 }}       -- both return true
{{ 42 > 24 }} or {{ 42 >= 24 }}          -- both return true
{{ 24 < 42 }} or {{ 24 <= 42 }}          -- both return true
```

如前面的示例所示，我们有常用的比较运算符：`==`——等于，`!=`——不等于，`>`——大于，`>=`——大于或等于，`<`——小于，`<=`——小于或等于。

- **使用逻辑运算符的示例：**

```text
{{ true and true }} or {{ not false }} -- will return true
{{ false or (42 > 24) }}              -- will return true
```

你可以使用逻辑运算符（and、or、not 以及 () 分组）来组合布尔表达式，并控制 if 语句或任何其他需要使用布尔值的地方。

- **使用其他运算符的示例：** `in` 运算符执行包含性测试，如果被测试的元素包含在 `in` 运算符之后的序列或映射中，则返回 true：

```text
{{ 1 in [1, 2, 3] }} or {{ 'bc' in ['bc', 'a'] }} -- in operator
```

`is` 运算符使用一种 Jinja 测试对变量或表达式执行测试。你编写表达式，然后是 `is` 运算符，接着是测试名称，最终可以在测试名称后面带上测试的其他参数：

```text
{{ (expr) is integer }}                 -- is operator
```

`~` 运算符将操作数转换为字符串并连接它们：

```text
{{ 1 ~ " string" ~ '!' }}             -- ~ operator
```

`()` 运算符允许我们调用可调用对象并传递最终参数：

```text
{{ "Welcome {}".format(name) }}        -- () operator
```

`|` 运算符，称为管道符或竖线，用于应用过滤器。过滤器会修改其应用到的值。过滤器可以链式使用，并依次应用，第一个过滤器的输出由第二个过滤器修改，依此类推：

```text
{{ "to uppercase"|upper }}          -- | operator (pipe)
```

`.` 或 `[]` 运算符允许访问存储在你应用运算符的变量中的对象的属性，其语法类似于 Java 或 Python：

```text
{{ obj.attr }} or {{ obj[attr] }}      -- . / [] operator
```

组合不同类型的表达式，你可以生成复杂的表达式，从而像在 Python 中一样表达几乎任何计算或测试。

## If 语句（if... then... 和 else）

if 语句，也称为条件语句，其工作方式与 Python 中相同，允许你根据一个或多个测试来决定在哪个分支中继续执行。

主要区别在于表示法略有不同，它以 `{% if value_to_test %}` 块开始，并始终以 `{% endif %}` 块结束。

在最简单的版本中，如果测试值为真，if 语句将继续流程，如以下示例所示：

```text
{% if value_to_test %}
some output
{% endif %}
```

如果你愿意，也可以将前面的示例全部写在一行：

```text
{% if value_to_test %}some output{% endif %}
```

如果测试为真，则 if 语句内的代码将被执行——在这种情况下，返回文本。你可以在 if 语句内放置其他语句和表达式。

if 语句的一般形式如下：

```text
{% if test1 %}
    Test 1 is true. Do something ...
{% elif test2 %}
    Test 2 is true, but not test 1. Do second thing...
{% else %}
    Both test1 and test2 did not return true. Do something else...
{% endif %}
```

查看前面的示例，你会发现你可以根据需要链式使用任意数量的 elif 块，并且可以使用 else 块来捕获未满足前述任一测试的所有情况。

## for 循环语句

for 循环是另一种主要的控制结构，与 if-else 语句一起，并且与 Python 的 for 循环非常接近。主要区别在于你不能在 Jinja for 循环中 break 或 continue，但可以应用过滤器和测试。

你可以使用 for 循环遍历序列，如以下示例所示：

```text
{% for item in sequence %}
  {{item}} {% if not loop.last %},{% endif %}
{% endfor %}
```

在这里，我们举例说明了 loop 特殊变量的 last 属性的用法。

示例中的 sequence 变量可以是任何类型内容的列表，通常是列名或值的列表。另一个常见用例是使用 range 函数生成数字列表——例如，要生成从 1 到 10 的列表，可以使用 range(1, 11) 表达式。

你也可以使用 for 语句遍历字典的内容：

```text
{% for key, value in a_dict | dictsort %}
{{ key }}, {{ value }} is the same as {{ key ~ ', ' ~ value}}
{% endfor %}
```

在前面的示例中，我们还应用了 dictsort 过滤器，以便在遍历之前对字典进行排序。

## set 语句

在 Jinja 中，你使用 set 语句来执行变量赋值。

赋值有两种格式；第一种是内联赋值，类似于 Python 中的赋值，如下面的示例所示：

```text
{% set var = "some value" %}
{% set a_mixed_list = ['one', 2, three] %}
{% set var1, var2 = my_function() %}
```

如你所见，你可以在同一次赋值中同时给多个变量赋值，就像在 Python 中一样。

请注意，for 循环引入了不同的作用域（而 if 条件语句则不会）；结果是，在 for 循环外部，你看不到在循环内部进行的赋值的效果，即使该变量是在 for 循环外部声明/初始化的。为此，你应该使用命名空间或其他不同的结构。
