You have a few choices of where to host the repository. The default is to use a dbt Cloud managed repo, but to provide you with the knowledge of a more commonly used setup in professional settings, we will go through the GitHub integration setup.

By picking **Git Clone**, you can set up a repository hosted on any other git provider, such as Azure DevOps or Bitbucket, while by picking **GitLab**, you can set up GitLab integration.

Select the **Github** button to start the setup.
