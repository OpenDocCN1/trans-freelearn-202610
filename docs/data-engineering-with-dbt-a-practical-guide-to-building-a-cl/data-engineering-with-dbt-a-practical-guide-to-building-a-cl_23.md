## 延伸阅读

Snowflake 和 dbt 是两款以光速发展的产品，几乎每季度都会推出新功能，因此我们的主要建议是熟悉它们的文档网站并加入它们的社区，这些是信息和支持的重要来源。

你可以在以下位置找到它们：

- dbt Cloud 文档：https://docs.getdbt.com/
- Snowflake 文档：https://docs.snowflake.com/

在静态媒体中捕捉这种演变是困难的，总会有一些重要的东西被排除在外，例如 Snowflake 中 SELECT 命令的 EXCLUDE（我们在它可用时就开始使用）或 dbt 中的指标（它们仍需成熟并得到支持才能正确使用）。
