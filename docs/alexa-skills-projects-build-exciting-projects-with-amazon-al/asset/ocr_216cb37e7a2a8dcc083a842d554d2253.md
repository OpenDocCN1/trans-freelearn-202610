Firstly, let's try to understand why we need a Twilio number.

The way Twilio works is as follows—a developer initially requests a Twilio number, and when they use the Twilio API to send SMSes or make calls, those SMSes and calls are generated from this prerequested number. Each generated Twilio number is tied to the country that you provided as a part of your details in Step 2 and its communication laws.
