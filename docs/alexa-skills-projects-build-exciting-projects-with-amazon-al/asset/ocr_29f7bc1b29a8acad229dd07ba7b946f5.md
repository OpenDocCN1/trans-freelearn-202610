# Setting up Firebase

We now have the data, and all that remains is to upload it to a server so that it can be remotely accessible to Alexa as it will need to read/access it. For this, we will integrate Firebase into our Android app and upload the temperature measurement to the Firebase Cloud. We will integrate Firebase into our mobile app by walking through the following steps:

+   1. To integrate Firebase, in the Android Studio, on the top Menu bar, navigate to Tools | Firebase. This should bring up the Firebase Assistant window:

![](bbox=[0.105, 0.315, 0.895, 0.595])

Figure 6.9: Firebase Assistant

+   2. Under the Firebase Assistant window, navigate to Realtime Database | Save and retrieve data. This should bring up the Save and retrieve data window.

+   3. Click on Connect your app to Firebase. The Firebase connection should ask you to choose an existing project or create a new one.
