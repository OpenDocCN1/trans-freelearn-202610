Google Now can do pretty much all that Siri can accomplish; however, it has better integration with the web and web-based queries, since the web is Google's main forte. Some of the things that a user can ask Google Now are:

| Categories | Commands |
|---|---|
| General commands | • "What is [Schrodinger's cat]?"\n• "Who invented [the internet]?"\n• "Post to Google+ [feeling great]" |
| Notes and reminders | • "Set alarm for [8 PM]"\n• "Note to self: [I parked my car in section D]" |
| Time and date | • "What is the time zone of [Berlin]"\n• "Time at home"\n• "Create a calendar event: [Dinner in restaurant] [Saturday at 8 PM]" |
| Communication | • "Call [Daniel]"\n• "[Contact name]"\n• "Send [email] to Daniel, [Subject: Meeting], [Message: Will be there in 5]" |
| Weather | • "Weather"\n• "Is it going to rain [tomorrow/Friday]"\n• "How's the weather in [Boston] on [Wednesday] going to be?" |
| Maps and navigation | • "Map of [Flagstaff]"\n• "Navigate to [Berlin] on car"\n• "Show me the nearby [restaurant] on map" |

Figure 1.10: Some of the things that Google Now can do (Data source: www.cnet.com)

Apart from Google Now, Google also has introduced Google Assistant, which is a more evolved version of Google Now, given the fact that the user can hold full-length conversations with Google Assistant, which is not possible with Google Now.
