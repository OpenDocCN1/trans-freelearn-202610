# Providing feedback to improve a detector

When you click on an anomaly in the Anomalies dashboard and scroll down to the last section of the detailed anomaly overview, you can find the metric graphs shown in Figure 15.15.

Beyond the metric visualization, at the top right of this widget, you can also provide feedback to Amazon Lookout for Equipment by telling it if this sharp increase in the number of views from PC web users in Germany is relevant or not.
