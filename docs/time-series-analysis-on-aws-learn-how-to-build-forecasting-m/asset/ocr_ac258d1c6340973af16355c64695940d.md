# Interpreting the model performance dashboard's overview

This section of the model performance dashboard contains the following information:

+   - How many known abnormal events (as provided in the historical events file) are captured by Amazon Lookout for Equipment. **An abnormal event** is considered detected if at least one anomaly detection is triggered by Amazon Lookout for Equipment. In our case, we mentioned five events in our historical abnormal event file and all of these were detected.
+   - How long before each known historical event (part of the label file) it takes Amazon Lookout for Equipment to detect something. This measure is averaged over all the known events located in the evaluation period and is labeled as the **Average forewarning time**.
