Our dataset has two dimensions: **Marketplace** and **Platform**. For each dimension, a percentage is associated with each possible value: on the previous anomaly shown, the detector only detected an issue for the marketplace dimension when it was set to De (Germany), hence the 100% value associated with it. If the anomaly was detected across multiple geographies for the number of views, Amazon Lookout for Metrics would group them together and the percentage associated with each dimension would be displayed in the extent the anomaly impacts each marketplace.
