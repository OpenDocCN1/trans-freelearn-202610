7. Click on the cross at the far right of the **AmazonSageMakerFullAccess** managed policy to remove the permission for this role (we only need this role to have access to Amazon S3 data).

8. Click on **Add inline policy** and then on the **JSON** tab. Then fill in the policy with the following document (update the name of the bucket with the one you created earlier):

```
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:ListBucket",
        "s3:GetObject",
        "s3:PutObject"
      ],
      "Resource": [
        "arn:aws:s3:::<YOUR-BUCKET>/*",
        "arn:aws:s3:::<YOUR-BUCKET>"
      ]
    }
  ]
}
```

9. Give a name to your policy (for instance, LookoutEquipmentS3Access) and then click on **Create policy**.
