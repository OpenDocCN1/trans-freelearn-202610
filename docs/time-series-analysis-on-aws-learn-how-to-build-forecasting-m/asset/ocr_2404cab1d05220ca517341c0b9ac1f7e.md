# Preparing the inference data

Preparing inference data manually can be a highly error-prone activity. In this section, you are going to use the CloudShell service to run a script that will generate this data and push it to Amazon S3 for you. Let’s go through the following instructions:

+   1. Log in to your AWS console.
+   2. At the top right of your console, make sure Region selector is located in one of the regions where Amazon Lookout for Equipment is available; either Europe (Ireland), US East (N. Virginia), or Asia Pacific (Seoul).
