# Exporting backtest results

Now, let's click on the **Export backtest results** button. You are brought to the following **Export details** screen:

![](bbox=[0.133, 0.174, 0.867, 0.452])

Figure 4.14 – Export details of backtest results

> **Important Note**
> 
> In AutoML mode, backtest results are only available for the winning algorithm.

As you can see in the preceding screenshot, you need to fill in the following parameters:

+   - **Export name:** `london_energy_automl_backtest_results`
+   - **IAM role:** Select **Enter a custom IAM role ARN** and paste the ARN of the `AmazonForecastEnergyConsumption` role that you created in *Chapter 3, Creating a Project and Ingesting Your Data*, in the IAM service. As a reminder, the format of the ARN should be `arn:aws:iam::<ACCOUNT-NUMBER>:role/AmazonForecastEnergyConsumption`, where `<ACCOUNT-NUMBER>` needs to be replaced by your AWS account number.
