# 第 1 部分：使用 Amazon Forecast 分析时间序列并交付高精度预测

本节将让你熟悉时间序列数据、其带来的挑战，以及如何将其用于解决实际业务问题。你将了解时间序列数据集可采用的不同形式，以及它们有助于解决的关键用例。

在本节中，你还将了解 Amazon Forecast，以及这一 AI 服务如何帮助你应对预测挑战。到本节结束时，你将训练出一个预测模型，并知道如何根据新数据生成新预测。你还将学习如何从模型结果中获得深入见解，从而改进预测策略，或更好地理解模型做出特定预测的原因。

本节包含以下章节：

- 第 1 章，时间序列分析概述
- 第 2 章，Amazon Forecast 概述
- 第 3 章，创建项目并摄取数据
- 第 4 章，使用 AutoML 训练预测器
- 第 5 章，自定义预测器训练
- 第 6 章，生成新预测
- 第 7 章，改进和扩展你的预测策略
