Now that everything is set, we can run iLEAPP. In this example, we're providing a ZIP archive as the input file and we're exporting the report to the output folder:

```
```bash
python3 ileapp.py -t zip -i ../iphone_dump.zip -o output
```
```

As you can see, we're using the `-t` option to specify what kind of input is provided, the `-i` option to specify the path to the input file, and the `-o` option to specify the path to the output folder.

Once iLEAPP is done processing, the results will be combined into an HTML report:
