Figure 4.14 – The page header

Now that we have loaded the second page into our hex editor, the next step involves examining the page header:

+   - At offset `01`, we can read the location of the first free block, which is `0x0FF6` or `4086` in decimal format.
+   - The value at offset `04` indicates the number of active cells on the page, `3`.
+   - By looking at offset `05`, we can find the location of the first non-empty data cell, which is `0x0FD6` or `4054`.
+   - Finally, the space between the header and the first data cell is unallocated space.
