The datetime SQL function converts the numeric value in the timestamp column to a string. The resulting time is supplied in UTC format:

```
```sql
SELECT id, uuid, datetime(timestamp, 'unixepoch') AS date FROM Events;
```

The time zone will reflect the settings of the device that is being used, usually the investigator's workstation.

# Mac timestamps

Another commonly used timestamp format is Mac absolute time, which is defined as the number of seconds elapsed since the Mac epoch on 01/01/2001 00:00:00. A Mac timestamp can be converted to a human-readable string by using online converters or simply by adding the number of seconds since the **Unix epoch** (978307200) to the Mac timestamp and then converting it to a string.
