# Generating a preliminary device report

A preliminary device report can be used by the investigation team to quickly identify a device based on some basic data that is extracted once the acquisition has been loaded into Cellebrite Physical Analyzer.

There are two ways to choose from to generate this report:

+   - From the tool's main menu, choose **Reports | Generate preliminary device report**.
+   - From **Extraction Summary**, click on **Generate preliminary device report**.
