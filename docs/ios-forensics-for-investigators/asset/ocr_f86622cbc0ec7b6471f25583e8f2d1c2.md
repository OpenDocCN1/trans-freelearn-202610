# Understanding Significant Locations

With the release of iOS 8, Apple introduced a feature known as **Frequent Locations**, which was renamed to **Significant Locations** starting from iOS 10. Essentially, every time a device visits a location, a record is stored in a SQLite database with details from the device's journey. When the device has returned to the same location enough times, that becomes a *significant location*.
