The database consists of a single table, APOLLO, which contains a timeline of all the data that was processed by the tool's modules. The following is a brief description of the table's columns:

+   - The Key column contains the timestamp of when the event occurred, displayed as a human-readable string.
+   - The Activity column shows a simple description of what kind of event was logged.
+   - The Output column contains a JSON object with all the data pertaining to a specific event.
+   - The Database column indicates from which database the event was extracted.
