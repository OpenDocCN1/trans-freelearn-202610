One of the most important subjects pertaining to pattern-of-life forensics is location data; on iOS, there is more than one file that tracks where a user is located at any given point in time, showing which places a user visits more often, such as the cache_encrypted.db database located at /private/var/root/Library/Caches/locationd/ or the consolidated.db database. Every database contains data with different granularity and levels of detail, and we'll look into this topic thoroughly in the next chapter.
