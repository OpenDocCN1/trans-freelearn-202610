# 本书涵盖内容

本书的组织方式是从移动取证的概述以及你应该了解的内容开始。第一部分介绍取证流程并讨论从iOS设备获取数据的不同选项。第二部分描述了分析数据的方法和最佳实践，例如手动解析artifacts。本节还涵盖了检查中使用的最受欢迎的取证工具。本书的最后一部分讨论如何构建时间线以及创建取证报告的最佳实践。

_第1章，介绍iOS取证,_通过描述取证流程和iOS操作系统来介绍移动取证主题。

_第2章，从iOS设备获取数据,_描述了成功从iOS设备获取数据的所有可用选项。我们将讨论逻辑、物理和文件系统获取，以及更多内容，例如基于代理的提取。

_第3章，使用取证工具,_描述了取证工具的重要性以及调查人员如何通过使用它们受益。本章深入探讨了一些最受欢迎的工具，例如Cellebrite Physical Analyzer和Magnet AXIOM。

_第4章，处理常见的iOS Artifacts,_介绍了可以在iOS设备上找到的常见artifacts，例如SQLite数据库和属性列表。我们将学习如何识别这些artifacts、在哪里找到它们以及如何分析它们。

_第5章，生活模式取证,_专注于可以帮助调查人员了解用户日常活动的artifacts，例如使用了哪些应用以及使用时长。

_第6章，剖析位置数据,_全部关于提取、分析和理解与位置相关的artifacts。

第7章，分析连接数据，讨论蜂窝取证、网络数据、蓝牙和Wi-Fi artifacts以及浏览历史。

第8章，电子邮件和消息取证，描述了不同的电子邮件客户端和消息应用程序以及如何分析其数据。

第9章，照片、视频和音频取证，深入探讨多媒体取证。

第10章，分析第三方应用，介绍第三方应用程序。你将学习如何分析任何类型的应用程序以及如何快速定位最受欢迎的iOS应用的artifacts。

第11章，锁定设备、iTunes备份和云取证，讨论更高级的主题，例如处理锁定设备以及从iCloud提取取证数据。

第12章，撰写取证报告和构建时间线，将前几章获得的所有知识汇集起来，通过教你如何制作全面的时间线报告。

# 如何充分利用本书

本书旨在让你可以使用任何类型的操作系统，因此大多数示例都可以通过使用Windows、macOS或Linux来复制；然而，需要注意的是，一些商业取证工具仅在Windows上可用。

| 书中涵盖的软件 | 操作系统要求 |
|---|---|
| Cellebrite UFED | Windows |
| Cellebrite Physical Analyzer | Windows（强烈建议至少16 GB RAM） |
| Magnet AXIOM | Windows |
| Elcomsoft iOS Forensic Toolkit | Windows, macOS |
| DB Browser for SQLite | Windows, macOS, Linux |
