# Analyzing the address book

Before we delve into the call history database, it's useful to introduce the AddressBook.sqlite database, which contains the names and details of the contacts stored on the device. The database is located at /private/var/mobile/Library/AddressBook/ and contains two tables of interest — ABPerson and ABMultiValue. The first contains the contact's name and additional metadata that is used by the device, while the second table stores the actual data, such as phone numbers and email addresses. The two tables are connected through a one-to-many relationship.
