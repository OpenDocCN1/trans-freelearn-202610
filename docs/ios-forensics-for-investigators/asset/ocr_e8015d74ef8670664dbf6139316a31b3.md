```
SELECT p.First AS "First Name",
       p.Last AS "Last Name",
       GROUP_CONCAT(c.value) AS "Contacts"
FROM   ABPerson AS p
       LEFT JOIN ABMultiValue AS c
             ON c.record_id = p.rowid
GROUP  BY p.rowid,
          p.first;
```

First, we must select the columns that are relevant to the first name and last name; then, we must use the GROUP_CONCAT SQL function to aggregate all the contact data (phone numbers, emails, and so on) into one column, Contacts. Then, we must use a JOIN statement to establish a relationship between the ABPerson and ABMultiValue tables.
