# Accessing iCloud data

Access to iCloud backups and synced data can be provided to law enforcement by Apple through the course of legal requests. As Apple holds the user's **encryption keys**, they can decrypt most of a user's iCloud data, except for sensitive data, which is encrypted with end-to-end encryption.

This solution, however, has several drawbacks:

+   - Processing law enforcement and government requests is a very slow process due to the large volumes of data requested.
+   - The data that is returned by Apple is incomplete, as it doesn't include sensitive artifacts, such as Apple card transactions, the keychain, messages, and Safari history.

There are other options that allow the investigator to pull the data directly from iCloud, but these requests will have to be authorized by Apple servers by providing some sort of **authentication credentials**.
