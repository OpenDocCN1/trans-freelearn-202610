## 前言

量化金融是一个高度复杂的跨学科领域，涵盖数学、金融和信息技术。要成功驾驭它，需要来自多个来源的专业知识，例如金融衍生品、随机微积分和蒙特卡洛模拟。关键的是，它还需要将理论有效转化为实践的动手能力。

在《高级量化金融与 C++》中，我们为您提供了这个激动人心领域的导览。解释了用于定价金融衍生品的关键数学模型以及用于求解它们的主要数值模型。特别是，讨论了股权、货币、利率和信用衍生品。本书还逐步介绍了如何在 C++ 中实现这些模型。提供了多个完整可运行的示例，读者可以立即测试，以支持和补充他们的学习。

## 本书内容

- 第 1 章，什么是量化金融？，简要介绍量化金融，将主题限定在使用 C++ 进行期权定价，并描述本书的结构。
- 第 2 章，数学模型，总结了现代金融市场中用于定价衍生品的基本模型。
- 第 3 章，数值方法，回顾了用于求解第 2 章“数学模型”中描述的数学模型的三大数值方法族。
- 第 4 章，C++ 中的股权衍生品，演示了使用 C++ 在基本合约（欧式看涨/看跌期权）和高级合约（多资产期权）中对股权衍生品进行具体定价。
- 第 5 章，使用 C++ 的外汇衍生品，说明了使用 C++ 在基本合约（连续障碍）和高级合约（到期障碍）中对外汇衍生品进行定价。
- 第 6 章，使用 C++ 的利率衍生品，展示了使用 C++ 在基本合约和高级利率互换（IRS）中对利率衍生品进行定价。
- 第 7 章，使用 C++ 的信用衍生品，演示了使用 C++ 在基本合约（默顿模型）和高级合约（信用违约互换 (CDS)）中对信用衍生品进行具体定价。
- 附录 A，用于期权定价的 C++ 数值库，简要介绍了可用于期权定价的各种数值库。
- 附录 B，参考文献，列出了本书各章中使用的所有书目参考文献。

## 本书所需

为了实现本书中描述的定价算法，您需要一些 C++ 基础知识以及您选择的集成开发环境 (IDE)。我使用的是 Code::Blocks，这是一个免费的 C、C++ 和 Fortran IDE，具有高度可扩展性和完全可配置性。您可以从 http://www.codeblocks.org/ 下载它。您还需要一个 C++ 编译器。我使用的是 MinGW，它是 GNU 编译器集合 (GCC) 的一部分，包括 C、C++、ADA 和 Fortran 编译器。此编译器可以从 http://www.mingw.org/ 下载。
