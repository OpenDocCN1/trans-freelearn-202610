Equity Basket option on the maximum of two assets. Counterparties are A and B. Underlying is Barclays stock and Rolls Royce stock. At t=0, A pays B a premium. At maturity (T=1 year), A will receive from B the payoff H: $H(S1_r, S2_r) = max(S1_r, S2_r)$

The underlyings, being a stocks, can be described using GBM process each: $dS1 = rS1dt + \sigma_1 dW_1$ $dS2 = rS2dt + \sigma_2 dW_2$

Use Monte Carlo Simulation as a method for the computation of the value of the discounted expected payoff. $\pi = exp(-rT) * E^Q[H(S1_r, S2_r)]$
