

衍生品合约的一个关键特征在于，其未来现金流是概率性的，而非确定性的。衍生品合约中的未来现金流取决于某些未来事件。这就是衍生品也被称为**或有要求**的原因。这一特征使得这类合约难以定价。

以下是最常见的金融衍生品类型：

- 期货
- 远期合约
- 期权
- 互换

期货和远期合约是双方之间的金融合约。一方同意在某个预定日期（到期日）以某个预定价格（交割价）从另一方购买标的资产。例如，一份对一盎司白银的为期一个月的远期合约。标的资产即为一盎司白银的价格。在开始时（今天，t=0）不会发生现金流交换，而仅在到期时（t=T）发生。这里 t 表示变量时间。远期合约由双方私下协商（即场外交易（OTC）），而期货则在交易所交易。

期权是双方之间的金融合约。一方（称为期权的**持有人**）向另一方（称为期权的**卖方**）支付权利金，以获得购买特定资产（标的资产）的权利，但无义务，在未来某个特定日期（到期日）以特定价格（行权价）购买。此类合约称为**欧式看涨期权**合约。

### 示例 1

考虑一份针对标准普尔 500 指数（S&P 500 index）的一个月看涨合约。在此情况下，标的资产为标准普尔 500 指数的价值。在开始时（今天，t=0）和到期时（t=T）都会发生现金流。在开始时（t=0）支付权利金，而在到期时（t=T），期权持有人将根据到期时标的资产的价值 S(T) 在以下两种可能情景中选择其一：

- 情景 A：行使其权利，以 K 购买标的资产
- 情景 B：如果到期时标的资产的价值低于行权价，即 S(T)<K，则不采取任何行动

如果到期时标的资产的价值高于行权价，即 S(T)>K，期权持有人将选择情景 A。这将确保其获得 S(T)-K 的利润。如果到期时标的资产的价值低于行权价，即 S(T)<K，期权持有人将选择情景 B。这将确保其将损失限制在零。

### 示例 2

利率互换（Interest Rate Swap, IRS）是双方 A 和 B 之间的金融合约，双方同意在给定时期（合约存续期）内以固定间隔交换（现金）流。通常，从 A 到 B 的现金流与固定利率挂钩，而从 B 到 A 的现金流与浮动利率挂钩。固定现金流组称为固定腿，浮动现金流组称为浮动腿。现金流在合约存续期（从开始时间 $t=0$ 到到期时间 $t=T$）内以固定间隔发生。例如，一份固定对浮动 IRS，每三个月支付约定名义本金 $N$ 上 5% 的利率，并每三个月收到约定名义本金 $N$ 上的 EURIBOR3M。

### 示例 3

股票指数期货合约也涉及在合约到期时支付的单笔未来现金流（交割价）。然而，在这种情况下，收益是不确定的，因为我从该操作中获得的利润取决于到期时标的资产的价值。

如果标的资产价格高于交割价，则我获得的收益（由函数 $H$ 表示）为正（表示利润），对应于到期时标的资产价值 $S(T)$ 与交割价 $K$ 之间的差额。如果标的资产价格低于交割价，则我获得的收益为负（表示损失），对应于交割价 $K$ 与到期时标的资产价值 $S(T)$ 之间的差额。这一特征可总结为以下收益公式：

```
H(S(T)) = S(T) - K
```

这里，$H(S(T))$ 是到期时的收益，是 $S(T)$ 的函数。金融衍生品对现代金融市场至关重要。根据**国际清算银行（Bank of International Settlements, BIS）**截至 2012 年 12 月的数据，全球场外交易衍生品合约未平仓金额为：外汇衍生品 67,358 亿美元、利率衍生品 489,703 亿美元、股票挂钩衍生品 6,251 亿美元、商品衍生品 2,587 亿美元、信用违约互换 25,069 亿美元。更多信息，请参见 http://www.bis.org/statistics/dt1920a.pdf。

## 学科 2 – 数学

我们需要数学模型来捕捉标的资产的未来演变以及在金融衍生品中遇到的或有现金流的概率性质。

关于或有现金流，可以用我们考虑的特定衍生品的收益函数 H(S(T)) 来表示。由于 S(T) 是随机变量，H(S(T)) 的值应计算为期望 E[H(S(T))]。为了计算这一期望，我们需要能够预测或模拟标的资产 S(T) 未来行为的技术，从而能够计算出 S_T 的值，并最终能够计算出收益的均值 E[H(S(T))]。

关于标的资产的行为，通常使用**随机微分方程（Stochastic Differential Equations, SDEs）**，如**几何布朗运动（Geometric Brownian Motion, GBM）**来形式化，如下所示：

```
dS = \mu S dt + \sigma S dW
```

公式 2

前一个方程基本上表明，股价变化（dS）可以理解为两种效应之和——确定性效应（等式右侧第一项）和随机项（等式右侧第二项）。参数 $\mu$ 称为漂移，参数 $\sigma$ 称为波动率。S 是股价，dt 是微小时间间隔，dW 是维纳过程的增量。

该模型是描述股票、商品和外汇行为最常见的模型。还存在其他模型，例如跳跃模型、局部波动率模型和随机波动率模型，它们增强了对标的资产动态的描述。

关于数值方法，这些对应于将数学模型（通常是连续时间）中描述的正式表达式转换为可用于计算的近似表示（通常是离散时间）的方式。这意味着描述某些股票指数（如 FTSE 100）未来演变的 SDE 被更改为描述离散间隔上的演变。可以使用欧拉近似计算 SDE 的近似表示，如下所示：

```
S_{t+1} - S_t = \mu S_t \Delta t + \sigma S_t \Delta W
```

公式 3

前一个方程需要以迭代方式在当前到合约到期之间的每个时间间隔上求解。如果这些时间间隔为天，且合约从现在起 30 天到期，那么我们先根据今天的价格计算明天的价格。然后根据明天的价格计算后天的价格，以此类推。为了定价衍生品，我们需要计算到期时的预期收益 E[H(S_T)]，然后将其贴现至现值。这样，我们就可以借助以下方程计算与欧式期权合约相关的公平权利金 π：

```
π = exp(−rT) × E[H(S_T)] = exp(−rT) × E[max(S_T − K, 0)]
```

### (C++ 编程)

C++ 在衍生品定价中的作用是什么？其作用是根本性的。它使我们能够实现解决定价问题所需的实际计算。使用上述技术描述标的资产的动态，我们需要模拟许多描述其演变的潜在未来场景。假设我们需要定价一份一年期的 EUR/USD 汇率期货合约。我们需要模拟未来一年每天的 EUR/USD 演变（使用公式 3）。然后我们可以计算到期时的收益（使用公式 1）。然而，为了计算预期收益（使用公式 4），我们需要通过称为蒙特卡洛模拟的技术模拟数千种这样的可能演变。完成此过程所需的一组步骤称为算法。为了定价衍生品，我们需要构建此类算法，然后在 C++ 等高级编程语言中实现它。当然，C++ 不是唯一的选择，其他语言包括 Java、VBA、C#、Mathworks Matlab 和 Wolfram Mathematica。但是，C++ 是行业标准，因为它灵活、快速且可移植。此外，多年来，已创建了几个数值库来在 C++ 中进行复杂的数值计算。最后，C++ 是一种强大的现代面向对象语言。

在清晰度和效率之间取得平衡一直很困难。我们的目标是制作自包含（不过于面向对象）且自解释的计算机程序。更高级的实现当然是可能的，特别是在企业环境中的更大规模金融定价库的上下文中。在本书中，所有程序均使用最新的 C++11 标准，配合 Code::Blocks (http://www.codeblocks.org) 和 MinGW (http://www.mingw.org) 实现。
