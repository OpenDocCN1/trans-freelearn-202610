**1 Bankruptcy**

The firm's assets (V) are the sum of the firm's equity (E) and the firm's debt (D). The firm defaults if the value of the assets V(T) is less than the debt D it has to pay at maturity. Merton showed that the firm's equity is a European call option with payoff:

\( H(V_T) = max(V_T - D, 0) \)

**2**

According to Merton's model the **firm** can be described using Geometric Brownian Motion (GBM):

\( dV = rVdt + \sigma VdW \)

**3**

Use **Monte Carlo Simulation** as a method for the computation of the value of the firm's equity as the discounted expected payoff.

\( \pi = exp(-rT) \times E^{\mathbb{Q}}[H(V_T)] \)
