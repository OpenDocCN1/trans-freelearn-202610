

## GSL 库

许可证：免费/GNU。

网站：www.gnu.org/s/gsl/。

GNU 科学库（GSL）是面向 C 和 C++ 的数值库。该库提供大量数学数值例程，包括随机数生成器、特殊函数和最小二乘拟合。总计超过 1000 个函数。该库涵盖的学科领域示例包括复数、多项式根、特殊函数、向量与矩阵、排列、线性代数、特征系统、快速傅里叶变换、数值积分、随机数、准随机序列、统计学、直方图和蒙特卡洛积分。
