# Testing Custom Workflows

Once you have created, validated, installed, and made the custom workflow template available in Web Publisher, you can test it by sending content in a workflow instance created from the custom workflow template.

Figure 20.1 depicts the sequence of activities in the custom workflow we created in the previous chapter. This should serve as a good help while testing the workflow steps.
