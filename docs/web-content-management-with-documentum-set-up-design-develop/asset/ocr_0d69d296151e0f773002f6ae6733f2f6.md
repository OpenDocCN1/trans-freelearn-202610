You can clearly see that the authors property has been automatically populated with the values that the user had saved in the Author Name fields in the template (refer to figure 18.12).
Additionally, by default, Documentum fills out the name of the content creator user in the authors attribute for all content that is created. Since we had created this content as the documentum user, the authors attribute contains this value as well.
