2. After Tomcat 4.1.30 has been installed on the application server host, the following system environment variables need to be set:

+   - JAVA_HOME: This is the Java installation directory, for example, C:\j2sdk1.4.2
+   - CATALINA_HOME: This is the Tomcat installation directory, for example, C:\Tomcat 4.1

3. Startup Tomcat 4.1.30 to ensure that it has been installed correctly before proceeding with DA installation.

Run the batch file startup.bat located under %CATALINA_HOME%\bin.

Once Tomcat has started up, open the default Tomcat page by invoking the following URL from your web browser: http://<app server host>:<port>/index.jsp.
