The structure of an empty FolderMap.xml file is shown below:

```
<folder_map>
  <rule>
    <attr_list>
      <attr>
        <name></name>
        <value></value>
      </attr>
    </attr_list>
    <path_list>
      <path></path>
    </path_list>
  </rule>
  <rule>
    <attr_list>
      <attr>
        <name></name>
        <value></value>
      </attr>
    </attr_list>
    <path_list>
      <path></path>
    </path_list>
  </rule>
</folder_map>
```
