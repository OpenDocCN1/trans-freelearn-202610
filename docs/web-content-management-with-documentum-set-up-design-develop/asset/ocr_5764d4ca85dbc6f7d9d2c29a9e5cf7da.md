6. The Transition tab (refer to figure 19.21) allows you to specify which activities in the workflow come next to this particular activity. If there are multiple connected activities (output flows) from this activity, you can:

+   - Designate the system to select all connected activities when this activity finishes.
+   - Let the performer of the activity choose at run time how many next activities can be selected after this activity completes.
+   - Specify certain conditions based on which the next activities can be selected when this activity finishes.
