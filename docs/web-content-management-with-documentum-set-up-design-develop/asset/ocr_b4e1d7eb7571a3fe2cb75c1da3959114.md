This DQL links the document object TestDocumentCreated_via_DQL with a cabinet Testing_API_DQL in the Docbase. However, as a prerequisite create a custom cabinet, say Testing_API_DQL, in Web Publisher before issuing this DQL query.

If you specify an incorrect cabinet/folder path in the link clause or if you specify a cabinet/folder name (say abcdef) that does not exist in the Docbase, the server throws the following error on running the above DQL query:

Error occurred during query execution :[DM_QUERY_E_UP_BAD_FOLDER]error: "You have specified an invalid folder path, /abcdef, in your LINK or MOVE TO clause."
