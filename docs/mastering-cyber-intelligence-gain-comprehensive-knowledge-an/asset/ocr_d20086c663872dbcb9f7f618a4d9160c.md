Figure 4.1 – STIX v1 architecture

The architecture illustrated in Figure 4.1 presents eight interrelated elements that define the structure of the STIX standard (https://bit.ly/2MgIJ88). It is based on the popular STIX v1 standard. The elements represent the core concept of cyber attacks. STIX provides more details on each component, which we will not explore in detail in this chapter. Refer to the preceding link to understand each element's parameters. STIX v1 SDOs are explained in the following points:

+   - **Observables:** *Observables* are simply what a CTI analyst sees. They include basic parameters such as filenames, file extensions, running services, service requests, registry keys, and more. To learn more about STIX observables, refer to the **Cyber Observable eXpression (CybOX)** standard (http://cyboxproject.github.io/).
