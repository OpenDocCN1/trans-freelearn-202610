# Part 2: Modern Jakarta EE

在本部分，我们将向您展示如何现代化 Cargo Tracker 应用。掌握必要的知识后，您将学习如何将这些技术应用于需要迁移的其他应用。我们涵盖了您可以用来从 Java EE 迁移到 Jakarta EE 的不同工具以及这些工具的工作方式。借助使用 Jakarta EE 10 的应用，我们将向您展示如何对其进行现代化并使用最佳实践使应用成为云原生，同时保持强大的测试覆盖率。

本部分包含以下章节：

- Chapter 3, Moving from Java EE to Jakarta EE
- Chapter 4, Modernizing Your Application with the Latest Features
- Chapter 5, Making Your Application Testable
