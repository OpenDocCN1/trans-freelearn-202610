# Building a container

The next step is to tell Docker Engine to build the container we just specified using the Dockerfile. To create the container, we will use the Docker client, which is a command-line interface that lets you interact with the Docker daemon and manage containers. Using the terminal, navigate to the root of the Cargo Tracker application where you just created the Dockerfile. When inside the Cargo Tracker directory, perform the following command:

```
docker build -t cargo-tracker .
```
