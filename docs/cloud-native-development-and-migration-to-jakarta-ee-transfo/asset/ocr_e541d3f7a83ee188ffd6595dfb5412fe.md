Once the plugin is installed, you will have a new tab in your UI labeled **Migration Toolkit for Applications**. Follow these steps:

+   1. Click on the tab.
+   
+   There should be a default configuration entry in the list.
+   
+   If not, right-click and choose **New Configuration**.
+   
+   Your screen should now look like this:

![](bbox=[0.142, 0.252, 0.825, 0.704])

Figure 3.5 – Configuration entry in the MTA plugin

+   2. Double-click the configuration.
+   3. Enter the information as shown in the following figure (note that we selected **Windup Configuration** at the bottom).
+   4. Make sure you enter the location where you installed the command-line tools for MTA.
+   5. Close the configuration.
