You can verify that the deployment created a pod by entering this command:

```
kubectl get pods
```

A pod with the same name as the deployment plus a unique suffix is created. At the same time, a service was created, which can be viewed by entering the following

```

```

The deployment is not exposed to your computer yet. For this, we need to expose it via the following:

```
kubectl port-forward service/greeting 8080:8080
```

This is best done in a new terminal window, as the port-forwarding will block the terminal from further input. We tell Kubernetes here that traffic arriving on port 8080 should be forwarded to the service named greeting on port 8080.
