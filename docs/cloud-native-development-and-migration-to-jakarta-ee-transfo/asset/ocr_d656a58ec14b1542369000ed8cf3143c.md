# Jakarta EE 10 Core Profile

This specification is new in MicroProfile 6.0. Before this, the core MicroProfile specification included Jakarta RESTful Web Services, Jakarta JSON Binding, Jakarta JSON Processing, Jakarta Dependency Injection, and Jakarta Annotations.

In MicroProfile 6.0, it was decided to add these specifications into an umbrella specification by adopting the Core Profile from Jakarta EE. This new core specification is lightweight yet powerful enough for both microservices and edge computing.
