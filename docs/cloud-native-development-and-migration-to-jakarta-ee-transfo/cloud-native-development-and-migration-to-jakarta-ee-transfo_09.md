# 第三部分：拥抱云

在本部分中，你将深入探讨如何将 Cargo Tracker 应用进行改造，使其无缝拥抱云。借助现在运行在 Jakarta 10 上的应用，你将学习如何创建 Docker 容器，并在 Kubernetes 集群上运行它。随后，你将了解云原生的本质，以及如何在 Azure 云环境中部署应用。本部分最后有一章关于 MicroProfile 的内容，因为它有助于 Jakarta EE 真正实现云原生。

本部分包含以下章节：

- 第 6 章：容器与 Docker 简介
- 第 7 章：认识 Kubernetes
- 第 8 章：什么是云原生
- 第 9 章：在云中部署 Jakarta EE 应用
- 第 10 章：MicroProfile 简介
- 附录 A：Java EE 到 Jakarta EE 名称
- 附录 B：即服务
