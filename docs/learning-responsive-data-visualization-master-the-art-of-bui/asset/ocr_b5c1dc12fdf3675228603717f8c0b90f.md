The cross-browser compatibility of SMIL Animations

While the lack of SMIL support in Microsoft products makes it a bad choice for many projects, there is a worst message hidden in the figure. In Chrome, SMIL animations are marked as deprecated since version 45, which means that they can be removed in any of the following versions. The decision of the Chrome team to stop supporting SMIL animations was to establish and strengthen JavaScript and CSS as a web standard for DOM animations. Therefore, developers should also favor web standards, such as CSS and JavaScript, when it comes to animations and transitions.

# # Animating HTML using CSS
