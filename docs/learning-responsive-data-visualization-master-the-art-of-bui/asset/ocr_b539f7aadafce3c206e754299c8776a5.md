# Projecting a sphere on a flat map

Now, we know how we can precisely identify any point on the surface of the world. But when it comes to visualizing these points in a flat map, there comes another problem. If we want to display a 2D representation of the world (or a sector of it), we have to project the 3D sphere on a 2D plane. The good news is that this can be done; however, the bad news is that this is not possible without distorting the representation.

When I was in primary school, I was always impressed by the huge size of Antarctica in my school atlas, which looked similar to the following figure. However, my imagination of the big continent was rectified a few years later when I first heard about geographical projections and how the 3D world can be mapped into a 2D page in a book:
