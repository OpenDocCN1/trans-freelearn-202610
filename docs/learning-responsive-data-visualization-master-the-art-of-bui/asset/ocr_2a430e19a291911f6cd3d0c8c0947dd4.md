Using none aspect ratio can, for example, scale the image into the viewport without preserving the aspect ratio as shown in the following figure:

![](bbox=[0.13, 0.1, 0.91, 0.34])

The chart scaled using the preserveAspectRatio none

Per default, browsers use the xMidYMid setting to scale the chart to the maximal centered dimension by possibly preserving the aspect ratio of the original chart:

![](bbox=[0.21, 0.44, 0.83, 0.78])

The chart scaled using preserveAspectRatio xMidYMid (default)
