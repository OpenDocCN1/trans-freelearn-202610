## 前言

数据可视化是理解复杂信息和数据的最佳方式。
人类大脑能够轻松感知视觉信息；它可以建立联系，并且相比于没有可视化的情况，更容易理解完整的过程。

每当用户通过查看数据可视化而轻松理解复杂系统，而不是阅读解释性文本和原始数据时，我都会对来自用户的正面反馈感到欣喜。借助 Web 和现代浏览器的力量，我可以将这些可视化分享给每个人，并使其具有交互性和动画效果。

为了实现跨浏览器的交互式可视化，我不愿在性能、调试、质量和交互性方面做任何妥协，这引导我选择了 SVG。在决定使用 SVG 后，我寻找一个用于 SVG 转换的框架，该框架既能提供对其所有底层标准的原始访问，又能提供一组丰富的可视化功能 — d3.js 库提供了所有这些功能。

D3.js 是一个可视化工具包，它便于生成和操作基于 Web 的矢量图形，并完全访问底层 SVG 标准。此外，动画和交互式可视化改变了用户对 Web 应用程序的感知方式，D3.js 提供了开箱即用的一切所需，让可视化具有交互性。

虽然在过去几年中这一直有效，但我意识到用户越来越多地使用移动设备访问可视化，主要是通过智能手机和平板电脑。在大多数平板电脑上，可视化效果看起来不错，但交互功能不再起作用。智能手机用户在尝试缩放浏览器时也遇到了这种情况，但它不知何故干扰了可视化的缩放，反而随机切换交互功能。对我来说，这是解决问题所需的信号。

随着响应式 Web 设计的兴起，已经有很多创建适应用户设备、屏幕尺寸和分辨率的跨浏览器和跨平台应用程序的想法。除此之外，现代浏览器已经提供了稳健的 CSS 和 JavaScript 功能，以实现各种 Web 应用程序的响应式设计。

对我而言，唯一合乎逻辑的步骤是组合丰富的工具来创建响应式应用程序，并将相同的理念引入数据可视化。我希望我的可视化能够适应用户的设备、屏幕尺寸和分辨率，同时为鼠标和触摸手势提供跨平台交互性。在本书中，我将与你分享我在响应式数据可视化方面的知识、经验和最佳实践。

## 本书内容概览

第 1 章，使用响应式设计、Bootstrap 和 D3.js 入门，将带你掌握当今用于创建响应式应用程序的概念、技术和框架。

第 2 章，使用 D3.js 和 SVG 创建柱状图，将帮助你入门 `D3.js` 及其概念。本章结束时，你将学会如何绘制点、形状和简单的柱状图。

第 3 章，加载、筛选和分组数据，将指导你从现实世界的数据中获取最大信息。

第 4 章，使用 Bootstrap 和媒体查询使图表具有响应性，将介绍使可视化具有响应性并将其适应用户设备所需的所有步骤。

第 5 章，构建响应式交互，将教你如何为可视化添加真正的响应式交互，这也使它们在用户设备上非常好用。

第 6 章，设计过渡和动画，将教你如何通过添加精美的过渡或自定义动画，使可视化看起来更具吸引力。

第 7 章，使用 GeoJSON 创建地图和制图可视化，将帮助你入门地理数据处理，然后在制图可视化中可视化这些数据。

第 8 章，测试响应式可视化，将向你展示如何手动和自动测试响应式可视化，并涵盖单元测试和端到端测试。

第 9 章，解决跨浏览器问题，将帮助你在处理响应式可视化的跨浏览器兼容性问题时避免最常见的陷阱。

## 本书所需内容

开始使用所需的第一件事是 Web 浏览器和文本编辑器，例如 Sublime Text 或 Atom。然后，你需要安装 node.js（http://nodejs.org/）– 它已包含 npm 包管理器 – 以及 bower 包管理器（http://bower.io/）。我将在相应章节中指导你安装所需的软件包。

对于需要从本地硬盘加载数据的示例，我建议你安装 `http-server` 模块（https://www.npmjs.com/package/http-server），以便从本地 Web 服务器运行所有示例。仅在安装工具和库时需要 Internet 连接，运行示例时不需要。

## 本书适用人群

本书面向数据科学家、开发人员和有动力的初学者，旨在使用矢量图形实现自定义响应式数据可视化。无论你是已了解浏览器中 SVG 和矢量图形的基础知识，还是从未使用过任何可视化库，你都能掌握 D3 的数据驱动技术。无论哪种情况，本书都能让你尽快上手，并且如果你已经使用过 D3，也会向你提出挑战。
