Next, we modify all our scales to work on a range of [0, 100] and subtract padding from both sides:

```
var xScale = d3.scale.ordinal()
    .domain(flatData.map(xKey))
    .rangeBands([padding, 100 - 2*padding]);
```

```
var yScale = d3.scale.linear()
    .domain([0, d3.max(flatData, yKey)])
    .range([100 - 2*padding, padding]);
```

Finally, we can draw the chart as before, but simply adding percentage signs (%) to the end of the attributes to indicate the use of percentage units:

```
$$bars
    .attr('x', function(d) { return (xScale(d.x) + i*barWidth) + '%'; })
    .attr('y', function(d) { return yScale(d.y) + '%'; })
    .attr('height', function(d) { return (yScale(0) - yScale(d.y)) + '%'; })
    .attr('width', barWidth + '%')
    .attr('fill', colors(data.key));
```
