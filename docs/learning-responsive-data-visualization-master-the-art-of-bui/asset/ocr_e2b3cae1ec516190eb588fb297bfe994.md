In the preceding code, we animate the x attribute of the rectangle by placing an animate tag inside the rect element and defining the attribute that should be animated via the attributeName attribute. You can find an animate demo of this example in the code folder.

By defining a values attribute instead of the from and to attributes, SMIL can also interpolate strings properly. This is very useful for animating the path element of SVG paths where the control points are encoded as strings. Using this technique, we can also do shape animations, as shown in the following figure:

![](bbox=[0.12, 0.24, 0.84, 0.51])

A shape animation
