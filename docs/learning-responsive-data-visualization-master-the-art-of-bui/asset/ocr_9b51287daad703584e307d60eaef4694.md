We see in the preceding dataset that the information is nested in the count property of the inner object. We can use the array.map(mapFn) method with a mapping function called mapFn to return elements for each element of the new array representation:

```
var mapped = data.map(function(d, i){
 return {
 x: d.x, y: d.inner.count
 }
 });
```

The mapped array now contains objects with the x and y properties that you can use to generate our visualizations, as you learned in the previous chapter. Although, this looks very trivial, many people have problems applying the map function properly.
