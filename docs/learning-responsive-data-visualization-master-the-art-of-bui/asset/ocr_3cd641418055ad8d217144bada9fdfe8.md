# # Prevent Strokes from Scaling

We can add simple options to prevent strokes from scaling through the transformations caused by the viewBox attribute. To do so, we have to add the following CSS snippet to the chart:

```
.chart path, .chart line, .chart text {
    vector-effect: non-scaling-stroke;
}
```

The vector-effect property (that only allows the none, inherit, and non-scaling-stroke values) is the attribute that can achieve exactly this. However, I don't really understand why there are no more supported values to, for example, prevent the scaling of fonts, and so on.
