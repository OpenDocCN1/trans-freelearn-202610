# # Changing Device Modes in a Chrome desktop browser

The fastest and most convenient way of quickly testing an application with a different screen resolution is to use the Device Mode setting in the Chrome Developer Tools. You can open it by first opening the Developer Tools (pressing F12) and then clicking on the tiny mobile phone icon on the top left-hand side. In the following figure, you can see the Developer Tools with a little mobile phone in blue, which means that Device Mode is enabled:
