## Learning Responsive Data Visualization

![](img/72559bd4713b2b89631dcca187d7e2db_263_0.png)

Using D3.js and Responsive Design principles, you will not just be able to implement visualizations that look and feel awesome across all devices and screen resolutions, but you will also boost your productivity and reduce development time by making use of Bootstrap—the most popular framework for developing responsive web applications.

## What you will learn from this book

- Get familiar with Responsive Design for data visualizations
- Understand the main concepts of D3.js to create interactive visualizations
- Unleash the power of Bootstrap to create stunning and responsive visualizations for all screen resolutions

This book teaches the basics of scalable vector graphics (SVG), D3.js, and Bootstrap while focusing on Responsive Design as well as mobile-first visualizations; the reader will start by discovering Bootstrap and learning how it can be used for creating responsive applications, and will then implement a basic bar chart in D3.js. You will learn about loading, parsing, and filtering data in JavaScript and then dive into creating a responsive visualization by using Media Queries, responsive interactions for mobile and desktop devices, and transitions to bring the visualization to life. In the following chapters, we build a fully responsive interactive map to display geographic data using GeoJSON and set up integration testing with Protractor to test the application across real devices using a mobile API gateway such as Browserstack.

- Implement touch and mouse interactions for mobile-first applications

You will finish the journey by discovering the caveats of mobile-first applications and learning how to master cross-browser complications.

- Design transitions and animations that impress in portrait and landscape

## Who this book is written for

This book is for web developers and data science professionals who want to make their visualizations work for smaller screen sizes. Some basic knowledge of JavaScript and data visualization is expected.

- Build a Responsive world map using GeoJSON and D3.js
