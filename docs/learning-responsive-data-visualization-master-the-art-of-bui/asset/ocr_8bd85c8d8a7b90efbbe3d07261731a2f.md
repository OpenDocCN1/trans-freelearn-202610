# Which data can be displayed on a map?

With bar charts, line charts, scatter plots, and pie charts, we can display all kinds of 1D, 2D, and 3D data. The dimensions can be encoded as numeric values, time, categorical values, and more and can be represented as dimensions on axis, the size of the data point, and colors. However, when dealing with geographic visualizations, we will mostly deal with 2D data where one dimension represents the location on the map and the remaining dimension represents a value (could be either numerical or ordinal) as a color according to a certain color scale.

There are multiple ways to encode locations:

+   - ID values can represent continents, countries, states, cities, and so on
+   - Latitude and longitude coordinates can represent a point on the map
+   - The coordinates of a polygon can represent an area on the map
