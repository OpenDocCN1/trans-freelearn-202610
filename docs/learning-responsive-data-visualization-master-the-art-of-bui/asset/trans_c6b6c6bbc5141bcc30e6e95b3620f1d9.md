## 关于作者

**Christoph Körner** 是初创公司 GESIM 的首席技术官兼首席开发人员，是一位充满热情的软件工程师、Web 爱好者，也是 JavaScript 社区的活跃成员，拥有超过 5 年开发面向客户的 Web 应用程序的经验。他是 *使用 D3 和 AngularJS 进行数据可视化* 的作者，目前正在维也纳技术学院攻读视觉计算硕士学位。

我要感谢我亲密的朋友 Firat Özdemir 和 Vidor Kanalas，感谢他们持续的支持与帮助，也要感谢我的老板兼同事 Dietmar Wiegand，感谢他支持我的所有想法和梦想。我也要感谢我的女朋友 Laura Andrea Rojas Padilla，她一直激励、鼓舞和支持我，以及 Packt Publishing 的整个团队，感谢他们在过去 6 个月里相信我并指导我。

## 关于审稿人

Sébastien Fragnaud 是一名在 Metamarkets 工作的前端工程师。他从精美的模型中创建出精美的 UI。在此之前，他曾为几家不同的公司工作，但他的关注点始终如一：以有意义的方式呈现数据。

他非常喜爱可复用代码，是 n3-charts 的作者，这是一个 JavaScript 库，为在 AngularJS 应用程序中操作图表提供了一种简便的方法。
