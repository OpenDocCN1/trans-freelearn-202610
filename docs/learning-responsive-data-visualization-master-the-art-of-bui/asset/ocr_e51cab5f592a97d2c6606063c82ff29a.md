The idea is simple, as shown in the following figure, all pointing input devices should not be treated separately (by separate events) but instead be combined into a single input device called Pointer. Developers would then implement support for pointer events and hence automatically provide a great UI for all the types of pointing devices.

![](bbox=[0.335, 0.17, 0.7, 0.45])

Pointer events (source. https:// www.w3.org/TR/pointerevents/)
