## 学习响应式数据可视化

![](img/72559bd4713b2b89631dcca187d7e2db_263_0.png)

使用 D3.js 和响应式设计原则，您不仅能够实现在所有设备和屏幕分辨率下看起来和感觉都很棒的可视化，还能通过使用 Bootstrap（开发响应式 Web 应用程序最流行的框架）来提高生产力并缩短开发时间。

## 从本书中您将学到

- 熟悉数据可视化的响应式设计
- 了解 D3.js 的主要概念以创建交互式可视化
- 发挥 Bootstrap 的强大功能，为所有屏幕分辨率创建惊艳且响应式的可视化

本书教授可缩放矢量图形 (SVG)、D3.js 和 Bootstrap 的基础知识，同时侧重于响应式设计和移动优先可视化；读者将首先了解 Bootstrap 并学习如何将其用于创建响应式应用程序，然后在 D3.js 中实现一个基本柱状图。您将学习在 JavaScript 中加载、解析和过滤数据，然后深入使用媒体查询、适用于移动端和桌面端设备的响应式交互以及过渡来创建响应式可视化，使可视化栩栩如生。在接下来的章节中，我们将使用 GeoJSON 构建一个完全响应式的交互式地图来显示地理数据，并使用 Protractor 设置集成测试，以通过 Browserstack 等移动 API 网关在真实设备上测试应用程序。

- 为移动优先应用程序实现触摸和鼠标交互

您将通过发现移动优先应用程序的注意事项并学习如何掌握跨浏览器复杂性来结束旅程。

- 设计在竖屏和横屏下都令人印象深刻的过渡和动画
